# 港股数据工具使用指南

本文档介绍如何使用独立的港股数据工具获取港股市场数据。

> **重要说明**：港股工具已重构到 `tools/hk_stock/` 目录下，通用工具重构到 `tools/common/` 目录下。原 `tools/stock_info_hk.py` 已拆分为 `tools/hk_stock/stock_info.py`（信息查询）与 `tools/hk_stock/stock_financial.py`（财务数据）两个模块。本文档已更新所有路径引用。

## 一、stock_info.py - 港股信息查询

### 功能说明

获取港股上市公司的代码、名称、实时行情等信息。本模块由原 `stock_info_hk.py` 拆分而来，包含 `--list`、`--search`、`--code`、`--hot` 功能；财务指标功能已迁移至 `stock_financial.py`。

### 使用方法

#### 1. 列出全部港股

```bash
python tools/hk_stock/stock_info.py --list
```

**输出示例**:

```json
{
  "success": true,
  "data": [
    {"code": "00001", "name": "长和", "market": "hk"},
    {"code": "00002", "name": "中电控股", "market": "hk"},
    ...
  ],
  "meta": {
    "tool": "stock_info",
    "command": "list",
    "market": "hk",
    "count": 2546,
    "timestamp": "2026-07-12T22:50:00"
  }
}
```

#### 2. 搜索港股

```bash
python tools/hk_stock/stock_info.py --search 腾讯
```

**输出示例**:

```json
{
  "success": true,
  "data": [
    {
      "code": "00700",
      "name": "腾讯控股",
      "market": "hk",
      "price": 420.5,
      "change_pct": 2.35,
      "volume": 12345678,
      ...
    }
  ],
  "meta": {
    "tool": "stock_info",
    "command": "search",
    "keyword": "腾讯",
    "count": 1
  }
}
```

#### 3. 查询单只港股

```bash
python tools/hk_stock/stock_info.py --code 00700
```

**输出字段说明**:

- `code`: 港股代码（5位数字）
- `name`: 公司名称
- `market`: 市场标识（"hk"）
- `price`: 最新价
- `change_pct`: 涨跌幅（%）
- `change`: 涨跌额
- `volume`: 成交量
- `amount`: 成交额
- `high`: 最高价
- `low`: 最低价
- `open`: 今开
- `pre_close`: 昨收

#### 4. 获取港股热度榜

```bash
python tools/hk_stock/stock_info.py --hot
```

## 二、stock_financial.py - 港股财务数据

### 功能说明

获取港股财务指标数据。本模块由原 `stock_info_hk.py` 拆分而来，包含 `--financial`、`--indicator` 功能。

### 使用方法

#### 1. 获取港股财务指标

```bash
# 获取年度财务指标（默认）
python tools/hk_stock/stock_financial.py --financial 00700

# 获取报告期财务指标
python tools/hk_stock/stock_financial.py --financial 00700 --indicator 报告期
```

**返回的关键指标字段**：

| 字段 | 含义 | 对应去劣指标 |
|------|------|-------------|
| `ROE_AVG` | 平均净资产收益率(%) | ① ROE |
| `GROSS_PROFIT_RATIO` | 毛利率(%) | 毛利率 |
| `NET_PROFIT_RATIO` | 净利率(%) | ⑥ 净利率 |
| `OCF_SALES` | 经营现金流/营业收入(%) | ⑤ 利润质量 |
| `HOLDER_PROFIT` | 归母净利润(亿元) | FCF辅助 |
| `OPERATE_INCOME` | 营业总收入(亿元) | 辅助 |
| `DEBT_ASSET_RATIO` | 资产负债率(%) | 利息覆盖辅助 |
| `CURRENT_RATIO` | 流动比率(倍) | 偿债能力 |
| `PER_NETCASH_OPERATE` | 每股经营现金流(元) | ⑤ 利润质量辅助 |
| `BPS` | 每股净资产(元) | ⑦ 股本稀释辅助 |

## 三、stock_quote.py - 港股行情数据

### 功能说明

获取港股历史K线数据，支持日/周/月线、前/后复权。

### 使用方法

#### 1. 获取最近30天数据

```bash
python tools/hk_stock/stock_quote.py --code 00700
```

#### 2. 指定日期范围

```bash
python tools/hk_stock/stock_quote.py --code 00700 --start 20260101 --end 20260710
```

#### 3. 选择复权方式

```bash
# 未复权
python tools/hk_stock/stock_quote.py --code 00700 --adjust ""

# 前复权（默认）
python tools/hk_stock/stock_quote.py --code 00700 --adjust qfq

# 后复权
python tools/hk_stock/stock_quote.py --code 00700 --adjust hfq
```

#### 4. 选择周期类型

```bash
# 日线（默认）
python tools/hk_stock/stock_quote.py --code 00700 --period daily

# 周线
python tools/hk_stock/stock_quote.py --code 00700 --period weekly

# 月线
python tools/hk_stock/stock_quote.py --code 00700 --period monthly
```

#### 5. 获取港股指数

```bash
# 恒生指数
python tools/hk_stock/stock_quote.py --index HSI

# 恒生科技指数
python tools/hk_stock/stock_quote.py --index CES100
```

## 四、stock_screen.py - 港股质量筛选

### 功能说明

对港股执行7条去劣指标筛选，快速排除不符合一流公司标准的标的。

### 7条去劣指标

| # | 指标 | 排除条件 |
|---|------|---------|
| ① | 10年平均ROE | < 8% |
| ② | 5年累计自由现金流 | 为负 |
| ③ | 利息覆盖倍数（EBIT/利息） | < 2倍 |
| ④ | 长期毛利率 | < 15% |
| ⑤ | 经营现金流/净利润（5年均值） | < 0.7 |
| ⑥ | 长期净利率 | < 5% |
| ⑦ | 5年总股本膨胀 | > 20%（非并购原因） |

### 使用方法

#### 1. 单只港股筛选

```bash
python tools/hk_stock/stock_screen.py --code 00700
```

#### 2. 多只港股筛选

```bash
python tools/hk_stock/stock_screen.py --code 00700,03690,01810
```

### 输出字段说明

**返回的指标字段**：

- `1_roe_avg`: ROE平均值（指标①）
- `2_fcf`: 自由现金流（指标②）
- `3_interest_coverage`: 利息覆盖倍数（指标③）
- `4_gross_margin_avg`: 毛利率平均值（指标④）
- `5_ocf_to_ni`: 经营现金流/净利润（指标⑤）
- `6_net_margin_avg`: 净利率平均值（指标⑥）
- `7_share_dilution`: 股本稀释比例（指标⑦）

**指标判断字段**：

- `value`: 计算值
- `pass`: 是否通过（true/false/null）
- `threshold`: 阈值
- `note`: 说明

**汇总字段**：

- `passed_count`: 通过指标数量
- `failed_count`: 失败指标数量
- `unknown_count`: 无法判断指标数量
- `overall_pass`: 整体是否通过

### 注意事项

1. **指标③和⑦数据限制**：港股财务数据通常不直接提供利息支出和股本变化，这两项指标需要从年报手动核实
2. **辅助判断**：工具会提供资产负债率、流动比率等辅助数据帮助判断
3. **数据源**：使用东方财富港股财务分析接口，网络连接可能不稳定，工具已内置重试机制

## 六、数据源说明

### stock_hk_spot()

- 来源：新浪财经
- 字段：代码、名称、最新价、涨跌幅、成交量等
- 特点：网络连接稳定、内置重试机制、数据实时
- 用途：`tools/hk_stock/stock_info.py` 获取港股列表和实时行情

### stock_hk_daily()

- 来源：新浪财经
- 参数：代码、复权方式（qfq/hfq/""）
- 特点：网络连接稳定、支持前/后复权、历史数据长
- 用途：`tools/hk_stock/stock_quote.py` 获取港股历史K线数据

### stock_hk_index_daily_sina()

- 来源：新浪财经
- 指数：HSI(恒生指数)、CES100(恒生科技)等
- 特点：历史数据长、网络连接稳定
- 用途：`tools/hk_stock/stock_quote.py` 获取港股指数数据

### stock_hk_hot_rank_em()

- 来源：东方财富
- 字段：排名、代码、名称、涨跌幅等
- 特点：数据实时、反映市场热度
- 用途：`tools/hk_stock/stock_info.py` 获取港股热度榜

### stock_financial_hk_analysis_indicator_em()

- 来源：东方财富
- 字段：ROE、毛利率、净利率、OCF_SALES等
- 特点：数据全面、覆盖近10年、支持年度/报告期
- 用途：`tools/hk_stock/stock_financial.py --financial` 获取港股财务指标

### stock_financial_hk_report_em()

- 来源：东方财富
- 参数：股票代码、报表类型（利润表/资产负债表/现金流量表）、报告期
- 字段：营业收入、净利润、资产总额、负债总额等
- 特点：数据详细、支持三大报表、覆盖近10年
- 用途：`tools/hk_stock/stock_screen.py` 获取港股财务报表数据（辅助计算自由现金流、利息覆盖等）

### 数据源对比总结

| 数据源 | 主要特点 | 适用场景 | 使用工具 |
|--------|---------|---------|---------|
| 新浪财经 | 网络稳定、数据实时、历史数据长 | 实时行情、历史K线、指数数据 | tools/hk_stock/stock_info.py, tools/hk_stock/stock_quote.py |
| 东方财富 | 数据全面、字段丰富、支持财务分析 | 热度榜、财务指标、财务报表 | tools/hk_stock/stock_info.py, tools/hk_stock/stock_financial.py, tools/hk_stock/stock_screen.py |

## 七、网络信息获取工具

港股网络信息获取提供三个搜索工具，完整的工具说明、参数详解、模块导入接口、返回字段、依赖配置、选型决策表与流程图，**请参阅 [A股工具使用指南.md](A股工具使用指南.md) 第八章~第十章**，本节仅说明港股场景的选用建议。

### 7.1 工具一览

| 工具 | 鉴权 | 协议 | 关键能力 |
|------|------|------|---------|
| `tools/common/doubao_search.py` | AK/SK | HTTP REST + 签名 | 正文、权威度、行业定向、报告导出、QPS 限流 |
| `tools/common/tavily_search.py` | DASHSCOPE_API_KEY | MCP（SSE） | title/url/content，深度搜索 |
| `tools/common/web_search.py` | DASHSCOPE_API_KEY | MCP（SSE） | title/link/snippet，多源视角 |
| `tools/common/exa_search.py` | EXA_API_KEY | HTTP REST | title/url/published_date/content，语义检索 + 深度档位 |

详细使用方法参见 [A股工具使用指南.md#八doubao_searchpy---豆包搜索](A股工具使用指南.md#八doubao_searchpy---豆包搜索)、[A股工具使用指南.md#九web_searchpy---阿里云百炼-websearch](A股工具使用指南.md#九web_searchpy---阿里云百炼-websearch) 与 [A股工具使用指南.md#十exa_searchpy---exa-语义搜索](A股工具使用指南.md#十exa_searchpy---exa-语义搜索)。

### 7.2 港股场景推荐

| 场景 | 推荐工具 | 命令示例 |
|------|---------|---------|
| 港股财报正文抓取（做大模型拆解） | `doubao_search.py --need-content --finance` | `python tools/common/doubao_search.py "腾讯控股 2025年报" --finance --need-content --export` |
| 港股股权变动/收购公告检索 | `doubao_search.py --sites` | `python tools/common/doubao_search.py "腾讯 回购" --sites hkexnews.hk` |
| 跨市场对比（A+H+中概股） | `doubao_search.py` | `python tools/common/doubao_search.py "腾讯控股 A股 港股 对比"` |
| 港股管理层讨论深度搜索 | `tavily_search.py` | `python tools/common/tavily_search.py "腾讯 2025Q4 管理层讨论" --max-results 10` |
| 港股行业新闻多源验证 | `web_search.py` | `python tools/common/web_search.py "恒生科技指数 走势"` |
| 港股深度研究报告检索 | `exa_search.py --type deep` | `python tools/common/exa_search.py "港股 互联网 行业 深度研究" --type deep` |

### 7.3 重要内容多源验证（推荐）

港股财报分析建议**同时调用 2~3 个工具**互为补充：

```bash
# 优先调用豆包搜索（含正文 + 权威度筛选）
python tools/common/doubao_search.py "腾讯控股 2025Q4 财报" --finance --need-content --export

# 补充 Tavily（深度内容）+ WebSearch（多源视角）
python tools/common/tavily_search.py "腾讯 2025Q4 管理层讨论"
python tools/common/web_search.py "腾讯 2025Q4 财报 分析师点评"
```

**优势**:
- `doubao_search.py`：权威信源 + 正文能力，适合投研报告自动化
- `tavily_search.py`：内容深度高，适合管理层讨论分析
- `web_search.py`：多源视角，适合交叉验证

### 7.4 港股特有注意事项

1. **港股信源覆盖**: 港交所披露易（hkexnews.hk）、AASTOCKS、新浪港股等均可被豆包搜索覆盖；如需官方公告原文，可 `--sites hkexnews.hk` 定向检索
2. **中概股双重上市**: 同时在 A 股/港股/美股上市的公司（如阿里巴巴-SW），豆包搜索支持跨市场综合检索，无需切换工具
3. **财经定向快捷选项**: 港股财报分析推荐 `--finance`（金融行业 + 仅非常权威信源）
4. **完整选型决策流程**: 参见 [A股工具使用指南.md#十一搜索工具选型对比](A股工具使用指南.md#十一搜索工具选型对比)

### 7.5 PDF 文档处理工具

港股财报 PDF 的文字与表格提取使用通用工具 `tools/common/pdf_extract.py`（基于 pdf-inspector 库），支持分类检测、纯文本提取、含财务附表的 Markdown 提取、全流程四种模式；检测到扫描格式时会返回 `scanned` 标志提示需走 OCR 流程。

**详细说明**（功能、子命令、参数、输出示例、扫描格式处理）请参阅 [A股工具使用指南.md#十三pdf_extractpy---pdf-文字与表格提取](A股工具使用指南.md#十三pdf_extractpy---pdf-文字与表格提取)。

**港股场景示例**:

```bash
# 分类检测（判断是否扫描件、总页数）
python tools/common/pdf_extract.py detect 00700_2025年报.pdf

# 提取含财务附表的 Markdown 并写盘
python tools/common/pdf_extract.py markdown 00700_2025年报.pdf --save-md --out-dir reports/pdf

# 全流程（分类 + 纯文本 + Markdown）
python tools/common/pdf_extract.py all 00700_2025年报.pdf --save-md
```

**港股特有说明**: 港股工具暂不支持 `stock_equity.py` 自动下载财报 PDF，可通过港交所披露易（hkexnews.hk）或浏览器手动获取财报 PDF 后，再使用 `pdf_extract.py` 提取文字与附表。

## 八、注意事项

### 1. 代码格式

港股代码必须为5位数字字符串，如 `00700`，不要添加 `.HK` 后缀。

### 2. 数据延迟

免费接口数据可能有数分钟延迟，不适合高频交易。

### 3. 访问限制

高频请求可能触发风控，建议增加延时、分批请求。

### 4. 字段差异

不同接口的字段名可能不同（中文/英文），工具已做适配。

### 5. **网络连接问题（重要）**

**东方财富港股数据源在中国大陆可能出现网络连接不稳定问题**，特别是在股市交易时间。

**现象**:

- `RemoteDisconnected: Remote end closed connection without response`
- 连接超时或无响应
- 网络请求失败

**原因**:

- 东方财富服务器负载较高
- 高峰时段网络拥堵
- 免费接口稳定性有限

**解决方案**:

**方案A: 工具已内置重试机制**

- 工具已自动添加重试机制（最多3次重试）
- 重试间隔递增（避免频繁请求）
- 自动切换到备用数据源

**方案B: 避开高峰时段**

- 避免在股市交易时间使用
- 股市交易日建议在09:00前或下午15:30后使用

**方案C: 多次尝试**

- 如果第一次失败，等待2-3分钟后重试
- 工具会自动重试，无需手动干预

**方案D: 使用备用数据源**

- 新浪港股接口：`ak.stock_hk_daily(symbol="00700")`
- 雪球港股接口：`ak.stock_individual_basic_info_hk_xq(symbol="00700")`

- A股工具：正常使用 ✅
- 港股工具：已优化（重试机制+备用数据源） ✅
