# 港股数据工具使用指南

本文档介绍如何使用独立的港股数据工具获取港股市场数据。

***

## 工具列表

| 工具文件                  | 功能          | 命令示例                                                              |
| --------------------- | ----------- | ----------------------------------------------------------------- |
| `stock_info_hk.py`    | 港股信息查询、财务指标 | `python tools/stock_info_hk.py --search 腾讯` / `--financial 00700` |
| `stock_quote_hk.py`   | 港股行情数据      | `python tools/stock_quote_hk.py --code 00700`                     |
| `stock_screen_hk.py`  | 港股质量筛选7条指标  | `python tools/stock_screen_hk.py --code 00700`                    |
| `tavily_search.py`    | 网络信息搜索（优先）  | `python tools/tavily_search.py "腾讯 财报" --max-results 5`         |
| `web_search.py`       | 网络信息搜索（备选）  | `python tools/web_search.py "腾讯 财报"`                             |

***

## 一、stock\_info\_hk.py - 港股信息查询

### 功能说明

获取港股上市公司的代码、名称、实时行情、财务指标等信息。

### 使用方法

#### 1. 列出全部港股

```bash
python tools/stock_info_hk.py --list
```

**输出示例**:

```json
{
  "success": true,
  "data": [

    {"code": "00002", "name": "中电控股", "market": "hk"},

    "command": "list",
    "market": "hk",
    "count": 2546,
    "timestamp": "2026-07-12T22:50:00"
  }
}
```

#### 2. 搜索港股

```bash
python tools/stock_info_hk.py --search 腾讯
```

**输出示例**:

```json
{

  "data": [
    {
      "code": "00700",
      "name": "腾讯控股",
      "market": "hk",
      "price": 420.5,

  ],
  "meta": {
    "tool": "stock_info_hk",
    "command": "search",
    "keyword": "腾讯",
    "count": 1
  }
}
```

#### 3. 查询单只港股

```bash
python tools/stock_info_hk.py --code 00700
```

**输出字段说明**:

- `code`: 港股代码（5位数字）
- `name`: 公司名称
- `market`: 市场标识（"hk"）
- `price`: 最新价
- `change_pct`: 涨跌幅（%）
- `change`: 涨跌额
- `volume`: 成交量
- `amount`: 成交额
- `high`: 最高价
- `low`: 最低价
- `open`: 今开
- `pre_close`: 昨收

#### 4. 获取港股热度榜

```bash
python tools/stock_info_hk.py --hot
```

#### 5. 获取港股财务指标（新增）

```bash
# 获取年度财务指标（默认）

# 获取报告期财务指标
```

| `NET_PROFIT_RATIO`    | 净利率(%)        | ⑥ 净利率    |

| `HOLDER_PROFIT`       | 归母净利润(亿元)     | FCF辅助    |
| `OPERATE_INCOME`      | 营业总收入(亿元)     | 辅助       |
| `DEBT_ASSET_RATIO`    | 资产负债率(%)      | 利息覆盖辅助   |

| `PER_NETCASH_OPERATE` | 每股经营现金流(元)    | ⑤ 利润质量辅助 |

## 二、stock\_quote\_hk.py - 港股行情数据

### 功能说明

获取港股历史K线数据，支持日/周/月线、前/后复权。

### 使用方法

#### 1. 获取最近30天数据

```bash
python tools/stock_quote_hk.py --code 00700
```

#### 2. 指定日期范围

```bash
python tools/stock_quote_hk.py --code 00700 --start 20260101 --end 20260710
```

#### 3. 选择复权方式

```bash
# 未复权
python tools/stock_quote_hk.py --code 00700 --adjust ""

# 前复权（默认）
python tools/stock_quote_hk.py --code 00700 --adjust qfq

# 后复权
python tools/stock_quote_hk.py --code 00700 --adjust hfq
```

#### 4. 选择周期类型

```bash
# 日线（默认）
python tools/stock_quote_hk.py --code 00700 --period daily

# 周线
python tools/stock_quote_hk.py --code 00700 --period weekly

# 月线
python tools/stock_quote_hk.py --code 00700 --period monthly
```

#### 5. 获取港股指数

```bash
# 恒生指数
python tools/stock_quote_hk.py --index HSI

# 恒生科技指数
python tools/stock_quote_hk.py --index CES100
```

## 三、stock\_screen\_hk.py - 港股质量筛选

### 功能说明

对港股执行7条去劣指标筛选，快速排除不符合一流公司标准的标的。

### 7条去劣指标

| # | 指标 | 排除条件 |
|---|------|---------|
| ① | 10年平均ROE | < 8% |
| ② | 5年累计自由现金流 | 为负 |
| ③ | 利息覆盖倍数（EBIT/利息） | < 2倍 |
| ④ | 长期毛利率 | < 15% |
| ⑤ | 经营现金流/净利润（5年均值） | < 0.7 |
| ⑥ | 长期净利率 | < 5% |
| ⑦ | 5年总股本膨胀 | > 20%（非并购原因） |

### 使用方法

#### 1. 单只港股筛选

```bash
python tools/stock_screen_hk.py --code 00700
```

#### 2. 多只港股筛选

```bash
python tools/stock_screen_hk.py --code 00700,03690,01810
```

### 输出字段说明

**返回的指标字段**：

- `1_roe_avg`: ROE平均值（指标①）
- `2_fcf`: 自由现金流（指标②）
- `3_interest_coverage`: 利息覆盖倍数（指标③）
- `4_gross_margin_avg`: 毛利率平均值（指标④）
- `5_ocf_to_ni`: 经营现金流/净利润（指标⑤）
- `6_net_margin_avg`: 净利率平均值（指标⑥）
- `7_share_dilution`: 股本稀释比例（指标⑦）

**指标判断字段**：

- `value`: 计算值
- `pass`: 是否通过（true/false/null）
- `threshold`: 阈值
- `note`: 说明

**汇总字段**：

- `passed_count`: 通过指标数量
- `failed_count`: 失败指标数量
- `unknown_count`: 无法判断指标数量
- `overall_pass`: 整体是否通过

### 注意事项

1. **指标③和⑦数据限制**：港股财务数据通常不直接提供利息支出和股本变化，这两项指标需要从年报手动核实

3. **数据源**：使用东方财富港股财务分析接口，网络连接可能不稳定，工具已内置重试机制

## 五、数据源说明

### stock\_hk\_spot()

- 来源：新浪财经
- 字段：代码、名称、最新价、涨跌幅、成交量等
- 特点：网络连接稳定、内置重试机制、数据实时
- 用途：`stock_info_hk.py` 获取港股列表和实时行情

### stock\_hk\_daily()

- 来源：新浪财经
- 参数：代码、复权方式（qfq/hfq/""）
- 特点：网络连接稳定、支持前/后复权、历史数据长
- 用途：`stock_quote_hk.py` 获取港股历史K线数据

### stock\_hk\_index\_daily\_sina()

- 来源：新浪财经
- 指数：HSI(恒生指数)、CES100(恒生科技)等
- 特点：历史数据长、网络连接稳定
- 用途：`stock_quote_hk.py` 获取港股指数数据

### stock\_hk\_hot\_rank\_em()

- 来源：东方财富
- 字段：排名、代码、名称、涨跌幅等
- 特点：数据实时、反映市场热度
- 用途：`stock_info_hk.py` 获取港股热度榜

### stock_financial_hk_analysis_indicator_em()

- 来源：东方财富
- 字段：ROE、毛利率、净利率、OCF_SALES等
- 特点：数据全面、覆盖近10年、支持年度/报告期
- 用途：`stock_info_hk.py --financial` 获取港股财务指标

### stock_financial_hk_report_em()

- 来源：东方财富
- 参数：股票代码、报表类型（利润表/资产负债表/现金流量表）、报告期
- 字段：营业收入、净利润、资产总额、负债总额等
- 特点：数据详细、支持三大报表、覆盖近10年
- 用途：`stock_screen_hk.py` 获取港股财务报表数据（辅助计算自由现金流、利息覆盖等）

### 数据源对比总结

| 数据源 | 主要特点 | 适用场景 | 使用工具 |
|--------|---------|---------|---------|
| 新浪财经 | 网络稳定、数据实时、历史数据长 | 实时行情、历史K线、指数数据 | stock_info_hk.py, stock_quote_hk.py |
| 东方财富 | 数据全面、字段丰富、支持财务分析 | 热度榜、财务指标、财务报表 | stock_info_hk.py, stock_screen_hk.py |

## 六、网络信息获取工具

港股网络信息获取采用分层策略，优先使用 Tavily 搜索，备选 WebSearch。

### 6.1 Tavily 搜索（优先）

**工具**: `tools/tavily_search.py`

**特点**:
- 提供更高质量的内容和更详细的信息
- 返回 title、url、content 三个字段
- 支持高级搜索（search_depth="advanced"）
- 通过阿里云百炼 MCP 服务调用

**使用方法**:

```bash
# 基本搜索
python tools/tavily_search.py "腾讯 2025Q4 财报"

# 指定返回结果数量
python tools/tavily_search.py "腾讯 2025Q4 财报" --max-results 5

# 高级搜索（内容质量更高）
python tools/tavily_search.py "腾讯 2025Q4 财报" --max-results 10
```

**输出字段**:
- `title`: 搜索结果标题
- `url`: 搜索结果链接
- `content`: 搜索结果内容摘要
- `raw_content`: 完整内容（可选）

### 6.2 WebSearch 搜索（备选）

**工具**: `tools/web_search.py`

**特点**:
- 阿里云百炼 WebSearch 服务
- 提供更多来源和不同视角
- 作为 Tavily 的补充信息源

**使用方法**:

```bash
# 网络搜索
python tools/web_search.py "腾讯 2025Q4 财报"
```

### 6.3 重要内容同时调用（推荐）

对于港股的重要财报分析，建议**同时调用两个工具**，互为补充：

```bash
# 并行调用示例
python tools/tavily_search.py "腾讯 2025Q4 财报 管理层讨论"
python tools/web_search.py "腾讯 2025Q4 财报 管理层讨论"
```

**优势**:
- Tavily：获取详细内容和深度分析
- WebSearch：获取更多来源和不同视角
- 交叉验证：提高信息准确性

### 6.4 使用场景对比

| 场景 | 推荐工具 | 理由 |
|------|---------|------|
| 财报分析 | Tavily（优先）+ WebSearch（补充） | 重要内容，需多源验证 |
| 管理层讨论 | Tavily | 内容深度要求高 |
| 行业趋势 | WebSearch | 需要更多来源 |
| 新闻事件 | Tavily + WebSearch | 需要全面覆盖 |

## 七、注意事项

### 1. 代码格式

港股代码必须为5位数字字符串，如 `00700`，不要添加 `.HK` 后缀。

### 2. 数据延迟

免费接口数据可能有数分钟延迟，不适合高频交易。

### 3. 访问限制

高频请求可能触发风控，建议增加延时、分批请求。

### 4. 字段差异

不同接口的字段名可能不同（中文/英文），工具已做适配。

### 5. **网络连接问题（重要）**

**东方财富港股数据源在中国大陆可能出现网络连接不稳定问题**，特别是在股市交易时间。

**现象**:

- `RemoteDisconnected: Remote end closed connection without response`
- 连接超时或无响应
- 网络请求失败

**原因**:

- 东方财富服务器负载较高
- 高峰时段网络拥堵
- 免费接口稳定性有限

**解决方案**:

**方案A: 工具已内置重试机制**

- 工具已自动添加重试机制（最多3次重试）
- 重试间隔递增（避免频繁请求）
- 自动切换到备用数据源

**方案B: 避开高峰时段**

- 避免在股市交易时间使用
- 股市交易日建议在09:00前或下午15:30后使用

**方案C: 多次尝试**

- 如果第一次失败，等待2-3分钟后重试
- 工具会自动重试，无需手动干预

**方案D: 使用备用数据源**

- 新浪港股接口：`ak.stock_hk_daily(symbol="00700")`
- 雪球港股接口：`ak.stock_individual_basic_info_hk_xq(symbol="00700")`

- A股工具：正常使用 ✅
- 港股工具：已优化（重试机制+备用数据源） ✅
