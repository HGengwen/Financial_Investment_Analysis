## 一、重构背景与目标

### 1.1 背景

项目现有五个网络搜索工具，散落在多处文档中，选型规范互相冲突、各自滞后：

| 工具                              | 对应服务             | 当前文档状态                     |
| --------------------------------- | -------------------- | -------------------------------- |
| `tools/common/doubao_search.py` | 火山引擎豆包搜索     | 各文档均为主搜推荐               |
| `tools/common/web_search.py`    | 阿里云百炼 WebSearch | 旧规范曾作为 A股首选（已过时）   |
| `tools/common/tavily_search.py` | Tavily               | 仅作港美辅助，A股指南无专章      |
| `tools/common/exa_search.py`    | Exa                  | 仅作研究型长文补充，未按报告升级 |
| `tools/common/anysearch.py`     | AnySearch            | 最新工具，多数文档未纳入         |

**现状问题**：

1. 五处文档（docs 三指南、skills 技能、工作步骤、CLAUDE.md、项目记忆）选型规则不一致
2. A股/港股/美股三市场缺乏统一的"市场 × 场景"选型矩阵
3. 报告明确结论（AnySearch 为 A股首选、Exa 为美股首选）未落地到文档
4. `web-search-tools.md` 仍为四工具版，缺 anysearch；`tavily` 在 A股指南中无专章

### 1.2 重构目标

- 依据对比报告第五、六章结论，确立**五工具角色定位**
- 建立**市场 × 场景双矩阵**选型策略，主/辅/专用三层角色
- 统一重写 docs、skills、工作步骤、CLAUDE.md、项目记忆全部引用点
- 技能文件搜索工具描述遵循**"引用优先、本地最小化"**原则（见 4.1 节），避免多文件重复堆砌搜索工具介绍
- 本次**仅重构文档策略**，不新增调度/编排代码，不涉及内容安全审核层代码

## 三、市场 × 场景选型矩阵（定稿）

### 3.1 A股 —— 双主组合

| 场景                         | 主搜索                                       | 辅/验证                     |
| ---------------------------- | -------------------------------------------- | --------------------------- |
| 财报/研报/公告/判例/专利深查 | `anysearch --tag finance/legal`            | `doubao --finance`        |
| 实时新闻/舆情/热点资讯       | `doubao --finance`                         | `anysearch`               |
| 精确数值核验                 | `financial_rigor.py`（专用工具，不属搜索） | —                          |
| 多源交叉验证                 | `anysearch` + `doubao` 双主              | `web_search` 兜底（手动） |

### 3.2 港股

| 场景                   | 主搜索                         | 辅/验证                                             |
| ---------------------- | ------------------------------ | --------------------------------------------------- |
| 港交所披露易/公告/回购 | `doubao --sites hkexnews.hk` | `tavily`                                          |
| 管理层讨论/分析师点评  | `tavily`                     | `doubao`                                          |
| 财报/研报深度检索      | `doubao --need-content`      | `anysearch`（通用搜索，**已验证港股覆盖**） |
| 双源验证               | `doubao` + `tavily`        | —                                                  |

> **实测结论**：anysearch 通用搜索模式对港股覆盖良好（腾讯 00700 返回 5 条权威财经媒体结果含精确财务数据；港交所 00388 返回 3 条含精确业绩数据）。`--tag finance` 垂直库需额外参数（symbol/type/cn_code），港股适用性待后续验证。港股财报/研报深度检索以 `doubao --need-content` 为主、`anysearch` 通用搜索为辅。

### 3.3 美股

| 场景                           | 主搜索               | 辅/验证                   |
| ------------------------------ | -------------------- | ------------------------- |
| SEC filings/财报/MD&A 深度检索 | `exa --type deep`  | `tavily`                |
| 美股新闻/舆情/跨市场对比       | `doubao`           | `anysearch --zone intl` |
| 双源验证                       | `exa` + `doubao` | —                        |

> **实测结论**：
>
> - `exa` 搜索 "AAPL 10-K" 直接命中 SEC.gov 原文（aapl-20240928.htm）+ Apple IR + EDGAR，5 条结果全部高质量，确认美股 SEC filings 检索首选地位
> - `anysearch --zone intl --language en` 搜索 "NVDA earnings" 返回 Yahoo Finance/NVIDIA 官网/Nasdaq，含精确财务数据（$130.5B revenue, $2.94 EPS），可作美股辅搜
> - `doubao` 实测正常
>
> 美股/海外检索使用英文关键词（`10-K`、`earnings call`、`guidance`）命中率更高；anysearch 检索海外建议加 `--zone intl --language en`。

### 3.4 通用规范（全市场适用）

1. 使用 `--time-range day/week/month` 限制时间范围，优先获取最新信息
2. 搜索结果必须包含数据来源日期；过时数据须标注时效性说明
3. 非境内上市公司关键信息须双源验证（港股：doubao+tavily；美股：exa+doubao）
4. 关键信息缺失时标注"信息不足"，不得用推测填充
5. 中概股双重上市（A+H / A+美股）用 `doubao` 跨市场综合检索，无需切换工具

## 四、文档重写清单（10 处）

### 4.1 技能文件搜索工具描述规范（重要）

除 `.trae/skills/tools-scripts/` 目录下的 md 文档（含 `web-search-tools.md` 本身）外，`.trae/skills/` 下各技能文件的搜索工具描述遵循 **"引用优先、本地最小化"** 原则：

**1. 统一引用入口**

- 搜索工具完整说明、参数详解、选型矩阵、命令速查**一律以 `.trae/skills/tools-scripts/web-search-tools.md`（v3.0）为唯一权威入口**
- 技能文件**不复制**工具介绍表格、命令速查、选型决策表等完整内容

**2. 技能文件仅保留本技能特有的内容**

- 一句话工具清单：本技能用到的工具名 + 用途（可附 1 个命令示例）
- 本技能特有的调用约束：如"管理层信息必须 Doubao + Tavily 双源验证"
- 指向 `web-search-tools.md` 的引用链接

**3. 引用格式示例**

```markdown
搜索工具完整说明与选型策略参见
[web-search-tools.md](../tools-scripts/web-search-tools.md)。

本技能管理层信息须双源验证：`doubao_search.py` + `tavily_search.py`。
```

**4. 例外**：`.trae/skills/tools-scripts/` 下的 md（a-share-data.md、hk-share-data.md、common-tools-guide.md、web-search-tools.md 等）作为公共工具规范本体，保留完整描述，不适用本原则。
