# 美股数据获取工具测试说明（yfinance 版本）

## 测试文件

- `tests/test_stock_us_yfinance.py` - 美股数据获取工具测试软件

## 主工具文件

- `tools/stock_us_yfinance.py` - 美股数据获取主工具

## 数据来源

- **Yahoo Finance** — 免费、无需 token、无需积分（科学上网、智能路由）

## 功能模块

### 1. 个股实时行情与估值指标

- 使用 `yf.Ticker.info` 接口
- 支持标准美股代码（如 AAPL、TSLA、MSFT）
- 获取字段：当前价格、开盘价、最高价、最低价、成交量、市值、PE、PB、52周高低、股息率、Beta、ROE、ROA 等

### 2. 美股三大指数历史日线

- 使用 `yf.download` 接口
- 支持：纳斯达克综合指数(^IXIC)、道琼斯工业指数(^DJI)、标普500指数(^GSPC)
- 可指定日期范围
- 支持自动前复权

### 3. 个股历史K线数据

- 使用 `yf.download` 接口
- 支持前复权/不复权
- 可指定日期范围

### 4. 完整财务报表

- 年度/季度利润表
- 年度/季度资产负债表
- 年度/季度现金流量表

### 5. 额外财务数据

- 分红历史
- 拆股历史
- 机构持股
- 分析师评级

## 使用示例

```bash
# 获取苹果实时行情
python tools/stock_us_yfinance.py --realtime AAPL

# 获取美股三大指数历史日线
python tools/stock_us_yfinance.py --index

# 获取苹果历史K线（指定日期）
python tools/stock_us_yfinance.py --daily AAPL --start 2025-01-01 --end 2026-07-27

# 获取苹果财务报表
python tools/stock_us_yfinance.py --financial AAPL

# 获取苹果额外数据（分红、机构、评级）
python tools/stock_us_yfinance.py --extra AAPL

# 获取所有数据
python tools/stock_us_yfinance.py --all AAPL

# JSON 格式输出
python tools/stock_us_yfinance.py --realtime AAPL --json

# 不复权模式
python tools/stock_us_yfinance.py --daily AAPL --no-adjust
```

## 注意事项

1. **时区问题**：yfinance 返回的数据是美东时间，如需北京时间可使用 `pytz` 转换
2. **中概股财报**：部分中概股财报可能缺失，优先测试 AAPL、MSFT、NVDA 等
3. **财务报表格式**：yfinance 财报默认行为科目、列为报告期，可用 `.T` 转置
