## API 接口状态（已更新）

### ✅ 可用的 API 接口

| 接口名称             | 功能                     | 状态    |
| -------------------- | ------------------------ | ------- |
| `stock_us_spot_em` | 美股实时行情（东方财富） | ✅ 存在 |
| `stock_us_hist`    | 美股历史K线数据          | ✅ 存在 |

## 功能模块

### 1. 个股实时行情获取

- 使用 `stock_us_spot_em` 接口
- 支持标准美股代码（如 AAPL、TSLA、MSFT）
- 自动转换为东方财富内部代码格式

### 2. 美股三大指数历史日线

- 使用 `stock_us_hist` 接口
- 支持：纳斯达克综合指数(^IXIC)、道琼斯工业指数(^DJI)、标普500指数(^GSPC)
- 可指定日期范围

### 3. 个股历史K线数据

- 使用 `stock_us_hist` 接口
- 支持前复权(qfq)、后复权(hfq)、不复权
- 可指定日期范围

### 网络问题说明

东方财富美股接口在中国大陆网络不稳定：

- 错误类型：`ConnectionError`、`RemoteDisconnected`
- 错误信息：`Remote end closed connection without response`

测试框架正确处理了网络失败的情况，不会因为网络问题导致测试失败。

## 新增功能

### 股票代码自动映射

工具已实现标准美股代码到东方财富内部代码的自动转换：

```python
# 标准代码 -> 东方财富代码
AAPL  -> 105.AAPL
MSFT  -> 105.MSFT
GOOGL -> 106.GOOGL
```

映射表首次使用时从东方财富获取并缓存。若网络不可用，自动使用构造格式。

## 使用示例

```bash
# 获取苹果实时行情
python tools/stock_info_us.py --realtime AAPL

# 获取美股三大指数历史日线
python tools/stock_info_us.py --index

# 获取苹果历史K线（指定日期）
python tools/stock_info_us.py --daily AAPL --start 20260101 --end 20260727

# JSON 格式输出
python tools/stock_info_us.py --realtime AAPL --json
```

## 网络限制说明（实测结果，采用代理反倒会网络访问超时）

东方财富美股接口在中国大陆网络连接不稳定：

- 建议使用代理或切换网络环境
- 工具已内置重试机制（默认3次重试）
- 代码映射功能在网络不可用时自动使用构造格式
- 可考虑使用 yfinance 作为备选数据源
