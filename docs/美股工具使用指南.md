## 一、stock_us_yfinance.py - 美股数据获取

### 功能说明

使用 yfinance 库获取美股上市公司的实时行情、历史K线、完整财务报表等数据。

**数据来源**: Yahoo Finance（免费、无需 token、无需积分）

**优势**:
- 底层接口稳定，时区处理专业
- 比部分第三方 API 封装更原生
- 支持完整财务数据和额外数据

### 使用方法

#### 1. 获取个股实时行情与估值指标

```bash
python tools/stock_us_yfinance.py --realtime AAPL
```

**返回的关键字段**:
- `当前价格` (currentPrice)
- `开盘价` (open)
- `最高价` (dayHigh)
- `最低价` (dayLow)
- `昨日收盘价` (previousClose)
- `成交量` (volume)
- `市值` (marketCap)
- `市盈率TTM` (trailingPE)
- `市净率PB` (priceToBook)
- `52周最高` (fiftyTwoWeekHigh)
- `52周最低` (fiftyTwoWeekLow)
- `股息率` (dividendYield)
- `Beta系数` (beta)
- `ROE` (returnOnEquity)
- `ROA` (returnOnAssets)

## 二、数据源说明

### yfinance 库

- **来源**: Yahoo Finance
- **特点**: 免费、无需 token、无需积分、底层接口稳定
- **优势**:
  - 时区处理专业
  - 支持完整财务数据
  - 支持分红拆股、机构持股、分析师评级
  - 封装原生，比部分第三方 API 更可靠

### API 接口说明

| 接口 | 功能 | 返回数据 |
|------|------|---------|
| `yf.Ticker.info` | 实时行情与估值指标 | PE、PB、市值、股息率、Beta、ROE、ROA 等 |
| `yf.download` | 历史K线数据 | 开高低收、成交量，支持前复权 |
| `yf.Ticker.income_stmt` | 年度利润表 | 收入、成本、利润等 |
| `yf.Ticker.balance_sheet` | 年度资产负债表 | 资产、负债、股东权益等 |
| `yf.Ticker.cashflow` | 年度现金流量表 | 经营、投资、筹资现金流 |
| `yf.Ticker.dividends` | 分红历史 | 分红日期、金额 |
| `yf.Ticker.splits` | 拆股历史 | 拆股日期、比例 |
| `yf.Ticker.institutional_holders` | 机构持股 | 机构名称、持股数、持股比例 |
| `yf.Ticker.recommendations` | 分析师评级 | 强烈买入、买入、持有、卖出、强烈卖出 |

## 四、注意事项

### 1. 时区问题

yfinance 返回的数据是**美东时间（US/Eastern）**，如需北京时间可使用 `pytz` 转换：

```python
from pytz import timezone
import pandas as pd

# 美东时间转北京时间
eastern = timezone('US/Eastern')
beijing = timezone('Asia/Shanghai')
dt = pd.Timestamp('2026-07-27 10:00:00', tz=eastern)
dt_beijing = dt.tz_convert(beijing)
```

### 2. 中概股财报

部分中概股（如 BIDU、JD、BABA）的财报可能缺失或格式不一致，建议优先测试 AAPL、MSFT、NVDA 等美股龙头。

### 3. 财务报表格式

yfinance 财务报表默认行为：
- 行：科目（如 Total Revenue、Net Income）
- 列：报告期（如 2025-09-30、2024-09-30）

可用 `.T` 转置：
```python
df = stock.income_stmt.T  # 转置为行=报告期，列=科目
```

### 4. 数据延迟

免费接口数据可能有数分钟延迟，不适合高频交易。

### 5. 访问限制

高频请求可能触发风控，建议增加延时、分批请求。

## 六、网络信息获取工具

美股网络信息获取采用分层策略，优先使用 Tavily 搜索，备选 WebSearch。

### 6.1 Tavily 搜索（优先）

**工具**: `tools/tavily_search.py`

**特点**:
- 提供更高质量的内容和更详细的信息
- 返回 title、url、content 三个字段
- 支持高级搜索（search_depth="advanced"）

**使用方法**:
```bash
python tools/tavily_search.py "AAPL Q3 2026 earnings" --max-results 5
```

**工具**: `tools/web_search.py`

**使用方法**:

## 九、局限性说明

1. **数据延迟**：免费接口数据可能有数分钟延迟，不适合高频交易
2. **中概股财报**：部分中概股财报可能缺失或格式不一致
3. **质量筛选**：暂不支持7条去劣指标筛选（可手动计算）
4. **分析师评级**：部分小盘股可能无分析师评级数据
5. **非实时数据**：工具获取的数据可能有延迟，不是实时数据
6. **不构成投资建议**：本工具仅供学习研究参考，不构成任何投资建议
