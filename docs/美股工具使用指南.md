### 1.1 stock_info.py - 实时行情与估值指标

使用 yfinance 库获取美股上市公司的实时行情与估值指标。

#### 获取个股实时行情与估值指标


#### 本地缓存与代码列表查询（--list / --search / --code / --refresh）

**本地缓存优化**（v2.0 起）：美股代码/名称/交易所列表保存在 `data/us_stock/stock_code.csv`（TTL 默认 7 天，`STOCK_CACHE_TTL_DAYS` 可配置，约 11000 只，含 `yf_symbol` 列兼容 yfinance 点号代码如 `BRK.B → BRK-B`）。查询/搜索优先读本地缓存，仅缓存缺失/过期时才重新拉取全量列表，避免每次查询重复下载；`meta.cache` 标识缓存命中状态。

**数据源（列表，按优先级逐源尝试）**:

1. NASDAQ Trader 官网（`nasdaqlisted.txt` + `otherlisted.txt`，主源，约 11000 只）
2. NASDAQ 官方 screener API（`api.nasdaq.com`，备源，JSON）
3. 自定义镜像（`.env` 的 `US_TICKER_MIRROR_URLS`，逗号分隔，管道分隔或 JSON 格式均可）
4. 旧缓存降级（stale）；无缓存时抛错由调用方处理

**限流降级**：`--realtime` 调用 yfinance 失败（HTTP 429/断连，已重试 3 次）时，估值指标（市值、PE、PB、股息率、Beta、ROE、ROA、52 周高低等）从本地慢变字段缓存 `data/us_stock/symbol_info.csv`（TTL 默认 1 天，`US_STOCK_INFO_TTL_DAYS` 可配置）降级返回，`meta.cache = "stale"`、`meta.api = "cache_degraded"`，价格字段为空；无缓存可用时才返回失败。

**meta.cache 缓存状态语义**:

- `hit`：直接命中本地缓存（零 API 调用）
- `refresh`：缓存缺失/过期，本次触发了一次全量刷新
- `stale`：刷新失败，降级返回旧缓存/慢变字段缓存

### 1.3 stock_financial.py - 财务报表与额外数据

使用 yfinance 库获取美股完整财务报表，以及分红拆股、机构持仓、分析师评级等额外数据。

**数据缓存**（`tools/common/us_stock_cache.py`）：三大报表与分红拆股历史按股票分文件缓存于
`data/us_stock/financial/`——报表 TTL 默认 7 天（`.env` 的 `US_FINANCIAL_TTL_DAYS`），
分红/拆股历史 TTL 默认 30 天（`US_DIVIDENDS_TTL_DAYS`）。命中缓存零 yfinance 调用；
yfinance 限流（429）/断连且已有旧缓存时降级返回旧缓存（`meta.cache = "stale"`），
无缓存时才返回失败。机构持仓与分析师评级属实时数据，不做缓存。

## 二、数据源说明

### yfinance 库

- **来源**: Yahoo Finance
- **特点**: 免费、无需 token、无需积分、底层接口稳定
- **优势**:
  - 时区处理专业

  - 封装原生，比部分第三方 API 更可靠

### API 接口说明

| 接口                                | 功能               | 所属模块           | 返回数据                                |

| `yf.Ticker.info`                  | 实时行情与估值指标 | stock_info.py      | PE、PB、市值、股息率、Beta、ROE、ROA 等 |
| `yf.download`                     | 历史K线数据        | stock_quote.py     | 开高低收、成交量，支持前复权            |

| `yf.Ticker.splits`                | 拆股历史           | stock_financial.py | 拆股日期、比例                          |
| `yf.Ticker.institutional_holders` | 机构持股           | stock_financial.py | 机构名称、持股数、持股比例              |

## 四、注意事项

### 1. 时区问题

yfinance 返回的数据是**美东时间（US/Eastern）**，如需北京时间可使用 `pytz` 转换：

```python
from pytz import timezone
import pandas as pd

# 美东时间转北京时间
eastern = timezone('US/Eastern')
beijing = timezone('Asia/Shanghai')
dt = pd.Timestamp('2026-07-29 10:00:00', tz=eastern)
dt_beijing = dt.tz_convert(beijing)
```

### 2. 中概股财报

部分中概股（如 BIDU、JD、BABA）的财报可能缺失或格式不一致，建议优先测试 AAPL、MSFT、NVDA 等美股龙头。

### 3. 财务报表格式

yfinance 财务报表默认行为：

- 行：科目（如 Total Revenue、Net Income）
- 列：报告期（如 2025-09-30、2024-09-30）

可用 `.T` 转置：

```python
df = stock.income_stmt.T  # 转置为行=报告期，列=科目
```

### 4. 数据延迟

免费接口数据可能有数分钟延迟，不适合高频交易。

### 5. 访问限制

高频请求可能触发风控，建议增加延时、分批请求。

### 6.3 重要内容多源验证（推荐）

美股关键信息须**双源验证**（exa + doubao），重要内容建议同时调用 2~3 个工具互为补充：

```bash
# 优先调用 Exa（SEC filings 深度检索，直接命中原文）
python tools/common/exa_search.py "AAPL 10-K 2025" --type deep --max-results 10

# 补充 Doubao（新闻/舆情/分析师点评 + 跨市场视角）
python tools/common/doubao_search.py "AAPL Q3 2026 earnings analyst reactions" --finance --need-content

# 如需 MD&A 深度内容，补充 Tavily
python tools/common/tavily_search.py "AAPL management discussion Q3 2026"
```

**优势**:

- `exa_search.py`：SEC filings 深度检索首选，直接命中 SEC.gov 原文，**美股主搜**
- `doubao_search.py`：新闻/舆情/跨市场检索，正文能力强，美股辅搜
- `tavily_search.py`：MD&A 与分析师点评深度内容，美股辅搜
- `anysearch.py`：`--zone intl` 已验证美股覆盖（NVDA 返回 $130.5B revenue, $2.94 EPS），适合财务数据交叉验证
- `web_search.py`：仅阿里云生态/轻量验证兜底，移出默认组合

### 6.4 美股特有注意事项

1. **exa 为美股主搜**：SEC filings / 财报 / MD&A 深度检索优先使用 `exa --type deep`，实测直接命中 SEC.gov 原文（aapl-20240928.htm）
2. **英文关键词**：美股搜索推荐使用英文关键词（如 `10-K`、`earnings call`、`guidance`），命中率更高
3. **anysearch 海外检索**：`anysearch` 检索海外建议加 `--zone intl --language en`，已实测覆盖美股（NVDA 返回 $130.5B revenue, $2.94 EPS）
4. **SEC 公告信源**：`exa` 可直接命中 SEC EDGAR（sec.gov）原文；`doubao` 可覆盖 Bloomberg、Reuters 等海外权威信源
5. **中概股双重上市**：同时在 A股/港股/美股上市的公司（如阿里巴巴 BABA/9988），`doubao` 支持跨市场综合检索
6. **时区问题**：搜索结果的 `publish_time` 通常为信源本地时间，美股相关结果多为美东时间，与 yfinance 数据时区一致
7. **Tavily 网络稳定性**：Tavily 为海外服务，国内网络可能不稳定，作为美股辅搜使用
8. **完整选型决策流程**：参见 A股工具使用指南.md 搜索工具选型对比章节

### 6.5 PDF 文档处理工具

美股 SEC 财报（10-K / 10-Q）PDF 的文字与表格提取使用通用工具 `tools/common/pdf_extract.py`（基于 pdf-inspector 库），支持分类检测、纯文本提取、含财务附表的 Markdown 提取、全流程四种模式；检测到扫描格式时会返回 `scanned` 标志提示需走 OCR 流程。

**详细说明**（功能、子命令、参数、输出示例、扫描格式处理）请参阅 A股工具使用指南.md pdf_extract 章节。

**美股场景示例**:

```bash
# 分类检测（判断是否扫描件、总页数）
python tools/common/pdf_extract.py detect AAPL_10K.pdf
```

## 七、国际主要货币汇率（fx_rate.py）

获取国际主要货币汇率数据，支持 19 个货币对（美元兑主要货币、人民币兑主要货币、人民币与港币双向）。采用 **Akshare 优先、yfinance 回退** 的双数据源策略，获取**市场浮动汇率（收盘价）**（盘面K线），非央行中间价。

> **美股用途**：美股以美元计价。结合 `fx_rate.py` 获取的 USDCNY 等汇率，可将美股行情、市值折算为人民币口径，便于与 A 股、港股进行跨市场估值对比；EURUSD、USDJPY 等可辅助跨国营收、汇率敞口分析。

**美股相关货币对**：

| 货币对 | 报价方向          | akshare 代码       | yfinance ticker |
| ------ | ----------------- | ------------------ | --------------- |
| USDCNY | 1美元=x人民币     | USDCNH（离岸代理） | CNY=X           |
| USDCNH | 1美元=x离岸人民币 | USDCNH             | CNH=X           |
| EURUSD | 1欧元=x美元       | EURUSD             | EURUSD=X        |
| GBPUSD | 1英镑=x美元       | GBPUSD             | GBPUSD=X        |
| USDJPY | 1美元=x日元       | USDJPY             | JPY=X           |

**使用方法**：

```bash
# 列出所有支持货币对
python tools/common/fx_rate.py --list

# 获取美元/人民币汇率（默认最近 10 条）
python tools/common/fx_rate.py --code USDCNY

# 批量获取美元兑主要货币
python tools/common/fx_rate.py --code USDCNY,EURUSD,GBPUSD

# 指定日期范围并限制记录数
python tools/common/fx_rate.py --code USDCNY --start 2026-07-20 --end 2026-08-01 --max-records 20
```

**限流保护**：单次获取默认最多 10 条、硬上限 50 条（`--max-records` 超限自动裁剪到阈值）；批量获取最多 5 个货币对；任意两次调用间隔 ≥0.5 秒；瞬时异常指数退避重试，服务端封禁信号（东方财富 RemoteDisconnected 等）自动识别并立即回退 yfinance。

**完整说明**（功能、全部 19 个货币对、数据源策略与回退机制、注意事项）请参阅 [A股工具使用指南.md#十四fx_ratepy---国际主要货币汇率](A股工具使用指南.md#十四fx_ratepy---国际主要货币汇率)。

**注意事项**：本工具获取的是市场浮动汇率，不适合直接做财报折算（会计准则承认的央行中间价需单独获取）；yfinance 在中国大陆可能超时或被限流，本工具会自动回退数据源。
