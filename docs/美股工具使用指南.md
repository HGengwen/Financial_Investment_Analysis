### 1.1 stock_info.py - 实时行情与估值指标

使用 yfinance 库获取美股上市公司的实时行情与估值指标。

#### 获取个股实时行情与估值指标

```bash
python tools/us_stock/stock_info.py --realtime AAPL
```

**返回的关键字段**:

- `当前价格` (currentPrice)
- `开盘价` (open)
- `最高价` (dayHigh)
- `最低价` (dayLow)
- `昨日收盘价` (previousClose)
- `成交量` (volume)
- `市值` (marketCap)
- `市盈率TTM` (trailingPE)
- `市净率PB` (priceToBook)
- `52周最高` (fiftyTwoWeekHigh)
- `52周最低` (fiftyTwoWeekLow)
- `股息率` (dividendYield)
- `Beta系数` (beta)
- `ROE` (returnOnEquity)
- `ROA` (returnOnAssets)

### 1.2 stock_quote.py - 历史K线与三大指数

使用 yfinance 库获取美股个股历史K线及三大指数历史日线。

#### 1. 获取个股历史K线数据

```bash
# 默认最近一年数据（自动前复权）
python tools/us_stock/stock_quote.py --daily AAPL

# 指定日期范围
python tools/us_stock/stock_quote.py --daily AAPL --start 2025-01-01 --end 2026-07-29

# 不复权模式
python tools/us_stock/stock_quote.py --daily AAPL --no-adjust
```

**复权说明**:

- **前复权**（默认）：消除分红、拆股影响，反映真实投资回报
- **不复权**：显示原始价格，用于技术分析

**输出示例**:

```json

  "symbol": "AAPL",
  "data": {
    "count": 250,
    "columns": ["Open", "High", "Low", "Close", "Volume"],
```

## 二、数据源说明

### yfinance 库

- **来源**: Yahoo Finance
- **特点**: 免费、无需 token、无需积分、底层接口稳定
- **优势**:
  - 时区处理专业
  - 支持完整财务数据
  - 支持分红拆股、机构持股、分析师评级
  - 封装原生，比部分第三方 API 更可靠

### API 接口说明

| 接口                                | 功能               | 所属模块           | 返回数据                                |
| ----------------------------------- | ------------------ | ------------------ | --------------------------------------- |
| `yf.Ticker.info`                  | 实时行情与估值指标 | stock_info.py      | PE、PB、市值、股息率、Beta、ROE、ROA 等 |
| `yf.download`                     | 历史K线数据        | stock_quote.py     | 开高低收、成交量，支持前复权            |
| `yf.Ticker.income_stmt`           | 年度利润表         | stock_financial.py | 收入、成本、利润等                      |
| `yf.Ticker.balance_sheet`         | 年度资产负债表     | stock_financial.py | 资产、负债、股东权益等                  |
| `yf.Ticker.cashflow`              | 年度现金流量表     | stock_financial.py | 经营、投资、筹资现金流                  |
| `yf.Ticker.dividends`             | 分红历史           | stock_financial.py | 分红日期、金额                          |
| `yf.Ticker.splits`                | 拆股历史           | stock_financial.py | 拆股日期、比例                          |
| `yf.Ticker.institutional_holders` | 机构持股           | stock_financial.py | 机构名称、持股数、持股比例              |
| `yf.Ticker.recommendations`       | 分析师评级         | stock_financial.py | 强烈买入、买入、持有、卖出、强烈卖出    |

## 四、注意事项

### 1. 时区问题

yfinance 返回的数据是**美东时间（US/Eastern）**，如需北京时间可使用 `pytz` 转换：

```python
from pytz import timezone
import pandas as pd

# 美东时间转北京时间
eastern = timezone('US/Eastern')
beijing = timezone('Asia/Shanghai')
dt = pd.Timestamp('2026-07-29 10:00:00', tz=eastern)
dt_beijing = dt.tz_convert(beijing)
```

### 2. 中概股财报

部分中概股（如 BIDU、JD、BABA）的财报可能缺失或格式不一致，建议优先测试 AAPL、MSFT、NVDA 等美股龙头。

### 3. 财务报表格式

yfinance 财务报表默认行为：

- 行：科目（如 Total Revenue、Net Income）
- 列：报告期（如 2025-09-30、2024-09-30）

可用 `.T` 转置：

```python
df = stock.income_stmt.T  # 转置为行=报告期，列=科目
```

### 4. 数据延迟

免费接口数据可能有数分钟延迟，不适合高频交易。

### 5. 访问限制

高频请求可能触发风控，建议增加延时、分批请求。

### 6.3 重要内容多源验证（推荐）

美股财报分析建议**同时调用 2~3 个工具**互为补充：

```bash
# 优先调用豆包搜索（含正文 + 权威度筛选）
python tools/common/doubao_search.py "AAPL Q3 2026 earnings" --finance --need-content --export

# 补充 Tavily（深度内容）+ WebSearch（多源视角）
python tools/common/tavily_search.py "AAPL Q3 2026 management discussion"
python tools/common/web_search.py "AAPL Q3 2026 analyst reactions"
```

**优势**:

- `doubao_search.py`：海外信源覆盖广，正文能力强，适合 SEC 公告与投研报告自动化
- `tavily_search.py`：内容深度高，适合 MD&A 与分析师点评
- `web_search.py`：多源视角，适合行业新闻与跨市场情绪
- `exa_search.py`：语义向量检索 + 深度档位，适合研究型长文与专业领域查询

### 6.4 美股特有注意事项

1. **SEC 公告信源**: 豆包搜索可覆盖 SEC EDGAR（sec.gov）、Bloomberg、Reuters 等海外权威信源；如需定向检索 SEC 公告，可 `--sites sec.gov`
2. **英文关键词**: 美股搜索推荐使用英文关键词（如 `10-K`、`earnings call`、`guidance`），命中率更高
3. **中概股双重上市**: 同时在 A 股/港股/美股上市的公司（如阿里巴巴 BABA/9988），豆包搜索支持跨市场综合检索
4. **时区问题**: 搜索结果的 `publish_time` 通常为信源本地时间，美股相关结果多为美东时间，与 yfinance 数据时区一致
5. **完整选型决策流程**: 参见 [A股工具使用指南.md#十一搜索工具选型对比](A股工具使用指南.md#十一搜索工具选型对比)

### 6.5 PDF 文档处理工具

美股 SEC 财报（10-K / 10-Q）PDF 的文字与表格提取使用通用工具 `tools/common/pdf_extract.py`（基于 pdf-inspector 库），支持分类检测、纯文本提取、含财务附表的 Markdown 提取、全流程四种模式；检测到扫描格式时会返回 `scanned` 标志提示需走 OCR 流程。

**详细说明**（功能、子命令、参数、输出示例、扫描格式处理）请参阅 [A股工具使用指南.md#十三pdf_extractpy---pdf-文字与表格提取](A股工具使用指南.md#十三pdf_extractpy---pdf-文字与表格提取)。

**美股场景示例**:

```bash
# 分类检测（判断是否扫描件、总页数）
python tools/common/pdf_extract.py detect AAPL_10K.pdf

# 提取含财务附表的 Markdown 并写盘
python tools/common/pdf_extract.py markdown AAPL_10K.pdf --save-md --out-dir reports/pdf

# 全流程（分类 + 纯文本 + Markdown）
python tools/common/pdf_extract.py all AAPL_10K.pdf --save-md
```

**美股特有说明**: 美股工具暂不支持 `stock_equity.py` 自动下载财报 PDF，可通过 SEC EDGAR（sec.gov）获取 10-K / 10-Q PDF 后，再使用 `pdf_extract.py` 提取文字与财务附表。

## 七、国际主要货币汇率（fx_rate.py）

获取国际主要货币汇率数据，支持 19 个货币对（美元兑主要货币、人民币兑主要货币、人民币与港币双向）。采用 **Akshare 优先、yfinance 回退** 的双数据源策略，获取**市场浮动汇率（收盘价）**（盘面K线），非央行中间价。

> **美股用途**：美股以美元计价。结合 `fx_rate.py` 获取的 USDCNY 等汇率，可将美股行情、市值折算为人民币口径，便于与 A 股、港股进行跨市场估值对比；EURUSD、USDJPY 等可辅助跨国营收、汇率敞口分析。

**美股相关货币对**：

| 货币对 | 报价方向      | akshare 代码   | yfinance ticker |
| ------ | ------------- | -------------- | --------------- |
| USDCNY | 1美元=x人民币 | USDCNH（离岸代理） | CNY=X        |
| USDCNH | 1美元=x离岸人民币 | USDCNH     | CNH=X           |
| EURUSD | 1欧元=x美元   | EURUSD         | EURUSD=X        |
| GBPUSD | 1英镑=x美元   | GBPUSD         | GBPUSD=X        |
| USDJPY | 1美元=x日元   | USDJPY         | JPY=X           |

**使用方法**：

```bash
# 列出所有支持货币对
python tools/common/fx_rate.py --list

# 获取美元/人民币汇率（默认最近 10 条）
python tools/common/fx_rate.py --code USDCNY

# 批量获取美元兑主要货币
python tools/common/fx_rate.py --code USDCNY,EURUSD,GBPUSD

# 指定日期范围并限制记录数
python tools/common/fx_rate.py --code USDCNY --start 2026-07-20 --end 2026-08-01 --max-records 20
```

**限流保护**：单次获取默认最多 10 条、硬上限 50 条（`--max-records` 超限自动裁剪到阈值）；批量获取最多 5 个货币对；任意两次调用间隔 ≥0.5 秒；瞬时异常指数退避重试，服务端封禁信号（东方财富 RemoteDisconnected 等）自动识别并立即回退 yfinance。

**完整说明**（功能、全部 19 个货币对、数据源策略与回退机制、注意事项）请参阅 [A股工具使用指南.md#十三fx_ratepy---国际主要货币汇率](A股工具使用指南.md#十三fx_ratepy---国际主要货币汇率)。

**注意事项**：本工具获取的是市场浮动汇率，不适合直接做财报折算（会计准则承认的央行中间价需单独获取）；yfinance 在中国大陆可能超时或被限流，本工具会自动回退数据源。

## 九、局限性说明

1. **数据延迟**：免费接口数据可能有数分钟延迟，不适合高频交易
2. **中概股财报**：部分中概股财报可能缺失或格式不一致
3. **质量筛选**：暂不支持7条去劣指标筛选（可手动计算）
4. **分析师评级**：部分小盘股可能无分析师评级数据
5. **非实时数据**：工具获取的数据可能有延迟，不是实时数据
6. **不构成投资建议**：本工具仅供学习研究参考，不构成任何投资建议
