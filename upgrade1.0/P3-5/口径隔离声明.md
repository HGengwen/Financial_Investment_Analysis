## 1. 本子命令只做什么（纯计算边界）

`research` 子命令是**纯计算工具**，仅对调用方传入的电平值执行「给定输入 → 确定性评分」，禁止 LLM 心算：

1. 研发投入（8 分）：研发强度（3）+ 资本化审慎（2）+ 研发人员占比（3）。
2. 研发产出（8 分）：专利质量（2）+ 新产品收入占比（2）+ 产品化周期（2）+ 项目节点（2）。
3. 资本回报（4 分）：ROIC > WACC（2）+ 增量 ROIC > 存量 ROIC（2），**严格大于**。
4. 三维求和后三档判定：≥15 重仓 / 10~14 观察（单只上限≤5%）/ <10 放弃。
5. 输入校验（研发强度/资本化率/研发人员占比/新产品占比 0~100、定性 `优/中/差`）fail-fast 拒绝非法输入。

## 2. 本子命令不做什么（事实取证与舆断边界）

| 不做的动作 | 归属 |
| --- | --- |
| **不检索**研发强度/资本化率/研发人员占比/专利/新产品占比等原始数值 | P3-7 `annual_report_parser` 与技能编排取证 |
| **不重算** ROIC / 增量 ROIC / WACC | P1-1 `roic`、P1-2 `incremental-roic`、P1-3 `wacc` 结果，由调用方数值透传 |
| **不 import `financial_rigor`**（其 roic/incremental_roic/wacc 函数含 print 副作用） | 纯数值透传避免进程内副作用 |
| **不判定事实真伪**（专利质量/产品化周期/项目节点档位） | 技能编排层取证后作为档位传入 |
| **不固化事实**（不将任何公司数据写入代码或磁盘常量） | 本工具无网络/缓存/落盘，事实均为调用方入参 |
| **不实现**诚信否决闸门 | 诚信否决属 `management` 子命令专属，`research` 输出无 `integrity_veto` 字段 |
| **不合成**「管理层 + 科研转化两套都须≥15」 | P4-6 技能编排承担，本子命令只输出单套 verdict |
