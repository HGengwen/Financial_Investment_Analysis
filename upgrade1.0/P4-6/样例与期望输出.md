### 2.1 夹具序列生成器（确定性，逐字）

```python
# -*- coding: utf-8 -*-
"""P4-6 交付件4 样例实测脚本（用于复现 T1~T9 输出）。"""
from __future__ import annotations

import json
import random
import sys

from tools.common import momentum


def gen(n: int, seed: int, base: float = 100.0, vol: float = 0.02,
        drift: float = 0.0) -> tuple:
    """生成确定性 OHLC 序列（仅需 high/low/close）。"""
    r = random.Random(seed)
    closes, highs, lows = [], [], []
    c = base
    for _ in range(n):
        c = c * (1 + r.gauss(drift, vol))
        hi = c * (1 + abs(r.gauss(0, vol / 2)))
        lo = c * (1 - abs(r.gauss(0, vol / 2)))
        closes.append(round(c, 2))
        highs.append(round(hi, 2))
        lows.append(round(lo, 2))
    return highs, lows, closes


def dump(raw: dict) -> str:
    """以固定缩进输出 JSON，便于逐字比对。"""
    return json.dumps(raw, ensure_ascii=False, indent=1)


out = {}

# T1 低波动（k = 5.53% < 8%，不适用 ATR）/ multiplier=2.0
h, l, c = gen(40, 11, vol=0.02)
out["T1"] = {"stop": momentum.stop_price(h, l, c, entry_price=100.0, multiplier=2.0)}

# T2 高波动（k = 33.64% > 20%）/ multiplier=3.0（预期封顶 20%）
h, l, c = gen(40, 88, vol=0.09)
out["T2"] = {"stop": momentum.stop_price(h, l, c, entry_price=100.0, multiplier=3.0)}

# T3 低波动（k = 1.96% < 8%，不适用 ATR）/ multiplier=2.0
h, l, c = gen(40, 33, vol=0.008)
out["T3"] = {"stop": momentum.stop_price(h, l, c, entry_price=100.0, multiplier=2.0)}

# T4 数据不足（n=10，有效 TR=9 < 14）
h, l, c = gen(10, 44, vol=0.02)
out["T4"] = {"stop": momentum.stop_price(h, l, c, entry_price=100.0, multiplier=2.0)}

# T5 护栏：entry_price=0
h, l, c = gen(40, 11, vol=0.02)
out["T5"] = {"stop": momentum.stop_price(h, l, c, entry_price=0.0, multiplier=2.0)}

# T6 交叉校验：atr() 与 stop_price()["atr14"]；round 后反推的差异
h, l, c = gen(40, 11, vol=0.02)
_atr = momentum.atr(h, l, c)
_sp = momentum.stop_price(h, l, c, entry_price=100.0, multiplier=2.0)
naive = round(100.0 - 2.0 * _atr, 2)
out["T6"] = {"atr_round": _atr, "stop": _sp, "naive_from_rounded_atr": naive,
             "gap": round(_sp["stop_price"] - naive, 2)}

# T7 中波动序列（k = 16.98% ∈ [8, 20]）multiplier 2 vs 3
h, l, c = gen(40, 22, vol=0.06)
out["T7"] = {"mult2": momentum.stop_price(h, l, c, entry_price=100.0, multiplier=2.0),
             "mult3": momentum.stop_price(h, l, c, entry_price=100.0, multiplier=3.0)}

# T8 无效 multiplier（沿用 T7 序列，atr14 = 8.49）
out["T8"] = {"stop": momentum.stop_price(h, l, c, entry_price=100.0, multiplier=0.0)}

# T9 高波动档判定样本（multiplier=2.0 下 stop_pct = 33.64% > 20%）
h, l, c = gen(40, 88, vol=0.09)
out["T9"] = {"stop": momentum.stop_price(h, l, c, entry_price=100.0, multiplier=2.0)}

print(dump(out))
sys.exit(0)
```

### 2.5 工具层期望处置映射（技能层必须落地的分档）

| 工具返回形态 | 技能层判定 | 依据 |
| --- | --- | --- |
| **`k` < 8%（低波动档）**（如 T1 = 5.53 / T3 = 1.96） | **不适用 ATR** → 一律 **8%~10% 硬止损**（含底仓路径）；工具三字段**仅作留痕**，**不作止损线** | 框架行 472 + `GX-15` |
| **8% ≤ `k` ≤ 20%（中波动档）**（如 T7-mult2 = 16.98） | 封顶**未**生效 → `multiplier` **固定 2.0**；有效止损幅度 = `k`；有效止损价 = `stop_price` | `GX-4` + 波动分档 |
| **`k` > 20%（高波动档）**（如 T9 = 33.64） | `multiplier` 取 **2.0~3.0（须说明理由）**；`stop_pct` > 20 → 封顶**生效** → 幅度取 **20%**，有效止损价 = **买入价 × 80%**；原始 `stop_price` 作「未封顶参考值」**并列呈现** | `GX-4` + 波动分档 |
| 三字段 `null`（如 T4 / T5 / T8） | **回退 8%~10% 硬止损口径**，标「ATR 未取得」；**不得**用其他窗口近似 | 数据缺失处理节 |

> **封顶生效时的动作顺序**：高波动档的 ATR 有效止损价落在 −20% 处，触及该价**同时**等于达到「深跌 >20%」门槛 → 须**先跑衰退清单复核、再按清单结论定动作**（见 S6.3 / S6.4）；**不得**仅凭跌幅直接下卖出结论。

| 概念 | 数值 | 语义 | 处置 |

## §4 用法错误与越界情形（E1~E15）

### 4.1 工具侧错误（E1~E6，**已实测确认**）

| 编号 | 错误用法 | 实测结果 | 危害 / 拦截要求 |
| --- | --- | --- | --- |
| **E1** | `python tools/common/momentum.py --stop-price` | **无任何输出，退出码 = 0**（静默空跑） | **静默失效**：看起来「跑过了」但什么都没算 → 必须改用**内联模块调用** |
| **E2** | `python -m tools.common.momentum` | **无任何输出，退出码 = 0** | 无 `__main__` → 同上 |
| **E3** | 用 `round(atr14, 2) × multiplier` 反推止损价 | `atr_round = 2.77` → 反推 **94.46**；工具 `stop_price()` = **94.47**；**gap = 0.01** | 反推口径**偏离工具真值** → 一律以 `stop_price()` 为准 |
| **E4** | `stop_price(..., entry_price=0.0, ...)` | `{"atr14": 2.77, "stop_price": null, "stop_pct": null}` —— **静默降级，不抛异常** | 须显式判 `None` 并走「数据缺失处理」；**不得**把 `null` 当 0 |
| **E5** | `stop_price(..., multiplier=0.0)` | `{"atr14": 8.49, "stop_price": null, "stop_pct": null}` —— **静默降级** | 同上；`multiplier` 必须取 **2~3** |
| **E6** | `financial_rigor.py calc --expr "2^10"` | `❌ 不安全的表达式: 2^10` | 幂运算须用 `**`；负号开头表达式须写 `--expr="-3+12"` |

> **E1 / E2 是本次实测新增的高危发现**：失败模式不是报错，而是**静默成功**。故本技能**不得**以任何 CLI 形态调用 ATR，必须 `from tools.common import momentum` 内联调用。
