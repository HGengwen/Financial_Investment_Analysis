### 2.3 复现性问题（R04~R05）

#### R04 — 复现性问题：`momentum.py` **无 CLI**（高危静默失效）

**命令与原始输出（逐字）**：

```
[R04] python tools/common/momentum.py --stop-price  ->  returncode=0 | stdout='' | stderr=''
[R04] python -m tools.common.momentum  ->  returncode=0 | stdout='' | stderr=''
```

**判定**：⚠️ **高危静默失效**——两种「看起来像 CLI」的调用形态均**不报错、不提示、退出码 0、无任何输出**。使用者极易误以为「已执行成功」而实际**未取得任何数值**。

**处置**：

1. `SKILL.md` 以 `GX-5` 硬编码 **一律内联模块调用**（`from tools.common import momentum`），并在「工具使用注意」中**显式列为禁止形态**；
2. 本技能的运行记录中，凡 ATR 相关条目**一律**以 `python -c "from tools.common import momentum; ..."` 形态留痕；
3. **不新增其命令行包装**（本技能为编排层，`GX-13`：不新增工具、不建聚合器）——该缺陷的 CLI 层修补**不属本任务范围**，已列入 §4 待上报。

#### R05 — 复现性问题：`financial_rigor.py` **不支持 `--json`**

**命令与原始输出（逐字）**：

```
[R05] returncode=2
[R05] stderr 末行: financial_rigor.py: error: unrecognized arguments: --json
```

**判定**：✅ **预期拦截**——`--json` 非本工具能力（工具从未声明该开关）。结构化结果以**末行 `结构化输出: {...}`** 呈现。

**处置**：本技能的样例与运行记录中，**不构造 `--json` 调用**；需要结构化取值时，从末行 `结构化输出:` 行解析。此项**非工具缺陷**（与 P4-5《回归核对记录》§9 已撤销事项②同口径）。
