## 四、与 1~3 年中期链的口径隔离对照

对照基准：既有技能 `valuation-thermometer`（中期链估值温度计，七步流程 + 五档温度表）

| 维度 | **1~3 年中期链**（`valuation-thermometer`） | **1~5 年 GARP 独立档**（本技能） | 隔离性质 |
| --- | --- | --- | --- |
| 持有周期 | 1~3 年 | **1~5 年** | 档位不同 |
| 大师体系 | 四大师（欧奈尔 / 林奇 / 郑希 / 李进） | **五大师（+ 费雪）** | **替换** |
| 主锚结构 | **单一主锚**（PEG / PE 分位 / implied-growth 等四工具中选一） | **类型五分主锚矩阵**：快速增长型→**调整后 PEG**；高研发投入型→**PS/EV-Sales + Rule of 40**；未盈利科技型→**PS/EV-Sales + 研发管线 NPV**；稳定增长型→**远期 PE + 隐含 PEG**；成熟型企业→**DCF**（框架行 381~387） | **整体换锚（三大硬差异之一）** |
| 类型判定 | 无（不区分公司类型） | **强制类型五分且须留证**（`GV-1`）；「类型选错，后面全是错的」 | **净新增** |
| 档位体系 | **五档温度表**（唯一权威，硬编码） | **统一收口六档**：显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支（门禁 **A-1**）；PEG 类与非 PEG 类**分列两张映射表** | **重构** |
| PEG 合理区间 | 固定口径 | **随宏观浮动**：`0.8~1.0`（加息/过热）↔ `1.2~1.5`（降息/复苏）（框架行 700~704 / 736~741）；**滞胀最紧取 `0.8`**（框架行 746）；衰退/滞胀对返回**单值**时下限沿用最紧档 **0.8**（门禁 **B-1**） | **重构（三大硬差异之二）** |
| 辅助指标处置 | 交叉校验与降级规则 | **辅助指标只降不升**（`GV-5`）——PE 分位 / 隐含增速与主锚冲突时**最多降一档**，禁止「用好看的辅助指标翻案」 | **重构** |
| 工具内置评级 | 工具即口径来源 | **一律不进档位判定**（`GV-2`）：`adjusted-peg` 的 `tier` / `peg` 的 `rating` 分档与本框架六档不一致，**只取数值** | **净新增纪律** |
| ESG 环境折价 | 无 | **叠加**：多工具估值照算，ESG 折价**施加在其结果之上**（框架行 429 / 436）；本技能**三级留痕**：基准 → 宏观校准后 → ESG 折价后 → 最终档位（门禁 **C-1**） | **净新增（三大硬差异之三）** |
| 判定顺序 | — | **先宏观 → 后 ESG**（门禁 C-1 用户拍板：**偏离原推荐的"先 ESG 后宏观"**），理由：宏观区间是档位分母，ESG 是在已定档位上的进一步折价 | **净新增** |
| 仓位处置 | **「仓位上限硬编码」+「底仓/机动仓操作映射」**（技能内给出仓位数值） | **只透传、不裁量**（`GV-7`）：`cash_floor` / `single_cap` / `industry_cap` / `single_caps` / `position_cap_after` **原样呈现**；**报告不得出现"建议单只上限 X%"**；最终数值归 `garp-portfolio-review`（P4-8） | **移出 + 转接（机制差异）** |
| 风控编号 | **无硬编码编号前缀**（实测：无 `R-*` / `VT-*`） | **`GV-1`~`GV-12`**（GARP Valuation，全新前缀） | **净新增** |
| 输出报告 | `六段式`（估值结论 / 四工具数值表 / 档位判定依据 / 底仓机动仓建议 / 数据来源 / 不确定性） | **九段式**（含「类型判定与留证」「主锚选择依据」「宏观校准留痕」「交叉校验」「ESG 折价」「统一档位收口」「分批建仓节奏」「下游转接」） | **重构** |
| 报告文件名 | `{公司名}-valuation-thermometer-{YYYYMMDD}.md` | `{公司名}-garp-valuation-{YYYYMMDD}.md` | **不冲突** |
| 数据时效 | 数据时效性与市场差异节 | 同样强制「数据截止日期」+ `as_of` 留痕；**宏观 `data` 子命令的 `manual_review` 标志原样透传** | 一致（本技能强化留痕） |

**隔离结论**：本技能与 `valuation-thermometer` **不共享任何量化阈值**——档位数（6 vs 5）、主锚结构（类型矩阵 vs 单一主锚）、PEG 区间（浮动 vs 固定）、仓位处置（只透传 vs 硬编码）、ESG/宏观叠加（有 vs 无）**全部不同**；二者结论即便对同一家公司不一致，也**不构成冲突**（档位与口径本就不同），属**功能互补**。

**PEG 类与非 PEG 类的口径来源声明（门禁 A-1）**：PEG 类六档映射**直接来自框架**（宏观校准区间 `[L, U]` + PEG 红线段）；**非 PEG 类操作化刻度**（高研发投入型倍数带 `0.6×/0.8×/1.2×/1.5×/2.0×`；未盈利科技型里程碑 + 现金跑道 `36/12` 个月，「显著低估」档**为空**；成熟型企业安全边际 `40%/20%/0%/20%/−50%`）**非框架原文**，为**本任务的操作化落地**，已在 `SKILL.md` 与《样例与期望输出.md》**逐处标注「非框架原文」**。
