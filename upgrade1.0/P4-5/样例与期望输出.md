## §1 夹具说明（构造示意数据声明）

1. **全部数值均为构造的示意图**，用于验证口径与判定链路，**不代表任何真实公司或其真实估值水平**。
2. 构造原则：**每个夹具只隔离一个待验证变量**（如 S1 只隔离「研发费用化扭曲」），其余输入保持中性，避免多因素混同导致无法归因。
3. 标杆样例中的**工具输出为真实执行结果**（命令与结构化输出逐字复制，见 `样例运行记录.md`）；**夹具输入值**为构造值。
4. 构造夹具时**刻意避开真实公司名**，以防示意数值被误读为对某公司的实际结论。
5. **每个夹具的输入必须完整标注口径**（币种 / 时点 / 增速来源），缺失即按 `GV-10` / `GV-11` 降级。

## §2 标杆样例（S1~S9）

### S1 快速增长型 · 调整后 PEG × 研发费用化扭曲对照（验收 6.2）

#### S1.1 夹具输入

| 项 | 值 | 口径说明 |
| --- | --- | --- |
| 市值 | 1,000.00 | 构造值（亿元） |
| 核心经营利润 | 20.00 | **剔除研发费用化影响后的核心口径** |
| 费用化研发支出 | 25.00 | 全额费用化（无资本化） |
| 未来 2~3 年一致预期增速 | 30.00% | 百分点口径（≥2 源一致） |
| 报表口径 PE（对照用） | 50.00 | 含研发费用化拖累 |

#### S1.2 实测命令与输出

```bash
python tools/common/financial_rigor.py adjusted-peg \
  --market-cap 1000 --core-operating-profit 20 --rnd-expense 25 --growth 30
```

结构化输出（逐字）：

```json
{"adjusted_pe": 22.22, "adjusted_peg": 0.74, "tier": "低估", "verdict": "低估（PEG<1，可加仓）", "warnings": [], "inputs": {"market_cap": 1000.0, "core_operating_profit": 20.0, "rnd_expense": 25.0, "growth": 30.0}}
```

对照的**报表口径**（仅作反例，**不得作为主锚**）：

```bash
python tools/common/financial_rigor.py peg --pe 50 --growth 30
```

```json
{"peg": 1.6666666666666667, "rating": "高估 (>1.5)"}
```

辅助精算（调整后 PE，精确值）：

```bash
python tools/common/financial_rigor.py calc --expr "1000/(20+25)"
#  结果: 22.22   精确值: 22.22222222222222
```

#### S1.3 期望结论

| 步骤 | 数值 | 判定 |
| --- | --- | --- |
| 公司类型 | 增速 30.00% ≥ 20% 且盈利稳定 | **快速增长型** |
| 主锚 | 调整后 PEG = **0.74** | 宏观基准区间 `[1.0, 1.2]`（中性，`L=1.0`） |
| 档位判定 | `0.74 < L − 0.2 = 0.8` | **显著低估**（绝佳买点；底仓可加；首批可按下限建仓） |
| 建仓节奏 | 见 §2 S1.4 | 默认三分法，首批 1/3 |
| 报表口径对照 | PEG = **1.67** > 1.5 | **高估**（不加仓；机动仓减持） |

**结论反转两档**（显著低估 → 高估），这正是框架行 421「研发费用化会虚增 PE、虚增 PEG」的量化证明，也是 `GV-2` 与 `GV-12` 第 4 项必须强制核查的原因。

> ⚠️ **`GV-2` 强制项**：`adjusted-peg` 工具自带 `tier="低估"`，其分档线是 `0.8`；本框架的低估线是 **`1.0`**（框架行 383）。S1 恰好两者同向，但**工具 `tier` / `verdict` / `rating` 一律不进档位判定**——档位只能由「统一收口六档」二次映射产生。反例见 S7（工具判「合理」，本框架判「合理偏贵」）。

#### S1.4 期望建仓节奏

- 档位为**显著低估** → 底仓可加、首批可按下限建仓；
- 但**仍须**先通过 `garp-investment-checklist`（P4-3）的门槛结论，本技能只回答「贵不贵」；
- 建仓初期（持仓 < 最终仓位 50%）执行 **8%~10% 硬止损**，**优先于**「跌破估值下限补仓」。

#### S2.3 期望结论（框架原文标准 + 操作化刻度换算，二者同时呈现）

**框架原文标准（行 384 / 行 389）逐条判定**：

| 标准 | 实测 | 是否满足 |
| --- | --- | --- |
| Rule of 40 ≥ 40（收入增速 + 利润率或 FCF 利润率） | 45.0（`profit` 口径） | ✅ 满足 |
| EV/Sales **低于同业可比** | 7.83× < 同业区间 9.5~10.5× | ✅ 满足 |

**操作化刻度换算（`本技能操作化刻度、非框架原文`，门禁 A-1）**：

| 判定项 | 数值 | 档位 |
| --- | --- | --- |
| EV/Sales ÷ 同业均值 | **0.78×** ≤ 0.8× | 满足「低估」带 |
| Rule of 40 | **45.0** ≥ 40 | 满足「低估」带 |
| 显著低估带（≤0.6× 且 ≥50） | 0.78× > 0.6× | **不满足** |
| **统一收口档位** | — | **低估** |

报告中**必须**同时写出「EV/Sales 倍数 7.83× vs 同业 9.5×/10.5×」与「Rule of 40 = 45.0（`profit` 口径）」两个**原始数值**，再给出换算档位，并标注「操作化刻度、非框架原文」。

#### S2.4 期望建仓节奏

- **低估** → 先建 1/3 首仓；

### S9 「不适用」判定与类型重定（验收 6.6）

> **`GV-9`**：增速 ≤0 / 亏损 / 周期顶点等情形须**显式判「不适用」**并按类型重定，**不得硬套 PEG**；三次重定仍不适用则出「数据不足，无法估值」。

#### S9.1 案例 a：未来增速为负 → PEG 不适用

| 项 | 值 |
| --- | --- |
| 未来 2~3 年一致预期增速 | **−5.00%** |
| 当前 PE | 12.00 |

**期望结论**：

1. **显式判「PEG 不适用」**——增速为负时 `PE ÷ 增速` 失去经济含义（负值 PEG 无档位语义）；
2. **重定类型**：增速 <10% 且现金流成熟 → **成熟型企业**；
3. 改走 **DCF** 主锚（`--fcf` 使用保守口径，`GV-4`）；
4. 报告中须写明「原拟类型：快速增长型 → 因增速为负判 PEG 不适用 → 重定为成熟型企业」的**完整链条**，**不得**静默跳档。

#### S9.2 案例 b：归母净利润为负 → 未盈利科技型

| 项 | 值 |
| --- | --- |
| 归母净利润 | **负值** |
| 研发强度 | 显著高于同业 |

**期望结论**：

1. 类型判定**优先级最高**（盈利为负 → 未盈利科技型），**不得**因「增速高」而套用快速增长型；
2. 主锚改走 **PS / EV-Sales**（`ev-sales`，同业可比 ≥2 家）；
3. 辅助走 **研发管线 NPV**（`pipeline-npv`），参数不全即 `data_insufficient=true` 并降级定性（`GV-10`）；
4. **不得**因未盈利而放弃估值（框架行 385）。

#### S9.3 案例 c：周期顶点低 PE（低 PE 陷阱）→ PEG 不适用

| 项 | 值 |
| --- | --- |
| 当前 PE | **12.00**（看起来便宜） |
| 行业周期位置 | **景气顶点**（产品价格处历史高位） |
| 未来 3 年盈利方向 | 下行（价格回落 → 盈利下降 → PE 被动抬升） |

**期望结论**：

1. 命中**估值陷阱第 1 项「低 PE 陷阱」**（框架行 417）→ 须在报告第八段**逐项留痕**（`GV-12`）；
2. **显式判「PEG 不适用」**——周期顶点盈利不可持续，PEG 的分母（增速）无预测意义；
3. **重定类型**：成熟型企业 → 主锚改走 **DCF**（用**保守**的周期中枢现金流，非顶点现金流）；
4. **不得**仅凭 PE = 12 判「低估」。

#### S9.4 三例速查

| 案例 | 触发条件 | 原拟类型 | 是否判「不适用」 | 重定类型 | 主锚 |
| --- | --- | --- | --- | --- | --- |
| **a** | 增速 −5% | 快速增长型 | ✅ **判不适用** | 成熟型企业 | DCF |
| **b** | 净利润为负 | （不可定为快速增长型） | ✅ **不适用 PEG** | 未盈利科技型 | PS / EV-Sales（+ 管线 NPV） |
| **c** | 周期顶点低 PE | 快速增长型 / 稳定增长型 | ✅ **判不适用** | 成熟型企业 | DCF（保守中枢口径） |

> 三例均须在报告第三段（公司类型判定）写明**依据 + 被排除类型 + 重定理由**（`GV-1`）。
