## 1. 本工具只做什么（纯计算边界）

`governance_data.py` 是**纯计算工具**，仅对调用方传入的电平值执行「给定输入 → 确定性评分」，禁止 LLM 心算：

1. 诚信否决闸门前置（5 项，任一命中即 `total=null`、`verdict=放弃`）。
2. 20 分制三维求和：对待股东 7 + 战略执行力 7 + 稳定性与激励 6。
3. 三档判定：≥15 重仓 / 10~14 观察 / <10 放弃。
4. 输入校验（数值 0~100、定性 `优/中/差`）fail-fast 拒绝非法输入。

## 2. 本工具不做什么（事实取证与舆断边界）

| 不做的动作 | 归属 |
| --- | --- |
| **不检索**兑现率/分红率/质押率/离职率等原始数值 | P3-7 `annual_report_parser` 治理字段抽取 |
| **不判定事实真伪**（是否造假/立案/减持异常/业绩预告失真/归因习惯异常） | 技能编排层取证后作为布尔/数值传入 |
| **不固化事实**（不将任何公司数据写入代码或磁盘常量） | 本工具无网络/缓存/落盘，事实均为调用方入参 |
| **不实现**仓位聚合（单只 10/15/20%、行业 40%、相关性、流动性） | `garp-investment-checklist`/`garp-management` 技能编排 |
| **不计分**费雪补充 / ESG 补充 | 仅在 `note` 字段提示存在，定性参考不计入 20 分制 |

## 3. 时变 / 静态分层

| 层 | 内容 | 说明 |
| --- | --- | --- |
| 静态 | 7+7+6 权重表、≥15/10 阈值、三档 verdict、否决规则表 | 框架明示长期适用，常量固化 |
| 时变 | 兑现率/分红率/质押率/离职率数值、否决事实、定性档位取值 | 随财报/公告动态变化，通过 `--as-of` 透传 + `time_sensitivity_note` 警示 |
