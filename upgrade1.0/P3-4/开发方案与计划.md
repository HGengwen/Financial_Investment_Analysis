## 0. 结论摘要（TL;DR）

本任务新建纯计算工具 `governance_data.py`，将框架第 3 步·支柱三的「管理层 20 分制」下沉为可执行工具命令，禁止 LLM 心算。

- **输入**：诚信否决闸门输入 + 对待股东 / 战略执行力 / 稳定性与激励三个维度的评分项（客观数值 + 定性档位 + 布尔标志）。
- **输出**：JSON，核心字段 `{integrity_veto, total, verdict(重仓/观察/放弃), score_breakdown}`，附 `data_as_of` 时效回显与口径来源标注。
- **核心难点**：框架只给出「7+7+6=20」三个维度的**总分**，未给出各维度内部子项的精确分值；本方案需将「子项 → 分数」的扣分/加权规则固化为可测试的确定性规则（§5.3），并在实现阶段以代码常量落地，消除 LLM 临场判断。
- **时变性与边界（与 P3-1 同构的分层）**：7+7+6 权重规则与 ≥15/10 阈值是**静态标签**（框架明示），但**各评分项的"取值判定"是时变项**——兑现率、分红率、质押率、离职率、以及"是否财务造假实锤"等事实，会随财报/公告动态变化。故本工具**不检索、不判定事实真伪、不固化事实**（实时取证交由 P3-7 `annual_report_parser` 治理字段与技能编排），只对调用方传入的电平值做确定性评分。含「费雪十五要点 / ESG」两项补充检查（定性参考，不计入 20 分制）仅在输出 `note` 提示其存在，**不纳入打分**。不含科研转化 20 分制（P3-5）、不含 ESG 环境折价（P3-6）。

## 1. 目标与范围

### 1.1 目标

新建 `tools/specialized/governance_data.py`，实现：

1. **诚信否决闸门前置**：命中任一否决项即 `integrity_veto=true`、`total` 无效、`verdict=放弃`，不进入 20 分制求和。
2. **20 分制三维求和**：对待股东 7 分 + 战略执行力 7 分 + 稳定性与激励 6 分 = 20 分。
3. **三档判定**：≥15 重仓；10~14 观察（单只上限 ≤5%，不重仓）；<10 放弃。

### 1.2 包含范围

- 诚信否决闸门规则表（常量固化，不计分）。
- 20 分制三维子项权重表（§5.3，常量固化）。
- 三档 `verdict` 与退档规则。
- 输入校验（数值范围 + 档位词表，fail-fast 拒绝非法输入）。
- 可选入参 `--as-of`（评分数据截止日期）透传 + 输出时效警示。
- CLI 子命令 `management`（单次评分，输出 JSON）。
- 单元测试（否决全命中 + 20 分边界 + 三档阈值边界 + 输入越界拒绝 + JSON 可解析）。

### 1.3 不包含范围（明确排除，防范围蔓延）

- **不含**科研转化 20 分制（8+8+4，P3-5）。
- **不含**ESG 环境风险折价（8~9折 / 搁浅资产贴现率 / 仓位上限下调，P3-6）。
- **不做**事实取证与网络检索——兑现率/分红率/质押率/离职率的数值、"是否造假/立案/减持异常"的判定，属 P3-7 与技能编排职责；本工具仅做「给定输入 → 确定性评分」。
- **不含**仓位聚合器（单只 10/15/20%、行业 40%、相关性、流动性等属框架第三部分，由 `garp-investment-checklist`/`garp-management` 技能编排）；本工具仅在 `verdict` 附注档内提示「观察仓 ≤5%」的退档含义，不实现仓位计算。
- **不含**费雪补充 / ESG 补充的计分（框架明示「定性参考，不计入 20 分制」），仅 `note` 提示。
- **不改动**既有 `.trae/skills/` 下技能文件。
- **不改动**既有工具签名（`geo_policy_screen.py` / `annual_report_parser.py` / `financial_rigor.py` 等仅作风格参照或后续依赖，本任务不修改其内容）。

## 2. 关键量化口径（唯一权威 = 框架第 3 步·支柱三）

> 以下全部取自《中长期价值成长（GARP）投资框架》第 3 步·支柱三（行 278~298）。任何实现与本文档或总计划/详细计划不一致时，**以框架正文为准**。

### 2.1 诚信否决闸门（不计分，命中即放弃/清仓）

> 诚信维度**独立于 20 分制、不赋分**——一旦命中，无论管理层总分是否 ≥15，直接放弃或清仓，不进入 20 分制求和。20 分制满分虽为 20，但**仅由「对待股东、战略执行力、稳定性与激励」三项构成（7+7+6=20）**，诚信不占分、只作前置否决闸门。

框架诚信闸门检查项（原文 4 类检查项，其中「监管记录」含 2 个触发点，离散为 5 个否决 flag，见 §3.1）：

| # | 检查项 | 量化触发条件（本工具离散化） |
| --- | --- | --- |
| 1 | 年报"说到做到"验证 | 兑现率 < 50% 一票否决 |
| 2 | 业绩预告准确性 | 业绩预告重大失真 |
| 3 | 归因习惯 | 归因习惯异常（习惯性甩锅外部/不可控因素） |
| 4 | 监管记录 | 监管立案 或 财务造假实锤 |

### 2.2 管理层评估清单（20 分制，≥15 分方可重仓）

| 维度 | 检查项（框架原文） | 满分 |
| --- | --- | --- |
| **对待股东** | 分红历史（≥30% 为优）；融资记录；回购行为；大股东质押率（>50% 预警） | 7 |
| **战略执行力** | 是否聚焦主业；核心战略落地情况；行业格局认知深度 | 7 |
| **稳定性与激励** | 核心团队稳定性（离职率 <10%）；股权激励合理性；内部人（董监高/大股东）增减持是否异常（异常减持或违规交易 → 预警扣分） | 6 |

### 2.3 阈值与退档规则（权威照录）

- **≥15 分 → 重仓**。
- **10~14 分 → 部分不达标，退观察仓**（单只上限 ≤5%，不重仓）。
- **<10 分 → 放弃**。
- **诚信否决命中 → 直接放弃或清仓**，不进入 20 分制求和（`total` 无效）。

### 2.4 费雪补充与 ESG 补充（权威照录，均不计入 20 分制）

- 费雪补充：销售组织出色、管理层持股 ≥3%（定性参考）。
- ESG 补充：治理(G) 优先纳入并可与诚信否决联动；环境(E) 本节仅定性提示；社会(S) 辅助参考；ESG 评级尾部作预警信号。

> 上述两项**不计入 20 分制**。本工具在输出 `note` 中保留其存在提示，但不实现打分；具体联动（治理触发诚信否决、环境走估值折价）分别由 P3-5/P3-6 与技能编排承接。

## 5. 实现设计（五步，与详细计划对齐）

### 5.1 数据模型

- 常量 `VETO_FLAGS`：5 个否决项键名 → 中文标签映射（`fulfillment_rate / guidance_misstatement / attribution_habit / regulatory_filing / financial_fraud`）。
- 常量 `DIMENSION_SCORES`：三维度（7/7/6）名 → 子项权重与计分函数。
- 常量 `QUALITY_VALUES = ("优", "中", "差")`：定性档位词表。
- `build_governance_result(...) -> Dict[str, Any]`：组装 §3.3 顶层 JSON。

### 5.2 诚信闸门判定（实现步骤①）

判定顺序固定，任一命中即返回否决：

1. `--fulfillment-rate` 传入且 `< 50.0` → 命中 `fulfillment_rate`。
2. `--guidance-misstatement` → 命中 `guidance_misstatement`。
3. `--attribution-habit` → 命中 `attribution_habit`。
4. `--regulatory-filing` → 命中 `regulatory_filing`。
5. `--financial-fraud` → 命中 `financial_fraud`。

命中后：`integrity_veto=true`、`integrity_veto_reasons` 为全部命中项、`total=null`、`verdict=放弃`、`score_breakdown={}`，**不进入 20 分制求和**。

### 5.3 子项打分（实现步骤②，本任务核心难点 → §9.B 待确认）

框架只给三维总分，未给子项精确分值。本方案将三维内部权重固化为以下确定性规则（5 档"优/中/差"统一映射 + 3 项数值阈值 + 2 项布尔扣分）：

**对待股东（满 7 分）**

| 子项 | 计分规则 | 分值 |
| --- | --- | --- |
| 分红历史 `dividend_payout_ratio` | ≥30% = 2；15%~30% = 1；<15% = 0 | 2 |
| 融资记录 `financing` | 优=2；中=1；差=0 | 2 |
| 回购行为 `buyback` | 优=2；中=1；差=0 | 2 |
| 大股东质押率 `pledge_ratio` | ≤50% = 1；>50% = 0（预警） | 1 |

**战略执行力（满 7 分）**

| 子项 | 计分规则 | 分值 |
| --- | --- | --- |
| 聚焦主业 `core_focus` | 优=3；中=1；差=0 | 3 |
| 核心战略落地 `strategy_exec` | 优=2；中=1；差=0 | 2 |
| 行业格局认知深度 `industry_cog` | 优=2；中=1；差=0 | 2 |

**稳定性与激励（满 6 分）**

| 子项 | 计分规则 | 分值 |
| --- | --- | --- |
| 核心团队稳定性 `turnover_rate` | <10% = 2；10%~20% = 1；>20% = 0 | 2 |
| 股权激励合理性 `equity_incentive` | 优=2；中=1；差=0 | 2 |
| 内部人增减持异常 `insider_abnormal` | 无异常=2；异常=0（预警扣分） | 2 |

> 数值阈值边界采用「左闭右开」约定：`[30, 100]` / `[15, 30)` / `[0, 15)`；`[0, 10)` / `[10, 20)` / `[20, 100]`；质押率 `[0, 50]` / `(50, 100]`。中间档切点（15%/20%）为框架未明示的自定档，随 §9.B/C 一并确认。

### 5.4 阈值与 verdict 判定（实现步骤③）

```text
if integrity_veto:
    total = null; verdict = "放弃"
elif total >= 15:
    verdict = "重仓"
elif 10 <= total < 15:
    verdict = "观察"  # 部分不达标→观察仓，单只上限≤5%
else:  # total < 10
    verdict = "放弃"
```

### 5.5 样例（实现步骤④）

- **通过例**：三维满分（或高分）→ `integrity_veto=false`、`total=20`（或 18）、`verdict=重仓`。
- **否决例**：命中 `--financial-fraud` → `integrity_veto=true`、`total=null`、`verdict=放弃`。
- **边界例**：`total=15` → 重仓；`total=14` → 观察；`total=10` → 观察；`total=9` → 放弃（三档边界全覆盖）。

- 新文件可独立 `import`、`python -m` 无副作用，且不影响既有 `tools/specialized/` 其他模块。
