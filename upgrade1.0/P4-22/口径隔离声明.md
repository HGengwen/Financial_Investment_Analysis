## 4. §2.10.1 子串包含口径（**本任务新披露点，U7**）

### 4.1 问题陈述

三档命名体系存在**子串包含**关系，若用**短串**计数会产生**假阳性**，导致隔离核验失真（方案 §7 R9）：

| 短串 | 被包含于 | 后果 |
| --- | --- | --- |
| `-garp-` | `-garp-wechat-`（**是前缀子串**） | 用 `-garp-` 计数会把**本技能产物误计入系列长文** |
| `wechat-article` | `-garp-wechat-` 与 `-mid-wechat-` 的**技能名片段** | 用 `wechat-article` 计数会把 `mid-wechat-article` / `garp-wechat-article` **全部误计入长期链** |
| `-garp-wechat-` | 未被他串包含 | ✅ 可安全用于本档核验 |
| `mid-wechat-article` | 不含 `-mid-wechat-`（**首字符为 `m`，无前导连字符**） | 用 `-mid-wechat-` 核验**不会**误伤技能名本身 |

### 4.2 核验口径（**强制**）

1. **文件名核验**：必须使用**完整后缀段**
   - 本档：`-garp-wechat-{YYYYMMDD}`
   - 本档内系列长文（他技能）：`-garp-{YYYYMMDD}`
   - 二者**互不为子串**（前者 `-garp-` 后接 `wechat-`，后者接数字）
2. **技能名核验**：必须使用**完整技能名**（`garp-wechat-article` / `mid-wechat-article` / `wechat-article`），**禁止**使用 `wechat-article` 作为计数串。
3. **反向核验**：相邻两档技能中**不得**出现对本档的**职能性引用**（引用本档内部流程），仅允许**三向划界**性质的指路引用。
