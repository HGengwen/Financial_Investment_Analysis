## 1. 目标与范围

### 1.1 目标

产出 GARP 独立档（**1~5 年**）的**单篇公众号文章**技能 `/garp-wechat-article {主题}`，并做到——

1. **五大师口径贯穿全篇**（共性 1 + 验收要点）：设计理念由骨架「四位景气大师（欧奈尔 / 林奇 / 郑希 / 李进）」**扩为五大师**（**费雪 / 林奇 / 郑希 / 李进 / 欧奈尔**，与 P4-12 / P4-13 / P4-19 / P4-21 **同序同口径**）；**六处**落位刚性（frontmatter `description` / 设计理念表 / 头部引语块 / 附录 A 速查卡 / 景气投资类文章结构 6 段→7 段 / 编辑审阅标准 + 读者问题）；`四大师` 命中 **= 0**（`GWA-2`）。
2. **三 Agent + 四阶段完整承接**（验收要点）：作者-编辑-读者三 Agent 不可退化为单 Agent；四阶段（研究 / 初稿 / 并行审阅 / 定稿）不可跳过；「编辑与读者冲突时**偏向读者**」刚性保留（`GWA-1`）。
3. **职能边界唯一性**（本技能**新增核心差异**）：**独立选题 / 单篇排版 / 平台投放**职能**唯一归属本技能**；`garp-earnings-team` 阶段三只产「本报告配套文章」（`GET-12`）、`garp-deep-company-series` 只产「系列长文」——三者**互不替代**，本技能须在「与现有 Skill 的关系」表中**显式划界**。
4. **共性口径七处替换全命中**：共性 **1** 为**点名差异**；共性 **2 / 3 / 4 / 5 / 6 / 7** 为**连带替换**（§7.2 刚性要求）；逐项对照见 §4.4。
5. **渗透率按 GARP 黄金窗判定**（共性 2）：渗透率判定由骨架「`10%~30%` 黄金区 / `15%` 加速临界点」改为 **`15%~40%` 五档** + **TAM ≥1000 亿**；**<5% 且无 EPS / 订单支撑 → 判题材**；每处并列标注**国产化率四梯队**（只读 `localize`）（`GWA-4`）。
6. **口径零复制（引用不重复定义）**：估值档位 / 卖出五级 / 管理层与科研转化分制 / 诚信前置闸门 / 三维交叉矩阵 / 宏观三表 / 渗透率与国产化率 / 六类分类 / 仓位上限 —— **一律引用**（指向框架章节号或 `garp-*` 技能出口或工具命令），本技能**只定义写作流程与编排**（`GWA-3`）。
7. **三档并存路由隔离**：技能内引用**只指向** `garp-*` 系列与两个复用技能（`qoq-accelerator` / `trend-momentum-scan`）；**禁止**引用 1~3 年中期链（`mid-*`）与 10 年长期链（`wechat-article` / `deep-company-series` / `quality-screen` / `investment-research`）技能；**禁止**出现 `--horizon`、`P0~P5`、`mid-wechat-article`、`-mid-wechat-` 等档位切换类口令与跨档路径（`GWA-10` / `GWA-11`）。
8. **风控硬编码 `GWA-1`~`GWA-12`**：骨架为**无编号化风控**（「注意事项 1~14」+「核心原则 1~8」裸列表），本技能**新建编号族**并附 **22 条 → `GWA-` 覆盖映射表**，保持「一技能一编号族」定例与三档隔离。
9. **零新增 CLI、引擎零改动**：`tools/common/*` 与 `tools/specialized/*` **不改签名、不改行为、不新增子命令**；估值档位经 `garp-valuation` 转接、卖出阈值经 `garp-exit` 转接、管理层计分经 `garp-management` 转接、地缘矩阵经 `garp-geo-policy` 转接、宏观参数经 `garp-macro` 转接；本技能不自建档位链 / 止损链 / 计分链 / 地缘评分链；**禁用** `terminal_value.py`。
10. **「内容输出」而非「下指令」的刚性边界**：本技能输出**可公开发布的单篇文章**；**不回答**「现在是否买入」；**不含**目标仓位 / 减仓百分比 / ATR 止损价等指令性数值；文中的估值与卖出**只读** GARP 出口技能，买入前须执行 `/garp-investment-checklist`（P4-3，**已交付**）（`GWA-6`）。
11. **报告路径 + 命名规约**：产出 `-garp-wechat-{YYYYMMDD}` 后缀文件（三档隔离），配图落 `assets/{主题简称}/`，见 §2.10。
12. **发布前准出刚性**（验收要点）：文章落盘后**必须**跑 **`report_audit.py` 抽检**（**偏差 ≤1% 准出、>1% 打回并重新抽检**）+ **隐私 grep**；**未通过不得推送 GitHub**（`GWA-8` / `GWA-9`）。
13. **双门禁 + 七项交付件**：开工门禁 A~H（本文件 §9）+ 完成门禁留痕（详细计划 §0.7）；交付件严格对齐 §0.5「技能类七项」。
