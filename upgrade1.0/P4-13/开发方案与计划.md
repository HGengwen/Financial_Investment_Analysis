## 1. 目标与范围

### 1.1 目标

产出 GARP 独立档（**1~5 年**）的**单公司团队化研究**技能 `/garp-investment-team {公司名}`，以「**五 Agent 并行 + Team Lead 综合研判**」产出系统化报告，并做到——

1. **五 Agent 并行**（共性 1，核心差异）：**Agent 1 欧奈尔**（风控底线：硬止损位、趋势与技术信号、底线纪律）+ **Agent 2 林奇**（选股起点 + 估值定价：生活常识选股、六类归类、财务初筛、估值陷阱、按公司类型选估值锚）+ **Agent 3 郑希**（赛道选择：产业景气、ROE 拐点、渗透率五档、国产化率四梯队、0.3 三维矩阵归属与赛道两分法）+ **Agent 4 李进**（组合管理 + 治理：底仓/机动仓、仓位上限、管理层 7+7+6、科研转化 8+8+4、ESG、诚信闸门）+ **Agent 5 费雪**（质化分析与长期持有：闲聊法第一手调研清单、十五要点质化筛选、销售组织、管理层持股≥3%、暂时性困难 vs 永久性衰退、「绝不卖」两前提检验）；**同一 Agent 不得代行他人职责**，5 个 Agent 必须在**同一条消息**中并行启动；
2. **Team Lead 五维评分 + 三大收口**（验收要点）：汇总**不是拼报告，而是找交叉与矛盾**——①**共识点**（五位大师同意的结论可信度最高）②**矛盾点**（如林奇说估值便宜、郑希说景气拐头向下，这类矛盾最有价值）③**被忽略的角落**；产出 **五维评分总表**（风控底线 / 选股与估值 / 赛道选择 / 组合与治理 / **质化与长期持有**）+ 综合评分 X/5；并完成**三大收口**——**(a) 五级卖出收口**（引 `garp-exit`）、**(b) 估值六档收口**（引 `garp-valuation` 多工具矩阵 + 统一六档）、**(c) 三档结论收口**（照引框架第 3 步「五大支柱汇总判定」→ 可建仓 / 观察仓 / 放弃）；
3. **估值结论改多工具矩阵**（共性 6）：「**GARP PEG**」一律解释为 **调整后 PEG 主锚（快速增长型）**，Agent 2 按**五类公司类型**（快速增长型 / 高研发投入型 / 未盈利科技型 / 稳定增长型 / 成熟型）选主锚 + 辅锚 + 可接受标准，**统一收口 `garp-valuation`（P4-5）统一六档**（显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支），并叠加 **ESG 折价**与**宏观 PEG 合理区间**；骨架「单一 PEG 五档 + `valuation-thermometer`」**整段废止**；
4. **赛道与渗透率口径替换**（共性 2）：Agent 3 的渗透率改 **`15%~40%` 黄金窗五档**（<5% 导入早期观察不建仓 / 5%~15% 突破期小仓跟踪 / **15%~40% 加速上行黄金窗主建仓** / 40%~60% 逐步兑现持有不新建 / >60% 天花板不加仓；增速归零或转负即见顶清仓）+ **国产化率四梯队**（<5% 过早 / 5%~20% 突破期 / 20%~50% 加速投资期 / >50% 收窄），**一律引用 `garp-industry-research`（P4-9）**，本技能**不做赛道级测算**；骨架「渗透率→仓位映射表」**整段废止**（仓位一律按 GIT-1 硬上限）；
5. **地缘模块整段替换**（共性 3）：删除 Agent 3 的「地缘政治六维度」与「『华为式』抗封锁能力评估」，改为 **0.3 三维交叉矩阵 + 赛道两分法**（引用 `garp-geo-policy` P4-1）+ 敞口体检；矩阵**未列组合按更审慎相邻档归档**，**国字号注资不作买入估值依据**；
6. **管理层与科研转化口径替换**（共性 5）：Agent 4 **只引 `garp-management`（P4-4）**——**诚信前置不计分闸门** + **对待股东 7 + 战略执行 7 + 稳定性与激励 6** + **科研转化 研发投入 8 + 研发产出 8 + 资本回报 4** + 费雪补充项 + ESG 三通道；骨架 4 维度 5+5+5+5 评分表**不得复现**；**诚信一票否决为全团队单一权威闸门**（Agent 4 与 Agent 5 共用，不得双闸门双结论）；
7. **卖出与止损只引不重建**（共性 4）：**五级卖出**（诚信否决 > 硬止损 8%~10% > 逻辑止损 > 产业景气判断 > 估值判断）+ **时间止损**（持有满 4 季度逻辑未兑现）+ **性价比替换**（每季最多 1 次），**一律引用 `garp-exit`（P4-6）**；Agent 1 负责第 2 级专项、Agent 4 负责第 1 级闸门、Team Lead 负责五级收口；骨架 `P0~P5` 六级表**整段废止**；ATR 止损为建议工具且经 `garp-exit` 转接 `momentum.stop_price()`；
8. **叠加宏观三表校准**（共性 7）：Agent 3 / Team Lead 的宏观参数一律经 `garp-macro`（P4-2）/ `macro_calibrator.py` 透传——利率周期 → **PEG 合理买入区间**（加息/高利率 0.8~1.0 / 中性 1.0~1.2 / 降息/低利率 1.2~1.5）、经济周期 → **现金仓位与个股上限**（衰退现金 30%~40%、单只初始≤8% / 验证后≤12% / 绝对≤15%）、美林时钟 + 信用周期 → 宏观阶段收口；本技能**不判 stage、不心算**；
9. **五大矛盾化解**（Team Lead 汇总专节；骨架四大矛盾 → 框架五矛盾）：**矛盾一**买点哲学（左侧 vs 右侧，以「杀估值 vs 杀逻辑」为分水岭）+ **矛盾二**持有时间维度（连续 2~3 季数据趋势）+ **矛盾三**止损 vs 越跌越买（以「仓位状态」为分水岭 + 8%~10%）+ **矛盾四**分散 vs 集中（5~10 只 / 3~4 核心 / 2~3 卫星）+ **矛盾五**费雪「绝不卖」vs 趋势景气纪律（**两前提缺一不可**：极度深度的研究认知 + 极度集中的持仓）；
10. **信息丰富度与诚实原则**（继承骨架）：A/B/C 三级评级写入报告开头并**告知每个 Agent**，影响其研究方式；**C 级不得作确定性结论**，须列「需要一手验证的问题清单」；Team Lead 必须评估各 Agent 是否受资料充裕度限制、是否与市场共识过度趋同；
11. **结论明确**：报告必须给出**三档结论之一**（可建仓 / 观察仓 / 放弃）+ **底仓/机动仓分层建议** + **建仓价区间** + **硬止损位（具体价格）** + **五级卖出触发条件清单**，并**强制转接 `garp-investment-checklist`（买入口径）**。

### 2.2 五 Agent 团队架构与职责（**核心骨架：四 Agent + Team Lead → 五 Agent + Team Lead**）

### 2.8 估值：多工具矩阵 + 统一六档（**共性 6；只读 `garp-valuation`**）

**五类公司类型 × 估值矩阵（框架行 381~387，逐字落表）**：

| 公司类型 | 核心工具（主锚） | 辅助工具 | 可接受标准 |
| --- | --- | --- | --- |
| **快速增长型（盈利稳定）** | **调整后 PEG**（即「**GARP PEG**」） | 远期 PE、PEG 分位 | PEG<1 低估 / 1~1.2 合理 / 1.2~1.5 合理偏贵（持有不加仓、机动仓择机减）/ **>1.5 高估** |
| **高研发投入型（利润被压低）** | **PS / EV-Sales** | **Rule of 40** | **Rule of 40 ≥ 40**（收入增速 + 利润率或 FCF 利润率）；EV/Sales 低于同业可比 |
| **未盈利科技型** | PS、EV/Sales | **研发管线 NPV** | 需有清晰的盈利路径与里程碑节点 |
| **稳定增长型** | 远期 PE + **隐含 PEG** | 股息率 | 当前 PE ≤ 未来 3 年 EPS 复合增速（百分数值）×1.2（**隐含 PEG≤1.2**） |
| **成熟型企业** | **DCF** | 股息贴现 | 当前市值 ≤ **保守 DCF 估值的 80%** |

**三级留痕（统一收口）**：`基准档位 → 宏观校准后 → ESG 折价后 → 最终档位`，收口至 `garp-valuation`（P4-5）**统一六档**（**显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支**）。

**叠加规则**：
- **ESG / 环境风险折价**（框架行 424~439）：高环境风险行业**合理估值再打 8~9 折**；有明确碳减排承诺与可验证转型路径 → 折价收窄至 **≤5% 或豁免**；面临「搁浅资产」风险 → **DCF 贴现率额外上调 1~2 个百分点**；ESG 评级处行业尾部 → **先降仓位上限**（如绝对上限 20% → 15%），而非继续压估值。
- **宏观 PEG 区间**（§2.9）：框架 PEG 阈值以**中性宏观环境**为基准，加息/降息周期**动态上浮或下调**。
- **PEG 使用边界**（框架行 391）：PEG 适用于盈利稳定的成长股；PS/EV-Sales 适用于高研发投入或未盈利科技股；DCF 适用于现金流稳定的成熟企业；**科技股须多工具交叉验证，避免单一指标误判**。
- **科技股调整后口径**（框架行 422）：高研发投入公司研发费用化会虚增 PE/PEG，**务必用「核心经营利润」口径回算调整后 PE**（`adjusted-peg`）。

> **口径禁令**：`valuation-thermometer` / PEG 五档档位表 / `PSG` / `target_pe` **一律不得出现**（禁用词第 3 / 15 / 16 项）；本技能**零 PEG 档位自建**、**零估值结论自建**；「**GARP PEG**」在报告中须以「**调整后 PEG（快速增长型主锚）**」表述，**不得**被解释为独立档位表。

### 2.9 宏观三表与 PEG 区间联动（**共性 7，新增**）

| 表 | 权威值（框架行 695~748） |

| **（二）经济周期 → 现金与个股上限** | 中性/复苏：现金 **10%~20%**（估值分位>80% 时提至 20%~30%）、单只 初始≤10% / 验证后≤15% / 绝对≤20%、单一行业 ≤40%；衰退：现金 **30%~40% 或更高**、单只 **≤8% / ≤12% / ≤15%**、单一行业 **≤30%**；过热：单只 ≤8% / ≤12% / ≤15%、单一行业 ≤25%、现金 ≥25%；滞胀：单只 ≤6% / ≤10% / ≤12%、单一行业 ≤20%、现金 ≥40% |
| **（三）美林时钟 + 信用周期 → 框架参数** | 衰退：PEG 上限 **1.0**（临时收紧）、现金 30%~40%、单只（验证后）≤12%；复苏：**1.5**（放宽）、现金 10%~20%、≤15%；过热：**1.0**（收紧）、现金 ≥25%、≤12%；滞胀：**0.8**（最紧）、现金 ≥40%、≤10% |

**刚性约束**：**「PEG>2 为严重透支」红线不因降息而取消**（仅可放缓减仓节奏）；宏观**只调「估值容忍度」与「仓位尺度」**，**不替代个股基本面判断、不作为择时清仓依据**（框架行 684）；参数一律经 `garp-macro`（P4-2）/ `macro_calibrator.py` 透传，本技能**不判 stage**（`GIT-9`）。

### 2.10 卖出与止损：**引用 `garp-exit` 五级（共性 4，门禁 F）**

| 优先级 | 触发条件 | 决策 | 责任 Agent |
| :--: | --- | --- | --- |
| **1 诚信否决** | 管理层诚信问题暴露、财务造假实锤、监管立案 | **立即清仓**，不考虑估值与趋势 | **Agent 4**（+ Agent 5 共用闸门） |
| **2 硬止损** | 单笔亏损达 **8%~10%** 且无明确基本面反转信号 | **止损离场** | **Agent 1** |
| **3 逻辑止损** | 连续 **2 个季度**业绩低于预期且产业景气未改善；财务不可逆恶化；龙头地位被颠覆 / 科研转化大幅低于预期；管理层或科研转化评分**跌破 10 分**（非诚信事项） | 减仓或清仓 | Team Lead（林奇 + 郑希结论交叉） |
| **4 产业景气判断** | 渗透率/ROE 出现拐点但景气尚可、**仅节奏放缓**（如进入 40%~60% 逐步兑现期）→ 减机动仓降仓位；**增速归零/转负 → 升级为逻辑恶化、清仓**（独立触发，与渗透率位置无关） | 按景气方向调仓 | Agent 3（+ Agent 4 仓位联动） |
| **5 估值判断** | 调整后 PEG>1.5 高估区 → 减机动仓；**PEG>2 严重透支 → 加速清机动仓**；市场情绪极度狂热（多信号共振）→ 减机动仓 | 底仓不动，机动仓调整 | Agent 2（+ Agent 1 机动仓纪律） |
| **补充机制** | **时间止损**：持有满 **4 个季度（1 年）**逻辑仍未兑现 → 减至观察仓或替换；**性价比替换（末位优化）**：其他标的估值显著更低且产业趋势更强可逐步切换，**每季度最多 1 次** | 兜底 / 优化 | Team Lead |

**止损分仓位口径**（框架行 528~538）：**「建仓初期」= ①持仓<最终仓位 50%，或 ②持仓≥50% 但逻辑尚未经 2~3 季财报持续兑现验证**（任一成立即适用 8%~10% 硬止损）；**底仓已建立且逻辑已验证**（须**同时满足**①达到最终仓位 50% ②逻辑经 2~3 季兑现）→ 下跌 ≤20% 且多维未恶化可在合理估值下限加仓；>20% 转入「暂时性困难 vs 永久性衰退」清单复核（**Agent 5 主责**）；**无论何种状态，逻辑被证伪立即清仓，不存在「越跌越买」**。

**一票否决的语境边界**（框架行 663）：优先级 1 针对**持仓后**的清仓信号；Team Lead 三档结论中的 **ROIC<5% 扩产 / 能力圈自检未通过 / 0.3 矩阵回避** 属**买入前**闸门，命中即**建仓前放弃**、**不进入卖出金字塔**。

> **口径禁令**：`P0~P5` / `P0` / `六级卖出` **一律不得出现**（禁用词第 17~19、21 项）；本技能**不自建卖出层级**、**不自建止损链**；ATR 止损为建议工具，经 `garp-exit` 转接 `momentum.stop_price()`（`atr(period=14)` / `multiplier=2.0`）。

### 2.11 五大矛盾化解（**Team Lead 汇总专节；骨架四大矛盾 → 五矛盾**）

| 矛盾 | 化解口径（框架第五部分） |
| --- | --- |
| **一 买点哲学**（左侧逆向 vs 右侧确认） | 分水岭 = **「杀估值」可逆向、「杀逻辑」必须止损**；左侧仅适用短期利空但长期逻辑未破坏，且首批 ≤ 最终仓位 50%、剩余待右侧确认补齐 |
| **二 持有时间维度**（长期持有 vs 动态调整） | 以**连续 2~3 季数据趋势**为判据；产业链景气与 ROE 趋势未破坏 → 持有；趋势破坏 → 调仓 |
| **三 止损 vs 越跌越买** | 以**仓位状态**为分水岭 + **8%~10% 硬止损**；底仓建立且逻辑验证后容忍度放宽至 20%；**逻辑证伪立即清仓** |
| **四 分散 vs 集中** | 组合 **5~10 只**；**3~4 只核心**（单只 **12%~15%**）+ **2~3 只卫星**（单只 **5%~8%**）；最多 **2 只**上浮至 **20%**（上浮后合计 ≤2 只）；单行业 ≤40%；相关性 <0.5 |
| **五 费雪「绝不卖」 vs 趋势/景气纪律（新增）** | **两前提缺一不可**：①**极度深度的研究认知**（确信是持续创造增量价值的「杰出企业」而非普通好公司）②**极度集中的持仓**（3~5 只、占总仓位 70%）。满足「深度认知 + 高确信度 + 管理层诚信 + 护城河稳固 + 财务健康」且下跌属**暂时性困难** → 可采纳费雪逻辑继续持有甚至加仓；**缺乏前提或属永久性衰退 → 按趋势/景气纪律离场或调仓**。**核心原则：费雪的「不卖」是「认知深度的奖赏」，不是「懒惰不研究的借口」** |

> **骨架阈值处置**：骨架矛盾三表述「基本面未变且估值合理可越跌越买」**与框架冲突**，改按框架行 396~401 / 411 / 528~538（**建仓初期 8%~10% 硬止损优先于补仓**）；骨架矛盾四「单一行业 ≤40%、单只 ≤10%/15%/20%」**与框架一致，保留并纳入 GIT-1**。
>
> **Team Lead 汇总纪律**：五矛盾**不逐条重述**，只输出**本标的当前处于哪一类矛盾**及**决议 + 依据（框架行号）+ 反面论据**。

### 3.3 降级与失败处置

| 情形 | 处置 |
| --- | --- |
| 市场识别失败 / 非三市场标的 | 明确标注「工具未覆盖」，**转人工/浏览器取数**，不得以境内数据代入境外标的 |

| 管理层评分数据缺失 | 标注「数据不足」；**诚信闸门不得因缺失而跳过**（缺失即标注风险，不用高分默认） |
