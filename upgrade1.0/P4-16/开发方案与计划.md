## 1. 目标与范围

### 1.1 目标

产出 GARP 独立档（**1~5 年**）的**论文漂移检测**技能 `/garp-thesis-drift {标的}`，并做到——

1. **H 基线七维显式提取（含费雪质化）**（验收要点 1）：H1 渗透率（`15%~40%` 五档 + 国产化率四梯队）／H2 订单·合同负债／H3 ROE 趋势／H4 毛利率／H5 增速加速度／H6 地缘（只读 0.3 矩阵）／**H7 费雪质化**（诚信闸门 + 销售组织 + 管理层持股 ≥3% + 困难性质判定）；**必须从基线文件显式提取，禁止 AI「脑补」**，缺项标注「无法验证，不纳入计数」。
2. **漂移等级与五级卖出强制联动**（验收要点 2）：**显著漂移 🟠 → 四级·产业景气判断；严重漂移 🔴 → 三级·逻辑止损；诚信线索命中 → 一级·诚信否决（前置最高优先）；持有满 4 季且漂移 ≥🟡 → 补充机制·时间止损（不占优先级）**；映射**硬编码、禁止降级、禁止低级别覆盖高级别**；命中即转接 `garp-exit`（P4-6，**已交付**）执行。
3. **四级漂移等级单一口径**：`0 项 → 未漂移 🟢 / 1 项 → 轻微漂移 🟡 / 2~3 项 → 显著漂移 🟠 / ≥4 项 → 严重漂移 🔴`；**仅 🔴 完全漂移计入计数**，⚠️ 部分漂移只记录不计数；**权重仅用于展示优先级，不参与加权**（沿用骨架等权计数，保留并显式声明）。
4. **共性口径七处替换全命中**：共性 1（四大师→五大师）与共性 4（`P0~P5`→五级卖出）为**点名差异**；共性 2/3/5/6/7 为**连带替换**（§7.2 刚性要求）；逐项对照见 §4.4。
5. **口径零复制（引用不重复定义）**：渗透率 / 国产化率 / 财务五门槛 / ROIC 四档 / 管理层与科研转化 / 估值六档 / ESG / 三维交叉矩阵 / 宏观三表 / 五级卖出 / 仓位规则 / ATR 止损 / 暂时性困难 vs 永久性衰退**一律引用**（指向框架章节号或 `garp-*` 技能出口或工具命令），本技能**只定义流程与编排**。
6. **三档并存路由隔离**：技能内引用**只指向** `garp-*` 系列 + 复用 2 技能（`qoq-accelerator`、`trend-momentum-scan`）；**禁止**引用 1~3 年中期链（`mid-*`）与 10 年长期链（`thesis-drift` / `dyp-*`）技能；**禁止**出现 `--horizon`、`P0~P5`、`-mid-thesis.md`、`-mid-drift-` 等档位切换类口令与中期文件名。
7. **风控硬编码 `GDR-1`~`GDR-12`**：把骨架 `R-1`~`R-10` 的内容**换号承接**（`R-` 编号族已被中期链与长期链大量占用，**换号即隔离**），并新增 GARP 专有闸门（诚信前置 / 五级映射不可降级 / 档位只读 / 地缘只读 / 管理层只读 / 宏观只调参 / 七维齐备）。
8. **零新增 CLI、引擎零改动**：`tools/common/*` 与 `tools/specialized/*` **不改签名、不改行为、不新增子命令**；ATR 止损价与衰退清单复核**经 `garp-exit` 转接**，本技能不自建止损链、不自行判定暂时/永久。
9. **与 `garp-thesis-tracker`（P4-7）边界清晰**：P4-7 = **建档 + 季度体检 + 健康度评分（回写论文）**；本技能 = **新旧论文两端漂移对比 + 四级漂移等级（不回写论文）**；本技能**只读** `-garp-thesis.md` / `-garp-track-*`，**不追加、不修改**。

11. **双门禁 + 七项交付件**：开工门禁 A~H（本文件 §9）+ 完成门禁留痕（详细计划 §0.7）；交付件严格对齐 §0.5「技能类七项」。

| **矛盾一** | 止损 vs 越跌越买 | 🟢 未漂移 + 建仓初期跌 >8% → **止损**；🟢 + 底仓已建跌 10%~20% 且各维未恶化 → 可加仓（须转 `garp-exit` 复核）；**≥🟡 漂移 → 禁止加仓**；🔴 → **立即清仓评估，不存在「越跌越买」** |
| **矛盾二** | 噪音 vs 拐点 | 单季异常**不判**拐点（`GDR-2`）；连续 3 季一致 → 确认拐点（`GDR-1`）；连续 2 季异常、第 3 季反弹 → 降级为 ⚠️ |
| **矛盾三** | 长期持有 vs 兑现纪律 | 持有 <4 季且 ≤🟡 → 继续持有；**持有 ≥4 季且 ≥🟡 → 补充机制·时间止损**（不占优先级，仅针对"逻辑未兑现"仓位） |
| **矛盾四** | 分散 vs 集中 | 单标的漂移 → 只调该标的（相对动作）；**同行业多标的漂移 → 行业级降级提示**（映射 `garp-industry-research` / `garp-portfolio-review`） |
| **矛盾五（新增）** | **费雪「绝不卖」vs 趋势 / 景气纪律** | **「不卖」两前提缺一不可**：① **极度深度的研究认知**（H7 ✅：十五要点式质化核查 + 持股 ≥3% + 销售组织强 + 诚信未命中）；② **极度集中的持仓**（底仓层级、长期不动用机动仓）。**任一前提缺失 → 回到五级卖出纪律**；**禁止**以「长期主义」「绝不卖」「护城河永续」对抗 `garp-exit` 触发结论；若下跌属**永久性衰退** → **无论盈亏立即清仓评估** |

> **落地刚性**：矛盾五的化解结论**必须在报告第九节与「行动建议」节两处出现**（双落位，仅写一处视为未落地）。

## 3. 执行流程与工具编排

### 3.1 执行流程（六步 + 前置 A/B）

#### 前置 A：日期与市场确认

1. 运行 `date` 确认当天日期，作为「报告生成日期 / 数据截止日期」基准。
2. 解析参数（§3.1 表）并识别市场（A 股 / 港股 / 美股），决定取数工具。
3. **三档并存提示**：同目录存在中期 / 长期档漂移或论文文件时**只提示不修改**。

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | :--: | --- | --- |
| `{标的}` | 位置 | 是 | — | 公司名或代码（A / 港 / 美股） |
| `--thesis-date` | 日期 | 否 | 最新 | 指定对比的 GARP 论文版本 |
| `--since` | 日期 | 否 | 读论文 | 买入日期（时间止损判断）；缺省则标注「无法判断时间止损」 |
| `--old` | 路径 | 否 | — | 基线降级来源④（显式指定旧报告） |
| `--export` | 标志 | 否 | false | 导出 Markdown 报告至 `reports/` |
| `--export-path` | 字符串 | 否 | `reports/` | 输出根路径 |
| `--json` | 标志 | 否 | false | 输出结构化 JSON（供下游解析） |
| ~~`--horizon`~~ | — | — | — | **废止**（档位切换类口令，违反三档隔离；本技能即 GARP 独立档唯一入口） |

#### 前置 B：基线提取与完整性检查

按 §2.2.3 优先级提取 H1~H7，执行完整性检查；**基线全缺 → 拒绝执行**。

#### 第一步：逐维假设验证

按 §2.3.1 阈值逐维采集最新数据并三档判定，**每条附证据链**（最新值 vs 基线值 + 偏差 + 数据来源 + 命令）。

#### 第二步：四级漂移等级评定

按 §2.3.2 统计 🔴 完全漂移项数 → 四级等级 + 颜色 + 趋势（`improving / stable / worsening`）。

#### 第三步：联动执行（6 + 1 项）

按 §2.9 逐项执行：`implied-growth` → `garp-exit` 五级映射 → `garp-valuation` 档位复核 → `qoq-accelerator` 交叉 → `trend-momentum-scan` 联动 → `garp-management` / `garp-geo-policy` 只读 → `garp-macro` 透传。

#### 第四步：矛盾化解应用

按 §2.11 把五大矛盾应用到当前场景；**矛盾五双落位**。

#### 第五步：报告落盘

按 §5.2 十四节模板写入 `reports/{标的}/{标的}-garp-drift-{YYYYMMDD}.md`。

#### 第六步：准出与转接

跑 `report_audit.py` 抽检；命中卖出映射 → 输出「转 `garp-exit`」动作指向；**不写回任何上游文件**。
