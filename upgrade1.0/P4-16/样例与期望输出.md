
### 2.2 基线快照（建仓论文，H1~H7 提取 + 与 P4-7 五维的映射）

### 2.4 期望输出

| 项 | 期望值 |
| --- | --- |

### 2.5 验收判据

1. 报告第一节**并列呈现** H1~H7 与 P4-7 五维的映射（`GDR-7`）。
2. 报告第二节 H1 / H2 各附**证据链**（最新值 vs 基线 + 偏差 + 来源 + 命令）。
3. 🔴 计数 = 2 → 等级必须为 🟠（`0/1/2~3/≥4` 单一口径）。
4. 第八节必须出现「四级 · 产业景气判断」并指向 `garp-exit`。
5. 第八节必须**显式声明二级硬止损与五级估值判断不由本技能判定**。
6. 报告**不得**出现档位修正因子（`GDR-8`）。
