## 5. 文件与命名隔离（**含「不写回上游」条款**）

### 5.1 本技能产出（唯一写入目标）

```
reports/{标的}/{标的}-garp-drift-{YYYYMMDD}.md
```

| 规则 | 内容 |
| --- | --- |
| 多版本 | 同日多次运行 `-v2` / `-v3` 追加，**不覆盖** |
| 目录 | 目录不存在则创建；与中期 / 长期链报告**物理隔离、不撞名** |

### 5.2 只读文件（**禁止写入**）

| # | 文件 | 归属 |
| :--: | --- | --- |
| 1 | `{标的}-garp-thesis.md` | `garp-thesis-tracker`（P4-7）活文档 |
| 2 | `{标的}-garp-track-{YYYYMMDD}.md` | `garp-thesis-tracker`（P4-7）季度体检 |
| 3 | `{标的}-garp-valuation-*.md` | `garp-valuation`（P4-5） |
| 4 | `{标的}-garp-management-*.md` | `garp-management`（P4-4） |
| 5 | `{标的}-garp-geo-*.md` | `garp-geo-policy`（P4-1） |
| 6 | 1~3 年中期链的全部论文 / 漂移 / 报告文件 | 中期链 |
| 7 | 10 年长期链的全部论文 / 漂移 / 报告文件 | 长期链 |

> **刚性条款（`GDR-10`）**：本技能**只读**上游、**只写** `-garp-drift-`；**不追加、不修改、不覆盖**任何上游文件；**禁止**回写 `-garp-thesis.md`（避免污染 P4-7 活文档）。
> **职责边界**：P4-7 `garp-thesis-tracker` 负责**建档 + 季度体检 + 回写追踪记录**；本技能负责**新旧两端漂移对比**，**只读、不回写**——二者互补不重叠。
