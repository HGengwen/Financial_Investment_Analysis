## 0. 命令说明

```text
python tools/common/financial_rigor.py wacc \
  --equity-value 80 --debt-value 20 \
  --cost-equity 10 --cost-debt 5 --tax-rate 0.25
```

公式：`WACC = E/(E+D)·re + D/(E+D)·rd·(1−t)`，结果量化至 2 位小数。

输入口径（D1 定稿）：
- `--equity-value` / `--debt-value`：同币种同单位金额。
- `--cost-equity` / `--cost-debt`：**百分点**（如 10 = 10%）。
- `--tax-rate`：**小数**（如 0.25 = 25%）。

## S1 基本样例（WACC = 8.75%）

命令：

```text
wacc --equity-value 80 --debt-value 20 --cost-equity 10 --cost-debt 5 --tax-rate 0.25
```

期望输出关键行：

```text
  股权权重 = E/(E+D) = 80.00%
  债务权重 = D/(E+D) = 20.00%
  权重重算校验         = 100.00%（应为 100.00%）
  税后债务成本         = rd×(1−t) = 3.75%
  WACC                 = 8.75%

  结构化输出: {"wacc": 8.75, "weights": {"equity": 80.0, "debt": 20.0}, "after_tax_debt_cost": 3.75, "warnings": [], ...}
```

期望：`wacc == 8.75`、`weights == {equity: 80.0, debt: 20.0}`、`after_tax_debt_cost == 3.75`、`warnings == []`。

验算：`0.8×10 + 0.2×(5×0.75) = 8 + 0.75 = 8.75%`。

```text

  合理性告警:
```

期望：`wacc == 3.95`，`warnings` 含「re < rd」。验算：`0.8×4 + 0.2×(5×0.75) = 3.2 + 0.75 = 3.95%`。

## 精度备注

JSON 结构化输出为 Python `json.dumps` 序列化的 float，**不保留尾随零**（例如 S1 的 `"wacc": 8.75`、`"weights": {"equity": 80.0, "debt": 20.0}`）。这是既有 `financial_rigor.py` 全工具的统一表现，函数返回值 `wacc`、`weights`、`after_tax_debt_cost` 均为 float；如需精确字符串展示，参考 `print` 行中的 `:.2f` 格式化结果。
