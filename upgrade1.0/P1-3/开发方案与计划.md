## 1. 子任务定位与权威依据

P1-3 是 `financial_rigor.py` 计算核心扩展的第 3 个子命令，目标是为 GARP 框架「支柱二：ROIC > WACC 且 ≥ 10%」「支柱三：资本回报效率 = ROIC > WACC」提供**资本成本侧**的精确计算工具。

权威口径（详细计划 171 行）：

$$
WACC = \frac{E}{E+D} \cdot r_e + \frac{D}{E+D} \cdot r_d \cdot (1-t)
$$

- `E` = 股权市值/权益价值（equity value）
- `D` = 有息债务值（debt value）
- `r_e` = 股权资本成本（cost of equity）
- `r_d` = 债务资本成本（税前，cost of debt）
- `t` = 企业所得税税率（tax rate）

本子命令定位为**纯计算 + 合理性提示**：接收 5 个输入，输出 WACC、权重、税后债务成本，并复用 `terminal_value.py audit` 的 `r` 参数思想对 `r_e` 取值给出参考区间提示（不新建 CAPM，不回改 `terminal_value.py`）。

## 2. 目标与范围

### 2.1 目标

1. 在 `financial_rigor.py` 新增 `wacc()` 函数，精确计算 WACC 至 2 位小数。
2. 新增 `wacc` 子命令（argparse 注册 + `main()` 派发）。
3. 输出 `{wacc, weights, after_tax_debt_cost}` 及审计回显字段。
4. 提供权重重算一致性与 `r_e` 合理性护栏，复用 `terminal_value.py audit` 三硬约束思想（不新建、不重复实现）。

### 2.2 范围（做什么 / 不做什么）

**做什么：**

- 精确 WACC 计算（`E/(E+D)·re + D/(E+D)·rd·(1-t)`）。
- 权重计算与一致性校验（`equity + debt = 100%`）。
- 税后债务成本 `after_tax_debt_cost = rd × (1 − t)`。
- 护栏：`E+D ≤ 0` 拒绝；`re < rd`、`re/rd < 0`、`t < 0` 或 `t ≥ 1` 等异常提示。
- 复用 `terminal_value.py audit` 的 `r` 参数币种护栏思想，作为 `re` 取值参考（静态提示文案）。

**不做什么：**

- **不新建 CAPM**，不在 `wacc` 子命令内部计算 `re = rf + β × ERP`。`re`/`rd` 由调用方（技能/研究 Agent）提供。
- **不回改** `terminal_value.py`、不回改 P1-1/P1-2 既有逻辑。
- **不引入 `--currency` 参数做强校验**（保持 5 参数权威签名）；币种区间仅作参考提示。
- 不做「ROIC vs WACC」判定（该判定已在 P1-1 `roic --wacc` 实现，本子命令只产出 WACC 值供其联动）。

## 3. 关键量化口径与单位规范

### 3.1 公式与单位

| 输入项 | CLI 参数 | 单位 | 说明 |
| --- | --- | --- | --- |
| 股权价值 E | `--equity-value` | 金额（与 D 同币种同单位） | 可为市值或权益账面值，由调用方口径决定 |
| 债务价值 D | `--debt-value` | 金额（与 E 同币种同单位） | 有息债务 |
| 股权成本 re | `--cost-equity` | **百分点**（如 10 = 10%） | 与 P1-1 `--wacc` 口径一致 |
| 债务成本 rd | `--cost-debt` | **百分点**（如 5 = 5%） | 税前债务成本 |
| 税率 t | `--tax-rate` | **小数**（如 0.25 = 25%） | 金融惯例，用于税盾 `(1−t)` |

> 单位约定为待确认决策点 D1（见第 8 节）。

### 3.2 权重重算一致性

- `equity_weight = E / (E + D)`
- `debt_weight = D / (E + D)`
- 恒有 `equity_weight + debt_weight = 1.0`（以百分数输出则为 `100.0`），函数内以 `Decimal` 精确计算并打印校验和。

### 3.3 `re` 估算复用 `terminal_value.py audit` 思想

`terminal_value.py` 中 `CURRENCY_BANDS` 的 `r` 三硬约束（C1 币种一致性、C2 分母宽度、C3 离散风险归属）用于**整股折现率 r**；本子命令的 `re`（股权成本）与折现率 r 同源，故复用其币种护栏思想作为**参考区间提示**（非强校验）：

- CNY：`re` 合理区间约 `6.0%~9.0%`（中国 10 年期国债 1.70% + ERP 5.18% 合成）
- USD / HKD：`re` 合理区间约 `9.0%~11.5%`（美国 10 年期国债 4.70% + ERP 5.18% 含国别溢价）

本子命令将这些区间作为 `re_reference` 提示文案输出，提示 `re` 取值偏离区间时需人工复核，但**不**据此拒绝计算。

## 6. 函数与 CLI 实现设计

### 6.1 `wacc()` 函数签名

```python
def wacc(equity_value, debt_value, cost_equity, cost_debt, tax_rate):
    """计算加权平均资本成本 WACC。

    公式：WACC = E/(E+D)·re + D/(E+D)·rd·(1−t)，结果精确至 2 位小数。
    权重校验：股权权重 + 债负权重 = 100%。
    复用 terminal_value.py audit 的 r 参数币种护栏思想，输出 re 参考区间提示（非强校验）。

    Args:
        equity_value: 股权价值 E（与 debt_value 同币种同单位）。
        debt_value: 有息债务值 D（与 equity_value 同币种同单位）。
        cost_equity: 股权成本 re（百分点，如 10 表示 10%）。
        cost_debt: 债务成本 rd（税前，百分点，如 5 表示 5%）。
        tax_rate: 企业所得税税率 t（小数，如 0.25 表示 25%）。

    Returns:
        dict: 含 wacc / weights / after_tax_debt_cost / warnings /
              re_reference / inputs 审计回显字段。
    """
```

### 6.2 核心计算逻辑（伪代码）

```python
e = exact(equity_value)
d = exact(debt_value)
re = exact(cost_equity)
rd = exact(cost_debt)
t = exact(tax_rate)

total = e + d

# 护栏 1：E+D ≤ 0 → 降级 N/A（非除零异常）
if total <= 0:
    # 返回 wacc=None, weights=None, after_tax_debt_cost=None, 提示「E+D≤0」
    return result

equity_wt = e / total * 100          # 百分数
debt_wt = d / total * 100            # 百分数
after_tax_rd = rd * (1 - t)          # 百分点
wacc = equity_wt/100 * re + debt_wt/100 * after_tax_rd

# 护栏 2：合理性告警（不拒绝计算，写入 warnings）
warnings = []
if re < rd: warnings.append("re < rd，股权成本低于债务成本，资本结构定价异常")
if re < 0:  warnings.append("re < 0，股权成本为负，异常")
if rd < 0:  warnings.append("rd < 0，债务成本为负，异常")
if t < 0 or t >= 1: warnings.append("税率 t 超出 [0,1) 区间，异常")

# 全部 quantize(Decimal("0.01")) 后转 float
```

验算：`WACC = 0.8×10 + 0.2×(5×(1−0.25)) = 8 + 0.75 = 8.75%`。

- 全股权 `--equity-value 100 --debt-value 0 --cost-equity 10 --cost-debt 5 --tax-rate 0.25` → `wacc=10.0`，`weights={"equity":100.0,"debt":0.0}`。

### 样例 3：护栏 E+D ≤ 0

`--equity-value -10 --debt-value -20 ...` → `wacc=None`，降级提示「E+D ≤ 0，无法计算 WACC（分母非法）」。

### 样例 4：与 P1-1 `roic --wacc` 联动

WACC 输出 `8.75%` 后，可直接作为 P1-1 判定输入：


期望判定：`合格（ROIC>WACC 且 ≥10%）`（ROIC=12.5% > WACC=8.75% 且 ≥10%）。这验证「与 P1-1 `roic --wacc` 联动可判定」验收项。

## 12. 风险与限制

- **单位易混**：`re`/`rd`（百分点）与 `t`（小数）单位不同，需在 `--help` 与提示文案中反复强调（D1 定稿后固化）。
- **`re` 估算口径**：本子命令只做静态参考区间提示，不强制校验；`re` 的实际取值与建模（CAPM/可比公司）由调用方技能负责，避免在工具层引入未约定的建模。
- **负权益/负债务场景**：资不抵债公司的 E 或 D 可能为负，本子命令按 D3 提示而非拒绝，避免误伤真实财报场景。
- **不构成决策**：WACC 只是资本成本侧的输入，是否「ROIC > WACC」仍由 P1-1 `roic --wacc` 统一判定。
