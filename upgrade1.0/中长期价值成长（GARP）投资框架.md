# 中长期价值成长（GARP）投资框架（科技与国产化主题增强版）

> **适用对象**：认同"以合理价格买入持续成长的好公司"理念，希望以1~5年中长期持有为主、拒绝频繁短线交易的个人投资者。
>
> **核心理念**：用产业趋势定方向，用生活常识和基本面选个股，用"管理层+科研转化"评估企业内在价值，用地缘政治与政策资本判断国产替代节奏，用底仓陪伴成长、用机动仓平滑波动，用系统化纪律控制回撤与情绪。
>
> **周期定位**：本框架为 **GARP 独立档（1~5年）**，介于项目「中期链（1~3年景气投资）」与「长期链（10年护城河投资）」之间——既非短期景气博弈，也非永续护城河持有。实际执行分两段：普通成长股按 1~3 年景气/估值纪律持有与调仓；仅极少数通过费雪式深研的杰出企业，可放宽至 3~5 年甚至更长。判断时勿与项目既有 1~3 年、10 年两档技能路由口径混用。
>
> **全局动态获取声明（适用于全文）**：文中所有具名的五年规划/专项政策、国家或地方产业基金名录与规模、制裁/管制清单、国产化率、注资金额、具体公司案例等，均为某一时点的**快照示例**，随时间与环境持续变化。**每次据此做投资判断前，须先联网检索"当前最新"信息，以最新公开信息为准，不得沿用历史示例**。按核验对象分两类：①政策资本侧（规划/政策表述/基金名录与规模）；②地缘政治与风险侧（制裁清单/出口管制/关税/地区冲突/风险行业清单/国产化率）。

# 第一部分 思想根基：五位投资大师的思维模式

本套投资框架融合了五位风格迥异但各具洞见的投资代表人物——**菲利普·费雪、彼得·林奇、郑希（易方达基金）、李进（融通基金）、威廉·欧奈尔** 。其中郑希、李进的思想提炼自其公开投资方法论与所管理产品中体现的系统性框架，并非对其个人业绩的背书，具体采用时请以公开可核验信息为准。在展开具体方法之前，先理解每一位大师的**思维模式**与**核心信仰**，有助于您融会贯通，而非机械套用。

## 一、菲利普·费雪——质化分析之父：闲聊法与长期持有

菲利普·费雪（1907-2004）被誉为"成长股价值投资之父"，是巴菲特亲口承认对其产生重要影响的"特别的老师"。他的投资哲学开创了一条与格雷厄姆"捡烟蒂"截然不同的路径——**寻找并长期持有那些能够持续创造增量价值的杰出公司，而非仅仅寻找价格便宜的股票**。

**思维模式特点：**

- **质化分析优先**：费雪认为，关于一家公司未来的最重要信息，尚未写进财务报表里。管理层品质、持久竞争优势、研发能力、销售组织等"财报上找不到的东西"，才是判断企业潜力的关键。
- **"闲聊法"（Scuttlebutt Method）** ：主张走出去，与企业的竞争对手、供应商、客户及员工交谈，从各种渠道收集第一手信息，而非坐在办公室里看财报拍脑袋。
- **极度集中与长期持有**：费雪一生真正赚到大钱的只有14只股票，投资组合通常只重仓3~5只，占总仓位的70%。他的核心信条是"卖出的最佳时机，几乎永远是不要卖"。他持有摩托罗拉长达44年，德州仪器经历80%暴跌仍坚持持有。
- **诚信一票否决**：费雪明确表示，如果一家公司在诚信问题上不合格，无论其他标准得分多高，他永远不会考虑这只股票。
- **十五要点选股框架**：在《怎样选择成长股》中提出"寻找优良普通股的十五点原则"，涵盖市场潜力、研发投入、销售组织、利润率、管理层能力等多个维度。

**对我们的启发**：在1~5年的持有周期中，核心底仓应借鉴费雪的质化分析框架和"闲聊法"，深度评估企业的管理层质量、销售组织与长期竞争力。一旦确认企业足够杰出，应以长期持有为信念，不被短期股价波动干扰。但费雪的"不卖"只适用于极少数经过深度研究的杰出企业，且必须配合极度的集中和极深的认知（详见第五部分"矛盾五"）。

## 二、彼得·林奇——侦探思维：常识与求证

林奇管理麦哲伦基金期间，每年调研数百家公司，工作方式像侦探破案。他最独特的贡献在于相信业余投资者凭借生活常识也能发现好公司。

**核心方法**：从具体消费体验出发，再回到财报验证。将股票分为六种类型（缓慢增长型、稳定增长型、快速增长型、周期型、困境反转型、隐蔽资产型），不同类型匹配不同的估值方法和卖出逻辑。

**在本框架中的角色**：选股起点。从日常生活观察中发现候选标的，用常识做第一道筛选。

## 三、郑希——物理学家思维：第一性原理与产业周期

郑希是物理系出身，思维模式带有鲜明的物理学家特质——从第一性原理出发，寻找事物最本质的驱动力量。他认为科技公司个股的涨跌是表象，真正的底层驱动力是技术迭代带来的产业景气周期。

**核心方法**：关注产业处在ROE曲线的什么位置，同时跟踪中美科技产业链寻找哪个环节率先出现ROE拐点。核心表述——"长期判断由无数短期客观判断拼接而成"，每一笔持仓都要在每个季度接受景气数据的检验。

**在本框架中的角色**：赛道选择。用ROE拐点和全球产业景气定方向。

## 四、李进——系统工程师思维：系统均衡与回撤控制

李进是清华大学工学博士，思维模式体现为系统工程师的全局优化思维——既要追求收益弹性，又要控制回撤，在矛盾中寻找最优解。

**核心方法**：将资产分为"景气成长"（进攻）和"价值成长"（防御）两类，根据市场环境动态调整比例。用渗透率曲线定位产业阶段（突破15%后加速上行期重仓，进入40%以上后逐步兑现、60%以上为天花板）。要求产业趋势必须有订单、收入、利润的客观数据支持，否则一律视为题材炒作。

**在本框架中的角色**：组合管理与渗透率择时。

## 五、威廉·欧奈尔——工程师思维：信号与纪律

欧奈尔复盘了美股百年历史上所有大牛股的共同特征，提炼出CAN-SLIM七大选股标准。他相信趋势跟随而非预测，一切决策基于明确信号。

**核心方法**：8%~10%止损作为"生存红线"；趋势确认后介入，趋势走坏后离场；忘掉买入成本，以市场信号为准。

**在本框架中的角色**：风控底线。用硬止损保护本金，防止深度套牢。

| 大师   | 思维模式关键词                   | 在个人投资者框架中的角色                                                             |
| ------ | -------------------------------- | ------------------------------------------------------------------------------------ |

| 林奇   | 侦探思维 · 常识与求证           | **选股起点**：从生活体验中发现机会，用常识做第一道筛选                         |

| 李进   | 系统工程师思维 · 均衡与渗透率   | **组合管理**：用渗透率定位产业阶段，用双资产配置控回撤                         |
| 欧奈尔 | 工程师思维 · 信号与纪律         | **风控底线**：8%~10%止损，防止深度套牢                                         |

**以上五位大师的组合，构成了本套投资框架的完整拼图：**

- 用**费雪**的质化分析框架和"闲聊法"，深度评估企业的管理层质量、诚信、销售组织与长期竞争力，确认核心底仓是否足够杰出（解决"是否杰出、能否长期持有"）；
- 用**林奇**的常识化基本面和生活观察，在赛道中筛选出自己看得懂、有壁垒的好公司（解决"买哪家公司"）；
- 用**郑希**的产业景气/ROE拐点框架，选择未来1~3年最具成长确定性的赛道（解决"买什么行业"）；
- 用**李进**的渗透率坐标与组合均衡，验证估值与仓位节奏、控制回撤（解决"何时买、如何控仓"）；
- 用**欧奈尔**的底线风控纪律，保护本金、控制回撤、规避大亏（解决"如何安全退出"）。

**管理层与科研转化评估（支柱三）是费雪质化分析与郑希/李进科技产业研究的交叉落地**——管理层质量主要借鉴费雪，科研转化效率主要借鉴郑希/李进的工程化视角，二者共同回答"这家公司是否值得长期持有"。

这套框架的目标不是追求短期爆发力，而是帮助个人投资者在**1~5年的持有周期中，以系统性方法对抗市场波动与自身情绪，稳健地赚取企业成长的钱**。

# 第二部分 核心筛选漏斗：从地缘政治到个股

## 第0步：地缘政治与政策资本前置判断（科技/高端制造国产化赛道核心前置，适用于所有逆全球化敏感行业）

在进入产业和个股筛选之前，先完成一层**前置判断**。这一步的核心逻辑是：**地缘政治倒逼决定国产替代的"确定性下限"，政策与国字号基金支持决定"国产企业能不能接得住"的可行性。**

**分层分工**：地缘政治与政策资本在本框架中分层递进、粒度逐级细化——地缘政治三层：①第0步（0.1）主题/赛道级前置闸门（识别风险形态与倒逼强度）；②第1步赛道级粗筛（仅看地缘风险敞口）；③支柱四个股级地缘打分。政策资本两层：④第0步（0.2）政策与基金支持强度评估；⑤支柱五个股级政策资本打分。前者粗筛排除，后者细研定档。

### 0.1 地缘政治倒逼强度评估

**顶层背景——逆全球化的长期大趋势**：自"效率优先"的全球化黄金期结束，世界正进入**逆全球化（de-globalization）**的长期结构性阶段，核心特征是从"效率优先"转向"安全优先"。这一趋势不会因短期贸易谈判或某一届政府更迭而轻易逆转，是以下所有地缘政治风险形态的共同底座。评估时先识别四类可观测信号，判断逆全球化对目标行业的渗透强度：

| 逆全球化信号                  | 具体表现                                                                  | 对投资判断的含义                                 |
| ----------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------ |
| **贸易壁垒常态化**      | 关税战、反倾销/反补贴调查、配额与各类非关税壁垒（技术标准、原产地规则）等 | 出口依赖型赛道利润与份额双承压，利好本土替代     |
| **产业链区域化/本土化** | 友岸/近岸外包、产业回流、"中国+N"产能备份、区域自贸协定重构等             | 抬升全球产能布局成本；利好自主可控与本土龙头     |
| **技术脱钩**            | 高端芯片/设备/软件出口管制、实体清单、数据主权与算力限制等                | 被"卡脖子"环节的国产替代确定性最高               |
| **资本与数据流动收紧**  | 跨境投资审查（类 CFIUS）、汇率/资本管制、数据跨境传输限制等               | 抬升跨国并购与海外扩张成本，须评估标的出海可行性 |

> 逆全球化同时带来**风险与机会的两面性**：对全球化依赖度高的标的（海外收入占比高、供应链外置）构成持续性压制；对"自主可控、本土替代、资源自给"的标的构成结构性利好。这正是本框架把地缘政治作为"第0步"而非背景噪声的原因。

在逆全球化底座之上，地缘政治具体风险不限于"中美科技竞争/芯片制裁"这一条线，须进一步覆盖三种相互交织、但传导路径不同的风险形态，避免把"芯片制裁"当作地缘政治的全部：

| 风险形态                    | 典型事件/手段                                                                                     | 传导路径与受影响标的类型                                                        | 对投资判断的含义                                                               |
| --------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| **技术/大国竞争对抗** | 实体清单、出口管制、芯片封锁、生物安全法案、生物技术出口管制、基因/生物数据限制、关税与反补贴调查 | 半导体设备材料、高端制造、军工、光通信、生物制药与创新药（CXO/基因测序/疫苗）等 | 高倒逼强度→国产替代确定性下限高；但仍须验证国产能否接住                       |
| **国家/经济民族主义** | 关键矿产出口管制（稀土/锂/钴/铜）、资源国有化、本土化替代、友岸/近岸外包、产业回流                | 矿产资源股、稀土产业链、出口依赖型制造、全球化产能布局                          | 推高资源成本与供应链重构成本；利好资源自主与本土龙头，压制海外收入占比高的标的 |
| **地区冲突与战争**    | 热战/代理人战争、制裁与反制裁、航运中断（海峡/运河）、能源与粮食安全                              | 能源、航运、大宗商品、出口导向、外汇敏感型                                      | 短期成本冲击叠加避险情绪；须关注通胀、汇率与供应链绕行能力                     |

> 三种形态常叠加共振（例如大国竞争+地区冲突同时抬升风险溢价）。评估单一标的时，须先定位它**具体暴露在哪条传导链上**，而不是笼统地说"有地缘风险"。逆全球化、全球民族主义兴起与地区冲突都是长期趋势性变量，须纳入每个标的的常态化体检，而非仅在危机爆发时才响应。

**风险行业清单会持续扩散**：地缘政治风险不会只停留在芯片与半导体上，而是沿着逆全球化进程持续向新行业扩散。截至当前，已明显暴露地缘政治风险的行业/领域包括：

| 行业/领域        | 主要地缘政治风险（示例，会随时间变化）                                  | 传导与受影响标的（示例）        |
| ---------------- | ----------------------------------------------------------------------- | ------------------------------- |
| 半导体与高端制造 | 出口管制、实体清单、芯片封锁、设备/材料限制                             | 设备材料、先进封测、AI算力      |
| 生物制药与创新药 | 生物安全法案、生物技术出口管制、基因/生物数据限制、CXO 供应链"去风险化" | 创新药出海、CXO、基因测序、疫苗 |
| 矿产资源         | 关键矿产出口管制、资源国有化、跨国并购审查                              | 铜、锂、钴、镍等矿业股          |
| 稀土             | 出口管制、出口许可证、战略储备、磁材技术限制                            | 稀土开采与冶炼、永磁材料、电机  |
| 能源与航运       | 地区冲突、能源制裁、航运要道中断                                        | 油气、LNG、航运、保险           |

> **关键操作纪律**：评估某个行业前，须先检索"该行业当前是否已被卷入地缘政治冲突/管制清单"，而非默认"上表之外的行业就无风险"。逆全球化是扩散性的长期变量，风险行业边界会持续外扩。

在此全景之下，再评估**"地缘政治倒逼国产替代的强度"**（以下四条针对科技/高端制造国产化主题）：

| 评估项                    | 具体内容                                                            | 对投资判断的含义                                       |
| ------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------ |
| **制裁/管制覆盖度** | 该领域是否已被列入实体清单、出口管制清单，或面临关税/反补贴等调查？ | 已被覆盖→被迫替代确定性高；尚未覆盖→仍以市场驱动为主 |
| **断供现实性**      | 进口供应是否已实际中断，还是仅有"断供隐忧"？                        | 已实际中断→下游客户已无选择，国产导入是生存刚需       |
| **政策强制力**      | 是否有类似"新增产能国产设备占比不低于50%"的强制性要求？             | 有强制要求→订单释放确定性极高                         |
| **制裁可持续性**    | 制裁是立法层面的长期安排，还是行政层面的短期措施？                  | 立法级→长期确定性高；行政级→可能随政府更迭变化       |

### 0.2 政策与国字号基金支持强度评估

**评估的核心不是"记住某一期基金名单"，而是掌握判断"政策资本力度"的方法**。以下从三个层面拆解评估逻辑，并仅在末尾附上一组**示例（仅作格式示范，非当前事实）**：

1. **规划与政策层面**：识别最新五年规划或专项政策中，是否以"超常规""全链条""决定性突破"等**强干预强度词汇**覆盖目标领域；是否包含**强制采购比例、部委协同攻关、应用场景强制开放**等硬性工具，以及**税收减免、研发费用加计扣除、首台套保险补偿等财税优惠配套政策**，而非仅停留在补贴与引导。
2. **基金与资本层面**：判断目标环节是否有**国家/地方产业基金直接注资或设立专项子基金**，并评估**注资额度与占比**（基金总规模、单项目投资额、占项目总投资比例——额度越大、占比越高，政策优先级越强），以及是否有**央企/产业资本**参与投资形成"资本+场景"绑定。
3. **时效核验层面**：每次评估时更新"基金名称、规模、投向"的实时数据，剔除已到期、已转向或规模缩水的基金，补充新设立的基金。

> **分工提示**：以上三层面为**赛道级**快速判断（回答"该环节/赛道是否被政策资本覆盖、力度如何"）；落到**具体标的**的个股级细研（注资额度占其市值/资本开支比例、场景绑定是否已产生可验证订单、相对同赛道企业的政策门槛优势）见支柱五。

**方法论结论（长期有效）**：

- **投资方法论转向**：国字号基金正从"支持已有基础的替代"转向"押注尚未突破但战略价值极高的卡脖子环节"。当某细分环节同时被**当前最新**规划/政策以强干预强度覆盖、且被**当前最新**国字号基金精准注资时，其国产替代从"市场驱动的渐进过程"升级为"制度驱动的加速过程"。
- **政策工具——首台（套）、首批次保险补偿**：下游客户采购首台国产重大装备或首批次新材料时，因质量问题的损失由保险机制补偿、保费由财政按比例补助，从而缩短国产产品的客户验证周期，是财税优惠中催化作用较强的一项。

### 0.3 综合判断：政策-资本-地缘三维交叉矩阵

| 地缘倒逼强度      | 政策覆盖度          | 国字号基金介入 | 投资含义                                                                                    |
| ----------------- | ------------------- | -------------- | ------------------------------------------------------------------------------------------- |
| 高（已制裁/断供） | 高（超常规+全链条） | 有直接注资     | **最优场景**：替代确定性和节奏均被外部力量锁定                                        |
| 高                | 中                  | 有专项子基金   | **次优场景**：替代方向明确，但节奏受技术突破制约                                      |
| 中（制裁升级中）  | 高                  | 有覆盖         | **潜伏场景**：制裁尚未落地但概率高，提前布局等待催化                                  |
| 高（已制裁/断供） | 低/无               | 无覆盖         | **高风险/回避**：下游被迫替代但国产短期接不住，须先验证承接能力，承接不足则回避       |
| 低                | 中/高               | 有覆盖/注资    | **政策驱动型增量创造**：不以地缘倒逼为门槛，达标与否以政策覆盖+基金介入（支柱五）为准 |
| 低                | 低                  | 无覆盖         | **回避**：替代节奏完全依赖市场驱动，不确定性过高                                      |

> **说明**：本矩阵中的"超常规+全链条""有直接注资"等表述，均为评估强度等级的标签，而非对某一具体政策或基金名的引用，因此长期适用。

> **未列组合处理**：地缘倒逼强度、政策覆盖度、国字号基金介入各含高低档，本表仅列六类代表性组合。凡未显式列出的中间组合（如"政策覆盖度低但国字号基金有覆盖"），一律按**更审慎的相邻档位**归档处理，不得因未列而默认放行。

**关键风险提示**：国字号基金的注资应被视为"政策优先序列"的信号，而非买入估值的依据。大基金以产业培育成本入股，其成本远低于二级市场投资者在消息公开后的买入价格。**最终决策仍需回到估值和业绩兑现框架。**

**赛道两分法（后文支柱四达标判定引用）**：科技/高端制造国产化赛道按"成长驱动主因"分为两类——

- **地缘倒逼型**（半导体设备/材料等）：成长由"被制裁/断供→被迫替代"驱动，地缘倒逼强度是确定性下限，故支柱四对地缘倒逼强度作**硬门槛**（倒逼强度非"低/无"方可建仓），同时以支柱五验证政策资本能否接住。
- **政策资本驱动型**（机器人、信创等增量创造）：成长由"政策创造需求 + 基金催化"驱动，地缘倒逼强度本就不高，故支柱四仅作**敞口体检**（海外收入/供应链/冲突暴露可控），达标与否交由支柱五判定。

判别方法：先看 0.3 三维矩阵的行归属——"高倒逼强度"起步的赛道属地缘倒逼型；"低倒逼强度 + 政策/基金高"起步的赛道属政策资本驱动型。两类并非互斥，介于其间时按**更审慎的那类**执行。

## 第1步：赛道选择——顺应时代增量，寻找景气向上的产业

| 筛选维度                               | 具体标准                                                                                                                                                                                                        | 实操方法                                                                                                                                                                                                                                                   |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **产业空间（TAM）**              | 行业潜在市场规模≥1000亿，未来3年复合增速≥20%                                                                                                                                                                  | 查阅券商深度研报、行业协会数据、上市公司招股书中的行业分析章节                                                                                                                                                                                             |
| **渗透率位置**                   | 当前渗透率在15%~40%之间，处于加速上行期（黄金建仓窗口）                                                                                                                                                         | 跟踪第三方数据；<5%为导入早期（不确定性高，观察不建仓）、5%~15%为突破期（高弹性，小仓跟踪）、15%~40%为加速上行期（黄金窗口，主建仓）、40%~60%为逐步兑现期（持有，不再新建仓）、>60%为天花板（即便增速暂未转负也不加仓）；一旦增速归零/转负即视为见顶、清仓 |

| **地缘政治风险敞口**             | 优先选择海外收入占比较低、供应链可控的赛道；被制裁/断供但国产能接住且政策基金配套的环节反而构成机会（见0.3矩阵）；仅当"被制裁但国产短期接不住"或"海外依赖高、供应链外置"时回避                                  | 跟踪目标市场关税/反补贴政策、出口管制清单、海外建厂与本地化进展；警惕过度依赖单一海外市场的赛道                                                                                                                                                            |

> **渗透率与国产化率的分工**：渗透率定位**产业**所处阶段（管"何时买"），国产化率定位**国产企业**可替代空间（管"标的成长弹性"）。科技赛道两者叠用——渗透率管择时、国产化率管弹性；国产化率进入 >50% 收窄阶段后，投资逻辑转向龙头份额提升与整机放量，而非继续押注"从0到1"的替代弹性。

## 第2步：个股初筛——从生活常识出发，建立备选池

### 能力圈自检：把"看得懂"从模糊感受变成可评估维度

"能力圈"常被误当成一句"我只投我懂的"的空话，但"懂不懂"若说不清，就无法自我约束。本框架将能力圈拆为**四个可评估维度**，在进入任何个股研究前先自检，把"是否在自己的能力圈内"变成一个可回答、可打分的判断题：

| 维度                             | 评估标准                                                                   | 自检问题（须能独立回答"是"）                                                      |
| -------------------------------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| **产业理解**               | 能否画出该产业链的上下游关系图？能否说出行业竞争格局与集中度（CR5）？      | 产业链有几层？上游关键原材料/设备来自谁？下游客户是谁？前五大玩家是谁、份额多少？ |
| **财务理解**               | 能否独立阅读并理解该行业公司的三张报表（资产负债表、利润表、现金流量表）？ | 营收、毛利率、应收/存货、经营现金流分别在哪张表？关键科目变动意味着什么？         |
| **估值理解**               | 能否用至少 2 种方法给出估值区间？                                          | 除了 PE/PEG，能否再用 PS、EV/Sales、DCF、可比公司等方法交叉验证？                 |
| **技术理解**（科技股必答） | 能否说清核心技术路线的差异？                                               | 不同技术路线的原理差异、成本差异、适用场景、主流玩家分别是谁？                    |

**判定规则**：

- 普通行业：须**同时满足"产业理解 + 财务理解 + 估值理解"三项**，方可进入深度研究；此三项中任一无法独立回答，即视为**能力圈之外**（技术理解为科技股附加项，普通行业可豁免）。
- 科技股：在上述基础上，**"技术理解"为必选项**——若说不清核心技术路线差异，即便其他三项都通过，也不得重仓，只能作为观察仓或直接放弃。
- **达不到门槛的应对**：不是"硬上"，而是三选一——①补课学习直到能独立回答；②只作低仓位的观察仓跟随；③果断放弃，赚认知范围内的钱。

> 能力圈的核心价值是**诚实地知道自己"不懂什么"**。通过初筛的标的，若未能通过以上自检，就不应进入下一步的深度研究。

### 生活常识与财务初筛

- **消费即调研**：关注您常用的APP、常买的品牌、信赖的产品。若您自己就是目标用户，您对产品力的判断可能比分析师更真实。
- **初筛财务门槛**（快速排除法）：
  - 营收规模≥10亿（剔除微盘股，避开量化收割区）；
  - 最近三年营收复合增速≥15%；
  - 资产负债率<60%（金融/地产行业除外）；
  - 经营性现金流净额为正；
  - 过去三年至少两年扣非净利润为正（避免纯概念股）。

> **科技股豁免**：对高研发投入的科技股，若"扣非净利润为负"仅由研发费用化压低当期利润所致，可用"经营性现金流净额为正 + 营收连续增长 + 研发强度≥15%"三项替代上述"扣非净利润"门槛，避免误杀具备清晰盈利路径的早期科技龙头（与第4步"未盈利科技型"衔接）；无法通过此豁免的仍应剔除。

通过初筛后，剩下约50~80只标的进入深度研究池（量级估算：全市场数千只经第1步赛道景气 + 第2步财务门槛后大致落到此区间，具体数量随市场环境浮动，非固定值）。个人投资者精力有限，进入第3步深度研究前先做一轮**降维收敛**：按"能力圈最强 + 产业景气最确定 + 最熟悉"优先，挑出约 10~20 只进入深度研究，其余留作备选池待替换。

## 第3步：深度研究——五大支柱交叉验证

### 支柱一：产业景气度（判断β）

- 行业供需格局：供不应求/供需平衡/供过于求？
- 价格趋势：产品单价是否稳定或上涨？
- 竞争格局：行业前五名集中度（CR5）是否提升？龙头份额是否扩大？

### 支柱二：公司基本面（判断α）

> **ROIC 口径总注**：本支柱四档阈值，科技股按"调整后核心经营 ROIC"（研发费用化加回）判定，普通行业按报表 ROIC 判定；下文"科技股口径协调"三条规则即是对科技股的调整口径。科研转化清单"资本回报效率"项（支柱三）与一票否决"ROIC 长期<5% 且仍在扩产"项，均独立按报表 ROIC 判定（详见各该处标注）。

- **ROE趋势**：当前ROE水平及近三年变化方向（参考郑希的ROE向上拐点逻辑）
- **毛利率与净利率**：是否稳定或提升？反映定价权和成本控制力
- **营收与利润增速匹配度**：利润增速是否跟上营收增速？若营收快但利润慢，警惕费用失控
- **ROIC（投入资本回报率）** ：分四档判定——
  - 合格：ROIC > WACC 且 ≥10%；
  - 优秀：ROIC > 15%——作为"最高确信度标的"候选的加分项，可支持单只上限上浮至绝对 20%（仅限长期充分验证的深护城河核心底仓），并允许 PEG 偏贵上沿接近 1.5；
  - 长期 <5% 不达标：其中 <5% 且仍在拼命扩产时触发一票否决；<5% 但不扩产归入「部分不达标（观察仓）」；
  - 介于 5%~10% 之间：同为「部分不达标」（既不否决也不达标，归入观察仓待观察）。
- **科技股口径协调（ROIC）** ：
  - 高研发投入科技股因研发费用化压低当期利润与 ROIC，本支柱的「≥10%」应改用**调整后核心经营ROIC**（将费用化研发支出加回后的口径），避免机械套用导致误判。
  - 调整后核心经营ROIC 仍 <10% 时，本项判「部分不达标（归入观察仓）」。
  - 但科研转化清单「资本回报效率」项仍独立按「ROIC > WACC」判定——即支柱二主阈值（≥10%）不豁免，仅豁免科研转化清单中的「资本回报效率」单项。
- **护城河（可量化，GARP 的"价值"侧）** ：个股层面显式评估竞争优势，须可量化验证——市占率趋势、客户续费率/NPS、定价权（毛利率稳定性）、转换成本、成本/技术壁垒。护城河停留在"感觉有壁垒"而无法量化验证的，视为本项不达标（退观察仓）；禁止仅凭行业β的 CR5 判断个股护城河。

### 支柱三：管理层（通用）与科研转化能力（科技赛道专用）

> **两套20分制的合成规则**：管理层评估为**通用硬门槛**——无论行业，管理层评分须≥15分方可重仓；**<15分退档规则**：10~14 分归"部分不达标→观察仓"（单只上限≤5%，不重仓），<10 分归"放弃"。科技股在此基础上**再叠加**科研转化评分≥15分，即"两套都须≥15"而非合计/加权；科研转化的 <15 分退档同管理层规则（10~14 观察、<10 放弃）。普通行业不适用科研转化清单时，仅以管理层20分制判定。
>
> **诚信"一票否决"的机制**：诚信维度**独立于20分制、不赋分**——一旦命中（兑现率<50%、业绩预告重大失真、监管立案或财务造假实锤），无论管理层总分是否≥15，直接放弃或清仓，不进入20分制求和。因此20分制满分虽仍为20分，但**仅由下方「对待股东、战略执行力、稳定性与激励」三项构成（7+7+6=20）**，诚信不占分、只作前置否决闸门。

**诚信否决闸门（不计入20分制，命中即放弃/清仓）** ：

| 检查项                                                                                                | 处置                                     |
| ----------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| 年报"说到做到"验证（兑现率<50%一票否决）；业绩预告准确性；归因习惯；监管记录（监管立案/财务造假实锤） | 命中 → 直接放弃或清仓，不进入20分制求和 |

**管理层评估清单（20分制，≥15分方可重仓）** ：

| 维度                   | 检查项                                                                                                              | 评分 |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------- | ---- |
| **对待股东**     | 分红历史（≥30%为优）；融资记录；回购行为；大股东质押率（>50%预警）                                                 | 7分  |
| **战略执行力**   | 是否聚焦主业；核心战略落地情况；行业格局认知深度                                                                    | 7分  |
| **稳定性与激励** | 核心团队稳定性（离职率<10%）；股权激励合理性；内部人（董监高/大股东）增减持是否异常（异常减持或违规交易→预警扣分） | 6分  |

**ESG 与可持续投资补充检查（定性参考，不计入20分制）** ：

A股/港股市场 ESG 评级与股价表现的相关性正在增强，ESG 已从"道德选项"逐步变为"风险定价因子"。本框架将其作为**管理层与治理维度的补充检查**，而非独立打分维度，以避免分散对"诚信+科研转化"这一核心的关注：

| **环境（E）**         | 是否属于高碳排放、高环境风险行业（化工、有色、钢铁、火电、高污染制造等）；环保合规与碳减排路线如何？ | 高环境风险标的须额外做环境合规、转型路径与"搁浅资产"评估（折价见第4步）                                                           |
| **社会（S）**         | 用工合规、产品质量与召回、供应链劳工等是否存在重大争议                                               | 作为辅助参考；重大负面事件计入风险提示                                                                                            |

**科研转化评估清单（20分制，≥15分可重仓）** ：

| 维度                         | 检查项                                                                        | 评分 |
| ---------------------------- | ----------------------------------------------------------------------------- | ---- |
| **研发投入"质"与"量"** | 研发强度≥15%且逐年提升；资本化率<30%为审慎；研发人员占比≥30%                | 8分  |
| **研发产出效率**       | 发明专利数量与质量；新产品收入占比≥20%；技术产品化周期；重大科研项目节点推进 | 8分  |
| **资本回报效率**       | ROIC > WACC；增量资本回报率 > 存量ROIC                                        | 4分  |

**科技股专用估值调整提示**：研发费用化会压低当期利润，导致PE虚高、PEG被动变大。建议将研发费用部分加回（或参考费用化研发支出而非全部研发支出），用**核心经营利润**计算调整后PE，再与增速比较，以更真实地反映科技公司的估值水平。

### 支柱四：地缘政治与外部环境

> 本支柱的制裁清单、出口管制现状、风险行业清单与国产化率均为**时变项**（核验入口见 0.1），评估前须先实时核验，勿沿用历史清单。

- **海外收入依赖度**：海外收入占比越高，越易受关税、出口管制冲击
- **逆全球化暴露度**：是否属于"全球化依赖型"（海外收入占比高、供应链外置）？在贸易壁垒、产业链本土化、技术脱钩、资本/数据流动收紧四类信号下的承压程度如何？
- **供应链安全**：关键零部件、资源等是否依赖特定国家或单一供应商？
- **资源与成本敏感度**：关键矿产/能源是否依赖进口？一旦出口国推行"资源民族主义"（出口管制/加税/国有化），成本与供应稳定性如何？
- **地区冲突暴露度**：业务是否位于或依赖冲突热点区域、航运要道？有无库存缓冲与供应链绕行/多源方案？
- **制裁与清单风险**：是否已被或可能被列入实体清单？
- **本地化对冲能力**：是否有海外建厂、多元供应链来对冲？
- **自主研发抗压能力（"华为式"抗封锁能力）** ：研发投入强度与持续性；核心技术自主可控程度；"备胎计划"与替代方案；极端情形下的生存能力

### 支柱五：政策与资本覆盖度

> 以下为**个股级增量核验**（具名规划/政策/基金名录以实时检索为准），在 0.2 完成"赛道级"判断的基础上，落到**具体标的**：

- **注资强度落到标的**：该标的已获国家/地方产业基金注资的**额度占其市值/资本开支比例**如何？额度占比越大，政策优先级越强。
- **场景绑定是否兑现**：央企/产业资本参与的"资本+场景"绑定，是否已转化为该标的**可验证的订单、收入或量产进展**（而非停留在框架协议/意向）？
- **相对同赛道企业的政策门槛优势**：相较同赛道竞争者，该标的在强制采购比例、部委协同、财税优惠（税收减免/研发加计扣除/首台套补偿）等硬性工具下，是否享有更高的准入门槛或份额锁定？

### 五大支柱汇总判定规则

五大支柱交叉验证须落到**明确结论**（买入 / 观察 / 放弃），避免各支柱罗列却无法收口：

**与 0.3 三维矩阵的映射（避免维度拆分歧义）**：0.3 是「地缘倒逼强度 × 政策覆盖度 × 国字号基金介入」的**三维综合**矩阵；落到五大支柱时——**支柱四对应「地缘倒逼强度」维，支柱五对应「政策覆盖度 + 国字号基金介入」两维**。「回避档」的共同特征是「政策覆盖度低/无 + 国字号基金无覆盖」（政策与资本两维同时失守），此时无论地缘倒逼高低均一票回避：地缘「高」时因国产接不住而回避，地缘「低」时因纯市场驱动而回避。

**一票否决清单（命中任意一条即放弃或清仓，不进入后续判定）**：

- 诚信一票否决：兑现率<50%、业绩预告重大失真、财务造假、监管立案
- ROIC 长期<5% 却在拼命扩产
- 能力圈自检未通过（尤其科技股"技术理解"不过关不得重仓）
- 0.3 三维矩阵综合归为"回避"档（政策覆盖度低/无 且 国字号基金无覆盖，无论地缘倒逼高低）

**达标判定（须全部满足方可建仓）**：

- 支柱一（β）：产业景气向上——供需不恶化、产品单价稳定或上涨、CR5 提升或龙头份额扩大
- 支柱二（α）：ROIC > WACC 且≥10%（5%~10% 归"部分不达标"→ 观察仓；科技股按支柱二正文"调整后核心经营ROIC"口径）；营收/利润增速匹配；ROE 趋势向上或企稳，毛利率/净利率不恶化
- 支柱三：科技股须"管理层≥15 + 科研转化≥15"；普通行业须"管理层≥15"
- 支柱四：海外收入、资源/供应链、地区冲突暴露可控；其中"地缘倒逼强度非低/无"仅对**地缘倒逼型**赛道（半导体设备/材料等）作为硬门槛，**政策资本驱动型**赛道（机器人、信创等增量创造，地缘倒逼强度本就不高）仅豁免这一条硬门槛，海外收入/供应链/地区冲突暴露等敞口仍须体检，其达标与否（政策覆盖度与基金介入）以支柱五判定为准
- 支柱五：政策覆盖度至少"中"及以上（0.3 矩阵非"低/无覆盖"），且国字号基金介入非"无覆盖"（至少有覆盖或专项子基金）

**三档结论**：

- **全部达标** → 进入第4步估值锚定，可建仓
- **部分不达标** → 观察仓（最多轻仓跟踪，等待信号补齐，不重仓）
- **任一否决命中** → 放弃或清仓

## 第4步：估值锚定——多工具矩阵

科技股投资不能仅依赖单一PEG指标。下表为不同公司类型匹配的估值工具矩阵：

| 公司类型                             | 核心工具         | 辅助工具        | 可接受标准                                                                           |
| ------------------------------------ | ---------------- | --------------- | ------------------------------------------------------------------------------------ |
| **快速增长型（盈利稳定）**     | 调整后PEG        | 远期PE、PEG分位 | PEG<1为低估，1~1.2为合理，1.2~1.5为合理偏贵（持有不加仓、机动仓择机减），>1.5为高估 |
| **高研发投入型（利润被压低）** | PS / EV/Sales    | Rule of 40      | Rule of 40 ≥ 40（收入增速 + 利润率或FCF利润率）；EV/Sales低于同业可比               |
| **未盈利科技型**               | PS、EV/Sales     | 研发管线NPV     | 需有清晰的盈利路径和里程碑节点                                                       |
| **稳定增长型**                 | 远期PE + 隐含PEG | 股息率          | 当前PE ≤ 未来3年EPS复合增速（百分数值）×1.2（即隐含 PEG≤1.2）                     |
| **成熟型企业**                 | DCF              | 股息贴现        | 当前市值 ≤ 保守DCF估值的80%                                                         |

**Rule of 40**是评估科技公司经营质量的关键工具：收入增长率 + 利润率（或FCF利润率）应≥40%，用来衡量一家公司在增长与盈利之间的平衡质量。

**PEG使用边界**：PEG适用于盈利稳定的成长股；PS/EV/Sales适用于高研发投入或未盈利科技股；DCF适用于现金流稳定的成熟企业。科技股估值需综合使用多种工具交叉验证，避免单一指标误判。上表 PEG 阈值以中性宏观环境为基准，**加息/降息周期需动态上浮或下调**，见第五部分"四、宏观环境适配"。

**分批建仓规则**（默认三分法；建仓初期不"越跌越买"）：

> **建仓节奏总纲（三条路径的主从关系）**：①默认三分法（1/3 首仓 → 右侧确认后补至 2/3 → 连续 2~3 季兑现后补齐）适用于绝大多数标的；②左侧布局因逆势介入风险更高，首批 ≤50% 为**可建上限、而非必须建到 50%**（越不确定越压低），剩余须待右侧确认后才补齐；③右侧一次性建 2/3 仅在最强势信号共振时启用（见下），否则即便属右侧介入也按三分法推进。

- 股价进入"合理买入区间"后，先建**1/3首仓**（"首仓"指单只个股的第一批建仓，此时持仓<最终仓位的50%，属建仓初期，止损按8%~10%执行）。
- 建仓初期（完整定义见「五、止损纪律」：持仓<最终仓位的50%，**或**持仓≥50%但逻辑尚未经2~3个季度财报持续兑现验证），**8%~10%硬止损优先于"跌破估值下限补仓"**：一旦跌至止损线即离场，不得以"股价更便宜"为由逆向补仓。
- 后续加仓一律以**右侧确认信号**为准（产业景气加速、财报超预期、趋势反转确认三者至少其一），而非"股价跌得更低"；右侧确认后补至2/3，再经连续2~3个季度财报持续兑现后补齐至最终仓位。**注意区分**：此处"三者至少其一"是补至 2/3 的**常规加仓信号**；下一条"一次性建 2/3"的触发是**三信号共振**的极端强势信号，两者不是同一门槛。
- 左侧布局因逆势介入风险更高，首批限制在该标的最终仓位的50%以内（此为可建上限、非必须比例），剩余待右侧信号确认后再补；右侧重仓允许一次性建2/3、剩余1/3在回调至20日均线时补，但仅当"渗透率突破15%临界点 + 财报连续2个季度超预期 + 行业景气明确上行"三信号共振时才启用。常态（含一般右侧介入）仍按三分法阶梯推进（1/3→2/3→满），只有极端单边行情才启用左右侧差异化一次性节奏。
- 总仓位控制：单只个股初始≤总资产的10%，逻辑验证后≤15%，绝对上限≤20%；单一行业不超过总资产的40%

### 左侧布局 vs 右侧介入的选择

| 布局方式                   | 适用场景                                                             | 操作要点                                                                                                    |
| -------------------------- | -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **左侧布局（逆向）** | 行业遭遇短期利空（政策打压、周期低谷、税务抛售期），但长期逻辑未破坏 | 分批建仓，第一批在合理估值下限介入，第二批在利空最恐慌、成交量放大时介入；仓位控制在该标的最终仓位的50%以内 |
| **右侧重仓（顺势）** | 渗透率突破15%临界点、财报连续2个季度超预期、行业景气明确上行           | 可一次性建立2/3仓位，剩余1/3在后续回调至20日均线时补齐；需设置8%~10%止损线以防假突破（止损口径见下方注）    |

**核心原则**：左侧布局仅适用于"杀估值"而非"杀逻辑"——杀估值可逆向，杀逻辑必须止损（详见第五部分"矛盾一"）。

> **右侧重仓止损口径**：右侧一次性建2/3后，虽然持仓已超过50%，但"逻辑验证"须经后续2~3个季度财报持续兑现才成立，故止损仍按"建仓初期"口径执行8%~10%；待财报持续兑现、逻辑充分验证后，止损线才放宽至底仓口径的20%。

> **左侧布局的补仓节奏**：左侧首批控制在标的最终仓位的50%以内；剩余50%不盲目加仓，须待右侧信号确认（景气加速/财报兑现）后再补齐，避免"左侧越跌越买"演变为接飞刀。

### 常见估值陷阱提醒

- **低PE陷阱**：PE低但行业处于景气顶点（如周期股），未来盈利下降会导致PE被动抬升，此时低PE是"价值陷阱"。应结合行业所处周期位置综合判断。
- **高PE但增速不可持续**：当前增速来自一次性收益（出售资产、疫情红利），需剔除后重新计算真实PEG。
- **忽略股权稀释**：EPS增长可能来自回购减少股本，而非真实盈利增长；需结合总利润增速与股本变化综合判断。
- **研发费用化扭曲**：高研发投入的科技股，研发费用化会虚增PE、虚增PEG，务必用"核心经营利润"口径回算调整后PE（见支柱三提示）。

### ESG / 环境风险的估值折价

对**高碳排放、高环境风险行业**（化工、有色、钢铁、火电、高污染制造等），市场对其环境合规、碳减排与"搁浅资产"风险的系统性折价正在上升。因此这类标的在套用前文估值工具后，还需叠加一层**环境风险折价**：

| 情形                                                    | 折价幅度                                    | 操作要点                                                                           |
| ------------------------------------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------- |
| **高环境风险行业（无明确转型路径）**              | 合理估值再打**8~9折**（折价 10%~20%） | 相当于合理 PEG 上限下调至约 1.0；DCF 目标价、PEG 区间一并下调                      |
| **有明确碳减排承诺与可验证转型路径**              | 折价收窄至**≤5% 或豁免**                   | 须有具体资本开支计划、减排节点与第三方验证，否则仍按无转型处理                     |
| **面临"搁浅资产"风险**（高碳资产或提前报废/减值） | 折价加大，且**上调贴现率**            | 在 DCF 中额外上调 1~2 个百分点的贴现率，反映资产被迫提前退役的不确定性             |
| **ESG 评级处于行业尾部/最低档**                   | 触发治理或环境风险预警                      | 与支柱三"ESG 补充检查"联动，评级明显偏低时不再下调估值、而是**先降仓位上限** |

**操作要点**：

- 环境风险折价是**在基本面估值之上再打一次折扣**，不是替代前文的多工具估值，二者须叠加使用。
- 折价的本质是"为不确定性留出安全边际"：环境风险越不透明、越缺乏转型路径，安全边际要求越高。
- 对高环境风险行业的标的，**即使估值折价后看似便宜，也应同步下调单只仓位上限**（如将绝对上限 20% 下调至 15%），避免单一 ESG 黑天鹅击穿组合。

# 第三部分 持仓管理与操作纪律

## 一、底仓 + 机动仓分离管理

| 仓位类型                    | 定位                          | 操作规则                                                                                            |
| --------------------------- | ----------------------------- | --------------------------------------------------------------------------------------------------- |
| **底仓（60%~80%）**   | 长线核心，赚企业1~5年成长的钱 | 只要买入逻辑未被破坏，始终保留。不因短期20%以内的波动而卖出。可每季度结合最新财报做小幅调整（±5%） |
| **机动仓（20%~40%）** | 平滑波动，赚估值波动的钱      | 当股价进入高估区间时减持，回落至合理区间时回补                                                      |

**底仓/机动仓与现金的两层口径**：底仓(60%~80%)与机动仓(20%~40%)之和恒为100%，指**股票仓位内部**的切分；"风险预算""宏观环境适配"中的现金比例（常态10%~20%、风险期20%~30%或更高）则指**占总资产**的比例。执行顺序：先按宏观/风险预算确定现金占总资产的比例，剩余部分再按底仓/机动仓切分。

**为什么要做底仓/机动仓分离？**

对个人投资者而言，最大的心理痛苦来源于"卖飞好公司"和"坐过山车"之间的反复纠结。通过底仓与机动仓分离，您可以在不触碰核心逻辑仓位的前提下，对估值过高的部分做获利了结，既锁定了利润，又保留了核心头寸的长期复利。

## 二、仓位管理与再平衡规则

| 管理维度               | 具体规则                                                                                                                          |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **总持股数**     | 5~10只为宜。过少则非系统性风险过大，过多则跟踪精力不足                                                                            |
| **单只个股上限** | 初始≤10%，逻辑验证后≤15%，绝对上限≤20%（绝对上限20%仅限最高确信度、护城河最深的核心底仓在长期充分验证后使用，普通持仓封顶15%；组合内上浮至绝对20%的标的合计不超过2只） |
| **单一行业上限** | ≤总资产的40%，避免行业黑天鹅导致组合崩溃                                                                                         |
| **行业相关性**   | 持有的行业之间相关系数<0.5（如消费+科技+医药的搭配优于纯科技赛道内部多只持仓）                                                    |
| **流动性**       | 持有标的日成交额至少>1亿元（小市值可放宽至>3000万），确保极端行情下能快速调整                                                     |

**再平衡触发规则**：每季度末检查组合，当单只个股占比偏离目标±5%时，进行再平衡——将占比升高的资产适当减持，补到占比下降的资产中，使组合回到目标比例。这种操作的核心目的是**不追涨、不杀跌，用规则替代情绪**。

**风险预算**：设定组合最大回撤目标（如不超过20%），当回撤接近目标时降低仓位或提高现金比例。常态现金仓位为10%~20%；市场整体估值分位>80%时提高至20%~30%；进入衰退/滞胀期则按第五部分宏观矩阵上抬（衰退30%~40%、滞胀≥40%）。**回撤控制衔接**：接近回撤目标时优先减机动仓、提高现金（底仓仅在逻辑证伪时退出）；机动仓不足以控制回撤时，再按底仓/机动仓比例同步下调。

**波动率调整止损**：对高波动科技股，用ATR（平均真实波幅）设置**底仓阶段的动态跟踪止损**（仅在底仓已建立且逻辑已验证后使用）。**计算公式**：止损价 = 买入价 −（2~3）× ATR(14)，其中 ATR(14) 为最近14个交易日的平均真实波幅，TR = max(当日最高−当日最低, |当日最高−昨收|, |当日最低−昨收|)。

**ATR 与硬止损的关系**：低波动股直接用 8%~10% 硬止损；建仓初期（持仓<最终仓位的50%且逻辑未验证）一律按 8%~10% 硬止损、不用 ATR。高波动科技股仅在底仓已建立且逻辑已验证后，用 2~3 倍 ATR 把固定的 20% 底仓容忍度精化为"跟随波动下移的动态跟踪止损"，而非放宽 8%~10% 初始止损。ATR 止损价对应的亏损幅度由 20% 底仓容忍度封顶——ATR 只能精化跟踪节奏，不能突破 20% 底仓容忍度。

## 三、卖出规则：诚信否决 > 硬止损 > 逻辑止损 > 产业景气判断 > 估值判断

以下卖出触发按优先级从高到低排列，与第五部分「决策优先级金字塔」及第六部分「一页纸备忘卡」完全一一对应：

**优先级1：诚信否决（立即清仓，一票否决）**

- 管理层诚信问题暴露、财务造假实锤、监管立案——无论估值、趋势、仓位状态如何，立即清仓，不找任何理由

**优先级2：硬止损**

- 单笔亏损达8%~10%且无明确基本面反转信号，止损离场（详见本部分「五、止损纪律」）

**优先级3：逻辑止损（减仓或清仓）**

- 连续2个季度业绩低于预期，且产业景气未改善
- 财务出现不可逆恶化（应收账款暴增、存货高企、现金流持续为负）
- 龙头地位被颠覆、科研转化大幅低于预期
- 管理层或科研转化评分跌破10分（非诚信事项；诚信事项走优先级1）→ 降观察仓/减仓

**优先级4：产业景气判断（按景气方向调仓）**

- 渗透率/ROE 出现拐点，但**景气尚可、仅节奏放缓**（如进入40%~60%逐步兑现期）→ 减机动仓、降仓位
- 若**增速归零/转负**（增长见顶）→ 升级为逻辑恶化、清仓（独立触发，与渗透率位置无关）

**优先级5：估值判断（底仓不动，机动仓调整）**

- 调整后PEG>1.5进入高估区 → 减机动仓；PEG>2为严重透支 → 加速清机动仓
- 市场情绪极度狂热（如两融余额骤增、换手率持续高位、成交额创新高、新开户激增等多信号共振）→ 减机动仓，多项共振时加速清机动仓

**补充机制（不占优先级，作为兜底/优化动作）**：

- **时间止损**：持有满4个季度（1年），买入逻辑仍未兑现，减仓至观察仓或替换（此止损仅针对"逻辑未兑现"的仓位，与"1~5年长期持有逻辑已兑现的杰出企业"并不冲突：前者是证伪退出，后者是价值兑现的耐心等待）
- **性价比替换（末位优化）**：发现其他标的估值显著更低且产业趋势更强，可逐步切换；调仓频率控制在每季度最多1次

## 四、补充：暂时性困难 vs 永久性衰退判断清单

费雪最擅长的，是在杰出企业遭遇暂时性困难时逆势加仓。但并非所有下跌都是"暂时性困难"，有些是"永久性衰退"。下表用于区分两者，帮助决定是加仓还是清仓：

| 判断维度           | 暂时性困难（可加仓）             | 永久性衰退（需清仓）       |
| ------------------ | -------------------------------- | -------------------------- |
| **行业需求** | 需求延迟，但长期趋势未变         | 需求被替代品永久性替代     |
| **竞争格局** | 份额短期波动，但优势仍在         | 份额持续流失，护城河消失   |
| **财务**     | 现金流短期承压，但资产负债表健康 | 现金流持续为负，债务恶化   |
| **管理层**   | 承认问题，有清晰应对方案         | 推卸责任，频繁更换高管     |
| **研发**     | 研发投入维持或增加               | 研发投入持续削减           |
| **客户**     | 客户流失是暂时性的，可挽回       | 核心客户永久性转向竞争对手 |

**使用规则**：对核心底仓，若判断为"暂时性困难"，且产业逻辑、科研转化（科技股）、管理层、财务等维度均未恶化，可在合理估值下限附近加仓；若判断为"永久性衰退"，无论盈亏立即清仓。

## 五、止损纪律

- **硬止损**：买入后若下跌超过**8%~10%** 且无明确基本面反转信号，止损离场。忘掉买入成本，以市场信号为准
- **逻辑止损**：若买入逻辑被证伪，无论盈亏立即离场
- **执行方式**：建议用条件单/止损单自动执行，避免临盘犹豫

**分仓位止损规则**（硬止损 8%~10% 与底仓容忍 20% 的衔接；此处"底仓已建立"指**单只标的达到最终仓位的50%且逻辑已验证**，非组合层面的60%~80%底仓）：

> **"建仓初期"完整定义**：指①持仓 < 最终仓位的50%；或②持仓≥50% 但逻辑尚未经 2~3 个季度财报持续兑现验证（如右侧一次性建 2/3 后、财报尚未兑现期间）。两者任一成立即适用 8%~10% 硬止损，而非仅看"<50%"这一个数字。

| 仓位状态                                 | 决策规则                                                                                                                                                                                          |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **建仓初期（持仓<最终仓位的50%，或持仓≥50%但逻辑未验证）** | 若下跌超过8%~10%，按欧奈尔规则止损离场，保护本金                                                                                                                                                  |
| **底仓已建立且逻辑已验证**         | 若自买入价下跌≤20%且产业逻辑、科研转化（科技股）、管理层、财务等维度均未恶化，可在合理估值下限附近加仓；若下跌>20%，不自动加仓，转入"暂时性困难 vs 永久性衰退"清单复核，据结果决定加仓/持有/清仓 |
| **无论何种状态，逻辑被证伪**       | 立即清仓，不存在"越跌越买"                                                                                                                                                                        |

**止损分水岭（以仓位状态为准，而非跌幅数字）**：8%~10% 止损适用于"建仓初期或未经逻辑验证的仓位"（含右侧一次性建 2/3 后、财报尚未兑现期间）；底仓建立且逻辑充分验证后，容忍度放宽至 20%。二者以"仓位状态"为分水岭——须**同时满足**『①达到最终仓位的50%』与『②逻辑经 2~3 季财报兑现验证』两个条件，缺一仍按建仓初期 8%~10% 执行。

# 第四部分 国产化投资专题：被迫替代下的价值成长

## 一、国产化率提升的成长逻辑

国产化率提升本质上是**"份额替代型成长"** ——国产企业从进口厂商手中抢下存量份额，可及市场（SAM）持续扩大，从而驱动企业内在价值增长。但这并非国产化率驱动的全部：**为对冲或减缓未来可能的地缘政治风险，国家层面主动推进国产替代，往往会同步创造出增量需求**，使产业总盘子（TAM）本身也在扩大。

具体而言，国产替代驱动的成长来源可拆成两条路径：

- **存量替代**：从进口厂商手中抢下既有市场的份额（SAM 内替代比例提升），这是经典的"份额替代型成长"。
- **增量创造**：为摆脱对外依赖、保障供应链安全，国家/大客户会**主动培育本土产业链**，从而催生本不存在的额外需求（如信创替换、设备更新与安全冗余备份、以国产为门槛的新增采购场景、应用场景强制开放等），这是"政策创造需求"的增量成长。

| 维度                 | 传统渗透率驱动     | 国产化率驱动                                       |
| -------------------- | ------------------ | -------------------------------------------------- |
| **TAM**        | 持续扩大           | 往往同时扩大：存量替代 + 政策/安全驱动的增量需求   |
| **成长来源**   | 行业蛋糕做大       | 抢进口厂商份额（存量）+ 政策创造的增量市场（增量） |
| **成长确定性** | 取决于技术接受速度 | 取决于**技术突破+客户验证+政策推力**三重因素 |

**关键区分**：国产替代的"内需/政策拉动"已是当前国产化行情的常态特征——判断某标的成长时，不应把 TAM 简单冻结为"替代前水平"，而应同时测算①可替代的存量市场空间、②政策与安全需求带来的增量空间。前者定"替代下限"，后者定"成长上限"。

# 第五部分 五位大师思想的矛盾分析与风险应对

> **诚实地面对风险，是长期生存的前提。** 以下分析聚焦于五位大师理念融合后产生的内在矛盾，以及这些矛盾在实战中可能引发的冲突。费雪的加入，让"长期持有"与"信号离场"的张力比四位大师时代更尖锐。理解这些矛盾，比背诵任何选股清单都更重要。

## 一、核心矛盾：当大师"打架"时，您听谁的？

### 矛盾一：买点哲学的根本对立

|                        | 欧奈尔                                           | 费雪 / 林奇 / 郑希 / 李进                                                                                                                       |
| ---------------------- | ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **买点偏好**     | **突破新高**时追涨，杯柄形态突破是核心买点 | **下跌或拐点确认**时买入：费雪在杰出企业暂时性困难时逆势加仓，林奇在恐慌时逆向布局，郑希在ROE拐点确认后右侧介入，李进在渗透率 15%~40% 加速上行期重仓 |
| **对下跌的态度** | 股价下跌必有原因，绝不主动抄底                   | 市场恐慌是买入优质公司的绝佳窗口                                                                                                                |

**实战冲突场景**：某只优质成长股从高点回撤25%，产业渗透率仍在加速上行，调整后PEG已降至0.8。欧奈尔说"绝不抄底，等待重新突破"；林奇/费雪说"好公司打折甩卖，此时不买更待何时？"

**化解方案——以"逻辑是否完整"为分水岭**：

- 若回撤源于**系统性恐慌**（市场整体暴跌、行业短暂政策扰动），且**产业逻辑完好 + 管理层诚信 + 财务健康 + 科研转化（科技股）**四维均通过，则采用费雪/林奇的逆向策略，分批左侧布局。
- 若回撤伴随**基本面恶化**（连续2个季度业绩低于预期、ROE拐头向下、管理层诚信问题），则按欧奈尔规则，**不抄底，等待趋势明朗**。
- **核心原则**：左侧布局仅适用于"杀估值"而非"杀逻辑"。杀估值可逆向，杀逻辑必须止损。

### 矛盾二：持有逻辑的时间维度冲突

|                    | 林奇 / 费雪                                                  | 郑希 / 李进                                                        |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------------------------------ |
| **持有逻辑** | 基于企业自身的成长，持有周期以年为单位（费雪更是长达数十年） | 基于产业景气周期，持有周期取决于景气长度（可能2年，也可能2个季度） |
| **卖出触发** | 增速放缓、基本面变化                                         | 产业景气下行、渗透率减速、ROE拐头                                  |

**实战冲突场景**：某科技龙头过去3年复合增速40%，近两个季度增速从40%降至25%，产业渗透率刚过30%（尚未见顶）。林奇/费雪框架说"快速增长型增速放缓，考虑卖出"；李进框架说"渗透率刚过30%，仍在加速区，继续持有"。

**化解方案——区分"增速放缓"的性质**：

- **短期波动（可容忍）** ：单季增速放缓但**全年预期不变 + 产业渗透率仍处 15%~40% 加速上行期 + 竞争格局未恶化**，底仓继续持有，仅调整机动仓。
- **趋势性拐点（需减仓）** ：连续2~3个季度增速放缓 + **订单增速同步放缓 + 行业竞争加剧**，则无论渗透率位置如何，系统性减仓。
- **核心原则**：以"连续2~3个季度的数据趋势"而非"单季数据"来区分短期波动与趋势性拐点，避免被噪音干扰。**阈值区分**："业绩低于预期"是强信号，连续2个季度即触发逻辑止损（见第三部分"三、卖出规则"）；"增速放缓"是弱信号，需连续2~3个季度并结合订单增速与竞争格局才能确认趋势性拐点。

> **渗透率口径统一**：<5%为导入早期、5%~15%为突破期、15%~40%为李进"加速上行期"、40%~60%为逐步兑现期、>60%为天花板（见顶以"增速归零/转负"为准，而非单一渗透率数值）。据此，"仍处加速区"的边界以40%为准。

### 矛盾三：止损与"越跌越买"的冲突

|                        | 欧奈尔                             | 林奇 / 郑希 / 费雪         |
| ---------------------- | ---------------------------------- | -------------------------- |
| **对下跌的应对** | 亏损8%~10%无条件止损，不找任何理由 | 好公司下跌是机会，逆向加仓 |

这是五位大师理念中**最尖锐的矛盾**，也是个人投资者最容易被撕裂的地方。

> **口径注**：上表"无条件止损"为欧奈尔原话引用；本框架结合基本面检验，将其修订为"8%~10% 且无明确基本面反转信号"的**有条件止损**（见第三部分"五、止损纪律"），下文化解方案按此修订口径执行。

**化解方案——引入"仓位状态"作为决策变量**：

| 仓位状态                                 | 决策规则                                                                                                                                                                                                                                          |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **建仓初期（持仓<最终仓位的50%）** | 若下跌超过8%~10%，按欧奈尔规则**止损离场**，保护本金。即使后来涨回来，也不过是错过机会，而不是亏掉本金。                                                                                                                                    |
| **底仓已建立且逻辑已验证**         | 若自买入价下跌≤20%，且**产业逻辑、科研转化（科技股）、管理层、财务等维度均未恶化**，可采用费雪/林奇/郑希逻辑，**在合理估值下限附近加仓**；若下跌>20%，不自动加仓，转入"暂时性困难 vs 永久性衰退"清单复核，据结果决定加仓/持有/清仓。 |
| **无论何种状态，逻辑被证伪**       | 立即清仓，不存在"越跌越买"。                                                                                                                                                                                                                      |

- **核心原则**：**欧奈尔的规则优先于林奇/费雪的乐观。** 先活下来，再谈收益。底仓未建立前，止损是第一位的；底仓建立后且逻辑充分验证，才考虑逆向加仓。

### 矛盾四：分散与集中的路线分歧

|                    | 林奇                           | 费雪 / 欧奈尔 / 郑希 / 李进                                                   |
| ------------------ | ------------------------------ | ----------------------------------------------------------------------------- |
| **持仓特征** | 极分散（数百只），降低个股风险 | 相对集中：费雪重仓3~5只占总仓位70%，欧奈尔/郑希/李进集中在8~30只高确信度标的 |

**化解方案——个人投资者取"中间路线"** ：

- 5~10只持仓，既不过度分散（失去精力聚焦的优势），也不过度集中（避免单点毁灭）。
- **"核心+卫星"结构**：3~4 只核心重仓（各占 12%~15%，初始建仓 ≤10%，逻辑验证后上浮；其中最多 2 只最高确信度标的在长期充分验证后可上浮至 20%）+ 2~3 只卫星仓位（各占 5%~8%，试探性布局或行业补充）。
- **底仓/机动仓与持仓结构的映射**：底仓（股票仓位的 60%~80%）由核心重仓承担，机动仓（20%~40%）由卫星仓承担；核心重仓必须分散在不同行业，同一行业核心仓位合计不得超过单行业上限 40%。
- **自洽配置示例（示范一组不违约的组合，以下百分比均指占总资产）**：现金 20%、股票 80%（= 底仓占总资产 60% + 机动仓占总资产 20%；折算成股票仓位内约 75%/25%）。底仓 = 4 只核心各 15%，跨 4 个行业；机动仓 = 3 只卫星（8% + 7% + 5%）。合计 7 只，单只 ≤15%、单一行业 ≤40%，全部合规。
- 行业层面按李进的思路**分散**，个股层面按费雪/欧奈尔的思路**集中**。

### 矛盾五：费雪"绝不卖" vs 趋势/景气纪律（新增张力）

|                    | 费雪                                                                   | 欧奈尔 / 李进 / 郑希                                                  |
| ------------------ | ---------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **持有立场** | "卖出的最佳时机，几乎永远是不要卖"，长期持有杰出企业（如摩托罗拉44年） | 趋势走坏离场（欧奈尔）、景气下行调仓（郑希/李进）、估值透支减持机动仓 |

**实战冲突场景**：某底仓深度研究、管理层诚信优秀的标的，因行业景气短暂下行，股价回撤18%，调整后PEG升至1.6。费雪说"杰出企业不要卖"；李进说"景气下行该调仓"；欧奈尔说"趋势已走坏"。

**化解方案——费雪"不卖"有两个前提，缺一不可**：

1. **极度深度的研究认知**：确信这是一家能够持续创造增量价值的"杰出企业"，而非普通好公司；
2. **极度集中的持仓**：费雪的"不卖"建立在只重仓3~5只、占总仓位70%的极致集中之上——既然认知深度足够支撑重仓，就承受得起波动。

对个人投资者而言：

- 若持仓同时满足"深度认知 + 高确信度 + 管理层诚信 + 护城河稳固 + 财务健康"，且下跌属**暂时性困难**，则可采纳费雪逻辑，用"暂时性困难 vs 永久性衰退"清单（第三部分四）判断后继续持有甚至加仓；
- 若缺乏上述前提、或下跌属**永久性衰退**，则应按欧奈尔/李进纪律离场或调仓。
- **核心原则**：费雪的"不卖"是"认知深度的奖赏"，不是"懒惰不研究的借口"。**普通人只对极少数真正杰出的标的适用"不卖"，其余持仓一律服从景气与止损纪律。**

## 二、冲突化解总纲：决策优先级金字塔

当五位大师的指令在实战中"打架"时，遵循以下**优先级从高到低**的决策规则：

| 优先级                               | 触发条件                                   | 决策                                 | 思想来源             |
| ------------------------------------ | ------------------------------------------ | ------------------------------------ | -------------------- |
| **第一优先级（一票否决）**     | 管理层诚信问题暴露、财务造假实锤、监管立案 | **立即清仓**，不考虑估值和趋势 | 费雪（诚信一票否决） |
| **第二优先级（硬止损）**       | 单笔亏损达8%~10%，且无明确基本面反转信号   | **止损离场**                 | 欧奈尔               |
| **第三优先级（逻辑止损）**     | 连续2个季度业绩低于预期，且产业景气未改善  | **减仓或清仓**                 | 林奇 + 郑希          |
| **第四优先级（产业景气判断）** | 前三项均未触发，但渗透率/ROE出现拐点信号   | **按景气方向调仓**             | 李进 + 郑希          |
| **第五优先级（估值判断）**     | 以上均未触发，仅股价短期波动或估值波动     | **底仓不动，机动仓调整**       | 林奇                 |

**一票否决的语境边界**：本表"第一优先级（诚信一票否决）"针对**持仓后**的清仓信号；第3步汇总判定中的 ROIC<5%扩产、能力圈自检未通过、0.3 三维矩阵回避属**买入前**闸门，命中即在建仓前放弃、不进入本表（持仓后卖出金字塔）。两类"否决"的语境不同。

**核心原则**：先保命（止损/防造假），再谈收益（景气/估值）。欧奈尔的底线规则优先于林奇/费雪的乐观逆向，郑希/李进的产业判断优先于短期的估值噪音。

## 四、宏观环境适配：框架参数的时变调节器

前文的估值区间、仓位上限、现金比例等参数，均以"中性宏观环境"为基准设定。但宏观利率、信用与经济周期会系统性改变成长股的估值中枢与风险偏好，**框架参数必须随宏观环境动态校准，而非当作常数使用**。

**核心原则**：宏观只用于调节"估值容忍度"与"仓位尺度"，**不替代个股基本面判断，也不作为择时清仓的依据**——内在价值决定长期收益，宏观决定当前该出多少钱、冒多大风险。宏观数据需按月/季更新，避免刻舟求剑。

**三表坐标轴索引（以美林四档为主坐标）**：第（一）表按"利率环境"三档、（二）表按"经济周期"两列、（三）表按"美林时钟"四档，三者是同一宏观判断的三层解构——利率环境是估值参数的直接锚，经济周期是仓位参数的直接锚，美林阶段是二者叠加的完整坐标。执行时以（一）+（二）算参数、（三）总收口，坐标换算关系为：

| 宏观阶段 | 对应利率环境（（一）表） | 对应经济周期档（（二）表） |
| -------- | ------------------------ | -------------------------- |
| 衰退     | 降息启动（临时按1.0）    | 衰退档（收紧）             |
| 复苏     | 低利率（放宽至1.5）      | 中性/复苏档（基准）        |
| 过热     | 加息（收紧至1.0）        | 过热档（收紧）             |
| 滞胀     | 高利率+信用收缩（0.8）   | 滞胀档（最紧）             |

### （一）利率周期 → PEG 合理区间动态调整

成长股估值对利率高度敏感：利率是贴现率的"锚"，利率上升压缩远端现金流现值（对长久的成长股杀伤尤大），利率下降则抬升其估值中枢。因此 **PEG 合理区间的上限不应固定，而应随利率环境上下浮动**：

| 利率环境                  | 调整后PEG 合理买入区间 | 低估（可加仓） | 高估（减机动仓）                                          |
| ------------------------- | ---------------------- | -------------- | --------------------------------------------------------- |
| **加息/高利率周期** | 收紧至 0.8~1.0         | <0.7           | >1.2（0.7~0.8为低估上沿、合理下沿之间的空档，不主动加仓） |
| **中性**（基准）    | 1.0~1.2                | <1.0           | >1.5                                                      |
| **降息/低利率周期** | 放宽至 1.2~1.5         | <1.2           | 仍>1.5减仓，>2绝对透支清机动仓                            |

> **PEG 区间定义（统一口径）**：合理买入区间之上、高估阈值之下的"中间带"（以中性环境为例即 1.2~1.5）定义为**合理偏贵**——可继续持有底仓，但不加仓，机动仓逢高择机减仓。增速确定性越高、护城河越深，可容忍的偏贵上限越接近 1.5。"增速确定性"以三者为量化锚：①连续 2~3 个季度增速的稳定性（波动越小越确定）；②订单可见度（在手订单/预收/合同负债对下季收入的覆盖度）；③竞争格局固化程度（CR5 与龙头份额趋势）。三者任意一项偏弱，偏贵上限即收紧至 1.2。

**使用要点**：

- 以国债收益率或政策利率的**趋势**判断所处利率阶段，而非靠单次升降息下结论。
- 加息周期中"看起来很贵"的成长股，可能因长久期而被更严厉地杀估值——此时即便 PEG 达标也应更保守；降息周期则相反，但须严防"利率幻觉"下的过度乐观。
- **"PEG>2 为严重透支"这条红线不因降息而取消**，只可在降息周期放缓减仓节奏。
- **滞胀期**（高利率+信用收缩）较加息档 0.8~1.0 更紧，合理买入上限进一步下探至 0.8（与（三）矩阵滞胀档一致）。

### （二）经济周期 → 现金仓位与个股上限调整

**经济衰退/滞胀期，应系统性降杠杆、降集中度、留现金**，为恐慌期的逆向加仓预留弹药：

| 参数                   | 中性/复苏期（基准）                    | 衰退期（收紧）                   | 调整逻辑                                         |
| ---------------------- | -------------------------------------- | -------------------------------- | ------------------------------------------------ |
| **现金仓位**     | 10%~20%（估值分位>80%时提高至20%~30%） | 提高至 30%~40% 或更高            | 衰退期资产普跌、机会成本下降，现金的期权价值上升 |
| **单只个股上限** | 初始≤10%、验证后≤15%、绝对≤20%      | 初始≤8%、验证后≤12%、绝对≤15% | 衰退期个股黑天鹅与流动性风险上升，须降低集中度   |
| **单一行业上限** | ≤40%                                  | ≤30%                            | 行业 beta 在衰退期同步放大，须降低单一行业暴露   |

**使用要点**：

- 衰退判断以"信用收缩 + 盈利下行 + 利率见顶拐头"三信号交叉印证，避免被单一指标误导。
- 提高现金不是"预测暴跌"，而是**为恐慌期的逆向加仓预留弹药**，与费雪/林奇的逆向布局形成闭环。
- 上表"衰退期"为基准收紧口径；**滞胀期**在此基础上进一步收紧——单只上限初始≤6%、验证后≤10%、绝对≤12%，单一行业上限≤20%，现金仓位≥40%（与（三）矩阵的滞胀档一致）。
- **过热期**（加息、信用扩张见顶）同样须收紧，参照衰退口径、现金略松：单只上限初始≤8%、验证后≤12%、绝对≤15%，单一行业上限≤25%，现金仓位≥25%（与（三）矩阵的过热档"验证后≤12%、现金≥25%"一致）。

### （三）宏观环境矩阵：美林时钟 + 信用周期 → 框架参数

将美林时钟四象限与信用周期（社融/信贷脉冲）结合，得到框架参数的快速对照表：

| 宏观阶段       | 利率/信用特征        | 风格倾向           | PEG合理买入上限 | 现金仓位 | 单只上限（验证后） |
| -------------- | -------------------- | ------------------ | --------------- | -------- | ------------------ |
| **衰退** | 降息启动、信用收缩   | 防御、低波成长优先 | 1.0（临时收紧） | 30%~40%  | ≤12%              |
| **复苏** | 低利率、信用扩张初期 | 成长/顺周期优先    | 1.5（放宽）     | 10%~20%  | ≤15%              |
| **过热** | 加息、信用扩张见顶   | 周期/价值优先      | 1.0（收紧）     | ≥25%    | ≤12%              |
| **滞胀** | 高利率、信用收缩     | 现金/防御为主      | 0.8（最紧）     | ≥40%    | ≤10%              |

**使用要点**：

- **美林时钟定"风格与行业 beta"**，**信用周期定"总仓位与现金"**：二者同向时信号最可靠，背离时以信用周期（更接近资金面真相）为准。
- **矩阵"PEG"列口径（=PEG合理买入区间上限，同（一）表）**：衰退期虽启动降息，但盈利下行与信用收缩主导、市场风险偏好极低，估值中枢先杀后抬，故合理买入上限临时收紧至1.0（而非降息档1.5）；待"宽信用"实质落地（信贷脉冲转正）后再切换至1.5。滞胀期为高利率+信用收缩+盈利下行"三杀"，较加息档（0.8~1.0）进一步收紧，合理买入上限取加息档区间下限 0.8（即 PEG≥0.8 即不新建仓）。
- **矩阵"单只上限"为"验证后"一档口径**，完整三档（初始/验证后/绝对）按（二）表同向收紧；例如滞胀期可细化为初始≤6%、验证后≤10%、绝对≤12%。**单一行业上限同向收紧**：中性/复苏≤40%、衰退≤30%、过热≤25%、滞胀≤20%，避免单一行业在极端期超额暴露。
- 矩阵"现金仓位"为该宏观阶段的**默认目标下限**；复苏/中性期现金下限为10%（常态10%~20%，不主动低于10%），只有进入衰退/滞胀/过热期才按矩阵值向上抬升下限——估值分位>80%时提高至20%~30%，进入衰退/滞胀/过热期后以矩阵值收口（衰退30%~40%、滞胀≥40%、过热≥25%，与风险预算规则一致）。
- 本框架的科技/国产化成长赛道，最适配的宏观窗口是**复苏期**（低利率+信用扩张）；进入**滞胀/衰退**阶段，应优先降仓位而非硬扛高估值。

# 第六部分 一页纸操作备忘卡

建议打印此页，贴在投资笔记中，每次操作前快速过一遍：

---

**【前置判断】**

- 地缘政治倒逼强度：制裁是否已落地？断供是否已实际发生？
- 政策覆盖度：按"全局动态获取声明"查**当前最新**五年规划/专项政策，是否以"超常规+全链条"等强干预强度覆盖？有无**强制采购、部委协同、财税优惠（税收减免/研发加计扣除/首台套补偿）**等硬性配套？
- 基金与资本介入：按"全局动态获取声明"查**当前最新**国家/地方产业基金名录，是否有直接注资或专项子基金？**注资额度与占比**（基金规模、单项目投资额、占总投资比例）是否足够大？（具体基金名/额度以实时检索为准）
- → 三维交叉判断后，才进入下一步筛选。

**【选股】**

- 产业空间≥1000亿，渗透率<5%导入早期、5%~15%突破期、15%~40%加速上行期、40%~60%逐步兑现、>60%天花板；增速归零/转负即见顶清仓
- 国产化率<5%过早（战略卡脖子环节可观察/小仓），5%~20%为突破期（跟踪/小仓），20%~50%为加速投资期（订单放量），>50%替代空间收窄
- 营收≥10亿，ROE有向上趋势，ROIC > WACC，现金流为正
- 管理层诚信（年报验证）+ 科研转化（专利/新产品收入/重大科研项目进展）
- 费雪补充检查：销售组织出色？管理层持股≥3%？
- 地缘政治：评估海外收入依赖度、供应链可控性、资源/大宗敏感度、地区冲突暴露与逆全球化暴露度

**【估值】**

- 快速增长型（中性环境，加息/降息期按第五部分"四"动态调整）：调整后PEG<1.0低估可加仓、1.0~1.2合理买入、1.2~1.5合理偏贵持有不加仓（机动仓择机减）、>1.5高估减仓
- 高研发投入型：Rule of 40 ≥ 40，PS/EV/Sales低于同业可比
- 稳定增长型：远期PE ≤ 未来3年EPS复合增速（百分数值）×1.2（隐含PEG≤1.2）；成熟型：市值 ≤ 保守DCF估值的80%
- 未盈利科技型：PS/EV/Sales + 研发管线NPV，需有清晰盈利路径和里程碑节点
- 分批建仓：合理区间先建1/3首仓，后续加仓以右侧确认信号（景气加速/财报超预期/趋势反转）为准；建仓初期（<最终仓位50%）跌超8%~10%即止损，不"越跌越买"
- 左侧布局只用于"杀估值"，"杀逻辑"必须离场

**【持仓】**

- 底仓（股票仓位的60%~80%）长持，机动仓（股票仓位的20%~40%）做估值波段
- 单只初始≤10%、验证后≤15%（绝对上限≤20%），单行业≤40%，持股5~10只
- 每季度末再平衡一次，偏离目标±5%触发

**【卖出（按优先级）】**

- 最高优先级：管理层失信/财务造假 → 立即清仓
- 次高优先级：硬止损8%~10%且无基本面反转信号 → 止损离场
- 第三优先级：连续2季业绩低于预期 → 减仓/清仓
- 第四优先级：渗透率减速/ROE拐头（如进入40%~60%逐步兑现期）→ 减机动仓；增速归零/转负 → 升级为逻辑恶化、清仓
- 第五优先级：估值PEG>1.5 → 减机动仓；PEG>2 → 加速清机动仓
- **永久性衰退判断**：若行业需求被替代、护城河消失、研发持续削减 → 立即清仓
- **费雪"不卖"的适用边界**：仅限极度深研的杰出企业；否则一律服从上述纪律

**【补充机制（不占优先级，兜底/优化动作）】**

- 时间止损：满1年（4季度）逻辑未兑现 → 减仓至观察仓（仅限"逻辑未兑现"的仓位，非杰出企业）
- 末位优化：发现估值更低、趋势更强的标的 → 逐步替换（每季度最多调仓1次）

**【风控】**

- 闲钱投资：资金期限 ≥ 持有期 + 至少1年安全垫
- 每季度复盘持仓逻辑 + 行业景气 + 地缘政治 + 估值水位 + 宏观阶段
- 组合最大回撤目标≤20%，接近目标时提高现金比例
- 宏观校准：先判利率/信用/经济阶段 → 动态调 PEG 区间、现金仓位、单只上限（见第五部分"四"）

**【决策优先级（当各维度"打架"时）】**

- 欧奈尔的止损 > 林奇/费雪的逆向加仓
- 逻辑证伪 > 估值便宜
- 先保命，再谈收益

# 结语

投资是一场认知的变现，更是心性的修炼。1~5年的中长期持有，既不是短期博弈，也不是"买入并遗忘"的被动投资，而是**主动研究、耐心持有、纪律风控**的结合。

**这套融合体系的精髓可以浓缩为一句话：**

> **在景气向上的产业中，选择管理层诚信、科研转化高效的好公司，以合理价格买入，用底仓陪伴成长，用机动仓平滑波动，用欧奈尔的纪律保护本金，用费雪的耐心持有真正的杰出企业，让时间成为朋友。**

**给个人投资者的实战建议：**

1. **做减法**：不要试图同时完美运用五位大师的所有指标。建议以"林奇的常识选股 + 郑希/李进的景气择时"为主轴，将费雪的质化分析（管理层诚信、长期竞争力）作为"是否值得重仓"的过滤器，将欧奈尔的止损作为"排雷底线"。
2. **守住能力圈**：如果无法通过第2步的"能力圈自检"四项维度（尤其科技股的"技术理解"），就果断放弃，哪怕它的产业趋势再好。赚认知范围内的钱，是中长期投资的铁律。
3. **定期"体检"** ：每半年或一年，用这套融合体系的逻辑对持仓进行全面复盘，重点检验"买入逻辑是否还在""管理层是否依然诚信""产业景气是否仍向上"，用客观的跟踪替代主观的信仰。
4. **先模拟后实盘**：建议先以模拟盘或小资金运行3~6个月，验证体系与自身心性的匹配度，再逐步加大投入。

市场有风险，投资需谨慎，独立判断永远是第一位的。
