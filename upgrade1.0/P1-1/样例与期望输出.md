## 1. 样例集说明

输入参数语义：`--nopat`（税后净营业利润）、`--invested-capital`（投入资本，须 > 0）、`--wacc`（WACC，百分点，可选）、`--expanding`（是否仍拼命扩产，可选）。

`ROIC = NOPAT ÷ 投入资本 × 100%`，结果精确至 2 位小数。

> **JSON 数值精度说明**：人类可读行的 `ROIC` 以 `:.2f` 显示为 2 位小数（如 `12.50%`）；结构化 JSON 中的 `roic` 字段为 float 类型，JSON 数字原生不保留尾随零（`12.50` 序列化为 `12.5`、`20.00` 序列化为 `20.0`），但其值已通过 `Decimal.quantize(Decimal("0.01"))` 精确量化到 0.01。判定（tier/verdict）基于未量化的精确 Decimal，输出展示基于量化后的 2 位小数。

## 3. 期望输出（关键断言字段）

### S1 优秀档

```text
ROIC       = NOPAT / 投入资本 = 20.0000 / 100.0000 = 20.00%
✅ 四档判定: 优秀
结论: 合格（优秀档，可支持单只上限上浮至绝对 20%）
```

```json
{"roic": 20.0, "tier": "优秀", "wacc_applied": false}
```

### S2 合格档（>WACC 且 ≥10%）

```text
ROIC       = NOPAT / 投入资本 = 12.5000 / 100.0000 = 12.50%
✅ 四档判定: 合格
结论: 合格（ROIC>WACC 且 ≥10%）
```

```json
{"roic": 12.5, "tier": "合格", "wacc_applied": true}
```
