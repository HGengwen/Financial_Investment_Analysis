## 3. `TestRoic` 用例明细（10 项）

| # | 方法 | 输入 | 断言（关键） | 覆盖口径 |
| --- | --- | --- | --- | --- |
| 1 | `test_roic_excellent` | `roic(20, 100)` | `roic == 20.0`；`tier == '优秀'`；verdict 含「优秀」 | ROIC > 15% → 优秀 |
| 2 | `test_roic_qualified_with_wacc` | `roic(12.5, 100, wacc=8)` | `roic == 12.5`；`tier == '合格'`；`wacc_applied == True` | 10%~15% 且 ROIC>WACC → 合格 |
| 3 | `test_roic_qualified_no_wacc` | `roic(12.5, 100)` | `tier == '合格'`；`wacc_applied == False`；verdict 含「未校验」 | 10%~15% 无 WACC → 合格（未校验） |
| 4 | `test_roic_between_5_and_10` | `roic(8, 100)` | `roic == 8.0`；`tier == '部分不达标'`；verdict 含「5%~10%」 | 5%~10% → 观察仓 |
| 5 | `test_roic_below_wacc` | `roic(12, 100, wacc=15)` | `tier == '部分不达标'`；verdict 含「ROIC≤WACC」 | 10%~15% 但 ROIC≤WACC → 审慎归位观察仓 |
| 6 | `test_roic_veto_expanding` | `roic(3, 100, expanding=True)` | `tier == '不达标'`；verdict 含「一票否决」 | ROIC<5% 且扩产 → 一票否决 |
| 7 | `test_roic_below_5_not_expanding` | `roic(3, 100, expanding=False)` | `tier == '部分不达标'`；verdict 含「不扩产」 | ROIC<5% 不扩产 → 观察仓 |
| 8 | `test_roic_two_decimal_precision` | `roic(1, 3)` | `roic == 33.33`；`tier == '优秀'` | 1/3×100 → 2 位小数 33.33 |
| 9 | `test_roic_zero_denominator` | `roic(10, 0)` | `roic is None`；`tier == 'N/A'`；verdict 含「投入资本」 | 投入资本 ≤ 0 → 降级提示（非除零异常） |
| 10 | `test_roic_negative_nopat` | `roic(-5, 100)` | `roic == -5.0`；`tier == '部分不达标'`；verdict 含「NOPAT 非正」 | NOPAT ≤ 0 → 仍计算并落 ROIC<5% 档 |
