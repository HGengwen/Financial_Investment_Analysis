## 2. 目标与范围

**本任务做的**：

1. 新增 `roic()` 纯计算函数：`ROIC = NOPAT ÷ 投入资本 × 100%`，输出 2 位小数。

## 3. 关键量化口径（权威 = 框架第 3 步·支柱二）

### 3.1 公式与权威值

- **公式**：`ROIC = NOPAT ÷ 投入资本`（结果以百分数表示，2 位小数）。
- **权威四档（框架原文）**：
  - **合格**：`ROIC > WACC` 且 `≥ 10%`；
  - **优秀**：`ROIC > 15%`——「最高确信度标的」候选加分项，可支持单只上限上浮至绝对 20%（仅限长期充分验证的深护城河核心底仓），并允许 PEG 偏贵上沿接近 1.5；
  - **长期 < 5% 不达标**：其中 `ROIC < 5%` 且仍在拼命扩产时触发**一票否决**；`< 5%` 但不扩产归入「部分不达标（观察仓）」；
  - **介于 5%~10%**：同为「部分不达标（观察仓）」。

### 3.2 四档判定决策表（P1-1 权威实现，含边界补齐）

> 框架对「`10% ≤ ROIC ≤ 15%` 但 `ROIC ≤ WACC`」未显式指档，属口径 gap。P1-1 按**更审慎相邻档**归位：该情形判「部分不达标（观察仓）」并提示 `ROIC≤WACC`。此为实现层的审慎归位，非框架新增口径。

| 优先级 | 条件 | tier | verdict |
| --- | --- | --- | --- |
| 1 | `ROIC > 15%`（未提供 WACC，或 `ROIC > WACC`） | 优秀 | 合格（优秀档，可支持单只上限上浮至绝对 20%） |
| 1' | `ROIC > 15%` 且提供了 WACC 且 `ROIC ≤ WACC` | 优秀 | 合格（优秀档绝对值达标，但 `ROIC≤WACC` 未覆盖资本成本，建议人工复核） |
| 2 | `10% ≤ ROIC ≤ 15%` 且（未提供 WACC 或 `ROIC > WACC`） | 合格 | 合格（未提供 WACC 时标注「未校验 ROIC>WACC」） |
| 3 | `10% ≤ ROIC ≤ 15%` 且 `ROIC ≤ WACC` | 部分不达标 | 观察仓（ROIC≤WACC，资本回报未覆盖资本成本） |
| 4 | `5% ≤ ROIC < 10%` | 部分不达标 | 观察仓（5%~10%） |
| 5 | `ROIC < 5%` 且 `expanding = true` | 不达标 | 一票否决（ROIC<5% 且仍扩产） |
| 6 | `ROIC < 5%` 且 `expanding = false` | 部分不达标 | 观察仓（ROIC<5% 不扩产） |

**负值护栏**：`NOPAT ≤ 0` 时仍计算 ROIC（可为 0 或负），天然落入 `ROIC < 5%` 档；verdict 追加「NOPAT 非正」。

### 3.3 科技股调整口径（tech_adjustment_hint 的权威内容）

依据框架第 3 步·支柱二「ROIC 口径总注」与「科技股口径协调」三条规则，提示固定文案为：

> 高研发投入科技股因研发费用化压低当期利润与 ROIC，本项「≥10%」阈值应改用「调整后核心经营 ROIC」（费用化研发支出加回后口径）判定；若调整后仍 <10% 归「部分不达标（观察仓）」；科研转化清单「资本回报效率」项仍独立按「ROIC > WACC」判定（本项 ≥10% 主阈值不豁免）。

### 3.4 NOPAT / 投入资本参考口径（供上层取数使用，本任务不实现自动抽取）

- **NOPAT（税后净营业利润）** `=` 息税前利润（EBIT）`× (1 − 有效税率)`；简化可用「营业利润 `× (1 − 有效税率)`」（剔除利息税盾，反映经营本身创造的价值）。
- **投入资本（Invested Capital）** `=` 有息负债 `+` 股东权益 `−` 货币资金（及交易性金融资产）；即「净债务 + 净资产（剔除闲置现金）」。

> 上述为行业通用口径参考。框架正文未逐一指定科目，本任务输入侧按「调用方 / `financial-data` 技能已完成科目归集」假设，不在此做报表解析。

## 4. 输入 / 输出签名

### 4.1 Python 函数签名

```python
def roic(nopat: float, invested_capital: float,
         wacc: float = None, expanding: bool = False) -> dict:
    """计算 ROIC（投入资本回报率）并给出四档判定。

    Args:
        nopat: 税后净营业利润（与 invested_capital 同币种同单位）。
        invested_capital: 投入资本（须 > 0）。
        wacc: 加权平均资本成本（百分点，如 8 表示 8%），可选，用于「合格」判定。
        expanding: 是否「仍拼命扩产」，可选，用于 ROIC<5% 时的一票否决判定。

    Returns:
        dict: 含 roic / tier / verdict / tech_adjustment_hint 及审计回显字段。
    """
```

### 4.2 CLI 参数

```text
python tools/common/financial_rigor.py roic \
  --nopat 12.5 \
  --invested-capital 100 \
  [--wacc 8] \
  [--expanding]
```

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| `--nopat` | 是 | float | 税后净营业利润 |
| `--invested-capital` | 是 | float | 投入资本（须 > 0） |
| `--wacc` | 否 | float | WACC，百分点（如 8 表示 8%） |
| `--expanding` | 否 | store_true | 仍在拼命扩产（ROIC<5% 时触发一票否决） |

### 4.3 JSON 输出 schema

核心字段（详细计划要求）+ 审计扩展字段：

```json
{
  "roic": 12.50,
  "tier": "合格",
  "verdict": "合格（ROIC>WACC 且 ≥10%）",
  "tech_adjustment_hint": "高研发投入科技股……",
  "wacc_applied": true,
  "inputs": {
    "nopat": 12.5,
    "invested_capital": 100.0,
    "wacc": 8.0,
    "expanding": false
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `roic` | float | ROIC 百分数，2 位小数 |
| `tier` | string | 四档枚举：`优秀` / `合格` / `部分不达标` / `不达标` |
| `verdict` | string | 一句判定结论（含观察仓 / 一票否决 / 未校验 WACC 等） |
| `tech_adjustment_hint` | string | 科技股调整口径提示（固定文案，见 3.3） |
| `wacc_applied` | bool | 是否实际应用了 WACC 校验 |
| `inputs` | object | 输入回显（审计复现，符合「禁止心算 + 可审计」总纲） |

## 6. 关键设计决策（已确认）

> 下列决策点已于 2026-09-14 经用户明确确认（开工门禁通过），固化为实现基线。

**D1 — `--json` 输出模式** ✅ 已确认：按推荐执行

- **已确认**：沿用现有风格，**不新增 `--json` flag**；将「`--json` 可解析」理解为「JSON 结构化输出可被 `json.loads` 解析」。

**D2 — 四档判定边界补齐** ✅ 已确认：按推荐执行
框架「合格 = ROIC>WACC 且 ≥10%」与「5%~10% 观察仓」之间存在 gap（`10%≤ROIC≤15%` 但 `ROIC≤WACC`）。
- **已确认**：归「部分不达标（观察仓）」并提示 `ROIC≤WACC`（已写入 3.2 决策表）；`ROIC>15%` 但 `≤WACC` 的罕见情形保留 tier=优秀、verdict 追加「建议人工复核」。

**D3 — 输入模式（纯计算版 vs 报表科目自动抽取）** ✅ 已确认：按推荐执行
详细计划输入签名注「（或由报表科目抽取，见实现阶段）」。
- **已确认**：本任务做**纯计算版**（NOPAT / 投入资本由调用方提供），不在此任务内实现报表科目自动解析；科目口径以 3.4 参考口径锁定，自动抽取留待 `financial-data` 技能层或后续任务。

**D4 — 引入 `--expanding` 标志** ✅ 已确认：按推荐执行
框架「<5% 且扩产 = 一票否决 / <5% 不扩产 = 观察仓」需「是否扩产」输入，但详细计划输入签名未列此参数。
- **已确认**：新增可选 `--expanding`（`store_true`，默认 false）。

**D5 — `tech_adjustment_hint` 实现形式** ✅ 已确认：按推荐执行
- **已确认**：本任务输出**固定提示文本**（3.3 文案），**不做**「调整后核心经营 ROIC」数值计算；数值加回归属 P1-6 `adjusted-peg`。

**D6 — 投入资本护栏** ✅ 已确认：按推荐执行
- **已确认**：`invested_capital ≤ 0` → 拒绝计算并输出降级提示（非除零异常），与 P1-2「分母≤0 降级提示」护栏口径一致；`NOPAT ≤ 0` → 仍计算（得 0 或负），落 `ROIC<5%` 档并标注。
