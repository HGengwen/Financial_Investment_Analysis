## 1. 子任务定位与权威依据

P1-8 是 Phase 1「计算核心扩展」的第 8 个子任务，也是 `momentum.py` 从「动量/技术面」向「ATR 动态止损」扩展的**纯计算核心**，为 GARP 框架「第三部分·五 止损纪律」中**底仓已建立且逻辑已验证后的高波动科技股动态跟踪止损**提供可复用计算，并供 Phase 1 P1-9 在 A股/港股/美股三个 `stock_quote.py --momentum` 中统一接线。

权威口径（框架第三部分·五 行 470，本任务唯一权威）：

```
TR = max(当日最高 − 当日最低, |当日最高 − 昨收|, |当日最低 − 昨收|)
止损价 = 买入价 − (2~3) × ATR(14)
ATR(14) = 最近 14 个交易日的平均真实波幅
```

框架行 472 的约束边界（编排放置，见 §3.2）：

> ATR 止损价对应的亏损幅度由 20% 底仓容忍度封顶——ATR 只能精化跟踪节奏，不能突破 20% 底仓容忍度。

与硬止损的关系（框架行 472、行 523~539）：低波动股直接用 8%~10% 硬止损；建仓初期（持仓 < 最终仓位 50% 且逻辑未验证）一律 8%~10% 硬止损、**不用 ATR**；仅在「底仓已建立 + 逻辑已验证」后，用 2~3 倍 ATR 把固定的 20% 底仓容忍度精化为「跟随波动下移的动态跟踪止损」。

> **本任务定位为纯算术工具**：只计算 `atr14 / stop_price / stop_pct` 三个数值，**不做**「8%~10% vs 20%」「建仓初期 vs 底仓已建立」的仓位状态分档判断，也不做 20% 封顶截断。这类判断与封顶属 P4-6 `garp-exit` 技能编排层职责（详见 §12 口径隔离声明）。

## 2. 目标与范围

### 2.1 目标

1. 在 `tools/common/momentum.py` 新增 `atr()` 函数，计算当前（最新一期）ATR 至 2 位小数。
2. 新增 `stop_price()` 函数，输出 `{atr14, stop_price, stop_pct}` 三字段（2 位小数）。
3. 不改动既有函数签名/行为（`sma`/`rsi`/`pct_change`/`percentile_rank`/`avg_volume`/`tech_check`/`compute_momentum`）。
4. 保持 `momentum.py`「数据源无关、纯计算、可离线单测」的模块定位。

### 2.2 范围（做什么 / 不做什么）

**做什么：**

- 将 `TR` 定义为 `max(high−low, |high−prev_close|, |low−prev_close|)`，其中 `prev_close` 为前一根收盘价。
- ATR 采用 Wilder 平滑（RMA），默认 `period=14`，支持 `method="sma"` 对照口径（见 D1/§3.1）。
- `stop_price(entry, multiplier)` = `entry − multiplier × atr14`；`stop_pct = (entry − stop_price) / entry × 100`。
- 数据不足 / 非法输入降级为 `None`（不抛异常），沿用既有 `rsi`/`pct_change`/`tech_check` 的**静默降级风格**，不引入 `warnings` 字段（见 D4/§6.3）。

**不做什么：**

- **不新增 CLI 子命令**（`momentum.py` 是纯函数模块，无 argparse/`main()`；与 `financial_rigor.py` 的子命令结构不同）。
- **不改** 既有 7 个函数的签名、语义与返回结构。
- **不做** 仓位状态分档（8%~10% / 20%）、不做 20% 封顶截断、不做「暂时性困难 vs 永久性衰退」判断——归 P4-6 编排层。
- **不做** 数据获取与三市场接线（那是 P1-9）。
- **不引入** `financial_rigor.py` 的 `Decimal` 体系（见 §3.3）。

## 3. 关键量化口径

### 3.1 TR 与 ATR 公式（口径项 D1）

对按时间升序排列的 `highs / lows / closes`（`closes[i-1]` 即「昨收」），第 `i` 根 K 线（`i ≥ 1`）的真实波幅：

```
TR[i] = max(high[i] − low[i], |high[i] − close[i−1]|, |low[i] − close[i−1]|)
```

**平滑方法（D1 待确认，推荐默认 Wilder）**：

| 方法                                   | 计算                                                                                                          | 适用说明                                                                                                          |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **Wilder 平滑（RMA，推荐默认）** | 初始`ATR_period = 前 period 个 TR 的简单平均`；之后 `ATR_t = (ATR_{t−1} × (period−1) + TR_t) / period` | 与详细计划开发步骤①「TR/ATR 初始化 Wilder 平滑」一致，与既有`rsi()` Wilder 平滑风格一致，且为 ATR 行业标准口径 |
| **SMA（对照）**                  | `ATR = 最近 period 个 TR 的简单平均`                                                                        | 框架正文行 470「最近 14 个交易日的平均真实波幅」字面口径                                                          |

> 二者在「恒定 TR」场景下结果相同；在 TR 波动场景下存在差异。本任务推荐**默认 Wilder + 可选 `method="sma"`**，同时满足「详细计划开发步骤」与「框架字面」两种口径，并可审计对照。

### 3.2 ATR 止损与 20% 封顶的关系（口径边界）

```
stop_price = entry_price − multiplier × atr14      （multiplier ∈ [2, 3]，框架「2~3 倍」）
stop_pct   = (entry_price − stop_price) / entry_price × 100
```

本工具只输出**原始** `stop_pct`，**不封顶 20%**。框架行 472「ATR 止损价对应亏损幅度由 20% 底仓容忍度封顶」属仓位状态判断，由 P4-6 在拿到本工具 `stop_pct` 后按持仓状态执行，避免工具层隐式截断导致口径不可追溯。

### 3.3 精度与舍入（区别于 `financial_rigor.py`）

- `momentum.py` 为**技术面指标纯计算模块**，沿用既有 `float + round(x, 2)` 风格，**不引入** `Decimal`（后者是 `financial_rigor.py` 财务精确计算专用，与 ATR 技术指标职责分离）。
- `atr()` 返回值在函数内部 `round(..., 2)`；`stop_price()` 对三字段 `atr14 / stop_price / stop_pct` 均 `round(..., 2)`，保证三市场复用（P1-9）输出一致，避免各市场自行 `round` 产生口径漂移。
- **止损价/幅度基于全精度 `_atr_raw()` 计算，仅在最终结果 `round`**，避免「先 round ATR 再乘倍数」的中间舍入误差（样例 4 由此得 `stop_price=77.35`/`stop_pct=22.65`，而非用 round 后 `11.33` 反算的 `77.34`/`22.66`）。
- 这与 `compute_momentum` 现有「在 `stock_quote` 层 round」的模式不同，但 ATR 属**新增字段**，独立口径，不改变既有字段的处理方式。

## 4. 输入 / 输出签名

### 4.1 函数签名（纯 Python，无 CLI）

```python
def atr(highs, lows, closes, period=14, method="wilder"):
    """计算当前（最新一期）ATR（平均真实波幅）。

    Args:
        highs: 最高价序列（按时间升序）。
        lows: 最低价序列（按时间升序）。
        closes: 收盘价序列（按时间升序；同时用于「昨收」计算）。
        period: ATR 周期（默认 14）。
        method: 平滑方法，'wilder'（默认）或 'sma'。

    Returns:
        最新一期 ATR（float，2 位小数）；数据不足返回 None。
    """

def stop_price(highs, lows, closes, entry_price, multiplier=2.0,
               period=14, method="wilder"):
    """计算 ATR 动态止损价与止损幅度。

    Args:
        highs/lows/closes: 高/低/收序列（按时间升序）。
        entry_price: 买入价。
        multiplier: ATR 倍数（框架取 2~3，默认 2.0）。
        period: ATR 周期（默认 14）。
        method: 平滑方法，'wilder'（默认）或 'sma'。

    Returns:
        dict: {"atr14": ..., "stop_price": ..., "stop_pct": ...}，2 位小数；
              数据不足或非法输入时对应字段为 None。
    """
```

### 4.2 返回结构

```json
{
  "atr14": 10.0,
  "stop_price": 80.0,
  "stop_pct": 20.0
}
```

- `atr14`：最新一期 ATR（float，2 位小数；不足取 None）。
- `stop_price`：`entry − multiplier × atr14`（float，2 位小数；`entry≤0` 或 `multiplier≤0` 或 `atr14=None` 时 None）。
- `stop_pct`：`(entry − stop_price)/entry × 100`（float，2 位小数；同 stop_price 无效条件）。

> 字段名与详细计划 P1-8 完全一致（`atr14` / `stop_price` / `stop_pct`）；无多余字段（不叠加 `verdict`/`warnings`/`inputs` 等，保持工具原子性与既有无参副作用风格，与 P1-4/P1-7 的 `financial_rigor` 子命令式结构刻意区分）。

## 6. 函数实现设计

### 6.1 `_true_range()` 内部辅助（可选内聚）

```python
def _true_range(high, low, prev_close):
    """单根 K 线的真实波幅（TR）。"""
    if None in (high, low, prev_close):
        return None
    return max(float(high) - float(low),
               abs(float(high) - float(prev_close)),
               abs(float(low) - float(prev_close)))
```

### 6.2 `_atr_raw()` 全精度与 `atr()` 核心（伪代码）

```python
def _atr_raw(highs, lows, closes, period=14, method="wilder"):
    """返回全精度 ATR（不 round），供 atr() 与 stop_price() 复用。"""
    n = len(highs)
    if period <= 0 or n < period + 1:
        return None

    # 逐根计算 TR，含 None 的三元组跳过
    trs = []
    for i in range(1, n):
        t = _true_range(highs[i], lows[i], closes[i - 1])
        if t is not None:
            trs.append(t)

    if len(trs) < period:
        return None

    if method == "sma":
        return sum(trs[-period:]) / period

    # 默认 Wilder 平滑：初始简单平均 + 递归平滑
    avg = sum(trs[:period]) / period
    for i in range(period, len(trs)):
        avg = (avg * (period - 1) + trs[i]) / period
    return avg


def atr(highs, lows, closes, period=14, method="wilder"):
    raw = _atr_raw(highs, lows, closes, period=period, method=method)
    return None if raw is None else round(raw, 2)
```

### 6.3 `stop_price()` 核心与护栏（伪代码）

```python
def stop_price(highs, lows, closes, entry_price, multiplier=2.0,
               period=14, method="wilder"):
    raw_atr = _atr_raw(highs, lows, closes, period=period, method=method)
    atr14 = None if raw_atr is None else round(raw_atr, 2)

    # 护栏：非法输入 → 对应字段 None（静默降级，不抛异常）
    if raw_atr is None or entry_price is None or float(entry_price) <= 0 \
            or multiplier is None or float(multiplier) <= 0:
        return {"atr14": atr14, "stop_price": None, "stop_pct": None}

    entry = float(entry_price)
    mult = float(multiplier)
    # 用全精度 ATR 计算止损价，最后 round，避免中间舍入误差
    sp = round(entry - mult * raw_atr, 2)
    pct = round((entry - sp) / entry * 100, 2)
    return {"atr14": atr14, "stop_price": sp, "stop_pct": pct}
```

### 6.4 降级与边界（口径项 D4）

| 场景                                                             | 结果                                                                           |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `period ≤ 0`                                                  | `atr()` → `None`；`stop_price()` 三字段中 `atr14=None`、其余 `None` |
| 有效 TR 数`< period`（K 线不足 `period+1` 根或含 None 过多） | 同上                                                                           |
| `method` 非 `'wilder'` 且非 `'sma'`                        | 按`None` 处理（`atr()` 返回 `None`），并在 docstring 声明仅支持两种取值  |
| `entry_price ≤ 0` 或 `entry_price=None`                     | `stop_price=None`、`stop_pct=None`，`atr14` 保留                         |
| `multiplier ≤ 0` 或 `multiplier=None`                       | `stop_price=None`、`stop_pct=None`，`atr14` 保留                         |
| `atr14=None`（数据不足）                                       | `stop_price`/`stop_pct` 均为 `None`                                      |

> 全部降级为 `None`，**不抛异常、不引入 `warnings` 字段**，与既有 `rsi`/`pct_change`/`tech_check` 的静默降级风格一致。是否「数据不足」由调用方（P1-9 接线层）根据 `atr14=None` 自行处理与标注，保持工具原子性。

## 8. 样例与期望输出（计划内验算，已用精确工具验算）

### 样例 1：恒定 TR（默认 Wilder + 默认倍数 2.0）

输入（15 根 K 线，`period=14`，`entry_price=100.0`，`multiplier=2.0`）：

```text
每根 K 线：(high=110, low=100, close=105)，共 15 根
TR[i] = max(110−100, |110−105|, |100−105|) = max(10, 5, 5) = 10（14 个 TR 全为 10）
```

期望输出：

```python
atr(highs, lows, closes) == 10.0
stop_price(highs, lows, closes, 100.0) == {"atr14": 10.0, "stop_price": 80.0, "stop_pct": 20.0}
```

> `stop_pct=20.0` 恰好命中框架「20% 底仓容忍度上限」，可直观验证「工具只输出原始 stop_pct，是否封顶由 P4-6 决定」的口径。

```text
同样例 1 K 线，entry_price=100.0，multiplier=3.0
```

期望输出：

```python
{"atr14": 10.0, "stop_price": 70.0, "stop_pct": 30.0}
```

### 样例 3：数据不足（13 根 K 线）

```text
13 根 K 线（每根 high=110, low=100, close=105），period=14
有效 TR 数 = 12 < 14
```

期望输出：

```python
atr(...) is None
stop_price(...) == {"atr14": None, "stop_price": None, "stop_pct": None}
```

### 样例 4：非恒定 TR（展示 Wilder 与 SMA 差异）

输入（16 根 K 线，`TR = [10]×13 + [30] + [10]`，共 15 个 TR）：

```text
K线 0：            (110, 100, 105)   # 供 TR[1] 的昨收
K线 1~13（13 根）：(110, 100, 105)   # TR = 10
K线 14：           (135, 125, 130)   # TR = max(10, 30, 20) = 30
K线 15：           (140, 130, 135)   # TR = max(10, 10, 0) = 10
```

验算（已运行精确工具确认）：

```text
Wilder：初值 = (13×10 + 30)/14 = 160/14 = 11.428571…；递归后
        avg = (160/14 × 13 + 10)/14 = 11.326530… ≈ 11.33
SMA：   最近 14 个 TR = (10×12 + 30 + 10)/14 = 160/14 ≈ 11.43
```

期望输出：

```python
atr(..., method="wilder") == 11.33
atr(..., method="sma")    == 11.43
stop_price(highs, lows, closes, 100.0, multiplier=2.0) ==
    {"atr14": 11.33, "stop_price": 77.35, "stop_pct": 22.65}
```

## 9. 验收标准

1. **ATR 正确至 2 位小数**：样例 1 → `10.0`；样例 4 → Wilder `11.33` / SMA `11.43`。
2. **止损价与框架一致**：`stop_price = entry − multiplier × atr14`；样例 1（`mult=2.0`）→ `80.0/20.0%`，样例 2（`mult=3.0`）→ `70.0/30.0%`。
3. **不封顶 20%**：工具仅输出原始 `stop_pct`，样例 1 的 `20.0` 不触发任何截断（封顶逻辑不在工具层）。

5. **返回结构原子性**：`stop_price()` 返回字典**仅含** `{atr14, stop_price, stop_pct}` 三键，`atr()` 返回 `float` 或 `None`。

## 12. 风险与限制

- **Wilder vs SMA 口径差异**：两者在「恒定 TR」下一致，在「波动 TR」下存在系统性差异（默认 Wilder 为行业标准与详细计划口径，SMA 仅作对照）。若下游 P1-9/P4-6 需与框架「平均」字面对齐，应显式传 `method="sma"`，避免混用。
- **TR 依赖昨收**：当日开多少、收盘多少由行情源 OHLC 决定；若行情源缺「昨收」字段，本工具用 `closes[i-1]` 代替昨收，与框架定义一致（框架即以「昨收」为跳空基准）。
- **ATR 与硬止损的赛道分工**：本工具无条件输出 ATR 止损，**不判断**持仓状态；8%~10% 硬止损、20% 容忍、分仓状态判断全部外置，若调用方误把 ATR 止损用于「建仓初期」，会与框架行 472「建仓初期不用 ATR」冲突，须由 P4-6 编排层拦截。
- **不封顶 20%**：工具输出原始 `stop_pct` 可能 >20%（如样例 2 的 30%），封顶由 P4-6 完成；任何在工具层二次封顶的行为都会破坏口径可追溯性，故明确不做。
- **停牌/缺失数据处理简化**：含 `None` 的三元组直接跳过（不参与 TR 序列），可能导致「有效 TR 数 < period」而返回 `None`；不补齐、不插值，由数据接线层保证 OHLC 完整性。
