## 3. 新增用例明细

### 3.1 `TestAtr`（7 项）

| 用例 | 断言关键点 |
| ---- | ---------- |
| `test_true_range_gap_and_range` | TR 三分支（振幅 / 高跳空 / 低跳空最大，任一 None 降级） |
| `test_atr_constant_tr_wilder` | 恒定 TR=10，Wilder = 10.0 |
| `test_atr_constant_tr_sma` | 恒定 TR=10，SMA = 10.0 |
| `test_atr_wilder_vs_sma_nonconstant` | 非恒定 TR 下 Wilder=11.33 / SMA=11.43 存在差异 |
| `test_atr_insufficient_data` | 13 根 K 线（有效 TR=12 < 14）返回 None |
| `test_atr_invalid_period` | `period=0` 返回 None |
| `test_atr_invalid_method` | `method="foo"` 静默降级为 None |

### 3.2 `TestStopPrice`（8 项）

| 用例 | 断言关键点 |
| ---- | ---------- |
| `test_stop_price_mult2` | 倍数 2.0 → `80.0 / 20.0` |
| `test_stop_price_mult3` | 倍数 3.0 → `70.0 / 30.0`（不封顶 20%） |
| `test_stop_price_full_precision` | 非恒定 TR 全精度反算 → `77.35 / 22.65`（非 `77.34/22.66`） |
| `test_stop_price_insufficient_data` | 13 根 K 线三字段均 None |
| `test_stop_price_invalid_entry` | `entry=0` → `atr14` 保留、`stop_price/stop_pct` 为 None |
| `test_stop_price_invalid_multiplier` | `multiplier=0` → `atr14` 保留、其余 None |
| `test_stop_price_none_entry` | `entry=None` → `atr14` 保留、其余 None |
| `test_stop_price_keys_only_three` | 返回字典仅含 `{atr14, stop_price, stop_pct}` 三键 |
