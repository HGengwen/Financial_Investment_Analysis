## 样例 1：恒定 TR（默认 Wilder + 默认倍数 2.0）

输入（15 根 K 线，`period=14`，`entry_price=100.0`，`multiplier=2.0`）：

```text
每根 K 线：(high=110, low=100, close=105)，共 15 根
TR[i] = max(110−100, |110−105|, |100−105|) = max(10, 5, 5) = 10（14 个 TR 全为 10）
Wilder 初值 = 前 14 个 TR 的简单平均 = 10
```

期望输出：

```python
atr(highs, lows, closes) == 10.0
stop_price(highs, lows, closes, 100.0) == {"atr14": 10.0, "stop_price": 80.0, "stop_pct": 20.0}
```

实际输出：

```text
sample1 atr=  10.0
sample1 stop= {'atr14': 10.0, 'stop_price': 80.0, 'stop_pct': 20.0}
```

> `stop_pct=20.0` 恰好命中框架「20% 底仓容忍度上限」，验证「工具只输出原始 stop_pct，是否封顶由 P4-6 决定」的口径。

## 样例 4：非恒定 TR（展示 Wilder 与 SMA 差异 + 全精度反算止损）

输入（16 根 K 线，`TR = [10]×13 + [30] + [10]`，共 15 个 TR）：

```text
K线 0：            (110, 100, 105)   # 供 TR[1] 的昨收
K线 1~13（13 根）：(110, 100, 105)   # TR = 10
K线 14：           (135, 125, 130)   # TR = max(10, 30, 20) = 30
K线 15：           (140, 130, 135)   # TR = max(10, 10, 0) = 10
```

理论验算：

```text
Wilder：初值 = (13×10 + 30)/14 = 160/14 = 11.428571…
        avg = (160/14 × 13 + 10)/14 = 11.326530… ≈ 11.33
SMA：   最近 14 个 TR = (10×12 + 30 + 10)/14 = 160/14 ≈ 11.43

止损价（基于全精度 ATR = 11.326530…）：
  stop_price = 100 − 2 × 11.326530… = 77.346938… ≈ 77.35
  stop_pct   = (100 − 77.35)/100 × 100 = 22.65
```

期望输出：

```python
atr(..., method="wilder") == 11.33
atr(..., method="sma")    == 11.43
stop_price(highs, lows, closes, 100.0, multiplier=2.0) ==
    {"atr14": 11.33, "stop_price": 77.35, "stop_pct": 22.65}
```

实际输出：

```text
sample4 wilder= 11.33
sample4 sma=    11.43
sample4 stop=   {'atr14': 11.33, 'stop_price': 77.35, 'stop_pct': 22.65}
```

> **关键点**：`stop_price` 基于全精度 `_atr_raw()`（`11.326530…`）反算，而非 round 后的 `11.33`，因此得到 `77.35 / 22.65`；若误用 round 后的 `11.33` 会得到 `77.34 / 22.66` 的中间舍入漂移。本样例为该精度口径的回归锚点。
