## 三、口径边界声明

### 本工具职责（原子计算 + 档位判定）

- 接收 `市值 + 核心经营利润 + 费用化研发支出 + future 增速`，计算 `调整后 PE` 与 `调整后 PEG`，并按框架第4步四档判定 `tier`。
- 输出 `adjusted_pe` / `adjusted_peg` / `tier` / `verdict` / `warnings` / `inputs`。

### 本工具不职责（交由下游技能层）

- **不定义/抽取**「核心经营利润」的会计科目（是否含股权激励、非经常损益剔除规则由调用方技能先行处理）。
- **不做研发费用资本化摊销建模**（仅当期费用化研发一次性回加口径）。
- **不做同业可比、ESG 折价、宏观利率 PEG 区间调整**（框架第五部分动态区间属技能编排层）。

### 单位约定

- 市值、核心经营利润、研发费用须为**同一货币单位**裸数值；调整后 PE/PEG 为无量纲倍数。
- `growth` 用**百分点数值**（`30=30%`，非小数 `0.30`）。
- 工具不跨单位校验，依赖调用方技能保证同单位。

### 档位语义

- 四档严格对齐框架行 384：`<1 低估` / `1~1.2 合理` / `1.2~1.5 合理偏贵` / `>1.5 高估`。
- `PEG>2` **不新增第五档**，仅在 `verdict` 补充「严重透支、加速减机动仓」文案。
- 边界判定基于 `Decimal` 28 位精算后 `quantize(0.01)` 的值，与控制台显示一致。

### 护栏语义

- `growth ≤ 0` → 降级 N/A（PEG 无意义）。
- `核心经营利润 + 研发回加 ≤ 0` → 降级 N/A（回加后仍亏损，PE/PEG 无意义）。
- 负市值、负研发 → 计入 `warnings` 数据异常提示，不拒绝计算。
