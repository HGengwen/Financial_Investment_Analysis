## 采样 1：标准·研发加回后低估

命令：

```text
python tools/common/financial_rigor.py adjusted-peg --market-cap 200 --core-operating-profit 10 --rnd-expense 5 --growth 30
```

期望输出（人机可读头 + JSON）：

```text
============================================================
调整后 PEG (研发费用加回核心经营利润口径)
============================================================
  市值 (market cap):            200.00
  核心经营利润:                 10.00
  费用化研发支出:               5.00
  未来盈利增速:                 30.00%

  调整后经营利润 = 核心经营利润 + 研发回加 = 10.00 + 5.00 = 15.00
  调整后 PE   = 市值 / 调整后经营利润 = 200.00 / 15.00 = 13.33
  调整后 PEG  = 调整后 PE / 增速 = 13.33 / 30.00 = 0.44

  ✅ 档位判定: 低估

  结构化输出: {"adjusted_pe": 13.33, "adjusted_peg": 0.44, "tier": "低估", "verdict": "低估（PEG<1，可加仓）", "warnings": [], "inputs": {"market_cap": 200.0, "core_operating_profit": 10.0, "rnd_expense": 5.0, "growth": 30.0}}
```

验算：调整后经营利润 `10+5=15`；调整后 PE `200/15=13.33`；调整后 PEG `13.33/30=0.44` → 低估 ✓。
