## 1. 目标与范围

### 1.1 目标

产出 GARP 独立档（**1~5 年**）的**单公司团队化财报精读 + 发布**技能 `/garp-earnings-team {公司名} {期间}`，并做到——

1. **五 Agent 并行研究**（共性 1，核心差异）：**Agent 1 林奇**（生意与估值：六类分类复核、按公司类型选估值锚、估值陷阱排查、林奇式卖出信号）+ **Agent 2 郑希**（ROE 与景气验证：ROE 趋势/拐点、二阶导、渗透率五档 + 国产化率四梯队、供需格局）+ **Agent 3 欧奈尔**（趋势信号与纪律更新：趋势通道、机构动向、止损位经 `garp-exit` 转接、抛售信号）+ **Agent 4 李进**（组合管理与治理：只引 `garp-management` 四段结论、只引 `garp-geo-policy` 0.3 矩阵、底仓/机动仓分层、宏观三表调档）+ **Agent 5 费雪**（**新增**：闲聊法第一手调研清单、十五要点质化筛选、销售组织、管理层持股≥3%、暂时性困难 vs 永久性衰退、「绝不卖」两前提检验）；**5 个 Agent 必须在同一条消息中并行启动，不可压缩、不可串行、不可由 Team Lead 代写**。
2. **Team Lead 五维评分与合成**（骨架四维 → **五维**）：风控底线（欧奈尔）/ 选股与估值（林奇）/ 赛道选择（郑希）/ 组合与治理（李进）/ **质化与长期持有（费雪）**；输出**共识 / 矛盾 / 被忽略的角落**三段式，并**必须回答三个收口问题**——「本期景气逻辑是否被验证」「估值落在 GARP 统一六档哪一档」「五级卖出是否触发任何一级」。
3. **阶段三：编辑润色 + 读者评审 + Team Lead 定稿**：编辑 Agent 将研究底稿改写为可发布文章（GARP 语域，禁中期/长期链术语），读者评审 Agent 按四维（看得懂 / 有收获 / 有问题 / 想转发）提修改意见，Team Lead 逐条采纳或说明不采纳理由后定稿。
4. **五大师 GARP 视角纳为独立评审维度**（验收要点 1）：费雪**不是补充说明**，而是**独立评分维 + 独立 Agent + 独立报告文件 + 独立矛盾条目（矛盾五）**四重落位。
5. **五大矛盾化解落地**（验收要点 2）：骨架四大矛盾（买点哲学 / 持有时间维度 / 止损 vs 越跌越买 / 分散 vs 集中）+ **矛盾五 费雪「绝不卖」vs 趋势景气纪律**；**五大矛盾的化解结论必须同时出现在「研究报告第八节」与「团队专节·五大矛盾化解」两处**（仅写在团队专节视为未落地）。
6. **共性口径七处替换全命中**：共性 1（四大师→五大师）为**点名差异**，共性 2/3/4/5/6/7 为**连带替换**（§7.2 刚性要求），替换前后对照见 §4.4。
7. **口径零复制（引用不重复定义）**：渗透率 / 国产化率 / 财务五门槛 / 科技豁免 / ROIC 四档 / 管理层与科研转化 / 估值矩阵 / ESG 折价 / 三维交叉矩阵 / 宏观三表 / 五级卖出 / 仓位规则 / ATR 止损**一律引用**（指向框架章节号或 `garp-*` 技能出口或 `financial_rigor.py` 命令），本技能**只定义流程与编排**。
8. **三档并存路由隔离**：技能内引用**只指向** `garp-*` 系列 + 复用 2 技能（`qoq-accelerator`、`trend-momentum-scan`）；**禁止**引用 1~3 年中期链（`mid-*`）与 10 年长期链（`earnings-team` / `dyp-*`）技能。
9. **风控硬编码 `GET-1`~`GET-12`**：把骨架「注意事项 14 条」的隐含纪律**显式编号化**，并新增 GARP 专有闸门（五维完整性 / 估值唯一出口 / 地缘只读 / 诚信单闸门 / 自评标注），见 §3.4。
10. **零新增 CLI、引擎零改动**：`tools/common/*` 与 `tools/specialized/*` **不改签名、不改行为、不新增子命令**；ATR 止损价经 `garp-exit` 转接，本技能不自建止损计算链。
11. **产出 8 个文件 + 命名规约**：1 份研究底稿 + 1 份定稿（可发布文章）+ 5 份 Agent 分报告 + 1 份读者评审报告；同日同期间多版本用 `-v2` / `-v3` **不覆盖**，见 §2.14。
12. **双门禁 + 七项交付件**：开工门禁 A~H（本文件 §9）+ 完成门禁留痕（详细计划 §0.7）；交付件严格对齐 §0.5「技能类七项」。

| 1 | **买点哲学** | 左侧（估值便宜先买） vs 右侧（趋势确认再买） | 按**仓位状态分水岭**分层：底仓可左侧（统一六档「低估/显著低估」+ 五维闸门通过），机动仓须右侧（趋势信号确认）；**禁止**单一口径一刀切 |
| 2 | **持有时间维度** | 财报是季度节点（快） vs GARP 是 1~5 年（慢） | 季度只做**验证与纪律更新**，不做频繁换仓；**时间止损满 4 季**为强制复评节点 |
| 3 | **止损 vs 越跌越买** | 欧奈尔硬止损 vs 低估值加仓 | **先判「杀估值」还是「杀逻辑」**：杀估值 → 允许底仓三分法加仓；杀逻辑 → 硬止损优先，**不得**加仓 |
| 4 | **分散 vs 集中** | 单只 ≤10/15/20% + 行业 ≤40% vs 集中持有 | 用**底仓集中 + 机动分散**化解：底仓聚焦优质标的，机动仓承担试错与轮动 |
| 5 | **费雪「绝不卖」 vs 趋势景气纪律**（新增） | 费雪：优质公司长期不卖 vs 五级卖出 / 二阶导转负减仓 | 「绝不卖」**两前提缺一不可**：**① 极度深度的研究认知**（十五要点质化筛选通过 + 管理层持股≥3% + 销售组织强）**② 极度集中的持仓**（底仓层级、长期不动用机动仓）；**两前提满足** → 可容忍短期景气波动（仅在诚信否决级退出）；**任一缺失** → 回到五级卖出纪律，**不得**以「长期主义」为由对抗纪律 |

> **落地刚性（验收要点 2）**：五大矛盾的化解结论**必须同时出现在 ①研究报告第八节「投资论文影响评估」②团队专节「五大矛盾化解」**；仅出现在团队专节 → **视为未落地**，验收不通过。

### 2.13 「假如空仓」测试与底仓/机动仓分离

- **「假如空仓」测试**（沿用骨架）：假设今日空仓，是否愿意按当前价格买入？回答必须**与最终三档结论一致**；不一致时 Team Lead 须在报告中**显式说明分歧原因**。
- **底仓 / 机动仓分离**：
  - 底仓：五维闸门**全部通过** + 统一六档 ∈ {显著低估, 低估, 合理} + 渗透率在**黄金窗或突破期** + 费雪质化「强/中性」 → 底仓区间（总底仓 60%~80%）。
  - 机动仓：估值「合理偏贵」或趋势信号未确认或质化「弱」→ 仅机动仓（总机动 20%~40%），**须设硬止损**。
  - 禁入：诚信前置命中 / ROIC 长期 <5% 且扩产 / 统一六档「严重透支」→ **不建仓**。
- **三档结论口径（写入 `GET-12`）**：**可建仓 / 观察仓 / 放弃**（三档），**不得**输出模糊结论（如「谨慎乐观」「值得关注」作为终结论）。
