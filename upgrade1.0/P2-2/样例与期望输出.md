## 2. 部分指标缺失样例（示意）

以下为**模拟 `macro_china_cpi` / `macro_china_ppi` 接口失败**时的期望输出形态，用于说明缺失标注契约（非本次实跑数据，实跑时六指标均正常）。

```json
{
  "data_ts": "2026-09-15",
  "rate_stage": {
    "stage": "降息/低利率",
    "confidence": "低",
    "basis": "10Y 国债收益率近 6 月趋势下行，判定为利率阶段 降息/低利率（框架行709/行703，非权威启发式）",
    "manual_review": true
  },
  "econ_stage": {
    "stage": "衰退",
    "confidence": "低",
    "basis": "信用收缩(信贷脉冲<0)+盈利/景气下行(PMI<50)，命中衰退两信号（框架行726）；利率见顶拐头待人工确认",
    "manual_review": true
  },
  "indicators": {
    "cn_10y_yield": {"value": 1.6888, "unit": "%", "as_of": "2026-09-14", "source": "akshare", "status": "ok", "trend": "down"},
    "pmi_manufacturing": {"value": 49.8, "unit": "点", "as_of": "2026-08", "source": "akshare", "status": "ok"},
    "cpi_yoy": {"value": null, "unit": "%", "as_of": null, "source": "akshare", "status": "insufficient"},
    "ppi_yoy": {"value": null, "unit": "%", "as_of": null, "source": "akshare", "status": "insufficient"},
    "social_financing_increment": {"value": 6245.0, "unit": "亿元", "as_of": "2026-04", "source": "akshare", "status": "ok"},
    "credit_impulse": {"value": -0.032128, "unit": "比率", "as_of": "2026-04", "source": "derived(akshare)", "status": "ok"}
  },
  "source": "akshare+search_hint",
  "degraded": true,
  "cache_status": "refresh",
  "search_hints": [
    "中国 CPI 同比 最新",
    "中国 PPI 同比 最新"
  ]
}
```

### 缺失契约要点

- 失败指标 `value=null` + `status="insufficient"`（不臆造数值）。
- 顶层 `degraded=true`，`source` 从 `akshare` 切换为 `akshare+search_hint`。
- `search_hints` 仅给出人工补数关键词，**不自动调用搜索工具、不自动从文本解析数值**（决策 D3）。
- 软判定仍基于可用指标执行，绝不因局部缺失而整体失败。
