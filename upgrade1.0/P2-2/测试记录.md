## 4. 关键断言示例（软判定）

```python
# 利率：下行趋势 + 信用扩张 → 降息/低利率
classify_rate_stage({"cn_10y_yield": {"status": "ok", "value": 1.68, "trend": "down"},
                     "credit_impulse": {"status": "ok", "value": 0.10}})["stage"] == "降息/低利率"

# 利率：上行趋势 + 信用收缩(信贷脉冲<0) → 高利率+信用收缩（滞胀）
classify_rate_stage({"cn_10y_yield": {"status": "ok", "value": 1.68, "trend": "up"},
                     "credit_impulse": {"status": "ok", "value": -0.10}})["stage"] == "高利率+信用收缩（滞胀）"

# 经济：信用收缩 + PMI<50 + 利率上行 → 滞胀（三信号交叉）
classify_econ_stage({"credit_impulse": {"status": "ok", "value": -0.10},
                     "pmi_manufacturing": {"status": "ok", "value": 49.0},
                     "cn_10y_yield": {"status": "ok", "trend": "up"}})["stage"] == "滞胀"
```

## 5. 缓存三态断言示例

```python
# refresh：不在新鲜期 → 拉取成功并写缓存
fetch_macro_indicators()["cache_status"] == "refresh"

# hit：新鲜期命中
fetch_macro_indicators()["cache_status"] == "hit"

# stale：拉取失败但有旧缓存 → 降级返回旧数据
fetch_macro_indicators()["cache_status"] == "stale"  # 且 degraded=True, source="cache_stale"
```
