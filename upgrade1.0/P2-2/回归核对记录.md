## 2. akshare 接口核对结论（与方案 3.1 差异记录）

方案 3.1 原文假设「各接口最新值均在 index 0（降序排列）」。实跑发现部分接口为**升序**，实现已改为「解析日期/月份 + 排序取最新」，不依赖返回顺序。

| `macro_china_pmi()` | 降序 | `制造业-指数`（列 `月份` 中文） | 2026-08 = 49.8 |
| `macro_china_cpi()` | 降序 | `全国-同比增长`（列 `月份` 中文） | 2026-08 = 0.8 |
| `macro_china_ppi()` | 降序 | `当月同比增长`（列 `月份` 中文） | 2026-08 = 3.8 |
| `macro_china_shrzgm()` | **升序（最新在末行）** | `社会融资规模增量`（列 `月份` 整数 YYYYMM） | 2026-04 = 6245 |
| `macro_china_new_financial_credit()` | — | `当月-同比增长`（辅助交叉） | 交叉线索 |

### 需注意的两处方案示例值差异

1. **PPI 最新值**：方案 4.3 样例写 `-2.5`，实跑为 **+3.8**。属示例占位字段差异，不影响实现。
2. **社融增量 as_of**：`macro_china_shrzgm` 当前接口末尾行为 `202604`（最新 = 2026-04），故 `social_financing_increment` 与 `credit_impulse` 的 `as_of=2026-04`。这是**源数据发布滞后**，非解析错误；每指标独立 `as_of` 已如实披露。

## 4. 精确算术核对（决策 D7）

信贷脉冲由程序精确计算并落盘公式，非 LLM 心算：

```text
credit_impulse = TTM(近12月社融增量) / 上年同期TTM - 1
实跑：ttm_cur=347103.0, ttm_prev=358625.0 → 347103 / 358625 - 1 = -0.032128
```

序列不足 24 月时，`credit_impulse.status="insufficient"` 并附 `note` 说明原因。
