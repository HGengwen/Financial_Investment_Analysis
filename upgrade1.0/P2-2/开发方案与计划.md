## 1. 任务定位与依据

- **来源**：总计划 P2-2（不拆）；详细计划 P2-2（第 284-293 行）。
- **目标**：在 `tools/specialized/macro_calibrator.py` 上**新增 `data` 子命令**，经 akshare 拉取五项宏观指标（10Y 国债收益率、PMI、CPI、PPI、社融/信贷脉冲），落地本地缓存，并据此判定当前利率阶段与经济阶段。
- **定位**：属 Phase 2「宏观校准引擎」第二棒，连接 P2-1（三表权威数据结构与 stage 枚举）与 P2-3（calibrate 参数校准）。P2-2 复用的 stage 枚举/三表结构来自 P2-1，拉取到的指标快照是 P2-3 校准的输入。
- **本质边界**：P2-1 = 查表（入 stage 出参数）；**P2-2 = 取数 + 软判定 stage**（入数据出 `rate_stage`/`econ_stage`/`indicators`）；P2-3 = 校准（入标参数出校准结论）。三者不合并推进。

## 2. 目标与范围

**本任务做的**：

1. 在 `macro_calibrator.py` 新增 `data` 子命令（`argparse` 子命令叠加，不破坏既有 `stage` 子命令）。
2. 实现五项宏观指标的 akshare 拉取（优先）与本地缓存落盘（`data/macro/`，TTL）。
3. 实现 `hit → refresh → stale` 三级缓存降级（对齐 `a_stock_cache.py` 模式）与 `--no-cache` 强制刷新。
4. 实现指标级缺失/降级标注与「数据不足」输出（带各指标数据截止日期）。
5. 输出结构化 JSON：`{data_ts, rate_stage, econ_stage, indicators:{...}, source, degraded}`。
6. 实现基于**框架定性规则**的利率/经济阶段**软判定**（无数值阈值臆造，附置信度与判定依据，见决策 D1）。

**边界（本任务不做的）**：

- 不实现「宏信号 → stage」的**数值阈值**硬判定（框架正文未显式给出阈值，见决策 D1 与第 3.3 节）。
- 不实现标的校准导出（输入 PEG/现金/单只占比 → 校准判断），**归属 P2-3 `calibrate`**。
- 不自动解析搜索五工具返回的非结构化文本为数值（见决策 D3，搜索回退边界）。
- 不改动 P2-1 既有三表结构、四函数、`stage` 子命令的对外签名（本任务为**增量新增**，对既有 `stage` 零回退破坏）。
- 不改动既有 43 技能及既有其他工具签名；不在本任务落 `docs/` 三份市场使用指南。

## 3. 关键量化口径

### 3.1 数据项与 akshare 接口清单（已实测确认，权威 = 详细计划 P2-2）

> 以下接口均已在本机 `Python_3_12_3` 环境实测存在且可返回非空 Dataframe（2026-09-15 验证）。各接口**最新值均在 `index 0`（降序排列）**，日期/月份列结构各异，开发时逐接口锁定并取「最新非 NaN 有效行」。

| 指标 | akshare 接口 | 取值列 | 数据截止字段 | 实测最新样例 |
| --- | --- | --- | --- | --- |
| 10Y 国债收益率 | `bond_zh_us_rate()` | `中国国债收益率10年` | `日期`（YYYY-MM-DD） | 2026-09-14 = 1.6888 |
| PMI（制造业） | `macro_china_pmi()` | `制造业-指数` | `月份`（如 `2026年08月份`） | 降序，最新在 index 0 |
| CPI（同比） | `macro_china_cpi()` | `全国-同比增长` | `月份`（如 `2026年08月份`） | 2026-08 同比 = 0.8 |
| PPI（同比） | `macro_china_ppi()` | `当月同比增长` | `月份`（如 `2026年08月份`） | 降序，最新在 index 0 |
| 社融规模增量 | `macro_china_shrzgm()` | `社会融资规模增量` | `月份`（如 `202604`） | 2026-04 = 6245 |
| （辅助）新增信贷 | `macro_china_new_financial_credit()` | `当月`、`当月-同比增长` | `月份`（YYYYMM） | 用于信贷脉冲交叉 |

- 主数据源 = **akshare**（结构化数据，精确数值）。
- 搜索五工具（anysearch/doubao/exa/tavily/web_search）**仅作外部补充线索**，不自动解析为数值（见决策 D3）。

### 3.2 缓存落点与 TTL 口径

- 缓存目录：`data/macro/`（尚不存在，本任务新建）。
- 缓存文件：单文件 `data/macro/macro_snapshot.json`（保存完整快照，含各指标原始值、派生值、来源、截止日期、采集时点）。
- TTL：默认 **7 天**，可通过 `.env` 新增 `MACRO_CACHE_TTL_DAYS` 覆盖（沿用 `a_stock_cache` 的 `_parse_int_env` 容错模式；缺省不影响运行）。
- 原子写：先写 `.tmp` 再 `os.replace`（沿用 `a_stock_cache._atomic_write_json` 模式），避免并发写坏。
- 缓存状态三态：`hit`（缓存新鲜命中）/ `refresh`（拉取刷新）/ `stale`（刷新失败降级旧缓存）。

### 3.3 阶段判定口径边界（核心风险，权威 = 框架第五部分·四）

框架正文（行 680-749）对「指标数值 → 美林四档」**只给定性规则，未给显式数值阈值**：

- 利率阶段：行 709「以国债收益率或政策利率的**趋势**判断所处利率阶段，而非靠单次升降息下结论」→ 只认**趋势**，无「收益率 X% = 加息」阈值。
- 经济阶段：行 726「衰退判断以『信用收缩 + 盈利下行 + 利率见顶拐头』三信号交叉印证」→ 三信号交叉定性，无「PMI < X = 衰退」阈值。
- 美林 + 信用周期：行 744「美林时钟定风格与行业 beta，信用周期定总仓位与现金」→ 矩阵是「阶段 → 参数」的对照表，**不是**「指标 → 阶段」的判定表。

因此 P2-2 若硬编码「PMI < 50 → 衰退」「CPI 同比 > X% → 滞胀」等数值阈值，将**臆造框架未显式给出的数值**，违反「不臆造框架未显式数值」的既有硬约束（与 P2-1 决策 D3 同理）。本方案推荐的落地方式是**软判定**（见决策 D1）。

### 3.4 信贷脉冲派生口径（程序精确计算，非 LLM 心算）

- 社融增量原始值：直接取 `macro_china_shrzgm()` 最新「社会融资规模增量」。
- 信贷脉冲（派生）：`近 12 个月社融增量滚动和（TTM）的同比 = 当前 TTM / 上年同期 TTM - 1`。需社融增量序列 ≥ 24 个月有效数据点，不足则标注「数据不足」（见决策 D7）。
- 计算由程序精确完成，公式在代码中显式落盘（可审计复现），与 `financial_rigor.py` 同属「精确算术」，不属于「LLM 心算」。

```json
{
  "data_ts": "2026-09-15",
  "rate_stage": {

    "confidence": "低",
    "basis": "10Y国债收益率近6月趋势下行（框架行709）",

  },
  "indicators": {
    "cn_10y_yield": {"value": 1.6888, "unit": "%", "as_of": "2026-09-14", "source": "akshare", "status": "ok"},
    "pmi_manufacturing": {"value": 49.5, "unit": "点", "as_of": "2026-08", "source": "akshare", "status": "ok"},
    "cpi_yoy": {"value": 0.8, "unit": "%", "as_of": "2026-08", "source": "akshare", "status": "ok"},
    "ppi_yoy": {"value": -2.5, "unit": "%", "as_of": "2026-08", "source": "akshare", "status": "ok"},
    "social_financing_increment": {"value": 6245.0, "unit": "亿元", "as_of": "2026-04", "source": "akshare", "status": "ok"},
    "credit_impulse": {"value": 0.12, "unit": "比率", "as_of": "2026-04", "source": "derived(akshare)", "status": "ok"}
  },
  "source": "akshare",
  "degraded": false,
  "cache_status": "refresh"

```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data_ts` | string | 快照采集时点（YYYY-MM-DD），用于「数据截止日期」披露 |
| `rate_stage` | object | 利率阶段软判定 `{stage, confidence, basis, manual_review}`；`stage` 枚举见决策 D1 |
| `econ_stage` | object | 经济阶段软判定（美林四档 + `数据不足`），结构同上 |
| `indicators` | object | 五项（+派生 1 项）指标：每项含 `value / unit / as_of / source / status` |
| `source` | string | 整体数据主源标识（`akshare` / `akshare+search_hint` / `cache_stale` 等） |
| `degraded` | bool | 任一指标 `status != "ok"` 时为 true |
| `cache_status` | string | `hit` / `refresh` / `stale`（缓存三态，供可审计追溯） |

> 指标 `status` 取值：`ok` = 正常；`stale` = 旧缓存降级；`insufficient` = 「数据不足」（缺失/序列过短/最新值为 NaN）。

## 6. 关键设计决策

> 下列决策点已于 **2026-09-15 逐项确认**，全部采纳推荐值并固化为开发口径；备选方案同步否决，不再作为开发分支保留。

| 决策点 | 确认结论（2026-09-15） | 否决备选 |
| --- | --- | --- |
| D1 阶段判定口径 | **软判定**（软结论 + confidence/basis/manual_review，不臆造阈值） | 纯采集不判定 / 硬阈值判定 |
| D2 数据源接口 | **akshare 七接口**（CPI 同比、PPI 同比增长） | CPI 改用月率 |
| D3 搜索回退 | **仅给 search_hints，不自动解析数值** | 自动提取数值 / 完全无搜索 |
| D4 缓存组织 | **单文件 macro_snapshot.json** | 按指标分文件 |
| D5 --no-cache | **强制刷新（force_refresh）** | 完全禁用缓存 |
| D6 缺失标注 | **每指标独立 as_of，顶层 data_ts=采集时点** | data_ts 取最新指标 |
| D7 信贷脉冲 | **TTM 同比派生，程序精确计算** | 仅原始值 / 存量同比 |

**D1 — 阶段判定口径（已确认）**
- 背景：框架正文（行 709/726/744）只给出「趋势 / 三信号交叉 / 美林+信用周期」的**定性规则**，**未给「指标数值 → stage」的显式阈值**。
- **已确认（软判定）**：`data` 子命令输出 `rate_stage`/`econ_stage` 的**软判定**字符串 + `confidence`（高/中/低）+ `basis`（命中框架原文哪条规则）+ `manual_review=true`。判定只依据框架明示的定性表述，引入的最小启发式（如「近 6 个月 10Y 收益率首尾方向」）在代码注释中显式声明为**非权威、可人工覆盖**，绝不将软判定当成硬结论。缺失无法满足最低输入时字段取 `数据不足`。
  - `rate_stage` 枚举：`加息/高利率` / `中性` / `降息/低利率` / `高利率+信用收缩（滞胀）`（框架表（一）利率三档 + 行 712 滞胀特殊档）。
  - `econ_stage` 枚举：`衰退` / `复苏` / `过热` / `滞胀`（复用 P2-1 `STAGE_ENUM`），缺失取 `数据不足`。
- 备选 A（纯采集不判定）：`rate_stage`/`econ_stage` 恒为 `数据不足`，仅输出 `indicators` 原始值 + 趋势方向指标，判定完全交下游/人工。满足 schema 但弱化「判定当前阶段」目标。
- 备选 B（硬阈值判定）：增加「PMI < 50 → 衰退」「CPI 高 + PMI 低 → 滞胀」等数值阈值自动判定。**需用户先提供权威阈值表**，否则属臆造，本任务不自行发明。

**D2 — 数据源优先级与接口清单（已确认）**
- **已确认**：akshare 优先，接口清单锁定 3.1 节七项（10Y 用 `bond_zh_us_rate`，CPI 用 `macro_china_cpi` 同比列，PPI 用 `macro_china_ppi` 同比增长列，社融用 `macro_china_shrzgm`，辅助 `macro_china_new_financial_credit`）。搜索五工具不进入自动数值链路（见 D3）。
- 备选：CPI 改用 `macro_china_cpi_monthly`（月率口径）——不采纳为主口径，因框架通胀判断更贴近同比，且已实测 `macro_china_cpi` 含同比列。

**D3 — 搜索五工具回退边界（已确认）**
- **已确认**：akshare 某指标失败/缺失时，该指标 `value=null` + `status="insufficient"`，并在输出附 `search_hints`（供人工用搜索五工具补数的关键词/站点建议）；**不自动调用搜索工具、不自动从搜索文本解析数值**。整体 `source` 反映主源，`degraded=true`。
- 理由：搜索五工具返回非结构化文本/链接，跨工具 schema 各异，自动解析数值脆弱、不可复现，且可能引入未经双源验证的误植。这符合「关键信息缺失时标注『信息不足』，不得用推测填充」的既有规范。
- 备选 A（自动提取）：akshare 失败后自动调用 `anysearch`/`doubao_search` 并用正则/LLM 提取数值填入指标体系——风险高，需额外凭证与解析稳定性保障，**不推荐首版**。
- 备选 B（完全无搜索）：仅文档注明搜索五工具为外部补充，不在命令内留下回退出口——弱于「缺失回退搜索五工具」的总体安排。

**D4 — 缓存落点与文件组织（已确认）**
- **已确认**：单文件 `data/macro/macro_snapshot.json`，TTL 默认 7 天，`.env` 新增 `MACRO_CACHE_TTL_DAYS` 可覆盖；原子写 `.tmp + os.replace`。理由：五项指标口径、发布节奏不同，聚合为单一快照便于 `data_ts` 统一披露与 P2-3 一次性消费。
- 备选：按指标分文件（`cn_10y_yield.json` 等）——粒度更细但增加 `data_ts`/降级聚合复杂度，性价比低。

**D5 — `--no-cache` 语义与缓存状态（已确认）**
- **已确认**：`--no-cache` = `force_refresh=True`（跳过 TTL 判断强制刷新）；未加时走 `hit → refresh → stale`。返回值附 `cache_status`。
- 备选：`--no-cache` 表示「完全禁用缓存读写」——偏离既有 `a_stock_cache` 语义，不采纳。

**D6 — 缺失/降级标注与 `data_ts` 语义（已确认）**
- **已确认**：`degraded = any(status != "ok")`；每指标带自己的 `as_of`（数据截止日期）；顶层 `data_ts` = 快照采集时点（当天 `date` 结果）。结构性缺失/序列不足/最新值为 NaN → `status="insufficient"` 并在 output 明确「数据不足」。
- 备选：`data_ts` = 最新单一指标截止日期——易造成「数据已更新到最新」的误导，不采纳。

**D7 — 信贷脉冲派生口径（已确认）**

## 9. 验收标准

逐条对照详细计划 P2-2 验收标准（并补硬约束）：

1. **数据落 `data/macro/`**：首次运行后生成 `data/macro/macro_snapshot.json`，含五项指标 + 派生信贷脉冲 + 各自 `as_of/source/status`；TTL 内再次运行命中缓存（`cache_status=hit`）。
2. **失败降级旧缓存**：新鲜缓存过期后，若 akshare 拉取失败且旧缓存仍存在，返回旧数据并标注 `cache_status=stale`、`degraded=true`，不抛异常（与 `a_stock_cache` 一致）。
3. **结构性缺失明确标注「数据不足」并带数据截止日期**：任一指标接口失败/序列不足/最新值为 NaN → 该指标 `status="insufficient"`、`value=null`，输出含 `data_ts` 与各指标 `as_of`，不臆造数值。
4. **阶段软判定可审计且不臆造阈值**：`rate_stage`/`econ_stage` 含 `confidence/basis/manual_review`，`basis` 指向框架原文行；不出现框架未给出的数值阈值（D1）。
5. **JSON 可解析且 schema 对齐 4.3**：`data` 输出能被 `json.loads` 解析，字段含 `data_ts/rate_stage/econ_stage/indicators/source/degraded`。
6. **精确算术非 LLM 心算**：信贷脉冲派生、TTM 计算均由程序完成且公式落盘可复现。
7. **回归无损**：新增 `data` 不破坏既有 `stage` 子命令、`--help`、P2-1 四函数与三表；既有 19 项测试全量通过 + 新增 `data` 测试通过。
