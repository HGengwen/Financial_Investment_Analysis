## 2. 目标与范围

**本任务做的**：

1. 新增 `incremental_roic()` 纯计算函数：`增量 ROIC = (NOPAT_to − NOPAT_from) ÷ (投入资本_to − 投入资本_from) × 100%`，输出 2 位小数。
2. 新增分母护栏：`Δ投入资本 ≤ 0` 时给出明确降级提示而非除零异常（见 3.2）。
3. 输出结构化 JSON（含 `delta_roic` 及 `period_from` / `period_to` 期间回显 + 审计字段）。
4. 新增 CLI 子命令 `incremental-roic` + 单元测试 + 回归核对。

**边界（本任务不做的）**：

- 不做「增量 ROIC vs 存量 ROIC」的**对比判定**（见决策 D1；该对比属 P4 科研转化清单技能，需联调 P1-1 `roic` 与 P1-2 `incremental-roic` 两个结果）。
- 不做「由报表科目自动抽取两期 NOPAT / 投入资本」。
- 不实现「调整后核心经营增量 ROIC」的数值加回计算（沿用 P1-1 的提示文本约定，见决策 D3）。
- 不改动 P1-1 已交付的 `roic()` / `_tier_roic()` / `roic` 子命令，以及既有 10 个子命令的签名与行为。

## 3. 关键量化口径（权威 = 框架第 3 步·支柱三 + 详细计划 P1-2）

### 3.1 公式与权威值

- **公式**：`增量 ROIC = ΔNOPAT ÷ Δ投入资本 × 100%`。
- **期间对齐**：`from` = 上期，`to` = 本期。即：
  - `ΔNOPAT = NOPAT_to − NOPAT_from`
  - `Δ投入资本 = 投入资本_to − 投入资本_from`
- **权威锚点**：框架第 3 步·支柱三「科研转化清单」的「资本回报效率」项 = `ROIC > WACC` 且「增量资本回报率 > 存量 ROIC」；本任务只产出「增量资本回报率」数值，供上层对比判定。

### 3.2 分母护栏决策表（P1-2 权威实现）

> 详细计划验收标准：**「分母≤0 时给出明确降级提示而非除零异常」**。因此 `Δ投入资本 ≤ 0` 一律降级（`delta_roic = None`），不强行计算负分母。

| 情形 | 处理 | `delta_roic` | `verdict` |
| --- | --- | --- | --- |
| `Δ投入资本 == 0` | 降级 N/A | `None` | 增量投入资本为 0，无法计算增量 ROIC（分母非法） |
| `Δ投入资本 < 0` | 降级 N/A | `None` | 投入资本收缩（Δ投入资本<0），增量口径不适用 |
| `Δ投入资本 > 0` 且 `ΔNOPAT` 任意 | 正常计算 | 2 位小数（可正可负） | 增量口径结果（负值 = 增量利润下滑，合法结果） |
| `Δ投入资本 > 0` 且 `ΔNOPAT ≤ 0` | 正常计算 | ≤ 0 | 结果附加「ΔNOPAT 非正」标注 |

### 3.3 科技股调整口径提示（复用 P1-1 常量）

增量 ROIC 同受「研发费用化压低当期利润」影响，本任务复用 P1-1 已锁定的 `_TECH_ADJUSTMENT_HINT` 常量（内容不变），在输出中附带。文案：

> 高研发投入科技股因研发费用化压低当期利润与 ROIC，本项「≥10%」阈值应改用「调整后核心经营 ROIC」（费用化研发支出加回后口径）判定；若调整后仍 <10% 归「部分不达标（观察仓）」；科研转化清单「资本回报效率」项仍独立按「ROIC > WACC」判定（本项 ≥10% 主阈值不豁免）。

### 3.4 NOPAT / 投入资本参考口径（继承 P1-1，本任务不实现自动抽取）

- **NOPAT（税后净营业利润）** = EBIT × (1 − 有效税率)；简化可用「营业利润 × (1 − 有效税率)」。
- **投入资本** = 有息负债 + 股东权益 − 货币资金（及交易性金融资产）。

> 与 P1-1 第 3.4 节完全一致，本任务输入侧按「调用方 / `financial-data` 技能已完成科目归集」假设，不做报表解析。

## 4. 输入 / 输出签名

### 4.1 Python 函数签名

```python
def incremental_roic(nopat_from, invested_capital_from,
                     nopat_to, invested_capital_to,
                     period_from="", period_to="") -> dict:
    """计算增量 ROIC（增量投入资本回报率）。

    公式：增量 ROIC = (NOPAT_to − NOPAT_from) ÷ (投入资本_to − 投入资本_from) × 100%。
    结果精确至 2 位小数；Δ投入资本 ≤ 0 时降级为 N/A（非除零异常）。

    Args:
        nopat_from: 上期税后净营业利润（与 invested_capital_from 同币种同单位）。
        invested_capital_from: 上期投入资本。
        nopat_to: 本期税后净营业利润。
        invested_capital_to: 本期投入资本。
        period_from: 上期标签（如 "2023"），可选，仅回显。
        period_to: 本期标签（如 "2024"），可选，仅回显。

    Returns:
        dict: 含 delta_roic / period_from / period_to / delta_nopat /
              delta_invested_capital 及审计回显字段。
    """
```

### 4.2 CLI 参数

```text
python tools/common/financial_rigor.py incremental-roic \
  --nopat-from 10 \
  --invested-capital-from 80 \
  --nopat-to 12.5 \
  --invested-capital-to 100 \
  [--period-from 2023] \
  [--period-to 2024]
```

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| `--nopat-from` | 是 | float | 上期税后净营业利润 |
| `--invested-capital-from` | 是 | float | 上期投入资本 |
| `--nopat-to` | 是 | float | 本期税后净营业利润 |
| `--invested-capital-to` | 是 | float | 本期投入资本 |
| `--period-from` | 否 | str | 上期标签（回显用，不影响计算） |
| `--period-to` | 否 | str | 本期标签（回显用，不影响计算） |

### 4.3 JSON 输出 schema

核心字段（详细计划要求）+ 审计扩展字段：

```json
{
  "delta_roic": 12.5,
  "period_from": "2023",
  "period_to": "2024",
  "delta_nopat": 2.5,
  "delta_invested_capital": 20.0,
  "tech_adjustment_hint": "高研发投入科技股……",
  "inputs": {
    "nopat_from": 10.0,
    "invested_capital_from": 80.0,
    "nopat_to": 12.5,
    "invested_capital_to": 100.0
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `delta_roic` | float / null | 增量 ROIC 百分数，2 位小数；降级时为 `null` |
| `period_from` | string | 上期标签（默认空串） |
| `period_to` | string | 本期标签（默认空串） |
| `delta_nopat` | float | ΔNOPAT（审计回显） |
| `delta_invested_capital` | float | Δ投入资本（审计回显） |
| `tech_adjustment_hint` | string | 科技股调整口径提示（复用 P1-1 固定文案） |
| `inputs` | object | 两期输入回显（审计复现） |

> 降级情形（`Δ投入资本 ≤ 0`）时，`delta_roic = null`，并附加 `verdict` 说明字段（见 3.2 表），`delta_nopat` / `delta_invested_capital` 仍正常回显。
