## 3. 期望输出（辅助样例：带标的输入）

输入 `--peg 1.3 --current-cash 15 --single-stake 12`（在衰退 stage 下）：

| 项 | 期望值 |
| --- | --- |
| `calibrated_peg_verdict.verdict` | **超出合理上限（不新建仓）**（1.3 > 1.0） |
| `cash_floor_min` / `cash_ok` / `cash_gap` | 30.0 / **false** / **-15.0**（现金不足） |
| `single_cap_value` / `single_cap_ok` / `single_cap_gap` | 12.0 / true / +1.0 |
| `industry_cap` | ≤30% |
| `validation` | 含 `stage_source=explicit`、`peg_compare` / `cash_compare` / `single_compare` 可审计复现 |

> 对照：同为 PEG 1.3，在**复苏** stage 下则为「合理买入」（区间 [1.2, 1.5]）——**同一估值在不同宏观阶段结论相反**，这是本技能存在的意义。期望报告显式呈现该对照差异。

## 5. 期望输出中的强制要素（缺一即不合格）

| # | 强制要素 | 检查点 |
| --- | --- | --- |
| 1 | **数据截止日期** | 报告头部与第二节均可追溯 `data_ts` |
| 2 | **非权威标注原样透传** | `confidence=低` / `manual_review=true` 出现且未被改写为确定语气 |
| 3 | **人工确认闸门** | 列出软判定 `basis` 与六指标现值，并给出确认结论；未确认时为「暂定」 |
| 4 | **单一收口结论** | 只给一套参数（不并列罗列利率表 / 经济表 / 矩阵三套），并写出收口说明 |
| 5 | **四项参数完整** | PEG 区间（含低估/高估阈值与偏贵中间带）+ 现金下限 + 单只三档 + 行业上限 |
| 6 | **边界三项声明** | 不替代个股基本面 / 不作为择时清仓依据 / 按月季更新 |
| 7 | **降级与缓存标注** | `source` / `cache_status` / `degraded` 三字段；`stale` 或 `degraded=true` 时提示 `--no-cache` |
| 8 | **缺省说明** | 未提供 `--peg` 时显式说明「未做标的级校准」 |
| 9 | **跨市场纪律** | 非 A 股市场不得套用中国指标软判定结果 |
| 10 | **免责声明** | 报告含「不构成投资建议」 |
| 11 | **口径隔离** | 全篇无中期链 / 长期链技能引用、无中期卖出体系与地缘术语 |

## 6. 期望的反例行为（工具校验）

| 反例输入 | 期望行为 |
| --- | --- |
| `stage --stage 繁荣`（非法阶段） | 报错 `❌ 非法 stage：'繁荣'，合法枚举：衰退 / 复苏 / 过热 / 滞胀`，**非零退出、不产出结论** |
| `calibrate --stake-tier foo` | argparse 拒绝 `invalid choice`，非零退出 |
| `calibrate --peg -1` | 报错 `❌ 非法 peg：-1.0，须 > 0`，非零退出 |
| `calibrate` 缺 `--stage` / `--from-data` | argparse 拒绝 `one of the arguments --stage --from-data is required`，非零退出 |
| 缓存 `stale` / `degraded=true` | 报告如实标注并提示 `--no-cache` 刷新；不得静默使用旧值 |
