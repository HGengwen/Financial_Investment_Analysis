## 0. 结论摘要（TL;DR）

本任务新增 GARP 独立档「命门净新增」技能 `garp-macro`（`.trae/skills/garp-macro/SKILL.md` + `README.md`），把《中长期价值成长（GARP）投资框架》**第五部分·四「宏观环境适配」三表**下沉为一条可执行的宏观校准流程，输出**调整后 PEG 合理区间 / 现金仓位下限 / 单只与行业上限**三项校准参数，供 `garp-valuation`、`garp-portfolio-review`、`garp-investment-checklist`、`garp-trend-tech-screen` 消费。

- **定位**：**参数时变调节器**（只调「估值容忍度」与「仓位尺度」），**不替代个股基本面、不作为择时清仓依据**（框架行 685 原文）。
- **无既有骨架**：属「命门净新增 2」之一（详细计划 §7.3 明示「无既有技能骨架」），格式风格参照既有技能，不复制其业务逻辑。
- **工具依赖已就绪**：Phase 2 已交付 `tools/specialized/macro_calibrator.py` 三子命令（`stage` / `data` / `calibrate`），本任务**不新增、不修改任何工具代码**，只做技能层编排。已实测：三子命令**脚本形式调用均可跑通**（该工具不 import `tools.*`，无 P4-1 发现的 `sys.path` 问题）。
- **核心难点 1（冲突消解）**：框架三表可能给出不一致信号（如 `data` 软判定当前为「利率降息档 1.2~1.5」但「经济衰退档 1.0」）。框架已给收口规则——**（一）+（二）算参数、（三）美林矩阵总收口**，且衰退期「虽启动降息但临时收紧至 1.0」；技能必须把该规则固化为强制步骤，禁止各表并列罗列而不收口。
- **核心难点 2（软判定的非权威性）**：`data` 的利率/经济阶段为**非权威启发式**（`manual_review=true`、`confidence=低`），框架未给显式数值阈值。技能必须设置**人工确认闸门**：未经确认的 stage 只能输出「暂定参数」并标注，不得作为最终校准依据。
- **核心难点 3（跨市场适配）**：工具 `data` 的六项指标均为**中国宏观指标**（10Y 国债 / PMI / CPI / PPI / 社融 / 信贷脉冲）；框架未就港股/美股给出宏观数据源指引。技能须按 `{市场}` 分层处理 stage 判定输入，并对工具未覆盖市场明确降级路径（§9.A）。
- **待确认点 6 项**：见 §9（A~F），**已于 2026-09-16 全部确认（均采用建议方案）**。

## 1. 目标与范围

### 1.1 目标

新增技能 `garp-macro`，使用户可用 `/garp-macro {市场}` 一次完成 GARP 宏观环境适配，输出可直接被下游技能消费的校准参数：

1. **阶段判定（stage）**：调用 `macro_calibrator.py data` 取宏观指标 + 软判定利率/经济阶段；按 `{市场}` 分层补充数据源；**强制人工确认**后定稿 stage（美林四档：衰退 / 复苏 / 过热 / 滞胀）。
2. **三表查表**：调用 `macro_calibrator.py stage` 输出利率表 / 经济表 / 美林矩阵三段参数（逐格硬编码、零心算）。
3. **参数收口**：按框架「（一）+（二）算参数、（三）总收口」规则，输出**单一**校准结论：调整后 PEG 合理买入上限 + 现金仓位下限 + 单只上限（三档）+ 单一行业上限。
4. **标的校准（可选）**：调用 `macro_calibrator.py calibrate`，输入标的 PEG / 当前现金占比 / 当前单只占比，输出达标判定与缺口（`cash_ok` / `single_cap_ok` / `cash_gap` / `single_cap_gap`）。
5. **边界声明**：显式输出「不替代个股基本面 + 不作为择时清仓依据 + 数据需按月/季更新」三项边界与数据截止日期。

## 2. 关键量化口径（唯一权威 = 框架第五部分·四）

> 以下全部取自《中长期价值成长（GARP）投资框架》第五部分·四（行 681~749），是唯一权威。任何实现与本文档 / 详细计划不一致时，**以框架正文为准**。技能正文按 §7.1 纪律「引用不重复定义」，只引用章节位置与工具命令。

### 2.1 核心原则与三表坐标轴索引（框架行 683~694）

**核心原则（原文）**：宏观只用于调节「估值容忍度」与「仓位尺度」，**不替代个股基本面判断，也不作为择时清仓的依据**——内在价值决定长期收益，宏观决定当前该出多少钱、冒多大风险。宏观数据需按月/季更新，避免刻舟求剑。

**三表坐标轴**：（一）以利率环境三档、（二）以经济周期两档、（三）以美林时钟四档；**以（一）+（二）算参数、（三）总收口**。坐标换算关系（照录）：

| 宏观阶段 | 对应利率环境（（一）表） | 对应经济周期档（（二）表） |
| --- | --- | --- |
| 衰退 | 降息启动（**临时按 1.0**） | 衰退档（收紧） |
| 复苏 | 低利率（放宽至 1.5） | 中性/复苏档（基准） |
| 过热 | 加息（收紧至 1.0） | 过热档（收紧） |
| 滞胀 | 高利率 + 信用收缩（0.8） | 滞胀档（最紧） |

### 2.2 （一）利率周期 → PEG 合理区间（框架行 696~713）

| 利率环境 | 调整后 PEG 合理买入区间 | 低估（可加仓） | 高估（减机动仓） |
| --- | --- | --- | --- |
| 加息/高利率周期 | 收紧至 **0.8~1.0** | <0.7 | >1.2（0.7~0.8 为空档，不主动加仓） |
| 中性（基准） | **1.0~1.2** | <1.0 | >1.5 |
| 降息/低利率周期 | 放宽至 **1.2~1.5** | <1.2 | 仍 >1.5 减仓，**>2 绝对透支清机动仓** |

- **「合理偏贵」中间带（统一口径）**：合理买入区间之上、高估阈值之下（中性例：1.2~1.5）→ **可持有底仓、不加仓，机动仓逢高择机减仓**。
- **确定性三锚（决定偏贵上限）**：① 连续 2~3 个季度增速稳定性（波动越小越确定）；② 订单可见度（在手订单/预收/合同负债对下季收入的覆盖度）；③ 竞争格局固化程度（CR5 与龙头份额趋势）。**三者任意一项偏弱，偏贵上限即收紧至 1.2**。
- **使用要点**：以利率**趋势**（国债收益率/政策利率）判档，不靠单次升降息；加息期即便 PEG 达标也应更保守；**「PEG>2 为严重透支」红线不因降息取消**，只可在降息周期放缓减仓节奏；**滞胀期**较高息档更紧，合理买入上限进一步下探至 **0.8**。

### 2.3 （二）经济周期 → 现金仓位与个股上限（框架行 715~730）

| 参数 | 中性/复苏期（基准） | 衰退期（收紧） |
| --- | --- | --- |
| 现金仓位 | 10%~20%（**估值分位 >80% 时提高至 20%~30%**） | 提高至 **30%~40% 或更高** |
| 单只个股上限 | 初始 ≤10% / 验证后 ≤15% / 绝对 ≤20% | 初始 ≤8% / 验证后 ≤12% / 绝对 ≤15% |
| 单一行业上限 | ≤40% | ≤30% |

- **衰退三信号（交叉印证，避免单一指标误导）**：信用收缩 + 盈利下行 + 利率见顶拐头。
- **提高现金的用意**：不是「预测暴跌」，而是**为恐慌期的逆向加仓预留弹药**。
- **滞胀期进一步收紧**：单只 初始 ≤6% / 验证后 ≤10% / 绝对 ≤12%，行业 ≤20%，现金 ≥40%。
- **过热期（加息、信用扩张见顶）**：参照衰退口径、现金略松 —— 单只 初始 ≤8% / 验证后 ≤12% / 绝对 ≤15%，行业 ≤25%，现金 ≥25%。

### 2.4 （三）宏观环境矩阵：美林时钟 + 信用周期 → 框架参数（框架行 732~749）

| 宏观阶段 | 利率/信用特征 | 风格倾向 | PEG 合理买入上限 | 现金仓位 | 单只上限（验证后） |
| --- | --- | --- | --- | --- | --- |
| **衰退** | 降息启动、信用收缩 | 防御、低波成长优先 | **1.0**（临时收紧） | 30%~40% | ≤12% |
| **复苏** | 低利率、信用扩张初期 | 成长/顺周期优先 | **1.5**（放宽） | 10%~20% | ≤15% |
| **过热** | 加息、信用扩张见顶 | 周期/价值优先 | **1.0**（收紧） | ≥25% | ≤12% |
| **滞胀** | 高利率、信用收缩 | 现金/防御为主 | **0.8**（最紧） | ≥40% | ≤10% |

- **分工**：**美林时钟定「风格与行业 beta」**，**信用周期定「总仓位与现金」**；二者**同向时信号最可靠，背离时以信用周期（更接近资金面真相）为准**。
- **矩阵 PEG 列口径** = 合理买入区间上限（同（一）表）。**衰退期虽启动降息，但盈利下行与信用收缩主导、风险偏好极低，估值中枢先杀后抬，故上限临时收紧至 1.0（而非降息档 1.5）**；待「宽信用」实质落地（信贷脉冲转正）后再切换至 1.5。**滞胀期为「高利率 + 信用收缩 + 盈利下行」三杀**，上限取加息档区间下限 0.8（即 PEG≥0.8 即不新建仓）。
- **矩阵单只上限为「验证后」一档口径**，完整三档（初始/验证后/绝对）按（二）表同向收紧（滞胀可细化为 6%/10%/12%）；**行业上限同向收紧**：中性/复苏 ≤40%、衰退 ≤30%、过热 ≤25%、滞胀 ≤20%。
- **现金仓位为默认目标下限**：复苏/中性下限 10%（常态 10%~20%，不主动低于 10%）；估值分位 >80% 时提高至 20%~30%；进入衰退/滞胀/过热后以矩阵值收口（衰退 30%~40%、滞胀 ≥40%、过热 ≥25%）。
- **适配性**：本框架的科技/国产化成长赛道**最适配复苏期**（低利率 + 信用扩张）；进入**滞胀/衰退**阶段应**优先降仓位而非硬扛高估值**。

## 3. 技能编排设计

### 3.1 命令与参数

```text
/garp-macro {市场}
```

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `{市场}` | 目标市场：`A股` / `港股` / `美股`（决定 stage 判定的宏观数据源，§9.A） | `A股`（§9.A 待确认） |
| `--stage` | 用户直接指定美林四档（`衰退`/`复苏`/`过热`/`滞胀`），填则**跳过软判定**直接查表（工具未覆盖市场或软判定不可用时的降级通道） | 无 |
| `--peg` | 标的当前调整后 PEG（>0），填则执行 `calibrate` 标的校准 | 无 |
| `--current-cash` | 当前现金占总资产 %（0~100），配合 `--peg` 使用 | 无 |
| `--single-stake` | 当前标的占总资产 %（0~100），配合 `--peg` 使用 | 无 |
| `--stake-tier` | 单只上限档位 `initial` / `verified` / `absolute` | `verified` |
| `--no-cache` | 强制刷新宏观数据缓存（透传 `data --no-cache`） | 关闭 |

> 参数设计原则：**最小必要**。参数与 `macro_calibrator.py` 既有签名一一对应，不新增工具侧能力。

### 3.2 执行流程（六步）

**第一步：确认参数与数据基准**
- 运行 `date` 确认当天日期，作为「数据截止日期」基准（全局规则 1）。
- 澄清 `{市场}`；未给时取默认 `A股` 并显式声明。
- 声明本次校准的**数据截止日期**与**数据来源**（`data` 的 `data_ts` / `cache_status` / `source`）。

**第二步：宏观指标取数与阶段软判定**

```bash
python tools/specialized/macro_calibrator.py data            # A股：中国六指标
python tools/specialized/macro_calibrator.py data --no-cache # 强制刷新
```

- 读回：`data_ts` / `rate_stage`（利率阶段软判定）/ `econ_stage`（美林经济阶段软判定）/ `indicators`（六指标）/ `source` / `degraded` / `cache_status` / `search_hints`。
- **按 `{市场}` 分层补充锚**（§3.3）：港股补美元流动性锚；美股以美债/美联储/美国信用周期为主。
- **强制标注非权威性**：`rate_stage` / `econ_stage` 的 `confidence=低` 与 `manual_review=true` **必须原样透传**；`degraded=true` / `cache_status=stale` 必须如实标注。

**第三步：人工确认闸门（stage 定稿，强制）**
- 向用户呈现**软判定结果 + 判定依据（`basis`）+ 六指标现值 + 数据截止日期**，请用户确认或修正 stage。
- **未确认前**：所有下游参数一律标注为「**暂定（待 stage 确认）**」，不得作为最终校准依据。
- 用户提供 `--stage` 时直接采用，并标注「stage 由用户提供，未做数据核验」。

**第四步：三表查表（工具调用，禁止心算）**

```bash
python tools/specialized/macro_calibrator.py stage --stage {已确认阶段} --markdown
```

- 读回三段参数：`rate_stage`（利率表）/ `econ_stage`（经济表）/ `merrill_stage`（美林矩阵）+ 聚合字段 `peg_interval` / `cash_floor` / `single_cap`。
- **收口规则（强制）**：以（三）美林矩阵为总收口；当（一）（二）与（三）不一致时**以（三）为准**，并在报告中写出收口说明（如「衰退期虽启动降息，但上限临时收紧至 1.0」）。
- 输出「单一」校准结论（不并列罗列多套参数）：
  - 调整后 PEG 合理买入上限（含低估/高估阈值与「合理偏贵」中间带）；
  - 现金仓位下限（含估值分位 >80% 的抬高情形提示）；
  - 单只上限三档（初始/验证后/绝对）+ 单一行业上限。

**第五步：标的校准（可选，提供 `--peg` 时执行）**

```bash
python tools/specialized/macro_calibrator.py calibrate \
  --stage {已确认阶段} --peg {PEG} --current-cash {现金%} --single-stake {单只%} [--stake-tier verified]
```

- 读回：`calibrated_peg_verdict`（含 `verdict` / `peg_interval` / `peg_ceiling` / `red_flag`）、`cash_floor_min` / `cash_ok` / `cash_gap`、`single_cap_value` / `single_cap_ok` / `single_cap_gap` / `single_caps` / `industry_cap`、`validation`（可审计复现）。
- `red_flag=true`（PEG>2）须显式提示「严重透支红线，**不因降息而取消**」。
- 未提供 `--peg` 时跳过本步，仅输出三表参数，并说明「未做标的级校准（缺 PEG/仓位输入）」。

**第六步：收口输出与下游转接**
- 按 §5 报告模板输出，写入 `reports/{市场}/macro-garp-{YYYYMMDD}.md`（目录不存在则创建）。
- 下游转接（只指向 `garp-*`，**不指向中期链 / 长期链技能**）：

| 校准输出 | 下游技能 | 用途 |
| --- | --- | --- |
| 调整后 PEG 合理区间 | `garp-valuation`（P4-5） | 估值矩阵中 PEG 主锚的宏观校准值 |
| 现金下限 / 单只上限 / 行业上限 | `garp-portfolio-review`（P4-8） | 仓位管理与再平衡 |
| 仓位尺度（建仓期） | `garp-investment-checklist`（P4-3） | 建仓门槛中的仓位约束 |
| 宏观 PEG 区间 | `garp-trend-tech-screen`（P4-11） | 景气打分输出的估值叠加项 |
