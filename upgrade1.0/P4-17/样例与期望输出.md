## 1. 通用输入约定（全部样例共用）

### 1.1 固定前置

| 项 | 约定 |
| --- | --- |
| 日期确认 | 运行 `date` 确认当天日期，作为「报告生成日期 / 数据截止日期」基准 |
| 价格锚 | **强制**调用对应市场 `stock_quote.py --realtime`，取最新实时价；休市日取最近交易日收盘价并标注 |
| 信息可得性 | 先给 A / B / C 级评级，并**告知每一个 Agent** |
| 并行刚性 | 5 路 Agent **同一条消息**启动，**各自独立搜索、不可共享结果** |
| 侦察窗口 | 默认 14 天；财报季可缩到 7 天；搜索统一 `--time-range week/day` |
| 产出路径 | `reports/{公司名}/{公司名}-garp-news-{YYYYMMDD}.md`（**单文件**） |
| 准出 | 发布前跑 `report_audit.py extract`；不通过**不得发布** |

### 1.2 报告头部四基准（**每份样例报告必须出现**）

```text
**数据基准**：实时价格获取时间 {YYYY-MM-DD HH:MM}（{交易日/休市日}）；各维度事件数据截止 {YYYY-MM-DD}
**估值基准**：估值线索来源 `garp-valuation`（结论日期 {YYYY-MM-DD}）；本技能不重算档位
**资料基准**：侦察窗口 {起始} ~ {今日}；信息可得性 {A/B/C} 级；主要信源层级 {官方原文/一手公告/二手转述}
**口径基准**：GARP 独立档 1~5 年；五级卖出引 `garp-exit`；地缘引 `garp-geo-policy`；
             H1~H7 对齐 `garp-thesis-drift`；「新闻脉搏 / 归因 / 性质判断」为骨架继承 + 本技能操作化、非框架原文
```

### 1.3 报告固定十一节

```text
一、一句话归因 + GARP 逻辑结论 + 五级卖出警示
二、完整事件时间线（合并 5 维度）
三、异动归因表
四、宏观金融与地缘政策归因表（Geo-macro Attribution）
五、GARP 逻辑影响评估（H1~H7 轻量七维）
六、五级卖出触发初筛
七、性质判断
八、各维度侦察摘要
九、行动建议
十、接下来 7-30 天 GARP 跟踪清单
十一、信息缺口声明
```

## 2. 样例 N-1：板块 beta 回调 + 增速二阶导减速 → 疑似四级

### 2.1 输入


### 2.2 前置（示意）

| 侦察窗口 | 2026-09-06 ~ 2026-09-19（14 天） |

### 2.3 5 路侦察摘要（示意）

| Agent | 3 条核心发现（示意） | 对 GARP 逻辑影响 |
| --- | --- | --- |
| 公司事件 | ① 无监管立案 / 无造假线索；② 无高管异常变动；③ 未披露大额订单变化 | ↑/→（**无诚信线索**） |
