## 1. 目标与范围

### 1.1 目标

产出 GARP 独立档（**1~5 年**）的**公司新闻脉搏**技能 `/garp-news-pulse {公司名}`，并做到——

1. **五级卖出触发初筛**（验收要点 1）：对股价异动完成「**一级 诚信否决 → 二级 硬止损 → 三级 逻辑止损 → 四级 产业景气判断 → 五级 估值判断**」逐级初筛，并单列**补充机制（时间止损 / 性价比替换，不占优先级）**；**命中一级 / 二级 → 立即转接 `garp-exit`（P4-6，已交付）**；疑似三级~五级 → 提示复核并给出转接动作；**阈值与逐级检查规则一律只引 `garp-exit`，本技能不重复定义、不重算阈值、不新建级别**。
2. **地缘政策归因接入 `garp-geo-policy`**（验收要点 2）：第 4 节（Geo-macro Attribution）与第 5 路 Agent 的**地缘部分只读** `garp-geo-policy`（P4-1，**已交付**）的 **0.3 三维交叉矩阵结论 / 赛道两分法归属 / 国产化率四档 / 敞口体检**；**废止**骨架「地缘政治六维自评分」；地缘属**买入前**闸门，**不入五级表**（与 P4-6 `GX-` 边界一致）。
3. **GARP 逻辑影响评估（H1~H7 轻量七维）**：与 `garp-thesis-drift`（P4-16，**已交付**）**同刻度**——H1 渗透率与国产化率 / H2 订单·合同负债 / H3 ROE 趋势 / H4 毛利率 / H5 增速加速度（二阶导）/ H6 地缘政策 / **H7 费雪质化**；**只做轻量初筛**（强化 / 中性 / 削弱），**权威漂移等级判定转 `garp-thesis-drift`**。
4. **共性口径七处替换全命中**：共性 3（地缘）与共性 4（卖出）为**点名差异**；共性 1/2/5/6/7 为**连带替换**（§7.2 刚性要求）；逐项对照见 §4.4。
5. **口径零复制（引用不重复定义）**：渗透率 / 国产化率 / 财务五门槛 / ROIC 四档 / 管理层与科研转化 / 估值六档 / ESG / 三维交叉矩阵 / 宏观三表 / 五级卖出 / 仓位规则 / ATR 止损 / 暂时性困难 vs 永久性衰退**一律引用**（指向框架章节号或 `garp-*` 技能出口或工具命令），本技能**只定义流程与编排**。
6. **三档并存路由隔离**：技能内引用**只指向** `garp-*` 系列 + 复用 2 技能（`qoq-accelerator`、`trend-momentum-scan`）；**禁止**引用 1~3 年中期链（`mid-*`）与 10 年长期链（`news-pulse` / `thesis-drift` / `dyp-*`）技能；**禁止**出现 `--horizon`、`P0~P5`、`-mid-news-`、`-news-`（长期档）等档位切换类口令与跨档文件名。
7. **风控硬编码 `GNP-1`~`GNP-12`**：把骨架「注意事项 11 条」**编号化承接**并新增 GARP 专有闸门（五级映射不可降级 / 地缘只读 / 七维同刻度 / 估值宏观只读 / 实时价格锚 / 五路独立 / 文件隔离）。
8. **零新增 CLI、引擎零改动**：`tools/common/*` 与 `tools/specialized/*` **不改签名、不改行为、不新增子命令**；ATR 止损价与衰退清单复核**经 `garp-exit` 转接**，本技能不自建止损链、不自行判定暂时/永久。
9. **快胜过全的刚性边界**：核心价值是 **10-15 分钟内给出归因判断**；深度检查交棒后置技能（`garp-exit` / `garp-thesis-drift` / `garp-valuation` / `garp-earnings-review` / `garp-earnings-team` / `garp-management` / `trend-momentum-scan`），本技能**不重复建设**。
10. **报告单文件 + 命名规约 + 四基准**：产出 1 份报告（**十一节固定结构**），头部必注明**四基准**（数据 / 估值 / 资料 / 口径），见 §2.12。
11. **双门禁 + 七项交付件**：开工门禁 A~H（本文件 §9）+ 完成门禁留痕（详细计划 §0.7）；交付件严格对齐 §0.5「技能类七项」。

- **转接刚性**：命中**一级 / 二级** → 报告醒目标注「**立即转 `/garp-exit`**」；疑似**三级~五级 / 补充机制** → 「**提示复核**」并给出转接动作。

- **二级 / 五级的深度判定不在本技能**：ATR 止损价、仓位状态（建仓初期 vs 底仓）判定、20% 封顶、多工具估值档位**一律转 `garp-exit` / `garp-valuation`**；本技能只做**幅度 / 线索级初筛**。

### 2.7 渗透率与国产化率（共性 2）

- **数据纪律**：渗透率 / 国产化率数值须注明来源与年份；双源误差 >5pct 标**低置信**（§4.5 **G8**）。

### 2.9 性质判断五类（骨架承接）

| 结论 | 含义 | GARP 化补充 |
| --- | --- | --- |
| **价值事件** | GARP 逻辑发生真实变化（ROE 拐头 / 二阶导转负 / 渗透率减速 / 订单下滑），需重审卖出纪律 | 联动 §2.4 五级初筛 |

| **混合** | 部分价值事件 + 部分情绪放大 | 须分层标注，禁止混为一谈 |

### 2.13 数据来源与置信度

- **诚实声明**：搜不到新闻时须写「真因不明 / 数据不足」，**不得**用推测填充（`GNP-4`）。

## 3. 执行流程与工具编排

### 3.1 执行流程（六步 + 前置 A/B）

#### 前置 A：日期与市场确认

1. 运行 `date` 确认当天日期，作为「报告生成日期 / 数据截止日期」基准。
2. 解析参数（下表）并识别市场（A 股 / 港股 / 美股），决定取数与搜索工具。
3. **三档并存提示**：同目录存在中期 / 长期档新闻脉搏或论文文件时**只提示不修改**。

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | :--: | --- | --- |
| `{公司名}` | 位置 | 是 | — | 中文 / 英文 / 股票代码（A / 港 / 美股） |
| `--window` | 整数（天） | 否 | 14 | 侦察新闻回溯天数；财报季可缩到 7 |
| `--move` | 字符串 | 否 | — | 股价异动描述，如「跌 12%/3 天」；有则用于聚焦归因 |
| `--focus` | 枚举 | 否 | 平均 | `公司` / `监管` / `行业` / `情绪` / `宏观地缘` |
| `--export` | 标志 | 否 | false | 导出 Markdown 报告至 `reports/` |
| `--export-path` | 字符串 | 否 | `reports/` | 输出根路径 |
| `--json` | 标志 | 否 | false | 输出结构化 JSON（供下游解析） |
| ~~`--horizon`~~ | — | — | — | **废止**（档位切换类口令，违反三档隔离；骨架前置引用 `thesis-tracker --horizon mid` 一并废止，改指 `garp-thesis-tracker`） |

> **澄清刚性**：用户仅给公司名时**先反问**「最近多少天的新闻？有具体的股价异动要解释吗？」，**不得默默假设**。

#### 前置 B：交易日实时价格锚

按 §2.11 调用对应市场行情工具取**最新实时交易价格**，判定交易日 / 休市日，记录「数据获取时间 / 截至时刻」。

#### 第一步：确认参数与场景

解析 §3.1 参数表 + 前置 A/B；确认关注侧重与异动描述。

#### 第二步：信息可得性分级

按 §2.10 给出 A / B / C 级评级，并**告知每个 Agent**，影响其侦察方式。

#### 第三步：启动 5 路并行侦察 Agent

按 §2.2 在**同一条消息**中启动 5 个后台 Agent（`subagent_type: search`）；每个 Agent **独立搜索、不可共享结果**（`GNP-11`）。

#### 第四步：实时跟踪进度

向用户实时展示进度（5 路 + 归因分析），每收到一份侦察报告即更新并展示该维度 3 条核心发现。

#### 第五步：Team Lead 综合归因 + 五级卖出触发初筛 + GARP 逻辑影响评估

按 §2.4 / §2.3 / §2.9 产出**异动归因与 GARP 逻辑评估报告**（不是研究报告，重点是「判断」）：

- **先分层再做减法**：宏观系统性事件（利率 / 汇率 / 地缘 / 衰退风险）与个股基本面事件**分开归因**，避免把大盘拖累误判为公司基本面恶化。
- **归因优先于罗列**：做减法，判断「哪个事件配得上这次股价异动」。
- **区分「催化剂」与「巧合」**：看影响量级是否匹配。
- **诚实面对「不明」**：找不到主因时明确写「真因不明」。

#### 第六步：保存报告 + 准出

按 §5.2 十一节模板写入 `reports/{公司名}/{公司名}-garp-news-{YYYYMMDD}.md`；跑 `report_audit.py` 抽检；命中一级 / 二级 → 醒目标注「立即转 `garp-exit`」；**不写回任何上游文件**。
