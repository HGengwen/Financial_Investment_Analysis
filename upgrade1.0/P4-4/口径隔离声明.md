## 四、与 1~3 年中期链的口径隔离对照

对照基准：既有技能 `mid-management-deep-dive`（中期链管理层纵深研究，13 步流程）

| 维度 | **1~3 年中期链**（`mid-management-deep-dive`） | **1~5 年 GARP 独立档**（本技能） | 隔离性质 |
| --- | --- | --- | --- |
| 持有周期 | 1~3 年 | **1~5 年** | 档位不同 |
| 大师体系 | 四大师（欧奈尔 / 林奇 / 郑希 / 李进） | **五大师（+ 费雪）** | **替换** |
| 管理层评分结构 | **5+5+5+5**（诚信 A 占 5 分，与计分混同，存在"高分对冲失信"路径） | **诚信前置（不计分闸门）+ 7+7+6** | **机制重构** |
| 诚信处置 | 一票否决项，但**占 5 分**（否决与计分并存） | **纯闸门**：命中即 `total=null` / `verdict=放弃`，**分数根本不参与计算** | **机制重构** |
| 冲抵路径 | 存在（诚信扣 5 分，其他项可补） | **被机制切断**（MG-1；实测 M3：全维度高分 + 兑现率 45% → `score_breakdown={}`） | **机制重构** |
| 科研转化 20 分制 | 有（A 8 / B 8 / C 4；子项 **4+2+2 / 2+2+1+1+2 / 1+2**） | **有**（研发投入 8 / 研发产出 8 / 资本回报 4；子项 **3+2+3 / 2+2+2+2 / 2+2**，**以工具固化常量为唯一权威**） | **子项拆分不一致 → 以工具为准** |
| 两套合成 | 不合成（分列两个 20 分制） | **「各自 ≥15」合成 + 退档分级**（10~14 观察 / <10 放弃），**禁止合计/加权** | **净新增** |
| 资本回报项口径 | 「ROIC > WACC 且 ≥10%」（含 ≥10% 主阈值） | **「ROIC > WACC」严格大于**，**不含 ≥10% 主阈值**（后者属支柱二，归 P4-3 的 S2） | **口径切分** |
| 估值联动 | 引用 `valuation-thermometer` 五档，按管理层质量调整折溢价 | **不参与估值**；只转达「研发费用化 → 调整后 PE」提示给 `garp-valuation` | **移除 + 转接** |
| 卖出纪律 | 与 P0~P5 六级联动（诚信 → P0） | **不内建**；转 `garp-exit`（P4-6）五级 | **移除 + 转接** |
| 费雪补充 | 无 | **有**（销售组织 / 管理层持股≥3%，C-1：定性不计分 + 阈值预警） | **净新增** |
| ESG | 无（仅地缘政治治理风险定性） | **ESG 三通道**（G 联动诚信 / E 定性 / 评级尾部），**只透传修正量、不算折价** | **净新增** |
| 宏观 | 无 | **叠加宏观三表**（引用 P4-2，**仅作环境提示、不参与评分**） | **净新增** |
| 结论形态 | 评级 / 分项打分（散文式） | **两套分值 + 三档**（重仓 / 观察 / 放弃；区分「诚信闸门」与「支柱三级否决」两种放弃） | **重构** |
| 风控编号 | **无硬编码编号** | **`MG-1`~`MG-10`**（全新前缀，无冲突） | **净新增** |
| 报告文件名 | `{公司名}-mid-management-{YYYYMMDD}.md` | `{公司名}-garp-management-{YYYYMMDD}.md` | **不冲突** |

**隔离结论**：本技能与 `mid-management-deep-dive` **不共享任何量化阈值**（管理层三维权重、科研子项拆分、合成规则、资本回报阈值全部不同）；二者结论即便对同一家公司不一致，也**不构成冲突**（档位与口径本就不同），属**功能互补**。

> **口径差异的处置依据**：科研转化子项拆分不一致时，**以工具固化常量为唯一权威**（`RESEARCH_SUBITEM_MAX`），**不按既有骨架实现**；这是本任务 §2 已确立的处置原则，已写入 `SKILL.md`「科研转化 20 分制」与「工具使用指南」节。
