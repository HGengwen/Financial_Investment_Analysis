### 1.3 ROIC 系列（实测命令与输出）

```bash
python tools/common/financial_rigor.py wacc \
  --equity-value 3377.35 --debt-value 7.5439 \
  --cost-equity 10 --cost-debt 4.5 --tax-rate 0.15
# → WACC = 9.99%（股权权重 99.78% / 债务权重 0.22% / 税后债务成本 3.82%）

python tools/common/financial_rigor.py roic \
  --nopat 2063609892 --invested-capital 14740070658.73 --wacc 9.99
# → ROIC = 14.00%，tier = "合格"（ROIC>WACC 且 ≥10%）

python tools/common/financial_rigor.py incremental-roic \
  --nopat-from 1613544738 --invested-capital-from 11908320163.24 \
  --nopat-to 2063609892 --invested-capital-to 14740070658.73 \
  --period-from 2024 --period-to 2025
# → 增量 ROIC = 15.89%（ΔNOPAT 450,065,154 / ΔIC 2,831,750,495.49）
```

> **实测注意**：`roic` 与 `incremental-roic` **不支持 `--as-of`**（会报 `unrecognized arguments`），数据截止日期须写在报告中。

**期望结论**：

| 项 | 期望 |

> **两种「放弃」的区分是本样例的验证重点**：诚信闸门（样例 B）→ 转 `garp-exit` 清仓；支柱三级否决（本样例）→ 转 P4-3 记不达标。**措辞与动作均不同**。
