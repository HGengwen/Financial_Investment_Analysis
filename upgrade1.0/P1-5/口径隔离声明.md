## 三、口径边界声明

### 本工具职责（原子计算）

- 接收 `市值 + 有息负债 − 现金` 与 `营收`，做 `EV` 与 `EV/Sales` 的精确计算。
- 输出 `ev` / `ev_sales` / `hint` / `warnings` / `inputs`。

### 本工具不职责（交由下游技能层）

- **不做** `EV/Sales` 绝对阈值判定（无天然阈值，框架要求「低于同业可比」）。
- **不做**同业可比数据获取与倍数对比。
- **不叠加** ESG 折价 / 宏观调整。

### 单位约定

- 四金额（市值、有息负债、现金、营收）必须为**同一货币单位**裸数值。
- `ev` 按原单位 2 位小数回显；`ev_sales` 无量纲（两金额同单位相除消除单位），2 位小数。
- 工具**不校验**跨单位混用（无法从裸数值推断单位），依赖调用方技能保证同单位。

### 护栏语义

- `revenue <= 0` → 降级 N/A（除零/负分母无意义）。
- 净现金公司 `EV < 0` → 正常计算负倍数，写 `warnings` 提示（未盈利科技股常见）。
- 负科目（`market-cap`/`debt`/`cash` 任一为负）→ 计入 `warnings` 数据异常提示，不拒绝计算。
