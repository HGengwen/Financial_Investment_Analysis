## 采样 1：标准净负债公司

命令：

```text
python tools/common/financial_rigor.py ev-sales --market-cap 800 --debt 150 --cash 50 --revenue 200
```

期望输出（人机可读头 + JSON）：

```text
============================================================
企业价值/营收倍数 (EV/Sales)
============================================================
  市值 (market cap):     800.00
  有息负债 (debt):       150.00
  现金 (cash):           50.00
  营收 (revenue):        200.00

  EV    = 市值 + 有息负债 − 现金 = 800.00 + 150.00 − 50.00 = 900.00
  EV/Sales = EV ÷ 营收 = 900.00 ÷ 200.00 = 4.50

  💡 EV/Sales 无绝对阈值，需与同业可比（高研发投入/未盈利科技股适用）

  结构化输出: {"ev": 900.0, "ev_sales": 4.5, "hint": "EV/Sales 无绝对阈值，需与同业可比（高研发投入/未盈利科技股适用）", "warnings": [], "inputs": {"market_cap": 800.0, "debt": 150.0, "cash": 50.0, "revenue": 200.0}}
```

验算：`EV = 800 + 150 − 50 = 900`；`EV/Sales = 900 / 200 = 4.50` ✓。

## 采样 2：净现金公司（EV 为负）

命令：

```text
python tools/common/financial_rigor.py ev-sales --market-cap 100 --debt 0 --cash 150 --revenue 50
```

期望输出：

```text
  EV    = 市值 + 有息负债 − 现金 = 100.00 + 0.00 − 150.00 = -50.00
  EV/Sales = EV ÷ 营收 = -50.00 ÷ 50.00 = -1.00

  合理性告警:
    ⚠️  净现金公司：EV 为负（现金 > 市值 + 有息负债），EV/Sales 为负值

  结构化输出: {"ev": -50.0, "ev_sales": -1.0, "hint": "EV/Sales 无绝对阈值，需与同业可比（高研发投入/未盈利科技股适用）", "warnings": ["净现金公司：EV 为负（现金 > 市值 + 有息负债），EV/Sales 为负值"], "inputs": {"market_cap": 100.0, "debt": 0.0, "cash": 150.0, "revenue": 50.0}}
```

验算：`EV = 100 + 0 − 150 = −50`；`EV/Sales = −50 / 50 = −1.00` ✓（负 EV 仅提示不拒绝）。

## 采样 5：负科目数据异常提示（仍计算）

命令：

```text
python tools/common/financial_rigor.py ev-sales --market-cap 800 --debt -50 --cash 50 --revenue 200
```

核心 JSON：

```json
{ "ev": 700.0, "ev_sales": 3.5, "warnings": ["有息负债为负（数据异常）"] }
```

验算：`EV = 800 + (−50) − 50 = 700`；`EV/Sales = 700 / 200 = 3.50`，负科目仅告警不拒绝。
