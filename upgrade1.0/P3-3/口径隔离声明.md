# P3-3 `scan` 口径隔离声明

- **任务编号**：P3-3
- **声明日期**：2026-09-15
- **依据**：《P3-3 开发方案与计划》§1.3、§2.3、§2.4 及框架第 0 步权威口径

---

## 1. 一句话边界

**`scan` 只检索、只呈现来源快照；不判定风险等级/基金力度，不输出 `screen` 的档位结论，
不固化框架示例名单为当前事实。**

---

## 2. 与 P3-1 / P3-2 的分工边界

| 能力 | 归属 | 说明 |
| --- | --- | --- |
| 三维交叉矩阵六行判定 / 赛道两分法 | P3-1 `screen` | 输入档位 → 输出结论 |
| 国产化率四档分层 / 半导体示例 | P3-2 `localize` / `examples` | 输入数值 → 输出档位 |
| 制裁清单/出口管制/风险行业/政策基金**检索** | **P3-3 `scan`（本任务）** | 输入行业/基金 → 输出来源快照，**不判档** |
| 维度叠用与最终研判 | Phase 4 `garp-geo-policy` 技能 | 编排 `scan` 取数 + `screen` 定档，本工具不越权 |

本工具**不接管** `screen` 的三维档位判定，也不把「高风险/低风险」「力度强/弱」
等结论写进 `scan` 输出；这些判定由 `screen`（P3-1）与后续人工研判承担。

---

## 3. 「不写硬结论」强制契约

`scan` 输出恒定携带两个字段（实现为常量 `SCAN_DISCLAIMER` / `SCAN_NOTE`）：

- `disclaimer`：
  「本输出仅为实时检索结果与来源快照，不构成对该行业风险等级或基金力度的判定结论；
  最终判断须以最新实时检索与独立研判为准。」
- `note`：
  「框架第0步·0.1 风险行业表与 0.2 基金名单仅为示例/格式示范，本输出不将其固化为当前事实。」

并强制携带数据时效三字段：`data_as_of`（数据截止日期）、`retrieved_at`（检索执行时间）、
`snapshot_example`（来源快照示例），落实「以最新实时检索为准」。

---

## 4. 框架示例名单位置的隔离

- 框架第 0 步 0.1 列出的五类「已明显暴露地缘政治风险的行业」与 0.2 末尾的基金名单，
  均标注为**示例/格式示范，非当前事实**。
- `scan` **不**在关键词模板之外把这些名单固化为输出结论；仅在检索关键词启发上使用，
  并在 `note` 中显式声明其非当前事实。
- 未来若需列表，需另行走实时检索并标注来源与截止日期，不得复用本工具的静态示例。

---

## 5. akshare「结构化优先」的诚实落地隔离

- `scan` 的 `structured_source` 返回探测结论（`probed=true` / `available=false`），
  `note` 明确说明「akshare 未发现制裁清单/出口管制/政策基金注资额度的直接结构化接口」。
- 本版本**不硬编 akshare 假接口**，探测无接口后直接走搜索工具并如实标注；
  未来若 akshare 新增对应接口，仅在 `_probe_structured_sources()` 内扩展，不破坏既有逻辑。

---

## 6. 搜索工具链隔离

固定为：`anysearch`（首选）→ `doubao_search`（回退）→ `exa_search`（第三级可选，
仅地缘维度且需 `EXA_API_KEY`）。**不接入** `tavily_search` / `web_search`
（async MCP 客户端），避免跨异步边界与 MCP SSE 会话复杂度，与方案 §1.3 一致。

---

## 7. 生效范围

本声明约束 `scan` 子命令及 `scan()` 函数的输出语义；不改动 `screen` / `localize` /
`examples` 三个既有子命令及其常量、dataclass、自检函数。若后续 `garp-geo-policy`
技能需要「取数 + 定档」组合，由该技能编排调用，本工具不越权。
