## 1. 任务定义与边界

### 1.1 问题实质

P5-4 已于 2026-09-19 交付《证券AI中长期价值成长（GARP）投资研究工作步骤》文档，并在 `qoq-accelerator` / `trend-momentum-scan` 各 2 文件的「**出口转接：GARP 独立档（1~5 年）适配**」节中落地 GARP 出口映射。

但另有 4 个 `garp-*` 技能在其依赖表中以「**出口转接归 P5-4**」指向上述工作——该表述是**任务前向引用**（指向 P5-4 这个**任务**）。P5-4 交付后**语义已兑现，文本却仍停留在「指向任务」**，形成**常驻引用缺失**：

- 对**读者**：`P5-4` 是内部子任务编号，外部读者无法据此定位真实内容；
- 对**可维护性**：后续若需查证「复用技能如何向 GARP 出口」，须先知晓 P5-4 是哪个任务。

本任务即把 9 处刷新为**指向已交付文档 §一·1.1 的常驻引用**。

### 13.1 订正明细（3 项）

### 13.2 订正依据

| 差异 | 事实 | 判据不适用 / 需订正的原因 |
| --- | --- | --- |
| **D2** | **22 个 `garp-*` 目录全部为 untracked** | ① `git diff --numstat` 对 untracked 文件**返回空**（实测输出为空串），无法反映行增删；② 即便纳入索引，**行内子串替换在 git 中本就会产生「1 增 1 删」**，故「增删列全为 0」**双重不成立**；③ `git status --porcelain` 对 untracked **目录**仅显示整目录（`?? .trae/skills/garp-exit/`），无法作为「零越界」的文件级判据 |
| **D3** | 8 文件 **EOF 均无换行终止符** | §3.3 基线数（703 / 238 / 695 / …）实为**换行符（`\n`）计数**；而 `splitlines()` 会为**末行无终止符**再计 1 行，故实测恒为「基线 + 1」（704 / 239 / 696 / …）。两者**均非行增删**——以 `\n` 计数为准，逐文件与基线**精确相等** |
