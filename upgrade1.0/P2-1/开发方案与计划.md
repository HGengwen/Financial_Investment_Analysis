## 3. 关键量化口径（权威 = 框架第五部分·四，行 681-747）

> 三表为同一宏观判断的三层解构，以**美林四档为主坐标**。利率环境是估值参数锚，经济周期是仓位参数锚，美林阶段是完整坐标。执行口径：以（一）+（二）算参数、（三）总收口。下列数值逐格照抄框架原文，**任何一格不做 LLM 心算或臆造**。

### 3.1 表 D：宏观阶段坐标换算关系（`STAGE_COORD_MAP`，权威 = 框架行 687-694）

| 宏观阶段 stage | 对应利率环境 rate_env | 对应经济周期档 econ_cycle |
| --- | --- | --- |
| 衰退 | 降息启动（临时按1.0） | 衰退档（收紧） |
| 复苏 | 低利率（放宽至1.5） | 中性/复苏档（基准） |
| 过热 | 加息（收紧至1.0） | 过热档（收紧） |
| 滞胀 | 高利率+信用收缩（0.8） | 滞胀档（最紧） |

### 3.2 表 A：利率环境 → PEG 参数（`RATE_TABLE`，按美林四档对齐）

> 权威值来源：框架表（一）行 700-704（利率三档）+ 坐标表行 687-694（四档映射）+ 行 713（滞胀更紧）。「衰退」「滞胀」两档的下限与低估/高估阈值框架**未显式给出**，一律填 `null` 并在 `note` 标注，不臆造（见决策 D3）。

| stage | rate_env（利率环境） | peg_interval（合理买入区间） | peg_undervalue（低估可加仓） | peg_overvalue（高估减机动仓） | note |
| --- | --- | --- | --- | --- | --- |
| 衰退 | 降息启动（临时按1.0） | `[1.0]`（临时收紧，仅上限） | `null` | `null` | 盈利下行+信用收缩主导，估值先杀后抬；宽信用实质落地（信贷脉冲转正）前临时按1.0 |
| 复苏 | 低利率（放宽至1.5） | `[1.2, 1.5]` | `<1.2` | `>1.5 减仓，>2 绝对透支清机动仓` | 降息/低利率周期，放宽档 |
| 过热 | 加息（收紧至1.0） | `[0.8, 1.0]` | `<0.7` | `>1.2` | 加息/高利率周期，收紧档；0.7~0.8 为低估上沿与合理下沿之间空档，不主动加仓 |
| 滞胀 | 高利率+信用收缩（0.8） | `[0.8]`（最紧，仅上限） | `null` | `null` | 较加息档 0.8~1.0 更紧，合理买入上限下探至 0.8；PEG≥0.8 即不新建仓 |

| --- | --- | --- | --- | --- | --- | --- |
| 衰退 | 衰退档（收紧） | 30%~40% 或更高 | ≤8% | ≤12% | ≤15% | ≤30% |
| 复苏 | 中性/复苏档（基准） | 10%~20%（估值分位>80%时提高至20%~30%） | ≤10% | ≤15% | ≤20% | ≤40% |
| 过热 | 过热档（收紧） | ≥25% | ≤8% | ≤12% | ≤15% | ≤25% |

| stage | rate_credit（利率/信用特征） | style（风格倾向） | peg_ceiling（PEG合理买入上限） | cash_floor（现金仓位） | single_cap_verified（单只上限·验证后） |

- 不实现「宏信号 → stage」的数值阈值判定（归属 P2-2）；P2-1 仅提供 stage 枚举校验与三表查表。

```python
    """返回给定美林阶段的利率/PEG 参数表。

    Args:
        stage: 美林阶段，须为 STAGE_ENUM 之一（衰退/复苏/过热/滞胀）。

    Returns:
        dict: RATE_TABLE 对应行 + 回显字段（stage 中文名 / stage_key）。
    """


def econ_stage(stage: str) -> dict:
    """返回给定美林阶段的经济周期/仓位参数表。"""


def merrill_stage(stage: str) -> dict:
    """返回给定美林阶段的美林时钟矩阵参数表。"""


def summary(stage: str) -> dict:
    """聚合三表输出完整参数表（美林阶段主坐标）。

    Returns:
        dict: 含 rate_stage / econ_stage / merrill_stage 三表行 +

    """
```

## 6. 关键设计决策

> 下列决策点已于 2026-09-14 经用户明确确认（「批准，进入开发」），D1~D6 全部按推荐值固化。

**D1 — stage 枚举规范**（推荐：中文四档为主，英文别名可选）
- **推荐**：规范枚举 = `衰退` / `复苏` / `过热` / `滞胀`（中文，与框架原文、美林标准一致，直接用于查表与输出）；非法值报错并列出合法枚举。
- 备选：额外接受英文别名（`recession`/`recovery`/`overheat`/`stagflation`）归一化为中文档位。
- 不实现「宏信号 → stage」数值阈值规则（归属 P2-2），本任务仅做枚举校验 + 查表。

**D2 — 三表主键统一为美林四档**（推荐）
- **推荐**：`RATE_TABLE` / `ECON_TABLE` / `MERRILL_TABLE` 三表均以**美林四档**（衰退/复苏/过热/滞胀）为主键。
- 理由：三者共享同一 stage 输入与「逐格一致」验收标准，统一主键使 `summary()` 零换算、零心算直接合并，消除跨表换算的臆造风险；框架表（一）利率三档与表（二）经济周期两列分别折叠为四行，每格值逐字来自框架原文。
- 备选：保持框架原表独立主键（利率三档 + 经济周期四档 + 美林四档），`rate_stage`/`econ_stage` 经 `STAGE_COORD_MAP` 二级换算。此方案需要为「衰退→降息启动（临时1.0）」等特殊档额外定义中间键，增加复杂性与不一致风险。

**D3 — 未显式格的处理**（推荐：填 `null` 并标注，不臆造）
- 框架仅对「复苏（降息档）」「过热（加息档）」给出完整低估/高估阈值；「衰退」「滞胀」两档的低估/高估阈值与区间下限**未显式给出**。
- **推荐**：相应字段填 `null`，`peg_interval` 对仅显式上限的档取单值列表 `[上限]`，并在 `note` / `peg_ceiling_note` 标注「框架未显式下限，不臆造」。
- 备选：沿用相邻收紧档（加息档 `<0.7` / `>1.2`）作近似——**不采纳**，因会引入非权威阈值。

**D4 — `single_cap` 汇总口径**（推荐：取「验证后」档）
- **推荐**：汇总字段 `single_cap` 取 `ECON_TABLE` 的 `single_verified`（验证后）档，与表（三）「单只上限（验证后）」列及详细计划「单只≤12%」示例口径一致；完整三档（初始/验证后/绝对）仍完整保存在 `econ_stage` 内。

**D5 — `cash_floor` 保留原文区间/下限文字**（推荐）
- **推荐**：`cash_floor` 用字符串保留框架原文（如 `30%~40% 或更高`、`≥40%`），不做数值区间解析，避免丢失「或更高」「估值分位>80%时…」等语义。

**D6 — `stage` 子命令不落盘**（推荐）
- **推荐**：`stage` 仅打印 JSON（可选 `--markdown`），不写文件；落盘与数据拉取归属 P2-2/P2-3。保持 P2-1 为纯查表/自测工具。

## 9. 验收标准

逐条对照详细计划 P2-1 验收标准：

1. **输入任一阶段输出完整参数表**：`summary(stage)` 对 `衰退/复苏/过热/滞胀` 四档均输出 `rate_stage` / `econ_stage` / `merrill_stage` 三表行 + `peg_interval` / `cash_floor` / `single_cap` 汇总字段，无缺失。
2. **与框架第五章三表逐格一致**：四张表每一格（数值/阈值/区间/文字/注释）与框架第五部分·四（行 687-747）逐格比对一致，逐格比对以「第 3 节第 3.1~3.4 节所列表格 + 框架原文对应行」为准；
3. **无 LLM 心算**：所有参数均来自硬编码字典取值，无任何模型手算或公式推导；`peg_interval`/`peg_ceiling` 等数值直接引用框架显式值。
4. **JSON 可解析**：`stage --stage 复苏` 输出可被 `json.loads` 解析，字段 schema 符合 4.3。
