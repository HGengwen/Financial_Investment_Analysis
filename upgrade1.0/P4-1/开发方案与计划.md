## 0. 结论摘要（TL;DR）

本任务新增 GARP 独立档「命门净新增」技能 `garp-geo-policy`（`.trae/skills/garp-geo-policy/SKILL.md` + `README.md`），把《中长期价值成长（GARP）投资框架》**第0步（0.1 / 0.2 / 0.3）**与**第1步国产化率四档**下沉为一条可执行的技能编排流程，作为**所有 GARP 个股/行业研究的第0步前置闸门**。

## 1. 目标与范围

### 1.1 目标

新增技能 `garp-geo-policy`，使用户可用 `/garp-geo-policy {行业/公司}` 一次性完成 GARP 第0步前置判定，并输出可直接被下游技能消费的结构化结论：

1. **0.1 地缘政治倒逼强度**：四类逆全球化信号渗透强度 → 三种风险形态传导链定位 → 四项倒逼强度评估 → 得出三维矩阵所需 `geo` 档位（高/中/低）。
2. **0.2 政策与国字号基金支持强度**：规划与政策 / 基金与资本 / 时效核验三层面 → 政策基金三层架构（第一层 / 第二层 / 第三层 / 专项子基金）→ 得出 `policy`（高/中/低）与 `fund`（四档）档位。
3. **0.3 三维交叉矩阵综合判定**：调用 `geo_policy_screen.py screen`，读回 `row_index` / `matrix_row` / `conclusion` / `track_type` / `archived`。
4. **赛道两分法落地**：判定「地缘倒逼型 / 政策资本驱动型」，并据此输出对**支柱四**的门槛要求（硬门槛 vs 敞口体检）。
5. **国产化率四档分层**（科技赛道）：调用 `geo_policy_screen.py localize`，输出 `tier` / `phase` / `action_hint`。
6. **前置闸门结论收口**：给出「放行 / 观察 / 回避（一票否决）」三档前置结论 + 证据链 + 数据截止日期 + 下游转接指引。

### 1.2 包含范围

- 新增目录 `.trae/skills/garp-geo-policy/`，同批交付 `SKILL.md` + `README.md`。
- 技能编排：调用 `geo_policy_screen.py` 四子命令（`screen` / `localize` / `examples` / `scan`）。
- 技能编排：调用搜索五工具（`anysearch` / `doubao_search` / `exa_search` / `tavily_search` / `web_search`）做档位判定的依据检索与交叉核验。
- 前置闸门三档结论与下游转接声明（转 `garp-investment-checklist` / `garp-industry-research` / `garp-trend-tech-screen` / `garp-bottleneck-hunter`）。
- 强制标注纪律：数据截止日期、数据来源依据、时变警示、降级标注、免责声明。
- 技能类七项交付件（§8）。

### 1.3 不包含范围（明确排除，防范围蔓延）

- **不含** 个股级支柱四（海外收入/供应链/地区冲突/自主研发抗压等八项细分）与支柱五（注资额度占市值比/场景绑定兑现/政策门槛优势）细研 —— 属 `garp-investment-checklist`（P4-3）与 `garp-investment-research`（P4-12）职责，本技能仅输出**赛道级**档位与转接指引。

## 2. 关键量化口径（唯一权威 = 框架第0步 + 第1步国产化率）

> 以下全部取自《中长期价值成长（GARP）投资框架》正文，是唯一权威。任何实现与本文档 / 详细计划不一致时，**以框架正文为准**。技能正文按 §7.1 纪律「引用不重复定义」，只引用章节位置，不复制完整规则表。

### 2.1 第0步·0.1 地缘政治倒逼强度（框架行 93~135）

| 层级 | 内容 | 技能中的用途 |
| --- | --- | --- |
| 底座 | 逆全球化四类信号：贸易壁垒常态化 / 产业链区域化·本土化 / 技术脱钩 / 资本与数据流动收紧 | 判断逆全球化对目标行业的**渗透强度** |
| 风险形态 | 技术·大国竞争对抗 / 国家·经济民族主义 / 地区冲突与战争 | 先定位标的**具体暴露在哪条传导链**，禁止笼统说「有地缘风险」 |
| 行业边界 | 风险行业清单（半导体与高端制造 / 生物制药与创新药 / 矿产资源 / 稀土 / 能源与航运）**持续扩散**，须先检索该行业是否已被卷入制裁或管制清单 | 检索纪律：**不得默认「清单外行业无风险」** |
| 倒逼强度四项 | ①制裁/管制覆盖度 ②断供现实性 ③政策强制力（如国产设备占比强制要求）④制裁可持续性（立法级 vs 行政级） | 汇总为 `geo` 档位（高/中/低）判定依据 |

> `geo` 档位取值映射（供 `screen` 传参）：高 = 已制裁/断供；中 = 制裁升级中；低 = 未覆盖、以市场驱动为主。

### 2.2 第0步·0.2 政策与国字号基金支持强度（框架行 137~161）

| 层面 | 核验内容 | 用途 |
| --- | --- | --- |
| 规划与政策 | 最新五年规划/专项政策是否以「超常规」「全链条」「决定性突破」等强干预强度词汇覆盖；是否含强制采购比例、部委协同攻关、应用场景强制开放；财税配套（税收减免/研发加计扣除/首台套保险补偿） | 判定 `policy` 档位（高/中/低） |
| 基金与资本 | 是否有国家/地方产业基金直接注资或专项子基金；注资额度与占比（总规模、单项目额、占项目总投资比）；是否有央企/产业资本形成「资本+场景」绑定 | 判定 `fund` 档位（四档：有直接注资 / 有专项子基金 / 有覆盖 / 无覆盖） |
| 时效核验 | 每次评估更新「基金名称、规模、投向」实时数据，剔除已到期/转向/缩水基金，补充新设立基金 | 强制以实时检索为准，不得沿用历史名单 |

**政策基金三层架构（框架 0.2 示例，须照录为「格式示范」）**：

| 层级 | 基金类型（示例） | 核心投向（示例） |
| --- | --- | --- |
| 第一层 | 国家人工智能产业投资基金（示例） | AI 全产业链 |
| 第二层 | 大基金三期（示例） | 设备材料国产替代 + 先进封装与 AI 存储 |
| 第三层 | 国家制造业转型升级基金（示例） | 工业母机、机器人核心零部件、新材料 |
| 专项子基金 | 工业母机产业投资基金（示例） | 工业母机全产业链 |

> **强制免责声明（框架原文）**：以上为某一历史时点的**格式示范，非当前事实**；技能输出该表时必须原样保留「示例」标注与免责声明，且强制标注数据截止日期，最终以实时检索为准。

### 2.3 第0步·0.3 三维交叉矩阵 + 赛道两分法（框架行 163~185）

**三维交叉矩阵（六行，权威照录）**：

| 行 | 地缘倒逼强度 | 政策覆盖度 | 国字号基金介入 | 投资含义 |
| --- | --- | --- | --- | --- |
| 1 | 高（已制裁/断供） | 高（超常规+全链条） | 有直接注资 | 最优场景：替代确定性和节奏均被外部力量锁定 |
| 2 | 高 | 中 | 有专项子基金 | 次优场景：替代方向明确，但节奏受技术突破制约 |
| 3 | 中（制裁升级中） | 高 | 有覆盖 | 潜伏场景：制裁尚未落地但概率高，提前布局等待催化 |
| 4 | 高（已制裁/断供） | 低/无 | 无覆盖 | 高风险/回避：须先验证承接能力，承接不足则回避 |
| 5 | 低 | 中/高 | 有覆盖/注资 | 政策驱动型增量创造：不以地缘倒逼为门槛，达标以政策覆盖+基金介入（支柱五）为准 |
| 6 | 低 | 低 | 无覆盖 | 回避：替代节奏完全依赖市场驱动，不确定性过高 |

- **未列组合处理（框架原文）**：凡未显式列出的中间组合，一律按**更审慎的相邻档位**归档，**不得因未列而默认放行**。工具侧已 36 组合全覆盖（11 条显式命中 + 25 条 `FALLBACK_MAP`），技能只透传 `archived` / `archive_from`，**不得自行解释性放行**。
- **关键风险提示（框架原文，须写入结论旁注）**：国字号基金注资是「政策优先序列」信号，**非买入估值依据**；最终决策仍需回到估值与业绩兑现框架。
- **赛道两分法（判别方法）**：先看 0.3 矩阵行归属——「高倒逼强度」起步 → **地缘倒逼型**（支柱四对倒逼强度作**硬门槛**：非「低/无」方可建仓）；「低倒逼强度 + 政策/基金高」起步 → **政策资本驱动型**（支柱四仅作**敞口体检**，达标与否交支柱五）。两类非互斥，**介于其间按更审慎的那类**执行。
- **与支柱四/五的映射（框架行 355）**：支柱四 ↔ 地缘倒逼强度维；支柱五 ↔ 政策覆盖度 + 国字号基金介入两维。
- **回避档的共同特征（框架行 355/362）**：**政策覆盖度低/无 且 国字号基金无覆盖**（政策与资本两维同时失守）→ 无论地缘倒逼高低**均一票回避**，即矩阵行 **4 与行 6**，属第五部分「一票否决清单」。

### 2.4 第1步 国产化率四档（框架行 193、200~211）

| 档 | 区间（%） | phase | action_hint |
| --- | --- | --- | --- |
| 1 过早 | <5 | 不确定性高 | 观察不建仓 |
| 2 突破期 | [5,20) | 从0到1突破期 | 高弹性，跟踪/小仓 |
| 3 加速投资期 | [20,50) | 加速投资期 | 订单放量 |
| 4 替代空间收窄 | [50,100] | 替代空间收窄 | 转向龙头份额提升与整机放量 |

- **战略卡脖子例外（框架原文）**：<5% 中若属战略必争卡脖子环节（如光刻），可作**高风险高弹性的观察/小仓、非回避**。
- **分工（框架行 198）**：渗透率管「产业所处阶段」（何时买），国产化率管「国产企业可替代空间」（标的成长弹性）——本技能**只取国产化率**，渗透率交 `garp-industry-research`。
- **判定不写死行业**：判定只依赖数值，任意行业经 `localize` 按数值落档；半导体设备四梯队（第一/二/三梯队 + 光刻）为**内置示例**（`examples` 子命令），仅作格式回归锚点。

## 3. 技能编排设计

### 3.1 命令与参数

```text
/garp-geo-policy {行业/公司}
```

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `{行业/公司}` | 目标对象，行业优先；填公司时先定位其**所属赛道/环节**再判定（§9.A） | **必填** |
| `--depth` | `standard`（含 `scan` 实时检索核验 + 搜索五工具回退）/ `fast`（跳过实时检索，仅用用户提供档位或既有缓存） | `standard`（§9.C 待确认） |
| `--geo` / `--policy` / `--fund` | 用户已判定的三维档位，填则**直接进入第四步**矩阵判定（用于 `scan` 全失败降级场景） | 无 |
| `--localization-rate` | 国产化率百分数（0~100，科技赛道可选），填则直接进第五步 `localize` | 无（缺省则检索获取，获取不到则标注「未判定」，§9.D） |
| `--strategic-choke-point` | 战略卡脖子环节标记，**仅用户显式指定**时透传给 `localize` | 关闭（§9.E） |

> 参数设计原则：**最小必要**。除上述外不新增开关，避免与下游技能职责重叠。

### 3.2 执行流程（六步）

**第一步：确认参数与数据基准**
- 运行 `date` 确认当天日期，作为「数据截止日期」基准（全局规则 1）。
- 澄清 `{行业/公司}` 与 `--depth`；填公司时先定位赛道/环节，并在报告显式写出「公司 → 赛道/环节」的定位依据。
- 声明本次判定的**数据截止日期**与**数据来源依据**（后续写入 `--as-of` / `--basis`）。

**第二步：0.1 地缘倒逼强度判定**
- 先做**检索纪律**：检索「该行业当前是否已被卷入地缘冲突/管制清单」（`scan --industry`，见第六步工具编排），而非默认清单外无风险。
- 按四类逆全球化信号判渗透强度 → 定位三种风险形态中的传导链 → 依四项倒逼强度评估汇总得 `geo` 档位。
- 输出：`geo` 档位 + 四项评估逐项依据（引用框架行 93~135）。

**第三步：0.2 政策与国字号基金支持强度判定**
- 按三层面（规划与政策 / 基金与资本 / 时效核验）核验 → 得 `policy` 档位与 `fund` 档位（四档）。
- 政策基金三层架构（框架 0.2 示例）按 §2.2 输出，**强制保留「示例」标注 + 免责声明 + 数据截止日期**（§9.F 待确认是否每次输出）。

**第四步：0.3 三维矩阵综合判定（工具调用，禁止心算）**

```bash
python tools/specialized/geo_policy_screen.py screen \
  --geo {高|中|低} --policy {高|中|低} --fund {有直接注资|有专项子基金|有覆盖|无覆盖} \
  --as-of {YYYY-MM-DD} --basis "{档位判定依据}"
```

- 读回 `row_index` / `matrix_row` / `conclusion` / `track_type` / `archived` / `archive_from`。
- `archived=true` 时**必须显式标注归档**，并展示 `archive_from` 原组合，**不做解释性放行**。
- 原样透传 `risk_note`（基金信号非估值依据）与 `time_sensitivity_note`（时变警示）。
- **落地赛道两分法**：`track_type=地缘倒逼型` → 转出对支柱四的**硬门槛**要求；`track_type=政策资本驱动型` → 转出支柱四**敞口体检**要求；`track_type=回避` → 转出一票否决提示。
- **前置闸门三档结论映射**（§9.B 待确认）：

| 矩阵行 | 前置闸门结论 | 处置 |
| --- | --- | --- |
| 1 最优场景 / 2 次优场景 | **放行** | 进入下游细研（转 `garp-investment-checklist` / `garp-investment-research`） |
| 3 潜伏场景 | **观察** | 提前布局等待催化，不建仓，纳入跟踪 |
| 4 高风险·回避 | **回避（一票否决）** | 政策+资本双失守；另附「须先验证国产承接能力」的重估路径 |
| 5 政策驱动型增量创造 | **放行** | 不以地缘倒逼为门槛，达标与否交支柱五 |
| 6 回避 | **回避（一票否决）** | 政策+资本双失守，纯市场驱动不确定性过高 |

**第五步：国产化率分层（科技赛道）**

```bash
python tools/specialized/geo_policy_screen.py localize \
  --industry {行业/环节} --localization-rate {数值} --as-of {YYYY-MM-DD} [--strategic-choke-point]
```

- 输出 `tier` / `tier_index` / `phase` / `action_hint` / `choke_point_applied`。
- 非科技赛道、或数值获取不到 → **标注「本项未判定」并继续**（国产化率非前置闸门必需项，§9.D）。
- 需参考梯队格式时调用 `examples`（半导体设备内置示例，仅作锚点）。

**第六步：收口输出与下游转接**
- 输出结构（技能正文模板，详见 §5 SKILL.md 结构）：①数据基准（截止日期/来源）→ ②0.1 证据链 → ③0.2 证据链 → ④0.3 工具 JSON 关键字段 → ⑤赛道两分法与支柱四门槛 → ⑥国产化率分层 → ⑦**前置闸门三档结论** → ⑧时变警示 + 免责声明 → ⑨下游转接指引。
- 下游转接（只指向 `garp-*`，**不指向 `mid-*` / 长期链**）：

| 前置结论 | 下游技能（同批 Phase 4 交付） |
| --- | --- |

| 行业级前置 | `garp-industry-research`（P4-9）/ `garp-industry-funnel`（P4-10）/ `garp-trend-tech-screen`（P4-11） |

| 回避（一票否决） | 直接终止，不进入下游 |
