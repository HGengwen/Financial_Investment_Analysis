### 2.3 期望工具调用序列（禁止心算）

```bash
# 第一步：日期基准
date

# 第二步：0.1 地缘风险检索（注意 scan 须用 -m 形式）
python -m tools.specialized.geo_policy_screen scan --industry 半导体设备

# 第三步：0.2 政策基金检索
python -m tools.specialized.geo_policy_screen scan --fund 半导体设备

# 第四步：0.3 矩阵判定
python tools/specialized/geo_policy_screen.py screen \
  --geo 高 --policy 高 --fund 有直接注资 \
  --as-of 2026-09-16 --basis "scan 检索结果 + 政策/基金公告"

# 第五步：国产化率分层
python tools/specialized/geo_policy_screen.py localize \
  --industry 量测检测 --localization-rate 12.5 --as-of 2026-09-16
```

## 5. 期望输出中的强制要素（缺一即不合格）

| # | 强制要素 | 检查点 |
| --- | --- | --- |
| 1 | **数据截止日期** | 报告头部与第二节均出现，且与 `date` 一致 |
| 2 | **数据来源依据** | `--basis` 写明检索来源（scan / 搜索工具 / 用户提供） |
| 3 | **时变警示** | 原样透传工具 `time_sensitivity_note` |
| 4 | **基金信号非估值依据** | 原样透传工具 `risk_note` |
| 5 | **降级标注** | `degraded=true` 时写明原因与替代来源 |
| 6 | **归档标注** | `archived=true` 时呈现 `archive_from`，不做解释性放行 |
| 7 | **基金三层架构免责** | 输出时保留「示例」标注 + 免责声明 |
| 8 | **免责声明** | 报告第八节含"不构成投资建议" |
| 9 | **口径隔离** | 全篇无中期链/长期链技能引用、无中期卖出体系与地缘术语 |
