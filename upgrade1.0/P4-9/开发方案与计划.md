## 1. 目标与范围

### 1.1 目标

产出 GARP 独立档（**1~5 年**）的行业研究技能 `/garp-industry-research {行业名}`，输出**行业层**结论：该赛道是否满足 GARP 门槛、处于生命周期什么位置、产业链哪一环是咽喉、全球有哪些标的、头部公司排序、景气定位、组合与卖出预览，并做到——

1. **六维选拔落地**（框架第 1 步六行表逐行）：产业空间（TAM ≥1000 亿 且 3 年 CAGR ≥20%）、**渗透率位置（15%~40% 黄金窗口）**、**国产化率位置（科技赛道专用）**、业绩兑现度（连续 2 季）、**题材辨别**（扣非匹配营收）、地缘政治敞口；
2. **0.3 三维交叉矩阵落地**：地缘倒逼强度 × 政策覆盖度 × 国字号基金介入 → 六类代表场景 + **未列组合按更审慎相邻档归档**；
3. **赛道两分法落地**：**地缘倒逼型**（地缘倒逼强度作**硬门槛**）vs **政策资本驱动型**（仅作**敞口体检**，达标交由政策资本判定），判别入口为 0.3 矩阵行归属，两类非互斥时**按更审慎那类执行**；
4. **卡脖子 6 标准 + Tier1~4 分层**（复用骨架，不改阈值）；
5. **引用式下游联动**：估值水位引用 `garp-valuation`（统一六档 / 多工具矩阵）、卖出预览引用 `garp-exit`（五级）、管理层与科研口径引用 `garp-management`（诚信前置 + 7+7+6）；通用复用仅 `qoq-accelerator` / `trend-momentum-scan` 两技能；
6. **结论明确**：综合赛道评级（A/B/C/拒绝）+ 三档动作（买 / 观察 / 放弃）+ 最该关注的一件事 + 当前最大风险。

### 2.2 渗透率五档（**替换核心，共性 2**）

| 档位 | 区间 | 动作 | 框架行号 |
| --- | --- | --- | --- |
| 导入早期 | **<5%** | 不确定性高，**观察不建仓** | 行 191 |
| 突破期 | **5%~15%** | 高弹性，**小仓跟踪** | 行 191 |

| 档位 | 区间 | 动作 | 框架行号 |
| --- | --- | --- | --- |
| 过早 | **<5%** | 不确定性高；**战略必争卡脖子环节**（如光刻）可作**高风险高弹性观察/小仓，非回避** | 行 192、207 |

### 2.4 0.3 三维交叉矩阵 + 赛道两分法（**替换核心，共性 3**）

**矩阵（框架行 163~171，照引不改）**：

| 地缘倒逼强度 | 政策覆盖度 | 国字号基金介入 | 投资含义 |
| --- | --- | --- | --- |
| 高（已制裁/断供） | 高（超常规+全链条） | 有直接注资 | **最优场景**：替代确定性与节奏被外部力量锁定 |
| 高 | 中 | 有专项子基金 | **次优场景**：方向明确，节奏受技术突破制约 |
| 中（制裁升级中） | 高 | 有覆盖 | **潜伏场景**：提前布局等待催化 |
| 高（已制裁/断供） | 低/无 | 无覆盖 | **高风险/回避**：须先验证承接能力，不足则回避 |
| 低 | 中/高 | 有覆盖/注资 | **政策驱动型增量创造**：达标以政策覆盖 + 基金介入为准 |
| 低 | 低 | 无覆盖 | **回避**：替代节奏完全依赖市场驱动 |

**三条刚性附带条款**：

1. **未列组合处理**：凡未显式列出的中间组合，一律按**更审慎的相邻档位**归档（行 175），**不得因未列而默认放行**；
2. **国字号基金注资 ≠ 估值依据**：仅视为「政策优先序列」信号，最终决策**回到估值与业绩兑现框架**（行 177）；
3. **时序同步**：制裁清单、出口管制、风险行业清单、国产化率均为**时变项**，评估前**须实时核验**，**勿沿用历史清单**（行 332）。

**赛道两分法（框架行 179~184）**：

| 类型 | 代表 | 地缘维度作用 | 达标判定 |
| --- | --- | --- | --- |
| **地缘倒逼型**（半导体设备/材料等） | 被制裁/断供 → 被迫替代 | 地缘倒逼强度**硬门槛**（非「低/无」方可建仓） | 同时以政策资本（0.3 矩阵）验证能否接住 |
| **政策资本驱动型**（机器人、信创等） | 政策创造需求 + 基金催化 | **仅作敞口体检**（海外收入/供应链/冲突暴露可控） | 达标与否交由政策资本维度判定 |

判别入口：**先看 0.3 矩阵的行归属**（行 184）；两类**非互斥**，介于其间时**按更审慎的那类执行**。

### 2.5 筛选维度——四维 → **六维**（对齐框架第 1 步六行表）

| # | 维度 | 标准 | 来源 |
| --- | --- | --- | --- |
| 1 | 产业空间（TAM） | ≥1000 亿 **且** 未来 3 年 CAGR ≥20% | 行 190 |
| 2 | **渗透率位置** | **15%~40% 加速上行期**（五档见 §2.2） | 行 191 |
| 3 | **国产化率位置（科技赛道专用）** | 四档见 §2.3；非科技赛道记「不适用」 | 行 192 |
| 4 | 业绩兑现度 | **连续 2 个季度**财报验证：营收增速 > 行业平均，毛利率稳定或提升 | 行 193 |
| 5 | **题材辨别** | 必须有 EPS 支撑；**扣非净利润增速须匹配营收增速**；纯概念无业绩**坚决回避** | 行 194 |
| 6 | 地缘政治敞口 | 由 **0.3 矩阵 + 赛道两分法**判定（见 §2.4） | 行 195 |

**综合赛道评级（硬编码）**：

```
A 级：六维全过
B 级：五维通过，一项待观察
C 级：未达门槛（TAM / 渗透率 / 国产化率）或业绩未兑现
拒 绝：题材炒作（维度 5 一票否决）或 0.3 矩阵归「回避」档（维度 6 一票否决）
```

> 仅评级 **A/B** 才允许进入 `/garp-trend-tech-screen` 正向排序（P4-11）。

### 2.6 卡脖子环节 6 标准（复用骨架，不改阈值）

| # | 标准 | 阈值 |
| --- | --- | --- |
| 1 | 供给集中度 | ≤ 2 家主导 |
| 2 | 扩产周期 | > 2 年 |
| 3 | 替代难度 | 高（技术/专利/工艺壁垒） |
| 4 | 产能利用率 | > 80% |
| 5 | 需求增速 | > 30% |
| 6 | 客户验证周期 | 长（客户切换成本高） |

**全满足 = 强卡脖子**；卡脖子环节即「咽喉位置」，是第二、三层机会来源（衔接 P4-18 `garp-bottleneck-hunter`）。

### 2.7 Tier1~4 确定性分层（复用骨架）

| 层级 | 条件 | 仓位建议 |
| --- | --- | --- |
| Tier 1 | 大市值、纯正标的、行业龙头 | 核心仓位（底仓） |
| Tier 2 | 中市值、纯正或高占比、细分龙头 | 卫星仓位 |
| Tier 3 | 小市值、开发阶段、高风险高弹性 | 机动仓 |
| Tier 4 | 多元化公司中有关联业务 | 观察仓或回避 |

须**标注未上市关键玩家**（独角兽/初创 = 未来竞争格局变量）。**仓位措辞层**：本技能只给**层级-仓位对应关系**，具体比例口径**引用** `garp-portfolio-review`（底仓 60%~80% / 机动 20%~40%），**不重复定义**。

### 2.8 头部公司四维打分（权重不变，**口径出口替换**）

| 维度 | 权重 | 打分标准 | 口径出口（GARP 档） |
| --- | :--: | --- | --- |
| 产业景气度 | 35% | 供需格局、价格趋势、CR3 集中度 | 工具 + 搜索 |
| 基本面 | 30% | ROE 趋势、毛利率、营收利润匹配度 | `stock_financial.py` + `financial_rigor.py` |

| 地缘政治 | 15% | 海外依赖、供应链、制裁、抗封锁韧性 | **引用 0.3 矩阵 + 赛道两分法**（§2.4） |

### 3.3 降级与失败处置

| 场景 | 处置 |
| --- | --- |
| 搜索无结果 / 单一来源 | 标「单一来源，置信度低」（`GI-8`）；**不得**作为确定性结论 |
| 渗透率 / 国产化率无权威数据 | 标「**未验证**」并给区间上限下限；**不得**因未验证而默认落黄金区 |
| 0.3 矩阵三项输入任一无法判定 | 按**更审慎相邻档**归档（行 175）；仍无法判定 → 归「回避」档并说明 |
| 美股取数失败（yfinance 受限） | 该标的标「**未验证**」，其 Tier 分层与打分标「无法判定」；**不在本技能内做网络修复**（归 P5-2） |
| 行业跨两类赛道（地缘倒逼型 ↔ 政策资本驱动型） | **按更审慎那类执行**（行 184）并显式标注 |
| 时变项（清单/管制/国产化率）未实时核验 | **禁止**沿用历史清单；未核验则标「未核验」并降级结论 |

### 3.4 风控硬编码（`GI-1`~`GI-12`，本技能新增；已实测全仓 `GI-\d` 命中 = 0）

| 编号 | 规则 |
| --- | --- |
| `GI-1` | TAM ≤500 亿 **或** 3 年 CAGR ≤15% → 必须标注「**不满足 GARP 中期门槛**」，**不得推荐** |
| `GI-2` | 渗透率 **<5% 且无业绩兑现** → 标注「**过早，不参与**」，**不得推荐建仓** |
| `GI-3` | 渗透率 **>60%（天花板）** → 标注「**已过黄金区**」，建议逐步退出，**不得进入正向排序** |
| `GI-4` | 国产化率 **<5%** 且**非**战略必争卡脖子环节 → 标注「过早」；**战略必争环节**须显式标注「可观察/小仓、非回避」 |
| `GI-5` | 0.3 矩阵归 **「回避」** 档 → 标注「**回避**」，**不得**以「利空出尽」为由推荐 |
| `GI-6` | **赛道类型未判别即打分** → 禁止；须先判「地缘倒逼型 / 政策资本驱动型」，**地缘倒逼型的地缘倒逼强度为硬门槛** |
| `GI-7` | 全行业**无一家公司连续 2 季盈利** → 标注「**纯概念阶段**」，不得推荐 |
| `GI-8` | 关键数据**仅单一来源** → 标注「单一来源，置信度低」，**不得**作为确定性结论 |
| `GI-9` | **所有估值/市值/PEG/加权打分**必须走工具（`financial_rigor.py` / `trend_tech_screen.py`），**禁止 LLM 心算** |
| `GI-10` | 头部公司**多数 PEG >2** → 标注「**严重透支**」，建议大幅减仓（PEG 口径引用 `garp-valuation`） |
| `GI-11` | 任一龙头触发**五级卖出**（引用 `garp-exit`）→ **必须最先输出**该级结论，**禁止跳过** |
| `GI-12` | 持有**满 4 季度**行业逻辑未兑现 → 标注「**时间止损预警**」，不得忽略（承接 `garp-exit` 时间止损） |
