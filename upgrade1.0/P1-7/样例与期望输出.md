## 样例 5：三硬约束告警（不拒绝，仍正常计算）

命令：`--r 10 --currency CNY`（r 超出 CNY [6.0%, 9.0%] 区间）。

```text
python tools/common/financial_rigor.py dcf \
  --fcf 100 --g-high 10 --years-high 5 --years-fade 5 --g-terminal 2 \
  --r 10 --shares 10 --market-cap 1000 --currency CNY
```

| 字段 | 值 |
| --- | --- |
| `pv` | 1970.70 |
| `per_share` | 197.07 |
| `margin_of_safety_pct` | 49.26 |
| `verdict` | 低估（市值≤保守DCF 80%） |
| `audit.passed` | false |

人机输出节选：

```text
  审计告警 (audit):
    🔍  C1: 折现率 r=10.00% 不在 CNY 的 [6.0%, 9.0%] 区间内
```

```json
{
  "pv": 1970.7,
  "per_share": 197.07,
  "margin_of_safety_pct": 49.26,
  "verdict": "低估（市值≤保守DCF 80%）",
  "audit": {"passed": false, "alerts": ["C1: 折现率 r=10.00% 不在 CNY 的 [6.0%, 9.0%] 区间内"]},
  "warnings": []

```

> 说明：样例 5 验证「三硬约束只告警不拒绝」——`audit.passed=false` 但 `pv/per_share/margin` 仍按模型正常输出，不 exit 1。
