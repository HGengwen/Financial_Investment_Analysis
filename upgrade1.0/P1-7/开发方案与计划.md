## 1. 子任务定位与权威依据

P1-7 是 `financial_rigor.py` 计算核心扩展的第 7 个子命令，目标是为 GARP 框架「第4步 估值锚定——多工具矩阵」中**现金流稳定的成熟型企业**提供简化三阶段 DCF（高增/过渡/永续）估值，输出**现值、每股价值、安全边际**。

权威口径（框架第4步 行 388 + 详细计划 P1-7）：

| 企业类型 | 主估值工具 | 辅工具 | 低估门槛 |
| --- | --- | --- | --- |
| **成熟型企业** | DCF | 股息贴现 | **当前市值 ≤ 保守 DCF 估值的 80%** |

另外两处权威边界（框架第4步 行 430~432）：

- 高环境风险行业（无明确转型路径）→ 合理估值再打 8~9 折，DCF 目标价、PEG 区间一并下调。
- 面临「搁浅资产」风险 → 折价加大，且**上调贴现率**，在 DCF 中额外上调 1~2 个百分点。

> 口径隔离（详见 §5/§12）：本条 ESG/搁浅资产的「折价」与「贴现率上调」属于**上游调整**，由 P4 技能编排层在生成 DCF 输入参数前完成；本工具只接收已调整后的单一 `--fcf` 与 `--r` 数值，不内置 ESG 折扣逻辑。

权威约束（详细计划 P1-7 + 总计划风险与依赖）：折现率/终值增速参数须**复用 `terminal_value.py audit` 三硬约束思想**（r−g 宽度、币种一致性、离散风险归属）。

### 2.2 范围

**做什么：**

- 简化三阶段 DCF：高增长阶段（n₁ 年）→ 过渡阶段（n₂ 年线性衰减）→ 永续终值。

## 3. 关键量化口径

### 3.1 简化三阶段 DCF 模型

设基准自由现金流 `FCF`（第 0 年年末/预测首年现金流），折现率 `r`（小数），高增长增速 `g₁`（小数，持续 `n₁` 年），过渡 `n₂` 年，永续增速 `g_T`（小数）：

1. **高增长阶段**（t = 1 … n₁）：

   $$
   CF_t = FCF \times (1 + g_1)^t
   $$

2. **过渡阶段**（t = n₁+1 … n₁+n₂）：增速从 `g₁` 线性衰减到 `g_T`，过渡第 `j` 年（j = 1 … n₂）的增速为：

   $$
   g_j = g_1 + (g_T - g_1) \times \frac{j}{n_2}
   $$

   $$
   CF_{n_1+j} = CF_{n_1} \times \prod_{k=1}^{j}(1 + g_k)
   $$

3. **永续终值**（Gordon 增长模型）：

   $$
   TV = \frac{CF_{n_1+n_2} \times (1 + g_T)}{r - g_T}
   $$

4. **现值与每股价值**：

   $$
   pv = \sum_{t=1}^{n_1+n_2} \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^{n_1+n_2}}
   $$

   $$
   per\_share = \frac{pv}{shares}
   $$

> `r`、`g₁`、`g_T` 在 CLI 层按「百分点」输入（如 `9` 表示 9%），函数内部统一 `/100` 转小数后以 `Decimal` 折现；`r − g_T` 即永续终值分母。

### 3.2 安全边际口径与低估门槛

$$
margin\_of\_safety\_pct = \frac{pv - market\_cap}{pv} \times 100
$$

- `margin_of_safety_pct > 0`：DCF 现值高于当前市值，存在安全边际。
- `margin_of_safety_pct < 0`：当前市值高于 DCF 现值（高估）。
- **成熟型低估门槛**（框架 行 388）：`市值 ≤ 保守 DCF 估值的 80%` ⟺ `margin_of_safety_pct ≥ 20%`。

> 「保守」的来源：终值增速 `g_T` 受币种 `g_max` 审计约束、折现率 `r` 落于币种合理区间、三硬约束告警提示风险分散/口径混用。工具输出的是「基准 DCF 现值」，安全边际以此为分母，不再二次打折。

### 3.3 三硬约束复用（`terminal_value.py audit` 思想，告警不拒绝）

| 约束 | 权威含义 | DCF 适配（输出 `audit.alerts`） |
| --- | --- | --- |
| **C1 币种一致性** | r 与 g 必须同币种 | 提供 `--currency` 时：校验 `r` 落于 `CURRENCY_BANDS[币种].r` 区间、`g_T` ≤ `g_max`（永续上限）、`r_f` 与币种基准偏差 ≤ 0.5pct；不提供 `--currency` 时跳过币种区间校验 |
| **C2 分母宽度** | `r−g` 至少 5 个百分点 | 校验永续分母 `r − g_T ≥ MIN_SPREAD(0.05)`；`≤0` → 模型失效（护栏降级 N/A），`0 < r−g_T < 0.05` → 告警 |
| **C3 离散风险归属** | 退市/VIE/地缘/监管不得进 r 或 β | 提供 `--discrete-risks` 时：校验每条归属不在 `{折现率,r,beta,β}`；归属 `未建模` → 告警；并提示「离散风险不得计入折现率 r」 |

> 币种区间常量沿用 `terminal_value.py` 的值（CNY `r∈[0.06,0.09]`/`g_max=0.02`/`rf=0.0170`；USD/HKD `r∈[0.09,0.115]`/`g_max=0.04`/`rf=0.0470`）。本工具**复制**这些常量到 `financial_rigor.py`（不 import `terminal_value`），避免工具间硬耦合。

### 3.4 单位与 FCF/r 口径

- `--fcf`、`--market-cap` 同货币单位裸数值；`--r`/`--g-high`/`--g-terminal` 为**百分点**（与 `wacc` 的 `re/rd`、`peg` 的 `growth` 一致）。
- `--shares` 为总股本（股/亿股，与市值口径同刻度，仅用于 `per_share` 换算）。
- **FCF 与 r 必须同口径**：FCFF 配 WACC，FCFE 配股权成本。本工具只接收单一数值并在 `--help`/提示里静态声明该口径，由调用方保证一致。

## 6. 函数与 CLI 实现设计

### 6.1 `dcf()` 函数签名

```python
def dcf(fcf, g_high, years_high, years_fade, g_terminal, r,
        shares, market_cap, currency=None, rf=None, discrete_risks=""):
    """计算简化三阶段 DCF 的现值、每股价值与安全边际。

    高增长阶段 n1 年（增速 g_high），过渡 n2 年（线性衰减至 g_terminal），
    之后 Gordon 永续终值。现值按折现率 r 折现到第 0 年。

    Args:
        fcf: 基准自由现金流（第 0 年，与市值同货币单位）。
        g_high: 高增长阶段增速，百分点（如 10 表示 10%）。
        years_high: 高增长阶段年数。
        years_fade: 过渡阶段年数（可为 0）。
        g_terminal: 永续终值增速，百分点（如 2 表示 2%）。
        r: 折现率，百分点（如 9 表示 9%）。
        shares: 总股本（与市值同刻度）。
        market_cap: 当前市值（与 fcf 同货币单位）。
        currency: 现金流币种，可选（CNY/USD/HKD），用于 C1 审计。
        rf: 无风险利率，百分点，可选，用于 C1 审计。
        discrete_risks: 离散风险归属声明，可选，用于 C3 审计。

    Returns:
        dict: 含 pv / per_share / margin_of_safety_pct / verdict /
              audit / warnings / inputs 字段。
    """
```

### 6.2 核心计算与护栏（伪代码）

```python
F = exact(fcf)
g1 = exact(g_high) / 100
gT = exact(g_terminal) / 100
rd = exact(r) / 100
n1 = int(years_high)
n2 = int(years_fade)

# 护栏（模型失效 → pv/per_share/margin 全降级 None）
if F <= 0 or rd <= 0 or n1 < 1 or n2 < 0 or gT >= rd:
    return {pv/per_share/margin_of_safety_pct 均为 None,
            verdict: "模型失效/输入非法", warnings 含具体原因}

# 现金流序列（高增 + 过渡线性衰减）
cfs = []
p = F
for _ in range(n1):
    p = p * (1 + g1)
    cfs.append(p)
for j in range(1, n2 + 1):
    gj = g1 + (gT - g1) * Decimal(j) / Decimal(n2)
    p = p * (1 + gj)
    cfs.append(p)

# 永续终值 + 现值
tv = p * (1 + gT) / (rd - gT)
one_r = 1 + rd
pv = sum(c * (one_r ** (-t)) for t, c in enumerate(cfs, 1)) \
     + tv * (one_r ** (-(n1 + n2)))

pv_q = pv.quantize(Decimal("0.01"))
per_share = (pv / exact(shares)).quantize(Decimal("0.01")) if shares > 0 else None
margin = ((pv - exact(market_cap)) / pv * 100).quantize(Decimal("0.01")) if market_cap > 0 else None

# 合理性告警（不拒绝）
warnings = []
if g_high < 0: warnings.append("高增长增速为负")
if g_terminal < 0: warnings.append("永续增速为负")
if shares <= 0: warnings.append("股数≤0，每股价值不可用")
if market_cap <= 0: warnings.append("市值≤0，安全边际不可用")

# 三硬约束审计（告警不拒绝）
audit = _audit_dcf(currency, rd, gT, rf, discrete_risks, n1, g1)

# verdict 判定（基于 2 位小数 margin）
verdict = _verdict_dcf(margin)
```

### 6.4 `verdict` 判定（新增）

```python
def _verdict_dcf(margin):
    if margin is None:
        return "N/A"
    if margin >= 20:
        return "低估（市值≤保守DCF 80%）"
    if margin >= 0:
        return "合理（安全边际<20%）"
    return "高估（市值高于DCF）"
```

| 编号 | 决策点 | 推荐方案 | 备选 |
| --- | --- | --- | --- |
| **D1** | 三阶段现金流基准与增速 | `--fcf` 为**第 0 年基准现金流**，第 1 年 = `FCF×(1+g₁)`；n₁ 年高增 → n₂ 年线性衰减至 g_T → Gordon 永续终值 | `--fcf` 为第 1 年现金流，直接折现不乘首年增速 |

| **D5** | 护栏与降级规则 | `fcf≤0 / r≤0 / g_T≥r / years_high<1 / years_fade<0` → `pv/per_share/margin` 全降级 N/A；`shares≤0`→`per_share=None`、`market_cap≤0`→`margin=None` 但 `pv` 保留；负字段计入 `warnings` | 任一非法即整体 N/A；或抛异常退出 |

> **定稿结论（2026-09-14 已确认）**：D1~D5 全部按推荐方案定稿——
> D1（`--fcf` 为第 0 年基准现金流，第 1 年 = `FCF×(1+g₁)`）、
> D2（增速/折现率/终值增速统一百分点，内部 `/100` 转小数）、
> D3（`margin=(pv−market_cap)/pv×100`，`≥20%` 为低估，等价市值≤0.8×pv）、
> D4（三硬约束输出 `audit{passed, alerts}` 只告警不拒绝，仅模型失效 `g_T≥r` 降级 N/A）、
> D5（护栏降级 N/A 风格：`fcf≤0 / r≤0 / g_T≥r / years_high<1 / years_fade<0` 全降级；`shares≤0`→`per_share=None`、`market_cap≤0`→`margin=None` 但 `pv` 保留；负字段计入 `warnings`）。
> 本表据此固化为开发口径，后续开发不另行变更。

## 9. 验收标准

1. **DCF 现值/每股价值/安全边际正确至 2 位小数**：样例 1 → `pv=2275.36 / per_share=227.54 / margin=56.05%`。
2. **低估门槛与框架一致**：`margin≥20%` → 低估；`0~20%` → 合理；`<0` → 高估。
3. **违反硬约束给出 audit 告警**：C1（币种/区间）、C2（分母<5pct）、C3（离散风险归属）写入 `audit.alerts`，不 exit 1。
4. **模型失效降级**：`g_T≥r` 等 → 输出 `None`/`N/A` 且无异常退出。
5. **JSON 可解析**：`pv/per_share/margin_of_safety_pct` 为数值或 `None`，`audit.passed` 为布尔，`alerts/warnings` 为字符串数组。
6. **回归无扰动**：既有 16 个子命令（原 9 + `roic/incremental-roic/wacc/rule-of-40/ev-sales/adjusted-peg/…`）功能与输出不变；`terminal_value.py` 未改动。

## 12. 风险与限制

- **FCF 口径依赖调用方**：工具无法自动区分 FCFF/FCFE，也无法抽取科目；若调用方把净利润/经营现金流误作 FCF，估值会失真。故静态提示「FCF 与 r 必须同口径」，不越权抽取。
- **简化三阶段的局限性**：线性衰减是近似，未建模资本开支周期、税率变化、营运资本波动等；结果对 `r` 与 `g_T` 高度敏感（尤其分母窄时），须配合三硬约束告警审慎采信。
- **安全边际以「基准 DCF」为分母**：本工具不做二次 8 折；「保守」由参数约束（g_T 卡 g_max、r 落币种区间）体现，下游若需更保守需在输入参数层先行下调。
- **ESG/搁浅资产折价不在本工具**：折价与贴现率上调（1~2pct）由 P4 编排层在入参前完成，避免工具内隐式叠加导致口径不可追溯。
- **离散风险不自动进折现率**：与 `terminal_value.py` 一致，C3 明确禁止将退市/VIE/地缘/监管塞进 r，违者以告警暴露。
