> 数据截止日期：2026-09-14

---

## 1. 工具层职责范围（做什么）

`financial_rigor.py` 新增的 `dcf()` 与 `dcf` 子命令**只**承担以下原子计算：

1. 简化三阶段现金流折现（高增 `n₁` 年 → 过渡 `n₂` 年线性衰减 → Gordon 永续终值）。
2. 输出 `pv`（现值）、`per_share`（每股价值）、`margin_of_safety_pct`（安全边际），2 位小数。
3. 三硬约束审计 `audit {passed, alerts}`（C1 币种一致性 / C2 分母宽度 / C3 离散风险归属），只告警不拒绝。
4. 合理性告警 `warnings` 与护栏降级（模型失效 → `None`/`N/A`，不抛异常）。
5. 静态口径提示（`--help` / 输入回显中声明「FCF 与 r 必须同口径」）。

---

## 2. 明确不做什么（边界）

以下事项**不属于** `dcf` 工具层，交由下游 P4 技能编排层或调用方技能完成：

| 事项 | 归属 | 原因 |
| --- | --- | --- |
| FCF 科目抽取（净利润→FCFF/FCFE 的科目映射） | 调用方技能 | 工具只接收单一 `--fcf` 数值，不越权抽取会计科目 |
| FCFF / FCFE 区分与换算 | P4 编排层 | 现值/市值口径由调用方保证一致 |
| ESG 环境风险折价（合理估值再打 8~9 折） | P4 编排层 | 折价在生成 DCF 输入参数**前**完成，避免工具内隐式叠加、口径不可追溯 |
| 搁浅资产风险的贴现率上调（1~2pct） | P4 编排层 | 同样为上游入参调整，工具不内部改动 `r` |
| 宏观 PEG 区间调整 | P4 编排层 | 非 DCF 职责 |
| 多情景蒙特卡洛 / 敏感性 sweep | P4 编排层 | 本工具单点折现，多档敏感性由编排层多次调用 |

## 3. 与 `terminal_value.py` 的关系

- `dcf` **复用** `terminal_value.py audit` 的「三硬约束思想」与常量值（`CURRENCY_BANDS`、`MIN_SPREAD=0.05`、`RISK_PLACEMENT_*`）。
- 采用**复制常量**到 `financial_rigor.py` 的方式实现，**不 import** `terminal_value.py`，二者互不依赖、互不改动。
- 核验：`git diff` 确认 `tools/common/terminal_value.py` 未发生任何变更。

---

## 4. 口径约束提示

- `--fcf`、`--market-cap` 同货币单位裸数值；`--r` / `--g-high` / `--g-terminal` 统一**百分点**输入（内部 `/100` 转小数）。
- **FCFF 配 WACC，FCFE 配股权成本**；调用方须保证 FCF 与 r 同口径。
- 安全边际以「基准 DCF 现值」为分母，工具不做二次 8 折；「保守」由参数约束（`g_T` 卡 `g_max`、`r` 落币种区间）体现。
