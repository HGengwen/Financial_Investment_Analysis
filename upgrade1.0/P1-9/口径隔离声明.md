# P1-9 口径隔离声明

> 状态：完成（2026-09-14）

---

## 1. 本任务做了什么（边界内）

1. 三市场各新增「三价齐全且等长对齐」的 OHLC 提取：
   - A股/港股：`_extract_ohlc_aligned(rows)`
   - 美股：`_extract_ohlc_for_atr(df)`
2. 三市场 `_momentum_from_series(...)` 各新增一次对 `momentum.atr()` 的调用，并在返回字典
   追加 `"atr14"` 字段（默认 `period=14, method="wilder"`，直接透传，不二次 round）。
3. `cmd_momentum` 中在既有 `closes/volumes` 提取之后追加三价提取并作为可选关键字传入。

---

## 2. 本任务没做什么（边界外，明确不触碰）

1. **不重新实现 ATR 公式**：完全复用 P1-8 `tools/common/momentum.py` 的 `atr()`。
   本任务对该文件**零编辑**。
2. **不输出 `stop_price`/`stop_pct`**：详细计划仅把 `stop_price` 标为「可选」，且当前
   `--momentum` 无 `entry_price` 入参；止损价/止损幅度/仓位状态判断归下游 P4-6。
3. **不新增 `--entry-price` / `--multiplier` CLI 参数**。
4. **不改动**三市场既有 `closes/volumes` 提取、既有字段名、既有输出结构与 `data_points` 口径。
5. **不做**仓位状态分档、20% 封顶、8%~10% 硬止损判断。
6. **不改** `docs/` 三指南（属验收通过后的后续动作，非本次门禁）。

---

## 3. 数据点口径差异说明（预期，非缺陷）

- 既有 `data_points = len(closes)`（现有 close 序列），保持不变。
- `atr14` 基于「三价齐全对齐」序列计算，长度可能 ≤ `len(closes)`；
  对齐后有效 TR < 14 时 `atr14=None`（静默降级，不抛异常、不加 note/warnings）。
- 两者口径解耦，正常行情下通常一致。

---

## 4. 降级与边界

| 场景 | 结果 |
| ---- | ---- |
| `momentum` 模块未安装 | 保留既有 `{"error": ...}`，`atr14` 不出现 |
| 三价任一为空或长度不等 | `atr14=None`，其余字段正常 |
| 有效 TR < 14 | `atr14=None`，静默降级 |
| 某行 high/low/close 缺失 | 该行跳过，序列仍等长对齐 |
