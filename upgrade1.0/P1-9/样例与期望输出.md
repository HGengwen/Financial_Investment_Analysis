## 1. 样例目标

验证接线层「三价对齐提取 → 调 `momentum.atr()` → 透传 `atr14`」三处链路正确：
- `atr14` 字段在 `data` 中**存在**且为 float；
- `atr14` 与对同一对齐序列独立调用 `momentum.atr()` 的结果**误差为 0**。

> ATR 公式正确性已在 P1-8 由 41 项测试验证，本样例不做公式复验。

### 3.3 复现方式

```powershell
@'
import json, pandas as pd
from tools.common import momentum as mm
from tools.a_share import stock_quote as aq
from tools.hk_stock import stock_quote as hq
from tools.us_stock import stock_quote as uq

def gen(n, base, step, hp, lp):
    cs = [base + i*step for i in range(n)]
    return ([c + hp + (i%3)*0.5 for i,c in enumerate(cs)],
            [c - lp - (i%2)*0.5 for i,c in enumerate(cs)], cs)

n = 260
# A股/港股 dict rows
for market, mod, base, step in [("a", aq, 100.0, 0.5), ("hk", hq, 300.0, 1.0)]:
    hs, ls, cs = gen(n, base, step, 2.0, 1.0)
    rows = [{"date": i, "high": hs[i], "low": ls[i], "close": cs[i], "volume": 1e6} for i in range(n)]
    c2 = [float(r["close"]) for r in rows if r.get("close") is not None]
    v2 = [float(r["volume"]) if r.get("volume") is not None else 0.0 for r in rows]
    hh, ll, cc = mod._extract_ohlc_aligned(rows)
    out = mod._momentum_from_series(c2, v2, None, highs=hh, lows=ll, atr_closes=cc)
    assert out["atr14"] == mm.atr(hh, ll, cc), market
    print(market, out["atr14"], mm.atr(hh, ll, cc))

# 美股 DataFrame
hs, ls, cs = gen(n, 180.0, 0.8, 3.0, 1.5)
df = pd.DataFrame({"High": hs, "Low": ls, "Close": cs, "Volume": [2e6]*n},
                  index=pd.date_range("2023-01-01", periods=n, freq="D"))
c2, v2 = uq._extract_series_from_df(df)
hh, ll, cc = uq._extract_ohlc_for_atr(df)
out = uq._momentum_from_series(c2, v2, None, highs=hh, lows=ll, atr_closes=cc)
assert out["atr14"] == mm.atr(hh, ll, cc), "us"
print("us", out["atr14"], mm.atr(hh, ll, cc))
'@ | python -
```

## 4. 期望输出判定

1. `success=true`，`data` 末尾新增 `atr14`（float 或 `null`）。
2. `atr14` 值与独立 `momentum.atr()` 误差 0。
3. 既有字段（`close/return_250d_pct/smr_percentile/rsi50/ma50/ma200/tech/data_points/note`）键与口径不变。
