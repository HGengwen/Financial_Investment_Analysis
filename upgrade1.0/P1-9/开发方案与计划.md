## 3. 关键量化口径

### 3.1 ATR 口径（权威 = P1-8 已定稿，本任务零新增计算）

```text
TR[i] = max(high[i] − low[i], |high[i] − close[i−1]|, |low[i] − close[i−1]|)
ATR(14) = Wilder 平滑（初始 14 个 TR 简单平均 + 递归平滑）
```

接线层**直接透传** `momentum.atr(highs, lows, closes)` 的返回值（已 `round(raw, 2)`），**不再二次 round**，避免三市场各自 round 造成口径漂移。默认参数取 `period=14, method="wilder"`，与 P1-8 定稿结论（D1/D2）一致。

### 3.2 OHLC 三价对齐口径（本任务新增的唯一实质逻辑）

`momentum.atr(highs, lows, closes)` 要求三个序列**等长且按时间升序对齐**（`closes[i-1]` 即「昨收」）。因此接线层必须保证：

1. 三条序列来自**同一行 K 线**（同一交易日）。
2. 该行 `high/low/close` **三者均非 None** 才纳入（即「三价齐全」条件）。
3. 序列按 `date` 升序排列（最新在末尾）。

> 三市场现有 `closes` 提取（喂给 `compute_momentum`）与 ATR 所需的三价对齐提取**刻意解耦**：
> - 现有 `closes` 仅按 `close is not None` 过滤，可能略短于 `rows`；
> - ATR 需要 `high/low/close` 三价齐全且等长，用独立对齐函数单独产出。
>
> 在正常行情数据下，同一根 K 线的 `high/low/close` 要么全部有值、要么全部缺失，两者结果通常一致；但在异常缺失数据下可能产生长度差异。为**绝对保证既有字段无回归**，本任务不动现有 `closes/volumes` 提取，只新增独立的 OhLC 对齐序列专供 ATR。

### 3.3 ATR 与既有字段的数据点口径差异

- 既有 `data_points` = `len(closes)`（现有 close 序列长度），**保持不变**。
- `atr14` 基于「三价齐全对齐」序列计算，其长度可能 ≤ `len(closes)`；当对齐后有效 TR 数 < 14 时 `atr14=None`。
- 两者口径不同但互不影响：`data_points` 反映动量计算用的收盘点数，`atr14` 反映 ATR 计算用的三价 K 线数。

## 7. 接线实现设计（伪代码）

### 7.1 A股 / 港股（新增 `_extract_ohlc_aligned` + `_momentum_from_series` 扩展）

```python
def _extract_ohlc_aligned(rows):
    """从 K 线记录中提取三价齐全且对齐的 highs/lows/closes。

    Args:
        rows: 按日期升序排列的 K 线记录列表（dict，含 high/low/close 键）。

    Returns:
        (highs, lows, closes) 三元组，三者等长且对齐；缺三价的行被跳过。
    """
    highs, lows, closes = [], [], []
    for r in rows:
        h, l, c = r.get("high"), r.get("low"), r.get("close")
        if h is None or l is None or c is None:
            continue
        highs.append(float(h))
        lows.append(float(l))
        closes.append(float(c))
    return highs, lows, closes


def _momentum_from_series(closes, volumes, peers,
                          highs=None, lows=None, atr_closes=None):
    if _momentum is None:
        return {"error": "momentum 模块未安装，无法计算动量指标"}

    m = _momentum.compute_momentum(
        closes, volumes or None, uplift_period=250, rsi_period=50, peer_pcts=peers)

    atr14 = None
    if highs and lows and atr_closes and len(highs) == len(lows) == len(atr_closes):
        atr14 = _momentum.atr(highs, lows, atr_closes)

    ret = {
        "close": m["close"],
        "return_250d_pct": round(m["return_250d_pct"], 2) if m["return_250d_pct"] is not None else None,
        "smr_percentile": round(m["smr_percentile"], 2) if m["smr_percentile"] is not None else None,
        "rsi50": round(m["rsi50"], 2) if m["rsi50"] is not None else None,
        "ma50": round(m["ma50"], 4) if m["ma50"] is not None else None,
        "ma200": round(m["ma200"], 4) if m["ma200"] is not None else None,
        "tech": m["tech"],
        "data_points": len(closes),
        "atr14": atr14,
    }
    if not peers:
        ret["note"] = "未提供板块截面(--peers)，smr_percentile 为 None"
    return ret
```

### 7.2 美股（新增 `_extract_ohlc_for_atr` + 接线）

```python
def _extract_ohlc_for_atr(df):
    """从 yfinance K 线 DataFrame 提取三价齐全对齐的 highs/lows/closes。"""
    def _col(df, *names):
        for n in names:
            if n in df.columns:
                return df[n]
        return None

    highs_col = _col(df, "High", "high")
    lows_col = _col(df, "Low", "low")
    closes_col = _col(df, "Close", "close")
    if highs_col is None or lows_col is None or closes_col is None:
        return [], [], []

    # 三列均非空才保留，保证按行（日期）对齐
    mask = highs_col.notna() & lows_col.notna() & closes_col.notna()
    highs = [float(v) for v in highs_col[mask].tolist()]
    lows = [float(v) for v in lows_col[mask].tolist()]
    closes = [float(v) for v in closes_col[mask].tolist()]
    return highs, lows, closes
```

## 13. 风险与限制

- **三价对齐与既有 closes 的口径差异**：已在 §3.3 明确——`atr14` 用三价齐全对齐序列，`data_points` 用既有 close 序列，两者在异常缺失数据下可能不同。属预期行为，不影响既有字段。
- **美股 DataFrame 列名差异**：yfinance 不同版本可能返回 `High/Low/Close`（首字母大写）或小写/多级列。`_extract_ohlc_for_atr` 沿用既有 `_col(df, "High", "high")` 的多命名回退与多级列拍平逻辑，与 `_extract_series_from_df` 一致。
- **停牌/缺失行**：三价不齐全的行被跳过，可能使有效 TR < 14 而返回 `None`；不补齐、不插值（与 P1-8 §12 结论一致）。
- **港股/美股手动 `--peers` 依赖**：`atr14` 不依赖 `--peers`，与 `smr_percentile` 解耦，故无额外数据源风险。
- **`stop_price` 未接线**：本任务仅输出 `atr14`，若后续 P4-6 需止损价，须在编排层补 `entry_price` 入参后调 `momentum.stop_price()`（P1-8 已完成），本任务不预埋。
