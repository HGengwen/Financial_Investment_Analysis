## 1. 目标与范围

### 1.1 目标

产出 GARP 独立档（**1~5 年**）的行业漏斗精选技能 `/garp-industry-funnel {行业名}`，回答「**这条赛道里具体买哪几家、仓位怎么配**」，并做到——

1. **能力圈闸门前置**（框架第 2 步）：候选标的进入任何财务/估值核验**之前**，先过「产业理解 / 财务理解 / 估值理解 / 技术理解（科技股必答）」**四维自检**，未通过即视为**能力圈之外**（框架行 360 列为**买入前一票否决**项），不进入后续层；
2. **6 硬指标 + 财务五门槛逐条对齐**：营收 ≥10 亿、3 年营收 CAGR ≥15%、资产负债率 <60%（金融/地产除外）、经营性现金流净额为正、近 3 年 ≥2 年扣非净利润为正；**科技豁免**（框架行 247）仅在「扣非为负**仅由研发费用化压低当期利润**」时启用，以「现金流为正 + 营收连续增长 + 研发强度 ≥15%」三项替代扣非门槛；
3. **五大支柱精析落地**（框架第 3 步）：产业景气度（β）/ 公司基本面（α，含 **ROIC 四档**与**可量化护城河**）/ 管理层与科研转化（**诚信前置 + 7+7+6**，科技股再叠加 **8+8+4**）/ 地缘政治与外部环境（**0.3 矩阵 + 赛道两分法**）/ **政策与资本覆盖度**（个股级注资强度、场景绑定兑现、政策门槛优势）；
4. **0.3 三维交叉矩阵落地**：地缘倒逼强度 × 政策覆盖度 × 国字号基金介入 → 六类代表场景 + **未列组合按更审慎相邻档归档**；**国字号注资是「政策优先序列」信号、非买入估值依据**；
5. **五大师研判 + 五大矛盾化解**：四大师增补**费雪**（质化分析 / 闲聊法 / 「绝不卖」两前提），矛盾由四条 → **五条**（新增「费雪绝不卖 vs 趋势景气纪律」）；
6. **引用式下游联动**：估值档位只读 `garp-valuation`（统一六档 + 多工具矩阵）、卖出只引 `garp-exit`（五级 + 时间止损 + ATR 动态止损）、治理/科研口径引 `garp-management`、地缘引 `garp-geo-policy`、宏观调档引 `garp-macro`、组合上限引 `garp-portfolio-review`；通用复用仅 `qoq-accelerator` / `trend-momentum-scan` **2 个全档位技能**；
7. **结论明确**：终选 **3 底仓 + 2 机动仓** + **阶段化目标仓位** + 建仓价区间 + 硬止损价 + 景气监测指标 + 核心逻辑一句话 + 后置动作（`garp-investment-checklist` 七关）。

### 2.3 能力圈四维自检（**新增，漏斗第一层**）

| 维度 | 评估标准 | 自检问题（须能独立回答「是」） |
| --- | --- | --- |
| **产业理解** | 能否画出产业链上下游关系图？能否说出竞争格局与集中度（CR5）？ | 产业链有几层？上游关键设备/材料来自谁？下游客户是谁？前五大玩家是谁、份额多少？ |
| **财务理解** | 能否独立阅读并理解该行业公司的三张报表？ | 营收、毛利率、应收/存货、经营现金流分别在哪张表？关键科目变动意味着什么？ |
| **估值理解** | 能否用**至少 2 种方法**给出估值区间？ | 除 PE/PEG 外，能否再用 PS、EV/Sales、DCF、可比公司法交叉验证？ |
| **技术理解**（**科技股必答**） | 能否说清核心技术路线差异？ | 不同技术路线的原理/成本/适用场景/主流玩家分别是谁？ |

**判定规则（硬编码）**：

```text
IF 普通行业：须「产业理解 + 财务理解 + 估值理解」三项同时通过
ELIF 科技股：上述三项 + 「技术理解」必选；技术理解不过关 → 不得重仓（观察仓或放弃）
IF 任一必需维度未通过：
    → 视为「能力圈之外」→ 淘汰（GF-8 后段），并给出三选一建议：
       ① 补课学习至可独立回答；② 仅作低仓位观察仓跟随；③ 放弃
```

> **落位说明**：框架行 360 将「能力圈自检未通过」列为**买入前一票否决项**，故本技能将其设为**闸门（淘汰层）**而非报告提示项（门禁 **D-1**，已确认）。**自检结论属主观自评**，须在报告中标注「自评项，非工具化判据」（登记为缺口 U4）。

### 2.4 6 硬指标与财务五门槛（含科技豁免）

| # | 硬指标 | 通过标准（GARP 档） | 否决编号 |
| :--: | --- | --- | :--: |
| 1 | 产业景气度 | 季度营收增速 > 行业平均（引用 `garp-industry-research` 业绩兑现维度）；或行业高频数据（排产/价格）连续 2 月环比向上 | — |
| 2 | **财务健康（财务五门槛）** | **营收 ≥10 亿；3 年营收 CAGR ≥15%；资产负债率 <60%（金融/地产除外）；经营性现金流净额为正；近 3 年 ≥2 年扣非净利润为正** | `GF-2` |
| 3 | **估值底线（多工具矩阵）** | 引用 `garp-valuation` 统一六档：**调整后 PEG ≤1.5** 方可入底仓候选；**>1.5 仅机动仓观察**；**>2.0 淘汰出终选**；宏观期按宏观 PEG 区间**动态上浮/下调**（框架第五部分·四） | `GF-3` |
| 4 | 流动性 | **日成交额 >1 亿；市值 <100 亿可放宽至 >3000 万**（框架行 463 同口径） | `GF-4` |
| 5 | 治理底线 | 无立案调查、无大额违规担保、审计意见非「非标」；**ESG 评级处于行业尾部/最低档 → 先降仓位上限**（框架行 432，**不直接折价**） | `GF-5` |
| 6 | **地缘红线（0.3 矩阵 + 赛道两分法）** | **地缘倒逼型**赛道：0.3 矩阵不得归「**高风险/回避**」或「回避」档；**政策资本驱动型**赛道：地缘仅作**敞口体检**（海外收入/供应链/冲突暴露可控），达标与否交由支柱五判定 | `GF-6` |

**科技豁免（框架行 247，替换骨架的「渗透率<5% 放宽现金流」条款）**：

```text
IF 「近 3 年 ≥2 年扣非净利润为正」不过
   AND 扣非为负「仅由研发费用化压低当期利润」所致（非经营恶化）
   AND 同时满足：① 经营性现金流净额为正 ② 营收连续增长 ③ 研发强度 ≥15%
   → 豁免该单项（标记「科技豁免」）并继续；否则淘汰（GF-2）
```

> **豁免边界（刚性）**：科技豁免**只豁免「扣非净利润为正」单项**——**治理底线（`GF-5`）与 ROIC/护城河判定（支柱二）不豁免**；豁免标的须显式标注「依赖科技豁免」并**仅在机动仓观察**，与框架行 247「与第 4 步『未盈利科技型』衔接」对齐。

**其余放宽（有限度，收敛自骨架）**：

- **战略必争卡脖子环节**（框架行 192「<5% 中若属战略必争卡脖子环节（如光刻），可作高风险高弹性的观察/小仓、非回避」）→ 可放宽「经营现金流为正」，须显式标注「烧钱换市场」逻辑，**仅限机动仓观察**；
- 治理瑕疵但非致命（如小额诉讼）→ 须**诚信前置闸门未命中且管理层 ≥15 分**方可豁免，并显式标注风险。

| **四 地缘政治与外部环境** | 外部冲击是否致命？ | **0.3 矩阵行归属 + 赛道两分法**（硬门槛 vs 敞口体检）；时变项（制裁/管制/关税）**须实时核验，勿沿用历史清单** | 框架行 329~341 / 行 163~184；`garp-geo-policy`（P4-1） |
| **五 政策与资本覆盖度**（**新增**） | 政策能否接住？注资是否落到标的？ | ① 该标的获国家/地方产业基金注资**额度占其市值/资本开支比例**；② **资本+场景绑定是否已兑现为可验证订单/收入/量产**（而非框架协议）；③ 相对同赛道竞争者的**政策门槛优势**（强制采购比例 / 部委协同 / 财税优惠） | 框架行 343~348 |

**ROIC 四档（支柱二硬编码，科技股用「调整后核心经营 ROIC」）**：

```text
优秀      : ROIC > 15%      → 最高确信度候选加分项（可支持单只上限上浮至绝对 20%）
合格      : ROIC > WACC 且 ≥10%
部分不达标: 5%~10%（既不否决也不达标）→ 观察仓
一票否决  : ROIC 长期 <5% 且仍在拼命扩产 → 放弃（框架行 269、行 359）
```

**五大支柱汇总判定（框架行 350~375，硬编码，避免各支柱罗列却不收口）**：

```text
一票否决清单（命中任一即放弃/清仓，不进入后续判定）：
  ① 诚信一票否决：兑现率<50%、业绩预告重大失真、财务造假、监管立案
  ② ROIC 长期<5% 却在拼命扩产
  ③ 能力圈自检未通过（尤其科技股「技术理解」不过关不得重仓）
  ④ 0.3 三维矩阵综合归为「回避」档（政策覆盖度低/无 且 国字号基金无覆盖）

达标判定（须全部满足方可建仓）：
  支柱一：景气向上（供需不恶化、单价稳定或上涨、CR5 提升或龙头份额扩大）
  支柱二：ROIC > WACC 且 ≥10%；营收/利润增速匹配；ROE 向上或企稳、毛利率不恶化
  支柱三：科技股「管理层≥15 且 科研转化≥15」；普通行业「管理层≥15」
  支柱四：海外收入/资源供应链/地区冲突暴露可控；「地缘倒逼强度非低/无」仅对地缘倒逼型作硬门槛
  支柱五：政策覆盖度 ≥「中」，且国字号基金介入非「无覆盖」

三档结论：全部达标 → 进入估值锚定（可建仓）；部分不达标 → 观察仓；任一否决命中 → 放弃
```

> **与 0.3 矩阵的映射（防维度拆分歧义）**：支柱四对应 0.3 的「地缘倒逼强度」维；支柱五对应「政策覆盖度 + 国字号基金介入」两维（框架行 354）。

### 2.6 0.3 三维交叉矩阵 + 赛道两分法（**照引框架，共性 3**）

| 地缘倒逼强度 | 政策覆盖度 | 国字号基金介入 | 投资含义 |
| --- | --- | --- | --- |
| 高（已制裁/断供） | 高（超常规+全链条） | 有直接注资 | **最优场景**：替代确定性和节奏均被外部力量锁定 |
| 高 | 中 | 有专项子基金 | **次优场景**：替代方向明确，但节奏受技术突破制约 |
| 中（制裁升级中） | 高 | 有覆盖 | **潜伏场景**：制裁尚未落地但概率高，提前布局等待催化 |
| 高（已制裁/断供） | 低/无 | 无覆盖 | **高风险/回避**：下游被迫替代但国产短期接不住 |
| 低 | 中/高 | 有覆盖/注资 | **政策驱动型增量创造**：达标与否以支柱五为准 |
| 低 | 低 | 无覆盖 | **回避**：替代节奏完全依赖市场驱动，不确定性过高 |

**附带条款（刚性）**：

1. **未列组合**一律按**更审慎的相邻档位**归档，不得因未列而默认放行（框架行 175）；
2. **国字号注资**视为「政策优先序列」信号，**不得作为买入估值依据**（框架行 177）；
3. **时变项**（制裁清单 / 出口管制 / 风险行业 / 国产化率）评估前须**实时核验**（框架行 331），禁用历史清单；
4. **赛道两分法**：地缘倒逼型（半导体设备/材料等）→ 支柱四作**硬门槛**；政策资本驱动型（机器人、信创等）→ 支柱四仅作**敞口体检**；两类非互斥时**按更审慎那类执行**（框架行 179~184）。

### 2.7 估值底线与多工具矩阵（共性 6）

- **唯一档位出口**：`garp-valuation`（P4-5）的**统一六档 + 多工具矩阵**（调整后 PEG / PS·EV-Sales / Rule of 40 / 远期 PE + 隐含 PEG / 研发管线 NPV / DCF）+ **ESG 环境风险折价** + **宏观 PEG 区间**；本技能**不重述档位表、零 PEG 算式**；
- **本技能只落两条阈值**（硬指标 #3 与 `GF-3`）：**1.5 = 高估线**（框架行 383「>1.5 为高估」，>1.5 **不得入底仓**、机动仓择机减）；**2.0 = 淘汰线**（框架行 671「调整后 PEG>2 时加速清机动仓」的上沿，作为**出终选**的硬阈值）；
- **口径披露（如实）**：2.0 淘汰线系由框架「加速清机动仓」条款**操作化**而来（骨架 `F-3` 的 PEG>2.0 亦同源），**非框架原文淘汰条款**；须在《口径隔离声明》登记为**推导口径**；
- **宏观联动**：加息 0.8~1.0 / 中性 1.0~1.2 / 降息 1.2~1.5 / 滞胀 0.8 的 **PEG 区间乘数**经 `macro_calibrator.py` 透传，本技能**不判 stage**；
- **陷阱清单**：低 PE 陷阱 / 高 PE 但增速不可持续 / 忽略股权稀释 / **研发费用化扭曲**（框架行 416~421）。

### 2.8 管理层与科研转化：诚信前置 + 7+7+6（**共性 5**）

```text
诚信前置闸门（不计分，命中即放弃/清仓，不以总分豁免）：
  年报"说到做到"兑现率<50% / 业绩预告重大失真 / 监管立案 / 财务造假实锤
      → 放弃或清仓，不进入 20 分制求和（GF-7）

管理层 20 分制（= 7 + 7 + 6，≥15 可重仓）：
  对待股东 7    ：分红历史（≥30% 为优）、融资记录、回购行为、大股东质押率（>50% 预警）
  战略执行力 7  ：是否聚焦主业、核心战略落地、行业格局认知深度
  稳定性与激励 6：核心团队稳定性（离职率<10%）、股权激励合理性、内部人增减持异常预警

退档规则：10~14 分 → 观察仓（单只上限 ≤5%，不重仓）；<10 分 → 放弃（GF-8）

科研转化 20 分制（科技股叠加，8 + 8 + 4，≥15 可重仓）：
  研发投入"质"与"量"8：研发强度≥15% 且逐年提升、资本化率<30%、研发人员占比≥30%
  研发产出效率 8      ：发明专利数量与质量、新产品收入占比≥20%、产品化周期、重大项目节点
  资本回报效率 4      ：ROIC > WACC；增量资本回报率 > 存量 ROIC
  退档同管理层规则；普通行业不适用科研转化清单时，仅以管理层 20 分制判定
```

> **两种否决的语境边界**：诚信前置闸门 = **持仓后清仓信号**；能力圈未过 / ROIC<5% 扩产 / 0.3 回避档 = **买入前闸门**（框架行 662）。**两套「≥15」为并列门槛，非合计、非加权**。

| :--: | --- | --- | --- |
| **一级 诚信否决** | 管理层诚信问题暴露、财务造假实锤、监管立案 | 立即清仓，不看估值与趋势 | 费雪 |

### 2.10 止损与仓位状态（**引用 `garp-exit`，不重建**）

| 仓位状态 | 跌幅 | 逻辑状态 | 操作 |
| --- | --- | --- | --- |
| **建仓初期**（持仓 < 最终仓位 50% **或** 逻辑未经验证） | −8%~−10% | 任意 | **8%~10% 硬止损离场**（**禁用 ATR**；硬止损优先于「跌破估值下限补仓」） |
| **底仓已建立且逻辑已验证**（持仓 ≥50% **且** 经 2~3 季财报兑现验证） | — | 逻辑完好，仅情绪杀 | 2~3 × ATR(14) 动态跟踪止损，**受 20% 底仓容忍度封顶** |
| 任意仓位 | 任意 | 逻辑证伪（技术路线被替代） | 立即清仓（不等反弹） |
| 持有 > 4 季度 | 横盘 | 逻辑未兑现 | **时间止损**（调仓换股，归入三级） |

> **ATR 止损价一律经 `garp-exit`（P4-6）转接 `momentum.stop_price()`**（内部调用 `atr()`），**禁止心算**；本技能**不自建止损计算链、不新增 CLI 包装**。

### 2.11 底仓/机动仓与阶段化仓位口径

| 仓位类型 | 比例 | 定位 | 操作规则 |
| --- | --- | --- | --- |
| **底仓** | **60%~80%** | 长线核心，赚企业 **1~5 年**成长的钱 | 逻辑未破坏则始终保留；**不因短期 20% 以内波动卖出**；每季度结合财报小幅调整（**±5%**） |
| **机动仓** | **20%~40%** | 平滑波动，赚估值波动的钱 | 股价进入**高估区间**减持，回落至**合理区间**回补 |

**两层口径（框架行 449，防混淆）**：底仓 + 机动仓**之和恒为 100%**，指**股票仓位内部**的切分；现金比例（常态 10%~20%、风险期 20%~30% 或更高、衰退 30%~40%、滞胀 ≥40%）指**占总资产**比例。**执行顺序**：先按宏观/风险预算确定现金占比，剩余部分再按底仓/机动仓切分。

**硬编码上限（框架行 459~463）**：持股 **5~10 只**；单只 **初始 ≤10% / 逻辑验证后 ≤15% / 绝对 ≤20%**（绝对 20% **仅限最高确信度深护城河核心底仓**，且组合内上浮至 20% 的标的**合计 ≤2 只**）；单一行业 **≤40%**；行业相关性 **<0.5**；流动性 **>1 亿**（小市值 >3000 万）；再平衡触发 **±5%**。

> **终选组合表「目标仓位」列**须按**阶段化**标注（初始 / 验证后 / 绝对），**不写固定百分比区间**——骨架「底仓 12%~15%」与框架「单只初始 ≤10%」冲突，须替换（门禁 **H-1**，已确认）。

### 3.3 降级与失败处置

| 情形 | 处置 |
| --- | --- |
| `garp-industry-research` 未跑过 | 提示用户先运行；或本技能内以「引用骨架级快速回填」获取赛道结论，并在报告**显式标注置信度受限** |
| 某市场工具连通失败（港美股接口偶发） | 重试 → 仍失败则标注「未取得」，**不以推测代替实测**；关键数据缺失须降级结论等级 |
| 渗透率 / 国产化率 / 政策清单取不到 | 标注「**未验证**」+ 区间上下限，**不默认落黄金区**；引用 `garp-geo-policy` 的核验入口 |
| 治理/科研打分数据不可得 | 标注「**低置信度**」并给出可得代理指标；**不得**以缺失为由跳过诚信前置闸门 |
| 引擎或工具报错 | 记录**原始报错与退出码**，标注「工具缺陷候选」并登记入待上报事项，**不得静默吞掉** |

### 3.4 风控硬编码（`GF-1`~`GF-12`，本技能新增；已实测全仓 `GF-\d` 命中 = **0**）

| 编号 | 规则 | 不可做的事 |
| --- | --- | --- |
| `GF-1` | 赛道评级非 A/B（引用 `garp-industry-research` 六维结论）→ **终止漏斗** | 不得对不合格赛道执行漏斗 |
| `GF-2` | **财务五门槛**任一不过且**不满足科技豁免** → 淘汰 | 不得以「成长想象」豁免财务底线 |
| `GF-3` | **调整后 PEG >2.0**（或经宏观 PEG 区间调整后对应档）→ 严重透支，**淘汰出终选**；**>1.5 → 不得入底仓**（机动仓观察） | 不得把高估标的纳入底仓 |
| `GF-4` | 流动性不达标（日成交 <1 亿且市值 ≥100 亿；市值 <100 亿时 <3000 万）→ 淘汰 | 不得纳入机动仓 |
| `GF-5` | 治理一票否决（立案调查/大额违规担保/非标审计）→ 淘汰；**ESG 评级行业尾部/最低档 → 先降仓位上限**（不折价） | 不得进入精析；不得以估值便宜抵消治理缺陷 |
| `GF-6` | **地缘倒逼型**赛道 0.3 矩阵归「回避/高风险回避」→ 淘汰；**政策资本驱动型**走**敞口体检** | 不得以「利空出尽」纳入；不得对两类赛道混用同一门槛 |
| `GF-7` | **诚信前置闸门**命中（兑现率<50%/预告失真/监管立案/造假实锤）→ 放弃或清仓 | 不得以管理层总分 ≥15 豁免 |
| `GF-8` | **能力圈自检未通过** → 淘汰；**管理层 <10 分或科研转化 <10 分** → 淘汰（10~14 观察仓；科技股须两套均 ≥15） | 不得让能力圈外标的进入后续层；不得重仓 |
| `GF-9` | 所有估值/市值/PEG/仓位计算必须走 `financial_rigor.py`；ATR 止损价必须经 `garp-exit` 转接 `momentum.stop_price()` | 禁止 LLM 心算；禁止自建止损链 |
| `GF-10` | 终选组合违反仓位上限（单只 >20% / 单行业 >40% / 绝对 20% 标的 >2 只）→ **强制调整** | 不得输出超限组合 |
| `GF-11` | 关键数据单一来源 → 标注「**单一来源，置信度低**」，不得作确定性结论 | 不得以单一来源支撑终选 |
| `GF-12` | 终选标的未经 `garp-investment-checklist` 七关 → **不得视为可买入** | 不得越权替代买入前检查 |

> 所有硬性规则输出必须包含**规则编号引用**（如「触发 `GF-2`」），确保可审计可追溯。
