## 2. 缺省例（无治理关键词）

输入行：

```text
只有一行无关文本
```

期望输出要点：

- 5 个子字段 `confidence` 均为 `"low"`。
- 数值子字段均为 `None`（`esg.found=false`、`esg.excerpts=[]`）。
- `parse_markdown_text` 的 `warnings` 追加治理提示（`大股东质押率未定位到`、`管理层持股未定位到`、`分红/回购未定位到`、`销售组织信息未定位到`、`ESG 信息未定位到`），且既有提示顺序不变。

## 4. 解析口径说明

- 百分比字段（质押率/持股比例/分红率/销售费用率）经 `_pct`/`_pct_after` 解析为**小数**（如 `28.75%` → `0.2875`）。
- 数量字段（经销商数量）经 `_num` 解析（去千分位逗号）。
- `_pct_after` 只取**锚点后带 `%` 的数值**，避免误取"累计质押 10,000 万股"中的 10000；锚点为「占其所持股份 / 占公司总股本 / 占总股本 / 质押比例 / 质押率」「合计 / 占公司总股本 / 占总股本」「占归母净利润 / 占净利润 / 分红率」。
- 本解析器**只抽事实不判档**（不做质押>50% 预警、分红≥30%、持股≥3% 等判定），阈值判定由 `governance_data.py` 承担。
