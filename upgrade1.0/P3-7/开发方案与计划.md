## 0. 结论摘要（TL;DR）

本任务在既有 `tools/common/annual_report_parser.py` 中**新增 `_extract_governance()` 抽取器**，并在 `parse_markdown_text()` 的返回结构中加入顶层 `governance` 字段组，把框架「第 3 步·支柱三」管理层 20 分制与费雪/ESG 补充检查所需的**事实取证**下沉为确定性抽取，供 `governance_data.py`（P3-4/P3-5/P3-6）与 `garp-management`（P4-6）/`garp-valuation`（P4-5）技能取值。

- **输入**：年报 markdown（`pdf_extract` 上游已做乱码检测 + OCR 回退，本解析器不新增 OCR）。
- **输出**：`governance` 字段组，含 5 个子字段（大股东质押率 / 管理层持股 / 分红回购 / 销售组织 / ESG 摘录），每个子字段带 `confidence` + 源文本摘录，缺省 `None`。
- **核心难点**：5 个字段的定位关键词、数值/文本的解析口径、以及 `confidence`（low/medium/high）的判定规则须固化为确定性规则，消除 LLM 临场判断；且必须**不改既有 6 类字段与既有抽取函数签名**。
- **边界**：本工具只做「给定 markdown → 定向抽取事实/摘录」，**不判定事实真伪、不评分**（评分由 `governance_data.py` 承担）。无法确定的字段置 `None` 并在 `warnings` 标注，不猜测。

## 1. 目标与范围

### 1.1 目标

在 `tools/common/annual_report_parser.py` 中新增治理字段抽取，输出以下 5 个治理字段（统一纳入 `governance` 组）：

| # | 字段 | 支撑的框架口径 |
| --- | --- | --- |
| 1 | 大股东质押率 `pledge_ratio` | 支柱三「对待股东」大股东质押率（>50% 预警） |
| 2 | 管理层持股 `management_shareholding` | 支柱三「费雪补充」管理层持股比例（核心管理层 ≥3%） |
| 3 | 分红/回购 `dividend_buyback` | 支柱三「对待股东」分红历史（≥30% 为优）、回购行为 |
| 4 | 销售组织 `sales_organization` | 支柱三「费雪补充」销售组织（销售费用率、经销商覆盖） |
| 5 | ESG 摘录 `esg` | 支柱三「ESG 补充检查」环境/治理/社会相关摘录 |

### 1.2 包含范围

- 新增 `_extract_governance(lines: List[str]) -> Dict` 抽取器。
- `parse_markdown_text()` 新增 `"governance": ...` 顶层字段（同步更新函数 docstring/返回说明）。
- `main()` 默认摘要新增 `governance` 输出；`description` 说明补充「治理」。
- 每个字段带 `confidence`（low/medium/high）与源文本摘录（`source`）。
- 低置信字段缺失时，在 `warnings` 中追加治理相关提示（不猜测）。
- 单元测试（5 字段各自命中/缺省 + confidence 判定 + 源文本摘录 + 既有字段无回归 + JSON 可解析）。

### 1.3 不包含范围（明确排除，防范围蔓延）

- **不含**评分/判定——质押率是否 >50% 预警、分红率是否 ≥30%、持股是否 ≥3% 等阈值判定属 `governance_data.py`（P3-4/P3-6）与技能编排职责，本解析器只抽事实不判档。
- **不含**乱码检测与 OCR 回退——该能力位于上游 `pdf_extract.py`，本解析器输入已是 markdown 文本，不新增 OCR。
- **不改动**既有 6 类字段（`employees`/`subsidiaries`/`rd`/`revenue_segments`/`new_product`/`supply_chain`）的抽取逻辑与输出 Schema。
- **不改动**既有抽取函数签名（`_extract_employees`、`_extract_subsidiaries`、`_extract_rd_section`、`_extract_revenue_segments`、`_text_excerpt`）。
- **不改动** `governance_data.py` / `financial_rigor.py` / `geo_policy_screen.py`（仅作下游消费方参照）。
- **不改动** `.trae/skills/` 下既有技能文件。

## 2. 关键量化口径（唯一权威 = 框架第 3 步·支柱三）

> 以下全部取自《中长期价值成长（GARP）投资框架》第 3 步·支柱三（行 289~318）。任何实现与本文档或总计划/详细计划不一致时，**以框架正文为准**。

### 2.1 治理字段与框架口径映射

| 治理字段 | 框架原文 | 框架位置 |
| --- | --- | --- |
| 大股东质押率 | 大股东质押率（>50% 预警） | 支柱三·管理层 20 分制「对待股东」 |
| 管理层持股 | 核心管理层是否持有公司 ≥3% 的股份 | 支柱三·费雪补充检查 |
| 分红/回购 | 分红历史（≥30% 为优）；回购行为 | 支柱三·管理层 20 分制「对待股东」 |
| 销售组织 | 经销商覆盖率、销售费用率变化 | 支柱三·费雪补充检查「销售组织出色」 |
| ESG 摘录 | 环境(E)/治理(G)/社会(S)/ESG 评级参考 | 支柱三·ESG 补充检查 |

> **本解析器职责**：抽取上述事实的**数值或文本摘录**，不带阈值判定。例如质押率抽 `0.28`（小数），不做「是否 >0.50」的预警判定；分红率抽每年数据，不做「是否 ≥30%」判定。

### 2.2 数值口径统一约定

- 百分比字段（质押率 / 分红率 / 销售费用率 / 持股比例）统一用既有 `_pct()` 解析，返回**小数**（如 `28.75%` → `0.2875`）。
- 数量字段（经销商数量）用既有 `_num()` 解析（去千分位逗号）。
- 所有数值字段解析失败时返回 `None`，不猜测、不回退为文本近似值。

## 3. 输入/输出签名

### 3.1 输入

- `lines: List[str]`：年报 markdown 按行切分后的字符串列表。
- 由 `parse_markdown_text(text)` 内部 `text.splitlines()` 生成，本任务不新增外部输入参数与 CLI 参数。

### 3.2 输出（`governance` 字段组）

新增顶层字段 `governance`，结构如下（推荐结构，§9.A 待确认）：

```json
{
  "pledge_ratio": {
    "holder_name": null,
    "pledge_ratio": null,
    "confidence": "low",
    "source": ""
  },
  "management_shareholding": {
    "holding_ratio": null,
    "excerpt": null,
    "confidence": "low",
    "source": ""
  },
  "dividend_buyback": {
    "dividend_payout_ratio": null,
    "buyback_excerpt": null,
    "confidence": "low",
    "source": ""
  },
  "sales_organization": {
    "selling_expense_ratio": null,
    "distributor_count": null,
    "confidence": "low",
    "source": ""
  },
  "esg": {
    "found": false,
    "excerpts": [],
    "confidence": "low",
    "source": ""
  }
}
```

字段说明：

| 字段 | 子字段 | 类型 | 说明 |
| --- | --- | --- | --- |
| `pledge_ratio` | `holder_name` | str\|null | 质押股东名称/称谓 |
| | `pledge_ratio` | float\|null | 大股东质押率（小数，`_pct` 解析） |
| `management_shareholding` | `holding_ratio` | float\|null | 核心管理层/董监高合计持股比例（小数） |
| | `excerpt` | str\|null | 持股相关文本摘录 |
| `dividend_buyback` | `dividend_payout_ratio` | float\|null | 现金分红率（小数） |
| | `buyback_excerpt` | str\|null | 回购相关文本摘录 |
| `sales_organization` | `selling_expense_ratio` | float\|null | 销售费用率（小数） |
| | `distributor_count` | float\|null | 经销商数量（家） |
| `esg` | `found` | bool | 是否命中 ESG 关键词 |
| | `excerpts` | list[str] | ESG 相关文本摘录（最多 8 条） |

每个子字段公共字段：

| 公共字段 | 类型 | 说明 |
| --- | --- | --- |
| `confidence` | str | `low`/`medium`/`high` |
| `source` | str | 源文本摘录（命中时非空，未命中为空串） |

> 缺省语义：任一字段**未命中**时，其数值子字段为 `None`（或空 `[]`/`false`）、`confidence="low"`、`source=""`，与既有抽取器一致（不存在整体返回 `None` 的对象）。

### 3.3 置信度判定规则（§9.B 待确认）

| 字段 | `low` | `medium` | `high` |
| --- | --- | --- | --- |
| `pledge_ratio` | 未命中任何质押关键词 | 命中关键词但未解析出质押率数值 | 解析出质押率数值（+ 股东名） |
| `management_shareholding` | 未命中持股关键词 | 命中关键词、仅有文本摘录无数值 | 解析出持股比例数值 |
| `dividend_buyback` | 未命中分红/回购关键词 | 命中分红或回购其一，无分红率数值 | 解析出分红率数值（+回购摘录） |
| `sales_organization` | 未命中销售组织关键词 | 命中销售费用率或经销商其一 | 销售费用率 + 经销商数量至少一个数值且另存摘录 |
| `esg` | 未命中 ESG 关键词 | 仅命中关键词、无有效摘录 | 命中关键词并产出有效摘录（≥1 条） |

## 5. 实现设计（五步，与详细计划对齐）

### 5.1 数据模型

- `_extract_governance(lines) -> Dict`：组装 §3.2 的 `governance` 组。
- 内部 5 个小抽取逻辑：`_g_pledge`、`_g_shareholding`、`_g_dividend_buyback`、`_g_sales`、`_g_esg`（可按需合并为单函数内分支，保持简洁）。

### 5.2 各字段抽取规则（实现步骤①/②，§9.C~D 待确认详细关键词）

**字段 1 大股东质押率 `pledge_ratio`**

- 定位关键词（命中即进入候选区）：`质押`、`股份质押`、`质押及冻结`、`累计质押`。
- 取值策略：在候选行内用 `_pct()` 解析「占其所持股份比例 / 占总股本比例」附近百分比；优先取「控股股东」「实际控制人」相关行的质押比例。
- `holder_name`：取关键词行中「控股股东」「实际控制人」或首个公司/自然人名称前缀（若可稳定提取）。

**字段 2 管理层持股 `management_shareholding`**

- 定位关键词：`董监高持股`、`董事、监事、高级管理人员持股`、`管理层持股`、`核心管理层持有`。
- 取值策略：`holding_ratio` 用 `_pct()` 取「合计持股比例/占公司总股本比例」；`excerpt` 存相关文本摘录。
- 未解析出比例时 `holding_ratio=None` 但保留 `excerpt`（confidence=medium）。

**字段 3 分红/回购 `dividend_buyback`**

- 分红定位：`现金分红`、`利润分配`、`每 10 股派`、`分红`。
- 回购定位：`回购`、`股份回购`、`回购股份`。
- `dividend_payout_ratio`：取「现金分红/归母净利润」占比或「每 10 股派」折算（仅当能解析出比例时填，否则 None）。
- `buyback_excerpt`：回购关键词行文本摘录。

**字段 4 销售组织 `sales_organization`**

- 销售费用率定位：`销售费用率`、`销售费用占营业收入比例`。
- 经销商定位：`经销商`、`经销`、`渠道数量`。
- `selling_expense_ratio` 用 `_pct()`；`distributor_count` 用 `_num()`（家）。

**字段 5 ESG 摘录 `esg`**

- 直接复用 `_text_excerpt(lines, ("ESG", "环境、社会及治理", "社会责任", "可持续发展", "环境信息"))`。
- 产出 `{found, excerpts}` 后并入 §3.2 结构。

### 5.3 缺省与警告（实现步骤③）

- 5 个字段中任一 `confidence == "low"`，在 `parse_markdown_text` 的 `warnings` 追加对应提示（如「大股东质押率未定位到」「分红/回购未定位到」…）。
- 既有 6 类字段的 `warnings` 顺序与文案保持不变（治理警告追加在其后），避免「既有字段输出无回归」被破坏。

### 5.4 组装接线（实现步骤④）

- `parse_markdown_text()` 新增一行 `governance = _extract_governance(lines)`，返回值增加 `"governance": governance`。
- `main()` 默认摘要 `print(_brief("治理", result["governance"]))`；`description` 补「治理」。

### 5.5 样例（实现步骤④）

- **命中例**：构造含质押率、分红、回购、经销商、ESG 的行，断言各数值与摘录正确。
- **缺省例**：不含治理关键词 → 5 字段 `confidence=low`、数值 None、warnings 追加。

### 5.6 回归空白（实现步骤⑤）

- 未改动既有 6 类字段逻辑与既有抽取函数签名。
- 既有测试 `tests/common/test_annual_report_parser.py` 中 7 个测试类全部保持通过。

## 7. 风险与依赖

| 类型 | 内容 | 应对 |
| --- | --- | --- |
| 抽取不确定性 | 年报披露格式多样（质押/分红/持股表述口径不一），关键词可能漏配 | 多关键词命中 + confidence 分级标注；不追求 100% 覆盖，未命中置 None + warning |
| 数值精度 | 比例与数量在表格/正文表述不一 | 复用 `_pct`/`_num`；解析失败回 None，不猜 |
| 范围蔓延 | 误把阈值判定（质押>50% 预警等）塞进解析器 | §1.3 明确排除，评分交 `governance_data.py` |

| 依赖风险 | 与 `governance_data.py` 字段契约不一致 | 本方案 §3.2 字段命名与 P3-4/P3-6 输入参数对齐，逐项对照 |
