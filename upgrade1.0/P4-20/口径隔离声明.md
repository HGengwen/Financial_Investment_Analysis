## 5. 文件与命名隔离

### 5.1 三档物理隔离条款

| 档位 | 报告路径 | 文件命名前缀段 | 隔离条款 |

### 5.2 ⚠️ 子串包含披露（`GPC-12`，刚性）

> **子串包含披露**：字符串 `-private-` **是** `-garp-private-` 的**子串**（`-garp-private-` 中 `-private-` **起始于第 5 字符**，即 **0-based index = 5**；同理 `-private-` 是 `-mid-private-` 的子串，0-based index = 4）。因此**纯子串检索 `-private-` 会同时命中三档报告**；三档隔离核验**必须使用完整前缀段（`garp-private` / `mid-private` / `private`）或按目录级**核对，**禁止以 `-private-` 单串计数下结论**。

> 该披露在 `SKILL.md`（第 552 行）与 `README.md`（第 128 行）**逐字一致**；本声明 §5.2 与之同源。

### 5.3 同名多版本

- 同日多版本：`-v2` / `-v3` 后缀，**不覆盖首版**；版本差异须在报告头部标注。
- 目录 `reports/{公司名}/` 不存在则创建；**只读上游、不写回**。

## 9. 只读边界与不写回上游

### 9.1 输出边界（本技能**不回答**什么）

| 项 | 声明 |
| --- | --- |
| **不回答「当前一级市场是否买入」** | 本技能输出的是「**上市前预研建档 + 上市后判断框架**」，**不是「当前一级市场是否买入」的指令**（`GPC-12`） |
| **不含指令性数值** | 报告**不得**出现「目标仓位 X%」「减至 X%」「清仓」「ATR 止损价」等指令性数值；权威判定归 `garp-valuation` / `garp-exit` / `garp-portfolio-review`（`GPC-10`） |
| **不判定卖出级别** | 只做「上市后若持有，触发时应转 `/garp-exit` 复核」的**预提醒**；**不判定级别、不计算止损价** |
| **不重算估值档位** | **零档位阈值定义、零档位重算**；上游结论不可得时**仅呈现原始指标、不下档位结论**（`GPC-9`） |

### 9.2 不写回上游文件条款

- `reports/{公司名}/` 下既有 `-garp-*` / `-mid-private-*` / `-private-*` 文件：**只读不写回**；
- `reports/` 下 `-garp-industry-` / `-garp-era-*` 等其他档位产物：**只读不写回**；
- 全部白名单出口技能（`garp-geo-policy` / `garp-macro` / `garp-investment-checklist` / `garp-management` / `garp-valuation` / `garp-exit` / `garp-portfolio-review` / `garp-thesis-tracker` / `garp-thesis-drift`）：**一律只读取回结论，不回写、不改写、不新增其文件**；
- `tools/` 下任何工具（41 个 `.py`）：**零写操作**（本技能只做调用编排，**不改签名、不新增命令行开关**）；
- 三档**互不写回**：本技能**不写回** 1~3 年中期链与 10 年长期链产物。
