## 1. 目标与范围

### 1.1 目标

产出 GARP 独立档（**1~5 年**）的**未上市公司研究**技能 `/garp-private-company-research {公司名}`，并做到——

1. **双结论刚性收口**（验收要点）：报告须**并列**输出「**是否值得等待上市**」（✅ 值得等待 / ⚠️ 有条件等待 / ❌ 不值得等待 / ❓ 需要更多信息）与「**上市后是否适用 GARP 框架**」（适用 / 有条件适用 / 不适用）两个判定；**任一缺失即不合格**（`GPC-1`）。
2. **五大师 + 费雪质化注入 6 路 Agent**（共性 1 + 验收要点）：设计理念由骨架「四位景气大师」**扩为五大师**（**费雪 / 林奇 / 郑希 / 李进 / 欧奈尔**）；**费雪三问**刚性落位**至少四处**（需求真实性 / 销售组织 + 管理层持股 ≥3% / 暂时性困难 vs 永久性衰退 / 上市后持有信念边界）；**保持 6 路并行**，**不新增第 7 路 Agent**（`GPC-7`）。
3. **共性口径七处替换全命中**：共性 1（五大师）为**点名差异**；共性 2/3/4/5/6/7 为**连带替换**（§7.2 刚性要求）；逐项对照见 §4.4。
4. **渗透率按 GARP 黄金窗判定**（共性 2）：渗透率位置判定由骨架「`15%~30%` 黄金加速区」改为 **`15%~40%` 五档** + **TAM ≥1000 亿**；**<5% 且无 EPS/订单支撑 → 判题材**；每个环节**并列标注国产化率四梯队档位**（只读 `localize`）（`GPC-4`）。
5. **口径零复制（引用不重复定义）**：渗透率 / 国产化率 / 财务五门槛 / 科技豁免 / ROIC 四档 / 管理层 7+7+6 与科研转化 8+8+4 / 诚信前置闸门 / 三维交叉矩阵 / 多工具估值矩阵 / ESG 折价 / 宏观三表 / 五级卖出 / 仓位纪律 / ATR 止损 / 暂时性困难 vs 永久性衰退 / 六类分类**一律引用**（指向框架章节号或 `garp-*` 技能出口或工具命令），本技能**只定义流程与编排**。
6. **三档并存路由隔离**：技能内引用**只指向** `garp-*` 系列；**禁止**引用 1~3 年中期链（`mid-*`）与 10 年长期链（`private-company-research` / `investment-research` / `dyp-*`）技能；**禁止**出现 `--horizon`、`P0~P5`、`mid-private-company-research`、`-mid-private-`、`-private-`（作为**独立报告前缀**）等档位切换类口令与跨档路径（`GPC-12`）。
7. **风控硬编码 `GPC-1`~`GPC-12`**：骨架**无编号化风控**（仅「注意事项 13 条 + 局限性 7 条」），本技能**新建编号族**并附**骨架条款 → `GPC-` 逐条映射表**，保持「一技能一编号族」定例与三档隔离。
8. **零新增 CLI、引擎零改动**：`tools/common/*` 与 `tools/specialized/*` **不改签名、不改行为、不新增子命令**；估值档位经 `garp-valuation` 转接、卖出阈值经 `garp-exit` 转接、管理层计分经 `garp-management` 转接、地缘矩阵经 `garp-geo-policy` 转接；本技能不自建档位链 / 止损链 / 计分链 / 地缘评分链；**禁用** `terminal_value.py`。
9. **「建档预判」而非「下指令」的刚性边界**：本技能输出**上市后 GARP 适配性判断 + 建档清单 + 上市后跟踪动作**；**不回答**「当前一级市场是否买入」；**不含**目标仓位 / 减仓百分比 / ATR 止损价等指令性数值；买入前须执行 `/garp-investment-checklist`（P4-3，**已交付**）。
10. **报告路径 + 命名规约 + 四基准**：产出 `reports/{公司名}/{公司名}-garp-private-{YYYYMMDD}.md`，报告头部必注明**四基准**（数据 / 估值 / 资料 / 口径），见 §2.12。
11. **双门禁 + 七项交付件**：开工门禁 A~H（本文件 §9）+ 完成门禁留痕（详细计划 §0.7）；交付件严格对齐 §0.5「技能类七项」。

### 2.4 渗透率黄金窗 + 第一性原理模式（共性 2 + **核心差异**）

| 档位 | 判定 | 行动含义（只读框架第 1 步） |
| --- | --- | --- |
| **<5%** | 导入早期 | 观察不建仓；**<5% 且无 EPS/订单支撑 → 判题材** |
| **5%~15%** | 突破期 | 高弹性，小仓跟踪 |
| **15%~40%** | **加速上行期（黄金窗口）** | **主建仓窗口** |
| **40%~60%** | 逐步兑现期 | 持有，不再新建仓 |
| **>60%** | 天花板 | 即便增速未转负也不加仓 |

- **TAM 闸门**：**TAM <1000 亿 → 黄金窗判定不成立**，须显式标注。
- **国产化率四梯队**（<5% 过早 / 5%~20% 突破期 / 20%~50% 加速投资期 / >50% 替代空间收窄）：**只读** `garp-geo-policy` `localize`，本技能**不自评、不定档**；**>50% 档位不淘汰**但须标注「逻辑转向龙头份额提升与整机放量」。
- **数据纪律**：渗透率 / 国产化率数据须注明**来源与年份**；双源误差 >5pct 标**低置信**（§4.5 **G18**）。
- **第一性原理模式（骨架承接，C 级信息稀缺专用）**：四问**逐问必答**——
  1. 这门生意解决什么真实问题？**需求是真需求还是伪需求？**（费雪）
  2. 赛道渗透率在什么位置？**是否落在 `15%~40%` 黄金窗？TAM 是否 ≥1000 亿？**
  3. 如果上市，**估值潜力**在哪一档？（**只读** `garp-valuation` 统一六档）
  4. 最大的「逻辑证伪」信号是什么？（**只读** `garp-exit` 五级卖出）

## 3. 执行流程与工具编排

### 3.1 执行流程（七步，骨架承接）

#### 第一步：确认参数与信息可得性分级（骨架第一/二步合并前置）

- **参数确认**：公司名（中文/英文）、**拟上市市场**（A 股/港股/美股/其他）、**融资阶段**（Pre-IPO / 已递表 / 辅导备案 / 暂无计划）、**研究侧重**（商业模式 / 财务与估值 / 竞争格局 / 管理层 / 技术 / 上市时机）。
- **刚性**：信息不足时**先反问，不默默假设**（`GPC-1`）。
- **信息可得性分级**：**A 级**（已递表/有招股书/母公司披露多）→ 降噪与交叉验证；**B 级**（有融资记录/部分覆盖）→ 标准模式 + 每关键数据 1~2 独立信源；**C 级**（早期/冷门/无招股书）→ **第一性原理模式**（§2.4 四问）+ 替代数据。
- **分级须告知每一路 Agent**，影响其检索策略与置信度标注（`GPC-3`）。

#### 第二步：同一条消息并行启动 6 路 Agent（`GPC-2`）

- 使用 Task 工具**同一条消息**并行调用 **6 次**；`subagent_type` = `general_purpose_task`。
- 每路任务描述模板须含：**角色** + **研究背景（GARP 独立档 1~5 年·五大师）** + **任务** + **研究要求** + **研究方法** + **搜索工具规范** + **数据标注规范** + **输出要求（含 GARP 适配性初步判断 + 费雪三问）**。
- 六路分工见 §2.3 表。

#### 第三步：接收报告并跟踪进度

- 向用户实时展示进度表；每收到一份报告更新进度并展示**核心要点 3~5 条**；等待 **6 份报告全部到齐**。

#### 第四步：交叉验证与信息拼图（team-lead 执行）

- 三轮校验见 §2.11；**GARP 信号收敛检验**须显式写出；**冲突优先采信冲突信号**。

#### 第五步：双结论收口（**本技能核心差异**，`GPC-1`）

| 结论 | 档位 | 判据来源 |
| --- | --- | --- |
| **是否值得等待上市** | ✅ 值得等待 / ⚠️ 有条件等待（列 X/Y/Z 条件）/ ❌ 不值得等待 / ❓ 需要更多信息（列缺口） | 五维判断表（商业模式可理解性 / 增长可持续性 / 上市后估值潜力 / 管理层可信度 / 行业景气方向） |
| **上市后是否适用 GARP 框架** | 适用 / 有条件适用 / 不适用 | ① 六类分类（缓慢增长型 → 不适用）② 诚信前置闸门命中 → **不适用**（停）③ 地缘回避档 → **不适用**（停）④ 渗透率与 TAM 闸门 ⑤ 财务五门槛（科技豁免）⑥ 上市后估值潜力档位 |

- **两个结论并列呈现、不得互相替代**；判据须**逐条列名**，不得只给结论。

#### 第六步：汇总最终报告（十六节结构，§5.2）

- 按 §5.2 报告模板输出；**五大师透镜结论汇总**须**逐位两列**（追问 → 结论），五位缺一即不合格。

#### 第七步：保存报告与审核

- 写入 `reports/{公司名}/{公司名}-garp-private-{YYYYMMDD}.md`（目录不存在则创建）。
- **发布审核（报告保存后必须执行）**：

```bash
# Step 1 - 提取抽检清单
python tools/common/report_audit.py extract \
  --report reports/{公司名}/{公司名}-garp-private-{YYYYMMDD}.md

# Step 2 - 对清单每项从可靠信源取数交叉验证
#   估值/财务计算验算：python tools/common/financial_rigor.py（禁止 LLM 心算）
#   跨币种折算：python tools/common/fx_rate.py --code USDCNY（或 HKDCNY）

# Step 3 - 输出准出/打回判决
python tools/common/report_audit.py verdict \
  --results '<verified JSON>' \
  --report reports/{公司名}/{公司名}-garp-private-{YYYYMMDD}.md
```

- **【准出】** 全部通过 → 报告可发布；**【打回】** 修正后重审；**保留未解决缺口**（降低置信度，不用假设填充）。
- **Windows 兼容**：不用 `/tmp/`（用 `%TEMP%` 或工作目录）；不用 `2>/dev/null`（PowerShell 用 `2>$null`）；不用 `tr -d '\r'`。
