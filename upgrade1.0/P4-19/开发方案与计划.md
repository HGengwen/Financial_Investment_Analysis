## 1. 目标与范围

### 1.1 目标

产出 GARP 独立档（**1~5 年**）的**时代α捕手**技能 `/garp-era-alpha {行业/方向}`，并做到——

1. **时代主线按 GARP 渗透率黄金窗收敛**（验收要点 1）：时代主线认知地图的每个候选环节须标注「**渗透率 `15%~40%` 黄金窗五档档位**」+「**TAM 是否 ≥1000 亿**」+「**国产化率四梯队档位**」（科技赛道专用）；**只有同时满足「渗透率落在 15%~40% 加速上行期」且「TAM ≥1000 亿」**的环节，才可进入「时代主线」候选并进入第二步（`GEA-2`）；`<5%` 且无 EPS/订单支撑 → **判题材**（`GEA-1`）。
2. **核心 α 五大师交叉验证**（验收要点 2）：第三步景气可持续性验证在骨架「四大师透镜」之上**扩为五大师**（**费雪 / 林奇 / 郑希 / 李进 / 欧奈尔**），并**刚性要求**：核心 α 须**逐位**通过五大师透镜追问；**五大师透镜与五维验证结论冲突时，优先采信冲突信号**并在报告第三节显式写出（`GEA-11`）。
3. **共性口径七处替换全命中**：共性 1（五大师）与共性 2（渗透率 `15%~40%` + 国产化率）为**点名差异**；共性 3/4/5/6/7 为**连带替换**（§7.2 刚性要求）；逐项对照见 §4.4。
4. **口径零复制（引用不重复定义）**：渗透率 / 国产化率 / 财务五门槛 / 科技豁免 / 能力圈自检 / ROIC 四档 / 管理层与科研转化 / 估值矩阵 / ESG 折价 / 三维交叉矩阵 / 宏观三表 / 五级卖出 / 仓位规则 / ATR 止损 / 暂时性困难 vs 永久性衰退 / 五大师矛盾化解**一律引用**（指向框架章节号或 `garp-*` 技能出口或工具命令），本技能**只定义流程与编排**。
5. **三档并存路由隔离**：技能内引用**只指向** `garp-*` 系列 + 复用 2 技能（`qoq-accelerator`、`trend-momentum-scan`）；**禁止**引用 1~3 年中期链（`mid-*`）与 10 年长期链（`era-alpha` / `industry-*` / `dyp-*`）技能；**禁止**出现 `--horizon`、`P0~P5`、`mid-era-alpha`、`{方向}-era-alpha-` 等档位切换类口令与跨档路径。
6. **风控硬编码 `GEA-1`~`GEA-12`**：骨架**无编号化风控**（仅「注意事项 7 条 + 局限性 8 条」），本技能**新建编号族**并附**骨架条款 → `GEA-` 逐条映射表**，保持「一技能一编号族」定例与三档隔离。
7. **零新增 CLI、引擎零改动**：`tools/common/*` 与 `tools/specialized/*` **不改签名、不改行为、不新增子命令**；估值档位与卖出阈值**经 `garp-valuation` / `garp-exit` 转接**，本技能不自建档位链、不自建止损链；**禁用** `terminal_value.py`（十年 DCF，长期链口径）。
8. **「识别与纪律」而非「下指令」的刚性边界**：本技能输出**核心 α 名单 + 介入条件 + 退出纪律（拐点清单）**；买入前须执行 `/garp-investment-checklist`（P4-3，**已交付**）；**组合层仓位数值裁决归 `garp-portfolio-review`**（P4-8，已交付），本技能只出**相对动作**与**框架既有仓位上限的只读复述**。
9. **报告目录 + 命名规约 + 四基准**：产出按方向名分目录的 4 类文件，报告头部必注明**四基准**（数据 / 估值 / 资料 / 口径），见 §2.12。
10. **双门禁 + 七项交付件**：开工门禁 A~H（本文件 §9）+ 完成门禁留痕（详细计划 §0.7）；交付件严格对齐 §0.5「技能类七项」。

### 2.13 数据来源与置信度

- **双源验证**：非境内上市关键数据按市场矩阵双源（港股 `doubao` + `tavily`；美股 `exa` + `doubao`）；误差 >1% 显式标记。
- **日韩台供应商必搜**：避免英文偏好遗漏日台厂商（骨架 AI 偏见自觉承接）。
- **时效性优先**：搜索须用 `--time-range month/week` 限定范围；高频数据为**修正二核心**，过时数据须标注时效性说明。
- **置信度标注**：渗透率 / 国产化率按 A / B / C 三级；C 级**不得**作确定性结论。
- **诚实声明**：关键出货量 / 价格 / 订单 / 渗透率数据缺失时写「信息不足」，**不得**用推测填充（`GEA-9`）。

## 3. 执行流程与工具编排

### 3.1 执行流程（五步 + 前置 A/B）

#### 前置 A：日期与市场确认

- 运行 `date` 确认当天日期，作为「最新数据」基准；报告头部标注数据截止日期。
- 确认目标方向所属市场（A 股 / 港股 / 美股 / 跨市场），选择对应数据工具与搜索工具组合。
- **方向含糊（跨度过大）→ 先反问澄清**（§3.3 #1）。

#### 前置 B：地缘政策前置闸门（**核心差异**）

- **只读** `garp-geo-policy`（P4-1，**已交付**）的 **0.3 三维交叉矩阵**结论 + **赛道两分法**归属（地缘倒逼型 / 政策资本驱动型）+ **国产化率四档** + 敞口体检。
- **回避档 → 终止扫描**（`GEA-5`），不进入五步。
- 不可达 → 降级改指框架**第0步·0.3**（行 87~186），报告标注「结论未取回」（§3.3 #4）。

#### 第一步：时代主线认知地图（§2.3）

- 建立「主线-产业链」认知地图，逐环节填 7 项（渗透率档位 / 产业空间 / 商业模式 / 竞争格局 / 地缘结论（只读）/ 国产化率梯队（只读）/ 核心 α 候选）。
- 信息源以一手资料为主；**产出环节表 + 2~3 个核心环节选择理由**（修正一）。

#### 第二步：自问核心问题（§2.4 收敛闸门）

- 用第一步数据回答，**禁止引用「市场共识」「机构观点」作为论据**：
  1. 当下这条主线**最核心、景气最确定**的环节是什么？（数据：渗透率档位、增速、订单能见度、业绩兑现度）
  2. 该环节的**核心 α 是谁**？（定价权 / 景气壁垒 / 增长质量）
  3. **为什么是它而不是老二？**（须能一句话说清 α 与 β 的差别）
- **收敛闸门**：候选环节须通过 §2.4 三条闸门（渗透率 `15%~40%` + TAM ≥1000 亿 + 业绩兑现），否则降级为「观察环节」。
- **产出**：1~3 家核心 α + 明确「为什么是它」论证。

#### 第三步：景气可持续性验证（五维 + 五大师 + 管理层只读）

- §2.5 五维逐项验证（财报 + 高频数据 + 行业景气 + 竞争格局 + 地缘/宏观只读）；
- §2.6.1 五大师透镜（**逐位**）+ 冲突优先采信；
- §2.6.2 管理层与科研转化**只读** `garp-management`；
- **矛盾信号必须明示**（`GEA-3`）。

#### 第四步：估值锚点与介入（§2.8，必做，不可跳过）

1. 档位**只读** `garp-valuation` 六档结论 + 宏观校准后 PEG 区间；
2. 增速与估值匹配（二阶导引用 `qoq-accelerator`，区分单季波动与趋势性拐点）；
3. 结论三选一：**低估/合理可介入** · **偏贵但景气可消化可持有或分批** · **严重透支只看不买**；
4. 介入方式三选一或组合：分批建仓 / 左侧布局 / 右侧重仓（止损线**只读** `garp-exit`）；
5. **全部算术经 `financial_rigor.py`**（`GEA-8`）。

#### 第五步：持仓与退出纪律 + 输出与准出（§2.9 / §2.10）

- 底仓/机动仓**只读**框架第三部分·一/二；三层拐点清单逐条写明「观察什么数据、多久看一次」；
- 五级卖出**只读** `garp-exit`（命中一级/二级醒目标注「立即转 `/garp-exit`」）；
- 五大师冲突化解（§2.10）；
- 输出报告（§2.12.1 四类文件）+ **`report_audit.py` 抽检准出**（不通过不得发布）。
