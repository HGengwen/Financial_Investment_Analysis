## 1. 目标与范围

### 1.1 目标

产出 GARP 独立档（**1~5 年**）的组合管理技能 `/garp-portfolio-review {持仓清单}`：输入持仓清单（比例形态或数量+成本形态），输出**组合层**的合规校验与调仓建议，做到——

1. **底仓/机动仓两层口径落地**：底仓 60%~80% / 机动仓 20%~40% 指**股票仓位内部**切分；现金比例（常态 10%~20%、风险期 20%~30% 或更高）指**占总资产**，两者**不得混用**；
2. **单只/单行业上限逐只逐行业硬校验**：单只初始 ≤10% / 验证后 ≤15% / 绝对 ≤20%（**绝对档全组合 ≤2 只**）；单一行业 ≤40% 并**随宏观四档收紧**（衰退 ≤30% / 过热 ≤25% / 滞胀 ≤20%）；
3. **四项组合层专有校验**：行业相关性 <0.5、流动性（日成交额 >1 亿，小市值可放宽至 >3000 万）、ESG 环境/评级风险 → **仓位上限下调**、ATR 关联（逐只 `atr14` + 组合波动概览 + 止损价引用 `garp-exit` 权威）；
4. **宏观三表调档**：现金下限与单只/行业上限按美林四档（衰退/复苏/过热/滞胀）**只读上游工具值**收口，**禁 LLM 心算**；
5. **五级卖出优先于再平衡**：命中五级任一即处置，**不受 ±5% 再平衡阈值束缚**；
6. **结论明确**：组合整体健康度四档（优秀/良好/需要调整/问题严重）+ 最该做的一件事 + 当前最大风险。

单只上限的宏观收紧档（**只读 `macro_calibrator`**）：

| 宏观阶段 | 初始 | 验证后 | 绝对 | 现金（占总资产） |

### 2.5 相关性（<0.5）

- 口径：**持有的行业之间相关系数 <0.5**（框架行 463，示例：消费+科技+医药 优于 纯科技赛道内多只）；
- **无工具**（既有工具链**不含**相关系数计算）：本技能采用**行业/主题暴露矩阵 + 反证清单**的**定性**方式，输出「同向共振风险」清单，**不得伪造数值相关系数**；
- 须回答四问（沿用中期骨架 L407 引用的长期清单）：同主题/同行业暴露是否 >50%、同国家/货币暴露是否 >50%、中美关系恶化亏多少、全球衰退亏多少。

### 2.6 流动性（>1 亿）

| 项 | 口径 |
| --- | --- |
| 基准 | 持有标的**日成交额 ≥ 1 亿元**（框架行 464） |
| 放宽 | **小市值可放宽至 >3000 万元**（须**显式标注「小市值放宽」并给出市值依据**） |
| 度量 | **近 20 个交易日均值**（待确认点 D；均值须经 `financial_rigor.py calc` 精确计算，零心算） |
| 数据字段 | A股 `stock_quote.py --code {代码}` → `amount`（元，**已实测**）；港股 `stock_quote.py --code {代码}` → `amount`（**港元**，已实测）；美股 `stock_quote.py --daily {代码} --start YYYY-MM-DD --end YYYY-MM-DD`（**参数为 `--daily`、日期须带连字符**，已实测参数名；**数据源本次复测超时，见 §4.5 U3**） |
| 币种 | 港股/美股须经 `fx_rate.py --code HKDCNY / USDCNY` 折算为人民币后与 1 亿阈值比较（**先折算再比较**） |

### 2.7 ESG 仓位上限下调（先降档，再叠加宏观）

- 口径：ESG 评级处于行业尾部/最低档、或环境风险高 → **先下调仓位上限**而非只调估值（框架行 316、433、439）；
- 工具出口：`governance_data.py esg --env-risk-level {高/中/低} --stranded-asset --esg-tail` → `discount_factor` / `position_cap_after` / `position_cap_downgrade`（P4-7 R07 已实测）；
- **叠加顺序（待确认点 E）**：**先 ESG 降档 → 再按宏观收紧 → 取二者更严者**（与 P4-5 开工门禁 C-2「先 ESG 后宏观」**同序**，保持框架内一致）；
- **纪律**：上限值**只读透传**，技能层**禁止**自行估算折价率或降档幅度。

### 2.8 ATR 关联（引用 `garp-exit` 权威，不重算）

| 项 | 口径 |
| --- | --- |
| 框架原文 | **止损价 = 买入价 − (2~3) × ATR(14)**，仅用于**底仓已建立且逻辑已验证**后（框架行 470） |
| 数据 | `stock_quote.py {市场} --code {代码} --momentum` → `atr14`（A股已实测 = 25.97） |
| 止损价权威 | **`tools/common/momentum.py` 的 `stop_price()`（内联模块调用）**——P4-6 已实测：`momentum.py` **无可用 CLI**（`--help` 无输出、退出码 0 的**静默失效**），且 `round(atr14,2)×乘数` 与 `stop_price()` 存在 **0.01 元口径差** → **`stop_price()` 为唯一权威** |
| 本技能职责 | ① 逐只呈现 `atr14` 与「ATR 占现价比例」（度量组合波动）；② 引用 `garp-exit` 给出的止损价；③ **禁止**自行乘算止损价（`GP-11`） |

### 2.9 再平衡（±5%，且不覆盖卖出纪律）

- 触发：**每季度末**检查组合，单只占比**偏离目标 ±5%** 时再平衡（框架行 466）；
- **优先级（刚性）**：**五级卖出 > 再平衡**——命中五级任一级的标的，**直接按 `garp-exit` 处置**，不得以「偏离未达 ±5%」为由延后（`GP-2`）；
- 再平衡方向：将占比升高者适当减持、补至占比下降者，**不追涨不杀跌，用规则替代情绪**（框架行 466~468）。

### 2.10 组合健康度与结论四档

| 项 | 口径 |
| --- | --- |
| 结论四档 | 优秀 / 良好 / 需要调整 / 问题严重（沿用中期骨架 L465） |
| 组合最大回撤目标 | **≤20%**，接近目标时提高现金比例（框架行 807）；压力测试须对**该阈值给出判定**（`GP-14`） |
| 必须明确回答 | ① 组合整体健康度；② 底仓结构是否合规（60%~80% 校验）；③ **最应该做的一件事**；④ **当前最大风险** |
| 持仓数量 | 5~10 只（框架行 785）；结构 3~4 核心（12%~15%）+ 2~3 卫星（5%~8%）（行 627） |

### 3.3 降级与失败处置

| 场景 | 处置 |
| --- | --- |
| 某持仓取数失败（网络/接口） | 该只标「**未验证**」，其合规校验结论标「**无法判定**」；**不得**按合规通过处理；整体结论降级说明 |
| 美股 yfinance 不可用（本次复测：沙箱内缓存写受限；沙箱外 curl 超时） | 降级为「**流动性未校验**」+ 标注数据缺口；**不在本技能内做网络修复**（归 P5-2） |

| ESG 输入缺失 | 输出 `position_cap_after=null` → 报告中标注「**ESG 未校验，上限未降档**」，不得默认放行 |

| 相关系数无法量化 | 定性输出 + 反证清单（`GP-6`），**禁止伪造数值** |

### 3.4 风控硬编码（`GP-1`~`GP-15`，本技能新增，前缀已核验未占用）

| 编号 | 规则 |
| --- | --- |
| `GP-1` | **诚信否决前置**：任一持仓命中一级（诚信）否决 → 该标的**直接给出清仓建议**，**不进入**权重优化与再平衡 |
| `GP-2` | **五级卖出优先于再平衡**：命中 `garp-exit` 五级任一即处置，不受 ±5% 阈值束缚 |
| `GP-3` | 底仓/机动仓（股票仓位内部）与现金（占总资产）**两层口径不得混用**；每个百分比须显式标注口径 |
| `GP-4` | 单只三档校验 + **上浮至绝对 20% 的标的合计 ≤2 只** |
| `GP-5` | 单一行业上限**四档**（中性/复苏 ≤40%、衰退 ≤30%、过热 ≤25%、滞胀 ≤20%），只读宏观档 |
| `GP-6` | 行业相关性 <0.5 **定性核验 + 反证清单**；**禁止伪造相关系数数值** |
| `GP-7` | 流动性 ≥1 亿元（小市值放宽 >3000 万须**显式标注**）；跨币种**先折算后比较** |
| `GP-8` | **先 ESG 降档 → 再宏观收紧 → 取更严者**；上限只读透传，禁止自行估算 |
| `GP-9` | 宏观现金下限为**占总资产**口径，不得与股票内部切分混用 |
| `GP-10` | 再平衡为**季度末 ±5%** 触发；且**不得**覆盖 `GP-1` / `GP-2` |
| `GP-11` | ATR 止损价权威 = **`momentum.stop_price()`（内联调用）**；**禁用** `momentum.py` CLI（静默失效）、**禁止**自行乘算 |
| `GP-12` | 所有数值（均值、占比、缺口、金额）**须工具产出**（`financial_rigor.py calc`），**零心算** |
| `GP-13` | 报告头部**三日期强制标注**（生成日｜审视日｜数据截止日） |
| `GP-14` | 压力测试须对「**组合最大回撤目标 ≤20%**」给出**明确判定**（达标/接近/超限） |
| `GP-15` | 只输出**合规判定与调仓建议**，**不替用户决策**；不越界输出个股研究结论（引用专科技能）；报告含免责声明 |
