## §3 执行命令与期望输出（报告审计三步工作流）

```powershell
F:/Anaconda3/envs/Python_3_12_3/python.exe tools/common/report_audit.py extract --report "reports/新易盛/新易盛-garp-checklist-20260919.md" [--ratio 0.15 --seed 42]

F:/Anaconda3/envs/Python_3_12_3/python.exe tools/common/report_audit.py extract --report "reports/新易盛/新易盛-garp-exit-20260919.md"
```

**期望输出（实测，落 `upgrade1.0/P5-2/audit-extract-*.json`）**：

| 报告 | 抽取条数 | 期望 |
| --- | --- | --- |
| checklist | 13 | `extract` 生成含 `id/reported/label` 的抽检清单 |
| valuation | 24 | 同上 |
| exit | 16 | 同上 |

**判据**：抽取条数 ≥ 总数下限；`label` 取自报告正文「数值得分主张」；任何抽取器误解析条目以 `fetched_source = "【抽取器误解析】…"` 置空（不计核验）。

### 3.2 步骤二：逐点独立取数（人工/工具核验值）

按 `extract` 清单，对每个**可核验**条目用独立工具复取 `fetched_value`。本任务使用的独立信源矩阵（节选）：

| 断言条目 | 独立工具 / 原始文件 | 复取值（元） |
| --- | --- | --- |
| checklist id 12 扣非归母 | `stock_financial.py --code 300502` | 95.07 亿 |
| checklist id 29 总市值 | `financial_rigor.py calc`：445.00×1,394,256,684 股 | 6204.44 亿（双源） |
| checklist id 32 ATR14 | `stock_quote.py --momentum` + 腾讯源 K 线复算 | 26.22 |
| valuation id 8 前瞻 PE | `financial_rigor.py calc`：6206.58/199.53 | 31.11 |
| valuation id 51 预期增速 | 同花顺「预测年报净利润」独立复核（2026E 均值 199.53 亿 / 2027E 344.90 亿） | 偏差 0.00% |
| valuation id 108 PE(静) | `financial_rigor.py calc` + `stock_value_em` | 65.28 / 65.11 |
| exit id 5 收盘价 | `stock_quote.py` + `stock_value_em` | 445.00 双源一致 |
| exit id 82/87 ATR14 | 东财 + 腾讯双源复算 | 26.22 双源一致 |

**判据**：独立信源**禁用报告自身与同源**；误差 >1% 须按 1% 容差规则打警告/失败并如实披露。

```powershell

```

| 报告 | verdict | pass | warn | fail | total | 退出码 |
| --- | --- | --- | --- | --- | --- | --- |
| checklist | **PASS（准出）** | 8 | 0 | 0 | 8 | 0 |
| valuation | **PASS（准出）** | 12 | 1 | 0 | 13 | 0 |
| exit | **PASS（准出）** | 9 | 0 | 0 | 9 | 0 |
| **合计** | **3/3 准出** | **29** | **1** | **0** | **30** | **0** |

**判据**：`verdict == "PASS"` 且**进程退出码 0**。1 项警告（valuation id 36「2025 毛利率误差」）为**误差率/百分比变化类小量的量级舍入伪差**（1% 相对容差不适用于原始值近 1% 的百分比增量），计入 warn 不判 fail（详见《集成验收记录》§7.1）。
