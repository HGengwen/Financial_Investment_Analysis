## 0. 结论摘要（TL;DR）

P4-3 是 GARP 独立档「买入前门槛」技能，属**口径重构型 4 之一**（与 P4-1/P4-2「命门净新增」不同：本任务**有既有骨架** `mid-investment-checklist`，但**关卡结构与全部量化口径均需重构**，而非简单替换参数）。

本方案的三条核心难点：

1. **能力圈四维自检是最大「净新增口径」，且它天然不可由工具判定**——框架第2步把"看得懂"拆成四维可打分判断题（行 219~236），但"能否画出产业链上下游""能否用 2 种方法估值"是**投资者的自我声明**，不是数据查询结果。若 AI 直接代答并定稿，等于替用户宣称"在能力圈内"，违背该维度的设立初衷。**处置方案：AI 代答 + 强制人工确认闸门**，未确认项一律标「暂定」，且科技股「技术理解」未确认时**不得给出「可建仓」结论**（与 P4-2 已确立的人工确认闸门纪律同构）。
2. **「能力圈未通过」在框架内部存在一处张力，必须显式口径化**——框架第2步判定规则给的是"三选一（补课 / 低仓观察仓 / 放弃）"（行 234），而第3步一票否决清单给的是"能力圈自检未通过 → 放弃"（行 361）。二者需要按「行业类型 + 维度类型」二次切分才能自洽（见 §2.1 与本方案 §9.B 待确认点）。
3. **本技能的范围边界必须与 P4-4/P4-5/P4-6 精确切割**——支柱三（管理层 7+7+6 / 科研 8+8+4）的权威口径归 `garp-management`（P4-4）；估值锚定（第4步）属 `garp-valuation`（P4-5）；卖出五级属 `garp-exit`（P4-6）。框架第3步收口原文即写明「**全部达标 → 进入第4步估值锚定，可建仓**」（行 374），**故本技能不含估值关卡**，只在收口段转接。

**本方案覆盖的净新增能力域**：C06 能力圈四维自检（差距分析判定为"新增技能（流程性）"）、C14 五大支柱三档结论聚合器（判定为"新增技能/工具"）、C07 财务初筛五门槛 + 科技豁免（判定为"增强"，本任务补齐豁免规则）。

## 1. 目标与范围

### 1.1 目标

新建 GARP 独立档技能 `garp-investment-checklist`，把框架**第2步 + 第3步**下沉为一条可执行的**买入前门槛流水线**，对 $ARGUMENTS 指定的公司输出**三档明确结论（可建仓 / 观察仓 / 放弃）**，回答一个问题：

> **这家公司，现在是否够格进入下一步的估值锚定与建仓？**

具体产出：

1. **能力圈四维自检**（产业理解 / 财务理解 / 估值理解 / 技术理解）→ 逐维「是 / 否 / 待确认」+ 是否通过门槛；
2. **财务初筛五门槛**（营收≥10 亿 / 3 年营收 CAGR≥15% / 资产负债率<60% / 经营现金流净额为正 / 3 年内≥2 年扣非净利润为正）+ **科技豁免**触发判定；
3. **五大支柱汇总判定** → 一票否决清单命中情况 + 达标判定逐条结果；
4. **三档结论**（全部达标 / 部分不达标 / 任一否决命中）+ 镜子测试；
5. 建仓前置约束与下游转接（估值、管理层、宏观仓位、卖出纪律各自归属下游技能）。

## 2. 关键量化口径（唯一权威 = 框架第2步 + 第3步）

> 本章所有口径逐条取自框架正文，**禁止 LLM 心算或臆造**；任何实现与本章不一致时，以框架正文为准。

### 2.1 能力圈四维自检（框架行 219~236）

| 维度 | 评估标准 | 自检问题（须能独立回答"是"） | 适用 |
| --- | --- | --- | --- |
| **产业理解** | 能否画出该产业链的上下游关系图？能否说出行业竞争格局与集中度（CR5）？ | 产业链有几层？上游关键原材料/设备来自谁？下游客户是谁？前五大玩家是谁、份额多少？ | 通用必答 |
| **财务理解** | 能否独立阅读并理解该行业公司的三张报表？ | 营收、毛利率、应收/存货、经营现金流分别在哪张表？关键科目变动意味着什么？ | 通用必答 |
| **估值理解** | 能否用至少 2 种方法给出估值区间？ | 除了 PE/PEG，能否再用 PS、EV/Sales、DCF、可比公司等方法交叉验证？ | 通用必答 |
| **技术理解** | 能否说清核心技术路线的差异？ | 不同技术路线的原理差异、成本差异、适用场景、主流玩家分别是谁？ | **科技股必答**；普通行业豁免 |

**判定规则（框架行 230~234，本技能必须逐字落地）**：

1. **普通行业**：须**同时满足「产业理解 + 财务理解 + 估值理解」三项**，方可进入深度研究；此三项中**任一无法独立回答，即视为能力圈之外**（技术理解为科技股附加项，普通行业可豁免）；
2. **科技股**：在上述基础上，**「技术理解」为必选项**——若说不清核心技术路线差异，**即便其他三项都通过，也不得重仓，只能作为观察仓或直接放弃**；
3. **达不到门槛的应对**：不是"硬上"，而是三选一——①补课学习直到能独立回答；②只作低仓位的观察仓跟随；③果断放弃。

**框架内部张力的显式口径化（本技能的自建规则，§9.B 已确认 B-1，下表为定稿口径）**：

| 情形 | 框架第2步（行 234） | 框架第3步一票否决（行 361） | 本技能统一口径（§9.B 定稿） |
| --- | --- | --- | --- |
| 普通行业：产业/财务/估值任一不过 | 三选一（含观察仓） | 归「能力圈自检未通过」→ 放弃 | **放弃**（以第3步为准：三项为门槛项，"任一不过即视为能力圈之外"） |
| 科技股：技术理解不过，其余三项通过 | 「不得重仓，只能观察仓或直接放弃」 | 「尤其科技股"技术理解"不过关**不得重仓**」 | **封顶为观察仓**，不得给出「可建仓」结论 |
| 科技股：技术理解不过 + 其他项也不过 | 三选一 | 放弃 | **放弃** |

> 该表是**本技能对框架两处表述的收敛处置**，不修改框架正文；处置口径须经 §9.B 确认后固化。

### 2.2 财务初筛五门槛 + 科技豁免（框架行 241~248）

**五门槛（快速排除法）**：

| # | 门槛 | 权威值 |
| --- | --- | --- |
| F1 | 营收规模 | **≥10 亿元**（剔除微盘股，避开量化收割区） |
| F2 | 最近三年营收复合增速 | **≥15%** |
| F3 | 资产负债率 | **<60%**（**金融/地产行业除外**） |
| F4 | 经营性现金流净额 | **为正** |
| F5 | 过去三年扣非净利润 | **至少两年为正**（避免纯概念股） |

**科技豁免（框架行 248，本技能必须精确触发）**：

> 对高研发投入的科技股，若「扣非净利润为负」**仅由研发费用化压低当期利润所致**，可用「**经营性现金流净额为正 + 营收连续增长 + 研发强度≥15%**」三项替代上述「扣非净利润」门槛；**无法通过此豁免的仍应剔除**。

**豁免判定的三层证据（本技能自建，§9.F 已确认 F-1；L3 为强制项，不得省略）**：

| 层 | 检查 | 判定 |
| --- | --- | --- |
| L1 | `研发强度 = 研发费用 ÷ 营业总收入 ≥ 15%` | 未达 15% → 豁免不成立 |
| L2 | `经营性现金流净额 > 0` **且** 营收连续增长（近 3 年营收逐年增长，不出现年度负增长） | 任一不满足 → 豁免不成立 |
| L3 | **「仅由研发费用化所致」的独立验证**：加回当期费用化研发支出后，核心经营利润转正（用 `financial_rigor.py calc` 精确计算，禁止心算） | 加回后仍为负 → 说明亏损非研发费用化单因所致 → **豁免不成立**，剔除 |

- L3 是本技能对"**仅**由研发费用化压低当期利润所致"这一限定语的必要落地：若不加 L3，任何亏损科技股只要研发强度≥15% 就能绕过门槛，豁免将退化为普适后门。
- 豁免**只替代 F5**（扣非净利润门槛），**不替代 F1~F4**；F3（负债率<60%）对科技股同样不豁免。
- 科技豁免的成立与否须在报告中**显式写出判定过程与三层证据**，不得以一句"符合科技豁免"带过。

### 2.3 五大支柱汇总判定 · 一票否决清单四条（框架行 357~362）

命中**任意一条**即「放弃或清仓」，**不进入后续达标判定**：

| # | 否决项 | 判定来源 |
| --- | --- | --- |
| V1 | **诚信一票否决**：兑现率<50%、业绩预告重大失真、财务造假、监管立案 | `governance_data.py management`（P4-4 口径，本技能只读结论） |
| V2 | **ROIC 长期<5% 却在拼命扩产** | `financial_rigor.py roic --expanding`（P1-1 工具） |
| V3 | **能力圈自检未通过**（尤其科技股"技术理解"不过关不得重仓） | 本技能 §2.1 四维自检（含 §9.B 收敛口径） |
| V4 | **0.3 三维矩阵综合归为"回避"档**（政策覆盖度低/无 **且** 国字号基金无覆盖，无论地缘倒逼高低） | `garp-geo-policy`（P4-1，已交付）的 `conclusion` / `track_type` 透传 |

> **V2 的独立口径（框架行 262 注）**：一票否决项「ROIC 长期<5% 且仍在扩产」**独立按报表 ROIC 判定**，**不适用**支柱二主阈值的"调整后核心经营 ROIC"豁免。即：科技股调整口径只豁免支柱二的「≥10%」主阈值，**不豁免 V2**。本技能须显式区分这两个 ROIC 口径。

### 2.4 五大支柱汇总判定 · 达标判定五条（框架行 364~370）

须**全部满足**方可建仓：

| # | 支柱 | 达标条件（权威原文要点） |
| --- | --- | --- |
| S1 | **支柱一（β）** | 产业景气向上——供需不恶化、产品单价稳定或上涨、CR5 提升或龙头份额扩大 |
| S2 | **支柱二（α）** | ROIC > WACC 且 ≥10%（5%~10% 归"部分不达标"→ 观察仓；科技股按"调整后核心经营 ROIC"口径）；营收/利润增速匹配；ROE 趋势向上或企稳，毛利率/净利率不恶化。**护城河须可量化验证**（市占率趋势 / 续费率·NPS / 定价权 / 转换成本 / 成本·技术壁垒）；停留在"感觉有壁垒"则本项不达标 → 退观察仓；**禁止仅凭行业 β 的 CR5 判断个股护城河** |
| S3 | **支柱三** | 科技股须「管理层≥15 **且** 科研转化≥15」（**两套都须≥15，非合计/加权**）；普通行业须「管理层≥15」 |
| S4 | **支柱四** | 海外收入、资源/供应链、地区冲突暴露可控；其中「**地缘倒逼强度非低/无**」**仅对地缘倒逼型赛道**（半导体设备/材料等）为**硬门槛**；**政策资本驱动型赛道**（机器人、信创等增量创造，地缘倒逼强度本就不高）**仅豁免这一条硬门槛**，海外收入/供应链/地区冲突暴露等敞口**仍须体检**，其达标与否（政策覆盖度与基金介入）以支柱五判定为准 |
| S5 | **支柱五** | 政策覆盖度至少"中"及以上（0.3 矩阵非"低/无覆盖"）**且** 国字号基金介入非"无覆盖"（至少有覆盖或专项子基金） |

**S2 的 ROIC 四档（框架行 267~275）**：

| 档 | 判定 | 处置 |
| --- | --- | --- |
| 合格 | ROIC > WACC **且** ≥10% | 达标 |
| 优秀 | ROIC > 15% | 加分项：可支持单只上限上浮至绝对 20%（**仅限长期充分验证的深护城河核心底仓**），并允许 PEG 偏贵上沿接近 1.5 |
| 部分不达标（a） | 5%~10% 之间 | 观察仓待观察（既不否决也不达标） |
| 部分不达标（b） | <5% 但不扩产 | 观察仓 |
| 一票否决 | <5% **且** 仍在拼命扩产 | 归入 V2 |

**科技股 ROIC 口径协调（框架行 272~275）**：高研发投入科技股因研发费用化压低当期利润与 ROIC，**支柱二主阈值「≥10%」应改用"调整后核心经营 ROIC"**（将费用化研发支出加回后的口径）；调整后仍 <10% → 本项判「部分不达标（观察仓）」；科研转化清单「资本回报效率」项**仍独立按「ROIC > WACC」判定**（即：**主阈值不豁免，仅豁免科研转化清单中的"资本回报效率"单项**）。

### 2.5 三档结论（框架行 372~376）

| 档 | 触发条件 | 处置 |
| --- | --- | --- |
| **全部达标** | V1~V4 均未命中 **且** S1~S5 全部满足 | 进入第4步估值锚定（`garp-valuation`），可建仓 |
| **部分不达标** | V1~V4 均未命中 **且** S1~S5 存在未满足项 | **观察仓**（最多轻仓跟踪，等待信号补齐，不重仓） |
| **任一否决命中** | V1~V4 命中任意一条 | **放弃或清仓** |

**聚合优先级（本技能自建，§9.E 已确认 E-1）**：**否决优先于达标求和**——先扫 V1~V4，命中即终止；未命中再逐条核 S1~S5，全满足才给"可建仓"。禁止"用 4 项达标对冲 1 项否决"。

### 2.6 与 0.3 三维矩阵的映射（框架行 355）

> 0.3 是「地缘倒逼强度 × 政策覆盖度 × 国字号基金介入」的**三维综合**矩阵；落到五大支柱时——**支柱四对应「地缘倒逼强度」维，支柱五对应「政策覆盖度 + 国字号基金介入」两维**。

- **本技能不做 0.3 判定**，只**透传** `garp-geo-policy`（P4-1）的 `matrix_row` / `conclusion` / `track_type` / `archived`；
- 「回避档」的共同特征是「政策覆盖度低/无 **且** 国字号基金无覆盖」，此时无论地缘倒逼高低**均一票回避** → 直接映射为 **V4**；
- **赛道两分法**（`track_type`）决定 S4 的收敛路径：地缘倒逼型 → 硬门槛；政策资本驱动型 → 仅敞口体检。

## 3. 技能编排设计

### 3.1 命令与参数

**命令**：`/garp-investment-checklist {公司名}`

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `{公司名}` | 目标公司名或代码，**支持多公司**（多公司时逐家独立成章 + 末尾总览对比表） | **必填** |
| `--market` | 市场分层 `A股 / 港股 / 美股`，决定取数工具链 | 自动识别；识别失败则询问 |
| `--no-industry` | 跳过赛道数据引用（S1 降级为定性描述），用于赛道口径缺失时 | 关闭 |
| `--geo-conclusion` | 用户已持有的 0.3 前置结论（`放行/观察/回避`）与 `track_type`，填则跳过 `garp-geo-policy` 调用 | 无 |
| `--stage` | 宏观档位（`衰退/复苏/过热/滞胀`），填则透传给 `garp-macro` 取收口参数 | 无（未填则提示单独执行 `/garp-macro`） |
| `--depth` | `standard`（全流程）/ `fast`（跳过实时检索，仅用缓存与用户输入） | `standard` |

### 3.2 执行流程（七步）

#### 第一步：确认参数与数据基准

运行 `date` 确认当天日期，作为「数据截止日期」基准（全局规则 1）。解析公司名 → 全称 / 代码 / 交易所 / 是否上市（未上市 → 标「未上市，跳过完整 Checklist」，并按需转 `garp-private-company-research` P4-20）。

**AI 研究偏见预警（继承既有骨架，口径保留）**：对公司做信息丰富度 A/B/C 评级；**C 级公司「数据不足」不等于「不通过」**，须诚实标注为「灰色地带，需补充一手信息」，不得勉强填满关卡。

#### 第二步：数据收集（按市场分层）

| 市场 | 工具链 |
| --- | --- |
| A股 | `tools/a_share/stock_info.py` / `stock_quote.py`（含 `--momentum`）/ `stock_financial.py`（含 `--advanced 研发费用,研发投入,员工总数`）/ `stock_screen.py` / `stock_equity.py`、`a_stock_cache` |
| 港股 | `tools/hk_stock/stock_info.py` / `stock_quote.py` / `stock_financial.py` / `stock_screen.py`、`hk_stock_cache` |
| 美股 | `tools/us_stock/stock_info.py` / `stock_quote.py` / `stock_financial.py`、`us_stock_cache` |

**取数清单**：营收与 3 年 CAGR、资产负债率、经营现金流净额、扣非净利润（近 3 年）、研发费用与研发强度、ROE 趋势、毛利率/净利率、市值与股本、行业集中度（CR5）、市占率趋势、续费率/NPS 等护城河量化证据。

**精确计算纪律**：一切比率与 CAGR 均由 `tools/common/financial_rigor.py calc` 执行，**禁止 LLM 心算**；关键财务数据须至少来自两个独立来源，误差>1% 须标记。

> **注意 `stock_screen.py` 的定位**：其"质量筛选 7 条指标"与 GARP「财务五门槛」**不是同一套口径**，本技能**不得以 `stock_screen` 输出直接充当五门槛判定**，只能作为**辅助佐证**；五门槛须按 §2.2 逐条独立计算。

#### 第三步：能力圈四维自检（含人工确认闸门）

逐维输出「AI 代答结论 + 依据」→ 标记 `self_check_confirm = 待用户确认` → 由用户确认后定稿。

| 维度 | AI 代答方式 | 无从代答时的处置 |
| --- | --- | --- |
| 产业理解 | 由产业链/CR5 检索结果生成"投资者应能回答的四问"及其参考答案 | 标「待确认」 |
| 财务理解 | 由三张报表科目清单生成对照问题 | 标「待确认」 |
| 估值理解 | 由 `garp-valuation`（P4-5）可用方法清单生成对照问题 | 标「待确认」 |
| 技术理解（科技股必答） | 由技术路线检索结果生成"路线差异四问" | **未确认即封顶观察仓** |

**人工确认闸门（与 P4-2 同构）**：未确认前，`confidence = 低`、`manual_review = true`，报告中该维度结论一律标「**暂定**」；**只要存在未确认维度，最终三档结论须标注「暂定」**，不得直接输出「可建仓」。

#### 第四步：财务初筛五门槛 + 科技豁免

逐条判定 F1~F5；**若 F5 不通过且公司属科技股**，进入科技豁免三层证据判定（§2.2）。输出：五门槛逐条「通过/不通过」+ 豁免是否成立 + 三层证据。**任一门槛不通过且豁免不成立 → 标的剔除**（不再进入第五步）。

#### 第五步：五大支柱汇总判定（工具调用，禁止心算）

1. **引用 0.3 前置结论**（未提供则调用）：

```bash
# scan 子命令须以 -m 模块形式调用（脚本形式会因 tools 包不在 sys.path 而报 ModuleNotFoundError）
python -m tools.specialized.geo_policy_screen scan --industry {行业}
python tools/specialized/geo_policy_screen.py screen --geo {高|中|低} --policy {高|中|低} --fund {四档} --as-of {YYYY-MM-DD} --basis "{依据}"
```

→ 读回 `matrix_row` / `conclusion` / `track_type` / `archived`，映射 **V4** 与 **S4/S5**。

2. **支柱二 ROIC 工具调用**：

```bash
python tools/common/financial_rigor.py roic --nopat {NOPAT} --invested-capital {IC} --wacc {WACC} [--expanding]
python tools/common/financial_rigor.py wacc --equity-value {E} --debt-value {D} --cost-equity {re} --cost-debt {rd} --tax-rate {t}
python tools/common/financial_rigor.py incremental-roic --nopat-from {..} --invested-capital-from {..} --nopat-to {..} --invested-capital-to {..}
```

→ 读回 `roic` / `tier` / `verdict` / `tech_adjustment_hint`，映射 **S2** 与 **V2**。
→ 科技股另需按 §2.4「调整后核心经营 ROIC」口径复算一次（研发费用加回）。

3. **支柱三门槛级判定**（只读结论）：

```bash
python tools/specialized/governance_data.py management --fulfillment-rate {..} --dividend-payout-ratio {..} --pledge-ratio {..} ...
python tools/specialized/governance_data.py research ...
```

→ 读回 `score` / `tier` / `veto`；映射 **V1**（诚信闸门）与 **S3**（是否≥15）。

4. **支柱一 / 支柱四 / 支柱五**：以检索证据 + 引用出口逐条判定（S1 / S4 / S5）。

5. **汇总**：先扫 V1~V4 → 未命中再扫 S1~S5 → 落 §2.5 三档结论。

#### 第六步：镜子测试（GARP 版五句话）

> 「我以 ___ 元买入 ___ 公司，因为：
> 1. 这门生意的本质是___，**能力圈四维自检结论是___**；
> 2. 它在产业链的位置是___，**未来 1~5 年赛道趋势（渗透率 15%~40% 黄金窗）确定的理由是___**；
> 3. 它的护城河量化证据是___，ROIC 为___（WACC 为___）；
> 4. 管理层评分___、科研转化评分___，**诚信闸门___**；
> 5. 若连续 2 季业绩低于预期，我将___；若触发硬止损 8%~10%，我将___。」

**5 句话说完整了才买**；明确标注「通过 / 未通过」。

#### 第七步：收口输出与下游转接

写入 `reports/{公司名}/{公司名}-garp-checklist-{YYYYMMDD}.md`（目录不存在则创建）；多公司时每家独立成文并在各自报告内附总览对比表。

| 三档结论 | 下游技能 |
| --- | --- |
| **可建仓**（全部达标） | `garp-valuation`（P4-5）估值锚定 → 建仓 |
| **观察仓**（部分不达标） | 记录待补齐信号；信号补齐后重跑本技能 |
| **放弃**（任一否决命中） | 终止，写明命中项 |
| 任一结论 | 建仓前置约束：引用 `garp-macro`（P4-2）的现金下限与单只上限；卖出纪律转 `garp-exit`（P4-6）；组合层仓位转 `garp-portfolio-review`（P4-8） |

### 3.3 按「公司类型」分层的关卡裁剪

| 公司类型 | 能力圈 | 五门槛 | 支柱三 | 支柱四 |

### 3.5 风控硬编码 `GC-*`（全新编号）

既有编号占用情况：`R-*`（`mid-industry-research`）、`F-*`（`mid-industry-funnel`）、`MC-*`（`mid-investment-checklist`）。本技能采用**全新前缀 `GC-*`**（GARP Checklist），与中期链编号物理隔离、避免语义漂移。

| 编码 | 规则 | 执行要求 |
| --- | --- | --- |
| **GC-1** | 否决优先于达标求和 | 先扫 V1~V4，命中即终止，禁止"4 项达标对冲 1 项否决" |
