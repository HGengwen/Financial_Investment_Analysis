## 四、与 1~3 年中期链的口径隔离对照

对照基准：既有技能 `mid-investment-checklist`（七关 Checklist）

| 维度 | **1~3 年中期链**（`mid-investment-checklist`） | **1~5 年 GARP 独立档**（本技能） | 隔离性质 |
| --- | --- | --- | --- |
| 持有周期 | 1~3 年 | **1~5 年** | 档位不同 |
| 大师体系 | 四大师（欧奈尔 / 林奇 / 郑希 / 李进） | **五大师（+ 费雪）** | **替换** |
| 关卡结构 | **七关**（含估值关、仓位卖出关、地缘关） | **四段**（能力圈 / 五门槛 / 五大支柱 / 镜子测试） | **结构重构** |
| 渗透率 | 10%~30% 黄金区 | **15%~40% 黄金窗**（引用 P4-9，不判定） | **替换** |
| 地缘 | 6 维度矩阵 + `MC-10` | **0.3 三维交叉矩阵 + 赛道两分法**（引用 P4-1） | **重构** |
| 管理层 | 5+5+5+5（诚信占 5 分） | **诚信前置 + 7+7+6**（引用 P4-4） | **重构** |
| 估值 | 第五关，引用既有温度计技能五档 | **不在本技能内**（转 P4-5） | **移除 + 转接** |
| 卖出 | 第六关，引用既有卖出信号技能六级 | **不在本技能内**（转 P4-6，五级） | **移除 + 转接** |
| 仓位 | 第六关内建单只 10/15/20%、行业 40% | **仅透传**（转 P4-2 宏观 / P4-8 组合） | **移除 + 转接** |
| 宏观 | 无 | **叠加宏观三表约束**（引用 P4-2，已交付） | **净新增** |
| 能力圈 | 无 | **四维自检 + 人工确认闸门** | **净新增** |
| 财务初筛 | 无独立门槛（散在第二关） | **五门槛 F1~F5 + 科技豁免三层证据** | **净新增** |
| 结论形态 | X/7 关通过（计数式） | **三档**（全部达标 / 部分不达标 / 任一否决命中） | **重构** |
| 风控编号 | `MC-1`~`MC-10` | **`GC-1`~`GC-10`**（全新前缀，无冲突） | **替换** |
| 报告文件名 | `{公司名}-...`（各技能自定） | `{公司名}-garp-checklist-{YYYYMMDD}.md` | **不冲突** |

**隔离结论**：本技能与 `mid-investment-checklist` **不共享任何量化阈值**；即便同一家公司在两套技能下得出不同结论，也**不构成冲突**（档位与口径本就不同），属**功能互补**。

## 五、与 10 年长期链的口径隔离对照

| 维度 | **10 年长期链**（护城河四大师体系） | **1~5 年 GARP 独立档**（本技能） | 隔离性质 |
| --- | --- | --- | --- |
| 持有周期 | 10 年（永续视角） | **1~5 年** | 档位不同 |
| 核心问题 | 「这家公司 10 年后是否还更强」 | 「**现在是否够格进入估值锚定与建仓**」 | 问题不同 |
| 估值方法 | 长期折现 / 终值口径（`terminal_value.py`） | **不涉及估值**（转 P4-5 多工具矩阵） | **完全隔离** |
| 财务门槛 | 长期链 `quality-screen` 7 条硬指标 | **GARP 五门槛 F1~F5**（口径不同，**不互换**） | **完全隔离** |
| 护城河判定 | 长期护城河（10 年可持续性） | **1~5 年尺度的可量化验证**（市占率趋势 / 续费率·NPS / 定价权 / 转换成本 / 成本·技术壁垒） | 尺度不同 |

**隔离结论**：本技能**不使用** `terminal_value.py`（长期折现工具）、**不使用** 长期护城河终局口径、**不出现**任何「持有 10 年 / 终局思维」类表述。

## 九、声明结论

1. **头部独立档声明已落地**：`SKILL.md` 与 `README.md` 均逐字包含「GARP 独立档（1~5 年，五大师…）与 1~3 年中期链、10 年长期链口径物理隔离、功能互补」。
2. **三档并存路由合规**：下游指向**只含 `garp-*` 与复用 2 技能**；**零指向** `mid-*` 作为口径提供者；赛道出口按 §9.C 定向改引 `garp-industry-research`（P4-9）。
3. **七处共性口径替换全部落位**：①五大师 ✅ ②渗透率 15%~40%（仅引用）✅ ③0.3 三维矩阵 + 赛道两分法 ✅ ④五级卖出（转出 P4-6）✅ ⑤诚信前置 + 7+7+6（引用 P4-4）✅ ⑥多工具估值矩阵（转出 P4-5）✅ ⑦宏观三表（引用 P4-2）✅。
4. **与中期链 / 长期链的口径隔离逐项对照完成**，无共享阈值、无口径混用。
5. **机械核验通过**：12 项禁用词**全部 0 命中**。
6. **边界隔离四项全部落地**，未越界到估值 / 卖出 / 仓位 / 管理层细则 / 赛道判定。

> **声明**：本技能（`garp-investment-checklist`，P4-3）为 **GARP 独立档（1~5 年）** 的买入前门槛技能，其全部量化口径以《中长期价值成长（GARP）投资框架》第2步 + 第3步为**唯一权威**，与既有 1~3 年中期链、10 年长期链**物理隔离**，不构成对既有 43 技能的任何口径侵入或替换。
