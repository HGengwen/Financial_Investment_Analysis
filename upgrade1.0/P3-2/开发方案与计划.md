## 0. 结论摘要（TL;DR）

本任务在 P3-1 已交付的 `geo_policy_screen.py` 上**新增**国产化率四档分层量化能力，将框架第 1 步「国产化率位置」下沉为可执行命令，禁止 LLM 心算。

- **输入**：`--industry`（任意行业/领域/环节名，纯透传）+ `--localization-rate`（百分数数值 0~100）+ 可选 `--strategic-choke-point`（战略卡脖子 flag）+ 可选 `--as-of`/`--basis`（时效透传）。
- **输出**：JSON，核心字段 `{tier, tier_index, phase, action_hint}`，附 `strategic_choke_point / choke_point_applied / time_sensitive / source / input` 回显与口径来源标注。
- **核心口径（唯一权威）**：`<5%` 过早 / `5%~20%` 从 0 到 1 突破期 / `20%~50%` 加速投资期 / `>50%` 替代空间收窄；补充 `<5%` 中属战略必争卡脖子环节（如光刻）→ 高风险高弹性观察/小仓、非回避。
- **关键设计原则**：判定**只依赖 `--localization-rate` 数值，不依赖行业名**，从而天然支持「任意行业/领域」；半导体设备仅作内置示例，通过独立 `examples` 子命令复现，**不写死进判定逻辑**。
- **复用与回归约束**：复用 P3-1 文件骨架与 `@dataclass asdict`/`argparse` 子命令/常量 dict/导入自检模式；**不改动** P3-1 的 `screen` 子命令、`GeoPolicyResult` 结构及任何既有常量。

## 1. 目标与范围

### 1.1 目标

在 `tools/specialized/geo_policy_screen.py` 上新增：

1. **四档分层判定**：对任意 `--localization-rate` 精确落档为四档之一（边界归属见 §2.2）。
2. **任意行业/领域参数化**：`--industry` 为自由文本透传，判定逻辑不写死半导体，不设行业白名单。
3. **战略卡脖子例外**：`<5%` 且命中 `--strategic-choke-point` 时，动作提示升级为「高风险高弹性观察/小仓、非回避」。
4. **半导体设备内置示例**：通过 `examples` 子命令复现框架第 1 步的三梯队 + 光刻表，作为回归锚点。

### 1.2 包含范围

- 四档规则表（常量固化，边界见 §2.2）。
- 输入校验（`--localization-rate` 为 0~100 数值、`--industry` 非空；非法即 fail-fast 拒绝，不降级归档）。
- 战略卡脖子例外的精确触发条件与输出覆盖。
- 时效审计：可选 `--as-of`/`--basis` 透传 + `time_sensitive` 警示（沿用 P3-1 模式）。
- CLI 子命令 `localize`（单点四档判定）+ `examples`（内置示例表）。
- 单元测试（四档边界 + 例外触发 + 任意行业名 + 示例复现 + JSON 可解析 + P3-1 回归不破坏）。

### 1.3 不包含范围（明确排除，防范围蔓延）

- **不含**渗透率五档（15%~40% 黄金窗等）——渗透率与国产化率在框架中是**两个独立维度**（框架行 198 明确分工），渗透率量化不属本任务。

- **不做**国产化率的网络/数据源自动获取，不判定数值真伪；数值由调用方或 P3-3 提供，本工具仅按数值落档。
- **不含**与估值、仓位、卖出纪律的联动（属 Phase 4 `garp-*` 技能编排，非本工具职责）。
- **不改动** P3-1 已交付的 `screen` 子命令、`GeoPolicyResult`、`GEO_VALUES/POLICY_VALUES/FUND_VALUES/ROW_META/MATRIX_ROWS/FALLBACK_MAP/RISK_NOTE/SOURCE/TIME_SENSITIVITY_NOTE` 及 `_assert_full_coverage()`。

## 2. 关键量化口径（唯一权威 = 框架第 1 步）

> 以下全部取自《中长期价值成长（GARP）投资框架》第 1 步（行 191~212），是唯一权威。任何实现与本文档/总计划/详细计划不一致时，**以框架正文为准**。

### 2.1 四档口径（权威照录）

> 国产化率<5%为过早（不确定性高）；5%~20%为从0到1突破期（高弹性，跟踪/小仓）；20%~50%为加速投资期（订单放量）；>50%替代空间收窄。补充：<5%中若属战略必争卡脖子环节（如光刻），可作高风险高弹性的观察/小仓、非回避。

四档映射如下（本表仅作实现锚定，正文仍是唯一权威）：

| tier（档名） | tier_index | 边界（§2.2 确认） | phase（阶段） | action_hint（动作提示，照录框架语义） |
| --- | --- | --- | --- | --- |
| 过早 | 1 | `rate < 5` | 不确定性高 | 观察不建仓；若命中战略卡脖子例外→高风险高弹性观察/小仓、非回避 |
| 突破期 | 2 | `5 ≤ rate < 20` | 从 0 到 1 突破期 | 高弹性，跟踪/小仓 |
| 加速投资期 | 3 | `20 ≤ rate < 50` | 加速投资期 | 订单放量 |
| 替代空间收窄 | 4 | `rate ≥ 50` | 替代空间收窄 | 转向龙头份额提升与整机放量，不继续押注「从 0 到 1」 |

### 2.2 四档边界归属（待确认点 A，核心口径锁定）

框架四档区间在 5%、20%、50% 三处存在表述重叠，需明确边界归属。依据框架半导体示例表（第三梯队 5%~20%∈突破期、第二梯队 30%~40%∈加速投资期、第一梯队 50%~90%∈已成熟/收窄）反推，建议采用**左闭右开 + 上限包含 50**：

- `<5` → 过早
- `[5, 20)` → 突破期（5% 含于突破期）
- `[20, 50)` → 加速投资期（20% 含于加速投资期）
- `[50, 100]` → 替代空间收窄（50% 含于收窄档）

> 此边界与框架示例完全自洽：刻蚀 55%~65%、清洗 50%~60% 均落收窄档；薄膜沉积/CMP 30%~40% 落加速档；量测检测 <15%、涂胶显影/离子注入 5%~20% 落突破档；光刻 <1% 落过早档。

### 2.3 战略卡脖子例外（权威原文）

> <5%中若属战略必争卡脖子环节（如光刻），可作高风险高弹性的观察/小仓、非回避。

例外**仅在 `rate < 5` 区间生效**：

| `rate < 5` | `--strategic-choke-point` | 动作提示 |
| --- | --- | --- |
| 是 | `true` | 战略必争卡脖子环节，高风险高弹性，仅观察/小仓、不重仓（非回避） |
| 是 | `false` | 过早，不确定性高，观察不建仓 |
| 否 | 任意 | 按所在档位正常动作提示（flag 不生效，仅回显） |

### 2.4 渗透率 vs 国产化率分工（负向边界，写入口径隔离）

> 渗透率定位**产业**所处阶段（管"何时买"），国产化率定位**国产企业**可替代空间（管"标的成长弹性"）。……国产化率进入 >50% 收窄阶段后，投资逻辑转向龙头份额提升与整机放量，而非继续押注"从0到1"的替代弹性。

本工具**只管国产化率**，不混入渗透率五档；两者叠用由 Phase 4 `garp-geo-policy` 技能编排完成，本工具不越权。

### 2.5 半导体设备四梯队内置示例（权威照录，用于 `examples` 子命令）

| cohort（梯队/例外） | 环节 | 当前国产化率 | 投资逻辑 | 对应 tier |
| --- | --- | --- | --- | --- |
| 第一梯队（已成熟） | 去胶、清洗、刻蚀 | 50%~90% | 替代空间收窄，关注龙头份额提升 | 替代空间收窄 |
| 第二梯队（主力增量） | 薄膜沉积、CMP | 30%~40% | 已跨过验证门槛，订单放量阶段 | 加速投资期 |
| 第三梯队（高弹性） | 涂胶显影、离子注入、量测检测 | 5%~20% | 从"0到1"突破带来最大业绩弹性 | 突破期 |
| 光刻（战略卡脖子） | 光刻设备 | <1% | 属"<5%过早"区间，但为最深卡脖子、政策最强押注环节，仅观察/小仓、不重仓 | 过早（战略卡脖子例外） |

## 3. 输入/输出签名

### 3.1 CLI 子命令

```text
# 单点四档判定（任意行业/领域/环节）
python tools/specialized/geo_policy_screen.py localize \
    --industry 量测检测 \
    --localization-rate 12.5 \
    --strategic-choke-point \
    --as-of 2026-09-15 \
    --basis "券商研报/行业协会数据"

# 内置半导体设备四梯队示例（回归锚点）
python tools/specialized/geo_policy_screen.py examples
```

- 子命令 `localize`：单点四档判定；P3-1 `screen`、P3-3 `scan` 与本命令命名不冲突。
- 子命令 `examples`：输出 §2.5 内置示例表，不复现网络数据，作口径回归锚点。
- `--industry`：**必填**，任意非空自由文本（行业/领域/环节名），纯透传，不参与判定、不做白名单校验。
- `--localization-rate`：**必填**（`localize` 下），百分数数值（如 `12.5` 表示 12.5%），校验范围 `0~100`，非法即报错返回非零。
- `--strategic-choke-point`：可选布尔 flag（`store_true`），仅 `rate < 5` 时生效（见 §2.3）。
- `--as-of`（国产化率数据截止日期）/`--basis`（判定依据）：可选，仅透传，不参与判定，缺省为 `null`。

### 3.2 输入校验（fail-fast 护栏）

| 校验项 | 规则 | 行为 |
| --- | --- | --- |
| `--industry` | 非空字符串（`strip()` 后非空） | 空 → 报错返回非零 |
| `--localization-rate` | 可解析为 `float` 且 `0 ≤ rate ≤ 100` | 非法 → 报错返回非零，拒绝落档 |
| `--strategic-choke-point` | 布尔 flag | 无需校验 |

> 与 P3-1 一致：**非法输入拒绝、不归档**（fail-fast，不猜）。国产化率数值为时变输入，本工具**不判定数值真伪、不来源核验**，仅透传 `as_of`/`basis`。

## 5. 实现设计（五步，与详细计划对齐）

### 5.1 数据模型与常量（实现步骤①）

- `@dataclass LocalizationResult`：字段对齐 §3.3，含 `asdict()` 序列化；**与 `GeoPolicyResult` 并存，不互改**。
- `@dataclass CohortExample`：`examples` 输出用（§3.4），含 `asdict()`。
- 常量 `LOCALIZATION_TIERS`：四档规则表（`tier_index -> {tier, phase, action_hint, bound}`），边界按 §2.2。
- 常量 `SEMICONDUCTOR_EXAMPLE`：§2.5 四梯队内置示例表（仅由 `examples` 消费）。
- 常量 `LOCALIZATION_SOURCE = "框架第1步"`、`LOCALIZATION_TIME_NOTE`、`CHOKE_POINT_ACTION_HINT`、`CHOKE_POINT_LOGIC`。
- **不改动** P3-1 的 `SOURCE`（其值为 `框架第0步·0.3`），新增常量使用独立名称，避免污染 P3-1 输出。

### 5.2 四档边界判定（实现步骤②）

- 判定函数 `_classify(rate: float) -> tuple[tier_index, tier, phase, action_hint]`，仅依赖 `rate` 数值。
- 边界用**容差比较**消除浮点误差：`rate < 5 - EPS`、`rate < 20 - EPS`、`rate < 50 - EPS`（`EPS=1e-9` 或等价 Decimal），确保 5.0/20.0/50.0 落档确定。
- 边界归属严格按 §2.2（待确认点 A）：`<5` 过早、`[5,20)` 突破期、`[20,50)` 加速投资期、`≥50` 收窄。

### 5.3 战略卡脖子例外（实现步骤③）

- 例外仅当 `rate < 5` 且 `strategic_choke_point=true` 时把 `action_hint` 覆盖为 CHOKE_POINT_ACTION_HINT，`choke_point_applied=true`；否则 `choke_point_applied=false`，`action_hint` 保持正常四档值。
- flag 在 `rate ≥ 5` 时**不生效**，仅回显 `strategic_choke_point`，`choke_point_applied=false`（防误用）。

### 5.4 半导体示例复现（实现步骤④）

- `examples` 子命令直接 `json.dumps` 输出 `SEMICONDUCTOR_EXAMPLE`（§3.4），逐字段照录 §2.5，作为口径回归锚点。
- 示例输出头部显式声明「半导体设备仅作内置示例，判定逻辑不写死半导体；任意行业经 `localize` 按数值落档」，落实「任意行业参数化」。

### 5.5 回归空白（实现步骤⑤）
