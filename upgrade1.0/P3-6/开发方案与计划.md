## 0. 结论摘要（TL;DR）

本任务在既有 `tools/specialized/governance_data.py` 中新增 `esg` 子命令，将框架「第 4 步·ESG/环境风险的估值折价」与「第 3 步·支柱三 ESG 补充检查」中的定量联动下沉为可执行命令，禁止 LLM 心算。

- **输入**：环境风险等级 + 转型路径 + 搁浅资产标志 + ESG 评级尾部标志 + 仓位上限基线（+ `--as-of` 时效透传）。
- **输出**：JSON，核心字段 `{discount_factor, discount_rate_adj_bps, position_cap_downgrade}`（对应详细计划 P3-6 给定的最小输出集），并扩展 `discount_pct / position_cap_base / position_cap_after / esg_tail_triggered` 等字段，附口径来源与时效警示。
- **核心难点**：框架给出的是**区间/定性描述**——「8~9 折（折价 10%~20%）」「折价收窄至 ≤5% 或豁免」「贴现率上调 1~2pct」「绝对上限 20%→15%」。本方案须把这些区间固化为**单一确定值 + 可测试规则**（§5.3），并以代码常量落地，消除 LLM 临场判断（与 P3-4/P3-5「子项权重」同构的难点）。
- **时变性与边界（与 P3-1/P3-4/P3-5 同构的分层）**：折价规则与档位是**静态标签**（框架明示长期适用）；但「是否高环境风险行业 / 是否有明确转型路径 / 是否搁浅资产 / 评级是否尾部」这些**事实判定是时变项**，随政策、评级、财报、碳减排承诺动态变化。故本工具**不检索、不判定事实真伪、不固化事实**（事实取证由 P3-7 `annual_report_parser` 治理字段 + P4-6 `garp-management`/P4-5 `garp-valuation` 技能编排承接），只对调用方传入的电平值做确定性折价计算。
- **边界**：本工具只输出**折价三通道的量化结果**（估值折价系数 / 贴现率上调 / 仓位上限下调），**不替代**第 4 步的多工具估值（调整后 PEG/PS/EV-Sales/Rule of 40/DCF），折价是「在基本面估值之上再打一次折扣」，由 P4-5 `garp-valuation` 技能编排把本工具输出叠加到估值结论上。

## 1. 目标与范围

### 1.1 目标

在既有 `tools/specialized/governance_data.py` 中新增 `esg` 子命令，实现：

1. **估值环境折价**：输出 `discount_factor`（折价系数，如 0.85 表示 8.5 折）与 `discount_pct`（折价百分比），区分「高环境风险无转型 / 明确转型 / 非高环境风险」三档，并叠加「搁浅资产折价加大」。
2. **搁浅资产贴现率上调**：输出 `discount_rate_adj_bps`（贴现率上调基点，DCF 中额外上调），对应框架「搁浅资产上调贴现率 1~2 个百分点」。
3. **仓位上限下调**：输出 `position_cap_downgrade`（下调百分点）及 `position_cap_base / position_cap_after`，对应框架「高环境风险行业同步下调单只仓位上限」与「ESG 评级尾部先降仓位上限」。

### 1.2 包含范围

- ESG 折价三通道规则表（常量固化，§5.3）。
- 折价系数 `discount_factor` 判定（含搁浅资产叠加）。
- 贴现率上调 `discount_rate_adj_bps` 判定。
- 仓位上限下调判定（含 `--esg-tail` 评级尾部与「高环境风险」双触发）。
- 输入校验（档位词表 + 数值范围 + fail-fast 拒绝非法输入）。
- 可选入参 `--as-of`（数据截止日期）透传 + 输出时效警示。
- CLI 子命令 `esg`（单次折价计算，输出 JSON）。
- 单元测试（三通道规则逐项 + 边界 + 输入越界拒绝 + JSON 可解析），且**不动 P3-4/P3-5 既有测试用例**。

### 1.3 不包含范围（明确排除，防范围蔓延）

## 2. 关键量化口径（唯一权威 = 框架第 4 步 + 第 3 步·支柱三）

> 以下全部取自《中长期价值成长（GARP）投资框架》。任何实现与本文档、总计划或详细计划不一致时，**以框架正文为准**。

### 2.1 ESG/环境风险的估值折价（第 4 步，权威四条）

| 情形 | 折价幅度（权威原文） | 操作要点 |
| --- | --- | --- |
| **高环境风险行业（无明确转型路径）** | 合理估值再打 **8~9 折**（折价 10%~20%） | 相当于合理 PEG 上限下调至约 1.0；DCF 目标价、PEG 区间一并下调 |
| **有明确碳减排承诺与可验证转型路径** | 折价收窄至 **≤5% 或豁免** | 须有具体资本开支计划、减排节点与第三方验证，否则仍按无转型处理 |
| **面临"搁浅资产"风险**（高碳资产或提前报废/减值） | 折价加大，且**上调贴现率** | 在 DCF 中额外上调 **1~2 个百分点**的贴现率 |
| **ESG 评级处于行业尾部/最低档** | 触发治理或环境风险预警 | 与支柱三联动，评级明显偏低时**不再下调估值、而是先降仓位上限** |

**操作要点（权威照录）**：

- 环境风险折价是**在基本面估值之上再打一次折扣**，不是替代前文的多工具估值，二者须叠加使用。
- 折价的本质是"为不确定性留出安全边际"：环境风险越不透明、越缺乏转型路径，安全边际要求越高。
- 对高环境风险行业的标的，**即使估值折价后看似便宜，也应同步下调单只仓位上限**（如将绝对上限 20% 下调至 15%），避免单一 ESG 黑天鹅击穿组合。

### 2.2 支柱三 ESG 补充检查（权威联动口径）

| 补充检查项 | 评估标准 | 操作指引 |
| --- | --- | --- |
| 治理（G，最关键） | 治理缺陷 | 与诚信一票否决联动（属 P3-4，本任务不实现） |
| 环境（E） | 是否高碳排放、高环境风险行业 | 高环境风险标的额外做环境合规、转型路径与"搁浅资产"评估（**折价见第 4 步，即本任务**） |
| 社会（S） | 用工/产品质量/供应链劳工重大争议 | 辅助参考，重大负面计入风险提示（本任务不量化） |
| ESG 评级参考 | 第三方评级是否明显低于行业平均 | 评级尾部/最低档作预警，**评级尾部走仓位上限下调**（本任务三通道之三） |

> **注意**：ESG 评级各机构口径不一、覆盖不全且时点滞后，**只作辅助信号**。治理(G) 优先纳入、联动诚信否决（P3-4）；环境(E) 本节仅作定性提示，**是否折价、折价多少，交由第 4 步定量处理（即本工具）**。

### 2.3 本任务"区间→确定值"的落地口径（§9 待确认）

框架给出的「8~9 折」「≤5% 或豁免」「1~2pct」均为区间/开放表述，代码须落地为单一确定值。本方案采用的确定性映射如下（全部列入 §9 待确认）：

- 「8~9 折（折价 10%~20%）」→ 无转型路径取**中值 0.85（8.5 折，折价 15%）**。
- 「折价收窄至 ≤5% 或豁免」→ 明确转型路径取**保守上沿 0.95（折价 5%）**。
- 「搁浅资产折价加大」→ 在基础 `discount_factor` 上**额外 −0.05**，下限 0.80（即「无转型 + 搁浅」恰为区间下限 8 折）。
- 「贴现率上调 1~2pct」→ **+150bp（1.5pct，中值）**，并回显区间 `[100, 200]`。
- 「绝对上限 20%→15%」→ **下调 5.0 个百分点**；基线默认 20.0%。

## 3. 输入/输出签名

### 3.1 输入项与档位词表

| 输入参数 | 类型 | 语义 / 取值 | 必填 |
| --- | --- | --- | --- |
| `--env-risk-level` | 档位 | 环境风险等级：`高` / `低`（高=高碳排放/高环境风险行业） | **是** |
| `--transition-pathway` | 档位 | 是否有明确碳减排承诺与可验证转型路径：`明确` / `无`（缺省 `无`） | 否（默认 `无`） |

| `--position-cap-base` | float | 单只绝对上限基线（%，0~100），用于计算下调后值 | 否（默认 20.0） |

- **档位词表**：`--env-risk-level` 取 `高` / `低`；`--transition-pathway` 取 `明确` / `无`。任何非法档位 → 打印错误并返回非零退出码，**拒绝判分**（fail-fast，不猜）。
- `--position-cap-base` 为 0~100 的 float，越界拒绝。
- `--transition-pathway` 若提供且非法词表 → 拒绝；缺省为 `无`。`--transition-pathway` 仅在 `--env-risk-level=高` 时参与 `discount_factor` 判定（`低` 时忽略其取值，但仍校验合法性）。

## 5. 实现设计（五步，与详细计划对齐）

### 5.1 数据模型

- 常量 `ENV_RISK_VALUES` / `TRANSITION_VALUES`：档位词表。
- 常量 `DISCOUNT_TABLE`：`(env_risk_level, transition_pathway) -> base_discount_factor`（低→1.00；高/明确→0.95；高/无→0.85）。
- 常量 `STRANDED_EXTRA_DISCOUNT = 0.05`、`DISCOUNT_FLOOR = 0.80`。
- 常量 `DISCOUNT_RATE_ADJ_BPS = 150`、`DISCOUNT_RATE_ADJ_RANGE_BPS = (100, 200)`。
- 常量 `POSITION_CAP_DOWNGRADE_PCT = 5.0`、`POSITION_CAP_BASE_DEFAULT = 20.0`。
- `build_esg_result(...) -> Dict[str, Any]`：组装 §3.3 顶层 JSON。

### 5.2 折价三通道判定（实现步骤①~③）

**通道一：估值折价系数 `discount_factor`**

```text
base = DISCOUNT_TABLE[(env_risk_level, transition_pathway 若 env=高 否则忽略)]
if stranded_asset:
    discount_factor = max(DISCOUNT_FLOOR, base - STRANDED_EXTRA_DISCOUNT)
else:
    discount_factor = base
```

| env_risk_level | transition_pathway | stranded | discount_factor | discount_pct |
| --- | --- | --- | --- | --- |
| 低 | （忽略） | 否 | 1.00 | 0.0% |
| 低 | （忽略） | 是 | 0.95 | 5.0% |
| 高 | 明确 | 否 | 0.95 | 5.0% |
| 高 | 明确 | 是 | 0.90 | 10.0% |
| 高 | 无 | 否 | 0.85 | 15.0% |
| 高 | 无 | 是 | 0.80 | 20.0% |

- `discount_factor` 四舍五入至 2 位小数；`discount_pct = round((1 - discount_factor) * 100, 2)`。
- `discount_range`：`env_risk_level=高` 时回显 `"0.80~0.90"`；`低` 时回显 `null`。

**通道二：贴现率上调 `discount_rate_adj_bps`**

```text
if stranded_asset:
    discount_rate_adj_bps = DISCOUNT_RATE_ADJ_BPS            # 150
    discount_rate_adj_range_bps = [100, 200]
else:
    discount_rate_adj_bps = 0
    discount_rate_adj_range_bps = []
```

**通道三：仓位上限下调 `position_cap_downgrade`**

触发条件为**任一**：`env_risk_level == "高"`（框架：高环境风险行业同步降仓位上限）**或** `esg_tail == True`（框架：评级尾部先降仓位上限）。

```text
if (env_risk_level == "高") or esg_tail:
    position_cap_downgrade = POSITION_CAP_DOWNGRADE_PCT   # 5.0
else:
    position_cap_downgrade = 0.0

position_cap_after = round(position_cap_base - position_cap_downgrade, 2)
```

> **叠加默认**：两者同时命中不叠加（仍下调 5.0pct，而非 10.0pct），因框架对「高环境风险」与「评级尾部」给的是同一动作示例「绝对上限 20%→15%」，未见叠加表述（→ §9.E 待确认）。

### 5.3 区间→确定值落地规则（本任务核心难点）

框架只给区间，需固化为确定值（本方案推荐值，全部列 §9 待确认）：

| 框架原文 | 推荐确定值 | 说明 |
| --- | --- | --- |
| 8~9 折（折价 10%~20%） | 0.85（8.5 折） | 取区间中值 |
| 折价收窄至 ≤5% 或豁免 | 0.95（折价 5%） | 取保守上沿（不默认豁免） |
| 搁浅资产"折价加大" | 额外 −0.05，下限 0.80 | 使「无转型+搁浅」恰为区间下限 8 折 |
| 贴现率上调 1~2pct | +150bp | 取区间中值，回显 [100,200] |
| 绝对上限 20%→15% | 下调 5.0pct | 框架唯一明确数值 |

### 5.4 输入校验（fail-fast）

- `--env-risk-level` 必填，须在 `高/低` 词表内。
- `--transition-pathway` 须在 `明确/无` 词表内（缺省 `无`）。
- `--position-cap-base` 为 0~100 float（复用 `_parse_rate`），越界拒绝；缺省 20.0。
- 非法档位/数值 → 打印错误返回非零，**拒绝判分**；`--stranded-asset`/`--esg-tail` 为 store_true flag。

### 5.5 样例（实现步骤④）

- **最大折价例**：`高 + 无转型 + 搁浅 + 尾部` → `discount_factor=0.80`、`discount_pct=20.0`、`discount_rate_adj_bps=150`、`position_cap_downgrade=5.0`、`position_cap_after=15.0`。
- **无折价例**：`低 + 无搁浅 + 无尾部` → `discount_factor=1.00`、`discount_rate_adj_bps=0`、`position_cap_downgrade=0.0`。
