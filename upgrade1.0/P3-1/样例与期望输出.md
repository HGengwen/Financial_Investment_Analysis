# P3-1 样例与期望输出

本文件给出 `geo_policy_screen.py` 的命令用法样例、期望 JSON 输出，以及 36 组合全枚举对照表。

## 1. 用法样例

```powershell
# 显式命中（行 1：最优场景）
python tools/specialized/geo_policy_screen.py screen `
    --geo 高 --policy 高 --fund 有直接注资 `
    --as-of 2026-09-15 --basis "P3-3 scan 检索结果 + 政策/基金公告"

# 未列组合归档（高/中/有覆盖 → 行 4：高风险/回避）
python tools/specialized/geo_policy_screen.py screen `
    --geo 高 --policy 中 --fund 有覆盖
```
