# P3-1 口径隔离声明

本声明界定 `tools/specialized/geo_policy_screen.py` 的口径边界与责任分离，防止与其他工具/阶段
发生口径混用或时变数据误认。

- 声明日期：2026-09-15
- 适用范围：P3-1 新增工具及其在 GARP 框架第 0 步·0.3 中的引用

## 1. 唯一权威口径

- 本工具的矩阵规则、六行场景结论、未列组合处理与赛道两分法，**唯一权威 = 《中长期价值成长（GARP）投资框架》第 0 步·0.3**。
- 工具不引入任何新口径，不自行定义档位含义，不对框架表述做二次解释式改写。
- 任何冲突以框架原文为准；若框架修订，本工具的常量与映射须同步回归核对（见 `回归核对记录.md`）。

## 2. 时变 vs 静态分层（关键隔离）

| 层 | 性质 | 由谁负责 |
| --- | --- | --- |
| 矩阵规则表（六行 + 未列归档 + 两分法） | **静态标签**，框架明示长期适用 | 固化在本工具 `MATRIX_ROWS` / `FALLBACK_MAP` / `ROW_META` |
| 三维档位的「取值判定」（地缘/政策/基金当下档位真假） | **时变项**，随政策、基金架构、地缘事件变化 | **不由本工具负责**；由 P3-3 `scan` 检索并核验 |

- 本工具**不检索、不判定、不固化**档位真值，仅在调用方给定档位后执行规则判定。
- 调用方通过 `--as-of`（档位判定时点）与 `--basis`（判定依据/来源）显式标注时效；工具恒定输出 `time_sensitive=true` 与警示注。
- 结论仅对档位判定时点有效，跨时点复用须重新核验档位。

## 3. 本工具不做什么（负向边界）

- 不联网抓取政策公告、基金名录、公告原文。
- 不评估档位是否成立、不校验 `as_of`/`basis` 真实性（仅透传）。
- 不给出买卖建议、不输出估值结论（最终决策回到估值与业绩兑现框架，见 `risk_note`）。
- 不做地缘事件的实时归因（该项属 `mid-news-pulse` / P3-3 范畴）。

## 4. 与其他工具的口径隔离

| 工具 / 技能 | 口径域 | 与本工具的关系 |
| --- | --- | --- |
| `geo_policy_screen.py` | 0.3 六行矩阵 + 赛道两分法 | 本工具（唯一 0.3 矩阵判定入口） |
| `trend_tech_screen.py` | 景气五维打分 + 地缘二维修正 | 各自独立；地缘维度字段与档位不同，不得混用 |
| P3-3 `scan` | 政策/基金/地缘档位实时核验 | 上游：产出本工具所需的档位取值（`as_of`/`basis`） |
| 框架支柱四/五 | 个股级细研 | 下游：消费本工具的赛道判定 + 支柱五核验基金介入细节 |

- 本工具只回答「给定三维档位 → 落在矩阵哪一行 / 哪个赛道」，不替代支柱四/五的个股级判定。

## 5. 禁止 LLM 心算

- 36 组合 → 行号/场景/赛道 的映射**必须**通过本工具产生，技能与研究报告不得由 LLM 手抄映射表。
- 报告或技能需引用 0.3 结论时，一律调用 `screen` 命令并保留 JSON 输出与 `input` 回显，确保可追溯、可复核。

## 6. 例外与升级路径

- 若未来框架新增档位或调整未列组合归档原则，须先更新框架正文，再同步 `MATRIX_ROWS` / `FALLBACK_MAP` 与对应单元测试，并重跑 `回归核对记录.md`。
- 本声明随框架 0.3 修订同步更新。
