## 0. 结论摘要（TL;DR）

本任务新建纯计算工具 `geo_policy_screen.py`，将框架第 0 步·0.3 的「政策-资本-地缘三维交叉矩阵」六行判定与「赛道两分法」下沉为可执行的工具命令，禁止 LLM 心算。

- **输入**：三维档位（地缘倒逼强度 / 政策覆盖度 / 国字号基金介入），各档位取值见 §3。
- **输出**：JSON，核心字段 `{matrix_row, conclusion, track_type}`，附 `row_index`、`archived`、`input` 回显与口径来源标注。
- **核心难点**：框架仅给出「未列组合一律按更审慎相邻档归档」的原则，未给精确算法；本方案需将该原则固化为可测试的确定性规则（§5.3），并在实现阶段以代码常量落地。
- **时变性与边界（关键分层）**：矩阵规则表为静态标签（框架明示长期适用），但**三维档位的"取值判定"是时变项**——地缘倒逼/政策覆盖/基金介入会随制裁、政策、基金动态变化。故本工具**不做检索、不判定档位真假、不固化档位**（实时核验交由 P3-3 `scan`），但通过可选入参 `--as-of`/`--basis` 透传档位判定时点与依据，并在输出加 `time_sensitive` 警示，避免把时变档位当成永久结论。不含国产化率四梯队（P3-2）、不含 `scan` 数据检索（P3-3）。

## 1. 目标与范围

### 1.1 目标

新建 `tools/specialized/geo_policy_screen.py`，实现：

1. 0.3 三维交叉矩阵的**六行精确判定**（六行命中率 100%）。
2. **赛道两分法**分发：地缘倒逼型 / 政策资本驱动型。
3. **未列组合归档护栏**：凡未显式列入六行的合法档位组合，一律按「更审慎相邻档」归档，不得默认放行。

### 1.2 包含范围

- 六行矩阵规则表（常量固化）。
- 三维档位词表与输入校验（fail-fast 拒绝非法档位值）。
- 赛道两分法判定逻辑。
- 未列组合的「更审慎相邻档」归档映射。
- 档位时效审计：可选入参 `--as-of`/`--basis` 透传 + 输出 `time_sensitive` 警示。
- CLI 子命令 `screen`（单组合判定，输出 JSON）。
- 单元测试（六行全命中 + 越界拒绝 + 未列归档 + JSON 可解析）。

### 1.3 不包含范围（明确排除，防范围蔓延）

- **不含**国产化率四梯队分层量化（P3-2）。
- **不含** `scan` 子命令与制裁清单/基金额度的网络检索（P3-3）。
- **不做**档位真伪/时效性的网络核验（属 P3-3 `scan`）；本工具仅透传调用方提供的时点与依据，**不自行判定档位、不固化档位**。
- **不含**任何与支柱四/支柱五的估值、透率、仓位联动（属后续 GARP 技能编排，非本工具职责）。
- **不改动**既有 `.trae/skills/` 下 43 技能文件。
- **不改动**既有工具签名（`trend_tech_screen.py` 等仅作代码风格参照，不修改其内容）。

## 2. 关键量化口径（唯一权威 = 框架第 0 步·0.3）

> 以下全部取自《中长期价值成长（GARP）投资框架》第 0 步·0.3，是唯一权威。任何实现与本文档或总计划/详细计划不一致时，**以框架正文为准**。

### 2.1 三维交叉矩阵（六行，权威照录）

| 行 | 地缘倒逼强度 | 政策覆盖度 | 国字号基金介入 | 投资含义（conclusion） |
| --- | --- | --- | --- | --- |
| 1 | 高（已制裁/断供） | 高（超常规+全链条） | 有直接注资 | **最优场景**：替代确定性和节奏均被外部力量锁定 |
| 2 | 高 | 中 | 有专项子基金 | **次优场景**：替代方向明确，但节奏受技术突破制约 |
| 3 | 中（制裁升级中） | 高 | 有覆盖 | **潜伏场景**：制裁尚未落地但概率高，提前布局等待催化 |
| 4 | 高（已制裁/断供） | 低/无 | 无覆盖 | **高风险/回避**：下游被迫替代但国产短期接不住，须先验证承接能力，承接不足则回避 |
| 5 | 低 | 中/高 | 有覆盖/注资 | **政策驱动型增量创造**：不以地缘倒逼为门槛，达标与否以政策覆盖+基金介入（支柱五）为准 |
| 6 | 低 | 低 | 无覆盖 | **回避**：替代节奏完全依赖市场驱动，不确定性过高 |

### 2.2 未列组合处理（权威原文）

> 地缘倒逼强度、政策覆盖度、国字号基金介入各含高低档，本表仅列六类代表性组合。**凡未显式列出的中间组合（如"政策覆盖度低但国字号基金有覆盖"），一律按更审慎的相邻档位归档处理，不得因未列而默认放行。**

### 2.3 关键风险提示（权威原文，写入结论旁注）

> 国字号基金的注资应被视为"政策优先序列"的信号，而非买入估值的依据……**最终决策仍需回到估值和业绩兑现框架。**

### 2.4 赛道两分法（权威原文）

> 科技/高端制造国产化赛道按"成长驱动主因"分为两类——
> - **地缘倒逼型**：成长由"被制裁/断供→被迫替代"驱动，地缘倒逼强度是确定性下限。
> - **政策资本驱动型**：成长由"政策创造需求 + 基金催化"驱动。
>
> 判别方法：先看 0.3 三维矩阵的行归属——"高倒逼强度"起步的赛道属地缘倒逼型；"低倒逼强度 + 政策/基金高"起步的赛道属政策资本驱动型。**两类并非互斥，介于其间时按更审慎的那类执行。**

## 3. 输入/输出签名

### 3.1 三维档位词表（唯一合法取值范围）

| 维度 | 参数 | 合法档位值（中文词表） | 对应框架表述 |
| --- | --- | --- | --- |
| 地缘倒逼强度 | `--geo` | `高` / `中` / `低` | 高（已制裁/断供）/ 中（制裁升级中）/ 低 |
| 政策覆盖度 | `--policy` | `高` / `中` / `低` | 高（超常规+全链条）/ 中 / 低·无 |
| 国字号基金介入 | `--fund` | `有直接注资` / `有专项子基金` / `有覆盖` / `无覆盖` | 四档，见下方说明 |

> **基金介入为何四档**：框架六行的基金列实际出现四类取值（有直接注资 / 有专项子基金 / 有覆盖 / 无覆盖），为精确命中六行，本工具将 `--fund` 离散为四档。这比详细计划「各 2~3 档」的粗略表述更细，依据是框架正文（唯一权威）。此决策列为 §9 待确认点 A。

### 3.2 CLI 命令

```text
python tools/specialized/geo_policy_screen.py screen \
    --geo 高 \
    --policy 高 \
    --fund 有直接注资 \
    --as-of 2026-09-15 \
    --basis "P3-3 scan 检索结果 + 政策/基金公告"
```

- 子命令 `screen`：单组合三维判定。P3-3 将扩展 `scan` 子命令，命名不冲突。
- 可选入参 `--as-of`（档位判定的数据截止日期）、`--basis`（判定依据/来源），仅透传到输出，**不参与判定**；缺省时输出 `as_of`/`basis` 为 `null`，由 P3-3 `scan` 补齐。
- 档位值非法（不在词表内）→ 打印错误并返回非零退出码，**拒绝判分**（不归档）。

### 3.3 输出 JSON Schema

```json
{
  "row_index": 1,
  "matrix_row": "最优场景",
  "conclusion": "替代确定性和节奏均被外部力量锁定",
  "track_type": "地缘倒逼型",
  "archived": false,
  "archive_from": null,
  "time_sensitive": true,
  "time_sensitivity_note": "档位为时变输入，结论仅对档位判定时点有效，须以最新数据复核",
  "risk_note": "国字号基金注资是政策优先序列信号，非买入估值依据；最终决策回到估值与业绩兑现框架",
  "source": "框架第0步·0.3",
  "input": {"geo": "高", "policy": "高", "fund": "有直接注资", "as_of": "2026-09-15", "basis": "P3-3 scan 检索结果 + 政策/基金公告"}
}
```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `row_index` | int | 行号 1~6（机器唯一键） |
| `matrix_row` | str | 六行场景中文名：最优场景 / 次优场景 / 潜伏场景 / 高风险·回避 / 政策驱动型增量创造 / 回避 |
| `conclusion` | str | 投资含义全文（照录框架） |
| `track_type` | str | `地缘倒逼型` / `政策资本驱动型` / `回避`（见 §5.2） |
| `archived` | bool | `true` = 未列组合按更审慎相邻档归档 |
| `archive_from` | str\|null | `archived=true` 时给出原三维组合，用于审计 |
| `time_sensitive` | bool | 恒为 `true`：档位为时变输入，非永久结论 |
| `time_sensitivity_note` | str | 警示「结论仅对档位判定时点有效，须以最新数据复核」 |
| `risk_note` | str | 关键风险提示（框架 2.4 节，恒定） |
| `source` | str | 口径来源（可追溯） |
| `input` | dict | 原始输入回显，含 `geo/policy/fund` 及可选 `as_of`/`basis`（档位判定时点/依据，由调用方或 P3-3 补齐） |

## 5. 实现设计（五步，与详细计划对齐）

### 5.1 数据模型

- `@dataclass GeoPolicyResult`：字段对齐 §3.3，含 `asdict()` 序列化。
- 常量 `MATRIX_ROWS`：六行规则表展开为 **11 条显式命中**（行 4 政策「低/无」在词表内合并为「低」；行 5 政策「中/高」 × 基金「有覆盖/有专项子基金/有直接注资」三档 = 6 条；行 1/2/3/4/6 各 1 条），严格照录 §2.1。
- 常量 `GEO_VALUES / POLICY_VALUES / FUND_VALUES`：三维档位词表。
- 常量 `FALLBACK_MAP`：未列组合 → 更审慎相邻档（§5.3，共 25 条 = 36 − 11）。

### 5.2 赛道两分法分发（实现步骤②）

按框架判别方法，六行 `track_type` 映射如下：

| 行 | 起步倒逼 | 分发判定 | `track_type` |
| --- | --- | --- | --- |
| 1 | 高 | 高倒逼起步 | 地缘倒逼型 |
| 2 | 高 | 高倒逼起步 | 地缘倒逼型 |
| 3 | 中 | 介于两类之间 → 按更审慎（硬门槛更严）一类 | 地缘倒逼型 |
| 4 | 高 | 高倒逼起步（但结论为回避倾向） | 地缘倒逼型 |
| 5 | 低 | 低倒逼 + 政策/基金高 | 政策资本驱动型 |
| 6 | 低 | 低倒逼 + 政策/基金均低，不属于两类可投赛道 | 回避 |

> 行 3 与行 6 的处置源自框架原文「介于其间时按更审慎的那类执行」与两分法「科技/高端制造国产化赛道」限定，列为 §9 待确认点 C。

### 5.3 未列组合归档护栏（实现步骤③，本任务核心难点）

**先区分两类护栏，不可混用：**

| 护栏 | 触发条件 | 行为 |
| --- | --- | --- |
| A. 输入校验 | 档位值不在词表内（如 `--geo 极高`） | **拒绝**，返回错误码，不归档（fail-fast，不猜） |
| B. 未列归档 | 档位值合法，但组合不在六行内（如 高/低/有覆盖） | 按 `FALLBACK_MAP` 归档到更审慎相邻档，`archived=true` |

**归档三原则（推荐，待 §9.B 确认）：**

1. **不变或降级**：归档目标行的三维档位，相对原始组合，任一维度**只能不变或向更审慎（更低强度）方向调整**，不得升级到更优档。
2. **审慎优先**：候选相邻档若多个，取投资含义更审慎（更保守/更回避）的一档。
3. **显式映射**：将 36 种组合（3×3×4）全覆盖为 `MATRIX_ROWS`（11 条显式命中）+ `FALLBACK_MAP`（其余 25 条未列），**每条附归档说明字段**，全部纳入单元测试，消除 LLM 临场判断。

**锚点示例（框架点名）：**

| 未列组合 | 归档目标 | 归档说明 |
| --- | --- | --- |
| 高 / 低 / 有覆盖 | 行 4（高风险·回避） | 框架点名「政策覆盖低但国字号基金有覆盖」→ 更审慎相邻档=高风险·回避，须先验证承接能力 |

> 完整 25 条 `FALLBACK_MAP` 将在实现步骤①随代码常量一次性固化，并随「样例与期望输出」交付，逐条可测试。方案阶段仅确定三原则 + 上述锚点，避免本文档过度膨胀。

### 5.4 样例（实现步骤④）

- 六行三个示例（每行一例，含行 1~6 全覆盖断言）。
- 越界示例：`--geo 极高` → 返回非零、不产出判分。
- 未列归档示例：`高/低/有覆盖` → 归档行 4，`archived=true`、`archive_from` 回显原组合。

### 5.5 回归空白（实现步骤⑤）
