## 1. 目标与范围

### 1.1 目标

产出 GARP 独立档（**1~5 年**）的景气趋势筛选技能 `/garp-trend-tech-screen {公司/行业/指数/主题}`，回答「**当下哪些标的景气与趋势最强、该怎么排序**」，并做到——

1. **四层递进式评估**（骨架机制保留）：**第零层 产业链周期定位**（决定权重）→ **第一层 前置硬性淘汰**（一票否决）→ **第二层 五维加权打分**（100 分 + 奖励分）→ **第三层 地缘与宏观修正/校准** → **最终评级 + 反证清单**；
2. **五维打分引擎零改动复用**：`trend_tech_screen.py score` 的 `--name` / `--cycle` / `--dims` / `--geo` / `--tech` / `--r8` / `--markdown-only` 与 `batch --input` 的**参数名、语义、权重算法一律不改**；本技能只负责**采集与口径映射**；
3. **地缘口径整段替换**：删除骨架「国产化率 × 海外对冲二维修正系数」，改为 **0.3 三维交叉矩阵**（地缘倒逼强度 × 政策覆盖度 × 国字号基金介入）+ **赛道两分法**（地缘倒逼型 → 硬门槛；政策资本驱动型 → 敞口体检）；矩阵由 `garp-geo-policy`（P4-1）判定，**未列组合按更审慎相邻档归档**，**国字号注资不作买入估值依据**；引擎 `--geo` 通道**中性占位**（系数锁定 1.00），骨架乘数**禁止再参与打分**；
4. **叠加宏观三表校准**（共性 7）：利率周期 → **调整后 PEG 合理买入区间**（加息 0.8~1.0 / 中性 1.0~1.2 / 降息 1.2~1.5）、经济周期 → **现金仓位与个股上限**、美林时钟 + 信用周期 → **宏观阶段收口**；参数一律经 `garp-macro`（P4-2）与 `macro_calibrator.py` 透传，本技能**不判 stage、不心算**；
5. **估值维度 GARP 化**：⑤估值安全垫得分由 `garp-valuation`（P4-5）**统一六档 + 多工具矩阵**结论**映射**，本技能**零估值结论、零 PEG 算式**，且 `PSG` 不得作主锚、`target_pe` 不得出现（禁用词 15 / 16）；
6. **费雪质化验证层**（共性 1，新增）：在五维打分之外增设**不计分的第六层**——质化四问（管理层品质 / 持有竞争优势 / 研发能力 / 销售组织）+ **闲聊法**证据链 + **「绝不卖」两前提**（① 极度深度研究认知 ② 极度集中持仓）检验；
7. **卖出与止损只引不重建**：技术面校验（`--tech`）**仅作引擎内评级降级与风险提示**；正式卖出纪律（五级优先级 + 8~10% 硬止损 + 4 季度时间止损 + ATR 动态止损）**一律转接 `garp-exit`（P4-6）**；
8. **结论明确**：四模式（个股 / 行业 / 指数 / 主题）统一输出 **S/A/B/C 评级 + 五维得分明细 + R8 评分卡 + 反证清单 + 行业景气一致性 + 后置转接**；行业/指数/主题模式额外输出**通过率统计、行业内排名、景气一致性判断、板块对比总结**。

### 2.4 地缘：0.3 三维交叉矩阵 + 赛道两分法（**替换骨架二维，共性 3**）

**矩阵（照引框架 0.3，行 163~172）**：

| 地缘倒逼强度 | 政策覆盖度 | 国字号基金介入 | 投资含义 |
| --- | --- | --- | --- |
| 高（已制裁/断供） | 高（超常规+全链条） | 有直接注资 | **最优场景**：替代确定性和节奏均被外部力量锁定 |
| 高 | 中 | 有专项子基金 | **次优场景**：替代方向明确，但节奏受技术突破制约 |
| 中（制裁升级中） | 高 | 有覆盖 | **潜伏场景**：制裁尚未落地但概率高，提前布局等待催化 |
| 高（已制裁/断供） | 低/无 | 无覆盖 | **高风险/回避**：下游被迫替代但国产短期接不住，须先验证承接能力，承接不足则回避 |
| 低 | 中/高 | 有覆盖/注资 | **政策驱动型增量创造**：不以地缘倒逼为门槛，达标与否以政策覆盖+基金介入（支柱五）为准 |
| 低 | 低 | 无覆盖 | **回避**：替代节奏完全依赖市场驱动，不确定性过高 |

**附带条款（刚性）**：

1. **未列组合**一律按**更审慎的相邻档位**归档，不得因未列而默认放行（框架行 176）；
2. **国字号注资**视为「政策优先序列」信号，**不得作为买入估值依据**（框架行 178）；
3. **时变项**（制裁清单 / 出口管制 / 关税 / 国产化率）评估前须**实时核验**，禁用历史清单；
4. **赛道两分法**（框架行 180~185）：**地缘倒逼型**（半导体设备/材料等）→ 支柱四对地缘倒逼强度作**硬门槛**（非「低/无」方可建仓）；**政策资本驱动型**（机器人、信创等）→ 仅作**敞口体检**；两类非互斥时**按更审慎那类执行**。

**引擎 `--geo` 通道的处理（门禁 A，见 §9）**：

```text
骨架旧口径（废止）：修正系数 = 国产化率[X] × 海外对冲[Y]     → 0.40 ~ 1.10
                    「最终得分 = (五维加权总分 + 奖励分) × 地缘修正系数」

GARP 新口径（本技能）：
  地缘档位判定   → 由 garp-geo-policy（P4-1）输出 0.3 矩阵行归属（六类场景）
  地缘闸门       → 归「高风险/回避」或「回避」→ 淘汰（GTS-3）；地缘倒逼型为硬门槛
  引擎 --geo     → 固定传 {"x":"高","y":"中"}（GEO_FACTOR = 1.00）作「中性占位」
  口径声明       → 引擎地缘乘数在 GARP 档被 0.3 矩阵取代，最终得分 = 五维加权总分 + 奖励分（× 1.00）
  禁止事项       → 不得按骨架「国产化率 × 海外对冲」任选 x/y 以取得 0.40~1.10 的乘数
```

> **为什么用「中性占位」而非改引擎**：`--geo` 为 `required=True` 且 `GEO_FACTOR` 为模块常量，**改签名/加系数参数会破坏「引擎零改动」刚性**；而框架**未给出** 0.3 矩阵各场景的修正系数数值，**自行发明系数将构成臆造阈值**。故采「矩阵作闸门 + 乘数中性化」，7.3「地缘二维 → 0.3 三维矩阵」的替换意图完整落地。
> **骨架 Y 轴（海外非制裁实体对冲有效性）的处置**：框架**未定义**该口径，属骨架自有机制 → **整段废除**，仅保留「海外收入占比 / 供应链可控性」作为**敞口体检项**（框架行 196）。

### 2.5 宏观三表与 PEG 区间联动（**共性 7，新增**）

**（一）利率周期 → 调整后 PEG 合理买入区间（框架行 700~713）**：

| 利率环境 | 调整后 PEG 合理买入区间 | 低估（可加仓） | 高估（减机动仓） |
| --- | --- | --- | --- |
| **加息/高利率周期** | 收紧至 **0.8~1.0** | <0.7 | >1.2 |
| **中性**（基准） | **1.0~1.2** | <1.0 | >1.5 |
| **降息/低利率周期** | 放宽至 **1.2~1.5** | <1.2 | 仍 >1.5 减仓，**>2 绝对透支清机动仓** |

**（二）经济周期 → 现金仓位与个股上限（框架行 719~730）**：

| 参数 | 中性/复苏期（基准） | 衰退期（收紧） | 滞胀期（进一步收紧） | 过热期 |
| --- | --- | --- | --- | --- |
| **现金仓位** | 10%~20%（估值分位>80% 时 20%~30%） | 30%~40% 或更高 | **≥40%** | ≥25% |
| **单只个股上限** | 初始≤10% / 验证后≤15% / 绝对≤20% | 初始≤8% / 验证后≤12% / 绝对≤15% | 初始≤6% / 验证后≤10% / 绝对≤12% | 初始≤8% / 验证后≤12% / 绝对≤15% |
| **单一行业上限** | ≤40% | ≤30% | ≤20% | ≤25% |

**（三）美林时钟 + 信用周期 → 框架参数收口（框架行 736~748）**：

| 宏观阶段 | 风格倾向 | PEG 合理买入上限 | 现金仓位 | 单只上限（验证后） |
| --- | --- | --- | --- | --- |
| **衰退** | 防御、低波成长优先 | 1.0（临时收紧） | 30%~40% | ≤12% |
| **复苏** | 成长/顺周期优先 | 1.5（放宽） | 10%~20% | ≤15% |
| **过热** | 周期/价值优先 | 1.0（收紧） | ≥25% | ≤12% |
| **滞胀** | 现金/防御为主 | 0.8（最紧） | ≥40% | ≤10% |

> **执行纪律**：三表参数**一律经 `garp-macro`（P4-2）输出 + `macro_calibrator.py` 透传**，本技能**不判 stage、不心算**；`PEG>2 为严重透支`**不因降息取消**（框架行 712）。**输出必须叠加**：报告中「估值」节须同时给出**个股 PEG 档位**与**当期宏观 PEG 区间**，并标注**是否越界**（这是本技能相对骨架的输出增益）。

### 2.6 估值：多工具矩阵（**共性 6；只读 `garp-valuation`**）

| 公司类型 | 核心工具 | 辅助工具 | 可接受标准（框架行 384~388） |
| --- | --- | --- | --- |
| **快速增长型（盈利稳定）** | 调整后 PEG | 远期 PE、PEG 分位 | PEG<1 低估 / 1~1.2 合理 / 1.2~1.5 合理偏贵 / **>1.5 高估** |
| **高研发投入型（利润被压低）** | PS / EV/Sales | Rule of 40 | Rule of 40 ≥ 40；EV/Sales 低于同业可比 |
| **未盈利科技型** | PS、EV/Sales | 研发管线 NPV | 需有清晰盈利路径和里程碑节点 |
| **稳定增长型** | 远期 PE + 隐含 PEG | 股息率 | 隐含 PEG ≤ 1.2 |
| **成熟型企业** | DCF | 股息贴现 | 市值 ≤ 保守 DCF 估值的 80% |

- **唯一档位出口**：`garp-valuation`（P4-5）的**统一六档 + 多工具矩阵** + **ESG 环境风险折价** + **宏观 PEG 区间**；本技能**不重述档位表、零 PEG 算式**；
- **本技能只做映射**：`--dims.e` 传「统一六档 → 10 分制」的**档位映射分**（映射规则由 `garp-valuation` 口径决定，本技能不新增阈值）；
- **禁用项（刚性）**：`PSG` **不得作主锚、不得作独立打分项**；估值结论**不得出现** `target_pe` 类目标价字段；⑤维度得分**不得替代** `garp-valuation` 的正式估值结论；
- **估值倒推验证（不占分，保留骨架）**：`financial_rigor.py implied-growth` 计算隐含增速要求 → 与公司指引比较，红灯（隐含增速 > 指引上限 × 1.5）→ **评级下调一级**；
- **陷阱清单**（骨架 → GARP 化）：低 PE 陷阱 / 高 PE 但增速不可持续 / 忽略股权稀释 / **研发费用化扭曲**。

### 2.7 卖出与止损：**引用 `garp-exit`，技术面仅作降级（门禁 C）**

**五级卖出（框架第三部分·三，行 473~505；本技能只引用）**：

| 级别 | 触发条件 | 决策 |
| :--: | --- | --- |
| **一级 诚信否决** | 管理层诚信问题暴露、财务造假实锤、监管立案 | 立即清仓，不看估值与趋势 |
| **二级 硬止损** | 单笔亏损 8%~10% 且无明确基本面反转信号 | 无条件止损 |
| **三级 逻辑止损** | 连续 2 季业绩低于预期且景气未改善；或持有满 4 季度逻辑未兑现（**时间止损**） | 减仓或清仓 |
| **四级 产业景气判断** | 前三项未触发，但渗透率/ROE 出现拐点（景气尚可、仅节奏放缓） | 减机动仓、降仓位 |
| **五级 估值判断** | 以上均未触发，仅估值/情绪波动 | 底仓不动，机动仓调整 |

> **铁律**：上层未通过，下层不讨论；顺序固定一级 → 五级，命中即停。**实现一律引用 `garp-exit`，本技能不重定义**。

**技术面校验（骨架 `--tech`）的定位**：

```text
骨架旧口径：跌破 50 日均线且放量 → 降 B 级、减仓 50%
            跌破 200 日均线        → 直接清仓/移出关注池
            （"技术面红牌为最高优先级，即时生效"）

GARP 新口径：--tech 通道保留（引擎签名不改）
            督导范围 = 引擎内评级降级 + 报告风险提示
            「降 B 级」保留为【评级降级】；「跌破 200 日线清仓」改为【提示 + 转接 garp-exit】
            正式止损一律走 garp-exit（8~10% 硬止损 / ATR 动态止损 / 4 季度时间止损）
            口径登记：50/200 日均线止损为【骨架推导口径】，框架正文未提及（仅提 ATR）
```

**ATR 止损**：一律**经 `garp-exit`（P4-6）转接 `momentum.stop_price()`**（内部调用 `atr()`，`period=14`、`multiplier=2.0` 默认），**禁止心算**；本技能**不自建止损计算链、不新增 CLI**。

### 2.8 费雪质化验证层（**共性 1；门禁 B**）

> **位置**：五维打分与地缘/宏观修正**之后**的**独立评审层**，**不计分**、不改变引擎输出；仅对 **S/A 级**标的执行。

| 评审项 | 问题 | 证据来源 |
| --- | --- | --- |
| **管理层品质** | 是否诚实、是否利益一致？（**诚信问题一票否决**） | 年报承诺兑现率、互动易、监管记录 |
| **持有竞争优势** | 优势是否可持续、是否在扩宽？ | 毛利率/份额趋势、CR5、护城河清单 |
| **研发能力** | 研发是否有效转化为产品与利润？ | MROI、新品收入占比、专利（R8 数据源） |
| **销售组织** | 是否有行业领先的销售组织？ | 经销商覆盖密度、销售团队离职率、销售费用率（框架行 304） |
| **闲聊法证据链** | 竞品 / 供应商 / 客户 / 员工四个侧面是否印证？ | `anysearch` / `doubao_search` / `exa_search` 多源交叉 |
| **「绝不卖」两前提** | ① 是否具备**极度深度的研究认知**？② 是否属**极度集中持仓**？ | 自评项（须标注「自评项，非工具化判据」） |

```text
IF 诚信问题命中 → 立即淘汰/清仓（GTS-2），费雪层不豁免
IF 两前提未同时满足 → 「长期持有/绝不卖」结论【不成立】，须按 garp-exit 五级纪律执行
IF 两前提同时满足 AND 下跌属「暂时性困难」（框架行 511~520 六维清单）→ 可继续持有甚至加仓
```

> **口径边界**：**「不卖」是认知深度的奖赏，不是不研究的借口**（框架行 631~648 矛盾五）。本技能**只做质化验证与前提检验**；管理层 **7+7+6** 与科研转化 **8+8+4** 的**完整评分**归 `garp-management`。

### 2.12 数据来源与置信度

- 关键财务数据 **≥2 独立来源**，**误差 >1% 须显式标记**；
- 打分与算术（PEG / 市值 / CAGR / 隐含增速）**一律经 `financial_rigor.py` 或引擎**，报告**不得出现手算数值**（`GTS-7`）；
- 置信度分级：**A 级**（工具/交易所原文）> **B 级**（权威第三方或券商）> **C 级**（媒体/单一来源）；**C 级不得作确定性结论**；
- 制裁清单、出口管制、国产化率、渗透率等**时变项**须标注**取数时点**，禁用历史清单；
- **年报一手数据优先**（骨架「翻石头」纪律保留）；关键财务数据不得以研报替代。

### 3.1 执行流程（八步）

| 步 | 动作 | 关键产出 |

### 3.3 降级与失败处置

| 情形 | 处置 |
| --- | --- |
| 周期阶段无法判断 | **默认「需求爆发期」权重**（继承骨架纪律），并标注「周期阶段未确认」 |
| 某市场工具连通失败（港美股接口偶发） | 重试 → 仍失败则标注「未取得」，**不以推测代替实测**；关键维度缺失 → 结论降级 |
| 渗透率 / 国产化率 / 制裁清单取不到 | 标注「**未验证**」+ 区间上下限，**不默认落黄金区**；引用 `garp-geo-policy` 核验入口 |
| `garp-geo-policy` / `garp-macro` / `garp-valuation` 未跑过 | 提示先运行；确无法补跑时**显式标注置信度受限**，**不得**以推测填充矩阵/区间 |
| R8 数据不可得（非科创或披露缺失） | 按「适用对象」判定**跳过**并显式标注；科创企业**不得**以缺失为由跳过 |
| `momentum` 无 `--tech` 数据 | `--tech` 传空（引擎不做技术面否决）并标注「技术面未校验」 |
| 引擎或工具报错 | 记录**原始报错与退出码**，标注「工具缺陷候选」并登记入待上报事项，**不得静默吞掉** |

### 3.4 风控硬编码（`GTS-1`~`GTS-12`，本技能新增；已实测全仓 `GTS-` 命中 = **0**）

| 编号 | 规则 | 不可做的事 |
| --- | --- | --- |
| `GTS-1` | **前置硬性淘汰**：①实体清单 + 核心环节国产化率<30% + 无非制裁海外有效实体；②核心技术人员流失>30% 且人均创利连续 2 年暴跌>40%；③在手订单（合同负债）同比<−50% 且存货周转天数同比增>80% → **直接淘汰** | 不得对命中标的继续打分 |
| `GTS-2` | **诚信一票否决**（框架优先级1）：兑现率<50% / 业绩预告重大失真 / 财务造假实锤 / 监管立案 → **淘汰或清仓** | 不得以五维高分或 R8 奖励豁免 |
| `GTS-3` | **地缘闸门**：0.3 矩阵归「高风险/回避」或「回避」→ 淘汰；**地缘倒逼型**赛道地缘倒逼强度为「低/无」→ 不得建仓；**政策资本驱动型**仅作敞口体检 | 不得按骨架二维乘数（0.40~1.10）修正得分；不得因未列组合默认放行 |
| `GTS-4` | **估值透支**：调整后 PEG **>2.0** → 出排序终选；**>1.5** → 不得入底仓候选；越出当期**宏观 PEG 合理区间上限** → 评级下调 | 不得以「高增速」豁免 PEG>2 红线；不得心算 PEG |
| `GTS-5` | **技术面降级**：`--tech` 触发 `warning` → 引擎降级并**仅作风险提示**；触发 `red` → 引擎内降级 | 不得把技术面红牌直接写成清仓指令；正式止损须转 `garp-exit` |
| `GTS-6` | **流动性门槛**：日成交额 >1 亿；市值 <100 亿可放宽至 >3000 万 | 不得把小市值高波动标的纳入重仓候选 |
| `GTS-7` | **计算纪律**：五维得分一律由引擎输出；估值/市值/PEG/隐含增速一律经 `financial_rigor.py`；ATR 止损价经 `garp-exit` 转接 `momentum.stop_price()` | **禁止 LLM 心算**；禁止自建止损链；禁止改写引擎终值 |
| `GTS-8` | **R8 风险降级**：R8 < 0 → 评级下调一级，且**不得重仓** | 不得忽略在研项目风险警告 |
| `GTS-9` | **数据置信度**：关键数据单一来源 → 标注「单一来源，置信度低」；C 级不得作确定性结论 | 不得以单一来源支撑 S/A 级结论 |
| `GTS-10` | **引擎签名冻结**：`score` / `batch` 参数名与语义不得改动；引擎落盘副作用须登记 | 不得为「适配 GARP」修改引擎或新增参数 |
| `GTS-11` | **不越权替代买入门槛**：本技能只做**正向排序**，S/A 级须**强制转接** `garp-investment-checklist` 七关 | 不得将 S 级直接视为「可买入」 |
| `GTS-12` | **报告与口径隔离**：报告命名一律含 `garp-` 标识；引用只指向 `garp-*` 与复用 2 技能 | 不得触碰中期链/长期链报告文件；不得出现其他档位可执行口令 |

> 所有硬性规则输出必须包含**规则编号引用**（如「触发 `GTS-3`」），确保可审计可追溯。
