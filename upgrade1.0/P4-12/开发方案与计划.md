## 1. 目标与范围

### 1.1 目标

产出 GARP 独立档（**1~5 年**）的单公司深度研究技能 `/garp-investment-research {公司名}`，回答「**这家公司值不值得买、买多少、什么时候买、什么条件下卖**」，并做到——

1. **八模块研究框架**（骨架机制保留，模块顺序不改）：**前置 AI 研究偏见预警** → **① 数据收集** → **② 生意本质与产业定位** → **③ 护城河评估** → **④ 逆向思考与风险清单** → **⑤ 产业景气与 ROE 拐点** → **⑥ 管理层与科研转化评估** → **⑦ 估值与买入时机** → **⑧ 综合决策备忘录与卖出纪律**；
2. **五大师视角贯穿**（共性 1）：费雪（质化分析 / 闲聊法 / 十五要点 / 诚信一票否决 / 「绝不卖」两前提）+ 林奇（常识验证 / 六类股票 / 侦探求证）+ 郑希（第一性原理 / 产业周期 / ROE 拐点）+ 李进（系统均衡 / 渗透率刻度 / 回撤控制）+ 欧奈尔（趋势信号 / 止损纪律），**每位大师在每个模块末尾的「追问」逐段落地**，骨架语录与表述**整段替换**；
3. **估值结论改多工具矩阵**（共性 6）：按**五类公司类型**（快速增长型 / 高研发投入型 / 未盈利科技型 / 稳定增长型 / 成熟型）匹配**主锚 + 辅锚 + 可接受标准**，**统一收口至 `garp-valuation`（P4-5）统一六档**，并叠加 **ESG 折价**与**宏观 PEG 合理区间**；骨架「单一 PEG + `valuation-thermometer` 五档 + 股息率对照国债」**整段废止**；
4. **渗透率与国产化率双口径**（共性 2）：渗透率 `15%~40%` 黄金窗五档（<5% 导入早期观察不建仓 / 5%~15% 突破期小仓跟踪 / **15%~40% 加速上行黄金窗主建仓** / 40%~60% 逐步兑现持有不新建 / >60% 天花板不加仓；增速归零或转负即见顶清仓）+ 国产化率四梯队（<5% 过早 / 5%~20% 突破期 / 20%~50% 加速投资期 / >50% 收窄），**一律引用 `garp-industry-research`（P4-9）**，本技能**不做赛道级测算**；
5. **地缘模块整段替换**（共性 3）：删除骨架「地缘政治六维度」与「『华为式』抗封锁能力 20 分制」，改为 **0.3 三维交叉矩阵 + 赛道两分法**（引用 `garp-geo-policy` P4-1）+ **支柱四八项敞口体检**；矩阵**未列组合按更审慎相邻档归档**，**国字号注资不作买入估值依据**；
6. **管理层与科研转化口径替换**（共性 5）：**诚信前置不计分闸门**（`integrity_veto` 命中即放弃）+ **对待股东 7 + 战略执行 7 + 稳定性与激励 6** + **科研转化 研发投入 8 + 研发产出 8 + 资本回报 4** + 费雪补充项（销售组织 / 管理层持股≥3% / 暂时性困难 vs 永久性衰退）+ ESG 三通道修正，**一律引用 `garp-management`（P4-4）**；骨架 5+5+5+5 评分表**不得复现**；
7. **卖出与止损只引不重建**（共性 4）：**五级卖出**（诚信否决 > 硬止损 8%~10% > 逻辑止损 > 产业景气判断 > 估值判断）+ **时间止损**（持有满 4 季度逻辑未兑现）+ **性价比替换**（每季最多 1 次），**一律引用 `garp-exit`（P4-6）**；ATR 止损为**建议工具**且经 `garp-exit` 转接 `momentum.stop_price()`；
8. **叠加宏观三表校准**（共性 7）：利率周期 → **PEG 合理买入区间**（加息/高利率 0.8~1.0 / 中性 1.0~1.2 / 降息/低利率 1.2~1.5）、经济周期 → **现金仓位与个股上限**（衰退现金 30%~40%、单只初始≤8% / 验证后≤12% / 绝对≤15%）、美林时钟 + 信用周期 → **宏观阶段收口**，参数一律经 `garp-macro`（P4-2）与 `macro_calibrator.py` 透传，本技能**不判 stage、不心算**；
9. **专节一改五大矛盾化解**（骨架四大矛盾 → 框架五矛盾）：**矛盾一**买点哲学（左侧 vs 右侧，以「杀估值 vs 杀逻辑」为分水岭）+ **矛盾二**持有时间维度（连续 2~3 季数据趋势）+ **矛盾三**止损 vs 越跌越买（以「仓位状态」为分水岭 + 8%~10%）+ **矛盾四**分散 vs 集中（5~10 只 / 3~4 核心 / 2~3 卫星）+ **矛盾五**费雪「绝不卖」vs 趋势景气纪律（**两前提缺一不可**：极度深度的研究认知 + 极度集中的持仓）；
10. **结论明确**：报告必须给出**三档结论之一**（可建仓 / 观察仓 / 放弃）——由**五大支柱汇总判定**（全部达标 → 进入估值锚定可建仓；部分不达标 → 观察仓，最多轻仓跟踪；任一否决命中 → 放弃或清仓）收口，**并附分批建仓计划、卖出触发条件、硬止损位**。

### 2.5 渗透率与国产化率双口径（**共性 2；引用 `garp-industry-research`**）

**渗透率五档**（管「**何时买**」）：

| 档 | 区间 | 操作含义 |
| --- | --- | --- |
| 导入早期 | **<5%** | 不确定性高，**观察不建仓** |
| 突破期 | 5%~15% | 高弹性，**小仓跟踪** |

| 天花板 | **>60%** | 即便增速暂未转负也**不加仓**；**一旦增速归零/转负即视为见顶、清仓** |

> **分工纪律（框架行 197）**：渗透率定位**产业**所处阶段（管「何时买」），国产化率定位**国产企业**可替代空间（管「标弹性」）；科技赛道**两者叠用**，不得互相替代。
>
> **口径禁令**：骨架「10%~30% 黄金区」表述**不得出现**（禁用词第 1 项）；国产化率分层**不得自建梯队数**，一律引用 `garp-industry-research`（P4-9）与 `garp-geo-policy`（P4-1）。

### 2.8 估值：多工具矩阵 + 统一六档（**共性 6；只读 `garp-valuation`**）

**五类公司类型 × 估值矩阵（框架行 382~388，逐字落表）**：

| 公司类型 | 核心工具 | 辅助工具 | 可接受标准 |
| --- | --- | --- | --- |
| **快速增长型（盈利稳定）** | **调整后 PEG** | 远期 PE、PEG 分位 | PEG<1 低估 / 1~1.2 合理 / 1.2~1.5 合理偏贵（持有不加仓、机动仓择机减）/ **>1.5 高估** |
| **高研发投入型（利润被压低）** | **PS / EV-Sales** | **Rule of 40** | **Rule of 40 ≥ 40**（收入增速 + 利润率或 FCF 利润率）；EV/Sales 低于同业可比 |
| **未盈利科技型** | PS、EV/Sales | **研发管线 NPV** | 需有清晰的盈利路径与里程碑节点 |
| **稳定增长型** | 远期 PE + **隐含 PEG** | 股息率 | 当前 PE ≤ 未来 3 年 EPS 复合增速（百分数值）×1.2（**隐含 PEG≤1.2**） |
| **成熟型企业** | **DCF** | 股息贴现 | 当前市值 ≤ **保守 DCF 估值的 80%** |

**三级留痕（统一收口）**：`基准档位 → 宏观校准后 → ESG 折价后 → 最终档位`，收口至 `garp-valuation`（P4-5）**统一六档**（**显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支**）。

**叠加规则**：
- **ESG / 环境风险折价**（框架行 424~439）：高环境风险行业**合理估值再打 8~9 折**；有明确碳减排承诺与可验证转型路径 → 折价收窄至 **≤5% 或豁免**；面临「搁浅资产」风险 → **DCF 贴现率额外上调 1~2 个百分点**；ESG 评级处行业尾部 → **先降仓位上限**（如绝对上限 20% → 15%），而非继续压估值。
- **宏观 PEG 区间**（§2.9）：框架 PEG 阈值以**中性宏观环境**为基准，加息/降息周期**动态上浮或下调**。
- **PEG 使用边界**（框架行 392）：PEG 适用于盈利稳定的成长股；PS/EV-Sales 适用于高研发投入或未盈利科技股；DCF 适用于现金流稳定的成熟企业；**科技股须多工具交叉验证，避免单一指标误判**。
- **科技股调整后口径**（框架行 422）：高研发投入公司研发费用化会虚增 PE/PEG，**务必用「核心经营利润」口径回算调整后 PE**（`adjusted-peg`）。

> **口径禁令**：`valuation-thermometer` / PEG 五档档位表 / `PSG` / `target_pe` **一律不得出现**（禁用词第 3 / 15 / 16 项）；本技能**零 PEG 档位自建**、**零估值结论自建**。

### 2.9 宏观三表与 PEG 区间联动（**共性 7，新增**）

| 表 | 权威值（框架行 695~748） |
| --- | --- |
| **（一）利率周期 → PEG 合理买入区间** | 加息/高利率 **收紧至 0.8~1.0**（低估 <0.7；>1.2 减机动仓）；中性（基准）**1.0~1.2**（低估 <1.0；>1.5 高估）；降息/低利率 **放宽至 1.2~1.5**（低估 <1.2；仍 >1.5 减仓，**>2 绝对透支清机动仓**）；**滞胀期进一步下探至 0.8** |
| **「合理偏贵」统一口径** | 合理买入区间之上、高估阈值之下的中间带（中性即 **1.2~1.5**）= **合理偏贵**——可继续持有底仓、**不加仓**，机动仓逢高择机减仓；**「增速确定性」三锚**：①连续 2~3 季增速稳定性 ②订单可见度（在手订单/预收/合同负债覆盖度）③竞争格局固化程度（CR5 与龙头份额趋势）；任一偏弱 → 偏贵上限**收紧至 1.2** |
| **（二）经济周期 → 现金与个股上限** | 中性/复苏：现金 **10%~20%**（估值分位>80% 时提至 20%~30%）、单只 初始≤10% / 验证后≤15% / 绝对≤20%、单一行业 ≤40%；衰退：现金 **30%~40% 或更高**、单只 **≤8% / ≤12% / ≤15%**、单一行业 **≤30%**；过热：单只 ≤8% / ≤12% / ≤15%、单一行业 ≤25%、现金 ≥25%；滞胀：单只 ≤6% / ≤10% / ≤12%、单一行业 ≤20%、现金 ≥40% |
| **（三）美林时钟 + 信用周期 → 框架参数** | 衰退：PEG 上限 **1.0**（临时收紧）、现金 30%~40%、单只（验证后）≤12%；复苏：**1.5**（放宽）、现金 10%~20%、≤15%；过热：**1.0**（收紧）、现金 ≥25%、≤12%；滞胀：**0.8**（最紧）、现金 ≥40%、≤10% |

**刚性约束**：**「PEG>2 为严重透支」红线不因降息而取消**（仅可放缓减仓节奏）；宏观**只调「估值容忍度」与「仓位尺度」**，**不替代个股基本面判断、不作为择时清仓依据**（框架行 684）；参数一律经 `garp-macro`（P4-2）/ `macro_calibrator.py` 透传，本技能**不判 stage**。

### 2.10 卖出与止损：**引用 `garp-exit` 五级（共性 4，门禁 E）**

| 优先级 | 触发条件 | 决策 |
| :--: | --- | --- |
| **1 诚信否决** | 管理层诚信问题暴露、财务造假实锤、监管立案 | **立即清仓**，不考虑估值与趋势 |
| **2 硬止损** | 单笔亏损达 **8%~10%** 且无明确基本面反转信号 | **止损离场** |
| **3 逻辑止损** | 连续 **2 个季度**业绩低于预期且产业景气未改善；财务不可逆恶化；龙头地位被颠覆 / 科研转化大幅低于预期；管理层或科研转化评分**跌破 10 分**（非诚信事项） | 减仓或清仓 |
| **4 产业景气判断** | 渗透率/ROE 出现拐点但景气尚可、**仅节奏放缓**（如进入 40%~60% 逐步兑现期）→ 减机动仓降仓位；**增速归零/转负 → 升级为逻辑恶化、清仓**（独立触发，与渗透率位置无关） | 按景气方向调仓 |
| **5 估值判断** | 调整后 PEG>1.5 高估区 → 减机动仓；**PEG>2 严重透支 → 加速清机动仓**；市场情绪极度狂热（多信号共振）→ 减机动仓 | 底仓不动，机动仓调整 |
| **补充机制** | **时间止损**：持有满 **4 个季度（1 年）**逻辑仍未兑现 → 减至观察仓或替换；**性价比替换（末位优化）**：其他标的估值显著更低且产业趋势更强可逐步切换，**每季度最多 1 次** | 兜底 / 优化 |

**止损分仓位口径**（框架行 528~538）：**「建仓初期」= ①持仓<最终仓位 50%，或 ②持仓≥50% 但逻辑尚未经 2~3 季财报持续兑现验证**（任一成立即适用 8%~10% 硬止损）；**底仓已建立且逻辑已验证**（须**同时满足**①达到最终仓位 50% ②逻辑经 2~3 季兑现）→ 下跌 ≤20% 且多维未恶化可在合理估值下限加仓；>20% 转入「暂时性困难 vs 永久性衰退」清单复核；**无论何种状态，逻辑被证伪立即清仓，不存在「越跌越买」**。

**一票否决的语境边界**（框架行 662）：优先级 1 针对**持仓后**的清仓信号；第 3 步汇总判定中的 **ROIC<5% 扩产 / 能力圈自检未通过 / 0.3 矩阵回避** 属**买入前**闸门，命中即**建仓前放弃**、**不进入卖出金字塔**。

> **口径禁令**：`P0~P5` / `P0` / `六级卖出` **一律不得出现**（禁用词第 17~19、21 项）；本技能**不自建卖出层级**、**不自建止损链**；ATR 止损为建议工具，经 `garp-exit` 转接 `momentum.stop_price()`（`atr(period=14)` / `multiplier=2.0`），骨架「跌破 50/200 日均线清仓」**不得**作为本技能卖出指令。

| 矛盾 | 化解口径（框架第五部分） |
| --- | --- |
| **一 买点哲学**（左侧逆向 vs 右侧确认） | 分水岭 = **「杀估值」可逆向、「杀逻辑」必须止损**；左侧仅适用短期利空但长期逻辑未破坏，且首批 ≤ 最终仓位 50%、剩余待右侧确认补齐 |
| **二 持有时间维度**（长期持有 vs 动态调整） | 以**连续 2~3 季数据趋势**为判据；产业链景气与 ROE 趋势未破坏 → 持有；趋势破坏 → 调仓 |
| **三 止损 vs 越跌越买** | 以**仓位状态**为分水岭 + **8%~10% 硬止损**；底仓建立且逻辑验证后容忍度放宽至 20%；**逻辑证伪立即清仓** |
| **四 分散 vs 集中** | 组合 **5~10 只**；**3~4 只核心**（单只 **12%~15%**）+ **2~3 只卫星**（单只 **5%~8%**）；最多 **2 只**上浮至 **20%**（上浮后合计 ≤2 只）；单行业 ≤40%；相关性 <0.5 |
| **五 费雪「绝不卖」 vs 趋势/景气纪律（新增）** | **两前提缺一不可**：①**极度深度的研究认知**（确信是持续创造增量价值的「杰出企业」而非普通好公司）②**极度集中的持仓**（3~5 只、占总仓位 70%）。满足「深度认知 + 高确信度 + 管理层诚信 + 护城河稳固 + 财务健康」且下跌属**暂时性困难** → 可采纳费雪逻辑继续持有甚至加仓；**缺乏前提或属永久性衰退 → 按趋势/景气纪律离场或调仓**。**核心原则：费雪的「不卖」是「认知深度的奖赏」，不是「懒惰不研究的借口」** |

> **骨架阈值处置**：骨架「左侧试探 5% + 右侧加仓 10%~15%」属**无框架依据的自造阈值**，**废止**并登记为骨架推导口径；一律改引框架行 396~401、408~415 的**「首批≤最终仓位 50%」与三分法**。

### 3.3 降级与失败处置

| 情形 | 处置 |
| --- | --- |
| 市场识别失败 / 非三市场标的 | 明确标注「工具未覆盖」，**转人工/浏览器取数**，不得以境内数据代入境外标的 |

| 工具报错 | 记录**原始报错与退出码**，标注「工具缺陷候选」并登记入待上报事项，**不得静默吞掉** |

### 3.4 风控硬编码（`GIR-1`~`GIR-12`，本技能新增；已实测全仓 `GIR-` 命中 = **0**）

| 编号 | 规则 | 不可做的事 |
| --- | --- | --- |
| `GIR-1` | **能力圈闸门 + 卖出前置否决**：普通行业须同时通过「产业理解 + 财务理解 + 估值理解」三项；**科技股「技术理解」为必答项**，不过关**不得重仓**；ROIC 长期<5% 却在拼命扩产 → **一票否决** | 不得对能力圈外标的给出可建仓结论；不得以「高增速」豁免 ROIC 否决 |
| `GIR-2` | **诚信一票否决前置**：兑现率<50% / 业绩预告重大失真 / 财务造假实锤 / 监管立案 → **放弃或清仓** | 不得以其他维度高分或估值便宜豁免；不得因数据缺失而跳过该闸门 |
| `GIR-3` | **五大支柱汇总判定**：全部达标 → 进入估值锚定可建仓；部分不达标 → **观察仓**（最多轻仓跟踪）；**任一否决命中 → 放弃或清仓**；0.3 矩阵归「回避」档 → 一票回避 | 不得各支柱罗列而不收口；不得跳过三档结论直接给买入建议 |
| `GIR-4` | **卖出只引不自建**：五级优先级 + 时间止损（满 4 季度）+ 性价比替换（每季最多 1 次）**一律引用 `garp-exit`** | 不得自建第二套卖出层级；不得把技术面信号写成清仓指令 |
| `GIR-5` | **估值唯一出口**：结论须按公司类型选锚并收口 `garp-valuation` **统一六档**；**禁止以单一 PEG 作估值结论**；`PSG` / `target_pe` 不得出现 | 不得自建 PEG 档位表；不得以 LLM 心算替代 `financial_rigor.py` |
| `GIR-6` | **宏观只调参不择时**：三表参数经 `garp-macro` / `macro_calibrator.py` 透传，只调「估值容忍度」与「仓位尺度」 | 不得以宏观判断替代个股基本面结论或作为清仓依据；不得自判 stage |
| `GIR-7` | **计算纪律**：市值/估值/ROIC/PEG/Rule of 40/EV-Sales/DCF/隐含增速一律经 `financial_rigor.py`；评分经 `governance_data.py`；宏观参数经 `macro_calibrator.py`；ATR 止损价经 `garp-exit` 转接 | **禁止 LLM 心算**；禁止自建止损链；禁止改写工具终值 |
| `GIR-8` | **渗透率与国产化率口径**：渗透率五档以 **15%~40% 为黄金窗**；国产化率四梯队；两者**分工不得互相替代** | 不得出现「10%~30% 黄金区」；不得自建梯队数 |
| `GIR-9` | **地缘闸门**：0.3 三维矩阵档位**只读 `garp-geo-policy`**；**地缘倒逼型**赛道地缘倒逼强度为「低/无」→ 不得建仓；**政策资本驱动型**仅作敞口体检；未列组合按**更审慎相邻档**归档；**国字号注资不作买入估值依据** | 不得自判矩阵档位；不得发明矩阵系数；不得因未列组合默认放行 |
| `GIR-10` | **数据置信度**：关键数据 ≥2 源、误差 >1% 标记；市值手算校验；信息丰富度 A/B/C 写入报告；**C 级不作确定性结论** | 不得以单一来源支撑可建仓结论；不得以推测填补缺口 |
| `GIR-11` | **报告与口径隔离**：报告命名一律含 `garp-` 标识；引用只指向 `garp-*` 与复用 2 技能 | 不得触碰中期链/长期链报告文件；不得出现其他档位可执行口令 |
| `GIR-12` | **自评项与骨架推导口径显式标注**：能力圈四维自检、费雪「绝不卖」两前提、骨架已废止项（地缘六维 / 「华为式」20 分制 / 骨架 PEG 五档 / 左侧 5%+右侧 10~15% 阈值）须在报告中标注来源 | 不得把自评项表述为工具化判据；不得把骨架推导口径表述为框架条款 |

> 所有硬性规则输出必须包含**规则编号引用**（如「触发 `GIR-2`」），确保可审计可追溯。
