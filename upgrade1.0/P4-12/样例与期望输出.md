### 2.4 估值子命令实测（`financial_rigor.py`）

**（a）`adjusted-peg` —— 高研发投入型 / 快速增长型主锚**

```bash
python tools/common/financial_rigor.py adjusted-peg \
  --market-cap 5000 --core-operating-profit 120 --rnd-expense 60 --growth 30
```

```text
  调整后经营利润 = 核心经营利润 + 研发回加 = 120.00 + 60.00 = 180.00
  调整后 PE   = 市值 / 调整后经营利润 = 5,000.00 / 180.00 = 27.78
  调整后 PEG  = 调整后 PE / 增速 = 27.78 / 30.00 = 0.93

  ✅ 档位判定: 低估

  结构化输出: {"adjusted_pe": 27.78, "adjusted_peg": 0.93, "tier": "低估",
              "verdict": "低估（PEG<1，可加仓）", ...}
```

  WACC (校验基准):                8.00%

  ⚠️ 四档判定: 部分不达标

| 硬止损 | ATR 口径与 8%~10% 口径**双写** |
| 三档结论 | **可建仓**（需五支柱全部达标） |

> **刚性**：「可建仓」**不等于**「立即买入」——仍须**强制转接 `garp-investment-checklist`**（买入前七关硬门槛）。

### 3.3 `S3` —— 某成熟型制造标的（`--market a --depth standard`）

#### 3.3.1 关键差异（相对 `S1`）

| 模块 | `S3` 结论 |
| --- | --- |
| 林奇类型 | **稳定增长型**（成熟期，增速放缓） |
| 渗透率档 | **40%~60% 逐步兑现期** → 持有、**不再新建仓**；若**增速归零 / 转负** → 升级为逻辑恶化、**清仓**（与渗透率位置无关） |
| 公司类型 | **成熟型企业** → 主锚 **DCF**；辅锚 股息贴现；可接受标准 **当前市值 ≤ 保守 DCF 估值的 80%** |
| ESG 折价 | 若属高环境风险行业（化工 / 有色 / 钢铁 / 火电 / 高污染制造）→ 合理估值再打 **8~9 折**；有明确转型路径 → 收窄至 **≤5% 或豁免**；面临**搁浅资产** → DCF **贴现率额外上调 1~2 个百分点** |
| 三档结论 | **观察仓**（渗透率进入逐步兑现期，不具备主建仓窗口） |

### 3.4 `S4` —— 某信息稀缺标的（`--market hk --depth deep`）

#### 3.4.1 关键差异（相对 `S1`）

| 模块 | `S4` 结论 |
| --- | --- |
| 信息丰富度 | **C 级（信息稀缺）** → **执行第一性原理五问**；结论**不得为确定性**，须列「需要一手验证的问题清单」 |
| 公司类型 | **未盈利科技型** → 主锚 PS、EV-Sales；辅锚 **研发管线 NPV**（粗算）；须有**清晰的盈利路径与里程碑节点** |
| 财务门槛 | 「扣非净利润」门槛不通过 → 走**科技豁免**（营收连续增长 + 经营现金流正 + **研发强度≥15%**）；**无法通过豁免的仍应剔除** |
| 渗透率档 | **5%~15% 突破期** → 高弹性，**小仓跟踪** |
| 三档结论 | **放弃**（信息不足以支撑可建仓结论，或豁免不通过） |
| 置信度分层 | 须区分「**AI 分析置信度**」与「**投资确定性**」，并列「需要一手验证的问题清单」 |
