## 6. 隔离核验方法与证据

### 6.1 核验方法（刚性）

| 核验对象 | 方法 | 禁止做法 |
| --- | --- | --- |
| 三档目录共存 | **完整后缀段**（`-garp-` / `-mid-`）或**目录级比对** | **禁止**以 `《看懂{公司名}》` **单串计数**下结论 |
| 跨档术语 | 按 `SKILL.md` 附录 C 跨档禁用清单**逐项扫描** | 禁止在扫描指令中内联枚举禁用 token（会造成**自命中**） |
| 跨档技能名 | 排除「骨架原口径」列后的正文扫描 | 禁止把映射表引述计为越档 |

**前缀包含披露（本任务实测发现）**：

```
长期版目录名        《看懂{公司名}》            ← 前缀子串
GARP 版目录名       《看懂{公司名}》-garp-{YYYYMMDD}
中期版目录名        《看懂{公司名}》-mid-{YYYYMMDD}
```

> 纯子串检索 `《看懂{公司名}》` **会同时命中三档** → 产生**假阴性**。
> **有利事实**：`-mid-` 与 `-garp-` **互不为子串** → **后缀段级核验可安全区分**。
