## 3. 期望输出关键结论（各篇硬性落点）

| 篇 | 期望必须出现的结论要素 | 禁止出现的表述 |

| 03 | 渗透率定位结论**附「估计」标注与来源**；**TAM ≥1000 亿闸门显式判定**（不成立须明示） | `10%~30%` / `15%~30%` 口径 |
| 04 | 分业务赢家/输家结论；二阶导方向；**地缘只读结论（0.3 三维交叉矩阵 + 赛道两分法）**；**国产化率四梯队只读标注** | 自建地缘维度/权重/档位 |
| 05 | **估值档位只读 `garp-valuation` 统一六档**（显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支）；**五级卖出只读 `garp-exit`**（诚信否决 > 硬止损 8%~10% > 逻辑止损 > 产业景气 > 估值）；**「精确算术工具输出」三段（命令 + 输入 + 输出）**；费雪「暂时性困难 vs 永久性衰退」+「绝不卖」适用边界 | `P0~P5`、`exit-signal`、`valuation-thermometer`、自造卖出层级、任何指令性数值（目标价 / 建议买入价 / 建议仓位%） |
