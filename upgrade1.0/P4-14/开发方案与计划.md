## 1. 目标与范围

### 1.1 目标

产出 GARP 独立档（**1~5 年**）的**单 Agent 轻量财报精读**技能 `/garp-earnings-review {公司名} {期间}`，并做到——

1. **五大师作为分析维度标尺**（共性 1，骨架「四位大师」整段替换）：**费雪**（质化分析与长期持有：质化分析优先 / 闲聊法第一手调研清单 / 十五要点补充检查（销售组织 + 管理层持股≥3%）/ 暂时性困难 vs 永久性衰退六维清单 / 「绝不卖」前提意识）+ **郑希**（产业景气：ROE 趋势与拐点、增速二阶导、渗透率位置、供需格局）+ **林奇**（生意与估值：收入量价拆解、毛利率与现金流质量、按公司类型选估值锚、估值陷阱排查）+ **欧奈尔**（风控底线：硬止损位、趋势信号、抛售信号、8%~10% 生存红线）+ **李进**（组合管理与治理：管理层 7+7+6 与科研转化 8+8+4 结论引用、地缘档位、底仓/机动仓分离、卖出纪律执行）；**本技能为单 Agent 轻量版，五大师为「分析维度标尺」而非多 Agent 角色**（团队版归 `garp-earnings-team` P4-15，**只指向名称、不描述其内部流程**）；
2. **GARP PEG 定位**（共性 6，验收要点）：结束骨架「一律以 `/valuation-thermometer` 输出为准」，改为——**先判定公司类型**（快速增长型 / 高研发投入型 / 未盈利科技型 / 稳定增长型 / 成熟型）→ **按类型选主锚 + 辅锚**（框架行 381~387）→ `基准档位 → 宏观校准后 → ESG 折价后 → 最终档位` **四级留痕** → **收口 `garp-valuation`（P4-5）统一六档**；「**GARP PEG**」一律表述为**调整后 PEG（快速增长型主锚）**，**不是独立档位表**；
3. **五级卖出联动**（共性 4，验收要点）：逐一核对**五级优先级**（1 诚信否决 / 2 硬止损 8%~10% / 3 逻辑止损（连续 2 个季度业绩低于预期且产业景气未改善） / 4 产业景气判断 / 5 估值判断）+ **时间止损（满 4 季度逻辑未兑现）** + **性价比替换（每季最多 1 次）**，**一律引用 `garp-exit`（P4-6）**；**任一命中即在该节标注并转接 `/garp-exit`**；骨架 `P0~P5` 检查表**整段废止**；
4. **渗透率与国产化率口径替换**（共性 2）：渗透率改 **`15%~40%` 黄金窗五档**（<5% 导入早期观察不建仓 / 5%~15% 突破期小仓跟踪 / **15%~40% 加速上行黄金窗主建仓** / 40%~60% 逐步兑现持有不新建 / >60% 天花板不加仓；增速归零或转负即见顶清仓）+ **国产化率四梯队**（<5% 过早 / 5%~20% 突破期 / 20%~50% 加速投资期 / >50% 收窄），**一律引用 `garp-industry-research`（P4-9）**；骨架 `10%~30%` **不得出现**；
5. **地缘模块整段替换**（共性 3）：删除骨架「地缘政治**六维度** + 『华为式』抗封锁韧性」，改为 **0.3 三维交叉矩阵 + 赛道两分法**（引 `garp-geo-policy` P4-1）+ **敞口体检**；矩阵**只读不判档**、**未列组合按更审慎相邻档归档**、**国字号注资不作买入估值依据**、**禁止发明系数**；
6. **管理层与科研转化只引不复制**（共性 5）：**诚信前置不计分闸门**（兑现率<50% / 业绩预告重大失真 / 财务造假实锤 / 监管立案 → 放弃或清仓）+ **管理层 7+7+6** + **科研转化 8+8+4** + **费雪补充项** + **ESG 三通道**，**只引 `garp-management`（P4-4）结论**，骨架 4 维度评分表**不得复现**；
7. **叠加宏观三表校准**（共性 7）：宏观参数一律经 `garp-macro`（P4-2）/ `macro_calibrator.py` 透传——利率周期 → **PEG 合理买入区间**（加息/高利率 0.8~1.0 / 中性 1.0~1.2 / 降息/低利率 1.2~1.5 / 滞胀 0.8）、经济周期 → **现金仓位与个股上限**（衰退现金 30%~40%、单只初始≤8% / 验证后≤12% / 绝对≤15%）、美林时钟 + 信用周期 → 阶段收口；本技能**不判 stage、不心算**；
8. **一手资料优先**（继承骨架刚性）：**A 股必须先 `stock_equity.py --download-report` 下载财报 PDF，下载成功后方可进入精读**；「读原文，不读摘要」；资料可得性 A/B/C 三级写入报告开头，**C 级不得作确定性结论**；
9. **双源交叉验证与禁心算**（继承骨架）：关键数据（收入 / 净利润 / 总股本与市值 / ROE / 估值指标）**至少 2 个独立来源**，误差 >1% **必须标记**；一切计算经 `financial_rigor.py` 等工具，**禁止 LLM 心算**；
10. **结论明确**：报告必须回答五个问题——**① 景气逻辑是否被验证 ② 估值落在 GARP 哪一档 ③ 五级卖出是否触发 ④ 底仓/机动仓如何分层 ⑤ 「假如空仓」会不会买**，并给出**操作建议（持有 / 加仓 / 减仓 / 清仓）**；命中卖出信号**强制转接 `garp-exit`**。

### 2.8 估值：GARP PEG 定位 = 多工具矩阵 + 统一六档（**共性 6；只读 `garp-valuation`**）

**五类公司类型 × 估值矩阵（框架行 381~387，逐字落表）**：

| 公司类型 | 核心工具（主锚） | 辅助工具 | 可接受标准 |
| --- | --- | --- | --- |
| **快速增长型（盈利稳定）** | **调整后 PEG**（即「**GARP PEG**」） | 远期 PE、PEG 分位 | PEG<1 低估 / 1~1.2 合理 / 1.2~1.5 合理偏贵（持有不加仓、机动仓择机减）/ **>1.5 高估** |
| **高研发投入型（利润被压低）** | **PS / EV-Sales** | **Rule of 40** | **Rule of 40 ≥ 40**（收入增速 + 利润率或 FCF 利润率）；EV/Sales 低于同业可比 |
| **未盈利科技型** | PS、EV/Sales | **研发管线 NPV** | 需有清晰的盈利路径与里程碑节点 |
| **稳定增长型** | 远期 PE + **隐含 PEG** | 股息率 | 当前 PE ≤ 未来 3 年 EPS 复合增速（百分数值）×1.2（**隐含 PEG≤1.2**） |
| **成熟型企业** | **DCF** | 股息贴现 | 当前市值 ≤ **保守 DCF 估值的 80%** |

**三级留痕（统一收口）**：`基准档位 → 宏观校准后 → ESG 折价后 → 最终档位`，收口至 `garp-valuation`（P4-5）**统一六档**（**显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支**）。

**叠加规则**：
- **ESG / 环境风险折价**（框架行 424~439）：高环境风险行业**合理估值再打 8~9 折**；有明确碳减排承诺与可验证转型路径 → 折价收窄至 **≤5% 或豁免**；面临「搁浅资产」风险 → **DCF 贴现率额外上调 1~2 个百分点**；ESG 评级处行业尾部 → **先降仓位上限**（如绝对上限 20% → 15%），而非继续压估值。
- **宏观 PEG 区间**（§2.9）：框架 PEG 阈值以**中性宏观环境**为基准，加息/降息周期**动态上浮或下调**。
- **科技股调整后口径**（框架行 422）：高研发投入公司研发费用化会虚增 PE/PEG，**务必用「核心经营利润」口径回算调整后 PE**（`adjusted-peg`）。
- **PEG 使用边界**（框架行 392）：PEG 适用于盈利稳定的成长股；PS/EV-Sales 适用于高研发投入或未盈利科技股；DCF 适用于现金流稳定的成熟企业；**科技股须多工具交叉验证，避免单一指标误判**。

> **口径禁令**：骨架「一律以 `/valuation-thermometer` 输出为准」**整段废止**；`valuation-thermometer` / PEG 五档温度 / `PSG` / `target_pe` **一律不得出现**（禁用词第 3 / 15 / 16 项）；本技能**零 PEG 档位自建、零估值结论自建**；「**GARP PEG**」在报告中须以「**调整后 PEG（快速增长型主锚）**」表述，**不得**被解释为独立档位表（门禁 **E**）。

### 2.9 宏观三表与 PEG 区间联动（**共性 7，新增**）

| 表 | 权威值（框架行 695~748） |
| --- | --- |
| **（一）利率周期 → PEG 合理买入区间** | 加息/高利率 **收紧至 0.8~1.0**（低估 <0.7；>1.2 减机动仓）；中性（基准）**1.0~1.2**（低估 <1.0；>1.5 高估）；降息/低利率 **放宽至 1.2~1.5**（低估 <1.2；仍 >1.5 减仓，**>2 绝对透支清机动仓**）；**滞胀期进一步下探至 0.8** |
| **「合理偏贵」统一口径** | 合理买入区间之上、高估阈值之下的中间带（中性即 **1.2~1.5**）= **合理偏贵**——可继续持有底仓、**不加仓**，机动仓逢高择机减仓；**「增速确定性」三锚**：①连续 2~3 季增速稳定性 ②订单可见度（在手订单/预收/合同负债覆盖度）③竞争格局固化程度（CR5 与龙头份额趋势）；任一偏弱 → 偏贵上限**收紧至 1.2** |
| **（二）经济周期 → 现金与个股上限** | 中性/复苏：现金 **10%~20%**（估值分位>80% 时提至 20%~30%）、单只 初始≤10% / 验证后≤15% / 绝对≤20%、单一行业 ≤40%；衰退：现金 **30%~40% 或更高**、单只 **≤8% / ≤12% / ≤15%**、单一行业 **≤30%**；过热：单只 ≤8% / ≤12% / ≤15%、单一行业 ≤25%、现金 ≥25%；滞胀：单只 ≤6% / ≤10% / ≤12%、单一行业 ≤20%、现金 ≥40% |
| **（三）美林时钟 + 信用周期 → 框架参数** | 衰退：PEG 上限 **1.0**（临时收紧）、现金 30%~40%、单只（验证后）≤12%；复苏：**1.5**（放宽）、现金 10%~20%、≤15%；过热：**1.0**（收紧）、现金 ≥25%、≤12%；滞胀：**0.8**（最紧）、现金 ≥40%、≤10% |

**刚性约束**：**「PEG>2 为严重透支」红线不因降息而取消**（仅可放缓减仓节奏）；宏观**只调「估值容忍度」与「仓位尺度」**，**不替代个股基本面判断、不作为择时清仓依据**（框架行 684）；参数一律经 `garp-macro`（P4-2）/ `macro_calibrator.py` 透传，本技能**不判 stage**（`GER-9`）。

### 2.10 卖出与止损：**引用 `garp-exit` 五级（共性 4，门禁 F）**

| **3 逻辑止损** | 连续 **2 个季度**业绩低于预期且产业景气未改善；财务不可逆恶化（应收暴增 / 存货高企 / 现金流持续为负）；龙头地位被颠覆 / 科研转化大幅低于预期；管理层或科研转化评分**跌破 10 分**（非诚信事项） | 减仓或清仓 | **本期财报直接核对**（核心触发点） |
| **4 产业景气判断** | 渗透率/ROE 拐点但**景气尚可、仅节奏放缓**（如进入 40%~60% 逐步兑现期）→ 减机动仓降仓位；**增速归零/转负 → 升级为逻辑恶化、清仓**（独立触发，与渗透率位置无关） | 按景气方向调仓 | **郑希维度**（ROE/二阶导/渗透率） |
| **5 估值判断** | 调整后 PEG>1.5 高估区 → 减机动仓；**PEG>2 严重透支 → 加速清机动仓**；市场情绪极度狂热（多信号共振）→ 减机动仓 | 底仓不动，机动仓调整 | **林奇维度**（估值档位） |
| **补充机制**（不占优先级） | **时间止损**：持有满 **4 个季度（1 年）**逻辑仍未兑现 → 减至观察仓或替换；**性价比替换（末位优化）**：其他标的估值显著更低且产业趋势更强可逐步切换，**每季度最多 1 次** | 兜底 / 优化 | 第十步兜底核对 |

**止损分仓位口径**（框架行 528~539）：**「建仓初期」= ①持仓<最终仓位 50%，或 ②持仓≥50% 但逻辑尚未经 2~3 季财报持续兑现验证**（任一成立即适用 8%~10% 硬止损）；**底仓已建立且逻辑已验证**（须**同时满足**①达到最终仓位 50% ②逻辑经 2~3 季兑现）→ 下跌 ≤20% 且多维未恶化可在合理估值下限加仓；>20% 转入「暂时性困难 vs 永久性衰退」清单复核（**费雪维度**主责）；**无论何种状态，逻辑被证伪立即清仓，不存在「越跌越买」**。

**传导纪律**：**任一优先级命中 → 报告第十节标注「命中级别 + 建议动作」并强制转接 `/garp-exit`**；本技能**只核对、不重排、不裁量**（`GER-4`）；一票否决的**买入前 / 持仓后语境**区分照引 `garp-exit`（买入前闸门如 ROIC<5% 扩产 / 0.3 矩阵回避 → 建仓前放弃，不入五级表）。

> **口径禁令**：骨架 `P0~P5` / `P0` / `六级卖出` **一律不得出现**（禁用词第 17~19、21 项）；本技能**不自建卖出层级**、**不自建止损链**；ATR 止损为建议工具，经 `garp-exit` 转接 `momentum.stop_price()`（`atr(period=14)` / `multiplier=2.0`）。

### 2.11 「假如空仓」测试与底仓/机动仓分离（继承骨架，GARP 化）

| 项 | 骨架 | GARP 独立档 |
| --- | --- | --- |
| **底仓（60%~80%）** | 不因短期 20% 以内波动卖出；仅在 P0 / P2 / P5 触发时调整 | 不因短期 20% 以内波动卖出；仅在**五级第 1 / 第 3 / 补充机制（性价比替换）** 触发时调整 |
| **机动仓（20%~40%）** | PEG 档位进入高估区（`valuation-thermometer`）时减持；P1 触发时优先砍机动仓 | **统一六档进入「高估 / 严重透支」**时减持；**五级第 2 级（硬止损）**触发时优先砍机动仓 |
| **上限** | 单只 10% / 15% / 20%；行业 ≤40% | **叠加宏观调档**：衰退 8% / 12% / 15%、行业 ≤30%；过热 8% / 12% / 15%、行业 ≤25%；滞胀 6% / 10% / 12%、行业 ≤20% |
| **「假如空仓」** | 会买 / 不会买 / 犹豫不决 | 保留；**理由必须具体**（如「调整后 PEG 1.8 落在高估档」「ROE 二阶导连续 2 季为负」），**不得以框架术语含糊搪塞** |

> **骨架阈值处置**：骨架「止损纪律」表「左侧宽止损 -15%」「右侧窄止损 -8%~-10%」**与框架冲突**（框架一律以**仓位状态**为分水岭，非跌幅数字），改按框架行 528~539 与 `garp-exit`；骨架「-15%」「-18%」等自造阈值**废止**（登记为骨架推导口径，见 §4.5）。

### 3.3 降级与失败处置

| 情形 | 处置 |
| --- | --- |
| 市场识别失败 / 非三市场标的 | 明确标注「工具未覆盖」，**转人工/浏览器取数**，不得以境内数据代入境外标的 |
