# 中长期价值成长（GARP）投资框架（草稿 · 科技与国产化主题增强版）

**适用对象**：认同“以合理价格买入持续成长的好公司”理念，希望以1~5年中长期持有为主、拒绝频繁短线交易的个人投资者。

**核心理念**：用产业趋势定方向，用生活常识和基本面选个股，用“管理层+科研转化”评估企业内在价值，用地缘政治与政策资本判断国产替代节奏，用底仓陪伴成长、用机动仓平滑波动，用系统化纪律控制回撤与情绪。

# 第一部分 思想根基：五位投资大师的思维模式

## 一、菲利普·费雪——质化分析之父：闲聊法与长期持有

菲利普·费雪（1907-2004）被誉为“成长股价值投资之父”，是巴菲特亲口承认对其产生重要影响的“特别的老师”。他的投资哲学开创了一条与格雷厄姆“捡烟蒂”截然不同的路径——**寻找并长期持有那些能够持续创造增量价值的杰出公司，而非仅仅寻找价格便宜的股票**。

**思维模式特点：**

- **质化分析优先**：费雪认为，关于一家公司未来的最重要信息，尚未写进财务报表里。管理层品质、持久竞争优势、研发能力、销售组织等“财报上找不到的东西”，才是判断企业潜力的关键。
- **“闲聊法”（Scuttlebutt Method）** ：主张走出去，与企业的竞争对手、供应商、客户及员工交谈，从各种渠道收集第一手信息，而非坐在办公室里看财报拍脑袋。
- **极度集中与长期持有**：费雪一生真正赚到大钱的只有14只股票，投资组合通常只重仓3~5只，占总仓位的70%。他的核心信条是“卖出的最佳时机，几乎永远是不要卖”。他持有摩托罗拉长达44年，德州仪器经历80%暴跌仍坚持持有。
- **诚信一票否决**：费雪明确表示，如果一家公司在诚信问题上不合格，无论其他标准得分多高，他永远不会考虑这只股票。
- **十五要点选股框架**：在《怎样选择成长股》中提出“寻找优良普通股的十五点原则”，涵盖市场潜力、研发投入、销售组织、利润率、管理层能力等多个维度。

**对我们的启发**：在1~5年的持有周期中，核心底仓应借鉴费雪的质化分析框架和“闲聊法”，深度评估企业的管理层质量、销售组织与长期竞争力。一旦确认企业足够杰出，应以长期持有为信念，不被短期股价波动干扰。但费雪的“不卖”只适用于极少数经过深度研究的杰出企业，且必须配合极度的集中和极深的认知。

## 二、彼得·林奇——侦探思维：常识与求证

林奇管理麦哲伦基金期间，每年调研数百家公司，工作方式像侦探破案。他最独特的贡献在于相信业余投资者凭借生活常识也能发现好公司。

**核心方法**：从具体消费体验出发，再回到财报验证。将股票分为六种类型（缓慢增长型、稳定增长型、快速增长型、周期型、困境反转型、隐蔽资产型），不同类型匹配不同的估值方法和卖出逻辑。

**在本框架中的角色**：选股起点。从日常生活观察中发现候选标的，用常识做第一道筛选。

## 三、郑希——物理学家思维：第一性原理与产业周期

郑希是物理系出身，思维模式带有鲜明的物理学家特质——从第一性原理出发，寻找事物最本质的驱动力量。他认为科技公司个股的涨跌是表象，真正的底层驱动力是技术迭代带来的产业景气周期。

**核心方法**：关注产业处在ROE曲线的什么位置，同时跟踪中美科技产业链寻找哪个环节率先出现ROE拐点。核心表述——“长期判断由无数短期客观判断拼接而成”，每一笔持仓都要在每个季度接受景气数据的检验。

**在本框架中的角色**：赛道选择。用ROE拐点和全球产业景气定方向。

## 四、李进——系统工程师思维：系统均衡与回撤控制

李进是清华大学工学博士，思维模式体现为系统工程师的全局优化思维——既要追求收益弹性，又要控制回撤，在矛盾中寻找最优解。

**核心方法**：将资产分为“景气成长”（进攻）和“价值成长”（防御）两类，根据市场环境动态调整比例。用渗透率曲线定位产业阶段（突破15%后加速上行期重仓，达到50%~60%后逐步兑现）。要求产业趋势必须有订单、收入、利润的客观数据支持，否则一律视为题材炒作。

**在本框架中的角色**：组合管理与渗透率择时。

## 五、威廉·欧奈尔——工程师思维：信号与纪律

欧奈尔复盘了美股百年历史上所有大牛股的共同特征，提炼出CAN-SLIM七大选股标准。他相信趋势跟随而非预测，一切决策基于明确信号。

**核心方法**：8%止损作为“生存红线”；趋势确认后介入，趋势走坏后离场；忘掉买入成本，以市场信号为准。

**在本框架中的角色**：风控底线。用硬止损保护本金，防止深度套牢。

### 五位大师与个人投资者的连接方式

| 大师   | 思维模式关键词                   | 在个人投资者框架中的角色                                                             |
| ------ | -------------------------------- | ------------------------------------------------------------------------------------ |
| 费雪   | 质化分析 · 闲聊法与长期持有     | **核心底仓质量评估**：深度调研管理层、销售组织与长期竞争力，确认杰出后长期重仓 |
| 林奇   | 侦探思维 · 常识与求证           | **选股起点**：从生活体验中发现机会，用常识做第一道筛选                         |
| 郑希   | 物理学家思维 · 周期与第一性原理 | **赛道选择**：用ROE拐点和全球产业景气定方向                                    |
| 李进   | 系统工程师思维 · 均衡与渗透率   | **组合管理**：用渗透率定位产业阶段，用双资产配置控回撤                         |
| 欧奈尔 | 工程师思维 · 信号与纪律         | **风控底线**：8%止损、抛售日减仓，防止深度套牢                                 |

**以上五位大师的组合，构成了本套投资框架的完整拼图：**

- 用**费雪**的质化分析框架和“闲聊法”，深度评估企业的管理层质量、销售组织与长期竞争力，确认核心底仓是否足够杰出（解决“是否杰出”）；
- 用**林奇**的常识化基本面和生活观察，在赛道中筛选出自己看得懂、有壁垒的好公司（解决“买哪家公司”）；
- 用**郑希/李进**的产业景气框架，选择未来1~3年最具成长确定性的赛道（解决“买什么行业”）；
- 用**李进**的渗透率坐标与科研转化评估，验证企业的护城河与治理质量（解决“能否长期持有”）；
- 用**欧奈尔**的底线风控纪律，保护本金、控制回撤、规避大亏（解决“如何安全退出”）。

这套框架的目标不是追求短期爆发力，而是帮助个人投资者在**1~5年的持有周期中，以系统性方法对抗市场波动与自身情绪，稳健地赚取企业成长的钱**。

# 第二部分 核心筛选漏斗：从地缘政治到个股

## 第0步：地缘政治与政策资本前置判断（国产化主题专用）

在进入产业和个股筛选之前，先完成一层**前置判断**。这一步的核心逻辑是：**地缘政治倒逼决定国产替代的“确定性下限”，政策与国字号基金支持决定“国产企业能不能接得住”的可行性。**

### 0.1 地缘政治倒逼强度评估

| 评估项                    | 具体内容                                                          | 对投资判断的含义                                       |
| ------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------ |
| **制裁/管制覆盖度** | 该领域是否已被列入实体清单、出口管制清单，或面临关税/反补贴调查？ | 已被覆盖→被迫替代确定性高；尚未覆盖→仍以市场驱动为主 |
| **断供现实性**      | 进口供应是否已实际中断，还是仅有“断供隐忧”？                    | 已实际中断→下游客户已无选择，国产导入是生存刚需       |
| **政策强制力**      | 是否有类似“新增产能国产设备占比不低于50%”的强制性要求？         | 有强制要求→订单释放确定性极高                         |
| **制裁可持续性**    | 制裁是立法层面的长期安排，还是行政层面的短期措施？                | 立法级→长期确定性高；行政级→可能随政府更迭变化       |

### 0.2 政策与国字号基金支持强度评估

“十五五”规划纲要提出“聚焦战略必争领域和产业链供应链薄弱环节，采取**超常规措施，全链条推动**集成电路、工业母机、高端仪器、基础软件、先进材料、生物制造等重点领域关键核心技术攻关取得**决定性突破**”。这意味着政策工具不再局限于补贴和引导，而是包括强制采购比例、部委协同攻关、应用场景强制开放等更强干预手段。“全链条”的政策目标则是“形成可规模化的国产技术供给体系”。

**国字号基金三层架构**：

| 层级                 | 基金名称                 | 规模             | 核心投向                                                 |
| -------------------- | ------------------------ | ---------------- | -------------------------------------------------------- |
| **第一层**     | 国家人工智能产业投资基金 | 600亿元          | AI全产业链（算力、算法、数据、具身智能终端）             |
| **第二层**     | 大基金三期               | 3440亿元         | 设备材料国产替代（约70%资金）+ 先进封装与AI存储（约30%） |
| **第三层**     | 国家制造业转型升级基金   | 1472亿元（目标） | 工业母机、机器人核心零部件、新材料                       |
| **专项子基金** | 工业母机产业投资基金     | 150亿元          | 工业母机全产业链                                         |

**评估维度**：该环节是否被上述基金中的至少一只直接注资或设立专项子基金？是否有央企/产业资本（如中国石化、上汽集团）参与投资，从而形成“资本+场景”的绑定？

### 0.3 综合判断：政策-资本-地缘三维交叉矩阵

| 地缘倒逼强度      | 政策覆盖度          | 国字号基金介入 | 投资含义                                                   |
| ----------------- | ------------------- | -------------- | ---------------------------------------------------------- |
| 高（已制裁/断供） | 高（超常规+全链条） | 有直接注资     | **最优场景**：替代确定性和节奏均被外部力量锁定       |
| 高                | 中                  | 有专项子基金   | **次优场景**：替代方向明确，但节奏受技术突破制约     |
| 中（制裁升级中）  | 高                  | 有覆盖         | **潜伏场景**：制裁尚未落地但概率高，提前布局等待催化 |
| 低                | 低                  | 无覆盖         | **回避**：替代节奏完全依赖市场驱动，不确定性过高     |

**关键风险提示**：国字号基金的注资应被视为“政策优先序列”的信号，而非买入估值的依据。大基金以产业培育成本入股，其成本远低于二级市场投资者在消息公开后的买入价格。**最终决策仍需回到估值和业绩兑现框架。**

## 第1步：赛道选择——顺应时代增量，寻找景气向上的产业

| 筛选维度                               | 具体标准                                              | 实操方法                                                          |
| -------------------------------------- | ----------------------------------------------------- | ----------------------------------------------------------------- |
| **产业空间（TAM）**              | 行业潜在市场规模≥1000亿，未来3年复合增速≥20%        | 查阅券商深度研报、行业协会数据、上市公司招股书中的行业分析章节    |
| **渗透率位置**                   | 当前渗透率在10%~30%之间，处于加速突破临界点           | 跟踪第三方数据；渗透率<5%过早（不确定性高），>50%过晚（增速放缓） |
| **国产化率位置**（科技赛道专用） | 国产化率在2%~10%之间为理想跟踪期，10%~30%为加速投资期 | 参照下表分环节判断                                                |
| **业绩兑现度**                   | 已出现订单、收入、利润的真实增长                      | 连续2个季度财报验证：营收增速>行业平均，毛利率稳定或提升          |
| **区分真实趋势与题材炒作**       | 必须有EPS支撑，纯概念无业绩的坚决回避                 | 查看扣非净利润增速是否匹配营收增速                                |

### 半导体设备国产化率分层（2026年数据）

| 梯队                           | 环节                         | 当前国产化率 | 投资逻辑                       |
| ------------------------------ | ---------------------------- | ------------ | ------------------------------ |
| **第一梯队（已成熟）**   | 去胶、清洗                   | 50%~90%      | 替代空间收窄，关注龙头份额提升 |
| **第二梯队（主力增量）** | 刻蚀、薄膜沉积、CMP          | 30%~40%      | 已跨过验证门槛，订单放量阶段   |
| **第三梯队（高弹性）**   | 涂胶显影、离子注入、量测检测 | 2%~20%       | 从“0到1”突破带来最大业绩弹性 |

刻蚀与清洗设备国产化率已分别达到55%~65%和50%~60%，而薄膜沉积、离子注入、量测检测、涂胶显影及光刻等环节国产化率仍处于低位，其中光刻设备国产化率不足1%，量测检测设备不足15%。

### 机器人产业链国产化进展

2026年以来，以减速器、伺服系统、控制器三大核心零部件为例，国产化率已攀升至75%至90%。核心部件的自主可控推动人形机器人整机成本从早年的百万元级下探至如今的20万元级，部分通用机型已进入10万元以内。**机器人领域的投资重点已从“零部件国产替代”转向“整机放量与场景落地”** 。

## 第2步：个股初筛——从生活常识出发，建立备选池

- **消费即调研**：关注您常用的APP、常买的品牌、信赖的产品。若您自己就是目标用户，您对产品力的判断可能比分析师更真实。
- **初筛财务门槛**（快速排除法）：
  - 营收规模≥10亿；
  - 最近三年营收复合增速≥15%；
  - 资产负债率<60%（金融/地产行业除外）；
  - 经营性现金流净额为正；
  - 过去三年至少两年扣非净利润为正。

## 第3步：深度研究——五大支柱交叉验证

### 支柱一：产业景气度（判断β）

- 行业供需格局：供不应求/供需平衡/供过于求？
- 价格趋势：产品单价是否稳定或上涨？
- 竞争格局：行业前三名集中度是否提升？龙头份额是否扩大？

### 支柱二：公司基本面（判断α）

- **ROE趋势**：当前ROE水平及近三年变化方向（参考郑希的ROE向上拐点逻辑）
- **毛利率与净利率**：是否稳定或提升？反映定价权和成本控制力
- **营收与利润增速匹配度**：利润增速是否跟上营收增速？
- **ROIC（投入资本回报率）** ：ROIC > WACC且≥10%为合格；ROIC > 15%为优秀；长期<5%却在拼命扩产——一票否决

### 支柱三：管理层与科研转化能力（科技赛道专用）

**管理层评估清单（20分制，≥15分方可重仓）** ：

| 维度                       | 检查项                                                                         | 评分 |
| -------------------------- | ------------------------------------------------------------------------------ | ---- |
| **诚信（一票否决）** | 年报“说到做到”验证（兑现率<50%一票否决）；业绩预告准确性；归因习惯；监管记录 | 5分  |
| **对待股东**         | 分红历史（≥30%为优）；融资记录；回购行为；大股东质押率（>50%预警）            | 5分  |
| **战略执行力**       | 是否聚焦主业；核心战略落地情况；行业格局认知深度                               | 5分  |
| **稳定性与激励**     | 核心团队稳定性（离职率<10%）；股权激励合理性；内部人交易                       | 5分  |

**费雪十五要点补充检查（定性参考，不计入20分制）** ：

费雪在《怎样选择成长股》中提出的“十五要点”中，有两点在现有框架中较弱，需专门补充：

| 补充检查项                 | 评估标准                                                                             | 操作指引                                                                                                      |
| -------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| **销售组织出色**     | 公司是否拥有行业领先的销售组织？经销商覆盖率、销售团队稳定性、客户获取成本趋势如何？ | 调研经销商覆盖密度、销售团队离职率、销售费用率变化；费雪曾注意到摩托罗拉的产品能覆盖85%的经销商，铺货能力一流 |
| **管理层持股比例高** | 核心管理层是否持有公司≥3%的股份？是否与股东利益高度一致？                           | 查阅年报“股东持股”章节及高管薪酬公告；管理层持股比例越高，利益绑定越深，长期决策更倾向于股东价值最大化      |

**科研转化评估清单（20分制，≥15分可重仓）** ：

| 维度                             | 检查项                                                                        | 评分 |
| -------------------------------- | ----------------------------------------------------------------------------- | ---- |
| **研发投入“质”与“量”** | 研发强度≥15%且逐年提升；资本化率<30%为审慎；研发人员占比≥30%                | 8分  |
| **研发产出效率**           | 发明专利数量与质量；新产品收入占比≥20%；技术产品化周期；重大科研项目节点推进 | 8分  |
| **资本回报效率**           | ROIC > WACC；增量资本回报率 > 存量ROIC                                        | 4分  |

**科技股专用估值调整提示**：研发费用化会压低当期利润，导致PE虚高、PEG被动变大。建议将研发费用部分加回（或参考费用化研发支出而非全部研发支出），用**核心经营利润**计算调整后PE，再与增速比较，以更真实地反映科技公司的估值水平。

### 支柱四：地缘政治与外部环境

- **海外收入依赖度**：海外收入占比越高，越易受关税、出口管制冲击
- **供应链安全**：关键零部件是否依赖特定国家或单一供应商？
- **制裁与清单风险**：是否已被或可能被列入实体清单？
- **本地化对冲能力**：是否有海外建厂、多元供应链来对冲？
- **自主研发抗压能力（“华为式”抗封锁能力）** ：研发投入强度与持续性；核心技术自主可控程度；“备胎计划”与替代方案；极端情形下的生存能力

### 支柱五：政策与资本覆盖度

- 该环节是否被“十五五”以“超常规”“全链条”表述覆盖？
- 是否有国字号基金直接注资或专项子基金覆盖？
- 是否有央企/产业资本参与投资形成“场景绑定”？

## 第4步：估值锚定——多工具矩阵

科技股投资不能仅依赖单一PEG指标。下表为不同公司类型匹配的估值工具矩阵：

| 公司类型                             | 核心工具      | 辅助工具        | 可接受标准                                                |
| ------------------------------------ | ------------- | --------------- | --------------------------------------------------------- |
| **快速增长型（盈利稳定）**     | 调整后PEG     | 远期PE、PEG分位 | PEG<1为低估，1~1.2为合理，>1.5为高估                      |
| **高研发投入型（利润被压低）** | PS / EV/Sales | Rule of 40      | Rule of 40 ≥ 40（收入增速+利润率）；EV/Sales低于同业可比 |
| **未盈利科技型**               | PS、EV/Sales  | 研发管线NPV     | 需有清晰的盈利路径和里程碑节点                            |
| **稳定增长型**                 | 远期PE        | 股息率          | 当前PE ≤ 未来3年EPS复合增速×1.2                         |
| **成熟型企业**                 | DCF           | 股息贴现        | 当前市值 ≤ 保守DCF估值的80%                              |

**Rule of 40**是评估科技公司经营质量的关键工具：收入增长率 + 利润率（或FCF利润率）应≥40%，用来衡量一家公司在增长与盈利之间的平衡质量。

**PEG使用边界**：PEG适用于盈利稳定的成长股；PS/EV/Sales适用于高研发投入或未盈利科技股；DCF适用于现金流稳定的成熟企业。科技股估值需综合使用多种工具交叉验证，避免单一指标误判。

**分批建仓规则**：

- 股价进入“合理买入区间”后，先建**1/3底仓**
- 若股价继续回调至合理区间下限以下（如调整后PEG<0.7），再加**1/3**
- 确认产业景气加速或财报超预期后，补齐剩余**1/3**
- 总仓位控制：单只个股初始≤总资产的10%，逻辑验证后≤15%，绝对上限≤20%；单一行业不超过总资产的40%

# 第三部分 持仓管理与操作纪律

## 一、底仓 + 机动仓分离管理

| 仓位类型                    | 定位                          | 操作规则                                                                                            |
| --------------------------- | ----------------------------- | --------------------------------------------------------------------------------------------------- |
| **底仓（60%~80%）**   | 长线核心，赚企业1~5年成长的钱 | 只要买入逻辑未被破坏，始终保留。不因短期20%以内的波动而卖出。可每季度结合最新财报做小幅调整（±5%） |
| **机动仓（20%~40%）** | 平滑波动，赚估值波动的钱      | 当股价进入高估区间时减持，回落至合理区间时回补                                                      |

## 二、仓位管理与再平衡规则

| 管理维度               | 具体规则                                            |
| ---------------------- | --------------------------------------------------- |
| **总持股数**     | 5~10只为宜                                          |
| **单只个股上限** | 初始≤10%，逻辑验证后≤15%，绝对上限≤20%           |
| **单一行业上限** | ≤总资产的40%                                       |
| **行业相关性**   | 持有的行业之间相关系数<0.5                          |
| **流动性**       | 持有标的日成交额至少>1亿元（小市值可放宽至>3000万） |

**再平衡触发规则**：每季度末检查组合，当单只个股占比偏离目标±5%时，进行再平衡——将占比升高的资产适当减持，补到占比下降的资产中，使组合回到目标比例。这种操作的核心目的是**不追涨、不杀跌，用规则替代情绪**。

**风险预算**：设定组合最大回撤目标（如不超过20%），当回撤接近目标时降低仓位或提高现金比例。市场整体估值分位>80%时，现金比例提高至20%~30%。

**波动率调整止损**：对高波动科技股，用ATR（平均真实波幅）设置止损，如2~3倍ATR，避免被正常波动震出。

## 三、卖出规则：逻辑恶化 > 估值透支 > 替换优化

**优先级1：基本面恶化（立即清仓）**

- 当初买入的核心逻辑被破坏（行业渗透率见顶、龙头地位被颠覆、管理层诚信问题暴露、科研转化大幅低于预期）
- 连续2个季度业绩低于预期且无合理解释
- 财务出现不可逆恶化（应收账款暴增、存货高企、现金流持续为负）
- **时间止损**：持有满4个季度，买入逻辑仍未兑现，减仓至观察仓或替换

**优先级2：估值透支（分批卖出机动仓）**

- 调整后PEG>1.5进入高估区，PEG>2为严重透支
- 行业渗透率超过50%后增速明显放缓
- 市场情绪极度狂热

**优先级3：性价比替换（调仓优化）**

- 发现其他标的估值显著更低且产业趋势更强，可逐步切换
- 调仓频率控制在每季度最多1次

## 四、补充：暂时性困难 vs 永久性衰退判断清单

费雪最擅长的，是在杰出企业遭遇暂时性困难时逆势加仓。但并非所有下跌都是“暂时性困难”，有些是“永久性衰退”。下表用于区分两者，帮助决定是加仓还是清仓：

| 判断维度           | 暂时性困难（可加仓）             | 永久性衰退（需清仓）       |
| ------------------ | -------------------------------- | -------------------------- |
| **行业需求** | 需求延迟，但长期趋势未变         | 需求被替代品永久性替代     |
| **竞争格局** | 份额短期波动，但优势仍在         | 份额持续流失，护城河消失   |
| **财务**     | 现金流短期承压，但资产负债表健康 | 现金流持续为负，债务恶化   |
| **管理层**   | 承认问题，有清晰应对方案         | 推卸责任，频繁更换高管     |
| **研发**     | 研发投入维持或增加               | 研发投入持续削减           |
| **客户**     | 客户流失是暂时性的，可挽回       | 核心客户永久性转向竞争对手 |

**使用规则**：对核心底仓，若判断为“暂时性困难”，且产业逻辑、管理层、财务三维度均未恶化，可在合理估值下限附近加仓；若判断为“永久性衰退”，无论盈亏立即清仓。

## 五、止损纪律

- **硬止损**：买入后若下跌超过**8%~10%** ，无条件卖出该笔仓位。忘掉买入成本，以市场信号为准
- **逻辑止损**：若买入逻辑被证伪，无论盈亏立即离场
- **执行方式**：建议用条件单/止损单自动执行，避免临盘犹豫

**分仓位止损规则**：

| 仓位状态                                 | 决策规则                                                                            |
| ---------------------------------------- | ----------------------------------------------------------------------------------- |
| **建仓初期（持仓<最终仓位的50%）** | 若下跌超过8%，按欧奈尔规则止损离场，保护本金                                        |
| **底仓已建立且逻辑已验证**         | 若自买入价下跌≤20%且产业逻辑、管理层、财务三维度均未恶化，可在合理估值下限附近加仓 |
| **无论何种状态，逻辑被证伪**       | 立即清仓，不存在“越跌越买”                                                        |

# 第四部分 国产化投资专题：被迫替代下的价值成长

## 一、国产化率提升的成长逻辑

国产化率提升本质上是一种**“份额替代型成长”** ——产业总盘子（TAM）不变，但国产企业的可及市场（SAM）在持续扩大，从而驱动企业内在价值增长。

| 维度                 | 传统渗透率驱动     | 国产化率驱动                                       |
| -------------------- | ------------------ | -------------------------------------------------- |
| **TAM**        | 持续扩大           | 基本不变或小幅波动                                 |
| **成长来源**   | 行业蛋糕做大       | 从进口厂商手中抢份额                               |
| **成长确定性** | 取决于技术接受速度 | 取决于**技术突破+客户验证+政策推力**三重因素 |

## 二、国字号基金的“全链条资本矩阵”

国家人工智能产业投资基金向北京可灵注入14亿元，瞄准视频生成大模型赛道。大基金三期通过国投集新基金认购中微公司配套募资，大基金三期认购比例达53.33%，上海本地国资认购比例达40.00%。这些案例表明，国字号基金的投资正在从“支持已有基础的替代”转向“押注尚未突破但战略价值极高的卡脖子环节”。

**核心判断**：当某个AI或机器人细分环节同时被“十五五”政策明确覆盖、且已被国字号基金精准注资时，该环节的国产替代就不再是“市场驱动的渐进过程”，而是“制度驱动的加速过程”。但**国字号基金的注资应被视为“政策优先序列”的信号，而非买入估值的依据**。

## 三、政策工具的作用机制

**首台（套）、首批次保险补偿政策**：下游客户采购首台国产重大装备或首批次新材料时，若因产品质量问题产生损失，由保险机制进行补偿，保费由财政资金按比例补助。这一工具直接缩短了国产产品的客户验证周期。

**地方实践**：深圳设立了首期规模50亿元的半导体与集成电路产业投资基金，天津设立了首期2亿元的集成电路早期专项基金，重点投向半导体装备、EDA工具、高端芯片设计。这些地方基金的共同特征是**不再广撒网，而是精准锁定本地产业链中“卡脖子”的特定环节**。

# 第五部分 风险与应对

| 风险点                           | 具体描述                                       | 应对方案                                                       |
| -------------------------------- | ---------------------------------------------- | -------------------------------------------------------------- |
| **国产化率提升≠利润提升** | 内卷侵蚀利润，有收入无利润                     | 严格审视竞争格局和利润转化能力；要求扣非净利润增速匹配营收增速 |
| **估值透支替代预期**       | 替代“故事”被充分定价，实际增速无法匹配       | 调整后PEG>2时机动仓必减；每季度做“假如空仓”测试              |
| **技术路线被颠覆**         | 国产替代前提是“技术已被验证”，但路线可能变革 | 组合中避免押注单一技术路线，或选择“卖水人”降低路线风险       |
| **政策节奏变化**           | 财政压力导致替代节奏不及预期                   | 关注财政支出和政企采购数据，出现实质放缓即重估                 |
| **产业非线性误判**         | 高科技产业演进非线性，拐点可能迟迟不来         | 坚守财务底线；设置1年时间止损                                  |
| **地缘政治冲击**           | 关税、出口管制、制裁清单等外部冲击             | 优先选供应链可控的标的；将地缘政治风险作为估值折价调节项       |
| **能力圈外硬撑**           | 看不懂科研转化却强行投资科技股                 | **果断放弃**，赚认知范围内的钱                           |

# 第六部分 决策优先级金字塔

当各维度判断出现冲突时，遵循以下**优先级从高到低**的决策规则：

| 优先级                               | 触发条件                                   | 决策                                 | 思想来源         |
| ------------------------------------ | ------------------------------------------ | ------------------------------------ | ---------------- |
| **第一优先级（一票否决）**     | 管理层诚信问题暴露、财务造假实锤、监管立案 | **立即清仓**，不考虑估值和趋势 | 李进（治理评估） |
| **第二优先级（硬止损）**       | 单笔亏损达8%~10%，且无明确基本面反转信号   | **无条件止损**                 | 欧奈尔           |
| **第三优先级（逻辑止损）**     | 连续2个季度业绩低于预期，且产业景气未改善  | **减仓或清仓**                 | 林奇 + 郑希      |
| **第四优先级（产业景气判断）** | 前三项均未触发，但渗透率/ROE出现拐点信号   | **按景气方向调仓**             | 李进 + 郑希      |
| **第五优先级（估值判断）**     | 以上均未触发，仅股价短期波动或估值波动     | **底仓不动，机动仓调整**       | 林奇             |

**核心原则**：先保命（止损/防造假），再谈收益（景气/估值）。欧奈尔的底线规则优先于林奇的乐观逆向。

# 第七部分 一页纸操作备忘卡

建议打印此页，贴在投资笔记中，每次操作前快速过一遍：

---

**【前置判断】**

- 地缘政治倒逼强度：制裁是否已落地？断供是否已实际发生？
- 政策覆盖度：是否被“十五五”以“超常规+全链条”覆盖？
- 国字号基金介入：是否有大基金/AI基金/制造业转型基金注资？
- → 三维交叉判断后，才进入下一步筛选

**【选股】**

- 产业空间≥1000亿，渗透率10%~30%，业绩已兑现
- 国产化率2%~10%为理想跟踪期，10%~30%为加速投资期
- 营收≥10亿，ROE有向上趋势，ROIC > WACC，现金流为正
- 管理层诚信（年报验证）+ 科研转化（专利/新产品收入/重大科研项目进展）
- 费雪补充检查：销售组织出色？管理层持股≥3%？
- 地缘政治：评估海外收入依赖度与供应链可控性

**【估值】**

- 快速增长型：调整后PEG<1.2买入，>1.5减仓
- 高研发投入型：Rule of 40 ≥ 40，PS/EV/Sales低于同业可比
- 分批建仓：合理区间下沿1/3，恐慌加1/3，景气确认补1/3

**【持仓】**

- 底仓（60%~80%）长持，机动仓（20%~40%）做估值波段
- 单只≤15%（绝对上限≤20%），单行业≤40%，持股5~10只
- 每季度末再平衡一次，偏离目标±5%触发

**【卖出（按优先级）】**

- 最高优先级：管理层失信/财务造假 → 立即清仓
- 次高优先级：硬止损8%~10% → 无条件离场
- 第三优先级：连续2季业绩低于预期 → 减仓/清仓
- 补充：满1年（4季度）逻辑未兑现 → 减仓至观察仓
- 第四优先级：渗透率减速/ROE拐头 → 减机动仓
- 第五优先级：估值PEG>1.5 → 减机动仓；PEG>2 → 加速清机动仓
- **永久性衰退判断**：若行业需求被替代、护城河消失、研发持续削减 → 立即清仓

**【风控】**

- 闲钱投资：资金期限 ≥ 持有期 + 至少1年安全垫
- 每季度复盘持仓逻辑 + 行业景气 + 地缘政治 + 估值水位
- 组合最大回撤目标≤20%，接近目标时提高现金比例

**【决策优先级（当各维度“打架”时）】**

- 欧奈尔的止损 > 林奇的逆向加仓
- 逻辑证伪 > 估值便宜
- 先保命，再谈收益
