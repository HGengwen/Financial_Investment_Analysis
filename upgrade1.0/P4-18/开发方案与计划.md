## 1. 目标与范围

### 1.1 目标

产出 GARP 独立档（**1~5 年**）的**供应链瓶颈猎手**技能 `/garp-bottleneck-hunter {趋势名}`，并做到——

1. **瓶颈分层叠加国产化率**（验收要点 1）：Layer 2/3 每个环节的瓶颈条目须**同时标注**「瓶颈评级（S/A/B）」+「GARP 景气度（强/中/弱）」+「**国产化率四梯队档位**（<5% 过早 / 5%~20% 突破期 / 20%~50% 加速投资期 / >50% 替代空间收窄）」；**定档一律只读** `garp-geo-policy`（P4-1，**已交付**）的 `localize`，本技能**不自评、不定档**（`GBH-11`）。
2. **地缘 0.3 矩阵叠加**（验收要点 2）：前置闸门与公司筛选段的地缘部分**只读** `garp-geo-policy` 的 **0.3 三维交叉矩阵结论 / 赛道两分法归属（地缘倒逼型 / 政策资本驱动型）/ 国产化率四档 / 敞口体检**；**废止**骨架「地缘政治六维自评分」与「华为式抗封锁」自评段；**0.3 矩阵回避档 → 终止扫描**（`GBH-5`）。
3. **3 年隐含回报计算复用工具**（验收要点 3）：估值安全边际沿用骨架「**3 年隐含回报**」（远期 PE + 渗透率），但**全部算术经 `financial_rigor.py`**（`calc` / `three-scenario --years 3`），**禁止 LLM 心算**；**不得**回退到 10 年长期版「10 年 25x PE 退出」口径（`GBH-8`）。
4. **共性口径七处替换全命中**：共性 2（渗透率 + 国产化率）与共性 3（地缘）为**点名差异**；共性 1/4/5/6/7 为**连带替换**（§7.2 刚性要求）；逐项对照见 §4.4。
5. **口径零复制（引用不重复定义）**：渗透率 / 国产化率 / 财务五门槛 / 科技豁免 / ROIC 四档 / 管理层与科研转化 / 估值矩阵 / ESG 折价 / 三维交叉矩阵 / 宏观三表 / 五级卖出 / 仓位规则 / ATR 止损 / 暂时性困难 vs 永久性衰退**一律引用**（指向框架章节号或 `garp-*` 技能出口或工具命令），本技能**只定义流程与编排**。
6. **三档并存路由隔离**：技能内引用**只指向** `garp-*` 系列 + 复用 2 技能（`qoq-accelerator`、`trend-momentum-scan`）；**禁止**引用 1~3 年中期链（`mid-*`）与 10 年长期链（`bottleneck-hunter` / `industry-*` / `dyp-*`）技能；**禁止**出现 `--horizon`、`P0~P5`、`mid-bottleneck`、`bottleneck-map` 等档位切换类口令与跨档路径。
7. **风控硬编码 `GBH-1`~`GBH-12`**：把骨架 `BN-1`~`BN-10` **逐条映射重编号**并新增 GARP 专有闸门（国产化率叠加 / 三档语域与文件隔离），保持「一技能一编号族」定例与三档隔离。
8. **零新增 CLI、引擎零改动**：`tools/common/*` 与 `tools/specialized/*` **不改签名、不改行为、不新增子命令**；估值档位与卖出阈值**经 `garp-valuation` / `garp-exit` 转接**，本技能不自建档位链、不自建止损链。
9. **「发现机会」而非「做决策」的刚性边界**：本技能输出**观察名单**，买入前须执行 `/garp-investment-checklist`（P4-3，**已交付**）；**组合层仓位数值裁决归 `garp-portfolio-review`**（P4-8，已交付），本技能只出**相对动作**。
10. **报告目录 + 命名规约 + 四基准**：产出按趋势名分目录的 5 类文件，报告头部必注明**四基准**（数据 / 估值 / 资料 / 口径），见 §2.12。
11. **双门禁 + 七项交付件**：开工门禁 A~H（本文件 §9）+ 完成门禁留痕（详细计划 §0.7）；交付件严格对齐 §0.5「技能类七项」。

### 2.6 国产化率四梯队叠加（共性 2 + 验收要点 1，**核心差异**）

> **引用刚性**：国产化率**定档唯一权威**为 `garp-geo-policy`（P4-1，**已交付**）的 `localize` 子命令；本技能**只读取回、不自评、不定档**（`GBH-11`）。

| 梯队 | 国产化率区间 | GARP 判定（框架第 1 步·行 200~212） | 瓶颈叠加含义 |
| --- | --- | --- | --- |
| 第一梯队 | **<5%** | **过早**（战略卡脖子环节可观察 / 小仓、不重仓） | 瓶颈真实但**国产替代尚未起量**，观察为主 |
| 第二梯队 | **5%~20%** | **突破期**（跟踪 / 小仓） | 瓶颈 + 替代起点，**重点跟踪** |
| 第三梯队 | **20%~50%** | **加速投资期**（订单放量） | **瓶颈 + 替代加速共振，最高优先级** |
| 第四梯队 | **>50%** | **替代空间收窄** | 瓶颈若在此档，**替代红利已兑现**，须下调优先级 |

- **不可达降级**：`garp-geo-policy` 结论不可得时 → 改指《框架》**第 1 步**（国产化率四梯队）并在报告标注「国产化率定档未取回，按框架原文口径呈现」，**不新增技能**（§3.3 #4）。

| 景气维度 | 骨架（**废止刻度**） | GARP 独立档（本技能） | 大师锚点 |
| --- | --- | --- | --- |

#### 前置 B：地缘政策前置闸门（**核心差异**）

按 §2.9 调 `geo_policy_screen.py screen` 取 **0.3 三维交叉矩阵结论**与**赛道两分法归属**：

- **回避档 → 终止扫描**（`GBH-5`），不进入后续七步；
- **地缘倒逼型** → 「地缘倒逼强度非低/无」为**硬门槛**（框架第 3 步·支柱四）；
- **政策资本驱动型** → 仅作**敞口体检**（海外收入 / 供应链 / 地区冲突暴露可控），达标与否交由支柱五判定；
- 结论不可得 → 按 §3.3 #4 降级，改指框架原文口径。

#### 第一步：超级趋势确认

按 §2.3 四标准（+ 需求真实性）验证趋势，输出**趋势验证块**（骨架承接）：趋势名称 / 核心驱动力 / ≥3 个验证事件（日期 + 事件 + 来源）/ 资本开支规模 / 供需缺口判断 / **渗透率位置（`15%~40%` 五档 + A/B/C 置信度）** / **未来 3 年复合增速（经 `financial_rigor.py`）** / **趋势确认 ✅ 可追踪 或 ❌ 证据不足终止（`GBH-1`）**。

#### 第二步：供应链物理拆解

按 §2.4 拆 Layer 0 → Layer 4；每个 **Layer 2/3** 环节标注「景气指标」+「**国产化率四梯队档位**」（只读 `garp-geo-policy` 的 `localize`）。骨架内置的 **AI 基础设施**与**创新药**拆解模板须 **GARP 化**（渗透率刻度替换 + 国产化率列新增 + 术语替换）。

#### 第三步：瓶颈识别 + GARP 景气度叠加 + 国产化率叠加

1. 按 §2.5 六条标准逐条评估 → **S / A / B 评级**；
2. 按 §2.7 叠加 **GARP 景气四维**（渗透率 `15%~40%` / ROE 趋势 / 二阶导 / 订单能见度）；
3. 按 §2.6 叠加**国产化率四梯队**；
4. 输出**瓶颈地图**（三要素齐备：瓶颈评级 + 景气度 + 国产化率梯队）；
5. 「瓶颈真实 + 景气度弱」→ 标**伪瓶颈**，不纳入观察名单；「瓶颈 S/A + 景气强 + 国产化率第二/三梯队」→ 进入重点扫描。

#### 第四步：公司筛选（初筛 + 深度）

1. **初筛**：按 §2.8 八项（含**财务五门槛 / 科技豁免 / 能力圈自检**）过滤；
2. **深度筛选**：对通过初筛公司逐家评估——瓶颈定位 / 产能与扩张 / 财务快照 / **ROE 趋势与 GARP 景气度** / **国产化率梯队位置** / **地缘 0.3 矩阵结论（只读）** / **管理层与科研转化结论（只读 `garp-management`）** / 风险检查清单 / **瓶颈持续性判断（1~5 年窗口；费雪「暂时性困难 vs 永久性衰退」）**。

#### 第五步：估值检查（必做，不可跳过）

1. **档位只读**：调 `garp-valuation`（P4-5）取**多工具矩阵统一六档**结论 + ESG 折价 + 宏观校准后 PEG 区间；**本技能不重算档位**（`GBH-4`）；
2. **瓶颈专属辅助提示**：骨架红/黄/绿灯中**瓶颈特有**条目保留为辅助提示，**须声明不构成档位判定**；
3. **3 年隐含回报（必做）**：按 §2.10 第 3 行，全部算术经 `financial_rigor.py`（`GBH-8`）；
4. **宏观透传**：调 `macro_calibrator.py` 取 stage 与参数，**只调参不择时**。

#### 第六步：交叉验证

按 §2.11 执行正向（含**国产化率验证**）/ 反向 / 信号三类交叉验证；每个结论 ≥2 个独立信源（`GBH-9`）。

#### 第七步：输出瓶颈机会看板 + 准出

1. 按 §5.2 输出**瓶颈机会排名表**（含瓶颈评级 / 景气度 / **国产化率梯队** / 估值档位 / 信号强度）+ **每机会一页纸摘要** + **行动建议表**；
2. 落盘至 §2.12.1 路径；跑 `report_audit.py` 抽检；
3. **醒目标注**：「本报告为**观察名单**，不是**买入清单**；买入前必须执行 `/garp-investment-checklist`（P4-3）七关检验」；
4. **不写回任何上游文件**。
