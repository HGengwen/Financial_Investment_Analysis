# GARP 中长期价值成长（1~5 年）框架升级——目标与当前实现差距分析

> 适用对象：本仓库软件（`tools/`）与技能（`.trae/skills/`）体系。
> 升级目标：《中长期价值成长（GARP）投资框架（科技与国产化主题增强版）》（本目录下）。
> 数据截止 / 盘点日期：2026-09-12。
> 结论导向：本文件只做差距分析，不展开实施细节；实施见《GARP升级-软件与技能升级方案与计划.md》。

## 1. 分析方法与结论速览

本仓库现有投研能力分**中期链（1~3 年，四大师：林奇 / 郑希 / 李进 / 欧奈尔）**与**长期链（10 年，护城河四大师）**两档，物理隔离。GARP 框架是 **1~5 年的独立档**，核心增量有三：

1. **第五位大师费雪加入**——质化分析、销售组织、管理层持股、暂时性困难 vs 永久性衰退、"不卖"边界；
2. **宏观环境适配层**——利率周期 / 经济周期 / 美林时钟三表，动态校准 PEG 区间、现金仓位、单只上限；
3. **地缘政策前置与国产化专项**——0.3 三维交叉矩阵、赛道两分法、指定行业/领域国产化率分层量化（框架以半导体设备为示例）、政策基金三层架构、ESG/环境风险折价。

**总判定**：现有体系已覆盖 GARP 约 **55%~60%** 的能力（财务初筛、景气打分、PEG 五档、底仓/机动仓、P0~P5 卖出、地缘六维、研发/在研项目扫描），**约 40%~45% 为缺口**。缺口集中在三层：

| 层                   | 缺口性质                                                                                                                                                                 | 占比 | 处置                                                   |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---- | ------------------------------------------------------ |
| 计算/工具层（tools） | ①估值多工具缺口（Rule of 40 / EV-Sales / 隐含 PEG / DCF）；②ATR 波动率止损缺口；③ROIC/WACC/增量回报缺口；④宏观校准引擎完全缺失；⑤地缘政策三维矩阵与国产化率分层缺失 | 核心 | 新增工具 + 扩展`financial_rigor.py`、`momentum.py` |
| 数据源层             | 管理层持股 / 大股东质押 / 销售组织 / ESG / 国产化率 / 渗透率 / 产业基金 / 制裁清单无结构化数据源                                                                         | 关键 | 新增数据工具（akshare 优先 + 搜索回退）                |
| 技能层（skills）     | GARP 独立档缺"买入检查·估值矩阵·地缘政策·宏观校准·卖出五级·能力圈自检"6 类命门                                                                                      | 关键 | 新增 GARP 独立档技能（不改动现有已完技能）             |

### 3.4 非 `mid-` 前缀强相关技能逐个判定（6 项）

`3.2 技能层`表格中，除 16 个 `mid-*` 技能外，另有 6 个**无 `mid-` 前缀**但承担具体投研流程的技能与 GARP 直接相关。按「逐个阅读、逐个判定」方式逐项比对 GARP 框架，结论分三类：

- **口径重构型**：骨架与数值口径均需改（估值工具矩阵重构、卖出体系重构）；
- **口径替换型**：骨架可复用、口径参数需替换；
- **复用不新建**：纯计算/纯技术型，与持有期限无关，仅做出口引用转接与工具层补齐。

| 现有技能 | 能否直接用于 GARP | 处置 | 对应 garp-* | 类型 | 判定依据 |
| --- | --- | --- | --- | --- | --- |
| `valuation-thermometer` | 否 | 开发独立 | `garp-valuation` | 口径重构型 | 现有仅 PEG/PSG/PE 分位/implied-growth 四工具 + 静态五档；GARP 需多工具矩阵（Rule of 40/EV-Sales/隐含 PEG/DCF）+ ESG 环境折价 + 宏观 PEG 区间动态校准 |
| `exit-signal` | 否 | 开发独立 | `garp-exit` | 口径重构型 | 现有 P0~P5 六级、P0 标"李进(治理)"；GARP 为五级卖出（诚信前置归费雪一票否决）+ 时间/性价比降为补充 + 暂时 vs 永久性衰退清单 |
| `qoq-accelerator` | 是（复用） | 不新建 | —（仅出口转接） | 纯计算型 | 规则 A~E（连续 3 季二阶导、YoY 主/QoQ 辅口径）与期限无关；出口引用需转接 `garp-exit` / `garp-valuation` |
| `trend-momentum-scan` | 是（复用） | 不新建 | —（仅出口转接） | 纯技术型 | SMR/RSI50/MA50/MA200/量能体检与期限无关；缺 ATR 由工具层 `momentum.atr` 补；破位引用转接 `garp-exit` |
| `thesis-tracker --horizon mid` | 否 | 开发独立 | `garp-thesis-tracker` | 口径替换型 | `--horizon mid` 分支锁死 P0~P5、旧 PEG 五档、四大师假设维度；GARP 需五级卖出 + GARP PEG 五档 + 费雪质化维度 + 独立 `-garp-thesis.md` |
| `portfolio-review --horizon mid` | 否 | 开发独立 | `garp-portfolio-review` | 口径替换型 | 底仓/机动仓骨架一致；缺流动性 >1 亿、ESG 仓位下调、ATR 关联、宏观周期现金/上限调档 |

**判定结论（6 项）**：4 个需开发独立、2 个复用不新建。

- 开发独立（4）：`valuation-thermometer`→`garp-valuation`、`exit-signal`→`garp-exit`（口径重构型）；`thesis-tracker --horizon mid`→`garp-thesis-tracker`、`portfolio-review --horizon mid`→`garp-portfolio-review`（口径替换型）。
- 复用不新建（2）：`qoq-accelerator`、`trend-momentum-scan`（纯计算/纯技术型，仅工具层补 ATR + 出口引用转接，不新增技能）。

此 6 项与 3.3 的 16 个 `mid-*` 判定合并后，构成 GARP 独立档完整技能集 **22 个 `garp-*`** 的技能层来源：口径重构型 4（`garp-investment-checklist` / `garp-management` / `garp-valuation` / `garp-exit`）+ 口径替换型 16（14 个 `mid-*` 对应 + `garp-thesis-tracker` / `garp-portfolio-review`）+ 命门净新增 2（`garp-geo-policy` / `garp-macro`）。

### 3.5 命名冲突处理（`garp-*` 前缀历史遗留）

仓库已有 `garp-ask`（GARP 问答·1~3 年·林奇主轴）、`garp-liquidity-reinvestment`（流动性再投资·1~3 年景气版）两个 `garp-` 前缀技能，实为**中期链（1~3 年、四大师）**口径，与本次 1~5 年 GARP（五大师）独立档存在前缀冲突。处置（已确认）：将两处历史遗留技能**重命名为 `mid-` 前缀**——`garp-ask` → `mid-ask`、`garp-liquidity-reinvestment` → `mid-liquidity-reinvestment`，彻底消除 `garp-` 前缀歧义，使 `garp-` 前缀专属于 1~5 年 GARP 独立档；同步更新 CLAUDE.md 路由与两份工作步骤文档中的命令引用（`/mid-ask`、`/mid-liquidity-reinvestment`）。此为对"不改动既有技能"硬约束的**定向豁免**（仅限这两处历史遗留命名的重命名）。

## 6. 结论

1. 现有体系是"**四大师、两档、无宏观、PEG 单锚**"；GARP 目标是"**五大师、三档、加宏观、多工具估值 + 地缘政策矩阵**"。
2. 差距不在地基（财务/行情/搜索/打分/仓位已就绪），而在**三个新增引擎**：宏观校准、估值多工具、地缘政策矩阵，以及**两个计算增强**：ATR、ROIC/增量回报。
3. 技能层采用**"新增独立档技能 + 引用不改动既有技能"**策略，工具层采用**"扩展已有多数字段 + 新增专用工具"**策略，遵循项目既有"工具沉淀、技能编排、禁止 LLM 心算"的架构原则。
