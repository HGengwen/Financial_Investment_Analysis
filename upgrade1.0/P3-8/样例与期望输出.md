## 9. 用法错误例（EXIT=**2**，错误写 stderr、stdout 不输出 JSON）

## 12. 口径说明与已知浮点现象

### 12.1 计算口径（不可变）

- `n_i = launch_year_i − as_of_year`；`PV_peak = peak_revenue/(1+r)**n`；`PV_cost = cost/(1+r)**n`；`NPV_i = probability_i × PV_peak_i − PV_cost_i`；`pipeline_npv = Σ NPV_i`；
- **概率是唯一风险调整因子**；不做分期投入、税率、摊销、残值、项目相关性调整；
- 金额单位由调用方自定义（亿元/百万元），工具只做同比运算、**不解释单位、不换算币种**。

### 12.2 敏感性网格折现率的浮点表示

网格首行为 `"discount_rate": 0.09000000000000001`，这是 `0.1 − 0.01` 的 IEEE-754 双精度表示（非口径错误）。同理 `0.1 + 0.01` 显示为 `0.11`。该末位差异对 NPV 的影响在 1e-13 量级以内（见 §11 第 5/6 行）。

### 12.3 基准年份来源与冲突校验

`as_of_year` 由 CLI `--as-of-year` 决定（缺省 = 系统当前年份并回显）；`--projects` 内**允许**出现 `as_of_year` 键，但必须为**整数**且与本次基准年**一致**，否则报用法错误（E13 冲突 / E14 类型非法）——**不得静默忽略**调用方提供的参数。下游调用（P4-5 `garp-valuation`）须显式传 `--as-of-year` 以保证可复现。

### 12.4 折现率上下限（U3）

- 下限：`r > -1`（保证 `(1+r)` 为正）；
- 上限：`r ≤ 1.0`（`MAX_DISCOUNT_RATE`）——**仅拦「百分数当小数」的量纲误用**（如把 10% 写成 `10`），不限制任何现实合理的折现率；
- 敏感性网格同口径：`r − Δr ≤ 0`（E8）或 `r + Δr > 1.0`（E15）均报用法错误。

### 12.5 与 P4-5 的衔接语义

- 本工具输出**数值**（NPV + 敏感性区间），供 P4-5 作为**未盈利科技型的辅助**输入（框架行 385），与 PS / EV-Sales 主锚并列，**不得替换主锚**；
- `data_insufficient=true` 时，P4-5 报告须按「定性 + 数据缺口标注」降级，**不得声称 NPV 已量化**；
- 必填 `launch_year` + `probability` + `source` 即框架「清晰的盈利路径和里程碑节点」的强制落点。
