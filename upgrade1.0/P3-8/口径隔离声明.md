## 3. 参数口径隔离（无内置假设）

| 参数 | 供给方 | 工具行为 | 隔离保证 |
| --- | --- | --- | --- |
| `--discount-rate` | **调用方必填** | 无默认、不回退 WACC / 无风险利率；`≤ -1` 或 `> 1.0` 报错 | 缺失时 argparse 以退出码 2 终止，**不产生替代值** |
| `--currency` | **调用方必填** | 无默认；不做汇率换算；文件内 `currency` 与 CLI 不一致即报错 | 不与 `fx_rate.py` 等任何汇率来源联动 |
| `peak_revenue`（峰值收入） | **调用方必填** | 无行业经验值、无行业均值回填 | 缺失 → `data_insufficient=true` + `missing[]` |
| `launch_year`（商业化年份） | **调用方必填** | 无缺省年份；早于基准年即报错 | 同上 |
| `probability`（成功概率） | **调用方必填** | 无默认成功率；越界报错（不做项目级截断） | 同上 |
| `source`（参数来源） | **调用方必填** | 原样回显，供审计追溯 | 缺失 → 计入 `missing[]` |
| `cost` | 调用方可选 | **唯一允许的缺省**：缺省 `0.0`，且必须写入 `defaults_applied` 回显 | 显式 `cost=0.0` 不进入 `defaults_applied` |
| `as_of_year` | CLI `--as-of-year`（缺省 = 系统当前年并回显） | 文件内若出现该键，必须为整数且与本次基准年一致，否则报错 | 不得静默忽略调用方参数 |

**上限 `MAX_DISCOUNT_RATE = 1.0` 的性质说明**：该常量**不是折现率的默认值或经验值**，而是**量纲误用拦截阈值**（折现率以小数给出，`0.10` 表示 10%；写入 `10` 显然是把百分数当小数）。它不限制任何现实合理的折现率，亦不参与任何计算。

## 7. 红线清单（工具内禁止出现的行为）

1. **禁止内置默认值**：折现率、币种、峰值收入、成功概率、商业化年份一律不得回退到任何经验值/行业值/历史值；
2. **禁止替代数值**：存在任一缺项时，一律 `data_insufficient=true` + `missing[]`，且**逐项目 `npv` / `pv_peak` / `pv_cost` 均为 `null`**（不做部分计算）；
3. **禁止汇率与单位解释**：不换算币种、不解释金额单位（亿元/百万元由调用方自定）；
4. **禁止模型加戏**：不做分年爬坡、税率、摊销、残值、项目相关性调整；概率是**唯一**风险调整因子；
5. **禁止项目级概率截断**（仅敏感性网格平移格允许截断，且必须标注 `clipped=true`）；
6. **禁止输出结论**：不输出买卖建议、档位、评级、排序、目标价；
7. **禁止替换主锚**：不得暗示 NPV 可替代 PS / EV-Sales 主锚；
8. **禁止跨档位取材**：不得引用 `mid-*` / 长期链的任何阈值、量表或档位。

> 上述第 1、2、6 条已在《样例与期望输出》§10 与《测试记录》§3（验收 6.2 / 6.4 / 6.5）逐条对应实测证据。

## 9. 结论

本任务产物为 GARP 独立档（1~5 年）专用、**参数全外供、离线纯计算**的数值工具：

- **口径唯一锚定**框架第 4 步·估值工具矩阵行 385（未盈利科技型·研发管线 NPV 辅助工具）与 P4-5 §2.5；
- **与中期链 / 长期链物理隔离**，与同文件既有 `scan` 口径共存但语义互不侵入，与相邻工具不重复实现、不自动取用；
- **无内置假设、无替代数值、无结论输出**，八条红线经样例与单测逐条落证；
- **无口径漂移。**
