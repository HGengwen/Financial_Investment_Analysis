# GARP 论文漂移检测（1~5 年）：H1~H7 七维假设逐条验证

对比**建仓时 GARP 投资论文的 H1~H7 七维假设**与**最新季度财报与景气数据**，逐条验证假设是否仍成立，输出「**四级漂移等级 + 证据链**」及行动建议，回答「**当初的 GARP 逻辑还在吗？**」。

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

**核心理念**：基于证据而非信仰。用最新季度数据逐条验证 GARP 假设，假设被证伪（**≥4 项完全漂移**）时，**无论股价涨跌均触发卖出评估**。

**检测频率**：季度（财报发布后必做）；事件驱动可即时复核（监管、并购、管理层变动、地缘政策变动）。

**本技能不提供档位切换参数**——它即 GARP 独立档专属入口，命令与输入中不含任何档位切换开关；档位切换类口令属 1~3 年中期链，在本技能中出现即违反 `GDR-12`（口径隔离与语域）。

## 一、设计原则（七条）

| # | 原则 | 含义 |
| --- | --- | --- |
| 1 | **证据优先于信仰** | 每维判定必须附证据链（最新值 vs 建仓基线 + 偏差 + 来源 + 命令），禁止「感觉逻辑还在」式主观结论 |
| 2 | **仅 🔴 完全漂移计入计数** | ⚠️ 部分漂移只记录、不计数；四级等级由「完全漂移项数」**等权计数**决定，权重列不参与加权 |
| 3 | **连续 3 季不靠单季** | 单季负加速**不判**拐点（`GDR-2`）；连续 3 季负加速**必须判** 🔴（`GDR-1`） |
| 4 | **禁止 LLM 心算** | 偏差百分比 / 加速度 / 隐含增速 / PEG **一律经 `financial_rigor.py`**，报告不得出现手算数值 |
| 5 | **基线必须显式提取** | H1~H7 必须从论文 / 报告中明确提取，禁止 AI「脑补」；缺项标注「无法验证，不纳入计数」（`GDR-7`） |
| 6 | **漂移等级强制映射，不可降级** | 🔴→**三级·逻辑止损**、🟠→**四级·产业景气判断**、诚信线索→**一级·诚信否决**（前置）；**只映射、不自建级别、不叠加估值修正**（`GDR-3`、`GDR-8`） |
| 7 | **档位只读、结论只出相对动作** | 估值档位只读 `garp-valuation`；卖出级别只读 `garp-exit`；只出「继续持有 / 底仓持有 / 减机动仓 / 减仓或清仓评估」等**相对动作**，**不出仓位数值** |

## 二、调用参数（技能调用约定，非新增命令行开关）

以下参数为技能调用时的解析约定，由 AI 解析并映射到既有工具调用与执行流程，**不新增任何 Python 命令行开关**（零新增 CLI / 零改动工具原则）：

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | :--: | --- | --- |
| `{标的}` | 位置 | 是 | — | 公司名或代码（支持 A 股 / 港股 / 美股） |
| `--thesis-date` | 日期 | 否 | 最新 | 指定对比的 GARP 论文版本（基线来源 ①） |
| `--since` | 日期 | 否 | 读论文 | 买入日期（供时间止损判断）；缺省则标注「无法判断时间止损」 |
| `--old` | 路径 | 否 | — | 基线降级来源 ④：显式指定旧报告路径 |
| `--export` | 标志 | 否 | false | 导出 Markdown 报告至 `reports/`（未开启则仅在对话内输出） |
| `--export-path` | 字符串 | 否 | `reports/` | 报告输出根路径（配合 `--export` 使用） |
| `--json` | 标志 | 否 | false | 输出结构化 JSON（供下游解析） |
| **档位切换类参数** | — | — | — | **不提供**：本技能即 GARP 独立档唯一入口；此类口令出现即违反 `GDR-12` |

**参数语义映射**：

- `--thesis-date`：指定对比的建仓论文版本；默认取最新 GARP 论文。
- `--since`：买入日期，用于「持有 ≥4 个季度」的时间止损判断；缺省时从论文读取，再缺省标注「无法判断时间止损」。
- `--old`：**新增**（骨架无此参数），用于基线来源 ④ 的显式降级路径；使用时报告须显式标注「基线来源 ④（用户指定），置信度中」。
- `--export` / `--export-path` / `--json`：同既有技能约定。

### 两种触发模式

1. **主动调用**：用户显式 `/garp-thesis-drift {标的}`（**每季报发布后必做**）。
2. **被动触发**（上游产出下列信号时提示转入）：

| 上游信号 | 来源技能 |
| --- | --- |
| 连续 3 季负加速（核心证据） | `qoq-accelerator`（复用 2 技能） |
| 连续 2 次评级下降 | `trend-momentum-scan`（复用 2 技能） |
| MA200 破位 + 增速连续负加速（**强制触发**） | `trend-momentum-scan` + `qoq-accelerator` |
| SMR 强势（>70）转弱势（<40）且持续 ≥2 次 | `trend-momentum-scan` |
| 论文健康度 ≤4 分 **或**五级卖出任一命中 | `garp-thesis-tracker`（P4-7） |
| 地缘结论落入回避档 / 赛道两分法改判 | `garp-geo-policy`（P4-1） |

### 3.1 七维基线表（权重仅展示优先级，**不参与加权**）

| **H2** | **订单 / 合同负债** | 郑希 | 建仓时合同负债水平、预期订单增长 | 15% |

| **H4** | **毛利率** | 林奇 | 建仓时毛利率水平、预期趋势 | 10% |

> **权重合计**：15 + 15 + 15 + 10 + 15 + 10 + **20** = **100%**。
> **计数刚性**：四级漂移等级由「🔴 完全漂移项数」**等权计数**决定；**权重列只用于报告展示优先级，不参与加权、不改变等级**（避免「权重高即自动升级」的自由裁量）。

### 3.2 与 `garp-thesis-tracker`（P4-7）五维假设清单的映射（防两套维度冲突）

> P4-7 的论文活文档使用**五大师假设维度（五维，每维 2~4 条，共 10~20 条）**；本技能使用**七维 H1~H7（固定七条）**。二者**不是同一刻度**，须按下表映射提取，**不得强行一一对应**。

| 本技能 H 维 | 映射 P4-7 论文维度 | 映射说明 |
| --- | --- | --- |
| H1 渗透率与国产化率 | ② 渗透率与产业阶段 | 取该维中涉渗透率 / 国产化率的假设条目 |
| H2 订单 / 合同负债 | ① 景气 | 取涉订单 / 合同负债的条目；无则标「论文未设该假设」 |
| H3 ROE 趋势 | ① 景气 | 取涉 ROE 的条目 |
| H4 毛利率 | ① 景气 | 取涉毛利率 / 盈利质量的条目 |
| H5 增速加速度 | ① 景气 | 取涉营收 / 利润增速与二阶导的条目（**主锚 `qoq-accelerator`**） |
| H6 地缘政策 | —（P4-7 五维未含地缘） | **由 `garp-geo-policy`（P4-1）报告或框架第 0 步·0.3 直接提取**；无则标「地缘风险未设基线」 |
| H7 费雪质化 | ④ 治理与质化 | 取诚信闸门 / 管理层评分 / 科研转化评分 / 销售组织 / 持股 ≥3% 条目 |
| —（P4-7 有、本技能不用作 H） | ③ 估值与类型；⑤ 趋势与纪律 | **不作为 H 漂移维**：③ 由「档位复核联动」承载（规则四）、⑤ 由「技术面联动」承载，**避免三重记账** |

- **映射刚性**（`GDR-7`）：**不得**把 P4-7 的五维直接当作本技能的 H 基线编号输出；报告第一节须**并列呈现映射关系**，便于双向追溯。

### 3.3 基线来源与提取纪律

| 优先级 | 基线来源 | 路径 / 出口 | 置信度 |

## 四、规则二：逐维三档判定（第二步）

每维输出「✅ 成立 / ⚠️ 部分漂移 / 🔴 完全漂移」，**仅 🔴 计入完全漂移计数**；每条附证据链。

| 维度 | 判定阈值（硬编码） |
| --- | --- |
| **H1 渗透率与国产化率** | 最新渗透率仍在 `15%~40%` 且二阶导非负 → ✅；偏差 <20% 或进入 `40%~60%` 兑现期 → ⚠️；偏差 ≥20% **或**二阶导转负 **或**渗透率 **>60%（天花板）** → 🔴；**TAM <1000 亿时黄金窗判定不成立**，须显式标注 |
| **H2 订单 / 合同负债** | 合同负债 ≥ 预期 → ✅；偏差 <15% → ⚠️；偏差 ≥15% **或环比绝对下降** → 🔴；存货大增但合同负债未增 → 库存积压预警（⚠️ 附加标注） |
| **H3 ROE 趋势** | 连续 3 季向上 → ✅；持平或小幅降（<10%）→ ⚠️；**下降 ≥10% 或连续 3 季下降** → 🔴 |
| **H4 毛利率** | ≥ 建仓时 → ✅；下降 <3 个百分点 → ⚠️；**下降 ≥3 个百分点或连续 3 季下降** → 🔴；利润增速 < 营收增速（差距 ≥10%）→ 费用失控预警 |
| **H5 增速加速度** | 连续 3 季增速上升 → ✅；先升后平 / 正负交替 → ⚠️；**连续 3 季增速下降** → 🔴；QoQ / YoY 双口径，矛盾时以 **YoY** 为主（**主锚 `qoq-accelerator`**） |
| **H6 地缘政策** | 0.3 矩阵结论**未由「非回避档」转坏**且敞口未实质恶化 → ✅；结论转坏但威胁未落地 → ⚠️；**结论落入回避档 / 赛道两分法改判 / 关税加征·制裁落地·供应链断裂** → 🔴；本地化产能投产 → 对冲有效（✅ 附加标注） |
| **H7 费雪质化** | 诚信闸门**未命中** 且 管理层 7+7+6 **≥15** 且（科技股）科研转化 8+8+4 **≥15** → ✅；单项边际弱化（评分 10~14 / 销售组织转弱 / 持股 <3%）→ ⚠️；**诚信闸门命中 → 🔴 且升级为前置否决**（见规则四）；管理层或科研评分 **<10** → 🔴；核查结论为「永久性衰退」→ 🔴；「暂时性困难」且其余维度未恶化 → ✅ 附加标注 |

**硬性规则（`GDR-1` / `GDR-2`）**：

```text
单季负加速不得判拐点（GDR-2）
连续 3 季负加速必须判拐点 → 🔴（GDR-1）
```

### 4.1 渗透率与国产化率双口径（引用不重复定义）

| 档位 | 渗透率区间 | 本技能用途 |
| --- | --- | --- |
| 导入早期 | <5% | H1 判「赛道未起」→ ⚠️ 及以上 |
| 突破期 | 5%~15% | H1 提示「临界点」 |
| **加速上行期** | **15%~40%（黄金窗）** | H1 判「黄金窗内」→ ✅ 前提下成立 |
| 逐步兑现 | 40%~60% | H1 判 **⚠️ 部分漂移**（骨架刻度判 🔴，**已废止**） |
| 天花板 | >60% | H1 判 **🔴 完全漂移**（骨架刻度为 50%，**已废止**） |

| 梯队 | 国产化率区间 | 含义 |
| --- | --- | --- |
| 第一 | <5% | 过早 |
| 第二 | 5%~20% | 突破期 |
| 第三 | 20%~50% | 加速投资期 |
| 第四 | >50% | 替代空间收窄 |

> **附加约束**：**TAM ≥ 1000 亿**（不足则黄金窗判定不成立，须显式标注「规模未达黄金窗门槛」）。口径归属框架第 1 步与 `garp-industry-research`（P4-9）。

### 4.2 地缘只读条款（`GDR-6`）

- 骨架的「地缘政治六维度自评分」与「抗封锁叙事」**整段废止**；H6 **不再自行打分**。
- **H6 判定输入**：`garp-geo-policy`（P4-1，已交付）输出的 **0.3 三维交叉矩阵（地缘倒逼 × 政策覆盖 × 基金介入）+ 赛道两分法（地缘倒逼型 vs 政策资本驱动型）+ 敞口体检**结论；**只读**；不可达时改指框架第 0 步·0.3 章节，**不新增技能**。
- **报告提示条款**：地缘前置闸门属**买入前**闸门，本技能**不把它并入五级卖出表**；H6 只承载「**建仓时地缘假设是否漂移**」。

### 4.3 管理层与科研转化（只引不复制，`GDR-5`）

| 项 | 权威值（断言基准） | 引用出口 |
| --- | --- | --- |
| 诚信前置 | **不计分闸门**：兑现率 <50% / 业绩预告失真 / 监管立案 / 财务造假 → 放弃 | `garp-management`（P4-4） |
| 管理层 20 分制 | **对待股东 7 + 战略执行 7 + 稳定性激励 6**；≥15 可重仓 | `garp-management`（P4-4） |
| 科研转化 20 分制 | **研发投入 8 + 研发产出 8 + 资本回报 4**；≥15 可重仓 | `garp-management`（P4-4） |
| 费雪补充 | **销售组织 + 管理层持股 ≥3%**（定性参考，不计入 20 分制） | `garp-management` + `governance_data.py` |

> **禁止**：本技能内出现等分四维度评分方案、自行重新计分或合并两套 20 分制。

## 五、规则三：四级漂移等级（第三步，**单一口径**）

| 完全漂移项数 | 漂移等级 | 颜色 | 行动建议（**相对动作**） |
| :--: | --- | :--: | --- |
| **0 项** | **未漂移** | 🟢 | 继续持有，关注 ⚠️ 项 |
| **1 项** | **轻微漂移** | 🟡 | 底仓持有，机动仓考虑减仓 |
| **2~3 项** | **显著漂移** | 🟠 | 大幅减机动仓，底仓设止损线 |
| **≥4 项** | **严重漂移** | 🔴 | **触发五级卖出映射（三级·逻辑止损），转 `garp-exit` 评估** |

> **口径统一依据（刚性留痕，必写入报告）**：1~3 年中期链骨架技能的内部两份文件对四级档位表述**自相矛盾**（一份为 `0~1 / 2 / 3 / ≥4`，另一份为 `0 / 1 / 2~3 / ≥4`）。本技能**统一采用 `0 / 1 / 2~3 / ≥4`**（与骨架示例用例「两项完全漂移 → 显著漂移 🟠」一致），**禁止双口径并存**；该缺口已在 P4-16《开发方案与计划》§4.5 登记为 **G1**，骨架本体不改，归属 P5。

**漂移趋势追踪**：逐季改善 → 逻辑修复，维持 / 加仓；逐季恶化 → 逻辑崩塌，准备退出。趋势列取值 `improving` / `stable` / `worsening`。

## 六、规则四：五级卖出映射与联动（第四步）

### 6.1 漂移等级 → 五级卖出强制映射表

> **口径归属**：五级卖出的**级别定义与阈值归 `garp-exit`（P4-6）**；本技能**只做映射与转接**，**不重定义级别、不新增级别**（`GDR-3`）。

| 触发情形 | 映射级别 | 动作（相对动作） | 转接 |
| --- | --- | --- | --- |
| **诚信线索命中（H7 前置）** | **一级 · 诚信否决**（**最高优先，前置**） | 立即清仓评估 | 立即转 `garp-exit` 一级 |
| 严重漂移 🔴（≥4 项完全漂移） | **三级 · 逻辑止损** | 减仓 / 清仓评估 | 转 `garp-exit` 三级 |
| 显著漂移 🟠（2~3 项完全漂移） | **四级 · 产业景气判断** | 减机动仓，底仓设止损线 | 转 `garp-exit` 四级 |
| 轻微漂移 🟡（1 项） | **不触发五级** | 底仓持有，机动仓考虑减仓 | 触发**档位复核**（见 6.3） |
| 未漂移 🟢（0 项） | **不触发五级** | 继续持有 | 仅提示 ⚠️ 项 |
| **持有满 4 个季度且漂移 ≥🟡** | **补充机制 · 时间止损**（**不占优先级**） | 减至观察仓 / 替换 | 转 `garp-exit` 补充机制 |
| 二级 · 硬止损（8%~10%）／五级 · 估值判断 | **本技能不判定** | — | 由 `garp-exit` / `garp-valuation` 独立判定；本技能**只作提示** |

**刚性条款（`GDR-3` / `GDR-4`）**：

1. **优先级不得倒置**：若 `garp-exit` 已命中**更高**级别（如二级硬止损、一级诚信），本技能的漂移映射**不得覆盖或降级**该结论；报告须并列呈现、以高优先级为准。
2. **补充机制不占优先级**：时间止损与五级**并列**、**仅针对「逻辑未兑现」的仓位**；**禁止**把它写成第六级，也**禁止**用它否定费雪式长期持有（见规则五·矛盾五）。
3. **不得心算止损**：ATR 止损价、衰退清单复核**一律经 `garp-exit` 转接取得**，本技能**零止损算式**。
4. **诚信是前置否决**：H7 命中诚信线索 → **直接按一级处置**，**禁止**以「质化其他项优秀」「估值便宜」「趋势向好」对冲。

### 6.3 档位复核联动（替代骨架的「档位修正因子」机制，`GDR-8`）

> 骨架的「漂移等级作为估值温度修正因子（-0.3 / -0.5 / -1.0 档，上限 ±1.0）」**整段废止**——档位取值以 `garp-valuation`（P4-5）**统一六档为唯一出口**，本技能**叠加修正会形成同一框架两套刻度**。

| 漂移等级 | 触发动作 | 档位取值 |
| --- | --- | --- |
| 🟢 / 🟡 | 不强制；🟡 时**建议**复跑 `garp-valuation` | **只读** `garp-valuation` 统一六档 |
| 🟠 / 🔴 | **强制复跑** `garp-valuation`（P4-5），取得最新档位 | **只读**其最新统一六档 |
| 任意等级 | 报告须呈现「**上次档位 → 本次档位 → 变化**」三列 | 变动原因须归因（估值变动 vs 漂移导致） |

- **统一六档**（唯一出口，**只读不重算**）：显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支。
- **禁止**：本技能**零 PEG 算式、零档位阈值定义**；发现上游结论异常 → **提示复核**，不自行修正。

## 七、规则五：五大矛盾化解（第五步）

| 编号 | 矛盾 | 本技能场景下的化解（硬编码） |
| --- | --- | --- |
| **矛盾一** | 止损 vs 越跌越买 | 🟢 未漂移 + 建仓初期跌 >8% → **止损**；🟢 + 底仓已建跌 10%~20% 且各维未恶化 → 可加仓（须转 `garp-exit` 复核）；**≥🟡 漂移 → 禁止加仓**；🔴 → **立即清仓评估，不存在「越跌越买」** |
| **矛盾二** | 噪音 vs 拐点 | 单季异常**不判**拐点（`GDR-2`）；连续 3 季一致 → 确认拐点（`GDR-1`）；连续 2 季异常、第 3 季反弹 → 降级为 ⚠️ |
| **矛盾三** | 长期持有 vs 兑现纪律 | 持有 <4 季且 ≤🟡 → 继续持有；**持有 ≥4 季且 ≥🟡 → 补充机制·时间止损**（不占优先级，仅针对「逻辑未兑现」仓位） |
| **矛盾四** | 分散 vs 集中 | 单标的漂移 → 只调该标的（相对动作）；**同行业多标的漂移 → 行业级降级提示**（映射 `garp-industry-research` / `garp-portfolio-review`） |
| **矛盾五（新增）** | **费雪「绝不卖」vs 趋势 / 景气纪律** | **「不卖」两前提缺一不可**：① **极度深度的研究认知**（H7 ✅：质化要点式核查 + 持股 ≥3% + 销售组织强 + 诚信未命中）；② **极度集中的持仓**（底仓层级、长期不动用机动仓）。**任一前提缺失 → 回到五级卖出纪律**；**禁止**以「长期主义」「绝不卖」「护城河永续」对抗 `garp-exit` 触发结论；若下跌属**永久性衰退** → **无论盈亏立即清仓评估** |

> **落地刚性**：矛盾五的化解结论**必须在报告第九节与第十一节「行动建议」两处出现**（**双落位**，仅写一处视为未落地）。

## 八、执行流程（前置 A/B + 六步）

### 前置 A：日期、参数与市场确认

1. 运行 `date` 确认当天日期，作为「报告生成日期 / 数据截止日期」基准（全局规则 1）。
2. 解析参数（第二节）并识别市场（A 股 / 港股 / 美股），决定取数工具。
3. **三档并存提示**：同目录存在 1~3 年 / 10 年档的漂移或论文文件时**只提示不修改**（`GDR-10`）。

### 前置 B：基线提取与完整性检查

按第三节优先级提取 H1~H7 并执行完整性检查；**基线全缺 → 拒绝执行**。

### 第一步：逐维假设验证

按第四节阈值逐维采集最新季度数据并三档判定，**每条附证据链**（最新值 vs 基线值 + 偏差 + 数据来源 + 命令）。

### 第二步：四级漂移等级评定

按第五节统计 🔴 完全漂移项数 → 四级等级 + 颜色 + 趋势。

### 第三步：联动执行（5 + 2 项）

按 6.2 逐项执行：`implied-growth` → `garp-exit` 五级映射 → `garp-valuation` 档位复核 → `qoq-accelerator` 交叉 → `trend-momentum-scan` 联动 → `garp-management` / `garp-geo-policy` 只读 → `garp-macro` 透传。

### 第四步：矛盾化解应用

按第七节把五大矛盾应用到当前场景；**矛盾五双落位**。

### 第五步：报告落盘

按第十节十四节模板写入 `reports/{标的}/{标的}-garp-drift-{YYYYMMDD}.md`。

### 第六步：准出与转接

跑 `report_audit.py` 抽检；命中卖出映射 → 输出「转 `garp-exit`」动作指向；**不写回任何上游文件**（`GDR-10`）。

## 十二、注意事项（编号化）

1. 开始前运行 `date` 确认当天日期，报告头部注明数据截止日期（**全局规则 1**）。
2. 关键数据须**双源交叉验证**，误差 >1% 标记；渗透率双源误差 >5pct 标低置信（`GDR-11`）。
3. 基线必须**显式提取**，禁止脑补；缺项标「无法验证，不纳入计数」（`GDR-7`）。
4. **禁止心算**：偏差百分比 / 加速度 / 隐含增速 / PEG 一律经 `financial_rigor.py`（`GDR-11`）。
5. A 股 QoQ 环比**必须先转单季**（本期累计 − 上期累计）（`GDR-11`）。
6. **禁止** `WebSearch` / `WebFetch`（中国大陆不可用），统一用本地取数工具（`GDR-11`）。
7. **禁止**回写上游论文文件；本技能**只读**（`GDR-10`）。
8. **禁用词清单**（出现即违规，除本节与「口径替换摘要」说明语境）：档位切换口令（`--horizon`）、六级卖出编号（`P0` / `P1` / `P2` / `P3` / `P4` / `P5`）、`exit-signal`、`valuation-thermometer`、`10%~30%`、以 `50%` 作为渗透率阈值、`四大师`、等分四维度评分方案、`地缘政治六维`、`护城河永续`、`终局思维`、`封仓十年`、中期链 / 长期链技能命令名与文件名（`GDR-12`）。
9. 「论文 / 漂移等级 / H1~H7」须标注「**骨架继承 + 本技能操作化、非框架原文**」（框架锚点 行 41 / 114 / 828）。
10. 未验证维度 ≥3 项 → 报告须声明「本次漂移判定置信度不足」。

## 十三、局限性说明

1. 只输出**漂移结论与相对动作**，不判断买卖价位（归 `garp-exit`）与估值档位（归 `garp-valuation`）。
2. 无 GARP 论文时基线降级，**置信度降低须显式标注**；无任何基线则**拒绝执行**。
3. 地缘维度（H6）与质化维度（H7）主观性较强，分别以「只读 `garp-geo-policy`」与「只读 `garp-management`」硬约束，**本技能不量化打分**。
4. 四级等级基于「完全漂移项数」**等权计数**，权重列仅用于展示优先级。
5. 渗透率数据由 `garp-industry-research`（P4-9）与搜索工具供给，第三方口径不统一（登记 §4.5 G6）。
6. **上游结论有误将直接传导**：H6 / H7 与估值档位均为只读，上游若有误，本技能结论随之偏误（报告须提示异常）。
