# GARP 论文漂移检测 (GARP Thesis Drift)

对比建仓时 GARP 投资论文中的 **H1~H7 七维假设**与最新季度财报及景气数据，逐条验证假设是否仍成立，输出「**四级漂移等级 + 完整证据链**」及相对行动建议，并联动 **GARP 五级卖出映射**与**档位复核**。回答一个问题：「**当初的 GARP 逻辑还在吗？**」

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

**核心理念**：基于证据而非信仰。假设被证伪（**≥4 项完全漂移**）时，**无论股价涨跌**均应触发卖出评估。

**检测频率**：季度（每季报发布后必做）。

## 一、适用口径

| 项 | 内容 |
| --- | --- |
| 所属档位 | **GARP 独立档（1~5 年，五大师）** |
| 检测对象 | 建仓论文的 **H1~H7 七维假设**（渗透率与国产化率 / 订单·合同负债 / ROE 趋势 / 毛利率 / 增速加速度 / 地缘政策 / 费雪质化） |
| 检测频率 | 季度；事件驱动可即时复核 |
| 与 1~3 年中期链 | **物理隔离**：中期链看「1~3 年景气兑现」，本技能看「1~5 年 GARP 假设漂移」；文件、编号族（`GDR-`）、报告命名互不撞名 |
| 与 10 年长期链 | **物理隔离**：长期链看「10 年护城河与商业模式永续性」，本技能**不评估永续性**、不适用长期链术语 |
| 输出性质 | **只出漂移结论与相对动作**，不判断买卖价位、不出仓位数值、**不写回上游文件** |

## 二、快速开始

### 基本调用方式

```
/garp-thesis-drift {标的} [--thesis-date 日期] [--since 日期] [--old 路径] [--export] [--json]
```

例如：

- `/garp-thesis-drift {标的}`
- `/garp-thesis-drift {标的} --thesis-date 2026-03-20 --export`
- `/garp-thesis-drift {标的} 00700 --since 2026-04-01`
- `/garp-thesis-drift {标的} --old reports/{标的}/{标的}-garp-insight-20260301.md`

### 参数表

| 参数 | 必填 | 默认 | 说明 |
| --- | :--: | --- | --- |
| `{标的}` | 是 | — | 公司名或代码（A 股 / 港股 / 美股） |
| `--thesis-date` | 否 | 最新 | 指定对比的 GARP 论文版本 |
| `--since` | 否 | 读论文 | 买入日期（供时间止损判断） |
| `--old` | 否 | — | 基线降级来源：显式指定旧报告路径 |
| `--export` | 否 | false | 导出 Markdown 报告至 `reports/` |
| `--export-path` | 否 | `reports/` | 报告输出根路径 |
| `--json` | 否 | false | 输出结构化 JSON |

> **本技能不提供档位切换参数**——它是 GARP 独立档专属入口；档位切换类口令属 1~3 年中期链，出现在本技能中即违反 `GDR-12`。

## 四、核心功能

### 4.1 H1~H7 七维假设模板（**含费雪质化**）

| 编号 | 假设类型 | 提取内容 | 权重 |
| --- | --- | --- | :--: |
| H1 | 渗透率与国产化率 | 建仓时渗透率档位（`15%~40%` 黄金窗五档）、预期提升路径；国产化率四梯队 | 15% |
| H2 | 订单 / 合同负债 | 建仓时合同负债水平、预期订单增长 | 15% |
| H3 | ROE 趋势 | 建仓时 ROE 水平、预期方向 | 15% |
| H4 | 毛利率 | 建仓时毛利率水平、预期趋势 | 10% |
| H5 | 增速加速度（二阶导） | 建仓时加速度方向、预期持续 | 15% |
| H6 | 地缘政策 | 建仓时 0.3 三维交叉矩阵结论、赛道两分法归属 | 10% |
| **H7** | **费雪质化** | 诚信闸门结论、管理层 7+7+6、科研转化 8+8+4、销售组织、持股 ≥3%、困难性质判定 | **20%** |

> 权重合计 100%，**仅用于展示优先级、不参与加权**；四级等级由 🔴 项数**等权计数**决定。

### 4.2 三档判定（每维）

```text
✅ 成立 / ⚠️ 部分漂移 / 🔴 完全漂移
仅 🔴 完全漂移计入计数
```

### 4.3 四级漂移等级（单一口径）

| 完全漂移项数 | 漂移等级 | 颜色 | 行动建议（相对动作） |
| :--: | --- | :--: | --- |
| **0 项** | 未漂移 | 🟢 | 继续持有，关注 ⚠️ 项 |
| **1 项** | 轻微漂移 | 🟡 | 底仓持有，机动仓考虑减仓 |
| **2~3 项** | 显著漂移 | 🟠 | 大幅减机动仓，底仓设止损线 |
| **≥4 项** | 严重漂移 | 🔴 | 触发五级卖出映射（三级·逻辑止损），转 `garp-exit` 评估 |

> **口径说明**：1~3 年中期链骨架技能内部两份文件对档位表述自相矛盾（`0~1/2/3/≥4` 与 `0/1/2~3/≥4`）。本技能**统一采用 `0 / 1 / 2~3 / ≥4`**，**禁止双口径并存**。

### 4.4 GARP 五级卖出映射

| 触发情形 | 映射级别 | 动作（相对动作） |
| --- | --- | --- |
| 诚信线索命中（H7 前置） | **一级 · 诚信否决**（最高优先） | 立即清仓评估 |
| 严重漂移 🔴 | **三级 · 逻辑止损** | 减仓 / 清仓评估 |
| 显著漂移 🟠 | **四级 · 产业景气判断** | 减机动仓，底仓设止损线 |
| 轻微漂移 🟡 | **不触发五级** | 底仓持有，机动仓考虑减仓；触发档位复核 |
| 未漂移 🟢 | **不触发五级** | 继续持有 |
| 持有满 4 季且漂移 ≥🟡 | **补充机制 · 时间止损**（**不占优先级**） | 减至观察仓 / 替换 |
| 二级硬止损 / 五级估值判断 | **本技能不判定** | 由 `garp-exit` / `garp-valuation` 独立判定 |

### 4.5 档位复核联动（**只读，不叠加修正**）

| 漂移等级 | 触发动作 |
| --- | --- |
| 🟢 / 🟡 | 不强制；🟡 时建议复跑 `garp-valuation` |
| 🟠 / 🔴 | **强制复跑** `garp-valuation`，取得最新统一六档 |

报告呈现「**上次档位 → 本次档位 → 变化**」三列；档位**只读** `garp-valuation`（P4-5），本技能**零 PEG 算式、零档位修正因子**。

## 五、使用示例

### 示例 1：显著漂移（两项 🔴）

```
/garp-thesis-drift {标的}
```

H1（渗透率跌出黄金窗）+ H2（合同负债环比绝对下降）两项 🔴 → **显著漂移 🟠** → 映射**四级 · 产业景气判断**，移交 `garp-exit`；同时强制复跑 `garp-valuation` 复核档位。

### 示例 2：未漂移

```
/garp-thesis-drift {标的} --thesis-date 2026-03-20
```

0 项 🔴 → **未漂移 🟢**，继续持有，仅提示 ⚠️ 项。

### 示例 3：加速度连续 3 季下降

```
/garp-thesis-drift {标的} --since 2025-06-01
```

营收增速 35% → 30% → 25% 连续 3 季下降，触发 `GDR-1`，H5 判 🔴 → **轻微漂移 🟡**，输出二阶导预警。

### 示例 4：时间止损

```
/garp-thesis-drift {标的} --since 2025-06-01
```

持有 5 个季度且漂移等级 🟡 → 触发 `GDR-4`，**补充机制·时间止损**（不占优先级），输出「减至观察仓 / 替换」相对动作。

### 示例 5：诚信线索（前置否决）

```
/garp-thesis-drift {标的}
```

H7 命中诚信闸门 → **一级 · 诚信否决**，**不参与计数**、直接按一级处置，立即转 `garp-exit`；禁止以「估值便宜」「趋势向好」对冲。

## 七、质量标准

- **基线显式提取**：H1~H7 必须从论文 / 报告明确提取，缺项标「无法验证，不纳入漂移计数」，**禁止脑补**。
- **双源交叉**：关键财务数据 ≥2 独立来源，误差 >1% 标记；渗透率双源误差 >5pct 标低置信。
- **禁止心算**：偏差百分比 / 加速度 / 隐含增速 / PEG 一律经 `financial_rigor.py`。
- **A 股累计转单季**：QoQ 环比必须先转单季。
- **准出必跑**：`report_audit.py` 抽检，不通过**不得发布**。
- **置信度声明**：未验证维度 ≥3 项 → 报告须声明「本次漂移判定置信度不足」。

## 九、核心原则

1. **引用不重复定义** — 级别定义、估值档位、管理层评分、地缘结论一律只读上游出口，本技能不复制、不重定义。
2. **口径隔离** — GARP 独立档专属；文件、编号族、报告命名、术语与 1~3 年 / 10 年档物理隔离。
3. **三档并存路由** — 中期档看 1~3 年景气、长期档看 10 年永续性、本档看 1~5 年 GARP 假设；三者论文文件互不覆盖。
4. **零新增 CLI** — 不新增参数、不新增工具文件、不修改工具行为；工具缺口只登记不修复。
5. **强制映射** — 漂移等级强制映射五级卖出，不可降级、不可倒置；诚信为前置否决。

## 十一、局限性说明

- 只输出漂移结论与**相对动作**，不判断买卖价位与估值档位（分别归 `garp-exit` / `garp-valuation`）。
- 无 GARP 论文时基线降级，置信度降低须显式标注；**无任何基线则拒绝执行**。
- 地缘（H6）与质化（H7）主观性较强，分别以「只读 `garp-geo-policy`」「只读 `garp-management`」硬约束，本技能不量化打分。
- 四级等级基于「完全漂移项数」等权计数，权重列仅展示优先级。
- **上游结论有误将直接传导**：H6 / H7 与估值档位均为只读，上游若有误，本技能结论随之偏误。

## 十二、三方选型对照

| 维度 | `garp-thesis-drift`（本技能） | 1~3 年中期链漂移技能 | 10 年长期链漂移技能 |
| --- | --- | --- | --- |
| 持有周期 | **1~5 年（GARP 独立档）** | 1~3 年 | 10 年 |
| 大师体系 | **五大师（含费雪质化 H7）** | 四大师（景气为主） | 巴菲特（护城河） |
| 检测对象 | **H1~H7 七维 GARP 假设** | 六维景气假设 | 护城河与商业模式永续性 |
| 核心追问 | 「**GARP 逻辑还在吗**」 | 「1~3 年景气逻辑还在吗」 | 「公司还是不是好公司」 |
| 渗透率刻度 | **`15%~40%` 黄金窗 + TAM ≥1000 亿** | 更窄的景气区刻度 | 不适用 |
| 卖出口径 | **GARP 五级卖出 + 补充机制** | 六级卖出编号体系 | 长期估值区间 |
| 风控编号 | **`GDR-1`~`GDR-12`** | 中期链编号族 | 长期链编号族 |
| 报告命名 | `-garp-drift-{YYYYMMDD}.md` | 中期漂移报告 | 长期漂移报告 |

**选型规则**：检测 **1~5 年 GARP 假设**用本技能；检测 1~3 年景气兑现用中期链；评估 10 年护城河永续性用长期链。

## 十三、数据不足处理指引

| 场景 | 处理 |
| --- | --- |
| 无 GARP 论文 | **明确拒绝执行**，引导先跑 `/garp-thesis-tracker {标的}` |
| 论文缺某 H 维 | 标注「该项无法验证，不纳入漂移计数」 |
| H6 缺失 | 标注「地缘风险未设基线」，不纳入计数 |
| H7 缺失 | 标注「质化维度未设基线」+ 报告声明「费雪维度缺失」，不纳入计数 |
| 上游 `qoq-accelerator` / `trend-momentum-scan` 报告缺失 | 引导先跑；H5 降级为「仅用季报直接计算二阶导」并标注 |
| `garp-valuation` 档位不可得 | 档位列标「未取得」，**不得推定** |
| 未验证维度 ≥3 项 | 报告声明「本次漂移判定置信度不足」 |
