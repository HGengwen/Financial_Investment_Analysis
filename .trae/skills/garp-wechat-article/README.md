# 微信公众号文章（GARP 1~5 年价值成长独立档）(GARP Wechat Article)

作者-编辑-读者三 Agent 协作深度研究，产出可直接发布的公众号文章，以 1~5 年价值成长（GARP）分析为主、技术解读为辅

> **本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。** 核心是「用文章把 1~5 年价值成长逻辑讲清楚」：费雪看质化校验、林奇看生意与估值、郑希看产业景气、李进看组合管理与治理、欧奈尔看风控底线。

## 一、独立档声明与定位

### 1.1 独立档声明（逐字）

**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

### 1.2 能力圈

**适用场景**：

- 科技 / 医药 / 高端制造 / 景气周期成长股等价值成长股的财报解读（价值成长视角）
- 产业链分析与行业景气研究类公众号文章
- 价值成长投资方法论科普（PEG / PSG、渗透率 `15%~40%` 黄金窗、ROE 拐点、五级卖出纪律等）
- 结合 GARP 研究结论（`garp-investment-team` / `garp-earnings-team` / `garp-industry-research` 等）的内容输出

**不适用场景**：

- 纯周期股（用 PE/PB 估值，PEG 不适用，文章视角需特殊处理）
- 困境反转股（PEG 不适用，需特殊框架）
- 金融股（资产负债表结构特殊，需单独评估框架）
- 被动指数投资
- 短期交易 / 日内波段

### 1.3 职能划界（三向唯一性）

| 内容形态 | 归属技能 |
|---------|---------|
| **独立选题的单篇公众号文章**（排版发布 / 平台投放） | **`garp-wechat-article`（本技能）** |
| 某份**财报报告的配套文章** | `garp-earnings-team`（其 `GET-12` 边界），本技能不承接 |
| **系列长文**（3-8 篇拆一家公司） | `garp-deep-company-series`，本技能不承接、不产系列、不产 00-索引 |
| 买入前检查 | `garp-investment-checklist`，文章只给前置条件、不回答「现在是否买入」 |

> **划界刚性**：本技能**只产单篇**；素材可来自上游技能，但**职能不重叠**。用户要求系列长文时转 `garp-deep-company-series`；要求财报配套文章时转 `garp-earnings-team`。

## 三、核心功能

对指定主题进行深度研究，产出可直接发布的公众号文章。三个 Agent 各司其职：

- **作者 Agent** — 深度研究后撰写初稿（价值成长类采用五大师分析框架）
- **编辑 Agent** — 精修结构、标题、节奏与表达
- **读者 Agent** — 从目标受众视角审读，找出「看不懂 / 不想看 / 不转发」的地方

### 3.1 四阶段流程

**阶段一·研究与素材收集**：明确文章定位（文章类型 / 目标读者 / 深度 / 长度 / 风格）→ **并行启动 2-3 个研究 Agent** 收集素材 → 信息丰富度评级（A/B/C）→ **取回 `garp-*` 出口技能结论** → 整理素材框架

**阶段二·作者写初稿**：作者 Agent 按通用模板撰写；价值成长类追加**五大师分析框架**（固定序）与**五级卖出映射表**，按 **7 段结构**成文

**阶段三·编辑 + 读者并行审阅**：编辑精修表达，读者模拟真实阅读体验，价值成长类文章另有额外审阅标准；**两者矛盾时偏向读者**

**阶段四·定稿**：综合反馈 → 执行修改 → 提取配图 → **数据抽检准出（`report_audit.py`）** → 产出最终文件

### 3.2 设计理念

一篇好的公众号文章需要同时满足三个维度：

1. **深度**——对得起花时间读完的人（作者负责）
2. **可读性**——结构清晰、节奏好、不劝退（编辑负责）
3. **真的能看懂**——目标读者不会在中途放弃（读者负责）

单人写作容易「自嗨」。三 Agent 协作的本质是**强制引入外部视角**。

**研究 Agent 路数刚性**：**保持 2-3 路，不扩张为 5 路**。五位大师是**分析维度标尺**（作者阶段使用），不是研究 Agent 的分工依据。

### 3.3 GARP 口径素材位（本档新增刚性）

研究 Agent 须**从 `garp-*` 出口技能取回**以下结论，**不得自行推算**：

| 素材位 | 来源 | 缺失时的处置 |
| --- | --- | --- |
| 估值统一六档 + ESG 折价 + 宏观 PEG 区间 | `garp-valuation` | 文章**不给档位结论**，改为「待 `garp-valuation` 出具」 |
| 五级卖出纪律 | `garp-exit` | 文章**不给卖出结论**，改为「待 `garp-exit` 出具」 |
| 诚信前置 + 管理层 7+7+6 + 科研 8+8+4 | `garp-management` | 只作定性描述，**不评分** |
| 0.3 三维交叉矩阵 + 赛道两分法 + 国产化率四梯队 | `garp-geo-policy` | 只作定性描述，**不分层** |
| 宏观三表（利率 / 经济 / 美林） | `garp-macro` | 宏观段**留空并说明**，不以其他口径替代 |
| 渗透率 `15%~40%` 五档 + TAM ≥ 1000 亿元 | `garp-industry-research` | 标注「估计」，给区间不给点估计 |

## 四、五大师视角分工

价值成长类文章的视角采用**五位大师**框架（**对齐 `upgrade1.0/中长期价值成长（GARP）投资框架.md` 第一部分**，**固定顺序：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔**）：

| 大师 | 思维模式 | 在框架中的角色 | 在文章写作中的落点 |
|------|---------|---------------|-------------------|
| **费雪** | 质化分析 · 闲聊法 | **质化校验**：研发转化效率、销售组织有效性、管理层诚信与坦诚、长期利润率潜力 | **质化校验章节（第 3 段）**：需求真实性、研发与销售组织、管理层坦诚度 |
| **林奇** | 侦探思维 · 常识与求证 | **选股起点 + 估值定价**：生活常识选股、六类分类、PEG | 生意本质章节：六类分类、常识验证；估值判断章节：统一六档 |
| **郑希** | 物理学家思维 · 周期与第一性原理 | **赛道选择**：ROE 拐点、产业景气、渗透率、地缘政治 | 景气验证章节：ROE 趋势、二阶导、地缘矩阵 |
| **李进** | 系统工程师思维 · 均衡与渗透率 | **组合管理 + 治理**：渗透率定位、底仓/机动仓、管理层与科研转化、诚信前置一票否决 | 景气验证 + 风险与纪律章节：渗透率定位、管理层评分、治理红线 |
| **欧奈尔** | 工程师思维 · 信号与纪律 | **风控底线**：硬止损 8%~10%、卖出触发、防止深度套牢 | 风险与纪律章节：五级卖出逐级核对、趋势信号 |

> 「真正能带来超额收益的，是那些在研发与销售组织上持续做对的少数公司。」 —— 费雪（质化分析）
>
> 「机会来自生活常识，而不仅仅是数据表格。」 —— 林奇（选股起点）
>
> 「ROE 向上是科技股最可靠的『重力加速度』——只要这个趋势在，估值波动只是噪音。」 —— 郑希（赛道选择）
>
> 「用渗透率定位阶段，用二阶导监测拐点，用纪律保护本金。」 —— 李进（系统均衡）
>
> 「先想清楚亏多少，再想赚多少。8% 是普通投资者的生存红线。」 —— 欧奈尔（风控底线）

### 4.1 价值成长类文章的七段结构

| # | 段落 | 承担大师 |
|---|------|---------|
| 1 | 开头钩子（估值 / 景气数据冲击开场） | 全员 |
| 2 | 生意本质（一句话说清靠什么赚钱 + 六类分类） | 林奇 |
| 3 | **质化校验：财报上找不到的东西**（需求真实性 / 研发与销售组织 / 管理层坦诚度） | **费雪（本档新增段）** |
| 4 | 景气验证（ROE 趋势 / 渗透率 `15%~40%` 五档 / 国产化率四梯队 / 二阶导 / 地缘 0.3 三维交叉矩阵） | 郑希 + 李进 |
| 5 | 估值判断（统一六档 + ESG 折价 + 宏观 PEG 区间校准） | 林奇 |
| 6 | 风险与纪律（诚信前置一票否决 / 管理层 7+7+6 / 科研转化 8+8+4 / 五级卖出逐级核对） | 李进 + 欧奈尔 + 费雪 |
| 7 | 结论：研究判断与观察清单（只给条件式表述） | 全员收口 |

### 4.2 五级卖出映射表（只读 `garp-exit`，阈值不重复定义）

| 级别 | 触发条件 | 文章中的处置 |
| --- | --- | --- |
| 一级 · 诚信否决 | 管理层失信、财务造假实锤、监管立案 | 立即清仓，不看估值趋势 |
| 二级 · 硬止损 | 单笔亏损 8%~10%，且无明确基本面反转信号 | 无条件止损 |
| 三级 · 逻辑止损 | 连续 2 季业绩低于预期且产业景气未改善；财务不可逆恶化；龙头地位被颠覆；管理层 / 科研转化评分跌破 10 分（**非诚信事项**） | 减仓或清仓 |
| 四级 · 产业景气判断 | 渗透率减速 / ROE 拐头向下但景气尚可、仅节奏放缓 | 按景气方向调仓 |
| 五级 · 估值判断 | 调整后 PEG > 1.5 高估 → 减机动仓；PEG > 2 严重透支 → 加速清机动仓 | 底仓不动，机动仓调整 |
| **补充机制（不占优先级）** | 时间止损（持有满 4 个季度逻辑未兑现）；性价比替换（每季度最多 1 次） | 与五级**并列**列示，**不得写成第六级** |

> 核心原则：**一级 > 二级 > 三级 > 四级 > 五级**，命中即停，禁止跳过一级。触发条件与阈值一律以 `garp-exit` 输出为准。

## 六、输出报告与三档隔离

报告将保存在以下位置：

| 报告类型 | 文件路径 |
|---------|---------|
| 价值成长主题 | `reports/{公司名}/{公司名}-garp-wechat-{YYYYMMDD}.md` |
| 技术主题 | `reports/AI产业研究/公众号-{主题关键词}-garp-wechat-{YYYYMMDD}.md` |
| 通用主题 | `reports/公众号-{主题关键词}-garp-wechat-{YYYYMMDD}.md` |
| 底稿（可选，自用） | 同上目录 `{公司名}-garp-wechat-{YYYYMMDD}-底稿.md` |
| 配图资源 | `assets/{主题简称}/fig{序号}-{描述}.png` |

### 6.1 输出文件结构

```
reports/
├── {公司名}/
│   ├── {公司名}-garp-wechat-{YYYYMMDD}.md        ← 价值成长类公众号文章（定稿）
│   └── {公司名}-garp-wechat-{YYYYMMDD}-底稿.md   ← 作者初稿/编辑读者反馈（可选，自用）
├── AI产业研究/
│   └── 公众号-{主题}-garp-wechat-{YYYYMMDD}.md   ← 技术解读类
└── assets/{主题简称}/fig{序号}-{描述}.png        ← 配图资源
```

### 6.2 三档物理隔离

| 档位 | 持有周期 | 大师体系 | 估值口径 | 卖出口径 | 文件名后缀段 |
|------|---------|---------|---------|---------|-------------|
| **长期链** `wechat-article` | 10 年 / 永续 | 巴芒段李 | 长期终值口径 | 不设止损 | 长期链专属后缀（本档禁用） |
| **1~3 年中期链** | 1~3 年 / 景气周期 | 四位 | 单一温度计五档 | 六级编号体系 | 中期链专属后缀（本档禁用） |
| **本技能（GARP 独立档）** | **1~5 年价值成长** | **费雪 / 林奇 / 郑希 / 李进 / 欧奈尔（五位）** | **统一六档 + ESG 折价 + 宏观 PEG 区间** | **五级卖出（+ 补充机制并列）** | **`-garp-wechat-{YYYYMMDD}`** |

> **命名规范**：本技能所有输出文件**只使用 `-garp-wechat-` 后缀**，与另外两档**物理隔离**，避免文件碰撞。
>
> **隔离核验口径（易错点）**：本 GARP 档内，系列长文使用 `-garp-{YYYYMMDD}` 后缀。由于 **`-garp-` 是 `-garp-wechat-` 的前缀子串**，若用 `-garp-` 单串计数会**把本技能产物误计入系列长文**（假阳性）。因此隔离核验**必须使用完整后缀段**（`-garp-{YYYYMMDD}` 与 `-garp-wechat-{YYYYMMDD}` 互不为子串）；技能名核验同理须用**完整技能名**，禁止用 `wechat-article` 这类子串计数。

### 6.3 文章头部必注明的四基准

| 基准 | 内容 |
|------|------|
| **数据基准** | 文章生成日期 + 数据截止日期（`date` 实测，禁训练假设） |
| **估值基准** | `garp-valuation` 六档结论 + 输出日期 |
| **纪律基准** | `garp-exit` 五级 + 管理层结论（`garp-management`）的日期 |
| **口径基准** | 独立档声明 +「三 Agent / 四阶段 / 信息丰富度 A/B/C」属骨架继承与本技能操作化、非框架原文 |

## 七、质量标准

### 7.1 价值成长类文章的五大检视维度

1. **五大师视角均衡** — 费雪（质化校验）、林奇（六类分类 + 统一六档）、郑希（ROE 趋势 + 渗透率 + 地缘矩阵）、李进（诚信前置 + 管理层 7+7+6 + 科研 8+8+4）、欧奈尔（硬止损 + 五级卖出）是否都有体现？
2. **费雪段独立性** — 第 3 段「质化校验」是否独立成段、且与第 4 段不重复（只讲财报上找不到的东西）？
3. **口径正确** — 估值档位是否与 `garp-valuation` 统一六档一致？ESG 折价与宏观 PEG 区间是否已引用？有无自行罗列阈值？
4. **卖出纪律准确** — 是否与 `garp-exit` 五级一致？**补充机制是否被误写成第六级**？硬止损位置是否明确？
5. **结论行动化且不越界** — 结论段是否只给**条件式研究判断**？有无目标价 / 目标仓位 / 具体买入价 / 具体止损价 / 减仓比例等**指令性数值**？有无回答「现在是否买入」？

### 7.2 数据抽检准出（发布前必做）

文章落盘后**必须**执行数据抽检，通过后方可视为定稿：

```bash
# Step 1 - 提取抽检清单（15%随机抽样）
python tools/common/report_audit.py extract \
  --report reports/{公司名}/{公司名}-garp-wechat-{YYYYMMDD}.md --seed 42

# Step 2 - 对清单每项从可靠信源取数（按市场分别使用对应工具，计算验算用 financial_rigor.py）

# Step 3 - 输出准出/打回判决
python tools/common/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report {公司名}-garp-wechat-{YYYYMMDD}.md
```

**【准出】** 所有抽检点偏差 ≤ 1% → 文章可发布；**【打回】** 任意点偏差 > 1% → 修正后重新抽检，**打回项不可申诉**。

> **实参语义说明（易错点）**：`extract` 的 `--report` 传**文件路径**（可含目录）；`verdict` 的 `--report` 传**报告显示名**（仅文件名）。两者语义不同，请勿混用。

### 7.3 信息丰富度评级（价值成长类必做）

| 等级 | 特征 | 影响 |
| ---- | ---- | ---- |
| A级 | 获取到完整原文（财报 / 研报 / 一手数据） | 正常执行全部步骤 |
| B级 | 仅获取到部分原文或第三方汇总 | 标注「非原始来源」，推算数据标注置信度 |
| C级 | 仅有新闻报道和数据网站摘要 | 转第一性原理模式：聚焦核心数据变化，明确标注「一手资料不足」，**不展开细节推断、不给六档与五级结论** |

## 九、核心原则（风控硬编码 `GWA-1` ~ `GWA-12`）

> 本技能新建 **`GWA-`（GARP WeChat Article）编号族**共 12 条，为本档唯一编号族，**不得与其他档位编号混用**。完整条款见 [SKILL.md](./SKILL.md)。

| 编号 | 原则 | 一句话要点 |
| --- | --- | --- |
| `GWA-1` | 三 Agent 协作不可退化 | 作者 / 编辑 / 读者三角色 + 四阶段；**矛盾时偏向读者** |
| `GWA-2` | 五大师口径贯穿 | 固定序 费雪 / 林奇 / 郑希 / 李进 / 欧奈尔；费雪落位第 3 段；禁「四位大师」表述 |
| `GWA-3` | 口径只读 | 估值 / 卖出 / 管理层 / 地缘 / 宏观零定义、零重算；上游未出具则不给该维度结论 |
| `GWA-4` | 渗透率黄金窗 | 统一 `15%~40%` 五档 + TAM ≥ 1000 亿元门槛；禁沿用其他档位旧区间口径 |
| `GWA-5` | 五级卖出 | 诚信否决 > 硬止损 8%~10% > 逻辑止损 > 产业景气判断 > 估值判断；补充机制并列不占优先级 |
| `GWA-6` | 结论边界 | 无指令性数值；不回答「现在是否买入」；买入前提转出 `garp-investment-checklist` |
| `GWA-7` | 事实核查 | 伪精确陷阱 6 条自检（概率加权期望**全删**） |
| `GWA-8` | 数据抽检准出 | `report_audit.py extract → verdict`（seed=42），≤1% 准出 / >1% 打回、不可申诉 |
| `GWA-9` | 数据来源与置信度 | 不虚构数据；关键财务双源交叉验证；每条非财报数据后跟「（来源：X）」 |
| `GWA-10` | 术语红线双向 | 不用长期链术语，也不原样承袭 1~3 年景气档表述 |
| `GWA-11` | 三档文件隔离与命名 | 只用 `-garp-wechat-{YYYYMMDD}`；核验用**完整后缀段 / 完整技能名** |
| `GWA-12` | 配图与公式纪律 | 公式 LaTeX 且配「翻译成人话就是……」；配图**实际插入**，禁占位符 |

**通用写作要求（不与编号冲突）**：

1. **不虚构数据** — 引用的数据必须有来源，搜不到就标注「估计」
2. **不用 AI 腔调** — 禁止「让我们一起来看看」「不得不说」等套话
3. **公式必须配大白话** — 每个公式后面都要有「翻译成人话就是……」
4. **配图必须实际插入** — 禁止用占位符
5. **结尾必须有传播力** — 最后一句话要值得被单独截图转发
6. **类比要一以贯之** — 全文用一个主线类比
7. **客观性原则** — 区分事实与观点，用数据支撑判断

## 十、注意事项

- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- 信息丰富度评级（A/B/C 级）需告知每个研究 Agent，影响其分析深度
- **共识偏见**：搜索结果高度一致看多 / 看空时（A级信息），主动做反面检验
- **光环效应**：不能因公司名气 / 股价上涨而放松对管理层诚信、财务质量的核查
- **信息缺口诚实**：渗透率、国产化率等数据缺乏官方统计时，标注为「估计」并给出区间，不虚构精确值
- 关键财务数据至少两个独立来源交叉验证，误差 > 1% 须标记
- 报告发布前必须通过 `tools/common/report_audit.py` 数据抽检
- 编辑和读者都指出的问题必须改；两者矛盾时偏向读者
- **价值成长类文章**：PEG 必须附计算依据和来源；卖出纪律必须与 `garp-exit` 五级一致；林奇六类分类不能跳过；第 3 段「质化校验」须独立成段
- **跨档红线**：不得混入长期链术语，也不得原样承袭 1~3 年景气档表述（旧口径词条见 [SKILL.md](./SKILL.md) 术语红线表）
- **结论不越界**：只给条件式研究判断与前置条件，不给目标价 / 目标仓位 / 具体买卖价
- 网络搜索须使用 `--time-range month/week` 限制时间范围，优先获取最新信息

## 十一、局限性说明

- **网络信息获取限制**：网络搜索须使用本地五工具组合
- **图片生成质量**：AI 生成的图片可能不符合预期
- **论文 PDF 可得性**：部分论文可能需要付费或无法下载
- **技术术语准确性**：非常专业的领域可能需要领域专家审核
- **时效性限制**：网络搜索结果可能有延迟
- **读者视角模拟局限**：Agent 模拟的读者视角可能无法完全代表真实读者体验
- **景气数据可得性**：部分行业渗透率等数据缺乏官方统计，需按 A/B/C 三级置信度标注
- **数据工具延迟**：本地数据工具获取的数据可能有延迟，非实时数据
- **上游口径依赖**：估值六档 / 五级卖出 / 管理层评分 / 地缘矩阵 / 宏观参数**依赖 `garp-*` 出口技能**；上游未出具时，文章**只作定性描述、不给定量结论**
- 不构成投资建议，仅供学习研究参考
