# 微信公众号文章（GARP 1~5 年价值成长独立档）：作者-编辑-读者三 Agent 协作

对 $ARGUMENTS 进行深度研究，产出一篇可直接发布的微信公众号文章。三个 Agent 各司其职：作者写深度初稿，编辑精修结构和表达，读者从目标受众视角审读。

**支持输入格式**：主题描述，例如：

- **价值成长类（默认）**：`腾讯2025Q4财报解读（价值成长视角）`、`AI算力产业链瓶颈分析`、`为什么 PEG<1 是观察信号`、`光模块行业 1~5 年景气怎么看`
- **技术解读类**：`大模型OPD技术解读`、`Qwen3技术报告解读`

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

---

## 能力圈声明

本技能文件适用于 **GARP（1~5 年价值成长）投资框架下的公众号文章写作**，非短期交易工具，非「封仓十年」式超长期持有，也非日内/周级别波段交易。

**适用场景**：

- 科技 / 医药 / 高端制造 / 景气周期成长股等价值成长股的财报解读（价值成长视角）
- 产业链分析与行业景气研究类公众号文章
- 价值成长投资方法论科普（PEG / PSG、渗透率、ROE 拐点、五级卖出纪律等）
- 结合 GARP 研究结论（`garp-investment-team` / `garp-earnings-team` / `garp-industry-research` 等）的内容输出

**不适用场景**：

- 纯周期股（用 PE/PB 估值，PEG 不适用，文章视角需特殊处理）
- 困境反转股（PEG 不适用，需特殊框架）
- 金融股（资产负债表结构特殊，需单独评估框架）
- 被动指数投资
- 短期交易 / 日内波段

## 设计理念

一篇好的公众号文章需要同时满足三个维度：

1. **深度**——对得起花时间读完的人（作者负责）
2. **可读性**——结构清晰、节奏好、不劝退（编辑负责）
3. **真的能看懂**——目标读者不会在中途放弃（读者负责）

单人写作容易「自嗨」——写的人觉得清楚，读的人看不懂。三 Agent 协作的本质是**强制引入外部视角**。

**价值成长类文章的特别说明**：

本技能支持两类文章：

1. **价值成长类（默认）**：财报解读 / 产业链分析 / 投资方法论——侧重 **GARP 1~5 年价值成长框架**（费雪质化校验、林奇 PEG、郑希 ROE 趋势、李进渗透率与治理、欧奈尔止损纪律）
2. **技术解读类**：论文 / 技术报告 / 新产品解读——侧重技术深度和通俗表达

写价值成长类文章时，作者 Agent 需采用**五位大师**的分析框架（**对齐 `upgrade1.0/中长期价值成长（GARP）投资框架.md` 第一部分「五位大师」**）：

| 大师 | 思维模式 | 在框架中的角色 | 在文章写作中的落点 |
| --- | --- | --- | --- |
| **费雪** | 质化分析 · 闲聊法 | **质化校验**：研发转化效率、销售组织有效性、管理层诚信与坦诚、长期利润率潜力 | **质化校验章节（第 3 段）**：需求真实性、研发与销售组织、管理层坦诚度 |
| **林奇** | 侦探思维 · 常识与求证 | **选股起点 + 估值定价**：生活常识选股、六类分类、PEG | 生意本质章节：六类分类、常识验证；估值判断章节：统一六档 |
| **郑希** | 物理学家思维 · 周期与第一性原理 | **赛道选择**：ROE 拐点、产业景气、渗透率、地缘政治 | 景气验证章节：ROE 趋势、二阶导、地缘矩阵 |
| **李进** | 系统工程师思维 · 均衡与渗透率 | **组合管理 + 治理**：渗透率定位、底仓/机动仓、管理层与科研转化、诚信前置一票否决 | 景气验证 + 风险与纪律章节：渗透率定位、管理层评分、治理红线 |
| **欧奈尔** | 工程师思维 · 信号与纪律 | **风控底线**：硬止损 8%~10%、卖出触发、防止深度套牢 | 风险与纪律章节：五级卖出逐级核对、趋势信号 |

> 「真正能带来超额收益的，是那些在研发与销售组织上持续做对的少数公司。」 —— 费雪（质化分析）
>
> 「机会来自生活常识，而不仅仅是数据表格。」 —— 林奇（选股起点）
>
> 「ROE 向上是科技股最可靠的『重力加速度』——只要这个趋势在，估值波动只是噪音。」 —— 郑希（赛道选择）
>
> 「用渗透率定位阶段，用二阶导监测拐点，用纪律保护本金。」 —— 李进（系统均衡）
>
> 「先想清楚亏多少，再想赚多少。8% 是普通投资者的生存红线。」 —— 欧奈尔（风控底线）

## 零、边界声明（五类口径只读，本技能的核心约束）

> **本技能不实现任何估值、卖出、管理层、地缘、宏观的判定逻辑，只做引用与转述。**

| 口径类别 | 权威实现方 | 本技能的动作 | 本技能禁止的动作 |
| --- | --- | --- | --- |
| 估值档位 / ESG 折价 / 宏观 PEG 区间 | `garp-valuation` | 引用统一六档结论（显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支） | 自行定义档位阈值、自行估算 ESG 折价率、用工具内置 `tier` / `rating` 判档 |
| 卖出纪律 | `garp-exit` | 引用五级（诚信否决 > 硬止损 8%~10% > 逻辑止损 > 产业景气判断 > 估值判断） | 自造层级、把时间止损 / 性价比替换提升为优先级位 |
| 管理层 / 科研转化 | `garp-management` | 引用诚信前置（一票否决，不计分）+ 管理层 20 分制（7+7+6）+ 科研转化 20 分制（8+8+4） | 重新计分、按行业自定义阈值、把诚信折算为分值 |
| 地缘 / 国产化率 | `garp-geo-policy` | 引用 0.3 三维交叉矩阵、赛道两分法判定、国产化率四梯队 | 自建评分、自行分层、在回避档下仍给正面结论 |
| 宏观参数 | `garp-macro` | 引用三表（利率 / 经济 / 美林）**修正参数** | 输出买卖方向指令、把宏观信号升级为卖出触发条件 |

**另**：本技能**禁止调用** `tools/common/terminal_value.py`（十年尺度终值口径属长期链，跨档即打回）。

## 阶段一：研究与素材收集

### 第一步：明确文章定位

在开始写作之前，先确认以下信息（如用户未指定则主动询问）：

| 维度 | 需要确认 | 默认值 |
| --- | --- | --- |
| **文章类型** | 价值成长 / 技术解读 / 其他 | **价值成长** |
| **目标读者** | 技术背景程度 | 有点技术背景但非该领域专家 |
| **文章深度** | 科普 / 中深度 / 硬核 | 中深度 |
| **文章长度** | 字数范围 | 3000-4000 字 |
| **是否需要下载原始论文 / 资料** | 需要 PDF / 配图 | 是 |
| **写作风格** | 正式 / 对话式 / 犀利 | 对话式（像写给聪明的朋友） |

**价值成长类文章额外确认**：

- 分析标的（公司名 / 行业名）
- 分析的维度：质化校验 / ROE 趋势 / 渗透率 / 估值 / 管理层 / 地缘 / 宏观（可多选）
- 是否涉及卖出纪律讨论（涉及时引用 `garp-exit` 五级）
- **上游口径是否齐备**：`garp-valuation`（六档）、`garp-exit`（五级）、`garp-management`、`garp-geo-policy`、`garp-macro` 是否已对该标的出具结论；**未出具的部分不得自行推算**

### 第二步：深度研究

使用 Task 工具**并行**启动 2-3 个研究 Agent，收集足够的素材：

**研究 Agent A：核心内容研究**

- **技术类**：下载论文 PDF、提取核心贡献、关键图表、实验结果
- **价值成长类**：搜索公司最新财报、财务数据、估值指标、分析师观点

**研究 Agent B：行业背景与应用**

- **技术类**：搜索该技术的行业落地情况、发展趋势、里程碑事件
- **价值成长类**：搜索行业景气数据、竞争格局、渗透率数据（`15%~40%` 五档定位）、国产化率（四梯队）、地缘政治风险

**研究 Agent C（可选）：对比 / 验证研究**

- **技术类**：同类方法 / 产品的对比、历史发展脉络
- **价值成长类**：同行业可比公司对比、历史估值区间、卖出信号验证（五级）

> **研究 Agent 路数刚性**：**保持 2-3 路，不扩张为 5 路**。五位大师是**分析维度标尺**（作者阶段使用），不是研究 Agent 的分工依据。

**GARP 口径素材位（本档新增刚性）**：研究 Agent 须**从 `garp-*` 出口技能取回**以下结论，**不得自行推算**：

| 素材位 | 来源 | 缺失时的处置 |
| --- | --- | --- |
| 估值统一六档 + ESG 折价 + 宏观 PEG 区间 | `garp-valuation` | 文章**不给档位结论**，改为「待 `garp-valuation` 出具」 |
| 五级卖出纪律 | `garp-exit` | 文章**不给卖出结论**，改为「待 `garp-exit` 出具」 |
| 诚信前置 + 管理层 7+7+6 + 科研 8+8+4 | `garp-management` | 只作定性描述，**不评分** |
| 0.3 三维交叉矩阵 + 赛道两分法 + 国产化率四梯队 | `garp-geo-policy` | 只作定性描述，**不分层** |
| 宏观三表（利率 / 经济 / 美林） | `garp-macro` | 宏观段**留空并说明**，不以其他口径替代 |
| 渗透率 `15%~40%` 五档 + TAM ≥ 1000 亿元 | `garp-industry-research` | 标注「估计」，给区间不给点估计 |

#### 信息丰富度评级（价值成长类必做）

研究 Agent 收集素材时，先做**资料可得性评级**，并告知每个 Agent，影响其分析深度：

| 等级 | 特征 | 影响 |
| --- | --- | --- |
| A级 | 获取到完整原文（财报 / 研报 / 一手数据） | 正常执行全部步骤 |
| B级 | 仅获取到部分原文或第三方汇总 | 标注「非原始来源」，推算数据标注置信度 |
| C级 | 仅有新闻报道和数据网站摘要 | 转第一性原理模式：聚焦核心数据变化，明确标注「一手资料不足」，**不展开细节推断、不给六档与五级结论** |

#### AI 研究偏见预警（贯穿全程）

- **共识偏见**：当搜索结果高度一致看多 / 看空时（A 级信息），主动做**反面检验**——搜「风险」「质疑」「不及预期」关键词，检验共识是否已被定价。
- **光环效应**：不能因公司名气 / 股价上涨而放松对管理层诚信、财务质量的核查。
- **信息缺口诚实**：渗透率、国产化率等数据缺乏官方统计时，标注为「估计」并给出区间，不虚构精确值。

#### 网络信息获取工具

研究 Agent 收集素材时，统一使用本地五工具组合（详见 [web-search-tools](../tools-scripts/web-search-tools.md)）。工具选型按主题涉及的市场参照矩阵：

- **A股主题**：`anysearch --tag finance` 主 + `doubao --finance` 辅
- **港股/美股/国际主题**：港股 `doubao --sites hkexnews.hk` + `tavily`（双源）；美股 `exa --type deep` + `doubao`（双源）
- **技术 / 论文主题**：英文文献优先 `exa --type deep`，中文资讯用 `doubao`，多源互补
- 使用 `--time-range month/week` 限制时间范围，优先获取最新信息
- **禁止使用** Anthropic 官方 `WebSearch` / `WebFetch`（中国大陆不可用）

#### PDF 文档内容提取（技术类文章）

论文解读类文章必须从 PDF 提取高清原图（≥500KB）。文字与表格提取**首选** `tools/common/pdf_extract.py`（基于 pdf-inspector 库，支持自动乱码检测 + OCR 回退），返回失败时才回退 Poppler；**高清图像渲染提取配图仍需使用 Poppler `pdftoppm`**（`pdf_extract.py` 不提供图像渲染能力）。完整流程见 [PDF 文档内容提取技能](../tools-scripts/pdf-extraction.md)。

```bash
# 文字与表格提取（首选）
python tools/common/pdf_extract.py markdown 论文.pdf --save-md --out-dir reports/pdf

# 高清图像渲染（用于配图，使用 Poppler pdftoppm）
pdftoppm -png -r 900 -f {页码} 论文.pdf output/page
```

### 第三步：整理素材框架

研究 Agent 全部完成后，整理出：

1. **核心论点**（一句话概括文章要传达的核心信息）
   - 技术类：论文 / 技术的核心突破是什么？
   - **价值成长类**：1~5 年价值成长逻辑是否成立？关键观察信号是什么？（涉及卖出纪律时，标注引用 `garp-exit` 的层级）
2. **关键数据**（3-5 个最有冲击力的数据点，每条附来源与数据截止日）
3. **配图清单**（需要哪些图，来源是什么）
4. **文章大纲**（7 个章节的标题和核心内容，对齐下文的七段结构）

```markdown
## 价值成长类文章的特别要求

你正在写一篇 **GARP（1~5 年价值成长）** 框架下的分析文章。本框架为 **1~5 年价值成长视角**。

### 分析框架
采用五位大师的视角（固定顺序：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔）：

1. **费雪（质化校验，本档新增）**：
   - **需求真实性**：增长有没有客观数据支撑？（订单、收入、用户付费）——**没有支撑即判题材炒作**，文章不得给正面结论

2. **林奇（选股起点 + 估值定价）**：

   - 六类分类变化是重要信号：快速增长型变稳定增长型 → 可能触发估值重新定价

   - **估值档位一律引用 `garp-valuation` 统一六档**（显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支），**不自行罗列阈值**；工具内置 `tier`/`rating` 不进档位判定
   - **ESG 折价**与**宏观 PEG 区间**同为 `garp-valuation` 输出，一并引用

3. **郑希（赛道选择）**：
   - ROE 趋势向上还是向下？拐点到了吗？（**连续 3 季同向才判拐点**，单季波动判噪音）
   - 产业景气在什么位置？**渗透率定位引用 `garp-industry-research` 口径**（<5% 导入早期 / 5%~15% 突破期 / **15%~40% 加速上行期（黄金窗）** / 40%~60% 逐步兑现 / >60% 天花板；**TAM ≥ 1000 亿元**为深度研究前置门槛）
   - 增速二阶导（增速加速度）是正是负？

4. **李进（组合管理 + 治理）**：
   - **诚信前置检验**：管理层诚信吗？（**一票否决，不计分**）——挑一次真实危机看应对，命中即出局

   - 国产化率定位：四梯队中的哪一档？（引用 `garp-geo-policy`，**不自行分层**）

5. **欧奈尔（风控底线）**：
   - 硬止损位在哪里？8%~10% 是生存红线（取值规则以 `garp-exit` 二级为准）
   - 趋势信号确认了吗？
   - **五级卖出逐级核对**（**映射表见下，细则引用 `garp-exit` 输出，不重复展开**）

6. **宏观（只调参不择时）**：
   - 宏观三表（利率 / 经济 / 美林）当前状态如何？
   - 引用 `garp-macro` 的**参数修正**结论，**只作参数调整、不作择时信号**

### 五级卖出映射表（引用 `garp-exit`，不重复定义阈值）

| 级别 | 触发条件 | 文章中的处置 | 思想来源 |
| --- | --- | --- | --- |
| 一级·诚信否决 | 管理层失信、财务造假实锤、监管立案 | 立即清仓，不看估值趋势；文章须明写该判定 | 李进（治理） |
| 二级·硬止损 | 单笔亏损 8%~10%，且无明确基本面反转信号 | 无条件止损；建仓初期一律适用 8%~10% | 欧奈尔 |
| 三级·逻辑止损 | 连续 2 季业绩低于预期且产业景气未改善；财务不可逆恶化；龙头地位被颠覆；管理层/科研转化评分跌破 10 分（**非诚信事项**） | 减仓或清仓 | 林奇 + 郑希 |
| 四级·产业景气判断 | 渗透率减速 / ROE 拐头向下但景气尚可、仅节奏放缓 → 减机动仓；**增速归零或转负 → 升级为逻辑恶化、清仓** | 按景气方向调仓 | 李进 + 郑希 |
| 五级·估值判断 | 调整后 PEG > 1.5 高估 → 减机动仓；PEG > 2 严重透支 → 加速清机动仓；市场情绪极度狂热多信号共振 → 减机动仓 | 底仓不动，机动仓调整 | 林奇 |
| **补充机制（不占优先级）** | 时间止损（持有满 4 个季度逻辑未兑现）；性价比替换（每季度最多 1 次） | 与五级**并列**列示，**不得写成第六级** | 机会成本 |

### 文章结构（价值成长类，七段）

1. **开头钩子**：用估值/景气数据冲击开场（如"ROE 连续 8 季度攀升后首次持平，是黄灯还是红灯？"）
2. **生意本质**：一句话说清楚这家公司靠什么赚钱（林奇测试：10 分钟能解释清吗？）+ **六类分类**（林奇）
3. **质化校验：财报上找不到的东西**（**费雪，本档新增段**）：需求真实性（有无订单/收入支撑，**无支撑即判题材**）+ 研发转化效率 + 销售组织有效性 + 管理层坦诚度。与第 4 段交叉印证但**不重复**第 4 段内容
4. **景气验证**：ROE 趋势（连续 3 季同向才判拐点）、**渗透率 `15%~40%` 五档定位**、**国产化率四梯队**、二阶导、**地缘 0.3 三维交叉矩阵与赛道两分法**（郑希/李进视角）
5. **估值判断**：**统一六档**（引用 `garp-valuation`）+ **ESG 折价叠加** + **宏观 PEG 区间校准**（引用 `garp-macro`，只调参不择时）（林奇视角）
6. **风险与纪律**：诚信前置一票否决 + 管理层 20 分制（7+7+6）+ 科研转化 20 分制（8+8+4）（引用 `garp-management`）+ **费雪：暂时性困难 vs 永久性衰退 + 「绝不卖」适用边界** + **五级卖出逐级核对**（引用 `garp-exit`）+ 补充机制并列（李进/欧奈尔/费雪视角）
7. **结论：研究判断与观察清单**（全员收口）：
   - 保留"对持有者、观望者分别指引"的**结构**，但**降格为研究判断**：只给**条件式表述**（如"若 X 条件成立则价值成长逻辑未变，若 Y 触发则按五级卖出对应级别处理"）
   - 对观望者**只给前置条件**：「买入前须过 `/garp-investment-checklist`」
   - **禁止**出现目标价、目标仓位、具体买入价、具体止损价、减仓比例等**指令性数值**
   - **禁止**回答「现在是否买入」
```

## 阶段四：定稿

### 第一步：综合两个 Agent 的反馈

重点关注以下高频问题：

| 问题类型 | 编辑常见反馈 | 读者常见反馈 | 处理方式 |
| --- | --- | --- | --- |
| 开头太弱 | 钩子不够强 | 前 3 段没动力继续 | 用数据 / 反直觉结论重写开头 |
| 技术 / 估值段劝退 | 公式 / PEG 计算太密集 | 某段需要重读 3 遍 | 删公式或加更直觉的类比 |
| 节奏拖沓 | 某节太长 | 某处失去耐心 | 合并或删减 |
| 结尾无力 | 缺传播力 | 不会转发 | 重写为一句可截图传播的判断 |
| **价值成长类特有** | 卖出纪律不够具体 | 「不知道该卖还是该买」 | 明确五级层级与硬止损位置；**仅作研究判断，不给指令性数值** |
| **价值成长类特有** | 估值档位口径模糊 | 「不知道贵还是便宜」 | 对齐 `garp-valuation` 统一六档结论 |
| **价值成长类特有** | 第 3 段与第 4 段重复 | 「这两段说的是同一件事」 | 第 3 段只留「财报上找不到的东西」，数据化的内容移到第 4 段 |

### 第二步：执行修改

根据反馈重写文章。核心修改原则：

1. **编辑和读者都指出的问题，必须改**
2. **只有编辑指出的问题，大概率要改**
3. **只有读者指出的问题，视情况改**
4. **两者矛盾时，偏向读者**

### 第三步：提取配图

#### 论文解读类文章

必须在定稿前完成配图提取：

1. **渲染**：`pdftoppm -png -r 900 -f {页码} 论文.pdf /tmp/page`（900 DPI 起步）
2. **定位**：先用 150 DPI 渲染全页，目视确认各图表的像素坐标
3. **裁切**：用 PIL 按坐标裁切，确保每张 ≥ 500KB
4. **存储**：保存到 `assets/{主题简称}/` 目录
5. **插入**：文章中用 `![描述](../../assets/{主题简称}/fig{序号}.png)` 引用

#### 价值成长类文章

如需配图（估值图表、趋势图等），可使用以下方式：

1. **数据可视化**：使用工具生成图表（如 matplotlib），保存为 PNG
2. **网络搜索图片**：使用 `tools/common/web_search.py` 搜索相关图表，下载后保存到 `assets/{主题简称}/` 目录

> **配图刚性**：配图**必须实际插入**正文，**禁止** `[图X]` 占位符。渲染失败时降低 DPI 重试（900 → 600），仍失败则改用表格 / 示意图，**不得留占位符**。

### 第四步：数据抽检（准出流程）

文章落盘后**必须**执行数据抽检，通过后方可视为定稿：

```bash
# Step 1 - 提取抽检清单（15%随机抽样）
python tools/common/report_audit.py extract \
  --report reports/{公司名}/{公司名}-garp-wechat-{YYYYMMDD}.md --seed 42

# Step 2 - 对清单每项从可靠信源取数（按市场分别使用对应工具）
#   A股：tools/a_share/stock_financial.py（东方财富主）-> 巨潮资讯副 -> 年报PDF原始一手
#   港股：tools/hk_stock/stock_financial.py -> HKEX披露易
#   美股：tools/us_stock/stock_financial.py -> SEC EDGAR
#   计算验算：tools/common/financial_rigor.py（禁止 LLM 心算）

# Step 3 - 输出准出/打回判决
python tools/common/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report {公司名}-garp-wechat-{YYYYMMDD}.md
```

## 注意事项（风控硬编码 GWA-1 ~ GWA-12）

1. **`GWA-1` 三 Agent 协作不可退化**：必须显式保留 作者 / 编辑 / 读者 三个角色与四阶段流程；**编辑与读者矛盾时偏向读者**。不得合并阶段、不得省略任一角色的审阅。
2. **`GWA-2` 五大师口径贯穿**：固定顺序 **费雪 / 林奇 / 郑希 / 李进 / 欧奈尔**；费雪落位**第 3 段「质化校验」**；全文**禁止**出现「四位大师」表述（本档一律为五位大师）。
3. **`GWA-3` 口径只读**：估值 / 卖出 / 管理层 / 地缘 / 宏观**零定义、零重算**，一律引用 `garp-valuation` / `garp-exit` / `garp-management` / `garp-geo-policy` / `garp-macro`；上游未出具时**不给该维度结论**。
4. **`GWA-4` 渗透率黄金窗**：统一使用 **`15%~40%` 五档** + **TAM ≥ 1000 亿元**前置门槛；**禁止**沿用其他档位的旧渗透率区间口径（旧口径词条见下节术语红线表）。
5. **`GWA-5` 五级卖出**：诚信否决 > 硬止损 8%~10% > 逻辑止损 > 产业景气判断 > 估值判断；**补充机制（时间止损 / 性价比替换）并列列示，不占优先级**，不得写成第六级；**禁止**沿用其他档位的六级卖出编号体系（旧编号词条见下节术语红线表）。
6. **`GWA-6` 结论边界**：结论段**不含指令性数值**（目标价 / 目标仓位 / 具体买入价 / 具体止损价 / 减仓比例）；**不回答「现在是否买入」**；买入前提**转出** `/garp-investment-checklist`。
7. **`GWA-7` 事实核查**：写之前先过「伪精确陷阱」6 条——① 概率加权期望值（**全删**，只列情景 + 触发条件 + 方向）② 第三方测算 MAU/份额（只用最可信的两个 anchor，其余定性）③ 历史增速线性外推（改为情景假设 + 高/低区间，不作承诺）④ 未公开的持股比例（给区间，标「不可知」）⑤ 强归因（多重原因都列出，不做单一归因）⑥ 渗透率精确值（标注「估计」并注明来源）。
8. **`GWA-8` 数据抽检准出**：定稿前**必须**执行 `report_audit.py extract → verdict`（seed=42）；偏差 **≤1% 准出 / >1% 打回**，打回项**不可申诉**，修正后重新抽检全流程。
9. **`GWA-9` 数据来源与置信度**：**不虚构数据**（搜不到就标注「估计」）；关键财务数据**双源交叉验证**，误差 >1% 须标记；信息丰富度 A/B/C 分级须告知每个研究 Agent；每条非财报数据后跟「（来源：X）」；**禁止**使用 `WebSearch` / `WebFetch`。
10. **`GWA-10` 术语红线双向**：不得使用长期链术语，也不得原样承袭 1~3 年景气档表述（详见下节术语红线）。
11. **`GWA-11` 三档文件隔离与命名**：一律使用 `-garp-wechat-{YYYYMMDD}` 后缀；隔离核验须用**完整后缀段 / 完整技能名**。
12. **`GWA-12` 配图与公式纪律**：公式必须用 LaTeX（`$$...$$`），且**每个公式后必须配「翻译成人话就是……」**；配图**必须实际插入**，**禁止** `[图X]` 占位符；PDF 文字表格首选 `pdf_extract.py`、高清渲染用 Poppler `pdftoppm`（900 DPI 起步）。

**通用写作要求（不与编号冲突）**：

- **不用 AI 腔调**：禁止「让我们一起来看看」「不得不说」等套话
- **不过度承诺**：技术文章不说「颠覆性的」，用数据说话
- **类比要一以贯之**：全文用一个主线类比
- **结尾必须有传播力**：最后一句话要值得被单独截图转发
- **客观性原则**：区分事实与观点，用数据支撑判断

## 局限性

1. **网络信息获取限制**：网络搜索须使用本地五工具组合
2. **图片生成质量**：AI 生成的图片可能不符合预期
3. **论文 PDF 可得性**：部分论文可能需要付费或无法下载
4. **技术术语准确性**：非常专业的领域可能需要领域专家审核
5. **时效性限制**：网络搜索结果可能有延迟
6. **读者视角模拟局限**：Agent 模拟的读者视角可能无法完全代表真实读者体验
7. **景气数据可得性**：部分行业渗透率等数据缺乏官方统计，需按 A/B/C 三级置信度标注
8. **数据工具延迟**：本地数据工具获取的数据可能有延迟，非实时数据
9. **上游口径依赖**：估值六档 / 五级卖出 / 管理层评分 / 地缘矩阵 / 宏观参数**依赖 `garp-*` 出口技能**；上游未出具时，文章**只作定性描述、不给定量结论**
10. **不构成投资建议**：涉及投资内容仅用于学习与研究，不构成任何投资建议

```markdown
腾讯2025Q4财报出炉：营收增长12%，但ROE连续8季度攀升后首次出现持平。

费雪说："真正能带来超额收益的，是那些在研发与销售组织上持续做对的少数公司。"
林奇说："PEG是我最喜欢的估值指标——但前提是你对增长率有把握。"
郑希说："ROE向上是科技股最可靠的'重力加速度'。"
李进说："用渗透率定位阶段，用二阶导监测拐点。"
欧奈尔说："8%止损是生存红线。"

这篇分析，我用五位大师的框架来拆解这份财报。

## 二、生意本质：一句话说清靠什么赚钱

林奇的第一问：这家公司属于六类中的哪一类？

腾讯当前的增速（12%）已经从"快速增长型"（>20%）滑落至"稳定增长型"（10-20%）。这个分类变化本身就是一个信号——不同类型的股票，估值逻辑完全不同。

## 三、质化校验：财报上找不到的东西

费雪最关心的问题：增长背后，有没有财报上找不到的东西在支撑？

腾讯的广告业务增长，不只是一串数字——它背后是微信生态内商家的实际投放意愿。看两个财报上不直接写的指标：一是小程序商家的复投率，二是视频号广告加载率的变化。如果这两项在改善，说明销售组织是有效的；如果只是靠提高加载率"压榨存量"，那增长的质量就要打折扣。

（**本节只讲财报上找不到的东西**；数据化的 ROE 与渗透率放在下一节。）

## 四、景气验证：ROE趋势与渗透率位置

郑希最关心的问题：ROE趋势如何？（**连续 3 季同向才判拐点，单季波动判噪音**）

| 季度 | Q4'24 | Q1'25 | Q2'25 | Q3'25 | Q4'25 |
|------|-------|-------|-------|-------|-------|
| ROE | 19.2% | 20.1% | 20.8% | 21.5% | 21.4% |

连续 8 季度上升后首次持平。郑希会说："ROE 向上是重力加速度——一旦拐头，必须立即重新评估。"目前是黄灯，不是红灯，但需要下季数据确认。

渗透率定位（**引用 `garp-industry-research` 口径**）：<5% 导入早期 / 5%~15% 突破期 / **15%~40% 加速上行期（黄金窗）** / 40%~60% 逐步兑现 / >60% 天花板。

地缘部分**引用 `garp-geo-policy` 的 0.3 三维交叉矩阵与赛道两分法**，本处不自行评分。

## 五、估值判断：统一六档（引用 garp-valuation）

林奇的核心工具：PEG = PE ÷ 增速

腾讯当前 PE 15x，增速 12%，PEG = 1.25（**PEG 计算用 `financial_rigor.py` 精确计算，档位判定以 `/garp-valuation` 统一六档输出为准**，此处不自行定义阈值）。

档位结论：**合理区间上沿**（**引用 `garp-valuation`**：显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支）。ESG 折价与宏观 PEG 区间同为该技能输出，一并引用；宏观部分**只调参不择时**（引用 `garp-macro`）。

## 六、风险与纪律：五级卖出逐级核对（依据 garp-exit）

欧奈尔最关心的问题：如果错了，亏多少？

| 级别 | 触发条件 | 是否触发 |
|------|---------|----------|
| 一级 诚信否决 | 管理层失信 / 财务造假 / 监管立案 | ❌ |
| 二级 硬止损 | 单笔亏损 8%~10% | ❌ |
| 三级 逻辑止损 | 连续 2 季低于预期且景气未改善 | ❌ |
| 四级 产业景气判断 | 渗透率减速 / ROE 拐头向下 | ⚠️ 观察区 |
| 五级 估值判断 | 调整后 PEG 进入高估 / 严重透支 | ❌ |
| 补充机制（不占优先级） | 时间止损 / 性价比替换 | ❌ |

（触发条件与阈值一律以 `/garp-exit` 输出为准）

管理层部分：**诚信前置检验未命中**（一票否决，不计分）；管理层 20 分制（7+7+6）与科研转化 20 分制（8+8+4）**引用 `garp-management`**，本处不重新计分。

## 七、结论：研究判断与观察清单

**逻辑未变的判断条件**：若下季 ROE 恢复上行、且广告业务复投率继续改善，则 1~5 年价值成长逻辑未变。

**需要警惕的条件**：若 ROE 连续 3 季下行（构成拐点）、或渗透率进入 40%~60% 逐步兑现档且增速转负，则按 `/garp-exit` 对应级别处理。

**风险提示：本文内容基于公开信息和 GARP（1~5 年价值成长）投资框架研究，不构成任何投资建议。**
```
