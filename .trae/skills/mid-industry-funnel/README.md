# 中期行业漏斗精选 (mid-industry-funnel)

1~3 年景气投资行业漏斗：在赛道已确认的前提下，对赛道内候选池执行「硬指标粗筛 → 四大支柱精析 → 四位大师研判 → 3+2 终选组合」逐层漏斗，收敛出 3 家底仓 + 2 家机动仓。属于中期链（1-3 年）功能技能，与长期链（10 年 / `industry-funnel`）物理隔离。

---

## 快速开始

### 基本调用方式

```
/mid-industry-funnel {行业名}
```

支持可选参数：

```
/mid-industry-funnel AI光模块 --scope 全球 --depth standard --export
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `{行业名}` | 位置参数（必填） | — | 赛道/行业名，如「AI 光模块」「人形机器人」 |
| `--scope` | 字符串 | 全球 | 候选池范围：`全球`/`A股`/`港股`/`美股` |
| `--depth` | 字符串 | standard | `fast`（粗筛+终选）/ `standard`（+四支柱+四大师）/ `deep`（+在研扫描） |
| `--export` | 标志 | false | 导出 Markdown 报告至 `reports/` |
| `--json` | 标志 | false | 输出结构化 JSON |

---

## 核心功能

在赛道已通过 `mid-industry-research` 四维筛选（A/B 级）的前提下，把赛道内 30~60 家候选标的逐层收敛为 3+2 终选组合，回答「这条赛道里具体买哪几家？仓位怎么配？」。

### 五步漏斗速览

| 步骤 | 名称 | 收敛 | 关键动作 |
|------|------|------|---------|
| 第一步 | 赛道确认与候选池构建 | 引用结论 | 引用 `mid-industry-research` 四维结论，A/B 级准入，构建 Tier 1~4 候选池 |
| 第二步 | 硬指标粗筛 | 30~60 → 10~20 | 6 条硬指标，任一不过即淘汰（F-2~F-6） |
| 第三步 | 四大支柱精析 | 10~20 → 5~8 | 四大支柱 + 地缘六维 + PEG 估值快评 + 假如空仓测试 |
| 第四步 | 四位大师研判 | 5~8 → 3+2 | 四大师视角 + 管理层 20 分 + 科研转化 20 分 + P0~P5 决策金字塔 |
| 第五步 | 综合输出 | 终选 3+2 | 3 底仓 + 2 机动仓组合表 + 建仓价/止损价 + 季度复盘清单 |

### 10 处口径对齐（与现有中期体系）

| 项 | 对齐方式 |
|------|---------|
| 渗透率坐标 | 统一到 V2.0 黄金区（10%~30% 重仓，>50% 兑现） |
| 6 条硬指标 | 对齐 V2.0 财务五门槛（营收≥10亿/3年CAGR≥15%/负债率<60%/现金流为正/扣非） |
| 3+2 仓位 | 对齐单只 12%~15%、绝对 ≤20% |
| 管理层评分阈值 | 对齐 15/10（≥15 重仓、10~14 轻仓、<10 回避） |
| 决策金字塔 | 统一 `exit-signal` P0~P5，时间止损归入 P2 |
| PEG 估值档位 | 引用 `valuation-thermometer` 五档，不重复定义 |
| 风控编号 | 采用 **F-1~F-10**（避免与 R-/MC- 冲突） |
| 与 `mid-industry-research` 边界 | 赛道结论引用不重做 |
| 报告路径 | `reports/{行业名}-mid-funnel-{YYYYMMDD}.md` |
| 术语红线 | 剔除残留长期「巴芒段李」「护城河永续」表述 |

## 使用示例

### 示例 1：标准漏斗（推荐）

```
/mid-industry-funnel AI光模块 --scope 全球 --depth standard --export
```

执行完整五步漏斗，输出 3+2 终选组合，并落盘 `reports/AI光模块-mid-funnel-20260901.md`。

### 示例 2：快速筛选

```
/mid-industry-funnel 人形机器人 --depth fast
```

只做赛道确认 + 硬指标粗筛 + 3+2 终选，快速出结论。

### 示例 3：深度漏斗（含在研项目扫描）

```
/mid-industry-funnel 创新药 --depth deep --export
```

在标准漏斗基础上追加 `in_research_scan.py` 在研重大项目扫描。

|---------|---------|
| 行业漏斗报告 | `reports/{行业名}-mid-funnel-{YYYYMMDD}.md` |

### 报告结构（十一节固定结构）

1. 赛道确认（引用四维结论 + 评级 + 候选池规模）
2. 硬指标粗筛（6 条逐条核验 + 淘汰名单）
3. 四大支柱精析
4. 四位大师深度研判
5. 终选 3+2 组合
6. 底仓/机动仓分离管理
7. 左侧布局 vs 右侧重仓
8. 常见估值陷阱提醒
9. 风控硬编码 F-1~F-10 检查
10. 每季度复盘清单
11. 综合结论

## 风控硬编码速查（F-1~F-10）

| 编号 | 规则 | 不可做的事 |
|------|------|-----------|
| F-1 | 赛道评级非 A/B → 终止漏斗 | 不得对不合格赛道执行漏斗 |
| F-2 | 财务五门槛任一不过 → 淘汰 | 不得以「成长想象」豁免财务底线 |
| F-3 | PEG>2.0 → 严重透支 | 不得纳入 3+2 终选 |
| F-4 | 流动性不达标 → 淘汰 | 不得纳入机动仓 |
| F-5 | 治理一票否决 → 淘汰 | 不得进入精析 |
| F-6 | 地缘红线 → 淘汰 | 不得以「利空出尽」纳入 |
| F-7 | 管理层<10 分或科研转化<10 分 → 淘汰 | 不得重仓 |
| F-8 | 估值/市值/PEG/仓位计算走 `financial_rigor.py` | 禁止 LLM 心算 |
| F-9 | 终选违反仓位上限 → 强制调整 | 不得输出超限组合 |
| F-10 | 关键数据单一来源 → 标注低置信度 | 不得作为确定性结论 |

---

## 仓位硬约束

- 底仓 60%~80%，机动仓 20%~40%
- 单只初始 ≤10%、验证后 ≤15%、绝对 ≤20%
- 单一行业 ≤40%，持股 5~10 只
- 「3+2」结构：3 家底仓（单只 12%~15%）+ 2 家机动仓（单只 5%~8%）

## 核心原则

1. **赛道结论引用不重做** — 直接引用 `mid-industry-research`，不重复测算 TAM/渗透率
2. **逐层淘汰，而非打分** — 硬指标不过即出局
3. **连续 3 季不靠单季** — ROE 拐点、业绩兑现以连续 3 季同向为准
4. **禁止 LLM 心算** — PEG/市值/CAGR/打分加权走 `financial_rigor.py`
5. **数据双源验证** — 关键数据 ≥2 来源，误差 >1% 标记
6. **终选不越权** — 只出组合+仓位+价区，买入前须过七关 Checklist
7. **卖出引用不重建** — PEG 引用 `valuation-thermometer`，卖出引用 `exit-signal` P0~P5

---

## 注意事项

- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- 开始前运行 `date` 确认当天日期，报告头部注明数据截止日期
- 关键财务数据必须至少来自两个独立来源交叉验证
- 渗透率数据按 A/B/C 三级置信度标注
- 中期术语红线：禁止「护城河永续」「终局思维」「持有10年」等长期框架术语
- 所有硬性规则输出必须包含规则编号引用（如「触发 F-2」）
