# 投资研究（1~3年景气）(Mid-Term Investment Research)

欧奈尔-林奇-郑希-李进 四位景气大师综合分析框架：对单家公司进行 1~3 年景气投资深度研究

> 本技能属**中期链（1-3 年）**，与长期链 `investment-research`（10 年 / 巴菲特-芒格-段永平-李录）**物理隔离、功能互补**。核心理念：**景气驱动，动态持有，纪律退出**——买入不是终点，每季度的景气数据验证才是持有或卖出的依据。

---

## 快速开始

### 基本调用方式

```
/mid-investment-research {公司名}
```

例如：
- `/mid-investment-research 新易盛`
- `/mid-investment-research 中芯国际`
- `/mid-investment-research 腾讯`

## 核心功能

对指定公司进行系统化 1~3 年景气投资研究，整合四位景气大师的方法论，从生意本质与渗透率定位、护城河、产业景气与 ROE 拐点、管理层、风险、估值与建仓、卖出纪律等维度深度研究，产出完整中期投资研究报告。

### 四大师方法论

| 大师 | 核心视角 | 关注重点 |
|------|---------|---------|
| 欧奈尔 | 趋势信号、止损底线、机构持仓 | 8% 止损、抛售日减仓、趋势确认 |
| 林奇 | 生活常识、六类股票、PEG、逆向情绪 | 常识验证、类型标签、估值纪律 |
| 郑希 | ROE 拐点、全球产业链景气传导 | 季度景气验证、ROE 趋势 |
| 李进 | 渗透率定位、二阶导监测、系统均衡 | 渗透率刻度、增速加速度、仓位配置 |

### 八步研究框架

**前置**：AI 研究偏见自觉 — 信息丰富度评级 A/B/C + 偏见自查清单 + 第一性原理追问

1. **数据收集** — 11 项景气数据 + 强制交叉验证（`financial_rigor.py` 杜绝心算）
2. **生意本质与产业定位** — 林奇「六类股票分类」+ 李进「渗透率刻度」（10%~30% 黄金区）
3. **护城河评估** — 郑希「ROE 护城河」+ 欧奈尔「趋势信号」（1~3 年视角）
4. **逆向思考与风险清单** — 硬止损/逻辑止损/时间止损 + 地缘政治六维 + R-1~R-10 对照
5. **产业景气与 ROE 拐点** — 郑希「景气判断」+ 李进「二阶导监测」（引用 `mid-industry-research`）
6. **管理层评估** — 20 分制 + 科研转化 20 分制（李进「治理」+ 林奇「诚信」）
7. **估值与买入时机** — 林奇「PEG」五档（引用 `valuation-thermometer`）+ 分批建仓
8. **综合决策备忘录与卖出纪律** — P0~P5 六级卖出触发（引用 `exit-signal`）

## 输出报告

报告将保存在以下位置：

| 报告类型 | 文件路径 |
|---------|---------|
| 中期景气研究报告 | `reports/{公司名}/{公司名}-景气研究-{YYYYMMDD}.md` |

> 与长期链 `reports/{公司名}/{公司名}-investment-research-{YYYYMMDD}.md` 物理隔离，避免混淆。

### 报告要求

1. 所有分析必须有数据支撑，附数据来源
2. 使用 Markdown 表格呈现关键数据
3. 每个模块末尾必须有对应大师的「追问」
4. 结论要明确，**必须包含卖出触发条件和硬止损位**，不回避买入/观望/回避的建议
5. 估值部分必须给出具体的价格区间和分批建仓计划
6. **报告开头**必须包含「信息丰富度评级」（A/B/C）和「AI 研究局限性声明」
7. **报告结尾**必须区分「AI 分析置信度」与「投资确定性」，并列出「需要一手验证的问题清单」

## 研究标准

### AI 研究偏见自觉（必须执行）

**信息丰富度评级**：

| 等级 | 特征 | AI 研究陷阱 | 应对策略 |
|------|------|-----------|---------|
| A级（信息充裕） | 上市多年、券商覆盖多、媒体报道密集 | 共识过强，AI 输出趋同于市场定价 | 重点做反面检验：景气是否被充分定价？ |
| B级（信息适中） | 上市1-3年、覆盖有限、部分数据需推算 | 用「合理推测」填补空白，产生虚假确定性 | 每个推算数据标注置信度 |
| C级（信息稀缺） | 刚上市/冷门股/新兴市场、几乎无覆盖 | 因资料不足过度保守，误判为「看不清=不好」 | 用第一性原理提问，聚焦核心商业逻辑 |

**偏见自查清单**：
- 我的「确定性」感受来自生意本质，还是来自资料数量？
- 如果资料量减少一半，结论会变吗？
- AI 输出是否与市场共识高度雷同？
- 是否存在「公开资料很少但生意本质极好」的可能性被低估？
- 我是否把「数据不足」等同于「风险过高」？（对 C 级公司尤其重要）

### 数据交叉验证（强制执行，使用工具）

**必须验证的数据点**：
- 总股本（至少 2 个源确认）
- 当前股价和市值（**手动计算 股价×总股本 并与报告市值对比**）
- 最近财年收入和净利润
- ROE（最近 3 年趋势）
- PEG（当前 PE/未来 2 年预期增速，必须精确计算）

**验证规则**：
1. 每个关键数据点至少 2 个独立来源
2. 发现差异时优先采用公司年报/交易所数据
3. **所有涉及计算的数据必须通过工具验算，禁止 LLM 心算**
4. 工具输出结果嵌入报告附录「关键数据交叉验证记录」
5. 工具报告❌偏差过大时，必须排查原因后才能继续分析

### 数据抽检（准出流程）

报告写入后必须执行抽检，通过方可发布：

```bash
# Step 1 — 提取抽检清单（15%随机抽样）
python tools/common/report_audit.py extract --report <报告文件路径>

# Step 2 — 取数核验（按 financial-data 技能规范）

# Step 3 — 输出判决
python tools/common/report_audit.py verdict \
  --results '<填好的JSON>' --report <报告文件名>
```

- **【准出】**：所有抽检点偏差 ≤ 1% → 报告可发布
- **【打回】**：任意点偏差 > 1% → 修正后重新抽检

### 精确计算与审核

| 工具 | 功能 |
|------|------|
| `tools/common/financial_rigor.py` | 精确金融计算（PE、ROE、PEG、市值验证、三情景估值） |
| `tools/common/report_audit.py` | 报告数据抽检与审核 |

**关键计算命令**：

```bash
# 市值验算
python tools/common/financial_rigor.py verify-market-cap \
  --price {股价} --shares {总股本} --reported {报告市值} --currency {币种}

# 关键数据交叉验证
python tools/common/financial_rigor.py cross-validate \
  --field {字段名} --values '{"来源1": 数值, "来源2": 数值}' --unit {单位}

# 估值指标验算
python tools/common/financial_rigor.py verify-valuation \
  --price {股价} --eps {EPS} --bvps {每股净资产} --fcf-per-share {每股FCF}

# PEG 计算（--growth 为百分点数值，如 40 表示 40%）
python tools/common/financial_rigor.py peg --pe {PE} --growth {增速百分点}

# 三情景估值模型
python tools/common/financial_rigor.py three-scenario \
  --price {股价} --eps {EPS} --shares {总股本亿} \
  --growth {乐观} {中性} {悲观} --pe {乐观PE} {中性PE} {悲观PE}

# 获取实时汇率（跨币种折算前必用，勿用固定汇率）
python tools/common/fx_rate.py --code USDCNY,HKDCNY
```

### 网络搜索

禁止使用 Anthropic 官方 WebSearch/WebFetch（中国大陆不可用），统一使用本地五工具组合。完整角色定位、市场×场景选型矩阵、命令速查见 [web-search-tools](../tools-scripts/web-search-tools.md)。

**景气投资研究场景下的搜索选型**（按公司上市地点）：
- A股：财报/研报/公告深查 → `anysearch --tag finance` 主 + `doubao --finance` 辅；实时景气新闻 → `doubao --finance` 主
- 港股：披露易/公告/回购 → `doubao --sites hkexnews.hk` 主 + `tavily` 辅；管理层讨论/分析师点评 → `tavily` 主 + `doubao` 辅
- 美股：SEC filings/财报/MD&A → `exa --type deep` 主 + `tavily` 辅；新闻/舆情 → `doubao` 主 + `anysearch --zone intl` 辅

**搜索规范**（景气投资特有）：
- **多空双方论点**：必须分别检索看多与看空视角，避免单一叙事偏差
- **时效性优先**：使用 `--time-range month/week` 限制时间范围，过时数据须标注时效性说明
- **景气数据**：订单增速、产能利用率、渗透率等领先指标必须搜索
- **双源验证**：非境内上市公司须按市场矩阵双源验证（港股 doubao+tavily；美股 exa+doubao）
- **信息缺口标注**：C级公司（信息稀缺）须诚实标注「数据不足」，不得用推测填充

## 核心原则

1. **数据必须标注来源** — 关键数据至少 2 个来源交叉验证，误差>1% 须标记
2. **禁止 LLM 心算** — 所有涉及计算的数据必须通过 `financial_rigor.py` 工具验算
3. **不虚构数据** — 搜不到就标注「估计」或「数据不足」
4. **客观性原则** — 区分事实与观点，用数据支撑判断
5. **呈现两面** — 每个核心判断附反面论据
6. **诚实面对信息缺口** — 区分「AI 分析置信度」与「投资确定性」
7. **AI 偏见自觉** — 警惕共识陷阱、合理推测填充、资料少≠看不懂
8. **不预设立场** — 先摆数据→推逻辑→出结论
9. **引用不重复定义** — 渗透率引用 `mid-industry-research`，估值引用 `valuation-thermometer`，卖出引用 `exit-signal`

## 注意事项

- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- 关键财务数据必须至少来自两个独立来源进行交叉验证
- 所有估计值必须明确标注「估计」
- 市值必须手算校验：股价 × 总股本，与报告市值对比
- 货币单位要明确（港币/人民币/美元），防止混淆
- PE/ROE/PEG 等指标用 `tools/common/financial_rigor.py` 精确计算，禁止心算
- 卖出纪律使用 `exit-signal` 的 P0~P5（时间止损归 P2，无 P6 层级）
- PEG 档位以 `valuation-thermometer` 五档为准（0.8/1.2/1.5/2.0 边界）
- 报告开头必须包含信息丰富度评级和 AI 研究局限性声明
- 报告结尾必须区分 AI 分析置信度与投资确定性
- C级公司必须列出「需要一手验证的问题清单」
- 报告发布前必须通过 `tools/common/report_audit.py` 数据抽检（准出流程）

## 局限性说明

- **网络限制**：网络搜索须使用本地五工具组合（详见 web-search-tools.md），美股数据需通过浏览器手动获取
- **数据源覆盖**：本地工具主要覆盖 A 股和港股，美股数据源较少
- **实时性**：本地工具数据可能滞后 1-2 天，最新财报建议查原始来源
- **港股接口稳定性**：东方财富港股接口在中国大陆网络连接不稳定（已内置重试机制）
- **AI 偏见**：AI 分析可能受训练数据影响，需通过偏见自查清单校验
- **一手验证**：C级公司（信息稀缺）需通过田野调查、产品体验等方式补充 AI 盲区
- **渗透率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算，按 A/B/C 三级置信度标注
- **地缘政治数据更新频率**：制裁清单、关税政策等变化较快，需定期更新
- 不构成投资建议，仅供学习研究参考
