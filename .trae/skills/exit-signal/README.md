# 卖出信号 (Exit Signal)

将「决策优先级金字塔」与「一页纸备忘卡卖出条目」映射为**硬编码**的 P0~P5 六级检查顺序：P0 → P5 逐级检查、命中即停、禁止跳过 P0。属于 1-3 年中期链功能技能。

---

## 快速开始

### 基本调用方式

```
/exit-signal {公司名}
```

支持两种检查模式：

| 模式 | 触发时机 | 覆盖优先级 |
|------|---------|-----------|
| daily | 每日收盘后（建议每周一开盘前运行） | P0（监管突发）、P1（止损）、P3（技术面辅助） |
| quarterly | 每季报发布后 | P0~P5 完整检查 |

例如：
- `/exit-signal 新易盛`
- `/exit-signal 腾讯 00700`

---

## 核心功能

对持仓标的执行 P0~P5 六级卖出检查，输出命中级别、信号（清仓/减仓/调仓/持有）与动作明细。

### P0~P5 六级映射表（唯一权威口径）

| 级别 | 触发条件 | 决策 | 思想来源 |
|------|---------|------|---------|
| P0 治理一票否决 | 管理层失信、财务造假实锤、监管立案 | 立即清仓，不看估值趋势 | 李进（治理） |
| P1 硬止损 | 单笔亏损 8%~10%，且无基本面反转信号 | 无条件止损 | 欧奈尔 |
| P2 逻辑止损 | 连续 2 季业绩低于预期且产业景气未改善；或持有满 4 季度逻辑未兑现（时间止损） | 减仓或清仓 | 林奇 + 郑希 |
| P3 产业景气拐点 | 渗透率减速 / ROE 拐头向下 | 减机动仓 | 李进 + 郑希 |
| P4 估值透支 | PEG > 1.5（减机动仓）；PEG > 2（加速清机动仓） | 减 / 清机动仓 | 林奇 |
| P5 性价比替换 | 其他标的 PEG 显著更低且产业趋势更强 | 调仓（每季度最多 1 次） | 机会成本 |

### 硬编码执行规则

- 检查顺序固定 P0 → P1 → P2 → P3 → P4 → P5；
- **命中即停**：输出命中的最高级别，不得继续检查更低级别；
- **禁止跳过 P0**：任何输入都必须先过 P0 治理检查；
- 「时间止损（满 4 季度逻辑未兑现）」**归入 P2**，不设独立层级；
- 硬止损 8%~10% 为硬性区间，AI 不得放宽。

## 使用示例

### 六级场景触发示例（每级 1 例）

| 级别 | 示例场景 | 预期动作 |
|------|---------|---------|
| P0 | 管理层被证监会立案（治理一票否决） | 立即清仓，不看估值趋势 |
| P1 | 单笔浮亏 9% 且无基本面反转信号 | 无条件止损 |
| P2 | 连续 2 季业绩低于预期且景气未改善 | 减仓或清仓 |
| P2（时间止损） | 持有满 4 季度逻辑未兑现 | 减仓至观察仓（归入 P2，非新层级） |
| P3 | 渗透率增速转负 / ROE 拐头向下 | 减机动仓 30%~50% |
| P4 | PEG=1.6；再测 PEG=2.2 | 减机动仓；加速清机动仓 |
| P5 | 存在 PEG 显著更低且产业趋势更强的替代标的 | 调仓（每季度最多 1 次） |

### P0 一票否决清单展开（判定线索）

| 检查项 | 触发条件 |
|--------|---------|
| 监管记录 | 近 3 年违规 / 问询函 / 警示函（财务造假相关为一票否决） |
| 财务造假 | 营收与经营现金流严重背离（现金流/营收 <0.5 连续 2 季）；利润与行业趋势严重不符 |
| 业绩预告 | 近 5 次预告偏差 >20% 且方向向下 |
| 归因习惯 | 年报「经营情况讨论」习惯性归咎宏观/政策、从不自省 |
| 大股东质押 | 质押比例 >50% 且持续攀升 |

> P0 触发后硬编码输出「立即清仓」，禁止输出「再观察一季」「估值便宜可持有」等弱化建议。

### 时间止损归入 P2 的说明

- 「时间止损（满 4 季度逻辑未兑现）」**不设独立层级**，统一归入 P2 逻辑止损，消除「五级金字塔 vs 六级 P0~P5」歧义；
- 满 4 季度 + 完全未兑现 → 减仓至观察仓（原仓位 30%~50%）；部分兑现 → 缓刑 1 季度；已兑现 → 继续持有并重置计数器。

## 输出报告

报告将保存在以下位置：

| 报告类型 | 文件路径 |
|---------|---------|
| 卖出信号检查 | `reports/exit-signals/{公司名}-exit-{YYYYMMDD}.md` |

命名规则：`{公司名}` 用中文或标准简称，`{YYYYMMDD}` 为报告生成日期（8 位）。

### 报告结构

```markdown
# {公司名} 卖出信号检查报告（1-3年中期）
## 一、卖出结论
## 二、逐级检查表（P0→P5）
## 三、动作明细
## 四、触发证据链
## 五、数据来源与不确定性标注
```

| 动量/技术面（P1/P3 辅助） | `a_share/stock_quote.py`、`hk_stock/stock_quote.py`、`us_stock/stock_quote.py` | `--momentum --auto-peers` |

| 隐含增速红黄绿（P4 联动） | `financial_rigor.py implied-growth` | `--market-cap --target-pe --net-margin --ttm-revenue --guidance-growth` |

### 关键约束

- 卖出决策不可被 AI 自由裁量：止损 8%~10%、时间止损 4 季度、PEG 阈值、底仓/机动仓区间全部硬编码。
- P4 的 PEG 档位必须来自 `valuation-thermometer` 输出，不在本技能内重新计算 PEG。
- 禁止使用 WebSearch / WebFetch 工具（中国大陆不可用），统一用本地搜索工具。

---

## 核心原则

1. **优先级固定** — P0→P5，高优先级触发即停，不被低优先级覆盖。
2. **P0 不可跳过** — 任何输入先过治理检查。
3. **硬编码阈值** — 卖出阈值写死，AI 不自由裁量弱化或绕过。
4. **证据驱动** — 每级触发给出财报/估值/动量/舆情证据链。

---

## 注意事项

- 命中即停：输出命中的最高级别，不得继续检查更低级别。
- P4 仅影响机动仓，不构成对底仓的卖出指令。
- 无 thesis 论文时仅能执行 P0/P3/P4，须显式标注数据缺口。
- 关键财务数据须至少两个来源交叉验证。

---

## 局限性说明

- 无 thesis 论文时检查不完整（仅 P0/P3/P4）。
- 技术面信息仅作 P3 辅助，不单独构成卖出层级。
- 不包含 `mid-thesis-drift`（论文漂移检测）依赖，该能力属 Sprint 1 范围外。
- 不构成投资建议，仅供学习研究参考。
