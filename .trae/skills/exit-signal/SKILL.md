# 卖出信号：1-3年中期 P0~P5 六级优先级硬编码卖出检查

将「决策优先级金字塔」与「一页纸备忘卡卖出条目」映射为**硬编码**的 P0~P5 六级检查顺序，从 P0 到 P5 逐级检查、命中即停、禁止跳过 P0。属于中期链（1-3 年）功能技能。

## 设计原则

1. **优先级固定**：P0 → P1 → P2 → P3 → P4 → P5，高优先级触发即停，不得被低优先级覆盖。
2. **P0 不可跳过**：任何输入都必须先过 P0 治理检查。
3. **硬编码阈值**：止损 8%~10%、时间止损 4 季度、PEG 阈值、底仓/机动仓区间全部写死，AI 不得自由裁量弱化。
4. **证据驱动**：每级触发必须给出财报数据、PEG 档位、动量指标或舆情来源等证据链。
5. **估值输入来自 `valuation-thermometer`**：P4 的 PEG 档位直接引用其输出，不在本技能重复计算。

## P0~P5 六级映射表（唯一权威口径，硬编码）

| 级别            | 触发条件                                                                               | 决策                    | 思想来源     |
| --------------- | -------------------------------------------------------------------------------------- | ----------------------- | ------------ |
| P0 治理一票否决 | 管理层失信、财务造假实锤、监管立案                                                     | 立即清仓，不看估值趋势  | 李进（治理） |
| P1 硬止损       | 单笔亏损 8%~10%，且无基本面反转信号                                                    | 无条件止损              | 欧奈尔       |
| P2 逻辑止损     | 连续 2 季业绩低于预期且产业景气未改善；**或持有满 4 季度逻辑未兑现（时间止损）** | 减仓或清仓              | 林奇 + 郑希  |
| P3 产业景气拐点 | 渗透率减速 / ROE 拐头向下                                                              | 减机动仓                | 李进 + 郑希  |
| P4 估值透支     | PEG > 1.5（减机动仓）；PEG > 2（加速清机动仓）                                         | 减 / 清机动仓           | 林奇         |
| P5 性价比替换   | 其他标的 PEG 显著更低且产业趋势更强                                                    | 调仓（每季度最多 1 次） | 机会成本     |

## 硬编码执行规则

- 检查顺序固定 P0 → P1 → P2 → P3 → P4 → P5；
- **命中即停**：输出命中的最高级别及对应动作，不得继续检查更低级别（高优先级场景不得被低优先级覆盖）；
- **禁止跳过 P0**：任何输入都必须先过 P0 治理检查；
- 「时间止损（满 4 季度逻辑未兑现）」**归入 P2**，不设独立层级；
- 硬止损 8%~10% 为硬性区间，AI 不得放宽。

## 执行流程

### 第一步：读取 thesis 论文与持仓信息

按「thesis 论文输入来源」节读取论文与持仓（买入日期、买入价格、买入逻辑摘要、建仓时 PEG、目标仓位比例），命令行 `--buy-date` / `--buy-price` 优先覆盖论文值。

### 第二步：收集输入数据

按「输入形态」节收集持仓、财报、动量/技术面、估值温度、治理与舆情线索。

### 第三步：逐级检查（P0→P5）

从 P0 到 P5 逐级检查，按「P0~P5 各层检查维度展开」节判定触发条件；命中即停，输出命中的最高级别及对应动作。

### 第四步：生成动作明细

按命中级别生成动作（清仓/止损/减仓/调仓/持有），底仓、机动仓分别说明，并引用仓位上限硬编码。

### 第五步：输出报告

按「输出结果」节固定模板写入 `reports/exit-signals/`，并在报告头部注明检查日期。

### 关键约束

- 卖出决策不可被 AI 自由裁量：止损 8%~10%、时间止损 4 季度、PEG 阈值、底仓/机动仓区间全部硬编码。

## P0~P5 各层检查维度展开

### P0 治理一票否决

| 检查项     | 触发条件                                                                       | 数据来源                                                     |
| ---------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| 监管记录   | 近 3 年违规 / 问询函 / 警示函（财务造假相关为一票否决）                        | `anysearch.py --tag legal`、`doubao_search.py --finance` |
| 财务造假   | 营收与经营现金流严重背离（现金流/营收 <0.5 连续 2 季）；利润与行业趋势严重不符 | `stock_financial.py` 交叉验证                              |
| 业绩预告   | 近 5 次预告偏差 >20% 且方向向下                                                | `stock_financial.py`                                       |
| 归因习惯   | 年报「经营情况讨论」习惯性归咎宏观/政策、从不自省                              | 年报文本分析                                                 |
| 大股东质押 | 质押比例 >50% 且持续攀升                                                       | 公告 / 交易所数据                                            |

> P0 触发后硬编码输出「立即清仓」，禁止输出「再观察一季」「估值便宜可持有」等弱化建议。

### P1 硬止损——止损比例取值规则（按仓位状态）

| 仓位状态                        | 止损比例 | 说明               |
| ------------------------------- | -------- | ------------------ |
| 建仓初期（持仓 < 目标仓位 50%） | 8%       | 严格执行，保护本金 |
| 底仓已建立且逻辑已验证（≥50%） | 10%      | 容忍空间更大       |
| 波动大标的（如科技成长股）      | 10%      | 避免噪音触发       |

- 触发止损 + 无明确基本面反转信号 → **无条件清仓**；
- 触发止损 + 有明确基本面反转（产业 / 管理层 / 财务三维度均未恶化）→ 暂不清仓，降为观察仓，并在报告说明证据；
- **10% 临界点处理**：10% 同时落在硬止损上限与「越跌越买」加仓下沿，触及先做止损复核——仅当三维度均未恶化且属已建立的底仓逻辑仓位时，才允许在合理估值下限加仓，否则一律退出。

### P2 逻辑止损——两个子项

- **子项 A（连续 2 季业绩低于预期）**检查维度：
  - 营收增速（连续 2 季低于买入时预期增速 50%）；
  - 扣非净利润（连续 2 季放缓或为负）；
  - 合同负债/订单（环比连续 2 季下降 >10%）；
  - 产业景气交叉（行业景气同步下行）。
- **连续 3 季度趋势判定**（区分波动与拐点）：
  - 连续 3 季加速 → 不触发；
  - 单季放缓 + 全年预期不变 + 渗透率 <40% → 短期波动，不触发、仅调机动仓；
  - 连续 2~3 季减速 + 订单增速同步放缓 + 竞争加剧 → 趋势拐点，**触发 P2**。
- **子项 B（时间止损，满 4 季度未兑现）**判断维度：
  - 订单（合同负债/在手订单未显著增长）；
  - 收入（季度营收增速 < 买入时预期 50%）；
  - 利润（扣非未增长或为负）。
  - 满 4 季度 + 完全未兑现 → 减仓至观察仓（原仓位 30%~50%）；部分兑现 → 缓刑 1 季度；已兑现 → 继续持有并重置计数器。

### P3 产业景气拐点

| 检查项                   | 触发条件                      | 数据来源                                |
| ------------------------ | ----------------------------- | --------------------------------------- |
| 渗透率减速（二阶导转负） | 渗透率接近或超 50% 且增速放缓 | `mid-industry-research` 输出          |
| ROE 拐头向下             | 从上行转为走平或下行          | `qoq-accelerator` 输出                |
| 行业供需逆转             | 供不应求 → 供过于求          | `mid-industry-research` 输出          |
| 技术面辅助               | 当前价 < MA200 + 放量破位     | `stock_quote --momentum --auto-peers` |

> 技术面信息仅作 P3 辅助确认，不单独构成优先级层级；纯技术面深度体检归 `trend-momentum-scan`。

### P4 估值透支——implied-growth 红黄绿灯联动

| 判定 | 条件                      | 操作                 |
| ---- | ------------------------- | -------------------- |
| 红灯 | 隐含增速 > 指引增速 ×1.5 | 强化 P4，加速减持    |
| 黄灯 | 隐含增速在指引 ×1.0~1.5  | 温和预警，减持机动仓 |
| 绿灯 | 隐含增速 ≤ 指引增速      | 估值可消化，不触发   |

> P4 仅影响机动仓，不影响底仓；P4 与 P1/P2 同时触发时以高优先级为准。

### P5 性价比替换

- 更优标的 PEG 差距 >0.3 且产业趋势更强；
- 调仓前新标的须通过完整选股流程验证，不可仅因 PEG 低就替换；
- 逐步切换：先建新标的底仓，再清旧标的机动仓；
- 每季度最多 1 次。

## thesis 论文输入来源

- 自动读取 `reports/{公司名}/{公司名}-mid-thesis.md`，解析 `buy_date` / `buy_price` / 买入逻辑摘要 / 建仓时 PEG / 目标仓位比例；
- 命令行显式提供 `--buy-date` / `--buy-price` 时优先覆盖论文值；
- 无买入日期 → 跳过 P2 时间止损子项；无买入价格 → 跳过 P1；无论文 → 仅执行 P0/P3/P4，P1/P2/P5 跳过并标记「数据不足」。

## 数据缺失处理

| 缺失数据                       | 处理                                   |
| ------------------------------ | -------------------------------------- |
| 买入日期                       | 跳过 P2 时间止损子项，标记「数据不足」 |
| 买入价格                       | 跳过 P1，标记「数据不足」              |
| 无 thesis 论文                 | 仅执行 P0/P3/P4                        |
| MA200 数据不足（上市 <200 日） | P3 技术面辅助跳过，标记「数据不足」    |
| 一致预期增速缺失               | P4 PEG 用历史 3 年复合增速替代并标注   |

## 检查频率

| 模式      | 触发时机                           | 覆盖优先级                                   |

| daily     | 每日收盘后（建议每周一开盘前运行） | P0（监管突发）、P1（止损）、P3（技术面辅助） |
| quarterly | 每季报发布后                       | P0~P5 完整检查                               |

## 注意事项

1. 开始前运行 `date` 确认当天日期，报告头部注明检查日期。
2. 命中即停：输出命中的最高级别，不得继续检查更低级别。
3. P0 在任何场景下均被检查，不可跳过。
4. 卖出决策阈值（止损 8%~10%、时间止损 4 季度、PEG 阈值）不可被 AI 弱化或绕过。

## 局限性

1. P4 仅影响机动仓，不构成对底仓的卖出指令。
2. 无 thesis 论文时仅能执行 P0/P3/P4，检查不完整，须显式标注数据缺口。
3. 技术面信息仅作 P3 辅助，不单独构成卖出层级。
4. 本技能不包含 `mid-thesis-drift`（论文漂移检测）依赖，该能力属 Sprint 1 范围外。

## 与其他Skill的关系

- **前置**：`valuation-thermometer`（P4 估值透支输入 PEG 档位）、`thesis-tracker --horizon mid`（买入逻辑与持仓来源）、`mid-industry-research`（P3 渗透率）、`qoq-accelerator`（P3 ROE）。
- **同级**：`quality-screen`（长期链逆向淘汰，与本技能中期卖出物理隔离）。
- **边界**：卖出决策硬编码，AI 不自由裁量；`mid-thesis-drift` 不在本技能依赖内。

## 附录：决策优先级速查卡（硬编码）

```
P0 治理一票否决（失信/造假/立案）      -> 立即清仓，不看估值趋势
P1 硬止损（欧奈尔 8%~10%）           -> 无条件清仓
```
