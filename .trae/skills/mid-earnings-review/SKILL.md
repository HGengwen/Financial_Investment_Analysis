# 财报精读（轻量版）：1~3 年景气投资版

对 $ARGUMENTS 进行财报精读分析。

**支持输入格式**：`公司名 季度`，例如：`腾讯 2025Q4`、`PDD 2025年报`、`美团 最新`（默认读取最近一期）

> 本技能属**中期链（1-3 年）**，与长期链 `earnings-review`（10 年 / 巴菲特-李录一手资料精读）及团队版 `mid-earnings-team`（四大师并行 + 编辑 + 读者评审 + 公众号发布）**物理隔离、功能互补**。禁止使用「护城河永续」「终局思维」「持有 10 年」等长期框架术语。

本技能是 `mid-earnings-team`（六 Agent 团队精读 + 公众号发布）的**轻量版**——适合日常财报快速跟踪，无需启动多个 Agent。如需深度团队分析和公众号文章发布，请使用 `mid-earnings-team`。

## 一、能力圈声明

本技能严格服务于 1~3 年景气成长投资框架，并非万能工具。

### 1.1 适用场景

- **科技/医药/高端制造**：具备技术壁垒或产品迭代周期的公司
- **景气周期成长股**：行业渗透率处于 10%~50% 黄金加速期
- **可持续成长**：ROE 有明确提升路径，且现金流能支撑再投资

### 1.2 不适用场景（请停止使用本技能）

- **纯周期股**：如航运、有色、煤炭（应使用 PE/PB 周期估值，PEG 失效）
- **困境反转股**：当前亏损或微利，PEG 无法计算或失真
- **金融股**：资产负债表结构特殊，需用 PB-ROE 或股息率模型
- **被动指数投资**：无需个股景气验证
- **短期交易**：本框架不关注日内波动、纯技术面超买超卖或宏观择时

## 二、与段永平价值投资的关系说明

⚠️ **重要界定**：段永平在本框架中仅作为「哲学补充」角色，不参与估值、择时、止损等操作层面决策。

**可借鉴的底层哲学**：

- 「买股票就是买公司」：强调一手资料、管理层诚信、生意模式。
- 「能力圈」：不懂不做，不碰看不懂的复杂金融衍生品或过度杠杆公司。
- 「本分」：不占便宜，关注企业内在价值而非短期股价波动。

**不完全适配的核心思想**：

- 「封仓十年」：本框架持有周期为 1~3 年，需根据景气拐点动态调整，不做无条件死扛。
- 「不预测宏观」：本框架需关注行业渗透率、政策导向及地缘政治对产业周期的影响。
- 「毛估估」：本框架要求精确的 PEG 估值定位（引用 `valuation-thermometer`）、二阶导计算及分批建仓纪律，拒绝模糊估值。

## 三、设计理念

大多数 AI 投研工具依赖二手信息。但景气投资的财报跟踪，必须读一手资料——因为景气拐点的信号往往藏在细节里：ROE 拐头、二阶导转负、管理层语气变化、研发进度滞后。

在 1~3 年景气投资框架中，每季度财报是验证投资逻辑的关键节点，必须回答四个问题：

1. **景气逻辑验证**：ROE 趋势是否持续？二阶导（增速加速度）是正是负？渗透率到哪了？
2. **卖出纪律更新**：本季度数据是否触发任何卖出条件？（P0~P5 优先级，引用 `exit-signal`）
3. **管理层是否在抓住窗口**：战略执行力、资本配置效率、科研转化进展。
4. **估值与仓位匹配**：当前 PEG 处于哪一档？底仓/机动仓比例是否合理？

**四位大师权威分工（对齐 `research/个人投资者1~3年中长期投资思想与理念 V2.0.md`，作为单 Agent 的分析维度标尺，非多 Agent 角色）**：

| 大师 | 思维模式 | 在财报精读中的维度 |
|------|---------|-------------------|
| 郑希 | 物理学家思维 · 周期与第一性原理 | **产业景气验证**：ROE 趋势/拐点、二阶导、渗透率位置、供需格局 |
| 林奇 | 侦探思维 · 常识与求证 | **生意与估值**：收入量价拆解、毛利率/现金流质量、PEG 估值更新（引用 `valuation-thermometer`）、估值陷阱排查 |
| 欧奈尔 | 工程师思维 · 信号与纪律 | **风控底线**：止损位更新、趋势信号、抛售信号 |
| 李进 | 系统工程师思维 · 均衡与渗透率 | **组合管理 + 治理**：管理层/科研转化评估、地缘政治、底仓/机动仓分离、卖出纪律执行 |

> "ROE 向上是科技股最可靠的'重力加速度'——只要这个趋势在，估值波动只是噪音。" —— 郑希（产业景气）
>
> "如果你花 10 分钟都解释不清一家公司是做什么的，那它的业务可能太复杂了。" —— 林奇（生意验证）
>
> "先想清楚亏多少，再想赚多少。8% 是普通投资者的生存红线。" —— 欧奈尔（风控底线）
>
> "管理层是'人'的因素，科研转化是'技术'的因素。两者必须交叉验证。" —— 李进（治理与组合）

## 四、执行流程

### 前置步骤：资料可得性评级

| 等级 | 特征 | 影响 |
| ---- | ---- | ---- |
| A级 | 获取到完整原文（10-K/年报/电话会纪要） | 正常执行全部步骤 |
| B级 | 仅获取到部分原文或第三方汇总 | 标注「非原始来源」，降低附注分析权重 |
| C级 | 仅有新闻报道和数据网站摘要 | 聚焦核心财务数据变化，标注「一手资料不足」，禁止给出买入建议 |

### 第一步：获取一手资料

#### 1.1 A股财报原文下载（优先执行，必须完成）

**重要流程**：对于 A 股公司，必须首先使用 `stock_equity.py` 工具下载原始财报 PDF，**下载完成后方可进行下一步的阅读分析工作**。

```bash
# 下载最新年报PDF
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type annual

# 下载最新半年报PDF（如需分析半年报）
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type semiannual

# 下载最新季报PDF（如需分析季报）
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type quarterly
```

下载的 PDF 文件保存在 `cninfo_reports/` 目录。**流程检查点**：确认 PDF 文件下载成功后，方可进行后续的财报阅读分析。

#### 1.2 PDF 文档阅读工具

下载的财报 PDF 文档提取文字与表格**首选** `tools/common/pdf_extract.py`（基于 pdf-inspector 库，支持自动乱码检测 + OCR 回退），返回失败（退出码非 0 / success=false / 扫描件）时才回退 Poppler 工具集：

**首选工具**：

```bash
# 分类检测 PDF 类型
python tools/common/pdf_extract.py detect cninfo_reports/002465_2025年报.pdf

# 提取含财务附表的 Markdown 并写盘
python tools/common/pdf_extract.py markdown cninfo_reports/002465_2025年报.pdf --save-md --out-dir reports/pdf

# 强制 OCR 提取（适用于 pdf-inspector 提取乱码时，如 Adobe-CNS1 繁体中文 PDF）
python tools/common/pdf_extract.py text cninfo_reports/688235_2025年报.pdf --force-ocr --ocr-langs chi_tra+eng
```

**回退工具（Poppler 工具集，仅当 pdf_extract.py 返回失败时使用）**：

```bash
pdfinfo cninfo_reports/002465_2025年报.pdf
pdftotext cninfo_reports/002465_2025年报.pdf cninfo_reports/002465_2025年报.txt
pdftoppm -png cninfo_reports/002465_2025年报.pdf cninfo_reports/002465_2025年报
```

**注意事项**：

- 首选 `pdf_extract.py` 提取文字与表格；返回失败时才回退 Poppler 工具集（详见 [PDF文档内容提取技能](../tools-scripts/pdf-extraction.md)）
- `pdf_extract.py` 内置自动乱码检测，当 pdf-inspector 提取文本出现乱码（如 Adobe-CNS1 字体编码问题）且 tesseract OCR 可用时，自动触发 OCR 回退
- **繁体中文 PDF**（如百济神州）需使用 `--force-ocr --ocr-langs chi_tra+eng` 指定繁体中文语言包
- 如果 PDF 无法提取内容，应在报告中标注「资料评级：B 级」，说明扫描版 PDF 限制

### 第二步：核心财务数据提取与验证（景气投资版）

#### 2.1 景气三要素：ROE、增速、二阶导

**郑希核心**：ROE 向上是科技股最可靠的「重力加速度」。

| 指标 | 本期 | 上季 | 去年同期 | 趋势判断 |
|------|------|------|---------|----------|
| ROE（TTM） |  |  |  | ↑/→/↓ |
| 营收增速（YoY） |  |  |  | ↑/→/↓ |
| 净利润增速（YoY） |  |  |  | ↑/→/↓ |
| 增速二阶导（本期增速 - 上期增速） |  |  |  | 正/负/持平 |

> **郑希式追问**：如果 ROE 连续 2 季度持平或下降，景气逻辑需要重新审视。二阶导连续 2 季度转负是系统性减仓信号（对齐 `exit-signal` P3）。

#### 2.2 收入与利润表（景气视角）

| 指标 | 本期 | 上期 | YoY变化 | 景气解读 |
|------|------|------|---------|---------|
| 总收入 |  |  |  |  |
| 分业务增速 |  |  |  | 哪些业务在加速/减速？ |
| 毛利率 |  |  |  | 定价权是否稳固？ |
| 经营利润率 |  |  |  | 费用控制是否有效？ |

必须覆盖：

- 总收入及分业务/分地区收入拆解（区分「量」还是「价」驱动的增长）
- 毛利润、毛利率变化
- 经营利润、经营利润率变化（区分 GAAP 和 Non-GAAP）
- 净利润（注意非经常性损益的影响）
- EPS（基本 vs 稀释）

#### 2.3 现金流表（景气可持续性验证）

| 指标 | 本期 | 上期 | 变化 | 景气解读 |
|------|------|------|------|---------|
| 经营现金流 |  |  |  | 利润质量如何？ |
| 自由现金流 |  |  |  | 能否支撑再投资？ |
| 资本开支 |  |  |  | 是扩张性还是维护性？ |

必须覆盖：

- 经营性现金流 vs 净利润的比率（>100% 为佳，<80% 需警惕）
- 资本开支及其构成（维护性 vs 扩张性）
- 自由现金流 = 经营现金流 - 资本开支

#### 2.4 资产负债表健康度

- 现金储备 vs 有息负债
- 应收账款周转天数（是否在放宽信用冲收入？）
- 存货周转天数（是否在积压？）

**数据验证**：使用 `tools/common/financial_rigor.py` 对关键数据进行校验，禁止 LLM 心算：

```bash
# 收入和净利润交叉验证（至少2个来源）
python tools/common/financial_rigor.py cross-validate \
  --metric "revenue" --values 108.3e9 107.9e9 --sources "公司财报" "Yahoo Finance"

# 估值指标验算
python tools/common/financial_rigor.py verify-valuation \
  --price 101 --eps 9.6 --bvps 26.5 --fcf-per-share 10.2
```

### 第三步：PEG 估值定位（引用 valuation-thermometer）

在财务数据验证后，必须进行 PEG 估值定位，作为操作依据。

#### 3.1 PEG 估值定位与操作联动

- **估值档位判定、边界约定与底仓/机动仓操作映射，一律以 `/valuation-thermometer` 输出为准，本技能不重复定义五档阈值。**
- 执行时先调用 `valuation-thermometer` 取得 PEG 档位，再给出建仓/持有/减持建议。
- 对比上季度 PEG 变化方向：变得更贵还是更便宜？

#### 3.2 渗透率位置（归入郑希赛道判断，引用 mid-industry-research）

渗透率不作为 PEG 数值上的加减项，而是归入郑希「产业景气 / 渗透率位置」判断（引用 `mid-industry-research`），在结论处与估值交叉比对：

- 渗透率位置：<10% 过早（左侧）/ 10%~30% 黄金区（右侧重仓）/ 30%~50% 成长期 / >50% 警戒区
- 变化方向：加速渗透 / 稳步提升 / 放缓

#### 3.3 常见估值陷阱提醒

- **低 PE 陷阱**：PE 低但行业处于景气顶点，未来盈利将大幅下滑（周期股特征）。
- **高 PE 但增速不可持续**：当前增速来自一次性收益（如卖地、补贴、汇率波动），需剔除后重算 PEG。
- **忽略股权稀释**：EPS 增长可能来自回购减少股本，而非净利润增长。需检查「净利润增速」与「EPS 增速」的剪刀差。

### 第四步：分批建仓规则

若估值进入合理区间，禁止一次性满仓，严格执行分批建仓：

- **底仓建立**：股价进入「合理买入区间」（档位判定引用 `valuation-thermometer`），先建 1/3 底仓。
- **回调加仓**：若继续回调至合理区间下限以下（档位判定引用 `valuation-thermometer`），再加 1/3。
- **确认加仓**：确认产业景气加速（渗透率突破关键位）或财报超预期（二阶导转正），补齐剩余 1/3。

**仓位红线（硬编码）**：

- 单只初始仓位 ≤ 10%
- 验证后仓位 ≤ 15%
- 绝对上限 ≤ 20%
- 单一行业仓位 ≤ 40%

### 第五步：左侧布局 vs 右侧重仓策略对照

| 维度 | 左侧布局（逆向） | 右侧重仓（顺势） |
|------|-----------------|-----------------|
| 触发信号 | 行业短期利空但长期逻辑未破坏，估值处于低估档（引用 `valuation-thermometer`） | 渗透率突破关键临界点、财报连续 2 季度加速 |
| 仓位策略 | 分批建仓，总仓位控制在最终目标的 50% 以内 | 可一次性建 2/3 仓位，剩余 1/3 留作机动 |
| 止损纪律 | 宽止损（-15%），但需逻辑未坏 | 窄止损（-8%~-10%），趋势走坏即走 |
| 核心心态 | 忍受波动，赚估值修复+业绩增长的钱 | 享受泡沫，赚业绩加速+估值提升的钱 |

### 第六步：管理层讨论精读（景气投资版）

#### 6.1 管理层对景气趋势的判断

逐段阅读管理层讨论/电话会发言，提取管理层对以下问题的判断：

| 问题 | 管理层表述 | 判断 |
|------|-----------|------|
| 对行业景气的看法 |  | 乐观/谨慎/悲观 |
| 对自身增速的判断 |  | 加速/稳定/放缓 |
| 对竞争格局的描述 |  | 良性/加剧/恶化 |
| 对未来的指引 |  | 上调/维持/下调 |

#### 6.2 管理层语气分析

| 信号类型 | 具体表现 | 本期表现 |
|---------|---------|---------|
| 🟢 坦诚信号 | 主动承认问题、给出具体原因 |  |
| 🟢 清晰信号 | 战略表述具体、有量化目标 |  |
| 🔴 模糊信号 | 大量空话、回避实质问题 |  |
| 🔴 归因外部化 | 把问题全甩给宏观/政策 |  |

#### 6.3 承诺追踪（李进维度A）

从上一期财报/电话会中提取管理层的具体承诺，与本期实际情况对比：

| 上期承诺 | 本期兑现 | 评价 |
|---------|---------|------|
| 「下半年 ROE 将提升至 X%」 | 实际 Y% | ✅/❌/⚠️ |

> **李进式提醒**：兑现率 ≥80% 为优秀，<50% 一票否决（对齐 `exit-signal` P0 治理风险）。

趋势判断要点：

- ROE 是连续上升、筑顶、还是已拐头？
- 营收增速二阶导：正（加速）、负（减速）、持平？
- 毛利率是提升、稳定、还是下降？

- 变化方向：加速渗透 / 稳步提升 / 放缓

### 第九步：决策优先级检查（引用 exit-signal P0~P5）

每季度财报必须按此顺序检查卖出纪律，高优先级触发即执行，不再看低优先级。

**本技能不重复定义 P0~P5 的触发阈值与条件，一律以 `exit-signal` 输出为准。**

口径要点：

- 检查顺序固定：**P0 治理一票否决 → P1 硬止损 → P2 逻辑止损（含时间止损）→ P3 产业景气拐点 → P4 估值透支 → P5 性价比替换**。
- **命中即停**：输出命中的最高级别及对应动作，不得继续检查更低级别；**禁止跳过 P0**。
- 时间止损（持有满 4 季度逻辑未兑现）**归入 P2**；技术面仅作 P3 辅助、不构成独立层级。

本节任务：逐一核对 `exit-signal` 的 P0~P5 各层是否被新财报数据触发，输出「是否触发 + 对应层级 + 建议动作」。

### 第十步：底仓/机动仓分离管理

在报告中必须明确当前仓位结构：

- **底仓（60%~80%）**：
  - 定位：长线核心，赚企业 1~3 年成长的钱。
  - 纪律：不因短期 20% 以内波动卖出；仅在 P0（治理一票否决）/P2（逻辑止损）/P5（性价比替换）触发时调整。
- **机动仓（20%~40%）**：
  - 定位：平滑波动，赚估值波动的钱。
  - 纪律：PEG 档位进入高估区（引用 `valuation-thermometer`）时减持；回落至合理区间回补；P1 触发时优先砍机动仓。

### 第十一步：「假如空仓」测试

在报告结论部分，必须回答：

- 如果现在让你空仓，你会以当前价格买入这家公司吗？
  - **会买** → 继续持有，甚至加仓。
  - **不会买** → 考虑减仓或清仓（理由必须具体，如「PEG 2.5 太贵」「ROE 拐头」）。
  - **犹豫不决** → 减仓至观察仓，等待更清晰的信号。

### 第十二步：季度复盘检查清单（7 项必查）

| 序号 | 检查项 | 本期结论 |
|------|--------|---------|
| 1 | 管理层承诺兑现情况 | ✅/❌/⚠️ |
| 2 | 科研转化进展（如适用） | 节点达成/滞后 |
| 3 | 资本配置效率（ROIC/再投资回报率） | 提升/下降 |
| 4 | 治理结构变化（高管/股权） | 稳定/动荡 |
| 5 | 地缘政治风险变化 | 升级/缓和 |
| 6 | 侧面验证（产品/客户/渠道） | 正向/负向 |
| 7 | 综合评分更新（PEG/管理层/科研） | 分数变化 |

## 五、输出精读报告（景气投资版）

### 报告结构

```markdown
# [公司名] [期间] 财报精读（景气投资版）

## 一、核心数据速览（景气三要素表格）
## 二、本期最重要的 3 个景气变化（不超过 500 字）
## 三、ROE 趋势与二阶导判断
## 四、管理层语气与承诺追踪
## 五、附注中的景气信号（科研转化/管理层四维度）
## 六、PEG 估值定位与操作建议（引用 valuation-thermometer）
## 七、地缘政治风险更新
## 八、仓位管理状态（底仓/机动仓）
## 九、假如空仓测试
## 十、卖出纪律更新（P0~P5 检查表，引用 exit-signal）
## 十一、季度复盘检查清单（7 项必查）
## 十二、结论：景气逻辑是否成立，卖出纪律是否触发，操作建议
```

### 结论必须明确回答

1. **ROE 趋势如何？** 上升 / 持平 / 拐头向下 → 对景气逻辑的影响。
2. **二阶导（增速加速度）如何？** 正 / 负 / 持平 → 对估值中枢的影响。
3. **PEG 处于哪一档？** （引用 `valuation-thermometer`）结合渗透率位置（郑希判断）交叉比对。
4. **卖出纪律触发了吗？** 引用 `exit-signal` P0~P5 检查结果。
5. **操作建议**：持有 / 加仓 / 减仓 / 清仓，底仓/机动仓分层说明。

## 七、数据抽检（准出流程）

- 不要使用 `2>/dev/null` 重定向 stderr，应使用 `2>$null`（PowerShell）

- 如需提取 JSON 输出，可直接使用 `--output-json` 参数，无需通过 shell 管道处理

## 注意事项

1. **读原文，不读摘要**：尽一切可能获取一手资料，避免依赖二手信息
2. **看变化，不看绝对值**：趋势比数字本身重要，景气投资尤其关注增速变化
3. **听语气，不只听内容**：管理层怎么说和说了什么一样重要，警惕语气从「清晰」转向「模糊」
4. **查附注，不只看正文**：魔鬼藏在细节里——研发资本化率、关联交易、或有负债
5. **给结论，不做汇总**：精读的目的是形成判断，不是复述财报
6. **数据验证**：关键数据必须至少来自两个独立来源，误差 >1% 须标记
7. **客观分析**：严格区分「事实」与「观点」，不预设立场
8. **呈现两面**：每个核心判断都必须附带反面论据
9. **网络搜索时效性**：使用 `--time-range month/week` 限制时间范围，优先获取最新信息
10. **非境内上市双源验证**：港股/美股须按市场双源验证（港股 doubao+tavily；美股 exa+doubao）
11. **每季必答核心问题**：景气逻辑是否成立？卖出纪律是否触发？——这两个问题不能回避
12. **轻量版定位**：本技能为单 Agent 快速精读，如需深度团队分析请使用 `mid-earnings-team`
13. **引用不重复定义**：估值档位引用 `valuation-thermometer`，卖出纪律引用 `exit-signal`（P0~P5），产业景气/渗透率引用 `mid-industry-research`，季度加速度引用 `qoq-accelerator`，管理层/科研转化 20 分制引用 `mid-management-deep-dive`
14. **止损纪律优先**：当 PEG「便宜」与 P0/P1 止损信号冲突时，止损优先于估值
15. **假如空仓测试**：每次输出报告结论前，必须完成此测试，克服沉没成本
16. **中期口径红线**：禁止使用「护城河永续」「终局思维」「持有10年」等长期框架术语，持有周期以「景气周期长度」为准

## 局限性

1. **资料可得性**：部分公司的完整财报原文可能难以获取，导致评级为 B 或 C 级
2. **语言限制**：非中英文财报可能无法准确解读
3. **非实时数据**：工具获取的数据可能有延迟，不是实时数据
4. **AI 解读局限**：AI 无法完全替代专业财务分析师的深度分析能力
5. **不构成投资建议**：本技能仅用于学习与研究，不构成任何投资建议
6. **景气判断不确定性**：ROE 趋势和二阶导是滞后指标，可能无法提前捕捉拐点
7. **渗透率数据获取**：行业渗透率数据依赖第三方估算，可能存在偏差，按 A/B/C 三级置信度标注
8. **地缘政治不可预测**：制裁、关税等黑天鹅事件无法通过框架完全规避

```markdown
# 腾讯 2025Q4 财报精读（景气投资版）

## 一、核心数据速览（景气三要素）

| 指标 | 本期 | 上季 | 去年同期 | 趋势判断 |
|------|------|------|---------|----------|
| ROE（TTM） | 21.4% | 21.5% | 19.2% | →（持平，连续8季上升后首次持平） |
| 营收增速（YoY） | 11% | 13% | 15% | ↓（连续2季度放缓） |
| 净利润增速（YoY） | 14% | 16% | 18% | ↓（连续2季度放缓） |
| 增速二阶导 | -2pp | -2pp | — | **负二阶导持续** |

> ⚠️ **郑希式预警**：ROE 连续8季度上升后首次持平，营收增速连续2季度放缓。景气逻辑从「强化」变为「部分验证」。需重点关注下季数据。

## 二、本期最重要的 3 个景气变化

1. **ROE 增速放缓**：21.5%→21.4%，首次持平——黄灯，不是红灯
2. **二阶导连续 2 季度为负**：营收增速 15%→13%→11%——估值收缩信号
3. **AI 相关收入占比突破 15%**：进入渗透率黄金加速区间——加分项

## 三、ROE 趋势与二阶导判断

- ROE 趋势：持平（警惕，但非拐点）
- 二阶导：连续 2 季度为负（估值收缩信号）
- 估值中枢影响：若二阶导持续为负，市场可能给予更低 PEG 倍数

## 四、管理层语气与承诺追踪

- 语气信号：管理层对 AI 收入增长表述「清晰」（有量化目标），但对广告增速表述「模糊」
- 承诺追踪：上季承诺「广告增速恢复15%」，实际仅 11%——❌ 未达标

## 五、附注中的景气信号

- 研发费用率：12%（稳定），资本化率：18%（审慎）
- 新产品收入占比：15%（上升中，未达 20% 优秀线）
- 管理层诚信：承诺兑现率 75%（⚠️ 部分达标）

## 六、PEG 估值定位与操作建议（引用 valuation-thermometer）

- 当前 PEG 档位：合理区间上沿（档位判定以 `/valuation-thermometer` 输出为准）
- 渗透率位置：AI 应用渗透率约 15%（成长期，标准估值体系）
- 操作建议：处于合理区间上沿，机动仓可减持 1/3

## 七、地缘政治风险更新

- 海外收入占比：35%（稳定）
- 供应链安全：核心 AI 芯片依赖海外（⚠️ 关注国产替代进展）
- 制裁风险：低（未被列入实体清单）

## 八、仓位管理状态

- 底仓：65%（未动）
- 机动仓：35% → 建议减持至 20%（估值偏贵 + 二阶导为负）

## 九、假如空仓测试

- 如果现在空仓，会以当前价格买入吗？——**犹豫不决**
- 原因：估值合理但二阶导为负，需等待下季 ROE 确认
- 操作：减仓至观察仓（底仓保留 20%），等待更清晰信号

## 十、卖出纪律更新（P0~P5 检查表，引用 exit-signal）

| 级别 | 是否触发 | 建议动作 |
|--------|---------|----------|
| P0 治理一票否决 | ❌ | — |
| P1 硬止损 | ❌ | 当前距买入价 +12%，未触发 |
| P2 逻辑止损（含时间止损） | ⚠️ | 广告增速未达标，进入观察 |
| P3 产业景气拐点 | ⚠️ | ROE 持平是黄灯，下季若再降则触发 |
| P4 估值透支 | ❌ | 处于合理区间上沿，未透支 |
| P5 性价比替换 | ❌ | 第 3 季度持有中 |

**更新后止损位**：
- 当前股价：380 港元
- 硬止损位（8%）：349.6 港元
- 硬止损位（10%）：342 港元

## 十一、季度复盘检查清单（7 项必查）

| 序号 | 检查项 | 本期结论 |
|------|--------|---------|
| 1 | 管理层承诺兑现情况 | ⚠️ 部分达标（75%） |
| 2 | 科研转化进展 | 新产品收入占比 15%（上升中） |
| 3 | 资本配置效率 | ROIC 18%（>WACC，健康） |
| 4 | 治理结构变化 | 稳定 |
| 5 | 地缘政治风险变化 | 缓和 |
| 6 | 侧面验证 | 用户增长稳健 |
| 7 | 综合评分更新 | PEG 合理上沿/管理层75%/科研转化60% |

## 十二、结论

- **ROE 趋势**：持平（警惕，但非拐点）
- **二阶导**：连续 2 季度为负（估值收缩信号）
- **PEG 档位**：合理区间上沿（引用 `valuation-thermometer`）
- **卖出纪律**：P2/P3 进入观察区，下季财报决定性
- **假如空仓**：犹豫不决 → 减仓至观察仓
- **操作建议**：减持机动仓至 20%，保留底仓 65%，等待下季 ROE 数据确认趋势。若下季 ROE 继续下降，触发 P3 减机动仓。
```

### 买入前检查清单

- [ ] 产业空间 ≥1000 亿，渗透率 10%~30%
- [ ] 营收 ≥10 亿，ROE 有向上趋势，现金流为正

- [ ] 管理层诚信通过（年报验证 + 承诺兑现率 ≥80%）
- [ ] 科研转化评分 ≥15 分（如适用，口径引用 `mid-management-deep-dive`）
- [ ] 地缘政治风险可控（海外收入占比、供应链安全）
- [ ] 「假如空仓」测试通过（会买）

### 持有中季度检查清单（7 项必查）

- [ ] 管理层承诺兑现情况
- [ ] 科研转化进展（如适用）
- [ ] 资本配置效率（ROIC/再投资回报率）
- [ ] 治理结构变化
- [ ] 地缘政治风险变化
- [ ] 侧面验证（产品/客户/渠道）
- [ ] 综合评分更新（PEG/管理层/科研转化）

### 卖出触发条件（引用 `exit-signal` P0~P5，本卡仅列级别名，阈值以 exit-signal 为准）

- P0 治理一票否决 → 立即清仓
- P1 硬止损（8%~10%）→ 无条件离场
- P2 逻辑止损（含时间止损）→ 减仓或清仓
- P3 产业景气拐点 → 减机动仓
- P4 估值透支 → 减/清机动仓
- P5 性价比替换 → 调仓

**核心原则**：先保命（止损/防造假），再谈收益（景气/估值）。欧奈尔的止损 > 林奇的逆向加仓。
