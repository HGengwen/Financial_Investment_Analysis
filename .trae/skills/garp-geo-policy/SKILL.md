# GARP 第0步前置：地缘政治与政策资本判定（1~5 年独立档）

对 $ARGUMENTS 执行《中长期价值成长（GARP）投资框架》**第0步**（0.1 / 0.2 / 0.3）与**第1步国产化率四档**的前置判定，回答一个问题：

> **这个赛道/环节，值不值得进入后续细研？国产替代的确定性下限与可行性分别如何？**

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。** 本技能的档位判定、矩阵行、国产化率档位**一律由工具产出**，禁止 LLM 心算；本技能只做**赛道级前置闸门**，不做个股级细研、不做估值、不做宏观校准。

> 💬 **郑希式提醒**："第一性原理问的是——这个环节为什么会被'卡'？卡住它的外部力量还能持续多久？答案决定了替代的确定性下限，而不是股价的想象空间。"

> 💬 **费雪式提醒**："好公司要拿得住，前提是它所在的赛道先要活得下去。第0步就是筛掉'活得下去但有条件'与'根本活不下去'的那两类。"

## 设计理念

GARP 框架把地缘政治与政策资本放在**第0步**（而非背景噪声），核心逻辑是两条：

1. **地缘政治倒逼决定国产替代的「确定性下限」**——被制裁/断供的环节，下游客户没有选择，国产导入是生存刚需；
2. **政策与国字号基金支持决定「国产企业能不能接得住」**——政策覆盖 + 基金介入回答可行性问题。

二者缺一，赛道就走不通：

- **只有倒逼、没有政策资本**（政策覆盖低/无 + 基金无覆盖）→ 下游被迫替代，但国产短期接不住 → 高风险或直接回避；
- **只有政策资本、没有地缘倒逼**（低倒逼 + 政策/基金高）→ 政策创造需求的「增量创造」赛道，仍可投，但达标与否交由支柱五（政策与资本覆盖度）判定。

**分层分工（框架原文，防维度拆分歧义）**：本技能是**赛道级前置闸门**（粗筛排除）；地缘个股级打分属支柱四、政策资本个股级打分属支柱五——前者粗筛排除，后者细研定档，不得越界互换。

### 本技能的三条硬纪律

| # | 纪律 | 原因 |
| --- | --- | --- |
| 1 | **工具判定，禁止心算** | 0.3 矩阵六行与国产化率四档是**确定性规则**，交 `geo_policy_screen.py` 执行，任何"我判断应为第 X 行"的推导均属违规 |
| 2 | **时变项必须标数据截止日期** | 制裁清单、政策文本、基金名录、国产化率数值均随环境变化，档位不是永久结论 |
| 3 | **未列组合不解释性放行** | 框架明示：未显式列出的组合一律按更审慎的相邻档归档，工具已给 `archived` / `archive_from`，本技能只透传，不得自行"讲道理"放行 |

## 执行流程（六步）

### 第一步：确认参数与数据基准

先运行 `date` 确认当天日期，作为「数据截止日期」基准（全局规则 1）。

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `{行业/公司}` | 目标对象，**行业优先**；填公司时先定位其所属赛道/环节（见下） | **必填** |
| `--depth` | `standard`（含 `scan` 实时检索核验 + 搜索五工具）/ `fast`（跳过实时检索，仅用用户提供档位或既有缓存） | `standard` |
| `--geo` / `--policy` / `--fund` | 用户已判定的三维档位，填则**跳过第二、三步**直接进第四步（`scan` 全失败时的降级通道） | 无 |
| `--localization-rate` | 国产化率百分数（0~100，科技赛道可选），填则直接进第五步 | 无 |
| `--strategic-choke-point` | 战略卡脖子环节标记，**仅用户显式指定**时透传（不由 AI 自行拔高） | 关闭 |

**「公司」输入的定位规则（强制）**：填公司时，**先将公司定位到所属赛道/环节**（依据主营构成、招股书/年报行业章节、券商研报），再按该赛道做第0步前置判定，并在报告中显式写出「公司 → 赛道/环节」的定位依据。**不做**个股级支柱四/五细研（转下游技能）。

参数确认后，向用户澄清（如未在 $ARGUMENTS 中给出）：目标对象是行业还是公司、是否有已知的国产化率数值、是否需要完整实时检索。**不要默默假设**。

### 第二步：0.1 地缘倒逼强度判定

**先做检索纪律（框架原文要求）**：检索「该行业当前是否已被卷入地缘政治冲突 / 制裁清单 / 出口管制」，**不得默认"清单外行业就无风险"**——逆全球化是扩散性长期变量，风险行业边界持续外扩。

```bash
# scan 子命令须以 -m 模块形式调用（脚本形式会因 tools 包不在 sys.path 而报 ModuleNotFoundError）
python -m tools.specialized.geo_policy_screen scan --industry {行业}
```

判定路径（三层递进，逐层留证据）：

| 层 | 检查内容 | 权威位置 |
| --- | --- | --- |
| ① 底座 | 四类逆全球化信号对目标行业的**渗透强度**：贸易壁垒常态化 / 产业链区域化·本土化 / 技术脱钩 / 资本与数据流动收紧 | 框架 0.1 |
| ② 形态 | 定位标的**具体暴露在哪条传导链**：技术·大国竞争对抗 / 国家·经济民族主义 / 地区冲突与战争（禁止笼统写"有地缘风险"） | 框架 0.1 |
| ③ 强度 | 四项评估逐项给依据：制裁/管制覆盖度、断供现实性（已实际中断 vs 仅有隐忧）、政策强制力（是否有强制国产占比要求）、制裁可持续性（立法级 vs 行政级） | 框架 0.1 |

**输出**：`--geo` 档位（高 = 已制裁/断供；中 = 制裁升级中；低 = 未覆盖、以市场驱动为主）+ 四项评估逐项依据 + 数据截止日期。

---

### 第三步：0.2 政策与国字号基金支持强度判定

**评估的核心不是"记住某一期基金名单"，而是掌握判断"政策资本力度"的方法**（框架原文）。按三层面逐层核验：

| 层面 | 核验内容 | 产出 |
| --- | --- | --- |
| ① 规划与政策 | 最新五年规划/专项政策是否以「超常规」「全链条」「决定性突破」等强干预强度词汇覆盖；是否含强制采购比例、部委协同攻关、应用场景强制开放；财税配套（税收减免 / 研发费加计扣除 / 首台套保险补偿） | `--policy`（高/中/低） |
| ② 基金与资本 | 是否有国家/地方产业基金**直接注资**或设立**专项子基金**；注资额度与占比（基金总规模、单项目投资额、占项目总投资比）；是否有央企/产业资本形成「资本+场景」绑定 | `--fund`（四档：有直接注资 / 有专项子基金 / 有覆盖 / 无覆盖） |
| ③ 时效核验 | 更新「基金名称、规模、投向」实时数据，剔除已到期/已转向/规模缩水基金，补充新设立基金 | 强制以实时检索为准 |

```bash
python -m tools.specialized.geo_policy_screen scan --fund {行业/领域/基金名}
# 两个维度可同时检索
python -m tools.specialized.geo_policy_screen scan --industry {行业} --fund {行业}
```

**政策基金三层架构（框架 0.2 示例格式）**：仅在 `--depth standard` 且基金维度检索有结果时输出，按「第一层 / 第二层 / 第三层 / 专项子基金」四行呈现（示例：国家人工智能产业投资基金 / 大基金三期 / 国家制造业转型升级基金 / 工业母机产业投资基金）。

> **强制免责声明（框架原文）**：三层架构为某一历史时点的**格式示范，非当前事实**；必须原样保留「示例」标注，并标注数据截止日期，最终以实时检索为准。

**输出**：`--policy` 档位 + `--fund` 档位 + 三层面逐层依据 + （可选）三层架构示例表 + 数据截止日期。

### 第四步：0.3 三维交叉矩阵综合判定（工具调用，禁止心算）

```bash
python tools/specialized/geo_policy_screen.py screen \
  --geo {高|中|低} --policy {高|中|低} \
  --fund {有直接注资|有专项子基金|有覆盖|无覆盖} \
  --as-of {YYYY-MM-DD} --basis "{档位判定依据：scan 检索结果 + 政策/基金公告，含来源}"
```

**读回字段与处置**：

| 字段 | 处置 |
| --- | --- |
| `row_index` / `matrix_row` | 矩阵行号与场景名（最优场景 / 次优场景 / 潜伏场景 / 高风险/回避 / 政策驱动型增量创造 / 回避），**原样引用** |
| `conclusion` | 投资含义全文，**原样引用** |
| `track_type` | 赛道两分法结果（地缘倒逼型 / 政策资本驱动型 / 回避） |
| `archived` / `archive_from` | `true` 时必须**显式标注归档**并展示原组合，**不做解释性放行** |
| `risk_note` | 原样透传：国字号基金注资是「政策优先序列」信号，**非买入估值依据**，最终决策回到估值与业绩兑现框架 |
| `time_sensitivity_note` | 原样透传：档位为时变输入，结论仅对档位判定时点有效，须以最新数据复核 |

**赛道两分法的落地（转出对支柱四的门槛要求）**：

| `track_type` | 对支柱四（地缘政治与外部环境）的门槛 |
| --- | --- |
| **地缘倒逼型** | **硬门槛**：地缘倒逼强度非「低/无」方可建仓；同时以支柱五验证政策资本能否接住 |
| **政策资本驱动型** | **仅敞口体检**：海外收入 / 供应链 / 地区冲突暴露可控即可，达标与否交支柱五判定 |
| **回避** | 不进入下游，直接终止 |

**前置闸门三档结论映射（本技能收口口径）**：

| 矩阵行 | 前置结论 | 处置 |
| --- | --- | --- |
| 1 最优场景 / 2 次优场景 | **放行** | 进入下游细研 |
| 3 潜伏场景 | **观察** | 制裁尚未落地但概率高 → 提前布局等待催化，不建仓，纳入跟踪 |
| 4 高风险/回避 | **回避（一票否决）** | 政策+资本两维同时失守；另附「须先验证国产承接能力」的重估路径 |
| 5 政策驱动型增量创造 | **放行** | 不以地缘倒逼为门槛，达标与否交支柱五 |
| 6 回避 | **回避（一票否决）** | 政策+资本两维同时失守，纯市场驱动不确定性过高 |

> 行 4 与行 6 的共同特征是**政策覆盖度低/无 且 国字号基金无覆盖**（政策与资本两维同时失守），框架明示此时无论地缘倒逼高低均一票回避：地缘「高」时因国产接不住而回避，地缘「低」时因纯市场驱动而回避。

| 项 | 值 |

## 注意事项

1. **先检索、后判定**——不得因"该行业看起来不像地缘敏感行业"就跳过检索；风险行业边界持续外扩。
2. **四信号 / 三形态 / 四评估不是打分表**——它们是**检查项**，输出的是逐项依据与档位结论，不产出"地缘风险得分"。
3. **禁止心算矩阵行与国产化率档位**——一律调用工具；用户直填档位（`--geo/--policy/--fund`）时须在报告中注明「档位由用户提供，未做实时核验」。
4. **禁止解释性放行归档组合**——`archived=true` 时原样呈现归档目标与 `archive_from`，不做"实际上应该更好"的补充判断。
5. **数据截止日期是必填项**——缺失即视为报告不合格；非交易日不影响档位判定，但影响检索时效，须如实标注。
6. **`degraded=true` 必须如实标注**——降级不等于可以下结论，须写明降级原因与替代来源，并提示用户以实时检索复核。
7. **政策基金三层架构仅作格式示范**——必须保留「示例」标注与免责声明，禁止表述为"当前基金布局"。
8. **公司输入先定位赛道**——不定位到具体赛道/环节不得判定；定位依据须可追溯。
9. **不越界到个股/估值/宏观**——第0步是前置闸门，越界会让下游技能职责重叠。
10. **不替用户做决策**——给出前置结论与转接指引，买卖决策由用户判断。
11. **独立档术语纪律**——本技能所有风控与卖出口径一律指向 `garp-exit`（GARP 五级卖出），不得使用中期链或长期链的卖出体系与地缘评估框架术语。

## 局限性

1. **档位判定的时变性**：制裁清单、政策文本、基金名录、国产化率数值均随环境变化，结论仅对数据截止日期有效。
2. **`scan` 检索的可得性**：搜索接口在受限网络下可能不稳定，实时检索失败会触发缓存回退或降级（`degraded=true`），此时结论置信度下降。
3. **政策文本的强度判定主观性**：判断"超常规""全链条"等强干预强度词汇是否命中目标领域，仍需人工阅读文本，本技能只提供检查项不提供自动判定。
4. **基金数据的不透明**：部分国家/地方产业基金的注资额度与占比不公开披露，`--fund` 档位可能只能到「有覆盖」而无法确定是否「有直接注资」。
5. **国产化率数据的分歧**：细分环节国产化率缺乏官方统计，不同第三方口径可相差较大；本技能只做**数值→档位**的确定性判定，不对数值本身背书。
6. **赛道级颗粒度**：同一赛道内不同环节的地缘倒逼与国产化率差异极大（如半导体设备内部第一梯队与第三梯队），赛道级结论不得直接套用到个别环节。
7. **不能替代个股基本面**：第0步只回答"赛道值不值得看"，公司的盈利质量、治理与估值仍需下游技能独立验证。
8. **不构成投资建议**：本技能仅用于研究框架的前置判定，不构成任何投资建议。
