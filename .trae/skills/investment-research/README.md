# 投资研究 (Investment Research)

巴菲特-芒格-段永平-李录 四大师综合分析框架：系统化深度研究单家公司

---

## 快速开始

### 基本调用方式

```
/investment-research {公司名}
```

例如：
- `/investment-research 腾讯`
- `/investment-research 紫金矿业`
- `/investment-research 苹果`

---

## 核心功能

对指定公司进行系统化投资研究分析，整合四位投资大师的方法论，从生意本质、护城河、管理层、风险、估值等多维度深度研究，产出完整投资研究报告。

### 四大师方法论

| 大师 | 核心视角 | 关注重点 |
|------|---------|---------|
| 巴菲特 | 经济护城河、管理层诚信、内在价值 | 护城河宽度、安全边际 |
| 芒格 | 逆向思考、风险清单、多学科视角 | 失败路径、偏误自查 |
| 段永平 | 对的生意、对的人、对的价格 | 生意本质、管理层 |
| 李录 | 文明演进框架、技术范式转移 | 行业终局、价值链位置 |

### 八步研究框架

**前置**：AI研究偏见自觉 — 信息丰富度评级 A/B/C + 偏见自查清单

1. **数据收集** — 10项数据+强制交叉验证（使用 `financial_rigor.py` 杜绝心算）
2. **生意本质分析** — 段永平"对的生意"
3. **护城河评估** — 巴菲特"经济护城河"五类验证
4. **逆向思考与风险清单** — 芒格"反过来想"+失败路径+历史类比
5. **管理层评估** — 段永平"对的人"+巴菲特"管理层诚信"
6. **行业与文明趋势** — 李录"文明演进框架"+TAM分析
7. **估值与安全边际** — 巴菲特"内在价值"+段永平"对的价格"+三情景估值
8. **综合决策备忘录** — 六维度汇总表+四大师模拟点评

## 输出报告

报告将保存在以下位置：

| 报告类型 | 文件路径 |
|---------|---------|
| 投资研究报告 | `reports/{公司名}/{公司名}-research-{YYYYMMDD}.md` |

### 报告要求

1. 所有分析必须有数据支撑，附数据来源
2. 使用 Markdown 表格呈现关键数据
3. 每个模块末尾必须有对应大师的"追问"
4. 结论要明确，不回避给出买入/观望/回避的建议
5. 估值部分必须给出具体的价格区间
6. **报告开头**必须包含"信息丰富度评级"（A/B/C）和"AI研究局限性声明"
7. **报告结尾**必须区分"AI分析置信度"与"投资确定性"
8. C级公司（信息稀缺）必须列出"需要一手验证的问题清单"

## 研究标准

### AI研究偏见自觉（必须执行）

**信息丰富度评级**：

| 等级 | 特征 | AI研究陷阱 | 应对策略 |
|------|------|-----------|---------|
| A级（信息充裕） | 上市多年、覆盖密集 | 共识过强，alpha有限 | 重点做反面检验 |
| B级（信息适中） | 上市1-3年、覆盖有限 | 用"合理推测"填补空白 | 每个推算数据标注置信度 |
| C级（信息稀缺） | 刚上市/冷门股/新兴市场 | 因资料不足过度保守 | 用第一性原理提问 |

**偏见自查清单**：
- 确定性感受是来自生意本质，还是来自资料数量？
- 如果资料量减少一半，结论会变吗？
- AI输出是否与市场共识高度雷同？
- 是否存在"公开资料很少但生意本质极好"的可能性被低估？

### 数据交叉验证（强制执行，使用工具）

**必须验证的数据点**：
- 总股本（至少2个源确认）
- 当前股价和市值（**手动计算 股价×总股本 并与报告市值对比**）
- 最近财年收入和净利润
- 现金储备和净现金
- 管理层持股比例（区分经济权益和投票权）

**验证规则**：
1. 每个关键数据点至少2个独立来源
2. 发现差异时优先采用公司年报/交易所数据
3. **所有涉及计算的数据必须通过工具验算，禁止LLM心算**
4. 工具输出结果嵌入报告附录"关键数据交叉验证记录"
5. 工具报告❌偏差过大时，必须排查原因后才能继续分析

### 数据抽检（准出流程）

报告写入后必须执行抽检，通过方可发布：

```bash
# Step 1 — 提取抽检清单（15%随机抽样）
python tools/common/report_audit.py extract --report <报告文件路径>

# Step 2 — 取数核验（按 financial-data 技能规范）

# Step 3 — 输出判决
python tools/common/report_audit.py verdict \
  --results '<填好的JSON>' --report <报告文件名>
```

- **【准出】**：所有抽检点偏差 ≤ 1% → 报告可发布
- **【打回】**：任意点偏差 > 1% → 修正后重新抽检

### 精确计算与审核

| 工具 | 功能 |
|------|------|
| `tools/common/financial_rigor.py` | 精确金融计算（PE、ROE、市值验证、三情景估值） |
| `tools/common/report_audit.py` | 报告数据抽检与审核 |

**关键计算命令**：

```bash
# 市值验算
python tools/common/financial_rigor.py verify-market-cap \
  --price {股价} --shares {总股本} --reported {报告市值} --currency {币种}

# 关键数据交叉验证
python tools/common/financial_rigor.py cross-validate \
  --field {字段名} --values '{"来源1": 数值, "来源2": 数值}' --unit {单位}

# 估值指标验算
python tools/common/financial_rigor.py verify-valuation \
  --price {股价} --eps {EPS} --bvps {每股净资产} --fcf-per-share {每股FCF}

# 三情景估值模型
python tools/common/financial_rigor.py three-scenario \
  --price {股价} --eps {EPS} --shares {总股本亿} \
  --growth {乐观} {中性} {悲观} --pe {乐观PE} {中性PE} {悲观PE}

# 获取实时汇率（跨币种折算前必用，勿用固定汇率）
python tools/common/fx_rate.py --code USDCNY,HKDCNY
```

## 核心原则

1. **数据必须标注来源** — 关键数据至少2个来源交叉验证，误差>1%须标记
2. **禁止LLM心算** — 所有涉及计算的数据必须通过 `financial_rigor.py` 工具验算
3. **不虚构数据** — 搜不到就标注"估计"或"数据不足"
4. **客观性原则** — 区分事实与观点，用数据支撑判断
5. **呈现两面** — 每个核心判断附反面论据
6. **诚实面对信息缺口** — 区分"AI分析置信度"与"投资确定性"
7. **AI偏见自觉** — 警惕共识陷阱、合理推测填充、资料少≠看不懂
8. **不预设立场** — 先摆数据→推逻辑→出结论

---

## 注意事项

- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- 关键财务数据必须至少来自两个独立来源进行交叉验证
- 所有估计值必须明确标注"估计"
- 市值必须手算校验：股价 × 总股本，与报告市值对比
- 货币单位要明确（港币/人民币/美元），防止混淆
- PE/ROE/估值等指标用 `tools/common/financial_rigor.py` 精确计算，禁止心算
- 报告开头必须包含信息丰富度评级和AI研究局限性声明
- 报告结尾必须区分AI分析置信度与投资确定性
- C级公司必须列出"需要一手验证的问题清单"
- 报告发布前必须通过 `tools/common/report_audit.py` 数据抽检（准出流程）

## 局限性说明

- **网络限制**：WebSearch/WebFetch 在中国大陆不可用，美股数据需通过浏览器手动获取
- **数据源覆盖**：本地工具主要覆盖A股和港股，美股数据源较少
- **实时性**：本地工具数据可能滞后1-2天，最新财报建议查原始来源
- **港股接口稳定性**：东方财富港股接口在中国大陆网络连接不稳定（已内置重试机制）
- **AI偏见**：AI分析可能受训练数据影响，需通过偏见自查清单校验
- **一手验证**：C级公司（信息稀缺）需通过田野调查、产品体验等方式补充AI盲区
- 不构成投资建议，仅供学习研究参考
