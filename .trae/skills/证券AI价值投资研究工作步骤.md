## 一、技能全景图

本项目共 21 个技能，按功能分为七大类：

### 1. 行业研究类

| 技能           | 命令                            | 核心功能                                                |
| -------------- | ------------------------------- | ------------------------------------------------------- |
| 行业投资研究   | `/industry-research {行业名}` | 产业链全景扫描 + 四大师个股分析，首次研究一个行业时使用 |
| 行业漏斗筛选   | `/industry-funnel {行业名}`   | 从全市场 30-60 家逐层精选到 3 家终选标的                |
| 供应链瓶颈猎手 | `/bottleneck-hunter {趋势名}` | 从超级趋势的供应链"咽喉位置"挖掘第二、第三层投资机会    |

### 2. 公司深度研究类

| 技能               | 命令                               | 核心功能                                               |
| ------------------ | ---------------------------------- | ------------------------------------------------------ |
| 投资研究（快速版） | `/investment-research {公司名}`  | 单 Agent 四大师综合分析框架，快速产出研究报告          |
| 投研团队（深度版） | `/investment-team {公司名}`      | 四 Agent 并行研究 + Team Lead 综合研判，产出系统化报告 |
| 深度公司系列       | `/deep-company-series {公司名}`  | 8 篇长文（约 12 万字）拆一家公司，适合公众号发布       |
| 管理层纵深研究     | `/management-deep-dive {公司名}` | 深度评估管理层诚信度、战略执行、资本配置、治理结构     |

### 3. 买入决策类

| 技能         | 命令                                 | 核心功能                                             |
| ------------ | ------------------------------------ | ---------------------------------------------------- |
| 去劣筛选     | `/quality-screen {公司/行业/指数}` | 7 条硬指标 + 3 条豁免规则，快速排除非一流公司        |
| 投资检查清单 | `/investment-checklist {公司名}`   | 巴菲特六关 Checklist + 镜子测试 + 8 条红线否决       |
| 收入投资分析 | `/income-investment {公司名}`      | 分红持久性、现金流覆盖、收益陷阱识别、收入型组合适配 |

### 4. 财报跟踪类

| 技能               | 命令                                 | 核心功能                                             |
| ------------------ | ------------------------------------ | ---------------------------------------------------- |
| 财报精读（快速版） | `/earnings-review {公司名} {期间}` | 单 Agent 八步精读流程，从一手资料深度解读财报        |
| 财报精读团队       | `/earnings-team {公司名} {期间}`   | 四大师并行解读 + 编辑润色 + 读者评审，产出可发布文章 |

### 5. 持仓管理类

| 技能         | 命令                             | 核心功能                                         |
| ------------ | -------------------------------- | ------------------------------------------------ |
| 投资论文追踪 | `/thesis-tracker {公司名}`     | 建立投资论文 + 季度检查论文健康度，持有纪律系统  |
| 论文漂移检测 | `/thesis-drift {公司名}`       | 对比新旧报告，基于证据判定论文是否漂移           |
| 组合管理     | `/portfolio-review {持仓清单}` | 组合集中度、相关性、机会成本、压力测试四维度分析 |
| 公司新闻脉搏 | `/news-pulse {公司名}`         | 股价异动时 10-15 分钟快速归因                    |

### 6. 基础工具与内容输出类

| 技能           | 命令                          | 核心功能                                                               |

### 阶段一：行业扫描

**目标**：从行业层面建立投资机会池，看清产业链格局。

**推荐流程**：

1. 运行 `/industry-research {行业名}`，产出产业链全景图和四大师个股分析
2. 如需从全市场精选标的，接着运行 `/industry-funnel {行业名}`，逐层精选到 3 家
3. 如关注供应链瓶颈套利，运行 `/bottleneck-hunter {趋势名}`，挖掘第二、第三层机会

**技能选用建议**：

- 首次接触新行业 → 先用 `industry-research` 看清格局
- 已有行业认知、想找具体标的 → 直接用 `industry-funnel`
- 关注超级趋势（AI 基础设施、能源转型等）的供应链套利 → 用 `bottleneck-hunter`

### 阶段二：快速筛选

**目标**：用硬指标快速排除非一流公司，缩小研究范围。

**推荐流程**：

1. 运行 `/quality-screen {公司名/行业/指数}`，7 条指标筛选
2. 通过筛选的公司进入深度研究阶段

**技能选用建议**：

- 有多只候选标的 → 用 `quality-screen` 批量筛选
- 已锁定 1-3 家公司 → 跳过筛选，直接进入深度研究

### 阶段三：深度研究

**目标**：对通过筛选的公司进行多维度深度分析。

**推荐流程**：

1. 运行 `/investment-team {公司名}`，四 Agent 并行研究
2. 如管理层是核心投资逻辑或评分不确定，追加 `/management-deep-dive {公司名}`
3. 如需产出系列长文，运行 `/deep-company-series {公司名}`

**技能选用建议**：

- 快速产出报告 → 用 `investment-research`（单 Agent）
- 深度多视角分析 → 用 `investment-team`（四 Agent 并行）
- 管理层是核心逻辑 → 追加 `management-deep-dive`
- 需要可发布的长文系列 → 用 `deep-company-series`

### 阶段四：买入决策

**目标**：系统过一遍买入前检查，排除坏选择。

**推荐流程**：

1. 运行 `/investment-checklist {公司名}`，六关 Checklist + 镜子测试
2. 通过 Checklist 后，建立投资论文（见阶段五）
3. 如关注收入/分红维度，运行 `/income-investment {公司名}`，评估分红持久性与收益陷阱风险

**技能选用建议**：

- 买入前最后检查 → 用 `investment-checklist`（不可跳过）
- 多只候选标的对比 → `/investment-checklist 腾讯, 美团, 拼多多`（支持多公司对比）
- 高股息率标的验证 → 用 `income-investment` 识别收益陷阱，评估分红覆盖与持久性
- 已有收入持仓再评估 → 用 `income-investment mode=existing` 评估是否仍适合作为收入核心

### 阶段五：建仓后持续跟踪

**目标**：建立买入论文，持续追踪论文健康度。

**推荐流程**：

1. 建仓后立即运行 `/thesis-tracker {公司名}`，建立投资论文（五要素）
2. 每季报发布后运行 `/thesis-tracker {公司名} 季度检查`，检查论文健康度
3. 财报发布后运行 `/earnings-review {公司名} {期间}` 或 `/earnings-team`，精读财报
4. 股价异动时运行 `/news-pulse {公司名}`，快速归因
5. 定期运行 `/thesis-drift {公司名}`，检测论文是否漂移

**技能选用建议**：

- 建仓后第一步 → 用 `thesis-tracker` 建立论文（买入前就写好卖出条件）
- 季度检查 → 用 `thesis-tracker 季度检查` + `earnings-review`
- 股价大跌/大涨 → 用 `news-pulse` 快速归因（10-15 分钟）
- 怀疑论文可能漂移 → 用 `thesis-drift` 对比新旧报告
- 财报需要多视角深度解读 → 用 `earnings-team`（四大师并行 + 公众号文章）

### 阶段六：组合管理

**目标**：从个股研究上升到组合层面管理。

**推荐流程**：

1. 每季度运行 `/portfolio-review {持仓清单}`，审视组合健康度
2. 组合调整后更新各持仓的论文追踪

**技能选用建议**：

- 季度组合复盘 → 用 `portfolio-review`（七步审视 + 四维度分析）
- 单持仓问题深挖 → 用 `investment-team` 或 `management-deep-dive`
- 组合调整决策 → 综合参考 `portfolio-review` 建议 + 各持仓 `thesis-tracker` 健康度

## 四、多技能组合建议

以下是经过验证的高效技能组合方案：

### 组合 1：行业研究 → 精选标的 → 深度研究（完整选股流水线）

```
/industry-research {行业名}        ← 看清产业链格局
        ↓
/industry-funnel {行业名}          ← 漏斗精选到 3 家
        ↓
/quality-screen {3家公司}          ← 7 条指标去劣筛选
        ↓
/investment-team {通过筛选的公司}   ← 四 Agent 深度研究
        ↓
/investment-checklist {公司名}     ← 买入前六关检查
```

**适用场景**：从零开始研究一个行业，系统化筛选到买入决策。

### 组合 2：财报季全套流程

```
/earnings-team {公司名} {期间}     ← 四大师并行精读 + 公众号文章
        ↓
/thesis-tracker {公司名} 季度检查   ← 检查论文健康度
        ↓
/thesis-drift {公司名}             ← 检测论文是否漂移
        ↓
/portfolio-review {持仓清单}       ← 组合层面审视
```

## 六、重点技能详细使用指南

以下七个技能代表了本项目的核心能力，分别覆盖供应链套利、深度内容产出、投资思想参考、数据规范、公众号写作、收入投资、未上市公司研究七大场景。

### 1. 供应链瓶颈猎手 `/bottleneck-hunter`

**定位**：从超级趋势的供应链"咽喉位置"挖掘第二、第三层隐性投资机会。

**何时使用**：

- 关注 AI 基础设施、能源转型、国防现代化、半导体再工业化、太空经济、创新药等超级趋势
- 想找未被市场充分定价的供应链瓶颈公司（而非已涨价的龙头）
- 需要系统化扫描产业链，定位"一旦断货整个行业都得等"的环节

**如何使用**：

```
/bottleneck-hunter {趋势名}
```

示例：`/bottleneck-hunter AI基础设施`、`/bottleneck-hunter 创新药`

**执行流程**（七步）：

1. **超级趋势确认** — 验证持续性、物理性、规模性、加速性四条标准
2. **供应链物理拆解** — 从 Layer 0 终端拆到 Layer 4 基础设施，重点扫描 Layer 2-3
3. **瓶颈识别** — 6 条标准（供给集中度/扩产周期/替代难度/产能利用率/需求增速/客户验证周期）判定 S/A/B 级瓶颈
4. **公司筛选** — 从瓶颈到标的，初筛 + 估值检查（红灯/黄灯/绿灯）+ 深度筛选
5. **交叉验证** — 正向验证（客户/收入/价格/产能/资本）+ 芒格式反向否定
6. **输出瓶颈机会看板** — 排名表 + 一页纸摘要 + 行动建议
7. **存量更新** — 瓶颈地图动态维护，每次运行检查已识别瓶颈是否仍成立

**希望达到的目的**：

- 产出 `reports/bottleneck-map/` 目录下的瓶颈总地图、观察名单、每日扫描报告
- 找到 Layer 2-3 中供给集中度 ≤2 家、扩产周期 >2 年的 S 级瓶颈公司
- 通过估值硬门槛（PS >30x 且增速 <100% 直接红灯）过滤掉"瓶颈真实但估值透支"的陷阱
- 每个机会给出信号强度评级（★1-5）和安全边际检验（10 年 25x PE 退出年化回报）

/deep-company-series {公司名}

示例：`/deep-company-series 腾讯`、`/deep-company-series 紫金矿业`

**8 篇长文结构**：

1. 认知重置 — 推翻市场共识，重新定义这家公司
2. 生意本质 — 一句话讲清赚钱方式
3. 护城河拆解 — 五类护城河逐一验证

### 3. 段永平问答 `/dyp-ask`

**定位**：以段永平投资哲学视角回答投资问题，提供思想参考。

**何时使用**：

- 遇到投资决策困惑，想从段永平"买股票就是买公司"的哲学视角获得参考
- 需要验证一个投资判断是否符合价值投资基本原则
- 想系统化理解段永平的九大核心思想如何应用到具体问题

**如何使用**：

```
/dyp-ask {问题}
```

示例：`/dyp-ask 管理层值不值得托付？`、`/dyp-ask 什么时候该止损？`

**九大核心思想体系**：

1. **本分** — 做对的事情，把事情做对
2. **买股票就是买公司** — 不关注股价短期波动，关注公司长期价值
3. **能力圈** — 不懂的不做
4. **商业模式优先** — 好生意 > 好价格 > 好管理层
5. **长期主义** — 时间是好公司的朋友
6. **集中投资** — 敢于重仓真正看懂的公司
7. **安全边际** — 留足犯错空间
8. **不为清单** — 知道不做什么比知道做什么更重要
9. **理性决策** — 不受市场情绪影响

**希望达到的目的**：

- 以段永平视角回答问题，引用其原话和案例作为支撑
- 区分"事实判断"与"价值判断"，帮助厘清决策思路
- 不直接给出买卖建议，而是提供思考框架，让用户自行决策
- 输出可保存为 `reports/dyp-ask/{问题关键词}-{YYYYMMDD}.md`

### 4. 财务数据规范 `/financial-data`

**定位**：所有涉及企业财务数据研究的基础规范，确保数据准确性。

**何时使用**：

- 任何涉及财务数据的研究（自动内嵌于其他技能中，也可单独调用）
- 需要对关键财务数据进行双源交叉验证
- 需要明确数据误差处理规则、股价复权规范
- 需要下载原始年报 PDF 并提取数据

**如何使用**：

```
/financial-data {公司名或股票代码}
```

示例：`/financial-data 紫金矿业`、`/financial-data 00700`、`/financial-data PDD`

**四步执行流程**：

1. **确认上市地点** — A 股/港股/美股/A+H 股分流
2. **获取财务数据** — 使用对应市场的本地工具
   - A 股：`tools/a_share/stock_financial.py`（主）+ 巨潮资讯年报 PDF（原始一手）
   - 港股：`tools/hk_stock/stock_financial.py`（主）+ aastocks（副）
   - 美股：`tools/us_stock/stock_financial.py`（主）+ macrotrends（副）
3. **误差计算与标记** — 两源对比
   - ≤1%：✅ 一致
   - 1%-5%：⚠️ 标记差异并说明原因
   - > 5%：❌ 重大差异，必须查原始财报核实
     >
4. **数据呈现格式** — 每个关键数据标注两个来源 + 误差率

**原始财报 PDF 获取**（A 股）：

```bash
# 下载年报/半年报/季报 PDF
python tools/common/report_hub.py ensure --code 601899 --report-type annual

# 用 Poppler 工具集提取内容
pdftotext -layout cninfo_reports/601899_2025年报.pdf 601899_2025年报.txt
```

**希望达到的目的**：

- 不生成独立报告，但其规范适用于所有投研技能的财务数据呈现
- 每个关键数据必须有两个独立来源，误差 >1% 须标记
- 原始财报优先：两个来源均与原始财报不符时，以原始财报为准
- 规范股价复权：历史价格分析统一用前复权，不得混用复权口径

### 5. 微信公众号文章 `/wechat-article`

**定位**：作者-编辑-读者三 Agent 协作，产出可直接发布的公众号深度文章。

**何时使用**：

- 需要写一篇公众号深度文章（3000-4000 字）
- 论文解读、技术主题、投资主题等需要兼顾深度与可读性
- 单人写作容易"自嗨"，需要强制引入外部视角

**如何使用**：

```
/wechat-article {主题描述}
```

示例：`/wechat-article 大模型OPD技术解读`、`/wechat-article 为什么巴菲特不买科技股`

**四阶段执行流程**：

1. **研究与素材收集** — 明确文章定位（目标读者/深度/长度/风格），并行启动 2-3 个研究 Agent
2. **作者 Agent 写初稿** — 按详细 Prompt 模板生成完整初稿，含强钩子开头、大白话翻译公式、配图
3. **编辑 + 读者 Agent 并行审阅** — 同一消息中启动两 Agent
   - 编辑：标题/开头/结构/节奏/配图/结尾
   - 读者：前 3 段能否留住、哪里看不懂、是否会转发
4. **定稿** — 综合反馈执行修改，提取配图，产出最终文件

**质量硬要求**：

- 公式必须用 LaTeX 格式（`$...$` 或 `$$...$$`），禁止纯文本
- 论文解读类必须从 PDF 提取高清原图（≥500KB），禁止用 `[图X]` 占位符
- 结尾必须有传播力，值得被单独截图转发
- 禁止 AI 腔调（"让我们一起来看看"、"值得关注的是"等套话）

**希望达到的目的**：

- 产出 `reports/{主题分类}/公众号-{主题关键词}-{YYYYMMDD}.md`
- 同时满足三个维度：深度（作者负责）、可读性（编辑负责）、真的能看懂（读者负责）
- 配图资源保存在 `assets/{主题简称}/` 目录
- 文件末尾附论文原文和参考资料链接

### 6. 收入投资分析 `/income-investment`

**定位**：评估公司是否能够产生足够持久且有吸引力的可分配收入，判断其适合长期收入核心持仓还是机会型收益仓位。

**何时使用**：

- 看到高股息率标的，需要验证分红可持续性而非盲目追息
- 需要系统化评估分红历史、现金流覆盖、资产负债表健康度
- 需要计算税后净收入（考虑预扣税、协定税率、跨币种折算）
- 已有收入持仓需要再评估是否仍适合作为收入核心
- 构建月度分红现金流日历，规划组合收入

**如何使用**：

```
/income-investment {公司名} [mode=new|existing] [role=core-income|opportunistic-income]
```

示例：`/income-investment 中国移动`、`/income-investment 00700 mode=existing`、`/income-investment KO role=core-income target_yield=4% tax_residence=CN`

**八步执行流程**：

1. **解析请求与数据质量确立** — 确定标的、上市地、货币、分红货币、模式、期望角色；评级证据质量 A/B/C
2. **理解分红** — 覆盖至少五年：频率、普通/特别/可变状态、年度每股分红、增减削减次数、CAGR、日历
3. **追踪可分配现金流** — 净利润/FCF 派息率、现金流稳定性、利息覆盖、净债务、再融资、资本开支、回购竞争
4. **测试质量与持久性** — 商业模式、护城河、周期性、下行情景维持分红能力；区分会计利润与可分配现金
5. **估值收入流** — 当前收益率、历史平均、FCF 收益率、安全边际、价格下跌与分红削减组合情景
6. **计算可用收入** — 毛分红、预扣税、净收入、组合贡献、交易后收入（税务不完整时只展示毛收入）
7. **检查组合适配** — 当前/建议权重、集中度、重复风险、月度收入日历
8. **构建三情景** — 基准/不利/严重，每个明确测试分红削减而非假设不变

**判决选项**：`核心收入` / `机会型收入` / `观察名单` / `持有-不加仓` / `减仓` / `拒绝/收益陷阱` / `数据不足`

**行业特定指标**：REIT 看 FFO/AFFO、银行看 CET1、保险看偿付能力、BDC 看 NII/NAV、资源类看周期中段现金流、电信/公用事业看 FCF 覆盖率

**希望达到的目的**：

- 产出 `reports/{公司名}-income-investment-{YYYYMMDD}.md`，包含 18 节结构化报告
- 识别收益陷阱：高股息率但覆盖不足、杠杆过高、结构性衰退
- 评估分红持久性：五项阻断门控（无覆盖分红/严重债务/结构恶化/数据不足/治理问题）
- 计算可用收入：跨币种折算用 `fx_rate.py`、估值用 `financial_rigor.py`、审核用 `report_audit.py`

### 7. 未上市公司研究 `/private-company-research`

**定位**：6 Agent 并行深度研究框架，专为蚂蚁集团、小红书、SpaceX、Stripe 等未上市公司设计，在信息稀缺条件下还原真实价值。

**何时使用**：

- 需要深度研究一家未上市公司（无标准化财报、估值锚定少、信息不对称大）
- 需要多源拼凑财务数据并进行估值推演
- 常规研究框架（如 `/investment-team`）因信息不足无法有效运作
- 需要评估未上市公司的真实估值区间和退出路径

**如何使用**：

```
/private-company-research {公司名}
```

示例：`/private-company-research 蚂蚁集团`、`/private-company-research 小红书`、`/private-company-research SpaceX`

**6 Agent 并行研究团队**：

| Agent | 职责 |
|-------|------|
| business-decoder | 商业模式拆解、收入模式、单位经济模型、护城河评估 |
| financial-detective | 财务数据多源拼凑、融资历史、5 种估值方法交叉 |
| competitive-mapper | 行业定位、波特五力、竞争格局、情景推演 |
| risk-governance-analyst | 管理层评估、股权结构、全维度风险、退出路径、最坏情景 |
| tech-ip-analyst | 技术栈、专利布局、研发能力、技术护城河 |
| signal-miner | 招聘信号、App 数据、舆情、工商法律、供应链、数字足迹 |

**执行流程**（六阶段）：

1. **展示团队框架** — 向用户确认 7 人团队结构
2. **并行启动 6 个 Agent** — 同一条消息调用 6 次 Task 工具
3. **接收报告并跟踪进度** — 实时更新进度表
4. **交叉验证与信息拼图** — 数据冲突仲裁、信号一致性检验、反偏见检查
5. **汇总最终报告** — 14 节结构化报告
6. **保存与审核** — 写入 `reports/{公司名}/{公司名}-private-{YYYYMMDD}.md`

**核心特色**：

- **AI 研究偏见自觉**：警惕虚假保守、虚假精确、对标陷阱、幸存者偏差
- **数据置信度标注**：🟢高（招股书/官方披露）/ 🟡中（可信媒体/研报）/ 🔴低（推算/传闻）
- **信号一致性矩阵**：增长叙事 vs 招聘趋势、技术叙事 vs 专利数据、估值 vs 竞争地位
- **第一性原理模式**：信息极度稀缺时聚焦核心问题，不追求报告形式完整

**希望达到的目的**：

- 产出 `reports/{公司名}/{公司名}-private-{YYYYMMDD}.md`，包含 14 节结构化报告
- 在信息稀缺条件下尽可能还原公司真实价值（不是市场估值，而是生意本身值多少钱）
- 5 种估值方法交叉：最近融资估值法、可比上市公司法、DCF 情景分析、终局市值倒推法、交易对标法
- 识别信息盲区，标注"白区/灰区/黑区"，诚实说明结论的置信度
