# garp-investment-checklist

**GARP 买入前门槛 Checklist（1~5 年独立档 · 五大师）**

对指定公司执行《中长期价值成长（GARP）投资框架》**第2步**（能力圈自检 + 财务初筛）与**第3步**（五大支柱交叉验证与汇总判定），输出**三档明确结论（可建仓 / 观察仓 / 放弃）**，回答一个问题：

> **这家公司，现在是否够格进入下一步的估值锚定与建仓？**

---

## 适用口径

| 项 | 说明 |
| --- | --- |
| **持有周期** | **1~5 年（GARP 独立档）** |
| **大师体系** | **五大师**：费雪（质化与「不卖」边界）/ 林奇（快速排雷与分类）/ 郑希（ROIC 与资本回报纪律）/ 李进（政策与资本落地的硬证据）/ 欧奈尔（产业景气与技术面辅助） |
| **口径隔离** | 与 **1~3 年中期链**、**10 年长期链**物理隔离、功能互补；本技能**不使用**任何中期链或长期链的量化口径 |
| **权威来源** | 《中长期价值成长（GARP）投资框架》第2步 + 第3步 |
| **定位** | 买入前**门槛**（排除坏选择），不是深度研究，不是估值，不是卖出 |

---

## 快速开始

```bash
# 单公司（自动识别市场）
/garp-investment-checklist 中微公司

# 指定市场
/garp-investment-checklist 腾讯控股 --market 港股

# 跳过赛道数据引用（S1 降级为定性描述）
/garp-investment-checklist 某公司 --no-industry

# 已知 0.3 前置结论与赛道类型，跳过 garp-geo-policy 调用
/garp-investment-checklist 某公司 --geo-conclusion 放行 --track-type 地缘倒逼型

# 透传宏观档位，取建仓前置约束
/garp-investment-checklist 某公司 --stage 复苏

# 快速模式（跳过实时检索，仅用缓存与用户输入）
/garp-investment-checklist 某公司 --depth fast

# 多公司横向对比
/garp-investment-checklist 中微公司,北方华创,拓荆科技
```

## 可选参数

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `{公司名}` | 目标公司名或代码，**支持逗号分隔的多公司**（逐家独立成文 + 末尾总览对比表） | **必填** |
| `--market` | 市场分层 `A股 / 港股 / 美股`，决定取数工具链 | 自动识别；识别失败则询问 |

| `--geo-conclusion` | 用户已持有的 0.3 前置结论（`放行 / 观察 / 回避`） | 无（未填则调用 `garp-geo-policy`） |
| `--track-type` | 赛道两分法类型（`地缘倒逼型 / 政策资本驱动型`），决定 S4 硬门槛适用性 | 无（由 `garp-geo-policy` 出口给出） |

| `--depth` | `standard`（全流程）/ `fast`（跳过实时检索，仅用缓存与用户输入） | `standard` |

## 核心功能

### 四段关卡

| 关卡 | 内容 | 关键口径 |
| --- | --- | --- |
| **关卡一 能力圈四维自检** | 产业理解 / 财务理解 / 估值理解 / 技术理解 | 普通行业须**同时满足前三项**；科技股「技术理解」**必答**。**人工确认闸门**：未确认项标「暂定」，科技股技术理解未确认 → 结论**封顶观察仓** |
| **关卡二 财务初筛五门槛 + 科技豁免** | F1 营收≥10 亿 / F2 三年营收 CAGR≥15% / F3 资产负债率<60%（金融、地产除外）/ F4 经营现金流净额为正 / F5 过去三年≥2 年扣非净利润为正 | 科技豁免**三层证据**：L1 研发强度≥15% + L2（经营现金流正 **且** 营收连续增长）+ **L3 加回当期费用化研发后核心经营利润转正**（强制项）。豁免**只替代 F5** |
| **关卡三 五大支柱汇总判定** | 一票否决 V1~V4 + 达标判定 S1~S5 | 支柱一 β / 支柱二 α（含 ROIC 四档）/ 支柱三 两套 20 分制 / 支柱四 八项敞口 + 赛道两分法 / 支柱五 个股级增量 |
| **关卡四 镜子测试** | GARP 版五句话 | 逐句标注「通过 / 未通过」，未通过句回填为待补齐信号 |

### 三档结论与聚合优先级

> **聚合优先级：否决优先于达标求和（GC-1）。** 先扫 V1~V4，命中即终止；未命中再逐条核 S1~S5。

| 档 | 触发条件 | 处置 |
| --- | --- | --- |
| **可建仓** | V1~V4 均未命中 **且** S1~S5 全部满足 | 转 `garp-valuation` 估值锚定 |
| **观察仓** | V1~V4 均未命中 **且** S1~S5 存在未满足项 | 最多轻仓跟踪，等待信号补齐 |
| **放弃** | V1~V4 命中任意一条 | 放弃或清仓，写明命中项 |

**「暂定」标记**：存在未确认维度或未判定项时，三档结论整体标注「暂定」，不得输出终态「可建仓」。

### 一票否决 V1~V4

| # | 否决项 |
| --- | --- |
| **V1** | 诚信一票否决：兑现率<50% / 业绩预告重大失真 / 财务造假 / 监管立案 |
| **V2** | ROIC 长期<5% 却在拼命扩产（**按报表 ROIC** 判定） |
| **V3** | 能力圈自检未通过 |
| **V4** | 0.3 三维交叉矩阵综合归为「回避」档（政策覆盖度低/无 **且** 国字号基金无覆盖） |

### 达标判定 S1~S5（须全部满足）

| # | 支柱 | 达标条件 |
| --- | --- | --- |
| **S1** | 支柱一（β） | 产业景气向上——供需不恶化、单价稳定或上涨、CR5 提升或龙头份额扩大 |
| **S2** | 支柱二（α） | ROIC > WACC 且 ≥10%（5%~10% → 部分不达标观察仓；科技股按「调整后核心经营 ROIC」）；增速匹配；ROE 趋势向上或企稳、毛利率/净利率不恶化；**护城河须可量化** |
| **S3** | 支柱三 | 科技股：管理层 ≥15 **且** 科研转化 ≥15（各自独立，不合计）；普通行业：管理层 ≥15 |
| **S4** | 支柱四 | 八项敞口可控；「地缘倒逼强度非低/无」仅对**地缘倒逼型**赛道为硬门槛，**政策资本驱动型**赛道豁免该条、敞口仍须体检 |
| **S5** | 支柱五 | 政策覆盖度至少「中」及以上 **且** 国字号基金介入非「无覆盖」 |

### ROIC 双口径（易错点）

| 用途 | 口径 |
| --- | --- |
| **S2 主阈值** | **调整后核心经营 ROIC**（科技股加回费用化研发支出） |
| **V2 一票否决** | **报表 ROIC**（**不适用**科技股调整口径） |

调整口径**只豁免 S2 主阈值，不豁免 V2**。

## 使用示例

### 示例 1｜A股科技股（中微公司 688012，五门槛全通过）

```bash
python tools/a_share/stock_financial.py --code 688012 \
  --indicator "净资产收益率,销售净利率,资产负债率,营业总收入,净利润,扣非净利润,经营现金流"

python tools/a_share/stock_financial.py --code 688012 --advanced "研发费用"

python tools/common/financial_rigor.py calc \
  --expr "((12384638268.11/4739830997.55)**(1/3)-1)*100"   # → 37.73（三年营收 CAGR，%）
```

**期望要点**：F1 123.85 亿 ✅；F2 37.73% ✅；F3 23.85% ✅；F4 +22.95 亿 ✅；F5 三年全正 ✅ → 五门槛全通过，**不触发科技豁免**。

### 示例 2｜科技豁免（豁免成立）

```bash
python tools/common/financial_rigor.py calc --expr "1200000000/5200000000*100"   # L1 研发强度 → 23.08
python tools/common/financial_rigor.py calc --expr="-3+12"                        # L3 加回研发后核心经营利润 → 9（>0）
```

**期望要点**：L1 研发强度 23.08% ≥15% ✅；L2 经营现金流为正 **且** 近 3 年营收逐年增长 ✅；L3 加回研发后核心经营利润 +9 亿 > 0 ✅ → **豁免成立**，F5 由豁免替代。

### 示例 3｜科技豁免（豁免不成立 → 剔除）

以 **寒武纪 688256** 类样本（经营现金流连续为负）：

```bash
python tools/a_share/stock_financial.py --code 688256 \
  --indicator "扣非净利润,经营现金流,营业总收入"
```

**期望要点**：F5 近三年仅 1 年扣非为正 → 不通过；进入豁免后 **L2 经营现金流净额为正不成立**（连续为负）→ **豁免失败** → 标的**剔除**，直接落「放弃」。

### 示例 4｜一票否决 V2（ROIC<5% 且扩产）

```bash
python tools/common/financial_rigor.py wacc \
  --equity-value 900 --debt-value 100 --cost-equity 10 --cost-debt 4.5 --tax-rate 0.15
# → wacc 9.38

python tools/common/financial_rigor.py roic \
  --nopat 16 --invested-capital 400 --wacc 9.38 --expanding
# → roi 4.0 / tier 不达标 / verdict 一票否决（ROIC<5% 且仍扩产）
```

**期望要点**：**否决优先于达标求和**——即便 S1~S5 中有多项达标，结论仍必须为「**放弃**」。

### 示例 5｜多公司横向对比

```bash
/garp-investment-checklist 中微公司,北方华创,拓荆科技
```

**期望要点**：每家公司独立成文（各含完整八段式 + 独立三档结论），末尾附总览对比表（公司 / 三档结论 / 命中否决项 / 未达标项 / 待补齐信号）。

## 强制纪律（GC-1 ~ GC-10 摘要）

| 编码 | 规则 |
| --- | --- |
| **GC-1** | 否决优先于达标求和，禁止「多项达标对冲一项否决」 |
| **GC-2** | 科技豁免须三层证据 L1/L2/L3 齐备，不得以一句「符合豁免」带过 |
| **GC-3** | 科技股「技术理解」未确认 → 结论封顶观察仓 |
| **GC-4** | 护城河不可量化 → S2 不达标退观察仓；禁止仅凭行业 β 的 CR5 判断个股护城河 |
| **GC-5** | 两套 20 分制须「各自 ≥15」，禁止合计 / 加权 |
| **GC-6** | ROIC 双口径不得混用：S2 用调整口径，V2 用报表口径 |
| **GC-7** | 数据不足不得默认通过；未判定项使结论降「暂定」 |
| **GC-8** | 计算类结论必须来自工具，工具不可用则不出结论 |
| **GC-9** | 估值 / 卖出 / 仓位数值不得内建，一律转下游技能 |
| **GC-10** | 数据截止日期强制标注（时变项须核验日期） |

## 核心原则

1. **门槛不是细研**——只回答「够不够格」，不回答「值多少钱」。
2. **引用不重建**——下游口径（估值 / 卖出 / 仓位 / 管理层细则 / 赛道判定）一律引用，不复制、不重定义。
3. **数据不足不默认通过**——宁可给「暂定」，不给虚假的「可建仓」。
4. **能力圈不可代答定稿**——AI 代答 + 人工确认闸门，未确认即「暂定」。
5. **计算禁心算**——一切比率、复合增速、加回测算均由 `financial_rigor.py` 执行。

| 类型 | 场景 |
| --- | --- |
| **适用** | ① 个股建仓前门槛检查；② 持仓标的定期复核；③ 多公司同标准横向比较；④ 加仓前门槛再确认 |
