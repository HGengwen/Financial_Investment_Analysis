# GARP 买入前门槛 Checklist（1~5 年独立档）

对 $ARGUMENTS 执行《中长期价值成长（GARP）投资框架》**第2步**（个股初筛：能力圈自检 + 财务初筛）与**第3步**（五大支柱交叉验证与汇总判定）的门槛级流水线，回答一个问题：

> **这家公司，现在是否够格进入下一步的估值锚定与建仓？**

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。** 本技能的关卡结论**一律由工具与框架明示规则产出**，禁止 LLM 心算；本技能只做**买入前门槛**，不做估值、不做卖出、不做仓位、不做行业漏斗。

> 💬 **费雪式提醒**："买之前先问自己——我是真的懂这门生意，还是只是懂它的股价走势？能力圈自检就是把这句话变成四道必须答得上来的题。"

> 💬 **林奇式提醒**："快速排雷比精挑细选更重要。五条财务门槛花十分钟就能筛掉一半的'讲故事'公司，剩下的才值得花时间。"

> 💬 **郑希式提醒**："ROIC 低于资金成本还在拼命扩产，不是成长，是价值毁灭。这条线一旦踩上去，其他四项再漂亮也不看。"

> 💬 **李进式提醒**："政策覆盖与国字号基金介入不是概念，是要落到'这家公司拿到多少、订单兑现多少'的硬证据。"

> 💬 **欧奈尔式提醒**："产业景气向上是买点的前提——供需在恶化、价格在下跌、龙头份额在流失的赛道，个股再强也只是逆水行舟。"

## 设计理念与定位

1. **本技能是 GARP 流程的「入口关卡」，目标是排除坏选择，不是找最好的公司**——它回答「够不够格」，不回答「值多少钱」。找最好的公司归 `garp-industry-funnel` / `garp-investment-research`。
2. **关卡是"门槛"，不是"细研"**——每一段只输出「通过 / 不通过 / 未判定」与一句依据；管理层的 7+7+6 细则、科研的 8+8+4 细则、估值矩阵全表、五级卖出规则**均不在本技能内定义**，一律引用下游技能。
3. **三条硬纪律**：
   - ① **否决优先于达标求和**（GC-1）——先扫一票否决四条，命中即终止，禁止用「多项达标」对冲「一项否决」；
   - ② **门槛级判定禁止越界定义下游口径**（GC-9）——不内建目标价、不内建卖出层级、不内建仓位数值；
   - ③ **数据不足不得默认通过**（GC-7）——未判定项一律标「未判定」并使最终结论降为「暂定」。

## 边界声明（本技能核心）

| # | 边界 | 处置 |
| --- | --- | --- |
| ① | **不含估值** | 框架第3步收口原文即「**全部达标 → 进入第4步估值锚定，可建仓**」——估值在门槛之后。本技能只在收口段输出「**待估值校验**」标记并转 `garp-valuation` |
| ② | **不含卖出五级** | 不内建卖出速查卡、不输出卖出触发价；转 `garp-exit` |
| ③ | **不含管理层 / 科研评分细则** | 只调用 `governance_data.py` 读回「分值 + 是否 ≥15 + 诚信闸门是否命中」，不重述 7+7+6 / 8+8+4 的评分项与阈值；细则归 `garp-management` |
| ④ | **不含赛道级判定** | 渗透率、TAM、供需、CR5、国产化率、0.3 矩阵**只引用出口结论**，不重复定义、不自行判定 |

> **范围自查原则**：本技能若出现「给出目标价 / 给出最终买入价 / 定义管理层评分细则 / 定义卖出层级 / 给出建仓比例」，即为越界。

## 执行流程（七步）

### 第一步：确认参数与数据基准（+ AI 研究偏见预警）

1. 运行 `date` 确认当天日期，作为「**数据截止日期**」基准，并在报告头部注明（GC-10）。
2. 解析 `{公司名}` → 全称 / 代码 / 交易所 / **是否上市**。
   - 未上市 → 标「未上市，跳过完整 Checklist」，按需转 `garp-private-company-research`（声明式引用）。
3. 解析可选参数（`--market` / `--no-industry` / `--geo-conclusion` / `--stage` / `--depth`）。
4. **AI 研究偏见预警（继承既有骨架，口径保留）**：对公司做信息丰富度评级：

| 等级 | 含义 | 处置 |
| --- | --- | --- |
| **A** | 信息丰富（券商覆盖多、公告齐全、数据源 ≥3） | 正常执行 |
| **B** | 信息中等（覆盖有限，部分指标需估算） | 正常执行，估算项须显式标注来源 |
| **C** | 信息匮乏（小市值 / 冷门 / 数据缺口大） | **「数据不足」不等于「不通过」**——诚实标注「灰色地带，需补充一手信息」，不得勉强填满关卡；缺项按 GC-7 标「未判定」 |

### 第二步：数据收集（按市场分层）

| 市场 | 工具链 |
| --- | --- |
| A股 | `tools/a_share/stock_info.py`（名称/代码/行业）、`tools/a_share/stock_quote.py`（行情，可选 `--momentum`）、`tools/a_share/stock_financial.py`（财务指标，含 `--advanced 研发费用,员工总数`）、`tools/a_share/stock_screen.py`（辅助佐证）、`tools/a_share/stock_equity.py`（股权结构 / 财报 PDF）、`tools/common/a_stock_cache.py` |
| 港股 | `tools/hk_stock/stock_info.py`、`tools/hk_stock/stock_quote.py`、`tools/hk_stock/stock_financial.py`、`tools/hk_stock/stock_screen.py`、`tools/common/hk_stock_cache.py` |
| 美股 | `tools/us_stock/stock_info.py`、`tools/us_stock/stock_quote.py`、`tools/us_stock/stock_financial.py`、`tools/common/us_stock_cache.py` |

**取数清单**（对应各关卡输入）：

| 类别 | 字段 |
| --- | --- |
| 财务五门槛 | 营业总收入（最近 3~4 个完整年度）、资产负债率、经营性现金流净额、扣非净利润（近 3 个完整年度） |
| 科技豁免 | 研发费用、营业总收入（算研发强度）、近 3 年营收逐年增速、经营现金流净额、**加回研发后的核心经营利润** |
| 支柱二 | ROE 趋势、毛利率 / 净利率趋势、营收与利润增速匹配度、NOPAT 与投入资本（算 ROIC）、WACC 组成、护城河量化证据（市占率趋势 / 续费率·NPS / 定价权 / 转换成本 / 成本·技术壁垒） |
| 支柱三 | 诚信闸门事实项（兑现率、业绩预告、归因习惯、监管立案、财务造假）、管理层评分项、科研转化评分项 |
| 支柱四 | 海外收入占比、海外产能与供应链布局、关键零部件/资源来源、制裁与实体清单状态、地区冲突暴露、本地化对冲、自主研发投入强度 |
| 支柱五 | 国家/地方产业基金注资额度与占市值·资本开支比、资本+场景绑定的订单/收入/量产兑现、强制采购/财税优惠/首台套等门槛优势 |

**精确计算纪律**：一切比率、复合增速、加回测算均由 `tools/common/financial_rigor.py calc` 执行，**禁止 LLM 心算**；关键财务数据须至少来自**两个独立来源**，误差 >1% 须标记。

**工具使用注意（实测已知）**：

- `calc` 的表达式白名单**不含 `^`**，幂运算须用 `**`，例如三年复合增速：
  `python tools/common/financial_rigor.py calc --expr "((期末营收/期初营收)**(1/3)-1)*100"`
- 表达式**以负号开头**时须写成 `--expr="-3+12"`，否则 PowerShell 报 `expected one argument`。
- `stock_screen.py` 的「质量筛选 7 条指标」与 GARP「财务五门槛」**不是同一套口径**，**不得以其输出直接充当五门槛判定**，只能作为**辅助佐证**。

### 第三步：能力圈四维自检（含人工确认闸门）

逐维输出「**AI 代答结论 + 依据**」→ 标 `self_check_confirm = 待用户确认` → 由用户确认后定稿。

| 维度 | AI 代答方式 | 无从代答时的处置 | 适用 |
| --- | --- | --- | --- |
| 产业理解 | 由产业链 / CR5 检索结果生成「投资者应能独立回答的四问」及其参考答案 | 标「待确认」 | 通用必答 |
| 财务理解 | 由三张报表科目清单生成对照问题 | 标「待确认」 | 通用必答 |
| 估值理解 | 由 `garp-valuation` 可用方法清单（PE/PEG/PS/EV-Sales/DCF/可比公司）生成对照问题 | 标「待确认」 | 通用必答 |
| 技术理解 | 由技术路线检索结果生成「路线差异四问」（原理 / 成本 / 适用场景 / 主流玩家） | 标「待确认」 | **科技股必答**；普通行业可豁免 |

**人工确认闸门（与 `garp-macro` 同构）**：

- 未确认前：`confidence = 低`、`manual_review = true`，报告中该维度结论一律标「**暂定**」；
- **只要存在未确认维度，最终三档结论须整体标注「暂定」**，不得直接输出「可建仓」；
- **科技股「技术理解」未确认 → 结论封顶为「观察仓」**（GC-3）。

### 第四步：财务初筛五门槛 + 科技豁免

逐条判定 F1~F5（口径见「关卡细则 · 关卡二」）。**若 F5 不通过且公司属科技股**，进入科技豁免三层证据判定。

输出：五门槛逐条「通过 / 不通过」+ 豁免是否成立 + 三层证据明细。

> **任一门槛不通过且豁免不成立 → 标的剔除**，不再进入第五步（直接给「放弃」并写明不通过项）。

### 第五步：五大支柱汇总判定（工具调用，禁止心算）

1. **引用 0.3 前置结论**（用户未通过 `--geo-conclusion` 提供则调用）：

```bash
# 行业级前置扫描：scan 子命令须以 -m 模块形式调用（脚本形式会因 tools 包不在 sys.path 而报 ModuleNotFoundError）
python -m tools.specialized.geo_policy_screen scan --industry {行业}

# 行业结论已有时的矩阵判定
python tools/specialized/geo_policy_screen.py screen \
    --geo {高|中|低} --policy {高|中|低} --fund {四档} \
    --as-of {YYYY-MM-DD} --basis "{依据}"
```

→ 读回 `matrix_row` / `conclusion` / `track_type` / `archived`，映射 **V4**（回避档一票否决）与 **S4 / S5**。

2. **支柱二 ROIC 工具调用**：

```bash
python tools/common/financial_rigor.py wacc \
    --equity-value {E} --debt-value {D} --cost-equity {re} --cost-debt {rd} --tax-rate {t}

python tools/common/financial_rigor.py roic \
    --nopat {NOPAT} --invested-capital {IC} --wacc {WACC} [--expanding]

python tools/common/financial_rigor.py incremental-roic \
    --nopat-from {..} --invested-capital-from {..} --nopat-to {..} --invested-capital-to {..}
```

→ 读回 `roic` / `tier` / `verdict` / `tech_adjustment_hint`，映射 **S2**（合格 / 优秀 / 部分不达标）与 **V2**（`--expanding` 时的 <5% 一票否决）。

> **科技股须另按「调整后核心经营 ROIC」口径复算一次**（将费用化研发支出加回 NOPAT 与投入资本后重跑 `roic`），用于 S2 主阈值判定；**V2 仍按报表 ROIC**（GC-6，两者不得混用）。

3. **支柱三门槛级判定（只读结论，不重述细则）**：

```bash
python tools/specialized/governance_data.py management \
    --fulfillment-rate {..} --guidance-misstatement --regulatory-filing \
    --dividend-payout-ratio {..} --financing {优|中|差} --buyback {优|中|差} --pledge-ratio {..} \
    --core-focus {优|中|差} --strategy-exec {优|中|差} --industry-cog {优|中|差} \
    --turnover-rate {..} --equity-incentive {优|中|差} \
    --as-of {YYYY-MM-DD}

python tools/specialized/governance_data.py research \
```

## 关卡细则

### 关卡一 能力圈四维自检

| 维度 | 评估标准 | 自检问题（须能独立回答「是」） |
| --- | --- | --- |
| **产业理解** | 能否画出该产业链的上下游关系图？能否说出行业竞争格局与集中度（CR5）？ | 产业链有几层？上游关键原材料/设备来自谁？下游客户是谁？前五大玩家是谁、份额多少？ |
| **财务理解** | 能否独立阅读并理解该行业公司的三张报表？ | 营收、毛利率、应收/存货、经营现金流分别在哪张表？关键科目变动意味着什么？ |
| **估值理解** | 能否用至少 2 种方法给出估值区间？ | 除了 PE/PEG，能否再用 PS、EV/Sales、DCF、可比公司等方法交叉验证？ |
| **技术理解** | 能否说清核心技术路线的差异？ | 不同技术路线的原理差异、成本差异、适用场景、主流玩家分别是谁？ |

**判定规则（逐字落地框架）**：

1. **普通行业**：须**同时满足「产业理解 + 财务理解 + 估值理解」三项**方可进入深度研究；三项中**任一无法独立回答，即视为能力圈之外**（技术理解为科技股附加项，普通行业可豁免）。
2. **科技股**：在上述基础上，**「技术理解」为必选项**——说不清核心技术路线差异，即便其他三项都通过，**也不得重仓，只能作为观察仓或直接放弃**。
3. **达不到门槛的应对**：不是「硬上」，而是三选一——①补课学习直到能独立回答；②只作低仓位观察仓跟随；③果断放弃。

**框架内部张力的收敛口径（本技能统一定稿）**：

| 情形 | 本技能统一口径 |
| --- | --- |
| 普通行业：产业 / 财务 / 估值**任一不过** | **放弃**（三项为门槛项，「任一不过即视为能力圈之外」） |
| 科技股：**仅「技术理解」不过**，其余三项通过 | **封顶为观察仓**，不得输出「可建仓」 |
| 科技股：技术理解不过 **且** 其他项也不过 | **放弃** |

> 该表同时满足框架第2步「三选一」与第3步一票否决「能力圈自检未通过」两处表述，**不修改框架正文**；执行时以「行业类型 × 维度类型」二次切分落地。

**科技股识别口径**：半导体 / 半导体设备与材料 / 信创与基础软件 / 高端制造（工业母机、精密零部件）/ 创新药与生物技术 / 新能源技术（固态电池、新型光伏路线）/ 军工电子 等以**技术路线差异为竞争核心**的公司；识别存疑时**默认按科技股处理**（更严格一方），并在报告中标注「科技股判定存疑，已从严处理」。

**输出**：逐维「是 / 否 / 待确认」+ AI 代答依据 + 用户确认状态 + 是否通过门槛。

### 关卡二 财务初筛五门槛 + 科技豁免

**五门槛（快速排除法）**：

| # | 门槛 | 权威值 | 计量口径（本技能落地） |
| --- | --- | --- | --- |
| **F1** | 营收规模 | **≥10 亿元** | 最近一个完整会计年度的营业总收入 |
| **F2** | 最近三年营收复合增速 | **≥15%** | 以「三年 CAGR」计算：`((期末营收/期初营收)**(1/3)-1)*100`，期初取最近完整年度往前推 3 年 |
| **F3** | 资产负债率 | **<60%**（**金融 / 地产行业除外**） | 最近一个完整会计年度末 |
| **F4** | 经营性现金流净额 | **为正** | 最近一个完整会计年度的经营活动现金流量净额 |
| **F5** | 过去三年扣非净利润 | **至少两年为正** | 最近**三个完整会计年度**的扣除非经常性损益后净利润 |

> **F3 例外**：金融 / 地产行业不适用负债率门槛（该两项行业高杠杆为经营常态），报告中须显式标注「F3 已按行业例外豁免」。

**科技豁免（精确触发，不得一句话带过）**：

> 对高研发投入的科技股，若「扣非净利润为负」**仅由研发费用化压低当期利润所致**，可用「经营性现金流净额为正 + 营收连续增长 + 研发强度≥15%」三项替代 F5 的「扣非净利润」门槛；**无法通过此豁免的仍应剔除**。

**三层证据（L3 为强制项，不得省略）**：

| 层 | 检查 | 判定 |
| --- | --- | --- |
| **L1** | `研发强度 = 研发费用 ÷ 营业总收入 ≥ 15%` | 未达 15% → 豁免不成立 |
| **L2** | `经营性现金流净额 > 0` **且** 营收连续增长（近 3 年营收**逐年增长**，不出现年度负增长） | 任一不满足 → 豁免不成立 |
| **L3** | **「仅由研发费用化所致」的独立验证**：加回当期费用化研发支出后，**核心经营利润转正**（`financial_rigor.py calc` 精确计算） | 加回后仍为负 → 亏损非研发费用化单因所致 → **豁免不成立**，剔除 |

**豁免的适用边界**：

- 豁免**只替代 F5**，**不替代 F1~F4**；F3（负债率 <60%）对科技股**同样不豁免**；
- L3 是「**仅**由研发费用化压低当期利润所致」这一限定语的必要落地——若不加 L3，任何亏损科技股只要研发强度≥15% 就能绕过门槛，豁免将退化为普适后门；
- 豁免是否成立须在报告中**显式写出 L1 / L2 / L3 三层证据与实测数值**，不得以一句「符合科技豁免」带过。

**输出**：五门槛逐条「通过 / 不通过」+（若进入豁免）三层证据表与豁免结论 + 是否剔除。

### 关卡三 五大支柱汇总判定

#### 3.1 一票否决扫描（V1~V4，命中任意一条即终止）

| # | 否决项 | 判定来源 | 本技能的取证方式 |
| --- | --- | --- | --- |
| **V1** | **诚信一票否决**：兑现率 <50% / 业绩预告重大失真 / 财务造假 / 监管立案 | `governance_data.py management` 的诚信闸门 | 读回 `integrity_veto` 与 `integrity_veto_reasons` |
| **V2** | **ROIC 长期 <5% 却在拼命扩产** | `financial_rigor.py roic --expanding` | 读回 `tier`/`verdict`；**按报表 ROIC 判定**（GC-6） |
| **V3** | **能力圈自检未通过** | 本技能关卡一（含收敛口径表） | 直接引用关卡一结论 |
| **V4** | **0.3 三维矩阵综合归为「回避」档**（政策覆盖度低/无 **且** 国字号基金无覆盖，无论地缘倒逼高低） | `garp-geo-policy`（已交付）的 `matrix_row` / `conclusion` | 透传，不自行判定 |

#### 3.2 达标判定逐条（S1~S5，须全部满足方可建仓）

| # | 支柱 | 达标条件 |
| --- | --- | --- |
| **S1** | 支柱一（β） | 产业景气向上——供需不恶化、产品单价稳定或上涨、CR5 提升或龙头份额扩大 |
| **S2** | 支柱二（α） | **ROIC > WACC 且 ≥10%**（5%~10% 归「部分不达标」→ 观察仓；科技股按「调整后核心经营 ROIC」口径）；营收/利润增速匹配；ROE 趋势向上或企稳，毛利率/净利率不恶化；**护城河须可量化验证**（市占率趋势 / 续费率·NPS / 定价权 / 转换成本 / 成本·技术壁垒）——停留在「感觉有壁垒」则本项不达标（GC-4），且**禁止仅凭行业 β 的 CR5 判断个股护城河** |
| **S3** | 支柱三 | **科技股**：管理层 ≥15 **且** 科研转化 ≥15（**两套都须 ≥15，不得合计 / 加权**）；**普通行业**：管理层 ≥15 |
| **S4** | 支柱四 | 海外收入、资源 / 供应链、地区冲突暴露可控；其中「**地缘倒逼强度非低/无**」**仅对地缘倒逼型赛道**（半导体设备 / 材料等）为**硬门槛**；**政策资本驱动型赛道**（机器人、信创等增量创造，地缘倒逼强度本就不高）**仅豁免这一条硬门槛**，海外收入 / 供应链 / 地区冲突暴露等敞口**仍须体检**，其达标与否（政策覆盖度与基金介入）以支柱五判定为准 |
| **S5** | 支柱五 | 政策覆盖度至少「中」及以上（0.3 矩阵非「低/无覆盖」）**且** 国字号基金介入非「无覆盖」（至少有覆盖或专项子基金） |

**S2 的 ROIC 四档**：

| 档 | 判定 | 处置 |
| --- | --- | --- |
| **合格** | ROIC > WACC **且** ≥10% | 达标 |
| **优秀** | ROIC > 15% | 加分项：可支持单只上限上浮至绝对 20%（**仅限长期充分验证的深护城河核心底仓**），并允许 PEG 偏贵上沿接近 1.5 |
| **部分不达标（a）** | 5%~10% | 观察仓待观察（既不否决也不达标） |
| **部分不达标（b）** | <5% 但**不扩产** | 观察仓 |
| **一票否决** | <5% **且** 仍在拼命扩产 | 归入 **V2** |

**ROIC 双口径（必须显式区分，GC-6）**：

| 用途 | 口径 | 说明 |
| --- | --- | --- |
| **S2 主阈值** | **调整后核心经营 ROIC** | 科技股将**费用化研发支出加回**后的口径；调整后仍 <10% → S2 判「部分不达标（观察仓）」 |
| **V2 一票否决** | **报表 ROIC** | 独立按报表口径判定，**不适用**科技股调整口径；即调整口径**只豁免 S2 主阈值，不豁免 V2** |
| 科研转化清单「资本回报效率」项 | **ROIC > WACC**（严格大于） | 由 `governance_data.py research` 独立判定，同样不豁免 |

#### 3.3 支柱证据明细（报告第五节范围）

- **支柱二**：ROIC 两口径实测值 + WACC 组成拆解 + `incremental-roic` 增量回报 + 护城河量化证据清单（须逐项可核）；
- **支柱四**：八项敞口逐项「可控 / 不可控 / 未判定」+ 赛道两分法适用性结论；

## 三档结论与聚合优先级（GC-1）

> **聚合优先级：否决优先于达标求和。** 先扫 V1~V4，命中即终止并给「放弃」；未命中再逐条核 S1~S5，全满足才给「可建仓」，存在未满足项则给「观察仓」。**禁止用多项达标对冲一项否决。**

| 档 | 触发条件 | 处置 |
| --- | --- | --- |
| **可建仓（全部达标）** | V1~V4 均未命中 **且** S1~S5 全部满足 | 转 `garp-valuation` 估值锚定，可建仓 |
| **观察仓（部分不达标）** | V1~V4 均未命中 **且** S1~S5 存在未满足项 | 最多轻仓跟踪，等待信号补齐，**不重仓** |
| **放弃（任一否决命中）** | V1~V4 命中任意一条 | 放弃或清仓，写明命中项 |

**「暂定」标记规则**：只要存在**未确认维度**（能力圈自检未确认）或**未判定项**（GC-7），三档结论须整体标注「**暂定**」，不得输出终态的「可建仓」。

**封顶规则**：科技股「技术理解」未确认 → 结论**封顶为观察仓**（GC-3）。

**边界情形处置**：

| 情形 | 处置 |
| --- | --- |
| 关卡二即剔除（门槛不通过且豁免不成立） | 直接落「**放弃**」，并写明不通过项；不再执行关卡三（但报告中仍保留 V1 诚信闸门与 0.3 回避档的扫描结果，便于归档） |
| 第 5 步工具不可用 | 标「**计算未完成**」，对应项判「未判定」，结论降为「暂定」；**禁止心算兜底**（GC-8） |
| `--no-industry` 或赛道出口未接入 | S1 降级为定性描述并显式标注「**赛道数据未接入，S1 降级为定性**」；不得默认 S1 达标 |
| `--stage` 未提供 | 输出「**待宏观校准**」标记，提示单独执行 `/garp-macro`；本技能不自行给现金下限 / 单只上限数值 |

| `financial-data` | 既有 | 数据获取标准流程 | 既有 → 直接引用 |
| `qoq-accelerator` / `trend-momentum-scan` | 复用 2 技能 | 加速度、技术面辅助（仅作佐证，不参与三档结论） | 既有 → 直接引用 |

**「声明式引用」的含义**：仅声明口径归属与编号，**不复制其规则内容**、不代替其执行判定；被引用技能结论未接入时，本技能对应项按「未判定」或「引用出口结论」处理，并在报告中标注编号。

**赛道数据出口纪律**：赛道级数据（渗透率黄金窗、TAM、供需、CR5）**只从 `garp-industry-research`（P4-9）取出口结论**；底层中性工具（`stock_quote` / `sector_screen` 等）可用于**取数**，但不得据此在本技能内自行判定赛道档位。**不引用中期链技能作为口径提供者。**

## 风控硬编码（GC-1 ~ GC-10）

| 编码 | 规则 | 执行要求 |
| --- | --- | --- |
| **GC-1** | **否决优先于达标求和** | 先扫 V1~V4，命中即终止、给「放弃」，禁止「多项达标对冲一项否决」 |
| **GC-2** | **科技豁免须三层证据齐备** | L1 / L2 / L3 任一不成立即豁免失败，不得以一句「符合豁免」带过 |
| **GC-3** | **科技股「技术理解」未确认** | 结论**封顶为观察仓**，不得输出「可建仓」 |
| **GC-4** | **护城河不可量化** | S2 本项判「不达标」→ 退观察仓；**禁止仅凭行业 β 的 CR5 判断个股护城河** |
| **GC-5** | **两套 20 分制须「各自 ≥15」** | 禁止合计 / 加权；管理层 <15 与科研转化 <15 各自独立退档 |
| **GC-6** | **ROIC 双口径不得混用** | S2 主阈值用「调整后核心经营 ROIC」；V2「<5% 且扩产」**必须按报表 ROIC** 判定，不适用科技股调整口径 |
| **GC-7** | **数据不足不得默认通过** | 未判定项一律标「未判定」，并使最终结论降档为「暂定」 |
| **GC-8** | **计算类结论必须来自工具** | `financial_rigor.py` 不可用时**不出结论**，禁止心算兜底 |
| **GC-9** | **估值 / 卖出 / 仓位数值不得内建** | 一律转 `garp-valuation` / `garp-exit` / `garp-portfolio-review` |
| **GC-10** | **数据截止日期强制标注** | 制裁清单、政策文本、基金名录、渗透率、国产化率均为**时变项**，须标注核验日期 |

## 注意事项

1. **`--depth fast` 的边界**：跳过实时检索、仅用缓存与用户输入时，所有依赖实时检索的项（支柱一 / 支柱四 / 支柱五 / 0.3 矩阵）须标「未判定」，结论降「暂定」。
2. **多公司模式**：每家公司独立成文（独立的三档结论），末尾附总览对比表（列：公司 / 三档结论 / 命中否决项 / 未达标项 / 待补齐信号）。
3. **持仓标的复核**：本技能可用于持仓复核，但**不输出卖出指令**；若复核结论为「放弃」，须显式提示「转 `garp-exit` 核对卖出纪律」。
4. **数据源交叉验证**：关键财务数据须至少两个独立来源，误差 >1% 须在报告第二节标记；无法获得第二来源时须标注「单源，未交叉验证」。
5. **时变项复核**：制裁清单 / 政策文本 / 基金名录 / 国产化率 / 渗透率均须以最新核验为准，**不得沿用历史清单**。
6. **`stock_screen.py` 定位**：仅作辅助佐证，不得以其 7 条质量指标代替五门槛判定。

## 局限性

1. **能力圈自检本质是投资者的自我声明**，AI 只能代答与给依据，**不能替用户宣称「在能力圈内」**；未确认时结论只能是「暂定」。
2. **本技能不含估值**，因此「可建仓」仅代表「够格进入估值锚定」，**不代表现价可买**。
3. **框架第2步与第3步对「能力圈不过」有两处表述**，本技能按「行业类型 × 维度类型」二次切分收敛；该处置为本技能自建规则，不改动框架正文。
4. **C 级信息丰富度公司**存在较多「未判定」项，结论多为「暂定」，属正常现象而非技能失效。
5. **科技股识别存疑时从严处理**，可能对边界型公司偏严（如高端制造中的部分传统环节）。
6. **赛道出口未接入时 S1 降级为定性**，此时「可建仓」的置信度须相应下调。

## 报告示例（摘要）

以 **中微公司（688012.SH，半导体设备 · 科技股）** 为标杆输入，数据截止 2026-09-17（最近完整年度 = 2025 年报）：

| 关卡 | 结果摘要 |
| --- | --- |
| **关卡一 能力圈** | 四维（产业 / 财务 / 估值 / **技术**）逐维 AI 代答并标「待用户确认」；确认前 `manual_review=true`，该维度结论标「暂定」 |
| **关卡二 五门槛** | F1 营收 123.85 亿 ≥10 亿 ✅；F2 三年 CAGR 37.73% ≥15% ✅；F3 负债率 23.85% <60% ✅；F4 经营现金流 +22.95 亿 为正 ✅；F5 2023/2024/2025 扣非 11.91 / 13.88 / 15.50 亿 → 三年全正 ✅ → **五门槛全通过，无需触发科技豁免** |
| **关卡三 五大支柱** | V1 诚信闸门未命中；V2 报表 ROIC 未跌破 5%（须以实测 NOPAT/IC 代入）；V3 能力圈待确认；V4 须由 `garp-geo-policy` 出口透传 → S1 半导体设备景气（引用赛道出口）；S2 ROIC 与护城河量化；S3 管理层 ≥15 **且** 科研转化 ≥15；S4 八项敞口 + 赛道两分法；S5 政策覆盖 ≥中 且 基金介入非无覆盖 |
| **关卡四 镜子** | 五句话逐句标注；未确认句回填为待补齐信号 |
| **三档结论** | 若存在未确认维度或未判定项 → 输出「**暂定**」；仅当四段全部闭合且 S1~S5 全满足时给「可建仓」 |
