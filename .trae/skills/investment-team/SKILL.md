# 投研团队：四角色并行分析框架

对 $ARGUMENTS 进行团队化投资研究分析。四位大师并行研究，Team Lead 综合研判，产出系统化的公司投资研究报告。

**支持输入格式**：`公司名`，例如：`腾讯`、`拼多多`、`茅台`

## 设计理念

一份好的公司研究报告要解决三个问题：

1. **这门生意本质是什么？**——需要段永平视角，看商业模式和护城河
2. **财务质量怎么样？**——需要巴菲特视角，审财务数据和估值
3. **竞争格局如何？**——需要芒格视角，读行业变化和对手
4. **风险在哪里？**——需要李录视角，猎管理层信号和潜在风险

本 Skill 通过四Agent并行研究，Team Lead综合研判，产出完整、系统、可操作的投资研究报告。

---

## 执行流程

### 第一步：展示团队框架

向用户展示以下团队结构，确认后启动：

| 角色 | 职责 | 分析框架 |
|------|------|----------|
| **Team Lead**（你自己） | 统筹协调、汇总研判、输出最终报告 | 四大师综合框架 |
| **business-analyst** | 商业模式 & 护城河分析 | 段永平视角 |
| **financial-analyst** | 财务报表 & 估值分析 | 巴菲特视角 |
| **industry-researcher** | 行业格局 & 竞争态势 | 芒格视角 |
| **risk-assessor** | 风险评估 & 管理层研判 | 李录视角 |

---

### 第二步：信息丰富度评估

在创建团队前，先评估该公司的"AI可研究性"：

| 等级 | 特征 | 研究策略调整 |
|------|------|------------|
| **A级（信息充裕）** | 上市多年、券商覆盖广 | 团队重点放在**反面检验**和**非共识视角**，避免输出与市场一致的"正确的废话" |
| **B级（信息适中）** | 上市不久、覆盖有限 | 每个Agent的推算数据必须标注置信度，team-lead汇总时标注"数据充分度" |
| **C级（信息稀缺）** | 冷门/新上市/新兴市场 | 团队转为"第一性原理模式"：不追求报告完整性，聚焦商业本质的几个核心问题 |

**关键提醒**：资料多≠确定性高，资料少≠确定性低。AI能输出的置信度 ≠ 投资的真实确定性。确定性来自商业模式本身，不来自资料数量。

将评级结果告知每个Agent，影响其研究方式。

### 第三步：A股财报原文下载（优先执行，仅A股）

**重要流程**：对于A股公司，必须首先使用 `stock_equity.py` 工具下载原始财报PDF，**下载完成后方可进行下一步的阅读分析工作**。

```bash
# 下载最新年报PDF
python tools/stock_equity.py --code {股票代码} --download-report --report-type annual

# 下载最新半年报PDF（如需分析半年报）
python tools/stock_equity.py --code {股票代码} --download-report --report-type semiannual

# 下载最新季报PDF（如需分析季报）
python tools/stock_equity.py --code {股票代码} --download-report --report-type quarterly
```

下载的PDF文件保存在 `cninfo_reports/` 目录，文件命名格式：

- 年报：`{股票代码}_{年份}年报.pdf`
- 半年报：`{股票代码}_{年份}半年报.pdf`
- 季报：`{股票代码}_{年份}{季度}季报.pdf`

可使用 `--report-dir` 参数指定其他保存目录：

```bash
python tools/stock_equity.py --code 601899 --download-report --report-type annual --report-dir ./reports/紫金矿业
```

**流程检查点**：确认PDF文件下载成功后，方可启动后续的4个研究Agent。

**PDF文档阅读工具**（推荐Poppler工具集）：

- `pdftotext`：将PDF转换为文本格式
- `pdfinfo`：查看PDF文件信息
- `pdftoppm`：将PDF转换为图像

```bash
# 查看PDF文件信息
pdfinfo cninfo_reports/601899_2025年报.pdf

# 将PDF转换为文本文件
pdftotext cninfo_reports/601899_2025年报.pdf cninfo_reports/601899_2025年报.txt

# 将PDF转换为图像（用于扫描版PDF）
pdftoppm -png cninfo_reports/601899_2025年报.pdf cninfo_reports/601899_2025年报
```

**注意事项**：如果PDF无法提取信息，应在报告中标注"资料评级：B级"，说明扫描版PDF限制。

### 第四步：启动4个并行研究Agent

使用 Task 工具在**同一条消息**中启动4个后台Agent。

---

#### Agent 1：商业模式分析（段永平视角）

**核心问题：这是一门什么生意？好生意还是坏生意？**

> 段永平："投资就是买一门生意。好生意就是有差异化、有定价权、有可持续竞争优势的生意。"

分析内容：

1. **商业模式本质**
   - 核心生意定义：这家公司到底在做什么生意？
   - 收入结构拆解：各业务板块占比、增长趋势
   - 平台/产品飞轮效应如何运转
2. **护城河分析**
   - 品牌：品牌认知度、品牌溢价能力
   - 转换成本：客户离开的成本有多高？
   - 网络效应：用户越多价值越大吗？
   - 规模效应：规模越大成本越低吗？
   - 技术壁垒：核心技术是否难以复制？
3. **用户/客户价值**
   - 为用户创造了什么独特价值？
   - 如果明天公司关门，用户会不会非常痛苦？
4. **段永平"好生意"标准评估**
   - 差异化：产品/服务是否独一无二？
   - 定价权：能否提价而不流失客户？
   - 可持续竞争优势：10年后还能保持优势吗？
5. **业务矩阵与协同效应**
   - 各业务之间是否有协同？
   - 新业务是增强还是稀释核心优势？

**输出要求**：每个维度标注 🟢优势/🟡持平/🔴劣势，给出段永平式总结点评。

---

#### Agent 2：财务与估值分析（巴菲特视角）

**核心问题：这家公司赚的是真钱还是假钱？值不值这个价？**

> 巴菲特："会计数字是商业语言，但不是我关注的重点。我关注的是这门生意的经济特征。"

分析内容：

1. **核心财务数据提取与验证**
   - 近3-5年营收、净利润、经营利润趋势
   - 盈利能力指标：ROE、ROA、毛利率、经营利润率
   - 关键数据至少两个来源交叉验证
   ```bash
   python tools/financial_rigor.py cross-validate \
     --metric "revenue" --values {值1} {值2} --sources "来源1" "来源2"
   ```
2. **现金流分析（最重要）**
   - 经营性现金流、自由现金流、资本开支
   - 经营现金流 vs 净利润比率（>100%佳，<80%警惕）
   - 回购和分红金额
3. **资产负债表健康度**
   - 现金储备、负债率、流动性
   - 应收账款/存货周转天数变化
   - 商誉及无形资产减值风险
4. **估值分析**
   - PE/PS/PB/EV等，与历史及同业对比
   - 安全边际评估：内在价值 vs 当前股价
   ```bash
   python tools/financial_rigor.py verify-market-cap \
     --price {价格} --shares {股本} --reported {报告市值} --currency {币种}
   python tools/financial_rigor.py verify-valuation \
     --price {价格} --eps {EPS} --bvps {每股净资产}
   python tools/financial_rigor.py three-scenario \
     --price {价格} --eps {EPS} --shares {股本亿} \
     --growth {乐观} {中性} {悲观} --pe {乐观PE} {中性PE} {悲观PE}
   ```

**输出要求**：所有计算附工具输出记录，利润质量信号灯 🟢/🟡/🔴，巴菲特式总结点评。

---

#### Agent 3：行业与竞争分析（芒格视角）

**核心问题：这个行业在怎么变？这家公司处于什么位置？**

> 芒格："在商业世界，我们通常会去研究那些做对了的公司，但我会反过来想——那些公司为什么会失败？"

分析内容：

1. **行业规模与增长**
   - 市场规模、增速、渗透率
   - 行业处于生命周期的哪个阶段？
2. **竞争格局**
   - 主要对手市场份额、竞争策略对比
   - 核心竞争者威胁评估：逐个分析主要竞争对手
   - 各细分赛道格局
3. **行业趋势**
   - 技术变革：AI/新平台等技术影响
   - 政策影响：监管政策对竞争格局的影响
   - 新进入者威胁
4. **产业链分析**
   - 上中下游价值分配
   - 供应商/客户的议价能力
5. **芒格式逆向思考**
   - 什么会杀死这家公司？有哪些威胁信号？
   - 5年后回看，这个行业会变成什么样？

**输出要求**：竞争格局判断（加强/持平/恶化），竞争对手对比表，芒格式逆向点评。

---

#### Agent 4：风险与管理层评估（李录视角）

**核心问题：管理层靠谱吗？有什么风险？**

> 李录："投资最重要的是避免永久性资本损失。管理层是最重要的风险因子。"

分析内容：

1. **管理层评估**
   - CEO能力圈、诚信度、战略眼光
   - 资本配置能力、历史决策质量
   - 管理层言行一致性：说的和做的是否一致？
2. **监管风险**
   - 当前及潜在监管影响
   - 是否有监管"黑天鹅"风险？
3. **竞争风险**
   - 各竞争对手威胁程度评估
   - 护城河是否在弱化？
4. **业务风险**
   - 新业务亏损、扩张不确定性
   - 核心业务是否出现下滑信号？
5. **宏观风险**
   - 经济周期、行业周期影响
   - 宏观环境变化对公司的影响
6. **治理结构**
   - 股权结构、关联交易、股东回报政策
   - 是否有损害小股东利益的行为？
7. **长期确定性**
   - 10年后公司会怎样？
   - 什么可能颠覆其商业模式？

**输出要求**：管理层可信度评分★1-5，风险信号清单，李录式总结点评。

向用户实时展示：

```
━━━━━━━━━━━━━━━━━━━━━━━
研究阶段
  ⏳ 段永平·商业模式    分析中...
  ⏳ 巴菲特·财务估值    分析中...
  ⏳ 芒格·行业竞争      分析中...
  ⏳ 李录·风险管理层    分析中...
```

### 第六步：Team Lead 汇总最终报告

全部4份研究报告到齐后，Team Lead综合产出最终投资研究报告。

**汇总要点**——不是拼报告，是找交叉和矛盾：

1. **四个视角的共识点**：四位大师都同意的结论，可信度最高
2. **四个视角的矛盾点**：比如段永平说生意好，但芒格说竞争恶化——这种矛盾才是最有价值的分析
3. **被忽略的角落**：四个人都没重点提的东西，是否恰恰是最重要的？

#### 最终报告结构

```markdown
# {公司名} 投资研究报告
**四大师并行分析 | {日期}**

## 一、一句话结论
> 50-100字：是否值得投资及核心逻辑

## 二、四维评分总表
| 维度 | 框架 | 评分(1-5星) | 核心判断 |
|------|------|------------|----------|

综合评分：X / 5

## 三、核心数据速览
关键财务和经营指标表格（近2年对比）

## 四、各维度分析摘要
每个维度摘取3-5条最重要的发现

## 五、投资论点（Bull vs Bear）
- 🟢 看多逻辑（5-7条）
- 🔴 看空逻辑（5-7条）

## 六、巴菲特买入前Checklist
| # | 检查项 | 通过? | 说明 |
10个核心检查项，逐一评估

## 七、最终投资建议
- 定性判断表（生意质量/管理层/估值/时机）
- 分层操作建议表（激进型/稳健型/保守型 → 建议+价格区间）
- 关键催化剂（加仓信号/减仓信号各3-5条）

## 八、总结段落
100-200字的最终总结
```

## 工具使用指南

### 财务数据获取工具

#### A股数据

- 股票信息：`python tools/stock_info.py --search {公司名}`
- 财务指标：`python tools/stock_financial.py --code {股票代码}`
- 股票行情：`python tools/stock_quote.py --code {股票代码}`
- 股权结构：`python tools/stock_equity.py --code {股票代码}`
- 财务报表下载：`python tools/stock_equity.py --code {股票代码} --download-report --report-type {annual|semiannual|quarterly}`
  - 支持下载年报、半年报、季报（PDF格式，从巨潮资讯网获取）
  - 年报示例：`python tools/stock_equity.py --code 601899 --download-report --report-type annual`
  - 半年报示例：`python tools/stock_equity.py --code 601899 --download-report --report-type semiannual`
  - 季报示例：`python tools/stock_equity.py --code 601899 --download-report --report-type quarterly`

#### 港股数据

- 股票信息与财务：`python tools/stock_info_hk.py --financial {股票代码}`
- 股票行情：`python tools/stock_quote_hk.py --code {股票代码}`

### 财务计算与验证工具

- 精确计算：`python tools/financial_rigor.py`（PE、ROE、市值校验等）
- 报告审核：`python tools/report_audit.py`（数据抽检）

### 网络信息获取

#### A股公司

- 网络搜索：`python tools/web_search.py "{搜索关键词}"`（阿里云百炼 WebSearch）

#### 港股/美股公司（非国内上市）

- **优先使用 Tavily 搜索**：`python tools/tavily_search.py "{搜索关键词}" --max-results 5`
  - Tavily 提供更高质量的内容和更详细的信息
  - 返回 title、url、content 三个字段
  - 支持高级搜索（search_depth="advanced"）
- **备选 WebSearch**：`python tools/web_search.py "{搜索关键词}"`
  - 作为补充信息源

#### 重要内容（同时调用）

对于港股/美股的重要研究，建议**同时调用两个工具**，互为补充：

- Tavily 搜索：获取详细内容和深度分析
- WebSearch 搜索：获取更多来源和不同视角

**示例**：

```bash
# 同时调用两个工具（并行执行）
python tools/tavily_search.py "腾讯 商业模式 护城河"
python tools/web_search.py "腾讯 商业模式 护城河"
```

**注意**：WebSearch/WebFetch 在中国大陆不可用，所有网络信息必须使用本地工具。

## 数据抽检（准出流程）

对最终报告执行抽检：

```bash
python tools/report_audit.py extract \
  --report reports/{公司名}/{公司名}-research-{YYYYMMDD}.md

python tools/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report {报告文件名}
```

**【准出】** 全部通过 → 可发布；**【打回】** 有不通过 → 修正后重审。

## 注意事项

1. **4个Agent必须并行启动**——在同一条消息中调用4次Task工具
2. **数据准确性**——关键数据至少来自两个独立来源，使用 financial_rigor.py 工具验算
3. **结论要明确**——不回避给出买入/观望/回避建议和具体价格区间
4. **所有分析必须有数据支撑**——附数据来源
5. **呈现正反两面**——每个核心判断都必须附带反面论据
6. **不预设立场**——不预设看多或看空，先摆数据、再推逻辑、最后得结论
7. **信息稀缺时的诚实原则**——宁可在报告中留白标注"数据不足"，也不要用推测填满框架伪装确定性
8. **反偏见意识**——team-lead在汇总时必须评估：各Agent的分析是否受限于资料充裕度？是否与市场共识过度趋同？

---

## 局限性

1. **信息可得性**：港股小票、新上市公司可能无法获取到完整信息
2. **扫描版PDF限制**：A股年报常为扫描版PDF，可能无法提取文本内容，影响附注分析
3. **语言限制**：非中英文财报可能无法准确解读
4. **非实时数据**：工具获取的数据可能有延迟，不是实时数据
5. **AI解读局限**：AI无法完全替代专业财务分析师的深度分析能力
6. **并行执行复杂度**：4个Agent并行执行可能需要较长时间
7. **不构成投资建议**：本技能仅用于学习与研究，不构成任何投资建议
