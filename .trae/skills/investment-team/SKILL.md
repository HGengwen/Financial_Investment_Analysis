# 投研团队：四角色并行分析框架

对 $ARGUMENTS 进行团队化投资研究分析。四位大师并行研究，Team Lead 综合研判，产出系统化的公司投资研究报告。

**支持输入格式**：`公司名`，例如：`腾讯`、`拼多多`、`茅台`

## 设计理念

一份好的公司研究报告要解决三个问题：

1. **这门生意本质是什么？**——需要段永平视角，看商业模式和护城河
2. **财务质量怎么样？**——需要巴菲特视角，审财务数据和估值
3. **竞争格局如何？**——需要芒格视角，读行业变化和对手
4. **风险在哪里？**——需要李录视角，猎管理层信号和潜在风险

本 Skill 通过四Agent并行研究，Team Lead综合研判，产出完整、系统、可操作的投资研究报告。

---

## 执行流程

### 第一步：展示团队框架

向用户展示以下团队结构，确认后启动：

| 角色                          | 职责                             | 分析框架       |
| ----------------------------- | -------------------------------- | -------------- |
| **Team Lead**（你自己） | 统筹协调、汇总研判、输出最终报告 | 四大师综合框架 |
| **business-analyst**    | 商业模式 & 护城河分析            | 段永平视角     |
| **financial-analyst**   | 财务报表 & 估值分析              | 巴菲特视角     |
| **industry-researcher** | 行业格局 & 竞争态势              | 芒格视角       |
| **risk-assessor**       | 风险评估 & 管理层研判            | 李录视角       |

---

### 第二步：信息丰富度评估

在创建团队前，先评估该公司的"AI可研究性"：

| 等级                      | 特征                 | 研究策略调整                                                                           |
| ------------------------- | -------------------- | -------------------------------------------------------------------------------------- |
| **A级（信息充裕）** | 上市多年、券商覆盖广 | 团队重点放在**反面检验**和**非共识视角**，避免输出与市场一致的"正确的废话" |
| **B级（信息适中）** | 上市不久、覆盖有限   | 每个Agent的推算数据必须标注置信度，team-lead汇总时标注"数据充分度"                     |
| **C级（信息稀缺）** | 冷门/新上市/新兴市场 | 团队转为"第一性原理模式"：不追求报告完整性，聚焦商业本质的几个核心问题                 |

**关键提醒**：资料多≠确定性高，资料少≠确定性低。AI能输出的置信度 ≠ 投资的真实确定性。确定性来自商业模式本身，不来自资料数量。

将评级结果告知每个Agent，影响其研究方式。

### 第三步：A股财报原文下载（优先执行，仅A股）

**重要流程**：对于A股公司，必须首先使用 `stock_equity.py` 工具下载原始财报PDF，**下载完成后方可进行下一步的阅读分析工作**。

```bash
# 下载最新年报PDF
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type annual

# 下载最新半年报PDF（如需分析半年报）
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type semiannual

# 下载最新季报PDF（如需分析季报）
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type quarterly
```

下载的PDF文件保存在 `cninfo_reports/` 目录，文件命名格式：

- 年报：`{股票代码}_{年份}年报.pdf`
- 半年报：`{股票代码}_{年份}半年报.pdf`
- 季报：`{股票代码}_{年份}{季度}季报.pdf`

可使用 `--report-dir` 参数指定其他保存目录：

```bash
python tools/a_share/stock_equity.py --code 601899 --download-report --report-type annual --report-dir ./reports/紫金矿业
```

**流程检查点**：确认PDF文件下载成功后，方可启动后续的4个研究Agent。

**PDF文档阅读工具**（推荐Poppler工具集）：

- `pdftotext`：将PDF转换为文本格式
- `pdfinfo`：查看PDF文件信息
- `pdftoppm`：将PDF转换为图像

```bash
# 查看PDF文件信息
pdfinfo cninfo_reports/601899_2025年报.pdf

# 将PDF转换为文本文件
pdftotext cninfo_reports/601899_2025年报.pdf cninfo_reports/601899_2025年报.txt

# 将PDF转换为图像（用于扫描版PDF）
pdftoppm -png cninfo_reports/601899_2025年报.pdf cninfo_reports/601899_2025年报
```

**注意事项**：如果PDF无法提取信息，应在报告中标注"资料评级：B级"，说明扫描版PDF限制。

### 第四步：启动4个并行研究Agent

使用 Task 工具在**同一条消息**中启动4个后台Agent。

---

#### Agent 1：商业模式分析（段永平视角）

**核心问题：这是一门什么生意？好生意还是坏生意？**

> 段永平："投资就是买一门生意。好生意就是有差异化、有定价权、有可持续竞争优势的生意。"

分析内容：

1. **商业模式本质**
   - 核心生意定义：这家公司到底在做什么生意？
   - 收入结构拆解：各业务板块占比、增长趋势
   - 平台/产品飞轮效应如何运转
2. **护城河分析**
   - 品牌：品牌认知度、品牌溢价能力
   - 转换成本：客户离开的成本有多高？
   - 网络效应：用户越多价值越大吗？
   - 规模效应：规模越大成本越低吗？
   - 技术壁垒：核心技术是否难以复制？
3. **用户/客户价值**
   - 为用户创造了什么独特价值？
   - 如果明天公司关门，用户会不会非常痛苦？
4. **段永平"好生意"标准评估**
   - 差异化：产品/服务是否独一无二？
   - 定价权：能否提价而不流失客户？
   - 可持续竞争优势：10年后还能保持优势吗？
5. **业务矩阵与协同效应**
   - 各业务之间是否有协同？
   - 新业务是增强还是稀释核心优势？

**输出要求**：每个维度标注 🟢优势/🟡持平/🔴劣势，给出段永平式总结点评。

---

#### Agent 2：财务与估值分析（巴菲特视角）

**核心问题：这家公司赚的是真钱还是假钱？值不值这个价？**

> 巴菲特："会计数字是商业语言，但不是我关注的重点。我关注的是这门生意的经济特征。"

分析内容：

1. **核心财务数据提取与验证**
   - 近3-5年营收、净利润、经营利润趋势
   - 盈利能力指标：ROE、ROA、毛利率、经营利润率
   - 关键数据至少两个来源交叉验证

   ```bash
   python tools/common/financial_rigor.py cross-validate \
     --metric "revenue" --values {值1} {值2} --sources "来源1" "来源2"
   ```
2. **现金流分析（最重要）**
   - 经营性现金流、自由现金流、资本开支
   - 经营现金流 vs 净利润比率（>100%佳，<80%警惕）
   - 回购和分红金额
3. **资产负债表健康度**
   - 现金储备、负债率、流动性
   - 应收账款/存货周转天数变化
   - 商誉及无形资产减值风险
4. **估值分析**
   - PE/PS/PB/EV等，与历史及同业对比
   - 安全边际评估：内在价值 vs 当前股价

   ```bash
   python tools/common/financial_rigor.py verify-market-cap \
     --price {价格} --shares {股本} --reported {报告市值} --currency {币种}
   python tools/common/financial_rigor.py verify-valuation \
     --price {价格} --eps {EPS} --bvps {每股净资产}
   python tools/common/financial_rigor.py three-scenario \
     --price {价格} --eps {EPS} --shares {股本亿} \
     --growth {乐观} {中性} {悲观} --pe {乐观PE} {中性PE} {悲观PE}
   ```

**输出要求**：所有计算附工具输出记录，利润质量信号灯 🟢/🟡/🔴，巴菲特式总结点评。

---

#### Agent 3：行业与竞争分析（芒格视角）

**核心问题：这个行业在怎么变？这家公司处于什么位置？**

> 芒格："在商业世界，我们通常会去研究那些做对了的公司，但我会反过来想——那些公司为什么会失败？"

分析内容：

1. **行业规模与增长**
   - 市场规模、增速、渗透率
   - 行业处于生命周期的哪个阶段？
2. **竞争格局**
   - 主要对手市场份额、竞争策略对比
   - 核心竞争者威胁评估：逐个分析主要竞争对手
   - 各细分赛道格局
3. **行业趋势**
   - 技术变革：AI/新平台等技术影响
   - 政策影响：监管政策对竞争格局的影响
   - 新进入者威胁
4. **产业链分析**
   - 上中下游价值分配
   - 供应商/客户的议价能力
5. **芒格式逆向思考**
   - 什么会杀死这家公司？有哪些威胁信号？
   - 5年后回看，这个行业会变成什么样？

**输出要求**：竞争格局判断（加强/持平/恶化），竞争对手对比表，芒格式逆向点评。

---

#### Agent 4：风险与管理层评估（李录视角）

**核心问题：管理层靠谱吗？制度可持续吗？有什么风险？**

> 李录："投资最重要的是避免永久性资本损失。优秀的单个CEO不可持续，完善的公司治理制度才是长久保障。"

**李录视角的特殊定位**：芒格嫡传第三代，从「文明演化 + 制度可持续」视角审视管理层。把管理层放置在现代化文明、制度组织、人类行为学框架下分析，更适合研究大型龙头、百年企业。差异化于其他三位大师：不只是评估"人"，更是评估"制度"。

分析内容：

##### 第一部分：管理层评估（李录四层框架）

1. **第一层：管理层的价值观与长期文明观**
   - 是否尊重市场经济底层规律、法治规则、契约精神，不依赖非市场化套利
   - 是否具备可持续发展的长期视角，不只追逐单季度利润，愿意为企业长期内在价值投入
   - 诚信是基石：会计真实、信息披露完整，把中小股东和大股东一视同仁
   - **红线触发**：财务造假、关联交易输送利益、频繁误导市场 → **一票否决**，直接判定C级

2. **第二层：治理结构 > 单个管理者（对抗人性短期冲动）**
   - **李录最大的差异化观点**：优秀的单个CEO不可持续，完善的公司治理制度才是长久保障
   - 重点考察：董事会独立性、高管制衡机制、股权架构、股东保护条款、继任者培养体系
   - 底层逻辑：人性天然追求短期利益，再好的管理者也会衰老、懈怠，靠制度约束远比靠个人道德靠谱
   - 直接承接芒格的逆向思维，用制度规避管理者道德风险与能力退化风险
   - 评估要点：是否存在创始人/实控人"一言堂"、关联交易是否透明公允、是否有清晰的接班人梯队

3. **第三层：资本配置能力 + 穿越周期的商业判断力**
   - 和巴菲特一脉相承，自由现金流使用效率是核心考核指标
   - 要求管理层具备宏观周期判断力：能预判行业技术迭代、宏观经济波动、竞争格局变化
   - 在泡沫期收缩、低谷期布局（考察历史决策记录：行业高峰期是否克制扩张、低谷期是否逆势加码）
   - 拒绝管理层被市场热点裹挟，跟风炒作概念、盲目烧钱
   - 资本行为是照妖镜：回购、分红、并购、减持、薪酬政策直接暴露管理层真实想法

4. **第四层：本土化适配（针对A股市场）**
   - 管理层是否合规经营、敬畏政策与行业监管
   - 避免政策黑天鹅导致企业价值清零
   - 评估要点：行业监管敏感度、政策导向契合度、历史合规记录、ESG与社会责任履行

##### 第二部分：风险评估

5. **监管风险**（与第四层本土化适配呼应）
   - 当前及潜在监管影响
   - 是否有监管"黑天鹅"风险？
6. **竞争风险**
   - 各竞争对手威胁程度评估
   - 护城河是否在弱化？
7. **业务风险**
   - 新业务亏损、扩张不确定性
   - 核心业务是否出现下滑信号？
8. **宏观风险**
   - 经济周期、行业周期影响
   - 宏观环境变化对公司的影响
9. **长期确定性**
   - 10年后公司会怎样？
   - 什么可能颠覆其商业模式与制度根基？

**输出要求**：
- 管理层四层框架评分表（每层★1-5）
- 制度可持续性评级（A=制度完善可持续 / B=制度基本健全 / C=依赖个人、制度脆弱）
- 红线触发标注（是/否 + 触发项）
- 风险信号清单
- 李录式总结点评（必须明确回答："这家公司10年后还在吗？靠制度还是靠人？"）

### 第六步：Team Lead 汇总最终报告

全部4份研究报告到齐后，Team Lead综合产出最终投资研究报告。

**汇总要点**——不是拼报告，是找交叉和矛盾：

1. **四个视角的共识点**：四位大师都同意的结论，可信度最高
2. **四个视角的矛盾点**：比如段永平说生意好，但芒格说竞争恶化——这种矛盾才是最有价值的分析
3. **被忽略的角落**：四个人都没重点提的东西，是否恰恰是最重要的？

#### 最终报告结构

```markdown
# {公司名} 投资研究报告
**四大师并行分析 | {日期}**

## 一、一句话结论
> 50-100字：是否值得投资及核心逻辑

## 二、四维评分总表
| 维度 | 框架 | 评分(1-5星) | 核心判断 |
|------|------|------------|----------|

综合评分：X / 5

## 三、核心数据速览
关键财务和经营指标表格（近2年对比）

## 四、各维度分析摘要
每个维度摘取3-5条最重要的发现

## 五、管理层深度评估（李录四层框架）
本章节为李录视角的核心输出，从「文明演化 + 制度可持续」视角系统评估管理层。

### 5.1 管理层四层框架评分表
| 层次 | 评估维度 | 评分(1-5星) | 核心判断 | 关键证据 |
|------|---------|------------|----------|----------|
| 第一层 | 价值观与长期文明观 | | | |
| 第二层 | 治理结构与制度可持续性 | | | |
| 第三层 | 资本配置与周期判断力 | | | |
| 第四层 | 本土化合规与监管适配 | | | |

### 5.2 制度可持续性评级
- 评级：A / B / C（A=制度完善可持续 / B=制度基本健全 / C=依赖个人、制度脆弱）
- 红线触发：是 / 否（触发项：______）
- 核心理据：李录式回答——"这家公司10年后还在吗？靠制度还是靠人？"

### 5.3 治理结构专项分析
- 董事会独立性、高管制衡机制、股权架构
- 接班人培养体系（如适用：管理层年龄≥60或任期≥15年需重点分析）
- 关联交易透明度与小股东保护

## 六、投资论点（Bull vs Bear）
- 🟢 看多逻辑（5-7条）
- 🔴 看空逻辑（5-7条）

## 七、巴菲特买入前Checklist
| # | 检查项 | 通过? | 说明 |
10个核心检查项，逐一评估

## 八、最终投资建议
- 定性判断表（生意质量/管理层/估值/时机）
- 分层操作建议表（激进型/稳健型/保守型 → 建议+价格区间）
- 关键催化剂（加仓信号/减仓信号各3-5条）

## 九、总结段落
100-200字的最终总结
```

### investment-team 的特殊工具使用注意

1. **A股财报下载是前置流程**：A股公司必须先执行第三步的 `stock_equity.py --download-report` 下载年报 PDF，提取一手数据后再启动 4 个研究 Agent
2. **港股公司数据获取**：使用 `tools/hk_stock/stock_financial.py --financial {代码}` 获取财务指标（ROE/毛利率/净利率等），港股历史行情用 `tools/hk_stock/stock_quote.py`。港股无 A股的 `stock_equity.py` 财报下载工具，年报一手数据需从 HKEX 披露易获取（可用豆包搜索 `--sites hkex.com.hk` 定向检索公告，或浏览器手动下载 PDF 后按 [pdf-extraction](../tools-scripts/pdf-extraction.md) 流程提取）。东方财富港股接口连接不稳定（非地理封锁），工具已内置重试机制
3. **美股公司数据获取**：使用 `tools/us_stock/` 三个模块（stock_info/stock_quote/stock_financial），详见 [美股工具使用指南](../../../docs/美股工具使用指南.md)
4. **4 个 Agent 的财务计算须用 financial_rigor.py 验算**：Agent 2（巴菲特视角）的核心财务数据必须使用 `tools/common/financial_rigor.py` 交叉验证，**禁止 LLM 心算** PE/ROE/市值等（具体命令见 Agent 2 分析内容）
5. **网络信息搜索优先使用豆包搜索**：支持 `--finance`（财经定向+权威信源）、`--need-content`（抓正文）、`--export`（导出 Markdown）、`--sites`（定向 SEC/港交所披露易），多源验证规范详见 [web-search-tools](../tools-scripts/web-search-tools.md)
6. **大宗商品相关公司须获取价格数据**：Agent 3（芒格视角·行业与竞争分析）在分析涉及大宗商品产业链的公司（如矿业、能源、新能源材料等）时，须使用 `tools/common/commodity_price.py` 获取相关品种价格，辅助判断公司盈利趋势与行业景气度

### 网络搜索多源验证示例

对于港股/美股的重要研究，建议以豆包搜索为主，Tavily 和 WebSearch 互为补充：

```bash
# 主：豆包搜索（正文 + 权威度 + 报告导出）
python tools/common/doubao_search.py "腾讯 商业模式 护城河" --need-content --export

# 补充1：Tavily（深度内容，适合管理层讨论、分析师点评）
python tools/common/tavily_search.py "腾讯 商业模式 护城河"

# 补充2：WebSearch（多源视角，交叉验证）
python tools/common/web_search.py "腾讯 商业模式 护城河"
```

**WebSearch/WebFetch 在中国大陆不可用，所有网络信息必须使用本地工具。**

## 数据抽检（准出流程）

报告写入后必须执行数据抽检，通过方可发布。具体流程详见 **[报告审核与数据抽检](../tools-scripts/report-audit.md)**。

```bash
# Step 1 - 提取抽检清单（15%随机抽样）
python tools/common/report_audit.py extract \
  --report reports/{公司名}/{公司名}-research-{YYYYMMDD}.md

# Step 2 - 对清单每项从可靠信源取数（按市场分别使用对应工具）
#   A股：tools/a_share/stock_financial.py（东方财富主） -> 巨潮资讯副 -> 年报PDF原始一手
#   港股：tools/hk_stock/stock_financial.py（aastocks/东方财富） -> HKEX披露易
#   美股：tools/us_stock/stock_financial.py（Yahoo Finance） -> SEC EDGAR
#   计算验算：tools/common/financial_rigor.py（禁止 LLM 心算）

# Step 3 - 输出准出/打回判决
python tools/common/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report {公司名}-research-{YYYYMMDD}.md
```

**【准出】** 全部通过 → 报告可发布；**【打回】** 有不通过 → 修正后重审。

## 注意事项

1. **4个Agent必须并行启动**——在同一条消息中调用4次Task工具
2. **数据准确性**——关键数据至少来自两个独立来源，使用 financial_rigor.py 工具验算
3. **结论要明确**——不回避给出买入/观望/回避建议和具体价格区间
4. **所有分析必须有数据支撑**——附数据来源
5. **呈现正反两面**——每个核心判断都必须附带反面论据
6. **不预设立场**——不预设看多或看空，先摆数据、再推逻辑、最后得结论
7. **信息稀缺时的诚实原则**——宁可在报告中留白标注"数据不足"，也不要用推测填满框架伪装确定性
8. **反偏见意识**——team-lead在汇总时必须评估：各Agent的分析是否受限于资料充裕度？是否与市场共识过度趋同？
9. **李录视角的四层框架必须完整应用**——Agent 4 不能只评估"人"，更要评估"制度"：价值观文明观 → 治理结构 → 资本配置周期判断 → 本土化合规。第一层红线触发即整体判定C级，直接进入"回避"建议
10. **管理层信息覆盖时效**——管理层评估须覆盖最近12个月动态，需双源验证（豆包搜索 + Tavily），信息缺口必须标注，不得用推测填补

## 局限性

1. **信息可得性**：港股小票、新上市公司可能无法获取到完整信息
2. **扫描版PDF限制**：A股年报常为扫描版PDF，可能无法提取文本内容，影响附注分析
3. **语言限制**：非中英文财报可能无法准确解读
4. **非实时数据**：工具获取的数据可能有延迟，不是实时数据
5. **AI解读局限**：AI无法完全替代专业财务分析师的深度分析能力
6. **并行执行复杂度**：4个Agent并行执行可能需要较长时间
7. **不构成投资建议**：本技能仅用于学习与研究，不构成任何投资建议

| 层次 | 评估维度 | 评分 | 核心判断 | 关键证据 |
