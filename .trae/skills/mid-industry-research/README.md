# 中期行业景气研究 (Mid Industry Research)

对 1~3 年景气赛道做深度研究，输出「四维筛选 + 产业链卡脖子环节 + 景气周期定位 + 头部公司清单 + 多技能交叉验证」的系统判断。属于 1-3 年中期链的研究入口技能，与长期 `industry-research`（10 年护城河）物理隔离、功能互补。

---

## 快速开始

### 基本调用方式

```
/mid-industry-research {行业名} [--scope 全球|A股|港股|美股] [--depth fast|standard|deep] [--export] [--json]
```

例如：

- `/mid-industry-research AI光模块`
- `/mid-industry-research 人形机器人 --scope A股 --depth deep --export`
- `/mid-industry-research 创新药 --scope 全球 --json`

---

## 核心功能

对指定行业执行「四维筛选 → 产业链卡脖子 → 全球扫描分层 → 头部打分 → 周期定位 → 四项交叉验证 → 组合配置 → 卖出预览」完整流程。

### 四维门槛速查卡（硬编码）

| 维度 | 通过标准 | 一票否决 |
| --- | --- | --- |
| ① 产业空间 | TAM≥1000 亿 且 3年CAGR≥20% | TAM≤500亿 且 CAGR≤15% → R-1 |
| ② 渗透率位置 | 10%~30% 黄金区 | <5% 且无业绩 → R-2；>50% 已过黄金区 → R-9 |
| ③ 业绩兑现 | 连续 2 季营收>行业平均 + 毛利率稳/升 | 题材炒作（无财报/均亏损）→ R-3 |
| ④ 地缘政治 | 海外<30% 低风险 | 实体清单且无抗封锁能力 → R-4 |

综合评级：A（四维全过）/ B（三维过）/ C（未达门槛）/ 拒绝（题材或地缘否决）。仅 A/B 可进入 `mid-trend-tech-screen`。

### 渗透率二阶导（李进）

```text
渗透率加速上行（二阶导为正）→ 景气扩散
渗透率减速上行（二阶导转负）→ 接近增速峰值，警惕
```

### 卡脖子环节 6 标准

供给集中度≤2家 / 扩产周期>2年 / 替代难度高 / 产能利用率>80% / 需求增速>30% / 客户验证周期长。

### 景气周期四阶段

| 阶段 | 渗透率 | 策略 |
| --- | --- | --- |
| 技术跃迁期 | 5%~15% | 积极布局 |
| 需求爆发期 | 10%~20% | **重仓参与** |
| 供给受限期 | 20%~35% | 持有为主 |
| 成熟稳定期 | >40% | 逐步兑现 |

## 使用示例

### 示例1：黄金区赛道（I-2 用例）

```
/mid-industry-research {某TAM=2000亿、CAGR=25%、渗透率20%的赛道}
```

判定黄金区，评级 A/B，输出头部公司四维打分 + 卡脖子环节 + 景气周期 + 四项交叉验证。

### 示例2：门槛不足（I-1 用例）

```
/mid-industry-research {某TAM=500亿、CAGR=15%的赛道}
```

明确输出「未达 TAM≥1000亿 / 增速≥20% 门槛」，触发 R-1，评级 C/拒绝，终止四维判断。

### 示例3：题材炒作（I-3 用例）

```
/mid-industry-research {某营收翻倍但扣非净利润为负的赛道}
```

维度三一票否决，触发 R-3，输出「题材炒作，拒绝」。

### 示例4：成熟赛道（I-4 用例）

```
/mid-industry-research {某渗透率=55%的赛道}
```

触发 R-9，标注「已过黄金区」，建议逐步退出，不进入正向排序。

### 关键约束

- **禁止 LLM 心算**：TAM/CAGR/PEG/打分加权一律走 `financial_rigor.py`。
- **数据双源验证**：关键数据 ≥2 来源，误差 >1% 标记。
- **渗透率三级置信度**：A 级（官方）/ B 级（券商转引）/ C 级（媒体估算，不得作确定性结论）。
- **中期术语红线**：禁止「护城河永续」「终局思维」「持有10年」。

## 与 `industry-research` 的选型对照

| 维度 | `mid-industry-research`（本技能） | `industry-research`（长期） |
| --- | --- | --- |
| 时间维度 | 1~3 年景气周期 | 10 年永续经营 |
| 核心框架 | 郑希/李进产业景气周期定位 | 李录文明趋势判断 |
| 估值锚 | PEG、渗透率、增速加速度 | DCF、护城河永续性 |
| 关键追问 | 「未来 4 个季度订单能见度如何？」 | 「10 年后护城河还在吗？」 |
| 卖出指引 | 渗透率减速 / ROE 拐头 / PEG>2 / 时间止损 | 护城河崩塌 |

**选型规则**：研究 1-3 年景气赛道用本技能；研究 10 年护城河/文明趋势用 `industry-research`。

## R-1~R-10 风控速查

| 编号 | 规则 |
| --- | --- |
| R-1 | TAM≤500亿 且 CAGR≤15% → 不满足中期投资门槛，不得推荐 |
| R-2 | 渗透率<5% 且无业绩兑现 → 过早，不参与 |
| R-3 | 全行业无一家连续 2 季盈利 → 纯概念阶段，不得推荐 |
| R-4 | 龙头在实体清单且无抗封锁能力 → 回避，不得以「利空出尽」推荐 |
| R-5 | 任一龙头触发 P0 → 必须最先输出 P0，禁止跳过 |
| R-6 | 持有满 4 季度逻辑未兑现 → 时间止损预警 |
| R-7 | 估值/市值/PEG 计算必须走 `financial_rigor.py` |
| R-8 | 单一来源数据 → 标注「低置信度」，不得作确定性结论 |
| R-9 | 渗透率>50% → 已过黄金区，逐步退出 |
| R-10 | 行业多数头部 PEG>2 → 严重透支，大幅减仓 |

## 核心原则

1. **四维先行、硬门槛一票否决** — 题材炒作、地缘否决立即终止。
2. **渗透率二阶导为准** — 不看绝对值，看增速的加速度。
3. **连续 3 季不靠单季** — ROE 拐点以连续 3 季同向为准。
4. **禁止心算** — 所有数值来自 `financial_rigor.py` 或数据工具。
5. **只出赛道结论，不给个股价位** — 估值归 `valuation-thermometer`，卖出归 `exit-signal`。

---

## 注意事项

- 开始前运行 `date` 确认当天日期，报告头部注明数据截止日期。
- 关键数据须双源交叉验证，误差 >1% 标记。
- 禁止使用 WebSearch / WebFetch（中国大陆不可用），统一用本地搜索工具。
- 地缘风险必须显式折价（中风险 -10%~-20%，高风险 -20%~-40%）。

---

## 局限性说明

- 只输出赛道结论与候选清单，不判断个股买卖价位。
- 新兴赛道 TAM/渗透率数据可能不可得，按证据链原则回退「无法判断」，禁止编造。
- 地缘维度主观性强，以六维硬编码 + 三级 + 韧性四子项约束，不量化打分。
- 行业级结论不等同于个股结论。
