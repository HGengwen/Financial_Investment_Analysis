# 中期行业景气研究（1-3年）：四维筛选 + 产业链卡脖子 + 景气周期定位

对 1~3 年景气赛道做深度研究，输出「**四维筛选 + 产业链卡脖子环节 + 景气周期定位 + 头部公司清单 + 多技能交叉验证**」的系统判断，回答「这赛道未来 1-3 年景气向上吗？值不值得进？」。属于中期链（1-3 年）研究入口技能，与长期 `industry-research`（10 年护城河/文明趋势）**物理隔离、功能互补**，禁止使用「护城河永续」「终局思维」「持有10年」等长期框架术语。

## 设计原则

1. **四维先行、硬门槛一票否决**：TAM / 渗透率 / 业绩兑现 / 地缘四维全过才算合格赛道，任何一项触发硬否决（题材炒作、地缘一票否决）立即终止，不进入后续分析。
2. **渗透率二阶导为准**：不看渗透率绝对值高低，看「增速的加速度」（李进二阶导）；加速上行→景气扩散，减速上行→接近增速峰值。
3. **连续 3 季不靠单季**：ROE 拐点、业绩兑现一律以连续 3 季同向为准，单季波动判噪音（对齐矛盾二）。
4. **禁止 LLM 心算**：TAM 换算、CAGR、PEG、隐含增速、打分加权一律经 `financial_rigor.py`，报告不得出现手算数值。
5. **数据双源验证**：关键数据 ≥2 独立来源，误差 >1% 显式标记；渗透率数据按来源分 A/B/C 三级置信度。
6. **地缘风险必须显式折价**：海外依赖/供应链/制裁/抗封锁韧性六维评估，中高风险必须给出估值折价区间，不得「利空出尽」一笔带过。
7. **只出赛道结论与候选清单**：不判断个股买卖价位（归 `mid-trend-tech-screen`/`exit-signal`），只输出赛道评级、头部公司分层与卖出预览。

## 调用参数（技能调用约定，非新增命令行开关）

以下参数为技能调用时的解析约定，由 AI 解析并映射到既有工具调用与执行流程，**不新增任何 Python 命令行开关**（Sprint 3 零代码开发原则）：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `{行业名}` | 位置参数 | 是 | — | 赛道/行业名，如「AI 光模块」「人形机器人」「创新药」 |
| `--scope` | 字符串 | 否 | 全球 | 研究范围：`全球`/`A股`/`港股`/`美股` |
| `--depth` | 字符串 | 否 | standard | `fast`（仅四维筛选+周期定位）/ `standard`（追加头部公司+卡脖子+组合建议）/ `deep`（追加在研项目扫描） |
| `--export` | 标志 | 否 | false | 导出 Markdown 报告至 `reports/`（未开启则仅在对话内输出） |
| `--export-path` | 字符串 | 否 | reports/ | 报告输出根路径（配合 `--export` 使用） |
| `--json` | 标志 | 否 | false | 输出结构化 JSON（供下游解析） |

**参数语义映射**：

- `--scope`：决定「全球扫描」步骤的搜索范围与数据工具（A 股/港股/美股/全球混合）。本技能不使用 `--mode`，研究范围用 `--scope`；技能名已含 `mid-` 前缀，与 `thesis-tracker`/`portfolio-review` 的 `--horizon` 不冲突。
- `--depth`：`fast` 只输出四维筛选 + 周期定位（供快速初筛）；`standard` 追加产业链卡脖子 + 头部公司四维打分 + 组合配置；`deep` 再叠加在研项目扫描（`in_research_scan.py`）。
- `--export`：未开启时仅在对话内呈现结论，不写文件；开启时按 `--export-path` 落盘。
- `--json`：开启时输出结构化 JSON（字段见「输出结果」节），关闭时输出 Markdown。

## 核心判定规则（硬编码）

### 规则一：四维筛选验证（第一步，对齐理念文档第 1 步）

#### 维度一：产业空间（TAM ≥ 1000 亿，复合增速 ≥ 20%）

| 检查项 | 通过标准 |
| --- | --- |
| 行业潜在市场规模（TAM） | ≥ 1000 亿元 |
| 未来 3 年复合增速（CAGR） | ≥ 20% |
| 市场空间可验证性 | ≥2 个独立来源，差异 >30% 时列出全部来源并标注「需人工判断」 |

处理逻辑：

```text
IF TAM ≥ 1000 亿 AND 3年CAGR ≥ 20%:
    → 通过，进入维度二
ELIF TAM ≤ 500 亿 AND 3年CAGR ≤ 15%:
    → 触发 R-1，评级 C/拒绝，终止四维判断（不得推荐）
ELIF TAM < 1000 亿 OR CAGR < 20%:
    → 标注「市场规模或增速不足，降低优先级」，评级 ≤B，不得重仓推荐
IF 数据来源冲突（差异 >30%）:
    → 标注「需核实」，该维度置信度降级
```

#### 维度二：渗透率位置（10%~30% 黄金区，15% 加速临界，50% 兑现分水岭）

| 渗透率区间 | 评级 | 投资策略 |
| --- | --- | --- |
| < 5% | 过早 | 不参与，保持观察 |
| 5%~10% | 萌芽期 | 少量观察仓，仅限高风险承受者 |
| **10%~30%** | **黄金区** | **积极布局，重仓参与** |
| 30%~50% | 成长期 | 持有为主，机动仓逐步兑现 |
| > 50% | 成熟期 | 逐步退出，仅保留底仓 |

**二阶导验证（李进「增速的加速度」）**：

```text
渗透率加速上行（二阶导为正）→ 景气扩散，可积极布局
渗透率减速上行（二阶导转负）→ 接近增速峰值，需警惕，减机动仓
```

**渗透率数据质量分级**（须交叉验证）：

| 置信度 | 来源 | 处理 |
| --- | --- | --- |
| A 级 | 行业协会官方 / 权威统计 | 可直接引用 |
| B 级 | 券商研报转引 | 需至少再找 1 个独立来源 |
| C 级 | 媒体估算 | 仅作参考，不得作为确定性结论 |

#### 维度三：业绩兑现度（连续 2 个季度验证）

| 验证维度 | 通过标准 |
| --- | --- |
| 营收增速 | 连续 2 季 > 行业平均 |
| 毛利率 | 连续 2 季稳定或提升 |
| 行业整体盈利 | 龙头已盈利，二线扭亏 |
| 利润 vs 营收匹配度 | 利润增速跟上营收增速，否则警惕费用失控 |

判定口径：

```text
强兑现：营收>行业平均 且 毛利率稳/升 且 利润增速跟上营收增速
弱兑现：增收不增利（营收>行业 但 利润增速显著落后或为负）
未兑现：营收<行业平均
题材炒作：无头部公司财报 或 头部公司均亏损 → 一票否决（触发 R-3）
```

**先行指标验证**：合同负债环比↑（未来收入加速）；存货合理↑（备货景气）；研发费用持续↑（企业信心）。

#### 维度四：地缘政治风险敞口（含「华为式」抗封锁韧性）

六维评估：海外收入依赖度 / 供应链安全 / 制裁与清单风险 / 本地化对冲能力 / 政策与合规环境 / **自主研发抗压韧性**。

「华为式」抗封锁韧性四子项：

| 子项 | 强韧性标准 |
| --- | --- |
| ① 研发投入强度与持续性 | 研发费用率 >15% 且逆周期不减 |
| ② 核心技术自主可控 | 掌握底层专利/工艺，而非仅集成组装 |
| ③ 「备胎计划」与替代方案 | 已储备国产替代/第二供应商 |
| ④ 极端情形生存能力 | 制裁后能否靠替代市场维持现金流 |

综合评级与估值修正：

```text
🟢 低风险：海外收入<30% + 供应链可控 + 无制裁 + 韧性强 → 无估值修正
🟡 中风险：海外 30%~50% + 有对冲 → 估值折价 -10%~-20%
🔴 高风险：海外>50% + 无对冲 + 制裁风险 + 韧性弱 → 降低行业优先级，估值折价 -20%~-40%
```

#### 综合赛道评级（硬编码输出）

```text
A 级：四维全过
B 级：三维通过，一项待观察
C 级：未达门槛（TAM/渗透率）或业绩未兑现
拒绝：题材炒作（维度三一票否决）或地缘一票否决
```

> 仅评级 A/B 才允许进入 `/mid-trend-tech-screen` 正向排序。

### 规则二：产业链全景图 + 卡脖子环节识别（第二步）

绘制「上游→中游→下游→辅助」产业链结构，叠加**全球产业链利润分配视角**（郑希框架：哪个环节 ROE 率先向上，优先配置哪个）。

**卡脖子环节识别（6 条标准，全满足为强卡脖子）**：

| # | 标准 | 阈值 |
| --- | --- | --- |
| 1 | 供给集中度 | ≤ 2 家主导 |
| 2 | 扩产周期 | > 2 年 |
| 3 | 替代难度 | 高（技术/专利/工艺壁垒） |
| 4 | 产能利用率 | > 80% |
| 5 | 需求增速 | > 30% |
| 6 | 客户验证周期 | 长（客户切换成本高） |

> 卡脖子环节即「咽喉位置」，是第二、三层投资机会的主要来源（衔接 `bottleneck-hunter`）。

### 规则三：全球上市公司扫描 + 确定性分层（第三步）

| 层级 | 条件 | 仓位建议 |
| --- | --- | --- |
| Tier 1 | 大市值、纯正标的、行业龙头 | 核心仓位（底仓） |
| Tier 2 | 中市值、纯正或高占比、细分龙头 | 卫星仓位 |
| Tier 3 | 小市值、开发阶段、高风险高弹性 | 机动仓 |
| Tier 4 | 多元化公司中有相关业务 | 观察仓或回避 |

必须标注**未上市关键玩家**（独角兽/初创，可能是未来 IPO 后的竞争格局变量）。

### 规则四：头部公司四维打分排序（第四步）

| 维度 | 权重 | 打分标准 |
| --- | --- | --- |
| 产业景气度 | 35% | 供需格局、价格趋势、CR3 集中度 |
| 基本面 | 30% | ROE 趋势、毛利率、营收利润匹配度 |
| 管理层与科研 | 20% | 诚信度、战略聚焦、科研转化（详见 `mid-management-deep-dive`） |
| 地缘政治 | 15% | 海外依赖、供应链、制裁、抗封锁韧性 |

综合评分（加权计算，禁 LLM 心算，走 `financial_rigor.py calc`）：

```text
≥80 → S 级（核心仓位候选）
65~79 → A 级（卫星仓位候选）
50~64 → B 级（机动仓/观察）
<50 → C 级（回避）
```

### 规则五：产业景气周期定位（第五步，中期与长期最关键区分点）

| 阶段 | 特征 | 渗透率位置 | 投资策略 |
| --- | --- | --- | --- |
| 技术跃迁期 | 新技术突破、供给创造需求 | 5%~15% | 积极布局，关注技术路线 |
| 需求爆发期 | 订单爆发、供给紧缺、价格上行 | 10%~20% | **重仓参与**（ROE 向上斜率最陡） |
| 供给受限期 | 产能瓶颈、价格维持高位 | 20%~35% | 持有为主，关注产能释放 |
| 成熟稳定期 | 增速放缓、竞争加剧、价格下行 | >40% | 逐步兑现，机动仓退出 |

**ROE 拐点判断（郑希框架）**：

```text
连续 3 季向上 → 拐点确认，积极配置
连续 3 季向下 → 景气下行，警惕
季度波动 → 噪音，不判拐点（对齐矛盾二规则）
```

### 规则六：多技能交叉验证（第六步，Sprint 3 核心价值）

| 联动技能 | 验证内容 | 判定输出 |
| --- | --- | --- |
| implied-growth（`financial_rigor.py`） | 行业头部公司加权隐含增速 vs 实际预期增速 | 🟢绿灯（隐含≤实际）/ 🟡黄灯（隐含>实际但<2倍）/ 🔴红灯（隐含>实际2倍） |
| qoq-accelerator | 头部公司加速度汇总 → 行业加速度矩阵 | 多数加速=行业加速；分化=精选个股；多数减速=景气拐点预警 |
| trend-momentum-scan | 行业 ETF 动量（SMR/RSI50/MA50 vs MA200/抛售日频率） | 基本面×技术面交叉矩阵；**背离时以基本面（qoq 加速度）为准** |
| valuation-thermometer | 头部公司 PEG 五档汇总 → 行业整体温度 | 多数<0.8 显著低估 / 多数0.8~1.2 合理 / 多数1.2~1.5 偏贵 / 多数>1.5 高估 / 多数>2 严重透支 |
| mid-thesis-drift | 本报告结论作为漂移检测基线假设 | 输出漂移触发条件清单 |

> 交叉验证的目的是「用多个独立视角互相证伪」，任一红灯不得忽略，须在报告显式标注并给出处理建议。

### 规则七：组合配置建议（第七步，对齐理念文档仓位规则）

- **仓位结构**：行业 ETF 20%~40%；龙头白马（Tier 1）30%~50%；成长黑马（Tier 2）15%~25%；期权标的（Tier 3）5%~15%。
- **行业仓位上限**：需求爆发/技术跃迁期 40%；供给受限期 25%；成熟稳定期 15%（单一行业不超过总资产 40%）。
- **底仓/机动仓**：底仓 60%~80%（赚 1~3 年成长的钱）、机动仓 20%~40%（赚估值波动的钱）。
- **分批建仓**：进入黄金区且估值合理先建 1/3 底仓 → 恐慌/短暂利空（逻辑未破坏）加 1/3 → 景气加速或财报超预期补齐 1/3。
- **矛盾一化解（止损 vs 越跌越买）**：建仓初期（<最终仓位 50%）下跌超 8% → 止损优先；底仓已建且三维度未恶化 → 可估值下限加仓；逻辑被证伪 → 立即清仓。**核心原则：杀估值可逆向，杀逻辑必须止损。**

### 规则八：卖出条件预览（第八步，对齐 exit-signal V1.0 P0~P5）

| 级别 | 触发条件 | 操作 |
| --- | --- | --- |
| P0 治理一票否决 | 行业龙头管理层诚信问题、财务造假实锤、监管立案 | **立即清仓**，不看估值趋势 |
| P1 硬止损 | 行业 ETF/核心标的单笔亏损 8%~10% 且无基本面反转 | 无条件止损 |
| P2 逻辑止损 | 头部公司连续 2 季业绩低于预期且景气未改善；或持有满 4 季度逻辑未兑现（时间止损） | 减仓或清仓 |
| P3 景气拐点 | 渗透率增速转负（二阶导转负）；或头部公司 ROE 连续 3 季向下 | 减机动仓 |
| P4 估值透支 | 行业整体 PEG>1.5 → 减机动仓；PEG>2 → 加速清机动仓 | 减/清机动仓 |
| P5 性价比替换 | 其他行业 PEG 显著更低且产业趋势更强 | 调仓（每季度最多 1 次） |

> 本报告为**行业级预警**；个股级卖出需调用 `exit-signal` 执行完整 P0~P5 检查。

## 执行流程

### 第一步：解析输入与调用参数，确定行业与范围

- 解析 `{行业名}`、`--scope`、`--depth`、`--export`、`--export-path`、`--json`。
- 运行 `date` 确认当天日期，作为报告「数据截止日期」基准。
- `--scope` 决定后续搜索与数据工具范围。

### 第二步：四维筛选验证

按「规则一」逐维验证，任一维度触发硬否决（R-1/R-2/R-3/R-4）立即终止并输出否决结论，不再进入后续步骤。

### 第三步：产业链全景图 + 卡脖子环节

按「规则二」绘制产业链结构，识别卡脖子环节。

### 第四步：全球扫描 + 确定性分层

按「规则三」扫描上市公司，输出 Tier 1~4 分层 + 未上市关键玩家。

### 第五步：头部公司四维打分

按「规则四」对 Tier 1/2 头部公司打分排序（`--depth` 为 `fast` 时跳过本步）。

### 第六步：景气周期定位 + ROE 拐点

按「规则五」判断四阶段位置与 ROE 趋势。

### 第七步：多技能交叉验证

按「规则六」执行四项交叉验证（`--depth` 为 `fast` 时仅执行 implied-growth + qoq 两项）。

### 第八步：组合配置 + 卖出预览 + 输出报告

按「规则七/规则八」给出组合配置建议与 P0~P5 卖出预览，按「输出结果」节固定模板落盘。

## 工具软件使用指南

### 固化命令（零开发，复用既有工具）

```bash
# 确认日期（研究质量规则 1）
date

# 搜索赛道/产业链/地缘信息（A股财经首选）
python tools/common/anysearch.py "{行业名} 产业链 渗透率 TAM" --tag finance --count 10 --zone cn --json --export

# 实时资讯/舆情（火山引擎）
python tools/common/doubao_search.py "{行业名} 景气 订单 渗透率" --finance --time-range month --need-content --content-format markdown --json --export

# 美股深度研究（SEC filings 直击原文）
python tools/common/exa_search.py "{行业英文名} industry penetration TAM" --type deep

# 港美股深度内容辅源
python tools/common/tavily_search.py "{行业名} 渗透率 产业链"

# 头部公司财务（按市场）
python tools/a_share/stock_financial.py --code {code} --indicator ROE,毛利率,营业总收入,归母净利润
python tools/hk_stock/stock_financial.py --financial {code}
python tools/us_stock/stock_financial.py --code {code}

# 头部公司动量/技术面（含板块截面）
python tools/a_share/stock_quote.py --code {code} --momentum --auto-peers

# 估值/隐含增速/PEG 计算（禁 LLM 心算）
python tools/common/financial_rigor.py peg --price {p} --eps {eps} --growth {g}
python tools/common/financial_rigor.py implied-growth --market-cap {cap} --target-pe {pe} --net-margin {margin} --ttm-revenue {revenue} --guidance-growth {growth}

# 在研重大项目扫描（--depth deep 时）
python tools/specialized/in_research_scan.py scan {公司名} --market {sz|sh|hk|us} --count 10 --json --export
```

### 关键约束

- 所有算术（TAM 换算、CAGR、PEG、隐含增速、打分加权）必须经 `financial_rigor.py calc` 执行，禁止 LLM 心算。
- 关键数据 ≥2 独立来源，误差 >1% 显式标记；渗透率按 A/B/C 三级置信度标注。
- 报告中的每个数值必须能追溯到对应命令输出或来源。

## 与 mid-trend-tech-screen / exit-signal / mid-thesis-drift 联动映射（硬编码）

| 本技能输出 | 目标技能 | 映射 |
| --- | --- | --- |
| 赛道评级 A/B | `mid-trend-tech-screen` | 进入五维正向排序的准入条件 |
| 渗透率位置 + 二阶导 | `exit-signal` P3 | 渗透率增速转负（二阶导转负）→ P3 核心触发之一 |
| 头部公司 ROE 连续 3 季向下 | `exit-signal` P3 | 产业景气拐点触发之一 |
| 行业整体 PEG>1.5 / >2 | `exit-signal` P4 | 估值透支减/清机动仓 |
| 本报告 H1~H6 结论 | `mid-thesis-drift` | 作为漂移检测的基线假设（Sprint 3 消费） |
| 卡脖子环节清单 | `bottleneck-hunter` | 第二、三层投资机会输入 |

> 渗透率位置是 P3 的**核心输入之一**，本技能兑现 `qoq-accelerator` 承诺的「P3 渗透率位置由 `mid-industry-research` 提供」。

## 风控硬编码（R-1~R-10，不允许 AI 自由裁量）

| 编号 | 规则 | 不可做的事 |
| --- | --- | --- |
| R-1 | TAM≤500 亿 且 CAGR≤15% → 必须标注「不满足中期投资门槛」 | 不得推荐 |
| R-2 | 渗透率<5% 且无业绩兑现 → 标注「过早，不参与」 | 不得推荐建仓 |
| R-3 | 全行业无一家公司连续 2 季盈利 → 标注「纯概念阶段」 | 不得推荐 |
| R-4 | 行业龙头已在实体清单且无抗封锁能力 → 标注「回避」 | 不得以「利空出尽」为由推荐 |
| R-5 | 任一龙头触发 P0 → 必须最先输出 P0 | 禁止跳过 P0 |
| R-6 | 持有满 4 季度行业逻辑未兑现 → 标注「时间止损预警」 | 不得忽略时间止损 |
| R-7 | 所有估值/市值/PEG 计算必须走 `financial_rigor.py` | 禁止 LLM 心算 |
| R-8 | 关键数据仅单一来源 → 标注「单一来源，置信度低」 | 不得作为确定性结论 |
| R-9 | 渗透率>50% → 标注「已过黄金区」 | 建议逐步退出，不得进入正向排序 |
| R-10 | 行业多数头部公司 PEG>2 → 标注「严重透支」 | 建议大幅减仓 |

> 所有硬性规则输出必须包含规则编号引用（如「触发 R-1」），确保可审计可追溯。

## 注意事项

1. 开始前运行 `date` 确认当天日期，报告头部注明数据截止日期。
2. 关键财务数据须至少两个独立来源交叉验证，误差 >1% 须标记。
3. 禁止 LLM 心算，所有 TAM/CAGR/PEG/打分加权经 `financial_rigor.py`。
4. 渗透率数据按 A/B/C 三级置信度标注，C 级不得作确定性结论。
5. 禁止使用 WebSearch / WebFetch 工具（中国大陆不可用），统一用 anysearch/doubao_search/exa_search/tavily_search/web_search。
6. 中期术语红线：禁止出现「护城河永续」「终局思维」「持有10年」等长期框架术语。

## 局限性

1. 本技能只输出赛道结论与候选清单，不判断个股买卖价位（归 `mid-trend-tech-screen`/`exit-signal`）。
2. 新兴赛道 TAM/渗透率数据可能不可得，须标注「数据缺口/低置信度」并按证据链原则回退「无法判断」，禁止编造。
3. 地缘政治维度主观性强，本技能以六维硬编码 + 低/中/高三级 + 抗封锁韧性四子项约束，不量化打分。
4. 头部公司四维打分中的「管理层与科研」维度依赖 `mid-management-deep-dive`，本技能仅作快速评估。
5. 行业级结论不等同于个股结论，个股需另行研究。

## 与其他Skill的关系

- **前置**：`mid-trend-tech-screen`（景气趋势五维筛选，本技能 A/B 评级是它的准入条件）、`mid-management-deep-dive`（管理层深度评估，供打分维度三）。
- **后置**：`mid-industry-funnel`（赛道内个股级漏斗精选，本技能 A/B 评级是它的准入条件）、`exit-signal`（本技能 P3 渗透率/ROE、P4 估值透支输出）、`mid-thesis-drift`（本报告结论作为漂移基线）、`bottleneck-hunter`（卡脖子环节输入）。
- **同级**：`industry-research`（长期产业链全景，本技能与它物理隔离、功能互补）、`industry-funnel`（长期精选个股）。
- **边界**：只出赛道结论与候选清单，不出个股买卖价位；渗透率数据是本技能对 `exit-signal` P3 的专属供给。
