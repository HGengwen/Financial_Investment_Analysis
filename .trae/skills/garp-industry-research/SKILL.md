# GARP 行业研究（1~5 年）：从「赛道是否值得配置」到「产业链哪一环最挣钱」

对 $ARGUMENTS 执行 GARP 行业研究。本技能属**行业层首站（框架第 1 步·赛道选择）**——只回答「行业本身是否值得配置」，**不给个股结论**、不做估值档位判定、不定义卖出级别、不定义仓位比例。

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

**支持输入格式**：

- `{行业名}` —— 赛道 / 行业名，如 `AI 光模块` / `人形机器人` / `半导体设备`
- `{行业名} {子赛道}` —— 可选子赛道细分（如 `半导体设备 光刻`），用于收窄扫描范围
- `{行业名} --depth deep` —— 深度参数（`fast` / `standard` / `deep`）

> **本技能不提供档位切换参数**——它即 GARP 独立档（1~5 年）行业研究专属入口，命令与输入中**不含任何档位切换开关**；档位切换类口令属其他档位口径，在本技能中出现即违反**口径隔离**纪律（见「注意事项」第 1 条与「与其他 garp- 技能的关系」）。

## 设计原则

1. **六维先行、硬门槛一票否决**：产业空间 / 渗透率位置 / 国产化率位置 / 业绩兑现度 / 题材辨别 / 地缘敞口六项全过才算合格赛道；**题材炒作**与 **0.3 矩阵「回避」档**为**一票否决**，命中即终止，不进入后续分析。
2. **渗透率管择时、国产化率管弹性**：渗透率定位产业阶段（管「何时买」），国产化率定位国产企业可替代空间（管「标的成长弹性」）；科技赛道两者叠用，非科技赛道国产化率记「不适用」。
3. **地缘以 0.3 三维交叉矩阵落位**：地缘**不做**「敞口打分 + 估值折价」，只作**矩阵归档 + 硬门槛 / 敞口体检**；估值折价**统一由 `garp-valuation` 承载**（避免双重计价）。
4. **连续 2 季不靠单季**：业绩兑现度一律以**连续 2 个季度**同向为准，单季波动判噪音。
5. **禁止 LLM 心算**：TAM 换算、CAGR、PEG、隐含增速、加权打分一律经 `financial_rigor.py`，报告不得出现手算数值。
6. **双源交叉验证 + 时变项实时核验**：关键数据 ≥2 独立来源，误差 >1% 显式标记；制裁清单 / 出口管制 / 风险行业清单 / 国产化率均为**时变项**，评估前须**实时核验**，禁止沿用历史清单。
7. **只出赛道结论与候选清单**：不判断个股买卖价位、不重定义卖出级别与估值档位，只输出赛道评级、产业链咽喉环节、头部公司分层与卖出预览。

**参数语义映射**：

- `--scope`：决定「全球扫描」步骤的搜索范围与数据工具（A 股 / 港股 / 美股 / 全球混合）。

## 核心判定规则（硬编码）

### 规则一：六维筛选验证（第一步，对齐框架第 1 步）

#### 维度一：产业空间（TAM ≥ 1000 亿，未来 3 年复合增速 ≥ 20%）

| 检查项 | 通过标准 |
| --- | --- |
| 行业潜在市场规模（TAM） | ≥ 1000 亿元 |
| 未来 3 年复合增速（CAGR） | ≥ 20% |
| 市场空间可验证性 | ≥2 个独立来源，差异 >30% 时列出全部来源并标注「需人工判断」 |

处理逻辑：

```text
IF TAM >= 1000 亿 AND 3年CAGR >= 20%:
    -> 通过，进入维度二
ELIF TAM <= 500 亿 OR 3年CAGR <= 15%:
    -> 触发 GI-1，评级 C / 拒绝，终止筛选判断（不得推荐）
ELIF TAM < 1000 亿 OR CAGR < 20%:
    -> 标注「市场规模或增速不足，降低优先级」，评级 <=B，不得重仓推荐
IF 数据来源冲突（差异 >30%）:
    -> 标注「需核实」，该维度置信度降级
```

#### 维度二：渗透率位置（15%~40% 黄金窗口）

| 渗透率区间 | 档位 | 投资动作 |
| --- | --- | --- |
| < 5% | 导入早期 | 不确定性高，**观察不建仓** |
| 5%~15% | 突破期 | 高弹性，**小仓跟踪** |
| **15%~40%** | **加速上行期** | **黄金建仓窗口，主建仓** |
| 40%~60% | 逐步兑现期 | 持有，**不再新建仓** |
| > 60% | 天花板 | **不加仓**；增速归零 / 转负即**见顶清仓** |

**配套门槛**：TAM ≥ 1000 亿 **且** 未来 3 年复合增速 ≥ 20%。

**斜率观察（定性）**：渗透率加速上行（二阶导为正）→ 景气扩散；减速上行（二阶导转负）→ 接近增速峰值，需警惕。本技能**只作定性观察**，不设数值阈值。

**渗透率数据质量分级**（须交叉验证）：

| 置信度 | 来源 | 处理 |
| --- | --- | --- |
| A 级 | 行业协会官方 / 权威统计 | 可直接引用 |
| B 级 | 券商研报转引 | 需至少再找 1 个独立来源 |
| C 级 | 媒体估算 | 仅作参考，不得作为确定性结论 |

> 渗透率**无独立工具出口**（缺口登记于 U1）；未取得权威数据时标注「**未验证**」并给区间上限下限，**不得因未验证而默认落黄金区**。

#### 维度三：国产化率位置（科技赛道专用）

| 国产化率区间 | 档位 | 投资动作 |
| --- | --- | --- |
| < 5% | 过早 | 不确定性高；**战略必争卡脖子环节**（如光刻）可作**高风险高弹性观察 / 小仓，非回避** |
| 5%~20% | 突破期 | 从 0 到 1，高弹性，**跟踪 / 小仓** |
| 20%~50% | 加速投资期 | **订单放量** |
| > 50% | 替代空间收窄 | 逻辑转向**龙头份额提升与整机放量**，**不再押注「从 0 到 1」的替代弹性** |

**分工（刚性）**：**渗透率管择时**（定位产业阶段，管「何时买」）；**国产化率管弹性**（定位国产企业可替代空间，管「标的成长弹性」）；**科技赛道两者叠用**。非科技赛道该维度记「**不适用**」，**不得**因不适用而扣分或放行。

**取数**：`geo_policy_screen.py localize --industry {环节} --localization-rate {百分比}`（国产化率四档判定）；战略必争环节加 `--strategic-choke-point`。

#### 维度四：业绩兑现度（连续 2 个季度验证）

| 验证维度 | 通过标准 |
| --- | --- |
| 营收增速 | 连续 2 季 > 行业平均 |
| 毛利率 | 连续 2 季稳定或提升 |
| 行业整体盈利 | 龙头已盈利，二线扭亏 |
| 利润 vs 营收匹配度 | 利润增速跟上营收增速，否则警惕费用失控 |

判定口径：

```text
强兑现：营收 > 行业平均 且 毛利率稳 / 升 且 利润增速跟上营收增速
弱兑现：增收不增利（营收 > 行业 但 利润增速显著落后或为负）
未兑现：营收 < 行业平均
纯概念：全行业无一家公司连续 2 季盈利 -> 触发 GI-7，一票否决
```

**先行指标验证**：合同负债环比上升（未来收入加速）；存货合理上升（备货景气）；研发费用持续上升（企业信心）。

#### 维度五：题材辨别（扣非匹配营收）

| 检查项 | 通过标准 |
| --- | --- |
| EPS 支撑 | 头部公司须有**实际 EPS 支撑**，非仅概念、意向订单或远期规划 |
| 扣非匹配 | **扣非净利润增速须匹配营收增速**；显著背离即警惕「题材注水」 |
| 概念纯度 | 纯概念、无业绩支撑 -> **一票否决**（评级「拒绝」） |

> 题材辨别为**一票否决维度**：命中即评级「拒绝」，不得以「预期先行」为由放行。

#### 维度六：地缘政治敞口（0.3 三维交叉矩阵 + 赛道两分法）

**0.3 三维交叉矩阵（框架原文，照引不改）**：

| 地缘倒逼强度 | 政策覆盖度 | 国字号基金介入 | 投资含义 |
| --- | --- | --- | --- |
| 高（已制裁 / 断供） | 高（超常规 + 全链条） | 有直接注资 | **最优场景**：替代确定性与节奏被外部力量锁定 |
| 高 | 中 | 有专项子基金 | **次优场景**：方向明确，节奏受技术突破制约 |
| 中（制裁升级中） | 高 | 有覆盖 | **潜伏场景**：提前布局等待催化 |
| 高（已制裁 / 断供） | 低 / 无 | 无覆盖 | **高风险 / 回避**：须先验证承接能力，不足则回避 |
| 低 | 中 / 高 | 有覆盖 / 注资 | **政策驱动型增量创造**：达标以政策覆盖 + 基金介入为准 |
| 低 | 低 | 无覆盖 | **回避**：替代节奏完全依赖市场驱动 |

**三条刚性附带条款**：

1. **未列组合处理**：凡未显式列出的中间组合，一律按**更审慎的相邻档位**归档，**不得因未列而默认放行**；
2. **国字号基金注资 ≠ 估值依据**：仅视为「政策优先序列」信号，最终决策**回到估值与业绩兑现框架**；
3. **时序同步**：制裁清单、出口管制、风险行业清单、国产化率均为**时变项**，评估前**须实时核验**，**勿沿用历史清单**。

**赛道两分法**：

| 类型 | 代表 | 地缘维度作用 | 达标判定 |
| --- | --- | --- | --- |
| **地缘倒逼型**（半导体设备 / 材料等） | 被制裁 / 断供 → 被迫替代 | 地缘倒逼强度**硬门槛**（非「低 / 无」方可建仓） | 同时以政策资本（0.3 矩阵）验证能否接住 |
| **政策资本驱动型**（机器人、信创等） | 政策创造需求 + 基金催化 | **仅作敞口体检**（海外收入 / 供应链 / 冲突暴露可控） | 达标与否交由政策资本维度判定 |

**判别入口**：先看 0.3 矩阵的**行归属**；两类**非互斥**，介于其间时**按更审慎的那类执行**。

**取数**：`geo_policy_screen.py screen --geo {高/中/低} --policy {高/中/低/无} --fund {有直接注资/有专项子基金/有覆盖/无覆盖}`（输出矩阵行、赛道类型与归档结论）；地缘矩阵结论引用 `garp-geo-policy`（P4-1，已交付）。

#### 综合赛道评级（硬编码输出）

```text
A 级：六维全过
B 级：五维通过，一项待观察
C 级：未达门槛（TAM / 渗透率 / 国产化率）或业绩未兑现
拒绝：题材炒作（维度五 一票否决）或 0.3 矩阵归「回避」档（维度六 一票否决）
```

> 仅评级 A / B 才允许进入 `garp-trend-tech-screen`（P4-11，已交付，**仅指向名称**）的正向排序。

### 规则二：产业链全景图 + 卡脖子环节识别（第二步）

绘制「上游→中游→下游→辅助」产业链结构，叠加**全球产业链利润分配视角**（哪个环节 ROE 率先向上，优先配置哪个）。

**卡脖子环节识别（6 条标准，全满足为强卡脖子）**：

| # | 标准 | 阈值 |
| --- | --- | --- |
| 1 | 供给集中度 | ≤ 2 家主导 |
| 2 | 扩产周期 | > 2 年 |
| 3 | 替代难度 | 高（技术 / 专利 / 工艺壁垒） |
| 4 | 产能利用率 | > 80% |
| 5 | 需求增速 | > 30% |
| 6 | 客户验证周期 | 长（客户切换成本高） |

> 卡脖子环节即「咽喉位置」，是第二、三层机会来源（承接 `garp-bottleneck-hunter`，P4-18，已交付，**仅指向名称**）。

### 规则三：全球上市公司扫描 + 确定性分层（第三步）

| 层级 | 条件 | 仓位措辞 |
| --- | --- | --- |
| Tier 1 | 大市值、纯正标的、行业龙头 | 核心仓位（底仓） |
| Tier 2 | 中市值、纯正或高占比、细分龙头 | 卫星仓位 |
| Tier 3 | 小市值、开发阶段、高风险高弹性 | 机动仓 |
| Tier 4 | 多元化公司中有关联业务 | 观察仓或回避 |

必须标注**未上市关键玩家**（独角兽 / 初创，可能是未来 IPO 后的竞争格局变量）。

> **仓位比例不重复定义**：本技能只给**层级-仓位对应关系**，具体比例口径**引用** `garp-portfolio-review`（P4-8，已交付；底仓 60%~80% / 机动仓 20%~40%）。
### 规则四：头部公司四维打分排序（第四步）

| 维度 | 权重 | 打分标准 | 口径出口（GARP 档） |
| --- | :--: | --- | --- |
| 产业景气度 | 35% | 供需格局、价格趋势、CR3 集中度 | 工具 + 搜索 |
| 基本面 | 30% | ROE 趋势、毛利率、营收利润匹配度 | `stock_financial.py` + `financial_rigor.py` |
| 管理层与科研 | 20% | 诚信度、战略聚焦、科研转化 | **引用 `garp-management`**（P4-4，已交付；诚信前置 + 7+7+6 + 科研转化） |
| 地缘政治 | 15% | 海外依赖、供应链、制裁、抗封锁韧性 | **引用 0.3 矩阵 + 赛道两分法** |

综合评分（`financial_rigor.py calc` 加权，**禁心算**）：

```text
>=80 -> S 级（核心仓位候选）
65~79 -> A 级（卫星仓位候选）
50~64 -> B 级（机动仓 / 观察）
<50 -> C 级（回避）
```

> 地缘维度权重**保持 15%**（门禁 G-1）；权重口径**不因赛道类型差异化**，赛道差异已由 `GI-6` 硬门槛承载。

### 规则五：景气周期定位 + ROE 拐点（第五步）

| 阶段 | 特征 | 定性定位 | 与本技能渗透率档位的对应（定性） |
| --- | --- | --- | --- |
| 技术跃迁期 | 新技术突破、供给创造需求 | 定性推断 | 多落「导入早期 / 突破期」 |
| 需求爆发期 | 订单爆发、供给紧缺、价格上行 | 定性推断 | 多落「加速上行期」 |
| 供给受限期 | 产能瓶颈、价格维持高位 | 定性推断 | 「加速上行期」后段 |
| 成熟稳定期 | 增速放缓、竞争加剧、价格下行 | 定性推断 | 「逐步兑现期 / 天花板」 |

**ROE 趋势（定性观察）**：以头部公司 ROE 趋势方向作定性描述（向上 / 走平 / 向下），**只作观察、不设阈值**。

> **纪律（门禁 D-1）**：景气周期定位**保持定性**——定性定位 + ROE 趋势观察；结论**必须显式标注「定性推断」**。框架**未定义**行业级「ROE 拐点」量化判据（缺口登记于 U2），本技能**不得**自设 ROE 拐点阈值。

### 规则六：多技能交叉验证（第六步）

| 联动技能 | 验证内容 | 判定输出 |
| --- | --- | --- |
| implied-growth（`financial_rigor.py`） | 行业头部公司加权隐含增速 vs 实际预期增速 | 绿灯（隐含 ≤ 实际）/ 黄灯（隐含 > 实际但 < 2 倍）/ 红灯（隐含 > 实际 2 倍） |
| `qoq-accelerator`（复用 2 技能） | 头部公司加速度汇总 -> 行业加速度矩阵 | 多数加速 = 行业加速；分化 = 精选个股；多数减速 = 景气拐点预警 |
| `trend-momentum-scan`（复用 2 技能） | 行业动量（SMR / RSI50 / MA50 vs MA200 / 抛售日频率） | 基本面 × 技术面交叉矩阵；**背离时以基本面（qoq 加速度）为准** |
| `garp-valuation`（P4-5，已交付） | 头部公司**统一六档** + **多工具矩阵**汇总 -> 行业整体估值水位 | 只读其档位结论，本技能**零 PEG 算式** |

> 交叉验证的目的是「用多个独立视角互相证伪」，任一红灯不得忽略，须在报告显式标注并给出处理建议。
>
> **引擎口径提示**：`trend_tech_screen.py` 的地缘维度当前仍为二维，与 0.3 三维交叉矩阵存在差异（缺口登记于 U5）；引擎签名与维度**本技能不改**，工具侧扩展归 P4-23。

### 规则七：组合配置建议（第七步）

- **层级-仓位对应**：Tier 1 核心仓位（底仓）/ Tier 2 卫星仓位 / Tier 3 机动仓 / Tier 4 观察仓或回避。
- **比例口径引用**：底仓与机动仓比例（底仓 60%~80% / 机动仓 20%~40%）、单只与单一行业上限、现金口径**一律引用** `garp-portfolio-review`（P4-8，已交付），本技能**不重复定义比例**。
- **建仓节奏**：分批建仓与估值联动节奏**引用** `garp-valuation`（P4-5，已交付），本技能不给建仓节奏数值。
- **矛盾化解（引用式）**：杀估值可逆向、杀逻辑必须止损；具体阈值与执行归 `garp-exit`（P4-6，已交付）。本技能只给**行业层建议**，**不替用户决策**。

### 规则八：卖出条件预览（第八步，引用 `garp-exit` 五级 + 时间止损）

> **本表只做「检查」，不做「定义」**——级别定义、阈值、动作归属 `garp-exit`（P4-6，**已交付**）；本技能**逐级检查并转接**。

| 级别 | 触发条件（引用 `garp-exit` 口径） | 本技能动作 |
| --- | --- | --- |
| **一级 · 诚信否决** | 行业龙头管理层诚信问题暴露、财务造假实锤、监管立案 | 立即给**清仓预警**，不看估值趋势 |
| **二级 · 硬止损** | 行业 ETF / 核心标的单笔亏损 **8%~10%** 且无明确基本面反转信号 | 转 `garp-exit` 止损执行 |
| **三级 · 逻辑止损** | 头部公司连续 2 季低于预期且景气未改善；财务不可逆恶化；龙头被颠覆 | 转 `garp-exit` 处置 |
| **四级 · 产业景气判断** | 渗透率 / ROE 拐点（景气尚可仅节奏放缓）；增速归零或转负 | 减机动仓 / 升级清仓（转 `garp-exit`） |
| **五级 · 估值判断** | 调整后 PEG > 1.5（> 2 严重透支）；情绪多信号共振 | 底仓不动，机动仓调整 |

**补充机制**：**时间止损**——持有满 4 季度行业逻辑未兑现 -> 输出「**时间止损预警**」（`GI-12`），承接 `garp-exit` 时间止损。

> 任一命中 -> **必须最先输出**该级结论，立即停止后续检查，报告醒目注明级别（`GI-11`）。

### 关键约束

- 所有算术（TAM 换算、CAGR、PEG、隐含增速、打分加权）必须经 `financial_rigor.py calc` 执行，**禁止 LLM 心算**（`GI-9`）。
- 关键数据 ≥2 独立来源，误差 >1% 显式标记；渗透率按 A / B / C 三级置信度标注。
- 报告中的每个数值必须能追溯到对应命令输出或来源。
- **禁用** 内置 WebSearch / WebFetch（中国大陆不可用），统一用取数五工具。

### 降级与失败处置

| 场景 | 处置 |
| --- | --- |
| 搜索无结果 / 单一来源 | 标「单一来源，置信度低」（`GI-8`）；**不得**作为确定性结论 |
| 渗透率 / 国产化率无权威数据 | 标「**未验证**」并给区间上限下限；**不得**因未验证而默认落黄金区 |
| 0.3 矩阵三项输入任一无法判定 | 按**更审慎相邻档**归档；仍无法判定 -> 归「回避」档并说明 |
| 美股取数失败（yfinance 受限） | 该标的标「**未验证**」，其 Tier 分层与打分标「无法判定」；**不在本技能内做网络修复** |
| 行业跨两类赛道（地缘倒逼型 ↔ 政策资本驱动型） | **按更审慎那类执行**并显式标注 |
| 时变项（清单 / 管制 / 国产化率）未实时核验 | **禁止**沿用历史清单；未核验则标「未核验」并降级结论 |

## 注意事项

1. **三档物理隔离**——本技能只读写 `reports/industry/{行业名}-garp-industry-*.md`；**不得触碰** 1~3 年中期链 / 10 年长期链的报告文件；本技能**不提供档位切换开关**。
2. **渗透率口径唯一**——黄金窗为 **15%~40%**；天花板为 **>60%**；本技能不得使用任何其他档位的渗透率区间。
3. **国产化率与渗透率分工不得互换**——渗透率管择时、国产化率管弹性；非科技赛道记「不适用」，**不得**因不适用而扣分或放行。
4. **地缘只作矩阵归档 + 硬门槛 / 敞口体检**——**不做估值折价**（折价统一由 `garp-valuation` 承载），避免**双重计价**。
5. **时变项必须实时核验**——制裁清单 / 出口管制 / 风险行业清单 / 国产化率**禁止沿用历史清单**。
6. **题材辨别是一票否决维度**——扣非不匹配营收、纯概念无业绩 -> 评级「拒绝」。
7. **景气定位与 ROE 拐点只能定性**——结论须标注「**定性推断**」，**不得**自设 ROE 拐点阈值。
8. **前向引用纪律**——下游 GARP 技能**仅指向名称、不描述其内部流程**。
9. **零心算**——所有估值 / 市值 / PEG / 加权打分须走工具（`GI-9`）。
10. **单一来源不得作确定性结论**——标「单一来源，置信度低」（`GI-8`）。
11. **取数失败不等于通过**——标「**未验证**」「**无法判定**」，整体结论须降级说明。
12. **不替用户决策**——只出赛道结论与行业层建议；报告须含免责声明。

## 局限性

1. **只输出赛道结论与候选清单**——不判断个股买卖价位，个股需另行研究（归 `garp-industry-funnel` P4-10，已交付，仅指向名称）。
2. **渗透率 / 国产化率数据可能不可得**（缺口登记于 U1）——须标注「未验证」；渗透率**无独立工具出口**，国产化率可经 `geo_policy_screen.py localize` 判定。
3. **行业级 ROE 拐点缺量化判据**（缺口登记于 U2）——结论为**定性推断**，不具备量化精度。
4. **美股行情连通性受限**（缺口登记于 U3）——`--daily` 参数形态已确认，但数据源连通性不稳定，可能降级为「未验证」。
5. **0.3 矩阵未覆盖全部组合**（缺口登记于 U4）——按「**更审慎相邻档**」执行，**不自行补全矩阵**。
6. **`trend_tech_screen.py` 地缘维度仍为二维**（缺口登记于 U5）——与 0.3 三维交叉矩阵存在差异；本技能**只调用不改引擎**。
7. **前向引用技能已全部交付**（原缺口 U6 已随 Phase 4 收口）——出口完整性复查统一执行。
8. **不构成投资建议**——本技能仅用于学习与研究；行业级结论不等同于个股结论。
