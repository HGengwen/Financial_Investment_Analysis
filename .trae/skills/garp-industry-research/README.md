# garp-industry-research — GARP 行业研究（1~5 年独立档）

> **技能命令**：`/garp-industry-research {行业名}`
> **所属档位**：GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔）
> **开发任务**：P4-9（行业研究层技能；开工门禁 A~H 全部按推荐确认）
> **版本**：1.0.0（2026-09-18）

---

## 一、技能用途

### 一句话定位

把《中长期价值成长（GARP）投资框架》**第 1 步「赛道选择」**落地为一张可执行的行业体检表：

**解析输入（三日期基准）→ 六维筛选验证（含 0.3 三维矩阵归档与赛道两分法判别）→ 产业链全景图与卡脖子 6 标准 → 全球扫描 Tier 1~4 → 头部公司四维打分 → 景气周期定性定位 → 多技能交叉验证 → 组合建议与五级卖出预览 → GI-1~GI-12 检查 → 十四节报告。**

本技能是**行业层首站（第 1 步·赛道选择）**——**不研究个股、不做估值档位判定、不定义卖出级别、不定义仓位比例**；它只回答「**这赛道值不值得配置、产业链哪一环最挣钱**」。

### 何时用

- 首次系统性评估一个赛道是否满足 GARP 中期门槛（TAM / 增速）；
- 判断赛道处于生命周期什么位置（渗透率档位 / 国产化率档位）；
- 定位产业链「咽喉环节」与全球利润分配格局；
- 拉出全球上市标的 Tier 1~4 分层与头部公司排序；
- 行业级卖出预警与组合层输入。

### 何时不用

| 场景 | 应使用的技能 |
| --- | --- |
| 个股深度研究与买入决策 | `garp-investment-research`（P4-12）/ `garp-investment-team`（P4-13） |
| 赛道内个股漏斗精选 | `garp-industry-funnel`（P4-10） |
| 买入前门槛检查 | `garp-investment-checklist`（P4-3） |
| 估值档位判定（贵不贵 / 建仓节奏） | `garp-valuation`（P4-5） |
| 卖出执行与止损 | `garp-exit`（P4-6） |
| 论文建档与季度体检 | `garp-thesis-tracker`（P4-7） |
| 管理层与科研转化评分 / 诚信闸门 | `garp-management`（P4-4） |
| 地缘与政策资本前置闸门 | `garp-geo-policy`（P4-1） |
| 组合合规校验与调仓建议 | `garp-portfolio-review`（P4-8） |
| 供应链瓶颈第二、三层机会 | `garp-bottleneck-hunter`（P4-18） |
| 纯技术面体检 | `trend-momentum-scan`（复用 2 技能） |
| 未上市公司研究 | `garp-private-company-research`（P4-20） |

## 二、适用口径与隔离声明

- **适用口径**：本技能属 **GARP 独立档（1~5 年，五大师）**，介于项目既有「1~3 年景气投资」与「10 年护城河投资」两档之间。
- **隔离声明**：
  1. 本技能**不引用** 1~3 年档位与 10 年档位的任何技能口径；其编号体系与本技能的 `GI-*` 体系**物理隔离**；
  2. 估值水位**只来自** `garp-valuation`（P4-5，GARP 档）的**统一六档 + 多工具矩阵**，本技能零 PEG 算式；
  3. 卖出层级为「**一级 ~ 五级**」，**只引用** `garp-exit`（P4-6）的定义，不重定义、不使用其他档位的层级编号体系；
  4. 渗透率黄金窗为 **15%~40%**（框架口径），天花板为 **>60%**；
  5. 产出文件为 `reports/industry/{行业名}-garp-industry-{YYYYMMDD}.md`，**与 1~3 年 / 10 年档的报告文件物理隔离**、互不覆盖；
  6. 复用类技能仅限全档位通用的 2 个（`qoq-accelerator`、`trend-momentum-scan`）；
  7. **不修改**既有行业研究技能；本技能为**独立目录技能**（门禁 H-1）。
- **本技能不提供档位切换参数**——它即 GARP 独立档专属入口；档位切换类口令属其他档位口径，出现即违反口径隔离纪律。

## 三、命令与报告路径

```bash
/garp-industry-research {行业名}
/garp-industry-research {行业名} {子赛道} --depth deep
/garp-industry-research {行业名} --scope A股 --export
```

| 输入项 | 说明 |
| --- | --- |
| `{行业名}` | 赛道 / 行业名（如 `AI 光模块`） |
| `{子赛道}` | 可选子赛道细分（收窄产业链与扫描范围） |
| `--scope` | 研究范围：`全球` / `A股` / `港股` / `美股`（默认 `全球`） |
| `--depth` | `fast` / `standard`（默认）/ `deep` |
| `--export` / `--export-path` | 导出报告；默认根路径 `reports/industry/` |
| `--json` | 输出结构化 JSON |

**报告输出**：

```text
reports/industry/{行业名}-garp-industry-{YYYYMMDD}.md
```

> **保留全部历史文件，不删除不覆盖**；同日多次加 `-v2` / `-v3`（门禁 F-1）。

## 六、关键口径速查

### 6.1 六维筛选与综合评级

| # | 维度 | 标准 |
| --- | --- | --- |
| 1 | 产业空间（TAM） | ≥1000 亿 **且** 未来 3 年 CAGR ≥20% |
| 2 | 渗透率位置 | **15%~40% 加速上行期** |
| 3 | 国产化率位置（科技赛道专用） | 四档见 6.3；非科技赛道记「不适用」 |
| 4 | 业绩兑现度 | 连续 2 个季度：营收增速 > 行业平均，毛利率稳定或提升 |
| 5 | 题材辨别 | 有实际 EPS 支撑；扣非净利润增速须匹配营收增速；纯概念**坚决回避** |
| 6 | 地缘政治敞口 | 0.3 三维矩阵 + 赛道两分法（见 6.4） |

**综合评级**：**A 级：六维全过** / **B 级：五维通过，一项待观察** / **C 级：未达门槛或业绩未兑现** / **拒绝：题材炒作或 0.3 「回避」档**。

### 6.2 渗透率五档（黄金窗 15%~40%）

| 档位 | 区间 | 动作 |
| --- | --- | --- |
| 导入早期 | <5% | 观察不建仓 |
| 突破期 | 5%~15% | 小仓跟踪 |
| **加速上行期** | **15%~40%** | **黄金建仓窗口，主建仓** |
| 逐步兑现期 | 40%~60% | 持有，不再新建仓 |
| 天花板 | >60% | 不加仓；增速归零 / 转负即见顶清仓 |

### 6.3 国产化率四档与分工

| 档位 | 区间 | 动作 |
| --- | --- | --- |
| 过早 | <5% | 战略必争卡脖子环节可观察 / 小仓（非回避） |
| 突破期 | 5%~20% | 从 0 到 1，跟踪 / 小仓 |
| 加速投资期 | 20%~50% | 订单放量 |
| 替代空间收窄 | >50% | 转向龙头份额提升与整机放量 |

> **分工**：**渗透率管择时**（何时买）、**国产化率管弹性**（成长弹性）；科技赛道两者叠用。

### 6.4 0.3 三维交叉矩阵与赛道两分法

六类场景：**最优场景 / 次优场景 / 潜伏场景 / 高风险·回避 / 政策驱动型增量创造 / 回避**（矩阵全文见同目录 [SKILL.md](./SKILL.md)）。

> **三条刚性附带条款**：① 未列组合按**更审慎相邻档**归档；② 国字号基金注资**非估值依据**；③ 时变项须**实时核验，勿沿用历史清单**。

| 赛道类型 | 地缘维度作用 |
| --- | --- |
| **地缘倒逼型** | 地缘倒逼强度为**硬门槛** |
| **政策资本驱动型** | 仅作**敞口体检** |

### 6.5 卡脖子 / Tier / 头部打分

| 项 | 口径 |
| --- | --- |
| 卡脖子 6 标准 | 供给集中度 ≤2 家 / 扩产周期 >2 年 / 替代难度高 / 产能利用率 >80% / 需求增速 >30% / 客户验证周期长 |
| Tier 1~4 | 大市值纯正龙头 / 中市值细分龙头 / 小市值高风险高弹性 / 多元化关联业务 |
| 头部四维打分 | 产业景气 35% + 基本面 30% + 管理层与科研 20% + 地缘 15%；≥80 S / 65~79 A / 50~64 B / <50 C |

### 6.6 五级卖出预览（引用 `garp-exit`）

| 级别 | 触发（引用 P4-6 口径） |
| --- | --- |
| **一级 · 诚信否决** | 失信 / 造假实锤 / 监管立案 |
| **二级 · 硬止损** | 单笔亏损 **8%~10%** 且无明确基本面反转信号 |
| **三级 · 逻辑止损** | 连续 2 季低于预期且景气未改善 / 财务不可逆恶化 / 龙头被颠覆 |
| **四级 · 产业景气判断** | 渗透率 / ROE 拐点 / 增速归零或转负 |
| **五级 · 估值判断** | 调整后 PEG > 1.5（> 2 严重透支）/ 情绪多信号共振 |

> **补充机制**：**时间止损**——持有满 4 季度逻辑未兑现 -> 输出「时间止损预警」。

## 九、常见误用提示

1. **渗透率口径混用是头号错误**——本技能黄金窗为 **15%~40%**，天花板 **>60%**；任何其他档位的渗透率区间都属越界（`GI-3`）。
2. **国产化率与渗透率分工不得互换**——渗透率管择时、国产化率管弹性；非科技赛道记「不适用」，**不得**因不适用扣分或放行（`GI-4`）。
3. **地缘不做估值折价**——地缘只作矩阵归档 + 硬门槛 / 敞口体检；折价统一由 `garp-valuation` 承载，行业层重复折价会造成**双重计价**。
4. **时变项禁止沿用历史清单**——制裁清单 / 出口管制 / 风险行业清单 / 国产化率须实时核验。
5. **题材辨别是一票否决维度**——扣非不匹配营收、纯概念无业绩 -> 评级「拒绝」（`GI-7`）。
6. **赛道类型必须先判后打分**——未判「地缘倒逼型 / 政策资本驱动型」即打分属越界（`GI-6`）。
7. **景气定位与 ROE 拐点只能定性**——必须标注「定性推断」，不得自设阈值。
8. **前向引用只指向名称**——下游 GARP 技能不描述其内部流程。
9. **零心算**——所有估值 / 市值 / PEG / 加权打分须走工具（`GI-9`）。
10. **取数失败不等于通过**——标「未验证」「无法判定」，不得按通过处理（`GI-8`）。
11. **三档报告文件物理隔离**——只读写 `reports/industry/{行业名}-garp-industry-*.md`，不得触碰其他档位的报告文件。
12. **不替用户决策**——只出赛道结论与行业层建议。
