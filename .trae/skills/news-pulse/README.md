# 公司新闻脉搏 (News Pulse)

股价异动时快速归因：10-15分钟内回答"发生了什么？真因是什么？要不要重审投资论文？"

---

## 快速开始

### 基本调用方式

```
/news-pulse {公司名} [可选：股价异动描述]
```

例如：
- `/news-pulse 拼多多 股价跌15%/一周`
- `/news-pulse 腾讯`
- `/news-pulse 美团 股价涨8%/3天`

---

## 核心功能

对指定公司进行最近新闻侦察与股价异动快速归因。**这不是深度投研，是情报快速响应**——通过4个并行Agent快速侦察，产出归因判断。

### 适用场景

- 持仓/关注股票股价大涨/大跌（一般触发线：单日±5%、一周±10%）
- 财报后股价异动，想快速搞清市场在反应什么
- 看到新闻标题，但不确定是噪音还是真信号

### 四Agent并行侦察

| Agent | 核心问题 |
|-------|---------|
| company-event-scout（公司事件侦察） | 公司本体最近发生了什么？ |
| regulatory-watcher（监管政策侦察） | 行业监管和政策最近有什么变化？ |
| industry-peer-analyst（行业对手侦察） | 是公司个体事件，还是整个行业的beta波动？ |
| sentiment-tracker（市场情绪侦察） | 是基本面驱动还是情绪/资金面驱动？ |

### 六步执行流程

1. **确认参数与场景** — 公司名+时间窗口+股价异动+关注侧重
2. **信息可得性分级** — A/B/C级评级，影响各Agent侦察方式
3. **启动4个并行侦察Agent** — 同一条消息中调用4次Task工具
4. **实时跟踪进度** — 每收到一份报告更新进度+3条核心发现
5. **Team Lead 综合归因** — 产出异动归因报告（不是研究报告，重点是"判断"）
6. **保存报告** — 写入 `reports/{公司名}/{公司名}-news-{YYYYMMDD}.md`

## 输出报告

报告将保存在以下位置：

| 报告类型 | 文件路径 |
|---------|---------|
| 异动归因报告 | `reports/{公司名}/{公司名}-news-{YYYYMMDD}.md` |

如果 `reports/{公司名}/` 目录不存在则创建（说明该公司还没建过任何研究报告）。

### 归因报告结构

```
一、一句话归因（30-60字：主因+次因+性质判断）
二、完整事件时间线（合并4个维度，按日期倒序）
三、异动归因表（候选解释/证据/反证/置信度/持续性）
四、性质判断（价值事件/情绪波动/真因不明/混合）
五、各维度侦察摘要（每维度3-5条最重要发现）
六、行动建议（是否触发论文重审/财报研读/管理层重审/调仓）
七、接下来7-30天的跟踪清单
八、信息缺口声明（诚实列出未能解决的疑点）
```

### 性质判断四类结论

- ✅ **价值事件**：基本面发生了真实变化，需要重审投资论文
- ⚡ **情绪/技术波动**：基本面无变化，是资金面/情绪/Beta驱动，可视为机会或噪音
- ❓ **真因不明**：找不到能匹配股价异动幅度的事件——**这是最危险的结论**
- 🔀 **混合**：部分价值事件 + 部分情绪放大

## 归因标准

### 异动归因权重大小

| 权重 | 含义 |
|------|------|
| 🔴 高 | 足以单独解释异动 |
| 🟡 中 | 贡献一部分 |
| ⚪ 低 | 背景噪音 |

### 信息可得性分级

| 等级 | 特征 | 侦察策略 |
|------|------|---------|
| **A级（信息充裕）** | 大盘股、媒体覆盖广、财报季 | 重点是降噪和归因，过滤重复转述的二手新闻 |
| **B级（信息适中）** | 中小盘、覆盖一般 | 标准模式，每条关键事件附1-2个独立信源 |
| **C级（信息稀缺）** | 港股小票、新上市、冷门 | 转入"扫盲模式"，找不到新闻本身就有价值 |

### Team Lead 归因要点

- **归因优先于罗列** — 发现事件不难，难的是判断"哪个事件配得上这次股价异动"。要做减法，不要做加法
- **区分"催化剂"和"巧合"** — 同一时间发生的事件不一定是异动主因，要看影响量级是否匹配
- **诚实面对"不明"** — 找不到主因时，明确写"真因不明"，比硬凑因果链更有价值

## 核心原则

1. **快胜过全** — 核心价值是10-15分钟内给出归因判断，不陷入深度分析
2. **归因优先于罗列** — 做减法不做加法，判断哪个事件配得上这次股价异动
3. **诚实面对"不明"** — 找不到主因时明确写"真因不明"，比硬凑因果链更有价值
4. **不预设立场** — 不要因为持仓就倾向于"这是情绪波动，没事"
5. **区分"催化剂"和"巧合"** — 同时间发生的事件不一定是异动主因，看影响量级
6. **尊重信息可得性** — C级公司可能查不到新闻，这个结论本身就要写出来
7. **遵循客观性原则** — 所有判断附数据来源，区分事实与观点
8. **不替用户做决策** — 给出归因和行动建议清单，但买卖决策由用户做

---

## 注意事项

- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- 4个Agent必须在同一条消息中并行启动
- 如果用户只说公司名，先反问时间窗口和股价异动，**不要默默假设**
- 资料评级（A/B/C级）需告知每个Agent，影响其侦察方式
- 所有判断必须附数据来源，区分事实与观点
- 行动建议仅做提示，最终买卖决策权在用户
- 报告需包含"信息缺口声明"，诚实列出未能解决的疑点
- 不适合用本Skill的场景：完整投研（用 `/investment-team`）、财报深读（用 `/earnings-review`）、长期论文跟踪（用 `/thesis-tracker`）

---

## 局限性说明

- **信息可得性**：港股小票、新上市公司可能无法获取到有效信息
- **时效性限制**：网络搜索结果可能有延迟，无法获取最新实时信息
- **归因不确定性**：股价异动可能由多个因素叠加，难以精确归因
- **内幕信息**：无法获取未公开披露的信息，可能导致归因错误
- **情绪量化困难**：市场情绪难以精确量化，判断可能主观
- **非实时数据**：工具获取的数据可能有延迟，不是实时数据
- 不构成投资建议，仅供情报快速响应参考
