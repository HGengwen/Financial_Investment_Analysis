# garp-investment-research（GARP 个股深度研究，1~5 年）

**五大师视角 + 八模块 + 多工具估值矩阵**：对单家公司进行 1~5 年价值成长（GARP）深度研究，输出「可建仓 / 观察仓 / 放弃」三档结论、估值档位、分批建仓计划与卖出触发条件。

---

## 技能用途 / 何时使用

### 解决什么问题

回答「**这家公司是否值得在 1~5 年维度建仓、以什么仓位与节奏建仓、什么条件下卖出**」——把「看得懂、算得清、买得对、卖得掉」串成一条可审计的决策链。

### 何时使用

| 场景 | 是否适用 |
| --- | --- |
| 已锁定候选标的，需要一份完整的个股深度研究报告 | ✅ 适用 |
| 需要判断标的处于哪一类公司类型、该用什么估值工具 | ✅ 适用 |
| 需要判定「能力圈是否覆盖」「诚信是否过关」「地缘是否回避」等硬闸门 | ✅ 适用 |
| 只需行业层结论、不给个股结论 | ❌ 用 `garp-industry-research` |
| 只需买入前硬门槛逐条核验 | ❌ 用 `garp-investment-checklist` |
| 只需组合层集中度 / 相关性 / 压力测试 | ❌ 用 `garp-portfolio-review` |
| 只需卖出信号核验 | ❌ 用 `garp-exit` |

### 前置建议

推荐执行顺序：`garp-industry-research` → `garp-industry-funnel` / `garp-trend-tech-screen` → **本技能** → `garp-investment-checklist` → `garp-thesis-tracker`。

## 所属档位与适用口径

| 项 | 值 |
| --- | --- |
| **所属档位** | **GARP 独立档（1~5 年）** |
| **大师体系** | 五大师：**费雪 / 林奇 / 郑希 / 李进 / 欧奈尔** |
| **持有周期** | 1~5 年（底仓口径同步按 1~5 年设定） |
| **档位隔离** | 与 1~3 年中期链、10 年长期链**物理隔离、功能互补** |
| **档位切换开关** | **不提供**——本技能即 GARP 独立档个股研究专属入口 |

### 本档五大关键口径

| 口径项 | 权威值 |
| --- | --- |
| **渗透率黄金窗** | **15%~40%**（五档：<5% / 5%~15% / **15%~40%** / 40%~60% / >60%）；TAM ≥1000 亿、未来 3 年复合增速 ≥20% |
| **地缘口径** | **0.3 三维交叉矩阵**（地缘倒逼强度 × 政策覆盖度 × 国字号基金介入）+ **赛道两分法**（地缘倒逼型 / 政策资本驱动型） |
| **估值口径** | **多工具矩阵**（五类公司类型 × 主锚 / 辅锚）+ **统一六档**（显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支） |
| **管理层口径** | **诚信前置不计分闸门 + 7+7+6**；科研转化 **8+8+4**；≥15 可重仓 |
| **卖出口径** | **五级卖出** + 时间止损（满 4 季度）+ 性价比替换（每季最多 1 次） |

## 命令与参数

### 基本调用

```text
/garp-investment-research {公司名}
```

### 参数

| 参数 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| `{公司名}` | 位置参数（必填） | — | 如 `中芯国际` |
| `--market` | `auto` / `a` / `hk` / `us` | `auto` | 市场识别；`auto` 时按名称自动匹配 |
| `--depth` | `fast` / `standard` / `deep` | `standard` | 研究深度 |
| `--export` | — | 关 | 导出开关 |
| `--export-path` | 路径 | 默认报告路径 | 导出路径 |
| `--json` | — | 关 | 结构化输出 |

> **本技能不新增任何 Python CLI 参数**，亦**不含任何档位切换开关**。

## 研究框架（前置 + 八模块）

**前置：AI 研究偏见预警** —— 信息丰富度 A/B/C 评级 + C 级第一性原理五问 + 偏见自查清单（须写入报告开头）

| 模块 | 名称 | 核心产出 |
| :--: | --- | --- |
| **①** | **数据收集 + 三剑客强制验算** | 11 项数据 + 市值验算 / 估值验算 / 三情景验算 |
| **②** | **生意本质与产业定位** | 一句话生意定义 + **林奇六类归类** + **渗透率五档定位** + **能力圈四维自检** + 财务五门槛 |
| **③** | **护城河评估（1~5 年视角）** | 五类护城河（须可量化）+ ROE 趋势 + **ROIC 四档**（科技股走调整后核心经营 ROIC） |
| **④** | **逆向思考与风险清单** | 失败路径 + **0.3 矩阵归属 + 赛道两分法** + 支柱四八项敞口体检 + 暂时 / 永久清单 |
| **⑤** | **产业景气与 ROE 拐点** | ROE 趋势（连续 3 季同向才判拐点）+ 渗透率 / 增速趋势（定性判断） |
| **⑥** | **管理层与科研转化** | **诚信前置闸门** + 7+7+6 + 8+8+4 + 费雪补充项 + ESG 三通道 |
| **⑦** | **估值与买入时机** | 公司类型判定 → 主锚 / 辅锚 → 四级收口 → 宏观区间 → 分批建仓 + 左侧 / 右侧 + **「假如空仓」** |
| **⑧** | **综合决策备忘录与卖出纪律** | **五大支柱汇总判定** + 四条一票否决 + **三档结论** + 五级卖出转引 |

**专节**：一 五大矛盾化解｜二 决策优先级速查卡｜三 每季度复盘检查清单｜四 能力圈声明

### 关键规则速览

| 规则 | 内容 |
| --- | --- |
| **能力圈闸门** | 普通行业须过「产业 + 财务 + 估值」三项；**科技股「技术理解」必答**，不过关不得重仓 |
| **诚信闸门** | 兑现率 <50% / 业绩预告重大失真 / 财务造假实锤 / 监管立案 → **一票否决**，不进入评分求和 |
| **ROIC 一票否决** | 长期 <5% 却在拼命扩产 → 放弃 |
| **估值选锚** | 快速增长型走调整后 PEG；高研发型走 PS / EV-Sales + Rule of 40 ≥40；未盈利型走 PS + 研发管线 NPV；稳定增长型走远期 PE + 隐含 PEG ≤1.2；成熟型走 DCF（市值 ≤ 保守 DCF 80%） |
| **分批建仓** | 默认三分法：1/3 首仓 → 右侧确认后补至 2/3 → 连续 2~3 季兑现后补齐 |
| **左侧上限** | 首批 ≤ 最终仓位 **50%**（**可建上限、非必须比例**）；**仅适用「杀估值」，不适用「杀逻辑」** |
| **仓位上限** | 单只 初始 ≤10% / 验证后 ≤15% / 绝对 ≤20%（衰退 ≤8%/≤12%/≤15%；过热同衰退；滞胀 ≤6%/≤10%/≤12%）；单一行业 ≤40% |
| **底仓 / 机动仓** | 底仓 60%~80% / 机动仓 20%~40%（**股票仓位内部**切分）；现金占总资产常态 10%~20% |
| **再平衡** | 底仓可每季度结合最新财报小幅调整（**±5%**） |

## 局限性

1. **能力圈四维自检、信息丰富度评级、费雪「绝不卖」两前提均为主观自评**，无工具化判据，报告中须显式标注
2. **渗透率与国产化率缺乏标准化工具出口**，依赖第三方数据与年报表述，可能滞后，须标注置信度，**不默认落黄金窗**
3. **0.3 三维交叉矩阵为定性档位**，无量化系数，档位判定归 `garp-geo-policy`
4. **宏观阶段由外部判定**（`garp-macro`），本技能不自判、不择时
5. **管理层 / 科研转化 / ESG 评分依赖年报文本与第三方评级**，覆盖不全且存在时点滞后
6. **估值矩阵的「可接受标准」为框架口径**，不构成对个股的精确目标价
7. **研发管线 NPV 为粗算**，对未盈利科技型的估值精度有限
8. **增速趋势判断为定性趋势判断**，非框架条款（推导口径）
9. 非三市场标的（未上市 / 冷门市场）**工具未覆盖**，须转人工取数
10. 本技能输出**用于学习与研究，不构成投资建议**
