# GARP 个股深度研究（1~5 年）：五大师视角 + 八模块 + 多工具估值矩阵

对 $ARGUMENTS 进行系统化 **1~5 年价值成长（GARP）** 深度研究。本技能是 **GARP 独立档个股研究入口**——回答「这家公司是否值得在 1~5 年维度建仓、以什么仓位与节奏建仓、什么条件下卖出」。

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

> "成长股投资的核心，是找到那些能够持续创造增量价值的杰出企业，并在它遭遇暂时性困难时敢于重仓。" —— 费雪（质化挖掘·认知深度）

> "投资的根本在于找到优秀的公司，然后耐心持有——但你得先确认它确实优秀。" —— 林奇（常识验证·类型标签）

> "ROE 向上是科技股最可靠的'重力加速度'——只要这个趋势在，估值波动只是噪音。" —— 郑希（产业景气·季度验证）

> "用渗透率定位阶段，用增速趋势判断拐点，用纪律保护本金。" —— 李进（系统均衡·仓位纪律）

> "投资的第一条规则是不要亏损，第二条规则是记住第一条。" —— 欧奈尔（底线思维·趋势止损）

**支持输入格式**：

- `{公司名}` —— 位置参数（必填），如 `/garp-investment-research 中芯国际`
- `{公司名} --market hk` —— 市场参数（`auto` / `a` / `hk` / `us`，默认 `auto`）
- `{公司名} --depth deep` —— 深度参数（`fast` / `standard` / `deep`，默认 `standard`）

> **本技能不提供档位切换参数**——它即 GARP 独立档（1~5 年）个股研究专属入口，命令与输入中**不含任何档位切换开关**；档位切换类口令属其他档位口径，在本技能中出现即违反**口径隔离**纪律（见「注意事项」第 1 条与「与各 garp- 技能的关系」）。

## 设计理念

本技能整合五位投资大师的方法论，形成 **1~5 年价值成长的完整决策闭环**：

| 大师 | 核心视角 | 在本技能中的落位 |
| --- | --- | --- |
| **费雪** | 质化挖掘、闲聊法、「绝不卖」两前提 | 护城河质化验证、诚信一票否决、矛盾五化解、暂时性困难判断 |
| **林奇** | 生活常识、六类股票分类、逆向情绪 | 生意本质与产业定位、类型标签、估值陷阱识别 |
| **郑希** | ROE 拐点、全球产业链景气传导 | 护城河 ROE 趋势、季度景气验证 |
| **李进** | 渗透率定位、系统均衡、仓位纪律 | 渗透率五档、赛道两分法、仓位与止损尺度 |
| **欧奈尔** | 趋势信号、8% 止损底线 | 硬止损、右侧确认、趋势与动量确认 |

**哲学根基**：**价值为锚、成长为翼、纪律为本**——「价值」侧用 ROIC / ROE / 护城河 / 现金流守住不亏，「成长」侧用渗透率 / 赛道景气 / 科研转化打开空间，「纪律」侧用五级卖出 / 硬止损 / 仓位上限守住本金。

**与单一估值指标的分野**：科技与国产化主题公司的利润常被研发费用化压低，单一 PEG 极易误判——本技能的估值结论一律由**多工具矩阵**（调整后 PEG / PS / EV-Sales / Rule of 40 / 隐含 PEG / DCF / 研发管线 NPV）按公司类型选锚后收口。

## 研究框架

前置步骤 + 八个研究模块，**模块顺序与骨架一致、不跳步**；模块内不做淘汰累积，唯一淘汰点为**一票否决清单**（四条）与**五大支柱达标判定**。

### 前置步骤：AI 研究偏见预警（必须执行）

在开始研究前，评估该公司的「可研究性」，识别潜在数据偏见。

**信息丰富度评级**：

| 等级 | 特征 | AI 研究陷阱 | 应对策略 |
| --- | --- | --- | --- |
| **A 级**（信息充裕） | 上市多年、券商覆盖多、媒体报道密集 | 共识过强，AI 输出趋同于市场定价 | 重点做反面检验：成长逻辑是否已被充分定价？哪些风险被忽略？ |
| **B 级**（信息适中） | 上市 1~3 年、覆盖有限、部分数据需推算 | AI 可能用「合理推测」填补空白，产生虚假确定性 | 每个推算数据标注置信度，区分「有据推算」与「凭空填充」 |
| **C 级**（信息稀缺） | 刚上市 / 冷门股 / 新兴市场、几乎无覆盖 | AI 会因资料不足而过度保守，误判为「看不清 = 不好」 | 用第一性原理五问，从有限信息中提取核心商业逻辑 |

**C 级公司的第一性原理五问**：

1. 客户是谁？为什么付钱？有没有替代选择？
2. 复购靠什么驱动？是习惯、锁定，还是持续创造新价值？
3. 竞争对手拿 100 亿能复制这门生意吗？
4. 管理层做过什么关键决策？反映什么判断力与价值观？
5. 这个产业未来 1~5 年的核心驱动力是什么（渗透率 / 技术迭代 / 政策支持）？

**偏见自查清单**（全程保持警惕）：

- [ ] 我的「确定性」感受来自生意本质，还是来自资料数量？
- [ ] 如果把这家公司的资料量减少一半，我的结论会变吗？
- [ ] AI 输出的分析是否与市场共识高度雷同？如果是，我的信息优势在哪？
- [ ] 是否存在「公开资料很少但生意本质极好」的可能性被低估了？
- [ ] 我是否正在把「数据不足」等同于「风险过高」？（对 C 级公司尤其重要）

> **自评项标注（`GIR-12`）**：信息丰富度评级为**主观自评**，无工具化判据，须在报告头部标注「自评项」。C 级公司**不得作确定性结论**，须列「需要一手验证的问题清单」。

### 第一步：数据收集（GARP 版）与三剑客强制验算

> **数据源规范**：所有财务数据必须来自两个独立来源，误差 >1% 须标记（`GIR-10`）。

使用后台 Agent 收集以下 **11 项数据**：

1. **收入结构**：最近财年及近 4 季度分部收入、增速、毛利率
2. **财务指标**：近 5 年收入、净利润、ROE（趋势是关键）、毛利率、经营利润率、自由现金流、现金储备
3. **景气数据**：近 8 个季度营收增速趋势、扣非净利润增速、订单增速、产能利用率
4. **产业渗透率**：当前行业渗透率（估计值）、变化趋势、未来 12 个月预期位置
5. **国产化率**（科技 / 国产化赛道）：所处环节国产化率、所处梯队、替代空间
6. **竞争格局**：市场份额、主要竞争对手对比、CR5 变化趋势
7. **护城河证据**：1~5 年内能守住的核心竞争优势来源（须可量化）
8. **科研转化**（科技 / 医药）：研发费用率、研发资本化率、研发人员占比、新产品收入占比、在研关键项目进展
9. **管理层**：创始人 / CEO 履历、持股比例、关键决策记录、历史承诺兑现率
10. **地缘政治**：海外收入占比、供应链关键环节依赖度、制裁 / 关税风险敞口、本地化布局进展
11. **当前估值**：市值、PE、远期 PE、PB、FCF Yield、主要可比公司估值

#### 三剑客强制验算（必须执行，使用精确算术工具）

数据收集完成后，**必须调用 `tools/common/financial_rigor.py` 对关键数据程序化验证**，杜绝心算误差。

**Step 1 — 市值验算**：

```bash
python tools/common/financial_rigor.py verify-market-cap \
  --price {股价} --shares {总股本} --reported {报告市值} --currency {币种}
```

> **跨币种折算**：须先取 `python tools/common/fx_rate.py --code USDCNY,HKDCNY` 实时汇率，再由 `financial_rigor.py calc` 显式折算，并在报告中标注**汇率时点**；`fx_rate.py` 的跨币种折算功能不可用（缺口 U8）。

**Step 2 — 估值指标验算（辅助读数）**：

```bash
python tools/common/financial_rigor.py verify-valuation \
  --price {股价} --eps {EPS} --bvps {每股净资产} --fcf-per-share {每股FCF} --dividend {每股股息}
```

> **口径说明（`GIR-5`）**：本命令输出为**辅助读数**，**估值结论不由单一 PEG 给出**——最终档位一律在第七步由多工具矩阵选锚后收口。

**Step 3 — 三情景估值**：

```bash
python tools/common/financial_rigor.py three-scenario \
  --price {股价} --eps {EPS} --shares {总股本亿} \
  --growth {乐观增速} {中性增速} {悲观增速} \
  --pe {乐观PE} {中性PE} {悲观PE} --years 3 --currency {币种}
```

> **刚性约束**：其 PE 情景取值**须落在 `garp-valuation` 统一六档区间内**，越界须在报告中标注。

**补充验算（按公司类型选用）**：

```bash
python tools/common/financial_rigor.py cross-validate --field {字段} --values '{…}' --unit {单位}
python tools/common/financial_rigor.py roic --nopat {NOPAT} --invested-capital {投入资本} --wacc {WACC}
python tools/common/financial_rigor.py incremental-roic …
python tools/common/financial_rigor.py wacc …
python tools/common/financial_rigor.py adjusted-peg --market-cap … --core-operating-profit … --rnd-expense … --growth …
python tools/common/financial_rigor.py ev-sales …
python tools/common/financial_rigor.py rule-of-40 …
python tools/common/financial_rigor.py implied-growth --market-cap … --target-pe … --net-margin … --ttm-revenue … --guidance-growth …
```

**验证规则**：

1. 每个关键数据点至少 2 个独立来源；差异时优先采用公司年报 / 交易所数据
2. **所有涉及计算的数据必须经工具验算，禁止心算**（`GIR-7`）
3. 工具输出直接嵌入报告附录「关键数据交叉验证记录」
4. 工具报错须记录**原始报错与退出码**，登记为「工具缺陷候选」，不得静默吞掉

### 第二步：生意本质与产业定位（林奇六类 + 渗透率五档）

**核心问题**：这门生意我看得懂吗？它处在产业周期的什么位置？

#### 2.1 生意本质

- 用一句话定义这门生意的本质——「如果 10 分钟讲不清楚，业务太复杂」
- **收入结构拆解**：钱从哪来？哪些业务在增长？哪些在萎缩？
- **5 年盈利能力趋势**：毛利率、净利率、ROE——向上还是向下？
- **商业模式画布**：一次性销售 vs 订阅 / 复购？硬件 vs 软件 vs 平台？生态锁定强度？

#### 2.2 林奇六类股票分类（**必须明确归类**）

| 类型 | 关注指标 | 卖出逻辑 |
| --- | --- | --- |
| 缓慢增长型 | 股息率 | 股息率下降 |
| 稳定增长型 | PE 区间 + 隐含 PEG | PE 过高 |
| **快速增长型** | **调整后 PEG** | 增速放缓 |
| 周期型 | 行业供需拐点 | 景气顶峰 |
| 困境反转型 | 反转证据 | 复苏不及预期 |
| 隐蔽资产型 | 资产重估 | 资产价值兑现 |

> **追问**：这家公司属于六类中的哪一类？不同类型的卖出逻辑完全不同——你清楚这只股票的「类型标签」吗？类型归类直接决定第七步的估值选锚。

#### 2.3 能力圈四维自检（**进入深度研究前的闸门**，`GIR-1`）

| 维度 | 评估标准 | 自检问题（须能独立回答「是」） |
| --- | --- | --- |
| **产业理解** | 能否画出产业链上下游关系图？能否说出竞争格局与集中度（CR5）？ | 产业链有几层？上游关键原材料 / 设备来自谁？下游客户是谁？前五大玩家是谁、份额多少？ |
| **财务理解** | 能否独立阅读并理解该行业公司的三张报表？ | 营收、毛利率、应收 / 存货、经营现金流分别在哪张表？关键科目变动意味着什么？ |
| **估值理解** | 能否用至少 2 种方法给出估值区间？ | 除 PE 外，能否再用 PS、EV-Sales、DCF、可比公司等方法交叉验证？ |
| **技术理解**（**科技股必答**） | 能否说清核心技术路线的差异？ | 不同技术路线的原理差异、成本差异、适用场景、主流玩家分别是谁？ |

**判定规则**：

- 普通行业：须**同时满足「产业理解 + 财务理解 + 估值理解」三项**，方可进入深度研究；任一无法独立回答即视为**能力圈之外**
- 科技股：**「技术理解」为必选项**——说不清核心技术路线差异，即便其他三项通过，**也不得重仓**，只能作观察仓或放弃
- 未达门槛的应对（三选一）：①补课学习至能独立回答；②只作低仓位观察仓跟随；③果断放弃，赚认知范围内的钱

> **自评项标注（`GIR-12`）**：能力圈四维自检为**主观自评**，无工具化判据，报告中须标注「自评项」。

#### 2.4 财务五门槛与科技豁免

| 门槛 | 标准 |
| --- | --- |
| 营收规模 | **≥10 亿**（剔除微盘股） |
| 营收复合增速 | 最近三年 **≥15%** |
| 资产负债率 | **<60%**（金融 / 地产除外） |
| 经营性现金流净额 | **为正** |
| 扣非净利润 | 过去三年**至少两年为正** |

> **科技股豁免**：若「扣非净利润为负」仅由研发费用化压低当期利润所致，可用「**经营性现金流净额为正 + 营收连续增长 + 研发强度≥15%**」三项替代「扣非净利润」门槛（与「未盈利科技型」估值锚衔接）；**无法通过此豁免的仍应剔除**。

#### 2.5 渗透率五档定位（**引用 `garp-industry-research`，`GIR-8`**）

> **口径来源**：渗透率分档与国产化率分层的权威口径见 `garp-industry-research`（P4-9）与 `garp-geo-policy`（P4-1），本技能**只引用结论、不重复定义、不自建梯队数**。

| 档 | 区间 | 操作含义 |
| --- | --- | --- |
| 导入早期 | **<5%** | 不确定性高，**观察不建仓** |
| 突破期 | 5%~15% | 高弹性，**小仓跟踪** |
| **加速上行期（黄金窗）** | **15%~40%** | **主建仓窗口** |
| 逐步兑现期 | 40%~60% | 持有、**不再新建仓** |
| 天花板 | **>60%** | 即便增速暂未转负也**不加仓**；**一旦增速归零 / 转负即视为见顶、清仓** |

**配套约束**：行业 TAM **≥1000 亿**，未来 3 年复合增速 **≥20%**。

**国产化率四梯队**（管「标的成长弹性」）：**<5% 过早**（战略必争卡脖子环节可作高风险高弹性观察 / 小仓，非回避）/ **5%~20% 从 0 到 1 突破期**（高弹性，跟踪 / 小仓）/ **20%~50% 加速投资期**（订单放量）/ **>50% 替代空间收窄**（转向龙头份额提升与整机放量）。

> **分工纪律**：**渗透率**定位**产业**所处阶段（管「何时买」），**国产化率**定位**国产企业**可替代空间（管「标弹性」）；科技赛道**两者叠用，不得互相替代**。

#### 2.6 生活常识验证

- 你或身边人在使用这家公司的产品吗？产品力如何？是否愿意向朋友推荐？
- 竞争对手的产品体验如何？

> **追问**：如果渗透率已 >40%，主业是否还能支撑 1~5 年的成长？新增量的第二曲线在哪里？

### 第三步：护城河评估（1~5 年视角）

**核心问题**：1~5 年内，这家公司的竞争优势能守住吗？ROE 与 ROIC 是向上还是向下？

逐一验证五类护城河，**不问「十年后是否还在」，而问「1~5 年内能否支撑成长兑现」**：

| 护城河类型 | 1~5 年验证方法（须可量化） |
| --- | --- |
| 品牌 / 定价权 | 过去 1 年是否提价？提价后销量变化？竞品能否跟进？毛利率是否稳定？ |
| 转换成本 | 客户迁移到竞品的成本有多高？迁移需要多长时间？续费率 / NPS？ |
| 网络效应 | 用户增长是否带来更高黏性？竞争对手进入壁垒多高？ |
| 规模效应 | 产能扩张后单位成本是否下降？与竞争对手成本差距多大？ |
| 技术 / 专利壁垒 | 核心技术领先竞品多少年？下一个技术迭代周期多长？发明专利数量与质量？ |

> **刚性约束**：护城河停留在「感觉有壁垒」而无法量化验证的，视为**本项不达标**（退观察仓）；**禁止仅凭行业 β 的 CR5 判断个股护城河**。

**追加检验**：

- **ROE 趋势**：近 3 年 ROE 是向上还是向下？最近季度是否出现拐点？
- **毛利率 / 净利率趋势**：是否稳定或提升？反映定价权与成本控制力
- **营收与利润增速匹配度**：利润增速是否跟得上营收增速？营收快而利润慢 → 警惕费用失控
- **ROIC vs WACC**：扩张是在创造价值还是在毁灭价值？

#### 3.1 ROIC 四档判定（`GIR-1`）

| 档位 | 标准 | 处置 |
| --- | --- | --- |
| **优秀** | ROIC **>15%** | 「最高确信度标的」候选加分项；可支持单只上限上浮至绝对 20%（仅限长期充分验证的深护城河核心底仓），并允许档位偏贵上沿接近 1.5 |
| **合格** | ROIC **>WACC 且 ≥10%** | 支柱二达标 |
| **部分不达标** | ROIC 介于 **5%~10%** | 归观察仓待观察（既不否决也不达标） |
| **一票否决** | ROIC **长期 <5% 且仍在拼命扩产** | **放弃**（`GIR-1`）；<5% 但不扩产 → 归「部分不达标（观察仓）」 |

> **强制计算**：`roic --nopat … --invested-capital … --wacc …`；增量资本回报用 `incremental-roic`；WACC 用 `wacc`（`GIR-7`）。

#### 3.2 科技股口径协调（**调整后核心经营 ROIC**）

- 高研发投入科技股因研发费用化压低当期利润与 ROIC，本支柱的「≥10%」应改用**调整后核心经营 ROIC**（将费用化研发支出加回后的口径），避免机械套用导致误判
- 调整后核心经营 ROIC 仍 <10% 时，本项判「**部分不达标**（归观察仓）」
- **例外**：科研转化清单「资本回报效率」项仍独立按「ROIC > WACC」判定——即支柱二主阈值（≥10%）不豁免，仅豁免科研转化清单中的该单项
- **一票否决项（ROIC 长期 <5% 且扩产）独立按报表 ROIC 判定**，不适用调整口径

> **追问**：ROE 向上是科技股最可靠的「重力加速度」——过去 8 个季度是上行、持平还是下行？若 ROE 已拐头向下，护城河讨论的意义大打折扣。

### 第四步：逆向思考与风险清单

**核心问题**：如果我看错了，我会亏多少？什么时候该认错离场？

#### 4.1 失败路径分析

- 列出「这家公司在 1~5 年内可能失败的所有路径」（表格：路径 / 概率 / 影响程度）
- **偏误自查**：叙事偏差、锚定效应、幸存者偏差、线性外推偏差

#### 4.2 硬止损位设定

- 基于当前价格，**8%~10%** 止损设在什么位置？（`garp-exit` 转接 `momentum.stop_price()`，`atr(period=14)` / `multiplier=2.0`）
- **建仓初期**（持仓 < 最终仓位 50%，**或**持仓 ≥50% 但逻辑尚未经 2~3 季财报持续兑现验证）下跌超 8%~10% → **无条件离场**，不得以「股价更便宜」为由逆向补仓
- **底仓已建立且逻辑已验证**（须**同时满足**①达到最终仓位 50% ②逻辑经 2~3 季兑现）→ 下跌 ≤20% 且多维未恶化，可在合理估值下限加仓；>20% 转入「暂时性困难 vs 永久性衰退」清单复核

#### 4.3 逻辑止损触发条件

- 连续 **2 个季度**业绩低于预期且产业景气未改善
- 财务不可逆恶化（应收账款暴增、存货高企、现金流持续为负）
- 龙头地位被颠覆、科研转化大幅低于预期
- 管理层或科研转化评分**跌破 10 分**（非诚信事项）

#### 4.4 时间止损

- 持有满 **4 个季度（1 年）**，买入逻辑仍未兑现（订单 / 收入 / 利润无实质改善）→ 减至观察仓或替换

> **层级归属**：本节的 4.2 / 4.3 / 4.4 为**风险预案描述**，其**权威定义与执行层级一律归 `garp-exit`（五级卖出 + 时间止损）**，本技能**不自建卖出层级、不自建止损链**（`GIR-4`）。

#### 4.5 地缘政治档位归属与敞口体检（**0.3 三维交叉矩阵 + 赛道两分法**）

> **口径来源**：**0.3 三维交叉矩阵**（地缘倒逼强度 × 政策覆盖度 × 国字号基金介入）的档位判定归 `garp-geo-policy`（P4-1），本技能**只照引档位、不自判、不发明系数**（`GIR-9`）。

**赛道两分法**：

| 赛道类型 | 典型环节 | 支柱四的处理 |
| --- | --- | --- |
| **地缘倒逼型** | 半导体设备 / 材料等 | 「地缘倒逼强度**非低 / 无**」为**硬门槛**，不满足即不建仓 |
| **政策资本驱动型** | 机器人、信创等增量创造 | **豁免**该硬门槛，但海外收入 / 供应链 / 地区冲突等**敞口仍须体检**，达标与否交由支柱五判定 |

**与五大支柱的映射**：**支柱四对应「地缘倒逼强度」维**；**支柱五对应「政策覆盖度 + 国字号基金介入」两维**。「回避档」的共同特征是**政策覆盖度低 / 无 + 国字号基金无覆盖**（政策与资本两维同时失守），此时无论地缘倒逼高低**均一票回避**。

**支柱四八项敞口体检**（逐项判定，须给出证据行）：

| # | 体检项 | 关注要点 |
| :--: | --- | --- |
| 1 | 海外收入依赖度 | 海外收入占比越高，越易受关税 / 出口管制冲击 |
| 2 | 资源与供应链依赖 | 关键零部件 / 原材料是否依赖特定国家或单一供应商 |
| 3 | 地区冲突暴露 | 产能、客户、物流是否落在冲突或高摩擦区域 |
| 4 | 供应链可控性 | 关键环节可否切换 / 自建 / 多源化 |
| 5 | 资源自给 | 上游资源自给率与议价能力 |
| 6 | 本地化进展 | 海外建厂 / 本地化运营 / 多元供应链进展 |
| 7 | 关税与出口管制 | 目标市场关税、反补贴、出口管制清单变化 |
| 8 | 替代进度 | 被断供环节的国产替代验证与放量进度 |

> **刚性约束**：矩阵**未列组合按更审慎的相邻档位归档**；**国字号注资不作买入估值依据**——其入股成本远低于二级市场，最终决策仍须回到估值与业绩兑现框架；**矩阵只有定性档位，一律禁止发明系数**（缺口 U3）。

#### 4.6 暂时性困难 vs 永久性衰退判断清单

| 判断维度 | 暂时性困难（可加仓） | 永久性衰退（需清仓） |
| --- | --- | --- |
| **行业需求** | 需求延迟，但长期趋势未变 | 需求被替代品永久性替代 |
| **竞争格局** | 份额短期波动，但优势仍在 | 份额持续流失，护城河消失 |
| **财务** | 现金流短期承压，但资产负债表健康 | 现金流持续为负，债务恶化 |
| **管理层** | 承认问题，有清晰应对方案 | 推卸责任，频繁更换高管 |
| **研发** | 研发投入维持或增加 | 研发投入持续削减 |
| **客户** | 客户流失是暂时性的，可挽回 | 核心客户永久性转向竞争对手 |

**使用规则**：对核心底仓，若判断为「暂时性困难」，且产业逻辑、科研转化（科技股）、管理层、财务等维度均未恶化，可在合理估值下限附近加仓；若判断为「**永久性衰退**」，**无论盈亏立即清仓**。

> **追问**：如果买入后下跌 8%，你会加仓还是止损？——如果答案是「加仓」，说明你还没想清楚最坏情景。**先想清楚亏多少，再想赚多少**。
>
> **追问**：市场恐慌时，这家公司的基本面发生了什么变化？基本面没变 → 恐慌是买入机会；基本面恶化 → 恐慌是逃命信号。

### 第五步：产业景气与 ROE 拐点分析

**核心问题**：产业处在景气周期的什么位置？增速方向与加速度是正还是负？

> **口径来源**：赛道景气维度、渗透率分档、ROE 拐点的权威口径见 `garp-industry-research`（P4-9），本步**引用其结论，不重复定义**。

**郑希维度 — 产业景气判断**：

- **ROE 趋势**：近 8 个季度 ROE 数据——上行、筑顶、还是下行？（**连续 3 季同向**才判拐点，单季波动判噪音）
- **营收增速趋势**：近 8 个季度营收增速——逐季加快、持平，还是放缓？
- **订单增速 / 产能利用率**：领先指标显示什么方向？
- **全球产业链位置**：公司在产业链中处于什么环节？上下游景气是否共振？
- **季度验证**：过去 4 个季度，每季度数据是否都在验证买入逻辑？

**李进维度 — 渗透率与增速趋势**：

- **渗透率定位**：当前渗透率精确刻度；距离 15% 加速临界点多远？距离 40%~60% 逐步兑现区间多远？
- **增速趋势判断**：最近 2~3 个季度增速的**方向与加速度**（加快 / 持平 / 放缓）——**此为定性趋势判断，非框架条款**（登记为推导口径，见 `GIR-12`）：增速加快 → 估值扩张阶段；增速放缓 → 估值收缩信号；即便行业仍在增长，一旦增速趋势转弱，估值中枢亦将下移
- **真实趋势 vs 题材炒作**：有订单 / 收入 / 利润支撑，还是纯概念？扣非净利润增速是否匹配营收增速？

**转接**：季度加速度的二阶验证可调用 `qoq-accelerator`（**全档位通用复用**技能）。

> **追问**：「长期判断由无数短期客观判断拼接而成」——过去 4 个季度的财报数据是否一致支持你的买入逻辑？如果不是，哪一季度的数据出现了偏离？

### 第六步：管理层与科研转化

**核心问题**：管理层可信吗？科研能力能转化为业绩吗？

> **口径来源**：**诚信前置闸门、7+7+6、科研转化 8+8+4、费雪补充项、ESG 三通道的权威定义归 `garp-management`（P4-4）**，本技能**只引用结论与闸门、不复制评分表**（`GIR-2`）。

#### 6.1 现任管理层画像

- **CEO / 创始人**：姓名、年龄、任职起止时间、关键决策记录（近 3~5 年）
- **核心高管团队**：CFO / COO / 技术负责人稳定性（离职率 <10%）
- **持股比例与利益对齐**：持股比例及变化、近 1 年增减持情况、大股东质押率（>50% 预警）
- **薪酬结构**：是否与长期业绩挂钩

#### 6.2 诚信前置闸门（**不计分，命中即放弃或清仓**，`GIR-2`）

| 检查项 | 处置 |
| --- | --- |
| 年报「说到做到」验证：**兑现率 <50%** | **一票否决** |
| 业绩预告重大失真（频繁大幅修正且方向向下） | **一票否决** |
| 财务造假实锤 | **一票否决** |
| 监管立案 | **一票否决** |
| 归因习惯：习惯性将未达目标归咎于外部环境、从不自省 | **一票否决** |

> **刚性**：诚信维度**独立于 20 分制、不赋分**——一旦命中，**无论总分是否达标，直接放弃或清仓**，不进入 20 分制求和；**不得因数据缺失而跳过该闸门**（缺失即标注风险，不用高分默认）。

#### 6.3 管理层 20 分制（**≥15 可重仓**）

| 维度 | 检查项 | 分值 |
| --- | --- | --- |
| **对待股东** | 分红历史（≥30% 为优）；融资记录；回购行为；大股东质押率（>50% 预警） | **7** |
| **战略执行力** | 是否聚焦主业；核心战略落地情况；行业格局认知深度 | **7** |
| **稳定性与激励** | 核心团队稳定性（离职率 <10%）；股权激励合理性；内部人增减持是否异常 | **6** |

**退档规则**：**≥15 → 可重仓**；**10~14 → 观察仓**（单只上限 ≤5%，不重仓）；**<10 → 放弃**。

#### 6.4 科研转化 20 分制（**科技 / 医药必填，≥15 可重仓**）

| 维度 | 检查项 | 分值 |
| --- | --- | --- |
| **研发投入「质」与「量」** | 研发强度 ≥15% 且逐年提升；资本化率 <30% 为审慎；研发人员占比 ≥30% | **8** |
| **研发产出效率** | 发明专利数量与质量；新产品收入占比 ≥20%；技术产品化周期；重大科研项目节点推进 | **8** |
| **资本回报效率** | ROIC > WACC（**独立按报表 ROIC 判定**）；增量资本回报率 > 存量 ROIC | **4** |

**合成规则（两套独立、不合计不加权）**：科技股须「**管理层 ≥15 且 科研转化 ≥15**」；普通行业只以管理层 20 分制判定。科研转化退档同管理层规则（10~14 观察、<10 放弃）。

#### 6.5 费雪补充项（定性，**不计入 20 分制**）

| 补充检查项 | 评估标准 |
| --- | --- |
| **销售组织出色** | 经销商覆盖率、销售团队稳定性、客户获取成本趋势、销售费用率变化 |
| **管理层持股比例高** | 核心管理层持股 **≥3%**，与股东利益高度一致 |
| **暂时性困难 vs 永久性衰退** | 见第四步 4.6（费雪逆势加仓的判断前提） |

#### 6.6 ESG 三通道（**联动**）

| 通道 | 评估要点 | 联动 |
| --- | --- | --- |
| **治理（G，最关键）** | 治理缺陷是财务造假、掏空资产、关联交易的核心风险源 | 与「诚信一票否决」联动；评分明显偏低或多次被问询 / 处罚 → 直接触发诚信否决 |
| **环境（E）** | 是否属高碳排放、高环境风险行业（化工、有色、钢铁、火电、高污染制造等）；环保合规与碳减排路线 | 定性提示，**定量折价交第七步** |
| **社会（S）** | 用工合规、产品质量与召回、供应链劳工争议 | 作辅助参考，重大负面事件计入风险提示 |

> **注意**：ESG 评级各机构口径不一、覆盖不全且存在时点滞后，**只作辅助信号，不替代基本面诚信核查与财务验证**。

> **追问**：管理层是「说到做到」，还是「说到算到」？过去 3 年年报的战略承诺，兑现了几成？

### 第七步：估值与买入时机（**多工具矩阵 + 统一六档**）

**核心问题**：这家公司该用什么工具估值？现在贵不贵？该怎么买？

> **口径来源**：**多工具矩阵、统一六档、ESG 折价、宏观区间、三级留痕的权威定义归 `garp-valuation`（P4-5）**——本技能的**估值结论唯一出口**即该技能，本技能**零档位自建、零结论自建**（`GIR-5`）。

#### 7.1 五类公司类型 × 估值矩阵（**先定类型，再选锚**）

| 公司类型 | 核心工具 | 辅助工具 | 可接受标准 |
| --- | --- | --- | --- |
| **快速增长型（盈利稳定）** | **调整后 PEG** | 远期 PE、PEG 分位 | PEG **<1 低估** / **1~1.2 合理** / **1.2~1.5 合理偏贵**（持有不加仓、机动仓择机减）/ **>1.5 高估** |
| **高研发投入型（利润被压低）** | **PS / EV-Sales** | **Rule of 40** | **Rule of 40 ≥ 40**（收入增速 + 利润率或 FCF 利润率）；EV/Sales 低于同业可比 |
| **未盈利科技型** | PS、EV-Sales | **研发管线 NPV** | 需有清晰的盈利路径与里程碑节点 |
| **稳定增长型** | 远期 PE + **隐含 PEG** | 股息率 | 当前 PE ≤ 未来 3 年 EPS 复合增速（百分数值）×1.2（即**隐含 PEG ≤1.2**） |
| **成熟型企业** | **DCF** | 股息贴现 | 当前市值 ≤ **保守 DCF 估值的 80%** |

**PEG 使用边界**：PEG 适用于盈利稳定的成长股；PS / EV-Sales 适用于高研发投入或未盈利科技股；DCF 适用于现金流稳定的成熟企业；**科技股须多工具交叉验证，避免单一指标误判**。

**科技股调整后口径**：高研发投入公司研发费用化会虚增 PE、虚增 PEG，**务必用「核心经营利润」口径回算调整后 PE**（`adjusted-peg`）。

**「合理偏贵」统一口径**：合理买入区间之上、高估阈值之下的中间带（中性环境即 **1.2~1.5**）= **合理偏贵**——可继续持有底仓、**不加仓**，机动仓逢高择机减仓。**「增速确定性」三锚**：①连续 2~3 季度增速稳定性 ②订单可见度（在手订单 / 预收 / 合同负债覆盖度）③竞争格局固化程度（CR5 与龙头份额趋势）；**任一偏弱 → 偏贵上限收紧至 1.2**。

#### 7.2 三级留痕与 ESG 折价（**四级收口**）

**收口链（每级须留痕）**：

```text
基准档位 → 宏观校准后 → ESG 折价后 → 最终档位
```

最终档位统一收口至 `garp-valuation`（P4-5）**统一六档**：**显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支**。

**ESG / 环境风险折价**：

| 情形 | 折价幅度 | 操作要点 |
| --- | --- | --- |
| **高环境风险行业（无明确转型路径）** | 合理估值再打 **8~9 折**（折价 10%~20%） | 相当于合理上限下调；DCF 目标价、区间一并下调 |
| **有明确碳减排承诺与可验证转型路径** | 折价收窄至 **≤5% 或豁免** | 须有具体资本开支计划、减排节点与第三方验证，否则仍按无转型处理 |
| **面临「搁浅资产」风险** | 折价加大，且**上调贴现率** | DCF 中额外上调 **1~2 个百分点**贴现率，反映资产被迫提前退役的不确定性 |
| **ESG 评级处行业尾部 / 最低档** | 触发治理或环境风险预警 | 不再下调估值，而是**先降仓位上限**（如绝对上限 20% → 15%） |

> **叠加纪律**：环境风险折价是**在基本面估值之上再打一次折扣**，**不替代**多工具估值，二者须叠加使用；对高环境风险标的，**即使折价后看似便宜，也应同步下调单只仓位上限**。

#### 7.3 宏观 PEG 区间（**只调参不择时**，`GIR-6`）

> **口径来源**：宏观三表与调档参数归 `garp-macro`（P4-2）/ `tools/specialized/macro_calibrator.py`——本技能**只读透传、不自判 stage**。

**（一）利率周期 → PEG 合理买入区间**

| 利率环境 | 合理买入区间 | 低估（可加仓） | 高估（减机动仓） |
| --- | --- | --- | --- |
| **加息 / 高利率** | 收紧至 **0.8~1.0** | <0.7 | >1.2（0.7~0.8 为空档，不主动加仓） |
| **中性（基准）** | **1.0~1.2** | <1.0 | >1.5 |
| **降息 / 低利率** | 放宽至 **1.2~1.5** | <1.2 | 仍 >1.5 减仓，**>2 绝对透支清机动仓** |
| **滞胀** | 进一步下探至 **0.8** | — | 同上 |

**（二）经济周期 → 现金与个股上限**

| 参数 | 中性 / 复苏期（基准） | 衰退期（收紧） | 过热期 | 滞胀期 |
| --- | --- | --- | --- | --- |
| **现金仓位** | 10%~20%（估值分位 >80% 时提至 20%~30%） | 30%~40% 或更高 | ≥25% | ≥40% |
| **单只个股上限** | 初始 ≤10% / 验证后 ≤15% / 绝对 ≤20% | ≤8% / ≤12% / ≤15% | ≤8% / ≤12% / ≤15% | ≤6% / ≤10% / ≤12% |
| **单一行业上限** | ≤40% | ≤30% | ≤25% | ≤20% |

**（三）美林时钟 + 信用周期 → 框架参数**

| 宏观阶段 | PEG 合理买入上限 | 现金仓位 | 单只上限（验证后） |
| --- | --- | --- | --- |
| **衰退** | **1.0**（临时收紧） | 30%~40% | ≤12% |
| **复苏** | **1.5**（放宽） | 10%~20% | ≤15% |
| **过热** | **1.0**（收紧） | ≥25% | ≤12% |
| **滞胀** | **0.8**（最紧） | ≥40% | ≤10% |

**刚性约束**：

- **「>2 为严重透支」红线不因降息而取消**（仅可放缓减仓节奏）
- 宏观**只调「估值容忍度」与「仓位尺度」**，**不替代个股基本面判断、不作为择时清仓依据**（`GIR-6`）

#### 7.5 分批建仓（**默认三分法**）

| 阶段 | 动作 | 触发 |
| --- | --- | --- |
| 首仓 | 建 **1/3** | 股价进入「合理买入区间」后 |
| 第二批 | 补至 **2/3** | **右侧确认信号**（产业景气加速 / 财报超预期 / 趋势反转确认，**三者至少其一**） |
| 补齐 | 补至最终仓位 | 经**连续 2~3 个季度财报持续兑现** |

- **「首仓」定义**：单只个股的第一批建仓，此时持仓 < 最终仓位的 50%，属**建仓初期**，止损按 8%~10% 执行
- **建仓初期**硬止损**优先于**「跌破估值下限补仓」；**加仓一律以右侧确认信号为准，而非「股价跌得更低」**
- **注意区分**：「三者至少其一」是补至 2/3 的**常规加仓信号**；下述「一次性建 2/3」的触发是**三信号共振**的极端强势信号，两者不是同一门槛

#### 7.6 左侧配置 vs 右侧确认

| 布局方式 | 适用场景 | 操作要点 |
| --- | --- | --- |
| **左侧（逆向）** | 行业遭遇**短期利空**（政策打压、周期低谷、税务抛售期），但**长期逻辑未破坏** | 分批建仓；**首批限制在该标的最终仓位的 50% 以内**（**此为可建上限、非必须比例**，越不确定越压低）；剩余须待右侧信号确认后补齐 |
| **右侧（顺势）** | 渗透率突破 15% 临界点、财报连续 2 个季度超预期、行业景气明确上行 | **可一次性建 2/3**，剩余 1/3 在回调至 20 日均线时补齐；**但仅当三信号共振时才启用**，常态（含一般右侧介入）仍按三分法阶梯推进 |

- **核心原则**：左侧仅适用于「**杀估值**」而非「**杀逻辑**」——杀估值可逆向，**杀逻辑必须止损**
- **右侧一次性建 2/3 后的止损口径**：虽持仓已 >50%，但「逻辑验证」须经后续 2~3 个季度财报持续兑现才成立，故止损仍按**建仓初期口径 8%~10%** 执行；待财报持续兑现、逻辑充分验证后才放宽至底仓口径 20%

#### 7.7 底仓 / 机动仓 / 现金（**两层口径，执行顺序不可颠倒**）

| 仓位类型 | 定位 | 操作规则 |
| --- | --- | --- |
| **底仓（60%~80%）** | 长线核心，赚企业 1~5 年成长的钱 | 只要买入逻辑未被破坏，始终保留；不因短期 20% 以内波动而卖出；可每季度结合最新财报小幅调整（**±5%**） |
| **机动仓（20%~40%）** | 平滑波动，赚估值波动的钱 | 股价进入高估区间时减持，回落至合理区间时回补 |

> **两层口径（务必区分）**：底仓与机动仓之和恒为 100%，指**股票仓位内部**的切分；现金比例（常态 **10%~20%**、风险期 20%~30% 或更高）指**占总资产**的比例。**执行顺序**：先按宏观 / 风险预算确定现金占总资产的比例，剩余部分再按底仓 / 机动仓切分。

**组合层约束（本技能不重做组合分析）**：组合 **5~10 只**；**3~4 只核心**（单只 **12%~15%**）+ **2~3 只卫星**（单只 **5%~8%**）；最多 **2 只**上浮至 **20%**（上浮后合计 ≤2 只）；单行业 ≤40%；标的相关性 <0.5。**集中度 / 相关性 / 机会成本 / 压力测试的组合级判定归 `garp-portfolio-review`（P4-8）**，本技能只在个股层面标注该标的上限占用。

#### 7.8 「假如空仓」测试（**每季度必做**）

> 「假如你现在空仓，你会以当前价格买入这家公司吗？」

- 若答案是「不会」→ 说明当前仓位是**沉没成本驱动**，而非逻辑驱动，须列入减仓候选
- 每季度复盘时重做一次；**估值透支替代预期**时必做

#### 7.9 趋势确认

调用 `tools/a_share/stock_quote.py --code {代码} --momentum --auto-peers` 获取 `atr14`、`smr_percentile`、`RSI(50)`、MA50 / MA200，用于**右侧确认信号的第三项**（趋势反转确认）；动量与均线技术面的完整判定归 `trend-momentum-scan`（**全档位通用复用**技能）。

> **刚性约束**：技术面信号**只用于「右侧确认」与「建仓节奏」，不作为卖出指令**——卖出层级一律引 `garp-exit`（`GIR-4`）。

#### 7.10 常见估值陷阱（**逐条核验**）

| 陷阱 | 识别要点 |
| --- | --- |
| **低 PE 陷阱** | PE 低但行业处于景气顶点，未来盈利下降会使 PE 被动抬升——须结合行业周期位置判断 |
| **高 PE 但增速不可持续** | 增速来自一次性收益（出售资产、外部红利），须剔除后重算真实值 |
| **忽略股权稀释** | 每股指标的增长可能来自回购减少股本，而非真实盈利增长——须结合总利润增速与股本变化 |
| **研发费用化扭曲** | 高研发投入科技股研发费用化虚增 PE / PEG，须用「核心经营利润」口径回算 |

### 第八步：综合决策备忘录与卖出纪律

**核心问题**：五大支柱汇总到底给什么结论？什么条件下必须卖出？

#### 8.1 五大支柱汇总判定（`GIR-3`）

**一票否决清单（命中任意一条即放弃或清仓，不进入后续判定）**：

| # | 否决项 | 语境 |
| :--: | --- | --- |
| 1 | **诚信一票否决**：兑现率 <50%、业绩预告重大失真、财务造假、监管立案 | **持仓后**为清仓信号（`garp-exit` 第一优先级） |
| 2 | **ROIC 长期 <5% 却在拼命扩产** | **买入前**闸门，命中即建仓前放弃 |
| 3 | **能力圈自检未通过**（尤其科技股「技术理解」不过关不得重仓） | **买入前**闸门 |
| 4 | **0.3 三维交叉矩阵综合归为「回避」档**（政策覆盖度低 / 无 且 国字号基金无覆盖，无论地缘倒逼高低） | **买入前**闸门 |

> **语境边界（务必区分）**：第 1 条针对**持仓后**的清仓信号；第 2~4 条属**买入前**闸门，命中即**建仓前放弃**、**不进入卖出金字塔**。

**达标判定（须全部满足方可建仓）**：

| 支柱 | 达标标准 |
| --- | --- |
| **支柱一（β）产业景气** | 产业景气向上——供需不恶化、产品单价稳定或上涨、CR5 提升或龙头份额扩大 |
| **支柱二（α）公司基本面** | ROIC > WACC 且 ≥10%（5%~10% 归「部分不达标」→ 观察仓；科技股按「调整后核心经营 ROIC」口径）；营收 / 利润增速匹配；ROE 趋势向上或企稳；毛利率 / 净利率不恶化 |
| **支柱三 管理层与科研转化** | 科技股须「管理层 ≥15 **且** 科研转化 ≥15」；普通行业须「管理层 ≥15」 |
| **支柱四 地缘与外部环境** | 海外收入、资源 / 供应链、地区冲突暴露可控；其中「地缘倒逼强度非低 / 无」**仅对地缘倒逼型赛道**作硬门槛，**政策资本驱动型赛道**豁免该门槛但敞口仍须体检 |
| **支柱五 政策与资本** | 政策覆盖度至少「中」及以上（矩阵非「低 / 无覆盖」），且国字号基金介入非「无覆盖」（至少有覆盖或专项子基金） |

**三档结论**：

- **全部达标** → 进入第七步估值锚定，**可建仓**
- **部分不达标** → **观察仓**（最多轻仓跟踪，等待信号补齐，**不重仓**）
- **任一否决命中** → **放弃或清仓**

## 专节一：五大矛盾化解方案

| 矛盾 | 化解口径 |
| --- | --- |
| **一 买点哲学**（左侧逆向 vs 右侧确认） | 分水岭 = **「杀估值」可逆向、「杀逻辑」必须止损**；左侧仅适用短期利空但长期逻辑未破坏，且**首批 ≤ 最终仓位 50%**、剩余待右侧确认补齐 |
| **二 持有时间维度**（长期持有 vs 动态调整） | 以**连续 2~3 季数据趋势**为判据；产业链景气与 ROE 趋势未破坏 → 持有；趋势破坏 → 调仓 |
| **三 止损 vs 越跌越买** | 以**仓位状态**为分水岭 + **8%~10% 硬止损**；底仓建立且逻辑验证后容忍度放宽至 20%；**逻辑证伪立即清仓** |
| **四 分散 vs 集中** | 行业层面按李进思路**分散**，个股层面按费雪 / 欧奈尔思路**集中**；组合 5~10 只；3~4 只核心（单只 12%~15%）+ 2~3 只卫星（单只 5%~8%）；最多 2 只上浮至 20%；单行业 ≤40%；相关性 <0.5 |
| **五 费雪「绝不卖」 vs 趋势 / 景气纪律** | **两前提缺一不可**：①**极度深度的研究认知**（确信是持续创造增量价值的「杰出企业」，而非普通好公司）②**极度集中的持仓**（3~5 只、占总仓位 70%）。满足「深度认知 + 高确信度 + 管理层诚信 + 护城河稳固 + 财务健康」且下跌属**暂时性困难** → 可采纳费雪逻辑继续持有甚至加仓；**缺乏前提或属永久性衰退 → 按趋势 / 景气纪律离场或调仓**。**核心原则：费雪的「不卖」是「认知深度的奖赏」，不是「懒惰不研究的借口」** |

**实战冲突场景（矛盾五）**：某底仓深度研究、管理层诚信优秀的标的，因行业景气短暂下行，股价回撤 18%，调整后估值升至偏贵区。费雪说「杰出企业不要卖」；李进说「景气下行该调仓」；欧奈尔说「趋势已走坏」。——**按上表两前提逐条检验后取唯一解**：两前提同时满足且属暂时性困难 → 持有或加仓；任一前提不满足 → 服从景气与止损纪律。

> **自评项标注（`GIR-12`）**：矛盾五的「深度认知」与「高确信度」为**主观自评**，无工具化判据，须在报告中标注；**不得把自评项表述为工具化判据**。

## 专节二：决策优先级速查卡

> **权威定义归 `garp-exit`（P4-6），本表为速查，不构成第二套卖出口径。**

| 优先级 | 触发条件 | 决策 | 思想来源 |
| :--: | --- | --- | --- |
| **第一（一票否决）** | 管理层诚信问题暴露、财务造假实锤、监管立案 | **立即清仓**，不考虑估值和趋势 | 费雪 |
| **第二（硬止损）** | 单笔亏损达 8%~10%，且无明确基本面反转信号 | **止损离场** | 欧奈尔 |
| **第三（逻辑止损）** | 连续 2 个季度业绩低于预期，且产业景气未改善 | **减仓或清仓** | 林奇 + 郑希 |
| **第四（产业景气）** | 前三项均未触发，但渗透率 / ROE 出现拐点信号 | **按景气方向调仓** | 李进 + 郑希 |
| **第五（估值判断）** | 以上均未触发，仅股价短期波动或估值波动 | **底仓不动，机动仓调整** | 林奇 |

**核心原则**：**先保命（止损 / 防造假），再谈收益（景气 / 估值）**——底线规则优先于乐观逆向，产业判断优先于短期估值噪音。

**一页纸执行顺序**：① 核验诚信闸门 → ② 核对硬止损位 → ③ 核对逻辑是否证伪 → ④ 核对景气方向 → ⑤ 核对估值档位 → ⑥ 决定底仓 / 机动仓动作。

## 专节四：能力圈声明

**本技能的适用边界**（研究报告须在开头声明）：

- **适用**：具备可核验财务数据、可识别产业链位置、可判定公司类型的上市标的（A 股 / 港股 / 美股）
- **不适用**：无公开财务数据的未上市标的（走 `garp-private-company-research`）；无业绩兑现的纯概念标的（一票回避）
- **局限性**（须逐条在报告「注意事项 / 局限性」中复述）：
  1. 能力圈四维自检为**主观自评**，非工具化判据
  2. 信息丰富度评级为**主观自评**，C 级公司结论不得为确定性
  3. **渗透率与国产化率数据缺乏标准化工具出口**，须依赖第三方数据与年报表述，可能滞后
  4. **0.3 三维交叉矩阵为定性档位**，无量化系数，档位判定归 `garp-geo-policy`
  5. **宏观阶段由外部判定**（`garp-macro`），本技能不自判
  6. **管理层 / 科研转化 / ESG 评分依赖年报文本与第三方评级**，覆盖不全且存在时点滞后
  7. **估值矩阵的「可接受标准」为框架口径**，不构成对个股的精确目标价
  8. **研发管线 NPV 为粗算**，对未盈利科技型的估值精度有限
  9. 本技能输出**不构成投资建议**，仅用于学习与研究
  10. 报告结论受**数据截止日**限制，须标注三日期并定期复核

## 输出要求

1. **报告头**：公司名 / 市场 / 研究深度 / **三日期**（数据基准日、报告生成日、下一复核日）/ 所属档位 / **信息丰富度 A/B/C** + AI 研究局限性声明
2. 所有分析必须有数据支撑，附数据来源；关键数据 ≥2 个独立来源，误差 >1% **必须标记**
3. 使用 Markdown 表格呈现关键数据
4. 每个模块末尾必须有对应大师的「追问」
5. 结论要明确：**必须包含五档估值位置、硬止损位、卖出触发条件**，不回避「可建仓 / 观察仓 / 放弃」的建议
6. 估值部分必须给出**公司类型判定 + 主锚 / 辅锚选型 + 四级收口留痕 + 分批建仓计划**
7. **必须标注自评项与推导口径**（`GIR-12`）：能力圈四维自检、费雪「绝不卖」两前提、增速趋势的定性判断
8. **所有硬性规则输出必须包含规则编号引用**（如「触发 `GIR-2`」）
9. 报告结尾必须区分「**AI 分析置信度**」与「**投资确定性**」，并列出「需要一手验证的问题清单」（C 级公司必填）
10. 报告命名一律含 `garp-` 标识（见下），**不触碰其他档位报告文件**
11. 报告写入后必须执行**数据抽检准出流程**，通过方可发布

**报告路径**：

reports/{公司名}/{公司名}-garp-research-{YYYYMMDD}.md

## 风控硬编码 GIR-1~GIR-12

| 编号 | 规则 | 不可做的事 |
| --- | --- | --- |
| `GIR-1` | **能力圈闸门 + ROIC 否决**：普通行业须同时通过「产业理解 + 财务理解 + 估值理解」；**科技股「技术理解」为必答项**，不过关不得重仓；ROIC 长期 <5% 却在拼命扩产 → **一票否决** | 不得对能力圈外标的给出可建仓结论；不得以「高增速」豁免 ROIC 否决 |
| `GIR-2` | **诚信一票否决前置**：兑现率 <50% / 业绩预告重大失真 / 财务造假实锤 / 监管立案 → **放弃或清仓** | 不得以其他维度高分或估值便宜豁免；不得因数据缺失而跳过该闸门 |
| `GIR-3` | **五大支柱汇总判定**：全部达标 → 进入估值锚定可建仓；部分不达标 → **观察仓**；**任一否决命中 → 放弃或清仓**；0.3 矩阵归「回避」档 → 一票回避 | 不得各支柱罗列而不收口；不得跳过三档结论直接给买入建议 |
| `GIR-4` | **卖出只引不自建**：五级优先级 + 时间止损（满 4 季度）+ 性价比替换（每季最多 1 次）**一律引用 `garp-exit`** | 不得自建第二套卖出层级；不得把技术面信号写成清仓指令 |
| `GIR-5` | **估值唯一出口**：结论须按公司类型选锚并收口 `garp-valuation` **统一六档**；**禁止以单一 PEG 作估值结论** | 不得自建档位表；不得以心算替代 `financial_rigor.py` |
| `GIR-6` | **宏观只调参不择时**：三表参数经 `garp-macro` / `macro_calibrator.py` 透传，只调「估值容忍度」与「仓位尺度」 | 不得以宏观判断替代个股基本面结论或作为清仓依据；不得自判宏观阶段 |
| `GIR-7` | **计算纪律**：市值 / 估值 / ROIC / 调整后 PEG / Rule of 40 / EV-Sales / DCF / 隐含增速一律经 `financial_rigor.py`；评分经 `governance_data.py`；宏观参数经 `macro_calibrator.py`；ATR 止损价经 `garp-exit` 转接 | **禁止心算**；禁止自建止损链；禁止改写工具终值 |
| `GIR-8` | **渗透率与国产化率口径**：渗透率五档以 **15%~40% 为黄金窗**；国产化率四梯队；两者**分工不得互相替代** | 不得自建梯队数；不得默认落黄金窗 |
| `GIR-9` | **地缘闸门**：0.3 三维矩阵档位**只读 `garp-geo-policy`**；**地缘倒逼型**赛道地缘倒逼强度为「低 / 无」→ 不得建仓；**政策资本驱动型**仅作敞口体检；未列组合按**更审慎相邻档**归档；**国字号注资不作买入估值依据** | 不得自判矩阵档位；不得发明矩阵系数；不得因未列组合默认放行 |
| `GIR-10` | **数据置信度**：关键数据 ≥2 源、误差 >1% 标记；市值手算校验；信息丰富度 A/B/C 写入报告；**C 级不作确定性结论** | 不得以单一来源支撑可建仓结论；不得以推测填补缺口 |
| `GIR-11` | **报告与口径隔离**：报告命名一律含 `garp-` 标识；引用只指向 `garp-*` 与复用 2 技能 | 不得触碰其他档位报告文件；不得出现其他档位可执行口令 |
| `GIR-12` | **自评项与推导口径显式标注**：能力圈四维自检、费雪「绝不卖」两前提、增速趋势的定性判断、已废止的推导阈值须在报告中标注来源 | 不得把自评项表述为工具化判据；不得把推导口径表述为框架条款 |

> 所有硬性规则输出必须包含**规则编号引用**（如「触发 `GIR-2`」），确保可审计可追溯。

## 注意事项 / 局限性

1. **档位隔离（最高优先）**：本技能属 GARP 独立档（1~5 年）。命令与输出中**不含任何档位切换开关**；引用只指向 `garp-*` 技能与全档位通用复用的 `qoq-accelerator` / `trend-momentum-scan`。
2. **不新增工具、不改工具签名**：本技能**零 Python CLI 新增**，全部依赖既有工具实测形态。
3. **估值结论唯一出口**：一律收口 `garp-valuation` 统一六档；**不以单一指标作估值结论**。
4. **卖出层级唯一出口**：一律引 `garp-exit`；本技能的第四步 4.2~4.4 为风险预案描述，不构成第二套口径。
5. **执行顺序刚性**：先确定现金占总资产比例，再切分底仓 / 机动仓；加仓以右侧确认信号为准，而非「股价跌得更低」。
6. **一票否决的语境边界**：诚信否决针对持仓后；ROIC / 能力圈 / 矩阵回避属买入前闸门，命中即建仓前放弃。
7. **数据不虚构**：搜不到即标注「估计」或「数据不足」；**不以推测填充矩阵 / 区间 / 评分**。
8. **工具缺陷如实披露**：`governance_data.py --help` 崩溃、`geo_policy_screen.py scan` 须用 `python -m`、`fx_rate.py` 跨币种折算不可用 —— 遇错记录原始报错与退出码，登记待上报事项，不得静默吞掉。
9. **主观自评项须显式标注**（`GIR-12`）：能力圈四维、信息丰富度评级、费雪「绝不卖」两前提、增速趋势定性判断。
10. **免责声明**：本技能用于学习与研究，**不构成投资建议**。

**已知数据缺口（不影响本技能执行，统一登记于待上报事项）**：

| # | 缺口 | 处置 |
| :--: | --- | --- |
| 1 | 渗透率 / 国产化率无标准化工具出口 | 依赖第三方数据与年报表述，**标注置信度**，不默认落黄金窗 |
| 2 | 0.3 矩阵各场景无量化系数 | 一律标注「定性档位」，**不发明系数** |
| 3 | 增速趋势判断无框架条款 | 保留为**定性判断**并登记为推导口径，**不设自造阈值** |
| 4 | 能力圈四维 / 费雪两前提为主观自评 | 报告中标注「自评项」，不作工具化判据 |
| 5 | `fx_rate.py` 跨币种折算不可用 | 取汇率后由 `financial_rigor.py calc` 显式折算并标注汇率时点 |
| 6 | 非三市场标的（未上市 / 冷门市场） | 明确标注「工具未覆盖」，转人工取数，**不以境内数据代入境外标的** |
