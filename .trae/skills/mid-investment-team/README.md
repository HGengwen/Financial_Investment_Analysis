# 投研团队（1~3年景气）(Mid-Term Investment Team)

欧奈尔-林奇-郑希-李进 四角色并行分析框架：对单家公司进行团队化 1~3 年景气投资研究

> 本技能属**中期链（1-3 年）**，与长期链 `investment-team`（10 年 / 段永平-巴菲特-芒格-李录）**物理隔离、功能互补**。核心理念：**景气驱动，动态持有，纪律退出**——四位大师并行研究，Team Lead 综合研判，产出系统化中期投资研究报告。

---

## 快速开始

### 基本调用方式

```
/mid-investment-team {公司名}
```

例如：
- `/mid-investment-team 新易盛`
- `/mid-investment-team 中际旭创`
- `/mid-investment-team 腾讯`

## 核心功能

对指定公司进行团队化 1~3 年景气投资研究分析。四位大师并行研究，Team Lead 综合研判，产出系统化的公司投资研究报告。

### 四角色团队结构（对齐 V2.0 权威分工）

| 角色 | 大师 | 职责 | 分析框架 |
|------|------|------|---------|
| **Team Lead**（你自己） | 四位大师综合 | 统筹协调、汇总研判、输出最终报告 | 欧奈尔-林奇-郑希-李进综合框架 |
| **Agent 1** | 欧奈尔 | 风控底线：止损位、卖出触发、趋势信号、底线纪律 | 工程师思维 · 信号与纪律 |
| **Agent 2** | 林奇 | 选股起点 + 估值定价：常识选股、财务初筛、PEG 五档、估值陷阱 | 侦探思维 · 常识与求证 |
| **Agent 3** | 郑希 | 赛道选择：产业景气、ROE 拐点、渗透率、地缘政治六维度 | 物理学家思维 · 周期与第一性原理 |
| **Agent 4** | 李进 | 组合管理 + 治理：底仓/机动仓、管理层与科研转化、治理一票否决 | 系统工程师思维 · 均衡与渗透率 |

### 七步执行流程

1. **展示团队框架** — 确认后启动四 Agent 并行研究
2. **信息丰富度评估** — A/B/C 级评级 + AI 研究偏见预警，影响各 Agent 研究方式
3. **A股财报原文下载** — 仅 A 股，必须先下载 PDF 才能启动 Agent
4. **启动 4 个并行研究 Agent** — 同一条消息中调用 4 次 Task 工具
5. **实时跟踪进度** — 每收到一份报告更新进度 + 核心发现
6. **Team Lead 汇总最终报告** — 找交叉和矛盾，不是拼报告
7. **保存报告** — 写入 `reports/{公司名}/{公司名}-mid-investment-team-{YYYYMMDD}.md`

### Team Lead 汇总要点

不是拼报告，是找交叉和矛盾：
1. **四个视角的共识点** — 四位大师都同意的结论，可信度最高
2. **四个视角的矛盾点** — 比如林奇说估值便宜，但郑希说产业景气拐头向下——这种矛盾才是最有价值的分析
3. **被忽略的角落** — 四个人都没重点提的东西，是否恰恰是最重要的？

## 输出报告

报告将保存在以下位置：

| 报告类型 | 文件路径 |
|---------|---------|
| 中期团队研究报告 | `reports/{公司名}/{公司名}-mid-investment-team-{YYYYMMDD}.md` |

> 英文后缀 `-mid-investment-team-` 直白区分中期，且不与长期链 `-investment-team-` 碰撞。

如果 `reports/{公司名}/` 目录不存在则创建。

### 最终报告结构

```
一、一句话结论（是否值得 1~3 年投资及核心逻辑）
二、四维评分总表（欧奈尔/林奇/郑希/李进 + 综合评分 X/5）
三、核心数据速览（近 2 年关键财务与经营指标）
四、各维度分析摘要（每维度 3-5 条核心发现）
五、管理层与科研转化评估（李进：管理层 20 分制 + 科研转化 20 分制）
六、估值与买卖区间（引用 valuation-thermometer 五档温度 + 底仓/机动仓操作）
七、投资论点（Bull vs Bear，各 5-7 条）
八、买入前 Checklist（引用 mid-investment-checklist 七关，逐一评估）
九、最终投资建议（底仓/机动仓分层建议 + 建仓价/止损价区间）
十、总结段落（100-200 字）
```

## 研究标准

### 信息丰富度评估（必执行）

| 等级 | 特征 | AI 研究陷阱 | 应对策略 |
|------|------|-----------|----------|
| **A级（信息充裕）** | 上市多年、券商覆盖广 | 共识过强，输出趋同市场定价 | 重点反面检验和非共识视角 |
| **B级（信息适中）** | 上市 1-3 年、覆盖有限 | 用推测填补空白，产生虚假确定性 | 推算数据标注置信度 |
| **C级（信息稀缺）** | 冷门/新上市/新兴市场 | 因资料不足过度保守 | 第一性原理模式，聚焦核心问题 |

**关键提醒**：资料多≠确定性高，资料少≠确定性低。AI 能输出的置信度 ≠ 投资的真实确定性。确定性来自生意本质与景气趋势，不来自资料数量。

### 4 个 Agent 核心问题

| Agent | 大师视角 | 核心问题 |
|-------|---------|---------|
| Agent 1 | 欧奈尔 | 最坏情况会亏多少？什么时候必须无条件离场？ |
| Agent 2 | 林奇 | 这门生意我看得懂吗？现在这个价格值不值？ |
| Agent 3 | 郑希 | 产业处在景气周期的什么位置？地缘政治会不会毁掉赛道？ |
| Agent 4 | 李进 | 仓位怎么配？管理层可信吗？科研能力能转化为业绩吗？ |

### 引用不重复定义（中期技能体系铁律）

| 内容 | 权威口径来源 | 本技能处理方式 |
|------|-------------|---------------|
| PEG 五档估值 | `valuation-thermometer` | Agent 2 引用，不重复定义阈值 |
| 卖出纪律 P0~P5 | `exit-signal` | Agent 1/4 引用，时间止损归 P2 |
| 产业景气/渗透率 | `mid-industry-research` | Agent 3 引用，不重复定义 |
| 管理层/科研转化 20 分制 | V2.0 + `mid-management-deep-dive` | Agent 4 内嵌快速评估，B/C 级调纵深研究 |

### 数据准确性要求

- 关键数据至少来自两个独立来源，使用 `financial_rigor.py` 工具验算
- **禁止 LLM 心算** PE/ROE/市值/PEG
- 所有计算附工具输出记录
- 报告发布前必须通过 `tools/common/report_audit.py` 数据抽检（准出流程）

## 工具依赖

### mid-investment-team 的特殊工具使用注意

1. **A股财报下载是前置流程**：A 股公司必须先执行 `stock_equity.py --download-report` 下载年报 PDF，提取一手数据后再启动 4 个研究 Agent
2. **港股公司数据获取**：使用 `tools/hk_stock/stock_financial.py --financial {代码}` 获取财务指标；港股无 A 股财报下载工具，年报一手数据需从 HKEX 披露易获取（豆包搜索 `--sites hkex.com.hk` 定向检索）
3. **美股公司数据获取**：使用 `tools/us_stock/` 三个模块（stock_info/stock_quote/stock_financial）
4. **4 个 Agent 的财务计算须用 financial_rigor.py 验算**：Agent 2（林奇视角）的核心财务数据与 PEG 必须交叉验证，**禁止 LLM 心算**
5. **大宗商品相关公司须获取价格数据**：Agent 3（郑希视角·赛道选择）须使用 `tools/common/commodity_price.py` 获取相关品种价格
6. **跨币种折算须用实时汇率**：使用 `tools/common/fx_rate.py` 获取实时汇率，勿用固定汇率

### 网络搜索

禁止使用 Anthropic 官方 WebSearch/WebFetch（中国大陆不可用），统一使用本地五工具组合：

- **A股**：`anysearch --tag finance` 主 + `doubao --finance` 辅
- **港股**：`doubao --sites hkexnews.hk` 主 + `tavily` 辅
- **美股**：`exa --type deep` 主 + `tavily` 辅；新闻/舆情 → `doubao` 主

搜索须使用 `--time-range month/week` 限制时间范围，确保数据最新。

## 核心原则

1. **4 个 Agent 必须并行启动** — 在同一条消息中调用 4 次 Task 工具
2. **Team Lead 的价值在于综合判断** — 找交集和矛盾点，不是拼报告
3. **数据准确性** — 关键数据至少来自两个独立来源，使用 `financial_rigor.py` 工具验算
4. **结论要明确** — 不回避给出买入/观望/回避建议和具体价格区间、硬止损位
5. **呈现正反两面** — 每个核心判断都必须附带反面论据
6. **不预设立场** — 不预设看多或看空，先摆数据、再推逻辑、最后得结论
7. **信息稀缺时的诚实原则** — 宁可留白标注「数据不足」，也不用推测填满框架伪装确定性
8. **反偏见意识** — Team Lead 汇总时必须评估各 Agent 分析是否受限于资料充裕度、是否与市场共识过度趋同
9. **引用不重复定义** — 估值引用 `valuation-thermometer`，卖出引用 `exit-signal`（P0~P5），景气引用 `mid-industry-research`
10. **中期口径红线** — 禁止「护城河永续」「终局思维」「持有10年」等长期术语，持有周期以景气周期长度为准

## 注意事项

- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- 4 个 Agent 必须在同一条消息中并行启动，不可串行
- A 股公司必须先下载财报 PDF，**下载完成后方可启动 4 个研究 Agent**
- 资料评级（A/B/C 级）需告知每个 Agent，影响其研究方式
- 所有分析必须有数据支撑，附数据来源
- 关键财务数据至少两个独立来源交叉验证，使用 `financial_rigor.py` 工具验算
- 市值必须手算校验：股价 × 总股本，与报告市值对比
- 卖出纪律使用 `exit-signal` 的 P0~P5（时间止损归 P2，无 P6 层级）
- PEG 档位以 `valuation-thermometer` 五档为准（0.8/1.2/1.5/2.0 边界）
- 报告发布前必须通过 `tools/common/report_audit.py` 数据抽检（准出流程）

## 局限性说明

- **信息可得性**：港股小票、新上市公司可能无法获取到完整信息
- **扫描版 PDF 限制**：A 股年报常为扫描版 PDF，可能无法提取文本内容，影响附注分析
- **语言限制**：非中英文财报可能无法准确解读
- **非实时数据**：工具获取的数据可能有延迟，不是实时数据
- **渗透率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算，按 A/B/C 三级置信度标注
- **地缘政治数据更新频率**：制裁清单、关税政策等变化较快，需定期更新
- **并行执行复杂度**：4 个 Agent 并行执行可能需要较长时间
- 不构成投资建议，仅供学习研究参考
