# 投研团队：四角色并行分析框架（1~3年景气投资版）

对 $ARGUMENTS 进行团队化 1~3 年景气投资研究分析。四位大师并行研究，Team Lead 综合研判，产出系统化的公司投资研究报告。

**支持输入格式**：`公司名`，例如：`新易盛`、`中际旭创`、`腾讯`

> 本技能属**中期链（1-3 年）**，与长期链 `investment-team`（10 年 / 段永平-巴菲特-芒格-李录）**物理隔离、功能互补**。禁止使用「护城河永续」「终局思维」「持有10年」等长期框架术语。

---

## 设计理念

一份 1~3 年景气投资研究报告要解决四个问题：

1. **最坏会亏多少？什么时候必须离场？**——需要欧奈尔视角，看风控底线与卖出纪律
2. **这门生意看得懂吗？值不值这个价？**——需要林奇视角，看生活常识选股与 PEG 估值
3. **产业处在景气周期什么位置？**——需要郑希视角，看产业景气、ROE 拐点与地缘政治
4. **如何配置仓位？管理层可信吗？**——需要李进视角，看组合管理、治理与科研转化

本 Skill 通过四 Agent 并行研究，Team Lead 综合研判，产出完整、系统、可操作的 1~3 年投资研究报告。

**四位大师权威分工（对齐 `research/个人投资者1~3年中长期投资思想与理念 V2.0.md`）**：

| 大师 | 思维模式 | 在框架中的角色 |
|------|---------|---------------|
| 欧奈尔 | 工程师思维 · 信号与纪律 | **风控底线**：8% 止损、卖出触发、防止深度套牢 |
| 林奇 | 侦探思维 · 常识与求证 | **选股起点 + 估值定价**：生活常识选股、财务初筛、PEG 五档 |
| 郑希 | 物理学家思维 · 周期与第一性原理 | **赛道选择**：ROE 拐点、产业景气、渗透率、地缘政治 |
| 李进 | 系统工程师思维 · 均衡与渗透率 | **组合管理 + 治理**：底仓/机动仓、管理层与科研转化、治理一票否决 |

> "投资的第一条规则是不要亏损，第二条规则是记住第一条。" —— 欧奈尔（底线思维）
>
> "机会来自生活常识，而不仅仅是数据表格。" —— 林奇（常识验证）
>
> "ROE向上是科技股最可靠的'重力加速度'——只要这个趋势在，估值波动只是噪音。" —— 郑希（产业景气）
>
> "用渗透率定位阶段，用二阶导监测拐点，用纪律保护本金。" —— 李进（系统均衡）

## 核心能力圈声明

- **适用场景**：科技、医药、高端制造、景气周期成长股（渗透率 10%~30% 黄金区）
- **不适用场景**：纯周期股、困境反转股、金融股、被动指数投资

## 执行流程

### 第一步：展示团队框架

向用户展示以下团队结构，确认后启动：

| 角色 | 大师 | 职责 | 分析框架 |
|------|------|------|---------|
| **Team Lead**（你自己） | 四位大师综合 | 统筹协调、汇总研判、输出最终报告 | 欧奈尔-林奇-郑希-李进综合框架 |
| **Agent 1** | 欧奈尔 | 风控底线：止损位、卖出触发、趋势信号、底线纪律 | 工程师思维 · 信号与纪律 |
| **Agent 2** | 林奇 | 选股起点 + 估值定价：常识选股、财务初筛、PEG 五档、估值陷阱 | 侦探思维 · 常识与求证 |

### 第二步：信息丰富度评估（AI 研究偏见预警）

在创建团队前，先评估该公司的「AI 可研究性」，识别潜在数据偏见：

| 等级 | 特征 | AI 研究陷阱 | 应对策略 |
|------|------|-----------|----------|
| **A级（信息充裕）** | 上市多年、券商覆盖广、媒体报道密集 | 共识过强，AI 输出趋同于市场定价 | 团队重点放在**反面检验**与**非共识视角**，避免输出与市场一致的"正确的废话" |
| **B级（信息适中）** | 上市 1-3 年、覆盖有限、部分数据需推算 | AI 用「合理推测」填补空白，产生虚假确定性 | 每个 Agent 的推算数据标注置信度，区分「有据推算」与「凭空填充」 |
| **C级（信息稀缺）** | 冷门/新上市/新兴市场、几乎无覆盖 | AI 因资料不足过度保守，误判「看不清=不好」 | 团队转为「第一性原理模式」：不追求报告完整性，聚焦商业本质的几个核心问题 |

**C级公司的第一性原理研究法**（林奇式追问）：

1. 客户是谁？为什么付钱？有没有替代选择？（林奇的「生活常识」）
2. 复购靠什么驱动？是习惯、锁定、还是持续创造新价值？
3. 竞争对手拿 100 亿能复制这门生意吗？（郑希的「ROE 护城河」）
4. 管理层做过什么关键决策？这些决策反映什么判断力和价值观？（李进的「治理评估」）
5. 这个产业未来 1~3 年的核心驱动力是什么？（渗透率、技术迭代、政策支持）

**偏见自查清单**（研究全程保持警惕）：

- [ ] 我的「确定性」感受来自生意本质，还是来自资料数量？
- [ ] 如果把这家公司的资料量减少一半，我的结论会变吗？
- [ ] AI 输出的分析是否与市场共识高度雷同？如果是，我的信息优势在哪？
- [ ] 是否存在「公开资料很少但生意本质极好」的可能性被低估了？
- [ ] 我正在把「数据不足」等同于「风险过高」吗？（对 C 级公司尤其重要）

将评级结果告知每个 Agent，影响其研究方式；并在最终结论中注明「AI 分析置信度」与「投资确定性」的区别。

### 第三步：A股财报原文下载（优先执行，仅A股）

**重要流程**：对于 A 股公司，必须首先使用 `stock_equity.py` 工具下载原始财报 PDF，**下载完成后方可进行下一步的阅读分析工作**。

```bash
# 下载最新年报PDF
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type annual

# 下载最新半年报PDF（如需分析半年报）
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type semiannual

# 下载最新季报PDF（如需分析季报）
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type quarterly
```

下载的 PDF 文件保存在 `cninfo_reports/` 目录。可使用 `--report-dir` 参数指定其他保存目录。

**流程检查点**：确认 PDF 文件下载成功后，方可启动后续的 4 个研究 Agent。

**PDF 文档阅读工具**（首选 `pdf_extract.py`，支持自动乱码检测 + OCR 回退）：

```bash
# 分类检测 PDF 类型
python tools/common/pdf_extract.py detect cninfo_reports/{股票代码}_{年份}年报.pdf

# 提取含财务附表的 Markdown 并写盘
python tools/common/pdf_extract.py markdown cninfo_reports/{股票代码}_{年份}年报.pdf --save-md --out-dir reports/pdf

# 强制 OCR 提取（适用于扫描版或繁体中文 PDF）
python tools/common/pdf_extract.py text cninfo_reports/{股票代码}_{年份}年报.pdf --force-ocr --ocr-langs chi_tra+eng
```

**注意事项**：
- 首选 `pdf_extract.py` 提取文字与表格；返回失败（退出码非 0 / success=false / 扫描件）时才回退 Poppler 工具集（`pdftotext` / `pdfinfo` / `pdftoppm`）
- 繁体中文 PDF（如百济神州）需 `--force-ocr --ocr-langs chi_tra+eng`
- 全量 OCR 年报耗时较长，建议先 `detect` 确认页码，用 `--pages` 指定关键页提取
- 如果 PDF 无法提取信息，应在报告中标注「资料评级：B 级」，说明扫描版 PDF 限制

### 第四步：启动4个并行研究Agent

使用 Task 工具在**同一条消息**中启动 4 个后台 Agent。

---

#### Agent 1：风控底线分析（欧奈尔视角）

**核心问题：最坏情况会亏多少？什么时候必须无条件离场？**

> 欧奈尔："先想清楚亏多少，再想赚多少。8% 是普通投资者的生存红线——忘记成本，以信号为准。"

分析内容：

1. **硬止损位设定**（口径对齐 `exit-signal` P1）
   - 基于当前价格，8%~10% 止损设在什么位置？
   - 建仓初期（持仓 < 最终仓位 50%）下跌超 8%，无条件离场
   - 底仓已建立且逻辑已验证，可考虑在合理估值下限加仓（仅限杀估值而非杀逻辑）
2. **卖出触发条件逐级检查**（口径对齐 `exit-signal` P0~P5，本 Agent 负责 P1 硬止损专项）
   - P1 硬止损：单笔亏损 8%~10%，且无基本面反转信号 → 无条件止损
   - 明确区分「杀估值」（可持有）与「杀逻辑」（必须离场）
3. **趋势与技术信号**（欧奈尔核心）
   - 当前股价处于上升通道、盘整还是下跌通道？
   - 近 30 天是否有放量突破或放量下跌信号？
   - 机构持仓近几个季度变化趋势？
4. **底线纪律**
   - 禁止在「杀逻辑」时越跌越买
   - 禁止因沉没成本拒绝止损
   - 单只个股、单一行业的仓位上限必须硬性执行（见附录 C R-1~R-10）

**输出要求**：给出明确的硬止损位（具体价格）、趋势判断（上升/盘整/下跌）、卖出触发清单，欧奈尔式总结点评。

#### Agent 2：选股起点与估值定价（林奇视角）

**核心问题：这门生意我看得懂吗？现在这个价格值不值？**

> 林奇："机会来自生活常识，而不仅仅是数据表格。先搞清楚它是六类中的哪一类——不同类型的卖出逻辑完全不同。"

分析内容：

1. **生活常识选股**（林奇核心）
   - 用一句话定义这门生意的本质——「如果 10 分钟讲不清楚，业务太复杂」
   - 你或身边人在使用这家公司的产品吗？是否愿意向朋友推荐？
   - 竞争对手的产品体验如何？
2. **林奇六类股票分类**（必须明确归类）
   - 缓慢增长型 / 稳定增长型 / **快速增长型**（核心关注）/ 周期型 / 困境反转型 / 隐蔽资产型
   - 不同类型的卖出逻辑完全不同——明确这只股票的「类型标签」
3. **财务初筛**
   - 近 3-5 年营收、净利润、ROE、毛利率、经营利润率趋势
   - 利润质量：经营现金流 vs 净利润比率
   - 关键数据至少两个来源交叉验证
4. **PEG 五档估值评估**（引用 `valuation-thermometer`，不重复定义阈值）
   - PEG = 当前 PE(TTM) ÷ 未来 2 年预期利润复合增速（%），增长率取保守估计
   - 档位判定、边界约定（0.8/1.2/1.5/2.0 归属）、四工具交叉校验（PSG/PE 历史分位/implied-growth）与降级规则，一律以 `valuation-thermometer` 输出为准
   - 执行时先调用 `valuation-thermometer` 取得 PEG 档位，再给出建仓/持有建议
5. **常见估值陷阱排查**
   - **低 PE 陷阱**：周期顶点盈利虚高，需结合 ROE 趋势与二阶导验证
   - **高 PE 增速不可持续**：缺乏核心技术壁垒，增速面临断崖风险
   - **忽略股权稀释**：频繁定增或期权行权导致实际 EPS 增速远低于表观利润增速

**输出要求**：给出林奇六类归类、PEG 档位（引用 `valuation-thermometer`）、估值陷阱排查结论，林奇式总结点评。

#### Agent 3：赛道选择（郑希视角）

**核心问题：产业处在景气周期的什么位置？地缘政治会不会毁掉这个赛道？**

> 郑希："ROE 向上是科技股最可靠的'重力加速度'——只要这个趋势在，估值波动只是噪音。"

分析内容：

1. **产业景气判断**（口径对齐 `mid-industry-research`）
   - ROE 拐点：近 8 个季度 ROE 趋势是上行、筑顶还是下行？（连续 3 季同向才判拐点，单季波动判噪音）
   - 营收增速加速度：近 8 个季度营收增速是逐季加快、持平还是放缓？
   - 订单增速、产能利用率等领先指标方向
   - 公司在全球产业链中的位置，上下游景气是否共振
2. **渗透率分析**（口径对齐 `mid-industry-research`）
   - 当前渗透率在什么位置？（<5% 过早 / 5%~10% 萌芽 / **10%~30% 黄金区** / 30%~50% 成长期 / >50% 成熟期）
   - 距离 15% 加速临界点还有多远？距离 50% 减速区间还有多远？
   - 渗透率变化速度（一年能提升多少百分点）？
3. **地缘政治六维度评估**

   | 评估维度 | 核心问题 | 风险信号 |
   |---------|---------|---------|
   | 海外收入依赖度 | 海外收入占比？是否过度依赖单一市场？ | 海外收入占比 >50% 且依赖单一国家/地区 |
   | 供应链安全 | 关键零部件/原材料是否依赖特定国家或单一供应商？ | 核心芯片/材料/设备依赖单一海外供应商 |
   | 制裁与清单风险 | 是否已被或可能被列入实体清单、未经核实清单？ | 已在清单上或处于被关注名单 |
   | 本地化对冲能力 | 是否有海外建厂、本地化运营、多元供应链？ | 无海外产能布局，完全依赖出口 |
   | 政策与合规环境 | 目标市场的数据安全、ESG、外资准入、技术出口管制变化？ | 目标市场正在收紧外资或技术准入 |
   | 自主研发能力与抗压韧性 | 外部封锁下能否凭借自身研发体系实现技术自主与替代？ | 研发投入强度低、核心技术不自主、无备胎计划 |

4. **华为式抗封锁韧性评估**

   | 评估维度 | 核心指标 | 优秀标准 |
   |---------|---------|---------|
   | 研发投入强度 | 研发费用率 | 持续 >10%，逆周期不减 |
   | 核心技术自主可控 | 关键零部件/软件国产化率 | 掌握底层专利、源代码、工艺与关键设备 |
   | 备胎计划 | 替代供应商/技术路线 | 关键环节被断供时有自研替代方案 |
   | 极端情形生存能力 | 断供 6 个月下的现金流与订单交付能力 | 能依靠国内/替代市场维持现金流并继续投入研发 |

   > 抗封锁能力越强，地缘政治估值折价越低、持有容忍度越高（参考华为「打压之下逆势成长」样本）。

**输出要求**：给出产业景气位置判断（上行/筑顶/下行）、渗透率刻度、地缘政治风险信号清单、抗封锁能力评级，郑希式总结点评。

#### Agent 4：组合管理与治理（李进视角）

**核心问题：仓位怎么配？管理层可信吗？科研能力能转化为业绩吗？**

> 李进："用渗透率定位阶段，用二阶导监测拐点，用纪律保护本金。不要跟你的仓位谈恋爱。"

分析内容：

1. **组合配置**（李进核心）
   - 渗透率定位与仓位映射：

     | 渗透率阶段 | 策略类型 | 仓位上限 | 核心逻辑 |
     |-----------|---------|---------|---------|
     | < 10% | 左侧试探 | ≤ 5% | 赔率高但胜率未明，小仓位验证 |
     | 10% ~ 20% | 左侧布局 | ≤ 10% | 黄金区前半段，分批建仓 |
     | 20% ~ 30% | 右侧重仓 | ≤ 15% | 黄金区后半段，逻辑验证后加仓 |
     | > 30% | 右侧减仓 | ≤ 10% | 渗透率见顶，逐步兑现收益 |

   - **底仓（60%~80%）**：长持核心资产，仅在基本面恶化或估值严重透支时调整，不因短期 20% 以内波动卖出
   - **机动仓（20%~40%）**：波段操作，严格执行止盈止损，高估区间（PEG>1.5 或估值分位 >80%）减持、回落至合理区间回补
2. **管理层四维度评估（20 分制，口径对齐 V2.0 与 `mid-management-deep-dive`）**

   | 维度 | 分值 | 核心检查项 |
   |------|------|-----------|
   | 诚信品格 | 5分 | 历史承诺兑现率、关联交易公允性、监管记录 |
   | 股东态度 | 5分 | 分红/回购意愿、中小股东沟通机制、大股东质押率 |
   | 战略执行力 | 5分 | 战略规划与财报数据的匹配度、战略聚焦度 |
   | 稳定性激励 | 5分 | 核心团队锁定期、激励方案合理性、内部人交易 |

   > 任一维度低于 3 分或触发一票否决项，直接终止研究。管理层评级为 B/C 或管理层是核心逻辑时，调用 `/mid-management-deep-dive` 做纵深研究。
3. **科研转化评估（20 分制，高科技/医药必填）**

   | 维度 | 分值 | 核心指标 |
   |------|------|---------|
   | 研发质与量 | 8分 | 专利含金量、研发人员占比、研发强度（R&D/营收） |
   | 产出效率 | 8分 | 新产品收入占比、研发费用资本化率、技术产品化周期 |
   | 资本回报效率 | 4分 | 研发投入 ROIC、再投资回报率 |

4. **治理一票否决**（口径对齐 `exit-signal` P0）
   - 管理层失信、财务造假实锤、监管立案 → 立即清仓，不看估值趋势
5. **四大核心矛盾与化解方案**

   | 矛盾 | 对立双方 | 化解方案 |
   |------|---------|---------|
   | 买点哲学 | 左侧 vs 右侧 | 杀估值可逆向左侧布局；杀逻辑必须右侧止损。以「逻辑是否完整」为分水岭 |
   | 持有时间 | 长期持有 vs 季度检验 | 以景气周期长度为准，每季度用景气数据做「体检」 |
   | 止损 vs 越跌越买 | 欧奈尔 vs 林奇 | 基本面未变且估值合理可越跌越买；逻辑破坏或触发硬止损必须卖出 |
   | 分散 vs 集中 | 控回撤 vs 求收益 | 单一行业 ≤40%，单只个股初始 ≤10%，逻辑验证后 ≤15%，绝对上限 ≤20% |

6. **决策优先级速查**（引用 `exit-signal` P0~P5，不重复定义，完整逐级检查见 `exit-signal`）

   | 优先级 | 触发条件 | 决策 | 思想来源 |
   |--------|---------|------|---------|
   | **P0 治理一票否决** | 管理层失信、财务造假实锤、监管立案 | 立即清仓，不看估值趋势 | 李进（治理） |
   | **P1 硬止损** | 单笔亏损 8%~10%，且无基本面反转信号 | 无条件止损 | 欧奈尔 |
   | **P2 逻辑止损** | 连续 2 季业绩低于预期且产业景气未改善；或持有满 4 季度逻辑未兑现（时间止损） | 减仓或清仓 | 林奇 + 郑希 |
   | **P3 产业景气拐点** | 渗透率减速 / ROE 拐头向下 | 减机动仓 | 李进 + 郑希 |
   | **P4 估值透支** | PEG > 1.5（减机动仓）；PEG > 2（加速清机动仓） | 减 / 清机动仓 | 林奇 |
   | **P5 性价比替换** | 其他标的 PEG 显著更低且产业趋势更强 | 调仓（每季度最多 1 次） | 机会成本 |

7. **季度复盘检查清单（7 项必查）**

   | 序号 | 检查项 | 触发条件 |
   |------|--------|---------|
   | 1 | 渗透率是否仍处于 10%~30% 黄金区？ | >30% 逐步减仓 |
   | 2 | 管理层四维度评分是否有变化？ | 任一维度 <3 分重估 |
   | 3 | 地缘政治六维度是否有新增风险？ | 新制裁/关税重估敞口 |
   | 4 | PEG 是否触发高估/严重透支档位？ | PEG>1.5 减机动仓 |
   | 5 | 底仓/机动仓比例是否偏离目标？ | 偏离 >10% 再平衡 |
   | 6 | 是否有 P0~P5 优先级事件触发？ | 按 `exit-signal` 逐级检查 |
   | 7 | 科研转化 20 分制评分是否下滑？ | 连续 2 季下滑重估 |

**输出要求**：给出仓位配置建议（底仓/机动仓分层）、管理层 20 分制 + 科研转化 20 分制评分、治理一票否决触发标注（是/否）、决策优先级映射，李进式总结点评。

## 数据抽检（准出流程）

报告写入文件后，**必须**执行数据抽检，通过后方可发布。具体流程详见 **[报告审核与数据抽检](../tools-scripts/report-audit.md)**。

```bash
# Step 1 - 提取抽检清单（15%随机抽样）
python tools/common/report_audit.py extract \
  --report reports/{公司名}/{公司名}-mid-investment-team-{YYYYMMDD}.md --seed 42

# Step 2 - 对清单每项从可靠信源取数（按市场分别使用对应工具）
#   A股：tools/a_share/stock_financial.py（东方财富主） -> 巨潮资讯副 -> 年报PDF原始一手
#   港股：tools/hk_stock/stock_financial.py -> HKEX披露易
#   美股：tools/us_stock/stock_financial.py -> SEC EDGAR
#   计算验算：tools/common/financial_rigor.py（禁止 LLM 心算）

# Step 3 - 输出准出/打回判决
python tools/common/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report {公司名}-mid-investment-team-{YYYYMMDD}.md
```

- **【准出】** 所有抽检点偏差 ≤ 1% → 报告可发布
- **【打回】** 任意点偏差 > 1% → 修正后重新抽检

**Windows 兼容说明**：不使用 `/tmp/` 路径与 `2>/dev/null`，临时文件用 `%TEMP%`，stderr 重定向用 `2>$null`，JSON 提取直接用 `--output-json` 或 `--dry-run`。

## 注意事项

1. **4个Agent必须并行启动**——在同一条消息中调用 4 次 Task 工具
2. **数据准确性**——关键数据至少来自两个独立来源，使用 financial_rigor.py 工具验算
3. **结论要明确**——不回避给出买入/观望/回避建议和具体价格区间、硬止损位
4. **所有分析必须有数据支撑**——附数据来源
5. **呈现正反两面**——每个核心判断都必须附带反面论据
6. **不预设立场**——不预设看多或看空，先摆数据、再推逻辑、最后得结论
7. **信息稀缺时的诚实原则**——宁可在报告中留白标注「数据不足」，也不要用推测填满框架伪装确定性
8. **反偏见意识**——Team Lead 在汇总时必须评估：各 Agent 的分析是否受限于资料充裕度？是否与市场共识过度趋同？
9. **引用不重复定义**——估值档位引用 `valuation-thermometer`，卖出纪律引用 `exit-signal`（P0~P5），产业景气/渗透率引用 `mid-industry-research`，管理层/科研转化 20 分制引用 V2.0 与 `mid-management-deep-dive`
10. **中期口径红线**——禁止使用「护城河永续」「终局思维」「持有10年」等长期框架术语，持有周期以「景气周期长度」为准

---

## 局限性

1. **信息可得性**：港股小票、新上市公司可能无法获取完整信息
2. **扫描版PDF限制**：A 股年报常为扫描版 PDF，可能无法提取文本内容，影响附注分析
3. **语言限制**：非中英文财报可能无法准确解读
4. **非实时数据**：工具获取的数据可能有延迟，不是实时数据
5. **渗透率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算，按 A/B/C 三级置信度标注
6. **地缘政治数据更新频率**：制裁清单、关税政策等变化较快，需定期更新
7. **并行执行复杂度**：4 个 Agent 并行执行可能需要较长时间
8. **不构成投资建议**：本技能仅用于学习与研究，不构成任何投资建议
