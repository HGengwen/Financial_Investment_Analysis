# 季度加速度：1-3年中期「增速的加速度」趋势判定

用连续 3 个季度财务数据判断「增速的加速度」（二阶导），区分短期波动与趋势拐点。输出「景气向上 🟢 / 拐点预警 🔴 / 噪音不判 🟡」三态结论，并映射到 `exit-signal`（P2/P3）与 `valuation-thermometer`（估值修正）。属于中期链（1-3 年）功能技能，与长期链估值口径物理隔离。

## 设计原则

1. **连续 3 季不靠单季**：只有连续 3 季同向才判趋势，单季或连续 2 季异动一律不判拐点（防噪音）。
2. **YoY 主口径、QoQ 辅口径**：同比用累计值直接对比；环比必须先累计转单季，且方向矛盾时以 YoY 为准。
3. **禁止 LLM 心算**：增速、环比、加速度、匹配度差值一律经 `financial_rigor.py calc` 或数据工具输出，报告不得出现手算数值。
4. **累计转单季口径写死**：`stock_financial_abstract` 返回的是报告期**累计值**，QoQ 环比必须先「本期累计 − 上期累计」转单季。
5. **只出趋势，不给价位**：本技能只输出加速/减速/拐点判定，不判断估值与买卖价位。

## 核心判定规则（硬编码）

### 规则 A：加速度定义与连续 3 季趋势判定（主规则）

**加速度（二阶导）定义**：

```
加速度 = 本季度增速 − 上季度增速
主口径加速度：YoY 营收增速的一阶差分（相邻两季 YoY 增速之差）
辅口径加速度：QoQ 营收增速的一阶差分（需先累计转单季）
```

**连续 3 季趋势判定**（以最近 3 个加速度值 a₁=最早、a₂=中间、a₃=最新）：

```text
IF a₁ > 0 AND a₂ > 0 AND a₃ > 0:
    → 景气向上 🟢
ELIF a₁ < 0 AND a₂ < 0 AND a₃ < 0:
    → 拐点预警 🔴
ELSE:
    → 噪音/波动，不判拐点 🟡
```

等价表述（以 YoY 增速序列本身单调性判定）：

| 序列形态（最近 3 季 YoY 营收增速） | 判定 | 动作建议 |
| --- | --- | --- |
| 连续加速（Q(-3) < Q(-2) < Q(-1)） | **景气向上 🟢** | 维持/可加底仓（结合估值） |
| 连续减速（Q(-3) > Q(-2) > Q(-1)） | **拐点预警 🔴** | 触发 P2/P3 复核（交 `exit-signal`） |
| 单季异动（不单调，如 Q(-3)<Q(-2)>Q(-1)） | **噪音，不判拐点 🟡** | 标记噪音，底仓不动 |

> **硬编码边界**：
> - 相邻两季增速差 < 1 个百分点视为「持平」，不构成加速/减速（避免浮点误差误判）；
> - **仅当连续 3 季同向**才判「景气向上/拐点预警」；单季或连续 2 季异动**不得**判拐点，仅标注「需关注下季确认」；
> - 连续 3 季数据不足时标注「数据不足，趋势判定置信度降低」。

### 规则 B：QoQ / YoY 双口径与一致性

| 口径 | 定义 | 用途 |
| --- | --- | --- |
| YoY（同比） | 本期累计值 ÷ 去年同期累计值 − 1 | **主口径**（累计值同比口径一致，无需换算） |
| QoQ（环比） | 本期单季值 ÷ 上期单季值 − 1 | 辅口径（**必须累计转单季**：单季值 = 本期累计 − 上期累计） |

**双口径一致性判定**（QoQ 受季节性影响时以 YoY 为准）：

| QoQ 方向 | YoY 方向 | 判定 |
| --- | --- | --- |
| 加速 | 加速 | 高置信度加速 |
| 减速 | 减速 | 高置信度减速 |
| 不一致 | — | **季节性干扰，以 YoY 为主**，须在报告标注「季节性干扰」 |

### 规则 C：利润增速 vs 营收增速匹配度

| 形态 | 判定 | 含义 |
| --- | --- | --- |
| 利润增速 − 营收增速 > +5pct | ✅ 匹配（利润跑赢） | 费用可控，规模效应 |
| −5pct ≤ 差值 ≤ +5pct | ⚠️ 基本匹配 | 正常，观察费用结构 |
| 差值 < −5pct（利润增速 < 营收增速） | 🔴 不匹配 | 警惕费用失控/增收不增利 |
| 营收增速 > 0 但利润增速 < 0 | 🔴 背离 | 强拐点预警信号 |

毛利率趋势辅助：毛利率稳定/提升→弱匹配可容忍；毛利率连续下降→不匹配为结构性（护城河侵蚀）。

### 规则 D：先行指标佐证（`--advanced`）

| 先行指标 | 加速信号 | 减速信号 |
| --- | --- | --- |
| 合同负债 | 环比增长 > 营收增速（订单领先） | 环比下降 |
| 存货 | 存货增速 < 营收增速（周转改善） | 存货增速 > 营收增速（积压风险） |
| 研发费用 | 研发费用率提升（未来储备） | 研发费用率下降（短期化倾向） |

**综合判断**：先行指标与加速度方向一致→结论置信度高 ✅；部分一致→谨慎 ⚠️；相反→加速度方向可能被证伪 🔴。

### 规则 E：季节性调整（辅口径专用）

强季节性行业（零售/旅游/农业/消费电子）Q1 环比 Q4 常系统性下滑，产生「假减速」。处理：

| 方法 | 规则 |
| --- | --- |
| YoY 辅助验证 | QoQ 连续为负但 YoY 加速/稳定 → 季节性干扰，维持「平稳 🟡」 |
| 同季 QoQ 基准比较 | 调整后 QoQ = 本季 QoQ − 去年同季 QoQ；>0 为真实改善 |

> 季节性调整是辅助手段，**不替代连续 3 季主判定**；报告同时展示「调整前/调整后」结论。

### 数据质量与降级处理

| 场景 | 处理 |
| --- | --- |
| 上市不足 8 季 | 用全部可用数据，标注「数据不足 8 季，趋势判定置信度降低」 |
| 仅 4 季 | 可算加速度，但**不执行连续 3 季趋势判定**（样本不足），仅展示数据 |
| 仅 3 季 | 仅展示 QoQ 增速，不计算加速度 |
| 单季数据缺失 | 用相邻季度均值估算，标注「估算值」 |
| 利润为负 | 改用 YoY 替代 QoQ，标注「因利润为负改用同比」 |

## 执行流程

### 第一步：解析输入与调用参数，确定标的与市场

- 输入形态：单个公司名（如「新易盛」）、「公司名 + 代码」、或逗号分隔的批量公司列表。
- 解析 `--quarters` / `--seasonal-adjust` / `--horizon` / `--export` / `--export-path` / `--json`（见「调用参数」节）；`--horizon` 非 `mid` 时报错终止。
- 识别市场（A 股 / 港股 / 美股），决定后续数据工具。
- 运行 `date` 确认当天日期，作为报告「数据截止日期」基准。

### 第二步：收集数据

按市场选择财务工具，提取最近 8 季（不足取全部）财务数据：

| 市场 | 财务工具 |
| --- | --- |
| A 股 | `python tools/a_share/stock_financial.py --code {代码} --indicator ...`、`--advanced ...` |
| 港股 | `python tools/hk_stock/stock_financial.py --financial {代码}` |
| 美股 | `python tools/us_stock/stock_financial.py --code {代码}` |

需收集：

- 营收与归母净利润（最近 8 季报告期 + 累计值）；
- 毛利率、ROE（辅助匹配度与景气判断）；
- 先行指标：合同负债、存货、研发费用（`--advanced`）。

### 第三步：累计转单季

对 A 股 `--indicator` 返回的累计值做 QoQ 单季换算：单季值 = 本期累计 − 上期累计。YoY 直接用累计值同比。

### 第四步：计算增速与加速度（禁 LLM 心算）

- YoY 增速、QoQ 增速、加速度（一阶差分）、匹配度差值均经 `financial_rigor.py calc` 执行；
- 增速序列用 `financial_rigor.py calc` 生成/验证，禁止 LLM 心算。

### 第五步：连续 3 季趋势判定

按规则 A 判定三态结论，并叠加规则 B（双口径）、C（匹配度）、D（先行指标）、E（季节性）校验。

### 第六步：联动映射

按「联动映射」节将结论映射到 `exit-signal`（P2/P3）与 `valuation-thermometer`（估值修正）。

### 第七步：输出报告

按「输出结果」节固定模板写入 `reports/{公司名}/`，并在报告头部注明数据截止日期。

## 与 exit-signal / valuation-thermometer / mid-thesis-drift 联动映射（硬编码）

| 本技能输出 | 目标技能 | 映射 |
| --- | --- | --- |
| 🔴 连续 3 季负加速（营收+利润） | `exit-signal` P3 | 产业景气拐点核心触发之一 |
| 🔴 连续 4 季负加速 + 业绩低于预期 | `exit-signal` P2 | 逻辑止损辅助触发 |
| 🔴 连续负加速 | `valuation-thermometer` | 估值修正 **−0.5 档** |
| 🟢 连续 2 季以上正加速 | `valuation-thermometer` | 估值修正 **+0.3 档** |
| 🟡 平稳/波动 | `valuation-thermometer` | 无修正 |
| 连续 3 季负加速 | `mid-thesis-drift` | 作为漂移检测的核心证据（Sprint 3 消费） |

> 修正幅度上限 **±1 档**，防止过度修正。

**P3 完整触发条件（跨技能依赖，非本技能单点判定）**：加速度连续 3 季为负是 P3 的**核心输入之一**，但 P3 完整触发还需结合：

- 渗透率位置（>50% 且增速放缓）→ 由 `mid-industry-research` 提供（Sprint 3）；
- ROE 趋势（拐头向下）→ 由 `stock_financial.py --indicator ROE` 提供；
- 技术面辅助（MA200 下方 + 放量破位）→ 由 `trend-momentum-scan` 提供。

> 硬编码：加速度连续 3 季为负 → 报告中必须标注「P3 产业景气拐点预警」，不可因「产业前景长期向好」而弱化该预警。

### 加速度-估值二维矩阵（与 valuation-thermometer 联合决策）

| 加速度 \ 估值 | 显著低估（PEG<0.8） | 合理（0.8~1.2） | 偏贵（1.2~1.5） | 高估（>1.5） | 严重透支（>2.0） |
| --- | --- | --- | --- | --- | --- |
| 🟢 加速向好 | 积极加仓 | 建仓/加仓 | 机动仓观望 | 机动仓不加仓 | 不加仓，等估值回落 |
| 🟡 平稳 | 分批建仓 | 持有/小仓位建 | 持有观望 | 机动仓减持 | 减机动仓 |
| 🔴 减速/拐点 | 轻仓试探 | 持有不动 | **机动仓减持** | **减机动仓** | **加速清机动仓** |

**核心逻辑**：加速度为正且估值合理 → 最佳买点（戴维斯双击条件）；加速度为负且估值偏高 → 双重风险，必须减仓；加速度为负但估值极低 → 可能是短期波动，轻仓试探。当 🔴 减速 且 高估/严重透支 时，同时触发 P3（景气拐点）与 P4（估值透支），以 P3 优先。

| 硬性规则 | 不可做的事 |
| --- | --- |
| 加速度连续 3 季为负 → 必须判「拐点预警 🔴」 | 不可输出「虽连续减速但产业前景向好」等弱化表述 |
| 单季负加速 ≠ 拐点 | 不可因单季波动触发拐点预警 |
| 利润连续 2 季为负且营收为正 → 必须判「不匹配 🔴」 | 不可输出「阶段性费用投入」等美化表述 |
| QoQ 与 YoY 方向不一致 → 必须标注「季节性干扰」 | 不可忽略方向矛盾直接取 QoQ 结论 |
| 加速度与先行指标相反 → 必须标注「方向可能被证伪」 | 不可忽略反向先行信号 |
| 修正因子幅度 ≤ ±1 档 | 不可叠加多个正向因子上调超 1 档 |
| 数据不足 4 季 → 必须标注置信度降低 | 不可在数据不足时仍给明确拐点判定 |
| 禁止 LLM 心算 | 所有增速/加速度/匹配度须经工具链 |

## 注意事项

1. 开始前运行 `date` 确认当天日期，报告头部注明数据截止日期。
2. 关键财务数据须至少来自两个独立来源，误差 >1% 须标记。
3. 禁止 LLM 心算，所有数值来自 `financial_rigor.py calc` 或数据工具输出。
4. A 股累计转单季口径写死：QoQ 环比必须先「本期累计 − 上期累计」转单季。
5. 连续 3 季判定是主规则，季节性调整只是辅助，不替代主判定。

## 局限性

1. 本技能只输出增速趋势判定，不判断估值高低（归 `valuation-thermometer`）与业务质量（归 `quality-screen`）。
2. 数据不足 8 季时趋势判定置信度降低，须显式标注。
3. 先行指标（合同负债/存货/研发费用）的解读为经验规则，非精确模型。
4. 强季节性行业的 QoQ 失真，本技能仅做 YoY 辅助验证，不建立精细的季节性因子模型。
5. 本技能不承担上游景气/渗透率判断，渗透率数据归 `mid-industry-research`（Sprint 3）。

## 与其他Skill的关系

- **前置**：`valuation-thermometer`（估值温度，供二维矩阵联合决策）、`mid-trend-tech-screen`（正向排序）。
- **后置**：`exit-signal`（本技能「拐点预警 🔴」→ P2/P3 输入）、`mid-thesis-drift`（连续 3 季负加速作为漂移检测证据）。
- **同级**：`trend-momentum-scan`（技术面体检，与本技能做量价交叉验证）。
- **边界**：只出增速趋势，不出买卖价位；估值归 `valuation-thermometer`，卖出归 `exit-signal`。
