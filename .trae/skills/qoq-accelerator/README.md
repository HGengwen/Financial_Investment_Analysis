# 季度加速度 (QoQ Accelerator)

用连续 3 个季度财务数据判断「增速的加速度」（二阶导），区分短期波动与趋势拐点，输出「景气向上 🟢 / 拐点预警 🔴 / 噪音不判 🟡」三态结论，并映射到 `exit-signal`（P2/P3）与 `valuation-thermometer`（估值修正）。属于 1-3 年中期链功能技能。

---

## 快速开始

### 基本调用方式

```
/qoq-accelerator {公司名}
```

支持三种输入形态：

| 输入方式 | 示例 | 说明 |
|---------|------|------|
| 单个公司名 | `/qoq-accelerator 新易盛` | 单标的加速度分析 |
| 公司名+代码 | `/qoq-accelerator 新易盛 300502` | 显式指定代码，跨市场明确 |
| 批量（逗号分隔） | `/qoq-accelerator 新易盛,中际旭创` | 多标的批量分析 |

例如：
- `/qoq-accelerator 新易盛`
- `/qoq-accelerator 腾讯 00700`

---

## 核心功能

对指定公司执行「连续 3 季加速度趋势判定 + 匹配度/先行指标/季节性校验」，输出三态结论与卖出/估值联动建议。

### 三态趋势判定（唯一权威口径）

```text
IF 加速度连续 3 季为正 → 景气向上 🟢
ELIF 加速度连续 3 季为负 → 拐点预警 🔴
ELSE → 噪音/波动，不判拐点 🟡
```

| 序列形态（最近 3 季 YoY 营收增速） | 判定 | 动作建议 |
| --- | --- | --- |
| 连续加速（Q(-3) < Q(-2) < Q(-1)） | 景气向上 🟢 | 维持/可加底仓（结合估值） |
| 连续减速（Q(-3) > Q(-2) > Q(-1)） | 拐点预警 🔴 | 触发 P2/P3 复核（交 `exit-signal`） |
| 单季异动（不单调） | 噪音，不判拐点 🟡 | 标记噪音，底仓不动 |

> 硬编码边界：相邻两季增速差 <1pct 视为持平；仅连续 3 季同向才判趋势；数据不足标注置信度降低。

### 双口径一致性

| 口径 | 定义 | 用途 |
| --- | --- | --- |
| YoY（同比） | 本期累计值 ÷ 去年同期累计值 − 1 | **主口径** |
| QoQ（环比） | 单季值 = 本期累计 − 上期累计，再环比 | 辅口径（必须累计转单季） |

QoQ 与 YoY 方向不一致时，以 YoY 为主，并在报告标注「季节性干扰」。

## 使用示例

### 示例1：连续加速（景气向上）

```
/qoq-accelerator {某高增长标的}
```

最近 3 季 YoY 营收增速 15%→20%→26%，连续加速，输出「景气向上 🟢」。

### 示例2：连续减速（拐点预警）

```
/qoq-accelerator {某减速标的}
```

最近 3 季 YoY 营收增速 26%→20%→15%，连续减速，输出「拐点预警 🔴」，联动 `exit-signal` P3 复核。

## 工具依赖

| 用途 | 工具 | 关键参数 |
|------|------|---------|
| 财务指标（营收/利润/ROE/毛利率） | `a_share/stock_financial.py` | `--code --indicator` |
| 先行指标（合同负债/存货/研发费用） | `a_share/stock_financial.py` | `--code --advanced` |
| 港股财务 | `hk_stock/stock_financial.py` | `--financial` |
| 美股财务 | `us_stock/stock_financial.py` | `--code` |
| 增速/加速度/匹配度计算 | `financial_rigor.py calc` | `--expr` |
| 估值交叉验证（可选） | `financial_rigor.py implied-growth` | `--market-cap --target-pe --net-margin --ttm-revenue --guidance-growth` |

### 关键约束

- **禁止 LLM 心算**：增速、环比、加速度、匹配度差值一律走 `financial_rigor.py calc`。
- **累计转单季**：A 股 `--indicator` 返回累计值，QoQ 环比必须先「本期累计 − 上期累计」转单季。
- **连续 3 季判定**：单季或连续 2 季异动不判拐点，仅标注「需关注下季确认」。

## 与 `exit-signal` / `valuation-thermometer` 的衔接

| 本技能输出 | 目标技能 | 映射 |
|-----------|---------|------|
| 🔴 连续 3 季负加速 | `exit-signal` P3 | 产业景气拐点核心触发之一 |
| 🔴 连续 4 季负加速 + 业绩低于预期 | `exit-signal` P2 | 逻辑止损辅助触发 |
| 🔴 连续负加速 | `valuation-thermometer` | 估值修正 −0.5 档 |
| 🟢 连续 2 季以上正加速 | `valuation-thermometer` | 估值修正 +0.3 档 |
| 连续 3 季负加速 | `mid-thesis-drift` | 漂移检测核心证据 |

> 修正幅度上限 ±1 档。P3 完整触发还需渗透率（`mid-industry-research`）+ ROE 拐头（`--indicator ROE`）+ 技术面破位（`trend-momentum-scan`）联合判定。

---

## 核心原则

1. **连续 3 季不靠单季** — 防噪音，单季/连续 2 季异动不判拐点。
2. **YoY 主口径、QoQ 辅口径** — 累计值同比为主，累计转单季环比为辅。
3. **禁止心算** — 所有数值来自 `financial_rigor.py calc` 或数据工具输出。
4. **只出趋势，不给价位** — 估值归 `valuation-thermometer`，卖出归 `exit-signal`。

---

## 注意事项

- 开始前运行 `date` 确认当天日期，报告头部注明数据截止日期。
- 关键财务数据须至少两个来源交叉验证，误差 >1% 须标记。
- A 股累计转单季口径写死，不可直接用累计值环比。
- 禁止使用 WebSearch / WebFetch 工具（中国大陆不可用），统一用本地搜索工具。

---

## 局限性说明

- 只输出增速趋势判定，不判断估值高低与业务质量。
- 数据不足 8 季时趋势判定置信度降低，须显式标注。
- 先行指标解读为经验规则，非精确模型。
- 强季节性行业 QoQ 失真，仅做 YoY 辅助验证。
- 不构成投资建议，仅供学习研究参考。
