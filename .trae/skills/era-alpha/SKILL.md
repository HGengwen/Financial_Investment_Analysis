# 时代α捕手：高增长核心资产的识别-验证-持有框架

对 $ARGUMENTS 行业/方向执行"时代α五步法"：建立行业认知地图 → 自问核心问题 → 全方位验证 → 估值锚点与介入 → 持有到拐点。

**目标**：找出当下最核心高增长行业中真正有定价权、有壁垒、能持续跑赢同行的 α 企业，并给出介入与退出纪律。这是一条**长期（10 年）价值投资**路径，与 1-3 年中期景气链（`mid-*` 系列）物理隔离。

## 方法论来源与本质

源自一套职业投资人的操作手册，本质一句话：**把财富建立在认知之上，而不是运气或情绪之上**。原版四步（读一年财报建地图 → 自问核心高增长行业与核心α → 财报+调研+行业+宏观全验证后介入 → 基本面拐点前死拿）是职业选手的修炼路径，本技能内置三项修正，使其成为可执行路径：

1. **修正一（精简范围）**：不覆盖所有行业，聚焦指定赛道的 2-3 个核心环节做深做透。三五家真正看透，胜过认识一千家。
2. **修正二（高频数据交叉验证）**：财报是三个月前的体检报告，必须用行业高频数据（周度/月度出货量、价格、订单、装机、渗透率）做实时体温计校正。
3. **修正三（估值锚点）**：长期看"高了还能更高"，但市盈率超历史均值 3 个标准差时介入可能长期输时间。合理或低估时重仓、明显泡沫时减仓、拐点确认时清仓，不闭眼买。

**四大师验证透镜**：在第三步"全方位验证"中，用 段永平（生意本质）/ 巴菲特（护城河）/ 芒格（风险逆向）/ 李录（文明趋势）四位大师的追问作为验证透镜，确保 α 的判断既聚焦高增长，又不失长期价值投资的安全边际。

## 第一步：行业认知地图（原版"读365份财报"的聚焦版）

对目标赛道建立产业链认知地图，每个环节回答：

1. 这个环节处于什么阶段？（导入期/成长期/成熟期/衰退期，用渗透率和增速定位）
2. 商业模式与赚钱方式？（毛利率、费用率、现金流与利润的匹配度）
3. 竞争格局？（CR3、定价权在谁手里、壁垒是技术/规模/生态/牌照）
4. 每个环节的 α 候选是谁？（营收增速、ROE 趋势、市占率变化三个维度筛）

**信息源要求**：以招股说明书、年报/季报、业绩说明会纪要等一手资料为主，券商观点只做线索不做结论。A股/港股/美股/未上市候选都要覆盖，不因资料难找而漏掉。

**产出**：产业链环节表（环节 | 阶段 | 格局 | α候选 | 一句话理由），并从中选出 2-3 个最值得做深的核心环节（修正一）。

## 第二步：自问核心问题（不听别人的）

用第一步的数据回答，禁止引用"市场共识""机构观点"作为论据：

1. **当下这条赛道最核心、增长最快的环节是什么？** 用数据说话：增速、渗透率、订单能见度。
2. **该环节的核心 α 是谁？** 标准：定价权（毛利率高于同行且稳定或提升）、壁垒（对手三年内追不上的东西是什么）、增长质量（收入增长伴随现金流增长，不是赊出来的）。
3. **为什么是它而不是老二？** 必须能一句话说清 α 与 β 的差别，说不清就是没看懂。

**产出**：1-3 家核心 α + 明确的"为什么是它"论证。

## 第三步：全方位验证（五维交叉 + 四大师透镜）

对每家核心 α 做增长可持续性验证，所有维度必须一致指向"高增长可持续"才算看懂。

### 3.1 五维验证（财报 + 高频数据交叉）

| 维度 | 验证内容 |
|------|---------|
| 财报 | 最近 4-8 个季度营收/利润增速趋势、毛利率方向、合同负债/存货/在建工程等前瞻科目 |
| 高频数据（修正二） | 该环节的周度/月度实时指标（出货量、价格、招标、流量、token 调用量等），是否与财报趋势一致 |
| 行业跟踪 | 政策方向、技术路线有无被颠覆风险、供给端扩产节奏（供过于求是成长股最大杀手） |
| 竞争格局 | 市占率变化方向、新进入者威胁、客户集中度与议价权 |
| 宏观 | 利率环境、资本开支周期位置、地缘/监管变量 |

**任何一个维度出现矛盾信号，必须明确写出，不许含糊带过。**

### 3.2 四大师验证透镜

在五维验证之上，用四位投资大师的追问对 α 做长期价值投资视角的二次验证：

| 大师 | 验证透镜 | 核心追问 |
|------|---------|---------|
| 段永平 | 生意本质 | 这是一门好生意吗？赚钱方式是否简单、可理解、可持续？ |
| 巴菲特 | 护城河 | 10 年后护城河还在吗？定价权是否可持续、是否会被颠覆？ |
| 芒格 | 风险逆向 | 这家公司最可能怎么失败？聪明人为什么不买？ |
| 李录 | 文明趋势定位 | 这是"文明级范式转移"还是"阶段性热潮"？（判断 α 是否具备 10 年维度） |

四大师透镜若与五维验证结论冲突，**优先采信冲突信号**，在报告中明确写出，不得按需取舍。

## 第四步：估值锚点与介入（修正三，替代"不看股价"）

1. 当前 PE/PS 处于自身历史分位数的什么位置？是否超过历史均值 +3 个标准差？
2. 估值与增速匹配吗？（高增速可以消化高估值，但要算清楚需要几年）
3. 结论三选一：**低估/合理可重仓介入**、**偏贵但增长可消化可持有或分批**、**明显泡沫只看不买**。
4. 给出介入方式建议：一次性/分批/等回调到什么水位。

**估值计算必须使用精确工具**，禁止 LLM 心算：

- 精确金融计算与三情景估值：`python tools/common/financial_rigor.py verify-valuation ...`
- 长期折现与安全边际（十年尺度终值、ROIC/g 硬约束）：`python tools/common/terminal_value.py audit --currency CNY --r 0.08 --roic 0.20 --g ...`

## 第五步：持有纪律与拐点清单

**持有纪律**：只要基本面一切正常（增速未放缓、格局未恶化、渗透率仍在提升、宏观未逆转），股价波动是噪音，说什么都不能随便离场。

**拐点清单**（每家 α 必须列出，逐条可观察、可证伪）：

| 层级 | 拐点信号示例 | 观察什么数据 | 多久看一次 |
|------|------------|------------|-----------|
| 宏观拐点 | 货币政策转向、资本开支周期见顶信号 | 利率、PMI、资本开支指引 | 月度/季度 |
| 行业拐点 | 供给过剩价格崩盘、技术路线被颠覆、渗透率见顶、政策逆转 | 价格、出货量、渗透率、政策文件 | 周度/月度 |
| 公司拐点 | 核心管理层离职、毛利率连续两季下滑、市占率被侵蚀、合同负债转负增长 | 高管变动公告、季报毛利率、份额数据、合同负债 | 季度 |

每条信号写明**观察哪个数据、多久看一次**，让"拐点"从感觉变成清单。

**拐点触发后的行动链路**（与持仓管理类技能联动）：

- 命中公司/行业拐点 → 转 `/exit-signal {标的}` 做 P0~P5 六级硬编码卖出纪律检查
- 怀疑核心假设漂移 → 转 `/thesis-drift {标的}` 对比新旧证据
- 建仓后例行跟踪 → 转 `/thesis-tracker {标的}` 建立投资论文 + 季度健康度检查

## 执行方式

1. **并发硬约束（必须先读，防止触发服务端 request burst 保护）**：
   - 同时运行的子代理**最多 2 个**，严禁「按产业链环节一次性并行铺开所有 Agent」。
   - 产业链环节按优先级排序后**分批串行**处理：每批最多 2 个环节，一批全部返回后再启动下一批。
   - 单个子代理内的搜索请求须**串行逐条执行**，两次请求间隔 ≥ 2 秒；单个环节搜索请求上限 8 次。
   - 遇到 `request burst` / `rate limit` / `System protection` 报错时，立即停止新增请求，按指数退避（30s → 60s → 120s）重试，最多 3 次；仍失败则降级为只用已获取数据，标注「信息不足」，不做无谓追问。
2. 每个环节派出的研究 Agent，要求联网获取最新财报与高频数据，返回结构化事实（数据+出处），不返回观点。
3. 主线程按第一到第五步综合成报告；单个环节子代理超时（> 15 分钟无返回）即放弃该环节，用已有数据标注「信息不足」继续推进，不阻塞整体。
4. 遵循 `financial-data` 技能的交叉验证规范；关键数字（增速、毛利率、估值分位）必须标注数据截至日期。

## 报告结构

```
一、行业认知地图（环节表 + 核心环节选择理由）
二、核心问题的回答（最核心高增长环节 + 核心α + 为什么是它）
三、增长可持续性验证（五维逐项 + 四大师透镜 + 矛盾信号明示）
四、估值锚点与介入建议
五、持有纪律与拐点清单（可观察、可证伪，链接 exit-signal/thesis-tracker）
六、本报告可能错在哪（至少 3 条自我证伪）
```

风格要求：数据密度优先，保留全部硬数据，砍掉脚手架语言；纯中文表达；不挂任何投资人名字，用分析维度命名章节。

## 数据抽检（准出流程）

报告写入后必须执行数据抽检，通过方可发布。流程详见 [报告审核与数据抽检](../tools-scripts/report-audit.md)。

```bash
# Step 1 - 提取抽检清单（15%随机抽样）
python tools/common/report_audit.py extract \
  --report reports/{方向}-era-alpha-{YYYYMMDD}.md

# Step 2 - 对清单每项从可靠信源取数（按市场选用对应工具）
#   关键计算用 financial_rigor.py 验算，估值分位/标准差用精确工具

# Step 3 - 输出准出/打回判决
python tools/common/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report reports/{方向}-era-alpha-{YYYYMMDD}.md
```

**【准出】** 全部通过 → 报告可发布；**【打回】** 有不通过 → 修正后重审。

**Windows 兼容说明**：本工作流在 Windows 环境下运行时注意：

- 不使用 `/tmp/` 路径保存临时文件（Windows 无此目录），改用 `%TEMP%` 或当前工作目录
- 不使用 `2>/dev/null` 重定向 stderr，改用 `2>$null`（PowerShell）
- 不使用 `tr -d '\r'` 等 Unix 命令，直接在 Python 中处理换行符
- 提取 JSON 输出直接用 `--output-json`/`--dry-run` 参数，不经 PowerShell 管道

## 注意事项

1. **所有分析必须有数据支撑**：附数据来源，不主观臆断
2. **关键数据至少两个独立来源交叉验证**，误差 >1% 须标记
3. **证伪优先**：每个核心判断附反面论据，正面证据再充分也不掩盖矛盾信号
4. **结论明确**：给出具体 α、介入条件、拐点清单，不两面讨好
5. **不预设立场**：先摆数据 → 推逻辑 → 出结论
6. **诚实面对信息缺口**：宁可标注"数据不足/信息充分度 B 级"，不用推测填充

## 局限性

1. **资料可得性**：新兴行业资料少，分析深度受限
2. **未上市公司信息**：估值和财务信息可能不够准确
3. **高频数据可得性**：部分环节缺乏周度/月度公开高频数据，交叉验证可能降级为季度数据
4. **非实时数据**：工具获取的数据可能有延迟，不是实时数据
5. **AI 筛选偏见**：可能存在成熟行业偏好、龙头偏好、英文偏好，需自觉检查
6. **护城河/文明趋势判断主观性**：依赖定性判断，可能因分析师而异
7. **估值分位历史长度限制**：次新行业/公司历史分位可能参考价值有限
8. **不构成投资建议**：本技能仅用于学习与研究
