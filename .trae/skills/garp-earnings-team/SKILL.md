# 财报精读团队：五大师并行解读 + 公众号发布（GARP 独立档 1~5 年）

对 $ARGUMENTS 进行团队化 GARP 价值成长视角的财报精读分析。五位大师并行解读财报，Team Lead 综合合成，编辑润色成文，读者评审把关质量，最终产出可直接发布的公众号文章。

**支持输入格式**：`公司名 期间`，例如：`腾讯 2025Q4`、`PDD 2025年报`、`美团 最新`

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

## 能力圈声明

本技能文件适用于 **GARP 价值成长框架（1~5 年持有周期）下的财报精读与景气验证**，非短期交易工具，非长期链式的「永久不卖」超长期持有，也非日内/周级别波段交易。

**适用场景**：
- 科技 / 医药 / 高端制造 / 景气周期成长股等具备可持续成长性的公司财报精读
- 季度财报发布后的景气逻辑验证与**五级卖出纪律**更新
- 公众号 / 投研报告的深度财报分析文章产出
- 需要「五大师交叉验证 + 团队化收口」的关键财报

**不适用场景**：
- 纯周期股（用 PE/PB 估值，PEG 类指标不适用）
- 困境反转股（需特殊框架）
- 金融股（资产负债表结构特殊，需单独评估框架）
- 被动指数投资
- 短期交易 / 日内波段

## 与中期链、长期链的关系说明

本技能与同项目另外两条链**物理隔离、功能互补**：

- **中期链**：`/mid-earnings-team`（1~3 年景气投资版）——其持有周期更短，在**渗透率黄金区间、卖出纪律层级、管理层评估维度**三处与本技能口径不同（逐项差异见 `upgrade1.0/P4-15/口径隔离声明.md`）。本技能**不复用、不引用**其中任何口径。
- **长期链**：`/earnings-team`（10 年长期版，段永平-巴菲特-芒格-李录）——其核心操作思想为「长期不卖」「不预测宏观」，与本技能 1~5 年持有周期 + 季度纪律更新存在本质区别。
- **哲学补充（有限）**：「买股票就是买公司」「能力圈」「本分」等底层投资哲学可跨周期借鉴，在讨论生意模式与企业文化时可用作哲学补充；但**不参与估值、择时、止损等操作层面决策**。

> **路由刚性**：技能内引用**只指向** `garp-*` 系列与两个复用技能（`qoq-accelerator`、`trend-momentum-scan`）；**禁止**引用中期链与长期链技能（`GET-12`）。

## 设计理念

在 GARP 价值成长框架（1~5 年）中，**每季度财报是验证投资逻辑的关键节点**：

1. **景气逻辑验证**：ROE 趋势是否持续？二阶导（增速加速度）是正是负？渗透率到哪一档了？国产化率在哪一梯队？
2. **估值档位更新**：按公司类型选定的估值锚，当前落在**统一六档**的哪一档？
3. **卖出纪律更新**：本季度数据是否触及**五级卖出**的任何一级？（引用 `garp-exit`）
4. **五个不同视角的深度解读**——不是只看数据，是看数据对 1~5 年成长逻辑的含义

本 Skill 的流程分三阶段：

- **阶段一·研究**：五位大师并行精读财报（林奇看生意与估值、郑希审 ROE 与景气、欧奈尔看风控底线、李进评组合管理与治理、**费雪评质化与长期持有**）
- **阶段二·合成**：Team Lead 以**五维评分**综合五个视角，产出研究报告底稿，**重点回答「景气逻辑是否成立、估值在统一六档哪一档、五级卖出是否触发」**
- **阶段三·发布**：编辑 Agent 改写为公众号文章 + 读者评审 Agent 提出修改意见 → Team Lead 定稿

**五位大师权威分工（对齐 `research/个人投资者1~3年中长期投资思想与理念 V2.0.md` 与 GARP 框架五大师章）**：

| 大师 | 思维模式 | 在财报精读中的角色 |
|------|---------|-------------------|
| 林奇 | 侦探思维 · 常识与求证 | **生意与估值**：六类分类复核、生意常识验证、收入量价拆解、**按公司类型选估值锚**、估值陷阱排查 |
| 郑希 | 物理学家思维 · 周期与第一性原理 | **产业景气验证**：ROE 趋势/拐点、二阶导、**渗透率五档 + 国产化率四梯队**、供需格局、产业景气级卖出信号 |
| 欧奈尔 | 工程师思维 · 信号与纪律 | **风控底线**：趋势信号、止损位（**经 `garp-exit` 转接**）、机构动向、抛售信号、CAN-SLIM |
| 李进 | 系统工程师思维 · 均衡与渗透率 | **组合管理与治理**：**只引**管理层与科研转化结论、**只引**地缘 0.3 矩阵结论、底仓/机动仓分离、宏观三表调档 |

## 阶段一：五 Agent 并行研究

### 第一步：获取一手资料

#### 1.1 A股财报原文下载（优先执行，必须完成）

**重要流程**：对于 A 股公司，必须首先使用 `stock_equity.py` 工具下载原始财报 PDF，**下载完成后方可进行下一步的阅读分析工作**（`GET-11`）。

```bash
# 下载最新年报PDF
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type annual

# 下载最新半年报PDF（如需分析半年报）
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type semiannual

# 下载最新季报PDF（如需分析季报）
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type quarterly
```

下载的 PDF 文件保存在 `cninfo_reports/` 目录，文件命名格式：

- 年报：`{股票代码}_{年份}年报.pdf`
- 半年报：`{股票代码}_{年份}半年报.pdf`
- 季报：`{股票代码}_{年份}{季度}季报.pdf`

可使用 `--report-dir` 参数指定其他保存目录：

```bash
python tools/a_share/stock_equity.py --code 601899 --download-report --report-type annual --report-dir ./reports/紫金矿业
```

**流程检查点**：确认 PDF 文件下载成功后，方可启动后续的 5 个研究 Agent。

#### 1.2 交易日与数据基准确认

```bash
date
```

以实测日期作为「最新数据」基准，并在报告头部注明**四基准**（数据基准 / 估值基准 / 资料基准 / 口径基准）。

#### 1.3 PDF 文档阅读工具

下载的财报 PDF 文档提取文字与表格**首选** `tools/common/pdf_extract.py`（基于 pdf-inspector 库，支持自动乱码检测 + OCR 回退），返回失败（退出码非 0 / success=false / 扫描件）时才回退 Poppler 工具集：

**首选工具**：

```bash
# 分类检测 PDF 类型
python tools/common/pdf_extract.py detect cninfo_reports/002465_2025年报.pdf

# 提取含财务附表的 Markdown 并写盘
python tools/common/pdf_extract.py markdown cninfo_reports/002465_2025年报.pdf --save-md --out-dir reports/pdf

# 强制 OCR 提取（适用于 pdf-inspector 提取乱码时，如 Adobe-CNS1 繁体中文 PDF）
python tools/common/pdf_extract.py text cninfo_reports/688235_2025年报.pdf --force-ocr --ocr-langs chi_tra+eng
```

**回退工具（Poppler 工具集，仅当 pdf_extract.py 返回失败时使用）**：

```bash
# 查看PDF文件信息
pdfinfo cninfo_reports/002465_2025年报.pdf

# 将PDF转换为文本文件
pdftotext cninfo_reports/002465_2025年报.pdf cninfo_reports/002465_2025年报.txt

# 将PDF转换为图像（用于扫描版PDF）
pdftoppm -png cninfo_reports/002465_2025年报.pdf cninfo_reports/002465_2025年报
```

**注意事项**：

- 首选 `pdf_extract.py` 提取文字与表格；返回失败时才回退 Poppler 工具集（详见 [PDF文档内容提取技能](../tools-scripts/pdf-extraction.md)）
- `pdf_extract.py` 内置自动乱码检测，当 pdf-inspector 提取文本出现乱码时，自动触发 OCR 回退
- **繁体中文 PDF**（如百济神州）需使用 `--force-ocr --ocr-langs chi_tra+eng` 指定繁体中文语言包
- 全量 OCR 年报耗时较长，建议先 `detect` 确认页码，用 `--pages` 指定关键页提取
- 如果 PDF 无法提取内容，应在报告中标注「资料评级：B 级」，说明扫描版 PDF 限制

#### 1.4 年报结构化定向抽取（A 股年报适用）

```bash
python tools/common/annual_report_parser.py reports/pdf/{年报}.md --output-json
```

可定向抽取 6 类字段：员工 / 研发 / 收入分部 / 新品 / 供应链风险 / 其他关键附注。

> **刚性（`GET-10`）**：必须使用 Task 工具在**同一条消息**中启动 5 个后台 Agent。**不得串行、不得拆分消息、不得由 Team Lead 代写任何缺失 Agent 的结论。**

#### Agent 1：生意与估值解读（林奇视角）

**核心问题：这份财报揭示的生意本质——六类分类有变化吗？按公司类型选定的估值锚，现在落在统一六档哪一档？**

> 林奇："如果你花 10 分钟都解释不清一家公司是做什么的，那它的业务可能太复杂了。"
> 林奇："估值指标本身没有意义，有意义的是它跟你对增长率的把握是否匹配。"

分析内容：

##### 1. 六类分类复核（林奇核心框架）

- 这家公司现在属于哪一类？**分类有变化吗？**
- GARP 框架五类分型：**快速增长型 / 高研发投入型 / 未盈利科技型 / 稳定增长型 / 成熟型**
- **分类变化是估值锚切换信号**：快速增长型滑入稳定增长型 → 主锚由「调整后 PEG」切换为「隐含 PEG」，估值可能被重新定价

##### 2. 生意常识验证（本季度更新）

- 你或身边人在使用这家公司的产品吗？用户反馈有变化吗？
- 用户/客户价值在增强还是减弱？平台黏性变化？

##### 3. 收入结构拆解——「量」还是「价」

- 收入增长来自「量」（用户数/销量）还是「价」（提价）？
- 哪种更健康？「量增价稳」 > 「量价齐升」 > 「价增量减」 > 「量价齐跌」
- 各业务板块：哪些在加速、哪些在减速、哪些在恶化

##### 4. 按公司类型选估值锚（GARP 核心，口径收口 `garp-valuation`）

| 公司类型 | 主锚 | 辅助锚 |
|---------|------|--------|
| 快速增长型 | **调整后 PEG**（研发费用加回核心经营利润口径；<1 低估 / 1~1.2 合理 / 1.2~1.5 偏贵 / >1.5 高估） | PS / EV-Sales |
| 高研发投入型 | **Rule of 40 ≥ 40**（营收增速% + 利润率%，或 FCF 利润率口径） | 调整后 PEG |
| 未盈利科技型 | **PS / EV-Sales** | Rule of 40 |
| 稳定增长型 | **隐含 PEG ≤ 1.2** | 远期 PE + 隐含 PEG |
| 成熟型 | **市值 ≤ 保守 DCF 80%** | 远期 PE |

- **估值档位判定与操作映射，一律以 `garp-valuation` 输出的「统一六档」为准**，本技能不重复定义阈值（`GET-5`）
- 统一六档：显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支
- **对比上期档位变化方向**：变得更贵还是更便宜？
- **渗透率不再用于修正 PEG 数值**：渗透率归 Agent 2「产业景气/渗透率位置」判断，由 Team Lead 合成时与本节估值结论交叉比对

##### 5. 估值陷阱排查（三陷阱）

- **低 PE 陷阱**：PE 低但行业处于景气顶点，未来盈利下降导致 PE 被动抬升
- **高 PE 但增速不可持续**：增速来自一次性收益（出售资产、疫情红利、会计政策变更），须剔除后重算
- **忽略股权稀释**：EPS 增长来自回购减少股本，而非真实盈利增长

##### 6. 林奇式卖出信号检查

- 快速增长型公司：增速连续 2 季度放缓 → 减仓信号
- 稳定增长型公司：PE 是否已到历史区间上沿？
- 调整后 PEG > 1.5 或隐含 PEG 明显超过 1.2 → 估值判断级卖出预警

**输出要求**：六类分类结论（GARP 五类分型）、**按类型选定的估值锚与统一六档落位**及档位变化方向、渗透率位置交叉后的估值判断、估值陷阱排查结论、林奇式总结点评。

#### Agent 5：质化分析与长期持有（费雪视角，本技能新增）

**核心问题：这家公司有没有持久的质化优势？管理层是否值得长期托付？当前困难是暂时性的还是永久性的？「绝不卖」的两个前提是否满足？**

> 费雪："买股票之前，去问它的竞争对手、它的客户、它的供应商——报表告诉你结果，调研告诉你原因。"
> 费雪："如果买入的判断是对的，那么卖出的时机几乎永远不会到来——前提是你的研究足够深、持仓足够集中。"

分析内容：

##### 1. 闲聊法第一手调研清单（可执行问题清单）

围绕「客户 / 竞争对手 / 供应商 / 前员工 / 行业专家」五类对象，输出**可执行的提问清单**（每类 3~5 问），例如：

- 客户：为什么选这家而不是竞品？如果它涨价 10% 你还会买吗？
- 竞争对手：你最尊重它哪一点？你最不担心它哪一点？
- 供应商：它的付款条件与议价能力如何？

##### 2. 十五要点质化筛选（逐条判定「通过 / 存疑 / 不通过」）

聚焦与财报可交叉验证的要点，至少覆盖：

1. 产品是否有足够的市场潜力（未来数年销售能否显著增长）
2. 管理层是否有决心继续开发新产品 / 新工艺
3. 研发组织是否有效（研发投入 → 产出的转化）
4. **销售组织是否出色**（本技能重点）
5. 利润率是否可观、是否有提升空间
6. 是否有改善利润率的明确动作
7. 劳资与人事关系是否良好
8. 高管之间的合作关系是否融洽
9. 管理层是否有足够的深度（梯队）
10. 成本分析与会计控制是否到位
11. 是否有其他行业难以复制的独特优势
12. 是否有短期或长期的利润展望
13. 未来是否会因扩张而大量稀释股权
14. 管理层是否在报喜不报忧
15. **管理层是否诚实、有持股（≥3%）**

##### 3. 销售组织专项评估

- 销售团队规模与人均产能变化趋势
- 渠道结构（直销 / 经销 / 线上）与渠道健康度
- 客户集中度与获客成本变化
- 地面推广能力是否被竞争对手模仿

##### 4. 管理层持股核对（**≥3% 阈值**）

```bash
python tools/specialized/governance_data.py
```

- 核心管理层合计持股比例是否 ≥3%？
- 近 3 年是否有增持 / 减持？方向与理由？
- 股权激励是否覆盖核心业务负责人？

##### 5. 暂时性困难 vs 永久性衰退（关键判定）

| 判据 | 暂时性困难 | 永久性衰退 |
|------|-----------|-----------|
| 原因归因 | 一次性事件（订单延迟、产能爬坡、原料涨价） | 结构性变化（技术路线被替代、需求消失、竞争格局逆转） |
| 财务表现 | 收入仍在增长或持平，毛利率波动 | 收入连续下滑 + 毛利率趋势性下降 |
| 研发与新品 | 新产品管线正常推进 | 管线停滞 / 研发人员流失 |
| 客户行为 | 客户仍在，只是推迟 | 客户转向竞品且不可逆 |

> **判定为「暂时性困难」** → 可容忍短期景气波动，支持长期持有论证；**判定为「永久性衰退」** → 不适用「绝不卖」，**回到五级卖出纪律**。

##### 6. 「绝不卖」两前提检验（**缺一不可**）

| 前提 | 检验标准 | 是否满足 |
|------|---------|---------|
| ① 极度深度的研究认知 | 十五要点筛选通过 + **管理层持股 ≥3%** + **销售组织强** + 第一手调研可执行清单已完成 | 满足 / 不满足 |
| ② 极度集中的持仓 | 属**底仓层级**、**长期不动用机动仓**、未因波动减仓 | 满足 / 不满足 |

- **两前提同时满足** → 可容忍短期景气波动，仅在**诚信否决级**退出
- **任一前提不满足** → **回到五级卖出纪律**，**禁止**以「长期主义」「绝不卖」为由对抗 `garp-exit` 的触发结论（`GET-12`）

##### 7. 费雪式总结点评

- 建仓方式：**三分法**（分批建仓，不一次性满仓）

### 止损按「仓位状态分水岭」（`GET-2`）

| 仓位状态 | 硬止损容忍度 | 说明 |
|---------|-------------|------|
| **建仓初期** | 8%~10% | 尚未验证，纪律优先 |
| **底仓已验证** | 容忍 20% | 已通过 ≥2 季度逻辑验证 |

> **禁止**统一按单一比例一刀切；**禁止**自行放宽。ATR 止损价**经 `garp-exit` 转接取得**，本技能不推算（`GET-4`）。

## 五大核心矛盾与化解方案

| # | 矛盾 | 对立双方 | 化解原则 |
|---|------|---------|---------|
| 一 | **买点哲学** | 左侧（估值便宜先买）vs 右侧（趋势确认再买） | 按**仓位状态分水岭**分层：底仓可左侧（统一六档「低估 / 显著低估」+ 五维闸门通过）；机动仓须右侧（趋势信号确认）；**禁止**单一口径一刀切 |
| 二 | **持有时间维度** | 财报是季度节点（快）vs GARP 是 1~5 年（慢） | 季度只做**验证与纪律更新**，不做频繁换仓；**时间止损满 4 季**为强制复评节点 |
| 三 | **止损 vs 越跌越买** | 硬止损纪律 vs 低估值加仓 | **先判「杀估值」还是「杀逻辑」**：杀估值 → 允许底仓三分法加仓；杀逻辑 → 硬止损优先，**不得**加仓 |
| 四 | **分散 vs 集中** | 单只上限 + 行业 ≤40% vs 集中持有 | 用**底仓集中 + 机动分散**化解：底仓聚焦优质标的，机动仓承担试错与轮动 |
| 五 | **费雪「绝不卖」 vs 趋势景气纪律** | 费雪：优质公司长期不卖 vs 五级卖出 / 二阶导转负减仓 | 「绝不卖」**两前提缺一不可**：① **极度深度的研究认知**（十五要点质化筛选通过 + 管理层持股 ≥3% + 销售组织强）② **极度集中的持仓**（底仓层级、长期不动用机动仓）；**两前提同时满足** → 可容忍短期景气波动（仅在诚信否决级退出）；**任一缺失** → **回到五级卖出纪律** |

### 矛盾五判据表（`GET-12`）

| 前提 | 检验标准 | 判定 |
|------|---------|------|
| ① 极度深度的研究认知 | 十五要点筛选通过 + 管理层持股 ≥3% + 销售组织强 + 第一手调研清单已执行 | 满足 / 不满足 |
| ② 极度集中的持仓 | 属底仓层级 + 长期不动用机动仓 + 未因波动减仓 | 满足 / 不满足 |

- **两前提同时满足** → 可容忍短期景气波动，仅在**诚信否决级**退出
- **任一前提不满足** → **回到五级卖出纪律**，由 `garp-exit` 判定

> **双落位刚性（验收要点 2）**：五大矛盾化解结论**必须同时出现在 ① 研究报告第八节「投资论文影响评估」② 团队专节「五大矛盾化解」**；仅出现在团队专节 → **视为未落地**。

| # | 陷阱 | 识别要点 |

## 局限性

1. **季度数据的滞后性**：财报反映过去，对 1~5 年逻辑的验证存在 1 个季度以上的时滞。
2. **渗透率与国产化率依赖第三方估算**：无统一口径，双源误差 >5pct 时须标注低置信。
3. **费雪质化结论难以量化**：闲聊法与十五要点依赖调研清单与搜索，非量化工具输出（缺口 G7）。
4. **宏观三表为工具内置口径**：与外部宏观观点可能不一致，以工具输出为准（缺口 G8）。
5. **跨币种折算受限**：`fx_rate.py` 跨币种折算不可用，港股 / 美股估值需手工换算并注明来源与日期（缺口 G1）。
6. **五维评分含主观判断**：档位判定依赖 Agent 输出质量，Team Lead 自评部分须显式标注。
7. **阶段三产出限于报告配套文章**：不含选题、排版与平台投放。
8. **不构成投资建议**：本技能用于学习与研究。

## 附录 B：一页纸操作备忘卡

**五维评分**：风控底线（及格 / 存疑 / 不合格）｜选股与估值（低估 / 合理 / 偏贵 / 透支）｜赛道选择（黄金窗 / 成长期 / 兑现期 / 天花板）｜组合与治理（可重仓 / 可底仓 / 仅机动 / 禁入）｜质化与长期持有（强 / 中性 / 弱）

**渗透率五档**：<5% 导入早期｜5%~15% 突破期｜**15%~40% 加速上行期（黄金窗，TAM ≥1000 亿）**｜40%~60% 逐步兑现｜>60% 天花板
