# 财报精读团队（GARP 独立档 1~5 年）(GARP Earnings Team)

**GARP 独立档团队化财报精读 + 发布入口**：对**单家公司 × 单期财报**（季报 / 半年报 / 年报）执行**三阶段流程**（五 Agent 并行研究 → Team Lead 五维合成 → 编辑润色 + 读者评审 + 定稿），用五大师视角回答「**本期景气是否被验证、估值落在 GARP 统一六档哪一档、五级卖出是否触发、底仓 / 机动仓怎么调**」，产出研究底稿与可直接发布的公众号文章。

> 本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。

> **前置建议**：先跑 `garp-investment-research` / `garp-investment-team` 建立基准投资论文，再用本技能做逐期验证；**A 股公司必须先下载财报 PDF 并确认成功**，方可启动 5 个研究 Agent。

| --- | --- | --- | --- |

### 能力圈声明

**适用**：科技 / 医药 / 高端制造 / 景气周期成长股等具备可持续成长性的公司季度、半年、年度财报精读；需要在「五大师交叉验证 + 团队化收口」基础上产出发布级文章的关键财报。

**不适用**：纯周期股、困境反转股、金融股、被动指数投资、短期交易 / 日内波段。

## 快速开始

### 基本调用方式

```text
/garp-earnings-team {公司名} {期间}
```

支持输入格式：

- `{公司名} {季度}` — 例如：`新易盛 2025Q3`、`腾讯 2025Q4`
- `{公司名} {年报 / 半年报}` — 例如：`中芯国际 2025年报`、`宁德时代 2025半年报`
- `{公司名} 最新` — 默认读取最近一期，例如：`PDD 最新`

| 参数 | 必填 | 取值 | 说明 |
| --- | :--: | --- | --- |
| `{公司名}` | ✅ | 文本 | 位置参数，公司名称或代码 |
| `{期间}` | ✅ | `2025Q3` / `2025年报` / `2025半年报` / `最新` | 位置参数，财报期间 |

> **零新增 CLI**：本技能**不新增任何 Python 命令行参数**、**不修改任何既有工具签名**，也**不提供档位切换参数**（详见「核心原则」）。

### 启动前置（三步）

1. **确认日期与市场**：`date` 实测撰写日；凭 `stock_info.py --search {公司名}` 识别 A 股 / 港股 / 美股与代码。
2. **A 股刚性前置**：`stock_equity.py --code {代码} --download-report --report-type {annual|semiannual|quarterly}` 下载财报 PDF，**确认成功**后方可启动 5 个研究 Agent。
3. **一手资料准备**：`pdf_extract.py markdown` 提取（失败回退 Poppler）→ 年报走 `annual_report_parser.py --output-json` → 搜索五工具补齐上季数据与电话会纪要 → 评定**资料可得性 A / B / C**并**显式告知全部 5 个 Agent**。

## 核心功能

对指定公司执行团队化 GARP 财报精读。**五 Agent 并行研究 → Team Lead 五维合成 → 编辑润色 + 读者评审 + 定稿**，最终产出研究底稿与可直接发布的公众号文章。

### 三阶段流程（文字版）

```text
前置：`date` 确认基准 → 市场识别 → A 股财报 PDF 下载确认 → PDF / 年报结构化提取
      → 搜索五工具补齐材料 → 资料可得性 A/B/C 评级（告知全部 Agent）
   │
   ├─ 阶段一·研究：同一条消息并行启动 5 个研究 Agent（不可压缩、不可串行）
   │    Agent 1 林奇    · 生意与估值      — 六类分类是否漂移？按公司类型选哪个估值锚？落在统一六档哪一档？
   │    Agent 2 郑希    · ROE 与景气验证  — ROE 拐了吗？二阶导是正是负？渗透率在哪一档、国产化率在哪一梯队？
   │    Agent 3 欧奈尔  · 趋势信号与纪律  — 趋势破了吗？止损位经 garp-exit 转接后是多少？机构在买还是卖？
   │    Agent 4 李进    · 组合管理与治理  — 管理层闸门（引 garp-management）变了吗？地缘 0.3 矩阵结论（引 garp-geo-policy）如何？底仓 / 机动仓怎么调？
   │    Agent 5 费雪    · 质化与长期持有  — 有无长期质化优势？销售组织与管理层持股 ≥3% 如何？是暂时性困难还是永久性衰退？
   │    产出：5 份 Agent 分报告落盘（缺任一即流程未完成，`GET-1`）
   │
   ├─ 阶段二·合成：Team Lead 五维评分 + 共识 / 矛盾 / 忽略角落 + 三问收口
   │    五维评分：风控底线（欧奈尔）/ 选股与估值（林奇）/ 赛道选择（郑希）/ 组合与治理（李进）/ 质化与长期持有（费雪）
   │    三问收口：景气问（支持 / 部分支持 / 证伪）· 估值问（统一六档落位）· 卖出问（五级卖出是否触发 + 时间止损）
   │    产出：研究报告底稿（含八节结构 + 五大矛盾化解）
   │
   └─ 阶段三·发布：编辑 Agent 改写为 GARP 语域文章 → 读者评审 Agent 四维提意见
        → Team Lead 逐条采纳或说明不采纳理由 → 定稿 → `report_audit.py` 数据抽检准出 → 发布
```

### 五 Agent 职责边界（防越界）

| Agent | 大师 | 核心职责 | 明确禁止 |
| :--: | --- | --- | --- |
| 1 | 林奇 | 六类分类复核、生意常识验证、收入「量 / 价」拆解、按公司类型选估值锚、估值陷阱排查、林奇式卖出信号 | 自建估值档位表；自行判定渗透率档位 |
| 2 | 郑希 | ROE 8 季趋势与拐点、营收增速二阶导（主锚引 `qoq-accelerator`）、渗透率五档 + 国产化率四梯队、供需与价格趋势 | 自行加减估值数值修正渗透率 |
| 3 | 欧奈尔 | 趋势通道与突破 / 跌破、机构与资金动向、止损位转接、抛售信号、CAN-SLIM 更新 | 不自行推算 ATR 止损价（须经 `garp-exit` 转接） |
| 4 | 李进 | **只引**管理层与科研转化结论、**只引**地缘 0.3 矩阵结论、底仓 / 机动仓分层、宏观三表调档、决策优先级执行 | 不复制其他档位管理层评分口径；不自建地缘评分维度 |
| 5 | 费雪 | 闲聊法第一手调研清单、十五要点质化筛选、销售组织评估、管理层持股 ≥3% 核对、暂时性困难 vs 永久性衰退、「绝不卖」两前提检验 | 不下估值结论；不下止损结论；不得以质化优秀对冲诚信前置闸门 |

> **刚性纪律（`GET-10`）**：5 个研究 Agent 必须在**同一条消息**中并行启动；**不得**由 Team Lead 代写任何缺失 Agent 的结论；**资料可得性 A/B/C 评级必须显式告知每一个 Agent**。

## 设计理念

在 GARP 价值成长框架（1~5 年）中，**每个季度财报是验证投资逻辑的关键节点**：

1. **景气逻辑验证** — ROE 趋势是否持续？二阶导是正是负？渗透率在哪一档、国产化率在哪一梯队？
2. **估值档位更新** — 按公司类型选定的估值锚，当前落在**统一六档**的哪一档？
3. **卖出纪律更新** — 本期数据是否触及**五级卖出**的任何一级？是否触及时间止损？
4. **五个视角的深度解读** — 不是只看数据，而是看数据对 1~5 年成长逻辑的含义。

### 五大师分工表

| 大师 | 思维模式 | 在财报精读中的角色 |
| --- | --- | --- |
| 林奇 | 侦探思维 · 常识与求证 | **生意与估值**：六类分类复核、生意常识验证、收入量价拆解、按公司类型选估值锚、估值陷阱排查 |
| 郑希 | 物理学家思维 · 周期与第一性原理 | **产业景气验证**：ROE 趋势 / 拐点、二阶导、渗透率五档 + 国产化率四梯队、供需格局、产业景气级卖出信号 |
| 欧奈尔 | 工程师思维 · 信号与纪律 | **风控底线**：趋势信号、止损位（经 `garp-exit` 转接）、机构动向、抛售信号、CAN-SLIM |
| 李进 | 系统工程师思维 · 均衡与渗透率 | **组合管理与治理**：只引管理层与科研转化结论、只引地缘 0.3 矩阵结论、底仓 / 机动仓分离、宏观三表调档 |
| 费雪 | 质化研究者思维 · 深度调研与长期持有 | **质化与长期持有**：闲聊法调研清单、十五要点质化筛选、销售组织、管理层持股 ≥3%、暂时性困难 vs 永久性衰退、「绝不卖」两前提检验 |

### Team Lead 五维评分总表

| 维度 | 归属 Agent | 打分依据 | 权重档 |
| --- | --- | --- | --- |
| 风控底线 | 欧奈尔（Agent 3） | 趋势是否破位、止损位是否触及、机构是否撤退 | 及格 / 存疑 / 不合格 |
| 选股与估值 | 林奇（Agent 1） | 六类分类是否漂移、估值锚是否支持、统一六档落位 | 低估 / 合理 / 偏贵 / 透支 |
| 赛道选择 | 郑希（Agent 2） | 渗透率档位、国产化率梯队、二阶导正负 | 黄金窗 / 成长期 / 兑现期 / 天花板 |
| 组合与治理 | 李进（Agent 4） | 管理层与科研转化闸门、地缘矩阵结论、仓位与宏观调档 | 可重仓 / 可底仓 / 仅机动 / 禁入 |
| **质化与长期持有** | **费雪（Agent 5）** | 十五要点质化筛选、销售组织、管理层持股 ≥3%、困难性质判定 | **强 / 中性 / 弱** |

- **硬闸门优先**：任一维触发「禁入」或「不合格」（含诚信前置命中）→ **不再进入加权排序**，直接输出「放弃」结论。
- **五维齐备性**：五维**缺一即视为流程未完成**，Team Lead 不得出报告（`GET-1`）。
- **自评标注**：凡由 Team Lead 自行补充（非 Agent 输出）的判断，**必须显式标注「[Team Lead 自评]」**（`GET-12`）。

### 五大核心矛盾与化解方案

| # | 矛盾 | 对立双方 | 化解原则 |
| :--: | --- | --- | --- |
| 一 | **买点哲学** | 左侧（估值便宜先买）vs 右侧（趋势确认再买） | 按**仓位状态分水岭**分层：底仓可左侧（统一六档「低估 / 显著低估」+ 五维闸门通过）；机动仓须右侧 |
| 二 | **持有时间维度** | 财报是季度节点（快）vs GARP 是 1~5 年（慢） | 季度只做**验证与纪律更新**，不做频繁换仓；**时间止损满 4 季**为强制复评节点 |
| 三 | **止损 vs 越跌越买** | 硬止损纪律 vs 低估值加仓 | **先判「杀估值」还是「杀逻辑」**：杀估值 → 允许底仓三分法加仓；杀逻辑 → 硬止损优先，不得加仓 |
| 四 | **分散 vs 集中** | 单只上限 + 行业 ≤40% vs 集中持有 | 用**底仓集中 + 机动分散**化解：底仓聚焦优质标的，机动仓承担试错与轮动 |
| 五 | **费雪「绝不卖」 vs 趋势景气纪律** | 费雪：优质公司长期不卖 vs 五级卖出 / 二阶导转负减仓 | 「绝不卖」**两前提缺一不可**：① 极度深度的研究认知 ② 极度集中的持仓；**两前提同时满足** → 可容忍短期景气波动（仅在诚信否决级退出）；**任一缺失** → **回到五级卖出纪律** |

> **双落位刚性**：五大矛盾化解结论**必须同时出现在研究报告第八节与「团队专节·五大矛盾化解」两处**；仅写在团队专节视为未落地。

## 使用示例

### 示例 1：A 股半年报（含 A 股 PDF 前置）

```text
输入：/garp-earnings-team 新易盛 2025Q3
```

先用 `stock_equity.py --download-report --report-type quarterly` 下载季报 PDF 并确认成功，再并行启动 5 个 Agent：重点验证光模块景气逻辑（ROE 趋势与二阶导）、按公司类型定位估值锚并落到统一六档，同步核对五级卖出是否触发。

### 示例 2：港股季度财报

```text
输入：/garp-earnings-team 腾讯 2025Q4
```

以 doubao + tavily 双源验证的港股数据为准，聚焦 ROE 趋势、渗透率档位与国产化率梯队，重点看管理层诚信前置闸门结论与地缘 0.3 矩阵是否变化。

### 示例 3：美股年报

```text
输入：/garp-earnings-team PDD 2025年报
```

财报指标走 `us_stock/stock_financial.py --indicators`，原文走 `exa_search.py --type deep` 直击 SEC filings；重点做费雪视角的质化筛选（十五要点 / 销售组织 / 管理层持股 ≥3%）与「暂时性困难 vs 永久性衰退」判定。

## 质量标准

| 维度 | 判据 |
| --- | --- |
| **五维齐备** | 风控底线 / 选股与估值 / 赛道选择 / 组合与治理 / 质化与长期持有**五维缺一即不合格**；5 份 Agent 分报告缺任一即流程未完成（`GET-1`） |
| **估值唯一出口** | 估值结论一律经 `garp-valuation` 多工具矩阵收口到**统一六档**；禁止自建档位表、禁止单工具口径（`GET-5`） |
| **五级卖出转接** | 五级卖出 + 时间止损 + 性价比替换**只引不自建**；命中任一级即**转接 `garp-exit`**；禁止自算止损价（`GET-4`） |
| **数据双源** | 关键财务数据须 ≥2 个独立来源交叉验证，**误差 >1% 须标记**；禁止 LLM 心算市值与估值（`GET-11`） |
| **`report_audit.py` 准出** | 定稿前必跑 `report_audit.py extract --seed 42` + `verdict`；**抽检不通过不得发布**（`GET-12`） |
| **三问收口** | 景气问 / 估值问 / 卖出问**三问必答、不可省略** |
| **三档结论** | 报告必须给出**可建仓 / 观察仓 / 放弃**三档之一，并与「假如空仓」测试结论一致 |

**Team Lead 的合成价值**：不是拼报告，而是找交叉和矛盾 —— ① 五个视角的共识点（可信度最高）② 五个视角的矛盾点（最有价值）③ 被忽略的角落 ④ 五级卖出触发评估。凡 Team Lead 自行补充的判断须标注「[Team Lead 自评]」。

**编辑 Agent 原则**：保留全部关键数据与结论、不降低专业深度；GARP 语域表述；文章长度控制在 1000~3000 字；剔除流程性文字。

**读者评审 Agent 四维**：看得懂（可读性）/ 有收获（信息价值）/ 有问题（可信度）/ 想转发（行动指导性）；**每条意见须可执行**（指明修改位置与建议改法）；「必须修改」项逐条处理，「建议优化」项选择性采纳。

## 核心原则

1. **读原文，不读摘要** — 尽一切可能获取一手资料；A 股必须先下载财报 PDF 并确认成功（`GET-11`）。
2. **五个视角不是五个部门** — 必须相互印证和挑战，不是各说各话；5 个 Agent 同一条消息并行启动、不可压缩（`GET-10`）。
3. **引用不重复定义** — 估值 / 卖出 / 渗透率与国产化率 / 管理层与科研转化 / 地缘矩阵 / 宏观调档 / 仓位规则**一律引用对应口径出口**，本技能只定义流程与编排。
4. **口径隔离** — 报告与语域只用 GARP 独立档口径；技能内引用只指向 `garp-*` 系列 + `qoq-accelerator` / `trend-momentum-scan`；不引用 1~3 年中期链与 10 年长期链的技能与术语（`GET-12`）。
5. **三档并存路由** — 本技能不与中期链、长期链互转、不提供档位切换开关；只读写 `-garp-earnings-team-*` 报告文件。
6. **结论要明确** — 必须给出可建仓 / 观察仓 / 放弃三档结论，不允许「总体来看基本符合预期但也有一些值得关注的点」。
7. **反面检验贯穿全程** — 每个积极发现都附带反面论据；常见估值陷阱（低估值陷阱 / 伪黄金窗 / 估值锚错配 / 质化优秀的伪对冲）逐一排查。
8. **零新增 CLI、引擎零改动** — 工具层任何缺口只登记不修复，统一归属后续阶段处理。

### 其他注意事项

- 禁止使用 Anthropic 官方 `WebSearch` / `WebFetch`（中国大陆不可用），统一使用本地搜索五工具组合。
- 资料可得性评级（A / B / C）须告知每个研究 Agent，并影响其分析深度（A 级全步骤 / B 级标注非原始来源并降权 / C 级聚焦核心数据）。
- 所有数据必须标注来源与取值时点；跨币种折算须注明汇率来源与日期。
- 搜索须限制时间范围（`--time-range month/week`），优先获取最新信息。
- 兜底与失败处置：某 Agent 未产出结论 → **不得代写**，相关维度记「不可评」，结论降级为「观察仓」；口径出口不可得 → 相关闸门记「未核」，结论**不得为「可建仓」**。
- 编辑改写时不可降低专业深度；读者评审「必须修改」项需逐条处理。

## 局限性说明

1. **季度数据的滞后性** — 财报反映过去，对 1~5 年逻辑的验证存在 1 个季度以上时滞。
2. **资料可得性有限** — 部分公司完整财报原文难以获取，评级可能为 B / C 级；A 股年报常为扫描版，可能无法提取文本，影响附注分析。
3. **渗透率与国产化率依赖第三方估算** — 无统一口径，双源误差 >5pct 时须标注低置信。
4. **费雪质化结论难以量化** — 闲聊法与十五要点依赖调研清单与搜索，非量化工具输出。
5. **宏观三表为工具内置口径** — 与外部宏观观点可能不一致，以工具输出为准；数据缺失时默认中性 1.0 并显式标注。
6. **跨币种折算受限** — `fx_rate.py` 仅取汇率，折算需显式完成并注明汇率时点。
7. **五维评分含主观判断** — 档位判定依赖 Agent 输出质量，Team Lead 自评部分须显式标注。
8. **阶段三产出限于报告配套文章** — 不含选题、排版与平台投放等公众号运营职能。
