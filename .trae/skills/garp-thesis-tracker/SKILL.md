# 投资论文追踪（GARP 1~5 年）：买入后的持有纪律系统

对 $ARGUMENTS 执行 GARP 投资论文追踪。从建立论文到持续季度体检，系统化管理**买入后**的持有纪律。

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

> "买入只是开始。真正的工作是持有期间的持续跟踪。" —— 李录
>
> "当事实改变时，我就改变想法。你呢？" —— 凯恩斯

**支持输入格式**：

- `{公司名}` — 首次调用**建立 GARP 论文**；已存在论文则执行**季度体检**
- `{公司名} 建立论文` — 强制重新建立 GARP 论文
- `{公司名} 季度检查` — 基于最新财报与景气数据体检

> **本技能不提供档位切换参数**——它即 GARP 独立档专属入口，命令与输入中不含任何档位切换开关；档位切换类口令属 1~3 年中期链，在本技能中出现即违反 `GT-15`（口径隔离）。

## 设计理念与定位

大多数投资者的流程是：研究 → 买入 → 祈祷。缺少买入后的系统化跟踪，导致：

- 该卖的时候舍不得卖（"再等等，会涨回来的"）
- 不该卖的时候恐慌卖出（"跌了 20%，是不是我错了"）
- 忘记了当初为什么买的（"我买这个是因为什么来着？"）

本框架与费雪的做法一致：**买入前就写下退出条件，然后每个季度用景气数据检验假设**（框架行 41：郑希「长期判断由无数短期客观判断拼接而成，每一笔持仓都要在每个季度接受景气数据的检验」）。

**本技能把框架第三部分「持仓管理与操作纪律」与第一部分「五大师思维模式」合成为一张可执行的体检表**：

**建立 GARP 论文（五大师假设清单 + 五级卖出检查表 + 六档估值锚点）→ 季度逐条验证假设 → 逐级执行五级卖出检查（命中即停）→ 输出健康度评分与底仓/机动仓相对动作 → 回写 `-garp-thesis.md` 追踪记录。**

### 本技能的五条硬纪律

| # | 纪律 | 原因 |
| --- | --- | --- |
| 1 | **诚信闸门前置，命中直判 1 分** | 诚信独立于评分体系、只作前置否决（框架行 281、行 477~479）；不得因估值便宜或趋势向好而降级处置（`GT-1`） |
| 2 | **五级优先级不得倒置，命中即停** | 卖出层级是硬编码检查树，低级别不得覆盖高级别（框架行 473~475、`GT-2`） |
| 3 | **估值档位只读不重算** | 档位与算数归 `garp-valuation`（P4-5）；本技能零 PEG 算式，避免同一框架两套刻度（`GT-3`） |
| 4 | **卖出级别只读不重定义** | 级别定义与阈值归 `garp-exit`（P4-6）；本技能只消费其五级出口（`GT-4`） |
| 5 | **论文文件物理隔离** | 只读写 `-garp-thesis.md` / `-garp-track-*`；不得触碰 1~3 年 / 10 年档的论文文件（`GT-5`） |

## 边界声明（本技能的核心约束）

1. **不做卖出决策**——不定义卖出级别、不改阈值、不输出「目标仓位 X%」；只逐级**检查**并**转 `garp-exit`** 执行（`GT-4`、`GT-9`）。
2. **不做估值档位判定**——不重算调整后 PEG / 隐含 PEG / EV-Sales / Rule of 40 / 研发管线 NPV / DCF；档位一律取 `garp-valuation` 出口（`GT-3`）。
3. **不做管理层与科研转化评分**——7+7+6 与 8+8+4 计分、诚信闸门判定归 `garp-management`（P4-4）；本技能只读结论并转触发（`GT-11`）。
4. **不做地缘前置闸门判定**——0.3 三维矩阵与回避档归 `garp-geo-policy`（P4-1），且属**买入前**闸门，**不进入**本技能五级检查表（`GT-12`）。
5. **不以宏观择时**——宏观只调节估值容忍度与仓位尺度，不是清仓依据（框架行 685）；本技能不调用宏观工具（`GT-13`）。
6. **不出仓位数值**——只出「底仓 / 机动仓」的**相对动作**（持有 / 加仓 / 减仓 / 清仓）；组合层数值裁决归 `garp-portfolio-review`（P4-8）（`GT-9`）。
7. **不新增工具、不建聚合器**——本技能是**编排层**（`GT-6`、§数据获取与工具编排）；全部数值来自既有工具与已交付 `garp-*` 技能的实测输出。
8. **不修改 1~3 年 / 10 年档的论文文件**——三档并存、互不覆盖（`GT-5`）。

> **范围自查**：本技能若出现「跳过诚信检查 / 低级别覆盖高级别 / 自算 PEG 档位 / 自造卖出级别或阈值 / 输出绝对仓位数值 / 写入 1~3 年档论文文件 / 用宏观做清仓理由 / 渗透率沿用 1~3 年档刻度 / 时间止损并入五级 / 引用中期链口令」，即为越界。

## 执行流程（九步）

### 第零步：参数与模式判定

1. 运行 `date` 确认当天日期，作为「论文建立日期 / 检查日期 / 数据截止日期」基准（全局规则 1；`GT-14`）。
2. 检查 `reports/{公司名}/{公司名}-garp-thesis.md` 是否存在：
   - **不存在** → 进入**模式 A：建立 GARP 论文**；
   - **存在** → 进入**模式 B：GARP 季度体检**（或按 `{公司名} 建立论文` 强制走模式 A）；
   - **不存在但用户表示已有** → 询问文件路径，**不得自动创建覆盖**（`GT-5`）。
3. **三档并存提示**：若同目录下存在 1~3 年 / 10 年档的论文文件，**只提示不修改**，并说明三档论文分别维护、互不覆盖（`GT-5`）。

### 第一步：数据收集

按上市地选择取数工具（见「数据获取与工具编排」节），采集：最新财报（含季报先行指标）、行情与技术面、景气/渗透率/订单数据、治理与舆情。**关键财务数据须至少两个独立来源，误差 >1% 须标记**（全局规则 2；`GT-14`）。

### 第二步：上游结论只读拉取

| 顺序 | 拉取对象 | 用途 |
| --- | --- | --- |
| 1 | `garp-management`（P4-4） | 诚信闸门结论 + 管理层 20 分制 + 科研转化 20 分制 → 「治理与质化」维 + 五级三级输入 |
| 2 | `garp-valuation`（P4-5） | 公司类型 + **统一收口六档**（基准 / 宏观校准后 / ESG 折价后三级）→ 估值锚点与档位扣分 |
| 3 | `garp-exit`（P4-6） | 五级卖出**级别定义**与当前是否已命中 → 五级检查表 |
| 4 | `garp-geo-policy`（P4-1） | 地缘前置闸门结论 → **仅报告提示，不入五级表**（`GT-12`） |
| 5 | `qoq-accelerator` / `trend-momentum-scan` | 增速二阶导 / 技术面破位 → 「景气」与「趋势与纪律」维 |

### 第三步：GARP 核心论文（200 字以内）

回答五问，每问一句话：

```markdown
我以 ___元 买入 ___公司（GARP 1~5 年，五大师），因为：
1. 赛道与景气：___（郑希视角——ROE 所处位置与景气方向）
2. 产业阶段：渗透率位于 ___%，处于（15%~40% 加速上行 / 40%~60% 逐步兑现 / >60% 天花板）期（李进视角）
3. 类型与壁垒：公司属 ___ 型，主锚为 ___，护城河证据是 ___（林奇视角）
4. 治理与质化：诚信闸门未命中，管理层评分 ___，科研转化评分 ___；销售组织与管理层持股 ≥3% 的证据是 ___（费雪视角）
5. 退出条件：若 ___ 发生，我将按五级规则（诚信否决 > 硬止损 > 逻辑止损 > 产业景气 > 估值判断）卖出（欧奈尔视角）
```

### 第四步：五大师假设清单

按「五大师假设维度」节落地，**五维齐全**，每维 2~4 条，共 10~20 条；每条含「**验证方式 / 验证频率 / 当前状态**」三列（`GT-6`）。

### 第五步：五级卖出检查

按「五级卖出检查表」节，**一级 → 五级依次检查，命中即停**；一级命中**直接判 1 分**（`GT-1`、`GT-2`）。

### 第六步：估值水位更新

呈现档位四列「买入时 / 上次 / 当前 / 变化」，**三级留痕**（基准档位 → 宏观校准后档位 → ESG 折价后档位），值全部**只读 `garp-valuation`**（`GT-3`）。

### 第七步：健康度评分与报告

## 五级卖出检查表（口径归属：`garp-exit` P4-6）

> **本表只做「检查」，不做「定义」**——级别定义、阈值、动作归属 `garp-exit`（P4-6）；本技能**逐级检查并转接**（`GT-4`）。

**【补充机制（不占优先级，兜底 / 优化动作）】**

## 健康度评分（GARP 版）

```markdown
GARP 健康度 = 10 - (⚫破裂假设 × 3) - (🔴受损假设 × 2) - (🟡弱化假设 × 1)
             - (五级卖出命中扣分) - (估值档位扣分)
最低 1 分，最高 10 分
```

**五级卖出命中扣分**（命中即停，**只取最高优先级一项，不累加**）：

| 命中级别 | 扣分 |
| --- | :--: |
| 一级 · 诚信否决 | **直接判 1 分**（`GT-1`） |
| 二级 · 硬止损 | -5 |
| 三级 · 逻辑止损 | -4 |
| 四级 · 产业景气判断 | -3 |
| 五级 · 估值判断 | -2 |
| 未命中 | 0 |

**估值档位扣分**（引用 `garp-valuation` 统一收口六档）：

| 档位 | 扣分 |
| --- | :--: |
| 显著低估 | 0 |
| 低估 | 0 |
| 合理 | 0 |
| 合理偏贵 | -1 |
| 高估 | -2 |
| 严重透支 | -3 |

**评分含义表**：

| 评分 | 含义 | 建议动作（**相对动作**） |
| :--: | --- | --- |
| 9-10 | 五大师假设全部成立 + 档位合理 | 底仓持有，机动仓可加 |
| 7-8 | 核心假设成立，个别边际弱化 | 底仓持有 |
| 5-6 | 假设受损或档位偏贵 | 持有但减机动仓 |
| 3-4 | 多假设受损或档位高估 | 减仓（先减机动仓） |
| 1-2 | 一级/二级命中或核心假设破裂 | 按五级规则转 `garp-exit` 执行 |

**评分硬约束（`GT-6`）**：

1. 扣分表**固定**，技能层**不得自造扣分项**、不得为「更好看的结论」改写系数；
2. 假设扣分与卖出/档位扣分**可叠加**，但**五级内部只取最高优先级一项**；
3. **「未验证」假设不计入扣分**，但须在报告中列出；
4. 若**未验证假设 ≥3 条**，报告须显式声明「**本次体检置信度不足**」，健康度标注为「**参考值**」；
5. 上游估值档位缺失时，**档位扣分记 0 并显式标注「本次未获取」**，不得推定。

## 注意事项

1. **诚信闸门是前置否决，不是扣分项**——命中即直判 1 分，**不得**进入「假设扣分 + 高级别扣分」的求和计算（`GT-1`）。
2. **命中即停后必须标注「检查终止」**，未检查的级别标「**未检查**」（**不得**标「未触发」）——否则会给人"五级全部排查过"的错误印象（`GT-2`）。
3. **时间止损不占优先级**——它与五级**并列**，且**仅针对"逻辑未兑现"的仓位**；不得用它去覆盖已命中的级别，也不得用它否定费雪式长期持有（`GT-8`，框架行 504）。
4. **两个「底仓」语义是最高频误用点**——「单只标的最终仓位 50%/已建立」与「组合层面股票仓位 60%~80%」不是一回事；报告中涉及时必须显式声明口径（框架行 449、行 528）。
5. **估值档位与卖出级别都是"只读"**——本技能**零 PEG 算式、零卖出阈值定义**；发现上游结论异常时应**提示复核**，而非自行修正（`GT-3`、`GT-4`）。
6. **「论文 / 假设 / 健康度」非框架原文**——属骨架继承与本技能操作化产物；三处（关键口径引用表 / 论文文件脚注 / 报告模板脚注）须显式标注，并写明框架分散锚点（行 41 / 114 / 520 / 536）。
7. **「未验证」不等于「成立」也不等于「破裂」**——不计入扣分，但必须列出；**未验证假设 ≥3 条**时报告须声明「本次体检置信度不足」，健康度标为「参考值」。
8. **渗透率窗口 15%~40% 是 GARP 独立档刻度**——不得沿用 1~3 年档刻度，也不得因「公司赛道特殊」自行放宽（`GT-10`）。
9. **不以宏观择时**——宏观只调节估值容忍度与仓位尺度（框架行 685）；报告的六、结论段不得出现「因宏观进入 X 期故清仓」类表述（`GT-13`）。
10. **三档并存**——同一标的存在 1~3 年 / 10 年档论文时，本技能**只提示不修改**；三份论文分别维护、互不覆盖（`GT-5`）。

## 局限性

1. **无法替代人工确认**——假设状态的定性判断、诚信类证据的**真实性**最终仍需人工确认；本技能只保证**流程与留痕的完整性**。
2. **依赖上游技能结论**——估值档位、管理层评分、卖出级别均来自 `garp-*` 技能；上游结论有误将直接传导（本技能只做**一致性与留痕校验**，不重算、不重定义）。
3. **「论文 / 假设 / 健康度」属操作化口径**——框架未定义该机制，维度切分与公式系数（3/2/1、5/4/3/2、档位 1/2/3）为骨架继承 + 本技能实现，**其绝对数值不具备框架原文的权威性**。
4. **数值阈值的粗糙性**——4 个季度、15%~40%、8%~10%、PEG 1.5/2.0 都是框架给定的**区间与量级**，不构成精确择时工具。
5. **不构成投资建议**——本技能仅用于学习与研究，不构成任何投资建议。
