# garp-thesis-tracker — GARP 投资论文追踪（1~5 年独立档）

> **技能命令**：`/garp-thesis-tracker {公司名}`
> **所属档位**：GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔）
> **开发任务**：P4-7（口径替换型 16 第 1 项）
> **版本**：1.0.0（2026-09-17）

---

## 一、技能用途

### 一句话定位

把《中长期价值成长（GARP）投资框架》**第三部分「持仓管理与操作纪律」**与**第一部分「五大师思维模式」**合成一张可执行的持有期体检表：

**建立 GARP 论文（五大师假设清单 + 五级卖出检查表 + 六档估值锚点）→ 季度逐条验证假设 → 逐级执行五级卖出检查（命中即停）→ 输出健康度评分与底仓/机动仓相对动作 → 回写 `-garp-thesis.md` 追踪记录。**

### 何时用

- **首次建档**——已持仓或已完成买入前研究，需要把买入逻辑写成**可检验的假设清单**；
- **季度体检**——财报发布后，逐条验证五大师假设是否仍成立；
- **事件体检**——监管、并购、管理层变动、地缘政策变动后即时复核；
- **健康度评分**——把多维证据收敛为 1~10 分与底仓/机动仓相对动作；
- **买入理由自查**——"我当初为什么买这只股票"；
- 为 `garp-exit`（P4-6）提供 `-garp-thesis.md` 建档与季度基线。

### 何时不用

| 场景 | 应使用的技能 |
| --- | --- |
| 首次深度研究与买入决策 | `garp-investment-research`（P4-12）/ `garp-investment-team`（P4-13） |
| 买入前门槛检查（能力圈 / 财务五门槛 / 三档结论） | `garp-investment-checklist`（P4-3） |
| 估值档位判定（贵不贵 / 建仓节奏） | `garp-valuation`（P4-5） |
| 卖出执行与止损 | `garp-exit`（P4-6） |
| 组合层仓位裁决与再平衡 | `garp-portfolio-review`（P4-8） |
| 论文漂移检测（新旧论文对比） | `garp-thesis-drift`（P4-16） |
| 财报全文精读 | `garp-earnings-review`（P4-14）/ `garp-earnings-team`（P4-15） |
| 纯技术面体检（相对强度 / 均线破位） | `trend-momentum-scan`（复用 2 技能） |
| 买入前地缘 / 政策闸门 | `garp-geo-policy`（P4-1） |

## 二、适用口径与隔离声明

- **适用口径**：本技能属 **GARP 独立档（1~5 年，五大师）**，介于项目既有「1~3 年景气投资」与「10 年护城河投资」两档之间。
- **隔离声明**：
  1. 本技能**不引用** 1~3 年档位与 10 年档位的任何技能口径；五级卖出与它们的层级体系**物理隔离**；
  2. 估值水位**只来自** `garp-valuation`（P4-5，GARP 档）的**统一收口六档**，本技能零 PEG 算式；
  3. 五级编号为「**一级 ~ 五级**」，不使用其他档位的层级编号体系；
  4. 论文文件为 `-garp-thesis.md`，**与 1~3 年 / 10 年档论文文件物理隔离**、互不覆盖；
  5. 渗透率窗口为 **15%~40%**（GARP 档刻度），不使用其他档位刻度；
  6. 复用类技能仅限全档位通用的 2 个（`qoq-accelerator`、`trend-momentum-scan`），其出口转接见《证券AI中长期价值成长（GARP）投资研究工作步骤》§一·1.1。

## 三、命令与报告路径

```bash
/garp-thesis-tracker {公司名}              # 首次建档；已有论文则季度体检
/garp-thesis-tracker {公司名} 建立论文      # 强制重新建立 GARP 论文
/garp-thesis-tracker {公司名} 季度检查      # 基于最新财报与景气数据体检
```

> **本技能不提供档位切换参数**——它即 GARP 独立档专属入口；档位切换类口令属 1~3 年中期链，出现即违 `GT-15`。

**报告输出**：

```
reports/{公司名}/{公司名}-garp-thesis.md                      # 论文活文档（固定文件名，持续追加）
reports/{公司名}/{公司名}-garp-track-{YYYYMMDD}.md            # 季度体检报告（文件名含检查日期）
```

**三档并存**：同一标的若已有 1~3 年 / 10 年档论文，本技能**只提示不修改**，三份论文分别维护。

## 五、快速示例（最小可用调用）

### 例 1：首次建立 GARP 论文

```bash
/garp-thesis-tracker 新易盛 建立论文
```

执行要点：

```bash
# 0) 日期基准
date

# 1) 财务数据（含季报先行指标）

# 2) 行情与技术面
python tools/a_share/stock_quote.py --code 300502 --momentum

# 3) 精确算术（禁心算）
python tools/common/financial_rigor.py calc --expr "..."

# 4) 只读上游结论（估值档位 / 治理评分 / 五级定义）
#    reports/新易盛/新易盛-garp-valuation-{YYYYMMDD}.md
#    reports/新易盛/新易盛-garp-management-{YYYYMMDD}.md
#    garp-exit（P4-6）五级定义

# 5) 景气 / 渗透率
python tools/common/anysearch.py "光模块 渗透率 订单" --count 10 --zone cn
```

产出：`reports/新易盛/新易盛-garp-thesis.md`（核心论文五问 + 五大师假设清单 + 五级检查表 + 六档估值锚点 + 空追踪记录表）。

### 例 2：季度体检

```bash
/garp-thesis-tracker 新易盛 季度检查
```

执行要点：读活文档 → 补最新数据 → 逐条验证假设（含**连续 3 季趋势判定**）→ 一级→五级依次检查（**命中即停**）→ 估值水位三级更新 → 健康度计分 → 输出 `-garp-track-{YYYYMMDD}.md` → 回写追踪记录表。

## 六、五级速查卡 + 补充机制

| 优先级 | 触发 | 动作 | 命中扣分 |
| --- | --- | --- | :--: |
| **一级** | 管理层失信 / 财务造假实锤 / 监管立案 | **立即清仓**（不看估值与趋势） | **直判 1 分** |
| **二级** | 单笔亏损 **8%~10%** 且无明确基本面反转信号 | **止损离场** | -5 |
| **三级** | 连续 **2 季**低于预期且景气未改善 / 财务不可逆恶化 / 龙头被颠覆·科研转化大幅低于预期 / **评分跌破 10 分** | 前三者减仓或清仓；评分项降观察仓 / 减仓 | -4 |
| **四级** | ① 渗透率·ROE 拐点但**景气尚可、仅节奏放缓**（40%~60% 兑现期）；② **增速归零 / 转负** | ① 减机动仓（底仓不动）；② 升级逻辑恶化、清仓 | -3 |
| **五级** | ① 调整后 PEG **> 1.5**（> 2 严重透支）；② 市场情绪多信号共振 | 底仓不动，机动仓调整 | -2 |

**【补充机制（不占优先级，兜底 / 优化动作）】**

| 机制 | 触发 | 动作 | 频次 |
| --- | --- | --- | --- |
| **时间止损** | 持有满 **4 个季度**逻辑仍未兑现（**仅限"逻辑未兑现"的仓位**） | 减至观察仓 / 替换 | — |
| **性价比替换（末位优化）** | 其他标的估值显著更低且产业趋势更强 | 逐步切换 | **每季度最多 1 次** |

**【命中即停】** 任何一级命中 → 立即停止后续检查，报告标「**检查终止**」，未检查级别标「**未检查**」（不得标「未触发」）。

## 七、风控硬编码摘要（GT-1 ~ GT-15）

| 编号 | 一句话约束 |
| --- | --- |
| GT-1 | **诚信闸门前置**：命中 → **直判 1 分**，禁止进入假设求和 |
| GT-2 | 五级优先级固定；**命中即停**；不得被低优先级覆盖 |
| GT-3 | 估值档位**只读不重算**（取 P4-5 结论）；报告零 PEG 算式 |
| GT-4 | 卖出级别**只读不重定义**（取 P4-6 结论） |
| GT-5 | 论文文件**物理隔离**：只读写 `-garp-thesis.md` / `-garp-track-*` |
| GT-6 | 扣分表与假设维度**不得自造**；假设不得少于 2 维 |
| GT-7 | **连续 3 季趋势判定**：单季波动不判拐点 |
| GT-8 | **时间止损独立于五级**（与五级并列），仅针对"逻辑未兑现"的仓位 |
| GT-9 | **不出绝对仓位数值**（唯一例外：观察仓 = 原仓位 30%~50%，归 P4-6 口径） |
| GT-10 | 渗透率窗口 **15%~40%**（GARP 档刻度） |
| GT-11 | 管理层 7+7+6 / 科研 8+8+4 **只读**（取 P4-4 结论） |
| GT-12 | 地缘前置闸门**不入五级表**（买入前闸门，仅提示） |
| GT-13 | **不以宏观择时**：宏观只调估值容忍度与仓位尺度 |
| GT-14 | 生成日期 / 检查日期 / **数据截止日期**强制标注；关键财务双源交叉 |
| GT-15 | **运行时零引用中期 / 长期链**：只指向 `garp-*` 与复用 2 技能 |

## 九、常见误用提示

1. **诚信闸门是前置否决，不是扣分项**——命中即**直判 1 分**，不得进入「假设扣分 + 高级别扣分」的求和（`GT-1`）。
2. **命中即停后须标注「检查终止」**，未检查的级别标「未检查」（不得标「未触发」）。
3. **时间止损不占优先级**——与五级**并列**；不得用它覆盖已命中级别，也不得用它否定费雪式长期持有（框架行 504）。
4. **两个「底仓」语义是最高频误用点**——「单只标的最终仓位 50% / 已建立」与「组合层面股票仓位 60%~80%」不是一回事，报告涉及时须显式声明。
5. **估值档位与卖出级别都是"只读"**——本技能零 PEG 算式、零卖出阈值定义；发现上游结论异常应**提示复核**，不得自行修正（`GT-3`、`GT-4`）。
6. **「论文 / 假设 / 健康度」非框架原文**——属 1~3 年中期论文追踪技能骨架继承 + 本技能操作化产物；框架分散锚点为行 41 / 114 / 520 / 536。报告须带模板脚注。
7. **「未验证」不等于「成立」也不等于「破裂」**——不计入扣分但必须列出；**未验证假设 ≥3 条**时报告须声明「本次体检置信度不足」，健康度标为「参考值」。
8. **渗透率 15%~40% 是 GARP 档刻度**——不得沿用其他档位刻度，也不得因「赛道特殊」自行放宽（`GT-10`）。
9. **不以宏观择时**——结论段不得出现「因宏观进入 X 期故清仓」类表述（`GT-13`）。
10. **美股取数硬约束**——`tools/us_stock/stock_quote.py` **无 `--code` 参数**，代码一律以 `--daily {代码}` 传入，且 `--momentum` **必须配合 `--daily`** 使用。
