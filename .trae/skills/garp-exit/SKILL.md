# GARP 卖出信号：五级优先级 + 补充机制 + 衰退清单 + ATR 动态止损（1~5 年独立档）

对 $ARGUMENTS 执行《中长期价值成长（GARP）投资框架》**第三部分·三（卖出规则）**、**·四（暂时性困难 vs 永久性衰退）**、**·五（止损纪律）**的纪律化落地，并承接**第五部分·二·决策优先级金字塔**与**第六部分·一页纸操作备忘卡（卖出段）**，回答一个问题：

> **这只标的现在该不该卖？该按什么级别、什么动作处置？**

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。** 五级优先级与全部阈值**硬编码**，AI 不得自由裁量；ATR 止损价**一律调用 `momentum.stop_price()`**，估值档位**一律读取 `garp-valuation` 结论**；本技能只做**优先级编排、证据收口、动作输出与下游转接**，全程**禁止 LLM 心算、禁止自造阈值**。

>  **费雪式提醒**："如果一家公司在诚信问题上不合格，无论其他标准得分多高，我永远不会考虑这只股票。"——诚信是唯一的、真正的一票否决。
>
> 💬 **林奇式提醒**："连续两个季度不及预期就要问：这是暂时的，还是生意本身变了？六种情形都对照过了，答案自己会浮出来。"
>
> 💬 **郑希式提醒**："增速二阶导转负，比渗透率数字更早报警；但渗透率还在加速区、只是节奏放慢，那是减机动仓的问题，不是清仓的问题。"
>
> 💬 **李进式提醒**："增速归零或转负，就是增长见顶——这与渗透率停在哪个位置无关，独立触发清仓。"
>
>  **欧奈尔式提醒**："先活下来，再谈收益。底仓未建立前，止损是第一位的；8%~10% 这条线，忘掉你的买入成本。"

## 设计理念与定位

GARP 框架第三部分的核心观点是：**卖出不是一个动作，而是一个有严格先后顺序的判断链**（框架行 474~475）。框架把卖出触发按优先级从高到低排成五级，并明确此排序与**第五部分·二·金字塔**（行 651~661）及**第六部分·备忘卡卖出段**（行 788~796）**完全一一对应**（框架行 475）。本技能把这套链条做成**逐级检查、命中即停、禁止跳过一级**的硬编码流程，并补齐框架特有的三类结构：

1. **优先级就是纪律**——"先保命（止损/防造假），再谈收益（景气/估值）"（框架行 665）。高优先级触发即停，**不得**被低优先级覆盖，**不得**跳过一级。
2. **补充机制不占优先级**——框架在**三处独立位置**（行 475 的结构声明、行 502、行 798）明确「时间止损」与「性价比替换」属**补充机制（不占优先级，兜底/优化动作）**。它们**不是**第六级，而是与五级**并列**、仅在五级**全不触发**时执行的兜底动作。
3. **下跌未必是坏事，但必须证明它是「暂时性」**——费雪最擅长的，是在杰出企业遭遇暂时性困难时逆势加仓；但"并非所有下跌都是暂时性困难，有些是永久性衰退"（框架行 509）。故深跌必须过**六个判断维度**的清单复核，且永久性衰退**无论盈亏立即清仓**（框架行 520）。

### 本技能的四条硬纪律

| # | 纪律 | 原因 |
| --- | --- | --- |
| 1 | **优先级固定、命中即停、禁止跳过一级** | 高优先级场景被低优先级覆盖 = 纪律失效（`GX-1` / `GX-2`） |
| 2 | **阈值硬编码，AI 不得裁量** | 8%~10%、4 个季度、调整后 PEG 1.5/2.0、20% 封顶全部写死（`GX-3` / `GX-4`） |
| 3 | **ATR 止损价必须调工具** | 心算 ATR 会引入不可审计的误差；`stop_price()` 用全精度链计算（`GX-5`） |
| 4 | **只出动作方向与级别，不裁量仓位数值** | 组合层仓位裁决归 `garp-portfolio-review`（P4-8）；避免双源冲突（`GX-10`） |

## 边界声明（本技能的核心约束）

1. **不做买入决策**——建仓节奏、分批建仓、能力圈与买入门槛判定一律归上游技能；本技能以"**已持仓**"为前提（`GX-14`）。
2. **不做估值档位判定**——调整后 PEG、隐含 PEG、EV-Sales、Rule of 40、DCF 的算数与档位归 `garp-valuation`（P4-5）；本技能**只读其结论**（`GX-9`）。
3. **不做组合层仓位裁决**——单只 10%/15%/20%、行业 40%、相关性 <0.5、流动性 >1 亿、再平衡 ±5% 归 `garp-portfolio-review`（P4-8）。本技能**报告中不得出现**"目标仓位 X%""减至 X%"（`GX-10`）；唯一例外为「**观察仓 = 原仓位的 30%~50%**」，它相对**标的自身原仓位**、非组合层数值，且**框架未显式定义**（详见「补充机制」节）。
4. **不做管理层评分**——7+7+6 与 8+8+4 计分归 `garp-management`（P4-4）；本技能只读结论并转接为触发。
5. **不判定地缘前置闸门**——0.3 三维矩阵与回避档归 `garp-geo-policy`（P4-1），且属**买入前**闸门，**不进入**本技能五级表（框架行 663）。
6. **不以宏观择时**——宏观只调节估值容忍度与仓位尺度，"不是择时清仓的依据"（框架行 685）；本技能不调用宏观参数。
7. **不新增工具、不建聚合器**——本技能是**编排层**；ATR 计算链保持 `momentum.py` 无 CLI 现状，不新增命令行包装。

> **范围自查**：本技能若出现「跳过诚信检查 / 低级别覆盖高级别 / 8%~10% 被放宽 / ATR 幅度突破 20% / ATR 止损价心算 / 时间止损被并入某一级 / 输出目标仓位数值 / 重算 PEG / 用宏观做清仓理由」，即为越界。

## 执行流程（八步）

### 第一步：确认参数与数据基准

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `{标的}` | 公司名或代码 | 必填 |
| `--buy-date` | 买入日期（时间止损与持有期计算） | 读论文；无则跳过时间止损 |
| `--buy-price` | 买入价（硬止损与 ATR 止损） | 读论文；无则跳过二级 |
| `--final-position` | 该标的**最终目标仓位**（判「建仓初期」） | 读论文；**无则按最保守口径视为建仓初期** |
| `--current-position` | 当前仓位（判是否已达最终仓位 50%） | 读论文 |
| `--mode` | `daily` / `quarterly` | `quarterly` |
| `--as-of` | 数据截止日期 | 当日 |

> **强制**：报告头部须注明**检查日期**与**数据截止日期**（`GX-13`）。

### 第二步：装配输入

按「关键口径引用表」与「工具使用指南」收集：持仓参数、`-garp-thesis.md`、`garp-valuation`（P4-5）估值档位、最新财报（双源）、治理与舆情线索、动量/ATR 数据、景气结论。

**缺失项须逐条登记**，并在第三步起按「数据缺失处理」节跳过对应层级。

### 第三步：一级 诚信否决（强制前置，不计分）

任何输入都必须先过一级检查（`GX-2`）。见「一级 诚信否决」节。

### 第四步：二级 硬止损（先判仓位状态，再决定是否用 ATR）

先按「建仓初期」双条件判定仓位状态，再选路径：建仓初期 → 8%~10% 硬止损（**禁用 ATR**）；底仓已建立且逻辑已验证 → 调 `momentum.stop_price()` 得 ATR 止损价并施加 **20% 封顶**。见「二级 硬止损」节。

### 第五步：三级 逻辑止损

四条触发逐条取证。见「三级 逻辑止损」节。

### 第六步：四级 产业景气判断

两条触发，其中第②条为**独立清仓触发**。见「四级 产业景气判断」节。

### 第七步：五级 估值判断

读 `garp-valuation` 档位 + 市场情绪多信号共振判定。见「五级 估值判断」节。

### 第八步：补充机制 + 收口输出

五级**全不触发**时执行补充机制两项（时间止损 / 性价比替换）；若触发深跌条件（自买入价下跌 >20%，或已脱离建仓初期而深跌），**强制**跑「暂时性困难 vs 永久性衰退」清单复核；最后输出动作明细与报告。

> **命中即停**：第三~七步中任一触发，输出该级动作并**终止**后续级别检查，报告中标注「检查终止」（未检查的级别标注「未检查」，**不得**标注「未触发」）。

## 五级卖出优先级映射表（唯一权威口径，硬编码）

| 级别 | 触发条件 | 决策 | 思想来源 |
| --- | --- | --- | --- |
| **一级 诚信否决** | 管理层诚信问题暴露、财务造假实锤、监管立案 | **立即清仓**，不看估值与趋势，不找任何理由 | 费雪（诚信一票否决） |
| **二级 硬止损** | 单笔亏损达 **8%~10%** 且无明确基本面反转信号 | **止损离场** | 欧奈尔 |
| **三级 逻辑止损** | ① 连续 **2 个季度**业绩低于预期**且**产业景气未改善；② 财务出现不可逆恶化（应收账款暴增 / 存货高企 / 现金流持续为负）；③ 龙头地位被颠覆、科研转化大幅低于预期；④ 管理层或科研转化评分**跌破 10 分**（非诚信事项） | ①②③ **减仓或清仓**；④ **降观察仓 / 减仓** | 林奇 + 郑希 |
| **四级 产业景气判断** | ① 渗透率 / ROE 出现拐点，但**景气尚可、仅节奏放缓**（如进入 40%~60% 逐步兑现期）→ 减机动仓、降仓位；② **增速归零 / 转负**（增长见顶）→ **升级为逻辑恶化、清仓**（独立触发，与渗透率位置无关） | ① **减机动仓**；② **清仓** | 李进 + 郑希 |
| **五级 估值判断** | ① 调整后 PEG **> 1.5** → 减机动仓；**> 2** 为严重透支 → 加速清机动仓；② 市场情绪极度狂热（两融余额骤增 / 换手率持续高位 / 成交额创新高 / 新开户激增等**多信号共振**）→ 减机动仓，多项共振时加速清机动仓 | **底仓不动，机动仓调整** | 林奇 |

## 硬编码执行规则

1. 检查顺序**固定**为 一级 → 二级 → 三级 → 四级 → 五级；
2. **命中即停**：输出命中的**最高**级别及对应动作，**不得**继续检查更低级别，**不得**被低优先级覆盖；
3. **禁止跳过一级**：任何输入都必须先过诚信否决检查；
4. 硬止损 **8%~10% 为硬性区间**，AI 不得放宽或收紧（`GX-3`）；
5. ATR 止损价对应的亏损幅度由 **20% 底仓容忍度封顶**，ATR 只能精化节奏（`GX-4`）；
6. **补充机制不占优先级**，与五级并列，不得覆盖已命中级别（`GX-6`）；
7. 技术面信息**仅作四级辅助确认**，不单独构成优先级层级（`GX-11`）。

**一票否决的语境边界（框架行 663，硬编码）**：

> 本技能"一级 诚信否决"针对**持仓后**的清仓信号；买入前闸门（0.3 三维交叉矩阵回避、能力圈自检未通过、ROIC<5% 扩产等）属**买入前**判定，命中即在建仓前放弃、**不进入**本技能五级表（持仓后卖出表）。两类"否决"语境不同，**报告中不得混用同一措辞**。

## 二级 硬止损

### 第一步：判定仓位状态（「建仓初期」完整定义，框架行 530 / 行 538，逐字固化）

> **「建仓初期」** 指：①**持仓 < 最终仓位的 50%**；**或** ②**持仓 ≥ 50% 但逻辑尚未经 2~3 个季度财报持续兑现验证**（如右侧一次性建 2/3 后、财报尚未兑现期间）。**两者任一成立**即适用 8%~10% 硬止损，而非仅看"<50%"这一个数字。

| 仓位状态 | 判定 | 止损路径 |
| --- | --- | --- |
| **建仓初期** | 持仓 < 最终仓位 50% **或** 逻辑未经验证 | **8%~10% 硬止损**，**禁用 ATR** |
| **底仓已建立且逻辑已验证** | **同时满足** ①持仓 ≥ 最终仓位 50% **且** ②逻辑经 2~3 季财报兑现验证 | **2~3 × ATR(14) 动态跟踪止损**，受 **20% 封顶** |

> **两个"底仓"语义不得混用（`GX-12`）**：此处"底仓已建立"指**单只标的**达到最终仓位的 50% 且逻辑已验证，**非**组合层面的"股票仓位 60%~80% 底仓"。报告中必须显式声明该区分。

### 第二步：按路径判定

| 仓位状态 | 决策规则（框架行 534~536） |
| --- | --- |
| **建仓初期** | 若下跌超过 **8%~10%**，按欧奈尔规则**止损离场**，保护本金 |
| **底仓已建立且逻辑已验证** | 自买入价下跌 **≤ 20%** 且产业逻辑、科研转化（科技股）、管理层、财务等维度**均未恶化** → 可在**合理估值下限附近加仓**；下跌 **> 20%** → **不自动加仓**，转入「暂时性困难 vs 永久性衰退」清单复核（**封顶生效时**触及有效止损价恒等于达到 20% 门槛 → 一律**先跑清单复核再定动作**，见第三步规则 9） |
| **无论何种状态，逻辑被证伪** | **立即清仓**，不存在"越跌越买" |

**止损分水岭（框架行 538，逐字固化）**：须**同时满足**『①达到最终仓位的 50%』与『②逻辑经 2~3 季财报兑现验证』**两个条件**，缺一仍按建仓初期 8%~10% 执行。

### 第三步：ATR 动态止损（仅在「底仓已建立且逻辑已验证」路径启用）

**计算公式（框架行 469）**：

```
止损价 = 买入价 −（2~3）× ATR(14)
TR = max(当日最高 − 当日最低, |当日最高 − 昨收|, |当日最低 − 昨收|)
```

**调用规则（硬编码，`GX-5`）**：

```python
from tools.common import momentum

res = momentum.stop_price(highs, lows, closes, entry_price=买入价, multiplier=2.0)
# res == {"atr14": ..., "stop_price": ..., "stop_pct": ...}
```

| # | 规则 |
| --- | --- |
| 1 | `momentum.py` **无 CLI**，一律以**内联 Python 模块调用**方式使用；**禁止**用公式心算 |
| 2 | 报告须**逐字贴出** `atr14` / `stop_price` / `stop_pct` 三个原始字段 |
| 3 | `multiplier` 取 **2~3**（框架区间）；**取值须先按「第四步」波动分档确定档位**——中波动取 **2.0**、高波动可在 **2.0~3.0** 内取但须说明理由；报告须标注**实际取用值**与档位依据 |
| 4 | `stop_price()` 返回的是**原始**止损幅度——它**不做 20% 封顶、不做仓位状态分档**，该判断**由本技能完成** |
| 5 | **20% 封顶**：若 `stop_pct > 20`，结论幅度**取 20%**（即"ATR 只能精化跟踪节奏，不能突破 20% 底仓容忍度"，框架行 471），并在报告中留痕"封顶已生效"。**封顶后有效止损价 = 买入价 × (1 − 20%)**；报告须**并列**呈现「原始 `stop_price`（**未封顶参考值**）」与「**封顶后有效止损价**」 |
| 6 | **交叉校验**：用三市场 `stock_quote.py --momentum` 输出的 `atr14` 独立复核；**不一致时以 `stop_price()` 为准**并并列留痕差异（详见「工具使用指南」） |
| 7 | **数据不足**（有效 TR 样本 < 14+1 根 K 线）→ 三字段为 `None` → **回退 8%~10% 硬止损口径**并标注"ATR 未取得"；**不得**用其他窗口近似 |
| 8 | **低波动豁免（`GX-15`）**：波动刻度 `k` **< 8%** → **不使用 ATR**，一律按 **8%~10% 硬止损**执行（**底仓路径下亦然**）；依据为框架行 472 **明示规则**；`k` 的取数口径见「第四步」 |
| 9 | **封顶后的动作顺序**：`k` **> 20%** → 封顶必然生效 → 触及有效止损价**等于**达到 20% 门槛 → **先跑「暂时性困难 vs 永久性衰退」清单复核，再按清单结论定动作**；**不得**仅凭跌幅直接下卖出结论 |

### 第四步：波动分档与 `multiplier` 选取（框架行 472 **明示规则** + **本技能操作化刻度**）

框架行 472 明示「**低波动股直接用 8%~10% 硬止损**」，但**未给出波动阈值**。本技能固定如下操作化刻度，**报告中须标注该刻度为"本技能操作化刻度、非框架原文"**。

**波动刻度 `k`（唯一取数口径）**：

```python
k = momentum.stop_price(highs, lows, closes, entry_price=买入价, multiplier=2.0)["stop_pct"]
```

> `k` **一律直接读**工具在 `multiplier=2.0` 下的 `stop_pct`；**禁止**用 `round(atr14, 2) × 2 ÷ 买入价` 反推——实测反推得 **5.54**，而工具给 **5.53**，存在分位差。

| 档位 | 判定（按 `k`） | 是否使用 ATR | `multiplier` | 有效止损幅度 | 依据 |
| --- | --- | --- | --- | --- | --- |
| **低波动** | `k` **< 8%** | **否** | — | **8%~10% 硬止损**（**底仓路径下亦然**） | 框架行 472 **明示** |
| **中波动** | **8% ≤ `k` ≤ 20%** | 是 | **2.0** | `k`（封顶未生效） | 框架行 470 区间取下限 |
| **高波动** | `k` **> 20%** | 是 | **2.0~3.0**（波动越高越靠上限，须说明理由） | **20%**（封顶生效） | 框架行 470~472 |

**判定顺序（硬编码）**：**先**算 `k` → **再**定档 → **最后**决定是否使用 ATR 及 `multiplier` 取值。**不得**先取 `multiplier=3.0` 再回头论证档位。

**两个 20% 的角色区分（防混用）**：

| 20% 的角色 | 含义 | 适用对象 |
| --- | --- | --- |
| **ATR 幅度封顶上限** | ATR 跟踪止损价最多只能离买入价 20% | 中波动 / 高波动（**低波动档不使用 ATR，故不涉及**） |
| **底仓容忍度门槛** | 自买入价下跌 **> 20%** → 不自动加仓 + 转清单复核 | **全部档位**（含低波动） |

### 关于「有明确基本面反转信号」的操作化口径（**本技能操作化，框架未定义**）

框架只写"无明确基本面反转信号"（行 483 / 行 524），**未给判定清单**。本技能固定如下口径，且**报告中必须标注其为"本技能操作化刻度、非框架原文"**：

出现以下**任 ≥2 项**并经证据核实，视为「**有明确基本面反转信号**」，此时二级**不触发**（但三级/四级仍须继续检查）：

1. 最新财报营收与扣非净利增速**拐头向上**且超市场一致预期；
2. 在手订单 / 合同负债**环比显著回升**；
3. 毛利率与经营现金流**连续两期改善**；
4. 产业景气指标（渗透率二阶导、ROE）**重新上行**；
5. 管理层/科研转化评分（P4-4）**回升至 15 分以上**。

> 证据不足 2 项 → **视为"无明确基本面反转信号"**，二级按 8%~10% 触发（**从严处置**，与"先活下来"原则一致）。

## 三级 逻辑止损

### 子项 A（连续 2 个季度业绩低于预期且产业景气未改善）

| 检查维度 | 触发条件 |
| --- | --- |
| 营收增速 | 连续 2 季低于买入时预期增速的 50% |
| 扣非净利润 | 连续 2 季放缓或为负 |
| 合同负债 / 订单 | 环比连续 2 季下降 > 10% |
| 产业景气交叉 | 行业景气同步下行（**且未改善**，与四级联动判定） |

**连续 3 季度趋势判定**（区分波动与拐点）：

- 连续 3 季**加速** → 不触发；
- 单季放缓 + 全年预期不变 + 渗透率仍处加速区 → **短期波动**，不触发本子项，仅调机动仓（并入四级第①条）；
- 连续 2~3 季**减速** + 订单增速同步放缓 + 竞争加剧 → **趋势拐点**，**触发本子项**。

### 子项 B（财务不可逆恶化）

应收账款暴增、存货高企、现金流持续为负（框架行 488）。三项须**分别取证并给出连续期数**，不得以单季波动定性"不可逆"。

### 子项 C（龙头地位被颠覆 / 科研转化大幅低于预期）

框架行 489。须给出**可量化证据**（市占率趋势、客户续费率/NPS、专利与新产品收入占比、重大科研项目进展延后情况）。

### 子项 D（评分跌破 10 分，非诚信事项）

读取 `garp-management`（P4-4）结论：**管理层或科研转化评分跌破 10 分** → **降观察仓 / 减仓**（框架行 490）。

> ⚠️ **来源必须区分**：诚信事项走**一级**（立即清仓），评分 <10 走**二级以外的三级子项 D**（降观察仓/减仓）。报告中**不得混用同一措辞**（框架行 490 括注 + 行 663）。

## 暂时性困难 vs 永久性衰退判断清单

> **强制触发情形**：① 自买入价下跌 **> 20%**（框架行 535）；② 已脱离"建仓初期"而出现深跌。其余情形按需展开。
>
> **逐维度留痕（`GX-7`）**：六个维度**逐条给出证据与数据来源**，未取证维度标「**未判定**」并计入不确定性；**禁止**一句话概括或只挑有利维度。

| 判断维度 | 暂时性困难（**可加仓**） | 永久性衰退（**需清仓**） |
| --- | --- | --- |
| **行业需求** | 需求延迟，但长期趋势未变 | 需求被替代品**永久性**替代 |
| **竞争格局** | 份额短期波动，但优势仍在 | 份额**持续流失**，护城河消失 |
| **财务** | 现金流短期承压，但资产负债表健康 | 现金流**持续为负**，债务恶化 |
| **管理层** | 承认问题，有清晰应对方案 | 推卸责任，频繁更换高管 |
| **研发** | 研发投入维持或增加 | 研发投入**持续削减** |
| **客户** | 客户流失是暂时性的，可挽回 | 核心客户**永久性**转向竞争对手 |

**使用规则（框架行 520，硬编码）**：

1. 判为「**暂时性困难**」，**且**产业逻辑、科研转化（科技股）、管理层、财务等维度**均未恶化** → 可在**合理估值下限附近加仓**；
2. 判为「**永久性衰退**」→ **无论盈亏立即清仓**（`GX-8`：与一级同为准出动作，**不得**以"估值便宜""等反弹"为由延后）；
3. 判定须给出**证据链**；六个维度中若"永久性衰退"列命中 **≥2 项**，即判**永久性衰退**；若命中 1 项且其余为"暂时性困难"或"未判定" → **判证据不足，计入不确定性并向用户明示**，**不得**擅自加仓。

## 费雪「不卖」的适用边界（框架行 632~649、行 796）

**核心原则**：**费雪的"不卖"是"认知深度的奖赏"，不是"懒惰不研究的借口"**（框架行 649）。**普通人只对极少数真正杰出的标的适用"不卖"，其余持仓一律服从止损与景气纪律。**

「不卖」**须同时满足**以下前提（缺一不可，框架行 640~643）：

1. **极度深研的认知深度**（费雪式闲聊法 + 质化分析已完整执行）；
2. **极度集中的持仓**（费雪"不卖"建立在只重仓 3~5 只、占总仓位 70% 的极致集中之上）。

**处置**：

- **同时满足**上述前提 + 管理层诚信 + 护城河稳固 + 财务健康 + 下跌属**暂时性困难** → 可采纳"不卖"逻辑，用本清单判断后**继续持有甚至加仓**；
- **任一前提不满足**，或下跌属**永久性衰退** → **按五级与补充机制纪律处置**（离场 / 调仓）。

> **报告留痕要求**：报告中若引用"不卖"结论，须**逐条列出两个前提的满足证据**；**不得**仅凭"长期看好"表述援引。

### 实测已知约束（务必遵守，2026-09-17 核对）

1. **`momentum.py` 无 CLI**——无 argparse、无 `__main__`、无 `--stop-price` 参数。**只能**以 `from tools.common import momentum` 内联调用；本技能**不新增**其命令行包装（属编排层，不建聚合器）。
2. **`stop_price()` 不做封顶、不做分档**——其 docstring 明确：「本函数仅输出『原始』止损幅度，**不做 20% 底仓容忍度封顶，也不做 8%~10% 硬止损与仓位状态分档——该类判断由上层编排（P4-6）完成**」。故**封顶与分档是本技能的职责**。
3. **全精度 ATR 计算链**——`atr()` 返回 **2 位小数**，而 `stop_price()` **用全精度 ATR 计算止损价、最后才 round**（避免中间舍入误差）。因此交叉校验时**不得**用 `round 后的 atr14 × multiplier` 反推止损价——二者会有分位差。**止损价以 `stop_price()` 为准**。
4. **`multiplier` 默认 2.0**——框架区间为 2~3；取 3.0 时须在报告中说明（波动越高越靠上限）。`period` 固定 14、`method` 默认 `'wilder'`。
5. **`stop_price()` 的护栏**：`entry_price ≤ 0` 或 `multiplier ≤ 0` 或 ATR 为 `None` 时，返回 `{'atr14': …或 None, 'stop_price': None, 'stop_pct': None}`（**静默降级，不抛异常**）——须显式检查 `None` 并走「数据缺失处理」。
6. **三市场 `stock_quote --momentum` 只输出 `atr14`，不含 `stop_price`**——`stop_price` 只能由 `momentum.stop_price()` 得到。
7. **`financial_rigor.py` 无 `--json`**——结构化结果以**末行**「`结构化输出: {...}`」呈现，解析时取末行。
8. **`macro_calibrator.py` 在本技能中不使用**——卖出决策不以宏观为择时依据（框架行 685）；本技能**不调用**宏观工具。
9. **禁止使用 WebSearch / WebFetch**（中国大陆不可用），统一用本地搜索工具（`anysearch` / `doubao_search` / `exa_search` / `tavily_search` / `web_search`）。

## 风控硬编码（GX-1 ~ GX-15）

| 编号 | 规则 | 一句话约束 |
| --- | --- | --- |
| **GX-1** | **五级优先级固定** | 顺序固定 诚信→硬止损→逻辑→景气→估值；**命中即停**；不得被低优先级覆盖 |
| **GX-2** | **一级不可跳过、不可弱化** | 任何输入先过诚信检查；触发后**不得**输出「再观察一季」等弱化建议 |

| **GX-13** | **检查日期与数据截止日强制标注** | 持仓、价格、财报、情绪均为时变项，结论仅对截止日有效 |
| **GX-14** | **不做买入决策、不做组合裁决** | 边界声明；越界即违规 |
| **GX-15** | **低波动股不得使用 ATR** | 波动刻度 `k` < 8% → 一律 **8%~10% 硬止损**（底仓路径下亦然）；阈值为**本技能操作化刻度** |

## 注意事项

1. **命中即停后必须标注「检查终止」**，未检查的级别标「未检查」（**不得**标「未触发」）——否则会给人"五级全部排查过"的错误印象。
2. **两个「底仓」语义是最高频误用点**——单只标的的最终仓位 50% 与组合层面股票仓位 60%~80% 不是一回事，报告中必须显式声明（`GX-12`）。
3. **ATR 只在"底仓已建立且逻辑已验证"路径启用**——建仓初期一律 8%~10%，**不是**"两个都用、取更宽的"。
4. **20% 是容忍度上限，不是止损线**——它是"底仓在逻辑未变坏时可容忍的最大跌幅"，其处置是"**不自动加仓 + 转衰退清单复核**"，而非"到 20% 就无条件卖出"。在**高波动封顶生效**时，ATR 有效止损价恰落在 −20% 处，触及该价**同时**等于达到强制复核门槛 —— 此时须**先跑清单复核再定动作**，**不得**仅凭跌幅下结论。
5. **「有明确基本面反转信号」与「观察仓比例」为本技能操作化口径**（框架未定义），报告中须标注"本技能操作化刻度、非框架原文"。
6. **时间止损不得用于杰出企业**——框架明确它"仅针对逻辑未兑现的仓位"，与费雪式耐心持有不冲突（框架行 504）。
7. **费雪"不卖"须逐条举证两个前提**，不得仅凭"长期看好"援引（框架行 640~649）。
8. **一级检索无结果 ≠ 无风险**——须写"基于现有检索未触发"。
9. **不以宏观择时**——宏观只调估值容忍度与仓位尺度（框架行 685）；本技能不调用宏观工具。

## 局限性

1. **无法替代人工确认**——诚信类证据的**真实性**、衰退清单的**定性判断**最终仍需人工确认；本技能只保证**流程与留痕的完整性**。
2. **依赖上游技能结论**——估值档位、管理层评分、景气拐点均来自 `garp-*` 技能；上游结论有误将直接传导（本技能只做**一致性与留痕校验**，不重算）。
3. **数值阈值的粗糙性**——8%~10%、20%、4 个季度、调整后 PEG 1.5/2.0 都是框架给定的**区间与量级**，不构成精确择时工具。
4. **`garp-thesis-tracker`（P4-7）已交付**——在论文文件缺失期，买入日期/价格需命令行传入，时间止损与二级可能因数据缺失而跳过。
5. **A 股 / 港股 / 美股数据可得性差异**——治理类证据在美股（SEC filings）与 A 股（交易所公告）口径不同，跨市场结论不宜直接对比。
