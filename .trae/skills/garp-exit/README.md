## 一、技能用途

### 一句话定位

把《中长期价值成长（GARP）投资框架》**第三部分「持仓管理与操作纪律」**的卖出三节做成可执行技能：

**五级优先级硬编码检查（诚信否决 > 硬止损 8%~10% > 逻辑止损 > 产业景气判断 > 估值判断）→ 命中即停 → 五级全不触发则跑补充机制（时间止损 / 性价比替换）→ 触及深跌时强制走「暂时性困难 vs 永久性衰退」清单复核 → 输出动作方向与级别。**

### 何时用

- 已持仓标的的**卖出决策**（该不该卖 / 卖多少级别的动作）；
- 单笔亏损接近 **8%~10%**，需要判定止损路径（硬止损 / ATR 动态跟踪）；
- **连续 2 个季度**业绩不及预期，需要判定是波动还是逻辑拐点；
- 渗透率 / ROE 出现拐点，需要区分「节奏放缓」与「增长见顶」；
- 估值档位转差（调整后 PEG 越过 1.5 / 2.0）或市场情绪多信号共振；
- 自买入价**下跌 > 20%**，需要判「暂时性困难（可加仓）」还是「永久性衰退（立即清仓）」；
- 季度复盘 / 每周风控巡检。

### 何时不用

| 场景 | 应使用的技能 |
| --- | --- |
| 未持仓标的的买入判断 | `garp-investment-checklist`（P4-3）/ `garp-valuation`（P4-5） |
| 纯估值判断（贵不贵 / 建仓节奏） | `garp-valuation`（P4-5） |
| 纯技术面体检（相对强度 / 均线破位） | `trend-momentum-scan`（复用 2 技能） |
| 组合层仓位裁决与再平衡 | `garp-portfolio-review`（P4-8） |
| 论文漂移检测 | `garp-thesis-drift`（P4-16） |
| 买入前地缘 / 政策闸门 | `garp-geo-policy`（P4-1） |


## 六、五级速查卡（对应框架备忘卡「卖出」段）

| 优先级 | 触发 | 动作 |
| --- | --- | --- |
| **一级** | 管理层失信 / 财务造假实锤 / 监管立案 | **立即清仓**（不看估值与趋势，不找理由） |
| **二级** | 单笔亏损 **8%~10%** 且无明确基本面反转信号 | **止损离场**（建仓初期一律 8%~10%；底仓已建立且逻辑已验证 → 2~3×ATR，受 **20% 封顶**） |
| **三级** | 连续 **2 季**低于预期且景气未改善 / 财务不可逆恶化 / 龙头被颠覆·科研转化大幅低于预期 / **评分跌破 10 分** | 前三者**减仓或清仓**；评分项**降观察仓 / 减仓** |
| **四级** | ① 渗透率·ROE 拐点但**景气尚可、仅节奏放缓**（如进入 40%~60% 兑现期）；② **增速归零 / 转负** | ① **减机动仓**（底仓不动）；② **升级逻辑恶化、清仓**（独立触发） |
| **五级** | ① 调整后 PEG **> 1.5**（> 2 严重透支）；② 市场情绪多信号共振 | **底仓不动，机动仓调整** |

**【补充机制（不占优先级，兜底 / 优化动作）】**

| 机制 | 触发 | 动作 | 频次 |
| --- | --- | --- | --- |
| **时间止损** | 持有满 **4 个季度**逻辑仍未兑现（**仅限"逻辑未兑现"的仓位**） | 减至观察仓 / 替换 | — |
| **性价比替换（末位优化）** | 其他标的估值显著更低且产业趋势更强 | 逐步切换（先建新底仓、再清旧机动仓） | **每季度最多 1 次** |

**【永久性衰退判断】** 若行业需求被替代、护城河消失、研发持续削减 → **立即清仓**（无论盈亏）。

**【费雪"不卖"的适用边界】** 仅限极度深研的杰出企业；否则一律服从上述纪律。

## 九、常见误用提示

1. **命中即停后须标注「检查终止」**，未检查的级别标「未检查」（不得标「未触发」）。
2. **两个「底仓」语义是最高频误用点**——单只标的最终仓位 50% 与组合层面股票仓位 60%~80% 不是一回事。
3. **ATR 只在「底仓已建立且逻辑已验证」路径启用**——建仓初期一律 8%~10%，**不是**「两个都用、取更宽的」。
4. **20% 是容忍度上限，不是止损线**——其处置是「不自动加仓 + 转衰退清单复核」。
5. **时间止损不得用于杰出企业**——框架明确它仅针对「逻辑未兑现」的仓位。
6. **一级检索无结果 ≠ 无风险**——须写「基于现有检索未触发」。
7. **不以宏观择时**——本技能不调用宏观工具。
8. **低波动股不得套用 ATR**——波动刻度 `k` < 8% 一律 8%~10% 硬止损（`GX-15`）；ATR 幅度比硬止损下沿（8%）还窄时**不具增量价值**。
9. **封顶生效后不得用原始 `stop_price` 当止损线**——须取 **买入价 × (1 − 20%)**；原始 `stop_price` 仅作「**未封顶参考值**」并列呈现（二级·规则 5）。
