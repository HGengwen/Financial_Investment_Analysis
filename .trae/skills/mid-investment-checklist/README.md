# 中期投资检查清单 (mid-investment-checklist)

1~3 年景气投资买入前 Checklist：系统过一遍七关，排除坏选择。属于中期链（1-3 年）功能技能，与长期链（10 年 / `investment-checklist`）物理隔离。

---

## 快速开始

### 基本调用方式

```
/mid-investment-checklist {公司名}
```

支持单个或多个公司，用逗号/顿号/空格分隔。例如：

- `/mid-investment-checklist 新易盛`
- `/mid-investment-checklist 新易盛, 中际旭创, 天孚通信`

---

## 核心功能

对指定公司执行 1~3 年景气投资买入前 Checklist 分析，系统过一遍七关，排除坏选择，明确是否可以进入深度研究阶段。

### 七关速览

| 关卡 | 名称 | 评分 | 权威口径来源 |
|------|------|------|-------------|
| 第一关 | 产业赛道爆发潜力（渗透率坐标） | ★1-5 | V2.0 第 1 步 / `mid-industry-research` |
| 第二关 | 行业景气主升浪（ROE/增速/供需） | ★1-5 | V2.0 第 1 步 |
| 第三关 | 核心竞争力（1~3 年护城河视角） | ★1-5 | V2.0 第 2 步 |
| 第四关 | 管理层 × 科研转化（40 分制） | ★1-5 | V2.0 第 3 步 |
| 第五关 | PEG 估值与建仓 | ★1-5 | `valuation-thermometer`（引用） |
| 第六关 | 仓位管理与卖出触发 | ★1-5 | V2.0 第 4 步 / `exit-signal`（引用） |
| 第七关 | 地缘政治与外部环境 | 否决项 | V2.0 第 3 步 |

### 七步执行流程

1. **解析输入** — 识别所有待分析公司，确定上市交易所
2. **AI 研究偏见预警** — 信息丰富度评级 A/B/C，警惕「资料少 ≠ 看不懂」
3. **并行数据收集** — 每家公司启动独立 Agent，收集 10 项数据
4. **逐公司七关 Checklist** — 产业赛道→景气主升浪→护城河→管理层×科研→估值建仓→仓位卖出→地缘
5. **镜子测试** — 5 句话说不完整买入理由 = 不买
6. **快速否决清单** — 13 条红线，触发任意一条直接否决
7. **输出总览对比表** — 多公司时必须输出对比表

### 5 处口径对齐（与现有中期体系）

| 项 | 对齐方式 |
|------|---------|
| 卖出触发 | 统一引用 `exit-signal` 的 **P0~P5**（时间止损归入 P2），不内建 P0~P6 |
| 风控硬编码 | 采用 **MC-1~MC-10**（避免与 `mid-industry-research` 的 R-1~R-10 冲突） |
| PEG 估值档位 | **引用 `valuation-thermometer` 五档**，不重复定义 |
| 报告路径 | 嵌套 **`reports/{公司名}/{公司名}-mid-checklist-{YYYYMMDD}.md`** |
| 决策优先级 | 不内建速查卡，以 `exit-signal` 附录速查卡为准 |

## 使用示例

### 示例 1：单公司买入前检查

```
/mid-investment-checklist 新易盛
```

对新易盛执行七关 Checklist，输出评分表 + 镜子测试 + 明确结论。

### 示例 2：多公司对比筛选

```
/mid-investment-checklist 新易盛, 中际旭创, 天孚通信
```

三家公司并行数据收集，各自过七关，最后输出总览对比表。

## 输出报告

### 报告路径

| 报告类型 | 文件路径 |
|---------|---------|
| 单公司报告 | `reports/{公司名}/{公司名}-mid-checklist-{YYYYMMDD}.md` |
| 多公司对比 | 每家公司独立成文（各自路径），并在报告内附总览对比表 |

### 报告结构

每家公司独立成章，包含：

- 七关评分表
- 核心数据表（含景气数据）
- 关键风险（3-5 条，含地缘政治风险）
- 镜子测试（5 句话）
- 明确结论

### 最终结论四类

- ✅ **通过 Checklist**（X/7 关）— 可以进入深度研究阶段，按仓位纪律执行建仓
- ❌ **未通过 Checklist** — 说明哪条红线被触发
- ❓ **灰色地带** — 说明关键争议点，投资者需自行判断
- N/A — 未上市/无法买入

## 检查标准速览

### 渗透率坐标（第一关核心锚点）

| 渗透率区间 | 阶段定性 | 投资动作 |
| :--- | :--- | :--- |
| < 5% | 导入期/过早 | 回避 |
| 10% ~ 30% | 黄金爆发区 | 重仓出击 |
| 30% ~ 50% | 成长中后期 | 精选龙头 |
| > 50% | 成熟/衰退期 | 回避/减仓 |

### 管理层 × 科研转化（40 分制，第四关）

| 维度 | 分值 | 重仓线 |
|------|------|--------|
| 管理层（诚信/股东态度/战略/激励） | 20 分 | ≥15 分可重仓，10~14 分轻仓，<10 分回避 |
| 科研转化（研发投入/产出效率/资本回报） | 20 分 | ≥15 分可重仓，10~14 分轻仓，<10 分回避 |

### 仓位硬约束（第六关）

- 底仓 60%~80%，机动仓 20%~40%
- 单只初始 ≤10%、验证后 ≤15%、绝对 ≤20%
- 单一行业 ≤40%，持股 5~10 只
- 行业相关系数 <0.5

## 核心原则

1. **景气优先** — 1~3 年持有周期的核心是产业景气方向
2. **宁可错过，不可做错** — Checklist 的目标是排除坏选择
3. **诚实面对能力圈** — 看不懂就说看不懂
4. **安全边际是生命线** — 好公司买贵了也会亏钱
5. **镜子测试不可跳过** — 说不清楚理由就不买
6. **杀估值可逆向，杀逻辑必须止损** — 1~3 年框架的第一铁律
7. **数据必须精确计算** — 估值指标用 `financial_rigor.py`，禁止心算

---

## 注意事项

- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- 关键财务数据必须至少来自两个独立来源进行交叉验证
- 所有估计值必须明确标注「估计」
- 市值必须手算校验：股价 × 总股本
- 所有评分必须使用 ★ 符号（★1-5），不含半星
- 数据必须标注来源时间，报告头部必须明确标注数据截止日期
- 估值档位、卖出触发、行业景气数据的口径分别以 `valuation-thermometer`、`exit-signal`、`mid-industry-research` 为准
