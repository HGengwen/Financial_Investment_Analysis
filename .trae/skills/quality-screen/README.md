# 去劣筛选 (Quality Screen)

7条指标快速排除非一流公司：不错杀任何一流好公司，但能排除确定的非一流公司

---

## 快速开始

### 基本调用方式

```
/quality-screen {公司名/行业/指数/主题}
```

支持四种输入格式：

| 输入方式 | 示例 | 说明 |
|---------|------|------|
| 个股 | `/quality-screen 腾讯, 美团, 英伟达` | 逐家筛选 |
| 行业 | `/quality-screen 中国啤酒行业` | 搜索行业主要公司（10-20家）后逐家筛选 |
| 市场/指数 | `/quality-screen 恒生指数成分股` | 拉取成分股列表，逐家筛选 |
| 主题 | `/quality-screen 全球AI算力链` | 搜索主题相关公司，逐家筛选 |

例如：
- `/quality-screen 腾讯`
- `/quality-screen 中国啤酒行业`
- `/quality-screen 沪深300`

---

## 核心功能

对指定公司/行业/指数/主题执行去劣指标筛选，通过7条硬指标 + 3条豁免规则，快速排除不符合一流公司标准的标的。

### 7条去劣指标

| # | 指标 | 排除条件 | 衡量的是什么 |
|---|------|---------|-------------|
| 1 | 10年平均ROE | < 8% | 资本效率——股东的钱能不能跑赢机会成本 |
| 2 | 5年累计自由现金流 | 为负 | 真金白银——利润是不是"纸面富贵" |
| 3 | 利息覆盖倍数（EBIT/利息） | < 2倍 | 偿债安全——还利息的能力 |
| 4 | 长期毛利率 | < 15% | 定价权——产品/服务有没有差异化 |
| 5 | 经营现金流/净利润（5年均值） | < 0.7 | 利润质量——赚到的利润能不能收回现金 |
| 6 | 长期净利率 | < 5% | 抗风险能力——收入波动时利润是否归零 |
| 7 | 5年总股本膨胀 | > 20%（非并购原因） | 股东利益——管理层是否在稀释你的权益 |

### 3条豁免规则

- **豁免A：战略投入期豁免**（适用于第1条）— 上市不足10年、毛利率>30%、近2年经营现金流为正
- **豁免B：主动低利润率豁免**（适用于第6条）— 毛利率>30%、近2年净利率回升至5%以上或呈上升趋势
- **豁免C：高周转薄利模式豁免**（适用于第4条和第6条）— ROE>20%、经营现金流/净利润>1.0、商业模式属于"会员制/平台佣金/高周转薄利"

### 四步执行流程

1. **解析输入，确定筛选范围** — 判断个股模式或批量模式
2. **数据收集** — 为每家公司收集7项指标所需数据
3. **逐条检验** — 逐条检验7个指标（✅通过 / ❌未通过 / ⚠️边界），触犯时检查豁免条件
4. **输出结果** — 生成汇总表 + 通过/排除/豁免分类 + 板块总结

## 使用示例

### 示例1：个股筛选
```
/quality-screen 腾讯, 美团, 英伟达
```
逐家筛选这三家公司，输出每家的7条指标检验结果。

### 示例2：行业筛选
```
/quality-screen 中国啤酒行业
```
搜索该行业市值前15-20家上市公司，逐家筛选，额外输出通过率统计、行业内排名、板块对比总结。

```

```

## 输出报告

报告将保存在以下位置：

| 报告类型 | 文件路径 |
|---------|---------|
| 个股筛选 | `reports/quality-screen/{公司名}-quality-screen-{YYYYMMDD}.md` |
| 行业筛选 | `reports/quality-screen/{行业名}-industry-screen-{YYYYMMDD}.md` |
| 指数筛选 | `reports/quality-screen/{指数名}-index-screen-{YYYYMMDD}.md` |
| 主题筛选 | `reports/quality-screen/{主题名}-theme-screen-{YYYYMMDD}.md` |

### 报告结构

```markdown
# 去劣筛选结果
**筛选日期**：{当天日期}
**公司数量**：{N}家

## 汇总表（公司/交易所/板块/上市日期/7条指标/结果）
## 通过的公司（N家）
## 排除的公司（N家）— 触犯指标 + 具体数据 + 排除理由
## 豁免通过的公司（N家）— 豁免条款 + 具体数据 + 豁免理由
## 边界争议（如有）— 对处于阈值附近的公司做补充说明
## 板块总结（行业/市场模式专用）— 通过率 + 质量分层 + 行业选股结论
```

## 筛选标准

### 设计原则

- **目标**：不错杀任何一流好公司，但能排除确定的非一流公司
- **逻辑**：7条硬指标 + 3条豁免规则，宁可漏网不可误杀
- **适用范围**：所有上市公司（银行/保险不适用第3条利息覆盖倍数）

### 数据窗口检查

| 数据年数 | 状态 | 说明 |
|---------|------|------|
| ≥10年 | 数据充足 | 指标可靠性高，可做完整判断 |
| 5-9年 | 数据基本充足 | 可做基本判断，但建议关注趋势 |
| <5年 | 数据窗口较短 | 建议谨慎解读，结合行业和商业模式判断 |

A股/港股/美股的行情、财务、信息查询工具的完整命令示例详见公共技能文件，此处不重复列举。以下仅强调去劣筛选中的关键约束：

- **年报一手数据**：使用 `stock_equity.py --download-report` 下载年报，再按 [pdf-extraction](../tools-scripts/pdf-extraction.md) 流程提取（关键财务数据须从一手数据源交叉验证）

- **网络搜索必须优先获取最新数据**：搜索时须使用 `--time-range month` 或 `--time-range week` 限制时间范围，确保获取的信息和数据为最新。禁止采用过时数据（如使用2024年数据描述2026年行业现状），避免分析偏差。搜索结果须标注数据来源日期，过时数据须明确标注并说明时效性

## 核心原则

1. **不错杀好公司** — 宁可漏网不可误杀，通过筛选不等于"确定好"
2. **数据驱动** — 所有判断基于财务数据，区分事实与观点
3. **完整周期视角** — 周期性行业用完整周期平均值，不用单一年份
4. **诚实面对数据缺口** — 数据无法获取时标注"数据不足"，而非直接判定通过/不通过
5. **豁免规则保护创新** — 战略投入期、主动低利润率、高周转薄利模式有对应豁免
6. **客观性原则** — 先摆数据 → 推逻辑 → 出结论，不预设立场

---

## 注意事项

- **银行/保险**：不适用第3条（利息覆盖），其商业模式本质就是利差经营
- **REIT**：ROE可能因物业重估波动大，用"核心营运利润ROE"代替
- **数据不足**：某项数据无法获取时，标注为"数据不足"而非直接判定
- **周期性行业**：用完整周期（至少覆盖一个高点和一个低点）的平均值
- **上市时间短**：不足5年的公司用全部可得数据，并标注"数据窗口不足"
- **新上市公司（不足3年）**：重点分析毛利率、净利率，考虑使用豁免A
- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- 关键财务数据须至少两个来源交叉验证

---

## 局限性说明

- **通过≠确定好**：这套指标能排除"确定不好"的公司，但通过筛选不等于"确定好"
- **港股小票、新上市公司**：可能无法获取到完整信息
- **非实时数据**：工具获取的数据可能有延迟
- **估值不涉及**：去劣筛选只看质量，不看估值，通过的公司仍需评估当前估值是否合理
- **行业差异**：不同行业的财务特征不同，需结合行业特性解读指标
- 不构成投资建议，仅供学习研究参考

**去劣是第一步，不是最后一步。** 通过的公司仍需进一步研究：商业模式是否可持续、管理层是否值得信赖、当前估值是否合理、竞争格局是否在恶化。
