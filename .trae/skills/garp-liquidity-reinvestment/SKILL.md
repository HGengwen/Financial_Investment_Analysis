# 流动性质量与再投资能力验证（1~3 年景气投资版）

对 $ARGUMENTS 进行系统化流动性质量与再投资能力分析。

> 在 1~3 年景气投资框架中，**分红不是核心目标**——快速增长型公司应当把利润再投资于增长，而非分红。本技能回答一个核心问题：**这家公司的自由现金流质量如何？管理层在高效地再投资吗？资本配置纪律是否严格？它的成长是建立在大幅账期、股权稀释、债务扩张之上，还是建立在真实的现金创造与高效再投资之上？**
>
> 本技能用于学习与研究，不构成个性化投资建议。

## 设计理念

本技能是**景气投资中「现金流质量」维度的专项验证工具**，聚焦三个核心问题：

1. **自由现金流质量**：赚的是真钱还是账面利润？（郑希关注的「ROE 向上」需要真实现金流支撑）
2. **再投资效率**：新增资本的回报率是否高于存量资本？（李进关注的「增量资本回报率 > 存量 ROIC」）
3. **资本配置纪律**：管理层是否在高效配置资本？（李进管理层评估的核心维度）

它在中长期（1~3 年）技能体系中的定位：

- 它是 `mid-investment-research`（全面研究）的**专项深化**：全面研究给出「这家公司好不好 + 值不值」，本技能给出「它的成长现金流是否扎实、再投资是否创造价值」的专项证据。
- 它是 `valuation-thermometer`（估值温度计）的**质量互补**：温度计回答「贵不贵」，本技能回答「增长质量真不真、能否撑住估值」。
- 它是 `mid-management-deep-dive`（管理层深挖）的**财务侧延伸**：管理层深挖覆盖「管理层诚信 + 资本配置」的评分维度，本技能以 FCF / 再投资为起点做系统化的财务纵深验证。

**本技能不是**：分红选股工具、股息率筛选器、收入型投资决策工具、全面投研报告工具。

> 与长期版 `income-investment` 的边界：`income-investment` 评估「能否产生持久、可分配的分红收入」，适用缓慢增长型 / 稳定增长型收息标的；本技能评估「快速增长型公司的现金流与再投资质量」，适用增速 >20% 的成长标的。二者路由互斥，不得混用。

## 四位大师分工

本技能作为**单 Agent** 执行，四位大师是**分析维度标尺**（非多 Agent 角色）。分工口径以《个人投资者 1~3 年中长期投资思想与理念 V2.0》为唯一权威：

| 大师 | 思维模式 | 在本技能中的维度 |
|------|---------|-----------------|
| **彼得·林奇** | 侦探思维 · 常识与求证 | **GARP 主轴 + 分类闸门**：六类分类确认标的适用性（快速增长型/稳定增长型适用，缓慢增长型转 `income-investment`）；PEG 估值引用 `valuation-thermometer`；利润真实性直觉（「赚的是真钱还是账面利润」） |
| **郑希** | 物理学家思维 · 周期与第一性原理 | **现金流支撑景气**：ROE 向上必须以真实经营现金流为底（「如果净利润涨但经营现金流萎缩，ROE 向上是虚假的」） |
| **李进** | 系统工程师思维 · 均衡与渗透率 | **再投资效率 + 资本配置**：增量资本回报率 > 存量 ROIC 才创造价值；管理层资本配置记录逐笔评估；治理一票否决 |
| **威廉·欧奈尔** | 工程师思维 · 信号与纪律 | **风控底线**：卖出触发一律引用 `exit-signal` 的 P0~P5，不自行发明；流动性恶化时对应 P4/P5 联动 |

## 研究纪律

1. 研究前运行 `date` 确认当天日期，在报告头部注明数据截止日期。
2. 优先使用年报、中期报告、业绩发布、投资者文档、监管文件、官方公告和交易所数据，其次用二手来源填补空白并标注为二手。
3. 遵循 `financial-data` 技能规范：关键财务数据至少两个独立来源验证，误差 >1% 须标记。
4. 每个时效性数据标注日期或期间。将每项重要陈述区分为**已验证事实**、**估计**、**假设**或**分析判断**。
5. 使用 `tools/common/financial_rigor.py` 进行精确的自由现金流、再投资回报率、估值、市值和流动性指标计算。**禁止 LLM 心算决策敏感数据**。
6. 跨币种（港股/美股）收入折算时，先用 `python tools/common/fx_rate.py --code HKDCNY`（或 `USDCNY`）获取实时汇率，勿用固定汇率。
7. 报告保存后，运行 `tools/common/report_audit.py extract` 和 `verdict` 审核流程。未通过审核的报告是草稿，不是可发布的研究。
8. **引用不重复定义铁律**：PEG 五档引用 `valuation-thermometer`、卖出纪律引用 `exit-signal` 的 P0~P5、ROIC / 增量资本回报率 / 资本配置 20 分制引用 `mid-management-deep-dive`，本技能只计算数值、不自行发明阈值或级别。
9. **本技能不替代分红 / 收入投资分析**——如需专门的收入型投资决策，请使用长期版 `income-investment` 技能。

## 执行流程

### 第一步：确认标的适用性（林奇六类分类）

**在开始分析前，必须确认标的属于快速增长型（或至少是有再投资需求的成长型）公司。**

使用林奇六类分类法：

| 类型 | 特征 | 是否适用本技能 |
|------|------|---------------|
| **快速增长型** | 增速 >20%，有大量再投资需求 | ✅ **最适用** |
| **稳定增长型** | 增速 10~20%，部分再投资 + 部分分红 | ✅ 适用 |
| **周期型** | 增速随周期波动 | ⚠️ 谨慎适用（需区分周期位置） |
| **困境反转型** | 暂未盈利或增速为负 | ⚠️ 不适用（现金流不可预测） |
| **隐蔽资产型** | 资产价值被低估 | ❌ 不适用 |
| **缓慢增长型** | 增速 <10%，主要靠分红 | ❌ **不适用**（请转 `income-investment`） |

如果标的属于缓慢增长型或主要靠分红驱动，**本技能不适用**——建议用户使用长期版 `income-investment` 技能。

> **林奇式提醒**：「如果你用股息率筛选快速增长型公司，你会错过几乎所有的伟大成长股。快速增长型公司的核心价值在于利润再投资——如果它们把赚的钱都分掉了，增长从哪里来？」

### 第三步：自由现金流质量分析（林奇 + 郑希视角）

> **郑希式提醒**：「ROE 向上是科技股最可靠的『重力加速度』。但 ROE 向上必须以真实现金流为基础——如果净利润增长但经营现金流在萎缩，ROE『向上』是虚假的。」

#### 3.1 利润质量检验

| 指标 | 公式 | 健康标准 | 警惕信号 |
|------|------|---------|----------|
| **FCF / 净利润比率** | 自由现金流 ÷ 净利润 | >100% 为佳 | <80% 需警惕 |
| **经营现金流 / 净利润** | 经营现金流 ÷ 净利润 | >100% 为佳 | 持续 <100% 且差距扩大 |
| **应收账款周转天数** | 应收账款 ÷ 日均收入 | 稳定或下降 | 上升且快于收入增速 |
| **存货周转天数** | 存货 ÷ 日均成本 | 稳定或下降 | 上升且快于收入增速 |

**历史趋势分析**（至少 4 个季度）：

| 季度 | Q-4 | Q-3 | Q-2 | Q-1 | 本期 | 趋势 |
|------|-----|-----|-----|-----|------|------|
| 经营现金流 | | | | | | |
| 自由现金流 | | | | | | |
| FCF / 净利润 | | | | | | |

**关键判断**：

- FCF / 净利润趋势：↑ / → / ↓
- 若 FCF / 净利润 < 80% 且持续下降 → 利润质量存疑（黄灯）
- 若 FCF / 净利润 < 50% 且无合理解释 → 利润质量严重存疑（红灯）

#### 3.2 资本开支结构分析

| 维度 | 本期 | 上期 | 变化 | 解读 |
|------|------|------|------|------|
| 总资本开支 | | | | |
| 维护性资本开支 | | | | 维持现有业务所需 |
| 扩张性资本开支 | | | | 新业务/产能扩张 |
| 扩张性资本开支占比 | | | | >60% 为成长型特征 |

**判断标准**：

- 扩张性资本开支占比高 + ROIC > WACC → **良性扩张**（创造价值）
- 扩张性资本开支占比高 + ROIC < WACC → **毁灭式扩张**（对应 `mid-management-deep-dive` 的 ROIC 一票否决）
- 扩张性资本开支占比低 + 增速快 → **轻资产模式优势**

### 第四步：再投资效率分析（李进视角）

> **李进式提醒**：「新增资本是否带来同等或更高的利润增长？增量资本回报率 > 存量 ROIC，说明扩张在创造价值——这是再投资效率最好的检验标准。」

#### 4.1 ROIC（投入资本回报率）

**ROIC = 税后营业净利润 ÷（总资产 - 现金 - 无息负债）**

> **口径铁律（引用不重复定义）**：ROIC 的合格 / 优秀阈值、一票否决条件、评分加减分，唯一权威口径来自 `mid-management-deep-dive` 技能，本技能**只计算 ROIC 数值、不自行判定阈值**。ROIC 数值须经 `financial_rigor.py calc` 执行，禁止 LLM 心算。

#### 4.2 增量资本回报率

**增量资本回报率 = 新增税后营业利润 ÷ 新增投入资本**

| 对比 | 判断 |
|------|------|
| 增量回报率 > 存量 ROIC | **扩张在创造价值**（加分） |
| 增量回报率 ≈ 存量 ROIC | 扩张在维持效率（中性） |
| 增量回报率 < 存量 ROIC | 扩张在稀释效率（减分） |

> 上述「创造价值 / 维持 / 稀释」的加分口径以 `mid-management-deep-dive` 为准（增量资本回报率 > 存量 ROIC = 创造价值），本技能展开趋势纵深判断，不重复定义评分标准。

#### 4.3 再投资充分性（本技能专有纵深）

**核心问题**：公司产生的自由现金流是否足以支撑其增长计划？

| 情景 | 判断 |
|------|------|
| FCF > 再投资需求 | 自主融资能力强（高质量流动性） |
| FCF ≈ 再投资需求 | 刚好覆盖（需监控） |
| FCF < 再投资需求 | 需要外部融资（警惕股权稀释或债务风险） |

**外部融资检查**（本技能专有纵深）：

- 近 3 年股本稀释率：____%
- 有息负债变化：↑ / → / ↓
- 再融资需求：____亿（12 个月内）

### 第六步：资产负债强度与财务弹性

#### 6.1 资产负债表健康度

| 指标 | 数值 | 判断 |
|------|------|------|

- 股票增发/可转债通道：是否已利用？剩余额度？

### 第七步：估值与安全边际（林奇 PEG 视角）

> **林奇式提醒**：「流动性质量分析的目的是验证增长是否可持续——最终估值还是要看 PEG。一家 FCF 质量再好的公司，如果 PEG 严重透支，也不是好投资。」

#### 7.1 核心估值指标

```bash
# 估值指标精确计算
python tools/common/financial_rigor.py verify-valuation \
  --price {股价} --eps {EPS} --bvps {每股净资产} --fcf-per-share {每股FCF}
```

| 指标 | 数值 | 判断 |
|------|------|------|
| **PEG** | | 引用 `valuation-thermometer` 五档判定 |
| PE (TTM) | | |
| FCF 收益率 | | >5% 为佳 |
| EV/EBITDA | | 与同行对比 |

> **口径铁律（引用不重复定义）**：PEG 五档（显著低估 / 合理 / 偏贵 / 高估 / 严重透支）的唯一权威口径来自 `valuation-thermometer`，本技能只计算 PEG 数值（`financial_rigor.py peg`），档位判定以其输出为准，不自行列出阈值表。

```bash
# PEG 数值精确计算（--growth 为百分点数值，如 30 表示 30%）
python tools/common/financial_rigor.py peg --pe {PE} --growth {增速百分点}
```

#### 7.2 三情景估值

```bash
python tools/common/financial_rigor.py three-scenario \
  --price {股价} --eps {EPS} --shares {总股本亿} \
  --growth {乐观增速} {中性增速} {悲观增速} \
  --pe {乐观PE} {中性PE} {悲观PE} --years 3 --currency {币种}
```

> 流动性质量是三情景中「悲观情景」的重要输入：现金流质量越差，悲观情景下的估值下修空间越大，安全边际要求越高。

---

### 第八步：流动性危机情景分析

在估值三情景之外，补充「流动性危机情景」——验证该公司在下行情景中是否会出现流动性断裂：

- **情景设定**：收入增速归零 / 负增长 + 融资渠道收紧 + 客户回款周期拉长
- **推演**：在手现金能覆盖多久运营？有息负债到期能否滚动？是否需要紧急股权融资？
- **结论**：流动性安全垫厚度 + 是否存在流动性断裂风险

---

### 第九步：综合判决

#### 判决分类

| 判决 | 定义 | 操作建议 |
|------|------|----------|
| **高质量流动性** | FCF 质量高、再投资效率高、财务弹性强 | 可安全持有，景气逻辑强化 |
| **中等质量流动性** | FCF 质量一般、再投资效率中等、财务弹性可接受 | 持有但需密切监控流动性指标 |
| **低质量流动性** | FCF/净利润 <50%、增量 ROIC < 存量 ROIC、财务弹性弱 | **减仓或回避**——景气逻辑可能脆弱 |
| **数据不足** | 无法获取足够的流动性数据 | 标注缺口，降低置信度 |

#### 判决门控

| 阻断门控 | 触发条件 | 操作 |
|---------|---------|------|
| FCF/净利润 < 50% 且连续 2 年恶化 | 利润质量严重存疑 | 判决 ≤ 中等质量流动性 |
| 增量 ROIC < 存量 ROIC 且持续 2 年 | 扩张在毁灭价值 | 判决 ≤ 中等质量流动性 |
| 有息负债/EBITDA > 5x | 债务风险过高 | 判决 ≤ 中等质量流动性 |
| 管理层诚信问题 | 一票否决 | **立即回避**（对应 `exit-signal` 的 P0） |

> **与 `exit-signal` 的关系**：本技能输出的是「流动性质量维度」的专项判决，**不替代 `exit-signal` 的组合级卖出决策**。「管理层诚信问题」即 `exit-signal` 的 **P0 治理一票否决**，命中即停；若流动性质量触发「低质量」，应提示进入 `exit-signal` 复核，涉及估值透支 / 逻辑止损 / 性价比替换时，一律引用 `exit-signal` 的 P0~P5。

- **ROIC 计算必须精确**：税后营业净利润 ÷（总资产 - 现金 - 无息负债），须经 `financial_rigor.py calc` 执行

- **估值与流动性指标计算须用 `financial_rigor.py`**，禁止 LLM 心算

## 注意事项

1. **本技能不替代分红投资分析**：如需专门的收入型投资决策，请使用长期版 `income-investment` 技能
2. **快速增长型公司不分红是正常的**：不要因为分红率低而扣分
3. **FCF 质量是核心**：赚真钱比赚账面利润重要得多
4. **再投资效率比 FCF 绝对值更重要**：即使 FCF 为负，如果增量回报率极高，也可能是好的投资
5. **数据验证**：关键数据必须至少来自两个独立来源，误差 >1% 须标记
6. **客观分析**：严格区分「事实」与「观点」
7. **呈现两面**：每个核心判断都必须附带反面论据
8. **网络搜索时效性**：使用 `--time-range month/week` 限制时间范围
9. **非境内上市双源验证**：港股/美股须按市场双源验证
10. **引用不重复定义**：PEG 五档、P0~P5、ROIC 阈值/评分，一律引用权威技能，不自建表格阈值

## 局限性

1. **资料可得性**：部分公司的完整财报原文可能难以获取
2. **FCF 口径差异**：不同来源对资本开支的定义可能不同
3. **增量回报率计算依赖准确的分部数据**：部分公司不披露分部资本开支
4. **AI 解读局限**：AI 无法完全替代专业财务分析师的深度分析能力
5. **不构成投资建议**：本技能仅用于学习与研究
