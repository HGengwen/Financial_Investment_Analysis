# 公司新闻脉搏（GARP 独立档·1~5 年）：股价异动快速归因 + 五级卖出触发初筛

对 $ARGUMENTS 进行最近新闻侦察与股价异动归因。**这不是深度投研，是情报快速响应与风控触发检查**——目标是 10-15 分钟内回答：

1. 这家公司最近发生了什么？
2. 股价异动的真因是什么？
3. **是否触发了五级卖出纪律？**
4. **是否动摇了 GARP 逻辑（H1~H7 七维）？**
5. **地缘政策与宏观因子是否放大了本次波动？**

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

**核心理念**：**异动是信号不是噪音**——先快速归因，再判断是否触发五级卖出纪律、是否动摇 GARP 逻辑。

**本技能不提供档位切换参数**——它即 GARP 独立档专属入口，命令与输入中不含任何档位切换开关；档位切换类口令属 1~3 年中期链，在本技能中出现即违反 `GNP-12`（口径隔离与语域）。

> 💬 **欧奈尔式提醒**："股价异动可能是噪音，也可能是信号。关键是判断：这个异动是否改变了 GARP 逻辑？是否触及了卖出底线？"
>
> 💬 **费雪式提醒**："先问一句——管理层有没有变？销售组织有没有坏？如果这两条还稳，短期波动多半只是波动。"

## 一、设计理念

当持仓或关注的公司股价出现异动时，投资者需要快速判断五个问题：

| # | 问题 | 落点 |
| --- | --- | --- |
| 1 | **是什么**：最近发生了什么事件？ | 第二步侦察 → 报告第二节时间线 |
| 2 | **为什么**：哪个事件导致了股价异动？ | 第三步归因 → 报告第三节归因表 |
| 3 | **是否触发五级卖出纪律**：是否触及「一级 诚信否决 → 二级 硬止损 → 三级 逻辑止损 → 四级 产业景气判断 → 五级 估值判断」及补充机制？ | 报告第六节 |
| 4 | **是否动摇 GARP 逻辑**：事件对 **H1~H7 七维**（渗透率与国产化率 / 订单·合同负债 / ROE 趋势 / 毛利率 / 增速加速度·二阶导 / 地缘政策 / 费雪质化）的影响是什么？ | 报告第五节 |
| 5 | **地缘政策与宏观背景**：是否存在国际地缘政策事件，或美联储 / 美财政部 / 美经济数据等官方重磅消息，放大了本次股价波动？ | 报告第四节 |

在 GARP 独立档（1~5 年）框架中，**股价异动后的快速归因**是风控体系的关键环节——不是每次下跌都要卖，但每次异动都必须快速检查**是否触及五级卖出触发条件**、**是否动摇 GARP 逻辑**。

本技能通过 **5 路并行 Agent** 快速侦察，产出归因判断与**五级卖出触发初筛 + GARP 逻辑影响评估**，帮助投资者在 10-15 分钟内做出初步判断。深度检查交棒给后置联动技能（`garp-exit` / `garp-thesis-drift` / `garp-valuation` 等），本技能**不重复建设**（`GNP-2`）。

## 二、适用场景

- 持仓 / 关注股票股价大涨 / 大跌（一般触发线：单日 ±5%、一周 ±10%）
- 财报后股价异动，想快速搞清市场在反应什么
- 看到新闻标题，但不确定是噪音还是真信号
- 想知道异动是否触及 GARP 五级卖出纪律、是否动摇 H1~H7 逻辑

## 三、调用参数

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | :--: | --- | --- |
| `{公司名}` | 位置 | 是 | — | 中文 / 英文 / 股票代码（A / 港 / 美股） |
| `--window` | 整数（天） | 否 | 14 | 侦察新闻回溯天数；财报季可缩到 7 |
| `--move` | 字符串 | 否 | — | 股价异动描述，如「跌 12%/3 天」；有则用于聚焦归因 |
| `--focus` | 枚举 | 否 | 平均 | `公司` / `监管` / `行业` / `情绪` / `宏观地缘` |
| `--export` | 标志 | 否 | false | 导出 Markdown 报告至 `reports/` |
| `--export-path` | 字符串 | 否 | `reports/` | 输出根路径 |
| `--json` | 标志 | 否 | false | 输出结构化 JSON（供下游解析） |

> **澄清刚性**（`GNP-11` 前置）：用户**仅给公司名**时，先反问「最近多少天的新闻？有具体的股价异动要解释吗？」——**不要默默假设**。
>
> **档位切换类口令一律不适用**：本技能不接受任何档位开关；若用户显式输入档位切换参数，须提示「本技能即 GARP 独立档专属入口，无需档位参数」（`GNP-12`）。

## 四、执行流程（六步 + 前置 A/B）

### 前置 A：日期与市场确认

1. 运行 `date` 确认当天日期，作为「报告生成日期 / 数据截止日期」基准。
2. 解析 §三 参数表并识别市场（A 股 / 港股 / 美股），决定取数与搜索工具。
3. **三档并存提示**：同目录存在其他档位的新闻脉搏或论文文件时**只提示不修改**（`GNP-10`）。

### 前置 B：交易日实时价格锚（强制）

按 §九 工具表调用对应市场行情工具，取标的**最新实时交易价格**作为本次波动溯源的**价格锚点**：

| 市场 | 命令 | 说明 |
| --- | --- | --- |
| A 股 | `python tools/a_share/stock_quote.py --realtime {代码}` | 新浪全市场快照，返回当日实时「最新价 / 涨跌幅」 |
| 港股 | `python tools/hk_stock/stock_quote.py --realtime {代码}` | 新浪全市场快照，返回当日实时「最新价 / 涨跌幅 / 成交额」 |
| 美股 | `python tools/us_stock/stock_quote.py --realtime {代码}` | yfinance 优先，失败回退新浪单只接口（延迟约 15 分钟） |

- **交易日判定**：比对行情工具返回的最新一条行情日期与今日是否一致——一致为**交易日**（盘中用实时最新价，收盘后用当日收盘价）；不一致为**休市日**（周末 / 节假日），采用最近交易日收盘价并在报告标注「**最近交易日 {日期}**」。
- **刚性**（`GNP-5`）：**禁止**用训练记忆或估算旧价替代；涨跌幅、回撤、均线偏离**均以该价格锚为基准**；报告须标注「数据获取时间 / 截至时刻」。

### 第一步：确认参数与场景

解析 §三 参数表 + 前置 A/B；确认关注侧重（`--focus`）与异动描述（`--move`）。

### 第二步：信息可得性分级

按 §八 给出 **A / B / C 级**评级，并**告知每一个 Agent**，影响其侦察方式（`GNP-4`）。

### 第三步：启动 5 路并行侦察 Agent

按 §五 在**同一条消息**中启动 5 个后台 Agent（`subagent_type: search`）。

- **并行刚性**（`GNP-11`）：5 个 Agent **必须同一条消息启动**；**各自独立搜索、不可共享结果**；可得性评级须随任务书一并下达。

### 第四步：实时跟踪进度

向用户实时展示进度，每收到一份侦察报告即更新并展示该维度的 3 条核心发现：

```text
📊 {公司名} 新闻脉搏进度（GARP 独立档 1~5 年）
━━━━━━━━━━━━━━━━━━━━━━━
价格锚：{最新价} / {涨跌幅}（{数据获取时间}）
侦察中...
  ⏳ 公司事件侦察（含诚信线索 / H7）        ⏳ 分析中...
  ⏳ 监管政策侦察（地缘只读）               ⏳ 分析中...
  ⏳ 行业对手侦察（渗透率 / 国产化率）      ⏳ 分析中...
  ⏳ 市场情绪侦察（估值线索只读）           ⏳ 分析中...
  ⏳ 宏观金融 / 地缘政策侦察（美官方优先）  ⏳ 分析中...
五级卖出触发初筛 + H1~H7 七维评估          ⏸ 等待中
```

### 第五步：Team Lead 综合归因 + 五级卖出触发初筛 + GARP 逻辑影响评估

全部 5 份侦察报告到齐后，产出**异动归因与 GARP 逻辑评估报告**（不是研究报告，重点是「**判断**」）：

- **先分层再做减法**（`GNP-3`）：宏观系统性事件（利率 / 汇率 / 地缘政策 / 衰退风险）与个股基本面事件**分开归因**，避免把大盘拖累误判为公司基本面恶化。
- **归因优先于罗列**（`GNP-3`）：发现事件不难，难的是判断「哪个事件配得上这次股价异动」。**做减法，不要做加法**。
- **区分「催化剂」与「巧合」**：同一时间发生的事件不一定是异动主因，要看影响量级是否匹配。
- **诚实面对「不明」**（`GNP-4`）：找不到主因时明确写「**真因不明**」，比硬凑因果链更有价值。

### 第六步：保存报告 + 准出

1. 按 §七 十一节模板写入 `reports/{公司名}/{公司名}-garp-news-{YYYYMMDD}.md`；目录不存在则创建。
2. 跑 `python tools/common/report_audit.py extract --report {报告路径}` 抽检；**不通过不得发布**（`GNP-9`）。
3. 命中**一级 / 二级** → 报告醒目标注「**立即转 `/garp-exit`**」。
4. **不写回任何上游文件**（`GNP-10`）。

## 五、五路并行侦察 Agent（任务书）

> **大师锚点**：五大师 = **费雪**（质化 / 诚信 / 销售组织）+ 林奇（成长与估值合理性）+ 郑希（ROE 与产业景气）+ 李进（渗透率与二阶导）+ 欧奈尔（趋势与风控）。
>
> **统一输出要求**：每条事件标注「**日期 / 来源链接 / 一句话摘要 / 对 GARP 逻辑的影响（↑强化 / →中性 / ↓削弱）**」，并按时间倒序排列。

### Agent 1：公司事件侦察（`company-event-scout`）

**核心问题：公司本体最近发生了什么？对 GARP 逻辑（尤其 H7 费雪质化）有何影响？**

侦察内容：

1. **官方公告**：港交所 / SEC / 巨潮等监管披露平台最近披露
2. **财报与业绩指引**：最新季报 / 年报、业绩预告、业绩会要点——**重点判断对 ROE 趋势、营收增速二阶导的影响**
3. **管理层动作**：高管变动、增减持、回购、分红、股权激励
4. **重大业务事件**：新产品发布、并购重组、业务剥离、大客户 / 大订单
5. **资本运作**：再融资、可转债、ADR 转换、回 A / 退市动议
6. **诉讼与合规**：被起诉、自行披露的合规事件
7. **诚信线索（GARP 新增，最高优先）**：监管立案、财务造假实锤、业绩预告失真、承诺兑现率 <50%、审计意见异常

**GARP 视角特别关注（费雪 + 郑希 + 李进）**：

- **诚信线索 → 一级初筛**：任一命中即**不计入七维综合判断**，直接升为**一级 诚信否决**（`GNP-1` / `GNP-7`）
- 事件是否影响 **ROE 趋势**（↑ / → / ↓）？
- 事件是否影响 **营收增速二阶导**（加速 / 持平 / 减速）？
- 事件是否影响 **订单 / 合同负债**（↑ / → / ↓）？
- 事件是否影响 **H7 费雪质化**：管理层动作异常、**销售组织**恶化、**暂时性困难 vs 永久性衰退**信号？

### Agent 2：监管与政策侦察（`regulatory-watcher`）

**核心问题：行业监管和政策最近有什么变化？地缘政策是否影响 H6？**

侦察内容：

1. **行业监管**：所在行业的新规、罚款、整改、牌照变化
2. **跨境政策**：中美关系（中概股）、关税、出口管制、数据安全
3. **税收政策**：增值税、企业所得税、个税相关变化
4. **反垄断与竞争法**：调查、罚款、并购否决
5. **特殊行业政策**：医药集采、教育双减、地产三道红线、互联网平台规制等
6. **货币与外汇**：影响该公司的汇率 / 利率 / 资本管制变化。判断外汇因素影响时，可用 `python tools/common/fx_rate.py --code USDCNY`（或 `HKDCNY` / `USDHKD`）获取实时汇率，辅助归因汇率波动对该公司利润 / 市值的影响

**GARP 视角特别关注（郑希 + 费雪）**：

- 是否有「**政策黑天鹅**」刚刚落地？
- **地缘政策部分一律只读** `garp-geo-policy`（P4-1）的 **0.3 三维交叉矩阵结论 / 赛道两分法归属 / 国产化率四档 / 敞口体检**（`GNP-6`）——**禁止**自建维度评分、**禁止**自行定档
- 政策变化是否影响 **H6 地缘政策**（升级 / 持平 / 降级）？
- 政策变化是否改变**销售组织与需求**结构（费雪视角）？

### Agent 3：行业与竞争对手侦察（`industry-peer-analyst`）

**核心问题：是公司个体事件，还是整个行业的 beta 波动？**

侦察内容：

1. **直接对手**：列出 3-5 个核心竞争对手，逐个查最近事件（财报、产品、价格战、人事）
2. **产业链上下游**：上游原材料 / 供应商、下游客户 / 渠道，最近的价格、产能、订单变化
3. **行业整体**：行业景气度数据、出货量、需求侧信号（消费数据、招标数据等）
4. **替代品威胁**：新技术、新业态对该行业的冲击
5. **行业指数表现**：同行业股票最近表现，该公司是跑赢 / 跑输 / 同步

**GARP 视角特别关注（郑希 + 李进）**：

- 同行 **ROE 趋势**：上行 / 下行 / 分化？
- 行业**渗透率位置**：是否处于 **`15%~40%` 黄金窗五档**（<5% 导入早期 / 5~15% 突破期 / **15%~40% 加速上行期** / 40~60% 逐步兑现 / >60% 天花板）？**TAM 是否 ≥1000 亿**？
- 行业**国产化率梯队**位置（<5% / 5~20% / 20~50% / >50%），**只读取回** `garp-geo-policy` 的 `localize` 结论（`GNP-6`）
- 行业**供需格局**变化：收紧 / 宽松 / 不变？

> **数据纪律**（`GNP-9`）：渗透率 / 国产化率数值须注明**来源与年份**；双源误差 >5pct 标**低置信**，相关维度判定须声明不确定性。

### Agent 4：市场情绪与机构观点侦察（`sentiment-tracker`）

**核心问题：是基本面驱动还是情绪 / 资金面驱动？估值是否透支？**

侦察内容：

1. **卖方评级变动**：高盛、摩根、中金等最近的评级 / 目标价调整
2. **机构持仓变化**：13F 披露（美股）、港股通持仓、北上资金流向
3. **做空数据**：做空比例、新发布的做空报告（如有）
4. **大 V 观点**：段永平等大 V 最近相关发言（如该公司是其关注标的）
5. **传言与小作文**：媒体未证实的传言、社交媒体讨论热点（雪球 / X / Reddit）
6. **技术面信号**：是否触及关键支撑 / 阻力、是否有大宗交易、融资融券异常

**GARP 视角特别关注（欧奈尔 + 林奇）**：

- 估值是否进入**透支区间**？——**只读** `garp-valuation`（P4-5）的**统一六档**线索，**零 PEG 算式、零档位阈值、零重算**（`GNP-8`）
- 是否出现**技术面破位**信号（SMR / RSI50 / MA50 / MA200 破位、放量下跌等）？——权威判定转 `trend-momentum-scan`（**技术面仅作四级辅助**）

### Agent 5：宏观金融与地缘政策侦察（`geo-macro-scout`）

## 六、五级卖出触发初筛（引用 `garp-exit`，不重复定义）

## 十、性质判断五类（核心结论）

打勾其一：

- [ ] **价值事件**：GARP 逻辑发生真实变化（ROE 拐头 / 二阶导转负 / 渗透率减速 / 订单下滑），需重审卖出纪律（联动 §六 五级初筛）
- [ ] **情绪 / 技术波动**：GARP 逻辑未变，是资金面 / 情绪 / Beta 驱动，可视为机会或噪音
- [ ] **宏观 / 地缘系统性**：无直接个股基本面变化，但受利率 / 汇率 / 制裁 / 关税 / 地缘政策拖累或助推（联动报告第四节，地缘部分须**只读** `garp-geo-policy`），需跟踪后续政策与数据
- [ ] **真因不明**：找不到能匹配股价异动幅度的事件——**这是最危险的结论**，要么是市场提前知道了什么（内幕 / 抢跑），要么是我们漏掉了信息源
- [ ] **混合**：部分价值事件 + 部分情绪放大（须**分层标注**，禁止混为一谈）

## 十四、注意事项

1. **禁止使用 WebSearch 和 WebFetch 工具**（中国大陆地区不可用）（`GNP-9`）
2. **5 个 Agent 必须在同一条消息中并行启动**，且各自独立搜索（`GNP-11`）
3. 如果用户只说公司名，先反问时间窗口和股价异动，**不要默默假设**
4. 资料评级（A / B / C 级）需**告知每个 Agent**，影响其侦察方式（`GNP-4`）
5. 所有判断必须附数据来源，**区分事实与观点**
6. **五级触发初筛必须完成**；命中一级 / 二级须提示立即转 `/garp-exit`（`GNP-1`）
7. **五级卖出为唯一级别体系，时间止损与性价比替换属补充机制、不占优先级，无第六级**（`GNP-1`）
8. **宏观与个股须分层归因**，禁止将宏观系统性回撤误归因于公司基本面（`GNP-3`）
9. 报告需包含「**信息缺口声明**」，诚实列出未能解决的疑点（`GNP-4`）
10. **交易日必须取实时价格锚**，禁止用训练记忆或估算旧价（`GNP-5`）
11. 网络搜索须使用 `--time-range week/day` 限制时间范围，优先获取最新信息
12. **港股 / 美股公司须按市场双源验证**（港股 `doubao` + `tavily`；美股 `exa` + `doubao`），确保信息准确性
13. **禁止**档位切换类口令、六级卖出编号、中期链命令名、其他档位新闻文件名与长期框架术语（`GNP-12`）
14. **不替用户做决策**——只给归因与行动建议清单；行动建议**不得出现目标仓位 / 减至 X% 等数值**（归 `garp-portfolio-review`）
15. **不适合用本 Skill 的场景**：完整投研（用 `/garp-investment-research`）、财报深读（用 `/garp-earnings-review`）、逻辑漂移验证（用 `/garp-thesis-drift`）、卖出完整检查（用 `/garp-exit`）

## 十五、局限性说明

- **信息可得性**：港股小票、新上市公司可能无法获取到有效信息
- **时效性限制**：网络搜索结果可能有延迟，无法获取最新实时信息
- **归因不确定性**：股价异动可能由多个因素叠加，难以精确归因
- **内幕信息**：无法获取未公开披露的信息，可能导致归因错误
- **宏观 / 官方信息时效**：美联储 / 美财政部等重大消息披露瞬时性强，快速归因时可能尚未被收录或为二手转述，须以 `exa_search.py` 直击原文并标注来源层级
- **宏观归因不确定性**：宏观系统性事件与个股基本面的传导路径复杂，难以精确量化各自贡献度，分层归因仅能给出方向性判断
- **情绪量化困难**：市场情绪难以精确量化，判断可能主观
- **景气数据滞后**：ROE / 二阶导 / 毛利率依赖最新财报，非财报季可能数据滞后
- **渗透率 / 国产化率数据可得性**：细分行业渗透率与国产化率缺乏官方统计，需依赖第三方估算；双源误差 >5pct 时相关维度判定为低置信
- **上游结论传导**：H6 / H7 / 估值档位 / 五级阈值为**只读**，上游若有误，本技能结论随之偏误（报告须提示异常）
- **非实时数据**：工具获取的数据可能有延迟，不是实时数据
- **快胜过全的代价**：10-15 分钟的快速归因**必然**牺牲部分深度；深度检查须交棒后置技能
- 不构成投资建议，仅供情报快速响应参考
