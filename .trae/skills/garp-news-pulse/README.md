# 公司新闻脉搏（GARP 独立档·1~5 年）(GARP News Pulse)

股价异动时快速归因：**10-15 分钟内**回答「发生了什么？真因是什么？**是否触发五级卖出纪律？是否动摇 GARP 逻辑（H1~H7）？地缘政策是否放大了波动？**」

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**
>
> **核心理念**：**异动是信号不是噪音**——先快速归因，再判断是否触发五级卖出纪律、是否动摇 GARP 逻辑。禁止使用长期框架术语（如「护城河永续」「终局思维」等）。

## 二、快速开始

### 基本调用

```text
/garp-news-pulse {公司名} [可选：股价异动描述]
```

示例：

- `/garp-news-pulse 新易盛 股价跌12%/3天`
- `/garp-news-pulse 腾讯`
- `/garp-news-pulse 紫金矿业 股价涨8%/3天`

### 参数表

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | :--: | --- | --- |
| `{公司名}` | 位置 | 是 | — | 中文 / 英文 / 股票代码（A / 港 / 美股） |
| `--window` | 整数（天） | 否 | 14 | 侦察新闻回溯天数；财报季可缩到 7 |
| `--move` | 字符串 | 否 | — | 股价异动描述，如「跌 12%/3 天」 |
| `--focus` | 枚举 | 否 | 平均 | `公司` / `监管` / `行业` / `情绪` / `宏观地缘` |
| `--export` / `--export-path` / `--json` | — | 否 | — | 输出控制 |

> **注意**：本技能**不接受任何档位切换参数**——它即 GARP 独立档专属入口。
>
> **仅给公司名时先反问**：「最近多少天的新闻？有具体的股价异动要解释吗？」——**不要默默假设**。

## 三、核心功能

对指定公司进行最近新闻侦察与股价异动快速归因。**这不是深度投研，是情报快速响应 + 风控触发检查**——通过 **5 路并行 Agent** 快速侦察（含地缘政策与宏观金融维度，重点美国官方消息），产出**归因判断 + 五级卖出触发初筛 + H1~H7 GARP 逻辑影响评估**。

### 适用场景

- 持仓 / 关注股票股价大涨 / 大跌（一般触发线：单日 ±5%、一周 ±10%）
- 财报后股价异动，想快速搞清市场在反应什么
- 看到新闻标题，但不确定是噪音还是真信号

### 五路并行侦察

| Agent | 核心问题 | GARP 视角特别关注 | 对应大师 |
| --- | --- | --- | --- |
| `company-event-scout`（公司事件侦察） | 公司本体最近发生了什么？ | **诚信线索（升一级）** / ROE 趋势 / 二阶导 / 订单·合同负债 / **H7 质化** | **费雪** + 郑希 + 李进 |
| `regulatory-watcher`（监管政策侦察） | 行业监管和政策最近有什么变化？ | 政策黑天鹅 / **地缘只读** `garp-geo-policy`（0.3 矩阵）对 H6 的影响 | 郑希 + **费雪** |
| `industry-peer-analyst`（行业对手侦察） | 是公司个体事件，还是行业 beta 波动？ | 同行 ROE / **渗透率 `15%~40%` 黄金窗** / **国产化率梯队** / 供需格局 | 郑希 + 李进 |
| `sentiment-tracker`（市场情绪侦察） | 是基本面驱动还是情绪/资金面驱动？ | **估值线索只读** `garp-valuation` 统一六档 / 技术面破位转 `trend-momentum-scan` | 欧奈尔 + 林奇 |
| `geo-macro-scout`（宏观金融与地缘政策侦察） | 国际地缘 + 金融/经济（重点美国官方）最近有什么重大消息？ | 利率/流动性 / 汇率/关税 / **地缘只读** / **宏观三表只读** `garp-macro`（只调参不择时） | **费雪** + 郑希 + 欧奈尔 |

### 六步执行流程

1. **前置 A：日期与市场确认** — `date` + 识别市场 + 三档并存提示
2. **前置 B：交易日实时价格锚（强制）** — 调用行情工具取最新实时价，判定交易日 / 休市日
3. **确认参数与场景** — `--window` / `--move` / `--focus`
4. **信息可得性分级** — A / B / C 级评级，**告知每个 Agent**
5. **启动 5 路并行侦察 Agent** — **同一条消息**中启动，各自独立搜索
6. **实时跟踪进度** → **Team Lead 综合归因 + 五级初筛 + H1~H7 评估** → **保存报告 + 跑 `report_audit.py` 准出**

### 五级卖出触发初筛（引用 `garp-exit`，不重复定义）

| 级别 | 初筛命中处置 |
| --- | --- |
| 一级 诚信否决（前置，最高优先） | **立即转 `/garp-exit`** |
| 二级 硬止损 | **立即转 `/garp-exit`** |
| 三级 逻辑止损 | 提示复核 → 转 `/garp-exit` |
| 四级 产业景气判断 | 提示复核 → 转 `/garp-exit` |
| 五级 估值判断 | 提示复核（档位线索只读 `garp-valuation`） |
| 补充机制（**不占优先级**） | 提示复核 → 转 `/garp-exit` |

**刚性**：优先级不得倒置、命中即停、低级别不得覆盖高级别；**补充机制与五级并列、不占优先级、不得写成第六级**；**地缘回避档属买入前闸门，不入本表**。

### GARP 逻辑影响评估（H1~H7 轻量七维）

H1 渗透率与国产化率 / H2 订单·合同负债 / H3 ROE 趋势 / H4 毛利率 / H5 增速加速度（二阶导）/ H6 地缘政策 / **H7 费雪质化**

**综合判断四档**：`强化 / 中性 / 削弱 / 破裂`（**权威漂移判定转 `garp-thesis-drift`**）。

## 五、输出报告

| 报告类型 | 文件路径 |
| --- | --- |
| 异动归因与 GARP 逻辑评估报告 | `reports/{公司名}/{公司名}-garp-news-{YYYYMMDD}.md` |

> 与 1~3 年中期链、10 年长期链的新闻脉搏报告**三档物理隔离**（各有独立前缀，互不覆盖、互不读取）。如果 `reports/{公司名}/` 目录不存在则创建。**同日多版本**用 `-v2` / `-v3`，**不覆盖**首版。**只读上游文件，不写回**。

### 报告四基准（头部必注明）

| 基准 | 内容 |
| --- | --- |
| **数据基准** | 实时价格获取时间 / 截至时刻 + 各维度事件数据截止日期 |
| **估值基准** | 估值线索来源（`garp-valuation` 结论日期）+「本技能不重算档位」声明 |
| **资料基准** | 侦察窗口（起止日期）+ 信息可得性等级（A / B / C）+ 主要信源层级 |
| **口径基准** | GARP 独立档 1~5 年；五级卖出引 `garp-exit`；地缘引 `garp-geo-policy`；H1~H7 对齐 `garp-thesis-drift`；「新闻脉搏 / 归因 / 性质判断」为**骨架继承 + 本技能操作化、非框架原文** |

### 归因报告结构（十一节）

```text
一、一句话归因 + GARP 逻辑结论 + 五级卖出警示
二、完整事件时间线（合并 5 维度，含 GARP 逻辑影响 + 异动权重）
三、异动归因表（候选解释/证据/反证/置信度/对 GARP 逻辑的影响）
四、宏观金融与地缘政策归因表（Geo-macro Attribution，官方来源原文优先；含 0.3 矩阵结论 / 赛道两分法 / 国产化率档）
五、GARP 逻辑影响评估（H1~H7 轻量七维，对齐 garp-thesis-drift）
六、五级卖出触发初筛（引用 garp-exit，不重复定义；含补充机制独立行）
七、性质判断（价值事件/情绪技术波动/宏观地缘系统性/真因不明/混合）
八、各维度侦察摘要（每维度 3-5 条）
九、行动建议（转 garp-exit / garp-thesis-drift / garp-valuation 等，相对动作不含仓位数值）
十、接下来 7-30 天 GARP 跟踪清单
十一、信息缺口声明
```

### 性质判断五类结论

- ✅ **价值事件**：GARP 逻辑发生真实变化（ROE 拐头 / 二阶导转负 / 渗透率减速 / 订单下滑），需重审卖出纪律
- ⚡ **情绪/技术波动**：GARP 逻辑未变，是资金面 / 情绪 / Beta 驱动，可视为机会或噪音
- 🌐 **宏观/地缘系统性**：无直接个股基本面变化，但受利率 / 汇率 / 制裁 / 关税 / 地缘政策拖累或助推（地缘部分须只读 `garp-geo-policy`），需跟踪后续政策与数据
- ❓ **真因不明**：找不到能匹配股价异动幅度的事件——**这是最危险的结论**
- 🔀 **混合**：部分价值事件 + 部分情绪放大（须分层标注）

## 六、归因标准

### 异动归因权重

| 权重 | 含义 |
| --- | --- |
| 🔴 高 | 足以单独解释异动 |
| 🟡 中 | 贡献一部分 |
| ⚪ 低 | 背景噪音 |

### 信息可得性分级

| 等级 | 特征 | 侦察策略 |
| --- | --- | --- |
| **A 级（信息充裕）** | 大盘股、媒体覆盖广、财报季 | 重点是**降噪和归因**，过滤重复转述的二手新闻 |
| **B 级（信息适中）** | 中小盘、覆盖一般 | 标准模式，每条关键事件附 1-2 个独立信源 |
| **C 级（信息稀缺）** | 港股小票、新上市、冷门 | 转入「扫盲模式」，**找不到新闻本身就有价值** |

### Team Lead 归因要点

- **先分层再做减法** — 宏观系统性事件（利率 / 汇率 / 关税 / 地缘政策 / 衰退风险）与个股基本面事件**分开归因**，避免把大盘拖累误判为公司基本面恶化
- **归因优先于罗列** — 发现事件不难，难的是判断「哪个事件配得上这次股价异动」。要做减法，不要做加法
- **区分「催化剂」和「巧合」** — 同一时间发生的事件不一定是异动主因，要看影响量级是否匹配
- **诚实面对「不明」** — 找不到主因时，明确写「真因不明」，比硬凑因果链更有价值

## 七、质量标准

| 项 | 要求 |
| --- | --- |
| **实时价格锚** | 交易日必须调用行情工具取最新实时价；**禁止**用旧价 / 估算价；休市日须标注「最近交易日 {日期}」 |
| **双源交叉** | 关键数据至少两个独立来源；误差 >1% 显式标记；渗透率 / 国产化率双源误差 >5pct 标**低置信** |
| **禁心算** | 一切算术交 `financial_rigor.py`；**禁止 LLM 心算** |
| **禁 WebSearch / WebFetch** | 中国大陆不可用，统一使用本地取数五工具 |
| **准出审核** | 发布前跑 `report_audit.py`，**不通过不得发布** |
| **官方原文优先** | 宏观金融 / 美国官方消息须以 `exa_search.py --type deep` 直击原文，二手转述标注来源层级 |
| **时效性** | 搜索必用 `--time-range week/day` 限定侦察窗口 |
| **快胜过全** | 10-15 分钟给出归因判断，**不陷入深度分析** |

## 九、核心原则

1. **快胜过全** — 核心价值是 10-15 分钟内给出归因判断，不陷入深度分析
2. **归因优先于罗列** — 做减法不做加法，判断哪个事件配得上这次股价异动
3. **诚实面对「不明」** — 找不到主因时明确写「真因不明」，比硬凑因果链更有价值
4. **不预设立场** — 不要因为持仓就倾向于「这是情绪波动，没事」
5. **区分「催化剂」和「巧合」** — 同时间发生的事件不一定是异动主因，看影响量级
6. **尊重信息可得性** — C 级公司可能查不到新闻，这个结论本身就要写出来
7. **引用不重复定义** — 卖出引 `garp-exit`、逻辑引 `garp-thesis-drift`、估值引 `garp-valuation`、地缘引 `garp-geo-policy`、宏观引 `garp-macro`
8. **不替用户做决策** — 给出归因和行动建议清单，但买卖决策由用户做
9. **口径隔离** — GARP 独立档语域；不出现档位切换类口令、六级卖出编号、中期链命令名、其他档位文件名与长期框架术语
10. **零新增 CLI** — 引擎零改动，只做调用编排

## 十、注意事项

- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- **5 个 Agent 必须在同一条消息中并行启动**
- 如果用户只说公司名，先反问时间窗口和股价异动，**不要默默假设**
- 资料评级（A/B/C 级）需告知每个 Agent，影响其侦察方式
- 所有判断必须附数据来源，区分事实与观点
- **五级触发初筛必须完成**；命中一级 / 二级须提示立即转 `/garp-exit`
- **五级卖出为唯一级别体系**，时间止损与性价比替换属**补充机制、不占优先级**，无第六级
- **宏观与个股须分层归因**，禁止将宏观系统性回撤误归因于公司基本面
- **宏观只调参不择时**，宏观不得单独构成卖出理由
- 报告需包含「信息缺口声明」，诚实列出未能解决的疑点
- **地缘回避档属买入前闸门，不入五级表**；报告中不得与五级表混用同一措辞
- **交易日必须取实时价格锚**，禁止用旧价 / 估算价
- 网络搜索须使用 `--time-range week/day` 限制时间范围，优先获取最新信息
- 港股/美股公司须按市场双源验证（港股 `doubao` + `tavily`；美股 `exa` + `doubao`）
- 行动建议**不得出现目标仓位 / 减至 X% 等数值**（归 `garp-portfolio-review`）
- 不适合用本 Skill 的场景：完整投研（用 `/garp-investment-research`）、财报深读（用 `/garp-earnings-review`）、逻辑漂移验证（用 `/garp-thesis-drift`）、卖出完整检查（用 `/garp-exit`）

## 十一、局限性说明

- **信息可得性**：港股小票、新上市公司可能无法获取到有效信息
- **时效性限制**：网络搜索结果可能有延迟，无法获取最新实时信息
- **归因不确定性**：股价异动可能由多个因素叠加，难以精确归因
- **内幕信息**：无法获取未公开披露的信息，可能导致归因错误
- **宏观/官方信息时效**：美联储/美财政部等重大消息披露瞬时性强，快速归因时可能尚未被收录或为二手转述，须以 `exa_search.py` 直击原文并标注来源层级
- **宏观归因不确定性**：宏观系统性事件与个股基本面的传导路径复杂，难以精确量化各自贡献度，分层归因仅能给出方向性判断
- **情绪量化困难**：市场情绪难以精确量化，判断可能主观
- **景气数据滞后**：ROE/二阶导/毛利率依赖最新财报，非财报季可能数据滞后
- **渗透率 / 国产化率数据可得性**：细分行业缺乏官方统计，需依赖第三方估算；双源误差 >5pct 时标低置信
- **上游结论传导**：H6 / H7 / 估值档位 / 五级阈值为只读，上游若有误，结论随之偏误
- **快胜过全的代价**：10-15 分钟快速归因必然牺牲部分深度，深度检查须交棒后置技能
- 不构成投资建议，仅供情报快速响应参考
