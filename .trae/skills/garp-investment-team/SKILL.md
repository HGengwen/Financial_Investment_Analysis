# GARP 投研团队：五角色并行分析框架（1~5 年价值成长版）
对 $ARGUMENTS 进行团队化 **1~5 年价值成长（GARP）** 投资研究分析。五位大师并行研究，Team Lead 综合研判，产出系统化的公司投资研究报告。

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

**支持输入格式**：

- `{公司名}` —— 位置参数（必填），如 `/garp-investment-team 中芯国际`
- `{公司名} --market hk` —— 市场参数（`auto` / `a` / `hk` / `us`，默认 `auto`）
- `{公司名} --depth deep` —— 深度参数（`fast` / `standard` / `deep`，默认 `standard`）
- `--export` / `--export-path` / `--json` —— 导出与结构化输出开关

> **本技能不提供档位切换开关**——它即 GARP 独立档（1~5 年）团队研究专属入口，命令与输入中**不含任何档位切换参数**；档位切换类口令属其他档位口径，在本技能中出现即违反**口径隔离**纪律（见「注意事项」第 1 条与「与各 garp- 技能的关系」）。

**权威设计依据**：`upgrade1.0/中长期价值成长（GARP）投资框架.md`（下称「框架」）。本技能所有量化口径（渗透率五档、国产化率四梯队、0.3 三维交叉矩阵、管理层 7+7+6、科研转化 8+8+4、估值多工具矩阵与统一六档、五级卖出、宏观三表、五大矛盾）**逐条对齐框架原文行号**，不自行推导。

## 设计理念

一份 1~5 年 GARP 投资研究报告要解决五个问题：

1. **这家公司是否足够杰出？能否长期持有？**——需要费雪视角，看质化分析、闲聊法与「绝不卖」的适用边界
2. **最坏会亏多少？什么时候必须无条件离场？**——需要欧奈尔视角，看风控底线与刚性止损纪律
3. **这门生意看得懂吗？值不值这个价？**——需要林奇视角，看生活常识选股、六类归类与估值锚选型
4. **产业处在景气周期什么位置？地缘会不会毁掉这条赛道？**——需要郑希视角，看产业景气、渗透率与 0.3 三维交叉矩阵
5. **仓位怎么配？管理层可信吗？科研能力能转化为业绩吗？**——需要李进视角，看组合管理、治理与科研转化

本技能通过**五 Agent 并行研究，Team Lead 综合研判**，产出完整、系统、可操作的 1~5 年 GARP 投资研究报告。

### 五位大师权威分工（对齐框架第一部分，行 14~79）

| 大师 | 思维模式 | 在框架中的角色 | 在本技能中的落位 |
|------|---------|---------------|-----------------|
| **费雪** | 质化分析 · 闲聊法与长期持有 | **核心底仓质量评估**：深度调研管理层、销售组织与长期竞争力，确认杰出后长期重仓 | **Agent 5**：质化与长期持有 + 矛盾五 「绝不卖」两前提 |

### 五大师语录

> "如果一家公司在诚信问题上不合格，无论其他标准得分多高，我永远不会考虑这只股票。" —— 费雪（质化挖掘 · 诚信一票否决）

> "投资的根本在于找到优秀的公司，然后耐心持有——但你得先确认它确实优秀。" —— 林奇（常识验证 · 类型标签）

> "ROE 向上是科技股最可靠的'重力加速度'——只要这个趋势在，估值波动只是噪音。" —— 郑希（产业景气 · 季度验证）

> "用渗透率定位阶段，用增速趋势判断拐点，用纪律保护本金。" —— 李进（系统均衡 · 仓位纪律）

> "投资的第一条规则是不要亏损，第二条规则是记住第一条。" —— 欧奈尔（底线思维 · 趋势止损）

### 与单一指标的分野

- **估值不靠单一 PEG**：科技与国产化主题公司的利润常被研发费用化压低，单一 PEG 极易误判——本技能估值结论**一律收口 `garp-valuation` 的多工具矩阵 + 统一六档**，按公司类型选主锚与辅锚（详见「第六步」Agent 2 与「三大收口」）。
- **卖出不自建层级**：五级卖出 + 时间止损 + 性价比替换**一律引用 `garp-exit`**，本技能只做职责分工与收口，不重排优先级。
- **仓位与渗透率解耦**：仓位一律按框架硬上限（`GIT-1`）执行，**不按渗透率折算仓位上限**。

### 第二步：信息丰富度评估（AI 研究偏见预警）

在创建团队前，先评估该公司的「AI 可研究性」，识别潜在数据偏见（**自评项，非工具化判据**）：

| 等级 | 特征 | AI 研究陷阱 | 应对策略 |
|------|------|-----------|----------|
| **A级（信息充裕）** | 上市多年、券商覆盖广、媒体报道密集 | 共识过强，AI 输出趋同于市场定价 | 团队重点放在**反面检验**与**非共识视角**，避免输出与市场一致的"正确的废话" |
| **B级（信息适中）** | 上市 1~5 年、覆盖有限、部分数据需推算 | AI 用「合理推测」填补空白，产生虚假确定性 | 每个 Agent 的推算数据标注置信度，区分「有据推算」与「凭空填充」 |
| **C级（信息稀缺）** | 冷门/新上市/新兴市场、几乎无覆盖 | AI 因资料不足过度保守，误判「看不清=不好」 | 团队转为「第一性原理模式」：不追求报告完整性，聚焦商业本质的几个核心问题；**不得作确定性结论** |

**C级公司的第一性原理研究法**（林奇式追问）：

1. 客户是谁？为什么付钱？有没有替代选择？（林奇的「生活常识」）
2. 复购靠什么驱动？是习惯、锁定、还是持续创造新价值？
3. 竞争对手拿 100 亿能复制这门生意吗？（郑希的「ROE 护城河」）
4. 管理层做过什么关键决策？这些决策反映什么判断力和价值观？（李进的「治理评估」+ 费雪的「质化判断」）
5. 这个产业未来 1~3 年的核心驱动力是什么？（渗透率、技术迭代、政策支持）

**偏见自查清单**（研究全程保持警惕）：

- [ ] 我的「确定性」感受来自生意本质，还是来自资料数量？
- [ ] 如果把这家公司的资料量减少一半，我的结论会变吗？
- [ ] AI 输出的分析是否与市场共识高度雷同？如果是，我的信息优势在哪？
- [ ] 是否存在「公开资料很少但生意本质极好」的可能性被低估了？
- [ ] 我正在把「数据不足」等同于「风险过高」吗？（对 C 级公司尤其重要）

将评级结果**告知每个 Agent**，影响其研究方式；并在最终结论中注明「AI 分析置信度」与「投资确定性」的区别。C 级公司的报告**必须**附「需要一手验证的问题清单」。

### 第三步：A股财报原文下载（优先执行，仅A股）

**重要流程**：对于 A 股公司，必须首先使用 `stock_equity.py` 工具下载原始财报 PDF，**下载完成后方可进行下一步的阅读分析工作**。

```bash
# 下载最新年报PDF
python tools/a_share/stock_equity.py --code {代码} --download-report --report-type annual

# 下载最新半年报PDF（如需分析半年报）
python tools/a_share/stock_equity.py --code {代码} --download-report --report-type semiannual

# 下载最新季报PDF（如需分析季报）
python tools/a_share/stock_equity.py --code {代码} --download-report --report-type quarterly
```

下载的 PDF 文件保存在 `cninfo_reports/` 目录。可使用 `--report-dir` 参数指定其他保存目录。

**流程检查点**：确认 PDF 文件下载成功后，方可启动后续的 5 个研究 Agent。

**PDF 文档阅读工具**（首选 `pdf_extract.py`，支持自动乱码检测 + OCR 回退）：

```bash
# 分类检测 PDF 类型
python tools/common/pdf_extract.py detect cninfo_reports/{代码}_{年份}年报.pdf

# 提取含财务附表的 Markdown 并写盘
python tools/common/pdf_extract.py markdown cninfo_reports/{代码}_{年份}年报.pdf --save-md --out-dir reports/pdf

# 强制 OCR 提取（适用于扫描版或繁体中文 PDF）
python tools/common/pdf_extract.py text cninfo_reports/{代码}_{年份}年报.pdf --force-ocr --ocr-langs chi_tra+eng

# 年报 Markdown 定向结构化抽取（员工/子公司/研发/分部/新品/供应链风险）
python tools/common/annual_report_parser.py reports/pdf/{代码}_{年份}年报.md --output-json
```

**注意事项**：

- 首选 `pdf_extract.py` 提取文字与表格；返回失败（退出码非 0 / success=false / 扫描件）时才回退 Poppler 工具集（`pdftotext` / `pdfinfo` / `pdftoppm`）；
- 繁体中文 PDF（如百济神州）需 `--force-ocr --ocr-langs chi_tra+eng`；
- 全量 OCR 年报耗时较长，建议先 `detect` 确认页码，用 `--pages` 指定关键页提取；
- 若 PDF 无法提取信息，应在报告中标注「资料评级：B 级」，说明扫描版 PDF 限制，**不得据此伪造附注分析**。

### 第四步：启动 5 个并行研究 Agent

使用 Task 工具在**同一条消息**中启动 5 个后台 Agent。**不得串行、不得压缩为 4 个**（`GIT-10`）。

#### Agent 1：风控底线分析（欧奈尔视角）

**核心问题：最坏情况会亏多少？什么时候必须无条件离场？**

> 欧奈尔："先想清楚亏多少，再想赚多少。8% 是普通投资者的生存红线——忘记成本，以信号为准。"

分析内容：

1. **硬止损位设定**（五级第 2 级专项；止损链口径引 `garp-exit`，本 Agent **不自建止损公式**）
   - 基于当前价格，8%~10% 止损设在什么位置？（给出**具体价格**）
   - **「建仓初期」完整定义**（框架行 530 / 行 538）：①持仓 < 最终仓位的 50%；**或** ②持仓 ≥50% 但逻辑尚未经 2~3 个季度财报持续兑现验证——**两者任一成立**即适用 8%~10% 硬止损；右侧一次性建仓后财报尚未兑现期间同样按此口径；
   - **底仓已建立且逻辑已验证**（须**同时满足** ①达到最终仓位 50% ②逻辑经 2~3 季兑现）→ 下跌 ≤20% 且多维未恶化可在合理估值下限附近加仓；>20% 转入「暂时性困难 vs 永久性衰退」清单复核（**Agent 5 主责**）；
   - **无论何种状态，逻辑被证伪立即清仓，不存在「越跌越买」**（`GIT-2`）。
2. **卖出触发条件逐级检查**（五级卖出引 `garp-exit`；本 Agent **只负责第 2 级专项**）
   - 第 2 级 硬止损：单笔亏损 8%~10% 且无明确基本面反转信号 → 止损离场；
   - 明确区分「**杀估值**」（逻辑完好，可持有/逆向布局）与「**杀逻辑**」（必须止损离场）；
   - 其余四级（诚信否决 / 逻辑止损 / 产业景气判断 / 估值判断）**不由本 Agent 收口**，只做线索上报。
3. **趋势与技术信号**（欧奈尔核心）
   - 当前股价处于上升通道、盘整还是下跌通道？
   - 近 30 天是否有放量突破或放量下跌信号？
   - 机构持仓近几个季度变化趋势？
   - 技术面信息**仅作辅助确认**，不得单独构成清仓指令。
4. **底线纪律**
   - 禁止在「杀逻辑」时越跌越买；禁止因沉没成本拒绝止损；
   - 单只个股、单一行业的仓位上限必须硬性执行（见「风控硬编码」`GIT-1`）；
   - 技术面信号**不得写成无条件清仓指令**。

**输出要求**：给出明确的硬止损位（具体价格）、趋势判断（上升/盘整/下跌）、第 2 级卖出触发清单、仓位状态判定（建仓初期 / 底仓已验证），欧奈尔式总结点评。**必用工具**：`stock_quote.py --momentum`（`atr14` / `smr_percentile` / `RSI(50)` / MA50 / MA200）+ `financial_rigor.py` 验算。

#### Agent 2：选股起点与估值定价（林奇视角）

**核心问题：这门生意我看得懂吗？现在这个价格值不值？**

> 林奇："机会来自生活常识，而不仅仅是数据表格。先搞清楚它是六类中的哪一类——不同类型的卖出逻辑完全不同。"

分析内容：

1. **生活常识选股**（林奇核心）
   - 用一句话定义这门生意的本质——「如果 10 分钟讲不清楚，业务太复杂」；
   - 你或身边人在使用这家公司的产品吗？是否愿意向朋友推荐？
   - 竞争对手的产品体验如何？
2. **林奇六类股票分类**（**必须明确归类**，框架行 33）
   - 缓慢增长型 / 稳定增长型 / **快速增长型**（核心关注）/ 周期型 / 困境反转型 / 隐蔽资产型；
   - 不同类型的估值方法与卖出逻辑完全不同——明确这只股票的「类型标签」。
3. **财务初筛**（框架行 241~248）
   - 营收规模 ≥10 亿；最近三年营收复合增速 ≥15%；资产负债率 <60%（金融/地产除外）；经营性现金流净额为正；过去三年至少两年扣非净利润为正；
   - **科技股豁免**：高研发投入科技股若「扣非净利润为负」仅由研发费用化压低当期利润所致，可用「经营性现金流净额为正 + 营收连续增长 + 研发强度 ≥15%」三项替代，无法通过豁免的仍应剔除；
   - 利润质量：经营现金流 vs 净利润比率；关键数据至少两个来源交叉验证。
4. **按公司类型选估值锚**（框架行 381~387；**只选锚、不定档**，档位一律收口 `garp-valuation`）
   - **快速增长型（盈利稳定）**：主锚 = **调整后 PEG**（即「**GARP PEG**」，须以此表述）、辅锚 = 远期 PE + PEG 分位；可接受标准 PEG<1 低估 / 1~1.2 合理 / 1.2~1.5 合理偏贵（持有不加仓、机动仓择机减）/ >1.5 高估；
   - **高研发投入型（利润被压低）**：主锚 = **PS / EV-Sales**、辅锚 = **Rule of 40**；可接受标准 Rule of 40 ≥40（收入增速 + 利润率或 FCF 利润率）；EV/Sales 低于同业可比；
   - **未盈利科技型**：主锚 = PS、EV/Sales，辅锚 = **研发管线 NPV**；可接受标准为需有清晰的盈利路径与里程碑节点；
   - **稳定增长型**：主锚 = 远期 PE + **隐含 PEG**、辅锚 = 股息率；可接受标准 当前 PE ≤ 未来 3 年 EPS 复合增速（百分数值）×1.2（即隐含 PEG ≤1.2）；
   - **成熟型企业**：主锚 = **DCF**、辅锚 = 股息贴现；可接受标准 当前市值 ≤ 保守 DCF 估值的 80%；
   - **PEG 使用边界**（框架行 391~392）：PEG 适用盈利稳定的成长股；PS/EV-Sales 适用高研发投入或未盈利科技股；DCF 适用现金流稳定的成熟企业；**科技股须多工具交叉验证，避免单一指标误判**；
   - **科技股调整后口径**（框架行 422）：高研发投入公司研发费用化会虚增 PE/PEG，**务必用「核心经营利润」口径回算调整后 PE**（`financial_rigor.py adjusted-peg`）。
5. **常见估值陷阱排查**（框架行 417~422）
   - **低 PE 陷阱**：PE 低但行业处于景气顶点，未来盈利下降会导致 PE 被动抬升，应结合行业周期位置判断；
   - **高 PE 但增速不可持续**：增速来自一次性收益（出售资产、疫情红利），须剔除后重算真实 PEG；
   - **忽略股权稀释**：EPS 增长可能来自回购减少股本而非真实盈利增长，须结合总利润增速与股本变化；
   - **研发费用化扭曲**：高研发投入科技股的研发费用化会虚增 PE 与 PEG，务必用「核心经营利润」口径回算调整后 PE。

**输出要求**：给出林奇六类归类、公司类型判定、主锚/辅锚选型与原始可接受标准的比对结果（**档位由 `garp-valuation` 收口**）、估值陷阱排查结论，林奇式总结点评。**必用工具**：`stock_financial.py` + `financial_rigor.py` 验算链（`verify-market-cap` / `verify-valuation` / `adjusted-peg` / `ev-sales` / `rule-of-40` / `implied-growth` / `dcf` / `pe-percentile` / `three-scenario`）+ 搜索五件套。**禁止心算 PE/ROE/市值/PEG；禁止自建 PEG 档位表**。

#### Agent 3：赛道选择（郑希视角）

**核心问题：产业处在景气周期的什么位置？地缘政治会不会毁掉这个赛道？**

> 郑希："ROE 向上是科技股最可靠的'重力加速度'——只要这个趋势在，估值波动只是噪音。"

分析内容：

1. **产业景气判断**（口径对齐 `garp-industry-research`，本 Agent **不做赛道级测算**）
   - ROE 拐点：近 8 个季度 ROE 趋势是上行、筑顶还是下行？（连续 3 季同向才判拐点，单季波动判噪音）
   - 营收增速加速度：近 8 个季度营收增速是逐季加快、持平还是放缓？
   - 订单增速、产能利用率等领先指标方向；公司在全球产业链中的位置，上下游景气是否共振；
   - **「增速趋势」为定性趋势判断**（增速方向描述）——框架未提「二阶导」，本技能**不设自造阈值**、不称框架条款。
2. **渗透率五档**（管「**何时买**」，照引 `garp-industry-research`，框架行 192）

   | 档 | 区间 | 操作含义 |
   | --- | --- | --- |
   | 导入早期 | **<5%** | 不确定性高，**观察不建仓** |
   | 突破期 | 5%~15% | 高弹性，**小仓跟踪** |
   | **加速上行期（黄金窗）** | **15%~40%** | **主建仓窗口**（框架定值） |
   | 逐步兑现期 | 40%~60% | 持有、**不再新建仓** |
   | 天花板 | **>60%** | 即便增速暂未转负也**不加仓**；**一旦增速归零/转负即视为见顶、清仓** |

   - 渗透率取不到时，标注「**未验证**」+ 区间上下限，**不默认落黄金窗**（`GIT-6`）。
3. **国产化率四梯队**（管「**标弹性**」，科技赛道专用，框架行 193 / 行 200~209）
   - **<5% 过早**：不确定性高；若属战略必争卡脖子环节（如光刻），可作高风险高弹性的观察/小仓，**非回避**；
   - **5%~20% 从 0 到 1 突破期**：高弹性，跟踪/小仓；
   - **20%~50% 加速投资期**：订单放量；
   - **>50% 替代空间收窄**：投资逻辑转向龙头份额提升与整机放量。
   - **分工纪律**（框架行 198）：渗透率定位**产业**所处阶段（管「何时买」），国产化率定位**国产企业**可替代空间（管「标弹性」）；科技赛道**两者叠用**，**不得互相替代**；**不得自建梯队数**。
4. **0.3 三维交叉矩阵归属 + 赛道两分法**（**只照引 `garp-geo-policy`，不自判档位、不发明系数**，框架行 163~186）

   | 地缘倒逼强度 | 政策覆盖度 | 国字号基金介入 | 投资含义 |
   | --- | --- | --- | --- |
   | 高（已制裁/断供） | 高（超常规+全链条） | 有直接注资 | **最优场景**：替代确定性和节奏均被外部力量锁定 |
   | 高 | 中 | 有专项子基金 | **次优场景**：替代方向明确，但节奏受技术突破制约 |
   | 中（制裁升级中） | 高 | 有覆盖 | **潜伏场景**：制裁尚未落地但概率高，提前布局等待催化 |
   | 高（已制裁/断供） | 低/无 | 无覆盖 | **高风险/回避**：下游被迫替代但国产短期接不住，须先验证承接能力，承接不足则回避 |
   | 低 | 中/高 | 有覆盖/注资 | **政策驱动型增量创造**：不以地缘倒逼为门槛，达标与否以政策覆盖+基金介入（支柱五）为准 |
   | 低 | 低 | 无覆盖 | **回避**：替代节奏完全依赖市场驱动，不确定性过高 |

   - **与五大支柱的映射**（框架行 355）：**支柱四对应「地缘倒逼强度」维**；**支柱五对应「政策覆盖度 + 国字号基金介入」两维**。「回避档」的共同特征是**政策覆盖度低/无 + 国字号基金无覆盖**（政策与资本两维同时失守），此时无论地缘倒逼高低**均一票回避**；
   - **赛道两分法**（框架行 180~185）：**地缘倒逼型**（半导体设备/材料等）——地缘倒逼强度是确定性下限，作**硬门槛**（倒逼强度非「低/无」方可建仓）；**政策资本驱动型**（机器人、信创等增量创造）——**豁免该硬门槛**，但海外收入/供应链/地区冲突暴露等**敞口仍须体检**，达标与否交支柱五判定；两类并非互斥，介于其间时按**更审慎的那类**执行；
   - **未列组合处理**：凡未显式列出的中间组合（如「政策覆盖度低但国字号基金有覆盖」），一律按**更审慎的相邻档位**归档，**不得因未列而默认放行**；
   - **国字号注资不作买入估值依据**（框架行 178）：注资是「政策优先序列」的信号，大基金以产业培育成本入股，其成本远低于二级市场投资者在消息公开后的买入价格；**最终决策仍须回到估值与业绩兑现框架**。
5. **敞口体检**（承接骨架「抗封锁韧性评估」废止后的定性敞口项，框架行 334~341）
   - 海外收入依赖度 / 逆全球化暴露度（贸易壁垒、产业链本土化、技术脱钩、资本与数据流动收紧四类信号）；
   - 供应链安全（关键零部件、资源是否依赖特定国家或单一供应商）；
   - 资源与成本敏感度（关键矿产/能源是否依赖进口，出口管制/加税/国有化下的成本与供应稳定性）；
   - 地区冲突暴露度（是否位于或依赖冲突热点区域、航运要道；有无库存缓冲与绕行/多源方案）；
   - 制裁与清单风险 / 本地化对冲能力 / 替代进度。
6. **宏观参数透传**（框架行 681~748；**只读、不判阶段**，`GIT-9`）
   - 经 `garp-macro` / `macro_calibrator.py` 取三表参数：利率周期 → PEG 合理买入区间；经济周期 → 现金仓位与个股上限；美林时钟 + 信用周期 → 宏观阶段收口；
   - 宏观**只调「估值容忍度」与「仓位尺度」**，不替代个股基本面判断、**不作为择时清仓依据**；**不自判阶段**。
7. **大宗商品敏感标的**：涉矿业/能源/新能源材料类公司须取相关品种价格辅助判断盈利趋势与行业景气。

**输出要求**：给出产业景气位置判断（上行/筑顶/下行）、渗透率档位、国产化率梯队、0.3 矩阵档位与赛道分类、敞口体检清单、宏观参数透传结果，郑希式总结点评。**必用工具**：`geo_policy_screen.py` + `macro_calibrator.py` + `commodity_price.py` + 搜索五件套。**禁止自判矩阵档位、禁止判阶段、禁止发明系数**。

#### Agent 4：组合管理与治理（李进视角）

**核心问题：仓位怎么配？管理层可信吗？科研能力能转化为业绩吗？**

> 李进："用渗透率定位阶段，用增速趋势判断拐点，用纪律保护本金。不要跟你的仓位谈恋爱。"

分析内容：

1. **组合配置**（李进核心）
   - **仓位一律按框架硬上限执行，与渗透率解耦**（`GIT-1` / `GIT-6`）：
     - 单只个股 **初始 ≤10% / 逻辑验证后 ≤15% / 绝对上限 ≤20%**（绝对上限 20% 仅限最高确信度、护城河最深的核心底仓在长期充分验证后使用；组合内上浮至 20% 的标的**合计不超过 2 只**）；
     - 单一行业 **≤40%**；总持股数 **5~10 只**；行业相关性 **<0.5**；日成交额 >1 亿元（小市值可放宽至 >3000 万）；
     - 宏观收紧档（衰退/过热/滞胀）按框架三表同向收紧单只与行业上限；
   - **底仓（股票仓位的 60%~80%）**：长线核心，赚企业 1~5 年成长的钱；只要买入逻辑未被破坏始终保留，不因短期 20% 以内的波动卖出，可每季度结合最新财报做小幅调整（±5%）；
   - **机动仓（股票仓位的 20%~40%）**：平滑波动，赚估值波动的钱；股价进入高估区间时减持，回落至合理区间时回补；
   - **两层口径**（框架行 450）：底仓 + 机动仓之和恒为 100%，指**股票仓位内部**切分；现金比例（常态 10%~20%、风险期 20%~30% 或更高）指**占总资产**的比例；执行顺序为先按宏观/风险预算确定现金占总资产比例，剩余部分再按底仓/机动仓切分；
   - **批量建仓**：默认三分法 **1/3 首仓 → 右侧确认后补至 2/3 → 连续 2~3 季兑现后补齐**；左侧布局首批 ≤ 该标的最终仓位的 50%（**可建上限、非必须比例**，越不确定越压低）；右侧一次性建 2/3 仅在三信号共振时启用（渗透率突破 15% 临界点 + 财报连续 2 个季度超预期 + 行业景气明确上行），常态仍按三分法推进；**禁止一次性满仓**；
   - **再平衡**：每季度末一次，单只占比偏离目标 **±5%** 触发。
2. **治理评估**（**只引 `garp-management`，不复制评分表**，`GIT-8`，框架行 282~296）

   | 评分器 | 结构与判定线 |
   |------|------|
   | **诚信前置（不计分闸门，全团队单一权威）** | 兑现率 <50% / 业绩预告重大失真 / 财务造假实锤 / 监管立案 → **放弃或清仓**（一律走 `GIT-3` 单一闸门） |
   | **管理层 20 分制** | **对待股东 7 + 战略执行 7 + 稳定性与激励 6**；**≥15 可重仓** / 10~14 观察仓 / <10 放弃（**非诚信事项**，走逻辑止损） |
   | **科研转化 20 分制**（科技/医药必填） | **研发投入 8 + 研发产出 8 + 资本回报 4**；**≥15 可重仓** |
   | **费雪补充项** | 销售组织出色 + 管理层持股 ≥3% + 暂时性困难 vs 永久性衰退 + 闲聊法清单 + 十五要点筛选 → **并入评估，不改 20 分制结构**（主责 Agent 5） |
   | **ESG 三通道** | 环境 / 治理 / 社会修正量；经 `garp-management` 出口，联动 `garp-valuation` 的 ESG 折价 |

   - **两套 20 分制的合成规则**（框架行 280）：管理层评估为**通用硬门槛**，无论行业须 ≥15 方可重仓；科技股在此基础上**再叠加**科研转化 ≥15，即「两套都须 ≥15」而非合计/加权；普通行业不适用科研转化清单时，仅以管理层 20 分制判定；
   - **诚信机制**（框架行 282）：诚信维度**独立于 20 分制、不赋分**——一旦命中，无论总分是否 ≥15，**直接放弃或清仓**，不进入求和；
   - **管理层评分数据缺失时**：标注「数据不足」；**诚信闸门不得因缺失而跳过**（缺失即标注风险，不用高分默认）。
3. **诚信一票否决（第 1 级专项，与 Agent 5 共用单一闸门）**（`GIT-3`）
   - 触发即**立即清仓/放弃**，不考虑估值与趋势；
   - **不得**以其他维度高分或估值便宜豁免；**不得**因数据缺失而跳过；
   - **Agent 4 与 Agent 5 共用同一闸门，不得双闸门双结论**。
4. **季度复盘检查清单（7 项必查）**

#### Agent 5：质化分析与长期持有（费雪视角）

**核心问题：这家公司是否足够杰出？它的下跌是暂时性困难还是永久性衰退？「绝不卖」的两个前提是否成立？**

> 费雪："如果一家公司在诚信问题上不合格，无论其他标准得分多高，我永远不会考虑这只股票。"

分析内容：

1. **闲聊法（Scuttlebutt）第一手调研清单**（框架行 22）
   - **向竞争对手问**：这家公司的产品/份额/定价权口碑如何？对手最忌惮它什么？对手在哪些环节自认领先？
   - **向供应商问**：其采购规模、付款条件、技术协同深度、对供应商的依赖与议价方式；
   - **向客户问**：复购驱动力是什么（习惯 / 锁定 / 持续创造新价值）？转换成本有多高？是否有过重大质量或服务事故？
   - **向前员工/离职人员问**：研发组织氛围、决策效率、核心人才流失方向与原因；
   - **向经销商/渠道问**：铺货覆盖密度、团队稳定性、终端动销与库存水位；
   - 全部结论须附**来源与日期**，禁止印象式判断；无公开一手信息时标注「未取得」并进入 C 级流程。
2. **十五要点质化筛选**（框架行 25；定性参考，**不计入 20 分制**）
   - 市场潜力是否足够大且可持续扩张？研发投入是否持续且高效？
   - 销售组织是否出色？利润率趋势是否改善？管理层是否坦诚、是否有能力？
   - 是否具备超越行业平均的长期竞争优势（护城河需**可量化验证**）？
   - 需明确标注：本项为**质化增量判断**，**不得另设第二套评分表**（`GIT-8`）。
3. **销售组织评估**（框架行 300~305）
   - 经销商覆盖密度与覆盖率、销售团队离职率、客户获取成本趋势、销售费用率变化方向；
   - 是否有行业领先的铺货能力（对标费雪对摩托罗拉「覆盖 85% 经销商」的观察口径）。
4. **管理层持股与利益绑定**（框架行 305）
   - 核心管理层是否持有公司 **≥3%** 股份？查阅年报「股东持股」章节及高管薪酬公告；
   - 持股比例越高，利益绑定越深，长期决策越倾向股东价值最大化；
   - 与 Agent 4 的「稳定性与激励」维度联动，但**不重复计分**。
5. **暂时性困难 vs 永久性衰退判断清单**（框架行 508~521；回撤 >20% 时的复核主责）

   | 判断维度 | 暂时性困难（可加仓） | 永久性衰退（需清仓） |
   | --- | --- | --- |
   | **行业需求** | 需求延迟，但长期趋势未变 | 需求被替代品永久性替代 |
   | **竞争格局** | 份额短期波动，但优势仍在 | 份额持续流失，护城河消失 |
   | **财务** | 现金流短期承压，但资产负债表健康 | 现金流持续为负，债务恶化 |
   | **管理层** | 承认问题，有清晰应对方案 | 推卸责任，频繁更换高管 |
   | **研发** | 研发投入维持或增加 | 研发投入持续削减 |
   | **客户** | 客户流失是暂时性的，可挽回 | 核心客户永久性转向竞争对手 |

   - **使用规则**：对核心底仓，若判断为「暂时性困难」且产业逻辑、科研转化（科技股）、管理层、财务等维度均未恶化，可在合理估值下限附近加仓；若判断为「永久性衰退」，**无论盈亏立即清仓**。
6. **「绝不卖」两前提检验**（框架行 632~649；**自评项，非工具化判据**）
   - **前提一：极度深度的研究认知**——确信这是一家能够持续创造增量价值的「杰出企业」，而非普通好公司；
   - **前提二：极度集中的持仓**——费雪的「不卖」建立在只重仓 3~5 只、占总仓位 70% 的极致集中之上；
   - **两前提缺一不可**：若持仓同时满足「深度认知 + 高确信度 + 管理层诚信 + 护城河稳固 + 财务健康」，且下跌属**暂时性困难**，可采纳费雪逻辑继续持有甚至加仓；**缺乏前提或属永久性衰退 → 按趋势/景气纪律离场或调仓**；
   - **核心原则**：费雪的「不卖」是「**认知深度的奖赏**」，不是「懒惰不研究的借口」。普通人只对极少数真正杰出的标的适用「不卖」，其余持仓一律服从景气与止损纪律。
7. **诚信闸门读取（不另设闸门）**（`GIT-3`）
   - 本 Agent **只读取** Agent 4 主导的单一权威诚信闸门结论，**不得自建评分表、不得另设闸门、不得给出与 Agent 4 冲突的第二结论**；
   - 命中即在全团队收口为「放弃或清仓」，与估值高低、趋势好坏无关。

**输出要求**：给出闲聊法调研清单与取证结果、十五要点质化结论（定性）、销售组织与持股 ≥3% 核验、暂时性困难 vs 永久性衰退判定、**「绝不卖」两前提检验结论（须标注「自评项，非工具化判据」）**、诚信闸门读取结果，费雪式总结点评。**必用工具**：`annual_report_parser.py` + 搜索五件套（闲聊法：竞争对手 / 供应商 / 客户 / 前员工公开访谈）+ `governance_data.py`（仅读结论）。**禁止另设评分表、禁止把自评项表述为工具化判据**。

### 第六步：Team Lead 汇总最终报告

全部 **5 份**研究报告到齐后，Team Lead 综合产出最终投资研究报告。**某 Agent 缺失时**：标注「该维度缺失」**并如实披露**，五维评分表中该维**留空**，综合评分**降级为无综合分**，**不得代写、不得伪造**（`GIT-10`）。

**汇总要点——不是拼报告，是找交叉和矛盾**：

1. **五个视角的共识点**：五位大师都同意的结论，可信度最高；
2. **五个视角的矛盾点**：比如林奇说估值便宜、郑希说产业景气拐头向下——这种矛盾才是最有价值的分析（**不得和稀泥、不得抹平矛盾**）；
3. **被忽略的角落**：五个人都没重点提的东西，是否恰恰是最重要的？
4. **反偏见自检**：各 Agent 的分析是否受限于资料充裕度？是否与市场共识过度趋同？

**汇总纪律**：五矛盾**不逐条重述**，只输出**本标的当前处于哪一类矛盾**及**决议 + 依据（框架行号）+ 反面论据**。

| --- | --- |

#### 宏观三表校准（照引框架行 695~748；参数经 `garp-macro` / `macro_calibrator.py` 透传）

| 表 | 权威值 |
| --- | --- |

| — | 头部含公司 / 市场 / 深度 / **三日期**（研究日期 / 数据截止日期 / 报告生成日期）/ 所属档位 / **信息丰富度 A/B/C** + AI 研究局限性声明 |

| 二 | 五维评分（欧奈尔 / 林奇 / 郑希 / 李进 / 费雪）+ 综合评分 X/5；**每维附 1 条核心判断**；Agent 缺失时该维留空 |
| 三 | 近 2 年关键财务与经营指标 + `financial_rigor.py` 多工具验算输出（禁止 LLM 心算） |
| 四 | **五维各 3~5 条核心发现**（与 Agent 分工一一对应） |
| 五 | **诚信前置闸门结论**（`GIT-3`）+ 7+7+6 得分 + 8+8+4 得分 + **费雪补充项（Agent 5）** + ESG 三通道修正量 |
| 六 | 公司类型判定 → **主锚/辅锚选型** → `基准档位 → 宏观校准后 → ESG 折价后 → 最终档位` 四级留痕 + **宏观 PEG 区间越界标注** + 底仓/机动仓操作 + **「GARP PEG」表述规范**（= 调整后 PEG，快速增长型主锚） |
| 七 | Bull vs Bear **各 5~7 条**，须分别检索多空双方论据；每条附反面论据 |
| 八 | **引用 `garp-investment-checklist` 七关逐一评估**（不重定义门槛） |
| 九 | **三档结论** + 底仓/机动仓分层 + 建仓价区间 + **硬止损位（具体价格）** + **五级卖出触发条件清单**（引 `garp-exit`） |
| 十 | 五大矛盾化解（本标的落在哪一类矛盾 + 决议 + 依据）+ 决策优先级速查卡 + 季度复盘 7 项清单 + 能力圈声明 |
| 十一 | 收口段；**不含新增结论** |

**「GARP PEG」表述规范**（`GIT-5`）：报告中**一律**写作「**调整后 PEG（快速增长型主锚）**」，**不得**解释为独立档位表；估值结论必须以 `garp-valuation` 的统一六档呈现，**不得以单一 PEG 单独作估值结论**。

**ESG / 环境风险折价叠加**（框架行 424~439）：

- 高环境风险行业（化工、有色、钢铁、火电、高污染制造等）：合理估值再打 **8~9 折**；
- 有明确碳减排承诺与可验证转型路径（须有资本开支计划、减排节点与第三方验证）：折价收窄至 **≤5% 或豁免**；
- 面临「搁浅资产」风险：DCF 贴现率**额外上调 1~2 个百分点**；
- ESG 评级处行业尾部/最低档：**先降仓位上限**（如绝对上限 20% → 15%），而非继续压估值；
- 环境风险折价是**在基本面估值之上再打一次折扣**，不是替代多工具估值，二者须叠加使用。

## 团队专节

### 专节一：五大矛盾化解方案

见「第六步」五大矛盾表。**Team Lead 输出要求**：只写「本标的落在哪一类矛盾 + 决议 + 依据（框架行号）+ 反面论据」，**不得逐条重述五矛盾**，**不得把矛盾点抹平**。

**核心原则**（框架行 665~666）：先保命（止损/防造假），再谈收益（景气/估值）。欧奈尔的底线规则优先于林奇/费雪的乐观逆向，郑希/李进的产业判断优先于短期的估值噪音。

### 专节二：决策优先级速查卡（引 `garp-exit`，**不重定义**）

| 级别 | 触发条件 | 决策 | 责任 Agent |
| :--: | --- | --- | --- |
| **一级 诚信否决** | 管理层诚信问题暴露、财务造假实锤、监管立案 | **立即清仓**，不考虑估值与趋势 | **Agent 4**（+ Agent 5 共用闸门） |
| **二级 硬止损** | 单笔亏损达 **8%~10%** 且无明确基本面反转信号 | **止损离场** | **Agent 1** |
| **三级 逻辑止损** | 连续 **2 个季度**业绩低于预期且产业景气未改善；财务不可逆恶化；龙头地位被颠覆 / 科研转化大幅低于预期；管理层或科研转化评分**跌破 10 分**（非诚信事项） | 减仓或清仓 | Team Lead（林奇 + 郑希结论交叉） |
| **四级 产业景气判断** | 渗透率/ROE 出现拐点但景气尚可、**仅节奏放缓**（如进入 40%~60% 逐步兑现期）→ 减机动仓；**增速归零/转负 → 升级为逻辑恶化、清仓**（独立触发，与渗透率位置无关） | 按景气方向调仓 | **Agent 3**（+ Agent 4 仓位联动） |
| **五级 估值判断** | 调整后 PEG>1.5 高估区 → 减机动仓；**PEG>2 严重透支 → 加速清机动仓**；市场情绪极度狂热（多信号共振）→ 减机动仓 | 底仓不动，机动仓调整 | Agent 2（+ Agent 1 机动仓纪律） |
| **补充机制** | **时间止损**：持有满 **4 个季度（1 年）**逻辑仍未兑现 → 减至观察仓或替换；**性价比替换（末位优化）**：其他标的估值显著更低且产业趋势更强可逐步切换，**每季度最多 1 次** | 兜底 / 优化 | Team Lead |

**执行纪律**（引 `garp-exit`）：检查顺序固定为一级 → 二级 → 三级 → 四级 → 五级；**命中即停**，输出命中的最高级别及动作，**不得被低优先级覆盖**；**禁止跳过一级**；补充机制**不占优先级**，不得覆盖已命中级别。

**一票否决的语境边界**（框架行 663）：**一级**针对**持仓后**的清仓信号；三档结论中的 **ROIC<5% 扩产 / 能力圈自检未通过 / 0.3 矩阵回避**属**买入前**闸门，命中即**建仓前放弃**、**不进入卖出金字塔**。两类「否决」语境不同，**报告中不得混用同一措辞**。

### 专节三：每季度复盘检查清单（7 项）

| 序号 | 检查项 | 触发条件 |
| :--: | --- | --- |
| 1 | 渗透率是否仍处 **15%~40%** 加速上行黄金窗？ | <5% 观察不建仓；>60% 不加仓；增速归零/转负 → 清仓 |
| 2 | 国产化率梯队是否位移？ | >50% 后逻辑转向龙头份额提升与整机放量 |
| 3 | 0.3 三维矩阵档位是否变化？ | 新制裁/新政策/基金新注资 → 重估档位与敞口 |
| 4 | 估值档位是否触发「高估 / 严重透支」？ | 调整后 PEG>1.5 减机动仓；>2 加速清机动仓 |
| 5 | 底仓/机动仓比例是否偏离目标？ | 偏离 >±5% 再平衡 |
| 6 | 五级卖出是否有触发？ | 按 `garp-exit` 逐级检查 |
| 7 | 管理层 7+7+6 与科研转化 8+8+4 是否下滑？ | 连续 2 季下滑或跌破 10 分 → 降观察仓/减仓 |

**另必做「假如空仓」测试**（框架行 450 段 / 行 672~677，每季度一次）：**「假如你现在空仓，你会以当前价格买入这家公司吗？」**

### 专节四：能力圈声明（四维自检，**自评项，非工具化判据**）

| 维度 | 评估标准 | 自检问题（须能独立回答「是」） |
| --- | --- | --- |
| **产业理解** | 能否画出该产业链的上下游关系图？能否说出行业竞争格局与集中度（CR5）？ | 产业链有几层？上游关键原材料/设备来自谁？下游客户是谁？前五大玩家是谁、份额多少？ |
| **财务理解** | 能否独立阅读并理解该行业公司的三张报表？ | 营收、毛利率、应收/存货、经营现金流分别在哪张表？关键科目变动意味着什么？ |
| **估值理解** | 能否用至少 2 种方法给出估值区间？ | 除了 PE/PEG，能否再用 PS、EV/Sales、DCF、可比公司等方法交叉验证？ |
| **技术理解**（科技股必答） | 能否说清核心技术路线的差异？ | 不同技术路线的原理差异、成本差异、适用场景、主流玩家分别是谁？ |

**判定规则**（框架行 230~236）：

- 普通行业：须**同时满足「产业理解 + 财务理解 + 估值理解」三项**方可进入深度研究；任一无法独立回答即视为**能力圈之外**；
- 科技股：**「技术理解」为必选项**——说不清核心技术路线差异，即便其他三项通过，也不得重仓，只能作观察仓或放弃；
- **达不到门槛的应对**：①补课学习直到能独立回答；②只作低仓位观察仓跟随；③果断放弃。
- 本专节结论**须在报告中标注「自评项，非工具化判据」**（`GIT-12`）。

## 输出要求

1. **三日期强制**：报告头部须列 研究日期 / 数据截止日期 / 报告生成日期，并给出下一复核日；
2. **信息丰富度标注**：A/B/C 级写入报告开头并**告知每个 Agent**，标注「自评项，非工具化判据」；**C 级不得作确定性结论**，须列「需要一手验证的问题清单」；
3. **置信度分层**：区分「有据推算」与「数据不足」；搜不到即标注「估计」或「数据不足」，**不以推测填充矩阵/区间/评分**；
4. **五维进度**：进度展示须含 5 个 Agent + Team Lead；
5. **结论明确**：须给出三档结论 + 底仓/机动仓分层 + 建仓价区间 + **硬止损位（具体价格）** + 五级卖出触发条件清单；
6. **规则编号可追溯**：所有硬性规则输出必须包含**规则编号引用**（如「触发 `GIT-3`」）；
7. **呈现正反两面**：每个核心判断都必须附带反面论据；不预设立场。

## 数据抽检（准出流程）

报告写入文件后，**必须**执行数据抽检，通过后方可发布。具体流程详见 **[报告审核与数据抽检](../tools-scripts/report-audit.md)**。

```bash
# Step 1 - 提取抽检清单（15%随机抽样）
python tools/common/report_audit.py extract \
  --report reports/{公司名}/{公司名}-garp-investment-team-{YYYYMMDD}.md --seed 42

# Step 2 - 对清单每项从可靠信源取数（按市场分别使用对应工具）
#   A股：tools/a_share/stock_financial.py（东方财富主） -> 巨潮资讯副 -> 年报PDF原始一手
#   港股：tools/hk_stock/stock_financial.py -> HKEX披露易
#   美股：tools/us_stock/stock_financial.py -> SEC EDGAR
#   计算验算：tools/common/financial_rigor.py（禁止 LLM 心算）

# Step 3 - 输出准出/打回判决
python tools/common/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report {公司名}-garp-investment-team-{YYYYMMDD}.md
```

- **【准出】** 所有抽检点偏差 ≤1% → 报告可发布；
- **【打回】** 任意点偏差 >1% → 修正后重新抽检。

**Windows 兼容说明**：不使用 `/tmp/` 路径与 `2>/dev/null`，临时文件用 `%TEMP%`，stderr 重定向用 `2>$null`，JSON 提取直接用 `--output-json` 或 `--dry-run`。

### 本技能的特殊工具使用注意

1. **A股财报下载是前置流程**：A 股公司必须先执行第三步的 `stock_equity.py --download-report` 下载年报 PDF，提取一手数据后再启动 5 个研究 Agent；
2. **港股公司数据获取**：使用 `tools/hk_stock/stock_financial.py --financial {代码}` 获取财务指标；港股无 A 股财报下载工具，年报一手数据需从 HKEX 披露易获取（`doubao_search.py --sites hkexnews.hk` 定向检索，或浏览器手动下载 PDF 后按 `pdf_extract.py` 流程提取）；
3. **美股公司数据获取**：使用 `tools/us_stock/` 三个模块，详见 [美股工具使用指南](../../../docs/美股工具使用指南.md)；
4. **五个 Agent 的计算须用 `financial_rigor.py` 验算**：**禁止 LLM 心算** PE/ROE/市值/PEG/ROIC/Rule of 40/EV-Sales/DCF/隐含增速；
5. **大宗商品相关公司须获取价格数据**：Agent 3 在分析涉及大宗商品产业链的公司（矿业、能源、新能源材料等）时，须使用 `commodity_price.py` 获取相关品种价格；
6. **跨币种折算**：先取汇率（`fx_rate.py`），再由 `financial_rigor.py calc` 显式折算并标注汇率时点（`fx_rate.py` 本身不含折算能力）；
7. **薪酬/治理数据**：评分器一律由 `governance_data.py`（`management` / `research` / `esg` 三子命令）产出，禁止心算。

## 注意事项

1. **档位隔离红线**——本技能只服务 GARP 独立档（1~5 年）；**禁止使用**其他档位的命令名、档位开关与层级编号体系；档位切换类口令在本技能中出现即违反口径隔离纪律；
2. **5 个 Agent 必须并行启动**——在同一条消息中调用 5 次 Task 工具，不得串行、不得压缩为 4 个（`GIT-10`）；
3. **数据准确性**——关键数据至少来自两个独立来源，误差 >1% 必须标记；使用 `financial_rigor.py` 验算，**禁止 LLM 心算**；
4. **结论要明确**——不回避给出三档结论、具体建仓价区间、硬止损位（具体价格）与五级卖出触发条件；
5. **所有分析必须有数据支撑**——附数据来源（来源 + 日期 + 原文要点）；
6. **呈现正反两面**——每个核心判断都必须附带反面论据；
7. **不预设立场**——不预设看多或看空，先摆数据、再推逻辑、最后得结论；
8. **信息稀缺时的诚实原则**——宁可在报告中留白标注「数据不足」，也不要用推测填满框架伪装确定性；
9. **反偏见意识**——Team Lead 汇总时必须评估：各 Agent 的分析是否受限于资料充裕度？是否与市场共识过度趋同？
10. **引用不重复定义**——估值 → `garp-valuation`；卖出 → `garp-exit`；渗透率/国产化率/产业景气 → `garp-industry-research`；地缘 → `garp-geo-policy`；管理层/科研转化/ESG → `garp-management`；宏观 → `garp-macro`；买入前 Checklist → `garp-investment-checklist`；组合层 → `garp-portfolio-review`；论文追踪 → `garp-thesis-tracker`；景气趋势 → `garp-trend-tech-screen`；
11. **矛盾不得和稀泥**——Team Lead 必须写明本标的落在哪一类矛盾、决议与依据（框架行号）；
12. **自评项须标注**——费雪「绝不卖」两前提、能力圈四维自检、信息丰富度 A/B/C 评级均须标注「**自评项，非工具化判据**」。

## 局限性

1. **信息可得性**：港股小票、新上市公司可能无法获取完整信息；
2. **扫描版 PDF 限制**：A 股年报常为扫描版 PDF，可能无法提取文本内容，影响附注分析；
3. **语言限制**：非中英文财报可能无法准确解读；
4. **非实时数据**：工具获取的数据可能有延迟，不是实时数据；
5. **渗透率/国产化率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算，按 A/B/C 三级置信度标注；**无 CLI 出口，按来源人工核验**；
6. **地缘政治数据更新频率**：制裁清单、出口管制、关税、政策与基金名录等变化较快，**属时变项，须实时核验，不得沿用历史快照**；
7. **0.3 矩阵无量化系数**：框架只给定性档位与「投资含义」，**运行期不得发明系数**；
8. **主观自评项无工具化判据**：费雪「绝不卖」两前提、能力圈四维自检、信息丰富度评级为主观判断，报告中已标注；
9. **跨币种折算能力受限**：`fx_rate.py` 仅取汇率，折算由 `financial_rigor.py calc` 显式完成并标注汇率时点；
10. **并行执行复杂度**：5 个 Agent 并行执行可能需要较长时间；
11. **不构成投资建议**：本技能仅用于学习与研究，不构成任何投资建议。

### 附录B：一页纸操作备忘卡（GARP 版，含宏观校准）

**【前置判断】**

- 地缘倒逼强度：制裁是否已落地？断供是否已实际发生？
- 政策覆盖度：按「全局动态获取声明」查**当前最新**规划/专项政策，是否以「超常规 + 全链条」等强干预强度覆盖？有无**强制采购、部委协同、财税优惠**等硬性配套？
- 基金与资本介入：按「全局动态获取声明」查**当前最新**国家/地方产业基金名录，是否有直接注资或专项子基金？**注资额度与占比**是否足够大？（具体基金名/额度以实时检索为准）
- → **0.3 三维交叉判断后**才进入下一步筛选；矩阵未列组合按更审慎相邻档归档；国字号注资不作买入估值依据。

**【选股】**

- 产业空间 ≥1000 亿、未来 3 年复合增速 ≥20%；渗透率 <5% 导入早期（观察不建仓）、5%~15% 突破期（小仓跟踪）、**15%~40% 加速上行期（主建仓）**、40%~60% 逐步兑现（持有不新建）、>60% 天花板（不加仓）；增速归零/转负即见顶清仓
- 国产化率 <5% 过早（战略卡脖子环节可观察/小仓）、5%~20% 突破期（跟踪/小仓）、20%~50% 加速投资期（订单放量）、>50% 替代空间收窄
- 营收 ≥10 亿；最近三年营收复合增速 ≥15%；资产负债率 <60%；经营现金流为正；ROE 有向上趋势；ROIC > WACC
- 管理层诚信（年报验证）+ 科研转化（专利/新产品收入/重大科研项目进展）
- 费雪补充检查：销售组织出色？管理层持股 ≥3%？
- 地缘政治：海外收入依赖度、供应链可控性、资源/大宗敏感度、地区冲突暴露与逆全球化暴露度

**【估值】**

- 快速增长型：主锚 **调整后 PEG（GARP PEG）**，中性环境 <1.0 低估可加仓、1.0~1.2 合理买入、1.2~1.5 合理偏贵（持有不加仓、机动仓择机减）、>1.5 高估减仓；加息/降息期按宏观三表动态调整
- 高研发投入型：Rule of 40 ≥ 40，PS/EV-Sales 低于同业可比
- 稳定增长型：远期 PE ≤ 未来 3 年 EPS 复合增速（百分数值）×1.2（隐含 PEG ≤1.2）；成熟型：市值 ≤ 保守 DCF 估值的 80%
- 未盈利科技型：PS/EV-Sales + 研发管线 NPV，需有清晰盈利路径和里程碑节点
- **ESG 折价叠加**：高环境风险 8~9 折；有可验证转型路径收窄至 ≤5% 或豁免；搁浅资产风险贴现率额外上调 1~2 个百分点；ESG 评级尾部**先降仓位上限**
- **分批建仓**：合理区间先建 1/3 首仓，后续加仓以右侧确认信号（景气加速 / 财报超预期 / 趋势反转）为准；建仓初期（<最终仓位 50% 或持仓 ≥50% 但逻辑未验证）跌超 8%~10% 即止损，**不「越跌越买」**
- 左侧布局只用于「杀估值」，「杀逻辑」必须离场

**【持仓】**

- 底仓（**股票仓位的 60%~80%**）长持，机动仓（**股票仓位的 20%~40%**）做估值波段；现金占总资产常态 10%~20%
- 单只初始 ≤10%、验证后 ≤15%（绝对上限 ≤20%，上浮至 20% 的标的合计 ≤2 只），单行业 ≤40%，持股 5~10 只，相关性 <0.5
- 每季度末再平衡一次，偏离目标 ±5% 触发；每季度做一次「假如空仓」测试

**【卖出（按五级优先级，引 `garp-exit`）】**

- 一级：管理层失信/财务造假/监管立案 → 立即清仓
- 二级：硬止损 8%~10% 且无基本面反转信号 → 止损离场
- 三级：连续 2 季业绩低于预期 → 减仓/清仓
- 四级：渗透率减速/ROE 拐头（如进入 40%~60% 逐步兑现期）→ 减机动仓；增速归零/转负 → 升级为逻辑恶化、清仓
- 五级：调整后 PEG>1.5 → 减机动仓；PEG>2 → 加速清机动仓
- **永久性衰退判断**：行业需求被替代、护城河消失、研发持续削减 → 立即清仓
- **费雪「不卖」的适用边界**：仅限极度深研的杰出企业且满足极度集中前提；否则一律服从上述纪律

**【补充机制（不占优先级，兜底/优化动作）】**

- 时间止损：满 1 年（4 季度）逻辑未兑现 → 减仓至观察仓（仅限「逻辑未兑现」的仓位）
- 末位优化：发现估值更低、趋势更强的标的 → 逐步替换（每季度最多调仓 1 次）

**【风控】**

- 闲钱投资：资金期限 ≥ 持有期 + 至少 1 年安全垫
- 每季度复盘持仓逻辑 + 行业景气 + 地缘政治 + 估值水位 + 宏观阶段
- 组合最大回撤目标 ≤20%，接近目标时优先减机动仓、提高现金（底仓仅在逻辑证伪时退出）
- **宏观校准**：先由 `garp-macro` 定稿阶段 → 动态调 PEG 合理买入区间、现金仓位、单只上限（利率表 / 经济表 / 美林表三表收口）

**【决策优先级（当各维度"打架"时）】**

- 欧奈尔的止损 > 林奇/费雪的逆向加仓
- 逻辑证伪 > 估值便宜
- 先保命，再谈收益
