# garp-investment-team（GARP 投研团队，1~5 年）

**五大师并行 + Team Lead 综合研判**：对单家公司进行 1~5 年价值成长（GARP）团队化研究，五维评分 + 三大收口，产出「可建仓 / 观察仓 / 放弃」三档结论、底仓/机动仓分层、建仓价区间、硬止损位与五级卖出触发条件。
> **所属档位**：GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔）

---

## 技能用途 / 何时使用

### 解决什么问题

回答「**这家公司是否值得在 1~5 年维度买入、仓位怎么配、什么时候买卖、什么条件下离场**」——把五位大师的分歧摆到台面上，再由 Team Lead 收口为**单一结论**，而不是五份报告的拼接。

### 何时使用

| 场景 | 是否适用 |
| --- | --- |
| 需要对一家公司做**五视角交叉验证**的团队化研究 | ✅ 适用 |
| 需要同时拿到风控 / 选股 / 赛道 / 组合治理 / 质化五维结论 | ✅ 适用 |
| 需要一份可直接落地的三档结论 + 仓位分层 + 硬止损位 | ✅ 适用 |
| 只需单 Agent 深度研究 | ❌ 用 `garp-investment-research` |
| 只需行业层结论、不给个股结论 | ❌ 用 `garp-industry-research` |
| 只需买入前七关硬门槛核验 | ❌ 用 `garp-investment-checklist` |
| 只需卖出信号核验 | ❌ 用 `garp-exit` |
| 只需组合层集中度 / 相关性 / 压力测试 | ❌ 用 `garp-portfolio-review` |

### 前置建议

推荐执行顺序：`garp-industry-research` → `garp-geo-policy` / `garp-trend-tech-screen` → **本技能** → `garp-investment-checklist` → `garp-thesis-tracker`。

## 团队结构（五 Agent + Team Lead）

| 角色 | 大师 | 职责（核心问题） | 关键产出 |
| --- | --- | --- | --- |
| **Team Lead** | 五大师综合 | 五维评分 + 共识/矛盾/忽略角落 + **三大收口** | 十一节最终报告（非拼报告） |
| **Agent 1** | 欧奈尔 | 最坏会亏多少？什么时候必须无条件离场？ | 硬止损位（具体价格）、趋势判断、第 2 级卖出专项 |
| **Agent 2** | 林奇 | 这门生意看得懂吗？现在这个价格值不值？ | 六类归类、公司类型与估值锚选型、估值陷阱 |
| **Agent 3** | 郑希 | 产业处在景气周期什么位置？地缘会不会毁掉赛道？ | 景气位置、渗透率档、国产化率梯队、0.3 矩阵档位 |
| **Agent 4** | 李进 | 仓位怎么配？管理层可信吗？科研能转化为业绩吗？ | 底仓/机动仓分层、诚信闸门、7+7+6 与 8+8+4 |
| **Agent 5** | **费雪** | 是否足够杰出？下跌是暂时性困难还是永久性衰退？ | 闲聊法清单、十五要点、销售组织、持股 ≥3%、「绝不卖」两前提 |

### 五维评分总表

| 维度 | 大师 | 核心判断 |
| --- | --- | --- |
| 风控底线 | 欧奈尔 | 硬止损位 / 趋势 / 底线纪律 |
| 选股与估值 | 林奇 | 六类归类 / 估值锚选型 / 陷阱排查 |
| 赛道选择 | 郑希 | 景气位置 / 渗透率档 / 地缘档位 |
| 组合与治理 | 李进 | 仓位分层 / 管理层与科研转化评分 |
| **质化与长期持有** | **费雪** | 杰出度 / 诚信 / 销售组织 / 「绝不卖」两前提 |

**综合评分：X / 5**（某一 Agent 缺失时该维留空、综合评分降级为无综合分，**不得代写**）。

### 五条团队纪律

1. **5 个 Agent 必须在同一条消息中并行启动**，不得串行、不得压缩为 4 个；
2. 某 Agent 缺失须**如实披露并留空**，**不得由 Team Lead 代写或伪造**；
3. **诚信一票否决为全团队单一权威闸门**——Agent 4 与 Agent 5 **共用**，不得双闸门双结论；
4. 信息丰富度评级（A/B/C）须**告知每个 Agent**；
5. 矛盾点**不得和稀泥**——Team Lead 必须写明本标的落在哪一类矛盾、决议与依据。

## 执行流程（七步）

| 步 | 动作 | 关键产出 |
| :--: | --- | --- |
| 1 | **展示五角色团队框架**（五 Agent 职责表 + Team Lead 定位）并确认 | 团队结构确认 |
| 2 | **信息丰富度评估**（A/B/C + C 级第一性原理五问 + 偏见自查五问；结果告知每个 Agent） | 评级结论（写入报告开头） |
| 3 | **A 股财报原文下载前置**（`stock_equity.py --download-report`；**下载成功后方可启动 Agent**） | PDF 落盘 + 提取（`pdf_extract.py` / `annual_report_parser.py`） |
| 4 | **五 Agent 并行启动**（**同一条消息 5 次调用**）：欧奈尔 / 林奇 / 郑希 / 李进 / **费雪** | 5 份分维度报告 |
| 5 | **实时跟踪进度**（五维进度条 + 每份报告展示 3~5 条核心发现） | 进度展示 |
| 6 | **Team Lead 综合研判**：五维评分总表 + 共识/矛盾/忽略角落 + **三大收口** + 五大矛盾 + 十一节落盘 | 最终报告 |
| 7 | **保存报告 + 数据抽检准出**（`report_audit.py` extract / verdict）+ 后置转接 | 准出结论 + 转接清单 |

### 三大收口（刚性）

| 收口 | 内容 | 权威出口 |
| :--: | --- | --- |
| **① 五级卖出收口** | 诚信否决 > 硬止损 8%~10% > 逻辑止损 > 产业景气判断 > 估值判断；+ 时间止损（满 4 季度）+ 性价比替换（每季最多 1 次） | `garp-exit` |
| **② 估值六档收口** | 公司类型 → 主锚/辅锚 → 四级留痕（基准档位 → 宏观校准后 → ESG 折价后 → 最终档位）→ 统一六档 | `garp-valuation` |
| **③ 三档结论收口** | 全部达标 → **可建仓** / 部分不达标 → **观察仓** / 任一否决命中 → **放弃** | 框架五大支柱汇总判定 |

### 五大矛盾化解

| 矛盾 | 化解口径 |
| --- | --- |
| **一 买点哲学** | 分水岭 = **「杀估值」可逆向、「杀逻辑」必须止损**；左侧首批 ≤ 最终仓位 50% |
| **二 持有时间维度** | 以**连续 2~3 季数据趋势**为判据；趋势破坏 → 调仓 |
| **三 止损 vs 越跌越买** | 以**仓位状态**为分水岭 + **8%~10% 硬止损优先于补仓**；底仓验证后容忍 20%；**逻辑证伪立即清仓** |
| **四 分散 vs 集中** | 组合 **5~10 只**；3~4 只核心（单只 12%~15%）+ 2~3 只卫星（单只 5%~8%）；最多 2 只上浮至 20%；单行业 ≤40% |
| **五 费雪「绝不卖」 vs 趋势/景气纪律** | **两前提缺一不可**：①极度深度的研究认知 ②极度集中的持仓；**缺乏前提或属永久性衰退 → 按纪律离场或调仓** |

## 研究标准

### 信息丰富度评估（必执行，**自评项，非工具化判据**）

| 等级 | 特征 | AI 研究陷阱 | 应对策略 |
| --- | --- | --- | --- |
| **A级（信息充裕）** | 上市多年、券商覆盖广 | 共识过强，输出趋同市场定价 | 重点反面检验和非共识视角 |
| **B级（信息适中）** | 上市 1~5 年、覆盖有限 | 用推测填补空白，产生虚假确定性 | 推算数据标注置信度 |
| **C级（信息稀缺）** | 冷门/新上市/新兴市场 | 因资料不足过度保守 | 第一性原理五问；**不得作确定性结论** |

**关键提醒**：资料多 ≠ 确定性高，资料少 ≠ 确定性低。AI 能输出的置信度 ≠ 投资的真实确定性。

### 数据准确性要求

- 关键数据（总股本 / 股价与市值 / 最近财年收入与净利润 / ROE 近 3 年趋势 / 估值指标）**至少 2 个独立来源**，误差 >1% **必须标记**；
- **市值手算校验**：股价 × 总股本 vs 报告市值，防单位错误；
- **禁止 LLM 心算** PE / ROE / 市值 / PEG / ROIC / Rule of 40 / EV-Sales / DCF / 隐含增速；
- 所有计算附工具输出记录；报告发布前必须通过数据抽检准出流程。

### 自评项标注要求

费雪「绝不卖」两前提、能力圈四维自检、信息丰富度 A/B/C 评级均属主观自评，报告中须标注「**自评项，非工具化判据**」。

## 局限性

- **信息可得性**：港股小票、新上市公司可能无法获取完整信息；
- **扫描版 PDF 限制**：A 股年报常为扫描版 PDF，可能无法提取文本内容，影响附注分析；
- **语言限制**：非中英文财报可能无法准确解读；
- **非实时数据**：工具获取的数据可能有延迟；
- **渗透率/国产化率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算，按 A/B/C 三级置信度标注，**无 CLI 出口**；
- **地缘与政策数据为时变项**：制裁清单、出口管制、关税、政策与基金名录变化较快，须实时核验，**不得沿用历史快照**；
- **0.3 矩阵无量化系数**：框架只给定性档位与投资含义，**运行期不得发明系数**；
- **主观自评项无工具化判据**：费雪「绝不卖」两前提、能力圈四维自检、信息丰富度评级为主观判断，报告中已标注；
- **并行执行复杂度**：5 个 Agent 并行执行可能需要较长时间；
- **不构成投资建议**：本技能仅用于学习与研究。
