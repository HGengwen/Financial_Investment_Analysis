# garp-management — GARP 管理层与科研转化纵深研究（1~5 年独立档）

> **所属档位**：GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔）
> **权威口径**：《中长期价值成长（GARP）投资框架》第3步·支柱三
> **版本**：1.0.0 ｜ **创建**：2026-09-17 ｜ **开发任务**：P4-4

对指定公司执行**管理层 20 分制**（对待股东 7 + 战略执行力 7 + 稳定性与激励 6）与**科研转化 20 分制**（研发投入 8 + 研发产出 8 + 资本回报 4），前置**诚信否决闸门**（不赋分），收口为**两套「各自 ≥15」的合成判定**，并附**费雪补充**与 **ESG 三通道**提示。

## 快速开始

```bash
# 标准流程（自动判定行业类型，含实时取证）
/garp-management 中微公司

# 聚焦单一维度
/garp-management 中微公司 --focus integrity     # 只做诚信闸门
/garp-management 中微公司 --focus research      # 只做科研转化

# 显式指定行业类型（跳过自动判定）
/garp-management 寒武纪 --industry-type tech

# 快速模式（跳过实时检索，仅用已有数据与缓存）
/garp-management 腾讯控股 --depth fast
```

## 核心功能

### 一、诚信否决闸门（不计分，前置）

| # | 检查项 | 处置 |
| --- | --- | --- |
| 1 | 年报"说到做到"兑现率 **<50%** | 命中 → **放弃** |
| 2 | 业绩预告**重大失真** | 命中 → **放弃** |
| 3 | **归因习惯**异常 | **仅该项单独命中 → 降为预警**（见下方 A-1 说明） |
| 4 | **监管立案** | 命中 → **放弃** |
| 5 | **财务造假实锤** | 命中 → **放弃** |

**闸门的机制保证**：命中时工具返回 `total=null` 且 `score_breakdown={}`——**分数根本不参与计算**，从机制上排除"用其他维度高分对冲失信"。

> **A-1 口径覆盖（本技能特有）**：框架行 282 的一票否决命中清单只列 4 项，不含「归因习惯」；而工具将 `attribution_habit` 实现为硬否决。本技能规定：当 `integrity_veto_reasons` **仅含** `attribution_habit` 时**改判为「强制预警」**，不判「放弃」；若与其余 4 项中任一项同时命中，仍按闸门处理。判定依据须在报告中写明。

### 二、管理层 20 分制（7+7+6）

| 维度 | 满分 | 子项 |
| --- | --- | --- |
| **对待股东** | **7** | 分红历史 2 / 融资记录 2 / 回购行为 2 / 大股东质押率 1 |
| **战略执行力** | **7** | 聚焦主业 3 / 核心战略落地 2 / 行业格局认知 2 |
| **稳定性与激励** | **6** | 核心团队稳定性 2 / 股权激励合理性 2 / 内部人增减持异常 2 |

| 总分 | 档位 | 处置 |
| --- | --- | --- |
| ≥15 | 重仓 | 达标 |
| 10~14 | 观察 | 部分不达标 → 观察仓（单只上限≤5%），不重仓 |
| <10 | 放弃 | **本技能级否决** |

### 三、科研转化 20 分制（8+8+4，科技股必填）

| 维度 | 满分 | 子项 |
| --- | --- | --- |
| **研发投入"质"与"量"** | **8** | 研发强度及逐年提升 3 / 资本化审慎 2 / 研发人员占比 3 |
| **研发产出效率** | **8** | 发明专利 2 / 新产品收入占比 2 / 技术产品化周期 2 / 重大科研项目节点推进 2 |
| **资本回报效率** | **4** | ROIC > WACC 2 / 增量 ROIC > 存量 ROIC 2 |

> **资本回报项的口径**：采 **「ROIC > WACC」严格大于**，**不含「≥10%」主阈值**（后者属支柱二，归 `garp-investment-checklist` 的 S2）。三个 ROIC 数值**必须先由 `financial_rigor.py` 产出**，本技能不重算。

### 四、两套合成判定（禁止合计/加权）

| 行业 | 条件 | 结论 |
| --- | --- | --- |
| **科技股** | 管理层 ≥15 **且** 科研 ≥15 | 达标 |
| | 任一套 10~14 | 部分不达标 → 观察仓 |
| | **任一套 <10** | **放弃（支柱三级否决）** |
| | 任一套命中诚信闸门 | **放弃（诚信闸门，最高优先级）** |
| **普通行业** | 仅管理层 20 分制判定 | 同上三档 |

> **「支柱三级否决」的编号纪律**：不并入 `garp-investment-checklist`（P4-3）的 V1~V4 编号体系，以避免越界修改已交付技能；报告中显式标注来源，并在下游转接表中单列。

### 五、费雪补充（定性参考，不计分）

| 检查项 | 阈值 | 处置 |
| --- | --- | --- |
| 销售组织出色 | 经销商覆盖 / 团队稳定性 / 销售费用率 | 不可得 → 标「**本项未判定**」，不默认通过 |
| 管理层持股比例高 | **≥3%** | **<3% → 仅预警**（不扣分、不致退档） |

### 六、ESG 三通道（只识别与透传，不算折价）

| 通道 | 处置 | 下游 |
| --- | --- | --- |
| **治理（G）** | **证据触发清单 + 人工确认闸门**（不臆造数值线） | 命中 → 归入诚信闸门 |
| **环境（E）** | 定性识别 → 调 `esg` **原样透传**修正量 | **折价归 `garp-valuation`（P4-5）** |
| **社会（S）** | 重大争议计入风险提示 | 报告"风险提示"节 |
| **评级尾部** | **透传**仓位上限下调量 | **数值收口归 `garp-portfolio-review`（P4-8）** |

> **本技能不输出任何折价后估值与最终仓位数值**——报告中出现"建议单只上限 X%"即为越界。

## 使用示例

### 示例 1：科技股双套达标（中微公司 688012）

```
/garp-management 中微公司
```

实测输出（数据截止 2026-09-17）：
- **诚信闸门**：未命中
- **管理层 20 分制**：`total=16` → **重仓**（对待股东 4/7 · 战略执行力 6/7 · 稳定性与激励 6/6）
- **科研转化 20 分制**：`total=20` → **重仓**（研发投入 8/8 · 研发产出 8/8 · 资本回报 4/4）
- **合成结论**：**达标**（两套均 ≥15）

关键依据：分红率 **10.43%**（`calc`：220,094,325.85 ÷ 2,111,000,000 × 100）；研发强度 **19.99%**（费用化口径）；研发人员占比 **52.24%**（1,548 / 2,963）；ROIC **14.00%** / WACC **9.99%** / 增量 ROIC **15.89%**。

### 示例 2：诚信闸门命中（全维度高分也无效）

```
/garp-management {某公司}    # 兑现率 45%，其余维度全满分
```

实测输出：`integrity_veto=true`、`integrity_veto_reasons=["fulfillment_rate"]`、`total=null`、`verdict=放弃`、`score_breakdown={}`

> **解读**：分红率 40%（满分）、聚焦主业优、股权激励优——**分数一个都没算**。这就是 MG-1「诚信前置且不计分」的机制效果。

### 示例 3：归因习惯单独命中（A-1 覆盖）

```
/garp-management {某公司}    # 仅 integrity_veto_reasons=["attribution_habit"]
```

工具输出：`integrity_veto=true`、`verdict=放弃`

**本技能处置**：按 A-1 口径覆盖，**改判为「强制预警 + 定性参考」**，不判「放弃」；报告须写明覆盖依据（框架行 282 的 4 项命中清单）并作为工具侧待补丁事项上报。

### 示例 4：本技能级否决（<10 → 放弃）

```
/garp-management {某公司}    # 分红 5%、质押 60%、离职率 25%、激励差、内部人异常减持
```

实测输出：`total=3`、`verdict=放弃`、`position_note="管理层评分<10，放弃"`

**本技能处置**：标注「**支柱三级否决**」（区别于诚信闸门），转 `garp-investment-checklist` 作为不达标项，并提示 `garp-exit` 复核。

### 示例 5：科研转化不达标致合成退档（6.4 反例）

```
/garp-management {某公司}    # 管理层 17 分（重仓）+ 科研转化 11 分（观察）
```

实测输出：管理层 `total=17` → 重仓；科研转化 `total=11` → 观察

**合成结论**：**部分不达标 → 观察仓**（**不得**因 17+11=28 而判"达标"——MG-2 禁止合计/加权）。

### 示例 6：ESG 三通道透传（高环境风险行业）

```
/garp-management {某化工企业}
```

实测输出（高风险 + 无转型 + 搁浅资产 + 评级尾部）：
`discount_factor=0.8`、`discount_pct=20.0`、`discount_range="0.80~0.90"`、`discount_rate_adj_bps=150`、`position_cap_downgrade=5.0`、`position_cap_after=15.0`、`esg_tail_triggered=true`、`stranded_asset_triggered=true`

**本技能处置**：**原样透传**，标注「折价交 `garp-valuation`（P4-5）应用、仓位修正量交 `garp-portfolio-review`（P4-8）应用」，**报告不出现最终仓位数值**。

## 强制纪律（MG-1 ~ MG-10 摘要）

| 编码 | 一句话 |
| --- | --- |
| **MG-1** | 诚信前置且不计分，禁止高分对冲（唯一例外：归因习惯单命中降为预警） |
| **MG-2** | 两套 20 分制**禁止合计/加权**，各自 ≥15 |
| **MG-3** | 数值必须来自工具或公开披露，禁止心算 |
| **MG-4** | 数据不足不得默认通过 |
| **MG-5** | 行业类型决定科研转化是否启用；无法判定时按科技股从严 |
| **MG-6** | 资本回报项引用 ROIC 工具输出，不重算、不引入「≥10%」 |
| **MG-7** | 费雪与 ESG 不计入 20 分制 |
| **MG-8** | 只透传修正量，不输出最终仓位数值 |
| **MG-9** | 估值与卖出层级不得内建 |
| **MG-10** | 数据截止日期强制标注（全部评分项为时变项） |

## 核心原则

1. **诚信是闸门不是分数**——失信即出局，无对冲空间。
2. **两套都过关才算过关**——科技股的"人"与"技术"是**且**关系。
3. **评分是证据的函数**——每一个分值都要能追到出处；追不到就标「未判定」。
4. **越界即违规**——不做估值、不定卖出、不给仓位数值。
5. **时变项须标时点**——结论只对数据截止日期有效。

## 适用 / 不适用

| 类型 | 场景 |
| --- | --- |
| **适用** | ① 单公司管理层纵深评估；② 诚信风险核查；③ 科技股科研转化效率评估；④ 治理结构诊断；⑤ 为 P4-3 的 S3 提供分值；⑥ 持仓管理层的季度复核 |
| **不适用** | ① 买入前门槛检查（转 `garp-investment-checklist`）；② 估值与折价（转 `garp-valuation`）；③ 卖出时机与止损（转 `garp-exit`）；④ 仓位与组合（转 `garp-portfolio-review`）；⑤ 财报整体解读（转 `garp-earnings-review` / `garp-earnings-team`）；⑥ 行业赛道研究（转 `garp-industry-research`）；⑦ 未上市公司（转 `garp-private-company-research`） |
