# GARP 管理层与科研转化纵深研究（1~5 年独立档）

对 $ARGUMENTS 执行《中长期价值成长（GARP）投资框架》**第3步·支柱三**的纵深评估，回答两个问题：

> **这家公司的管理层，值不值得托付？其科研投入，是否真的在转化为业绩？**

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。** 两套 20 分制的**总分与档位一律由 `governance_data.py` 产出**，禁止 LLM 心算；本技能只做**评分入参映射、行业适用性判定、两套合成、定性补充（费雪 / ESG）与下游转接**。

> 💬 **费雪式提醒**："买股票就是买公司，买公司就是买管理层。我宁愿要一流管理层加二流业务，也不要二流管理层加一流业务——因为后者迟早会把好业务做坏。"

> 💬 **林奇式提醒**："财报数字能化妆，但员工怎么看老板、经销商愿不愿意压货、客户敢不敢下大单——这些化妆不了。"

> 💬 **郑希式提醒**："科技股的研发投入不是越大越好，是要看它有没有变成订单、变成毛利、变成更高的资本回报率。只有投入没有产出的研发，是在烧股东的钱。"

> 💬 **李进式提醒**："治理结构决定分蛋糕的规则。规则不公平，公司赚再多，小股东也拿不到——这是我首先看的一层。"

> 💬 **欧奈尔式提醒**："诚信一旦有污点，任何技术面、任何业绩爆发都不值得冒。这不是止损问题，是出局问题。"

## 设计理念与定位

GARP 框架把管理层与科研转化放在支柱三，并用**两套 20 分制**分别度量"人"与"技术"，核心逻辑是三条：

1. **诚信是闸门，不是分数**——框架行 282 明示：诚信**不占分、只作前置否决闸门**，一旦命中（兑现率<50% / 业绩预告重大失真 / 监管立案 / 财务造假实锤），**无论管理层总分是否≥15，直接放弃或清仓**。这从机制上切断了"用其他维度高分对冲失信"的路径。
2. **科技股须"两套都过关"**——框架行 280：科技股管理层评分≥15 分只是底线，**还要叠加科研转化评分≥15 分**；**两套各自独立判定，禁止合计或加权**（18 分 + 12 分 ≠ 通过）。
3. **评分是"证据的函数"，不是"印象的产物"**——评分项（兑现率 / 分红率 / 质押率 / 离职率 / 研发强度 / 新产品收入占比 / ROIC 系列）全部是**可核查的数值或布尔事实**，须给出处；数据不可得时标「未判定」并降档，**不得默认通过**。

### 本技能的三条硬纪律

| # | 纪律 | 原因 |
| --- | --- | --- |
| 1 | **诚信前置，且不计分** | 诚信一旦变成"20 分里的 5 分"，就出现"失信但其他项满分 → 仍过关"的漏洞；改为闸门后，失信即出局，无对冲空间 |
| 2 | **两套 20 分制各自 ≥15，禁止合计/加权** | 框架行 280 原文；"两套都须≥15"是**且**逻辑，不是求和 |
| 3 | **数据不足不得默认通过** | 未判定项须标「本项未判定」并降档至「暂定」；默认满分等于虚构结论 |

### 与其他环节的分工（防维度拆分歧义）

| 环节 | 归属 | 本技能的处理 |
| --- | --- | --- |

## 边界声明（本技能的核心约束）

1. **不含估值**——本技能**不给出目标价、不给出折价后估值、不做 PE/PEG 区间**。框架行 318 明示：环境（E）风险"本节**仅作定性提示**，是否折价、折价多少，交由**第4步**定量处理"；框架行 328 的"科技股专用估值调整提示"同样属第4步。本技能只**转达**该提示给 `garp-valuation`。
2. **不含卖出层级**——不内建任何止损/清仓规则；只在诚信否决命中时输出"转 `garp-exit`（P4-6）"的转接信号。
3. **不含最终仓位数值**——只透传 `governance_data.py esg` 输出的 `position_cap_downgrade` / `position_cap_after`；**报告中不得出现"建议单只上限 X%"**。最终数值收口归 `garp-portfolio-review`（P4-8）。
4. **不含买入门槛判定**——能力圈四维、财务五门槛、科技豁免、五大支柱三档结论均归 `garp-investment-checklist`（P4-3）；本技能只输出两套 20 分制的分值与其 ≥15 结论。

> **范围自查**：本技能若出现「给出目标价 / 给出折价后估值 / 给出最终单只上限数值 / 定义卖出层级」，即为越界。

| 类型 | 场景 |
| --- | --- |
| **适用** | ① 对单一公司做**管理层纵深评估**（创始人/实控人/CEO/CFO/技术负责人）；② **诚信风险核查**（承诺兑现、业绩预告、监管记录）；③ **科技股科研转化效率评估**（研发投入质量、产出效率、资本回报）；④ **治理结构诊断**（股权结构、质押、激励、关联交易）；⑤ 为 `garp-investment-checklist` 的 S3 提供分值输入；⑥ 对既有持仓做**管理层恶化信号**的季度复核 |

## 执行流程（八步）

### 第一步：确认参数与数据基准

先运行 `date` 确认当天日期，作为「数据截止日期」基准（全局规则 1）。

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `{公司名}` | 目标公司（A 股 / 港股 / 美股）；亦可写 `{人名}@{公司}` 聚焦特定管理层 | **必填** |
| `--industry-type` | `tech` / `normal`：行业类型，决定是否启用科研转化 20 分制 | **自动判定**（见下） |
| `--depth` | `standard`（含搜索五工具实时取证）/ `fast`（仅用用户提供数据与已有缓存） | `standard` |
| `--focus` | `integrity`（只做诚信闸门）/ `management`（只做管理层）/ `research`（只做科研转化）/ `all` | `all` |

**行业类型判定规则（决定科研转化是否启用）**：满足以下**任一**即判为**科技股**——① 研发强度（研发费用 ÷ 营业总收入）**≥ 5%**；② 所属行业属半导体 / 软件 / AI / 创新药 / 高端装备等科技赛道；③ 年报明示"核心技术驱动"。**无法判定时按科技股从严处理**（启用科研转化 20 分制），并在报告"数据基准与来源"节标注判定依据。

参数确认后，向用户澄清（如未在 $ARGUMENTS 中给出）：目标公司、是否需要完整实时取证、是否有已知的特定管理层人选。**不要默默假设**。

### 第三步：诚信否决闸门（不计分，工具调用）

```bash
python tools/specialized/governance_data.py management \
  --fulfillment-rate {兑现率0~100} \
  [--guidance-misstatement] [--attribution-habit] [--regulatory-filing] [--financial-fraud] \
  --dividend-payout-ratio {分红率} --financing {优/中/差} --buyback {优/中/差} --pledge-ratio {质押率} \
  --core-focus {优/中/差} --strategy-exec {优/中/差} --industry-cog {优/中/差} \
  --turnover-rate {离职率} --equity-incentive {优/中/差} [--insider-abnormal] \
  --as-of {YYYY-MM-DD}
```

**读回与处置**：

| 字段 | 处置 |
| --- | --- |
| `integrity_veto` = `true` | 闸门命中：`total` 无效（工具返回 `null` 且 `score_breakdown` 为空）、`verdict=放弃` → **不进入第四步**，直接出「放弃」结论 + 转 `garp-exit` 清仓信号 |
| `integrity_veto_reasons` | 逐条列出并给出证据来源与数据截止日期 |
| `integrity_veto` = `false` | 进入第四步 |

> **A-1 口径覆盖（本技能自建，须严格按此执行）**
>
> 工具 `VETO_FLAGS` 含 5 项，其中 `attribution_habit`（归因习惯异常）在**框架行 282 的命中清单中未列**（该行只列：兑现率<50%、业绩预告重大失真、监管立案、财务造假实锤 4 项），行 288 的表格将其列为**检查项**。因此本技能规定：
>
> 1. 当 `integrity_veto_reasons` **仅含 `attribution_habit`** 时 → **改判为「强制预警 + 定性参考」**，`verdict` **不取「放弃」**，改按第四步正常评分并给档位；报告中须显式写明该覆盖的**依据**（框架行 282 的 4 项命中清单）与**被降级的事实**。
> 2. 当 `attribution_habit` 与其余 4 项中**任一项同时命中** → 按闸门命中处理（「放弃」）。
> 3. 该覆盖是**技能层对工具输出的有据处置，不是工具的缺陷修复**；须在报告与运行记录中标注，并作为**工具侧待补丁事项**上报（详见"注意事项"节）。

**兑现率（`--fulfillment-rate`）取证要求**：以「年报/公告中的承诺 → 实际完成情况」逐条核对，兑现率 = 达标条数 ÷ 承诺总条数 × 100%（用 `financial_rigor.py calc` 精确计算，**禁止心算**）。**不得以"管理层历史表现良好"的印象代替兑现率统计**。

### 第四步：管理层 20 分制（7+7+6，工具调用）

**逐项给出依据，再映射入参**（依据不足则标「未判定」）：

| 维度 | 子项 | 满分 | 依据要求 |
| --- | --- | --- | --- |
| **对待股东（7）** | 分红历史 | 2 | 近 3~5 年分红率 ≥30% 为优；**须用 `calc` 计算分红率 = 现金分红总额 ÷ 归母净利润 ×100** |
| | 融资记录 | 2 | 是否频繁增发/配股摊薄；融资用途与回报 |
| | 回购行为 | 2 | 是否有真金白银回购（尤其低迷期） |
| | 大股东质押率 | 1 | 数值（%）；>50% 预警 |
| **战略执行力（7）** | 聚焦主业 | 3 | 主营收入占比、跨界并购记录 |
| | 核心战略落地 | 2 | 过去 3 年战略目标兑现情况 |
| | 行业格局认知深度 | 2 | 年报/交流中体现的行业判断质量 |
| **稳定性与激励（6）** | 核心团队稳定性 | 2 | 核心高管离职率（%）；<10% 为优 |
| | 股权激励合理性 | 2 | 激励范围、行权条件、是否有"福利型"激励 |
| | 内部人增减持异常 | 2 | 高管/大股东是否有异常减持（布尔） |

**三档判定（框架行 280）**：

| `total` | `verdict` | 处置 |
| --- | --- | --- |
| ≥15 | 重仓 | 达标（可进入合成） |
| 10~14 | 观察 | **部分不达标 → 观察仓**（单只上限≤5%，不重仓） |
| <10 | 放弃 | **本技能级否决**（见"两套合成判定"节） |

### 第五步：科研转化 20 分制（8+8+4，科技股）

> **适用性**：行业类型为**科技股**时**必填**；普通行业不适用本清单时跳过本步，直接进第六步并**显式说明依据**。

**先调 ROIC 工具，再传值**（禁止在技能内重算 ROIC）：

```bash
# 资本回报项的三个数值必须先由工具产出
python tools/common/financial_rigor.py roic --nopat {NOPAT} --invested-capital {投入资本} [--wacc {WACC}]
python tools/common/financial_rigor.py wacc --equity-value {E} --debt-value {D} \
  --cost-equity {re} --cost-debt {rd} --tax-rate {t}
python tools/common/financial_rigor.py incremental-roic \
  --nopat-from {上期NOPAT} --invested-capital-from {上期投入资本} \
  --nopat-to {本期NOPAT} --invested-capital-to {本期投入资本} \
  --period-from {上期} --period-to {本期}
```

```bash
python tools/specialized/governance_data.py research \
  --rd-intensity {研发强度} [--rd-intensity-rising] \
  --capitalization-rate {资本化率} --rd-personnel-ratio {研发人员占比} \
  --patent-quality {优/中/差} --new-product-revenue-ratio {新产品收入占比} \
  --commercialization-cycle {优/中/差} --project-milestone {优/中/差} \
  --roic {工具输出} --wacc {工具输出} --incremental-roic {工具输出} \
  --as-of {YYYY-MM-DD}
```

**子项与依据要求**：

| 维度 | 子项 | 满分 | 依据要求 |
| --- | --- | --- | --- |
| **研发投入（8）** | 研发强度及逐年提升 | 3 | 研发费用 ÷ 营业总收入，**≥15% 且逐年提升**；**须标注口径**（研发费用口径 vs 研发投入口径，见"注意事项"） |
| | 资本化审慎 | 2 | 研发资本化率 **<30%** 为审慎 |
| | 研发人员占比 | 3 | 研发人员数 ÷ 员工总数，**≥30%** |
| **研发产出（8）** | 发明专利数量与质量 | 2 | 发明专利（非实用新型）数量、授权率、核心专利 |
| | 新产品收入占比 | 2 | **≥20%**；近 1~2 年新品贡献收入 |
| | 技术产品化周期 | 2 | 从研发到量产的时间趋势 |
| | 重大科研项目节点推进 | 2 | 在研项目节点兑现（`in_research_scan`） |
| **资本回报（4）** | ROIC > WACC | 2 | **严格大于**；数值来自 `roic` / `wacc` 工具输出 |
| | 增量 ROIC > 存量 ROIC | 2 | **严格大于**；数值来自 `incremental-roic` |

> **关键边界**：科研转化的资本回报项采 **「ROIC > WACC」**，**不含「≥10%」主阈值**——「≥10%」属支柱二主阈值（归 `garp-investment-checklist` P4-3 的 S2，且科技股按"调整后核心经营 ROIC"口径）。框架行 275 明示「科研转化清单『资本回报效率』项仍独立按『ROIC > WACC』判定」。

**三档判定**：同管理层规则（≥15 重仓 / 10~14 观察 / <10 放弃）。

### 第六步：两套合成判定（工具调用后，本技能承担）

**合成规则（框架行 280，禁止合计/加权）**：

| 行业类型 | 合成条件 | 合成结论 |
| --- | --- | --- |
| **科技股** | 管理层 ≥15 **且** 科研转化 ≥15 | 达标 |
| | 两套均 ≥15 但**其中一套命中诚信闸门** | 诚信否决 → 放弃 |
| | 两套均在 10~14 | 部分不达标 → **观察仓** |
| | 任一套 10~14（另一套 ≥15） | 部分不达标 → **观察仓** |
| | **任一套 <10** | **本技能级否决 → 放弃** |
| **普通行业** | 管理层 ≥15 | 达标 |
| | 管理层 10~14 | 部分不达标 → 观察仓 |
| | 管理层 <10 | **本技能级否决 → 放弃** |

**「本技能级否决」的表述纪律（须严格遵守）**：

1. 它是**本技能自身的否决**，**不并入** `garp-investment-checklist`（P4-3）的 V1~V4 编号体系（避免越界修改已交付技能）；
2. 报告中须显式标注「**支柱三级否决**」并写明触发原因（哪一套得分<10）；
3. 下游转接表中须显式列出该否决来源，与 V1~V4 并列但编号独立；
4. 与 P4-3 三档结论**不冲突**：P4-3 侧按"存在未满足项"处理（观察仓），本技能侧给出更强的"放弃"，二者不互相覆盖。

> **「放弃」的两种来源须区分**：① **诚信闸门命中**（`integrity_veto=true`）→ 最高优先级，直接放弃或清仓；② **本技能级否决**（20 分制 <10）→ 放弃。报告中必须写清来源，不得混用同一措辞。

### 第七步：费雪补充检查 + ESG 三通道 + "假如空仓"测试

**费雪补充检查（定性参考，不计分）**：

| 检查项 | 评估标准 | 处置 |
| --- | --- | --- |
| **销售组织出色** | 经销商覆盖密度、销售团队稳定性、销售费用率趋势、客户获取成本 | 数据不可得 → 标「**本项未判定**」，**不得默认通过** |
| **管理层持股比例高** | 核心管理层持股 **≥3%** | **<3% → 仅输出预警标注**（不扣分、不致退档），并写入"待跟踪信号" |

**ESG 三通道（此处只做识别与透传，不做折价计算）**：

```bash
python tools/specialized/governance_data.py esg \
  --env-risk-level {高/低} [--transition-pathway {明确/无}] \
  [--stranded-asset] [--esg-tail] [--position-cap-base 20.0] \
  --as-of {YYYY-MM-DD}
```

| 通道 | 处置 | 下游 |
| --- | --- | --- |
| **治理（G，最关键）** | **证据触发清单 + 人工确认闸门**：列出可核查证据（信息披露多次被问询/处罚、审计意见非标、关联交易异常、监管关注函等）→ 显式提示「**建议触发诚信否决**」→ **由人工确认**是否归入第三步闸门。**不臆造数值线** | 命中 → 归入诚信闸门 |
| **环境（E）** | 仅作**定性识别**（是否属高环境风险行业 + 是否有明确转型路径）→ 调 `esg` 工具**原样透传**修正量 | **折价归 `garp-valuation`（P4-5）** |
| **社会（S）** | 用工合规、产品质量与召回、供应链劳工等重大争议 → 计入风险提示 | 报告"风险提示"节 |
| **ESG 评级参考** | 第三方评级处行业尾部或最低档 → **透传**仓位上限下调量 | **数值收口归 `garp-portfolio-review`（P4-8）** |

**工具透传字段（原样展示，不得二次计算）**：`discount_factor` / `discount_pct` / `discount_range` / `discount_rate_adj_bps` / `discount_rate_adj_range_bps` / `position_cap_base` / `position_cap_after` / `position_cap_downgrade` / `esg_tail_triggered` / `stranded_asset_triggered`。

> **强制注意（框架行 318）**：ESG 评级各机构**口径不一、覆盖不全且存在时点滞后**，**只作辅助信号，不替代**基本面的诚信核查与财务验证。

**"假如空仓"测试**（克服沉没成本）：假设此刻空仓、无持仓成本，我还会以当前评分结论买入/继续持有吗？若答案是否定的 → 提示"结论与持仓状态存在偏离，须复核是否受沉没成本影响"。

### 第八步：收口、五矛盾化解与下游转接

**管理层维度的五个矛盾（GARP 版，其中第五项为本次新增的费雪视角）**：

| # | 矛盾 | 化解原则 |
| --- | --- | --- |
| 1 | 短期业绩 vs 长期战略投入 | 看战略投入是否转化为 3 年后的产能/产品/份额 |
| 2 | 股东回报 vs 再投资需求 | 成长期再投资优先；成熟期分红优先，用 ROIC 与增量 ROIC 判定 |
| 3 | 管理层激励 vs 股东利益 | 看激励的**行权条件**是否与 ROE/ROIC/营收挂钩，而非仅与股价挂钩 |
| 4 | 创始人权威 vs 治理制衡 | 看是否有独立董事实质作用、关联交易是否公允、审计意见是否干净 |
| **5** | **费雪"不卖"边界 vs 现实约束** | **费雪**主张对卓越管理层长期不卖；但 GARP 独立档为 1~5 年，须承认：若诚信受损、或科研转化连续两期 <15，则"不卖"不成立——**卓越管理层不构成免检牌** |

**季度复盘检查清单（管理层恶化信号）**：

| # | 信号 | 阈值/触发 |
| --- | --- | --- |
| 1 | 承诺兑现率下降 | 连续两期 <70% |
| 2 | 核心高管离职 | 关键岗位 1 年内变动 |
| 3 | 大股东质押率上升 | >50% |
| 4 | 分红政策变化 | 分红率大幅下调且无合理说明 |
| 5 | 研发强度下降 | 降至 15% 以下 |
| 6 | 新产品收入占比下降 | 连续两期下滑 |
| 7 | 增量 ROIC 低于存量 ROIC | 扩张效率退化 |
| 8 | ESG 评级下调 / 环境处罚 | 任一发生 |

**下游转接**：

| 结论 | 下游 |
| --- | --- |
| 两套均达标 / 部分不达标 | 分值交 `garp-investment-checklist`（P4-3）落位 S3；估值与 ESG 折价转 `garp-valuation`（P4-5） |
| 诚信闸门命中 | **转 `garp-exit`（P4-6）**：诚信否决层级 → 立即清仓信号 |
| 本技能级否决（<10） | 转 `garp-investment-checklist` 作为不达标项；同时提示 `garp-exit` 复核 |

## 工具使用指南

### 工具使用注意（实测已知，务必遵守）

1. **`financial_rigor.py calc` 不支持 `^` 幂运算符**——字符白名单为 `0123456789.+-*/() eE`，幂运算须写 `**`。
2. **PowerShell 下负号开头的表达式须加引号**：`--expr="-3+12"`，否则被误解析为参数。
3. **`roic` / `incremental-roic` 子命令不支持 `--as-of`**（实测报 `unrecognized arguments`）——数据截止日期须写在报告而非命令中。
4. **`governance_data.py` 三子命令可直接以脚本形式调用**（与 `geo_policy_screen.py scan` 不同，后者须 `-m` 模块形式）。
5. **`anysearch.py` 的 `--tag finance` 需要额外参数**（`symbol` / `type` / `cn_code`），否则报 HTTP 400；直接不带 `--tag` 或改用 `doubao_search.py`。

### `governance_data.py` 输出要点

| 子命令 | 关键字段 | 注意 |
| --- | --- | --- |
| `management` | `integrity_veto` / `integrity_veto_reasons` / `total` / `verdict` / `position_note` / `score_breakdown` | 闸门命中时 `total=null`、`score_breakdown={}`——**这是"禁止高分对冲"的机制保证**；`note` 字段提示费雪与 ESG 不计分 |
| `research` | `total` / `verdict` / `warning` / `score_breakdown` | **无诚信闸门**（诚信属 management 专属）；资本回报项**只做严格大于判定，不重算 ROIC** |
| `esg` | `discount_factor` / `discount_pct` / `position_cap_downgrade` / `position_cap_after` / `esg_tail_triggered` / `stranded_asset_triggered` | **非评分制**，无 `verdict` / `score_breakdown`；输出为修正量 |

| **MG-6** | 科研转化「资本回报效率」引用 ROIC 工具输出 | `roic` / `wacc` / `incremental-roic` 数值唯一来自 `financial_rigor.py`；不重算 ROIC、不引入「≥10%」主阈值 |
| **MG-7** | 费雪补充与 ESG 不计入 20 分制 | 二者均为定性参考；ESG 折价不在本技能计算 |
| **MG-8** | ESG 修正量只透传，不输出最终仓位数值 | `position_cap_downgrade` / `position_cap_after` 原样透传；**报告不得出现"建议单只上限 X%"** |
| **MG-9** | 估值与卖出层级不得内建 | 转 `garp-valuation` / `garp-exit`；本技能只输出转接信号 |
| **MG-10** | 数据截止日期强制标注 | 兑现率 / 质押率 / 离职率 / 研发强度 / 资本化率 / 新产品占比 / ROIC 系列均为**时变项**，结论仅对数据截止日期有效 |

## 注意事项

1. **「归因习惯」的 A-1 覆盖须留痕**——当 `integrity_veto_reasons` 仅含 `attribution_habit` 时，报告中必须写明：① 工具判为否决；② 本技能按框架行 282 的 4 项命中清单降为预警；③ 该差异已作为工具侧待补丁事项上报。**不得静默处理**。
2. **研发强度有两个口径，须标注**——「**研发费用 ÷ 营业总收入**」（费用化口径，较审慎）与「**研发投入 ÷ 营业总收入**」（含资本化与股份支付，口径较宽）。框架未指定时，**默认采用费用化口径**并在报告中标注；若采用较宽口径须说明理由与差异。
3. **`research` 工具 `note` 字段编号笔误 —— 已于 2026-09-17 修复（闭环）**：修复前原文写「与管理层 20 分制『两套都须≥15』的合成由 **P4-6** 技能编排承担」，按详细计划应为 **P4-4 `garp-management`**（P4-6 为 `garp-exit`）。经用户指令直接修正工具内 `RESEARCH_NOTE` 常量与模块 docstring 两处（`P4-6`→`P4-4`）；修复后 `note` 字段实测输出已更正、回归 `tests/specialized/test_governance_data.py` **113 passed**，**工具判分行为不变**。本技能**按 P4-4 承担合成**实现该功能。
4. **两种「放弃」的来源必须区分**——诚信闸门命中 vs 20 分制 <10（本技能级否决），措辞与下游动作不同（前者转 `garp-exit` 清仓，后者转 P4-3 记不达标）。
5. **单靠单项低分往往不足以致不达标**——实测显示：ROIC < WACC（该项 0 分）但其余项满分时，科研转化仍可得 18 分（重仓）。**结论须看总分，不得因单项低分就径行判退档**；反之，也不得因单项满分就忽略其他低分项。
6. **多地上市须分别取数**——同一公司的 A/H/美股股权与治理披露存在差异，须分别取证并显式标注口径。

## 局限性

1. **评分项的证据可得性不均**——质押率、管理层持股、经销商覆盖、ESG 摘录在部分公司披露不足；此时**只能标「未判定」**，结论的完备性随之下降。
2. **评分是时变项的确定性映射，不预测未来**——兑现率、离职率、研发强度均为历史数据；结论仅对数据截止日期有效（MG-10）。
3. **20 分制的权重是静态标签**——7+7+6 / 8+8+4 与 ≥15 / 10 阈值由框架固化、长期适用；但"取值判定"（如分红率 30% 为优）在不同行业存在合理弹性，本技能按框架统一口径执行，**不按行业自定义阈值**。
4. **侧面验证（员工/客户/经销商）为定性材料**——可交叉验证但不单独计分，其质量取决于检索可得性。
5. **ESG 评级信号滞后且口径不一**——框架行 318 已警示，本技能只作辅助，且**不承接折价计算**。
