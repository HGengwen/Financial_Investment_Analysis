# 供应链瓶颈猎手（中期版）(mid-bottleneck-hunter)

AI 驱动的全球产业链瓶颈套利（1~3 年景气投资版）：从超级趋势的「咽喉位置」挖掘第二、第三层投资机会，叠加景气度（渗透率/ROE/二阶导/订单能见度）与地缘六维评估，经 PEG 五档与 3 年隐含回报估值检查后输出瓶颈机会观察名单。属于中期链（1-3 年）功能技能，与长期 `bottleneck-hunter`（10 年）**物理隔离、功能互补**。

---

## 快速开始

### 基本调用方式

```
/mid-bottleneck-hunter {趋势名}
```

例如：
- `/mid-bottleneck-hunter AI基础设施`
- `/mid-bottleneck-hunter 创新药`
- `/mid-bottleneck-hunter 能源转型`
- `/mid-bottleneck-hunter 半导体再工业化`

支持可选参数：

```
/mid-bottleneck-hunter AI基础设施 --scope 全球 --depth standard --export
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `{趋势名}` | 位置参数（必填） | — | 超级趋势名，如「AI基础设施」「创新药」「能源转型」 |
| `--scope` | 字符串 | 全球 | 扫描范围：`全球`/`A股`/`港股`/`美股` |
| `--depth` | 字符串 | standard | `fast`（趋势确认+瓶颈识别+估值快筛）/ `standard`（+公司深度筛选+地缘六维+交叉验证+完整输出）/ `deep`（+在研项目扫描） |
| `--export` | 标志 | false | 导出 Markdown 报告至 `reports/` |
| `--json` | 标志 | false | 输出结构化 JSON |

> 注：以上为技能调用时的解析约定，映射到既有工具与执行流程，**不新增任何 Python 命令行开关**。

## 核心功能

对指定超级趋势执行供应链瓶颈扫描与套利机会发现，从物理供应链的咽喉位置出发，找出那些没人注意但一旦断货整个行业都得停下来等的公司，并判定瓶颈是否处于 1~3 年景气主升浪。

**一句话差异**：与长期版 `bottleneck-hunter`（10 年持有、PS/PE + 10 年 25x PE 退出）相比，本版本改为 1~3 年景气框架——叠加渗透率/ROE/二阶导/订单能见度景气度四维判断，估值用 PEG 五档 + **3 年隐含回报**，卖出引用 `exit-signal` P0~P5，报告路径物理隔离至 `reports/mid-bottleneck/`。

### 七步执行流程

1. **超级趋势确认** — 验证趋势的持续性/物理性/规模性/加速性，明确 1~3 年景气兑现窗口，输出渗透率位置与未来 3 年复合增速
2. **供应链物理拆解** — 从 Layer 0 终端拆到 Layer 4 基础设施，标注各环节景气指标
3. **瓶颈识别 + 景气度叠加** — 6 条标准判定「咽喉」，叠加四维景气度判断，输出 S/A/B 级瓶颈地图
4. **公司筛选 + 地缘六维** — 初筛（含业绩兑现硬指标）+ 深度筛选模板（ROE 趋势/地缘六维/华为式抗封锁）
5. **估值检查** — PS/PE/PEG 三重检查 + PEG 五档 + **3 年隐含回报**（必做）
6. **交叉验证** — 正向六维验证 + 芒格式反向否定 + 信号交叉验证
7. **输出瓶颈机会看板** — 排名表（含 PEG/景气度）+ 一页纸摘要 + 行动建议

### 存量更新（非每日扫描）

1~3 年投资不频繁扫描，本技能以**季度/月度增量更新**节奏维护瓶颈地图，无「每小时扫描模式」（与长期版物理隔离）。

## 研究标准

### 核心理念：不问"AI 推荐什么股票"，问"哪一环会先不够用"

超额收益来源：第一层瓶颈（GPU、HBM、电力）已被充分定价，真正的 alpha 在第二层、第三层——光模块、激光器、InP 衬底、SOI 晶圆、外延设备、晶圆级测试、IC 载板、特殊玻纤等环节。

### 瓶颈判定 6 条标准

| # | 标准 | 🔴 高瓶颈 | 🟡 中等 | 🟢 低瓶颈 |
|---|------|---------|---------|---------|
| 1 | 供给集中度 | ≤2家 | 3-5家 | >5家 |
| 2 | 扩产周期 | >2年 | 1-2年 | <1年 |
| 3 | 替代难度 | 不可替代 | 部分可替代 | 易替代 |
| 4 | 产能利用率 | >90% | 70-90% | <70% |
| 5 | 需求增速 | >50%/年 | 20-50% | <20% |
| 6 | 客户验证周期 | >1年 | 6-12月 | <6月 |

**瓶颈评级**：🔴≥4个 = S级（单点故障）/ 🔴3个 = A级 / 🔴1-2个 = B级

### 景气度四维叠加判断（1~3 年框架核心）

| 景气维度 | 判断 |
|---------|------|
| 渗透率位置 | 10%~30% 黄金区 → 加分；>50% 减速区 → 减分；<5% 且无 EPS/订单支撑 → 判题材（BN-2） |
| ROE 趋势 | 连续 3 季同向为准；向上 → 加分；拐头向下 → 警惕 |
| 二阶导 | 需求增速加快 → 加分；放缓 → 减分 |
| 订单能见度 | >6 个月 → 加分；3-6 个月 → 中性；<3 个月 → 减分 |

只有「瓶颈 S/A 级 + 景气度强」才进入重点扫描；瓶颈真实但景气度弱 → 标注「伪瓶颈」。

### PEG 五档估值（引用 valuation-thermometer）

| 档位 | PEG 区间（边界约定） | 操作指引 |
|------|----------------------|---------|
| 显著低估 | PEG < 0.8 | 绝佳买点，底仓可加 |
| 合理 | 0.8 ≤ PEG ≤ 1.2 | 正常建仓，分批买入 |
| 偏贵 | 1.2 < PEG ≤ 1.5 | 仅底仓持有，禁止加仓 |
| 高估 | 1.5 < PEG ≤ 2.0 | 逐步卖出机动仓 |
| 严重透支 | PEG > 2.0 | 加速清机动仓，绝不追高（BN-4） |

**3 年隐含回报**（估值安全边际，必做）：3 年后预计利润 × 合理远期 PE（渗透率越高/越接近兑现期越低）折现至当前，隐含年化回报 >25% 可建仓、15%~25% 一般、<15% 等待更好价格。同时保留 PEG 红灯底线（PEG>2.0 即使隐含回报高仍按透支处理）。

### 地缘政治六维度评估

海外收入占比（>60% 且无本地化 → BN-5 一票否决预警）/ 供应链依赖度 / 制裁/关税/出口管制风险 / 本地化对冲能力 / 自主研发能力（「华为式」抗封锁韧性：研发费用率>15% 逆周期不减、核心技术自主可控、备胎计划、极端生存能力）/ 综合评级。

## 核心原则

1. **不让 AI 推荐股票，让 AI 拆供应链** — 问题比答案重要
2. **物理优先 + 景气叠加** — 只关注需要实际物理产品/材料/设备的环节，且瓶颈真实 ≠ 投资时机
3. **第二层、第三层** — 不追已被充分定价的龙头
4. **交叉验证** — 每个结论至少 2 个独立信源
5. **诚实面对不确定性** — 找不到数据就写"数据不足"，不用推测填充
6. **瓶颈有时效性** — 每个瓶颈都会被解除，关键是判断 1~3 年持有周期内的时间窗口
7. **小市值≠好机会** — 必须过财务质量关
8. **瓶颈真实≠投资机会** — 估值是硬门槛（PS/PE/PEG + 3 年隐含回报）
9. **遵循客观性原则** — 不预设看多，先数据后结论
10. **连续 3 季不靠单季** — ROE 趋势、二阶导、业绩兑现以连续 3 季同向为准
11. **引用不重建** — PEG 引用 `valuation-thermometer`，卖出引用 `exit-signal`，买入前引用 `mid-investment-checklist`
12. **景气优先** — 产能紧张但 ROE 在下降，是伪瓶颈
13. **估值是硬门槛** — PEG>2.0 或仍在亏损，当前价格就不是买点

## 注意事项

- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- 开始前运行 `date` 确认当天日期，报告头部注明数据截止日期
- 关键财务数据必须至少来自两个独立来源交叉验证，误差 >1% 标记
- 渗透率数据按 A/B/C 三级置信度标注
- **中期术语红线**：禁止「护城河永续」「终局思维」「持有10年」「巴芒段李」等长期框架术语
- 估值安全边际用 **3 年隐含回报**，不得回退到长期版「10 年 25x PE」口径
- 所有硬性规则输出必须包含规则编号引用（如「触发 BN-3」）
- 本技能输出「观察名单」不是「买入清单」，买入前须执行 `/mid-investment-checklist` 七关检验
- 卖出决策以 `exit-signal` P0~P5 为唯一权威口径（时间止损并入 P2，不设独立层级）

## 局限性说明

- 数据依赖本地工具和 API 可用性
- 网络搜索接口在中国大陆网络连接可能不稳定
- 对于信息稀缺的环节，无法保证分析完整性
- 渗透率、ROE 趋势等景气数据可能需要依赖第三方估算，须标注置信度
- 国际市场覆盖可能因语言限制遗漏日韩台欧供应商
- AI 筛选偏见：可能存在龙头偏好、英文偏好、叙事偏好、确认偏见、时效偏见、景气线性外推
- 不构成投资建议，仅供学习研究参考
