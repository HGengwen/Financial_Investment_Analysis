# 供应链瓶颈猎手（中期版）：AI 驱动的全球产业链瓶颈套利（1~3 年景气投资版）

对指定超级趋势执行**供应链瓶颈扫描与套利机会发现**，从物理供应链的「咽喉位置」挖掘未被充分定价的第二层、第三层机会，并叠加 1~3 年景气投资框架（渗透率/ROE 趋势/二阶导/PEG/地缘六维）判定**瓶颈是否处于景气主升浪**。属于中期链（1-3 年）功能技能，与长期 `bottleneck-hunter`（10 年）**物理隔离、功能互补**，禁止使用「护城河永续」「终局思维」「持有10年」「巴芒段李」等长期框架术语。

> 💬 **林奇式提醒**：「你买入的不只是『瓶颈概念』——你买入的是一家具体公司的生意。这个生意是否可理解？PEG<1 才是真正低估的信号。」
>
> 💬 **郑希式提醒**：「瓶颈的真实性必须由 ROE 趋势验证——如果一家公司坐在最紧的瓶颈上，但 ROE 在下降，说明要么瓶颈在松动，要么管理层在浪费机会。」
>
> 💬 **欧奈尔式提醒**：「瓶颈逻辑再完美，如果股价已经透支了 3 年增长，当前价格也不是买点。8% 止损是你的生存红线。」
>
> 💬 **李进式提醒**：「渗透率突破 15% 后加速上行期重仓，达到 50%~60% 后逐步兑现。不仅看产业是否增长，更关注增速的加速度（二阶导）。」

## 设计原则

1. **物理优先 + 景气叠加**：从物理供应链找咽喉（Layer 2/3），但瓶颈真实 ≠ 投资时机，必须叠加景气度四维判断（渗透率位置/ROE 趋势/二阶导/订单能见度）。
2. **第二层、第三层 alpha**：第一层瓶颈（GPU、HBM、电力）已被充分定价，真正的 alpha 在光模块、激光器、InP 衬底、SOI 晶圆、外延设备、晶圆级测试、IC 载板、特殊玻纤等环节。
3. **引用不重建**：PEG 五档引用 `valuation-thermometer`，卖出优先级引用 `exit-signal` P0~P5，买入前检查引用 `/mid-investment-checklist` 七关，本技能不自建口径。
4. **连续 3 季不靠单季**：ROE 趋势、二阶导、业绩兑现一律以连续 3 季同向为准（对齐理念文档矛盾二），不靠单季数据下结论。
5. **禁止 LLM 心算**：PEG、复合增速、3 年隐含回报、分位等一切算术经 `financial_rigor.py`，报告不得出现手算数值。
6. **数据双源验证**：关键数据 ≥2 独立来源，误差 >1% 显式标记；渗透率按 A/B/C 三级置信度标注。
7. **输出观察名单，不是买入清单**：本技能只做瓶颈机会发现，候选标的须再过 `/mid-investment-checklist` 七关硬门槛方可建仓。
8. **双轨并存、物理隔离**：与长期 `bottleneck-hunter` 报告路径（`reports/bottleneck-map/`）隔离，中期版输出至 `reports/mid-bottleneck/{趋势名}/`。

## 能力圈声明

**本 Skill 适用场景**：

- 科技/医药/高端制造等景气成长赛道的供应链瓶颈机会发现；
- AI 基础设施、能源转型、半导体、创新药等需要物理硬件/材料/设备的超级趋势；
- 个人投资者 1~3 年中长期持有的标的初筛。

**本 Skill 不适用场景**：

- 纯周期股（钢铁、煤炭、航运等，需用周期估值法）；
- 困境反转股（需用资产清算法）；
- 金融股（银行/保险，需用 PB/ROE 法）；
- 被动指数投资；
- 短期交易/择时操作。

> ⚠️ **重要提示**：本 Skill 仅做瓶颈机会发现，输出的是「观察名单」不是「买入清单」。买入决策须执行 `/mid-investment-checklist`（七关硬门槛）检验。

## 核心判定规则（硬编码）

### 规则一：超级趋势确认（第一步）

#### 1.1 趋势筛选标准

不在小风口里找幻觉，只追符合以下全部条件的超级趋势（1~3 年景气兑现窗口须明确）：

| 标准 | 要求 | 验证方法 | 1~3 年框架关注 |
| --- | --- | --- | --- |
| 持续性 | 至少 3~5 年确定性增长 | 搜索行业预测、资本开支计划 | 本技能聚焦其中 1~3 年景气兑现窗口 |
| 物理性 | 需要实际硬件/材料/设备建设 | 区分「软件升级」和「物理扩建」 | 物理瓶颈才有扩产周期约束 |
| 规模性 | 全球资本开支 > 500 亿美元/年 | 搜索头部玩家 capex 指引 | TAM ≥ 1000 亿（对齐理念文档第 1 步） |
| 加速性 | 需求增速 > 供给扩产速度 | 对比需求增长率 vs 产能扩张计划 | 供需缺口是瓶颈的前提 |

> 💬 **李进式提醒**：「真实趋势必须有订单、收入、利润的客观数据支持，否则一律视为题材炒作，不参与。这是控制回撤的第一道防线。」

#### 1.2 当前跟踪的超级趋势清单

每次运行时更新，初始清单：

1. **AI 基础设施建设** — 数据中心、GPU 集群、网络互联、电力
2. **能源转型** — 核电重启、电网升级、储能
3. **国防现代化** — 西方军费上升周期、供应链重构
4. **半导体再工业化** — 美欧日补贴建厂、设备/材料瓶颈
5. **太空经济** — 卫星互联网、发射频次激增
6. **生物药/创新药** — 抗体/ADC/CAR-T/GLP-1 爆发、CDMO 产能紧张、培养基/层析树脂/病毒载体/预充注射器/放射性同位素瓶颈

如果用户指定了具体趋势（如「AI基础设施」），只聚焦该趋势。

### 规则二：供应链物理拆解（第二步）

#### 2.1 分层拆解框架

不停留在概念层，拆到物理实体。

```
Layer 0（终端）：最终产品/服务
    │
Layer 1（核心组件）：已被市场充分关注的核心硬件
    │                 ⬆ 定价充分，alpha有限
    │─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
    │                 ⬇ 关注度低，alpha集中区
    │
Layer 2（子组件/材料）：支撑核心组件的零部件和材料
    │
Layer 3（上游设备/原料）：制造子组件所需的设备和原材料
    │
Layer 4（基础设施）：电力、冷却、土地、人才、认证
```

#### 2.2 以 AI 基础设施为例的拆解模板（含景气指标）

```
Layer 0：AI模型训练/推理服务
Layer 1：GPU/加速器、HBM内存、服务器、数据中心
Layer 2（重点扫描区）：
  ├─ 网络互联：光模块、光纤、交换芯片、铜缆
  │   └─ 景气指标：800G/1.6T 光模块渗透率、出货量二阶导
  ├─ 光通信核心：激光器（EML/VCSEL/CW）、调制器、光探测器
  │   └─ 景气指标：激光器价格趋势、交期（周）
  ├─ 半导体材料：InP衬底、GaAs衬底、SOI晶圆、SiC衬底
  │   └─ 景气指标：衬底产能利用率、扩产周期
  ├─ 先进封装：CoWoS载板、HBM TSV、ABF基板膜
  │   └─ 景气指标：CoWoS 产能利用率（>90% 为紧绷）
  ├─ PCB/载板：高频高速PCB、IC载板、特殊玻纤布
  │   └─ 景气指标：特殊玻纤布价格、交期
  ├─ 测试：晶圆级测试（Probe Card）、老化测试、ATE
  │   └─ 景气指标：测试机台交期、利用率
  ├─ 散热/冷却：液冷系统、CDU、浸没式冷却液
  │   └─ 景气指标：液冷渗透率、订单能见度
  └─ 电力连接：母线槽、UPS、配电柜、变压器

  ├─ 外延设备：MOCVD、MBE
  ├─ 光刻/刻蚀：特殊波长光刻、InP刻蚀

  └─ 认证/标准：MSA标准、Telcordia认证

  ├─ 电力：核电、天然气发电、输变电
  ├─ 冷却水/散热基础设施
  └─ 数据中心土地/许可
```

#### 2.3 创新药的拆解模板（景气投资版）

在 1~3 年景气框架中，创新药瓶颈的分析必须纳入渗透率、临床进展、审批节奏等景气指标：

```
Layer 0：肿瘤/自免/罕见病/代谢病创新疗法
Layer 1：创新药产品（PD-1/PD-L1、ADC、CAR-T、双抗、GLP-1多肽药等）
Layer 2（重点扫描区，含景气指标）：
  ├─ 生物药生产：生物反应器、培养基、层析树脂/色谱填料、过滤膜
  │   └─ 景气指标：全球生物药渗透率、CDMO产能利用率
  ├─ CDMO服务：细胞系开发、工艺开发、商业化生产
  │   └─ 景气指标：CDMO订单增速、产能扩张计划（1~3年）
  ├─ 核心原料：抗体、病毒载体、连接子、毒素、核苷酸
  │   └─ 景气指标：核心原料价格趋势、供应商扩产节奏
  ├─ 细胞治疗：细胞培养基、细胞分离设备、冻存袋
  │   └─ 景气指标：CAR-T渗透率（当前<5%，仍处早期）
  ├─ 基因治疗：病毒载体（AAV/慢病毒）、质粒DNA
  │   └─ 景气指标：FDA/EMA基因治疗审批数量趋势
  └─ 制剂包装：预充注射器、特种硼硅玻璃瓶、自动注射器
      └─ 景气指标：GLP-1渗透率（当前~3%，加速中）
Layer 3：
  ├─ 设备：生物反应器、层析系统、超滤/纳滤设备
  ├─ 原料：培养基组分、层析树脂原料、特种化学品
  └─ 认证：GMP认证、FDA/EMA/NMPA审批
Layer 4：
  ├─ 临床试验：患者招募、临床基地、CRO服务
  ├─ 冷链物流：2-8°C温控运输、干冰供应
  └─ 人才：生物工艺工程师、GMP操作人员（全球性短缺）
```

> 💬 **李进式提醒**：「创新药的渗透率判断比消费电子更复杂——要看『渗透率曲线』（已获批适应症的覆盖速度）而非装机率。一个治疗领域渗透率达到 30% 时，意味着绝大多数适用患者已得到治疗，增速将放缓。同时，『二阶导』要看每个季度的新增患者数——即使累计渗透率仍在上升，新增患者数减少预示景气拐点。」

### 规则三：瓶颈识别 + 景气度叠加判断（第三步）

#### 3.1 瓶颈判定 6 条标准

对 Layer 2-3 的每个环节，逐条评估：

| # | 标准 | 问题 | 得分 |
| --- | --- | --- | --- |
| 1 | **供给集中度** | 全球供应商 ≤ 3 家？ | 🔴 ≤2家 / 🟡 3-5家 / 🟢 >5家 |
| 2 | **扩产周期** | 新增产能需要多久？ | 🔴 >2年 / 🟡 1-2年 / 🟢 <1年 |
| 3 | **替代难度** | 能否用其他技术/材料替代？ | 🔴 不可替代 / 🟡 部分可替代 / 🟢 易替代 |
| 4 | **产能利用率** | 当前产能利用率？ | 🔴 >90% / 🟡 70-90% / 🟢 <70% |
| 5 | **需求增速** | 下游需求增速？ | 🔴 >50%/年 / 🟡 20-50% / 🟢 <20% |
| 6 | **客户验证周期** | 新供应商进入需要多久验证？ | 🔴 >1年 / 🟡 6-12月 / 🟢 <6月 |

**瓶颈评级**：

- 🔴 ≥4 个 → **S 级瓶颈**（单点故障级，最高优先级）
- 🔴 3 个 → **A 级瓶颈**（严重受限）
- 🔴 1-2 个 → **B 级瓶颈**（有压力但可控）
- 无 🔴 → 非瓶颈，跳过

#### 3.2 瓶颈景气度叠加判断（1~3 年框架核心新增）

瓶颈评级 ≠ 投资时机。必须叠加景气度四维判断：

| 景气维度 | 问题 | 判断 |
| --- | --- | --- |
| **渗透率位置** | 该瓶颈所在产业处于渗透率什么位置？ | 10%~30% 黄金区 → 加分 / >50% 减速区 → 减分 / <5% 过早 → 判题材（BN-2） |
| **ROE 趋势** | 该环节头部企业 ROE 向上还是向下？（连续 3 季同向为准） | 向上 → 加分 / 拐头向下 → 警惕信号 |
| **二阶导** | 需求增速在加快还是放缓？ | 正二阶导 → 加分 / 负二阶导 → 减分 |
| **订单能见度** | 头部企业订单排期到多久？ | >6 个月 → 加分 / 3-6 个月 → 中性 / <3 个月 → 减分 |

**综合评级**：瓶颈评级（S/A/B）+ 景气度（强/中/弱）= 综合优先级。

- 只有「瓶颈 S/A 级 + 景气度强」才进入重点扫描；
- 瓶颈真实但景气度弱（ROE 下行/渗透率 >50%）→ 标注「伪瓶颈」，不纳入观察名单。

### 规则五：估值检查（必须执行，不可跳过）

瓶颈真实 ≠ 投资机会。必须对每家公司计算 PS、PE、PEG 并标注在报告中。

#### 5.1 PEG 五档估值（引用 valuation-thermometer，不重复定义）

PEG 档位的**唯一权威口径来自 `valuation-thermometer`**，本技能不重复定义。先调用 `valuation-thermometer` 获得五档温度，再据此判定。速览如下（以 `valuation-thermometer` 为准）：

| 档位 | PEG 区间（边界约定） | 操作指引 |
| --- | --- | --- |
| 显著低估 | PEG < 0.8 | 绝佳买点，底仓可加 |
| 合理 | 0.8 ≤ PEG ≤ 1.2 | 正常建仓，分批买入 |
| 偏贵 | 1.2 < PEG ≤ 1.5 | 仅底仓持有，禁止加仓 |
| 高估 | 1.5 < PEG ≤ 2.0 | 逐步卖出机动仓 |
| 严重透支 | PEG > 2.0 | 加速清机动仓，绝不追高（BN-4） |

> **边界约定**：PEG=0.8、1.2 归「合理」；PEG=1.5 归「偏贵」；PEG=2.0 归「高估」。任意 PEG 值有唯一档位归属。
>
> **主锚选择**（常规增长走 PEG、爆发期走 PSG、增速≤0 判「不适用 PEG」）及 PE 分位/implied-growth 交叉校验降级规则，**一律按 `valuation-thermometer` 执行**，本技能不复制其逻辑。

#### 5.2 估值红灯（满足任意一条 → 信号强度封顶 ★★，标注"⚠️ 估值透支"）

1. **市值 > TAM 的 20%**：公司市值已超过其可触达市场规模的 20%；
2. **PS > 30x 且 收入增速 < 100%**：高估值但增速不足。增速>100% 可豁免 PS 红线；
3. **市值 > 5 年乐观收入预测的 10 倍**：即使最乐观假设全部兑现，定价仍然过高；
4. **增发后 60 天内股价翻倍**：情绪驱动特征明显；
5. **PEG > 2.0（严重透支）**：当前 PE 已是未来 2 年预期增速的 2 倍以上。

#### 5.3 估值黄灯（需要额外解释）

1. 亏损 + PS > 15x：必须说明盈利路径和时间表；
2. PS 是同行盈利公司的 5 倍以上：必须解释溢价来源；
3. PE > 80x：需要计算 PEG 并说明增速是否支撑；
4. PEG 1.5~2.0（高估）：估值偏高但增速可覆盖。

#### 5.4 估值绿灯（加分项）

- PS < 10x 且收入在增长 → 信号强度可加一级；
- PE < 30x 且竞争格局稳定 → 标注「估值具有安全边际」；
- PEG < 0.8（显著低估）→ 标注「林奇式绝佳买点」；
- PEG 0.8~1.2（合理）→ 标注「合理估值区间」。

#### 5.5 估值安全边际检验：3 年隐含回报（必做，1~3 年框架核心口径）

**替代长期版「10 年后 25x PE 退出」口径**，采用 V2.0 的「远期 PE + 渗透率」：

```
回答："以当前市值买入，3 年后以合理远期 PE 退出（渗透率越高/越接近兑现期，远期 PE 越低），隐含年化回报是多少？"

计算方法（全部经 financial_rigor.py，禁止 LLM 心算）：
  1. 未来 3 年复合增速：经 financial_rigor.py calc 计算（一致预期或历史 3 年复合）
  2. 3 年后预计净利润 = 当前净利润(TTM) × (1 + 复合增速)^3
  3. 合理远期 PE：按渗透率阶段与行业可比公司取值（渗透率 10~30% 黄金区给中高 PE，
     渗透率 >50% 兑现期下修至行业中枢）
  4. 3 年后预计市值 = 3 年后预计净利润 × 合理远期 PE
  5. 隐含年化回报 = (3 年后预计市值 / 当前市值)^(1/3) - 1

判定：
  - 隐含年化回报 > 25% → 具备安全边际，可建仓
  - 15%~25% → 安全边际一般，等待更好价格或小仓试探
  - < 15% → 不具备安全边际，标注「当前价格不具备安全边际」

同时保留 PEG 红灯底线：PEG > 2.0 即使隐含回报高，仍按估值透支处理（BN-4）。
```

> 💬 **林奇式追问**：「这家公司的 PEG 是多少？如果 PEG>2，即使增速很快，当前价格也不是好买点。记住：PEG<1 才是真正低估的信号。」
>
> **注意**：估值检查的目的是防止推荐「PS 100 倍的亏损公司」，关键是增速、TAM、竞争格局、渗透率位置能否支撑当前估值。

## 风控硬编码（BN-1~BN-10，不允许 AI 自由裁量）

以下规则**不允许 AI 自由裁量**，必须严格执行。编号采用 BN-* 前缀，避免与 `mid-industry-funnel` 的 F-*、`mid-industry-research` 的 R-*、`mid-investment-checklist` 的 MC-* 冲突：

| 编号 | 规则 | 不可做的事 |
| --- | --- | --- |
| BN-1 | 趋势证据不足（<3 个验证事件或供需缺口不确定）→ 终止扫描 | 不得对证据不足的趋势执行供应链拆解 |

## 仓位与买卖纪律（1~3 年框架核心新增）

### 仓位结构分离（对齐理念文档第四部分）

| 仓位类型 | 比例 | 定位 | 操作规则 |
| --- | --- | --- | --- |
| 底仓 | 60%~80% | 赚企业 1~3 年成长的钱 | 长持，忽略短期波动，仅在基本面恶化或 PEG>2.0 时卖出 |
| 机动仓 | 20%~40% | 赚估值波动的钱 | 波段，PEG>1.5 分批止盈，硬止损坚决执行 |

**单只/单行业上限（硬编码）**：单只初始 ≤10%、验证后 ≤15%、绝对 ≤20%；单一行业 ≤40%；持股 5~10 只。

### 左侧布局 vs 右侧重仓（对齐理念文档第三部分）

| 阶段 | 特征 | 策略 | 仓位上限 |
| --- | --- | --- | --- |
| 左侧布局 | 行业短期利空但长期逻辑未破坏，渗透率<15%，估值合理 | 小仓试探，越跌越买（需仓位状态表支持） | 该标的最终仓位的 50% 以内 |
| 右侧确认 | 渗透率突破 15% 临界，财报连续 2 季加速，行业景气明确上行 | 一次性建 2/3 仓位，剩余 1/3 回调至 20 日均线补齐；设 8%~10% 止损 | 60% |
| 高潮/透支 | 渗透率>50% 或 PEG>1.5，情绪亢奋 | 只卖不买，机动仓止盈，底仓设移动止盈 | 降仓 |

### 分批建仓规则（1/3 → 1/3 → 1/3）

- 当股价进入「合理买入区间」后，先建 **1/3 底仓**；
- 若股价继续回调至合理区间下限以下（如 PEG<0.7），再加 **1/3**；
- 确认产业景气加速或财报超预期后，补齐剩余 **1/3**。

### 决策优先级金字塔（引用 exit-signal P0~P5，不重建）

| 级别 | 触发条件 | 决策 | 思想来源 |
| --- | --- | --- | --- |
| P0 治理一票否决 | 管理层失信、财务造假实锤、监管立案 | 立即清仓，不看估值趋势 | 李进（治理） |
| P1 硬止损 | 单笔亏损 8%~10%，且无基本面反转信号 | 无条件止损 | 欧奈尔 |
| P2 逻辑止损 | 连续 2 季业绩低于预期且产业景气未改善；**或持有满 4 季度逻辑未兑现（时间止损）** | 减仓或清仓 | 林奇 + 郑希 |
| P3 产业景气拐点 | 渗透率减速（二阶导转负）/ ROE 拐头向下 | 减机动仓 | 李进 + 郑希 |
| P4 估值透支 | PEG > 1.5（减机动仓）；PEG > 2.0（加速清机动仓） | 减/清机动仓 | 林奇 |
| P5 性价比替换 | 其他标的 PEG 显著更低且产业趋势更强 | 调仓（每季度最多 1 次） | 机会成本 |

> 铁律：上层未通过，下层不讨论。治理暴雷，估值再低也不碰；检查顺序固定 P0→P5，命中即停；时间止损并入 P2，不设独立层级。卖出决策以 `exit-signal` 为唯一权威口径。

### 止损 vs 越跌越买：仓位状态决策表

| 仓位状态 | 跌幅 | 逻辑状态 | 操作 |
| --- | --- | --- | --- |
| 建仓初期（<最终仓位 50%） | -8% | 任意 | 硬止损离场（欧奈尔优先） |
| 底仓已建（≥最终仓位 50%） | -10%~-20% | 逻辑完好，仅情绪杀 | 估值下限附近加仓 |
| 任意仓位 | 任意 | 逻辑证伪（技术路线被替代） | 立即清仓（不等反弹） |
| 持有 > 4 季度 | 横盘 | 逻辑未兑现 | 时间止损（调仓换股，归入 P2） |

### 「假如空仓」测试

> 灵魂拷问：「如果我现在持有现金，以当前价格、当前基本面，我还会买入这只股票吗？」
> - YES → 继续持有/加仓。
> - NO → 无论盈亏，必须减仓或清仓（克服沉没成本的最强工具）。

## 四大矛盾化解（对齐理念文档第五部分）

| 矛盾场景 | 冲突点 | 化解方案 |
| --- | --- | --- |
| 买点哲学冲突 | 欧奈尔要突破买，林奇要低估买 | 杀估值（PEG<0.8）→ 林奇左侧买；杀逻辑（景气证伪）→ 欧奈尔止损 |
| 持有时间冲突 | 郑希看 3 年周期，欧奈尔看 3 月趋势 | 连续 3 季数据：趋势向上 → 郑希持有；连续 2 季下滑 → 欧奈尔减仓 |
| 止损 vs 越跌越买 | 李进要控回撤，林奇要逆向 | 仓位状态变量：建仓初期（<最终仓位 50%）→ 止损优先；底仓已建且三维度未恶化 → 估值下限加仓 |
| 分散 vs 集中 | 李进要分散，郑希要集中 | 行业分散控回撤（单行业≤40%），个股集中求收益（单只≤20%），行业相关系数<0.5 |

### 7.1 每次运行时的增量更新

   - 搜索最近 30 天的 supply chain / shortage / bottleneck 新闻；

3. 更新瓶颈评级（升级/降级/解除）。
4. 更新景气度：渗透率变化、ROE 趋势变化、二阶导变化、订单能见度变化。

## 核心原则（最高优先级）

1. **不让 AI 推荐股票，让 AI 拆供应链** — 问题比答案重要；
2. **物理优先** — 只关注需要实际物理产品/材料/设备的环节；
3. **第二层、第三层** — 不追已被充分定价的龙头；
4. **交叉验证** — 每个结论至少 2 个独立信源；
5. **诚实面对不确定性** — 找不到数据就写「数据不足」，不用推测填充；
6. **瓶颈有时效性** — 每个瓶颈都会被解除，关键是判断 1~3 年持有周期内的时间窗口；
7. **小市值≠好机会** — 小市值也可能是烂公司，必须过财务质量关；
8. **瓶颈真实≠投资机会** — 必须过估值关（PS/PE/PEG 三重检查 + 3 年隐含回报）；
9. **遵循客观性原则** — 不预设看多，先数据后结论；
10. **网络搜索时效性** — 使用 `--time-range month/week` 限制时间范围；
11. **非境内上市双源验证** — 港股须 doubao+tavily；美股须 exa+doubao；
12. **景气优先** — 瓶颈逻辑必须由 ROE 趋势、渗透率、二阶导验证。产能紧张但 ROE 在下降，是伪瓶颈；
13. **估值是硬门槛** — 一家公司可以坐在最紧的瓶颈上，但如果 PEG>2.0 或仍在亏损，当前价格就不是买点。

## 注意事项

1. 开始前运行 `date` 确认当天日期，报告头部注明数据截止日期。
2. 关键财务数据须至少两个独立来源交叉验证，误差 >1% 须标记。
3. 禁止 LLM 心算，所有 PEG/复合增速/3 年隐含回报/分位经 `financial_rigor.py`。
4. 渗透率数据按 A/B/C 三级置信度标注，C 级不得作确定性结论。
5. 禁止使用 WebSearch / WebFetch 工具（中国大陆不可用），统一用 anysearch/doubao_search/exa_search/tavily_search/web_search。
6. **中期术语红线**：禁止出现「护城河永续」「终局思维」「持有10年」「巴芒段李」等长期框架术语。
7. PEG 五档、卖出 P0~P5、买入前检查分别以 `valuation-thermometer`、`exit-signal`、`mid-investment-checklist` 为唯一权威口径，本技能引用不重复定义。
8. 估值安全边际用 **3 年隐含回报**（远期 PE + 渗透率），不得回退到长期版「10 年 25x PE」口径。
9. 地缘政治风险评估必须包含：海外收入占比、主要市场、制裁/关税风险、本地化对冲能力、自主研发能力（「华为式」抗封锁韧性）。
10. 景气度判断必须包含：渗透率位置、ROE 趋势（连续 3 季同向）、二阶导方向、订单能见度。

## 局限性说明

1. 数据依赖本地工具和 API 可用性。
2. 网络搜索接口在中国大陆网络连接可能不稳定。
3. 对于信息稀缺的环节，无法保证分析完整性。
4. 渗透率、ROE 趋势等景气数据可能需要依赖第三方估算，须标注置信度。
5. 本 Skill 仅做瓶颈机会发现，输出「观察名单」，买入决策须执行 `/mid-investment-checklist` 七关检验。
6. 不构成投资建议，仅供学习研究参考。

## 附录 B：一页纸操作备忘卡

```
【发现瓶颈】
- 从 Layer 2/3 找没人注意但断货就停线的环节
- 瓶颈评级 S/A 级 + 景气度强 → 进入下一步
- 渗透率 10~30% 加分，>50% 减分，<5% 无 EPS 支撑判题材

【筛选公司】
- 初筛：上市 + 瓶颈业务>30% + 业绩兑现（近 2 季收入增速>行业平均）
- 估值：PEG<1.2 可建仓，PEG>1.5 减机动仓，PEG>2.0 清机动仓；3 年隐含回报>25% 可建仓
- 地缘：海外收入占比、制裁风险、自主研发能力六维度评估

【交叉验证】
- 正向：客户/收入/价格/产能/资本/景气六维验证
- 反向：聪明人为什么不买？瓶颈能被绕过吗？

【输出】
- 排名表：含 PEG、景气度、信号强度
- 一页纸摘要：含景气度快照、地缘风险、卖出触发提示

【买入前必做】
- 执行 /mid-investment-checklist 七关检验
- "假如空仓"测试：如果我现在空仓，还会买这家公司吗？

【持有中监控】
- 每季度更新景气度（渗透率/ROE/二阶导/订单）
- 关注地缘政治变化（关税/制裁/供应链）
- 检查估值水位（PEG 是否进入高估区）

【卖出触发（按优先级，引用 exit-signal）】
- P0 管理层失信/财务造假 → 立即清仓
- P1 硬止损 8~10% → 无条件离场
- P2 连续 2 季业绩低于预期+景气未改善 → 减仓/清仓（时间止损并入 P2）
- P3 渗透率>50%+增速放缓 → 减机动仓
- P4 PEG>1.5 → 减机动仓；PEG>2.0 → 加速清机动仓
- P5 性价比替换（PEG 差距>0.3） → 逐步切换，每季度最多 1 次
```
