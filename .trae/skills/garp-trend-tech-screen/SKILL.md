# GARP 景气趋势筛选（1~5 年）：四层递进 + 五维打分 + 0.3 地缘矩阵 + 宏观校准

对 $ARGUMENTS 执行 GARP 景气趋势筛选。本技能是**筛选与排序层（全档位通用入口之一）**——对「公司 / 行业 / 指数 / 主题」执行**四层递进 + 五维加权打分**的**正向排序**，输出 S/A/B/C 评级与反证清单，回答「**当下哪些标的景气与趋势最强、该怎么排序**」。

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

**支持输入格式**（四模式）：

| 输入方式 | 示例 | 说明 |
| --- | --- | --- |
| **个股** | `腾讯, 美团, 英伟达` | 逐家筛选 |
| **行业** | `AI 光模块` `半导体设备` | 先取该行业主要上市公司清单（10~20 家），再逐家筛选 |
| **指数** | `科创50` `纳斯达克100` | 拉取成分股清单，逐家筛选 |
| **主题** | `全球AI算力链` `中国国产替代50强` | 先检索主题相关公司，再逐家筛选 |

行业 / 指数 / 主题模式下，输出额外包含：**通过率统计、行业内排名、景气一致性判断、板块对比总结**。

> **本技能不提供档位切换参数**——它即 GARP 独立档（1~5 年）趋势筛选专属入口，命令与输入中**不含任何档位切换开关**；档位切换类口令属其他档位口径，出现即违反**口径隔离**纪律。

## 设计原则

1. **正向排序而非逐层收敛**：本技能**无层间配额**（区别于行业漏斗），只做**排序**；**仅第一层做淘汰**，其余层只打分 / 降级，淘汰与降级须给出**规则编号**与**证据行**。
2. **引擎零改动、签名冻结**：`trend_tech_screen.py` 的 `score` / `batch` 参数名、语义、权重算法**一律不改**；本技能**不新增任何 Python CLI 参数**，只负责**采集与口径映射**；引擎输出即终值，**禁止 LLM 复算或改写**（`GTS-7`）。
3. **地缘口径唯一为 0.3 三维交叉矩阵 + 赛道两分法**：矩阵作**档位归属 / 闸门**（`GTS-3`），引擎 `--geo` 通道采**中性占位（系数 1.00）**；骨架旧的两轴乘数口径**整段废止、不得再参与打分**。
4. **宏观只调参数、不改基本面**：叠加宏观三表（利率 / 经济 / 美林）校准**调整后 PEG 合理区间、现金仓位与单只上限**；参数一律经 `garp-macro`（P4-2）与 `macro_calibrator.py` **只读透传**，本技能**不判 stage、不心算**。
5. **估值零结论、零算式**：⑤估值维度得分由 `garp-valuation`（P4-5）**统一六档 + 多工具矩阵**结论**映射**而来；本技能**不重述档位表**，且 `--dims.e` **不得替代**正式估值结论。
6. **卖出只引不重建**：技术面校验仅作**引擎内评级降级与风险提示**；正式卖出 / 止损**一律转接** `garp-exit`（P4-6）五级（诚信否决 / 硬止损 / 逻辑止损 / 产业景气 / 估值）+ 4 季度时间止损 + ATR 动态止损（经其转接 `momentum.stop_price()`），本技能**不自建止损链**。
7. **费雪质化验证不计分**：五维之外增设**第六层**（质化四问 + 闲聊法 + 「绝不卖」两前提），仅对 S/A 级执行；**引擎五维不新增维度**。
8. **禁止 LLM 心算 + 双源交叉验证**：调整后 PEG、市值、CAGR、隐含增速、加权打分一律经 `financial_rigor.py` 或引擎（`GTS-7`）；关键数据 ≥2 独立来源，误差 >1% 显式标记；制裁清单 / 出口管制 / 关税 / 国产化率 / 渗透率均为**时变项**，评估前须**实时核验**，禁用历史清单。
9. **不越权替代买入门槛**：本技能只做正向排序；S/A 级**强制转接** `garp-investment-checklist`（P4-3）七关，**S 级不得直接视为可买入**（`GTS-11`）。
10. **前向引用只指向名称**：下游 GARP 技能**仅指向名称、不描述内部流程**。

## 核心判定规则（硬编码）

### 规则零：产业链周期定位与权重调整（含渗透率五档交叉验证）

在执行任何筛选之前，先判断标的所处产业链周期阶段；不同阶段赋予不同指标更高权重。**本层仅调整 ①②⑤ 权重，不淘汰任何标的。**

```bash
python tools/common/doubao_search.py "{行业名} 产能利用率 排产 订单排期" --time-range month
python tools/common/doubao_search.py "{行业名} 库存水位 去库存 周转天数" --time-range month
python tools/common/doubao_search.py "{行业名} 涨价函 价格走势 价格谈判" --time-range month
python tools/common/doubao_search.py "{行业名} 资本开支 扩产 设备投资" --time-range month
```

| 定位维度 | 关键搜索词 | 需求爆发期信号 | 供给受限期信号 | 成熟稳定期信号 |
| :--- | :--- | :--- | :--- | :--- |
| **产能利用率** | `产能利用率 排产` | > 85% 且排产满 | > 90% | < 70% |
| **库存水位** | `库存水位 周转天数` | 同比下降 > 15% | 极低库存（< 30 天） | 同比持平或上升 |
| **产品价格** | `涨价函 价格走势` | 主流产品发布涨价函 | 价格持续攀升 | 价格战 / 以价换量 |
| **资本开支** | `资本开支 扩产计划` | 头部公司大幅扩产 | 扩产受限（环保 / 设备卡脖子） | 扩产谨慎 |

**周期性权重调整表（引擎内置，本技能不重定义）**：

| 周期阶段 | 判断标准 | 权重调整（引擎 `--cycle`） |
| --- | --- | --- |
| **需求爆发期** | 下游需求暴增，订单能见度极高 | ① 35→**42**；② 25→**18** |
| **技术跃迁期** | 新技术替代旧技术，行业标准重塑 | ② 25→**32**；① 35→**28** |
| **供给受限期** | 关键原材料 / 设备被卡 | 地缘 0.3 矩阵**闸门权重提升**（不再使用乘数） |
| **成熟稳定期** | 行业格局稳定，增长靠份额提升 | ⑤ 10→**15** |

> **默认纪律**：若无法明确判断周期阶段，**默认采用「需求爆发期」**权重分配，并标注「周期阶段未确认」；权重调整**仅影响 ①②⑤**，不影响 ③④。

**渗透率五档交叉验证（GARP 新增，框架行 192）**——渗透率定位**产业所处阶段（管「何时买」）**，与国产化率（管「标的成长弹性」）分工不同：

| 渗透率区间 | 阶段定位 | 处置 |
| --- | --- | --- |
| **< 5%** | 导入早期（不确定性高） | 观察不建仓 |
| **5%~15%** | 突破期（高弹性） | 小仓跟踪 |
| **15%~40%** | **加速上行期（黄金窗口）** | **主建仓** |
| **40%~60%** | 逐步兑现期 | 持有，不再新建仓 |
| **> 60%** | **天花板**（即便增速暂未转负也不加仓） | 见顶以**增速归零 / 转负**为准 → 清仓 |

> **执行纪律**：渗透率取不到时标注「**未验证**」+ 区间上下限，**不默认落黄金区**；国产化率参照由 `garp-geo-policy`（P4-1）四梯队口径供给，本技能**不重做测算**。

### 规则一：前置硬性淘汰（骨架三条 + GARP 诚信一票否决）

满足以下任一条件，**直接淘汰，不再进行后续打分**：

| # | 前置淘汰条件 | 判断逻辑 / 数据来源 | 编号 |
| :--: | --- | --- | :--: |
| 1 | **被列入实体清单 + 核心环节国产化率 < 30% + 无非制裁海外有效实体**（既无硬替代，又无软迂回，彻底封死） | 年报「供应链风险」章节 + 子公司列表核查 | `GTS-1` |
| 2 | **核心技术人员流失 > 30% 且人均创利连续 2 年暴跌 > 40%**（人才体系崩塌，不可逆） | 年报「员工情况」历年对比 + 财务数据 | `GTS-1` |
| 3 | **在手订单（合同负债）同比 < −50% 且存货周转天数同比增加 > 80%**（订单崩盘 + 库存爆仓） | 季报合同负债 + 存货周转率 | `GTS-1` |
| 4 | **诚信一票否决**：年报承诺兑现率 < 50% / 业绩预告重大失真 / 财务造假实锤 / 监管立案 | 年报承诺兑现比对、互动易、监管处罚记录（框架优先级 1，行 477~479） | `GTS-2` |

> **关键修正（继承骨架）**：被制裁本身**不再**是一票否决项——制裁可以倒逼出更强的自主创新。我们只淘汰「被制裁后毫无应对能力」的公司。
> **诚信闸门的刚性**：诚信问题命中即**淘汰或清仓**，**五维高分、R8 奖励、费雪质化层均不得豁免**（`GTS-2`）。

### 规则二：五维加权打分（引擎调用 + 口径映射）

| 维度 | 基准权重 | 周期调整 | GARP 化口径（本技能） |
| :--- | :--: | :--- | --- |
| **① 景气前瞻** | **35 分** | 需求爆发期 → **42 分** | 订单 / 合同负债增速、政策环境、毛利率边际、供应链话语权 —— 口径保留，**增补渗透率五档交叉验证**（15%~40% 黄金窗） |
| **② 研发执行力与转化** | **25 分** | 技术跃迁期 → **32 分** | MROI、新品占比、落地速度、存货匹配、自主替代分级、供应链备选 —— **自主替代分级重锚至国产化率四梯队 + 支柱五政策与资本覆盖度**（门禁 H-1） |
| **③ 人才质量与密度** | **15 分** | — | 人均创利增速、人才密度、团队稳定与薪酬 —— 口径保留；**完整管理层评分归 `garp-management`**，本技能只取人才子项 |
| **④ 动量与市场共识** | **15 分** | — | 250 日 SMR、RSI(50)、盈利预测上调、低关注度溢价 —— 口径保留；骨架「RPS / CAN-SLIM」项目内**无实现**，以 `stock_quote --momentum` 与 `trend-momentum-scan` 替代并标注（口径缺口） |
| **⑤ 估值安全垫** | **10 分** | 成熟稳定期 → **15 分** | **口径替换**：得分由 `garp-valuation` **统一六档 + 多工具矩阵**结论**映射**（门禁 D-1） |

> **`--dims` 填报刻度（刚性，`GTS-10`）**：引擎对 `--dims` 的 a~e **不做归一化、不做加权乘法**——它按 `CYCLE_WEIGHTS[cycle]` 给出的**各维度满分**逐项校验后**直接求和**（`base_total = Σ dims`；负数钳制为 0；**超过周期满分的部分不截断**，以保留已并入维度得分的奖励分）。据此：
>
> - **各维度必须按「该周期下的满分刻度」填报**，四个周期的满分表固定为：

| 周期阶段 | a ①景气前瞻 | b ②研发转化 | c ③人才密度 | d ④动量共识 | e ⑤估值安全垫 | 合计 |
| --- | :--: | :--: | :--: | :--: | :--: | :--: |
| **需求爆发期**（= 引擎默认） | **42** | **18** | 15 | 15 | 10 | 100 |
| **技术跃迁期** | **28** | **32** | 15 | 15 | 10 | 100 |
| **成熟稳定期** | 35 | 25 | 15 | 15 | **15** | 100 |
| **供给受限期** | 35 | 25 | 15 | 15 | 10 | 100 |

> - **禁止按 0~100 单项刻度填报**（会使 `base_total` 膨胀到数百，评级恒为 S——本项为已知引擎特性，非可选项）；
> - 维度内的各项奖励分（供应链备选 +1~+3、研发费用率 +1、低关注度 +2、行业景气一致性 ±2、盈利超预期 +1）**先并入该维度得分后再传入**，**不得另设键位**；
> - **`--r8` 的 R8 奖励分不得重复计入 `--dims.b`**：该奖励分由引擎在求和之后单独叠加（`final_score = (base_total + r8_bonus) × 1.00`），技能侧**只传 `--r8` 五子项、不再手工加分**。

**① 景气前瞻维度（35 分；需求爆发期 42 分）**：

| 指标 | 计算方式 | 得分梯度 | 大师思想溯源 |
| :--- | :--- | :--- | :--- |
| **订单增速** | （最新季报合同负债 − 上年同期）/ 上年同期 | > 30% 得 12 分；15%~30% 得 8 分；< 15% 得 4 分；负增长 0 分 | **欧奈尔**：合同负债是收入的前瞻指标 |
| **政策环境** | 国家级规划 + 财政补贴落地检索 | 明确写入 + 资金配套（8 分）；仅提及支持（4 分）；政策收紧 / 集采（0 分） | **李进**：聚焦社会变迁与产业演进主线 |
| **毛利率变化** | 最新季度毛利率同比提升百分点 | > 2pct 得 8 分；0~2pct 得 4 分；下滑 0 分 | **李进**：需求扩张的验证指标 |
| **供应链话语权** | 应付账款周转天数同比变化 + 预付款项同比变化 | 应付天数同比增加 > 10% → +4 分；预付款项同比增加 > 30% → +3 分 | **郑希**：科技成长的通胀本质是「供不应求」 |
| **行业景气一致性**（批量模式） | 同行业筛选通过率 | 通过率 > 60% → 该行业公司集体 **+2 分**；< 30% → 集体 **−2 分** | **郑希**：行业景气聚合效应。**奖励分登记为骨架推导口径**（门禁 H-1 / `U8`） |

**② 研发执行力与转化维度（25 分 + 奖励分；技术跃迁期 32 分）**：

| 指标 | 计算方式 | 得分 / 扣分逻辑 |
| :--- | :--- | :--- |
| **MROI（含时间滞后备选）** | 主公式（成熟期）：（本年毛利 − 去年毛利）/ 本年研发费用；备选公式（高成长）：本年毛利增量 / 前一年研发费用 | 主公式 > 5 倍（10 分）/ 3~5 倍（7 分）/ 1.5~3 倍（4 分）/ < 1.5 倍（0 分）；备选 > 4 倍（10 分）/ 2~4 倍（7 分）/ 1~2 倍（4 分）/ < 1 倍（0 分） |
| **研发费用率变化**（辅助，不占分） | 本年研发费用率 vs 前一年 | 费用率同比下降 > 2pct 且营收增速 > 30% → 额外 +1 分 |
| **新品占比 / 溢价** | 年报「新品收入占比」；新品毛利率 − 旧品毛利率 | 占比 > 30% 且溢价 > 8pct（8 分）；占比 15%~30%（5 分）；< 15%（2 分） |
| **落地速度** | 年营收 / 平均（开发支出 + 专利账面值） | > 2.5 倍（4 分）；1.5~2.5 倍（2 分）；< 1.5 倍（0 分） |
| **存货匹配** | 研发费用增速 vs 存货周转天数变化 | 研发增 > 30% 且周转天数缩短（3 分）；同步增加（−3 分） |
| **自主替代成果**（奖励） | 国产化率四梯队位置 + 支柱五政策与资本覆盖度 | **分级依据重锚至框架**（见规则三）；**骨架 Level A/B/C 的固定 +8/+5/+2 档位登记为骨架推导口径，不再作为独立判据** |

### 规则三：R8 在研项目评分卡 + 自主替代分级

> **嵌入位置**：②研发执行力与转化模块的独立奖励分项。科创企业的在研重大项目（AI / 半导体 / 生物医药 / 高端装备 / 信创）是判断其**未来景气爆发力的核心先验指标**，通常比历史财务数据更具前瞻性。

### 规则四：地缘 0.3 三维交叉矩阵 + 赛道两分法（引擎 `--geo` 中性占位）

地缘风险由 **地缘倒逼强度 × 政策覆盖度 × 国字号基金介入** 三维交叉判定，由 `garp-geo-policy`（P4-1）输出**矩阵行归属（六类场景）**；本技能**引用不重做**。

| 地缘倒逼强度 | 政策覆盖度 | 国字号基金介入 | 投资含义 |
| --- | --- | --- | --- |
| 高（已制裁 / 断供） | 高（超常规 + 全链条） | 有直接注资 | **最优场景**：替代确定性和节奏均被外部力量锁定 |
| 高 | 中 | 有专项子基金 | **次优场景**：替代方向明确，但节奏受技术突破制约 |
| 中（制裁升级中） | 高 | 有覆盖 | **潜伏场景**：制裁尚未落地但概率高，提前布局等待催化 |
| 高（已制裁 / 断供） | 低 / 无 | 无覆盖 | **高风险 / 回避**：下游被迫替代但国产短期接不住，须先验证承接能力，承接不足则回避 |
| 低 | 中 / 高 | 有覆盖 / 注资 | **政策驱动型增量创造**：不以地缘倒逼为门槛，达标与否以政策覆盖 + 基金介入（支柱五）为准 |
| 低 | 低 | 无覆盖 | **回避**：替代节奏完全依赖市场驱动，不确定性过高 |

**附带条款（刚性）**：

1. **未列组合**一律按**更审慎的相邻档位**归档，**不得因未列而默认放行**（框架行 176）；
2. **国字号注资**视为「政策优先序列」信号，**不得作为买入估值依据**（框架行 178）；
3. **时变项**（制裁清单 / 出口管制 / 关税 / 国产化率）评估前须**实时核验**，**禁用历史清单**；
4. **赛道两分法**（框架行 180~185）：**地缘倒逼型**（半导体设备 / 材料等）→ 支柱四对地缘倒逼强度作**硬门槛**（非「低 / 无」方可建仓）；**政策资本驱动型**（机器人、信创等）→ 仅作**敞口体检**；两类非互斥时**按更审慎那类执行**。

```text
GARP 新口径（本技能）：
  地缘档位判定 → 由 garp-geo-policy 输出 0.3 矩阵行归属（六类场景）
  地缘闸门     → 归「高风险 / 回避」或「回避」→ 淘汰（GTS-3）；地缘倒逼型为硬门槛
  引擎 --geo   → 固定传 {"x":"高","y":"中"}（GEO_FACTOR = 1.00）作「中性占位」
  口径声明     → 引擎地缘乘数在 GARP 档被 0.3 矩阵取代，
                 最终得分 = 五维加权总分 + 奖励分（× 1.00）
  禁止事项     → 不得按骨架旧的两轴口径自行挑选 x / y 以套取非中性乘数
```

> **为什么用「中性占位」而非改引擎**：`--geo` 为必填且乘数为模块常量，**改签名 / 加系数参数会破坏「引擎零改动」刚性**；而框架**未给出** 0.3 矩阵各场景的修正系数数值，**自行发明系数将构成臆造阈值**。故采「矩阵作闸门 + 乘数中性化」。
> **骨架旧两轴口径的处置**：该口径（以国产化率与海外实体布局构造的两轴乘数）框架**未定义**，属骨架自有机制 → **整段废除**，仅保留「海外收入占比 / 供应链可控性」作为**敞口体检项**（框架行 196）。

### 规则六：技术面校验（仅降级）+ 正式止损转接 `garp-exit`

**五级卖出（框架行 473~505；本技能只引用 `garp-exit`，不重定义）**：

| 级别 | 触发条件 | 决策 |
| :--: | --- | --- |
| **一级 · 诚信否决** | 管理层诚信问题暴露、财务造假实锤、监管立案 | 立即清仓，不看估值与趋势 |
| **二级 · 硬止损** | 单笔亏损 8%~10% 且无明确基本面反转信号 | 无条件止损 |
| **三级 · 逻辑止损** | 连续 2 季业绩低于预期且景气未改善；或持有满 4 季度逻辑未兑现（**时间止损**） | 减仓或清仓 |
| **四级 · 产业景气判断** | 前三项未触发，但渗透率 / ROE 出现拐点（景气尚可、仅节奏放缓） | 减机动仓、降仓位 |
| **五级 · 估值判断** | 以上均未触发，仅估值 / 情绪波动 | 底仓不动，机动仓调整 |

> **铁律**：上层未通过，下层不讨论；顺序固定一级 → 五级，命中即停。
> **ATR 止损**：一律**经 `garp-exit`（P4-6）转接** `momentum.stop_price()`（内部调用 `atr(period=14, method="wilder")`、`multiplier=2.0`），**禁止心算**；本技能**不自建止损计算链、不新增 CLI**（`GTS-7`）。

### 规则七：最终评级 + GARP 三档结论对接

**最终得分 = 五维加权总分 + 奖励分（× 1.00，中性占位）**，由引擎输出。

| 评级 | 阈值（不改） | GARP 三档结论标签 | 后置动作 |
| :--: | :--: | --- | --- |
| **S 级** | ≥ 80 分 | **买入候选** | **强制转接** `garp-investment-checklist`（P4-3）七关 |
| **A 级** | 65~79 分 | **买入候选** | **强制转接** `garp-investment-checklist` 七关 |
| **B 级** | 50~64 分 | **观察仓** | 不进入买入候选，跟踪反证清单 |
| **C 级** | < 50 分 | **放弃** | 移出关注池 |

> **不越权声明（刚性）**：本技能**只做正向排序**——**S 级不得直接视为「可买入」**；未经 `garp-investment-checklist` 七关，不得形成买入结论（`GTS-11`）。
> **降级来源汇总**：R8 < 0（`GTS-8`）、估值倒推红灯、`--tech` 触发、越出宏观 PEG 区间上限（`GTS-4`）、地缘闸门命中（`GTS-3`）——均须在报告中标注规则编号。

### 规则八：费雪质化验证层（不计分，仅 S/A 级）

> **位置**：五维打分与地缘 / 宏观修正**之后**的**独立评审层**，**不计分、不改变引擎输出**；仅对 **S / A 级**标的执行（门禁 B-1）。

| 评审项 | 问题 | 证据来源 |
| --- | --- | --- |
| **管理层品质** | 是否诚实、是否利益一致？（**诚信问题一票否决**） | 年报承诺兑现率、互动易、监管记录 |
| **持有竞争优势** | 优势是否可持续、是否在扩宽？ | 毛利率 / 份额趋势、CR5、护城河清单 |


> **费雪层不新增打分维度**：引擎五维权重与维度已冻结（`--dims` 键 a~e），本层为**评审层而非打分层**。

### 打分引擎与工具链的配合

`trend_tech_screen.py` 是**聚合计算层**，不直接拉取网络数据：

1. **LLM 采集与判断**：用数据 / 搜索 / 年报工具采集指标，定性判断周期阶段、政策环境、自主替代分级、地缘矩阵行归属、技术面数据；
2. **工具计算**：`financial_rigor.py` 计算 PEG / 投资回报率 / 隐含增速；`annual_report_parser.py` 抽取年报字段；`in_research_scan.py` 扫描在研项目渠道供 R8 评分卡；
3. **引擎聚合**：将五维得分（`--dims`，按**该周期满分刻度**填报）、地缘中性占位（`--geo`）、技术面数据（`--tech`）、在研项目评分（`--r8`）传入引擎；引擎按周期满分表校验后**对 `--dims` 直接求和**（**不归一、不做加权乘法、不截断超额**），再叠加 R8 奖励分、乘以地缘系数（本技能恒为 1.00）、执行评级映射；批量模式用 `batch --input` 做行业景气一致性两轮修正。
4. **引擎输出须在报告层覆写两处（刚性，`GTS-5` / `GTS-10`）**——这是本技能与骨架的口径分界，**不得直接照抄引擎文案**：
   - **技术面红牌文案**：引擎对 `close_above_ma200 = false` 会输出「**强制降级 / 清仓**」「**最高优先级即时生效**」并将评级**硬置为 C**。GARP 档须改写为「**引擎内评级降级（C）+ 风险提示**」，并**显式转接 `garp-exit`**；**不得以技术面为由**给出「清仓」动作——正式清仓 / 止损动作只能来自 `garp-exit` 五级卖出的引用（见规则六、`GTS-5`）；
   - **反证清单模板**：引擎内置 `COUNTER_ARGUMENT_TEMPLATE`（8 条）仍含骨架口径——「跌破 200 日线 → **清仓**」与「毛利率单季跌破 **固定百分比**」。GARP 档须以**本技能规则九的 10 条清单**替换，并改写技术面行与毛利率行口径（毛利率阈值按**行业中位数**设定）；`batch` 模式会重置为骨架模板，**必须逐条覆写后再输出**。

### 引擎签名冻结（`GTS-10`，逐字）

```text
score  : --name（必填）/ --cycle / --dims（必填，JSON a~e）/ --geo（必填，JSON x,y）
         / --tech（可选，JSON close_above_ma200 / close_above_ma50 / volume_above_1_5x）
         / --r8（可选，JSON 五子项）/ --markdown-only（跳过落盘）
batch  : --input（必填）/ --cycle          ← 无 --markdown-only
```

> 上述参数名与语义**不得改动**；本技能**不得为「适配 GARP」修改引擎或新增参数**。

### 关键约束

- **财务计算验算**：使用 `financial_rigor.py` 与打分引擎，**禁止 LLM 心算**（`GTS-7`）；
- **年报一手数据**：关键财务数据须从年报 PDF 一手提取，禁止用研报替代；结构化字段优先用 `annual_report_parser.py`；
- **网络搜索**：禁止使用 Anthropic 官方 WebSearch / WebFetch，统一使用本地搜索工具组合；
- **时效性**：搜索时须使用 `--time-range month` 或 `--time-range week` 限制时间范围；
- **跨市场市值统一口径**：跨市场筛选时用 `tools/common/fx_rate.py` 折算到统一币种；
- **工具报错**：记录**原始报错与退出码**，标注「工具缺陷候选」，**不得静默吞掉**。

## 风控硬编码 `GTS-1` ~ `GTS-12`

| 编号 | 规则 | 不可做的事 |
| --- | --- | --- |
| `GTS-1` | **前置硬性淘汰**：① 实体清单 + 核心环节国产化率 < 30% + 无非制裁海外有效实体；② 核心技术人员流失 > 30% 且人均创利连续 2 年暴跌 > 40%；③ 在手订单（合同负债）同比 < −50% 且存货周转天数同比增 > 80% → **直接淘汰** | 不得对命中标的继续打分 |
| `GTS-2` | **诚信一票否决**：兑现率 < 50% / 业绩预告重大失真 / 财务造假实锤 / 监管立案 → **淘汰或清仓** | 不得以五维高分、R8 奖励或费雪层豁免 |
| `GTS-3` | **地缘闸门**：0.3 矩阵归「高风险 / 回避」或「回避」→ 淘汰；**地缘倒逼型**赛道地缘倒逼强度为「低 / 无」→ 不得建仓；**政策资本驱动型**仅作敞口体检 | 不得按骨架旧两轴口径修正得分；不得因未列组合默认放行 |
| `GTS-4` | **估值透支**：调整后 PEG **> 2.0** → 出排序终选；**> 1.5** → 不得入底仓候选；越出当期**宏观 PEG 合理区间上限** → 评级下调 | 不得以「高增速」豁免 PEG > 2 红线；不得心算 PEG |

## 注意事项 / 局限性

1. **本技能定位**：**正向排序**，识别景气与趋势最强的标的；**不收敛组合、不替代买入门槛、不定义卖出级别、不定义估值档位**。
2. **周期权重调整纪律**：无法明确判断周期阶段时**默认「需求爆发期」**并标注；权重调整**仅影响 ①②⑤**，不影响 ③④。
3. **地缘口径唯一**：只用 **0.3 三维交叉矩阵 + 赛道两分法**；不得改用其他档位的地缘口径，也不得做地缘估值折价（折价由 `garp-valuation` 承载）。
4. **中性占位不得被绕过**：`--geo` 固定 `{"x":"高","y":"中"}`（系数 1.00）；**禁止**自行挑选 x / y 以套取非中性乘数。
5. **技术面不越权**：`--tech` 仅作引擎内降级与风险提示；跌破 200 日线**不等于清仓指令**，须转 `garp-exit`。
6. **口径登记三处**：① 50 / 200 日均线止损为**框架未提及的骨架推导口径**；② 骨架自主替代固定档位；③ 行业景气一致性 ±2 分——均须在报告中显式标注来源，**不得表述为框架条款**。
7. **费雪层边界**：不计分、不改变引擎输出；两前提**未同时满足**则「长期持有 / 绝不卖」结论**不成立**，须按 `garp-exit` 五级纪律执行；两前提为**主观自评项，非工具化判据**。
8. **零心算 + 取数失败不等于通过**：所有估值 / 市值 / 调整后 PEG / 加权打分须走工具（`GTS-7`）；取数失败标注「未验证」「低置信度」，不得按通过处理（`GTS-9`）；渗透率 / 国产化率 / 制裁清单取不到时**不默认落黄金区**。
9. **降级与失败处置**：某市场工具连通失败 → 重试，仍失败则标注「未取得」，**不以推测代替实测**；关键维度缺失 → 结论降级；`garp-geo-policy` / `garp-macro` / `garp-valuation` 未跑过 → 提示先运行，确无法补跑时**显式标注置信度受限**，**不得**以推测填充矩阵 / 区间。
10. **数据窗口与结构性局限**：本技能不要求 10 年历史数据，**近 6 个季度的边际变化**比历史均值更重要；上市不足 3 年的公司，允许用招股书「管理层指引」代替历史数据；本模型在纯周期股与早期未盈利创新药标的中有效性显著下降；地缘突变（战争、突发极端制裁）无法预测；前向引用的技能**只指向名称、不描述内部流程**。
