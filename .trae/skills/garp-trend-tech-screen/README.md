# GARP 景气趋势筛选（1~5 年）· README

> **技能命令**：`/garp-trend-tech-screen {公司/行业/指数/主题}`
> **所属档位**：GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔）
> **适用口径**：筛选与排序层（全档位通用入口之一）——四层递进 + 五维加权打分的**正向排序**，输出 S/A/B/C 评级与 GARP 三档结论 + 反证清单

本 README 为速查版；**完整口径以 [SKILL.md](./SKILL.md) 为准**。

---

## 一、技能用途

**一句话定位**：对「公司 / 行业 / 指数 / 主题」执行**四层递进 + 五维加权打分**的**正向排序**，回答「当下哪些标的景气与趋势最强、该怎么排序」。

| 模式 | 示例 | 输出附加 |
| --- | --- | --- |
| **个股** | `腾讯, 美团, 英伟达` | 逐家筛选 |
| **行业 / 指数 / 主题** | `AI 光模块` / `科创50` / `全球AI算力链` | 通过率统计 / 行业内排名 / 景气一致性 / 板块对比 |

**使用**：1~5 年景气与趋势视角下的正向排序；需要 S/A/B/C 评级与反证清单；行业 / 指数 / 主题模式需要板块内排名。**不使用**：赛道是否值得配置（走 `garp-industry-research`）；赛道内收敛（走 `garp-industry-funnel`）；买入前七关（走 `garp-investment-checklist`）；卖出 / 止损价（走 `garp-exit`）；正式估值档位（走 `garp-valuation`）。

## 二、适用口径与隔离声明

1. **档位**：GARP 独立档（1~5 年），与 1~3 年中期链、10 年长期链**口径物理隔离、功能互补**。
2. **无档位切换参数**：不含任何档位切换开关；出现档位切换类口令即违反**口径隔离**纪律。
3. **地缘口径唯一**：只用 **0.3 三维交叉矩阵（地缘倒逼强度 × 政策覆盖度 × 国字号基金介入）+ 赛道两分法**；**不做**地缘估值折价（折价由 `garp-valuation` 承载，避免双重计价）。
4. **估值唯一出口**：`garp-valuation`（统一六档 + 多工具矩阵）；本技能**零 PEG 算式**。
5. **卖出唯一出口**：`garp-exit`（五级 + 4 季度时间止损 + ATR 动态止损）；本技能**不自建止损链**。
6. **宏观只读**：`garp-macro` + `macro_calibrator.py` **只读透传**；本技能**不判 stage、不心算**。
7. **引擎零改动**：`trend_tech_screen.py` 的 `score` / `batch` **签名冻结**，本技能**不新增任何 Python CLI 参数**。
8. **报告隔离**：GARP 档报告一律含 `garp-` 标识，与其他档位报告**互不覆盖、互不引用**。

## 七、关键口径速查

### 7.1 四层递进与五维权重

| 维度 | 基准 | 需求爆发期 | 技术跃迁期 | 成熟稳定期 |
| :--- | :--: | :--: | :--: | :--: |
| ① 景气前瞻 | 35 | **42** | 28 | 35 |
| ② 研发执行力与转化 | 25 | 18 | **32** | 25 |
| ③ 人才质量与密度 / ④ 动量与市场共识 | 各 15 | 各 15 | 各 15 | 各 15 |
| ⑤ 估值安全垫 | 10 | 10 | 10 | **15** |

四层：第零层 周期定位（+ 渗透率五档）→ 第一层 前置淘汰（**仅本层淘汰**）→ 第二层 五维打分（满分 100 + 奖励分）→ 第三层 地缘 + 宏观 + 估值映射 + 技术面降级 → 最终评级。
**供给受限期**权重不调（35/25/15/15/10），改以 0.3 矩阵**闸门权重提升**承接；无法判断周期时**默认「需求爆发期」**并标注。

### 7.2 渗透率五档

| 区间 | 阶段定位 | 处置 |
| --- | --- | --- |
| < 5% | 导入早期 | 观察不建仓 |
| 5%~15% | 突破期 | 小仓跟踪 |
| **15%~40%** | **加速上行期（黄金窗口）** | **主建仓** |
| 40%~60% | 逐步兑现期 | 持有，不再新建仓 |
| > 60% | 天花板 | 增速归零 / 转负即见顶清仓 |

### 7.3 地缘 0.3 三维交叉矩阵（六类场景）

| 地缘倒逼强度 | 政策覆盖度 | 国字号基金介入 | 场景 |
| --- | --- | --- | --- |
| 高 | 高 | 有直接注资 | **最优场景** |
| 高 | 中 | 有专项子基金 | **次优场景** |
| 中 | 高 | 有覆盖 | **潜伏场景** |
| 高 | 低 / 无 | 无覆盖 | **高风险 / 回避** |
| 低 | 中 / 高 | 有覆盖 / 注资 | **政策驱动型增量创造** |
| 低 | 低 | 无覆盖 | **回避** |

**附带条款**：① 未列组合按**更审慎的相邻档位**归档；② **国字号注资非估值依据**；③ 制裁清单 / 出口管制 / 关税 / 国产化率均为**时变项**，评估前须**实时核验**。
**赛道两分法**：**地缘倒逼型** → 地缘倒逼强度作**硬门槛**；**政策资本驱动型** → 仅作**敞口体检**；两类非互斥时按更审慎那类执行。

> **引擎 `--geo` 固定传 `{"x":"高","y":"中"}` 作「中性占位」（系数 1.00）**，即 **最终得分 = 五维加权总分 + 奖励分（× 1.00）**；**禁止**按骨架旧的两轴口径自行挑选 x / y 以套取非中性乘数。

### 7.4 宏观三表与估值多工具矩阵

**利率周期 → 调整后 PEG 合理买入区间**：加息 / 高利率周期 0.8~1.0；中性（基准）1.0~1.2；降息 / 低利率周期 1.2~1.5（PEG > 2 仍为绝对透支）。

| 宏观阶段 | PEG 上限 | 现金仓位 | 单只上限（验证后） |
| --- | :--: | :--: | :--: |
| 衰退 / 复苏 / 过热 / 滞胀 | 1.0 / 1.5 / 1.0 / 0.8 | 30%~40% / 10%~20% / ≥ 25% / ≥ 40% | ≤ 12% / ≤ 15% / ≤ 12% / ≤ 10% |

越出当期宏观 PEG 区间上限 → **评级下调**（`GTS-4`）。估值按公司类型匹配工具：**快速增长型** → 调整后 PEG（> 1.5 高估）；**高研发投入型** → PS / EV/Sales + Rule of 40（≥ 40）；**未盈利科技型** → PS / EV/Sales + 研发管线 NPV；**稳定增长型** → 远期 PE + 隐含 PEG（≤ 1.2）；**成熟型企业** → DCF（市值 ≤ 保守 DCF 的 80%）。

### 7.5 五级卖出（本技能只引用 `garp-exit`）

| 级别 | 触发 | 决策 |
| :--: | --- | --- |
| 一级 · 诚信否决 | 造假实锤 / 监管立案 | 立即清仓 |
| 二级 · 硬止损 | 单笔亏损 8%~10% 且无基本面反转 | 无条件止损 |
| 三级 · 逻辑止损 | 连续 2 季低于预期；或持有满 4 季度逻辑未兑现 | 减仓或清仓 |
| 四级 · 产业景气 | 渗透率 / ROE 拐点（仅节奏放缓） | 减机动仓 |
| 五级 · 估值 | 仅估值 / 情绪波动 | 底仓不动，机动仓调整 |

> **ATR 动态止损**一律**经 `garp-exit` 转接** `momentum.stop_price()`（`atr(period=14, method="wilder")`、`multiplier=2.0`），**禁止心算**。
> **技术面**：跌破 50 日线且放量 → **引擎内降级**；跌破 200 日线 → **提示 + 转接 `garp-exit`**（**不是清仓指令**）。

### 7.6 费雪质化验证层（不计分，仅 S/A 级）

质化四问（管理层品质 / 持有竞争优势 / 研发能力 / 销售组织）+ **闲聊法证据链**（竞品 / 供应商 / 客户 / 员工四侧面交叉）+ **「绝不卖」两前提**（① 极度深度的研究认知 ② 极度集中持仓）。

> 诚信问题命中即淘汰，**费雪层不豁免**；两前提**未同时满足**则「长期持有 / 绝不卖」结论**不成立**，须按 `garp-exit` 五级纪律执行。两前提为**自评项，非工具化判据**。

### 7.7 评级与 GARP 三档结论

| 评级 | 阈值 | GARP 三档结论 | 后置动作 |
| :--: | :--: | --- | --- |
| S | ≥ 80 | 买入候选 | 强制转接七关 |
| A | 65~79 | 买入候选 | 强制转接七关 |
| B | 50~64 | 观察仓 | 跟踪反证清单 |
| C | < 50 | 放弃 | 移出关注池 |

> 本技能**只做正向排序**，**S 级不得直接视为可买入**（`GTS-11`）。

## 九、口径差异与常见误用

| # | 常见误用 | 正确做法 |
| :--: | --- | --- |
| 1 | 自行挑 `--geo` 的 x / y 套取非中性乘数 | **固定 `{"x":"高","y":"中"}` 中性占位（1.00）**，地缘改由 0.3 矩阵作闸门 |
| 2 | 把「跌破 200 日线」写成清仓指令 | 改为**风险提示 + 转接 `garp-exit`** |
| 3 | 把 50 / 200 日均线止损当成框架条款 | 登记为**框架未提及的骨架推导口径**（框架只提 8%~10% 硬止损 + ATR） |
| 4 | 自建止损链或新增 CLI 参数 | 止损一律经 `garp-exit`；引擎签名冻结（`GTS-7` / `GTS-10`） |
| 5 | 把 `--dims.e` 当作正式估值结论 | 它只是统一六档的**档位映射分**，不得替代正式结论 |
| 6 | 在本技能内做地缘估值折价 | 折价统一由 `garp-valuation` 承载（避免双重计价） |
| 7 | 把 S 级直接视为「可买入」 | **强制转接** `garp-investment-checklist` 七关（`GTS-11`） |
| 8 | 把骨架 Level A/B/C 固定档位或行业景气一致性 ±2 分表述为框架条款 | 同批登记为**骨架推导口径**；分级依据重锚至国产化率四梯队 + 支柱五 |
| 9 | 沿用历史制裁清单 / 国产化率 / 渗透率 | 均为**时变项**，评估前须**实时核验** |
| 10 | 渗透率取不到就默认落黄金区 | 标注「**未验证**」+ 区间上下限，**不默认落黄金区** |
| 11 | 用 `score` 时不加 `--markdown-only` | `score` **一律追加 `--markdown-only`**；`batch` 无该开关，其落盘文件登记为**引擎已知副作用、非 GARP 交付物** |
