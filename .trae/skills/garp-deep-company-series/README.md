# 深度公司系列（GARP 1~5 年价值成长独立档）(GARP Deep Company Series)

3-8 篇长文拆一家公司：从认知重置到决策框架完整闭环（GARP 1~5 年价值成长框架）

> **本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。** 核心理念：**价值成长驱动，质化预判，纪律退出**——在五大师视角下，为指定公司撰写可公开发布的深度长文系列。**禁止使用「护城河永续」「终局思维」「持有10年」等长期框架术语，亦禁止原样沿用「1~3 年景气持有」等中期链表述。**

**本技能的参考样本**：`reports/腾讯/《看懂腾讯》/`（长期版产物，**仅参考篇目结构与写作格式**），本 GARP 版按 **1~5 年价值成长框架**重写全部口径。

## 快速开始

### 基本调用方式

```
/garp-deep-company-series {公司名}
```

例如：

- `/garp-deep-company-series 腾讯`
- `/garp-deep-company-series 新易盛`

## 核心功能

为指定公司撰写一个深度长文系列（**3-8 篇**，按公司复杂度定，约 **3-12 万字**），从认知重置到决策框架完整闭环，适合公众号/视频号等公开渠道发布。

**核心 IP 不是"会写"，而是"会改"——99% 的财经文章违反本技能的事实核查标准。**

| 维度 | 本技能 | 单篇研报类技能 |
|------|--------|---------------|
| 篇数 | 3-8 篇（按复杂度定） | 1 篇 |
| 字数 | 3-12 万字 | 数千至万余字 |
| 口径 | 全系列贯穿同一套估值 / 管理层 / 卖出判断 | 单篇自洽 |
| 读者 | 愿意花 90 分钟读懂一家公司的读者 | 快速取结论者 |

**不适合用本技能的场景**：单篇研报、季报点评、行业研究——那些用 `/garp-investment-research`、`/garp-earnings-review`、`/garp-industry-research`。

| 大师 | 思维模式 | 职责 | 对应篇目 |
|------|---------|------|---------|

| 林奇 | 侦探思维 · 常识与求证 | 选股起点 + 估值定价 | 01/03/04 选股、08 估值 |
| 郑希 | 物理学家思维 · 周期与第一性原理 | 赛道选择（ROE 拐点、产业景气） | 02/05/06 ROE、景气 |

## 篇数适配公司复杂度（先定篇数，再定篇目）

**篇数不固定为 8。** 8 篇是腾讯这种"多业务 + 万亿投资组合 + 20 年管理层故事"的公司才撑得起的容量。写之前先问：这家公司有几个能用"一个尖锐问题"独立成文的主轴？有几个写几篇。

| 复杂度 | 特征 | 篇数 | 例子 |
|--------|------|------|------|
| 高 | 多条业务线各自成生意 + 隐藏资产/投资组合 + 管理层史料丰富 | **7-8 篇** | 腾讯 |
| 中 | 2-3 条业务线 + 一个重大时代变量 | **4-6 篇** | — |
| 低 | 主业清晰、核心问题少而集中 | **3 篇** | 快手 |

### 3 篇标准合并方式（GARP 化）

| # | 篇名方向 | 折入的主轴 | GARP 收口点 |
|---|---------|-----------|------------|
| 01 | 你以为你看懂了 X（开篇 + 生意与护城河） | 认知重置 + 护城河 + 利润引擎概览 | **费雪需求真实性**破错觉 |
| 02 | X 的最大变量（当下叙事/隐藏资产/产业景气） | 隐藏资产 + 时代变量（含产业景气） | **渗透率 `15%~40%` 档位 + TAM ≥1000 亿 + 国产化率四梯队**（只读） |
| 03 | 多少钱值得买，什么信号必须卖（决策终章） | 财务深度 + 管理层要点 | **GARP 多工具估值矩阵（只读 `garp-valuation`）+ 五级卖出（只读 `garp-exit`）** |

**判断信号**：某篇写到一半发现"凑内容"（同一事实换说法重复出现）→ **合并**；某篇超 **12,000 字**仍塞不下 → **拆分**。**写前须与用户确认核心论点与定目**，不跳步。

**字数基准**：单篇 4,000~12,000 字；全系列约 **3~12 万字**。

## 8 主轴全模板（复杂公司用；简单公司当检查清单折叠）

| # | 篇名模板 | 核心问题 | 核心思想来源 | 字数 |
|---|---------|---------|------------|------|
| 01 | 你以为你看懂了 X，其实没有 | 认知重置：破 3 个常见错觉 | 林奇「常识验证」+ **费雪「需求真实性」** | 4,000-5,000 |
| 02 | X 的护城河——`<生意本质一句话>` | 护城河深不深、**1~5 年 GARP 周期中能否支撑 ROE 向上** | 郑希「ROE 护城河」+ **费雪「需求真实性」** | 6,000-8,000 |
| 03 | X 的最大利润引擎——`<最赚钱业务>` | 主业是什么、为什么能持续、**渗透率位置与产业景气** | 林奇 + 李进 | 6,000-8,000 |
| 04 | X 藏在账上的另一家公司——`<隐藏资产>` | 投资组合 / 子公司 / 隐藏价值 | 林奇「隐蔽资产型」 | 8,000-10,000 |
| 05 | AI 与产业景气时代，X 是赢家还是输家 | **分业务拆 AI 影响 + 渗透率与产业景气判断 + 地缘政治（只读）** | 郑希 + 李进 + **费雪** | 8,000-10,000 |
| 06 | 拆 X 的财报：ROE、现金流与景气信号 | **ROE 8 季度趋势、毛利率/FCF、二阶导、渗透率** | 郑希 + 李进 | 8,000-10,000 |
| 07 | `<管理层金句>`——X 的管理层值不值得托付 | **只读 `garp-management`（诚信前置 + 7+7+6 + 科研 8+8+4）+ 费雪补充检查** | 李进 + **费雪** | 8,000-10,000 |
| 08 | 多少钱值得买，什么信号必须卖（系列终章） | **GARP 多工具估值矩阵（只读 `garp-valuation`）+ 分批建仓 + 五级卖出（只读 `garp-exit`）+ 费雪「绝不卖」边界** | 林奇 + 欧奈尔 + **费雪** | 10,000-12,000 |

加一篇 `00-系列说明.md` 作为目录索引（**不发表**，含信息丰富度评级 + 定篇数依据）。

**篇目必须适配公司**：模板是腾讯长出来的，不是套子。某篇没有独立内容（如没有投资组合的公司写不了 04），就替换成该公司特有的主轴，或按上面的合并方式折进更少的篇数。

## 使用示例

### 示例 1：撰写 A 股成长股深度系列

```
/garp-deep-company-series 新易盛
```

## 输出报告

报告将保存在以下位置：

| 报告类型 | 文件路径 |
|---------|---------|
| GARP 深度系列 | `reports/{公司名}/《看懂{公司名}》-garp-{YYYYMMDD}/` 目录下的 3-8 篇文章 + `00-系列说明.md` |

### 报告目录结构

```
reports/
├── {公司名}/                                     — 公司所有研究报告
│   ├── 《看懂{公司名}》-garp-{YYYYMMDD}/         — GARP 版系列长文目录（物理隔离）
│   │   ├── 00-系列说明.md                        — 目录索引（不发表，含信息丰富度评级 + 定篇数依据）
│   │   ├── 01-你以为你看懂了X，其实没有.md
│   │   ├── 02-X的护城河（价值成长版）.md
│   │   ├── 03-X的最大利润引擎.md
│   │   ├── 04-X藏在账上的另一家公司.md
│   │   ├── 05-国产化与产业景气时代，X是赢家还是输家.md
│   │   ├── 06-拆X的财报：ROE、现金流与景气信号.md
│   │   ├── 07-X的管理层值不值得托付.md
│   │   └── 08-多少钱值得买，什么信号必须卖.md
│   ├── 《看懂{公司名}》-mid-{YYYYMMDD}/          — 中期版系列长文目录（原样保留，不动）
│   ├── 《看懂{公司名}》/                          — 长期版系列长文目录（原样保留，不动）
│   └── ...
```

### 目录冲突规则

若 `reports/{公司名}/《看懂{公司名}》-garp-{YYYYMMDD}/` 已存在（旧版 GARP 系列），**不覆盖、不混放**——新系列写入**新日期后缀**文件夹，旧文件夹原样保留；同日多版本用 `-v2` / `-v3` 后缀，**不覆盖首版**。

### 【子串包含披露（刚性）】

长期版目录名 **`《看懂{公司名}》` 是** GARP 版 `-garp-{YYYYMMDD}` 与中期版 `-mid-{YYYYMMDD}` 目录名的**前缀子串**——纯子串检索 `《看懂{公司名}》` **会同时命中三档**。

因此**三档隔离核验必须使用完整后缀段（`-garp-` / `-mid-`）或目录级比对**，**禁止以「`《看懂{公司名}》`」单串计数下结论**，否则产生**假阴性**。

另一侧确认（有利事实）：`-mid-` 与 `-garp-` **互不为子串**，故**后缀段级**核验可安全区分中期 / GARP 两档。

### 报告头部必注明：四基准

| 基准 | 内容 |
|------|------|
| **数据基准** | `date` 实测日期 + 检索截止日 |
| **估值基准** | `garp-valuation` 调用日期 + 行情截止日 |
| **资料基准** | 本技能操作化口径（非框架原文）+ 框架章节号锚点 |
| **口径基准** | **GARP 独立档 1~5 年·五大师** |

## 三档隔离对照（新增）

同为「深度公司系列」，三档**只共享篇目结构与写作格式**，**口径、术语、目录后缀均不互用**：

| 档位 | 目录后缀 | 持有周期 | 大师阵容 | 口径出口 |
|------|---------|---------|---------|---------|
| **GARP 独立档（本技能）** | **`-garp-{YYYYMMDD}`** | **1~5 年** | **五大师（费雪 / 林奇 / 郑希 / 李进 / 欧奈尔）** | `garp-valuation` / `garp-exit` / `garp-management` / `garp-geo-policy` / `garp-macro` |

| 10 年长期链 | **无后缀** | 10 年 / 永续 | 长期链框架 | 长期链口径出口 |

**红线**：本技能**不转接**另两档、**不引用**其口径出口、**不沿用**其术语；撰写时若出现"景气中期""永续""终局"类表述，即为跨档，须改写为 GARP 1~5 年价值成长口径（`GDS-12`）。

## 写作标准

### 写作风格规范

- **语气**：直接、犀利、不说废话，第一句就给数字或反常识结论
- **五大师视角穿插**：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔视角交替出现（但**不堆砌名言**）
- **不预设立场**：先摆数据 → 推逻辑 → 得结论
- **呈现正反两面**：每个核心判断都附"但另一方面..."的反方
- **公众号体感**：前 **18-20 字**必须能独立站住（手机预览）
- **标题风格**：用反差数字或反共识结论做钩子（"ROE 连续 8 季度攀升"），避免流量党比喻

### 禁用词（双向红线：长期链 + 中期链同时禁）

| 禁用 | 原因 | 替代 |
|------|------|------|
| 显然 / 必然 / 一定 | 主观绝对化 | 数据显示 / 证据表明 |
| 我认为 / 我觉得 | 主观腔调 | 删除或改为"按本框架" |
| 教科书级别 / 神来之笔 | 流量党褒奖 | 描述具体事实 |
| 严重不匹配 / 严重低估 | 强主观词 | 给具体折让百分比 |
| 完美 / 无可挑剔 | 单边判断 | 加上反方观察 |
| 「长期持有」/「永远不卖」/「买入并遗忘」 | **长期框架术语（禁）** | 「GARP 独立档周期内持有」/「每季度按 GARP 口径体检」 |
| 护城河永续 / 终局思维 / 持有10年 | **长期框架术语（禁）** | 1~5 年 GARP 周期中护城河是否支撑 ROE 向上 |
| 「1~3 年景气持有」/「中期口径」 | **中期链术语（跨档，禁）** | 「1~5 年 GARP 独立档周期内持有」 |
| `mid-*` 技能名 / `-mid-` 目录后缀 / 跨档持有周期口令 | **跨档口令与路径（禁）** | 只指向 `garp-*` 系列与 `-garp-` 目录后缀 |

### 篇内结构模板

每篇有固定骨架，共性结构四项：

- **头部引用块**：`> 《看懂X》系列 · 第 0N 篇 · <主轴>`，开篇加阅读时间 + **本档口径标注（GARP 独立档 1~5 年）**
- **第一节永远是钩子**：一组反常识数字 / 一条反常曲线 / 一个让市场担心的数字，**不写背景铺垫**
- **每篇末尾**：`## 本篇要点回顾`（5-8 条，数字与正文**严格一致**）+ `## 下期预告`（用尖锐问题预告，**不剧透结论**）
- **结尾两行斜体**：`*本文是《看懂X》系列第 0N 篇...*` + `*本系列基于公开信息和 GARP 独立档（1~5 年）投资框架研究，不构成任何投资建议。*`

**各篇专属骨架（GARP 独立档版）**：

| 篇 | 骨架 | 核心思想来源 |
|---|------|------------|
| 01 开篇 | 股价被市场反复"重新定性"的历史曲线 → 三个常见错觉（每个用财报数据破，**其中至少一个用费雪需求真实性破**）→ 阅读地图 → 估值钩子数字表（只留悬念不给结论） | 林奇 + **费雪** |
| 02 护城河 | 挑战者失败名单（有名有姓有年份）→ 迁移成本的本质 → 生态飞轮 → **1~5 年 GARP 周期中 ROE 能否持续向上** → 反向思维实验（"1000 亿能否复制它"）→ **需求真实性复核** | 郑希 + **费雪** |
| 03 利润引擎 | 反常识数字开场 → 核心产品为何长青 → **产业渗透率定位（`15%~40%` 黄金窗？TAM ≥1000 亿？）** → 增长空间量化 → 反面论据 → AI/产业景气影响 → 未来一年图景 | 林奇 + 李进 |
| 04 隐藏资产 | TOP 持仓表（**只统计未并表部分**，并表的单独说明防双算）→ 会计处理差异 → "不会卖 vs 可能减持"分类 → 市场为何打折价 → 估算折扣 | 林奇 |
| 05 AI/产业景气时代 | 让市场担心的数字 → **分业务拆赢家/输家** → **渗透率趋势 + TAM 闸门 + 国产化率四梯队（只读）** → **二阶导判断** → **地缘政治只读（0.3 三维交叉矩阵 + 赛道两分法）** → **费雪需求真实性分辨真假赢家** → 未来一年监控信号清单 | 郑希 + 李进 + **费雪** |
| 06 财务与景气信号 | 一条反常曲线开场 → 利润表（毛利率变化归因）→ **ROE 8 季度趋势** → **营收增速二阶导** → **产业渗透率变化** → FCF Yield → 股东回报 → 估值横向 + 历史比较（**只读 `garp-valuation`**）→ 把财报压缩成三句话 | 郑希 + 李进 |
| 07 管理层 | 核心团队表 → 关键人物长期贡献 → 利益对齐 → **诚信检验：挑一次真实危机看应对** → **5 年承诺兑现率（逐条核对）** → **只读 `garp-management`：诚信前置闸门 + 7+7+6 + 科研 8+8+4** → **费雪补充检查：销售组织 + 管理层持股 ≥3%** → 治理一票否决红线 → 接班人隐忧 → 综合结论（**只读结论，不重新计分**） | 李进 + **费雪** |
| 08 估值与卖出纪律 | **GARP 多工具估值矩阵只读（统一六档 + ESG 折价 + 宏观 PEG 区间）** → **分批建仓计划** → **五级卖出只读（诚信否决 > 硬止损 8%~10% > 逻辑止损 > 产业景气 > 估值）** → 历史估值分位 → 未来利润三情景 → **费雪「暂时性困难 vs 永久性衰退」+「绝不卖」适用边界** → 赔率思维收尾 | 林奇 + 欧奈尔 + **费雪** |

### 严苛事实核查 Checklist

#### 写之前就要警惕的"伪精确"陷阱（6 条）

1. **概率加权期望值** — 只列情景 + 触发条件 + 方向，不算加权期望
2. **第三方测算 MAU/份额** — 用最可信两个 anchor，其他定性描述
3. **历史增速线性外推** — 改用情景假设 + 高/低区间 + 不是承诺
4. **未公开的持股比例** — 给区间，标"不可知"
5. **强归因** — 多重原因都列出来，不做单一归因
6. **渗透率精确值** — 标注"估计"并注明来源，黄金窗口径对齐 `garp-industry-research`（`15%~40%` + TAM ≥1000 亿）

#### 修订时必跑的 7 项检查

```
□ 1. 跨篇数字一致性：总市值、净利润、关键持股 %、ROE、估值档位全系列对齐
□ 2. 口径标注：Non-IFRS / GAAP / Non-IFRS-SBC / FCF / 调整后 PEG 各用哪个，全文清楚
□ 3. 重复加计扫描：已并表子公司不在"投资组合"里、SOTP 不双算
□ 4. 横向比较公平性：不能"主业 PE" vs "对手 PE（不剔）"
□ 5. 概率加权全删
□ 6. 绝对化与跨档术语全弱化（按本档双向红线 grep）
□ 7. 第三方数据来源标注：每条非财报数据后跟"（来源：X）"
```

#### 模型偏好（已知硬错误风险，GARP 1~5 年独立档版）

- 历史回报倍数：必须用累计投入口径
- 持股比例：必须看最新富途/财报口径
- "派息分派"会计处理：视同处置收益按 IFRIC 17 在宣派日确认
- 总股本会反弹：SBC 集中年初授予会让股本短期上升
- **调整后 PEG 必须用 `financial_rigor.py` 计算，禁止 LLM 心算**；**档位判定以 `garp-valuation` 统一六档输出为准**（显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支）
- **ROE 8 季度趋势**：连续 3 季同向才判拐点，单季波动判噪音（对齐郑希口径）
- **禁止用十年尺度终值口径**给本系列估值（长期链专用工具）——跨档即打回

## 执行流程

### 阶段 0：定篇数与定目（**本档强制前置**）

1. 判定**信息丰富度评级**（A 级信息充裕 / B 级信息适中 / C 级信息稀缺），写入 `00-系列说明.md`
2. 按复杂度表**定篇数**（高 7-8 / 中 4-6 / 低 3），说明是否有主轴被合并或拆分
3. **逐篇定目**：篇号 + 篇名 + 核心问题 + 承担大师 + 预期字数
4. **与用户确认核心论点与定目**（不跳步，避免写完才发现方向不对）

### 阶段 1：调研（写 01-02 篇前完成）

1. 阅读公司近 5 年年报、最新季报 — 使用对应市场数据工具 + 搜索五工具
2. 阅读至少 3 份独立卖方研报（找共识 + 反共识）

4. 取回口径出口结论：`garp-valuation` / `garp-exit` / `garp-management` / `garp-geo-policy` / `garp-macro`

### 阶段 2：写作（按 01 → 末篇顺序写，不跳）

- 每篇写完先存 `reports/{公司名}/《看懂{公司名}》-garp-{YYYYMMDD}/0X-XX.md`
- **不立即推 GitHub**——等用户审阅再提交

### 阶段 3：跨篇一致性扫描（全部篇目写完后）

**五项**扫描（骨架四项 + **本档新增串档扫描**）：

1. 同一数字跨篇是否一致
2. 同一术语首次出现是否解释
3. 引用关系是否对应
4. 要点回顾 vs 正文数字是否一致
5. **三档口径串档扫描**（跨档禁用清单逐项扫描，命中须为 0）

### 阶段 4：数据抽检与发布前最终核查

```bash
# Step 1 - 提取抽检清单（15%随机抽样；--report 实参为「报告文件路径」）
python tools/common/report_audit.py extract \
  --report reports/{公司名}/《看懂{公司名}》-garp-{YYYYMMDD}/00-系列说明.md --seed 42
```

## 修订意见处理流程

### 1. 先核查事实（不要直接改）

用户说"X 数据不对"时，先用工具找原始数据交叉验证，给出"用户说的数据 vs 我查到的数据 vs 我之前用的数据"三方对比。

### 2. 判断修订级别

| 级别 | 类型 | 处理 |
|------|------|------|
| 🔥 硬错误 | 数字错、归因错、口径错 | 必改，不需犹豫 |
| ⚠️ 主观化 | 强主观词、绝对化、流量党比喻 | 弱化或删除 |
| 🔬 颗粒度 | 来源标注、口径细化 | 优先级低，按可读性平衡 |
| ❓ 不可靠 | 第三方测算差异大 | **删比改更稳** |

### 3. 修订后联动检查

修一处先想"哪些地方还会引用这个数字/概念"——改了总市值，全系列联动改 PE；改了持股 %，改 TOP 10 排序；改了术语口径，改首次定义 + 后续引用。

### 4. 推送后立即报告

推送成功（commit hash），[N] 处修订总结带表。

## 核心原则

1. **事实核查标准** — 每个数据必须来自可靠来源，修订时必跑 7 项检查
2. **数据必须标注来源** — 关键数据至少 2 个来源交叉验证
3. **不虚构数据** — 搜不到就标注"估计"或"不可知"
4. **不用 AI 腔调** — 禁止"让我们一起来看看"等套话
5. **客观性原则** — 区分事实与观点，用数据支撑判断
6. **呈现正反两面** — 每个核心判断附反面论据
7. **诚实面对信息缺口** — 宁可标注"数据不足"，也不用推测填充
8. **不算期望年化回报加权值** — 主观概率分配会误导读者
9. **引用不重复定义** — 估值引用 `garp-valuation`（统一六档），卖出引用 `garp-exit`（五级），渗透率引用 `garp-industry-research`，管理层引用 `garp-management`，地缘引用 `garp-geo-policy`，宏观引用 `garp-macro`；本技能零阈值定义、零重新计分
10. **费雪质化 = 是否值得重仓的过滤器** — 需求真实性、销售组织、管理层持股 ≥3%、暂时性 vs 永久性衰退，决定"这家公司值不值得下重手"，而非"要不要写进来"
11. **GARP 口径双向红线 + 禁止 LLM 心算** — 同时禁长期链术语（护城河永续 / 终局思维 / 持有10年）与中期链术语（1~3 年景气持有）；PE/ROE/调整后 PEG/市值必须用 `financial_rigor.py` 验算

## 注意事项

- 网络搜索须使用本地五工具组合（详见 [web-search-tools](../tools-scripts/web-search-tools.md)），港股须 doubao+tavily 双源、美股须 exa+doubao 双源

- 信息丰富度评级（A/B/C 级）与定篇数依据必须在 `00-系列说明.md` 中注明

## 局限性说明

1. **信息可得性**：港股小票、新上市公司可能无法获取完整信息
2. **扫描版 PDF 限制**：A 股年报常为扫描版 PDF，可能无法提取文本内容，影响附注分析
3. **非实时数据**：工具获取的数据可能有延迟，不是实时数据
4. **渗透率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算，按 A/B/C 三级置信度标注并注明"估计"
5. **写作框架非决策工具**：本技能产出的是内容，不替代买入决策技能（`garp-investment-checklist`）与卖出决策技能（`garp-exit`）
6. **深度长文耗时/字数大**：适合公开内容输出场景，若仅需快速结论请用 `/garp-investment-research` 或 `/garp-investment-team`
7. **8 主轴模板的适配性未经验证**：模板源于长期版样本，GARP 版按 1~5 年口径重写，但未新增公司级样本验证；首次实跑后视需要回补
8. **不构成投资建议**：本技能仅用于学习与研究，不构成任何投资建议
