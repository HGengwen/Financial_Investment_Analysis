# 深度公司系列：3-8 篇长文拆一家公司（GARP 1~5 年价值成长独立档）

为 $ARGUMENTS 撰写一个《看懂 XX》深度长文系列（3-8 篇，按公司复杂度定，见"篇数适配"），发布在公众号/视频号等公开渠道。**核心 IP 不是"会写"，而是"会改"——99% 的财经文章在违反本 skill 的事实核查标准**。

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

> 💬 **本系列的底层思想框架（对齐 `upgrade1.0/中长期价值成长（GARP）投资框架.md`）**：
> - **费雪（质化分析）**：研发转化效率 + 销售组织有效性 + 管理层诚信与坦诚 + 长期利润率潜力——"真正能带来超额收益的，是那些在研发与销售组织上持续做对的少数公司。"
> - **林奇（选股起点 + 估值定价）**：常识验证 + 六类股票分类 + PEG 估值——"如果你花 10 分钟都解释不清一家公司是做什么的，那它的业务可能太复杂了。"
> - **郑希（赛道选择）**：ROE 趋势 + 产业景气 + 地缘政治——"ROE 向上是科技股最可靠的'重力加速度'。"
> - **李进（组合管理 + 治理）**：渗透率定位 + 二阶导监测 + 管理层与科研转化 + 治理一票否决——"用渗透率定位阶段，用二阶导监测拐点。"
> - **欧奈尔（风控底线）**：止损纪律 + 趋势信号——"8% 止损是生存红线。"
>
> 本系列不是巴菲特式"买入并永远持有"的研究，而是 **1~5 年价值成长持有 + 五级卖出纪律** 的深度研究框架。**禁止使用「护城河永续」「终局思维」「持有10年」「长期持有」「买入并遗忘」等长期框架术语；亦禁止原样沿用中期链的「1~3年景气持有」表述。**

参考样本：`reports/腾讯/《看懂腾讯》/`（长期版产物，仅参考篇目结构与写作格式；本 GARP 版按 1~5 年价值成长框架输出）

## 零、边界声明（四类口径只读，本技能的核心约束）

> **本技能不实现任何估值、卖出、管理层、地缘、宏观的判定逻辑，只做引用与转述。**

| 口径类别 | 权威实现方 | 本技能的动作 | 本技能禁止的动作 |
|---------|-----------|------------|----------------|
| 估值档位 / ESG 折价 / 宏观 PEG 区间 | `garp-valuation` | 引用统一六档结论（显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支） | 自行定义档位阈值、自行估算 ESG 折价率、用工具内置 `tier` / `rating` 判档 |
| 卖出纪律 | `garp-exit` | 引用五级（诚信否决 > 硬止损 8%~10% > 逻辑止损 > 产业景气判断 > 估值判断） | 自造层级、把时间止损/性价比替换提升为优先级位 |
| 管理层 / 科研转化 | `garp-management` | 引用诚信前置（一票否决，不计分）+ 管理层 20 分制（7+7+6）+ 科研转化 20 分制（8+8+4） | 重新计分、按行业自定义阈值、把诚信折算为分值 |
| 地缘 / 国产化率 | `garp-geo-policy` | 引用 0.3 三维交叉矩阵、赛道两分法判定、国产化率四梯队 | 自建评分、自行分层、在回避档下仍给正面结论 |
| 宏观参数 | `garp-macro` | 引用三表（利率 / 经济 / 美林）**修正参数** | 输出买卖方向指令、把宏观信号升级为卖出触发条件 |

**另**：本技能**禁止调用** `tools/common/terminal_value.py`（十年尺度终值口径属长期链，跨档即打回）。

## 一、触发场景

用户希望为一家公司做"教科书级别"的深度研究，并以**系列长文**形式公开发布。区别于一篇研报：
- 3-8 篇（复杂公司 8 篇约 12 万字，简单公司 3 篇约 3 万字），从认知重置到决策框架完整闭环
- 每篇独立成文（适合单篇分享），但贯穿一套估值/管理层/价格判断
- 写给"愿意花 90 分钟读懂一家公司"的读者，不是写给券商客户

**不适合用本 skill 的场景**：单篇研报、季报点评、行业研究——那些用 `/garp-investment-research`（快速五大师报告 GARP 版）、`/garp-earnings-review`、`/garp-industry-research`。

## 二、系列篇目模板

### 阶段 0 前置：先定篇数，再定篇目（强制）

**篇数不固定为 8。** 8 篇是腾讯这种"多业务 + 万亿投资组合 + 20 年管理层故事"的公司才撑得起的容量。写之前先执行**阶段 0（定篇数与定目）**：

1. 完成**信息丰富度评级（A/B/C 级）**（见"五、执行流程 · 阶段 1"）
2. 清点这家公司有几个能用"一个尖锐问题"独立成文的主轴
3. 按复杂度表定篇数 → 定篇目 → **与用户确认后才进阶段 1 调研**

| 复杂度 | 特征 | 篇数 | 例子 |
|--------|------|------|------|
| 高 | 多条业务线各自成生意 + 隐藏资产/投资组合 + 管理层史料丰富 | 7-8 篇 | 腾讯 |
| 中 | 2-3 条业务线 + 一个重大时代变量 | 4-6 篇 | — |
| 低 | 主业清晰、核心问题少而集中 | **3 篇** | 快手 |

### 3 篇标准合并方式（GARP 版）

**篇数不固定为 8。** 下面的 8 主轴仍是**检查清单**（全部要覆盖，只是折进 3 篇）：

| # | 篇名方向 | 折入的主轴 | 承担大师 |
|---|---------|-----------|---------|
| 01 | 你以为你看懂了 X（开篇 + 生意与护城河） | 认知重置 + 护城河 + 利润引擎概览 + **费雪质化视角** | 林奇 + 费雪 |
| 02 | X 的最大变量（当下叙事/隐藏资产/产业景气） | 隐藏资产 + 时代变量（含产业景气 + **地缘三维交叉矩阵**） | 郑希 + 李进 |
| 03 | 多少钱值得买，什么信号必须卖（决策终章） | 财务深度 + 管理层要点 + **估值多工具矩阵六档 + 五级卖出纪律** | 林奇 + 欧奈尔 + 李进 |

判断信号：如果某篇写到一半发现在"凑内容"（同一事实换说法重复出现），说明篇数定多了——合并。反之，某篇超过 12,000 字还塞不下，拆开。

### 8 主轴全模板（复杂公司用；简单公司当检查清单折叠）

| # | 篇名模板 | 核心问题 | 核心思想来源 | 字数 |
|---|---------|---------|------------|------|
| 01 | 你以为你看懂了 X，其实没有 | 认知重置：破 3 个常见错觉（**含"质化叙事"错觉**） | 林奇"常识验证" + **费雪"质化分析"** | 4,000-5,000 |
| 02 | X 的护城河——`<生意本质一句话>` | 护城河深不深、**1~5 年价值成长周期中能否支撑 ROE 向上**（**含研发转化/销售组织维度**） | 郑希"ROE护城河" + **费雪"研发与销售组织"** | 6,000-8,000 |
| 03 | X 的最大利润引擎——`<最赚钱业务>` | 主业是什么、为什么能持续、**渗透率位置与景气节奏** | 林奇 + 李进 | 6,000-8,000 |
| 04 | X 藏在账上的另一家公司——`<隐藏资产>` | 投资组合 / 子公司 / 隐藏价值 | 林奇"隐蔽资产型" | 8,000-10,000 |
| 05 | 国产化与产业景气时代，X 是赢家还是输家 | 时代变量：**分业务拆国产化与产业影响 + 渗透率 `15%~40%` 五档 + 国产化率四梯队 + 地缘 0.3 三维交叉矩阵** | 郑希 + 李进 + **费雪"研发管线"** | 8,000-10,000 |
| 06 | 拆 X 的财报：ROE、现金流与景气信号 | 财务深度：**ROE 8 季度趋势、毛利率/FCF、二阶导、渗透率变化** | 郑希 + 李进 | 8,000-10,000 |
| 07 | `<管理层金句>`——X 的管理层值不值得托付 | **诚信前置（一票否决）+ 管理层 20 分制（7+7+6）+ 科研转化 20 分制（8+8+4）+ 承诺兑现率 + 接班人** | 李进 + **费雪"管理层坦诚"** | 8,000-10,000 |
| 08 | 多少钱值得买，什么信号必须卖（系列终章） | **估值多工具矩阵六档（引用 `garp-valuation`，含 ESG 折价与宏观 PEG 区间）+ 分批建仓 + 五级卖出纪律（引用 `garp-exit`）+ 宏观三表只调参不择时** | 林奇 PEG + 欧奈尔止损 + **费雪"质化校验"** | 10,000-12,000 |

加一篇 `00-系列说明.md` 作为目录索引（不发表，含信息丰富度评级 + 定篇数依据 + 每篇主轴）。

**篇目必须适配公司**：模板是腾讯长出来的，不是套子。某篇没有独立内容（如没有投资组合的公司写不了 04），就替换成该公司特有的主轴，或按上面的合并方式折进更少的篇数。

## 二·五、篇内结构模板（从《看懂腾讯》8 篇正文提炼）

每篇不是自由发挥，有固定骨架。共性结构：

- **头部引用块**：`> 《看懂X》系列 · 第 0N 篇 · <主轴>`，开篇加阅读时间
- **第一节永远是钩子**：一组反常识数字 / 一条反常曲线 / 一个让市场担心的数字，不写背景铺垫
- **每篇末尾**：`## 本篇要点回顾`（5-8 条，数字与正文严格一致）+ `## 下期预告`（用尖锐问题预告，不剧透结论）
- **结尾两行斜体**：`*本文是《看懂X》系列第 0N 篇...*` + `*本系列基于公开信息和GARP（1~5年价值成长）投资框架研究，不构成任何投资建议。*`

**终章（末篇）另有六项附加刚性**：① 估值档位须标注「引用 `garp-valuation` 六档」；② 卖出触发须标注「引用 `garp-exit` 五级」；③ 宏观段须标注「只调参不择时」；④ 股息/赔偿类结论不得给指令性数值；⑤ 若赛道被判「回避档」，**不得给出买入倾向**（分级降格须显式写明）；⑥ 全系列关键数字须与正文逐一对齐并附抽检结论。

各篇专属骨架（GARP 1~5 年独立档版）：

| 篇 | 骨架 | 核心思想来源 |
|---|------|------------|
| 01 开篇 | 股价被市场反复"重新定性"的历史曲线 → 三个常见错觉（每个用财报数据破，**其中一个必须是"质化叙事"错觉**）→ 阅读地图（链接到 02-08）→ 估值钩子数字表（只留悬念不给结论） | 林奇"常识验证" + 费雪"质化分析" |
| 02 护城河 | 挑战者失败名单（有名有姓有年份）→ 迁移成本的本质 → 生态飞轮 → **1~5 年价值成长周期中 ROE 能否持续向上** → **研发转化效率与销售组织有效性（费雪维度）** → 反向思维实验（"1000 亿能否复制它"） | 郑希"ROE护城河" + 费雪 |
| 03 利润引擎 | 反常识数字开场 → 核心产品为何长青 → **渗透率定位（`15%~40%` 五档中的哪一档？）** → 增长空间量化 → 反面论据 → 国产化/产业景气影响 → 未来一年图景 | 林奇 + 李进 |
| 04 隐藏资产 | TOP 持仓表（**只统计未并表部分**，并表的单独说明防双算）→ 会计处理差异 → "不会卖 vs 可能减持"分类 → 市场为何打折价 → 估算折扣（**给区间，不给点估计**） | 林奇"隐蔽资产型" |
| 05 国产化与产业景气 | 让市场担心的数字 → **分业务拆赢家/输家（严重分化）** → **渗透率 `15%~40%` 五档定位 + 国产化率四梯队（引用 `garp-geo-policy`）** → **二阶导判断（增速加速还是减速）** → **地缘 0.3 三维交叉矩阵与赛道两分法判定** → 未来一年监控信号清单 | 郑希 + 李进 + 费雪 |
| 06 财务与景气信号 | 一条反常曲线开场 → 利润表（毛利率变化归因）→ **ROE 8 季度趋势图** → **营收增速二阶导** → **渗透率变化** → FCF Yield → 股东回报 → 估值横向+历史比较 → 把财报压缩成三句话 | 郑希 + 李进 |
| 07 管理层 | 核心团队表 → 关键人物长期贡献 → 利益对齐 → **诚信前置检验：挑一次真实危机看应对（命中即出局，不计分）** → **5 年承诺兑现率（逐条核对）** → **科研转化 20 分制（8+8+4）** → **管理层 20 分制（7+7+6）** → 费雪补充（管理层坦诚度 / 销售组织） → 接班人隐忧 → 综合评分（**口径对齐 `garp-management`，本系列不重新计分**） | 李进 + 费雪 |
| 08 估值与卖出纪律 | **估值档位（引用 `garp-valuation` 统一六档：显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支）** → **ESG 环境风险折价叠加** → **宏观 PEG 区间校准（引用 `garp-macro`，只调参不择时）** → **分批建仓节奏（参数化，不给指令性数值）** → **五级卖出触发条件（引用 `garp-exit`：诚信否决 > 硬止损 8%~10% > 逻辑止损 > 产业景气判断 > 估值判断）** → 历史估值分位 → 未来利润三情景 → 欧奈尔止损位（8%~10%）→ 赔率思维收尾 | 林奇 PEG + 欧奈尔止损 + 费雪"质化校验" |

## 三、写作风格规范

### 语气

- **直接、犀利、不说废话**——第一句就给数字或反常识结论
- **GARP 价值成长框架**——费雪/林奇/郑希/李进/欧奈尔视角穿插（但不堆砌名言）
- **不预设立场**——先摆数据、再推逻辑、最后得结论
- **呈现正反两面**——每个核心判断都附"但另一方面..."的反方
- **公众号体感**——前 18-20 字必须能独立站住（手机预览）

### 禁用词（双向红线：长期链 + 中期链同时禁）

| 禁用 | 原因 | 替代 |
|------|------|------|
| 显然 / 必然 / 一定 | 主观绝对化 | 数据显示 / 证据表明 |
| 我认为 / 我觉得 | 主观腔调 | 删除或改为"按本框架" |
| 教科书级别 / 神来之笔 | 流量党褒奖 | 描述具体事实 |
| 严重不匹配 / 严重低估 | 强主观词 | 给具体折让百分比 |
| 完美 / 无可挑剔 | 单边判断 | 加上反方观察 |
| "长期持有" / "永远不卖" / "绝不卖" / "买入并遗忘" | 长期框架术语（**跨档红线**，含费雪"绝不卖"式误用） | "GARP 1~5 年价值成长持有" / "每季度用财报与景气数据体检" |
| 护城河永续 / 终局思维 / 持有10年 | 长期框架术语（**跨档红线**） | 1~5 年价值成长周期中护城河是否支撑 ROE 向上 |
| "1~3年景气持有" / "景气周期内持有" 原样承袭 | 中期链表述（**跨档红线**） | 统一改写为 GARP 1~5 年价值成长口径 |

### 标题风格

- 用**反差数字**或**反共识结论**做钩子（"15 年 7 次挑战全失败"、"ROE 连续 8 季度攀升"）
- 副标题中性、概括内容（"——`<本质判断>`"）
- **避免流量党比喻**："小巴菲特"、"中国版 X"、"YYDS" 一律避开
- 用专业读者熟悉的术语（"PEG"而不是"估值指标"，"二阶导"而不是"增速变化"）

## 四、严苛事实核查 Checklist（核心 IP）

### 写之前就要警惕的"伪精确"陷阱

1. **概率加权期望值**：`30% × A + 50% × B + 20% × C = 期望 +X%` 这种计算几乎全是垃圾——概率分配是纯主观，给读者错误精确感。**只列情景 + 触发条件 + 方向，不算加权期望**。
2. **第三方测算 MAU/份额**：QuestMobile/七麦/CBNData 等口径差异巨大（同一时点能差 2-3 倍）。**只用最可信的两个对比作 anchor，其他做定性描述**。
3. **历史增速线性外推**：`2025 年 +33% × 5 年复合 → 2030 年 X` 是金融文盲式预测。**情景假设 + 高/低区间 + 不是承诺**。
4. **未公开的持股比例**：字节、Halti 类未上市公司持股**从未公开披露**。**给区间，标"不可知"**。
5. **强归因**：竞争对手失败 = 因为 X。多重原因都列出来，**本文不做单一归因**。
6. **渗透率精确值**：细分行业渗透率多数无官方统计，必须标注"估计"并注明来源；跨越 **`15%~40%` 黄金窗**的判断口径对齐 `garp-industry-research`（**TAM ≥ 1000 亿元**为进入深度系列的前置门槛）。

### 修订时必跑的 7 项检查

```
□ 1. 跨篇数字一致性：总市值、净利润、关键持股 %、ROE、估值档位 全系列对齐
□ 2. 口径标注：Non-IFRS / GAAP / Non-IFRS-SBC / FCF / 调整后 PEG 各用哪个，全文清楚
□ 3. 重复加计扫描：已并表子公司不在"投资组合"里、SOTP 不双算
□ 4. 横向比较公平性：不能"主业 PE" vs "对手 PE（不剔）"
□ 5. 概率加权全删
□ 6. 绝对化与跨档术语全弱化：grep "显然|必然|严重|教科书|完美|长期持有|永远不卖|绝不卖|买入并遗忘|护城河永续|终局思维|持有10年"
□ 7. 第三方数据来源标注：每条非财报数据后跟"（来源：X）"
```

### 模型偏好（已知硬错误风险，GARP 1~5 年独立档版）

写之前**先列出已知硬错误风险**：
- 历史回报倍数：必须用累计投入口径（如 Riot 33 倍 不是 58 倍）
- 持股比例：必须看最新富途/财报口径（如腾讯持有美团 1.5% 不是 6.4%）
- "派息分派"会计处理：视同处置收益按 IFRIC 17 在宣派日确认（如京东在 2021，美团在 2022 但金额小）
- 总股本会反弹：SBC 集中年初授予会让股本短期上升
- **调整后 PEG 必须用 `financial_rigor.py adjusted-peg` 计算，禁止 LLM 心算**；**档位判定以 `garp-valuation` 统一六档输出为准**（工具内置 `tier` / `rating` 一律不进档位判定）
- **ROE 8 季度趋势**：连续 3 季同向才判拐点，单季波动判噪音（对齐郑希口径）
- **禁止用十年尺度终值口径**给本系列估值（长期链专用工具，见「零、边界声明」）——跨档即打回

## 五、执行流程

### 阶段 0：定篇数与定目（**GARP 版新增，强制前置**）

**顺序不可颠倒：先评级 → 再清点主轴 → 再定篇数 → 再定篇目 → 与用户确认 → 才进阶段 1。**

1. **信息丰富度评级（AI 研究偏见预警，必执行）**

   | 等级 | 特征 | AI 研究陷阱 | 应对策略 |
   |------|------|-----------|----------|
   | **A级（信息充裕）** | 上市多年、券商覆盖广、媒体报道密集 | 共识过强，AI 输出趋同于市场定价 | 重点做**反面检验**与**非共识视角**，避免输出与市场一致的"正确的废话" |
   | **B级（信息适中）** | 上市 1-3 年、覆盖有限、部分数据需推算 | AI 用「合理推测」填补空白，产生虚假确定性 | 每个推算数据标注置信度，区分「有据推算」与「凭空填充」 |
   | **C级（信息稀缺）** | 冷门/新上市/新兴市场、几乎无覆盖 | AI 因资料不足过度保守，误判「看不清=不好」 | 转「第一性原理模式」：不追求系列完整性，聚焦商业本质的几个核心问题 |

   关键提醒：资料多≠确定性高，资料少≠确定性低。确定性来自生意本质与景气趋势，不来自资料数量。评级结果影响各篇调研深度，并在 `00-系列说明.md` 中注明。

2. **主轴清点**：逐条列出"能用尖锐问题独立成文"的候选主轴，标注每条的**承担大师**（费雪/林奇/郑希/李进/欧奈尔）与预期字数。
3. **定篇数**：按复杂度表（高 7-8 / 中 4-6 / 低 3）定篇数，并写明**定篇数依据**。
4. **定篇目**：产出篇目清单（篇名 + 主轴 + 大师 + 字数），写入 `00-系列说明.md`。
5. **与用户确认篇目**（避免写完才发现方向不对）。

### 阶段 1：调研（写 01-02 篇前完成）

1. **阅读公司近 5 年年报、最新季报**（按市场选择工具）
   - A股：`tools/a_share/stock_screen.py` + `tools/common/anysearch.py`（主）+ `tools/common/doubao_search.py`（辅）
   - 港股：`tools/hk_stock/stock_screen.py` + `tools/common/doubao_search.py`（主）+ `tools/common/tavily_search.py`（辅）
   - 美股：`tools/us_stock/stock_financial.py --indicators` + `tools/common/exa_search.py`（主）+ `tools/common/doubao_search.py`（辅）
2. **阅读至少 3 份独立卖方研报**（找共识 + 反共识）
3. **使用 `/garp-investment-research` 先生成内部研究底稿**（快速五大师报告 GARP 版，替代长期版 `/quality-screen` 去劣筛选——本系列面向已入选赛道的好公司）
4. **只读引用四类下游口径**（**本技能不重新定义、不重新计分**）：
   - 估值档位 → `/garp-valuation`（统一六档 + ESG 折价 + 宏观 PEG 区间）
   - 卖出纪律 → `/garp-exit`（五级）
   - 管理层/科研转化 → `/garp-management`（诚信前置 + 7+7+6 + 8+8+4）
   - 地缘与国产化 → `/garp-geo-policy`（0.3 三维交叉矩阵 + 赛道两分法 + 国产化率四梯队）
   - 宏观参数 → `/garp-macro`（三表，**只调参不择时**）

### 阶段 2：写作（按 01→末篇顺序写，不跳）

- 每篇写完先存 `reports/{公司名}/《看懂{公司名}》-garp-{YYYYMMDD}/0X-XX.md`
- **目录冲突规则**：新系列写入带日期后缀的新文件夹 `-garp-{YYYYMMDD}`，旧文件夹（含长期版 `《看懂{公司名}》/` 与中期版 `-mid-{YYYYMMDD}/`）原样保留，不覆盖、不混放
- 不立即推 GitHub——等用户审阅

### 阶段 3：跨篇一致性扫描（全部篇目写完后）

派 Explore agent 并行扫描全系列做以下**五项**检查（前四项承接骨架，**第五项为 GARP 新增**）：

1. 同一数字跨篇是否一致
2. 同一术语首次出现是否解释
3. 引用关系是否对应
4. 要点回顾 vs 正文是否数字一致
5. **三档口径串档扫描（GARP 新增）**：按**附录C 跨档禁用清单**（`GDS-7` / `GDS-12` 所列）逐项扫描全系列，全部**命中须为 0**；清单不在本行重复枚举（避免"扫描指令自身含禁用词"造成的自命中）

### 阶段 4：数据抽检与发布前最终核查

```bash
# Step 1 - 提取抽检清单（15%随机抽样；--report 实参为「报告文件路径」）

  --report reports/{公司名}/《看懂{公司名}》-garp-{YYYYMMDD}/00-系列说明.md --seed 42

# Step 2 - 对清单每项从可靠信源取数（按市场分别使用对应工具）

# Step 3 - 输出准出/打回判决

  --results '<填好的JSON>' --report {系列目录}
```

- **【准出】** 所有抽检点偏差 ≤ 1% → 报告可发布
- **【打回】** 任意点偏差 > 1% → 修正后重新抽检

## 六、修订意见处理流程

用户给修订意见时，按以下顺序处理：

### 1. 先核查事实（不要直接改）

如果用户说"X 数据不对"，先用工具找原始数据交叉验证（按市场选择对应工具），给出"用户说的数据 vs 我查到的数据 vs 我之前用的数据"三方对比。

### 2. 判断修订级别

| 级别 | 类型 | 处理 |
|------|------|------|
| 🔥 硬错误 | 数字错、归因错、口径错 | 必改，不需犹豫 |
| ⚠️ 主观化 | 强主观词、绝对化、流量党比喻 | 弱化或删除 |
| 🔬 颗粒度 | 来源标注、口径细化 | 按可读性平衡 |
| ❓ 不可靠 | 第三方测算差异大 | **删比改更稳** |

### 3. 修订后联动检查

修一处先想"哪些地方还会引用这个数字/概念"——改了总市值，全系列联动改估值档位；改了持股 %，改 TOP 10 排序；改了术语口径，改首次定义 + 后续引用。

### 4. 推送后立即报告

推送成功（commit hash），[N] 处修订总结带表。

## 十、本 skill 不做什么

- **不替读者做投资决策**——所有篇章末尾"不构成投资建议"
- **不预测股价**——只给"情景 + 触发条件"
- **不给指令性数值**——不写"建议 X 元买入 Y 股 / 目标价 / 何时买"，建仓结论一律**参数化**呈现
- **不算"期望年化回报"加权值**——主观概率分配会误导读者
- **不写"X 大佬也持有"**——用别人的持仓为自己的判断背书是反价值投资的
- **不强求 8 篇都写**——如果某篇没足够独立内容，合并或减篇数
- **不重新定义下游口径**——估值档位、卖出五级、管理层计分、地缘评分、宏观参数**一律只读引用** `garp-*` 出口技能，本技能零定义、零重新计分
- **不做择时**——宏观三表只用于**修正参数**，不得输出买卖方向指令，不得升级为卖出触发条件
- **不承诺"永远持有"**——本系列是 GARP 1~5 年价值成长框架，不是"买入并遗忘"；终章必须给五级卖出纪律（引用 `garp-exit`），不能用"长期持有"替代

## 十一、合规与隐私

- 所有公开报告**只用公开信息**（财报、官方披露、券商研报、知名第三方机构）
- 不用任何**用户个人信息**（公司花名、内部 IM、未公开持仓信息）
- 推送前必须用 grep 扫描 本机用户名 / `/Users/` / 真实姓名 等隐私字段
- 公开署名按用户多层身份策略，不混用

## 十二、注意事项

- 市值必须手算校验：股价 × 总股本
- 货币单位要明确（港币/人民币/美元）
- PE/ROE/调整后 PEG 等指标用 `tools/common/financial_rigor.py` 精确计算，**禁止 LLM 心算**；**禁止调用十年尺度终值口径工具**（长期链专用，见「零、边界声明」）
- 网络搜索须使用 `--time-range month/week` 限制时间范围
- 港股/美股须按市场双源验证
- 调整后 PEG = 研发费用回加核心经营利润后的 PE ÷ 未来盈利增速（%），**档位判定以 `garp-valuation` 统一六档输出为准**（显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支），不自行重复定义阈值
- 卖出纪律统一引用 `garp-exit` **五级**（诚信否决 > 硬止损 8%~10% > 逻辑止损 > 产业景气判断 > 估值判断），不用自造层级；时间止损/性价比替换仅作**补充机制**列示，**不占优先级位**
- 管理层 20 分制（7+7+6）/ 科研转化 20 分制（8+8+4）/ 诚信前置一票否决 口径对齐 `garp-management`
- 地缘 0.3 三维交叉矩阵 / 赛道两分法 / 国产化率四梯队 口径对齐 `garp-geo-policy`
- 渗透率 `15%~40%` 五档与 TAM ≥ 1000 亿元 口径对齐 `garp-industry-research`
- 信息丰富度评级（A/B/C 级）与定篇数依据必须在 `00-系列说明.md` 中注明
- 报告发布前必须通过 `tools/common/report_audit.py` 数据抽检（偏差 ≤1% 准出、>1% 打回）
- 推送前必须用 grep 扫描本机用户名、`/Users/`、真实姓名等隐私字段
- 报告写完后主动询问是否推送到 GitHub

## 十四、局限性

1. **信息可得性**：港股小票、新上市公司可能无法获取完整信息
2. **扫描版PDF限制**：A 股年报常为扫描版 PDF，可能无法提取文本内容，影响附注分析
3. **非实时数据**：工具获取的数据可能有延迟，不是实时数据
4. **渗透率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算，按 A/B/C 三级置信度标注并注明"估计"
5. **写作框架非决策工具**：本技能产出的是内容，不替代买入决策技能（`garp-investment-checklist`）与卖出决策技能（`garp-exit`）
6. **深度长文耗时/字数大**：适合公开内容输出场景，若仅需快速结论请用 `/garp-investment-research` 或 `/garp-investment-team`
7. **8 主轴模板的适配性未经验证**：模板源于腾讯长期版样本，GARP 版按 1~5 年口径重写，但未新增公司级样本验证；首次实跑后视需要回补
8. **不构成投资建议**：本技能仅用于学习与研究，不构成任何投资建议

## 一句话总结

**写《看懂 X 系列》的核心能力 ≠ 写得好，而是改得严**——
89% 的财经长文死于伪精确数字、主观加权期望值、绝对化表述。本 skill 的存在就是为了把这些坑全部标记出来，写之前避开，写之后扫干净。

**在 GARP 1~5 年价值成长框架下，增加了三个必须检查的维度**：
- ROE 8 季度趋势 + 二阶导 + 渗透率 `15%~40%`（郑希/李进）
- 估值多工具矩阵六档 + ESG 折价 + 宏观 PEG 区间 + **五级卖出纪律（引用 `garp-exit`）**（林奇/欧奈尔）
- 管理层科研转化（8+8+4）+ 诚信前置一票否决 + **费雪质化分析**（李进/费雪，引用 `garp-management`）

*融合费雪/林奇/郑希/李进/欧奈尔五位大师视角 + 长期版写作框架 | 适用于 GARP 1~5 年中长期价值成长深度长文创作 | V1.0.0*
