# PDF文档提取 (PDF Extraction)

使用Poppler工具集从PDF格式文档中提取数据和信息，支持文本版和扫描版PDF处理

---

## 快速开始

### 基本调用方式

```
/pdf-extraction {PDF文件路径}
```

例如：
- `/pdf-extraction 601899_2025年报.pdf`
- `/pdf-extraction ./cninfo_reports/茅台_2024年报.pdf`
- `/pdf-extraction reports/腾讯_2025Q2财报.pdf`

---

## 核心功能

使用 Poppler 工具集从 PDF 格式文档中提取数据和信息，提供标准化的 PDF 提取流程，确保财务数据提取的准确性和效率。适用于从下载的年报、季报、半年报等财务报告中提取财务数据。

### Poppler 三大工具

| 工具 | 功能 | 主要用途 |
|------|------|---------|
| `pdftotext` | 将PDF转换为纯文本 | 提取年报中的文字内容 |
| `pdfinfo` | 获取PDF文档信息 | 查看页数、标题、作者等元数据 |
| `pdftoppm` | 将PDF页面渲染为图像 | 处理扫描版PDF、提取图表 |

### 年报数据提取标准流程

1. **下载年报PDF** — 使用 `tools/stock_equity.py --download-report`
2. **检查PDF类型** — 文本版 vs 扫描版（用 pdftotext 快速测试）
3. **文本版提取** — `pdftotext -layout` 提取文本，grep 搜索关键词
4. **扫描版处理** — `pdftoppm -png -r 300` 渲染为图像，OCR识别或人工核对
5. **数据交叉验证** — 与东方财富、巨潮资讯等数据源对比

### 三类PDF处理策略

| PDF类型 | 识别方法 | 处理工具 | 数据提取方式 |
|---------|---------|---------|-------------|
| **文本版PDF** | pdftotext 能正常输出文本 | pdftotext | 直接提取文本，用 grep 搜索关键词 |
| **扫描版PDF** | pdftotext 输出乱码或空白 | pdftoppm + OCR | 渲染为图像，用 OCR 工具识别或人工核对 |
| **混合版PDF** | 部分页面可提取，部分不能 | pdftotext + pdftoppm | 区分处理，文本部分直接提取，扫描部分渲染 |

## 使用示例

### 示例1：提取文本版年报财务数据
```bash
# 提取文本内容
pdftotext -layout 601899_2025年报.pdf 601899_2025年报.txt

# 搜索关键财务数据
grep -n "净利润\|营业收入\|毛利率\|ROE\|资产负债率" 601899_2025年报.txt
```
提取年报全文并搜索关键财务指标。

### 示例2：处理扫描版年报
```bash
# 渲染为高分辨率PNG图像
pdftoppm -png -r 300 601899_2025年报.pdf output/page

# 对渲染的图像进行OCR识别
tesseract output/page-100.png output/page-100 -l chi_sim
```
将扫描版PDF转为图像，再用 OCR 工具识别文字。

### 示例3：提取特定章节
```bash
# 提取第80-100页（财务报表章节）
pdftotext -f 80 -l 100 -layout 601899_2025年报.pdf 601899_2025年报_财务报表.txt
```
按页面范围提取特定章节内容。

## 输出报告

报告将保存在以下位置：

| 报告类型 | 文件路径 |
|---------|---------|
| 文本提取结果 | `{原PDF文件名}.txt`（同目录） |
| 图像渲染结果 | `{输出目录}/page-{页码}.png` |
| OCR识别结果 | `{图像文件名}.txt`（同目录） |

### 输出文件命名规则

- 文本提取：`{股票代码}_{年份}年报.txt`（如 `601899_2025年报.txt`）
- 图像渲染：`{输出目录}/page-{页码}.png`（如 `output/page-100.png`）
- 部分提取：`{原文件名}_部分.txt` 或 `{原文件名}_财务报表.txt`

## 提取标准

### 数据准确性要求

财务数字必须准确无误，不得有偏差。核心指标（净利润、营业收入、ROE等）建议人工复核。

### 误差控制

- 从PDF提取的数据必须与其他来源进行交叉验证
- 特别关注数字、单位、小数点位置的准确性
- **误差>1%必须标记**

### 文件大小管理

- 高分辨率渲染会生成大量图像文件（每页1-5MB）
- 300页年报渲染为300dpi PNG，总计约1-1.5GB
- **建议**：先用低分辨率预览，确定需要的页面后再高分辨率渲染

## 工具依赖

| 工具 | 功能 |
|------|------|
| `pdftotext` | PDF转纯文本（Poppler工具集） |
| `pdfinfo` | 获取PDF文档信息（Poppler工具集） |
| `pdftoppm` | PDF页面渲染为图像（Poppler工具集） |
| `tesseract` | OCR文字识别（可选，处理扫描版PDF） |
| `tools/stock_equity.py` | 下载A股年报PDF |
| `tools/stock_financial.py` | A股财务指标（用于交叉验证） |

**工具安装**：
- **Windows**：[Poppler for Windows](http://blog.alivate.com.au/poppler-windows/)
- **Linux**：`sudo apt-get install poppler-utils`
- **macOS**：`brew install poppler`
- **验证安装**：运行 `pdftotext -v` 检查是否可用

**重要约束**：
- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- 提取的财务数据必须与其他来源交叉验证，不能单独使用

## 核心原则

1. **准确性优先** — 财务数字必须准确无误，核心指标建议人工复核
2. **交叉验证** — 从PDF提取的数据必须与东方财富、巨潮资讯等数据源对比
3. **区分PDF类型** — 文本版用 pdftotext，扫描版用 pdftoppm + OCR
4. **分批处理** — 超大PDF文件按页面范围分批提取，避免一次性处理
5. **诚实面对限制** — 扫描版PDF处理准确度依赖图像质量，标注低置信度
6. **数据溯源** — 所有提取数据必须标注来源PDF文件和页码

---

## 注意事项

- **扫描版PDF限制**：A股年报常为扫描版，无法直接提取文本，必须使用 pdftoppm 转为图像
- **文件大小管理**：高分辨率渲染会生成大量图像文件，先低分辨率预览再高精度渲染
- **内容完整性验证**：扫描版PDF可能存在字迹模糊、页面倾斜，重要数据建议人工复核
- **工具可用性**：Windows 用户需要安装 Poppler for Windows
- **数据验证原则**：从PDF提取的数据必须与其他来源交叉验证，误差>1%必须标记
- **关键数字必须人工验证**：净利润、营业收入、ROE等核心指标
- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）

---

## 局限性说明

- **扫描版PDF处理限制**：扫描版PDF需要额外使用OCR工具，准确度依赖图像质量
- **表格数据提取困难**：PDF中的复杂表格难以完美还原，建议手动核对
- **数据验证要求**：提取的数据必须与其他来源交叉验证，不能单独使用
- **工具依赖性**：需要安装 Poppler 工具集，Windows 用户需要额外配置
- **OCR准确度**：tesseract 等开源OCR工具准确度中等，核心数据建议人工输入验证
- 不构成投资建议，仅供学习研究参考
