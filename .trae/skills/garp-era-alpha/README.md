# 时代α捕手（GARP 独立档·1~5 年）(GARP Era Alpha)

时代级高增长主线与核心 α 的识别-验证-持有框架，聚焦 **1~5 年**持有周期内的高景气主线锁定与核心 α 验证，给出明确的介入与退出纪律。

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

本技能是长期链时代α捕手技能与 1~3 年中期链时代α捕手技能在 **GARP 独立档（1~5 年）** 的对应物，三者**物理隔离**：长期回答「10 年后还在吗？」，中期回答「未来 1-3 年景气向上吗？」，本技能回答「**未来 1~5 年最核心高景气主线中，谁是有定价权、有景气壁垒、能持续跑赢同行的核心 α？值不值得进？**」。

## 核心功能

对指定行业/方向执行「GARP 时代α五步法」，找出当下 1~5 年最核心高景气主线中真正有定价权、有景气壁垒、能持续跑赢同行的核心 α。

### 五步研究框架（前置 A/B + 五步）

1. **前置 A（日期与市场）** — 确认当天日期、市场归属与数据工具组合；方向含糊先澄清
2. **前置 B（地缘前置闸门）** — **只读** `garp-geo-policy` 0.3 三维交叉矩阵 + 赛道两分法 + 国产化率四档；**回避档 → 终止扫描**
3. **时代主线认知地图** — 基于渗透率 `15%~40%` 坐标 + 国产化率四梯队 + 地缘只读，锁定 2-3 个核心环节
4. **自问核心问题（收敛闸门）** — 渗透率 `15%~40%` + TAM ≥1000 亿 + 连续 2 季业绩兑现，三条缺一即降级
5. **景气可持续性验证** — 五维交叉（财报 + 高频数据）+ 五大师透镜 + 管理层/科研转化只读
6. **估值锚点与介入** — 档位**只读** `garp-valuation` 六档 + 宏观只调参不择时；结论三选一 + 介入方式三选一
7. **持仓与退出纪律** — 底仓/机动仓只读 + 三层拐点清单 + 五级卖出只读 `garp-exit`

### 三项修正（落到 GARP 1~5 年语境）

| 修正 | 内容 |
|------|------|
| 修正一（精简范围） | 不覆盖所有行业，聚焦主线中 2-3 个核心环节做深做透 |
| 修正二（高频数据交叉验证） | 财报是三个月前的体检报告，用周度/月度出货量、价格、订单、渗透率做实时体温计校正 |
| 修正三（估值锚点） | 以 **多工具矩阵统一六档** 为核心锚点替代「闭眼买」——档位只读 `garp-valuation`，合理/低估可介入、偏贵但景气可消化可持有或分批、严重透支只看不买 |

### 五大师验证透镜（GARP 独立档）

| 大师 | 验证透镜 | 核心追问 |
|------|---------|---------|
| 费雪 | 需求真实性与持续性 | 需求有订单/收入/利润支撑吗？销售组织健康吗？持股 ≥3% 吗？困难是暂时性还是永久性衰退？ |
| 林奇 | 常识与求证 | 这门生意「看得懂」吗？属六类中的哪一类？增长来自真实需求还是题材炒作？ |
| 郑希 | 产业景气与第一性原理 | 产业处于 ROE 曲线哪个位置？有无 ROE 向上拐点？全球产业链哪个环节率先景气？ |
| 李进 | 渗透率坐标与系统均衡 | 渗透率处于 `15%~40%` 五档哪一档？二阶导是加速还是减速？治理有无硬伤？ |
| 欧奈尔 | 信号与风控底线 | 技术面趋势是否确认？突破买点/抛售日信号？硬止损底线在哪（只读 `garp-exit`）？ |

## 使用示例

### 示例 1：研究 AI 算力主线
```
/garp-era-alpha AI算力
```
建立主线与产业链认知地图，经渗透率 `15%~40%` 黄金窗收敛闸门锁定核心环节，识别核心 α，五维 + 五大师验证景气可持续性，档位只读 `garp-valuation` 六档给出介入锚点，并列出三层拐点清单与五级卖出提示。

### 示例 2：研究人形机器人
```
/garp-era-alpha 人形机器人 --scope A股
```
限定 A 股范围扫描，判断渗透率是否进入 `15%~40%` 加速上行期，国产化率落在第几梯队，筛选有定价权与景气壁垒的 α，高频数据（订单/招标/出货）交叉验证。

### 示例 3：方向名含糊需澄清
```
/garp-era-alpha AI
```
「AI」跨度过大 → 技能先反问澄清细分方向（是 AI 算力 / AI 应用 / AI 芯片？），澄清后再执行。

## 输出报告

报告将保存在 `reports/era-alpha/{方向}/` 目录下，共 **四类文件**：

| 报告类型 | 文件路径 |
|---------|---------|
| 时代主线认知地图（存量） | `reports/era-alpha/{方向}/mainline-map.md` |
| 核心 α 名单 + 介入条件 + 三层拐点清单（存量） | `reports/era-alpha/{方向}/alpha-watchlist.md` |
| 完整五步研究报告 | `reports/era-alpha/{方向}/full-scan/{方向}-garp-era-alpha-{YYYYMMDD}.md` |
| 月度/季度增量更新 | `reports/era-alpha/{方向}/monthly/{方向}-garp-era-update-{YYYYMM}.md` |

- **三档物理隔离**：GARP 档 `reports/era-alpha/`；1~3 年中期链与 10 年长期链各为单文件、路径命名不同，**三者互不覆盖、互不读取**。
- **四基准必注明**：数据 / 估值 / 资料 / 口径。
- **只读上游、不写回**：`reports/{公司名}/-garp-*` 与 `reports/industry/-garp-industry-` 只读不写回。

## 研究标准

### 与相邻技能的差异化定位

| Skill | 定位 | 何时用 |
|-------|------|--------|
| **`/garp-era-alpha`（本Skill）** | GARP 时代级高增长主线的核心 α 识别 + 景气验证 + 介入/退出纪律 | 锁定 1~5 年高景气主线与核心 α |
| `/garp-industry-research`（P4-9） | 单赛道六维筛选（TAM/渗透率/业绩/国产化率/题材/地缘） | 锁定主线后深扫该赛道 |
| `/garp-industry-funnel`（P4-10） | 单赛道内逐层收敛到 3 底仓 + 2 机动仓 | 偏个股漏斗收敛 |
| `/garp-trend-tech-screen`（P4-11） | 给定标的五维打分 + 地缘修正 + 技术面止损 | 对核心 α 做正向排序打分 |
| `/garp-bottleneck-hunter`（P4-18） | 供应链咽喉位置挖第二、三层机会 | 物理供应链瓶颈机会 |

两者可互补：先用 `garp-era-alpha` 锁定时代主线与核心 α，再用 `garp-industry-research` 深扫该主线赛道、`garp-investment-checklist` 对锁定核心 α 过买入前硬门槛。

### 报告结构（十章节）

1. 一句话结论 + 核心 α 名单概览（含「核心 α 名单非买入指令」声明）
2. 前置闸门：地缘 0.3 矩阵结论（只读）
3. 时代主线认知地图（环节表 + 渗透率档位 + 国产化率梯队 + 核心环节选择理由）
4. 核心问题的回答（收敛闸门三条判定表 + 核心 α + 为什么是它）
5. 景气可持续性验证（五维逐项 + 五大师透镜结论汇总 + 管理层与科研转化（只读）+ 矛盾信号明示）
6. 估值锚点与介入建议（档位只读 garp-valuation 六档 + ESG 折价 + 宏观校准后 PEG 区间 + 二阶导 + 结论三选一 + 介入方式）
7. 持仓与退出纪律（底仓/机动仓只读 + 三层拐点清单 + 五级卖出提示（只读 garp-exit）+ 行动链路）
8. 五大师冲突化解（决策优先级金字塔只读 + 费雪「绝不卖」适用边界 + 暂时性 vs 永久性）
9. 本报告可能错在哪（≥3 条自我证伪）
10. 信息缺口声明 + 四基准

## 质量标准

1. **双源交叉验证**：关键数据至少 2 个独立来源，误差 >1% 须标记；渗透率/国产化率双源误差 >5pct 标低置信
2. **黄金窗收敛**：时代主线须按渗透率 `15%~40%` + TAM ≥1000 亿 + 连续 2 季业绩兑现收敛，不靠叙事
3. **禁心算**：PEG / 复合增速 / 二阶导 / 分位等一切算术经 `financial_rigor.py`，报告须列精确算术工具输出
4. **引用不重复定义**：估值/卖出/地缘/管理层/宏观一律只读 `garp-*` 权威出口，零档位阈值定义
5. **五大师交叉验证**：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔逐位结论，缺位即不合格
6. **`report_audit.py` 抽检准出**：发布前必须通过数据抽检，不通过不得发布
7. **并发硬约束**：同时运行子代理最多 2 个，环节分批串行，搜索请求间隔 ≥ 2 秒

## 核心原则

1. **证伪优先** — 每个核心判断附反面论据，矛盾信号优先采信，不按需取舍
2. **黄金窗收敛** — 时代主线按渗透率 `15%~40%` 黄金窗 + TAM ≥1000 亿 + 连续 2 季业绩兑现收敛
3. **国产化率叠加** — 科技赛道并列标注国产化率四梯队（只读 `garp-geo-policy`）
4. **五大师交叉验证** — 费雪 / 林奇 / 郑希 / 李进 / 欧奈尔逐位结论
5. **引用不重复定义** — 估值/卖出/地缘/管理层/宏观一律只读 `garp-*` 权威出口，禁心算
6. **三档隔离 + 核心 α 名单非买入指令** — GARP 语域与文件路径隔离；输出研究结论与相对动作，不越界下指令

## 注意事项

- 开始研究前运行 `date` 确认当天日期，报告头部注明**四基准**（数据 / 估值 / 资料 / 口径）
- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- 坑口数据须注明来源与年份；渗透率/国产化率双源误差 >5pct 标低置信
- 关键财务数据 ≥2 独立来源交叉验证，误差 >1% 须标记
- 禁 LLM 心算，一切算术经 `financial_rigor.py`
- 核心 α 须逐位通过五大师透镜，缺位即不合格
- 主线须过收敛闸门三条，缺一降级为「观察环节」
- 估值档位与卖出级别只读权威出口，不得自建阈值、不得越界下指令
- 报告发布前须通过 `report_audit.py` 数据抽检
- 并发硬约束：子代理最多 2 个，环节分批串行，搜索间隔 ≥ 2 秒
- 风控编号：`GEA-1`~`GEA-12`

## 局限性说明

- **资料可得性**：新兴方向一手资料较少，分析深度受限
- **未上市公司信息**：估值和财务信息可能不够准确
- **高频数据可得性**：部分环节缺乏周度/月度公开高频数据，交叉验证可能降级为季度数据
- **渗透率 / 国产化率口径不统一**：第三方数据源口径差异较大，双源误差 >5pct 须标低置信
- **非实时数据**：工具获取的数据可能有延迟
- **估值分位历史长度限制**：次新行业 / 公司历史分位参考价值有限
- **AI 筛选偏见**：可能存在成熟行业偏好、龙头偏好、英文偏好
- **不构成投资建议**：本技能仅用于学习与研究
