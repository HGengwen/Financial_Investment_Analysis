# 时代α捕手（GARP 独立档·1~5 年）：时代级高增长主线与核心 α 的识别-验证-持有框架

对 `$ARGUMENTS` 行业/方向执行「GARP 时代α五步法」：**地缘前置闸门 → 时代主线认知地图 → 自问核心问题（收敛闸门）→ 景气可持续性验证（五维 + 五大师）→ 估值锚点与介入 → 持仓与退出纪律**。

**目标**：找出当下 **1~5 年**最核心高景气主线中真正有定价权、有景气壁垒、能持续跑赢同行的核心 α，并给出介入条件与退出纪律。**输出的是「核心 α 名单 + 介入条件 + 退出纪律」，不是「买入指令」。**

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

**支持输入格式**：

- `{行业/方向}` —— 如 `AI算力` / `人形机器人` / `创新药出海`
- `{行业/方向} --scope {范围}` —— 环节范围（默认全环节；可限定某一环节或某一市场）
- `{行业/方向} --depth {fast|standard|deep}` —— 扫描深度（默认 `standard`）
- `{行业/方向} --export --export-path {路径}` / `--json` —— 导出与结构化输出

> **本技能不提供任何档位切换参数**——它即 GARP 独立档（1~5 年）时代α捕手专属入口；档位切换类口令属其他档位口径，出现即违反**三档语域隔离**（`GEA-12`）。

## 五大师提醒

> 💬 **费雪式提醒**：「**需求真实性**先于景气叙事——主线须有订单 / 收入 / 利润客观数据支撑，否则就是题材；同时看**销售组织健康度**与**管理层持股 ≥3%**，并把回撤区分为**暂时性困难**与**永久性衰退**——这决定回撤时是加仓还是离场。」
>
> 💬 **林奇式提醒**：「你买的不是『时代』，是一家具体公司的生意。这门生意**看得懂**吗？属六类中的哪一类？增长来自**真实需求**还是题材炒作？估值锚一律以 `garp-valuation` 统一六档为准。」
>
> 💬 **郑希式提醒**：「时代主线的真实性必须由 **ROE 趋势**验证——坐在最景气的环节上但 ROE 在下降，说明景气未转化为股东回报，那叫**伪 α**。同时看**国产化率处在第几梯队**。」
>
> 💬 **李进式提醒**：「**渗透率落在 `15%~40%` 加速上行期**才是黄金窗口，突破 15% 后加速、进入 40%~60% 逐步兑现、越过 60% 不再新建仓；不仅看产业是否增长，更看增速的**加速度（二阶导）**。」
>
> 💬 **欧奈尔式提醒**：「景气逻辑再完美，若股价已透支未来增长，当前价格也不是介入点。**硬止损是生存红线**（阈值只读 `garp-exit`，本技能不得自建、不得重算）。」

## 方法论来源与本质

本技能结构**继承自 1~3 年中期链时代α捕手技能**（五步法骨架 + 三项修正），**并作 GARP 独立档口径替换**；**「时代α捕手 / 五步法 / 三项修正」为本技能的操作化命名，非《中长期价值成长（GARP）投资框架》原文**（框架分散锚点：第 1 步赛道选择 / 第 3 步五大支柱 / 第 4 步估值多工具矩阵 / 第三部分·三 五级卖出 / 第五部分·二 决策优先级金字塔）。

本质一句话：**把 1~5 年的收益建立在产业景气与企业成长的认知之上，而不是运气或情绪之上。** 三项修正落到 GARP 语境：

1. **修正一（精简范围）**：不覆盖所有行业，聚焦指定主线的 **2~3 个核心环节**做深做透（做减法）。
2. **修正二（高频数据交叉验证）**：财报是三个月前的体检报告，必须用周度/月度出货量、价格、招标、订单、渗透率等高频数据做实时体温计校正。
3. **修正三（估值锚点）**：**以多工具矩阵统一六档为锚点替代「闭眼买」**——档位**只读** `garp-valuation`，合理/低估可介入、偏贵但景气可消化可持有或分批、严重透支只看不买；**保留「用估值锚点替代盲目买入」的方法论内核**。

## 设计原则

1. **地缘前置**：地缘 0.3 三维交叉矩阵为**买入前闸门**，先于主线扫描；回避档直接终止（`GEA-5`）。
2. **黄金窗收敛**：候选环节须通过**渗透率 `15%~40%` + TAM ≥1000 亿 + 连续 2 季业绩兑现**三条闸门（`GEA-2`），不接受纯叙事。
3. **国产化率叠加**：科技赛道须**并列标注**国产化率四梯队档位（只读 `garp-geo-policy`）。
4. **五大师交叉验证**：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔**逐位**给出结论，缺位即不合格（`GEA-11`）。
5. **引用不重建**：估值 / 卖出 / 地缘 / 管理层 / 宏观一律**只读** `garp-*` 权威出口，本技能零档位阈值定义、零重算。
6. **三档隔离**：GARP 独立档语域与文件路径，禁其他档位口令、编号、命令名、路径与长期链术语（`GEA-12`）。
7. **禁心算**：一切算术经 `financial_rigor.py`（`GEA-8`）。

## 能力圈声明

**适用**：处在 GARP 景气黄金窗（渗透率 `15%~40%` + TAM ≥1000 亿）的成长型赛道，尤其是**科技与国产化主题**相关主线；可覆盖 A 股 / 港股 / 美股 / 跨市场。

**不适用**：纯周期股、金融股、困境反转类、未上市标的（建议改用其他框架或技能）；**本技能不替代买入前硬门槛检查**——核心 α 名单确认后须转 `/garp-investment-checklist` 过买入前七关。

> **核心 α 名单非买入指令**：本技能输出的是**研究结论与相对动作**，不含目标仓位、减仓比例、止损价等指令性数值；仓位与组合层裁决归 `/garp-portfolio-review`，卖出级别判定归 `/garp-exit`，估值档位归 `/garp-valuation`。

## 第一步：时代主线认知地图

对目标方向建立「主线-产业链」认知地图，**每个候选环节**回答以下 **7 项**：

1. **渗透率位置**：处于五档中的哪一档？——`<5%` 导入早期（观察不建仓）/ `5%~15%` 突破期（高弹性，小仓跟踪）/ **`15%~40%` 加速上行期（黄金窗口，主建仓）** / `40%~60%` 逐步兑现期（持有，不再新建仓）/ `>60%` 天花板（即便增速未转负也不加仓）；**增速归零或转负即视为见顶**。用渗透率 + 增速的**二阶导**定位。
2. **产业空间与速度**：**TAM 是否 ≥ 1000 亿**？未来 3 年 CAGR 是否具备高增长特征？
3. **商业模式与赚钱方式**：毛利率、费用率、现金流与利润的匹配度。
4. **竞争格局**：CR5、定价权在谁手里、壁垒是技术 / 规模 / 生态 / 牌照。
5. **地缘政治结论（只读）**：**只读** `garp-geo-policy` 的 0.3 三维交叉矩阵结论 + 赛道两分法归属（地缘倒逼型 / 政策资本驱动型 / 回避）+ 敞口体检；**本技能不自评、不定档**（`GEA-5`）。
6. **国产化率位置（科技赛道专用，只读）**：**只读** `garp-geo-policy` 的 `localize` 结论四梯队——`<5%` 过早 / `5%~20%` 突破期 / `20%~50%` 加速投资期 / `>50%` 替代空间收窄；**`>50%` 档位不因此被淘汰**，但须标注「投资逻辑转向龙头份额提升与整机放量，而非继续押注从 0 到 1 的替代弹性」。
7. **核心 α 候选**：营收增速 / ROE 趋势 / 市占率变化三维筛；费雪「销售组织与持股 ≥3%」前置提示。

**信息源要求**：以招股说明书、年报/季报、业绩说明会纪要等一手资料为主，券商观点只做线索不做结论。A 股 / 港股 / 美股 / 未上市候选都要覆盖，不因资料难找而漏掉（`GEA-1`）。

**产出**：环节表（环节 | **渗透率档位** | 阶段 | **国产化率梯队** | 格局 | 地缘结论（只读） | 核心 α 候选 | 一句话理由），并从中选出 **2~3 个**最值得做深的核心环节（修正一）。

## 第二步：自问核心问题（不听别人的）

用第一步数据回答，**禁止引用「市场共识」「机构观点」作为论据**：

1. **当下这条主线最核心、景气最确定的环节是什么？** 用数据说话：渗透率档位、增速、订单能见度、业绩兑现度。
2. **该环节的核心 α 是谁？** 标准：定价权（毛利率高于同行且稳定或提升）、景气壁垒（对手 1~5 年追不上的东西是什么）、增长质量（收入增长伴随现金流增长，不是赊出来的）、**需求真实性（费雪：有订单 / 收入 / 利润支撑）**。
3. **为什么是它而不是老二？** 必须能一句话说清 α 与 β 的差别，说不清就是没看懂。

### 时代主线收敛闸门（`GEA-2`，**三条缺一即降级**）

| # | 闸门 | 判据 | 不通过处置 |
| --- | --- | --- | --- |
| 1 | **渗透率黄金窗** | 渗透率落在 **`15%~40%` 加速上行期** | `<5%` 导入早期（观察不建仓）；`5%~15%` 突破期（小仓跟踪）；`40%~60%` 逐步兑现期（持有，不新建仓）；`>60%` 天花板（不加仓） |
| 2 | **产业空间** | **TAM ≥ 1000 亿** | TAM < 1000 亿 → **黄金窗判定不成立**，须显式标注 |
| 3 | **业绩兑现度** | 连续 **2 个季度**财报验证：营收增速 > 行业平均，毛利率稳定或提升 | 未兑现 → **判题材**（`GEA-1`），不得进入主线候选 |

- **降级规则**：三条**缺一即降级为「观察环节」**，**不得**进入核心 α 验证。
- **国产化率并列标注**：环节须**同时**标注国产化率四梯队档位（只读 `garp-geo-policy` `localize`）；`>50%` 档位不淘汰但须标注逻辑切换。
- **报告显式化**：收敛结果须在报告第四节列出「**三条闸门判定表**」，**不得隐式判定**。
- **数据口径**：渗透率 / 国产化率须注明**来源与年份**；双源误差 > 5pct 标**低置信**。

**产出**：**1~3 家核心 α** + 明确的「为什么是它」论证。

## 第三步：景气可持续性验证（五维 + 五大师 + 管理层只读）

对每家核心 α 做 1~5 年景气可持续性验证，**所有维度必须一致指向「高景气可持续」才算看懂**。

### 3.1 五维验证（财报 + 高频数据交叉，`GEA-3`）

| # | 维度 | 验证内容 |
| --- | --- | --- |
| 1 | **财报** | 最近 4~8 个季度营收/利润增速趋势、毛利率方向、ROE 趋势（是否向上拐点）、合同负债 / 存货 / 在建工程等前瞻科目；**叠加财务五门槛 + 科技股豁免 + 能力圈自检**（框架第 2 步） |
| 2 | **高频数据**（修正二） | 该环节的周度/月度实时指标（出货量、价格、招标、订单、渗透率等），是否与财报趋势一致；**时效性优先** |
| 3 | **行业景气** | 政策方向、技术路线有无被颠覆风险、供给端扩产节奏（供过于求是成长股最大杀手）、**渗透率二阶导**（主锚引用 `qoq-accelerator`） |
| 4 | **竞争格局** | 市占率变化方向、新进入者威胁、客户集中度与议价权 |
| 5 | **地缘/宏观（只读）** | **只读** `garp-geo-policy`（0.3 矩阵 / 敞口体检）+ **只读** `garp-macro`（宏观三表）；**只调参不择时**；**本技能不自评** |

- **刚性**：五维**逐维**给出结论；**任一维度出现矛盾信号必须显式写出**，不得含糊带过；任一维度矛盾 → **降级结论**。
- **财务五门槛口径**：门槛项与科技股豁免条款**只读**框架第 2 步，本技能不重定义。

### 3.2 五大师验证透镜（`GEA-11`）

在五维验证之上，用五位大师的追问对 α 做二次验证，**逐位给出「追问 → 结论」**：

| 大师 | 验证透镜 | 核心追问 | 冲突处置 |
| --- | --- | --- | --- |
| **费雪** | **需求真实性与持续性** | 需求是否有订单 / 收入 / 利润支撑？销售组织是否健康？管理层持股是否 ≥3%？当前困难是**暂时性**还是**永久性衰退**？ | 与景气维度冲突 → 优先采信冲突信号 |
| 林奇 | 常识与求证 | 这门生意「看得懂」吗？属六类中的哪一类？增长来自真实需求而非题材炒作？ | 同上 |
| 郑希 | 产业景气与第一性原理 | 产业正处在 ROE 曲线的什么位置？有无 ROE 向上拐点？全球产业链中哪个环节率先景气？ | 同上 |
| 李进 | 渗透率坐标与系统均衡 | 渗透率处于 `15%~40%` 五档的哪一档？二阶导是加速还是减速？治理是否有硬伤？ | 同上 |
| 欧奈尔 | 信号与风控底线 | 技术面趋势是否确认？突破买点 / 抛售日信号如何？硬止损底线在哪（只读 `garp-exit`）？ | 同上 |

- **刚性**：① 五位大师**逐位**给出结论，**缺位即不合格**；② 与五维验证**冲突时优先采信冲突信号**并在报告显式写出，**不得按需取舍**；③ 报告第五节须有「**五大师透镜结论汇总**」段。
- **费雪视角落位四处**：认知地图需求真实性 / 自问核心问题「为什么是它」/ 景气验证暂时性 vs 永久性 / 回撤应对加仓 vs 离场。

### 3.3 管理层与科研转化评估（**只读，引用不重做**，`GEA-6`）

- **管理层 20 分制**（**诚信前置闸门 + 对待股东 7 + 战略执行 7 + 稳定性激励 6**，≥15 分方可重仓）——口径**只读** `garp-management`（P4-4）；本技能**只读取回结论、不逐项重算**。
- **科研转化 20 分制**（研发投入 8 + 研发产出 8 + 资本回报 4，≥15 分可重仓）——口径**只读** `garp-management`；在研项目可用 `in_research_scan.py scan` 扫描、年报字段可用 `annual_report_parser.py` 抽取，**评分仍归 `garp-management`**。
- **费雪补充**（销售组织 + 管理层持股 ≥3% + 暂时性困难 vs 永久性衰退）**只读** `garp-management`。
- **一票否决**：诚信闸门命中（财务造假实锤 / 监管立案 / 兑现率 <50% / 业绩预告失真）→ **一票否决**，直接转 `garp-exit` 一级，**禁止自行计分替代**。

## 第四步：估值锚点与介入（修正三）

1. **档位只读**：当前档位**只读** `garp-valuation`（P4-5）**多工具矩阵 + 统一六档**（调整后 PEG / PSG / EV-Sales / Rule of 40 / 远期 PE + 隐含 PEG / DCF）+ **ESG 折价** + **宏观校准后 PEG 区间**；**本技能零档位阈值定义、零档位重算**（`GEA-4`）。
2. **增速与估值匹配**：引用 `qoq-accelerator` 连续 3 季二阶导，区分「单季波动」与「趋势性拐点」。
3. **结论三选一**（依据一律为六档结论）：**低估 / 合理可介入** · **偏贵但景气可消化可持有或分批** · **严重透支只看不买**；**档位越过透支线 → 不进入核心 α 名单**。
4. **介入方式三选一或组合**（不含具体仓位百分比）：
   - **分批建仓**：进入合理区间先建底仓 → 回调至区间下沿加仓 → 景气加速 / 财报超预期补齐；
   - **左侧布局**：杀估值不杀逻辑，逆向分批；
   - **右侧重仓**：渗透率突破 15% 临界点 + 连续 2 季加速 + 行业景气明确（**止损线只读** `garp-exit`）。
5. **宏观只调参不择时**：**只读** `garp-macro`（P4-2）宏观三表（利率 / 经济 / 美林），仅用于**调整 PEG 区间与仓位节奏参数**；**禁止**以宏观结论作为清仓 / 择时理由。
6. **精确算术**：PEG / 复合增速 / 二阶导 / 分位等一切算术经 `financial_rigor.py`（`GEA-8`），报告须列「精确算术工具输出」（命令 + 输入 + 输出）。

> **禁用工具**：**十年尺度终值折现（DCF）类估值工具**（长期链口径，`GEA-12`）；如需 DCF 走 `garp-valuation` 转接。

## 执行方式

1. **并发硬约束（必须先读，防止触发服务端 request burst 保护）**：
   - 同时运行的子代理**最多 2 个**，严禁「按产业链环节一次性并行铺开所有 Agent」。
   - 产业链环节按优先级排序后**分批串行**处理：每批最多 2 个环节，一批全部返回后再启动下一批。
   - 单个子代理内的搜索请求须**串行逐条执行**，两次请求间隔 ≥ 2 秒；单个环节搜索请求上限 8 次。
   - 遇到 `request burst` / `rate limit` / `System protection` 报错时，立即停止新增请求，按指数退避（30s → 60s → 120s）重试，最多 3 次；仍失败则降级为只用已获取数据，标注「信息不足」。
2. 每个环节派出的研究 Agent，要求联网获取最新财报与高频数据，返回**结构化事实（数据 + 出处）**，不返回观点。
3. 主线程按前置 A/B 与第一到第五步综合成报告；单个环节子代理超时（> 15 分钟无返回）即放弃该环节，用已有数据标注「信息不足」继续推进，不阻塞整体。
4. 关键数字（增速、毛利率、渗透率、档位）必须标注数据截至日期；一切算术经 `financial_rigor.py`。

## 核心原则

1. **证伪优先** — 每个核心判断附反面论据，矛盾信号优先采信，不按需取舍
2. **黄金窗收敛** — 时代主线须按渗透率 `15%~40%` 黄金窗 + TAM ≥1000 亿 + 连续 2 季业绩兑现**收敛**，不靠叙事
