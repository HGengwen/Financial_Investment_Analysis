# 公司新闻脉搏（景气投资版·1-3年）：股价异动快速归因 + P0~P5 卖出纪律触发检查

对 $ARGUMENTS 进行最近新闻侦察与股价异动归因。**这不是深度投研，是情报快速响应与风控触发检查**——目标是 10-15 分钟内回答："这家公司最近发生了什么？股价异动的真因是什么？**是否触发了 P0~P5 卖出纪律？是否动摇了 H1~H6 景气逻辑？**"

本技能属**中期链（1-3 年）**，与长期链 `news-pulse`（10 年 / 护城河永续）**物理隔离、功能互补**。禁止使用「护城河永续」「终局思维」「持有10年」等长期框架术语。

> 💬 **欧奈尔式提醒**："股价异动可能是噪音，也可能是信号。关键是判断：这个异动是否改变了景气逻辑？是否触及了卖出底线？"

> 💬 **郑希式提醒**："ROE 向上是科技股最可靠的'重力加速度'——只要这个趋势在，估值波动只是噪音；但它一旦拐头，异动就可能是拐点的第一声警报。"

---

## 设计理念

当持仓或关注的公司股价出现异动时，投资者需要快速判断四个问题：

1. **是什么**：最近发生了什么事件？
2. **为什么**：哪个事件导致了股价异动？
3. **是否触发卖出纪律**：是否触发了 P0~P5 六级卖出触发条件？
4. **是否动摇景气逻辑**：事件对 H1~H6 六大景气假设（渗透率/订单·合同负债/ROE 趋势/毛利率/增速加速度·二阶导/地缘政治）的影响是什么？
5. **宏观与地缘背景**：是否存在国际地缘政治事件，或美联储/美财政部/美经济数据等官方重磅消息，放大了本次股价波动？

在 1~3 年景气投资框架中，**股价异动后的快速归因**是风控体系的关键环节——不是每次下跌都要卖，但每次异动都必须快速检查是否触及 P0~P5 卖出触发条件、是否动摇景气逻辑。

本 Skill 通过 4 个并行 Agent 快速侦察，产出归因判断和**卖出纪律触发初筛 + 景气影响评估**，帮助投资者在 10-15 分钟内做出初步决策。深度检查交棒给后置联动技能（`exit-signal` / `mid-thesis-drift` / `valuation-thermometer` 等），本技能不重复建设。

---

## 适用场景

- 持仓/关注股票股价大涨/大跌（一般触发线：单日 ±5%、一周 ±10%）
- 财报后股价异动，想快速搞清市场在反应什么
- 看到新闻标题，但不确定是噪音还是真信号
- **不适用**：完整投研（用 `/mid-investment-research` 或 `/mid-investment-team`）、财报深读（用 `/mid-earnings-review` 或 `/mid-earnings-team`）、景气逻辑漂移验证（用 `/mid-thesis-drift`）、卖出纪律完整检查（用 `/exit-signal`）

## 执行流程（六步）

### 第一步：确认参数与场景

向用户澄清以下信息（如未在 $ARGUMENTS 中提供）：

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| **公司名** | 中文/英文/股票代码均可 | 必填 |
| **时间窗口** | 侦察新闻的回溯天数 | 默认 14 天，财报季可缩到 7 天 |
| **股价异动** | 涨/跌幅度 + 时间，如"跌 12%/3 天" | 选填，有则用于聚焦归因 |
| **关注侧重** | 公司事件/监管/行业/情绪 | 默认四方平均 |

如果用户只说了公司名，先反问："最近多少天的新闻？有具体的股价异动要解释吗？"——**不要默默假设**。

开始前运行 `date` 确认当天日期，作为报告「数据截止日期」基准。

**交易日实时行情（强制）**：确认日期后，立即按上市地点调用对应行情工具，拉取标的**最新实时交易价格**作为本次股价波动溯源的**价格锚点**（涨跌幅、回撤、均线偏离均基于它计算，禁止用训练记忆或估算的旧价替代）：

| 市场 | 实时/最新价格命令 | 说明 |
| --- | --- | --- |
| A股 | `python tools/a_share/stock_quote.py --realtime {代码}` | 新浪全市场快照，返回当日实时「最新价 / 涨跌幅」 |
| 港股 | `python tools/hk_stock/stock_quote.py --realtime {代码}` | 新浪全市场快照，返回当日实时「最新价 / 涨跌幅 / 成交额」 |
| 美股 | `python tools/us_stock/stock_quote.py --realtime {代码}` | yfinance 优先，失败回退新浪单只接口（延迟约 15 分钟，非实时盘口） |

**交易日判定**：比对行情工具返回的最新一条行情日期与今日是否一致——一致为**交易日**（盘中用实时最新价，收盘后用当日收盘价）；不一致为**休市日**（周末/节假日），采用最近交易日收盘价为基准，并在报告中如实标注「最近交易日 {日期}」。

---

### 第二步：信息可得性分级

| 等级 | 特征 | 侦察策略 |
| --- | --- | --- |
| **A 级（信息充裕）** | 大盘股、媒体覆盖广、财报季 | 重点是**降噪和归因**——信息太多反而难找真因，每个 Agent 要有判断力，过滤掉"重复转述"的二手新闻 |
| **B 级（信息适中）** | 中小盘、覆盖一般 | 标准模式，每条关键事件附 1-2 个独立信源 |
| **C 级（信息稀缺）** | 港股小票、新上市、冷门 | 转入"扫盲模式"——可能找不到任何能解释异动的新闻，**这个结论本身就有价值**（可能是技术性/资金面而非基本面） |

将评级告知每个 Agent，影响其侦察方式。

---

### 第三步：启动 5 个并行侦察 Agent

使用 Task 工具在**同一条消息**中启动 5 个后台 Agent（`subagent_type: search`）。每个 Agent 独立搜索、不可共享结果。

---

#### Agent 1：公司事件侦察（company-event-scout）

**核心问题：公司本体最近发生了什么？对景气逻辑有何影响？**

侦察内容：

1. **官方公告**：港交所/SEC/巨潮等监管披露平台最近披露
2. **财报与业绩指引**：最新季报/年报、业绩预告、业绩会要点——**重点判断对 ROE 趋势、营收增速二阶导的影响**
3. **管理层动作**：高管变动、增减持、回购、分红、股权激励
4. **重大业务事件**：新产品发布、并购重组、业务剥离、大客户/大订单
5. **资本运作**：再融资、可转债、ADR 转换、回 A/退市动议
6. **诉讼与合规**：被起诉、自行披露的合规事件

**景气视角特别关注（对应郑希 + 李进）**：
- 事件是否影响 **ROE 趋势**（↑向上 / →持平 / ↓向下）？
- 事件是否影响 **营收增速二阶导**（加速 / 持平 / 减速）？
- 事件是否影响 **订单/合同负债**（↑增长 / →持平 / ↓下降）？

输出要求：
- 每条事件标注：**日期 / 来源链接 / 一句话摘要 / 对景气逻辑的影响（↑强化 / →中性 / ↓削弱）**
- 按时间倒序的时间线表格

---

#### Agent 2：监管与政策侦察（regulatory-watcher）

**核心问题：行业监管和政策最近有什么变化？地缘政治是否影响 H6？**

侦察内容：

1. **行业监管**：所在行业的新规、罚款、整改、牌照变化
2. **跨境政策**：中美关系（中概股）、关税、出口管制、数据安全
3. **税收政策**：增值税、企业所得税、个税相关变化
4. **反垄断与竞争法**：调查、罚款、并购否决
5. **特殊行业政策**：医药集采、教育双减、地产三道红线、互联网平台规制等
6. **货币与外汇**：影响该公司的汇率/利率/资本管制变化。判断外汇因素影响时，可用 `python tools/common/fx_rate.py --code USDCNY`（或 `HKDCNY`/`USDHKD`）获取实时汇率，辅助归因汇率波动对该公司利润/市值的影响

**景气视角特别关注（对应郑希·地缘六维）**：
- 是否有"**政策黑天鹅**"刚刚落地？
- 地缘政治风险（关税/制裁/供应链）是否升级，直接影响 **H6 地缘政治假设**？

输出要求：
- 每条政策标注：**日期 / 来源 / 直接影响该公司的程度（直接/间接/无关）**
- 重点判断对 **H6 地缘政治假设**的影响（升级 / 持平 / 降级）

---

#### Agent 3：行业与竞争对手侦察（industry-peer-analyst）

**核心问题：是公司个体事件，还是整个行业的 beta 波动？**

侦察内容：

1. **直接对手**：列出 3-5 个核心竞争对手，逐个查最近事件（财报、产品、价格战、人事）
2. **产业链上下游**：上游原材料/供应商、下游客户/渠道，最近的价格、产能、订单变化
3. **行业整体**：行业景气度数据、出货量、需求侧信号（消费数据、招标数据等）
4. **替代品威胁**：新技术、新业态对该行业的冲击
5. **行业指数表现**：同行业股票最近表现，该公司是跑赢/跑输/同步

**景气视角特别关注（对应郑希 + 李进）**：
- 同行 **ROE 趋势**：上行/下行/分化？
- 行业**渗透率节奏**（如可获取）：加速/平稳/减速？
- 行业**供需格局**变化：收紧/宽松/不变？

输出要求：
- 关键判断：**这是公司个体事件，还是整个行业的 beta 波动？**
- 每条事件标注来源和日期

---

#### Agent 4：市场情绪与机构观点侦察（sentiment-tracker）

**核心问题：是基本面驱动还是情绪/资金面驱动？估值是否透支？**

侦察内容：

1. **卖方评级变动**：高盛、摩根、中金等最近的评级/目标价调整
2. **机构持仓变化**：13F 披露（美股）、港股通持仓、北上资金流向
3. **做空数据**：做空比例、新发布的做空报告（如有）
4. **大 V 观点**：段永平等大 V 最近相关发言（如该公司是其关注标的）
5. **传言与小作文**：媒体未证实的传言、社交媒体讨论热点（雪球/X/Reddit）
6. **技术面信号**：是否触及关键支撑/阻力、是否有大宗交易、融资融券异常

**景气视角特别关注（对应欧奈尔 + 林奇）**：
- 估值是否进入**透支区间**（联动 PEG 五档线索，权威判定转 `valuation-thermometer`）？
- 是否出现**技术面破位**信号（MA200 破位、放量下跌等，权威判定转 `trend-momentum-scan`）？

输出要求：
- 关键判断：**是基本面驱动还是情绪/资金面驱动？**
- 每条事件标注来源和日期

---

#### Agent 5：宏观金融与地缘政治侦察（geo-macro-scout）

**核心问题：国际地缘政治，以及金融、经济方面（特别是美国官方）最近有什么重大消息？对市场整体风险偏好、利率与汇率、H6 地缘假设有何影响？**

侦察内容（官方原文优先，二手转述须标注来源层级）：

1. **美联储（Fed）**：FOMC 利率决议与点阵图、鲍威尔讲话、缩表/流动性操作、官员公开表态
2. **美国财政部（Treasury）**：美债拍卖与收益率异动、财政赤字/债务上限、**制裁/出口管制等行政令（直接关系中概股与供应链）**
3. **美国官方经济数据**：CPI/PPI、非农与失业率、零售销售、ISM PMI、GDP、初请失业金——判断利率路径与衰退风险
4. **美国监管机构**：SEC/CFTC 市场监管新规与执法、中概审计监管（PCAOB）、上市/退市相关
5. **美国国会/白宫**：财政与贸易法案、关税政策、对华科技/产业政策立法
6. **国际地缘**：俄乌、中东、台海、朝鲜半岛、中美/中欧/中日关系、供应链关键节点（航运、资源国）局势
7. **主要经济体官方**：欧央行/日央行决议、中国央行与财政部的宏观政策、汇率干预信号

**景气视角特别关注（对应郑希·地缘六维 + 欧奈尔·大盘风控）**：
- 利率/流动性是否转向（影响成长股估值分母）？
- 汇率/关税是否影响该公司利润与出口竞争力（可用 `python tools/common/fx_rate.py --code USDCNY` 或 `HKDCNY`/`USDHKD` 佐证）？
- 国际地缘风险是否升级，直接影响 **H6 地缘政治假设**？
- 区分"宏观系统性"与"个股基本面"：宏观利空 vs 公司利空不能混为一谈

**搜索选型（美国官方/宏观）**：美股与美官方消息用 `exa_search.py --type deep` 直击原文（FOMC 声明、财政部公告、SEC 文件）主 + `doubao_search.py` 辅；国际地缘用 `doubao_search.py` 主 + `tavily_search.py` 辅；重大宏观数据可用 `python tools/common/commodity_price.py --code GC,CL`（黄金/原油等避险指标）辅助判断市场情绪。

输出要求：
- 关键判断：**是否有足以解释/放大股价异动的宏观或地缘事件？是"宏观系统性"还是"个股基本面"？**
- 每条事件标注：**日期 / 来源（官方原文优先）/ 对该公司影响（直接/间接/无关）/ 对 H6 地缘假设的影响（升级/持平/降级）**

### 第五步：Team Lead 综合归因 + 卖出纪律触发初筛 + 景气影响评估

全部 5 份侦察报告到齐后，Team Lead 综合产出**异动归因与景气逻辑评估报告**（不是研究报告，重点是"判断"）。归因要点：
- 5 个 Agent 分别从公司/监管/行业/情绪/宏观地缘五个维度侦察，**先分层再做减法**：宏观系统性事件（利率、汇率、地缘、衰退风险）与个股基本面事件要分开归因，避免把大盘拖累误判为公司基本面恶化。
- **归因优先于罗列**——发现事件不难，难的是判断"哪个事件配得上这次股价异动"。要做减法，不要做加法。
- **区分"催化剂"和"巧合"**——同一时间发生的事件不一定是异动主因，要看影响量级是否匹配。
- **诚实面对"不明"**——找不到主因时明确写"真因不明"，比硬凑因果链更有价值。

## 一、一句话归因 + 景气结论 + 卖出纪律警示

> 30-60 字：股价异动的主因 + 次因 + 性质判断 + 是否疑似触发 P0~P5 / 是否动摇景气逻辑

## 二、完整事件时间线（合并 5 维度）

按日期倒序，合并所有维度的事件：

| 日期 | 维度 | 事件 | 来源 | 景气影响 | 异动权重 |
| --- | --- | --- | --- | --- | --- |

权重图例：🔴 高（足以单独解释异动）/ 🟡 中（贡献一部分）/ ⚪ 低（背景噪音）

## 三、异动归因表

| 候选解释 | 证据 | 反证 | 置信度 | 对景气逻辑的影响 |

## 注意事项

1. **快胜过全**——核心价值是 10-15 分钟内给出归因判断，不陷入深度分析（那是 `exit-signal` / `mid-thesis-drift` / `mid-earnings-team` 的职责）
2. **归因优先于罗列**——做减法，不做加法，判断"哪个事件配得上这次股价异动"
3. **诚实面对"不明"**——找不到主因时明确写"真因不明"，比硬凑因果链更有价值（市场可能在抢跑）
4. **不预设立场**——不要因为持仓就倾向于"这是情绪波动，没事"，证据指向哪边就写哪边
5. **区分"催化剂"和"巧合"**——同时间发生的事件不一定是异动主因，看影响量级是否匹配
6. **尊重信息可得性**——C 级公司可能查不到新闻，这个结论本身就要写出来
7. **P0~P5 触发初筛必须完成**——这是本技能的核心输出，命中 P0/P1 须提示立即转 `exit-signal`
8. **景气影响判断必须完成**——每个事件都要评估对 ROE/二阶导/渗透率/订单/毛利率/地缘的影响
9. **不替用户做决策**——给出归因和行动建议清单，但买卖决策由用户做
10. **中期术语红线**——禁止出现「护城河永续」「终局思维」「持有10年」等长期框架术语；卖出纪律统一 P0~P5，时间止损归 P2，无 P6 层级
11. **交易日必须实时取价**——若当日为交易日，必须通过行情工具获取标的当日最新实时交易价格作为归因锚点，禁止用旧价或估算价替代；价格须标注「数据获取时间 / 截至时刻」，休市日须如实标注「最近交易日 {日期}」

## 局限性

1. **信息可得性**：港股小票、新上市公司可能无法获取到有效信息
2. **时效性限制**：网络搜索结果可能有延迟，无法获取最新实时信息
3. **归因不确定性**：股价异动可能由多个因素叠加，难以精确归因
4. **内幕信息**：无法获取未公开披露的信息，可能导致归因错误
5. **情绪量化困难**：市场情绪难以精确量化，判断可能主观
6. **景气数据滞后**：ROE/二阶导/毛利率等景气指标依赖最新财报，非财报季可能数据滞后
7. **渗透率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算，按 A/B/C 三级置信度标注
8. **非实时数据**：工具获取的数据可能有延迟，不是实时数据
9. **宏观/官方信息时效与可得性**：美联储/美财政部等官方重大消息（尤其政策窗口期 FOMC、非农、关税行政令）披露瞬时性强，快速归因时可能尚未被搜索收录或为二手转述，须以 `exa_search.py` 直击原文并标注来源层级
10. **宏观归因不确定性**：宏观系统性事件与个股基本面的传导路径复杂（利率/汇率/情绪），难以精确量化各自贡献度，"先分层再做减法"仅能给出方向性判断
11. **不构成投资建议**：本技能仅用于情报快速响应，不构成任何投资建议
