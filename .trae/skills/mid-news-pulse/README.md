# 公司新闻脉搏（景气投资版·1-3年）(Mid-News Pulse)

股价异动时快速归因：10-15 分钟内回答"发生了什么？真因是什么？是否触发 P0~P5 卖出纪律？是否动摇 H1~H6 景气逻辑？"

> 本技能属**中期链（1-3 年）**，与长期链 `news-pulse`（10 年 / 护城河永续）**物理隔离、功能互补**。核心理念：**异动是信号不是噪音——先快速归因，再判断是否触发卖出纪律、是否动摇景气逻辑**。禁止使用「护城河永续」「终局思维」「持有10年」等长期框架术语。

---

## 快速开始

### 基本调用方式

```
/mid-news-pulse {公司名} [可选：股价异动描述]
```

例如：
- `/mid-news-pulse 拼多多 股价跌15%/一周`
- `/mid-news-pulse 腾讯`
- `/mid-news-pulse 新易盛 股价涨8%/3天`

---

## 核心功能

对指定公司进行最近新闻侦察与股价异动快速归因。**这不是深度投研，是情报快速响应 + 风控触发检查**——通过 5 个并行 Agent 快速侦察（含宏观金融与地缘政治维度，重点美国官方消息），产出归因判断、P0~P5 卖出纪律触发初筛、H1~H6 景气影响评估。

### 适用场景

- 持仓/关注股票股价大涨/大跌（一般触发线：单日 ±5%、一周 ±10%）
- 财报后股价异动，想快速搞清市场在反应什么
- 看到新闻标题，但不确定是噪音还是真信号

### 五 Agent 并行侦察

| Agent | 核心问题 | 景气视角特别关注 | 对应大师 |
| --- | --- | --- | --- |
| company-event-scout（公司事件侦察） | 公司本体最近发生了什么？ | ROE 趋势 / 营收增速二阶导 / 订单·合同负债 | 郑希 + 李进 |
| regulatory-watcher（监管政策侦察） | 行业监管和政策最近有什么变化？ | 政策黑天鹅 / 地缘政治对 H6 的影响 | 郑希 |
| industry-peer-analyst（行业对手侦察） | 是公司个体事件，还是行业 beta 波动？ | 同行 ROE / 行业渗透率节奏 / 供需格局 | 郑希 + 李进 |
| sentiment-tracker（市场情绪侦察） | 是基本面驱动还是情绪/资金面驱动？ | 估值透支（联动 PEG 五档）/ 技术面破位 | 欧奈尔 + 林奇 |
| geo-macro-scout（宏观金融与地缘政治侦察） | 国际地缘 + 金融/经济（重点美国官方）最近有什么重大消息？ | 利率/流动性 / 汇率/关税 / 国际地缘对 H6 的影响 | 郑希 + 欧奈尔 |

### 六步执行流程

1. **确认参数与场景** — 公司名 + 时间窗口 + 股价异动 + 关注侧重
2. **信息可得性分级** — A/B/C 级评级，影响各 Agent 侦察方式
3. **启动 5 个并行侦察 Agent** — 同一条消息中调用 5 次 Task 工具
4. **实时跟踪进度** — 每收到一份报告更新进度 + 3 条核心发现
5. **Team Lead 综合归因 + 卖出纪律触发初筛 + 景气影响评估**
6. **保存报告** — 写入 `reports/{公司名}/{公司名}-mid-news-{YYYYMMDD}.md`

## 输出报告

报告将保存在以下位置：

| 报告类型 | 文件路径 |
| --- | --- |
| 异动归因与景气评估报告 | `reports/{公司名}/{公司名}-mid-news-{YYYYMMDD}.md` |

> 与长期链 `reports/{公司名}/{公司名}-news-{YYYYMMDD}.md` **物理隔离**，避免混淆。如果 `reports/{公司名}/` 目录不存在则创建。

### 归因报告结构（十一节）

```
一、一句话归因 + 景气结论 + 卖出纪律警示
二、完整事件时间线（合并 5 维度，含景气影响 + 异动权重）
三、异动归因表（候选解释/证据/反证/置信度/对景气逻辑的影响）
四、宏观金融与地缘政治归因表（Geo-macro Attribution，官方来源原文优先）
五、景气逻辑影响评估（H1~H6 轻量六维，对齐 mid-thesis-drift）
六、卖出纪律触发初筛（引用 exit-signal P0~P5，不重复定义）
七、性质判断（价值事件/情绪技术波动/宏观地缘系统性/真因不明/混合）
八、各维度侦察摘要（每维度 3-5 条）
九、行动建议（转 exit-signal / mid-thesis-drift / valuation-thermometer 等）
十、接下来 7-30 天景气跟踪清单
十一、信息缺口声明
```

### 性质判断五类结论

- ✅ **价值事件**：景气逻辑发生真实变化（ROE 拐头/二阶导转负/渗透率减速/订单下滑），需重审卖出纪律
- ⚡ **情绪/技术波动**：景气逻辑未变，是资金面/情绪/Beta 驱动，可视为机会或噪音
- 🌐 **宏观/地缘系统性**：无直接个股基本面变化，但受利率/汇率/制裁/地缘等宏观因子拖累或助推（联动第四节归因表），需跟踪后续政策与数据
- ❓ **真因不明**：找不到能匹配股价异动幅度的事件——**这是最危险的结论**
- 🔀 **混合**：部分价值事件 + 部分情绪放大

## 归因标准

### 异动归因权重

| 权重 | 含义 |
| --- | --- |
| 🔴 高 | 足以单独解释异动 |
| 🟡 中 | 贡献一部分 |
| ⚪ 低 | 背景噪音 |

### 信息可得性分级

| 等级 | 特征 | 侦察策略 |
| --- | --- | --- |
| **A级（信息充裕）** | 大盘股、媒体覆盖广、财报季 | 重点是降噪和归因，过滤重复转述的二手新闻 |
| **B级（信息适中）** | 中小盘、覆盖一般 | 标准模式，每条关键事件附 1-2 个独立信源 |
| **C级（信息稀缺）** | 港股小票、新上市、冷门 | 转入"扫盲模式"，找不到新闻本身就有价值 |

### Team Lead 归因要点

- **先分层再做减法** — 宏观系统性事件（利率/汇率/关税/地缘/衰退风险）与个股基本面事件分开归因，避免把大盘拖累误判为公司基本面恶化
- **归因优先于罗列** — 发现事件不难，难的是判断"哪个事件配得上这次股价异动"。要做减法，不要做加法
- **区分"催化剂"和"巧合"** — 同一时间发生的事件不一定是异动主因，要看影响量级是否匹配
- **诚实面对"不明"** — 找不到主因时，明确写"真因不明"，比硬凑因果链更有价值

## 核心原则

1. **快胜过全** — 核心价值是 10-15 分钟内给出归因判断，不陷入深度分析
2. **归因优先于罗列** — 做减法不做加法，判断哪个事件配得上这次股价异动
3. **诚实面对"不明"** — 找不到主因时明确写"真因不明"，比硬凑因果链更有价值
4. **不预设立场** — 不要因为持仓就倾向于"这是情绪波动，没事"
5. **区分"催化剂"和"巧合"** — 同时间发生的事件不一定是异动主因，看影响量级
6. **尊重信息可得性** — C 级公司可能查不到新闻，这个结论本身就要写出来
7. **引用不重复定义** — 卖出引用 `exit-signal` P0~P5，景气引用 `mid-thesis-drift` H1~H6，估值引用 `valuation-thermometer`
8. **不替用户做决策** — 给出归因和行动建议清单，但买卖决策由用户做

## 注意事项

- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- 5 个 Agent 必须在同一条消息中并行启动
- 如果用户只说公司名，先反问时间窗口和股价异动，**不要默默假设**
- 资料评级（A/B/C 级）需告知每个 Agent，影响其侦察方式
- 所有判断必须附数据来源，区分事实与观点
- P0~P5 触发初筛必须完成；命中 P0/P1 须提示立即转 `exit-signal`
- 卖出纪律统一 P0~P5，时间止损归 P2，无 P6 层级
- 宏观与个股须分层归因，禁止将宏观系统性回撤误归因于公司基本面
- 报告需包含"信息缺口声明"，诚实列出未能解决的疑点
- 不适合用本 Skill 的场景：完整投研（用 `/mid-investment-research`）、财报深读（用 `/mid-earnings-review`）、景气漂移验证（用 `/mid-thesis-drift`）、卖出完整检查（用 `/exit-signal`）
- 网络搜索须使用 `--time-range month/week` 限制时间范围，优先获取最新信息
- 港股/美股公司须按市场双源验证（港股 doubao+tavily；美股 exa+doubao），确保信息准确性

## 局限性说明

- **信息可得性**：港股小票、新上市公司可能无法获取到有效信息
- **时效性限制**：网络搜索结果可能有延迟，无法获取最新实时信息
- **归因不确定性**：股价异动可能由多个因素叠加，难以精确归因
- **内幕信息**：无法获取未公开披露的信息，可能导致归因错误
- **宏观/官方信息时效**：美联储/美财政部等重大消息披露瞬时性强，快速归因时可能尚未被收录或为二手转述，须以 `exa_search.py` 直击原文并标注来源层级
- **宏观归因不确定性**：宏观系统性事件与个股基本面的传导路径复杂，难以精确量化各自贡献度，分层归因仅能给出方向性判断
- **情绪量化困难**：市场情绪难以精确量化，判断可能主观
- **景气数据滞后**：ROE/二阶导/毛利率依赖最新财报，非财报季可能数据滞后
- **渗透率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算
- **非实时数据**：工具获取的数据可能有延迟，不是实时数据
- 不构成投资建议，仅供情报快速响应参考
