# 未上市公司研究（景气投资版·1-3年）(Mid-Private-Company Research)

对未上市公司进行团队化深度研究，判断"如果这家公司上市，是否符合 1~3 年景气投资（GARP）框架、值得持有吗"。

> 本技能属**中期链（1-3 年）**，与长期链 `private-company-research`（10 年 / 护城河永续）**物理隔离、功能互补**。核心理念：**上市前的"预研建档"——为上市后的 1~3 年景气投资提前建立标的池与判断框架**，而非研究"现在是否买入未上市股权"。禁止使用「护城河永续」「终局思维」「持有10年」「论文已破」等长期框架术语；壁垒表述统一为「1~3 年景气竞争力」。

---

## 快速开始

### 基本调用方式

```
/mid-private-company-research {公司名}
```

例如：
- `/mid-private-company-research 蚂蚁集团`
- `/mid-private-company-research 小红书`
- `/mid-private-company-research SpaceX`
- `/mid-private-company-research 某Pre-IPO公司`

### 核心问题

不是"现在值多少钱"，而是"**上市后值得持有吗**"。最终输出：林奇六类分类 + PEG 潜力推演 + 渗透率位置 + ROE 趋势 + 管理层·科研·地缘评估 + **是否值得等待上市**（✅/⚠️/❌/❓）。

---

## 核心功能

对指定未上市公司进行 6 个并行 Agent 深度研究，通过多源拼凑、交叉验证与置信度标注，产出 GARP 适配性预判。

### 适用场景

- 研究**未上市公司**（Pre-IPO / 独角兽 / 一级市场标的），判断其上市后是否可能成为 1~3 年景气 GARP 标的
- 已知某公司即将 IPO，想提前建立判断框架，上市后第一时间可跟踪
- 为 1~3 年景气投资建立的**未上市标的池预研建档**

### 不适用场景

- **已上市公司**（有公开财报与股价）→ 转 `/mid-investment-research`（单 Agent）或 `/mid-investment-team`（四 Agent）
- **现在是否买入未上市股权/一级基金份额** → 本技能不回答一级定价是否值得，只回答上市后是否符合 GARP 框架
- **长期（10 年）未上市公司研究** → 转长期链 `/private-company-research`

### 六 Agent 并行研究

| Agent | 核心任务 | 对应大师 |
| --- | --- | --- |
| business-decoder（商业模式解码） | 商业模式深度拆解 + 林奇六类分类（必答） | 林奇 |
| financial-detective（财务侦探） | 财务拼凑 + ROE 趋势推断 + PEG 潜力推演 | 郑希 + 林奇 |
| competitive-mapper（竞争图谱） | 行业景气位置 + 渗透率五区间 + 竞争格局 | 郑希 + 李进 |
| risk-governance-analyst（风险治理） | 管理层四维评估 + 科研转化 + 地缘政治六维 | 李进 + 欧奈尔 |
| tech-ip-analyst（技术IP） | 技术壁垒 + 专利布局 + 科研转化效率 | 李进 |
| signal-miner（信号挖掘） | 替代数据信号 + 上市时机验证 | 欧奈尔 |

### 七步执行流程

1. **确认参数** — 公司名 + 拟上市市场 + 融资阶段 + 研究侧重（信息不足**先反问，不默默假设**）
2. **信息可得性分级** — A/B/C 级评级，影响各 Agent 搜索策略与置信度标注
3. **启动 6 个并行 Agent** — 同一条消息中调用 6 次 Task 工具
4. **实时跟踪进度** — 每收到一份报告更新进度 + 核心要点
5. **Team Lead 交叉验证与信息拼图** — 数据冲突仲裁 + 信号一致性检验 + 反偏见检查
6. **汇总最终报告** — 按 16 节结构输出，核心是 GARP 适配性总览 + 是否值得等待上市
7. **保存报告与审核** — 写入 `reports/{公司名}/{公司名}-mid-private-{YYYYMMDD}.md`，运行 `report_audit.py` 审核

## 输出报告

报告将保存在以下位置：

| 报告类型 | 文件路径 |
| --- | --- |
| 未上市公司研究（中期版） | `reports/{公司名}/{公司名}-mid-private-{YYYYMMDD}.md` |

> 与长期链 `reports/{公司名}/{公司名}-private-{YYYYMMDD}.md` **物理隔离**，避免混淆。如果 `reports/{公司名}/` 目录不存在则创建。

### 报告结构（十六节，含 2 节新增核心章节）

```
一、一句话结论 + GARP 适配速判 + 是否值得等待上市
二、公司概况与商业模式
三、林奇六类分类（必答）
四、财务体检与 ROE 趋势推断
五、渗透率位置与产业景气判断
六、竞争格局与全球产业链位置
七、管理层四维评估（诚信/股东态度/战略执行/稳定性）
八、科研转化与地缘政治六维评估
九、GARP 适配性总览（新增核心）
十、估值推演与一二级定价折溢价（PEG 潜力推演，替换终局市值倒推）
十一、是否值得等待上市吗？（新增核心）
十二、上市后卖出纪律预提醒（引用 exit-signal P0~P5，不内建）
十三、信息拼图来源清单（多源交叉验证）
十四、信息缺口与不确定性声明
十五、免责声明
十六、附录：替代数据与信号源清单
```

### "是否值得等待上市"四类结论

- ✅ **值得等待**：上市后即纳入 GARP 标的池
- ⚠️ **有条件等待**：需满足 X/Y/Z 条件
- ❌ **不值得等待**：不符合 1~3 年景气框架
- ❓ **需要更多信息**：列出信息缺口

## GARP 适配判断与估值（核心改造）

### 林奇六类分类（必答）

| 分类 | 特征 | 上市后 GARP 适配 |
| --- | --- | --- |
| 快速增长型 | 增速>20% | ✅ 核心适配 |
| 稳定增长型 | 增速 10%~20% | ✅ 用远期 PE |
| 周期型 | 利润随周期波动 | ⚠️ 需景气择时 |
| 困境反转型 | 前期低迷，有望反转 | ⚠️ 看反转证据 |
| 隐蔽资产型 | 含未反映在报表的资产 | ⚠️ 看资产兑现 |
| 缓慢增长型 | 增速<10% | ❌ 不适合 1~3 年景气 |

### PEG 潜力推演（五档，对齐 valuation-thermometer）

| 档位 | 范围 | 结论 |
| --- | --- | --- |
| 显著低估 | PEG<0.8 | 若上市且增速可持续，为绝佳潜在 GARP 标的 |
| 合理 | 0.8~1.2 | 符合 GARP 合理区 |
| 偏贵 | 1.2~1.5 | 需等待更优价格或景气再确认 |
| 高估 | 1.5~2.0 | 上市初期机动仓需谨慎 |
| 严重透支 | >2.0 | 不符合 GARP，回避或仅观察 |

### 渗透率位置判定（五区间）

| 区间 | 判定 |
| --- | --- |
| <5% | 过早，不确定性高 |
| 5%~15% | 培育期，关注是否逼近 15% 临界点 |
| 15%~30% | **黄金加速区（重仓窗口）** |
| 30%~50% | 成熟期，关注增速二阶导 |
| >50% | 警戒减速区 |

## 核心原则

1. **反偏见优先** — 资料少 ≠ 公司不好；AI 分析篇幅短 ≠ 投资确定性低
2. **GARP 适配性必须回答** — 每份报告必须明确"如果上市，符合 GARP 标准吗？PEG 潜力如何？"
3. **六类分类必须完成** — 林奇六类分类是 GARP 框架的入口
4. **渗透率必须推算** — 即使无官方数据，也要基于行业数据合理推算并标注置信度
5. **诚实留白** — 信息不足时明确说"数据缺失"，不用推测填满表格伪装确定性
6. **区分事实与推理** — 事实用正常字体，推理/推算用*斜体*并标注推算方法
7. **多源交叉验证** — 关键数据至少 2 个来源，冲突时全部列出并说明采信
8. **信号一致性检验** — 增长信号 vs 招聘信号、技术叙事 vs 专利数据、管理层叙事 vs 实际行动
9. **反向利用信息不对称** — 信息越少，定价效率越低，潜在认知差越大
10. **上市后视角导向** — 最终目标是判断"值不值得等待上市"，不是输出一份好看的报告
11. **引用不重复定义** — 卖出引用 `exit-signal` P0~P5，景气引用 `mid-thesis-drift` H1~H6，估值引用 `valuation-thermometer`
12. **不替用户做决策** — 给出判断和建议清单，但买卖决策由用户做

## 注意事项

- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- 6 个 Agent 必须在同一条消息中并行启动
- 如果用户只给公司名，先反问拟上市市场/融资阶段/研究侧重，**不要默默假设**
- 资料评级（A/B/C 级）需告知每个 Agent，影响其检索策略与置信度标注
- 每个关键数据标注来源（具体到媒体与文章标题）、时间（精确到年月）、置信度（🟢高/🟡中/🔴低）
- 不支持编造"估算数据"冒充"有据分析"；无法获取的信息明确标注"数据缺失"
- 卖出纪律统一 P0~P5，时间止损归 P2，无 P6 层级
- 术语红线：禁止"护城河永续""终局思维""持有 10 年""论文已破"等长期术语，壁垒表述统一为"1~3 年景气竞争力"
- 报告路径统一 `-mid-private-` 前缀，与长期版 `-private-` 区分
- 估值与财务计算使用 `financial_rigor.py` 精确计算，禁止 LLM 心算；跨币种折算用 `fx_rate.py` 实时汇率
- 不适合用本 Skill 的场景：已上市公司（用 `/mid-investment-research` / `/mid-investment-team`）、当前一级买入决策、长期研究（用 `/private-company-research`）

## 局限性说明

- **信息可得性**：未上市公司信息天然稀缺，部分维度可能完全无法获取数据
- **数据准确性**：第三方推算数据可能有较大误差
- **监管风险**：未上市公司的合规披露标准低于上市公司
- **估值不确定性**：缺乏公开市场锚定，上市后 PEG 区间推演可能偏差较大
- **AI 解读局限**：AI 无法完全替代深入的公司调研
- **渗透率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算
- **非实时数据**：工具获取的数据可能有延迟，不是实时数据
- 不构成投资建议，仅用于学习与研究
