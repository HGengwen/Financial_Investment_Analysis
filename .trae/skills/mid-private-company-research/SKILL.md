# 未上市公司研究（1~3 年景气版）：上市后 GARP 适配性预判

对 $ARGUMENTS 进行团队化深度研究分析。专为蚂蚁集团、小红书、SpaceX、Stripe 等未上市公司设计。

**最终目标**：判断这家未上市公司——**如果上市，是否可能成为符合 1~3 年景气投资框架的 GARP 标的？** 核心问题不是"现在值多少钱"，而是"上市后值得持有吗"。

> 本技能是**上市前的"预研建档"工具**：为上市后的 1~3 年景气投资提前建立标的池与判断框架，而非研究"现在是否买入未上市股权"。

> 💬 **林奇式提醒**："未上市公司的信息天然稀缺，但这不意味着不值得研究。恰恰相反——信息越少，定价效率越低，潜在的认知差越大。关键是：你能否在有限信息中，看清这门生意的本质？"
>
> 💬 **欧奈尔式提醒**："未上市公司没有股价让你止损。这意味着你的'买入决策'必须更谨慎——因为没有公开市场让你快速纠错。信号会藏在融资轮次、辅导备案、赛道热度里。"
>
> 💬 **郑希式提醒**："未上市公司没有季度财报来验证 ROE 趋势。你需要从融资轮次、用户增长、市场份额等替代指标来推断——'景气的信号'可能藏在招聘数据和 App 排名里。ROE 向上才是科技股最可靠的重力加速度。"
>
> 💬 **李进式提醒**："未上市公司的管理层评估比上市公司更重要——因为没有财报的硬约束，管理层的诚信和科研转化能力几乎全凭公开信息推断。'翻石头'要从创始人的公开演讲、访谈、内部信中寻找线索。"

> **本工作流用于学习与研究，不构成投资建议。**

## 一、设计理念（四位景气大师视角）

本技能绑定 1~3 年景气投资框架的四位大师，取代长期链的段永平/芒格视角：

| 大师 | 核心方法论 | 在本技能中的落点 |
| --- | --- | --- |
| **欧奈尔** | 信号驱动 + 风控底线（8% 止损、只做强势成长） | 上市时机信号识别、题材炒作 vs 真实趋势、风控兜底 |
| **林奇** | PEG + 六类分类 | 商业模式解码时必答六类分类；财务拼图后必做 PEG 潜力推演 |
| **郑希** | ROE 拐点 + 产业景气 | 从碎片信息推断 ROE 趋势（↑/→/↓）；识别景气位置与拐点 |
| **李进** | 渗透率坐标 + 二阶导 + 管理层四维 + 科研转化 + 地缘六维 | 渗透率位置判定、管理层/科研/地缘三重深评、15% 渗透率临界点 |

## 二、适用场景与不适用场景

### 适用场景

- 研究**未上市公司**（Pre-IPO / 独角兽 / 一级市场标的），判断其上市后是否可能成为 1~3 年景气 GARP 标的
- 已知某公司即将 IPO，想提前建立判断框架，上市后第一时间可跟踪
- 为 1~3 年景气投资建立的**未上市标的池预研建档**

### 不适用场景

- **已上市公司**（有公开财报与股价）→ 转 `/mid-investment-research`（单 Agent）或 `/mid-investment-team`（四 Agent）
- **现在是否买入未上市股权/一级基金份额** → 本技能不回答"当前一级定价是否值得买入"，只回答"上市后是否符合 GARP 框架"
- **长期（10 年）未上市公司研究** → 转长期链 `/private-company-research`

## 三、框架特点

未上市公司 vs 上市公司研究的核心差异：

- **无标准化财报**：需多源拼凑、交叉验证
- **估值锚定少**：依赖融资轮次、可比上市公司、情景推演、PEG 潜力推演
- **信息不对称大**：需要更多"拼图式"研究方法
- **退出路径不确定**：IPO / 并购 / 二级转让 / SPAC 均有可能
- **无公开市场信号**：没有股价和 PEG 让你判断"便宜还是贵"，必须推演上市后的 PEG

## 四、AI 研究偏见自觉（本框架的核心前提）

未上市公司是 AI 研究偏见最严重的领域。必须时刻警惕以下陷阱：

**核心矛盾**：AI 擅长结构化已有信息，但未上市公司的信息天然稀缺。这会导致：

1. **虚假保守**：因为资料少，AI 倾向给出保守/模糊的结论，但资料少 ≠ 公司不好
2. **虚假精确**：为了填满报告模板，AI 可能用"合理推测"伪装成"有据分析"
3. **对标陷阱**：强行与上市公司对标时，会继承上市公司的估值逻辑，忽略景气周期位置差异
4. **幸存者偏差**：网上能搜到的公司信息往往有正面偏向（公司主动传播的多是好消息）
5. **线性外推偏差**：将短期高增速外推多年，忽略渗透率拐点与二阶导

**应对原则（1~3 年 GARP 视角）**：

- 宁可留白说"不知道"，也不要用推测填满表格伪装确定性
- 每个数据点必须标注置信度（🟢高/🟡中/🔴低），让读者自己判断
- 区分"可验证的事实"与"AI 的推理"，用不同格式标注
- **对于信息极度稀缺的公司，切换为"第一性原理模式"**——不追求报告完整，只回答几个核心问题：
  1. 这门生意解决什么真实问题？需求是真需求还是伪需求？
  2. 赛道渗透率在什么位置？是 15%~30% 的黄金加速区吗？
  3. 如果上市了，PEG 可能在什么区间？是否满足 GARP 标准（五档温度）？
  4. 最大的"逻辑证伪"信号是什么？（对应上市后 P0~P5 卖出纪律）

**反向利用信息不对称**：市场对未上市公司信息少 → 定价效率低 → 恰恰可能是超额收益的来源。AI 研究的目标不是消除信息不对称（做不到），而是在有限信息中提取最关键的判断依据。

## 五、研究纪律

1. **日期确认**：研究前运行 `date` 确认当天日期，以此作为"最新数据"的基准，并在报告头部注明数据截止日期。不得依赖训练数据中的日期假设。
2. **数据交叉验证**：关键财务数据须至少来自两个独立来源，误差 >1% 须标记。未上市公司数据来源参差不齐，每个关键数据必须标注来源和置信度（🟢高/🟡中/🔴低）。
3. **区分事实与推理**：将每项重要陈述区分为**已验证事实**、**估计**、**假设**或**分析判断**。事实用正常字体，推理/推算用*斜体*并标注推算方法。无法获取的信息明确标注"数据缺失"，不要编造。
4. **精确算术工具**：估值计算、跨源校验使用精确工具 `tools/common/financial_rigor.py`，**禁止 LLM 心算**决策敏感数据。
5. **跨币种折算**：跨币种估值对比时，先用 `python tools/common/fx_rate.py --code USDCNY`（或 `HKDCNY`）获取实时汇率，勿用固定汇率。
6. **不确定性标注**：明确标注低置信度结论、不完整数据及来源缺口。推算过程要完全透明，展示计算逻辑和每一步假设。
7. **诚实留白**：信息不足以做出可靠估值判断时，直接说"信息不足，无法给出可靠估值"。允许出现"此维度数据不足，无法给出有意义的结论"。
8. **反偏见核心原则**：资料少 ≠ 公司不好，AI 分析篇幅短 ≠ 投资确定性低。对于信息极度稀缺的公司，切换"第一性原理模式"聚焦核心问题，不追求报告形式完整。
9. **报告审核**：报告保存后，运行 `tools/common/report_audit.py extract` 和 `verdict` 审核流程。未通过审核的报告是草稿，不是可发布的研究。

**⚠️ GARP 版特有纪律**：

10. **GARP 适配性必须回答**：每份报告必须明确回答"如果这家公司上市，它符合 GARP 标准吗？PEG 潜力如何？"
11. **六类分类必须完成**：林奇的六类分类是 GARP 框架的入口，未上市公司也必须判断类型。
12. **渗透率必须推算**：即使没有官方数据，也要基于行业数据做合理推算，标注置信度。

## 六、执行流程

### 第一步：确认参数

向用户确认以下信息，信息不足时**先反问，不默默假设**：

- 公司名（中文/英文，A 股待上市 / 港股 / 美股 / 其他）
- 拟上市市场（如已知）
- 是否已知上市计划/融资阶段（Pre-IPO / 已递表 / 辅导备案 / 暂无计划）
- 研究侧重（商业模式 / 财务与估值 / 竞争格局 / 管理层 / 技术 / 上市时机）

### 第二步：信息可得性分级

| 等级 | 特征 | 研究策略 |
| --- | --- | --- |
| **A 级（信息充裕）** | 已递表/有招股书、媒体覆盖广、母公司披露多 | 重点是降噪与交叉验证，可对标已上市 GARP 标的 |
| **B 级（信息适中）** | 有融资记录、部分媒体覆盖 | 标准模式，每条关键数据附 1-2 个独立信源 |
| **C 级（信息稀缺）** | 早期、冷门、无招股书 | 转入"第一性原理模式" + 替代数据，找不到信息本身就有价值 |

该分级须告知每个 Agent，影响其搜索策略与置信度标注。

### 第三步：启动 6 个并行 Agent

使用 Task 工具同时启动 6 个 Agent（**必须在同一条消息中并行调用**）。

每个 Agent 的配置：

- `subagent_type`: `general_purpose_task`
- `description`: 简短描述角色任务

每个 Agent 的任务描述模板（按角色填入对应任务内容）：

```

- 数据可能不完整或相互矛盾，需要标注置信度
- 需要更多的推理和合理推算，但要透明展示推算过程
```

```
- **林奇测试**：如果你花 10 分钟都解释不清这家公司是做什么的，那它的业务可能太复杂了

- 用户规模：MAU/DAU（从 QuestMobile、Sensor Tower、SimilarWeb 等推算）

- 用户粘性指标：DAU/MAU 比率、平均使用时长

  - 是真实需求驱动还是补贴驱动？
  - 增长是否依赖单一渠道或单一产品？
  - 增长速度是否在加快、稳定还是放缓？
  - 与同行业头部公司的增速对比
```

综合 6 份分析报告，按第七节报告结构输出最终报告，核心是**给出林奇六类分类 + GARP 适配性总览 + 是否值得等待上市**的明确判定（✅/⚠️/❌/❓）。

### 第七步：保存报告与审核

将完整最终报告写入 `reports/{公司名}/{公司名}-mid-private-{YYYYMMDD}.md`。如果 `reports/{公司名}/` 目录不存在则创建。

**发布审核**（报告保存后必须执行）：

```bash
# Step 1 - 提取抽检清单
python tools/common/report_audit.py extract \
  --report reports/{公司名}/{公司名}-mid-private-{YYYYMMDD}.md

# Step 2 - 对清单每项从可靠信源取数交叉验证
#   估值/财务计算验算：python tools/common/financial_rigor.py（禁止 LLM 心算）
#   跨币种折算：python tools/common/fx_rate.py --code USDCNY（或 HKDCNY）

# Step 3 - 输出准出/打回判决
python tools/common/report_audit.py verdict \
  --results '<verified JSON>' \
  --report reports/{公司名}/{公司名}-mid-private-{YYYYMMDD}.md
```

**【准出】** 全部通过 → 报告可发布；**【打回】** 有不通过 → 修正后重审。修复未通过项并重复审核。明确保留未解决的缺口，降低置信度而非用假设填充。

## 七、GARP 适配判断与估值推演（核心新增）

### 7.1 林奇六类分类（必答）

| 分类 | 特征 | 上市后 GARP 适配 |
| --- | --- | --- |
| 快速增长型 | 增速>20%，PEG 工具适用 | ✅ 核心适配 |
| 稳定增长型 | 增速 10%~20% | ✅ 用远期 PE |
| 周期型 | 利润随周期波动 | ⚠️ 需景气择时 |
| 困境反转型 | 前期低迷，有望反转 | ⚠️ 看反转证据 |
| 隐蔽资产型 | 含未反映在报表的资产 | ⚠️ 看资产兑现 |
| 缓慢增长型 | 增速<10% | ❌ 不适合 1~3 年景气 |

### 7.2 PEG 潜力推演（五档，对齐 valuation-thermometer）

上市后 PEG = 预估上市 PE ÷ 未来 1~3 年净利润复合增速：

| 档位 | 范围 | 结论 |
| --- | --- | --- |
| 显著低估 | PEG<0.8 | 若上市且增速可持续，为绝佳潜在 GARP 标的 |
| 合理 | 0.8~1.2 | 符合 GARP 合理区 |
| 偏贵 | 1.2~1.5 | 需等待更优价格或景气再确认 |
| 高估 | 1.5~2.0 | 上市初期机动仓需谨慎 |
| 严重透支 | >2.0 | 不符合 GARP，回避或仅观察 |

> **注意**：一级市场最近融资估值/Pre-IPO 估值可能已显著高于上市后合理 PE，需明确"当前一级定价"与"上市后合理定价"的**折溢价**，防止把一级高估值直接套到上市后判断。

### 7.3 渗透率位置判定（五区间，对齐 V2.0 + mid-thesis-drift H1）

| 区间 | 判定 |
| --- | --- |
| <5% | 过早，不确定性高 |
| 5%~15% | 培育期，关注是否逼近 15% 临界点 |
| 15%~30% | **黄金加速区（重仓窗口）** |
| 30%~50% | 成熟期，关注增速二阶导 |
| >50% | 警戒减速区 |

### 7.4 估值方法改造对照

| 长期版方法 | 中期版改造 |
| --- | --- |
| 最近融资估值法 | 保留：仅作"当前一级市场定价锚"，并标注与上市后合理估值的折溢价 |
| 可比上市公司法 | 改造：对标**已上市 GARP 标的**的 PEG/PE 区间，而非同类公司绝对市值 |
| DCF 情景分析 | 改造：1~3 年短周期折现（配合景气假设 H1~H6），不做 10 年终局 |
| 终局市值倒推法（5~10 年） | **删除**，替换为 **PEG 潜力推演法**（见 7.2） |
| 交易对标法 | 保留：参考同类公司并购/融资交易倍数作交叉验证 |

## 十一、重要注意事项

1. **6 个 Agent 必须并行启动**——在同一条消息中调用 6 次 Task 工具
2. **数据置信度标注**——未上市公司数据来源参差不齐，每个关键数据必须标注来源和置信度
3. **推算要透明**——所有推算过程要展示计算逻辑，不能凭空给数字
4. **交叉验证**——关键数据至少 2 个来源交叉验证，来源冲突时都列出
5. **GARP 适配性必须回答**——这是本技能的核心输出，不能回避
6. **六类分类必须完成**——林奇六类分类是 GARP 框架的入口
7. **反偏见核心原则**——资料少 ≠ 公司不好，AI 分析篇幅短 ≠ 投资确定性低
8. **诚实留白**——允许"数据不足，无法给出可靠判断"
9. **替代数据不是噪音**——招聘、专利、诉讼、App 数据等可能比新闻报道更接近真实
10. **上市后视角导向**——最终目标是判断"值不值得等待上市"，不是输出一份好看的报告
11. **术语红线**——全文禁止"护城河永续""终局思维""持有 10 年""论文已破"等长期术语；壁垒表述统一为"1~3 年景气竞争力"；卖出纪律统一 P0~P5，时间止损归 P2，无 P6 层级
12. **报告物理隔离**——报告路径统一 `-mid-private-` 前缀，与长期版 `-private-` 区分
13. **技能名准确**——中期链技能名为 `/mid-investment-checklist`、`/mid-earnings-review`、`/mid-earnings-team`、`/mid-investment-research`、`/mid-investment-team`、`/mid-bottleneck-hunter`；`garp-ask`、`garp-liquidity-reinvestment` 为真实中期专用技能可正常引用

## 十二、局限性

1. **信息可得性**：未上市公司信息天然稀缺，部分维度可能完全无法获取数据
2. **数据准确性**：第三方推算数据可能有较大误差
3. **监管风险**：未上市公司的合规披露标准低于上市公司
4. **估值不确定性**：缺乏公开市场锚定，上市后 PEG 区间推演可能偏差较大
5. **AI 解读局限**：AI 无法完全替代深入的公司调研
6. **渗透率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算
7. **不构成投资建议**：本技能仅用于学习与研究
