# garp-earnings-review（GARP 财报精读·轻量版，1~5 年）

**单 Agent 快速财报精读**：对单家公司 × 单期财报执行十二条精读流程，用五大师视角验证景气逻辑、定位 GARP 估值档位、更新五级卖出纪律，产出「**本期景气是否被验证、估值落在哪一档、五级卖出是否触发**」的季度跟踪报告。

> **所属档位**：GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔）
> **适用口径**：GARP 独立档 1~5 年（渗透率 15%~40% 黄金窗 / 0.3 三维交叉矩阵 / 多工具估值矩阵 + 统一六档 / 五级卖出）

---

## 技能用途 / 何时使用

### 解决什么问题

回答「**这一期财报出来后，原来的投资逻辑还成立吗？该加仓、持有、减仓还是离场？**」——把五大师的分歧摊开核验，再收口为**单一结论**（**五问必答**），而不是复述财报。

### 何时使用

| 场景 | 是否适用 |
| --- | --- |
| 持仓标的**季度 / 半年 / 年度财报**发布后的快速跟踪 | ✅ 适用 |
| 需要逐期校验**财务五门槛**与景气三要素（ROE / 增速 / 二阶导） | ✅ 适用 |
| 需要更新**五级卖出纪律**与止损位 | ✅ 适用 |
| 需要更新**估值档位**与底仓 / 机动仓建议 | ✅ 适用 |
| 需要团队化深度精读 + 发布级产出 | ❌ 用 `garp-earnings-team` |
| 首次深度研究一家公司（建论文） | ❌ 用 `garp-investment-research` / `garp-investment-team` |
| 只需买入前七关硬门槛核验 | ❌ 用 `garp-investment-checklist` |
| 只需卖出信号核验 | ❌ 用 `garp-exit` |
| 只需组合层集中度 / 相关性 / 压力测试 | ❌ 用 `garp-portfolio-review` |
| 盘中股价异动归因 | ❌ 用 `garp-news-pulse` |

### 前置建议

推荐执行顺序：`garp-investment-research` / `garp-investment-team`（建论文）→ **本技能（逐期验证）** → `garp-exit`（命中卖出信号时强制转接）→ `garp-thesis-tracker`（更新论文健康度）。

## 所属档位与适用口径

| 项 | 值 |
| --- | --- |
| **所属档位** | **GARP 独立档（1~5 年）** |
| **大师体系** | 五大师：**费雪 / 林奇 / 郑希 / 李进 / 欧奈尔**（**分析维度标尺，非并行 Agent**） |
| **执行形态** | **单 Agent 轻量版**（团队版归 `garp-earnings-team`） |
| **持有周期** | 1~5 年 |
| **档位隔离** | 与 1~3 年中期链、10 年长期链**物理隔离、功能互补** |
| **档位切换开关** | **不提供**——本技能即 GARP 独立档财报精读专属入口 |

### 本档五大关键口径

| 口径项 | 权威值 |
| --- | --- |
| **渗透率黄金窗** | **15%~40%**（五档：<5% / 5%~15% / **15%~40%** / 40%~60% / >60%）+ **国产化率四梯队**（<5% / 5%~20% / 20%~50% / >50%） |
| **地缘口径** | **0.3 三维交叉矩阵**（地缘倒逼强度 × 政策覆盖度 × 国字号基金介入）+ **赛道两分法**（地缘倒逼型 / 政策资本驱动型），**只照引、不自判** |
| **估值口径** | **多工具矩阵**（五类公司类型 × 主锚 / 辅锚）+ **四级留痕** + **统一六档**（显著低估 / 低估 / 合理 / 合理偏贵 / 高估 / 严重透支） |
| **管理层口径** | **诚信前置不计分闸门 + 7+7+6**；科研转化 **8+8+4**；≥15 可重仓（**只引结论，不复制评分表**） |
| **卖出口径** | **五级卖出** + 时间止损（满 4 季度）+ 性价比替换（每季最多 1 次）；**命中即转接 `garp-exit`** |

### 财务五门槛（本技能逐期校验）

| # | 门槛 | 权威值 |
| :--: | --- | --- |
| 1 | 营收规模 | ≥10 亿 |
| 2 | 成长性 | 最近三年营收复合增速 ≥15% |
| 3 | 负债率 | <60% |
| 4 | 现金流 | 经营现金流为正 |
| 5 | 盈利质量 | 最近 3 年内 ≥2 年扣非净利润为正 |
| — | **科技豁免** | 营收连续增长 + 经营现金流为正 + **研发强度 ≥15%** |

### 基本调用


### 参数说明

| 参数 | 必填 | 取值 | 说明 |
| --- | :--: | --- | --- |
| `{公司名}` | ✅ | 文本 | 位置参数，公司名称或代码 |

## 五大师维度标尺（单 Agent 版）

| 大师 | 维度 | 核心问题 | 必用工具 |
| --- | --- | --- | --- |
| **费雪** | 质化与长期持有 | 它是「杰出企业」吗？质化信息说了什么？下跌是暂时性还是永久性？ | `annual_report_parser.py` + 搜索五件套（**闲聊法**）+ `governance_data.py`（仅读结论） |
| **郑希** | 产业景气验证 | ROE 拐点到了吗？二阶导方向？渗透率在哪一档？ | `stock_financial.py` + 搜索五件套 + `qoq-accelerator` |
| **林奇** | 生意与估值 | 增长由「量」还是「价」驱动？该用哪个估值锚？ | `financial_rigor.py`（验算链）+ `stock_financial.py` + 搜索五件套 |
| **欧奈尔** | 风控底线 | 止损位多少？趋势是否走坏？ | `stock_quote.py --momentum` + `trend-momentum-scan` |
| **李进** | 组合管理与治理 | 底仓 / 机动仓怎么配？管理层可信吗？科研能转化吗？ | `governance_data.py` + `geo_policy_screen.py` + `macro_calibrator.py` |

**核心口诀**：郑希定方向 → 林奇验生意 → 李进验质量 → 费雪判性质 → 欧奈尔守底线。

> **刚性纪律**：五大师是**分析维度标尺**，**不是五个并行 Agent**；**五维缺一即报告不合格**（`GER-1`）。

## 执行流程（前置 + 十二步）

| 步 | 动作 | 关键产出 |
| :--: | --- | --- |
| 前置 | 资料可得性评级（A / B / C 三级） | 评级结论（写入报告头部） |
| 1 | 解析 `{公司名}` + `{期间}` + 市场识别 + 确认日期 | 参数表 + **四基准** |
| 2 | 获取一手资料（**A 股财报 PDF 下载前置** → PDF 提取 → 结构化抽取 → 并行取材料） | 财报原文 + 结构化字段 |
| 3 | 核心财务数据提取与验证（三表拆解 + 双源交叉验证） | 数据底稿 + 误差标记 |
| 4 | 盈利趋势与二阶导（ROE / 营收增速 / 净利润增速 / 二阶导） | 趋势判断表 |
| 5 | **GARP PEG 定位**（公司类型 → 主锚 / 辅锚 → 四级留痕 → 统一六档 + 宏观 PEG 区间 + ESG 折价） | 估值档位结论 |
| 6 | 三表精读（利润表 / 现金流表 / 资产负债表 + **财务五门槛校验 + 科技豁免**） | 三表解读 + 门槛判定 |
| 7 | 管理层讨论精读（语气 + 承诺追踪 + **诚信前置闸门** + 费雪补充检查） | 诚信结论 + 费雪补充项 |
| 8 | 附注与隐藏信息（科研转化 8+8+4 / 管理层 7+7+6 / ESG 三通道 / 暂时性 vs 永久性复核） | 附注结论 |
| 9 | 地缘与国产化更新（0.3 矩阵档位照引 + 赛道两分法 + 敞口体检 + 国产化率四梯队） | 地缘档位 + 敞口结论 |
| 10 | 与历史数据对比（近 8 季趋势 + 渗透率位置更新） | 八季趋势表 |
| 11 | **卖出纪律检查**（五级逐一核对 + 时间止损 + 性价比替换） | 五级检查表 |
| 12 | 底仓 / 机动仓分离 +「假如空仓」测试 + 季度复盘 7+1 项 → 报告落盘 → 数据抽检准出 | 报告 + 后置转接 |

### 结论五问必答（缺一即不合格，`GER-1`）

1. 景气逻辑是否被验证？（验证 / 部分验证 / 未验证）
2. GARP 估值落在哪一档？
3. 五级卖出是否触发？（命中即转接 `/garp-exit`）
4. 底仓 / 机动仓如何操作？
5. 「假如空仓」结论？（会买 / 不会买 / 犹豫不决 + 具体理由）

```bash
# Step 1 — 提取抽检清单
```

## 局限性

1. **资料可得性**：部分公司完整财报原文难以获取，评级可能为 B / C 级；
2. **扫描版 PDF 限制**：A 股年报常为扫描版，可能无法提取文本，影响附注分析；
3. **非实时数据**：工具数据可能有延迟，不是实时数据；
4. **景气判断滞后性**：ROE 趋势与增速二阶导是滞后指标，可能无法提前捕捉拐点；
5. **渗透率 / 国产化率无 CLI 出口**：依赖第三方估算，按 A/B/C 三级置信度标注；
6. **地缘数据时变**：制裁清单、出口管制、关税与基金名录变化较快，须实时核验；
7. **0.3 矩阵无量化系数**：框架只给定性档位，**运行期不得发明系数**；
8. **主观自评项无工具化判据**：费雪补充检查、暂时性 vs 永久性判定、资料可得性评级为主观判断，报告中已标注「自评项，非工具化判据」；
