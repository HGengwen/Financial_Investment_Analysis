# 财报精读（轻量版）：GARP 独立档 1~5 年价值成长版

对 $ARGUMENTS 进行 **1~5 年价值成长（GARP）** 财报精读分析。

**支持输入格式**：`{公司名} {期间}`，例如 `/garp-earnings-review 腾讯 2025Q4`、`/garp-earnings-review 中芯国际 2025年报`、`/garp-earnings-review 新易盛 最新`（默认读取最近一期）

- `{公司名}` —— 位置参数（必填）
- `{期间}` —— 位置参数（必填，季报 / 半年报 / 年报期间，或 `最新`）
- `--market` —— 市场参数（`auto` / `a` / `hk` / `us`，默认 `auto`）
- `--depth` —— 精读颗粒度（`fast` / `standard` / `deep`，默认 `standard`；**本技能为单 Agent**，该参数控制**精读颗粒度**而非 Agent 数量，见「注意事项」第 16 条）
- `--export` / `--export-path` / `--json` —— 导出与结构化输出开关

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

> **本技能不提供档位切换开关**——它即 GARP 独立档（1~5 年）财报精读专属入口，命令与输入中**不含任何档位切换参数**；档位切换类口令属其他档位口径，在本技能中出现即违反**口径隔离**纪律（见「注意事项」第 1 条与「与各 garp- 技能的关系」）。

**权威设计依据**：`upgrade1.0/中长期价值成长（GARP）投资框架.md`（下称「框架」）。本技能所有量化口径（渗透率五档、国产化率四梯队、0.3 三维交叉矩阵、管理层 7+7+6、科研转化 8+8+4、估值多工具矩阵与统一六档、五级卖出、宏观三表、财务五门槛）**逐条对齐框架原文行号**，不自行推导。

## 一、能力圈声明

本技能严格服务于 **GARP 独立档（1~5 年价值成长）** 财报跟踪，并非万能工具。

### 1.1 适用场景

- **科技 / 医药 / 高端制造 / 国产化替代与增量创造型成长股**：具备技术壁垒或产品迭代周期
- **景气周期成长股**：行业渗透率处于 **15%~40% 加速上行黄金窗**
- **可持续成长**：ROE 有明确提升路径，且现金流能支撑再投资
- **已建立投资论文的持仓或候选标的**：建议先跑 `garp-investment-research` 或 `garp-investment-team` 建立基准论文，本技能负责**逐期验证**

### 1.2 不适用场景（请停止使用本技能）

- **纯周期股**：如航运、有色、煤炭（应使用 PE/PB 周期估值，PEG 失效）
- **困境反转股**：当前亏损或微利且无清晰盈利路径，PEG 无法计算或失真
- **金融股**：资产负债表结构特殊，需用 PB-ROE 或股息率模型
- **被动指数投资**：无需个股景气验证
- **短期交易**：本技能不关注日内波动、纯技术面超买超卖或宏观择时

## 二、与段永平价值投资的关系说明

⚠️ **重要界定**：段永平在本框架中仅作为「哲学补充」角色，**不参与估值、择时、止损等操作层面决策**。

**可借鉴的底层哲学**：

- 「买股票就是买公司」：强调一手资料、管理层诚信、生意模式。
- 「能力圈」：不懂不做，不碰看不懂的复杂金融衍生品或过度杠杆公司。
- 「本分」：不占便宜，关注企业内在价值而非短期股价波动。

**不完全适配的核心思想**：

- 「封仓十年」：本框架持有周期为 **1~5 年**，需根据景气拐点与估值档位动态调整，不做无条件死扛。
- 「不预测宏观」：本框架**叠加宏观三表**（利率 / 经济 / 美林），但宏观**只调「估值容忍度」与「仓位尺度」**，不替代个股基本面判断。
- 「毛估估」：本框架要求精确的**多工具估值定位**（收口 `garp-valuation` 统一六档）、二阶导趋势判断及分批建仓纪律，拒绝模糊估值。

## 三、设计理念

大多数 AI 投研工具依赖二手信息。但价值成长的财报跟踪，必须读一手资料——因为景气拐点的信号往往藏在细节里：ROE 拐头、增速二阶导转负、管理层语气变化、研发进度滞后。

在 GARP 独立档（1~5 年）框架中，每期财报是验证投资逻辑的关键节点，必须回答**五个问题**：

1. **景气逻辑验证**：ROE 趋势是否持续？增速二阶导（加速度）是正是负？渗透率到哪一档了？
2. **GARP 估值档位**：按公司类型选主锚 / 辅锚后，落在**统一六档**的哪一档？
3. **卖出纪律更新**：本季度数据是否触发**五级卖出**或补充机制（时间止损 / 性价比替换）？
4. **管理层是否在抓住窗口**：诚信前置闸门是否通过？战略执行力、资本配置效率、科研转化进展如何？
5. **估值与仓位匹配**：底仓 / 机动仓比例是否合理？仓位上是否触及宏观调档后的上限？

### 五大师语录

> "如果一家公司在诚信问题上不合格，无论其他标准得分多高，我永远不会考虑这只股票。" —— 费雪（质化挖掘 · 诚信一票否决）

> "ROE 向上是科技股最可靠的'重力加速度'——只要这个趋势在，估值波动只是噪音。" —— 郑希（产业景气 · 季度验证）

> "如果你花 10 分钟都解释不清一家公司是做什么的，那它的业务可能太复杂了。" —— 林奇（生意验证 · 估值锚选型）

> "先想清楚亏多少，再想赚多少。8% 是普通投资者的生存红线。" —— 欧奈尔（风控底线 · 趋势止损）

> "管理层是'人'的因素，科研转化是'技术'的因素。两者必须交叉验证。" —— 李进（治理与组合 · 仓位纪律）

### 与单一指标的分野

- **估值不靠单一 PEG**：科技与国产化主题公司的利润常被研发费用化压低，单一 PEG 极易误判——本技能估值结论**一律按公司类型选主锚与辅锚，并收口 `garp-valuation` 的多工具矩阵 + 统一六档**。
- **卖出不自建层级**：**五级卖出 + 时间止损 + 性价比替换**一律引用 `garp-exit`，本技能只做逐级核对与标注，不重排优先级、不裁量仓位数值。
- **仓位与渗透率解耦**：仓位一律按框架硬上限执行，**不按渗透率折算仓位上限**。
- **治理不重复评分**：管理层 7+7+6、科研转化 8+8+4、ESG 三通道**只引 `garp-management` 结论**，不复制评分表。

**刚性纪律**：

1. 本技能为**单 Agent 轻量版**——五大师**是分析维度标尺，不是五个并行 Agent**；多 Agent 团队版归 `garp-earnings-team`（**只指向名称，不描述其内部流程**）；
2. 每位大师在每个模块的「追问」须逐段落地；
3. **不得**因轻量定位而省略任一维度——**五维缺一即报告不合格**（`GER-1`）。

## 四、执行流程

### 前置步骤：资料可得性评级

| 等级 | 特征 | 影响 |
| ---- | ---- | ---- |
| **A 级** | 获取到完整原文（年报 / 半年报 / 季报 / 电话会纪要） | 正常执行全部步骤 |
| **B 级** | 仅获取到部分原文或第三方汇总 | 标注「非原始来源」，降低附注分析权重 |
| **C 级** | 仅有新闻报道和数据网站摘要 | 聚焦核心财务数据变化，标注「一手资料不足」，**结论不得为确定性**，须列「需要一手验证的问题清单」 |

> **评级为自评项，非工具化判据**（`GER-12`）；评级结论须写入报告头部。

### 第一步：获取一手资料

#### 1.1 A 股财报原文下载（优先执行，必须完成）

**重要流程**：对于 A 股公司，必须首先使用 `stock_equity.py` 工具下载原始财报 PDF，**下载完成后方可进行下一步的阅读分析工作**（`GER-10`）。

```bash
# 下载最新年报PDF
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type annual

# 下载最新半年报PDF（如需分析半年报）
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type semiannual

# 下载最新季报PDF（如需分析季报）
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type quarterly
```

下载的 PDF 文件保存在 `cninfo_reports/` 目录。**流程检查点**：确认 PDF 文件下载成功后，方可进行后续的财报阅读分析。**下载失败时不得进入下一步精读**，须标注「资料可得性降级」并说明原因，改以可用公开数据执行并**逐处标注来源等级**；**不得据此伪造附注分析**。

#### 1.2 PDF 文档阅读工具

下载的财报 PDF 文档提取文字与表格**首选** `tools/common/pdf_extract.py`，返回失败（退出码非 0 / `success=false` / 扫描件）时才回退 Poppler 工具集：

```bash
# 分类检测 PDF 类型
python tools/common/pdf_extract.py detect cninfo_reports/002465_2025年报.pdf

# 提取含财务附表的 Markdown 并写盘
python tools/common/pdf_extract.py markdown cninfo_reports/002465_2025年报.pdf --save-md --out-dir reports/pdf

# 强制 OCR 提取（适用于提取乱码时，如 Adobe-CNS1 繁体中文 PDF）
python tools/common/pdf_extract.py text cninfo_reports/688235_2025年报.pdf --force-ocr --ocr-langs chi_tra+eng
```

**回退工具（Poppler 工具集，仅当 `pdf_extract.py` 返回失败时使用）**：

```bash
pdfinfo cninfo_reports/002465_2025年报.pdf
pdftotext cninfo_reports/002465_2025年报.pdf cninfo_reports/002465_2025年报.txt
pdftoppm -png cninfo_reports/002465_2025年报.pdf cninfo_reports/002465_2025年报
```

**注意事项**：

- 首选 `pdf_extract.py` 提取文字与表格；返回失败时才回退 Poppler 工具集（详见 [PDF文档内容提取技能](../tools-scripts/pdf-extraction.md)）
- `pdf_extract.py` 内置自动乱码检测，当提取文本出现乱码且 tesseract OCR 可用时，自动触发 OCR 回退
- **繁体中文 PDF**（如百济神州）需使用 `--force-ocr --ocr-langs chi_tra+eng` 指定繁体中文语言包
- 如果 PDF 无法提取内容，应在报告中标注「资料评级：B 级」，说明扫描版 PDF 限制

#### 1.3 年报结构化定向抽取

```bash
python tools/common/annual_report_parser.py reports/pdf/{代码}_{年份}年报.md --output-json
```

覆盖 **员工 / 子公司 / 研发 / 收入分部 / 新品 / 供应链风险** 六类字段；失败或字段缺失须**如实标注缺口**，不得以推测填充。

#### 1.4 并行获取其他原始材料

| 资料类型 | 获取来源 | 优先级 | GARP 特别关注 |
|---------|---------|--------|-----------------|
| 财报原文 | 公司 IR 页面、SEC EDGAR（美股）、港交所披露易（港股）、巨潮资讯网（A 股） | 最高 | — |
| 业绩电话会纪要 | 公司 IR 页面、雪球、财经媒体转录 | 最高 | 管理层对景气趋势与在手订单的评论 |
| 上期核心数据 | 上一期财报 | 高 | ROE / 增速 / 二阶导对比 |
| 行业可比公司财报 | 竞争对手 IR 页面 | 中 | 景气是否行业性共振 |
| 侧面渠道信息（**闲聊法**） | 竞争对手 / 供应商 / 客户 / 前员工公开访谈、经销商反馈 | 中 | 费雪维度：质化信息先于财报 |

**注意**：禁止使用 Anthropic 官方 WebSearch / WebFetch（中国大陆不可用），统一使用本地五工具组合（详见 [web-search-tools](../tools-scripts/web-search-tools.md)），按市场 × 场景矩阵选型，命令形态**逐字采用**「工具使用指南」中的实测形态。

### 第二步：核心财务数据提取与验证（GARP 版）

#### 2.1 景气三要素：ROE、增速、二阶导

**郑希核心**：ROE 向上是科技股最可靠的「重力加速度」。

| 指标 | 本期 | 上季 | 去年同期 | 趋势判断 |
|------|------|------|---------|----------|
| ROE（TTM） |  |  |  | ↑/→/↓ |
| 营收增速（YoY） |  |  |  | ↑/→/↓ |
| 净利润增速（YoY） |  |  |  | ↑/→/↓ |
| 增速二阶导（本期增速 − 上期增速） |  |  |  | 正 / 负 / 持平 |

> **二阶导口径**：框架未定义二阶导阈值，本技能保留为**定性趋势判断**（增速方向与加速度描述），**不设自造阈值**、不称框架条款；三态口径（景气向上 🟢 / 拐点预警 🔴 / 噪音不判 🟡）引 `qoq-accelerator`。
>
> **郑希式追问**：如果 ROE 连续 2 季度持平或下降，景气逻辑需要重新审视；二阶导连续 2 季度转负是**重点核对信号**，须在第十步对照五级第 4 级（产业景气判断）逐条核对。

#### 2.2 收入与利润表

| 指标 | 本期 | 上期 | YoY 变化 | 景气解读 |
|------|------|------|---------|---------|
| 总收入 |  |  |  |  |
| 分业务增速 |  |  |  | 哪些业务在加速 / 减速？ |
| 毛利率 |  |  |  | 定价权是否稳固？ |
| 经营利润率 |  |  |  | 费用控制是否有效？ |

必须覆盖：

- 总收入及分业务 / 分地区收入拆解（区分「量」还是「价」驱动的增长）
- 毛利润、毛利率变化
- 经营利润、经营利润率变化（区分 GAAP 和 Non-GAAP）
- 净利润（注意非经常性损益的影响）
- EPS（基本 vs 稀释；检查「净利润增速」与「EPS 增速」的剪刀差）

#### 2.3 现金流表（景气可持续性验证）

| 指标 | 本期 | 上期 | 变化 | 景气解读 |
|------|------|------|------|---------|
| 经营现金流 |  |  |  | 利润质量如何？ |
| 自由现金流 |  |  |  | 能否支撑再投资？ |
| 资本开支 |  |  |  | 是扩张性还是维护性？ |

必须覆盖：

- 经营性现金流 vs 净利润的比率（>100% 为佳，<80% 需警惕）
- 资本开支及其构成（维护性 vs 扩张性）
- 自由现金流 = 经营现金流 − 资本开支

### 第四步：GARP PEG 定位（引用 `garp-valuation`，**本技能零档位自建**）

在财务数据验证后，必须进行估值定位，作为操作依据。**本技能不重复定义任何档位阈值，一律收口 `garp-valuation`。**（`GER-5`）

#### 4.1 第一步：判定公司类型（五类，框架行 381~387）

| 公司类型 | 核心工具（主锚） | 辅助工具 | 可接受标准 |
| --- | --- | --- | --- |
| **快速增长型（盈利稳定）** | **调整后 PEG**（即「GARP PEG」） | 远期 PE、PEG 分位 | PEG<1 低估 / 1~1.2 合理 / 1.2~1.5 合理偏贵（持有不加仓、机动仓择机减）/ **>1.5 高估** |
| **高研发投入型（利润被压低）** | **PS / EV-Sales** | **Rule of 40** | **Rule of 40 ≥ 40**；EV/Sales 低于同业可比 |
| **未盈利科技型** | PS、EV-Sales | **研发管线 NPV** | 需有清晰的盈利路径与里程碑节点 |
| **稳定增长型** | 远期 PE + **隐含 PEG** | 股息率 | 当前 PE ≤ 未来 3 年 EPS 复合增速（百分数值）×1.2（**隐含 PEG ≤1.2**） |
| **成熟型企业** | **DCF** | 股息贴现 | 当前市值 ≤ **保守 DCF 估值的 80%** |

> **PEG 使用边界**（框架行 392）：PEG 适用于盈利稳定的成长股；PS / EV-Sales 适用于高研发投入或未盈利科技股；DCF 适用于现金流稳定的成熟企业；**科技股须多工具交叉验证，避免单一指标误判**。公司类型难判定（如盈利波动大 / 转亏）时**必须换锚**，**不得强行套 PEG**。

#### 4.2 第二步：技术性口径（科技股调整后口径）

- 高研发投入公司**研发费用化会虚增 PE / PEG**，务必用「**核心经营利润**」口径回算**调整后 PE / 调整后 PEG**：

#### 4.3 第三步：四级留痕（统一收口）

```text
基准档位 → 宏观校准后 → ESG 折价后 → 最终档位
```

**叠加规则**：

- **宏观 PEG 合理买入区间**（见 4.4）：框架 PEG 阈值以**中性宏观环境**为基准，加息 / 降息周期**动态上浮或下调**；参数经 `garp-macro` / `macro_calibrator.py` 透传（`GER-9`）。
- **ESG / 环境风险折价**（框架行 424~439）：高环境风险行业**合理估值再打 8~9 折**；有明确碳减排承诺与可验证转型路径 → 折价收窄至 **≤5% 或豁免**；面临「搁浅资产」风险 → **DCF 贴现率额外上调 1~2 个百分点**；ESG 评级处行业尾部 → **先降仓位上限**（如绝对上限 20% → 15%），而非继续压估值。

#### 4.4 宏观 PEG 合理买入区间与「合理偏贵」统一口径（框架行 695~748）

| 利率环境 | 合理买入区间 | 越界处置 |
| --- | --- | --- |
| 加息 / 高利率 | **收紧至 0.8~1.0** | 低估 <0.7；**>1.2 减机动仓** |
| 中性（**基准**） | **1.0~1.2** | 低估 <1.0；**>1.5 高估** |
| 降息 / 低利率 | **放宽至 1.2~1.5** | 低估 <1.2；仍 **>1.5 减仓**，**>2 绝对透支清机动仓** |
| 滞胀期 | **进一步下探至 0.8** | 按最紧档处置 |

- **「合理偏贵」统一口径**：合理买入区间之上、高估阈值之下的**中间带**（中性即 **1.2~1.5**）——可继续持有底仓、**不加仓**，机动仓逢高择机减仓。
- **「增速确定性」三锚**：①连续 2~3 季增速稳定性 ②订单可见度（在手订单 / 预收 / 合同负债覆盖度）③竞争格局固化程度（CR5 与龙头份额趋势）；**任一偏弱 → 偏贵上限收紧至 1.2**。
- **绝对红线**：**「PEG>2 为严重透支」不因降息而取消**（仅可放缓减仓节奏）。

> **口径禁令**：**其他档位的估值工具名、档位开关与温度计式刻度一律不得出现**；本技能**零 PEG 档位自建、零估值结论自建**（`GER-5`）。

### 第十步：卖出纪律检查（引用 `garp-exit`，**命中即转接**）

每期财报必须按此顺序检查卖出纪律，高优先级触发即执行，不再看低优先级。**本技能不重复定义五级的触发阈值与条件，一律以 `garp-exit` 输出为准。**（`GER-4`）

| 优先级 | 触发条件 | 决策 | 本技能落位 |
| :--: | --- | --- | --- |
| **1 诚信否决** | 管理层诚信问题暴露、财务造假实锤、监管立案 | **立即清仓**，不考虑估值与趋势 | 第六步承诺追踪 / 第七步附注 |
| **2 硬止损** | 单笔亏损达 **8%~10%** 且无明确基本面反转信号 | **止损离场** | **欧奈尔维度**专项（更新止损位） |
| **3 逻辑止损** | 连续 **2 个季度**业绩低于预期且产业景气未改善；财务不可逆恶化（应收暴增 / 存货高企 / 现金流持续为负）；龙头地位被颠覆 / 科研转化大幅低于预期；管理层或科研转化评分**跌破 10 分**（非诚信事项） | 减仓或清仓 | **本期财报直接核对**（核心触发点） |
| **4 产业景气判断** | 渗透率 / ROE 拐点但**景气尚可、仅节奏放缓**（如进入 40%~60% 逐步兑现期）→ 减机动仓降仓位；**增速归零 / 转负 → 升级为逻辑恶化、清仓** | 按景气方向调仓 | **郑希维度**（ROE / 二阶导 / 渗透率） |
| **5 估值判断** | 调整后 PEG**>1.5 高估区** → 减机动仓；**PEG>2 严重透支 → 加速清机动仓**；市场情绪极度狂热（多信号共振）→ 减机动仓 | 底仓不动，机动仓调整 | **林奇维度**（估值档位） |
| **补充机制**（不占优先级） | **时间止损**：持有满 **4 个季度（1 年）**逻辑仍未兑现 → 减至观察仓或替换；**性价比替换（末位优化）**：其他标的估值显著更低且产业趋势更强可逐步切换，**每季度最多 1 次** | 兜底 / 优化 | 本节兜底核对 |

**止损分仓位口径**（框架行 528~539）：

- **「建仓初期」** = ①持仓 < 最终仓位 50%，**或** ②持仓 ≥50% 但逻辑尚未经 2~3 季财报持续兑现验证（**任一成立**即适用 **8%~10% 硬止损**）
- **底仓已建立且逻辑已验证**（须**同时满足** ①达到最终仓位 50% ②逻辑经 2~3 季兑现）→ 下跌 **≤20%** 且多维未恶化可在合理估值下限加仓；**>20%** 转入「暂时性困难 vs 永久性衰退」清单复核（**费雪维度**主责）
- **无论何种状态，逻辑被证伪立即清仓，不存在「越跌越买」**

**传导纪律**：**任一优先级命中 → 报告第十节标注「命中级别 + 建议动作」并强制转接 `/garp-exit`**；本技能**只核对、不重排、不裁量**（`GER-4`）。一票否决的**买入前 / 持仓后语境**区分照引 `garp-exit`（买入前闸门如 ROIC<5% 扩产 / 矩阵「回避档」→ 建仓前放弃，**不入五级卖出表**）。

> **止损链口径**：ATR 止损价为建议工具，由 `garp-exit` 转接权威实现（`atr(period=14)` / `multiplier=2.0`），**本技能不自建止损公式、不自建止损链、不调用该链 CLI**。

### 第十一步：底仓 / 机动仓分离 + 「假如空仓」测试 + 季度复盘

#### 11.1 仓位结构与上限

在报告中必须明确当前仓位结构：

- **底仓（股票仓位的 60%~80%）**：定位长线核心，赚企业 1~5 年成长的钱；**不因短期 20% 以内波动卖出**；仅在**五级第 1 级（诚信否决）/ 第 3 级（逻辑止损）/ 补充机制（性价比替换）**触发时调整。
- **机动仓（股票仓位的 20%~40%）**：定位平滑波动，赚估值波动的钱；**统一六档进入「高估 / 严重透支」**时减持；**五级第 2 级（硬止损）**触发时优先砍机动仓。
- **现金占「总资产」**：中性 / 复苏常态 **10%~20%**（估值分位 >80% 时提至 20%~30%）。

**仓位红线（硬编码，含宏观调档）**：

| 宏观阶段 | 单只 初始 / 验证后 / 绝对 | 单一行业 |
| --- | --- | --- |
| 中性 / 复苏 | ≤10% / ≤15% / ≤20% | ≤40% |
| 衰退 | ≤8% / ≤12% / ≤15% | ≤30% |
| 过热 | ≤8% / ≤12% / ≤15% | ≤25% |
| 滞胀 | ≤6% / ≤10% / ≤12% | ≤20% |

- **宏观阶段定稿由 `garp-macro` 完成**，本技能**不判阶段**，只消费 `stage` / `calibrate` 出口参数（`GER-9`）。
- **再平衡**：每季度末一次，偏离目标 **±5%** 触发。

#### 11.2 分批建仓规则（左侧 / 右侧主从关系，框架行 394~415）

- **常态三分法**：1/3 首仓 → 右侧确认后补至 2/3 → 连续 2~3 季兑现后补齐。
- **左侧布局**：仅适用「**杀估值**」而非「**杀逻辑**」；首批 **≤ 该标的最终仓位的 50%**（**可建上限、非必须比例**；越不确定越压低），剩余待右侧信号确认后补齐。
- **右侧重仓**：一次性建 2/3、剩余 1/3 回调至 20 日均线补——**仅当三信号共振**（渗透率突破 15% 临界点 + 财报连续 2 个季度超预期 + 行业景气明确上行）方可；**常态仍按三分法**。
- **核心原则**：左侧仅适用「**杀估值**」；**杀逻辑必须离场**。

#### 11.3 左侧布局 vs 右侧重仓策略对照

| 维度 | 左侧布局（逆向） | 右侧重仓（顺势） |
|------|-----------------|-----------------|
| 触发信号 | 行业短期利空但长期逻辑未破坏，估值处于**显著低估 / 低估**档 | 渗透率突破关键临界点、财报连续 2 季度加速 |
| 仓位策略 | 分批建仓，总仓位控制在最终目标的 50% 以内 | 可一次性建 2/3 仓位，剩余 1/3 留作机动 |
| **止损纪律** | **按框架仓位状态分水岭执行**：属「建仓初期」→ **8%~10% 硬止损优先于补仓**；底仓已建立且逻辑验证后 → 可容忍至 **20%**，>20% 转「暂时性困难 vs 永久性衰退」复核 | 同上（**不按跌幅数字自设阈值**） |
| 核心心态 | 承受波动，赚估值修复 + 业绩增长的钱 | 享受泡沫，赚业绩加速 + 估值提升的钱 |

#### 11.4 「假如空仓」测试（每季度必做）

- 如果现在让你空仓，你会以当前价格买入这家公司吗？
  - **会买** → 继续持有，甚至加仓。
  - **不会买** → 考虑减仓或清仓。
  - **犹豫不决** → 减仓至观察仓，等待更清晰的信号。
- **理由必须具体**（如「调整后 PEG 1.8 落在高估档」「ROE 二阶导连续 2 季为负」），**不得以框架术语含糊搪塞**。

#### 11.5 季度复盘检查清单（**7 + 1 项必查**）

| 序号 | 检查项 | 本期结论 |
| :--: |------|---------|
| 1 | 管理层承诺兑现情况 | ✅ / ❌ / ⚠️ |
| 2 | 科研转化进展（如适用） | 节点达成 / 滞后 |
| 3 | 资本配置效率（ROIC / 增量 ROIC vs WACC） | 提升 / 下降 |
| 4 | 治理结构变化（高管 / 股权） | 稳定 / 动荡 |
| 5 | 地缘政治与国产化变化 | 升级 / 缓和 |
| 6 | 侧面验证（产品 / 客户 / 渠道） | 正向 / 负向 |
| 7 | 综合评分更新（**统一六档 / 管理层 7+7+6 / 科研转化 8+8+4**） | 档位与分值变化 |
| **8** | **费雪维度**（销售组织 / 管理层持股 ≥3% / 暂时性 vs 永久性 / 「绝不卖」前提） | 达标 / 不达标 / 自评项 |

## 注意事项

1. **档位隔离红线**——本技能只服务 GARP 独立档（1~5 年）；**禁止使用**其他档位的命令名、档位开关与层级编号体系；档位切换类口令在本技能中出现即违反口径隔离纪律；
2. **读原文，不读摘要**——尽一切可能获取一手资料，避免依赖二手信息；A 股**必须先完成财报 PDF 下载**（`GER-10`）；
3. **看变化，不看绝对值**——趋势比数字本身重要，价值成长尤其关注增速变化；
4. **听语气，不只听内容**——管理层怎么说和说了什么一样重要，警惕语气从「清晰」转向「模糊」；
5. **查附注，不只看正文**——魔鬼藏在细节里：研发资本化率、关联交易、或有负债、收入分部；
6. **给结论，不做汇总**——精读的目的是形成判断，不是复述财报；**五问缺一即不合格**（`GER-1`）；
7. **数据验证**——关键数据必须至少来自两个独立来源，误差 >1% 须标记；使用 `financial_rigor.py` 验算，**禁止 LLM 心算**；
8. **呈现两面**——每个核心判断都必须附带反面论据；
9. **网络搜索时效性**——使用 `--time-range month/week` 限制时间范围，优先获取最新信息；
10. **非境内上市双源验证**——港股 / 美股须按市场双源验证（港股 doubao+tavily；美股 exa+doubao）；
11. **每期必答核心问题**——景气逻辑是否被验证？五级卖出是否触发？这两个问题不能回避；
12. **轻量版定位**——本技能为**单 Agent** 快速精读；如需团队化深度精读与发布级产出，使用 `garp-earnings-team`（**仅名称指向**）；
13. **引用不重复定义**——估值档位 → `garp-valuation`；卖出与止损 → `garp-exit`；渗透率 / 国产化率 / 产业景气 → `garp-industry-research`；地缘矩阵 → `garp-geo-policy`；管理层 / 科研转化 / ESG → `garp-management`；宏观 → `garp-macro`；买入前提 → `garp-investment-checklist`；组合层 → `garp-portfolio-review`；论文健康度 → `garp-thesis-tracker`；二阶导 → `qoq-accelerator`；技术面 → `trend-momentum-scan`；
14. **止损纪律优先**——当估值「便宜」与第 1 / 第 2 级止损信号冲突时，**止损优先于估值**；
15. **「假如空仓」测试**——每次输出报告结论前，必须完成此测试，克服沉没成本；理由必须具体；
16. **`--depth` 语义**——本技能为单 Agent 轻量版，`--depth` 控制**精读颗粒度**（`fast` / `standard` / `deep`），**不改变 Agent 数量**；
17. **自评项须标注**——费雪补充检查、暂时性困难 vs 永久性衰退判定、资料可得性 A/B/C 评级、「绝不卖」前提均须标注「**自评项，非工具化判据**」；
18. **GARP 口径红线**——禁止使用其他档位的术语与编号体系；持有周期以「**1~5 年**」为准，**不得**表述为无期限封仓或永久持有。

## 局限性

1. **资料可得性**：部分公司的完整财报原文可能难以获取，导致评级为 B 或 C 级；
2. **扫描版 PDF 限制**：A 股年报常为扫描版 PDF，可能无法提取文本内容，影响附注分析；
3. **语言限制**：非中英文财报可能无法准确解读；
4. **非实时数据**：工具获取的数据可能有延迟，不是实时数据；
5. **AI 解读局限**：AI 无法完全替代专业财务分析师的深度分析能力；
6. **景气判断不确定性**：ROE 趋势与增速二阶导是**滞后指标**，可能无法提前捕捉拐点；
7. **渗透率 / 国产化率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算，按 A/B/C 三级置信度标注；**无 CLI 出口，按来源人工核验**；
8. **地缘数据更新频率**：制裁清单、出口管制、关税、政策与基金名录等变化较快，**属时变项，须实时核验，不得沿用历史快照**；
9. **0.3 矩阵无量化系数**：框架只给定性档位与「投资含义」，**运行期不得发明系数**；
10. **主观自评项无工具化判据**：费雪补充检查、暂时性困难 vs 永久性衰退判定、资料可得性评级、「绝不卖」前提为主观判断，报告中已标注；
11. **跨币种折算能力受限**：`fx_rate.py` 仅取汇率，折算由 `financial_rigor.py calc` 显式完成并标注汇率时点；
12. **不构成投资建议**：本技能仅用于学习与研究，不构成任何投资建议。

### 附录B：一页纸操作备忘卡（GARP 版，含宏观校准）

**【前置判断】**

- 资料可得性 A/B/C 评级；A 股**先下载财报 PDF**，下载成功后方可精读
- 地缘倒逼强度 / 政策覆盖度 / 国字号基金介入 → **0.3 三维交叉矩阵档位照引 `garp-geo-policy`**（未列组合按更审慎相邻档归档；国字号注资不作买入估值依据）
- 赛道类型：**地缘倒逼型**（地缘倒逼强度为「低 / 无」→ 不得建仓）vs **政策资本驱动型**（豁免该硬门槛，敞口仍须体检）

**【本期财务（五门槛 + 三表）】**

- 营收 ≥10 亿；最近三年营收复合增速 ≥15%；资产负债率 <60%；经营现金流为正；最近 3 年内 ≥2 年扣非净利润为正
- **科技豁免**：营收连续增长 + 经营现金流为正 + 研发强度 ≥15%
- 三表：经营现金流 / 净利润 ≥100% 为佳；应收 / 存货周转是否恶化；有息负债与现金结构

**【盈利趋势】**

- ROE 向上是科技股最可靠的「重力加速度」；二阶导判**定性趋势**（不设自造阈值，三态引 `qoq-accelerator`）
- 渗透率：<5% 观察不建仓 / 5%~15% 小仓跟踪 / **15%~40% 主建仓窗** / 40%~60% 持有不新建 / >60% 不加仓，增速归零或转负即见顶清仓
- 国产化率：<5% 过早 / 5%~20% 从 0 到 1 / 20%~50% 加速投资 / >50% 替代空间收窄

**【估值（按公司类型选锚，收口统一六档）】**

- **快速增长型**：主锚**调整后 PEG（GARP PEG）**——中性环境 <1.0 低估、1.0~1.2 合理、1.2~1.5 合理偏贵（持有不加仓、机动仓择机减）、**>1.5 高估**
- **高研发投入型**：PS / EV-Sales 低于同业可比，**Rule of 40 ≥ 40**
- **未盈利科技型**：PS / EV-Sales + 研发管线 NPV，需有清晰盈利路径与里程碑
- **稳定增长型**：当前 PE ≤ 未来 3 年 EPS 复合增速 × 1.2（隐含 PEG ≤1.2）；**成熟型**：市值 ≤ 保守 DCF 的 80%
- **四级留痕**：基准档位 → 宏观校准后 → ESG 折价后 → 最终档位
- **宏观 PEG 合理买入区间**：加息 / 高利率 0.8~1.0；中性 1.0~1.2；降息 / 低利率 1.2~1.5；滞胀下探至 0.8；**PEG>2 严重透支红线不因降息取消**
- **ESG 折价**：高环境风险 8~9 折；可验证转型路径收窄至 ≤5% 或豁免；搁浅资产风险贴现率额外上调 1~2 个百分点；ESG 评级行业尾部**先降仓位上限**

**【仓位】**

- 三分法：1/3 首仓 → 右侧确认补至 2/3 → 连续 2~3 季兑现后补齐；左侧首批 ≤ 最终仓位的 50%（仅适用「杀估值」）；右侧重仓 2/3 仅当**三信号共振**（渗透率突破 15% + 财报连续 2 季超预期 + 行业景气上行）
- 单只初始 ≤10% / 验证后 ≤15% / 绝对 ≤20%（衰退 ≤8 / ≤12 / ≤15；过热 ≤8 / ≤12 / ≤15；滞胀 ≤6 / ≤10 / ≤12）；单一行业 ≤40%（衰退 ≤30 / 过热 ≤25 / 滞胀 ≤20）
- 底仓（股票仓位的 60%~80%）长持，机动仓（股票仓位的 20%~40%）做估值波段；现金占总资产常态 10%~20%
- 每季度末再平衡一次，偏离目标 ±5% 触发；每季度做一次「假如空仓」测试

**【卖出（按五级优先级，引 `garp-exit`）】**

- 一级：管理层失信 / 财务造假实锤 / 监管立案 → **立即清仓**
- 二级：硬止损 **8%~10%** 且无基本面反转信号 → 止损离场
- 三级：连续 2 季业绩低于预期 / 财务不可逆恶化 / 龙头地位被颠覆 / 管理层或科研转化跌破 10 分（非诚信事项）→ 减仓或清仓
- 四级：渗透率减速或 ROE 拐头但景气尚可 → 减机动仓；**增速归零 / 转负 → 升级为逻辑恶化、清仓**
- 五级：调整后 PEG **>1.5** → 减机动仓；**>2 严重透支 → 加速清机动仓**
- **永久性衰退判断**（六个判断维度）：需求被替代、壁垒消失、研发持续削减 → **无论盈亏立即清仓**
- **费雪「不卖」的适用边界**：仅限极度深研的杰出企业且满足极度集中前提；否则一律服从上述纪律

**【补充机制（不占优先级）】**

- 时间止损：满 **1 年（4 季度）**逻辑未兑现 → 减至观察仓或替换
- 性价比替换：发现估值更低、趋势更强的标的 → 逐步替换（**每季度最多 1 次**）

**【止损分仓位口径（框架行 528~539）】**

- **建仓初期**（持仓 < 最终仓位 50%，**或** 持仓 ≥50% 但逻辑未经 2~3 季兑现验证）→ **8%~10% 硬止损优先于补仓**
- **底仓已建立且逻辑已验证**（**同时满足** 达到最终仓位 50% + 逻辑经 2~3 季兑现）→ 下跌 ≤20% 且多维未恶化可在合理估值下限加仓；**>20%** 转「暂时性困难 vs 永久性衰退」复核
- **逻辑被证伪立即清仓，不存在「越跌越买」**

**【风控】**

- 闲钱投资：资金期限 ≥ 持有期 + 至少 1 年安全垫
- 每期复盘持仓逻辑 + 行业景气 + 地缘政治 + 估值水位 + 宏观阶段（月度宏观提醒锚点：PMI <50 持续 → 人工复核；10 年期国债利率方向变化 → 人工复核）
- 组合最大回撤目标 ≤20%，接近目标时优先减机动仓、提高现金（底仓仅在逻辑证伪时退出）
- **宏观校准**：先由 `garp-macro` 定稿阶段 → 动态调 PEG 合理买入区间、现金仓位、单只上限
