# GARP 组合管理（1~5 年）：从「研究公司」到「管理组合」

对 $ARGUMENTS 执行 GARP 组合审视。本技能属**组合层（第 5 步·组合管理与再平衡）编排型技能**——**不研究个股、不做估值、不定义卖出级别**，只消费上游结论并对组合做「**合规校验 + 调仓建议**」。

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

> "如果你有 40 个妻子，你永远不会了解她们中的任何一个。" —— 巴菲特
>
> "分散化是保护无知者的。对知道自己在做什么的人来说，分散化没有意义。" —— 芒格

**支持输入格式**：

- `{持仓清单}` — **比例形态**（如 `A 20% / B 15% / C 12% / 现金 53%`）或**数量+成本形态**（如 `A 1000 股 @120 元`）
- `{持仓清单} 底仓=A,B 机动仓=C` — **显式标注**底仓/机动仓归属（**优先于**规则推断，门禁 A-1）
- `{持仓清单} 阶段=过热` — **显式指定**宏观阶段（仅在 `macro_calibrator.py data` 软判定 `manual_review=true` 时使用）

> **本技能不提供档位切换参数**——它即 GARP 独立档专属入口，命令与输入中不含任何档位切换开关；档位切换类口令属 1~3 年中期链，在本技能中出现即违反**口径隔离**纪律（见「边界声明」第 8 条）。

## 参数说明（持仓清单 / 底仓标注）

| 参数 | 形态 | 示例 | 说明 |

## 设计理念与定位（第 5 步·组合管理与再平衡）

大多数投资者的流程是：研究 → 买入 → 祈祷。**组合层是最容易被忽略、却最能决定长期结果的一环**——即使每一只标的单独看都合格，组合仍可能因**单一行业过度集中、流动性不足、ESG 尾部风险、宏观反向、相关性同向共振**而被一次冲击击穿。

本技能把《中长期价值成长（GARP）投资框架》**第三部分「仓位管理与组合纪律」**与**第五部分·四「宏观适配」**合成为一张可执行的组合体检与调仓表：

**解析持仓（两层口径）→ 分离校验（底仓/机动仓）→ 逐只逐行业上限校验（三档四档 + ≤2 只名额）→ 四类组合层专有校验（相关性 / 流动性 / ESG 降档 / ATR 关联）→ 宏观调档（只读工具值）→ 五级卖出预检（优先于再平衡）→ 压力测试（对 ≤20% 回撤目标判定）→ 调仓建议与报告。**

### 本技能的五条硬纪律（GP-1 / GP-2 / GP-3 / GP-4 / GP-8）

| # | 纪律 | 原因 |
| --- | --- | --- |
| 1 | **诚信否决前置，命中即清仓** | 一级（诚信）否决 → 该标的**直接给清仓建议**，**不进入**权重优化与再平衡（`GP-1`） |
| 2 | **五级卖出优先于再平衡** | 命中 `garp-exit` 五级任一即处置，**不受 ±5% 阈值束缚**；不得以「偏离未达阈值」延后（`GP-2`） |
| 3 | **两层口径不得混用** | 底仓/机动仓为**股票仓位内部**切分，现金为**占总资产**；每个百分比须**显式标注口径**（`GP-3` / `GP-9`） |
| 4 | **绝对档名额受限** | 单只三档校验 + **上浮至绝对 20% 的标的合计 ≤2 只**；名额超限即为不合规（`GP-4`） |
| 5 | **ESG 先降档、再宏观、取更严** | 顺序固定「**先 ESG 降档 → 再宏观收紧 → 取二者更严者**」；上限值**只读透传**，禁自行估算（`GP-8`） |

## 边界声明（本技能的核心约束）

1. **不做个股深度研究**——不重估内在价值、不重做估值、不写个股论文；只**引用**上游结论（`GP-15`）。
2. **不重算止损价、不重定义卖出纪律**——五级级别与阈值归 `garp-exit`（P4-6）；止损价**一律**取 `momentum.stop_price()` 内联调用结果（`GP-11`）。
3. **不重定义估值档位**——统一六档归 `garp-valuation`（P4-5）；本技能只读水位值（`GP-12`）。
4. **不判定宏观 stage、不自行估算降档幅度**——`stage` / `calibrate` 与 `position_cap_after` 均**只读透传**（`GP-5` / `GP-8`）。
5. **不做地缘矩阵与国产化率重算**——归 `garp-geo-policy`（P4-1）；本技能仅引用。
6. **不伪造数值**——相关系数**无工具**，只能**定性 + 反证清单**，**禁止**写出伪造的相关系数（`GP-6`）。
7. **不新增工具、不建聚合器**——本技能是**编排层**；全部数值来自既有工具与已交付 `garp-*` 技能的实测输出。
8. **运行时零引用其他档位**——本文件禁止出现 1~3 年中期链 / 10 年长期链的**可执行口令**（命令名、档位开关、其组合文件名、其层级编号体系）；引用只指向 `garp-*` 与复用 2 技能；**不修改**既有组合审视技能（门禁 H-1）。

> **范围自查**：本技能若出现「跳过诚信检查 / 命中五级却以 ±5% 未达为由延后 / 现金与股票内部切分混用 / 自造相关系数 / 自算止损价或调用 `momentum.py` CLI / 自造行业或单只上限档位 / 估算 ESG 降档幅度 / 用宏观做清仓理由 / 输出个股研究结论 / 写入其他档位的组合文件」，即为越界。

## 模式 A：组合合规校验（A1~A7）

### A1 持仓解析与两层口径

1. **解析形态**：比例形态直接取占比；数量+成本形态须经行情快照（`stock_quote.py`）与 `fx_rate.py` 折算为**占总资产占比**（`GP-12`：占比一律经 `financial_rigor.py calc`）。
2. **口径显式化（刚性）**——报告必须**分行**呈现两层，**禁止裸写百分比**：

| 层级 | 口径 | 建议范围 | 当前值 | 判断 |
| --- | --- | --- | --- | --- |
| 底仓合计 | **占股票仓位** | 60%~80% | | |
| 机动仓合计 | **占股票仓位** | 20%~40% | | |
| **股票仓位小计** | 占股票仓位 | **恒为 100%** | | |
| 现金 / 类现金 | **占总资产** | 常态 10%~20%；风险期 20%~30% 或更高 | | 取 `calibrate` 下限 |
| **合计** | 占总资产 | **100%** | | |

3. **执行顺序（刚性）**：① 先按宏观 / 风险预算确定**现金占总资产**比例 → ② 剩余部分再按**底仓 / 机动仓**切分（框架行 450）。
4. **底仓/机动仓归属判定**（门禁 A-1，按优先级）：
   - ① **用户显式标注**（`底仓=…` / `机动仓=…`）→ 以标注为准，**不重判**；
   - ② **无标注 → 规则推断**（报告中标注「**推断**」）：论文健康度 ≥7 **且** GARP 六档 ∈ {**显著低估 / 合理**} → **底仓候选**；GARP 六档 ∈ {高估 / 严重透支} **或** 论文健康度 <5 → **机动仓**（触发减持提示）；卫星/试探性小仓位（≤8%）→ **机动仓**；
   - ③ 归属依据须**逐只留痕**（标注 / 推断 + 判据来源）。
5. **缺项标注**：占比、成本、现金口径缺失者**留空并标注「缺项」**，不得以推测填充。

## 注意事项

1. **两层口径是最高频误用点**——底仓 60%~80% / 机动仓 20%~40% 是**占股票仓位**内部切分，现金是**占总资产**；两者**不得相加、不得混算**（`GP-3` / `GP-9`）；报告中**每个百分比都必须标注口径**。
2. **执行顺序刚性**——**先定现金（占总资产）→ 再切分股票内部（底仓 / 机动仓）**（框架行 450）；顺序颠倒会导致合计数失真。
3. **绝对档名额易被忽略**——单只 ≤20% **不等于**可以有多只 20%；**上浮至绝对 20% 的标的合计 ≤2 只**（`GP-4`）。
4. **行业上限是四档不是单一 40%**——随宏观收紧至 30% / 25% / 20%；档位**只读** `macro_calibrator`，**不得自行发明**（`GP-5`）。
5. **相关性只能定性**——工具链无相关系数计算，**禁止伪造数值**（`GP-6`）；须给出「同向共振风险清单」与**反证清单**；「未验证」不等于「合规」。
6. **流动性先折算后比较**——港股 `amount` 为**港元**、美股为**美元**，须经 `fx_rate.py` 折算为人民币后再与 1 亿阈值比较（`GP-7`）；小市值放宽须**显式标注**且注明「框架未定义小市值口径」。
7. **ESG 与宏观的叠加顺序不可颠倒**——**先 ESG 降档 → 再宏观收紧 → 取更严者**（`GP-8`）；上限值**只读透传**，不得自行估算折价率。
8. **ATR 止损价禁止自算**——权威是 `momentum.stop_price()`（**内联模块调用**）；`momentum.py` **CLI 静默失效**（`--help` 无输出、退出码 0），**禁用**（`GP-11`）。
9. **五级优先于再平衡**——命中五级任一即处置，**不得**以「偏离未达 ±5%」为由延后（`GP-2`）；诚信否决命中者**不进入**再平衡（`GP-1`）。
10. **压力测试必须对 ≤20% 回撤目标给出判定**（达标 / 接近 / 超限），判定为接近或超限时须给出**提高现金比例**的建议（`GP-14`）。
11. **取数失败 ≠ 合规**——标「**未验证**」「**无法判定**」，**不得**按合规通过处理；整体结论须降级说明（`GP-15`）。
12. **不替用户决策**——本技能只输出**合规判定与调仓建议**，决策权在用户；报告须含免责声明（`GP-15`）。
13. **三档组合文件物理隔离**——本技能只读写 `reports/portfolio-garp-*.md`；**不得触碰** 1~3 年 / 10 年档的组合文件（门禁 G-1 / H-1）。

## 局限性

1. **无法替代人工决策**——合规判定只能给出「是否越限」与「建议方向」，最终买卖由用户决定（`GP-15`）。
2. **相关性只能定性**——工具链不含相关系数计算，相关性结论**不具备量化精度**，**不得**被当作精确风险度量（`GP-6`；缺口归 P5-2 / P4-23）。
3. **「小市值」阈值框架未定义**——放宽至 >3000 万元的适用对象需**用户显式确认**，本技能**不臆造**阈值。
4. **宏观 stage 为软判定**——`data` 子命令输出 `manual_review=true`；未确定前**不输出调档后的上限**，只输出中性档并标注「未调档」。
5. **美股行情连通性受限**——`stock_quote.py --daily` 参数形态已确认，但数据源连通性不稳定（沙箱内缓存写受限 / 沙箱外超时），可能降级为「流动性未校验」；缺口归 P5-2。
6. **ESG 与宏观上限为上游工具口径**——本技能**只读透传**；上游结论有误将直接传导。
7. **数值阈值的粗糙性**——60%~80% / 20%~40% / 10%~15%~20% / 40%~30%~25%~20% / ±5% / 1 亿元 / 3000 万元 / ≤20% 均为框架给定的**区间与量级**，不构成精确择时工具。
8. **不构成投资建议**——本技能仅用于学习与研究，不构成任何投资建议。
