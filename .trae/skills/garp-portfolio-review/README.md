# garp-portfolio-review — GARP 组合管理（1~5 年独立档）

> **技能命令**：`/garp-portfolio-review {持仓清单}`
> **所属档位**：GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔）
> **开发任务**：P4-8（组合管理层技能；开工门禁 A~H 全部按推荐确认）
> **版本**：1.0.0（2026-09-17）

---

## 一、技能用途

### 一句话定位

把《中长期价值成长（GARP）投资框架》**第三部分「仓位管理与组合纪律」**与**第五部分·四「宏观适配」**合成一张可执行的组合体检与调仓表：

**解析持仓（两层口径）→ 底仓/机动仓分离校验 → 逐只逐行业上限校验（三档 + ≤2 只名额 / 行业四档）→ 四项组合层专有校验（相关性 / 流动性 / ESG 降档 / ATR 关联）→ 宏观调档（只读工具值）→ 五级卖出预检（优先于再平衡）→ 压力测试（对 ≤20% 回撤目标判定）→ 调仓建议与报告。**

本技能是**组合层（第 5 步·组合管理与再平衡）编排型技能**——**不研究个股、不做估值、不定义卖出级别**；它只消费上游结论，做「**合规校验 + 调仓建议**」。

### 何时用

- **定期组合审视**——季度末检查集中度、上限与再平衡触发；
- **买入新标的前的组合校验**——容量、名额与行业上限是否允许；
- **股价异动 / 黑天鹅后**——集中度、相关性与流动性复核；
- **宏观阶段切换后**——现金下限与单只 / 行业上限收口；
- **ESG 尾部风险事件后**——仓位上限下调与叠加校验；
- **单只越限时**——调仓建议与「最该做的一件事」；
- 给出**组合整体健康度四档**结论（优秀 / 良好 / 需要调整 / 问题严重）。

### 何时不用

| 场景 | 应使用的技能 |
| --- | --- |
| 个股深度研究与买入决策 | `garp-investment-research`（P4-12）/ `garp-investment-team`（P4-13） |
| 买入前门槛检查（能力圈 / 财务五门槛 / 三档结论） | `garp-investment-checklist`（P4-3） |
| 估值档位判定（贵不贵 / 建仓节奏） | `garp-valuation`（P4-5） |
| 卖出执行与止损价 | `garp-exit`（P4-6） |
| 论文建档与季度体检 | `garp-thesis-tracker`（P4-7） |
| 管理层与科研转化评分 / 诚信闸门 | `garp-management`（P4-4） |
| 买入前地缘 / 政策闸门 | `garp-geo-policy`（P4-1） |
| 财报全文精读 | `garp-earnings-review`（P4-14）/ `garp-earnings-team`（P4-15） |
| 纯技术面体检（相对强度 / 均线破位） | `trend-momentum-scan`（复用 2 技能） |
| 未上市公司研究 | `garp-private-company-research`（P4-20） |

## 二、适用口径与隔离声明

- **适用口径**：本技能属 **GARP 独立档（1~5 年，五大师）**，介于项目既有「1~3 年景气投资」与「10 年护城河投资」两档之间。
- **隔离声明**：
  1. 本技能**不引用** 1~3 年档位与 10 年档位的任何技能口径；其层级体系与本技能的五级体系**物理隔离**；
  2. 估值水位**只来自** `garp-valuation`（P4-5，GARP 档）的**统一收口六档**，本技能零 PEG 算式；
  3. 卖出层级为「**一级 ~ 五级**」，**只引用** `garp-exit`（P4-6）的定义，不重定义、不使用其他档位的层级编号体系；
  4. 产出文件为 `reports/portfolio-garp-{YYYYMMDD}.md`，**与 1~3 年 / 10 年档的组合文件物理隔离**、互不覆盖；
  5. 上限与现金档位**只读** `macro_calibrator.py` 与 `governance_data.py esg` 出口，本技能不自行估算；
  6. 复用类技能仅限全档位通用的 2 个（`qoq-accelerator`、`trend-momentum-scan`），其出口转接见《证券AI中长期价值成长（GARP）投资研究工作步骤》§一·1.1；
  7. **不修改**既有组合审视技能；本技能为**独立目录技能**（门禁 H-1）。
- **本技能不提供档位切换参数**——它即 GARP 独立档专属入口；档位切换类口令属 1~3 年中期链，出现即违反口径隔离纪律。

## 三、命令与报告路径

```bash
/garp-portfolio-review {比例形态持仓清单}
/garp-portfolio-review {数量+成本形态持仓清单}
/garp-portfolio-review {持仓清单} 底仓=A,B 机动仓=C
/garp-portfolio-review {持仓清单} 阶段=过热 现金=15%
```

| 输入项 | 说明 |
| --- | --- |
| `{持仓清单}` | 比例形态（`A 20% / B 15%`）或数量+成本形态（`A 1000 股 @120 元`） |
| `底仓=…` / `机动仓=…` | **显式归属标注**，优先于规则推断（门禁 A-1） |
| `阶段=…` | 宏观阶段人工指定（仅工具软判定 `manual_review=true` 时用） |
| `现金=…` | 现金**占总资产**比例（`GP-3` / `GP-9`） |

**报告输出**：

```
reports/portfolio-garp-{YYYYMMDD}.md        # 组合审视报告（同日多次加 -v2 / -v3）
```

> **保留全部历史文件，不删除不覆盖**（门禁 G-1）。

## 五、快速示例（最小可用调用）

### 例：季度末组合审视

```bash
/garp-portfolio-review 腾讯 18% / 新易盛 12% / 紫金矿业 10% / 现金 15% 底仓=腾讯,新易盛 机动仓=紫金矿业
```

执行要点：

```bash
# 0) 日期基准（三日期标注；GP-13）
Get-Date -Format 'yyyy-MM-dd HH:mm:ss'

# 1) 行情 / 技术面 / 止损价权威（内联调用，禁用 CLI）
python tools/a_share/stock_quote.py --code 300502 --momentum
python tools/hk_stock/stock_quote.py --code 00700 --start 20260821 --end 20260917

# 2) 财务与先行指标（--advanced 为带值参数）
python tools/a_share/stock_financial.py --code 300502 --advanced 合同负债,存货,研发费用
python tools/hk_stock/stock_financial.py --financial 00700

# 3) 跨币种折算（先折算后比较；GP-7）
python tools/common/fx_rate.py --code HKDCNY

# 4) ESG 降档（先 ESG；GP-8）
python tools/specialized/governance_data.py esg --env-risk-level 高 --stranded-asset --esg-tail

# 5) 宏观调档（stage 一次 + calibrate 逐只；门禁 C-1）
python tools/specialized/macro_calibrator.py stage --stage 复苏
python tools/specialized/macro_calibrator.py calibrate --stage 复苏 --peg 1.3 --current-cash 15 --single-stake 12

# 6) 精确算术（零心算；GP-12）
python tools/common/financial_rigor.py calc --expr "..."

# 7) 只读上游结论（六档 / 健康度 / 五级定义）
#    reports/{标的}/{标的}-garp-valuation-{YYYYMMDD}.md
#    reports/{标的}/{标的}-garp-thesis.md
#    garp-exit（P4-6）五级定义
```

## 六、关键口径速查

### 6.1 两层口径（**最高频误用点**）

| 层级 | 口径 | 范围 |
| --- | --- | --- |
| 底仓合计 | **占股票仓位** | 60%~80% |
| 机动仓合计 | **占股票仓位** | 20%~40% |
| 现金 / 类现金 | **占总资产** | 常态 10%~20%；风险期 20%~30% 或更高 |

> **执行顺序（刚性）**：① 先定**现金占总资产** → ② 剩余部分再按**底仓 / 机动仓**切分。两者**不得相加、不得混算**（`GP-3` / `GP-9`）。

### 6.2 上限档位

| 项 | 档位 |
| --- | --- |
| 单只上限 | 初始 ≤10% / 验证后 ≤15% / 绝对 ≤20% |
| 绝对档名额 | 上浮至绝对 20% 的标的合计 **≤2 只** |
| 行业上限（中性 / 复苏） | ≤40% |
| 行业上限（衰退） | ≤30% |
| 行业上限（过热） | ≤25% |
| 行业上限（滞胀） | ≤20% |
| 组合最大回撤目标 | ≤20%（压力测试须给出判定） |
| 持仓结构 | 5~10 只；**3~4 只**核心（12%~15%）+ **2~3 只**卫星（5%~8%） |

> 单只 / 行业上限的**宏观收紧档**与现金下限**一律只读** `macro_calibrator` 出口，本技能**不复制数字、不自行发明档位**。

### 6.3 四项组合层专有校验

| 校验 | 口径 | 纪律 |
| --- | --- | --- |
| **相关性** | <0.5 | **定性 + 反证清单**；**禁止伪造相关系数数值**（`GP-6`） |
| **流动性** | 日成交额 ≥1 亿元（小市值放宽 >3000 万） | 近 **20 个交易日**均值；跨币种**先折算后比较**；放宽须**显式标注**且注明「框架未定义小市值口径」（`GP-7`） |
| **ESG 降档** | 评级尾部 / 环境风险高 → **先下调仓位上限** | `position_cap_after` **只读透传**（`GP-8`） |
| **ATR 关联** | 止损价 = 买入价 − (2~3) × ATR(14) | 权威 = `momentum.stop_price()`（**内联调用**）；**禁用** CLI、**禁自行乘算**（`GP-11`） |

### 6.4 五级卖出预检（引用 `garp-exit`）

| 级别 | 触发（引用 P4-6 口径） | 本技能动作 |
| --- | --- | --- |
| **一级 · 诚信否决** | 失信 / 造假实锤 / 监管立案 | **清仓建议**；不进入再平衡（`GP-1`） |
| **二级 · 硬止损** | 单笔亏损 **8%~10%** 且无明确基本面反转信号 | 转 `garp-exit` 处置 |
| **三级 · 逻辑止损** | 连续 2 季低于预期且景气未改善 / 财务不可逆恶化 / 龙头被颠覆 / 评分跌破 10 分 | 转 `garp-exit` 处置 |
| **四级 · 产业景气判断** | 渗透率·ROE 拐点（景气尚可仅节奏放缓）/ 增速归零或转负 | 减机动仓 / 升级清仓 |
| **五级 · 估值判断** | 调整后 PEG > 1.5（> 2 严重透支）/ 情绪多信号共振 | 底仓不动，机动仓调整 |

> **五级卖出优先于再平衡**：命中即处置，**不受 ±5% 阈值束缚**（`GP-2`）；未检查级别标「**未检查**」。

## 九、常见误用提示

1. **两层口径混用是头号错误**——现金 15% 是**占总资产**，底仓 72% 是**占股票仓位**；把两者放进同一个分母汇总即为越界（`GP-3` / `GP-9`）。
2. **执行顺序不能颠倒**——必须先定现金（占总资产），再切分股票内部（框架行 450）。
3. **单只 ≤20% ≠ 可以多只 20%**——**上浮至绝对 20% 的标的合计 ≤2 只**（`GP-4`）。
