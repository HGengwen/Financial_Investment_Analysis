# 持仓动量体检：1-3年中期纯技术面趋势体检

对**已持仓**标的做纯技术面体检（SMR / RSI50 / MA50 / MA200 / 量能），判断趋势是否走坏并触发技术破位预警。与 `mid-trend-tech-screen`（选股正向排序）区分：`mid-trend-tech-screen` 回答「哪些股票值得买入？」，本技能回答「我手里的股票趋势还在吗？」。属于中期链（1-3 年）功能技能。

## 设计原则

1. **纯技术面体检，不掺基本面**：本技能只看动量与技术指标，基本面判断归 `qoq-accelerator`。
2. **只对已持仓标的**：输入非持仓标的应提示改用 `mid-trend-tech-screen`（选股正向排序）。
3. **大小比较硬编码，禁 LLM 心算**：SMR 百分位、RSI、均线位置、量比大小比较一律依据工具返回数值。
4. **MA200 破位为独立否决项**：股价 < MA200 必须判「趋势破位」，不直接映射单一 P 级，按仓位状态 + 量能走决策树后交 `exit-signal` 完整检查。

## 调用参数（技能调用约定，非新增命令行开关）

以下参数为技能调用时的解析约定，由 AI 解析并映射到既有工具调用与执行流程，**不新增任何 Python 命令行开关**（Sprint 2 零代码开发原则）：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `{持仓代码}` | 位置参数 | 是 | — | 持仓代码（单个，或逗号分隔批量列表） |
| `--benchmark` | 字符串 | 否 | 沪深300 | 基准指数（用于 SMR 相对强度计算；美股需指定，缺省 SPY） |
| `--lookback` | 整数 | 否 | 250 | 回溯交易日数（默认 250 ≈ 1 年） |
| `--export` | 标志 | 否 | false | 导出 Markdown 报告至 `reports/`（未开启则仅在对话内输出） |
| `--export-path` | 字符串 | 否 | reports/ | 报告输出根路径（配合 `--export` 使用） |
| `--json` | 标志 | 否 | false | 以 JSON 格式输出（供下游程序解析） |

**参数语义映射**：

- `--benchmark`：A 股经 `--auto-peers` 自动生成板块截面，忽略该参数；美股无自动截面时用该基准计算相对强度，缺省 SPY；港股默认无截面，按降级规则置 None 并标注缺口。
- `--lookback`：决定回溯交易日数，默认 250；<200 时 MA200 可能不可用，按 R-7 用 MA120 替代并标注。
- `--export`：未开启时仅在对话内呈现结论，不写文件；开启时按 `--export-path` 落盘。
- `--json`：开启时输出结构化 JSON（字段见「输出结果」节），关闭时输出 Markdown。

## 核心判定规则（硬编码）

### 规则 A：SMR / 绝对动量（双口径）

| 字段 | 语义 | 判定 |
| --- | --- | --- |
| `return_250d_pct` | 250 日涨幅（绝对动量） | ≥ 0 为正；< 0 为负 |
| `smr_percentile` | 板块内相对强度百分位（0–100） | **>70 强势 🟢 / 40~70 中性 🟡 / <40 弱势 🔴**；**None = 截面不可用** |

> **口径约定**：「SMR 正负」指 `return_250d_pct` 符号；`smr_percentile` 作为相对强弱辅助，None 时按降级规则处理。

**板块相对强弱（个股涨跌幅 vs 板块平均，`--auto-peers` 截面补充）**：

| 个股 vs 板块 | 判定 | 含义 |
| --- | --- | --- |
| 个股涨跌幅 > 板块平均 ×1.5 | 显著跑赢 | 个股有 α，继续持有 |
| 个股涨跌幅 > 板块平均 | 小幅跑赢 | 正常表现 |
| 个股涨跌幅 < 板块平均 | 跑输板块 | 个股相对走弱，需警惕 |
| 个股涨跌幅 < 板块平均 ×0.5 | 显著跑输 | 个股 α 消失，考虑替换 |

> SMR 百分位反映「过去 6 个月累计相对位置」，板块相对强弱反映「近期相对动量」；二者互补，SMR 高但近期跑输板块 → 标注「相对走弱需跟踪」。

### 规则 B：RSI50 超买超卖

| RSI50 | 状态 |
| --- | --- |
| > 70 | 超买 🟠（机动仓可部分止盈，不追高） |
| 50 ~ 70 | 偏强 🟢（动量健康） |
| 30 ~ 50 | 偏弱 🟡（关注是否跌破关键均线） |
| < 30 | 超卖 🔴（结合基本面判断是否逆势加仓） |

### 规则 C：MA50 / MA200 多空排列

| 排列 | 判定 |
| --- | --- |
| 股价 > MA50 > MA200 | 多头排列 🟢，趋势健康 |
| MA50 > 股价 > MA200 | 中性偏弱 🟡，短期均线已破 |
| 股价 < MA200（不论 MA50 位置） | 空头排列/破位 🔴，**独立否决项** |

**价格偏离度辅助**（股价 ÷ MA200）：>1.3 极度偏离 / 1.1~1.3 健康溢价 / 0.9~1.1 合理 / 0.7~0.9 深度折价 / <0.7 极度折价（需查基本面是否恶化）。

### 规则 D：破位预警阈值与 MA200 破位决策树

| 级别 | 触发条件 | 动作 |
| --- | --- | --- |
| 初级预警 | close < MA50 且放量（量比 > 1.5） | 减机动仓，观察 |
| 独立技术预警 | close < MA200 | **降级至观察仓**（不直接映射单一 P 级） |

**MA200 破位决策树**（融入「仓位状态」变量）：

```text
MA200 破位
├─ 建仓初期（持仓 < 最终仓位 50%）
│   ├─ 亏损 > 8% → 交 exit-signal P1 硬止损
│   └─ 亏损 ≤ 8% → 降级至观察仓，等待重新站上 MA200
├─ 底仓已建且三维度（产业/管理层/财务）未恶化
│   ├─ 缩量破位（量比 < 0.7）→ 给 1~2 周观察期
│   └─ 放量破位（量比 > 1.5）→ 机动仓减持 50%，底仓不变
└─ 任一维度恶化或逻辑证伪 → 立即交 exit-signal 完整检查/清仓
```

**预警解除条件**：观察期内股价**放量重新站上 MA200** → 解除预警，恢复原仓位；持续运行在 MA200 下方超 2 周且未站回 → 按放量破位处理，不再延长观察期。

### 规则 E：成交量辅助（欧奈尔抛售日）

| 信号 | 定义 | 影响 |
| --- | --- | --- |
| 放量上涨 | 量 > 5 日均量 ×1.5 且上涨 | 确认趋势 🟢 |
| 放量下跌 | 量 > 5 日均量 ×1.5 且下跌 | 风险信号，可能反转 |
| 缩量下跌 | 量 < 5 日均量 ×0.7 且下跌 | 抛压有限，可能洗盘 |
| 天量滞涨 | 量异常放大、股价不涨 | 危险信号，可能见顶 |

> 欧奈尔抛售日：放量下跌（量比 >1.5 且跌幅 >0.2%）记 1 个；一周内 ≥3 个抛售日 → 输出「抛售日预警」，建议大幅降低总仓位。

### 综合趋势判定矩阵

| 条件组合 | 综合评级 | 操作建议 |
| --- | --- | --- |
| SMR>70 且 RSI>50 且 股价>MA50>MA200 | 趋势健康 🟢 | 底仓+机动仓继续持有 |
| SMR>40 且 RSI>30 且 股价>MA200 | 趋势正常 🟡 | 底仓持有，机动仓观望 |
| SMR<40 或 RSI<30 或 MA50<股价<MA200 | 趋势弱化 🟠 | 底仓不变，机动仓减仓 |
| 股价<MA200（任一组合） | 趋势破位 🔴 | **降级至观察仓**（独立否决，见决策树） |

## 执行流程

### 第一步：解析输入，确认持仓标的

- 输入形态：持仓代码（单个或逗号分隔批量）。
- 确认标的为**已持仓**：非持仓标的提示改用 `mid-trend-tech-screen`。
- 运行 `date` 确认当天日期，作为报告「数据截止日期」基准。

### 第二步：收集动量数据

按市场选择行情工具，跑 `--momentum --auto-peers`：

| 市场 | 行情工具 |
| --- | --- |
| A 股 | `python tools/a_share/stock_quote.py --code {代码} --momentum --auto-peers` |
| 港股 | `python tools/hk_stock/stock_quote.py --code {代码} --momentum` |
| 美股 | `python tools/us_stock/stock_quote.py --code {代码} --momentum` |

### 第三步：解析字段

解析输出字段：`close`、`return_250d_pct`、`smr_percentile`、`rsi50`、`ma50`、`ma200`、`tech{close_above_ma50, close_above_ma200, volume_above_1_5x}`、`data_points`、`note`。

### 第四步：五规则判定 + 综合评级

按规则 A/B/C/D/E 逐项判定，再套综合趋势判定矩阵输出综合评级。

### 第五步：港股/美股 SMR 降级处理

港股/美股 `--auto-peers` 不自动生成截面，`smr_percentile` 置 None 并显式标注「板块截面不可用」，不静默使用错误数据。

### 第六步：联动映射

按「跨技能联动」节映射到 `exit-signal`、`valuation-thermometer`、`qoq-accelerator`。

### 第七步：输出报告

按「输出结果」节固定模板写入 `reports/{公司名}/`，并在报告头部注明数据截止日期。

## 工具软件使用指南

### 固化命令

```bash
python tools/a_share/stock_quote.py --code {code} --momentum --auto-peers
```

输出字段（已核实）：`close`、`return_250d_pct`、`smr_percentile`、`rsi50`、`ma50`、`ma200`、`tech{close_above_ma50, close_above_ma200, volume_above_1_5x}`、`data_points`、`note`。

### 港股/美股 SMR 截面降级路径（关键验收点）

| 市场 | `--auto-peers` 行为 | 要求 |
| --- | --- | --- |
| A 股 | 经 `sector_screen` 自动生成；sector 不可用时 `peers_source="sector_unavailable"` | 正常消费 |
| 港股 | `--auto-peers` **不自动生成**（需手动 `--peers`） | `smr_percentile` 置 None 并显式标注「板块截面不可用」 |
| 美股 | 同上（需手动 `--peers` / 指定基准） | 同上降级 |

降级规则：`smr_percentile = None` 时，技术面结论仅基于 `return_250d_pct`/RSI50/MA 排列，并在「不确定性标注」节显式声明 SMR 缺口。

### 关键约束

- 禁止 LLM 心算，大小比较一律依据工具返回数值；
- `tech` 字段为 None（数据不足）时须标注；
- 上市不足 200 交易日时 MA200 不可用 → 用 MA120 替代并标注。

## 跨技能联动（硬编码）

### 与 qoq-accelerator 交叉验证（量价背离）

| 技术面动量 | 基本面加速度 | 交叉判定 | 操作建议 |
| --- | --- | --- | --- |
| 🟢 健康/正常 | 🟢 正加速 | 量价齐升（最强确认） | 坚定持有 |
| 🟢 健康/正常 | 🔴 负加速 | 量价背离（危险） | 机动仓减持，关注下季确认 |
| 🔴 破位/弱化 | 🟢 正加速 | 量价背离（机会） | 结合估值判断是否被错杀 |
| 🔴 破位/弱化 | 🔴 负加速 | 量价齐跌（最弱确认） | **降级至观察仓或清仓** |

> 背离时以基本面加速度为准（盈利增长是最终驱动力）；背离持续 2 季以上触发 `mid-thesis-drift`。

### 与 exit-signal / valuation-thermometer / mid-thesis-drift 联动

| 本技能输出 | 目标技能 | 映射 |
| --- | --- | --- |
| 🔴 破位（放量，亏损>8%） | `exit-signal` P1 | 硬止损辅助确认 |
| 🔴 破位（叠加景气拐点） | `exit-signal` P3 | 景气拐点辅助确认 |
| 🔴 放量破位 | `valuation-thermometer` | 估值修正 **−0.5 档** |
| 🟢 连续 3 次体检健康 | `valuation-thermometer` | 估值修正 **+0.3 档** |
| 连续 2 次评级下降 | `mid-thesis-drift` | 触发逻辑漂移检测 |
| MA200 破位 + qoq 连续负加速 | `mid-thesis-drift` | 强制触发漂移检测 |
| SMR 从强势（>70）降至弱势（<40）且持续 ≥2 次 | `mid-thesis-drift` | 检查龙头地位是否被颠覆 |

> 修正幅度上限 **±1 档**。背离持续 2 季以上触发 `mid-thesis-drift`。

## 风控硬编码（不可被 AI 自由裁量）

| 编号 | 规则 | 强制执行动作 |
| --- | --- | --- |
| R-1 | MA200 破位独立否决 | 股价 < MA200 **必须**判「趋势破位」，无论 SMR/RSI 多高 |
| R-2 | 放量破位立即降级 | 股价 < MA200 且量比 >1.5 **必须**输出「降级至观察仓」，不给观察期 |
| R-3 | 建仓期止损优先 | 建仓初期（<50%）+ 亏损 >8% **必须**建议止损，不得「越跌越买」 |
| R-4 | 逻辑证伪立即清仓 | 破位 + qoq 连续 3 季负加速 **必须**建议清仓 |
| R-5 | 抛售日累计预警 | 一周内抛售日 ≥3 **必须**输出「欧奈尔抛售日预警」 |
| R-6 | 修正幅度上限 | 估值修正 ≤ ±1 档 |
| R-7 | 数据不足降级 | 上市不足 200 交易日 MA200 不可用 → 用 MA120 替代并标注 |
| R-8 | 禁止 LLM 心算 | 一律依据工具返回数值 |

**风控优先级**（高覆盖低）：R-4 逻辑证伪清仓 > R-3 建仓期止损 > R-2 放量破位降级 > R-1 MA200 独立否决 > R-5 抛售日预警。

**跨技能决策优先级（MA200 破位在 P0~P5 体系中的定位）**：

| 优先级 | 触发条件 | 决策 | 思想来源 |
| --- | --- | --- | --- |
| 第一（一票否决） | 管理层诚信/财务造假/监管立案 | 立即清仓，不看技术面 | 李进（治理） |
| 第二（硬止损） | 单笔亏损 8%~10%，或 MA200 放量破位 | 无条件止损 | 欧奈尔 |
| 第三（逻辑止损） | 连续 2 季业绩低于预期 / 持有满 4 季未兑现 | 减仓或清仓 | 林奇+郑希 |
| 第四（产业景气） | 渗透率减速 / ROE 拐头 / qoq 连续负加速 | 按景气方向调仓 | 李进+郑希 |
| 第五（估值判断） | 以上未触发，仅估值偏高或技术面弱化 | 底仓不动、机动仓调整 | 林奇 |
| 第六（技术面辅助） | 以上均未触发，仅动量信号变化 | 关注但不行动 | 欧奈尔（辅助） |

> 核心原则：先保命（防造假/止损），再谈收益（景气/估值）；技术面是辅助确认，不是独立决策依据——除非触发 MA200 破位硬性规则（R-1）。

## 检查频率约定

| 模式 | 时机 | 适用 |
| --- | --- | --- |
| 月度检查 | 每月初 | 常规持仓体检 |
| 季度检查 | 每季报发布后 | 结合 `qoq-accelerator` 全面体检 |
| 事件驱动 | 单日波动 >±5% 或周波动 >±10% | 异动后快速检查 |

## 注意事项

1. 开始前运行 `date` 确认当天日期，报告头部注明数据截止日期。
2. 只对**已持仓**标的体检，非持仓标的提示改用 `mid-trend-tech-screen`。
3. 港股/美股自动截面不可用，强制降级为 None 并标注缺口。
4. 禁止 LLM 心算，大小比较一律依据工具返回数值。
5. MA200 破位是独立否决项，不直接映射单一 P 级，须走决策树后交 `exit-signal` 完整检查。

## 局限性

1. 本技能是纯技术面体检，不掺基本面判断；基本面加速度归 `qoq-accelerator`。
2. 港股/美股无自动板块截面时 SMR 降级为 None，相对强弱维度缺失。
3. 技术指标基于历史价格，存在滞后性，不预测未来。
4. 上市不足 200 交易日的标的 MA200 不可用，用 MA120 替代并标注。
5. 本技能不承担买卖价位与估值判断，归 `valuation-thermometer`。

## 与其他Skill的关系

- **前置**：`mid-trend-tech-screen`（正向排序，选出持仓标的）、`valuation-thermometer`（建仓时机）。
- **后置**：`exit-signal`（本技能「MA200 破位」→ 独立技术预警 + P1/P3 辅助确认）、`mid-thesis-drift`（评级连续下降触发漂移检测）。
- **同级**：`qoq-accelerator`（基本面加速度，与本技能做量价交叉验证）。
- **边界**：与 `mid-trend-tech-screen` 分工明确（选股正向排序 vs 持仓体检），物理隔离。
