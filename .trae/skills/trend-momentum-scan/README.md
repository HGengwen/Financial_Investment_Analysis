# 持仓动量体检 (Trend Momentum Scan)

对**已持仓**标的做纯技术面体检（SMR / RSI50 / MA50 / MA200 / 量能），判断趋势是否走坏并触发技术破位预警。与 `mid-trend-tech-screen`（选股正向排序）区分：本技能回答「我手里的股票趋势还在吗？」。属于 1-3 年中期链功能技能。

---

## 快速开始

### 基本调用方式

```
/trend-momentum-scan {持仓代码}
```

支持批量输入（逗号分隔）：

| 输入方式 | 示例 | 说明 |
|---------|------|------|
| 单个持仓 | `/trend-momentum-scan 300502` | 单标的动量体检 |
| 批量持仓 | `/trend-momentum-scan 300502,601899` | 多持仓批量体检 |

例如：
- `/trend-momentum-scan 300502`
- `/trend-momentum-scan 00700 --benchmark 恒生指数 --export`

> 本技能只对**已持仓**标的执行；非持仓标的请改用 `/mid-trend-tech-screen`（选股正向排序）。

---

## 参数说明

> 以下为技能调用参数的解析约定，由 AI 按约定执行，**不新增任何 Python 命令行开关**。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `{持仓代码}` | 位置参数 | — | 持仓代码（单个 / 逗号分隔批量） |
| `--benchmark` | 字符串 | 沪深300 | 基准指数（美股 SMR 需指定，缺省 SPY） |
| `--lookback` | 整数 | 250 | 回溯交易日数（默认 250 ≈ 1 年） |
| `--export` | 标志 | false | 导出 Markdown 报告至 `reports/` |
| `--export-path` | 字符串 | reports/ | 报告输出根路径 |
| `--json` | 标志 | false | 以 JSON 格式输出 |

## 核心功能

对持仓标的执行「五规则判定 + 综合评级」，输出「趋势健康 🟢 / 正常 🟡 / 弱化 🟠 / 破位 🔴」四态结论与破位预警动作。

### 综合趋势判定矩阵（唯一权威口径）

| 条件组合 | 综合评级 | 操作建议 |
| --- | --- | --- |
| SMR>70 且 RSI>50 且 股价>MA50>MA200 | 趋势健康 🟢 | 底仓+机动仓继续持有 |
| SMR>40 且 RSI>30 且 股价>MA200 | 趋势正常 🟡 | 底仓持有，机动仓观望 |
| SMR<40 或 RSI<30 或 MA50<股价<MA200 | 趋势弱化 🟠 | 底仓不变，机动仓减仓 |
| 股价<MA200（任一组合） | 趋势破位 🔴 | 降级至观察仓（独立否决） |

### MA200 破位决策树（独立否决项，不直接映射单一 P 级）

```text
MA200 破位
├─ 建仓初期（持仓 < 最终仓位 50%）
│   ├─ 亏损 > 8% → 交 exit-signal P1 硬止损
│   └─ 亏损 ≤ 8% → 降级至观察仓，等待重新站上 MA200
├─ 底仓已建且三维度（产业/管理层/财务）未恶化
│   ├─ 缩量破位（量比 < 0.7）→ 给 1~2 周观察期
│   └─ 放量破位（量比 > 1.5）→ 机动仓减持 50%，底仓不变
└─ 任一维度恶化或逻辑证伪 → 立即交 exit-signal 完整检查/清仓
```

**预警解除**：观察期内放量重新站上 MA200 → 解除预警；2 周未站回 → 按放量破位处理。

## 工具依赖

| 用途 | 工具 | 关键参数 |
|------|------|---------|
| 动量/技术面 | `a_share/stock_quote.py` | `--code --momentum --auto-peers` |
| 港股行情 | `hk_stock/stock_quote.py` | `--code --momentum` |
| 美股行情 | `us_stock/stock_quote.py` | `--code --momentum` |
| 估值交叉验证（可选） | `financial_rigor.py implied-growth` | `--market-cap --target-pe --net-margin --ttm-revenue --guidance-growth` |

输出字段：`close`、`return_250d_pct`、`smr_percentile`、`rsi50`、`ma50`、`ma200`、`tech{close_above_ma50, close_above_ma200, volume_above_1_5x}`、`data_points`、`note`。

### 港股/美股 SMR 降级路径（关键约束）

| 市场 | `--auto-peers` 行为 | 处理 |
| --- | --- | --- |
| A 股 | 自动生成（sector 不可用时标注） | 正常消费 |
| 港股 | 不自动生成 | `smr_percentile` 置 None 并标注「板块截面不可用」 |
| 美股 | 不自动生成 | 同上降级 |

> 降级规则：`smr_percentile = None` 时，技术面结论仅基于 `return_250d_pct`/RSI50/MA 排列，并在报告显式声明 SMR 缺口，不静默使用错误数据。

## 核心原则

1. **纯技术面体检** — 不掺基本面判断（基本面归 `qoq-accelerator`）。
2. **只对已持仓标的** — 非持仓标的提示改用 `mid-trend-tech-screen`。
3. **MA200 破位独立否决** — 无论 SMR/RSI 多高，股价 < MA200 必判破位。
4. **禁止心算** — 大小比较一律依据工具返回数值。

---

## 注意事项

- 开始前运行 `date` 确认当天日期，报告头部注明数据截止日期。
- 港股/美股自动截面不可用，强制降级为 None 并标注缺口。
- MA200 破位是独立否决项，不直接映射单一 P 级，须走决策树后交 `exit-signal` 完整检查。
- 禁止使用 WebSearch / WebFetch 工具（中国大陆不可用），统一用本地搜索工具。

---

## 局限性说明

- 纯技术面体检，不掺基本面判断。
- 技术指标基于历史价格，存在滞后性，不预测未来。
- 港股/美股无自动板块截面时 SMR 维度缺失。
- 上市不足 200 交易日标的 MA200 不可用，用 MA120 替代并标注。
- 不构成投资建议，仅供学习研究参考。
