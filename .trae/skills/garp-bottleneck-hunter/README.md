# garp-bottleneck-hunter — GARP 供应链瓶颈猎手（1~5 年独立档）

> **技能命令**：`/garp-bottleneck-hunter {趋势名}`｜**所属档位**：GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔）
> **一句话定位**：从物理供应链的「咽喉位置」挖掘第二、第三层瓶颈机会，叠加 GARP 景气度（渗透率 `15%~40%` 黄金窗 / ROE 趋势 / 二阶导 / 订单能见度）与**国产化率四梯队**，经估值六档与 3 年隐含回报检查后输出**瓶颈机会观察名单**
> **开发任务**：P4-18｜**版本**：1.0.0（2026-09-19）

## 适用口径

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

**适用**：科技 / 医药 / 高端制造等景气成长赛道的供应链瓶颈机会发现；AI 基础设施、能源转型、半导体、创新药等需物理硬件 / 材料 / 设备的超级趋势；个人投资者 **1~5 年**持有周期标的的初筛。**不适用**：纯周期股（需周期估值）；困境反转股（需资产清算）；金融股（需 PB/ROE）；被动指数投资；短期交易 / 择时；未上市公司。

**口径隔离**：① 估值档位**只来自** `garp-valuation`（P4-5）的统一六档 + 多工具矩阵，零阈值定义、零重算；② 卖出级别**只来自** `garp-exit`（P4-6）的五级卖出 + 补充机制，不自建止损链；③ 地缘与国产化率**只来自** `garp-geo-policy`（P4-1）的 0.3 三维交叉矩阵 + 赛道两分法 + 国产化率四档，只读取回、不自评、不定档；④ 管理层**只来自** `garp-management`（P4-4），宏观**只来自** `garp-macro`（P4-2）且**只调参不择时**；⑤ 报告落 `reports/garp-bottleneck/`，与其他档位瓶颈报告目录互不覆盖、互不读取，**不写回任何上游文件**；⑥ **不提供任何档位切换参数**——它即 GARP 独立档（1~5 年）瓶颈猎手专属入口，档位切换类口令出现即违反**三档语域隔离**（`GBH-12`）。

## 核心功能

对指定超级趋势执行供应链瓶颈扫描与机会发现：从物理供应链的咽喉位置出发，找出那些没人注意、但一旦断货整个行业都得停下来等的公司，并判定该瓶颈是否处于 GARP 景气黄金窗、国产化率处于第几梯队。

**七步执行流程（+ 前置 A/B）**：

| 步骤 | 名称 | 核心动作 | 关键闸门 |
| --- | --- | --- | --- |
| 前置 A | 日期与市场确认 | `date` 定基准日；解析参数与扫描范围 | 趋势名含糊 → 反问 |
| **前置 B** | **地缘政策前置闸门（只读）** | `geo_policy_screen.py screen` 取 0.3 矩阵 + 赛道两分法 | **回避档 → 终止扫描**（`GBH-5`） |
| 一 | 超级趋势确认 | 五标准（含需求真实性）+ 渗透率五档 + 3 年复合增速（工具） | 证据不足 → 终止（`GBH-1`） |
| 二 | 供应链物理拆解 | Layer 0 → Layer 4；每个 Layer 2/3 环节标景气指标 + 国产化率梯队 | 拆到物理实体 |
| 三 | 瓶颈识别 + 景气 + 国产化率 | 六条标准 → S/A/B；景气四维叠加；**国产化率四梯队叠加** | 三要素齐备（`GBH-11`） |
| 四 | 公司筛选 | 八项初筛（含财务五门槛 / 科技豁免 / 能力圈自检）+ 深度模板（地缘只读 + 管理层只读） | 五门槛不过 → 淘汰（`GBH-3`） |
| 五 | 估值检查（**必做**） | 档位**只读** `garp-valuation` 六档 + **3 年隐含回报**（工具强制）+ 宏观只读 | 档位透支 → 不入名单（`GBH-4`） |
| 六 | 交叉验证 | 正向（含国产化率验证）/ 反向 / 信号 | 每结论 ≥2 独立信源（`GBH-9`） |
| 七 | 输出看板 + 准出 | 排名表 + 一页纸摘要 + 行动建议；落盘；跑 `report_audit.py` | 抽检不过不得发布（`GBH-9`） |

**物理分层**：`Layer 0 终端 → Layer 1 核心组件（定价充分，alpha 有限）→ Layer 2 子组件/材料（重点扫描区）→ Layer 3 上游设备/原料（重点扫描区）→ Layer 4 基础设施（电力/冷却/土地/人才/认证）`；每个 Layer 2/3 环节须标注「景气指标 + **国产化率四梯队档位**」（只读 `garp-geo-policy` 的 `localize`）。

**瓶颈判定 6 条标准**：供给集中度（≤2 家）/ 扩产周期（>2 年）/ 替代难度（不可替代）/ 产能利用率（>90%）/ 需求增速（>50%/年）/ 客户验证周期（>1 年）。**评级**：🔴 ≥4 个 = **S 级**（单点故障）；🔴 3 个 = **A 级**（严重受限）；🔴 1-2 个 = **B 级**（有压力可控）；无 🔴 = 非瓶颈，跳过。

**GARP 景气四维叠加**：① **渗透率位置**——`15%~40%` 黄金窗 → 加分，40%~60% → 减分，>60% → 判伪瓶颈，<5% 且无 EPS/订单 → 判题材（`GBH-2`）；② **ROE 趋势**——连续 3 季同向为准，向上加分、拐头向下 → 伪瓶颈信号；③ **二阶导**——正加分 / 负减分（主锚引用 `qoq-accelerator` 现有输出数值）；④ **订单能见度**——>6 月加分 / 3-6 月中性 / <3 月减分。综合评级 = 瓶颈评级（S/A/B）× 景气度（强/中/弱）× **国产化率梯队**；仅「瓶颈 S/A + 景气强 + 国产化率处第二/三梯队」进入重点扫描，景气度弱 → 标「**伪瓶颈**」不入名单（`GBH-3`）。

**国产化率四梯队叠加（核心差异）**：

| 梯队 | 国产化率区间 | GARP 判定 | 瓶颈叠加含义 |
| --- | --- | --- | --- |
| 第一梯队 | **<5%** | 过早（可观察 / 小仓不重仓） | 瓶颈真实但替代未起量，观察为主 |
| 第二梯队 | **5%~20%** | 突破期（跟踪 / 小仓） | 瓶颈 + 替代起点，重点跟踪 |
| 第三梯队 | **20%~50%** | 加速投资期（订单放量） | **瓶颈 + 替代加速共振，最高优先级** |
| 第四梯队 | **>50%** | 替代空间收窄 | 替代红利已兑现，须下调优先级 |

**叠加刚性（`GBH-11`）**：① 瓶颈地图与观察名单**每一条目**三要素齐备（瓶颈评级 + 景气度 + 国产化率梯队），缺一即不合格；② **梯队仅作排序 tie-break，不改写 S/A/B 评级**（维度正交：瓶颈看供给物理约束，国产化率看替代进程）；③ 定档只读 `garp-geo-policy` 的 `localize`，**不可得时标「未取得」，禁止推定**；④ 数值注明来源与年份，双源误差 >5pct 标低置信。

**存量更新（季度 / 月度增量更新，非每日扫描）**：检查瓶颈是否仍成立 → 扫最近 30 天供应链新闻与财报披露 → 复核渗透率档位 / ROE 趋势 / **国产化率梯队 / 地缘矩阵 / 估值档位**（重取不沿用）→ 更新 `master-map.md` 与 `watchlist.md`。

## 使用示例

### 示例 1：扫描 AI 基础设施供应链瓶颈

`/garp-bottleneck-hunter AI基础设施 --scope 全球 --depth standard --export` —— 拆解 GPU → 光模块 → 激光器 → InP 衬底的物理链条，定位 Layer 2/3 的 S/A 级瓶颈公司，叠加景气四维与国产化率梯队，输出含估值档位与 3 年隐含回报的观察名单。

### 示例 2：扫描创新药供应链瓶颈

`/garp-bottleneck-hunter 创新药 --depth standard --export` —— 拆解生物药生产 → CDMO → 培养基 / 层析树脂 / 病毒载体 / 预充注射器瓶颈，纳入渗透率（GLP-1 加速中、CAR-T 仍处早期）与二阶导指标，挖掘未充分定价的供应商。

### 示例 3：深度扫描（含在研项目扫描）

`/garp-bottleneck-hunter 半导体再工业化 --depth deep --export` —— 在标准扫描基础上追加 `in_research_scan.py` 在研重大项目扫描，并对候选做五维打分排序辅助。

### 示例 4：趋势名含糊 → 先澄清（不默默假设）

`/garp-bottleneck-hunter 新能源` —— 「新能源」跨度过大（光伏 / 风电 / 储能 / 核电 / 电网的瓶颈结构完全不同）。本技能**先反问**确认细分方向与扫描范围（如「储能电芯，还是电网变压器？」），确认后再启动七步流程；**不得**在未澄清时自行假设一个细分赛道。

## 输出报告

所有报告按**趋势名**分目录管理，路径基数为 `reports/garp-bottleneck/{趋势名}/`。

| 报告类型 | 文件路径 |
| --- | --- |
| 完整七步扫描 | `reports/garp-bottleneck/{趋势名}/full-scan/{趋势名}-garp-bottleneck-{YYYYMMDD}.md` |
| 月度 / 季度更新 | `reports/garp-bottleneck/{趋势名}/monthly/{趋势名}-garp-update-{YYYYMM}.md` |
| 瓶颈总地图 | `reports/garp-bottleneck/{趋势名}/master-map.md`（固定名，持续更新） |
| 观察名单 | `reports/garp-bottleneck/{趋势名}/watchlist.md`（固定名，含估值档位与卖出提示，持续更新） |
| 深度分析 | `reports/garp-bottleneck/{趋势名}/deep-dive/{代码}-{公司名}-garp-deep-{YYYYMMDD}.md` |

- **三档物理隔离**：文件名令牌固定 `-garp-bottleneck-` / `-garp-update-` / `-garp-deep-`；与其他档位瓶颈报告目录互不覆盖、互不读取（跨档路径对照见 `SKILL.md` 附录 C）。
- **多版本规则**：同日多次运行加 `-v2` / `-v3`，**不覆盖首版**；目录不存在则创建；历史文件保留不删除。
- **只读上游、不写回**：`reports/{公司名}/` 下的 `-garp-*` 文件**只读不写回**，本技能不修改任何上游文件。
- **四基准（报告头部必注明）**：

| 基准 | 内容 |
| --- | --- |
| **数据基准** | 各维度数据截止日期 + 渗透率 / 国产化率来源与年份 + 置信度（A/B/C） |
| **估值基准** | 估值档位来源（`garp-valuation` 结论日期）+「本技能不重算档位」声明 + 3 年隐含回报算式工具（`financial_rigor.py`） |
| **资料基准** | 扫描范围（`--scope`）+ 深度（`--depth`）+ 主要信源层级 + 搜索时间范围 |
| **口径基准** | GARP 独立档 1~5 年；渗透率 `15%~40%`；国产化率四梯队；地缘引 `garp-geo-policy`；估值引 `garp-valuation`；卖出引 `garp-exit` |

报告主体为 **11 节模板**：① 一句话结论 + 观察名单概览 → ② 前置闸门：地缘 0.3 矩阵结论（只读）→ ③ 超级趋势确认 → ④ 供应链物理拆解 → ⑤ **瓶颈地图（三要素齐备）** → ⑥ 公司深度筛选（逐家）→ ⑦ **估值检查**（只读六档 + 3 年隐含回报）→ ⑧ 交叉验证 → ⑨ **排名表 + 一页纸摘要** → ⑩ 行动建议 → ⑪ 信息缺口声明 + 四基准。

## 研究标准

**核心理念**：不问「AI 推荐什么股票」，问「哪一环会先不够用」。超额收益来源：第一层瓶颈（GPU、HBM、电力）已被充分定价，真正的 alpha 在第二层、第三层——光模块、激光器、InP 衬底、SOI 晶圆、外延设备、晶圆级测试、IC 载板、特殊玻纤等环节。**瓶颈真实 ≠ 投资机会**：须同时过景气关、国产化率关与估值关。

**瓶颈 6 条标准 / S-A-B 评级 / GARP 景气四维**：6 条标准判定供给物理约束，🔴 计数定 S/A/B；景气四维以渗透率 `15%~40%` 黄金窗为主锚，叠加 ROE 趋势（连续 3 季）、二阶导（`qoq-accelerator` 数值）、订单能见度；**景气度弱 → 伪瓶颈，不入名单**。

**国产化率四梯队（只读定档）**：`<5%` 第一梯队（过早）/ `5%~20%` 第二梯队（突破期）/ `20%~50%` 第三梯队（加速投资期，最高优先级）/ `>50%` 第四梯队（替代空间收窄）。**定档唯一权威为 `garp-geo-policy` 的 `localize`**，本技能只读取回、**不自评、不定档**，梯队仅作 tie-break 不改写 S/A/B（`GBH-11`）。

**估值六档（只读 `garp-valuation`）**：档位统一引用其**多工具矩阵 + 统一六档**（调整后 PEG / PSG / EV-Sales / Rule of 40 / 远期 PE + 隐含 PEG / DCF）+ ESG 折价 + 宏观校准后 PEG 区间。操作含义（只读映射）：显著低估 → 可建仓并按下限加底仓；低估 / 合理 → 建仓；**合理偏贵 → 持有不加仓、不新建仓**；高估 → 机动仓减持；严重透支 → 加速清机动仓、不纳入观察名单（`GBH-4`）。

> **辅助提示降级声明**：骨架承接的红 / 黄 / 绿灯条目**仅作辅助提示**，用于解释「为什么某标的档位值得复核」，**一律不构成档位判定**；档位一律以 `garp-valuation` 为准，冲突时亦以其为准。

**地缘 0.3 矩阵（只读 `garp-geo-policy`）**：口径唯一为 **0.3 三维交叉矩阵（地缘倒逼强度 × 政策覆盖度 × 国字号基金介入）+ 赛道两分法（地缘倒逼型 / 政策资本驱动型）+ 国产化率四档 + 敞口体检**。**前置 B 闸门**：矩阵归「回避」档 → **终止扫描**（`GBH-5`）；**地缘倒逼型**以「地缘倒逼强度非低 / 无」为**硬门槛**，**政策资本驱动型**仅作**敞口体检**（达标与否交政策与资本覆盖度维度判定）；**零自建评分**——不设任何自评维度打分表；地缘属**买入前**闸门，**不入五级卖出表**；时变项（制裁清单 / 出口管制 / 风险行业 / 国产化率）须**实时核验**，禁用历史清单。

**3 年隐含回报（GARP 档估值安全边际，必做）**：3 年后预计利润 × 合理远期 PE（渗透率越高 / 越接近兑现档，远期 PE 越低）折现至当前，隐含年化回报 **>25% 可建仓 / 15%~25% 一般 / <15% 等待更好价格**。本项为「**1~5 年档内 3 年窗口快筛**」，**不构成持有期定义**；**全部算术经 `financial_rigor.py`**（`calc` / `three-scenario --years 3` / `implied-growth` / `peg` / `adjusted-peg`），**禁止 LLM 心算**（`GBH-8`）。

## 质量标准

| 项 | 要求 |
| --- | --- |
| **双源交叉验证** | 关键数据 ≥2 独立来源，误差 >1% 显式标记；渗透率 / 国产化率按 A/B/C 三级置信度，双源误差 >5pct 标低置信（`GBH-9`） |

## 核心原则

1. **不让 AI 推荐股票，让 AI 拆供应链**（问题比答案重要）；2. **物理优先 + 景气叠加**（只关注需实际物理产品 / 材料 / 设备的环节，瓶颈真实 ≠ 投资时机）；3. **第二层、第三层**（不追已被充分定价的龙头）；4. **引用不重复定义**（估值 / 卖出 / 地缘 / 管理层 / 宏观只读 `garp-*`：零档位阈值、零止损链、零自评计分）；5. **国产化率叠加**（每一条目四梯队档位，定档只读、tie-break 不改写 S/A/B，`GBH-11`）；6. **三档隔离**（只读写 `reports/garp-bottleneck/`，不覆盖、不读取其他档位目录、不写回上游，`GBH-12`）；7. **交叉验证**（每个结论至少 2 个独立信源）；8. **诚实面对不确定性**（找不到数据就写「信息不足」，不用推测填充）；9. **瓶颈有时效性**（判断 **1~5 年**窗口内的时间价值）；10. **小市值 ≠ 好机会**（必须过财务五门槛或科技豁免）；11. **瓶颈真实 ≠ 投资机会**（估值是硬门槛：六档只读 + 3 年隐含回报）；12. **景气优先**（产能紧张但 ROE 掉头向下，是伪瓶颈）；13. **连续 3 季不靠单季**（ROE 趋势、二阶导、业绩兑现以连续 3 季同向为准）；14. **零新增 CLI**（只做调用编排，不改工具签名、不新增命令行开关）。

## 局限性说明
