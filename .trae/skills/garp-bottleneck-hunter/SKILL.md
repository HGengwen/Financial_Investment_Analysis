# 供应链瓶颈猎手（GARP 独立档·1~5 年）：从咽喉位置挖掘第二、三层机会

对 `$ARGUMENTS` 执行 GARP 供应链瓶颈扫描与机会发现。本技能属 **GARP 独立档（1~5 年）供应链瓶颈机会发现层**，回答「**哪一环会先不够用？这一环的国产化率处在第几梯队？它是否处在 GARP 景气黄金窗？当前价格是否具备安全边际？**」；**输出的是「观察名单」，不是「买入清单」**。

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

**支持输入格式**：

- `{趋势名}` —— 超级趋势名，如 `AI基础设施` / `创新药` / `能源转型` / `半导体再工业化`
- `{趋势名} --scope A股` —— 扫描范围（`全球` / `A股` / `港股` / `美股`）
- `{趋势名} --depth deep` —— 深度参数（`fast` / `standard` / `deep`）

> **本技能不提供任何档位切换参数**——它即 GARP 独立档（1~5 年）瓶颈猎手专属入口；档位切换类口令属其他档位口径，出现即违反**三档语域隔离**（`GBH-12`）。

## 五大师提醒

> 💬 **费雪式提醒**：「瓶颈公司『**能不能把产能卖出去**』比『能不能造出来』更关键——先看需求真实性（订单 / 收入 / 利润客观数据），再看销售组织健康度与管理层 **持股 ≥3%**；并把回撤区分为**暂时性困难**与**永久性衰退**。」
>
> 💬 **林奇式提醒**：「你买入的不只是『瓶颈概念』——你买入的是一家具体公司的生意。**瓶颈业务占比与纯正度**决定弹性，估值档位一律以 `garp-valuation` 统一六档为准。」
>
> 💬 **郑希式提醒**：「瓶颈的真实性必须由 **ROE 趋势**验证——如果一家公司坐在最紧的瓶颈上，但 ROE 在下降，说明瓶颈在松动或管理层在浪费机会，那叫**伪瓶颈**。」
>
> 💬 **欧奈尔式提醒**：「瓶颈逻辑再完美，如果股价已透支未来增长，当前价格也不是买点。**硬止损是你的生存红线**（阈值只读 `garp-exit`，不得自建）。」
>
> 💬 **李进式提醒**：「**渗透率突破 15% 后加速上行期重仓，进入 40%~60% 逐步兑现**；不仅看产业是否增长，更关注增速的加速度（**二阶导**）。」

## 设计原则

1. **物理优先 + 景气叠加**：从物理供应链找咽喉（Layer 2/3），但**瓶颈真实 ≠ 投资时机**，必须叠加 GARP 景气四维（渗透率 `15%~40%` 黄金窗 / ROE 趋势 / 二阶导 / 订单能见度）。
2. **第二层、第三层 alpha**：第一层瓶颈（GPU、HBM、电力）已被充分定价，真正的 alpha 在光模块、激光器、InP 衬底、SOI 晶圆、外延设备、晶圆级测试、IC 载板、特殊玻纤等环节。
3. **引用不重建（口径零复制）**：估值档位**只读** `garp-valuation`（P4-5，已交付）统一六档；卖出**只读** `garp-exit`（P4-6，已交付）五级；地缘与国产化率**只读** `garp-geo-policy`（P4-1，已交付）；管理层与科研转化**只读** `garp-management`（P4-4，已交付）；宏观**只读** `garp-macro`（P4-2，已交付）。本技能**不自建档位链、不自建止损链、不重新计分**。
4. **国产化率叠加不可省**：瓶颈地图与观察名单**每一条目**须三要素齐备（瓶颈评级 + GARP 景气度 + **国产化率四梯队档位**），缺一即该项不合格（`GBH-11`）。
5. **连续 3 季不靠单季**：ROE 趋势、二阶导、业绩兑现一律以**连续 3 季同向**为准。
6. **禁止 LLM 心算**：PEG / 调整后 PEG / 复合增速 / **3 年隐含回报** / 分位等一切算术经 `tools/common/financial_rigor.py`（`GBH-8`）。
7. **数据双源验证**：关键数据 ≥2 独立来源，误差 >1% 显式标记；渗透率 / 国产化率按 **A/B/C 三级置信度**标注，双源误差 >5pct 标**低置信**。
8. **输出观察名单，不是买入清单**：候选标的须再过 `garp-investment-checklist`（P4-3，已交付）**买入前七关硬门槛**方可建仓（`GBH-10`）。
9. **三档并存、物理隔离**：本技能只读写 `reports/garp-bottleneck/`；与其他档位报告目录**互不覆盖、互不读取**，且**不写回任何上游文件**（`GBH-12`）。
10. **零新增 CLI、引擎零改动**：本技能只做**调用编排**，不改任何工具签名、不新增任何 Python 命令行开关。

## 能力圈声明

**适用**：科技 / 医药 / 高端制造等景气成长赛道的供应链瓶颈机会发现；AI 基础设施、能源转型、半导体、创新药等需物理硬件 / 材料 / 设备的超级趋势；个人投资者 **1~5 年**持有周期标的的初筛。

**不适用**：纯周期股（钢煤航运，需周期估值）；困境反转股（需资产清算）；金融股（需 PB/ROE）；被动指数投资；短期交易 / 择时；未上市公司（另走未上市研究入口）。

> ⚠️ **重要提示**：本 Skill 仅做**瓶颈机会发现**，输出「**观察名单**」非「**买入清单**」。买入须执行 `/garp-investment-checklist`（P4-3）七关硬门槛；**组合层仓位数值裁决**归 `garp-portfolio-review`（P4-8），本技能只出**相对动作**。

## 执行流程（七步 + 前置 A/B）

| 步骤 | 名称 | 核心动作 | 关键闸门 |
| --- | --- | --- | --- |
| 前置 A | 日期与市场确认 | `date` 定基准日；解析参数与扫描范围；三档并存提示（只提示不修改） | 趋势名含糊 → 反问 |
| **前置 B** | **地缘政策前置闸门（只读）** | 调 `geo_policy_screen.py screen` 取 0.3 三维交叉矩阵 + 赛道两分法 | **回避档 → 终止扫描**（`GBH-5`） |
| 第一步 | 超级趋势确认 | 五标准（含需求真实性）+ 渗透率五档 + 3 年复合增速（工具） | 证据不足 → 终止（`GBH-1`） |
| 第二步 | 供应链物理拆解 | Layer 0 → Layer 4；每个 Layer 2/3 环节标景气指标 + **国产化率梯队** | 拆到物理实体 |
| 第三步 | 瓶颈识别 + 景气 + 国产化率 | 六条标准 → S/A/B；景气四维叠加；**国产化率四梯队叠加** | 三要素齐备（`GBH-11`） |
| 第四步 | 公司筛选（初筛 + 深度） | 八项初筛（含**财务五门槛 / 科技豁免 / 能力圈自检**）+ 深度模板（地缘只读 + 管理层只读） | 五门槛不过 → 淘汰（`GBH-3`） |
| 第五步 | 估值检查（**必做**） | 档位**只读** `garp-valuation` 六档 + **3 年隐含回报**（工具强制）+ 宏观只读 | 档位透支 → 不入名单（`GBH-4`） |
| 第六步 | 交叉验证 | 正向（含**国产化率验证**）/ 反向 / 信号 | 每结论 ≥2 独立信源（`GBH-9`） |
| 第七步 | 输出看板 + 准出 | 排名表 + 一页纸摘要 + 行动建议；落盘；跑 `report_audit.py` | 抽检不过不得发布（`GBH-9`） |

1. 运行 `date` 确认当天日期，作为「报告生成日期 / 数据截止日期」基准。
2. 解析参数并识别**扫描范围**（全球 / A 股 / 港股 / 美股），决定取数与搜索工具。
3. **三档并存提示**：同仓存在其他档瓶颈地图时**只提示不修改**（本技能不读取、不写回）。

### 前置 B：地缘政策前置闸门（只读）

- **回避档 → 终止扫描**（`GBH-5`），不进入后续七步；
- **地缘倒逼型** → 「**地缘倒逼强度非低 / 无**」为**硬门槛**（框架第 3 步·支柱四）；

- 结论不可得 → 改指框架**第0步·0.3** 与**第 1 步·国产化率分层**，报告标注「结论未取回」，**不新增技能**。

## 规则一：超级趋势确认（第一步）

### 1.1 趋势筛选标准（骨架承接 + 需求真实性新增）

| 标准 | 要求 | 验证方法 | GARP 独立档关注 | 大师锚点 |
| --- | --- | --- | --- | --- |
| 持续性 | 至少 3~5 年确定性增长 | 搜索行业预测、资本开支计划 | 聚焦其中 **1~5 年**景气兑现窗口 | 郑希 |
| 物理性 | 需要实际硬件 / 材料 / 设备建设 | 区分「软件升级」与「物理扩建」 | 物理瓶颈才有扩产周期约束 | 郑希 |
| 规模性 | 全球资本开支 > 500 亿美元/年 | 搜索头部玩家 capex 指引 | **TAM ≥ 1000 亿** | 李进 |
| 加速性 | 需求增速 > 供给扩产速度 | 对比需求增长 vs 产能扩张 | 供需缺口是瓶颈前提 | 李进 |
| **需求真实性（新增）** | 趋势须有**订单 / 收入 / 利润客观数据**支撑 | 检索最近 2~3 季财报与订单公告 | 无客观支撑 → **判题材**（`GBH-1`） | **费雪** + 李进 |

> 💬 **费雪式提醒**：「真实趋势必须有订单、收入、利润的客观数据支持，否则一律视为题材炒作——先问『**能不能卖出去**』，再问『能不能造出来』。」

### 1.2 渗透率黄金窗五档（`15%~40%`，框架第 1 步）

| 档位 | 渗透率区间 | GARP 判定 |
| --- | --- | --- |
| 萌芽档 | **<5%** | **过早**（无 EPS / 订单支撑 → 判题材，`GBH-2`） |
| 导入档 | **5%~15%** | 跟踪观察，小仓试探 |
| **黄金窗** | **15%~40%** | **加速上行期，重点扫描（主战场）** |
| 兑现档 | **40%~60%** | 逐步兑现，减机动仓 |
| 成熟档 | **>60%** | 减速区，**判伪瓶颈**（`GBH-3` 联动） |

- **TAM 门槛**：TAM ≥ 1000 亿。
- **未来 3 年复合增速**：经 `financial_rigor.py calc` 计算，**禁止心算**（`GBH-8`）。

### 1.3 当前跟踪的超级趋势清单

1. **AI 基础设施建设**；2. **能源转型**；3. **国防现代化**；4. **半导体再工业化**；5. **太空经济**；6. **生物药 / 创新药**。每次运行时更新；用户指定趋势则只聚焦该趋势。

### 1.4 趋势验证输出块

```text
趋势名称：/ 核心驱动力：
验证事件（≥3）：1.[日期][事件][来源] 2.… 3.（缺一否）→

TAM：XX 亿（是否 ≥1000 亿）
未来 3 年复合增速：XX%（financial_rigor.py calc）
趋势确认：✅ 可追踪 / ❌ 证据不足终止（触发 GBH-1）
```

## 规则二：供应链物理拆解（第二步）

### 2.1 Layer0~4 分层框架

```text
Layer 0（终端）→ Layer 1（核心组件，定价充分 alpha 有限）
→ Layer 2（子组件/材料，关注度低 alpha 集中区 → 重点扫描）
→ Layer 3（上游设备/原料，关注度低 alpha 集中区 → 重点扫描）
→ Layer 4（基础设施：电力/冷却/土地/人才/认证）
```

> **刚性**：拆到**物理实体**；每个 **Layer 2/3 环节**须标注「景气指标」+「**国产化率四梯队档位**」（只读 `garp-geo-policy` 的 `localize`）。

### 2.2 AI 基础设施拆解模板（GARP 化）

```text
Layer 2（重点扫描）：网络互联（光模块/光纤/交换芯片/铜缆）；光通信核心（激光器 EML/VCSEL/CW、调制器）；半导体材料（InP/GaAs 衬底、SOI/SiC 晶圆）；先进封装（CoWoS 载板、HBM TSV、ABF 基板膜）；PCB/载板（高频高速 PCB、IC 载板、特殊玻纤布）；测试（探针卡、老化测试、ATE）；散热冷却（液冷、CDU）；电力连接（母线槽、UPS、配电柜、变压器）
  境气指标示例：光模块渗透率（是否处 15%~40%）、衬底产能利用率（>90% 紧绷）、CoWoS 利用率、交期
Layer 3：外延设备（MOCVD/MBE）；光刻/刻蚀（特殊波长、InP 刻蚀）；原材料（高纯金属、特气、靶材）；认证标准（MSA、Telcordia）
Layer 4：电力（核电/天然气/输变电）；散热供水；数据中心土地/许可
```

### 2.3 创新药拆解模板（GARP 化）

```text
Layer 2（重点扫描）：生物药生产（生物反应器、培养基、层析树脂、过滤膜）；CDMO 服务；核心原料（抗体、病毒载体、连接子、毒素、核苷酸）；细胞治疗（培养基、分离设备）；基因治疗（AAV/慢病毒、质粒）；制剂包装（预充注射器、特种硼硅玻璃瓶）
  境气指标：生物药渗透率、CDMO 产能利用率、CAR-T 渗透率（<5% 萌芽）、GLP-1 渗透率（~3% 加速）
Layer 3：设备（生物反应器、层析、超滤）；原料（培养基组分、层析树脂原料）；认证（GMP、FDA/EMA/NMPA）
Layer 4：临床试验（患者/基地/CRO）；冷链物流；人才（生物工艺/GMP 工程师）
```

> 💬 **李进式提醒**：「创新药渗透率看『渗透率曲线』（已获批适应症覆盖速度）而非装机率。进入 **40%~60% 兑现档**时增速放缓；『二阶导』看每季新增患者数——累计渗透率上升但新增减少预示拐点。」

### 3.1 瓶颈判定 6 条标准（骨架承接，不改）

| # | 标准 | 🔴 高瓶颈 | 🟡 中等 | 🟢 低瓶颈 |
| --- | --- | --- | --- | --- |

### 3.2 GARP 景气度四维叠加（骨架承接 + 刻度替换）

| 景气维度 | GARP 独立档判断 | 大师锚点 |
| --- | --- | --- |
| **渗透率位置** | **`15%~40%` 黄金窗** → 加分；40%~60% → 减分；>60% → 判伪瓶颈；<5% 且无 EPS/订单 → 判题材（`GBH-2`） | 李进 |
| **ROE 趋势** | 连续 3 季同向为准；向上 → 加分；拐头向下 → 伪瓶颈信号 | 郑希 |
| **二阶导** | 正 → 加分；负 → 减分；**主锚引用 `qoq-accelerator` 的现有输出数值** | 李进 + 欧奈尔 |
| **订单能见度** | >6 月 → 加分；3-6 月 → 中性；<3 月 → 减分 | 郑希 |

**综合评级**：瓶颈评级（S/A/B）× 景气度（强/中/弱）× **国产化率梯队** = 综合优先级。仅「**瓶颈 S/A + 景气度强 + 国产化率处第二/第三梯队**」进入**重点扫描**；景气度弱 → 标「**伪瓶颈**」，不入名单（`GBH-3`）。

| 第二梯队 | **5%~20%** | **突破期**（跟踪 / 小仓） | 瓶颈 + 替代起点，**重点跟踪** |

## 规则五：估值检查（第五步，必做）

### 5.1 档位只读：`garp-valuation` 统一六档（共性 6，验收要点 3 联动）

> **口径刚性（`GBH-4`）**：估值档位唯一权威为 `garp-valuation`（P4-5，已交付）的**多工具矩阵 + 统一六档**（调整后 PEG / PSG / EV-Sales / Rule of 40 / 远期 PE + 隐含 PEG / DCF）+ **ESG 折价** + **宏观校准后 PEG 区间**。本技能**零档位阈值定义、零档位重算**。

- 档位**只读** `garp-valuation` 结论（含结论日期）；多工具矩阵 / ESG 折价 / 宏观校准区间均只读。
- **操作含义（只读映射）**：显著低估 → 可建仓并按下限加底仓；低估 / 合理 → 建仓；**合理偏贵 → 持有不加仓、不新建仓**；高估 → 机动仓减持；严重透支 → 加速清机动仓、**不纳入观察名单**（`GBH-4`）。
- 档位不可得 → 标「**未取得**」，**不得推定**（降级 #5）；3 年隐含回报仍按工具计算。

### 5.2 骨架辅助提示（降级为辅助，不构成档位判定）

> **降级声明（`GBH-4`）**：以下红 / 黄 / 绿灯条目**仅作辅助提示**，用于解释「为什么某标的档位值得复核」；**一律不构成档位判定**，档位**一律以 `garp-valuation` 为准**，冲突时以 `garp-valuation` 为准。

**辅助红灯（任意一条 → 信号强度封顶 ★★，标注「⚠️ 估值透支（辅助提示，非档位判定）」）**：① 市值 > TAM 20%；② PS > 30x 且收入增速 <100%（增速>100% 豁免）；③ 市值 > 5 年乐观收入 10 倍；④ 增发后 60 天内股价翻倍。

**辅助黄灯（需解释）**：亏损 + PS >15x；PS 为同行盈利公司 5 倍以上；PE >80x；档位处「合理偏贵」须解释增速覆盖。

**辅助绿灯（加分）**：PS <10x 且收入增长；PE <30x 且格局稳定；档位「显著低估」→ 林奇式绝佳买点；档位「低估 / 合理」→ 合理区间。

### 5.3 3 年隐含回报（必做，验收要点 3）

> **口径声明**：本项为「**1~5 年档内 3 年窗口快筛**」，**不构成持有期定义**；**不得**回退到 10 年长期口径（`GBH-12`）。**全部算术经 `financial_rigor.py`，禁止 LLM 心算**（`GBH-8`）。

```text
回答："以当前市值买入，3 年后以合理远期 PE 退出（渗透率越高/越接近兑现档，远期 PE 越低），隐含年化回报是多少？"
算法（financial_rigor.py calc / three-scenario --years 3 / implied-growth / peg / adjusted-peg）：
  1. 未来 3 年复合增速 = calc
  2. 3 年后净利润 = 当前净利润(TTM) × (1+复合增速)^3
  3. 合理远期 PE：15%~40% 黄金窗中高 PE；40%~60% 下修行业中枢；>60% 按行业中枢或以下
  4. 3 年后市值 = 3 年后净利润 × 远期 PE
  5. 隐含年化回报 = (3 年后市值/当前市值)^(1/3) - 1
判定（沿用骨架判定档）：>25% 可建仓 / 15%~25% 一般 / <15% 等待更好价格
```

## 仓位与买卖纪律（GARP 独立档）

**仓位结构分离（只读框架第三部分·二）**：底仓 60%~80%（赚 1~5 年成长钱，仅在基本恶化或档位越过透支线按 `garp-exit` 处理）；机动仓 20%~40%（赚估值波动钱，档位「合理偏贵」分批止盈）。**单只 ≤10%/15%/20%、单行业 ≤40%、持股 5~10 只**（组合层裁决归 `garp-portfolio-review`，`GBH-10`）。

**左侧 vs 右侧**：左侧（渗透率 <15%，档位「低估 / 合理」）→ 小仓试探越跌越买；右侧（渗透率突破 15%、连续 2 季加速）→ 一次性建 2/3、回调补齐；高潮 / 透支（渗透率 >60% 或档位「合理偏贵」以上）→ 只卖不买。

**分批建仓（1/3 → 1/3 → 1/3）**：进入合理买入区间先建 1/3；回调至区间下限以下加 1/3；景气加速或财报超预期后补齐 1/3。

**五级卖出（只读 `garp-exit`，不重建）**：

| 级别 | 触发条件（定义与阈值以 `garp-exit` 为准） | 决策 | 大师 |
| --- | --- | --- | --- |
| **一级 诚信否决（前置）** | 诚信问题 / 造假实锤 / 监管立案 | 立即清仓 | 费雪 |
| **二级 硬止损** | 单笔亏损达阈值且无基本面反转 | 止损离场（禁用自算 ATR） | 欧奈尔 |
| **三级 逻辑止损** | 连续 2 季业绩低于预期且景气未改善；财务不可逆恶化；龙头被颠覆；管理层 / 科研转化跌破阈值 | 减仓或清仓 | 林奇 + 郑希 |
| **四级 产业景气判断** | 渗透率 / ROE 拐点但景气尚可；或增速归零转负（升级逻辑恶化） | 减机动仓 / 清仓 | 李进 + 郑希 |
| **五级 估值判断** | 档位越过透支线；情绪多信号共振 | 底仓不动，机动仓调整 | 林奇 |

> **补充机制（与五级并列、不占优先级、不得写成第六级）**：**时间止损**（持有满约定季度逻辑未兑现 → 调仓）与**性价比替换**（其他标档位显著更优 → 切换）仅**五级全不触发**时执行；只读 `garp-exit`（`GBH-7`）。检查顺序固定 一级 → … → 五级，命中即停。

**止损 vs 越跌越买**：建仓初期（<50%）达硬止损阈值离场；底仓已建且逻辑完好属**暂时性困难** → 估值下限加仓；逻辑证伪属**永久性衰退** → 立即清仓；持有满约定季度横盘 → 时间止损。

**「假如空仓」测试**：若现在持有现金，以当前价格与基本面还会买吗？NO → 无论盈亏减仓或清仓。

## 五矛盾化解（对齐框架第五部分）

| 矛盾场景 | 冲突点 | 化解方案 |
| --- | --- | --- |
| 买点哲学 | 欧奈尔突破买 vs 林奇低估买 | 杀估值（档位「低估 / 显著低估」）→ 林奇左侧；杀逻辑（景气证伪）→ 欧奈尔止损 |
| 持有时间 | 郑希看 3 年 vs 欧奈尔看 3 月 | 连续 3 季向上 → 郑希持有；连续 2 季下滑 → 欧奈尔减仓 |
| 止损 vs 越跌越买 | 李进控回撤 vs 林奇逆向 | 仓位状态变量：建仓初期止损优先；底仓已建且景气未恶化 → 估值下限加仓 |
| 分散 vs 集中 | 李进分散 vs 郑希集中 | 行业分散（单行业 ≤40%），个股集中（单只 ≤20%），相关系数 <0.5 |
| **费雪「绝不卖」vs 趋势 / 景气纪律（新增）** | 费雪主张优质公司长期不卖，但 GARP 有景气拐点与估值纪律 | 以「**暂时性困难 vs 永久性衰退**」清单分界：暂时性困难（需求真实、销售组织健康、ROE 未拐头）→ 不因短期回撤卖出；永久性衰退（技术路线被替代 / 增速归零转负 / 诚信）→ 按 `garp-exit` 五级执行 |

## 存量更新（季度 / 月度增量更新，非每日扫描）

1. 检查瓶颈仍成立（新供应商？产能扩张？替代突破？）。

## 核心原则（最高优先级）

1. **不让 AI 推荐股票，让 AI 拆供应链**；2. **物理优先**（需实际物理产品 / 材料 / 设备）；3. **第二层、第三层**（不追已被充分定价龙头）；4. **国产化率叠加**（每条目标四梯队档位，`GBH-11`）；5. **三档隔离**（只读写 `reports/garp-bottleneck/`，不写回上游）；6. **引用不重复定义**（估值 / 卖出 / 地缘 / 管理层 / 宏观只读 `garp-*`）；7. **交叉验证**（至少 2 独立信源）；8. **诚实面对不确定性**（找不到就写「信息不足」）；9. **瓶颈有时效性**（判断 1~5 年窗口）；10. **小市值 ≠ 好机会**（过财务五门槛）；11. **瓶颈真实 ≠ 投资机会**（过估值关）；12. **景气优先**（ROE 掉 → 伪瓶颈）；13. **零新增 CLI**（只调用编排）。

1. **三档语域与文件隔离（`GBH-12`）**——GARP 独立档（1~5 年）；禁其他档位口令、编号体系、命令名、路径与文件名、长期链术语与长期退出倍数口径（禁用词表见「风控硬编码」）。

4. 禁 LLM 心算，一切算术经 `financial_rigor.py`（`GBH-8`）。
5. 渗透率 / 国产化率按 A/B/C 置信度；双源误差 >5pct 标低置信。
6. 禁 `WebSearch` / `WebFetch`（geo-blocking），统一用本地五工具。

9. 地缘一律 **0.3 三维交叉矩阵 + 赛道两分法 + 敞口体检**（只读），不自建维度评分（`GBH-5`）。

11. **国产化率叠加不可省**（`GBH-11`），三要素缺一不合格；梯队仅 tie-break，不改写 S/A/B。
