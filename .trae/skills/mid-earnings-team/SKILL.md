# 财报精读团队：四大师并行解读 + 公众号发布（1~3年景气投资版）

对 $ARGUMENTS 进行团队化 1~3 年景气投资视角的财报精读分析。四位景气大师并行解读财报，编辑润色成文，读者评审把关质量，最终产出可直接发布的公众号文章。

**支持输入格式**：`公司名 季度`，例如：`腾讯 2025Q4`、`PDD 2025年报`、`美团 最新`

> 本技能属**中期链（1-3 年）**，与长期链 `earnings-team`（10 年 / 段永平-巴菲特-芒格-李录）**物理隔离、功能互补**。禁止使用「护城河永续」「终局思维」「持有10年」等长期框架术语。

## 能力圈声明

本技能文件适用于 **1~3 年中长期投资框架下的财报精读与景气验证**，非短期交易工具，非「封仓十年」式超长期持有，也非日内/周级别波段交易。

**适用场景**：
- 科技/医药/高端制造/景气周期成长股等具备可持续成长性的公司财报精读
- 季度财报发布后的景气逻辑验证与卖出纪律更新
- 公众号/投研报告的深度财报分析文章产出

**不适用场景**：
- 纯周期股（用 PE/PB 估值，PEG 不适用）
- 困境反转股（PEG 不适用，需特殊框架）
- 金融股（资产负债表结构特殊，需单独评估框架）
- 被动指数投资
- 短期交易/日内波段

## 与段永平价值投资的关系说明

段永平问答技能主要针对证券市场长期投资（「封仓十年」式持有），其核心思想如「不预测宏观」「毛估估」「买股票就是买公司」等，与 1~3 年景气投资框架存在以下关系：

- **可借鉴的底层哲学**：「买股票就是买公司」「能力圈」「本分」等底层投资哲学可跨周期适用，在讨论「生意模式」「企业文化」「本分」等底层问题时，可调用段永平视角作为哲学补充。
- **不适用的操作层面**：段永平的「封仓十年不卖」「不预测宏观」「不择时」等核心操作思想不完全适配 1~3 年持有周期。本框架中，季度财报是景气验证的关键节点，卖出纪律有明确的 P0~P5 触发体系（引用 `exit-signal`），与「封仓不动」有本质区别。
- **定位**：段永平在本框架中仅作为「哲学补充」角色，不参与估值、择时、止损等操作层面的决策。

## 设计理念

在 1~3 年景气投资框架中，**每季度财报是验证投资逻辑的关键节点**：

1. **景气逻辑验证**：ROE 趋势是否持续？二阶导（增速加速度）是正是负？渗透率到哪了？
2. **卖出纪律更新**：本季度数据是否触发任何卖出条件？（P0~P5 优先级，引用 `exit-signal`）
3. **四个不同视角的深度解读**——不是只看数据，是看数据对景气周期的含义

本 Skill 的流程分三阶段：

- **阶段一·研究**：四位景气大师并行精读财报（林奇看生意与估值、郑希审 ROE 与景气、欧奈尔看风控底线、李进评组合管理与治理）
- **阶段二·合成**：Team Lead 综合四个视角，产出研究报告初稿，**重点回答「景气逻辑是否成立、卖出纪律是否触发」**
- **阶段三·发布**：编辑 Agent 改写为公众号文章 + 读者评审 Agent 提出修改意见 → Team Lead 定稿

**四位大师权威分工（对齐 `research/个人投资者1~3年中长期投资思想与理念 V2.0.md`）**：

| 大师 | 思维模式 | 在财报精读中的角色 |
|------|---------|-------------------|
| 林奇 | 侦探思维 · 常识与求证 | **生意与估值**：六类分类复核、生意常识验证、收入量价拆解、PEG 估值更新、估值陷阱排查 |
| 郑希 | 物理学家思维 · 周期与第一性原理 | **产业景气验证**：ROE 趋势/拐点、二阶导、渗透率位置、供需格局、景气卖出信号 |
| 欧奈尔 | 工程师思维 · 信号与纪律 | **风控底线**：趋势信号、止损位更新、机构动向、抛售信号、CAN-SLIM |
| 李进 | 系统工程师思维 · 均衡与渗透率 | **组合管理 + 治理**：管理层 20 分制、科研转化 20 分制、地缘政治六维度、治理一票否决、底仓/机动仓分离、决策优先级执行 |

> "机会来自生活常识，而不仅仅是数据表格。" —— 林奇（常识验证）
>
> "ROE 向上是科技股最可靠的'重力加速度'——只要这个趋势在，估值波动只是噪音。" —— 郑希（产业景气）
>
> "先想清楚亏多少，再想赚多少。8% 是普通投资者的生存红线。" —— 欧奈尔（风控底线）
>
> "用渗透率定位阶段，用二阶导监测拐点，用纪律保护本金。" —— 李进（系统均衡）

## 阶段一：四大师并行研究

### 第一步：获取一手资料

#### 1.1 A股财报原文下载（优先执行，必须完成）

**重要流程**：对于 A 股公司，必须首先使用 `stock_equity.py` 工具下载原始财报 PDF，**下载完成后方可进行下一步的阅读分析工作**。

```bash
# 下载最新年报PDF
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type annual

# 下载最新半年报PDF（如需分析半年报）
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type semiannual

# 下载最新季报PDF（如需分析季报）
python tools/a_share/stock_equity.py --code {股票代码} --download-report --report-type quarterly
```

下载的 PDF 文件保存在 `cninfo_reports/` 目录，文件命名格式：

- 年报：`{股票代码}_{年份}年报.pdf`
- 半年报：`{股票代码}_{年份}半年报.pdf`
- 季报：`{股票代码}_{年份}{季度}季报.pdf`

可使用 `--report-dir` 参数指定其他保存目录：

```bash
python tools/a_share/stock_equity.py --code 601899 --download-report --report-type annual --report-dir ./reports/紫金矿业
```

**流程检查点**：确认 PDF 文件下载成功后，方可启动后续的 4 个研究 Agent。

#### 1.2 PDF 文档阅读工具

下载的财报 PDF 文档提取文字与表格**首选** `tools/common/pdf_extract.py`（基于 pdf-inspector 库，支持自动乱码检测 + OCR 回退），返回失败（退出码非 0 / success=false / 扫描件）时才回退 Poppler 工具集：

**首选工具**：
```bash
# 分类检测 PDF 类型
python tools/common/pdf_extract.py detect cninfo_reports/002465_2025年报.pdf

# 提取含财务附表的 Markdown 并写盘
python tools/common/pdf_extract.py markdown cninfo_reports/002465_2025年报.pdf --save-md --out-dir reports/pdf

# 强制 OCR 提取（适用于 pdf-inspector 提取乱码时，如 Adobe-CNS1 繁体中文 PDF）
python tools/common/pdf_extract.py text cninfo_reports/688235_2025年报.pdf --force-ocr --ocr-langs chi_tra+eng
```

**回退工具（Poppler 工具集，仅当 pdf_extract.py 返回失败时使用）**：

```bash
# 查看PDF文件信息
pdfinfo cninfo_reports/002465_2025年报.pdf

# 将PDF转换为文本文件
pdftotext cninfo_reports/002465_2025年报.pdf cninfo_reports/002465_2025年报.txt

# 将PDF转换为图像（用于扫描版PDF）
pdftoppm -png cninfo_reports/002465_2025年报.pdf cninfo_reports/002465_2025年报
```

**注意事项**：

- 首选 `pdf_extract.py` 提取文字与表格；返回失败时才回退 Poppler 工具集（详见 [PDF文档内容提取技能](../tools-scripts/pdf-extraction.md)）
- `pdf_extract.py` 内置自动乱码检测，当 pdf-inspector 提取文本出现乱码（如 Adobe-CNS1 字体编码问题）且 tesseract OCR 可用时，自动触发 OCR 回退
- **繁体中文 PDF**（如百济神州）需使用 `--force-ocr --ocr-langs chi_tra+eng` 指定繁体中文语言包
- 全量 OCR 年报耗时较长，建议先 `detect` 确认页码，用 `--pages` 指定关键页提取
- 如果 PDF 无法提取内容，应在报告中标注「资料评级：B 级」，说明扫描版 PDF 限制

### 第三步：启动 4 个并行研究 Agent

使用 Task 工具在**同一条消息**中启动 4 个后台 Agent。

---

#### Agent 1：生意与估值解读（林奇视角）

**核心问题：这份财报揭示的生意本质——六类分类有变化吗？PEG 更新后是贵了还是便宜了？**

> 林奇："如果你花 10 分钟都解释不清一家公司是做什么的，那它的业务可能太复杂了。"
> 林奇："PEG 是我最喜欢的估值指标——但前提是你对增长率有把握。"

分析内容：

##### 1. 六类分类复核（林奇核心框架）

- 这家公司现在属于哪一类？**分类有变化吗？**
- 缓慢增长型 / 稳定增长型 / 快速增长型 / 周期型 / 困境反转型 / 隐蔽资产型
- **分类变化是卖出信号**：快速增长型变稳定增长型 → 可能触发估值重新定价

##### 2. 生意常识验证（本季度更新）

- 你或身边人在使用这家公司的产品吗？用户反馈有变化吗？
- 用户/客户价值在增强还是减弱？平台黏性变化？

##### 3. 收入结构拆解——「量」还是「价」

- 收入增长来自「量」（用户数/销量）还是「价」（提价）？
- 哪种更健康？「量增价稳」 > 「量价齐升」 > 「价增量减」 > 「量价齐跌」
- 各业务板块：哪些在加速、哪些在减速、哪些在恶化

##### 4. PEG 更新（GARP 核心）

- PEG = PE(TTM) ÷ 未来 2 年预期增速（%）
- **估值档位判定、边界约定与底仓/机动仓操作映射，一律以 `/valuation-thermometer` 输出为准，本技能不重复定义五档阈值**
- 执行时先调用 `valuation-thermometer` 取得 PEG 档位，再给出建仓/持有建议
- **对比上季度 PEG 变化方向**：变得更贵还是更便宜？
- **渗透率作为估值修正**：不再在 PEG 数值上自行加减，而是归郑希（Agent 2）「产业景气/渗透率位置」判断，由 Team Lead 合成时交叉比对

##### 5. 林奇式卖出信号检查

- 快速增长型公司：增速从 XX% 降到 XX%（连续 2 季度放缓 → 减仓信号）
- 稳定增长型公司：PE 是否已到历史区间上沿？
- 周期型公司：是否处于景气顶峰？

**输出要求**：六类分类结论，PEG 最新值及变化方向（引用 `valuation-thermometer` 档位），结合渗透率位置（郑希输出）交叉后的估值判断，林奇式总结点评。

---

#### Agent 2：ROE 与景气验证（郑希视角）

**核心问题：ROE 拐点到了吗？产业景气在什么位置？二阶导（增速加速度）是正是负？**

> 郑希："ROE 向上是科技股最可靠的'重力加速度'——只要这个趋势在，估值波动只是噪音。"
> 郑希："长期判断由无数短期客观判断拼接而成。一旦景气下行，果断调仓。"

分析内容：

##### 1. ROE 趋势分析（郑希核心）

- **本期 ROE** vs **上季度** vs **去年同期** vs **上上季度**
- 近 8 个季度 ROE 趋势：↑/→/↓（画趋势图）
- ROE 拐点判断：本轮 ROE 上行周期持续了多久？是否已见顶？
- ROE 向上的驱动因素：利润率提升/资产周转加速/财务杠杆增加？

##### 2. 营收增速二阶导（主锚引用 `qoq-accelerator`，本 Agent 仅作辅助判断）

- **本期营收增速** vs **上季度** vs **去年同期**
- 二阶导判断：
  - 正二阶导 = 增速在加快 → 估值扩张阶段
  - 负二阶导 = 增速在放缓 → 估值收缩信号
- **关键预警**：如果二阶导连续 2 季度转负 → 系统性减仓信号（景气拐点口径对齐 `exit-signal` P3）

##### 3. 产业景气位置判断（口径对齐 `mid-industry-research`）

- 渗透率当前在什么位置？（<5% 过早 / 5%~10% 萌芽 / **10%~30% 黄金区** / 30%~50% 成长期 / >50% 成熟期）
- 行业供需格局：供不应求 / 供需平衡 / 供过于求？
- 价格趋势：产品单价稳定、上涨还是下跌？

##### 4. 季度数据一致性检验

- 过去 4 个季度，每个季度的数据是否都在验证买入逻辑？
- 有没有哪个季度出现了偏离？偏离是暂时性的还是趋势性的？

##### 5. 郑希式卖出信号检查

- ROE 拐头向下且无合理解释 → 系统性减仓（对齐 `exit-signal` P3）
- 渗透率 >50% 且增速明显放缓 → 减机动仓
- 连续 2~3 个季度增速放缓 + 订单同步放缓 → 趋势性拐点确认

**输出要求**：ROE 8 季度趋势判断，二阶导正/负，渗透率位置，郑希式总结点评。

---

#### Agent 3：趋势信号与纪律更新（欧奈尔视角）

**核心问题：趋势信号如何？止损位需要调整吗？机构在买还是卖？**

> 欧奈尔："忘掉买入成本，忘掉'已经跌了这么多该反弹了'的幻想。市场不会因为你亏了钱就怜悯你。"
> 欧奈尔："8% 止损是生存红线。"

分析内容：

##### 1. 股价趋势判断

- 当前股价处于上升通道、盘整还是下跌通道？
- 本季度是否出现关键突破或跌破？
- 近 30 天是否有放量突破或放量下跌信号？

##### 2. 机构持仓动向

- 近几个季度机构增减持情况
- 北向资金/南向资金流向（如适用）

## 仓位管理框架（底仓/机动仓分离管理）

在财报精读后，Team Lead 必须在研究报告中明确仓位管理建议（由 Agent 4 李进视角输出），基于底仓/机动仓分离管理体系：

### 底仓（60%~80%）

- **定位**：长线核心，赚企业 1~3 年成长的钱
- **操作规则**：只要买入逻辑未被破坏（产业景气上行、管理层可信），始终保留。不因短期 20% 以内的波动而卖出。可每季度结合最新财报做小幅调整（±5%）
- **触发卖出**：仅 P0（治理一票否决）或 P2（逻辑止损）触发时卖出底仓

### 机动仓（20%~40%）

- **定位**：平滑波动，赚估值波动的钱
- **操作规则**：当股价进入高估区间（PEG>1.5 或估值分位>80%）时减持，回落至合理区间时回补。机动仓的操作不影响底仓的长期判断，能有效缓解心理压力
- **触发卖出**：P3（景气拐点）、P4（估值透支，PEG 档位引用 `valuation-thermometer`）触发时优先减持机动仓

### 分批建仓规则

- 当股价进入「合理买入区间」后，先建 **1/3 底仓**
- 若股价继续回调至合理区间下限以下，再加 **1/3**
- 确认产业景气加速或财报超预期后，补齐剩余 **1/3**
- 总仓位控制：单只个股初始 ≤ 总资产的 10%，逻辑验证后 ≤15%，绝对上限 ≤20%；单一行业不超过总资产的 40%

### 行业分散与个股集中

| 管理维度 | 具体规则 |
|---------|---------|
| **总持股数** | 5~10 只为宜。过少则非系统性风险过大，过多则跟踪精力不足 |
| **单只个股上限** | 初始建仓不超过总资产的 10%，随着逻辑验证后可提升至 15%，但不超过 20% |
| **单一行业上限** | 不超过总资产的 40%，避免行业黑天鹅导致组合崩溃 |
| **行业相关性管理** | 持有的行业之间相关系数 <0.5（例如：消费+科技+医药的搭配优于纯科技赛道内部的多只持仓） |
| **流动性管理** | 持有标的日成交额至少 >1 亿元（市值<100 亿的公司可放宽至 >3000 万），确保极端行情下能快速调整 |

## 四大核心矛盾与化解方案

四位大师的理念在四个关键维度上存在结构性矛盾。融合体系的关键不是消除这些矛盾（因为无法消除），而是建立清晰的决策优先级规则。

### 矛盾一：买点哲学的根本对立

| | 欧奈尔 | 林奇 / 郑希 / 李进 |
|------|--------|-------------------|
| **买点偏好** | 突破新高时追涨，杯柄形态突破是核心买点 | 下跌或拐点确认时买入：林奇在恐慌时逆向布局，郑希在 ROE 拐点确认后右侧介入，李进在渗透率加速初期重仓 |
| **对下跌的态度** | 股价下跌必有原因，绝不主动抄底 | 市场恐慌是买入优质公司的绝佳窗口 |

**化解方案——以「逻辑是否完整」为分水岭**：
- 若回撤源于**系统性恐慌**（如市场整体暴跌、行业短暂政策扰动），且**产业逻辑完好 + 管理层诚信 + 财务健康**三项均通过，则采用林奇的逆向策略，分批左侧布局。
- 若回撤伴随**基本面恶化**（连续 2 个季度业绩低于预期、ROE 拐头向下、管理层诚信问题），则按欧奈尔规则，不抄底，等待趋势明朗。
- **核心原则**：左侧布局仅适用于「杀估值」而非「杀逻辑」。杀估值可逆向，杀逻辑必须止损。

### 矛盾二：持有逻辑的时间维度冲突

| | 林奇 / 欧奈尔（部分） | 郑希 / 李进 |
|------|------|------|
| **持有时间** | 「好公司永远持有」，不主动择时卖出 | 每季度用景气数据检验，景气下行果断调仓 |
| **对「长期」的理解** | 以企业生命周期为尺度 | 以产业景气周期为尺度（1~3 年） |

**化解方案——底仓长持 + 机动仓季度调整**：
- 底仓（60%~80%）：采用林奇/欧奈尔的长期持有逻辑，只要买入逻辑未被破坏就不卖
- 机动仓（20%~40%）：采用郑希/李进的季度景气检验逻辑，每季度根据最新财报调整
- **核心原则**：底仓赚企业成长的钱，机动仓赚估值波动的钱，二者分工明确，互不干扰

### 矛盾三：止损 vs 越跌越买的对立

| | 欧奈尔 | 林奇 |
|------|--------|------|
| **对下跌的态度** | 绝不抄底，8% 止损无条件执行 | 恐慌时买入，越跌越买 |
| **核心逻辑** | 趋势走坏必须离场 | 好公司打折是机会 |

**化解方案——区分「杀估值」和「杀逻辑」**：
- 若下跌源于**杀估值**（市场恐慌、行业短期利空但长期逻辑完好），可采用林奇策略，分批左侧布局
- 若下跌源于**杀逻辑**（基本面恶化、竞争格局恶化、管理层诚信问题），必须按欧奈尔规则止损，绝不抄底
- **核心原则**：杀估值可逆向，杀逻辑必须止损

### 矛盾四：分散 vs 集中的对立

| | 欧奈尔 | 林奇 |
|------|--------|------|
| **持仓策略** | 分散投资，持股 20~30 只，单只不超过 10% | 集中投资，重仓最看好的几只 |
| **风控逻辑** | 分散降低非系统性风险 | 深度研究降低风险，重仓好公司 |

**化解方案——行业分散控回撤、主线集中求收益**：
- 总持股 5~10 只（介于欧奈尔的 20~30 只和林奇的 3~5 只之间）
- 单只上限 15%（欧奈尔 10%~20% 的中间值）
- 单一行业上限 40%（行业分散控回撤）
- 主线赛道（如 AI、新能源）可集中至 40%，非主线赛道单只不超过 10%
- **核心原则**：行业分散控回撤，主线集中求收益

## 「假如空仓」测试工具

在持有管理中，当对是否应该卖出产生犹豫时，使用「假如空仓」测试——克服沉没成本的最强工具：

**测试方法**：
- 假设你现在空仓（没有持有任何仓位），你会以当前价格买入这家公司吗？

**三档判定**：

| 回答 | 操作建议 | 说明 |
|------|---------|------|
| **会买** | 继续持有 | 买入逻辑依然完整，无需操作 |
| **不会买** | 考虑减仓或清仓 | 买入逻辑可能已被破坏，需重新评估 |
| **犹豫不决** | 减仓至观察仓 | 说明持仓逻辑不够清晰，应降低仓位至观察级别，等待更清晰的信号 |

**使用场景**：
- 股价大幅波动后（无论涨跌）
- 持有时间超过 2 个季度，对持仓产生疲劳时
- 卖出纪律触发但心理上有抵触时
- 发现更好的投资机会，考虑调仓时

## 季度复盘检查清单（7 项必查）

每季度财报发布后，Team Lead 必须完成以下 7 项检查，并记录在研究报告中：

| 序号 | 检查项 | 检查内容 | 触发条件 |
|------|--------|---------|---------|
| 1 | 管理层承诺兑现情况 | 对比上季度管理层承诺与实际落地情况，兑现率是否下降 | 兑现率<50% → P0 一票否决预警 |
| 2 | 科研转化进展 | 高科技/医药企业的研发节点是否按计划推进 | 连续 2 季度无进展 + 高研发费用 → 减仓 |
| 3 | 资本配置效率 | ROIC 是否>WACC？再投资回报率是否健康？ | ROIC 长期<5% 且扩产 → 一票否决 |
| 4 | 治理结构变化 | 是否有高管离职、股权变动、章程修改等？ | 核心高管离职率>10% → 预警 |
| 5 | 地缘政治风险变化 | 六维度评估中是否有风险升级？ | 风险从中→高 → 系统重估 |
| 6 | 侧面验证 | 产品/客户/渠道的侧面信息是否验证买入逻辑？ | 侧面信息恶化 → 重新评估 |
| 7 | 综合评分更新 | PEG/管理层/科研转化/地缘政治综合评分更新 | 评分下降≥2 档 → 减仓 |

## 常见估值陷阱提醒

在财报精读和 PEG 估值过程中，需警惕以下三种常见估值陷阱（归属 Agent 1 林奇视角）：

### 陷阱一：低 PE 陷阱

PE 低但行业处于景气顶点（如周期股），未来盈利下降会导致 PE 被动抬升，此时低 PE 是「价值陷阱」。应结合行业所处周期位置综合判断，关注 PE 是「真低」还是「假低」。

### 陷阱二：高 PE 但增速不可持续

当前增速来自一次性收益（如出售资产、疫情红利、会计政策变更），需剔除后重新计算真实 PEG。关键检查项：扣非净利润增速是否匹配营收增速？经营性现金流是否支撑利润增长？

### 陷阱三：忽略股权稀释

EPS 增长可能来自回购减少股本，而非真实盈利增长。需结合总利润增速与股本变化综合判断。若总股本持续扩张但利润增速跟不上，实际每股价值可能在下降。

## 数据抽检（准出流程）

报告写入文件后，**必须**执行数据抽检，通过后方可发布。具体流程详见 [报告审核与数据抽检](../tools-scripts/report-audit.md)。

```bash
# Step 1 - 提取抽检清单（15%随机抽样）
python tools/common/report_audit.py extract \
  --report reports/{公司名}/{公司名}-mid-earnings-{期间}.md --seed 42

# Step 2 - 对清单每项从可靠信源取数（按市场分别使用对应工具）
#   A股：tools/a_share/stock_financial.py（东方财富主） -> 巨潮资讯副 -> 年报PDF原始一手
#   港股：tools/hk_stock/stock_financial.py -> HKEX披露易
#   美股：tools/us_stock/stock_financial.py -> SEC EDGAR
#   计算验算：tools/common/financial_rigor.py（禁止 LLM 心算）

# Step 3 - 输出准出/打回判决
python tools/common/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report {公司名}-mid-earnings-{期间}.md
```

**【准出】** 所有抽检点偏差 ≤ 1% → 报告可发布；**【打回】** 任意点偏差 > 1% → 修正后重新抽检。

**Windows 兼容说明**：不使用 `/tmp/` 路径与 `2>/dev/null`，临时文件用 `%TEMP%`，stderr 重定向用 `2>$null`，JSON 提取直接用 `--output-json` 或 `--dry-run`。

## 注意事项

1. **读原文，不读摘要**——尽一切可能获取一手资料
2. **四个视角不是四个部门**——必须相互印证和挑战
3. **Team Lead 的价值在于综合判断**——找交集和矛盾点
4. **结论要明确**——不允许模糊表述
5. **反面检验贯穿全程**——每个积极发现都附带反面论据
6. **编辑不是降低专业度**——是让专业内容更易读
7. **读者评审不是走过场**——真的站在读者角度挑毛病
8. **数据准确性**——关键数据交叉验证，使用 financial_rigor.py 工具验算
9. **网络搜索时效性**——使用 `--time-range month/week` 限制时间范围
10. **非境内上市双源验证**——港股/美股公司须按市场双源验证（港股 doubao+tavily；美股 exa+doubao）
11. **每季必答核心问题**：景气逻辑是否成立？卖出纪律是否触发？——这两个问题不能回避
12. **引用不重复定义**——估值档位引用 `valuation-thermometer`，卖出纪律引用 `exit-signal`（P0~P5），产业景气/渗透率引用 `mid-industry-research`，季度加速度引用 `qoq-accelerator`，管理层/科研转化 20 分制引用 V2.0 与 `mid-management-deep-dive`
13. **中期口径红线**——禁止使用「护城河永续」「终局思维」「持有10年」等长期框架术语，持有周期以「景气周期长度」为准
14. **底仓/机动仓分离**——估值透支（P4）仅影响机动仓，治理/逻辑问题（P0/P2）才触动底仓

## 局限性

1. **资料可得性**：部分公司的完整财报原文可能难以获取，导致评级为 B 或 C 级
2. **扫描版 PDF 限制**：A股年报常为扫描版 PDF，可能无法提取文本内容，影响附注分析
3. **语言限制**：非中英文财报可能无法准确解读
4. **非实时数据**：工具获取的数据可能有延迟，不是实时数据
5. **渗透率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算，按 A/B/C 三级置信度标注
6. **地缘政治数据更新频率**：制裁清单、关税政策等变化较快，需定期更新
7. **并行执行复杂度**：6 个 Agent 并行执行可能需要较长时间
8. **不构成投资建议**：本技能仅用于学习与研究，不构成任何投资建议

## 附录B：一页纸操作备忘卡

### 买入前检查清单
- [ ] 赛道选择：渗透率 10%~30%，产业空间 ≥1000 亿
- [ ] 个股初筛：营收 ≥10 亿，三年复合增速 ≥15%，负债率 <60%
- [ ] 管理层评估：四维度 ≥15 分，无一票否决项
- [ ] 科研转化（如适用）：≥15 分
- [ ] 地缘政治：六维度评估通过
- [ ] PEG 估值：在合理买入区间内（档位引用 `valuation-thermometer`）
- [ ] 分批建仓：先建 1/3 底仓

### 持有中季度检查清单（7 项必查）
- [ ] 管理层承诺兑现情况
- [ ] 科研转化进展（如适用）
- [ ] 资本配置效率（ROIC/再投资回报率）
- [ ] 治理结构变化
- [ ] 地缘政治风险变化
- [ ] 侧面验证（产品/客户/渠道）
- [ ] 综合评分更新（PEG/管理层/科研转化）

### 卖出触发条件（引用 `exit-signal` P0~P5，本卡仅列级别名，阈值以 exit-signal 为准）
- P0 治理一票否决 → 立即清仓
- P1 硬止损（8%~10%）→ 无条件离场
- P2 逻辑止损（含时间止损）→ 减仓或清仓
- P3 产业景气拐点 → 减机动仓
- P4 估值透支 → 减/清机动仓
- P5 性价比替换 → 调仓
