# 管理层纵深研究（1~3年景气）(Mid-Term Management Deep Dive)

买股票就是买人：对指定公司进行 1~3 年景气投资框架下的管理层深度研究，评估诚信度、战略执行、科研转化、资本配置、治理结构等核心维度，并与卖出纪律 P0~P5 联动。

> 本技能属**中期链（1-3 年）**，与长期链 `management-deep-dive`（10 年 / 巴菲特-芒格-段永平-李录）**物理隔离、功能互补**。核心理念：在景气周期中，评估"这个人值不值得信任 1~3 年"，而非"值不值得信任 10 年"。

## 核心功能

对指定公司进行 1~3 年景气投资框架下的管理层纵深研究，是 `/mid-investment-research` 第六步"管理层评估"的**深化版**。当标准投资研究中管理层评分不确定（B级或以下）、或管理层/科研转化是核心投资逻辑时使用。

### 四大师方法论

| 大师 | 核心视角 | 在管理层评估中的角色 |
|------|---------|---------------------|
| 欧奈尔 | 工程师思维：信号与纪律 | 风控底线：诚信一票否决、8%~10% 硬止损、P0/P1 纪律 |
| 林奇 | 侦探思维：常识与求证 | 常识求证：侧面验证、承诺兑现追踪 |
| 郑希 | 物理学家思维：第一性原理 | 科研转化 + ROE 拐点：研发效率与资本回报 |
| 李进 | 系统工程师思维：渗透率坐标 | 治理框架 + 渗透率定位：治理稳健性与产业周期匹配 |

### 13 步执行流程

1. **识别关键管理层** — 识别 CEO/CFO/创始人/实控人/技术负责人 + 多地上市识别 + 并行数据收集
2. **诚信度评估** — 一票否决项：承诺兑现率、困难时期表现、利益相关方态度
3. **科研转化评估** — 研发投入质与量、产出效率、资本回报效率（独立 20 分制）
4. **资本配置能力** — 并购/回购/分红/新业务投资，景气周期中的配置效率
5. **治理结构评估** — 股权结构、薪酬合理性、关联交易、地缘政治风险
6. **侧面验证** — 员工/客户/行业口碑
7. **CEO 离开情景分析** — 1~3 年视角下对持有期的影响
8. **四大矛盾化解** — 左侧/右侧、长期/季度检验、止损/越跌越买、分散/集中
9. **综合评分** — 管理层 20 分制 + 科研转化 20 分制（两个独立评分）
10. **"假如空仓"测试** — 克服沉没成本
11. **决策优先级金字塔** — 卖出纪律 P0~P5 联动（引用 `exit-signal`）
12. **季度复盘清单** — 7 项必查
13. **保存报告** — 写入 `reports/{公司名}/{公司名}-mid-management-{YYYYMMDD}.md`

## 输出报告

报告将保存在以下位置：

| 报告类型 | 文件路径 |
|---------|---------|
| 管理层纵深研究报告 | `reports/{公司名}/{公司名}-mid-management-{YYYYMMDD}.md` |

> 与长期链 `reports/{公司名}/{公司名}-management-{YYYYMMDD}.md` 物理隔离，避免混淆。

### 报告要求

1. 每个维度必须有具体证据支撑，禁止空泛评价
2. 评分必须给出明细，禁止只给总分
3. 管理层 20 分制与科研转化 20 分制须**分别列出，禁止合并为单一总分**
4. "假如空仓"测试结论必须明确，禁止模糊表述
5. 卖出优先级必须明确标注（P0~P5），禁止遗漏
6. 季度复盘检查清单必须逐项填写，禁止留空

## 研究标准

### 数据交叉验证（强制执行，使用工具）

- 关键财务数据至少 2 个独立来源，误差 >1% 须标记
- 市值必须手算校验：股价 × 总股本
- ROIC、再投资回报率等计算必须通过 `financial_rigor.py`，禁止 LLM 心算
- A/H 溢价率计算前先获取实时汇率 `python tools/common/fx_rate.py --code HKDCNY`

### 数据抽检（准出流程）

报告写入后必须执行抽检，通过方可发布：

```bash
python tools/common/report_audit.py extract --report <报告文件路径>
python tools/common/report_audit.py verdict \
  --results '<填好的JSON>' --report <报告文件名>
```

- **【准出】**：所有抽检点偏差 ≤ 1%
- **【打回】**：任意点偏差 > 1% → 修正后重新抽检

## 核心原则

1. **诚信是一票否决项** — 能力不足可学习，品格有问题无法修复
2. **看行为不看言辞** — 管理层说什么不重要，做了什么才重要
3. **科研转化是科技/医药企业的生命线** — 研发费用率高但转化率低是价值毁灭
4. **数据必须标注来源** — 关键数据至少 2 个来源交叉验证
5. **禁止 LLM 心算** — 所有涉及计算的数据必须通过 `financial_rigor.py` 验算
6. **引用不重复定义** — PEG 档位引用 `valuation-thermometer`，卖出优先级引用 `exit-signal`，产业景气引用 `mid-industry-research`
7. **"假如空仓"测试必须独立执行** — 禁止与综合评分混淆
8. **P0/P1 为刚性纪律** — 禁止人为干预或延迟执行

---

## 注意事项

- 禁止使用 WebSearch 和 WebFetch 工具（中国大陆地区不可用）
- 卖出纪律使用 `exit-signal` 的 P0~P5（时间止损归 P2，无 P6 层级）
- PEG 档位以 `valuation-thermometer` 五档为准（0.8/1.2/1.5/2.0 边界），本技能仅做管理层质量对估值的折价/溢价调整
- 管理层 20 分制与科研转化 20 分制是两个独立评分，禁止合并为单一总分
- 科技/医药企业须管理层与科研转化双 ≥15 分方可视为 A 级
- 货币单位要明确（港币/人民币/美元），防止混淆
- 报告发布前必须通过 `tools/common/report_audit.py` 数据抽检

## 局限性说明

- **信息不对称**：AI 无法像传统价值投资者那样与管理层面对面交流
- **侧面信息不完整**：员工评价、客户反馈等可能不完整
- **扫描版 PDF 限制**：A 股年报常为扫描版 PDF
- **科研转化数据可得性**：部分公司新产品收入占比等数据披露不充分
- **多地上市复杂性**：A+H 股、港股+美股 ADR 等股权结构分析较复杂
- **主观判断风险**：尽管遵循客观原则，评分仍有一定主观性
- 不构成投资建议，仅供学习研究参考
