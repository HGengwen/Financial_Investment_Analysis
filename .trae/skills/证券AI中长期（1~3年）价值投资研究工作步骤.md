# 证券AI中长期（1~3年）价值投资研究工作步骤

>
> **数据截止日期**：2026-09-01 | **免责声明**：仅供学习研究参考，不构成投资建议。

## 二、六阶段闭环工作流程

中期投研是一个**无断点的六阶段闭环**，从选赛道到卖出触发首尾衔接：

```
行业扫描                漏斗精选              正向排序                个股验证                   估值择时                持仓管理                         卖出触发
         ──►                  ──►                ──►                  ──►                     ──►                  ──►
│                      │                    │                      │                         │                      │                               │
mid-era-alpha
mid-industry-research   mid-industry-funnel   mid-trend-tech-screen   mid-investment-checklist   valuation-thermometer   trend-momentum-scan              exit-signal (P0~P5)
                                                                                                                         mid-news-pulse
                                                                                                                         mid-earnings-team / mid-earnings-review
mid-bottleneck-hunter                                                  mid-investment-research    qoq-accelerator         mid-thesis-drift
                                                                      mid-investment-team                                thesis-tracker --horizon mid
                                                                      mid-management-deep-dive                           portfolio-review --horizon mid
                                                                      mid-deep-company-series
                                                                      garp-liquidity-reinvestment
```

### 阶段〇：未上市公司预研建档（前置工具）

**目标**：对未上市（Pre-IPO / 独角兽 / 一级市场）公司做上市前预研，判断「上市后是否符合 1~3 年景气 GARP 框架、是否值得等待上市」。

**推荐流程**：

1. 运行 `/mid-private-company-research {公司名}`，6 Agent 并行研究（信息拼图 + 多源交叉验证 + 置信度标注），产出建档报告（路径 `reports/{公司名}/{公司名}-mid-private-{YYYYMMDD}.md`）。
2. 报告结论为「✅ 值得等待上市」时，公司上市后依次进入 `mid-investment-checklist`（买入前七关硬门槛）→ `valuation-thermometer`（上市后估值五档温度）→ `mid-investment-research` / `mid-investment-team`（深度研究）。
3. 结论为「❌ 不符合 GARP / 不建议等待」时，终止对该公司的一级市场跟踪，不进入后续六阶段。

> 边界：`mid-private-company-research` 是六阶段闭环**之前**的前置预研工具，不入主流程；未上市公司无公开财报/行情，不适用 `/financial-data`、`/trend-momentum-scan` 等仅面向上市公司的工具，估值推演以「上市后 PEG 五档预判」与「渗透率五区间」为口径（引用 `valuation-thermometer` / `mid-industry-research`，不重建）。

### 阶段一：行业扫描

**目标**：判断「这赛道未来 1-3 年景气向上吗？值不值得进？」

**推荐流程**：

0. （可选，面向「时代主线」的入口）当诉求是「时代α / 高增长核心资产 / 时代主线 / 范式转移」时，先运行 `/mid-era-alpha {行业/方向}`，自上而下锁定 1-3 年最核心高景气主线与核心 α（五步法：主线认知地图 → 核心问题 → 景气验证 → PEG 锚点 → 底仓/机动仓纪律），再进入赛道深扫与个股验证。
1. 运行 `/mid-industry-research {行业名}`，做四维筛选（TAM ≥ 1000 亿、渗透率 10%~30% 黄金区、业绩兑现度、地缘风险敞口）+ 产业链卡脖子环节 + 景气周期定位 + 头部公司清单。
2. 如需从供应链「咽喉位置」挖掘第二、三层机会，追加 `/bottleneck-hunter {趋势名}`。
3. 赛道评级 A/B 后，运行 `/mid-industry-funnel {行业名}`，对候选池执行个股级漏斗精选（见下方「阶段一·五：漏斗精选」）。

**关键硬门槛（四维全过才算合格赛道）**：

| 维度         | 通过标准                       | 否决条件                               |
| ------------ | ------------------------------ | -------------------------------------- |
| 产业空间 TAM | ≥ 1000 亿元，3 年 CAGR ≥ 20% | ≤ 500 亿且 CAGR ≤ 15% → 评级 C/拒绝 |
| 渗透率位置   | 10%~30% 黄金区                 | > 50% 成熟期逐步退出；< 5% 过早不参与  |
| 业绩兑现度   | 连续 3 季同向兑现              | 题材炒作、无业绩支撑                   |
| 地缘风险敞口 | 中低风险                       | 一票否决（海外依赖+制裁不可对冲）      |

> 渗透率看「增速的加速度」（二阶导）：加速上行→景气扩散；减速上行→接近增速峰值。

### 阶段一·五：漏斗精选（赛道内 → 3+2 终选组合）

**目标**：在赛道已确认（A/B 级）的前提下，把赛道内 30~60 家候选标的逐层收敛为「3 家底仓 + 2 家机动仓」，回答「这条赛道里具体买哪几家？仓位怎么配？」。

**五步漏斗**（`mid-industry-funnel` 内置）：

| 步骤 | 名称                 | 收敛            | 关键动作                                                                  |
| ---- | -------------------- | --------------- | ------------------------------------------------------------------------- |
| 1    | 赛道确认与候选池构建 | 引用结论        | 引用`mid-industry-research` 四维结论与 Tier 1~4 清单，A/B 级准入        |
| 2    | 硬指标粗筛           | 30~60 → 10~20 | 6 条硬指标（财务五门槛/PEG/流动性/治理/地缘），任一不过即淘汰             |
| 3    | 四大支柱精析         | 10~20 → 5~8   | 产业景气 β / 公司基本面 α / 管理层治理 / 地缘环境 + PEG 快评 + 假如空仓 |
| 4    | 四位大师研判         | 5~8 → 3+2      | 欧奈尔/林奇/郑希/李进 + 管理层 20 分 + 科研转化 20 分 + P0~P5             |
| 5    | 综合输出             | 终选 3+2        | 3 底仓 + 2 机动仓组合表 + 建仓价/止损价 + 季度复盘清单                    |

**风控硬编码 F-1~F-10**：F-1 赛道评级非 A/B 终止；F-2 财务五门槛；F-3 PEG>2.0；F-4 流动性；F-5 治理一票否决；F-6 地缘红线；F-7 管理层/科研转化 <10 分；F-8 禁 LLM 心算；F-9 仓位上限；F-10 单一来源标注。

> 边界：漏斗精选只做「赛道确定后的个股级漏斗」，赛道四维结论**引用不重做**；终选标的仍须过 `mid-investment-checklist` 七关硬门槛，本技能不替代。

### 阶段二：正向排序

**目标**：在赛道内正向排序出领涨标的（区别于长期链 `quality-screen` 的逆向淘汰）。

**示例**：`/mid-trend-tech-screen 中际旭创`（个股）、`/mid-trend-tech-screen 中国AI算力行业`（行业）、`/mid-trend-tech-screen 恒生科技指数成分股`（指数）。

**四层递进流程**（`mid-trend-tech-screen` 内置）：

1. **第零层：产业链周期定位**（前置判断，动态调整权重）：| 周期阶段   | 权重调整                                                 |
   | ---------- | -------------------------------------------------------- |
   | 需求爆发期 | ①景气前瞻 35→**42**；②研发转化 25→**18** |
   | 技术跃迁期 | ②研发转化 25→**32**；①景气前瞻 35→**28** |
   | 供给受限期 | 地缘政治修正系数权重提升                                 |
   | 成熟稳定期 | ⑤估值安全垫 10→**15**                            |
2. **第一层：前置硬性淘汰（一票否决 3 条，命中即淘汰、不再打分）**：① 被列入实体清单 + 核心环节国产化率 <30% + 无非制裁海外有效实体；② 核心技术人员流失 >30% 且人均创利连续 2 年暴跌 >40%；③ 在手订单（合同负债）同比 < -50% 且存货周转天数同比增加 >80%。
3. **第二层：五维加权打分（满分 100 + 奖励）**——见下方五维表。
4. **第三层：地缘修正 + 估值倒推 + 技术面止损**——最终得分 =（五维总分 + 奖励）× 地缘修正系数；市值隐含增速倒推触发红灯则下调一级；技术面破位独立否决。

**五维打分（满分 100 + 奖励）**：① 景气前瞻 35 ② 研发转化 25+奖励 ③ 人才 15 ④ 动量 15+溢价 ⑤ 估值安全垫 10。

**技术面止损（独立否决项）**：破 50 日线放量预警降级；破 200 日线红牌清仓。

**完整流水线**：

```
/mid-trend-tech-screen {行业/指数/主题}     ← 产业链周期定位 + 五维打分，排序出领涨标的
        ↓
/mid-trend-tech-screen {入选领涨标的}       ← 逐家打分 + 地缘修正 + 技术面止损，出 S/A/B/C 评级
        ↓
/financial-data {入选标的}                 ← 双源交叉验证财务基线
        ↓
/mid-investment-checklist {入选标的}        ← 趋势标的也须过七关 Checklist（不可跳过）
        ↓
/thesis-tracker {入选标的} --horizon mid    ← 建立中期论文（含技术面止损阈值）
```

**打分引擎工具链**（禁止 LLM 心算）：`tools/specialized/trend_tech_screen.py`（`score`/`batch`）+ `tools/common/financial_rigor.py`（`peg`/`ps-g`/`pe-percentile`/`implied-growth`）+ `tools/common/annual_report_parser.py`（年报结构化抽取）。

**产出路径**：个股 `reports/trend-screen/{公司名}-trend-screen-{YYYYMMDD}.md`。

### 阶段三：个股验证

**目标**：对候选公司做深度基本面验证，排除坏选择（买入前以 `mid-investment-checklist` 七关为硬门槛，快速报告、四角色团队研究与管理层深挖均为中期链技能）。

**推荐流程**：

1. 运行 `/mid-investment-research {公司名}`，快速产出四大师综合分析报告。
2. 需要系统化深度研判时，运行 `/mid-investment-team {公司名}`，四角色并行研究 + Team Lead 综合（欧奈尔/林奇/郑希/李进）。
3. 买入前必须过 `/mid-investment-checklist {公司名}`（趋势标的也须过七关 Checklist，不可跳过）。
4. 管理层是核心逻辑时，追加 `/mid-management-deep-dive {公司名}`。

### 阶段四：估值择时

**目标**：判断当前估值贵不贵，确定底仓/机动仓买卖区间。

**推荐流程**（两个技能互补）：

1. 运行 `/valuation-thermometer {公司名}`，用 PEG/PSG/PE 历史分位/implied-growth 四工具输出五档温度。
2. 运行 `/qoq-accelerator {公司名}`，用连续 3 个季度数据判断「增速的加速度」，区分短期波动与趋势拐点。

**五档温度表（唯一权威口径，硬编码）**：

| 档位     | PEG 区间（边界约定） | 操作建议                       |
| -------- | -------------------- | ------------------------------ |
| 显著低估 | PEG < 0.8            | 绝佳买点，底仓可加             |
| 合理     | 0.8 ≤ PEG ≤ 1.2    | 合理买入区间，先建 1/3 底仓    |
| 偏贵     | 1.2 < PEG ≤ 1.5     | 机动仓观望（过渡档，不买不卖） |
| 高估     | 1.5 < PEG ≤ 2.0     | 机动仓减持                     |
| 严重透支 | PEG > 2.0            | 加速清机动仓                   |

**季度加速度三态结论**：

| 序列形态（最近 3 季 YoY 营收增速） | 判定              | 动作建议                             |
| ---------------------------------- | ----------------- | ------------------------------------ |
| 连续加速（Q(-3) < Q(-2) < Q(-1)）  | 景气向上 🟢       | 维持/可加底仓（结合估值）            |
| 连续减速（Q(-3) > Q(-2) > Q(-1)）  | 拐点预警 🔴       | 触发 P2/P3 复核（交`exit-signal`） |
| 单季异动（不单调）                 | 噪音，不判拐点 🟡 | 标记噪音，底仓不动                   |

### 阶段五：持仓管理

**目标**：建仓后持续体检持仓的「趋势」与「逻辑」两条腿。

**推荐流程**：

1. 建仓后立即运行 `/thesis-tracker {公司名} --horizon mid`，建立中期论文（中期假设清单 + P0~P5 检查表 + PEG 水位维度）。
2. 每季度运行 `/trend-momentum-scan {持仓代码}`，做纯技术面体检（SMR/RSI50/MA50/MA200），回答「趋势还在吗？」。
3. 每季报发布后运行 `/mid-thesis-drift {标的}`，对 H1~H6 六大景气假设逐条验证，回答「景气逻辑还在吗？」。
4. 每季度运行 `/portfolio-review {持仓清单} --horizon mid`，做底仓/机动仓分离与「3+2」结构校验。

**中期逻辑漂移（H1~H6 六大假设）**：H1 渗透率 / H2 订单（合同负债）/ H3 ROE 趋势 / H4 毛利率 / H5 增速加速度 / H6 地缘政治。

**四级漂移等级**：

| 完全漂移项数 | 漂移等级 | 颜色 | 行动建议                     |
| ------------ | -------- | ---- | ---------------------------- |
| 0~1 项       | 未漂移   | 🟢   | 继续持有，关注 ⚠️ 项       |
| 2 项         | 轻微漂移 | 🟡   | 底仓持有，机动仓考虑减仓     |
| 3 项         | 显著漂移 | 🟠   | 大幅减机动仓，底仓设止损线   |
| ≥4 项       | 严重漂移 | 🔴   | 触发`exit-signal` 卖出评估 |

### 阶段六：卖出触发

**目标**：用硬编码的 P0~P5 六级优先级做卖出检查，命中即停、禁止跳过 P0。

**推荐流程**：

1. 每季度或触发预警信号时运行 `/exit-signal {标的}`，从 P0 到 P5 逐级检查，命中即停，输出命中的最高级别及对应动作。

> 联动触发：`qoq-accelerator` 连续 3 季负加速、`mid-thesis-drift` 显著/严重漂移、`trend-momentum-scan` MA200 破位，均须转入 `exit-signal` 完整检查。

## 三、决策优先级金字塔（P0~P5）

卖出决策的唯一权威口径（硬编码于 `exit-signal`，与理念文档「决策优先级金字塔」完全对齐）：

| 级别            | 触发条件                                                                               | 决策                    | 思想来源     |
| --------------- | -------------------------------------------------------------------------------------- | ----------------------- | ------------ |
| P0 治理一票否决 | 管理层失信、财务造假实锤、监管立案                                                     | 立即清仓，不看估值趋势  | 李进（治理） |
| P1 硬止损       | 单笔亏损 8%~10%，且无基本面反转信号                                                    | 无条件止损              | 欧奈尔       |
| P2 逻辑止损     | 连续 2 季业绩低于预期且产业景气未改善；**或持有满 4 季度逻辑未兑现（时间止损）** | 减仓或清仓              | 林奇 + 郑希  |
| P3 产业景气拐点 | 渗透率减速 / ROE 拐头向下                                                              | 减机动仓                | 李进 + 郑希  |
| P4 估值透支     | PEG > 1.5（减机动仓）；PEG > 2（加速清机动仓）                                         | 减 / 清机动仓           | 林奇         |
| P5 性价比替换   | 其他标的 PEG 显著更低且产业趋势更强                                                    | 调仓（每季度最多 1 次） | 机会成本     |

**硬编码执行规则**：

- 检查顺序固定 P0 → P1 → P2 → P3 → P4 → P5；
- **命中即停**：输出命中的最高级别及对应动作，不得继续检查更低级别；
- **禁止跳过 P0**：任何输入都必须先过 P0 治理检查；
- 「时间止损（满 4 季度逻辑未兑现）」归入 P2，不设独立层级；
- 硬止损 8%~10% 为硬性区间，AI 不得放宽；
- P4 的 PEG 档位直接引用 `valuation-thermometer` 输出，不在 `exit-signal` 内重复计算。

## 四、底仓/机动仓分离规则

中期组合采用**底仓 + 机动仓**双轨结构（硬编码于 `portfolio-review --horizon mid`）：

| 结构   | 比例区间 | 定位                                          |
| ------ | -------- | --------------------------------------------- |
| 底仓   | 60%~80%  | 深度研究后的高确信标的，长期持有核心          |
| 机动仓 | 20%~40%  | 景气博弈、趋势增强，技术面/估值触发时灵活增减 |

**单只/单行业上限（硬编码）**：

| 上限           | 阈值   |
| -------------- | ------ |
| 单只初始上限   | ≤ 10% |
| 单只验证后上限 | ≤ 15% |
| 单只绝对上限   | ≤ 20% |
| 单一行业上限   | ≤ 40% |

**「3+2」集中度结构**：

- 核心重仓 3 只，单只 12%~15%；
- 卫星仓位 2~3 只，单只 5%~8%。

**底仓/机动仓归属判定（优先级递减）**：

1. 用户显式标注（`标的=底仓/机动仓`）→ 以标注为准；
2. 有深度研究报告 且 论文健康度 ≥ 7 且 PEG ≤ 1.2 → 底仓候选；
3. PEG > 1.5 或论文健康度 < 5 → 机动仓（触发减持提示）；
4. 卫星/试探性小仓位（≤ 8%）→ 机动仓。

## 八、多技能组合建议

以下是经过验证的高效中期技能组合方案，全部围绕「行业扫描（+漏斗精选）→ 正向排序 → 个股验证 → 估值择时 → 持仓管理 → 卖出触发」六阶段闭环设计：

### 组合 1：中期选股完整流水线（选赛道 → 买入）

```
/mid-industry-research {行业名}            ← 四维筛选 + 赛道 A/B 评级
        ↓
/mid-industry-funnel {行业名}              ← 漏斗精选出 3 底仓 + 2 机动仓
        ↓
/mid-trend-tech-screen {终选标的}           ← 五维打分 + 地缘修正 + 技术面止损
        ↓

        ↓
/mid-investment-checklist {公司名}          ← 七关 Checklist 硬门槛（不可跳过）
        ↓
/valuation-thermometer {公司名}             ← 五档温度确定建仓区间
        ↓
/thesis-tracker {公司名} --horizon mid      ← 建立中期论文（含技术面止损阈值）
```

**适用场景**：从零开始研究一个行业，系统化走完「选赛道 → 精选标的 → 正向排序 → 个股验证 → 估值择时 → 建仓」全流程。

**适用场景**：已有明确的候选标的（如热点龙头），跳过赛道研究直接验证个股。
