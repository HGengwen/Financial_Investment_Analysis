# 估值温度计：1-3年中期估值温度与底仓/机动仓操作

用 PEG / PSG / PE 历史分位 / implied-growth 四个工具，输出「显著低估 / 合理 / 偏贵 / 高估 / 严重透支」五档温度，并映射到底仓/机动仓操作。属于中期链（1-3 年）功能技能，与长期链（10 年 / `quality-screen`）估值口径物理隔离。

## 设计原则

1. **四工具交叉，不靠单一指标**：PEG 为主锚，PSG / PE 分位 / implied-growth 辅助校验，冲突时降级而非硬套。
2. **只取数值，不取评级**：`peg` 命令内置的评级文字是林奇原版三档口径，本技能一律忽略，仅取 PEG 数值并按本技能五档表二次映射。
3. **禁止 LLM 心算**：PEG、复合增速、分位、隐含增速等一切算术必须经 `financial_rigor.py` 执行。
4. **仓位硬编码**：底仓/机动仓区间、单只个股上限、行业上限全部写死，AI 不得自由裁量。
5. **只出温度，不给价位**：本技能输出档位与操作建议，不定义安全边际参考价位公式。

## 五档温度表（唯一权威口径，硬编码）

| 档位     | PEG 区间（边界约定） | 操作建议                       |
| -------- | -------------------- | ------------------------------ |
| 显著低估 | PEG < 0.8            | 绝佳买点，底仓可加             |
| 合理     | 0.8 ≤ PEG ≤ 1.2    | 合理买入区间，先建 1/3 底仓    |
| 偏贵     | 1.2 < PEG ≤ 1.5     | 机动仓观望（过渡档，不买不卖） |
| 高估     | 1.5 < PEG ≤ 2.0     | 机动仓减持                     |
| 严重透支 | PEG > 2.0            | 加速清机动仓                   |

> **边界约定（消除歧义）**：PEG=0.8 归「合理」；PEG=1.2 归「合理」（1.2 为买入线，与「PEG<1.2 买入」备忘卡一致）；PEG=1.5 归「偏贵」；PEG=2.0 归「高估」。区间均为下开上闭（首档除外），保证任意 PEG 值有唯一档位归属。

## 主锚选择规则（四工具如何组合）

| 场景                                  | 主锚                                                                     | 辅助校验                     |
| ------------------------------------- | ------------------------------------------------------------------------ | ---------------------------- |
| 常规增长（增速 >0 且非爆发期）        | PEG                                                                      | PSG、PE 分位、implied-growth |
| 爆发期（净利率 <5% 或 营收增速 >50%） | PSG（<0.5 显著低估 / 0.5~1.0 合理 / >1.0 高估）                          | PEG 降为辅助                 |
| 增速 ≤ 0（PEG 无意义）               | 直接判「不适用 PEG」，转 PSG（若营收增速 >0）或标注「亏损/负增长不适用」 | PE 分位、implied-growth      |

## 交叉校验与降级规则

- PE 历史分位（<40% 低估 / 40%~60% 合理 / >60% 偏高）与主锚档位冲突时，**降一档处理并显式标注冲突原因**；
- implied-growth 红灯（隐含增速 > 指引上限 ×1.5）时，**主锚档位下调一档**；黄灯标注「偏贵预警」；绿灯标注「估值未透支」。

## 执行流程

### 第一步：解析输入，确定标的与市场

- 输入形态：单个公司名（如「新易盛」）或「公司名 + 代码」。
- 识别市场（A 股 / 港股 / 美股），决定后续数据工具与 PE 均值水平处理。
- 运行 `date` 确认当天日期，作为报告「估值日期」基准。

### 第二步：收集数据

按市场选择数据工具：

| 市场 | 行情/财务工具                                                         |
| ---- | ---------------------------------------------------------------------- |
| A 股 | `python tools/a_share/stock_financial.py --code {代码}`、`stock_quote.py --code {代码}` |
| 港股 | `python tools/hk_stock/stock_financial.py --financial {代码}`、`stock_quote.py --code {代码}` |
| 美股 | `python tools/us_stock/stock_financial.py --code {代码}`、`stock_quote.py --code {代码}` |

需收集：

- 当前 PE（TTM）、当前 PS、历史 PE 序列（供 `pe-percentile`）；
- 未来 2 年 EPS 一致预期增速（获取与校验流程见「growth 口径」节）；
- 当前市值、目标 PE、净利率、TTM 营收、指引增速（供 `implied-growth`）；
- 净利率、营收增速（判断是否爆发期，决定主锚）。

### 第三步：确定主锚

按「主锚选择规则」判断：常规增长走 PEG；爆发期走 PSG；增速 ≤0 判「不适用 PEG」。

### 第四步：调用四工具计算（禁 LLM 心算）

命令模板见「工具软件使用指南」。全部数值来自 `financial_rigor.py` 输出，报告不得出现手算数值。

### 第五步：交叉校验与降级

按「交叉校验与降级规则」执行，冲突/红灯须显式标注原因。

### 第六步：档位判定与操作映射

- 按五档温度表 + 底仓/机动仓操作映射表输出操作建议；
- 套用仓位上限硬编码，逐条注明上限。

### 第七步：输出报告

按「输出结果」节固定模板写入 `reports/valuation/`，并在报告头部注明数据截止日期。

## 工具软件使用指南

### 核心工具清单与用途

四命令调用模板（参数签名已实测）：

```bash
python tools/common/financial_rigor.py peg --pe 25 --growth 20
python tools/common/financial_rigor.py ps-g --ps 5 --revenue-growth 30
python tools/common/financial_rigor.py pe-percentile --pe-series "[10,12,15,18,20,22]" --current 25
python tools/common/financial_rigor.py implied-growth --market-cap 1000 --target-pe 25 --net-margin 0.15 --ttm-revenue 100 --guidance-growth 0.3
```

> **关键约定（D-1）**：`peg` 命令输出的 `rating` 文字是林奇原版三档口径（<1 低估 / ≤1.5 合理 / >1.5 高估），**仅取 PEG 数值**，档位判定一律按上文五档表二次映射，报告中注明「忽略内置林奇评级」。
>
> **关键约定（D-2）**：`pe-percentile` 分位采用「历史 PE 中 ≤ 当前 PE 的样本占比（含等于）」口径；当当前 PE 等于历史最低/最高时，须在报告中显式标注边界情形。

- `--growth` 语义：`peg` 的 `--growth` 为「百分点」数值（如 40 表示 40%），非小数。
- 复合增速计算用 `python tools/common/financial_rigor.py calc --expr "(未来第2年EPS/当前TTM EPS)**(1/2)-1"`，禁止 LLM 心算。注意：CLI 幂运算用 `**`，`^` 会被 `calc` 白名单拒绝。
- 若需参考价位/三情景估值，用 `python tools/common/financial_rigor.py three-scenario --help` 输出，本技能不定义价位公式。

### growth 口径与一致预期增速获取

PEG 的 `--growth` 输入为「未来 2 年 EPS 复合增速」，获取与校验流程：

| 步骤 | 操作                                                                                                                                                       | 说明                                          |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| 1    | 搜索一致预期：`anysearch.py "{公司名} 一致预期 EPS {年份}" --tag finance`；A 股辅源 `doubao_search.py --finance`；港美股 `exa_search.py --type deep` | 优先取 mean/consensus                         |
| 2    | 提取未来第 2 年一致预期 EPS                                                                                                                                | 至少 2 个来源，误差 >10% 须标记               |
| 3    | 计算复合增速：`(未来第2年EPS / 当前TTM EPS)**(1/2) - 1`                                                                                                   | 必须经 `financial_rigor.py calc` 执行，禁止 LLM 心算（CLI 幂运算用 `**`，非 `^`） |
| 4    | 校验：一致预期增速 > 历史 3 年增速 ×2 时                                                                                                                  | 标注「过于乐观预警」                          |

- **缺失降级**：无一致预期时，用历史 3 年 EPS 复合增速替代，并标注「基于历史增速推算，未经一致预期验证」；两者皆无则输出「数据不足，无法计算 PEG」。
- **同口径原则**：PE 与增速必须同口径（本技能统一 TTM PE + 未来 2 年一致预期增速）。

### 关键约束

- 所有算术（PEG、PSG、分位、隐含增速、复合增速）必须经 `financial_rigor.py` 执行；
- 报告中的每个数值必须能追溯到对应命令输出；
- `peg` 内置评级文字不进入档位判定，仅取数值。

## 注意事项

1. 开始前运行 `date` 确认当天日期，报告头部注明数据截止日期。
2. 关键财务数据须至少来自两个独立来源，误差 >1% 须标记。
3. 禁止 LLM 心算，所有数值来自 `financial_rigor.py` 输出。
4. `peg` 内置评级文字（林奇三档）不进入档位判定，仅取数值按五档表二次映射。
5. PE 分位边界（历史最低/最高）须显式标注口径。

## 局限性

1. 本技能只输出估值档位与仓位操作建议，不给出具体目标价或买卖价位。
2. 一致预期增速存在分析师乐观偏差，本技能仅做「>历史3年增速×2」的预警，不替代独立判断。
3. 港股流动性折价、美股成长溢价的市场阈值微调（±0.2）为经验值，非精确模型。
4. 本技能不承担上游景气/质量判断，修正因子打分归 `mid-industry-research`、`qoq-accelerator`。

## 与其他Skill的关系

- **前置**：`mid-industry-research`（渗透率/景气）→ `mid-trend-tech-screen`（正向排序）→ `quality-screen`（排雷）。
- **后置**：`exit-signal`（本技能输出的 PEG 档位作为其 P4 估值透支输入）；`thesis-tracker --horizon mid`（建仓后建论文）。
- **边界**：与长期链 `quality-screen` 估值口径物理隔离，本技能五档仅存在于技能层，不改共享工具。
