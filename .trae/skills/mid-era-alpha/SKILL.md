# 时代α捕手（1~3年景气版）：时代级高增长主线与核心α的识别-验证-持有框架

对 $ARGUMENTS 行业/方向执行「时代α五步法（中期版）」：建立时代主线认知地图 → 自问核心问题 → 景气可持续性验证 → PEG 估值锚点与介入 → 底仓/机动仓持有与卖出纪律。

**目标**：找出当下 1-3 年最核心高景气主线中真正有定价权、有景气壁垒、能持续跑赢同行的核心 α，并给出介入与退出纪律。这是一条**中期（1~3 年）景气投资**路径，与长期（10 年）链的 `/era-alpha` **物理隔离**——长期回答「10 年后还在吗？」（永续护城河），本技能回答「未来 1-3 年景气向上吗？值不值得进？」。

## 方法论来源与本质

源自 `/era-alpha`（长期 10 年版）的「时代α五步法」骨架，移植到 V2.0《个人投资者1~3年中长期投资思想与理念》的中期景气框架。本质一句话：**把 1-3 年的收益建立在产业景气与企业成长的认知之上，而不是运气或情绪之上**。原版五步是职业选手的修炼路径，本技能保留三项修正并将其落到 1-3 年景气语境：

1. **修正一（精简范围）**：不覆盖所有行业，聚焦指定主线的 2-3 个核心环节做深做透。与 V2.0「做减法」「集中精力跟踪 3-5 个重点赛道」一致。
2. **修正二（高频数据交叉验证）**：财报是三个月前的体检报告，必须用行业高频数据（周度/月度出货量、价格、订单、装机、渗透率）做实时体温计校正。1-3 年景气投资中，高频景气校验的地位高于长期。
3. **修正三（估值锚点）**：以 PEG 为核心锚点替代「闭眼买」。合理/低估时重仓、偏贵时观望、严重透支时减机动仓、拐点确认时清仓。

**四大师验证透镜（中期版）**：在第三步「景气可持续性验证」中，用 **林奇（常识与求证）/ 郑希（产业景气与第一性原理）/ 李进（渗透率坐标与系统均衡）/ 欧奈尔（信号与风控底线）** 四位大师的追问作为验证透镜，确保核心 α 的判断既聚焦景气爆发力，又不失 1-3 年安全边际与纪律。

## 第一步：时代主线认知地图（基于渗透率坐标 + 四大支柱）

对目标方向建立「主线-产业链」认知地图，每个候选环节回答：

1. **渗透率位置**：该环节处于渗透率曲线哪个区间？（<5% 过早、10%~30% 黄金加速区、15% 为加速临界点、>50% 增速放缓逐步兑现）。用渗透率 + 增速的加速度（二阶导）定位。
2. **产业空间与速度**：TAM 是否 ≥ 1000 亿？未来 3 年 CAGR 是否 ≥ 20%？
3. **商业模式与赚钱方式**：毛利率、费用率、现金流与利润的匹配度。
4. **竞争格局**：CR3、定价权在谁手里、壁垒是技术/规模/生态/牌照。
5. **地缘政治风险敞口**：海外收入占比、供应链可控性、制裁/关税暴露、本地化对冲、自主研发抗封锁韧性（「华为式」四维：研发费用率、核心技术自主可控、备胎计划、极端生存能力）。
6. **每个环节的核心 α 候选是谁**：营收增速、ROE 趋势、市占率变化三个维度筛。

**信息源要求**：以招股说明书、年报/季报、业绩说明会纪要等一手资料为主，券商观点只做线索不做结论。A股/港股/美股/未上市候选都要覆盖，不因资料难找而漏掉。

**产出**：主线/产业链环节表（环节 | 渗透率区间 | 阶段 | 格局 | 地缘风险 | 核心α候选 | 一句话理由），并从中选出 2-3 个最值得做深的核心环节（修正一）。

## 第二步：自问核心问题（不听别人的）

用第一步的数据回答，禁止引用「市场共识」「机构观点」作为论据：

1. **当下这条主线最核心、景气最确定的环节是什么？** 用数据说话：渗透率区间、增速、订单能见度、业绩兑现度。
2. **该环节的核心 α 是谁？** 标准：定价权（毛利率高于同行且稳定或提升）、景气壁垒（对手 1-3 年追不上的东西是什么）、增长质量（收入增长伴随现金流增长，不是赊出来的）。
3. **为什么是它而不是老二？** 必须能一句话说清 α 与 β 的差别，说不清就是没看懂。

**产出**：1-3 家核心 α + 明确的「为什么是它」论证。

## 第三步：景气可持续性验证（五维交叉 + 四大师透镜 + 管理层/科研转化）

对每家核心 α 做 1-3 年景气可持续性验证，所有维度必须一致指向「高景气可持续」才算看懂。

### 3.1 五维验证（财报 + 高频数据交叉）

| 维度 | 验证内容 |
|------|---------|
| 财报 | 最近 4-8 个季度营收/利润增速趋势、毛利率方向、ROE 趋势（是否向上拐点）、合同负债/存货/在建工程等前瞻科目 |
| 高频数据（修正二） | 该环节的周度/月度实时指标（出货量、价格、招标、订单、渗透率、token 调用量等），是否与财报趋势一致 |
| 行业景气 | 政策方向、技术路线有无被颠覆风险、供给端扩产节奏（供过于求是成长股最大杀手）、渗透率二阶导 |
| 竞争格局 | 市占率变化方向、新进入者威胁、客户集中度与议价权 |
| 地缘/宏观 | 关税/制裁/出口管制、供应链卡脖子、利率环境、资本开支周期位置 |

**任何一个维度出现矛盾信号，必须明确写出，不许含糊带过。**

### 3.2 四大师验证透镜（中期版）

在五维验证之上，用四位中期投资大师的追问对 α 做 1-3 年景气视角的二次验证：

| 大师 | 验证透镜 | 核心追问 |
|------|---------|---------|
| 林奇 | 常识与求证 | 这门生意「看得懂」吗？属于六类中的哪一类？增长是否来自真实需求而非题材炒作？ |
| 郑希 | 产业景气与第一性原理 | 产业正处在 ROE 曲线的什么位置？有无 ROE 向上拐点？全球产业链中哪个环节率先景气？ |
| 李进 | 渗透率坐标与系统均衡 | 渗透率处于哪个区间？增速的加速度（二阶导）是加速还是减速？治理是否有硬伤（诚信/质押/减持）？ |
| 欧奈尔 | 信号与风控底线 | 技术面趋势是否确认？突破买点/抛售日信号如何？8% 止损底线在哪？ |

四大师透镜若与五维验证结论冲突，**优先采信冲突信号**，在报告中明确写出，不得按需取舍。

### 3.3 管理层与科研转化评估（引用不重做）

- **管理层 20 分制**（诚信品格/股东态度/战略执行力/稳定性激励，≥15 分方可重仓）——口径引用 `mid-management-deep-dive`，本技能只做关键项速判，不逐项重算。
- **科研转化 20 分制**（研发投入质与量/产出转化效率/资本回报效率，≥15 分可重仓）——可在研项目用 `in_research_scan.py` 扫描，年报字段用 `annual_report_parser.py` 抽取，评分口径引用 `mid-management-deep-dive`。
- 两项评分中任一出现**一票否决项**（财务造假/监管立案/大股东质押>50%/研发 ROIC 长期<5% 仍扩产等），直接进入 `exit-signal` P0。

## 第四步：PEG 估值锚点与介入（修正三，替代「不看股价」）

1. 当前 PEG 处于哪个档位？PE/PS 相对历史分位如何？
2. 增速与估值匹配吗？（引用 `qoq-accelerator` 连续 3 季二阶导，区分「单季波动」与「趋势性拐点」）
3. 结论三选一：**低估/合理可重仓介入**、**偏贵但景气可消化可持有或分批**、**严重透支只看不买**。
4. 给出介入方式（三选一或组合）：
   - **分批建仓**：进入合理区间先建 1/3 底仓 → 回调至区间下沿加 1/3 → 景气加速/财报超预期补 1/3；
   - **左侧布局**（杀估值不杀逻辑，逆向分批）；
   - **右侧重仓**（渗透率突破 15% 临界点 + 连续 2 季加速 + 行业景气明确，一次性 2/3 仓，设 8-10% 止损）。

**估值计算必须使用精确工具，禁止 LLM 心算**：

- PEG 五档口径**唯一权威来源**：`/valuation-thermometer {公司名}`（本技能引用，不重建不重算）。
- 精确金融计算：`python tools/common/financial_rigor.py peg ...` / `implied-growth ...` / `pe-percentile ...`。
- **禁用 `terminal_value.py`（十年 DCF）**：该工具是长期链估值口径，中期链不引用。

## 第五步：持仓与卖出纪律（底仓/机动仓 + P0~P5）

**持仓纪律（底仓/机动仓分离）**：

- **底仓（60%~80%）**：只要景气逻辑未破坏（产业景气上行、渗透率未减速、ROE 未拐头、管理层可信），始终保留；不因短期 20% 以内波动卖出，每季度结合财报做 ±5% 微调。
- **机动仓（20%~40%）**：当 PEG > 1.5 或估值分位 > 80% 时减持，回落合理区间回补；机动仓操作不影响底仓的景气判断。
- **仓位上限（硬编码）**：单只初始 ≤ 10%、验证后 ≤ 15%、绝对上限 ≤ 20%；单一行业 ≤ 40%；持股 5-10 只。

**拐点清单**（每家核心 α 必须列出，逐条可观察、可证伪）：

| 层级 | 拐点信号示例 | 观察什么数据 | 多久看一次 |
|------|------------|------------|-----------|
| 宏观拐点 | 利率转向、资本开支周期见顶、地缘制裁升级 | 利率、PMI、资本开支指引、关税/清单 | 月度/季度 |
| 行业拐点 | 供给过剩价格崩盘、技术路线被颠覆、渗透率减速/见顶、政策逆转 | 价格、出货量、渗透率二阶导、政策文件 | 周度/月度 |
| 公司拐点 | 核心管理层离职、毛利率连续两季下滑、市占率被侵蚀、合同负债转负增长 | 高管变动公告、季报毛利率、份额数据、合同负债 | 季度 |

每条信号写明**观察哪个数据、多久看一次**，让「拐点」从感觉变成清单。

**拐点触发后的行动链路**（与中期持仓管理技能联动）：

- 命中公司/行业拐点 → 转 `/exit-signal {标的}` 做 P0~P5 六级硬编码卖出纪律检查（**命中即停，禁止跳过 P0**）
- 硬止损 8%~10% 触发 → 无条件离场（欧奈尔底线，AI 不得放宽）
- 持有满 4 季度逻辑未兑现（订单/收入/利润无实质改善）→ 时间止损，减至观察仓或替换
- 怀疑景气假设漂移 → 转 `/mid-thesis-drift {标的}` 对 H1~H6 六大景气假设逐条验证
- 建仓后例行跟踪 → 转 `/thesis-tracker {公司名} --horizon mid` 建立中期论文 + 季度健康度检查

## 执行方式

1. **并发硬约束（必须先读，防止触发服务端 request burst 保护）**：
   - 同时运行的子代理**最多 2 个**，严禁「按产业链环节一次性并行铺开所有 Agent」。
   - 产业链环节按优先级排序后**分批串行**处理：每批最多 2 个环节，一批全部返回后再启动下一批。
   - 单个子代理内的搜索请求须**串行逐条执行**，两次请求间隔 ≥ 2 秒；单个环节搜索请求上限 8 次。
   - 遇到 `request burst` / `rate limit` / `System protection` 报错时，立即停止新增请求，按指数退避（30s → 60s → 120s）重试，最多 3 次；仍失败则降级为只用已获取数据，标注「信息不足」，不做无谓追问。
2. 每个环节派出的研究 Agent，要求联网获取最新财报与高频数据，返回结构化事实（数据+出处），不返回观点。
3. 主线程按第一到第五步综合成报告；单个环节子代理超时（> 15 分钟无返回）即放弃该环节，用已有数据标注「信息不足」继续推进，不阻塞整体。
4. 遵循 `financial-data` 技能的交叉验证规范；关键数字（增速、毛利率、PEG、渗透率）必须标注数据截至日期。

## 报告结构

```
一、时代主线认知地图（主线/产业链表 + 渗透率坐标 + 核心环节选择理由）
二、核心问题的回答（最核心 1-3 年高景气主线 + 核心α + 为什么是它）
三、景气可持续性验证（五维逐项 + 四大师透镜 + 管理层/科研转化 + 矛盾信号明示）
四、PEG 估值锚点与介入建议（PEG 五档 + 二阶导 + 分批建仓）
五、底仓/机动仓与卖出纪律（拐点清单，链接 exit-signal/thesis-tracker --horizon mid/mid-thesis-drift）
六、本报告可能错在哪（至少 3 条自我证伪）
```

风格要求：数据密度优先，保留全部硬数据，砍掉脚手架语言；纯中文表达；不挂任何投资人名字，用分析维度命名章节。

## 注意事项

1. **所有分析必须有数据支撑**：附数据来源，不主观臆断
2. **关键数据至少两个独立来源交叉验证**，误差 >1% 须标记
3. **证伪优先**：每个核心判断附反面论据，正面证据再充分也不掩盖矛盾信号
4. **结论明确**：给出具体核心 α、介入条件、底仓/机动仓计划、拐点清单，不两面讨好
5. **不预设立场**：先摆数据 → 推逻辑 → 出结论
6. **诚实面对信息缺口**：宁可标注「数据不足/信息充分度 B 级」，不用推测填充
7. **口径统一**：PEG 五档引用 `valuation-thermometer`、P0~P5 引用 `exit-signal`、渗透率坐标引用 `mid-industry-research`，不重复定义

## 局限性

1. **资料可得性**：新兴行业资料少，分析深度受限
2. **未上市公司信息**：估值和财务信息可能不够准确
3. **高频数据可得性**：部分环节缺乏周度/月度公开高频数据，交叉验证可能降级为季度数据
4. **非实时数据**：工具获取的数据可能有延迟，不是实时数据
5. **AI 筛选偏见**：可能存在成熟行业偏好、龙头偏好、英文偏好，需自觉检查
6. **景气/渗透率判断主观性**：依赖定性判断，可能因分析师而异
7. **估值分位历史长度限制**：次新行业/公司历史分位可能参考价值有限
8. **不构成投资建议**：本技能仅用于学习与研究
