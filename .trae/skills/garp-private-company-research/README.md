# 未上市公司研究（GARP 独立档·1~5 年）：上市后 GARP 适配性预判建档层 (Garp Private Company Research)

对未上市公司做 6 路并行 Agent 深度研究，判断「**这家公司若上市，是否符合 GARP 独立档（1~5 年）框架、是否值得等待上市**」。

> 本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。

**核心理念**：上市前的「**预研建档**」——为上市后的 GARP 投资提前建立标的池与判断框架，而非研究「现在是否买入未上市股权」。**禁止**使用「护城河永续」「终局思维」「持有 10 年」「论文已破」等长期档术语；壁垒表述统一为「**1~5 年景气竞争力**」。

**输出边界**：本技能输出的是「**上市前预研建档 + 上市后判断框架**」，**不是「当前一级市场是否买入」的指令**；不含目标仓位、减仓比例、止损价等指令性数值。

## 快速开始

### 基本调用方式
```
/garp-private-company-research {公司名}
```

例如：

- `/garp-private-company-research 蚂蚁集团`
- `/garp-private-company-research 小红书`
- `/garp-private-company-research SpaceX`
- `/garp-private-company-research 某Pre-IPO公司`

### 可选参数

| --- | --- | --- | --- |

| `--focus` | `商业模式` / `财务与估值` / `竞争格局` / `管理层` / `技术` / `上市时机` | 全维度 | 研究侧重 |

| `--json` | 开关 | 关 | 输出结构化结果 |

> **本技能不提供任何档位切换参数**——它即 GARP 独立档（1~5 年）未上市公司预研建档的专属入口；档位切换类口令属其他档位口径，出现即违反**三档语域隔离**（`GPC-12`）。

### 核心问题

不是「现在值多少钱」，而是「**上市后值得持有吗**」。

最终输出：**林奇六类分类** + **财务五门槛推演** + **渗透率 `15%~40%` 黄金窗定位** + **国产化率四梯队并列标注** + **管理层 / 地缘 / 估值 / 卖出四重只读结论** + **双结论**（是否值得等待上市 · 上市后是否适用 GARP 框架）。

## 核心功能

对指定未上市公司启动 6 路并行 Agent，通过多源拼凑、交叉验证与置信度标注，产出 GARP 适配性预判。

### 适用场景
- 研究**未上市公司**（Pre-IPO / 独角兽 / 一级市场标的），判断其上市后是否可能成为符合 GARP 独立档（1~5 年）框架的标的
- 已知某公司即将 IPO，想提前建立判断框架，上市后第一时间可跟踪
- 为 GARP 投资建立的**未上市标的池预研建档**

### 不适用场景
- **已上市公司**（有公开财报与股价）→ 转 `/garp-investment-research`（单 Agent）或 `/garp-investment-team`（多 Agent 团队）
- **现在是否买入未上市股权 / 一级基金份额** → 本技能不回答一级定价是否值得，只回答上市后是否符合 GARP 框架
- **其他持有周期口径的未上市公司研究** → 本技能不覆盖，请按持有周期路由至对应档位入口

### 6 路 Agent 并行
| Agent | 核心任务 | 对应大师 |
| --- | --- | --- |
| `business-decoder`（商业模式解码） | 商业模式深度拆解 + 林奇六类分类（必答）+ 费雪需求真实性判定 | 林奇 + 费雪 |
| `financial-detective`（财务侦探） | 财务拼凑 + ROE 趋势推断 + 财务五门槛推演 + 上市后估值潜力 | 郑希 + 林奇 |
| `competitive-mapper`（竞争图谱） | 行业景气位置 + 渗透率五档 + TAM 闸门 + 竞争格局 | 郑希 + 李进 |
| `risk-governance-analyst`（风险治理） | 管理层与科研转化（只读）+ 地缘 0.3 矩阵（只读）+ 费雪补充检查 | 李进 + 欧奈尔 |
| `tech-ip-analyst`（技术 IP） | 技术壁垒 + 专利布局 + 科研转化效率 | 李进 |
| `signal-miner`（信号挖掘） | 替代数据信号 + 上市时机验证 | 欧奈尔 |

> **刚性**：6 路 Agent **必须在同一条消息中并行调用 6 次任务工具**；**不扩为 7 路**；**费雪不作为独立 Agent**，其质化三问注入任务 1（需求真实性）与任务 4（销售组织 + 管理层持股 ≥3% / 暂时性困难 vs 永久性衰退）。

### 七步执行流程

1. **确认参数与信息可得性分级** — 公司名 + 拟上市市场 + 融资阶段 + 研究侧重（信息不足**先反问，不默默假设**）；评定 A / B / C 级
2. **同一条消息并行启动 6 路 Agent** — 每路均显式知悉「信息可得性等级（A/B/C）」与「GARP 独立档（1~5 年·五大师）」背景
3. **接收报告并跟踪进度** — 每收到一份报告更新进度与核心要点
4. **交叉验证与信息拼图** — 数据冲突仲裁 + 信号一致性检验 + 反偏见检查
5. **双结论收口** — 「是否值得等待上市」与「上市后是否适用 GARP」**并列输出**（`GPC-1`）
6. **汇总最终报告** — 按十六节结构输出
7. **保存报告与审核** — 写入 `reports/{公司名}/{公司名}-garp-private-{YYYYMMDD}.md`，运行 `tools/common/report_audit.py` 三步审核（`extract` → 取数 → `verdict`）

## 使用示例

### 示例 1：已知即将 IPO 的公司（A 级信息充裕）
```
/garp-private-company-research 蚂蚁集团 --market A股 --stage 已递表
```

6 路 Agent 并行研究，判断蚂蚁若上市：属林奇六类中的哪一类？渗透率落在哪一档？财务五门槛能否满足？上市后估值潜力落在统一六档的哪一档？双结论分别是什么？

A 级信息下，重点转为**降噪与交叉验证**：招股书 / 监管文件为 🟢高信源，媒体推算为 🟡中，冲突项全部列出并说明采信理由。

### 示例 2：冷门未上市公司（C 级信息稀缺，第一性原理模式）
```
/garp-private-company-research 某早期Pre-IPO公司 --first-principles
```

转入「**第一性原理模式**」——不追求报告形式完整，**四问逐问必答**：

1. **需求真伪**：这门生意解决什么真实问题？需求是真需求还是被政策 / 资本催生的伪需求？
2. **渗透率与空间**：渗透率是否落在 `15%~40%` 加速上行期？TAM 是否 ≥1000 亿？
3. **上市后估值潜力档**：只读 `garp-valuation` 统一六档，给出档位结论（本技能**零档位阈值定义、零重算**）
4. **最大「逻辑证伪」信号**：只读 `garp-exit` 五级卖出纪律，指出最可能触发的级别

> 数据须注明**来源与年份**；双源误差 > 5pct 标**低置信**；`<5%` 渗透率且无订单 / EPS 支撑时**直接判题材**。

### 示例 3：仅公司名（需澄清）
```
/garp-private-company-research 小红书
```

先反问拟上市市场、融资阶段、研究侧重——**不默默假设**。澄清未果时以最窄合理口径执行并在报告头部注明。

### 双结论（并列输出，缺一即不合格）

**结论一：是否值得等待上市？**

- ✅ **值得等待**：上市后即纳入 GARP 标的池预研名单
- ⚠️ **有条件等待**：须满足 X / Y / Z 条件（逐条列出）
- ❌ **不值得等待**：不符合 GARP 独立档（1~5 年）框架
- ❓ **需要更多信息**：列出信息缺口

判据六维：商业模式可理解性 / 增长可持续性 / 上市后估值潜力 / 管理层可信度 / 行业景气与渗透率 / 地缘放行。

**结论二：上市后是否适用 GARP 框架？**

- **适用** / **有条件适用** / **不适用**

判据六条：① 六类分类（缓慢增长型 → 不适用）② 诚信前置闸门命中 → **不适用（停止）** ③ 地缘回避档 → **不适用（停止）** ④ 渗透率与 TAM 闸门 ⑤ 财务五门槛（含科技豁免）⑥ 上市后估值潜力档位。

## GARP 适配判断与估值推演

### 林奇六类分类（必答）
| 分类 | 特征 | 上市后 GARP 适配 |
| --- | --- | --- |
| 快速增长型 | 增速 >20%，有大量再投资需求 | ✅ 核心适配 |
| 稳定增长型 | 增速 10%~20%，合理分红 | ✅ 用远期 PE |
| 周期型 | 利润随宏观 / 行业周期波动 | ⚠️ 需景气择时 |
| 困境反转型 | 暂未盈利或增速为负，有望反转 | ⚠️ 看反转证据 |
| 隐蔽资产型 | 含未反映在报表的资产 | ⚠️ 看资产兑现 |
| 缓慢增长型 | 增速 <10%，主要靠分红 | ❌ 不适用 GARP |

### 渗透率位置判定（五档固定）
| 档位 | 判定 | 行动含义 |
| --- | --- | --- |
| `<5%` | 导入早期 | 观察不建仓；**`<5%` 且无订单 / EPS 支撑 → 判题材** |
| `5%~15%` | 突破期 | 高弹性，小仓跟踪 |
| **`15%~40%`** | **加速上行期（黄金窗口）** | **主建仓窗口** |
| `40%~60%` | 逐步兑现期 | 持有，不再新建仓 |
| `>60%` | 天花板 | 即便增速未转负也不加仓 |

- **TAM 闸门**：**TAM <1000 亿 → 黄金窗判定不成立**，须显式标注（`GPC-4`）。
- **国产化率四梯队并列标注**：`<5%` 过早 / `5%~20%` 突破期 / `20%~50%` 加速投资期 / `>50%` 替代空间收窄；**只读** `garp-geo-policy` 的 `localize` 结论，本技能**不自评、不定档**；`>50%` 档位**不淘汰**，但须标注「**逻辑转向龙头份额提升与整机放量**」。
- 报告第五节须显式列出「**渗透率档位 + TAM 判定 + 国产化率梯队**」三列表，**不得隐式判定**。

### 财务五门槛（只读，不重定义）
| # | 门槛 |
| --- | --- |
| 1 | 营收 ≥10 亿 |
| 2 | 近 3 年营收 CAGR ≥15% |
| 3 | 负债率 <60% |
| 4 | 经营现金流为正 |
| 5 | 3 年内 ≥2 年扣非净利润为正 |

**科技豁免**：营收连续增长 + 经营现金流为正 + **研发强度 ≥15%**，可豁免部分门槛（口径只读框架第 2 步与 `garp-investment-checklist`）。

### 上市后估值潜力推演（只读 `garp-valuation`，`GPC-9`）
- **权威出口**：`garp-valuation` **多工具矩阵统一六档** + **ESG 环境折价** + **宏观校准后 PEG 合理区间**（宏观只读 `garp-macro` 三表：利率 / 经济 / 美林）。
- **本技能边界**：**零档位阈值定义、零档位重算**；上游结论不可得时，**仅呈现原始指标、不下档位结论、不得自行补算**。
- **未上市场景特化**：最近融资估值法保留为**当前一级定价锚**（须显式计算**一二级折溢价**）；可比上市公司法改造为对标已上市 GARP 标的的调整后 PEG / EV-Sales 区间；交易对标法保留作交叉验证。
- **禁用**：终局市值倒推法与十年尺度 DCF（长期档口径）；如需 DCF 走 `garp-valuation` 转接。
- **宏观落位**：仅用于调整 PEG 区间与仓位尺度参数；报告须显式声明「**宏观结论不作为清仓 / 择时理由**」。

### 管理层与科研转化（只读 `garp-management`）
- **口径**：**诚信前置（不计分闸门 4 项：兑现率 <50% / 业绩预告失真 / 监管立案 / 财务造假 → 放弃）** + 对待股东 7 + 战略执行 7 + 稳定性激励 6，**≥15 可重仓**。
- **科研转化 20 分制** = 研发投入 8 + 研发产出 8 + 资本回报 4，**≥15 可重仓**。
- **映射说明**：旧版否决项中的「大股东质押率 >50%」**不属诚信前置四项**，**降级为风险提示项**（影响稳定性激励计分），**不构成放弃**；其余四项与 GARP 诚信前置**同向**。
- **诚信否决 → 直接判定「上市后不适用 GARP 框架」**。

### 地缘政治（只读 `garp-geo-policy`）
- 只读 **0.3 三维交叉矩阵** + **赛道两分法（地缘倒逼型 / 政策资本驱动型）** + **国产化率四梯队**。
- **回避档 → 直接判「不适用」**；**地缘倒逼型**以「地缘倒逼强度非低 / 无」为**硬门槛**；**政策资本驱动型**仅作**敞口体检**。
- **地缘不入五级卖出表**。

### 卖出纪律（只读 `garp-exit` 五级）
| 级别 | 触发 |
| --- | --- |
| 一级 | 诚信否决（前置） |
| 二级 | 硬止损 8%~10% |
| 三级 | 逻辑止损（连续 2 季业绩低于预期） |
| 四级 | 产业景气判断 |
| 五级 | 估值判断 |

- **补充机制**：时间止损 / 性价比替换——与五级**并列、不占优先级**。
- 本技能只做「**上市后若持有，触发时应转 `/garp-exit` 复核**」的**预提醒**，**不判定级别、不计算止损价**。

## 核心原则

1. **反偏见优先** — 资料少 ≠ 公司不好；AI 分析篇幅短 ≠ 投资确定性低
2. **双结论必须回答** — 每份报告必须**并列**给出「是否值得等待上市」与「上市后是否适用 GARP 框架」（`GPC-1`）
3. **六类分类必须完成** — 林奇六类分类是 GARP 框架的入口
4. **费雪三问刚性落位** — 需求真实性（任务 1）；销售组织 + 管理层持股 ≥3%（任务 4）；暂时性困难 vs 永久性衰退（任务 4）；上市后持有信念边界（报告第十一节）
5. **渗透率与 TAM 双闸门** — 渗透率必须落在 `15%~40%` 且 TAM ≥1000 亿，黄金窗才成立
6. **财务五门槛只读** — 不在本技能内重定义阈值
7. **四重只读** — 管理层 / 地缘 / 估值 / 卖出一律**只读** `garp-*` 权威出口，**零阈值定义、零重算**
8. **诚实留白** — 信息不足时明确说「数据缺失」，不用推测填满表格伪装确定性
9. **区分事实与推理** — 事实用正常字体，推理 / 推算用*斜体*并标注推算方法
10. **多源交叉验证** — 关键数据至少 2 个独立来源，冲突时全部列出并说明采信
11. **信号一致性检验** — 增长信号 vs 招聘信号、技术叙事 vs 专利数据、管理层叙事 vs 实际行动
12. **反向利用信息不对称** — 信息越少，定价效率越低，潜在认知差越大
13. **上市后视角导向** — 最终目标是判断「值不值得等待上市」，不是输出一份好看的报告
14. **不替用户做决策** — 给出判断与建议清单，但买卖决策由用户做

## 注意事项
- 禁止使用 `WebSearch` 与 `WebFetch` 工具（中国大陆地区不可用）
- **6 路 Agent 必须在同一条消息中并行启动**，且**不扩为 7 路**；费雪**不作为独立 Agent**
- 如果用户只给公司名，先反问拟上市市场 / 融资阶段 / 研究侧重，**不要默默假设**
- 信息可得性等级（A / B / C）须告知每路 Agent，影响其检索策略与置信度标注
- 每个关键数据标注来源（具体到媒体与文章标题）、时间（精确到年月）、置信度（🟢高 / 🟡中 / 🔴低）
- 不支持编造「估算数据」冒充「有据分析」；无法获取的信息明确标注「数据缺失」
- **报告不写指令性数值**：不出现「目标仓位 X%」「减至 X%」「清仓」「ATR 止损价」等表述
- **本技能不外答「当前一级市场是否买入」**
- 估值与财务计算使用 `financial_rigor.py` 精确计算，禁止 LLM 心算；跨币种折算用 `fx_rate.py` 实时汇率
- 报告保存后运行 `report_audit.py` 三步审核；未通过审核的报告是草稿，不是可发布的研究
- 术语红线：禁止「护城河永续」「终局思维」「持有 10 年」「论文已破」等长期档术语；壁垒表述统一为「**1~5 年景气竞争力**」
- Windows 环境兼容：不使用 `/tmp/`；静默错误用 `2>$null`；不使用 `tr -d '\r'`

## 局限性说明
- **信息可得性**：未上市公司信息天然稀缺，部分维度可能完全无法获取数据
- **数据准确性**：第三方推算数据可能有较大误差，双源误差 > 5pct 须标低置信
- **监管披露差异**：未上市公司的合规披露标准低于上市公司，历史数据可比性弱
- **估值不确定性**：缺乏公开市场锚定，上市后估值潜力档位推演可能偏差较大
- **渗透率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算并注明来源与年份
- **管理层判断的间接性**：无财报硬约束，诚信与科研转化几乎全凭公开信息推断
- **上市时点不可控**：本技能判断的是「上市后是否适用」，**不预测 IPO 时点**
- **AI 解读局限**：AI 无法完全替代深入的公司调研
- **非实时数据**：工具获取的数据可能有延迟，不是实时数据
- **不构成投资建议**，仅用于学习与研究
