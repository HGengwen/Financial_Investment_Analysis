# 未上市公司研究（GARP 独立档·1~5 年）：上市后 GARP 适配性预判建档层
对 `$ARGUMENTS` 执行「未上市公司 GARP 预研建档七步法」：**参数确认与信息可得性分级 → 6 路 Agent 并行（注入费雪质化）→ 信息拼图与交叉验证 → 双结论收口 → 十六节报告准出**。

**最终目标**：判断这家未上市公司——**如果上市，是否符合 GARP 独立档（1~5 年·五大师）框架？是否值得等待上市？** 核心问题不是「现在值多少钱」，而是「**上市后值得持有吗**」。
> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

> 本技能是**上市前的「预研建档」工具**：为上市后的 GARP 投资提前建立标的池与判断框架，而非研究「现在是否买入未上市股权」。**输出的是「上市前预研建档 + 上市后判断框架」，不是「当前一级市场是否买入」的指令。**

**支持输入格式**：
- `{公司名}` —— 如 `蚂蚁集团` / `小红书` / `SpaceX`
- `{公司名} --market {A股/港股/美股/其他}` —— 拟上市市场
- `{公司名} --stage {Pre-IPO/已递表/辅导备案/暂无计划}` —— 融资阶段
- `{公司名} --focus {商业模式/财务与估值/竞争格局/管理层/技术/上市时机}` —— 研究侧重
- `{公司名} --depth {fast|standard|deep} --first-principles --export --export-path {路径} --json`

> **本技能不提供任何档位切换参数**——它即 GARP 独立档（1~5 年）未上市公司预研建档的专属入口；档位切换类口令属其他档位口径，出现即违反**三档语域隔离**（`GPC-12`）。

## 五大师提醒
> 💬 **费雪式提醒**：「**需求真实性**先于增长叙事——需求须有订单 / 收入 / 用户付费等客观数据支撑，否则就是题材；同时看**销售组织**与**管理层持股 ≥3%**，并把回撤区分为**暂时性困难**与**永久性衰退**——这决定上市后回撤时是加仓还是离场，也决定『绝不卖』是否适用。」

> 💬 **林奇式提醒**：「未上市公司的信息天然稀缺，但这不意味着不值得研究——信息越少，定价效率越低，潜在的认知差越大。关键是：你能否在有限信息中**看清这门生意的本质**，并给出六类分类？增长来自真实需求还是题材？」

> 💬 **郑希式提醒**：「未上市公司没有季度财报来验证 ROE 趋势，你需要从融资轮次、用户增长、市场份额等替代指标去推断——ROE 向上才是科技股最可靠的重力加速度；若推断 ROE 向下，景气逻辑需要重新审视。」

> 💬 **李进式提醒**：「**渗透率落在 `15%~40%` 加速上行期**才是黄金窗口，且 **TAM 须 ≥1000 亿**；未上市阶段还要并列标注**国产化率四梯队**。不仅看产业是否增长，更看增速的**加速度（二阶导）**。」

> 💬 **欧奈尔式提醒**：「未上市公司没有股价让你止损——这意味着你的『买入决策』必须更谨慎，因为没有公开市场让你快速纠错。信号会藏在融资轮次、辅导备案、招聘与赛道热度里；上市后硬止损底线**只读** `garp-exit`，本技能不得自建、不得重算。」

> **本工作流用于学习与研究，不构成投资建议。**

## 一、设计理念（五大师视角）
本技能绑定 GARP 独立档（1~5 年）的五位大师，取代其他档位口径：
| 大师 | 核心方法论 | 在本技能中的落点 |
| --- | --- | --- |
| **费雪** | 质化分析 · 闲聊法 | **需求真实性判定**（任务 1 必答）；**销售组织 + 管理层持股 ≥3%**（任务 4 费雪补充检查）；**暂时性困难 vs 永久性衰退**（任务 4 + 报告第十二节语境）；**上市后持有信念边界**（报告第十一节） |
| **林奇** | 侦探思维 · 常识与求证 | **六类分类**（必答入口）；核心生意「讲得清吗」；增长来自真实需求还是题材；估值锚只读 `garp-valuation` |
| **郑希** | 物理学家思维 · 第一性原理 | 从碎片信息推断 **ROE 趋势（↑/→/↓）**；产业景气位置与拐点；全球产业链中哪个环节率先景气；伪 α 判定 |
| **李进** | 系统工程师思维 · 均衡与渗透率 | **渗透率 `15%~40%` 黄金窗定位**；二阶导判断增速加速度；国产化率四梯队并列标注；均衡与回撤控制 |
| **欧奈尔** | 工程师思维 · 信号与纪律 | **替代数据信号一致性**；题材炒作 vs 真实趋势辨识；上市后硬止损纪律只读 `garp-exit` |
> 五大师**顺序固定**：**费雪 / 林奇 / 郑希 / 李进 / 欧奈尔**；头部引语块、第九节透镜表、附录 A 速查卡**三处同序**（`GPC-7`）。

## 二、适用场景与不适用场景
### 适用场景
- 研究**未上市公司**（Pre-IPO / 独角兽 / 一级市场标的），判断其上市后是否可能成为符合 GARP 独立档（1~5 年）框架的标的
- 已知某公司即将 IPO，想提前建立判断框架，上市后第一时间可跟踪
- 为 GARP 投资建立的**未上市标的池预研建档**

### 不适用场景
| 情形 | 去向 |
| --- | --- |
| **已上市公司**（有公开财报与股价） | 转 `/garp-investment-research`（单 Agent）或 `/garp-investment-team`（多 Agent） |
| **现在是否买入未上市股权 / 一级基金份额** | **本技能不回答**「当前一级定价是否值得买入」，只回答「上市后是否符合 GARP 框架」 |
| **行业级赛道六维测算与逐层漏斗精选** | 转 `/garp-industry-research` / `/garp-industry-funnel` |
| **供应链瓶颈分层与第二、三层机会** | 转 `/garp-bottleneck-hunter` |
| **建立 1~3 年或 10 年口径** | 本技能为 GARP 独立档（1~5 年），与其他档位口径**物理隔离** |

## 三、框架特点（未上市 vs 上市差异）
- **无标准化财报**：需多源拼凑、交叉验证；财务五门槛只能做「上市后是否可能满足」的**推演**
- **估值锚定少**：依赖最近融资一级定价锚、可比已上市 GARP 标的区间、情景推演；档位一律只读 `garp-valuation`
- **信息不对称大**：需要更多「拼图式」研究方法，允许维度留白
- **退出路径不确定**：IPO / 并购 / 二级转让 / SPAC 均有可能
- **无公开市场信号**：没有股价让你判断「便宜还是贵」，也没有技术面确认，只能靠替代数据与信号一致性

## 四、AI 研究偏见自觉（本框架的核心前提）
未上市公司是 AI 研究偏见最严重的领域。必须时刻警惕以下陷阱：
| # | 偏见 | 应对 |
| --- | --- | --- |
| 1 | **虚假保守** | 资料少 ≠ 公司不好；AI 分析篇幅短 ≠ 投资确定性低；不得因资料少就一律给保守结论 |
| 2 | **虚假精确** | 禁止用「合理推测」伪装「有据分析」；宁可留白，不用推测填满表格 |
| 3 | **对标陷阱** | 对标已上市 GARP 标的的**调整后 PEG / EV-Sales 区间**，而非继承同类公司绝对市值逻辑 |
| 4 | **幸存者偏差** | 能搜到的信息往往有正面偏向（公司主动传播的多是好消息），须主动搜负面与反常信号 |
| 5 | **线性外推偏差** | 不得将短期高增速外推多年，须用渗透率档位与二阶导校正 |
| 6 | **共识偏好** | 禁止引用「市场共识」「机构观点」作为论据 |

**核心原则**：**资料少 ≠ 公司不好；AI 分析篇幅短 ≠ 投资确定性低；允许留白。**

**反向利用信息不对称**：市场对未上市公司信息少 → 定价效率低 → 恰恰可能是超额收益的来源。AI 研究的目标不是消除信息不对称（做不到），而是在有限信息中提取最关键的判断依据。

### 第一性原理模式（C 级信息稀缺专用，四问**逐问必答**）
信息可得性为 **C 级**（或 A/B 级但关键维度数据缺失）时启用；允许其余章节留白，**不追求报告形式完整**：
| # | 核心问题 | 口径出处 |
| --- | --- | --- |
| 1 | 这门生意解决什么真实问题？**需求是真需求还是伪需求？** | 费雪需求真实性 |
| 2 | 赛道渗透率是否落在 **`15%~40%` 黄金窗**？**TAM 是否 ≥1000 亿**？ | 框架第 1 步 |
| 3 | 如果上市，**估值潜力**在哪一档？ | **只读** `garp-valuation` 统一六档 |
| 4 | 最大的「**逻辑证伪**」信号是什么？ | **只读** `garp-exit` 五级卖出 |

## 五、研究纪律
1. **日期确认**：研究前运行 `date` 确认当天日期，以此作为「最新数据」的基准，并在报告头部注明数据截止日期。不得依赖训练数据中的日期假设。
2. **数据交叉验证**：关键财务数据须至少来自两个独立来源，误差 >1% 须标记。每个关键数据必须标注来源、时间与置信度。
3. **区分事实与推理**：事实用正常字体，推理 / 推算用*斜体*并标注推算方法；无法获取的信息明确标注「**数据缺失**」，不编造。
4. **精确算术工具**：估值计算、一二级折溢价、跨源校验一律使用 `tools/common/financial_rigor.py`，**禁止 LLM 心算**（`GPC-11`）。
5. **跨币种折算**：先用 `python tools/common/fx_rate.py --code USDCNY`（或 `HKDCNY`）获取汇率，勿用固定汇率。
6. **不确定性标注**：明确标注低置信度结论、不完整数据及来源缺口；推算过程完全透明（展示计算逻辑与每一步假设）。
7. **诚实留白**：信息不足以做出可靠判断时直接说「信息不足」；允许出现「此维度数据缺失，无法给出有意义的结论」。
8. **反偏见核心原则**：见第四节；C 级信息转第一性原理模式聚焦核心问题。
9. **报告审核**：报告保存后，必须走 `report_audit.py extract` → 取数核验 → `report_audit.py verdict` 三步；未通过审核的报告是草稿，不是可发布的研究。

**⚠️ GARP 专有纪律**：
10. **双结论必须回答**（`GPC-1`）：每份报告必须**并列**回答「是否值得等待上市」与「上市后是否适用 GARP 框架」，缺一即不合格。
11. **六类分类必须完成**：林奇的六类分类是 GARP 框架的入口，未上市公司也必须判断类型。
12. **渗透率必须推算**：即使没有官方数据，也要基于行业数据做合理推算并标注置信度；<5% 且无订单 / EPS 支撑 → **判题材**。
13. **四重只读**：管理层（`garp-management`）/ 地缘（`garp-geo-policy`）/ 估值（`garp-valuation`）/ 卖出（`garp-exit`）一律**只读**，本技能零计分、零定档、零阈值定义。

## 六、执行流程（七步）
### 第一步：确认参数与信息可得性分级
- **参数确认**：公司名（中文/英文）、**拟上市市场**（A股/港股/美股/其他）、**融资阶段**（Pre-IPO / 已递表 / 辅导备案 / 暂无计划）、**研究侧重**。
- **刚性**：信息不足时**先反问，不默默假设**（`GPC-1`）；澄清未果则以最窄合理口径执行并在报告注明。
- **信息可得性分级**：

| 等级 | 特征 | 研究策略 |
| --- | --- | --- |
| **A 级（信息充裕）** | 已递表 / 有招股书 / 母公司披露多 | 重点是降噪与交叉验证；可对标已上市 GARP 标的 |
| **B 级（信息适中）** | 有融资记录、部分媒体覆盖 | 标准模式；每关键数据 1~2 个独立信源 |
| **C 级（信息稀缺）** | 早期 / 冷门 / 无招股书 | 转**第一性原理模式**（第四节四问）+ 替代数据 |
- 分级须**告知每一路 Agent**，影响其检索策略与置信度标注（`GPC-3`）。

### 并发前置：东财闸门自检（必做）

启动并行 Agent **之前**，先执行：

```bash
python tools/common/em_gate.py status
```

输出为仓库统一三层信封，判定字段位于 `data.*`：

| 字段 | 含义 | 处置 |
| --- | --- | --- |
| `data.allowed` | 当前是否放行东财请求 | `false` → **改为串行**或**延后到盘后** |
| `data.circuit` | 熔断器状态（`closed` / `open`） | `open` → **停止并发**，改串行或延后盘后 |
| `data.remaining_min` / `data.remaining_5min` | 剩余预算 | 偏低时优先读缓存、只对目标标的定向取数 |

放行时可直接并行：东财请求由**跨进程闸门串行**排队，预期耗时 ≈ 东财请求数 × 1.2s，N 路 Agent **不会**叠加出 N 倍 QPS。

> **命名区隔**：本步是**数据面并发闸门**，与本文档「第 0 步：地缘政策前置」无关，两者不可混用。
> 依据：《AKShare东方财富反爬限流改进方案.md》§3.3 / §3.5 / §3.6。

### 第二步：同一条消息并行启动 6 路 Agent
- 使用 Task 工具**必须在同一条消息中并行调用 6 次**；`subagent_type` = `general_purpose_task`。
- 每路任务描述模板须含八要素（见「六·附 1」）：**角色 / 研究背景 / 任务 / 研究要求 / 研究方法 / 搜索工具规范 / 数据标注规范 / 输出要求（含 GARP 适配性初步判断 + 费雪三问）**。
- 六路分工见下表（**不扩为 7 路**，费雪**不作为独立 Agent**）：

| # | Agent | 任务重心 | GARP 化差异 |
| --- | --- | --- | --- |
| 1 | `business-decoder` | 商业模式拆解 + 林奇六类分类 | **+ 费雪需求真实性判定**；六类分类必答；GARP 适配性初判 |
| 2 | `financial-detective` | 财务拼凑 + ROE 趋势 | **财务五门槛 + 科技豁免只读**；上市后估值潜力推演**只读** `garp-valuation`；**禁用终局市值倒推法** |
| 3 | `competitive-mapper` | 行业景气 + 渗透率 + 竞争格局 | 渗透率改 **`15%~40%` 五档 + TAM ≥1000 亿**；**并列标注国产化率四梯队**（只读 `localize`） |
| 4 | `risk-governance-analyst` | 治理 / 管理层 / 地缘 | **管理层只读** `garp-management` + **费雪补充检查** + **地缘只读** `garp-geo-policy` |
| 5 | `tech-ip-analyst` | 技术壁垒 + 专利 + 科研转化 | 科研转化**只读** `garp-management`（研发投入 8 / 研发产出 8 / 资本回报 4）；在研管线**只读** `in_research_scan.py pipeline-npv` |
| 6 | `signal-miner` | 替代数据信号 + 上市时机 | **+ GARP 验证信号**（渗透率档位 / ROE 趋势 / 上市后估值潜力档 / 管理层兑现率 / 五级卖出预提醒触发项） |

### 第三步：接收报告并跟踪进度
- 向用户实时展示进度表（哪些 Agent 已完成、哪些仍在研究中）；每收到一份报告，更新进度并展示核心要点 3~5 条；等待 **6 份报告全部到齐**。

### 第四步：交叉验证与信息拼图（team-lead 执行）
**三轮校验**（见「九·工具使用指南」）：
1. **数据冲突仲裁**：提取关键数据，识别冲突，列出全部来源并说明采信理由。
2. **信号一致性检验**：增长信号 vs 招聘信号 / 技术叙事 vs 专利数据 / 管理层叙事 vs 实际行动。
3. **GARP 信号收敛检验**：六路 Agent 的 GARP 判断是否指向同一方向；**五大师结论与六路结论冲突时优先采信冲突信号**并显式写出。

### 第五步：双结论收口（本技能核心差异，`GPC-1`）
| 结论 | 档位 | 判据 |
| --- | --- | --- |

- **两个结论并列呈现、不得互相替代**；判据须**逐条列名**，不得只给结论。

## 十一、风控硬编码（`GPC-1`~`GPC-12`）
| 编号 | 纪律 | 刚性级别 |
| --- | --- | --- |
| **`GPC-1`** | **参数与双结论前置**：参数不足**先反问不假设**；报告须**并列**给出「是否值得等待上市」与「上市后是否适用 GARP」双结论，**缺一即不合格** | 阻断 |
| **`GPC-2`** | **6 路并行刚性**：**必须在同一条消息中并行调用 6 次 Task 工具**；缺路即不合格 | 阻断 |
| **`GPC-3`** | **信息可得性分级贯穿**：A/B/C 分级须**告知每一路 Agent**；C 级转**第一性原理模式** | 阻断 |
| **`GPC-4`** | **渗透率黄金窗**：`15%~40%` 五档 + **TAM ≥1000 亿**；**<5% 且无订单 / EPS 支撑 → 判题材**；**并列标注国产化率四梯队**（只读 `localize`） | 阻断 |
| **`GPC-5`** | **财务五门槛只读**：只读框架第 2 步（含科技豁免）；**不重定义门槛、不自行放宽**；缺失即标注缺失 | 阻断 |
| **`GPC-6`** | **管理层只读 + 诚信前置**：只读 `garp-management`（诚信前置 + 7+7+6 + 科研 8+8+4 + 费雪补充）；**诚信否决 → 直接判「不适用 GARP」**；**不重新计分** | 阻断 |
| **`GPC-7`** | **费雪质化必答**：五大师（费雪 / 林奇 / 郑希 / 李进 / 欧奈尔）固定顺序；**费雪三问**（需求真实性 / 销售组织 + 持股 ≥3% / 暂时性 vs 永久性）**至少四处落位**；**不新增第 7 路 Agent** | 阻断 |
| **`GPC-8`** | **地缘只读**：只读 `garp-geo-policy` **0.3 三维交叉矩阵 + 赛道两分法**；**回避档 → 判「不适用 GARP」**；**零自建地缘维度 / 权重 / 档位**；地缘**不入五级卖出表** | 阻断 |
| **`GPC-9`** | **估值只读 + 禁终局倒推**：只读 `garp-valuation` 多工具矩阵**统一六档** + ESG 折价 + 宏观 PEG 区间；**禁用**十年尺度终值折现工具与终局市值倒推法；**零档位阈值定义** | 阻断 |
| **`GPC-10`** | **卖出只读**：只读 `garp-exit` **五级**（诚信否决 > 硬止损 8%~10% > 逻辑止损 > 产业景气 > 估值）+ 补充机制；**只预提醒、不判定级别、不算止损价** | 阻断 |

## 十二、重要注意事项
1. **6 路 Agent 必须并行启动**——在**同一条消息**中调用 6 次 Task 工具（`GPC-2`）。
2. **双结论必须齐备**——报告第十一节须并列给出两个结论，**缺一即不合格**（`GPC-1`）。
3. **数据置信度标注**——每个关键数据标注来源（媒体 + 标题）、时间（年月）、置信度（🟢/🟡/🔴）。
4. **推算要透明**——所有推算过程展示计算逻辑，不能凭空给数字；无法获取的信息标注「数据缺失」。
5. **四重只读**——管理层 / 地缘 / 估值 / 卖出一律只读，零计分、零定档、零阈值定义（`GPC-6`~`GPC-10`）。
6. **六类分类必须完成**——林奇六类分类是 GARP 框架的入口。
7. **费雪三问必须回答**——需求真实性 / 销售组织 + 持股 ≥3% / 暂时性 vs 永久性（`GPC-7`）。
8. **反偏见核心原则**——资料少 ≠ 公司不好；AI 分析篇幅短 ≠ 投资确定性低；允许留白。
9. **替代数据不是噪音**——招聘、专利、诉讼、App 数据可能比新闻报道更接近真实。
10. **上市后视角导向**——最终目标是判断「值不值得等待上市」，不是输出一份好看的报告。
11. **结论定位与越界红线**——本技能**不回答一级市场是否买入**；**不得**出现「目标仓位 X%」「减至 X%」「清仓」「ATR 止损价」等指令性数值；权威判定归 `garp-valuation` / `garp-exit` / `garp-portfolio-review`。
12. **报告物理隔离**——路径统一 `-garp-private-` 前缀；隔离核验须用完整前缀段或目录级，**禁止以 `-private-` 单串计数下结论**（`GPC-12`）。

## 十三、局限性说明
1. **信息可得性**：未上市公司信息天然稀缺，部分维度可能完全无法获取数据。
2. **数据准确性**：第三方推算数据可能有较大误差。
3. **监管风险**：未上市公司的合规披露标准低于上市公司。
4. **估值不确定性**：缺乏公开市场锚定，上市后估值潜力区间推演可能偏差较大。
5. **渗透率与国产化率数据可得性**：细分行业缺乏官方统计，依赖第三方估算，双源误差 >5pct 须标低置信。
6. **上市后适配性判断存在固有偏差**：上市后信息环境与经营条件可能显著变化，本技能给出的是**上市前时点的预判**，上市后须以实际披露复核。
7. **骨架继承的未上市信息稀缺限制**：本技能结构继承自既有未上市公司研究骨架并作 GARP 口径替换，**非框架原文**；底层信息稀缺限制被一并继承。
8. **AI 解读局限**：AI 无法完全替代深入的公司调研；存在成熟行业偏好、龙头偏好、英文偏好等筛选偏见。
9. **非实时数据**：工具获取的数据可能有延迟。
10. **不构成投资建议**：本技能仅用于学习与研究。
