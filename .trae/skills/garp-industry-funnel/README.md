# garp-industry-funnel — GARP 行业漏斗精选（1~5 年独立档）

> **技能命令**：`/garp-industry-funnel {行业名}`
> **所属档位**：GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔）
> **适用口径**：赛道已确认后的**行业层第二站**——赛道内候选池逐层漏斗，收敛「3 家底仓 + 2 家机动仓」
> **开发任务**：P4-10（行业漏斗层技能；开工门禁 A~H 全部按推荐确认）
> **版本**：1.0.0（2026-09-18）

---

## 一、技能用途

### 一句话定位

把《中长期价值成长（GARP）投资框架》**第 2 步「个股初筛」与第 3 步「深度研究」**落地为一张可执行的行业精选漏斗：

**解析输入（三日期基准）→ 赛道确认与候选池构建（引用 `garp-industry-research`）→ 能力圈四维自检闸门 → 6 硬指标粗筛（含财务五门槛 + 科技豁免）→ 五大支柱精析（含 ROIC 四档 / 护城河 / 0.3 三维交叉矩阵 / 支柱五政策与资本覆盖度）→ 五大师研判与五大矛盾化解 → 3 底仓 + 2 机动仓输出（阶段化仓位 / 建仓价区间 / 硬止损价 / 景气监测指标）→ `GF-1`~`GF-12` 检查 → 十二节报告。**

本技能是**行业层第二站**——它只回答「**这条赛道里具体买哪几家、仓位怎么配**」；**不重做赛道级测算**、**不定义估值档位**、**不定义卖出级别**、**不替代买入前七关检查**。

### 何时用

- 赛道已完成行业研究（评级 A / B），需要把候选池收敛为可执行的终选组合；
- 需要把「能力圈是否看得懂」变成一个可淘汰的闸门，而不是模糊感受；
- 需要判断科技股能否走**科技豁免**路径（现金流为正 + 营收连续增长 + 研发强度 ≥15%）；
- 需要做五大支柱交叉验证（含新增的**政策与资本覆盖度**）；
- 需要给出「3 家底仓 + 2 家机动仓」的阶段化仓位、建仓价区间与硬止损价。

### 何时不用

| 场景 | 应使用的技能 |
| --- | --- |
| 赛道级研究（TAM / 渗透率 / 国产化率 / 产业链 / Tier 分层） | `garp-industry-research`（P4-9） |
| 个股深度研究与买入决策 | `garp-investment-research`（P4-12）/ `garp-investment-team`（P4-13） |
| 买入前门槛检查（七关） | `garp-investment-checklist`（P4-3） |
| 估值档位判定（贵不贵 / 建仓节奏） | `garp-valuation`（P4-5） |
| 卖出执行与止损 | `garp-exit`（P4-6） |
| 管理层与科研转化评分 / 诚信闸门 | `garp-management`（P4-4） |
| 地缘与政策资本前置闸门 | `garp-geo-policy`（P4-1） |
| 组合合规校验与调仓建议 | `garp-portfolio-review`（P4-8） |
| 纯技术面体检 | `trend-momentum-scan`（通用复用 2 技能） |

## 二、适用口径与隔离声明

- **适用口径**：本技能属 **GARP 独立档（1~5 年，五大师）**，介于项目既有「1~3 年景气投资」与「10 年护城河投资」两档之间。
- **隔离声明**：
  1. 本技能**不引用** 1~3 年档位与 10 年档位的任何技能口径；其编号体系与本技能的 `GF-*` 体系**物理隔离**；
  2. 估值档位**只来自** `garp-valuation`（P4-5，GARP 档）的**统一六档 + 多工具矩阵**，本技能零 PEG 算式，只落 **1.5 高估线**与 **2.0 淘汰线**两条阈值；
  3. 卖出层级为「**一级 ~ 五级**」，**只引用** `garp-exit`（P4-6）的定义，不重定义、不使用其他档位的层级编号体系；ATR 止损价**经其转接**，本技能不自建止损链；
  4. 地缘口径**唯一**为 **0.3 三维交叉矩阵 + 赛道两分法**（硬门槛 / 敞口体检）；本技能**不做**地缘敞口多维度打分、**不做**估值折价；
  5. 管理层口径为**诚信前置（不计分闸门）+ 7+7+6**，科技股**再叠加**科研转化 **8+8+4**；
  6. 产出文件为 `reports/industry/{行业名}-garp-funnel-{YYYYMMDD}.md`，**与 1~3 年档 / 10 年档的报告文件物理隔离**、互不覆盖；
  7. 复用类技能仅限全档位通用的 2 个（`qoq-accelerator`、`trend-momentum-scan`）；
  8. **不修改**既有行业漏斗技能；本技能为**独立目录技能**（门禁定例「否，独立目录技能」）。
- **本技能不提供档位切换参数**——它即 GARP 独立档专属入口；档位切换类口令属其他档位口径，出现即违反口径隔离纪律。

## 三、命令与报告路径

```bash
/garp-industry-funnel {行业名}
/garp-industry-funnel {行业名} --scope A股 --export
/garp-industry-funnel {行业名} --depth deep --json
```

| 输入项 | 说明 |
| --- | --- |
| `{行业名}` | 赛道 / 行业名（如 `AI 光模块`） |
| `--scope` | 候选池范围：`全球` / `A股` / `港股` / `美股`（默认 `全球`） |

| `--export` / `--export-path` | 导出报告；默认根路径 `reports/industry/` |
| `--json` | 输出结构化 JSON |

```text
reports/industry/{行业名}-garp-funnel-{YYYYMMDD}.md
```

> **保留全部历史文件，不删除不覆盖**；同日多次加 `-v2` / `-v3`（开工门禁 F 项）。
> **报告头部须含三日期**：数据基准日 / 报告生成日 / 下一复核日。

## 六、关键口径速查

### 6.1 逐层漏斗与配额

| 层 | 名称 | 输入 → 输出 | 淘汰方式 |
| :--: | --- | --- | --- |
| 0 | 赛道确认 | 赛道评级 → 候选池 **30~60 家** | 非 A/B → 终止（`GF-1`） |
| **1** | **能力圈四维自检**（新增层） | 30~60 家 → 通过者 | **未通过即淘汰**（`GF-8`） |
| 2 | 6 硬指标粗筛 | 通过者 → **10~20 家** | 任一不过即淘汰（`GF-2`~`GF-6`） |
| 3 | 五大支柱精析 | 10~20 家 → **5~8 家** | 一票否决命中即出局；部分不达标降观察仓 |
| 4 | 五大师研判 | 5~8 家 → **3 底仓 + 2 机动仓** | 矛盾化解与决策优先级收口 |
| 5 | 综合输出 | 3+2 → 报告 + JSON | 仓位上限校验（`GF-10`） |

> **每层做淘汰、不做打分累积**；淘汰须给出**规则编号**与**证据行**。

### 6.2 能力圈四维自检（漏斗第一层闸门）

| 维度 | 自检问题（须能独立回答「是」） |
| --- | --- |
| 产业理解 | 产业链有几层？上游关键设备/材料来自谁？下游客户是谁？前五大玩家份额多少？ |
| 财务理解 | 营收 / 毛利率 / 应收存货 / 经营现金流分别在哪张表？关键科目变动意味着什么？ |
| 估值理解 | 除 PE/PEG 外，能否再用 PS、EV/Sales、DCF、可比公司法交叉验证？ |
| **技术理解**（**科技股必答**） | 不同技术路线的原理 / 成本 / 适用场景 / 主流玩家分别是谁？ |

> 普通行业须「产业理解 + 财务理解 + 估值理解」三项同过；科技股再叠加「技术理解」**必选**。任一必需维度未过 → 视为能力圈之外 → **淘汰 + 三选一建议**（补课 / 低仓位观察仓 / 放弃）。结论标注「**自评项，非工具化判据**」。

### 6.3 6 硬指标与财务五门槛（含科技豁免）

| # | 硬指标 | 通过标准 | 编号 |
| :--: | --- | --- | :--: |
| 1 | 产业景气度 | 季度营收增速 > 行业平均；或高频数据连续 2 月环比向上 | — |
| 2 | 财务健康（五门槛） | 营收 ≥10 亿 / 3 年营收 CAGR ≥15% / 资产负债率 <60%（金融地产除外）/ 经营现金流净额为正 / 近 3 年 ≥2 年扣非为正 | `GF-2` |
| 3 | 估值底线 | 调整后 PEG ≤1.5 方可入底仓候选；>1.5 仅机动仓观察；>2.0 出终选；宏观 PEG 区间动态调整 | `GF-3` |
| 4 | 流动性 | 日成交额 >1 亿；市值 <100 亿可放宽至 >3000 万 | `GF-4` |
| 5 | 治理底线 | 无立案 / 无大额违规担保 / 非标审计一票否决；ESG 行业尾部**先降仓位上限** | `GF-5` |
| 6 | 地缘红线 | 地缘倒逼型：0.3 矩阵不得归「回避」档；政策资本驱动型：仅作敞口体检 | `GF-6` |

> **科技豁免**：扣非为负**仅由研发费用化压低当期利润**所致，且同时满足「① 经营现金流净额为正 ② 营收连续增长 ③ 研发强度 ≥15%」→ 豁免「扣非净利润为正」**单项**；**治理与 ROIC 不豁免**，豁免标的**仅机动仓观察**。

### 6.4 五大支柱与 0.3 三维交叉矩阵

| 支柱 | 核心验证点 |
| --- | --- |
| 一 产业景气度（β） | 供需 / 价格 / CR5；渗透率黄金窗 **15%~40%** |
| 二 公司基本面（α） | ROE 趋势、毛利率、增速匹配度、**ROIC 四档**、**可量化护城河** |
| 三 管理层与科研转化 | **诚信前置**（不计分）+ **7+7+6**（≥15 可重仓）；科技股再叠加 **8+8+4**（两套均须 ≥15） |
| 四 地缘政治与外部环境 | 0.3 矩阵行归属 + 赛道两分法（硬门槛 / 敞口体检）；时变项实时核验 |
| **五 政策与资本覆盖度**（新增） | 注资强度落到标的、场景绑定是否兑现为可验证订单/收入/量产、政策门槛优势 |

> **ROIC 四档**：优秀 >15%（可支持单只上限上浮至绝对 20%）；合格 >WACC 且 ≥10%；部分不达标 5%~10%（观察仓）；一票否决 = 长期 <5% 且仍在拼命扩产。

六类场景：**最优场景 / 次优场景 / 潜伏场景 / 高风险·回避 / 政策驱动型增量创造 / 回避**（矩阵全文见同目录 [SKILL.md](./SKILL.md)）。

> **刚性附带条款**：① 未列组合按**更审慎相邻档**归档；② 国字号注资**非买入估值依据**；③ 时变项须**实时核验，勿沿用历史清单**；④ **赛道两分法**——地缘倒逼型作硬门槛、政策资本驱动型作敞口体检，非互斥时按更审慎那类执行。

### 6.5 五大师与五大矛盾

| 大师 | 本技能落点 |
| --- | --- |
| **费雪**（新增） | 能力圈闸门 + 支柱三质化项 + 「绝不卖」两前提检验 |
| 林奇 | 草根调研、PEG、自由现金流、扣非匹配 |
| 郑希 | 渗透率坐标、ROE 曲线、供需模型 |
| 李进 | 3+2 结构、底仓/机动分离、回撤控制 |
| 欧奈尔 | 动量/技术面确认、8%~10% 硬止损 |

> **矛盾五（新增）**：费雪「绝不卖」vs 趋势/景气纪律——「不卖」有**两个缺一不可的前提**（极度深度的研究认知 + 极度集中的持仓）；缺乏前提或属永久性衰退 → 按纪律离场。

### 6.6 五级卖出与止损状态（引用 `garp-exit`）

| 级别 | 触发（引用 P4-6 口径） |
| --- | --- |
| **一级 · 诚信否决** | 失信 / 造假实锤 / 监管立案 |
| **二级 · 硬止损** | 单笔亏损 **8%~10%** 且无明确基本面反转信号 |
| **三级 · 逻辑止损** | 连续 2 季低于预期且景气未改善；**或持有满 4 季度逻辑未兑现（时间止损）** |
| **四级 · 产业景气判断** | 渗透率 / ROE 拐点 / 增速归零或转负 |
| **五级 · 估值判断** | 调整后 PEG > 1.5（> 2.0 严重透支）/ 情绪多信号共振 |

| 仓位状态 | 操作 |
| --- | --- |
| 建仓初期（持仓 < 最终仓位 50% 或逻辑未验证） | **8%~10% 硬止损**（**禁用 ATR**） |
| 底仓已建立且逻辑已验证 | 2~3 × ATR(14) 动态跟踪，**受 20% 底仓容忍度封顶** |
| 逻辑证伪（任意仓位） | 立即清仓 |
| 持有 > 4 季度未兑现 | **时间止损** |

> **ATR 止损价一律经 `garp-exit` 转接** `momentum.stop_price()`；本技能**不自建止损计算链、不新增 CLI**。

### 6.7 仓位口径（阶段化 + 两层口径）

| 项 | 口径 |
| --- | --- |
| 单只标的「目标仓位」列 | **阶段化**：初始 ≤10% → 逻辑验证后 ≤15% → 绝对 ≤20% |
| 绝对 20% 的适用条件 | **仅限最高确信度、护城河最深的核心底仓**，且组合内上浮至 20% 的标的**合计 ≤2 只** |
| 底仓 / 机动仓 | **60%~80% / 20%~40%**（**仅作角色标签**，不作为单只目标仓位数值） |
| 两层口径 | 底仓 + 机动仓之和恒为 **100%**，指**股票仓位内部**切分；现金比例指**占总资产**，**先定现金占比再切分** |
| 其他上限 | 持股 **5~10 只**；单一行业 **≤40%**；行业相关性 **<0.5**；流动性 **>1 亿**（小市值 >3000 万）；再平衡触发 **±5%** |

## 九、常见误用提示

1. **能力圈当提示项是头号错误**——它是**淘汰闸门**，未通过即出局（`GF-8`）；科技股「技术理解」必答。
2. **科技豁免被扩大化**——只豁免「扣非净利润为正」单项；**治理与 ROIC 不豁免**，豁免标的仅机动仓观察。
3. **地缘口径混用**——本技能唯一口径是 **0.3 三维交叉矩阵 + 赛道两分法**；不得改用「敞口多维度打分」类旧口径，也不得做地缘估值折价（折价由 `garp-valuation` 承载）。
4. **估值自造档位表**——档位统一引用 `garp-valuation` 的统一六档 + 多工具矩阵；本技能**零 PEG 算式**，只落 1.5 高估线与 2.0 淘汰线（后者为**推导口径**，须如实披露）。
5. **仓位列写固定区间**——终选组合表一律**阶段化**标注；**底仓 / 机动仓比例只作角色标签**。
6. **两层口径混用**——底仓 + 机动仓之和恒为 100% 指**股票仓位内部**；现金比例指**占总资产**，须先定现金再切分。
7. **自建止损链**——ATR 止损价必须经 `garp-exit` 转接；本技能不新增 CLI。
8. **时变项沿用历史清单**——制裁清单 / 出口管制 / 风险行业清单 / 国产化率 / 产业基金名录须实时核验。
9. **零心算**——所有估值 / 市值 / 调整后 PEG / 加权打分须走工具（`GF-9`）。
10. **取数失败不等于通过**——标「未验证」「低置信度」，不得按通过处理（`GF-11`）。
11. **前向引用只指向名称**——下游 GARP 技能不描述其内部流程。
12. **越权替代买入前检查**——未经 `garp-investment-checklist` 七关，不得视为可买入（`GF-12`）。
