# GARP 行业漏斗精选（1~5 年）：赛道内逐层漏斗 → 3 底仓 + 2 机动仓

对 $ARGUMENTS 执行 GARP 行业漏斗精选。本技能属**行业层第二站（框架第 2 步·个股初筛 → 第 3 步·深度研究）**——在**赛道已确认**的前提下，把候选池**逐层收敛为「3 家底仓 + 2 家机动仓」终选组合**，回答「**这条赛道里具体买哪几家、仓位怎么配**」。

> **独立档声明**：**本技能属 GARP 独立档（1~5 年，五大师：费雪 / 林奇 / 郑希 / 李进 / 欧奈尔），与 1~3 年中期链、10 年长期链口径物理隔离、功能互补。**

**支持输入格式**：

- `{行业名}` —— 赛道 / 行业名，如 `AI 光模块` / `人形机器人` / `半导体设备`
- `{行业名} --scope A股` —— 候选池范围（`全球` / `A股` / `港股` / `美股`）
- `{行业名} --depth deep` —— 深度参数（`fast` / `standard` / `deep`）

> **本技能不提供档位切换参数**——它即 GARP 独立档（1~5 年）行业漏斗专属入口，命令与输入中**不含任何档位切换开关**；档位切换类口令属其他档位口径，在本技能中出现即违反**口径隔离**纪律（见「注意事项」第 1 条与「与其他 garp- 技能的关系」）。

## 设计原则

1. **赛道结论引用不重做**：第一层直接引用 `garp-industry-research`（P4-9，已交付）的**六维赛道结论 + Tier1~4 分层清单**，不重复测算 TAM / 渗透率 / 国产化率；赛道评级非 A/B 即终止漏斗（`GF-1`）。
2. **能力圈闸门前置**：候选标的进入任何财务/估值核验**之前**先过「产业理解 / 财务理解 / 估值理解 / 技术理解（科技股必答）」四维自检，**未通过即视为能力圈之外并淘汰**（`GF-8`），不作为报告提示项处理。
3. **逐层漏斗只做淘汰**：每层做淘汰、不做打分累积；层间配额 **30~60 → 10~20 → 5~8 → 3+2** 继承不改；淘汰须给出**规则编号**与**证据行**。
4. **五大支柱交叉验证**：产业景气度（β）/ 公司基本面（α，含 ROIC 四档与可量化护城河）/ 管理层与科研转化（诚信前置 + 7+7+6，科技股再叠加 8+8+4）/ 地缘政治与外部环境（0.3 三维交叉矩阵 + 赛道两分法）/ **政策与资本覆盖度**（支柱五），五支柱须收口为「买入 / 观察 / 放弃」。
5. **估值只读不重定义**：档位统一引用 `garp-valuation`（P4-5，已交付）的**统一六档 + 多工具矩阵**；本技能**零 PEG 算式**，只落**1.5 高估线**与 **2.0 淘汰线**两条阈值，并叠加**宏观 PEG 区间**动态调整。
6. **卖出只引不重建**：五级卖出、时间止损、ATR 动态止损一律引用 `garp-exit`（P4-6，已交付）；ATR 止损价**经 `garp-exit` 转接** `momentum.stop_price()`，本技能**不自建止损计算链、不新增任何 CLI**。
7. **禁止 LLM 心算**：调整后 PEG、市值、CAGR、隐含增速、加权打分一律经 `financial_rigor.py`，报告不得出现手算数值（`GF-9`）。
8. **双源交叉验证 + 时变项实时核验**：关键数据 ≥2 独立来源，误差 >1% 显式标记；制裁清单 / 出口管制 / 风险行业清单 / 国产化率 / 产业基金名录均为**时变项**，评估前须**实时核验**，禁止沿用历史清单。
9. **终选不越权**：本技能只输出终选组合与仓位、建仓价区间、硬止损价、景气监测指标；终选标的**强制转接** `garp-investment-checklist`（P4-3，已交付）七关，未经七关**不得视为可买入**（`GF-12`）。
10. **前向引用只指向名称**：下游 GARP 技能（如 `garp-trend-tech-screen`）**仅指向名称、不描述其内部流程**，避免制造滞后故障点。

**参数语义映射**：

- `--scope`：决定候选池构建的搜索范围与数据工具（A 股 / 港股 / 美股 / 全球混合）。
- `--depth`：`fast` 只做赛道确认 + 硬指标粗筛 + 3+2 终选；`standard` 追加五大支柱精析与五大师研判；`deep` 再叠加在研项目扫描（`in_research_scan.py`）。
- `--export`：未开启时仅在对话内呈现结论，不写文件；开启时按 `--export-path` 落盘，默认 `reports/industry/`。
- `--json`：开启时输出结构化 JSON（字段见「输出结果」节），关闭时输出 Markdown。

## 核心判定规则（硬编码）

### 规则一：赛道确认与候选池构建（第一步，引用 `garp-industry-research`）

```text
IF 赛道评级 = A 或 B（引用 garp-industry-research 的六维赛道筛选结论）:
    → 进入漏斗，候选池 = Tier 1~4 全部标的（30~60 家）
ELIF 赛道评级 = C 或 拒绝:
    → 触发 GF-1，终止漏斗，输出「赛道不合格」结论
IF 未跑过 garp-industry-research:
    → 先提示用户运行该前置技能；或本技能内以「引用骨架级快速回填」获取赛道结论，
      并在报告显式标注「置信度受限」
IF 候选池 < 30 家:
    → 标注「候选池规模不足 30 家」，不擅自扩充赛道外标的
```

**候选池来源（引用 `garp-industry-research` 规则三的分层结果，不重做分层）**：

| 层级 | 条件 | 漏斗初始定位 |
| --- | --- | --- |
| Tier 1 | 大市值、纯正标的、行业龙头 | 底仓候选池 |
| Tier 2 | 中市值、纯正或高占比、细分龙头 | 底仓 / 机动仓候选池 |
| Tier 3 | 小市值、开发阶段、高风险高弹性 | 机动仓候选池 |
| Tier 4 | 多元化公司中有关联业务 | 观察，一般淘汰 |

> **「六维」语义限定**：本技能中的「六维」**仅**指 `garp-industry-research`（P4-9）的**六维赛道筛选**结论（产业空间 / 渗透率位置 / 国产化率位置 / 业绩兑现度 / 题材辨别 / 地缘政治敞口）；**禁止**把「六维」与「地缘」或「敞口」连用（即禁止把该词当作其他档位的地缘敞口口径使用）——本技能的地缘口径**唯一**为 **0.3 三维交叉矩阵 + 赛道两分法**（见规则四）。

### 规则二：能力圈四维自检（漏斗第一层前置淘汰闸门，新增）

目标：候选池 30~60 家 → 通过者。**本层先于 6 硬指标，未通过即淘汰**（框架行 360 将「能力圈自检未通过」列为**买入前一票否决项**，故本技能将其设为**闸门**而非提示项）。

| 维度 | 评估标准 | 自检问题（须能独立回答「是」） |
| --- | --- | --- |
| **产业理解** | 能否画出产业链上下游关系图？能否说出竞争格局与集中度（CR5）？ | 产业链有几层？上游关键原材料/设备来自谁？下游客户是谁？前五大玩家是谁、份额多少？ |
| **财务理解** | 能否独立阅读并理解该行业公司的三张报表（资产负债表、利润表、现金流量表）？ | 营收、毛利率、应收/存货、经营现金流分别在哪张表？关键科目变动意味着什么？ |
| **估值理解** | 能否用**至少 2 种方法**给出估值区间？ | 除 PE/PEG 外，能否再用 PS、EV/Sales、DCF、可比公司法交叉验证？ |
| **技术理解**（**科技股必答**） | 能否说清核心技术路线差异？ | 不同技术路线的原理差异、成本差异、适用场景、主流玩家分别是谁？ |

**判定规则（硬编码）**：

```text
IF 普通行业：须「产业理解 + 财务理解 + 估值理解」三项同时通过
ELIF 科技股：上述三项 + 「技术理解」必选；技术理解不过关 → 不得重仓（观察仓或放弃）
IF 任一必需维度未通过：
    → 视为「能力圈之外」→ 淘汰（GF-8），并给出三选一建议：
       ① 补课学习至可独立回答；② 仅作低仓位观察仓跟随；③ 放弃，赚认知范围内的钱
```

> **落位说明**：能力圈闸门位于漏斗第一层，淘汰对象**不得进入**后续 6 硬指标与五大支柱层。**自检结论属主观自评**——报告须逐家标注「自评项，非工具化判据」，不得伪装为工具化判据。

### 规则三：6 硬指标粗筛（第二步，含财务五门槛 + 科技豁免）

目标：能力圈通过者 → **10~20 家**（框架自述该量级为「非固定值」，随市场环境浮动）。**6 条硬指标，任一不过即淘汰**：

| # | 硬指标 | 通过标准（GARP 档） | 否决编号 |
| :--: | --- | --- | :--: |
| 1 | 产业景气度 | 季度营收增速 > 行业平均（引用 `garp-industry-research` 业绩兑现维度）；或行业高频数据（排产/价格）连续 2 月环比向上 | — |
| 2 | **财务健康（财务五门槛）** | **营收 ≥10 亿；3 年营收 CAGR ≥15%；资产负债率 <60%（金融/地产除外）；经营性现金流净额为正；近 3 年 ≥2 年扣非净利润为正** | `GF-2` |
| 3 | **估值底线（多工具矩阵）** | 引用 `garp-valuation` 统一六档：**调整后 PEG ≤1.5** 方可入底仓候选；**>1.5 不得入底仓、仅机动仓观察**；**>2.0 淘汰出终选**；宏观期按宏观 PEG 区间**动态上浮/下调** | `GF-3` |
| 4 | 流动性 | **日成交额 >1 亿；市值 <100 亿可放宽至 >3000 万** | `GF-4` |
| 5 | 治理底线 | 无立案调查、无大额违规担保、审计意见非「非标」；**ESG 评级处于行业尾部/最低档 → 先降仓位上限**（**不直接折价**） | `GF-5` |
| 6 | **地缘红线（0.3 矩阵 + 赛道两分法）** | **地缘倒逼型**赛道：0.3 三维矩阵不得归「高风险/回避」或「回避」档；**政策资本驱动型**赛道：地缘仅作**敞口体检**（海外收入/供应链/冲突暴露可控），达标与否交由支柱五判定 | `GF-6` |

**科技豁免（框架科技股豁免条款，替换骨架中按渗透率放宽现金流的条款）**：

```text
IF 「近 3 年 ≥2 年扣非净利润为正」不过
   AND 扣非为负「仅由研发费用化压低当期利润」所致（非经营恶化）
   AND 同时满足：① 经营性现金流净额为正 ② 营收连续增长 ③ 研发强度 ≥15%
   → 豁免该单项（标记「科技豁免」）并继续；否则淘汰（GF-2）
```

> **豁免边界（刚性）**：科技豁免**只豁免「扣非净利润为正」单项**——**治理底线（`GF-5`）与 ROIC/护城河判定（支柱二）不豁免**；豁免标的须显式标注「**依赖科技豁免**」并**仅在机动仓观察**，与框架「未盈利科技型」衔接口径对齐。

**其余放宽（有限度，收敛自骨架）**：

- **战略必争卡脖子环节**（如光刻）：若属国产化率 <5% 的战略必争环节，可放宽「经营现金流为正」，须显式标注「**烧钱换市场**」逻辑，**仅限机动仓观察**（调用 `geo_policy_screen.py localize --strategic-choke-point` 显式标注，勿靠人工默认）；
- 治理瑕疵但非致命（如小额诉讼）→ 须**诚信前置闸门未命中且管理层 20 分制 ≥15 分**方可豁免，并显式标注风险。

### 规则四：五大支柱精析（第三步）

目标：10~20 家 → **5~8 家**。

#### 4.1 五大支柱交叉验证

| 支柱 | 核心问题 | 关键验证点 | 工具出口 |
| --- | --- | --- | --- |
| **一 产业景气度（β）** | 景气是 β 还是 α？能持续多久？ | 供需格局（供不应求 / 平衡 / 过剩）、价格趋势、CR5 是否提升；渗透率曲线位置（**15%~40% 黄金窗**） | `garp-industry-research` |
| **二 公司基本面（α）** | 竞争优势是否可量化？ | ROE 趋势与近三年方向、毛利率/净利率、营收与利润增速匹配度、**ROIC 四档**、**可量化护城河** | `financial_rigor.py roic / wacc` |
| **三 管理层与科研转化** | 是否利益一致？是否有能力？ | **诚信前置闸门**（不计分）+ 对待股东 7 / 战略执行 7 / 稳定性激励 6（≥15 可重仓）；科技股**再叠加**科研转化 **8+8+4**（两套均须 ≥15）；费雪补充（销售组织 / 管理层持股 ≥3%） | `garp-management`（P4-4）；`governance_data.py` |
| **四 地缘政治与外部环境** | 外部冲击是否致命？ | **0.3 三维交叉矩阵行归属 + 赛道两分法**（硬门槛 vs 敞口体检）；时变项（制裁/管制/关税）**须实时核验，勿沿用历史清单** | `garp-geo-policy`（P4-1）；`geo_policy_screen.py` |
| **五 政策与资本覆盖度**（**新增**） | 政策能否接住？注资是否落到标的？ | ① 该标的获国家/地方产业基金注资**额度占其市值/资本开支比例**；② **资本+场景绑定是否已兑现为可验证订单/收入/量产**（而非框架协议）；③ 相对同赛道竞争者的**政策门槛优势**（强制采购比例 / 部委协同 / 财税优惠） | 无独立 CLI 出口（缺口登记），以检索类工具 + 年报字段为代理指标，须标注**低置信度** |

**ROIC 四档（支柱二硬编码，科技股用「调整后核心经营 ROIC」）**：

```text
优秀      : ROIC > 15%       → 最高确信度候选加分项（可支持单只上限上浮至绝对 20%）
合格      : ROIC > WACC 且 ≥10%
部分不达标: 5%~10%（既不否决也不达标）→ 观察仓
一票否决  : ROIC 长期 <5% 且仍在拼命扩产 → 放弃
```

**五大支柱汇总判定（硬编码，避免各支柱罗列却不收口）**：

```text
一票否决清单（命中任一即放弃/清仓，不进入后续判定）：
  ① 诚信一票否决：兑现率<50%、业绩预告重大失真、财务造假、监管立案
  ② ROIC 长期<5% 却在拼命扩产
  ③ 能力圈自检未通过（尤其科技股「技术理解」不过关不得重仓）
  ④ 0.3 三维矩阵综合归为「回避」档（政策覆盖度低/无 且 国字号基金无覆盖）

达标判定（须全部满足方可建仓）：
  支柱一：景气向上（供需不恶化、单价稳定或上涨、CR5 提升或龙头份额扩大）
  支柱二：ROIC > WACC 且 ≥10%；营收/利润增速匹配；ROE 向上或企稳、毛利率不恶化
  支柱三：科技股「管理层≥15 且 科研转化≥15」；普通行业「管理层≥15」
  支柱四：海外收入/资源供应链/地区冲突暴露可控；「地缘倒逼强度非低/无」仅对地缘倒逼型作硬门槛
  支柱五：政策覆盖度 ≥「中」，且国字号基金介入非「无覆盖」

三档结论：全部达标 → 进入估值锚定（可建仓）；部分不达标 → 观察仓；任一否决命中 → 放弃
```

> **与 0.3 矩阵的映射（防维度拆分歧义）**：支柱四对应 0.3 的「地缘倒逼强度」维；支柱五对应「政策覆盖度 + 国字号基金介入」两维，两者分开、不得压进同一支柱。

#### 4.2 0.3 三维交叉矩阵 + 赛道两分法（照引框架，不改写）

| 地缘倒逼强度 | 政策覆盖度 | 国字号基金介入 | 投资含义 |
| --- | --- | --- | --- |
| 高（已制裁/断供） | 高（超常规+全链条） | 有直接注资 | **最优场景**：替代确定性和节奏均被外部力量锁定 |
| 高 | 中 | 有专项子基金 | **次优场景**：替代方向明确，但节奏受技术突破制约 |
| 中（制裁升级中） | 高 | 有覆盖 | **潜伏场景**：制裁尚未落地但概率高，提前布局等待催化 |
| 高（已制裁/断供） | 低/无 | 无覆盖 | **高风险/回避**：下游被迫替代但国产短期接不住 |
| 低 | 中/高 | 有覆盖/注资 | **政策驱动型增量创造**：达标与否以支柱五为准 |
| 低 | 低 | 无覆盖 | **回避**：替代节奏完全依赖市场驱动，不确定性过高 |

**附带条款（刚性）**：

1. **未列组合**一律按**更审慎的相邻档位**归档，不得因未列而默认放行；
2. **国字号注资**视为「政策优先序列」信号，**不得作为买入估值依据**；
3. **时变项**（制裁清单 / 出口管制 / 风险行业 / 国产化率）评估前须**实时核验**，禁用历史清单；
4. **赛道两分法**：地缘倒逼型（半导体设备/材料等）→ 支柱四作**硬门槛**；政策资本驱动型（机器人、信创等）→ 支柱四仅作**敞口体检**；两类非互斥时**按更审慎那类执行**。

#### 4.3 估值底线与多工具矩阵（只读 `garp-valuation`，只落两条阈值）

- **唯一档位出口**：`garp-valuation`（P4-5，已交付）的**统一六档 + 多工具矩阵**（调整后 PEG / PS·EV-Sales / Rule of 40 / 远期 PE + 隐含 PEG / 研发管线 NPV / DCF）+ **ESG 环境风险折价** + **宏观 PEG 区间**；本技能**不重述档位表、零 PEG 算式**；
- **本技能只落两条阈值**（硬指标 #3 与 `GF-3`）：**1.5 = 高估线**（调整后 PEG >1.5 不得入底仓，机动仓择机减）；**2.0 = 淘汰线**（调整后 PEG >2.0 出终选）；
- **口径披露（如实）**：**2.0 淘汰线**系由框架「**调整后 PEG>2 时加速清机动仓**」条款**操作化推导**而来的口径（骨架同类阈值亦同源），**并非框架原文的淘汰条款**——报告与《口径隔离声明》须按**推导口径**登记，不得表述为框架原文；
- **宏观联动**：加息 0.8~1.0 / 中性 1.0~1.2 / 降息 1.2~1.5 / 滞胀 0.8 的 **PEG 区间乘数**经 `macro_calibrator.py` **只读透传**，本技能**不判宏观阶段、不重述三表**；
- **陷阱清单**：低 PE 陷阱 / 高 PE 但增速不可持续 / 忽略股权稀释 / **研发费用化扭曲**（高研发投入科技股须用「核心经营利润」口径回算调整后 PE）。

#### 4.4 「假如空仓」测试

> 灵魂拷问：「如果我现在持有现金，以当前价格、当前基本面，我还会买入这只股票吗？」
> - YES → 继续持有 / 加仓。
> - NO → 无论盈亏，必须减仓或清仓（克服沉没成本的最强工具）。

### 规则五：五大师研判 + 五大矛盾化解（第四步）

目标：5~8 家 → **3 家底仓 + 2 家机动仓**。

#### 5.1 五大师思维模式

#### 5.2 管理层与科研转化：诚信前置 + 7+7+6（科技股再叠加 8+8+4）

```text
诚信前置闸门（不计分，命中即放弃/清仓，不以总分豁免）：
  年报「说到做到」兑现率<50% / 业绩预告重大失真 / 监管立案 / 财务造假实锤
      → 放弃或清仓，不进入 20 分制求和（GF-7）

管理层 20 分制（= 7 + 7 + 6，≥15 可重仓）：
  对待股东 7    ：分红历史（≥30% 为优）、融资记录、回购行为、大股东质押率（>50% 预警）
  战略执行力 7  ：是否聚焦主业、核心战略落地、行业格局认知深度
  稳定性与激励 6：核心团队稳定性（离职率<10%）、股权激励合理性、内部人增减持异常预警

退档规则：10~14 分 → 观察仓（单只上限 ≤5%，不重仓）；<10 分 → 放弃（GF-8）

科研转化 20 分制（科技股叠加，8 + 8 + 4，≥15 可重仓）：
  研发投入「质」与「量」8：研发强度≥15% 且逐年提升、资本化率<30%、研发人员占比≥30%
  研发产出效率 8        ：发明专利数量与质量、新产品收入占比≥20%、产品化周期、重大项目节点
  资本回报效率 4        ：ROIC > WACC；增量资本回报率 > 存量 ROIC

退档同管理层规则；普通行业不适用科研转化清单时，仅以管理层 20 分制判定
```

> **两种否决的语境边界**：诚信前置闸门 = **持仓后清仓信号**；能力圈未通过 / ROIC<5% 扩产 / 0.3 回避档 = **买入前闸门**。**两套「≥15」为并列门槛，非合计、非加权**。

#### 5.3 五大矛盾化解

| 矛盾 | 冲突点 | 化解方案 |
| --- | --- | --- |
| 一 买点哲学 | 欧奈尔要突破买 vs 林奇要低估买 | 杀估值（低 PEG）→ 林奇左侧买；杀逻辑（景气证伪）→ 欧奈尔止损 |
| 二 持有时间 | 郑希看 1~3 年周期 vs 欧奈尔看 3 月趋势 | 连续 3 季同向 → 郑希持有；连续 2 季下滑 → 欧奈尔减仓（`qoq-accelerator`） |
| 三 止损 vs 越跌越买 | 李进要控回撤 vs 林奇要逆向 | 仓位状态表：建仓初期 → 止损优先；底仓已建且逻辑已验证 → 估值下限加仓 |
| 四 分散 vs 集中 | 李进要分散 vs 郑希要集中 | 3+2 结构 + 单只/单行业上限 + 行业相关性 <0.5 |
| **五 费雪「绝不卖」vs 趋势/景气纪律**（**新增**） | 费雪「卖出的最佳时机几乎永远是不要卖」vs 欧奈尔/李进/郑希的趋势与景气纪律 | **「不卖」有两个缺一不可的前提**：① **极度深度的研究认知**（确认是能持续创造增量价值的杰出企业）② **极度集中的持仓**；前提满足且下跌属**暂时性困难** → 可继续持有甚至加仓；**缺乏前提或属永久性衰退** → 按纪律离场。**「不卖」是认知深度的奖赏，不是不研究的借口** |

#### 5.4 决策优先级金字塔（五级，与 `garp-exit` 一一对应）

| 级别 | 触发条件 | 决策 | 思想来源 |
| :--: | --- | --- | --- |
| **一级 诚信否决** | 管理层诚信问题暴露、财务造假实锤、监管立案 | 立即清仓，不看估值与趋势 | 费雪 |
| **二级 硬止损** | 单笔亏损 8%~10% 且无明确基本面反转信号 | 无条件止损 | 欧奈尔 |
| **三级 逻辑止损** | 连续 2 季业绩低于预期且景气未改善；**或持有满 4 季度逻辑未兑现（时间止损）** | 减仓或清仓 | 林奇 + 郑希 |
| **四级 产业景气判断** | 前三项未触发，但渗透率/ROE 出现拐点信号 | 按景气方向调仓（机动仓优先） | 李进 + 郑希 |
| **五级 估值判断** | 以上均未触发，仅股价/估值短期波动 | 底仓不动，机动仓调整 | 林奇 |

> **铁律**：上层未通过，下层不讨论；检查顺序固定一级 → 五级，命中即停。**本技能只引用 `garp-exit` 实现，不重定义五级卖出**。

#### 5.5 止损与仓位状态（引用 `garp-exit`，不重建）

| 仓位状态 | 跌幅 | 逻辑状态 | 操作 |
| --- | --- | --- | --- |
| **建仓初期**（持仓 < 最终仓位 50% **或** 逻辑未经验证） | −8%~−10% | 任意 | **8%~10% 硬止损离场**（**禁用 ATR**；硬止损优先于「跌破估值下限补仓」） |
| **底仓已建立且逻辑已验证**（持仓 ≥50% **且** 经 2~3 季财报兑现验证） | — | 逻辑完好，仅情绪杀 | 2~3 × ATR(14) 动态跟踪止损，**受 20% 底仓容忍度封顶** |
| 任意仓位 | 任意 | 逻辑证伪（技术路线被替代） | 立即清仓（不等反弹） |
| 持有 > 4 季度 | 横盘 | 逻辑未兑现 | **时间止损**（调仓换股，归入三级） |

> **ATR 止损价一律经 `garp-exit`（P4-6）转接 `momentum.stop_price()`**（内部调用 `atr()`），**禁止心算**；本技能**不自建止损计算链、不新增 CLI 包装**。

#### 6.1 终选 3+2 组合表

| 代码 | 名称 | 角色 | 目标仓位（**阶段化**） | 建仓价区间 | 硬止损价 | 景气监测指标 | 核心逻辑（一句话） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| — | — | 底仓 / 机动仓 | 初始 ≤10% → 逻辑验证后 ≤15% → 绝对 ≤20% | — | — | — | — |

> **「目标仓位」列口径（硬编码）**：一律按**阶段化**标注——**初始 ≤10% / 逻辑验证后 ≤15% / 绝对 ≤20%**；**不得写固定百分比区间**。**底仓（60%~80%）/ 机动仓（20%~40%）仅作角色标签**，不作为单只标的的目标仓位数值使用。

#### 6.2 底仓 / 机动仓分离管理

| 仓位类型 | 比例（角色标签） | 定位 | 操作规则 |
| --- | --- | --- | --- |
| **底仓** | **60%~80%** | 长线核心，赚企业 **1~5 年**成长的钱 | 逻辑未破坏则始终保留；**不因短期 20% 以内波动卖出**；每季度结合财报小幅调整（**±5%**） |
| **机动仓** | **20%~40%** | 平滑波动，赚估值波动的钱 | 股价进入**高估区间**减持，回落至**合理区间**回补 |

**两层口径（防混淆，硬编码）**：底仓 + 机动仓**之和恒为 100%**，指**股票仓位内部**的切分；现金比例（常态 10%~20%、风险期 20%~30% 或更高、衰退 30%~40%、滞胀 ≥40%）指**占总资产**比例。**执行顺序**：先按宏观/风险预算确定现金占总资产的占比，剩余部分再按底仓/机动仓切分。

**硬编码上限**：持股 **5~10 只**；单只 **初始 ≤10% / 逻辑验证后 ≤15% / 绝对 ≤20%**（绝对 20% **仅限最高确信度、护城河最深的核心底仓**，且组合内上浮至绝对 20% 的标的**合计 ≤2 只**）；单一行业 **≤40%**；行业相关性 **<0.5**；流动性 **日成交 >1 亿**（小市值 >3000 万）；再平衡触发 **±5%**。

#### 6.3 左侧布局 vs 右侧介入

| 阶段 | 特征 | 策略 | 仓位上限 |
| --- | --- | --- | --- |
| 左侧布局 | 行业短期利空但长期逻辑未破坏，渗透率处导入/突破期，估值合理 | 分批建仓，越跌越买（须仓位状态表支持） | 该标的最终仓位的 50% 以内（**可建上限、非必须比例**） |
| 右侧确认 | 渗透率进入 **15%~40% 加速上行期**，财报连续 2 季超预期，行业景气明确上行 | 三分法推进（1/3 → 2/3 → 补满）；仅三信号共振方可一次性建 2/3 | 逐级上移 |
| 高潮 / 透支 | 渗透率 >60% 或调整后 PEG >1.5，情绪亢奋 | 只卖不买，机动仓止盈，底仓设移动止盈 | 降仓 |

> **本表只做「检查」，不做「定义」**——级别定义、阈值、动作归属 `garp-exit`（P4-6，**已交付**）；本技能逐级检查并强制转接。

| 级别 | 触发条件（引用 `garp-exit` 口径） | 本技能动作 |

### 关键约束

- 所有算术（调整后 PEG、市值、CAGR、隐含增速、加权打分）必须经 `financial_rigor.py` 执行，**禁止 LLM 心算**（`GF-9`）。
- 关键数据 ≥2 独立来源，误差 >1% 显式标记；渗透率、国产化率按 A / B / C 三级置信度标注，C 级不得作确定性结论（`GF-11`）。
- 报告中的每个数值必须能追溯到对应命令输出或来源。
- **禁用** 内置 WebSearch / WebFetch（中国大陆不可用），统一用取数五工具。
- 本技能**不新增任何 Python CLI**；`garp-exit` 相关止损计算**一律经其转接**，不自建包装。

### 降级与失败处置

| 情形 | 处置 |
| --- | --- |
| `garp-industry-research` 未跑过 | 提示用户先运行；或以「引用骨架级快速回填」获取赛道结论，并在报告**显式标注置信度受限** |
| 某市场工具连通失败（港美股接口偶发） | 重试 → 仍失败则标注「未取得」，**不以推测代替实测**；关键数据缺失须降级结论等级 |

## 注意事项

1. **三档物理隔离**——本技能只读写 `reports/industry/{行业名}-garp-funnel-*.md`；**不得触碰** 1~3 年档与 10 年档的报告文件；本技能**不提供档位切换开关**。
2. **能力圈是闸门不是提示**——未通过四维自检即淘汰（`GF-8`）；科技股「技术理解」为**必选项**，不过关不得重仓；结论须标注「自评项，非工具化判据」。
3. **科技豁免不得扩大化**——只豁免「扣非净利润为正」单项；**治理底线与 ROIC/护城河判定不豁免**；豁免标的仅在机动仓观察。
4. **地缘口径唯一**——一律为 **0.3 三维交叉矩阵 + 赛道两分法**（硬门槛 / 敞口体检）；**不得**使用任何「地缘敞口多维度打分」类旧口径（见规则一「六维」语义限定）。
5. **估值只读不重定义**——统一六档 + 多工具矩阵以 `garp-valuation` 为唯一权威；本技能只落 1.5 高估线与 2.0 淘汰线，**零 PEG 算式**；**2.0 淘汰线为推导口径**（由框架「调整后 PEG>2 加速清机动仓」操作化而来），须如实披露。
6. **仓位口径阶段化**——终选组合表「目标仓位」列一律「初始 ≤10% → 逻辑验证后 ≤15% → 绝对 ≤20%」；**底仓 60%~80% / 机动仓 20%~40% 仅为角色标签**，**不得**作为单只标的目标仓位；**两层口径**（股票仓位内部切分 vs 占总资产）不得混用。
7. **卖出与止损只引不重建**——五级卖出、时间止损、ATR 动态止损以 `garp-exit` 为唯一权威；ATR 止损价经其转接，本技能不新增 CLI。
8. **时变项必须实时核验**——制裁清单 / 出口管制 / 风险行业清单 / 国产化率 / 产业基金名录**禁止沿用历史清单**。
9. **零心算**——所有估值 / 市值 / 调整后 PEG / 加权打分须走工具（`GF-9`）。
10. **单一来源不得作确定性结论**——标「单一来源，置信度低」（`GF-11`）。
11. **前向引用只指向名称**——下游 GARP 技能不描述其内部流程。
12. **终选不越权**——只出赛道内终选组合与仓位纪律；买入前七关归 `garp-investment-checklist`（`GF-12`）；不替用户决策，报告须含免责声明。

## 局限性

1. **能力圈四维自检为主观自评**（缺口登记）——无工具化判据，不同研究者结论可能不一致，报告已标注「自评项」。
2. **支柱五「政策与资本覆盖度」无独立 CLI 出口**（缺口登记）——注资比例 / 场景绑定兑现 / 政策门槛优势依赖检索与年报字段，结论须标注低置信度，**不臆造阈值**。
3. **渗透率 / 国产化率无独立工具出口**（缺口登记）——依赖检索与人工核验，未取得权威数据时标「未验证」。
4. **行业/个股级 ROE 拐点无量化判据**（缺口登记）——一律标注「定性推断」，**不得**自设阈值。
5. **欧奈尔视角部分指标项目内无直接实现**（缺口登记）——以动量与技术面工具替代并标注口径差异。
6. **0.3 矩阵未覆盖全部组合**——按「更审慎相邻档」执行，**不自行补全矩阵**。
7. **赛道结论依赖前置技能**——若 `garp-industry-research` 未执行，快速回填结论置信度受限。
8. **不构成投资建议**——本技能仅用于学习与研究；组合级结论不等同于个股结论。
