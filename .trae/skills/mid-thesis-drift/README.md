# 中期逻辑漂移检测 (Mid Thesis Drift)

对比建仓时投资论文中的景气假设与最新季度财报数据，对六大维度（渗透率/订单/ROE/毛利率/加速度/地缘政治）逐条验证，输出「四级漂移等级 + 证据链」及行动建议，联动 `exit-signal` P0~P5。属于 1-3 年中期链持有期监控技能，检测频率为季度。

**核心理念**：基于证据而非信仰。假设被证伪（≥4 项完全漂移）无论股价涨跌均应触发卖出评估。

---

## 快速开始

### 基本调用方式

```
/mid-thesis-drift {标的} [--thesis-date 日期] [--since 日期] [--export] [--json]
```

例如：

- `/mid-thesis-drift 新易盛`
- `/mid-thesis-drift 腾讯 00700 --since 2026-01-20`
- `/mid-thesis-drift 新易盛 --thesis-date 2026-01-15 --export`

## 核心功能

### H1~H6 六大景气假设模板

| 编号 | 假设类型 | 提取内容 | 权重 |
| --- | --- | --- | --- |
| H1 | 渗透率假设 | 建仓时渗透率位置、预期提升路径 | 20% |
| H2 | 订单/合同负债假设 | 建仓时合同负债水平、预期订单增长 | 20% |
| H3 | ROE 趋势假设 | 建仓时 ROE 水平、预期方向 | 20% |
| H4 | 毛利率假设 | 建仓时毛利率水平、预期趋势 | 15% |
| H5 | 增速加速度假设 | 建仓时加速度方向、预期持续 | 15% |
| H6 | 地缘政治假设 | 建仓时地缘评估、关税/制裁/供应链预期 | 10% |

### 三档判定（每维）

```text
✅ 成立 / ⚠️ 部分漂移 / 🔴 完全漂移
仅 🔴 完全漂移计入计数
```

### 四级漂移等级（已对齐 D-1 用例，0/1/2-3/≥4）

| 完全漂移项数 | 漂移等级 | 颜色 | 行动建议 |
| --- | --- | --- | --- |
| 0 项 | 未漂移 | 🟢 | 继续持有，关注 ⚠️ 项 |
| 1 项 | 轻微漂移 | 🟡 | 底仓持有，机动仓考虑减仓 |
| 2~3 项 | 显著漂移 | 🟠 | 大幅减机动仓，底仓设止损线 |
| ≥4 项 | 严重漂移 | 🔴 | **触发 exit-signal 卖出评估** |

### exit-signal P0~P5 映射

| 漂移等级 | exit-signal 级别 | 操作 |
| --- | --- | --- |
| 显著漂移 🟠 | **P3 景气拐点** | 减机动仓 |
| 严重漂移 🔴 | **P2 逻辑止损** | 减仓或清仓 |
| 持有≥4 季度且漂移≥🟡 | **P2 时间止损** | 减仓或清仓 |

> 漂移等级同时作为 `valuation-thermometer` 估值修正因子：🟡→-0.3 档 / 🟠→-0.5 档 / 🔴→-1.0 档，**修正幅度上限 ±1.0 档**。

## 使用示例

### 示例1：显著漂移（D-1 用例）

```
/mid-thesis-drift {旧论文「渗透率12%加速」，新数据「渗透率持平且订单环比下降」}
```

H1/H2 两项完全漂移 → 显著漂移 🟠，映射 P3，移交 `exit-signal`。

### 示例2：未漂移（D-2 用例）

```
/mid-thesis-drift {旧论文假设与最新季度数据一致}
```

0 项完全漂移 → 未漂移 🟢，继续持有。

### 示例3：加速度连续 3 季下降（D-3 用例）

```
/mid-thesis-drift {营收增速 35%→30%→25% 连续 3 季下降}
```

触发 R-1，H5 完全漂移 → 轻微漂移 🟡，输出二阶导预警。

### 示例4：时间止损（D-4 用例）

```
/mid-thesis-drift {持有 5 季度且漂移等级 🟡}
```

触发 R-3，时间止损映射 P2，输出减仓建议。

## 工具依赖

| 用途 | 工具 | 关键参数 |
|------|------|---------|
| 最新季度财务（H2~H5） | `a_share|hk_stock|us_stock/stock_financial.py` | 按市场 |
| 先行指标（合同负债/存货） | `a_share/stock_financial.py` | `--advanced 合同负债,存货,研发费用` |
| 偏差百分比/加速度计算 | `common/financial_rigor.py calc` | `--expr` |
| 隐含增速交叉验证 | `common/financial_rigor.py implied-growth` | `--market-cap --target-pe ...` |
| PEG 与估值温度 | `common/financial_rigor.py peg` | `--price --eps --growth` |
| 渗透率/订单/地缘信息 | `common/anysearch.py` / `doubao_search.py` | — |

### 关键约束

- **禁止 LLM 心算**：偏差百分比、加速度、PEG 一律走 `financial_rigor.py`。
- **基线显式提取**：H1~H6 必须从论文提取，缺项标注「无法验证，不纳入计数」，禁止脑补。
- **A 股累计转单季**：QoQ 环比必须先「本期累计 − 上期累计」。
- **连续 3 季规则**：单季负加速不判拐点（R-2）；连续 3 季负加速必判拐点（R-1）。

## 与长期 `thesis-drift` 的选型对照

| 维度 | `mid-thesis-drift`（本技能） | `thesis-drift`（长期） |
| --- | --- | --- |
| 检测对象 | 景气假设（渗透率/订单/ROE/毛利率/加速度/地缘） | 护城河永续性、商业模式 |
| 核心追问 | 「当初的景气逻辑还在吗？」 | 「公司还是不是好公司？」 |
| 判定口径 | 四级漂移等级 + 证据链 | Improved / Unchanged / Weakened |
| 检测频率 | 季度 | 年度/半年度 |
| 时间止损 | 满 4 季度逻辑未兑现即触发 P2 | 可容忍数年业绩平淡 |
| 参考大师 | 郑希（景气跟踪）+ 李进（二阶导） | 巴菲特（护城河评估） |

**选型规则**：检测 1-3 年景气逻辑用本技能；评估 10 年护城河用 `thesis-drift`。

## 数据不足处理指引

| 场景 | 处理 |
| --- | --- |
| 无中期论文 | 提示先运行 `/thesis-tracker {标的} --horizon mid`，或降级从最近 `mid-industry-research` 报告提取基线 |
| 论文缺某假设 | 标注「该项无法验证，不纳入漂移计数」 |
| H6 缺失 | 标注「地缘风险未设基线」 |
| 上游 qoq/momentum 报告缺失 | 引导先跑 `/qoq-accelerator`、`/trend-momentum-scan` |
| 无任何基线 | 明确拒绝并引导先建论文 |

## 风控硬编码（R-1~R-10）

| 编号 | 规则 |
| --- | --- |
| R-1 | 连续 3 季负加速 → 必须判完全漂移，禁止以「基数效应」「季节性」豁免 |
| R-2 | 单季负加速 → 不得判拐点，必须等连续 3 季确认 |
| R-3 | 持有≥4 季度 + 漂移≥🟡 → 必须触发时间止损（P2） |
| R-4 | 漂移等级 🔴 → 必须触发 exit-signal，禁止 AI「综合判断」后降级 |
| R-5 | PEG>1.5 → 标注「估值高估」 |
| R-6 | PEG>2.0 → 标注「严重透支」 |
| R-7 | PE 历史分位>90% → 标注「估值极端」 |
| R-8 | 估值修正幅度上限 ±1.0 档 |
| R-9 | 禁止跳过 P0 检查；发现治理线索 → 标注并建议运行 exit-signal |
| R-10 | 利润增速负+营收增速正 → 标注「利润营收不匹配」 |

## 核心原则

1. **证据优先于信仰** — 每维判定必须附证据链，禁止主观结论。
2. **仅 🔴 计入计数** — ⚠️ 部分漂移只记录不计数。
3. **连续 3 季不靠单季** — 单季不判拐点，连续 3 季必判拐点。
4. **禁止心算** — 所有数值来自 `financial_rigor.py` 或数据工具。
5. **漂移等级强制映射卖出** — 显著→P3、严重→P2、时间止损→P2，禁止降级。

---

## 注意事项

- 开始前运行 `date` 确认当天日期，报告头部注明数据截止日期。
- 关键数据须双源交叉验证，误差 >1% 标记。
- 禁止使用 WebSearch / WebFetch（中国大陆不可用），统一用本地搜索工具。
- 中期术语红线：禁止「护城河永续」「终局思维」「持有10年」。

---

## 局限性说明

- 只输出漂移结论与行动建议，不判断买卖价位（归 `exit-signal`/`valuation-thermometer`）。
- 无中期论文时基线降级，置信度降低须显式标注。
- 地缘维度（H6）主观性强，以硬编码阈值约束，不量化打分。
- 四级等级基于「完全漂移项数」等权计数，权重仅用于展示优先级。
- 渗透率数据由 `mid-industry-research` 供给。
