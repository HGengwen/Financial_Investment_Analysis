# 中期逻辑漂移检测（1-3年）：六大景气假设逐条验证

对比**建仓时投资论文中的景气假设**与**最新季度财报数据**，逐条验证假设是否仍成立，输出「**四级漂移等级 + 证据链**」及行动建议，回答「当初的景气逻辑还在吗？」。属于中期链（1-3 年）持有期监控技能，与长期 `thesis-drift`（护城河永续性评估）**物理隔离、功能互补**，检测频率为季度，禁止使用「护城河永续」「终局思维」「持有10年」等长期框架术语。

**核心理念**：基于证据而非信仰。用最新季度数据逐条验证景气假设，假设被证伪（≥4 项完全漂移）无论股价涨跌均应触发卖出评估。

## 设计原则

1. **证据优先于信仰**：每个维度的判定必须附证据链（最新数据 vs 建仓基线），禁止「感觉逻辑还在」式的主观结论。
2. **仅 🔴 完全漂移计入计数**：⚠️ 部分漂移只记录不计数，四级等级由「完全漂移项数」决定。
3. **连续 3 季不靠单季**：单季负加速不判拐点（R-2），连续 3 季负加速必须判拐点（R-1）。
4. **禁止 LLM 心算**：偏差百分比、PEG、隐含增速一律经 `financial_rigor.py`，报告不得出现手算数值。
5. **基线必须显式提取**：H1~H6 必须从论文/报告中明确提取，禁止 AI「脑补」；缺项标注「无法验证，不纳入计数」。
6. **漂移等级强制映射卖出**：显著→P3、严重→P2、时间止损→P2，禁止 AI「综合判断」后降级。
7. **只出漂移结论与行动建议**：不判断个股买卖价位（归 `exit-signal`/`valuation-thermometer`）。

## 调用参数（技能调用约定，非新增命令行开关）

以下参数为技能调用时的解析约定，由 AI 解析并映射到既有工具调用与执行流程，**不新增任何 Python 命令行开关**（Sprint 3 零代码开发原则）：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `{标的}` | 位置参数 | 是 | — | 公司名或代码（支持 A/港/美股） |
| `--thesis-date` | 日期 | 否 | 最新 | 建仓论文日期（默认取最新中期论文） |
| `--since` | 日期 | 否 | 自动 | 买入日期（时间止损判断，可从论文读取） |
| `--export` | 标志 | 否 | false | 导出 Markdown 报告至 `reports/`（未开启则仅在对话内输出） |
| `--export-path` | 字符串 | 否 | reports/ | 报告输出根路径（配合 `--export` 使用） |
| `--json` | 标志 | 否 | false | 输出结构化 JSON（供下游解析） |

**参数语义映射**：

- `--thesis-date`：指定对比的建仓论文版本；默认取最新中期论文。
- `--since`：买入日期，用于时间止损（持有≥4 季度）判断；缺省时从论文读取，再缺省标注「无法判断时间止损」。
- `--export` / `--export-path` / `--json`：同任务 A。
- 命名一致性：不使用 `--mode`；持有周期参数统一 `--horizon`（本技能名已含 `mid-` 前缀，`--horizon` 仅在与 `thesis-tracker`/`portfolio-review` 对齐时保留）。

**两种触发模式**：

1. **主动调用**：用户显式 `/mid-thesis-drift {标的}`（每季报发布后必做）。
2. **被动触发**（上游产出下列信号时提示转入）：
   - `qoq-accelerator` 连续 3 季负加速（核心证据）；
   - `trend-momentum-scan` 连续 2 次评级下降；
   - MA200 破位 + qoq 连续负加速（强制触发）；
   - SMR 强势（>70）转弱势（<40）且持续 ≥2 次（龙头地位检查）。

## 核心判定规则（硬编码）

### 规则一：提取六大基准假设（H1~H6，第一步）

**基线来源（优先级递减）**：

1. `thesis-tracker --horizon mid` 论文（`reports/{公司名}/{公司名}-mid-thesis.md`）；
2. 最近一次 `mid-industry-research` 报告结论；
3. 用户 `--old` 显式指定旧报告。

**必须从论文中明确提取，禁止 AI「脑补」**。

| 编号 | 假设类型 | 提取内容 | 权重 |
| --- | --- | --- | --- |
| H1 | 渗透率假设 | 建仓时渗透率位置、预期提升路径 | 20% |
| H2 | 订单/合同负债假设 | 建仓时合同负债水平、预期订单增长 | 20% |
| H3 | ROE 趋势假设 | 建仓时 ROE 水平、预期方向 | 20% |
| H4 | 毛利率假设 | 建仓时毛利率水平、预期趋势 | 15% |
| H5 | 增速加速度假设 | 建仓时加速度方向、预期持续 | 15% |
| H6 | 地缘政治假设 | 建仓时地缘评估、关税/制裁/供应链预期 | 10% |

**假设完整性检查**：

```text
无中期论文 → 提示先运行 /thesis-tracker {标的} --horizon mid（或降级从行业报告提取）
论文缺某假设 → 标注「该项无法验证，不纳入漂移计数」
H6 缺失 → 标注「地缘风险未设基线」
```

### 规则二：逐条假设验证（三档判定 + 证据链，第二步）

每维输出「✅ 成立 / ⚠️ 部分漂移 / 🔴 完全漂移」，**仅 🔴 计入完全漂移计数**。

| 维度 | 判定阈值（硬编码） |
| --- | --- |
| H1 渗透率 | 最新≥预期→成立；偏差<20%→部分漂移；偏差≥20%→完全漂移；**渗透率>50%→完全漂移**；二阶导为负→完全漂移 |
| H2 订单 | 合同负债≥预期→成立；偏差<15%→部分漂移；偏差≥15%→完全漂移；**环比绝对下降→完全漂移**；存货大增但合同负债未增→库存积压预警 |
| H3 ROE | 连续 3 季向上→成立；持平或小幅降（<10%）→部分漂移；**下降≥10% 或连续 3 季下降→完全漂移**（郑希「ROE 向上是重力加速度」被证伪） |
| H4 毛利率 | ≥建仓时→成立；下降<3 个百分点→部分漂移；**下降≥3 个百分点或连续 3 季下降→完全漂移**；利润增速<营收增速（差距≥10%）→费用失控预警 |
| H5 加速度 | 连续 3 季增速上升→成立；先升后平/正负交替→部分漂移；**连续 3 季增速下降→完全漂移**（李进二阶导）；QoQ/YoY 双口径，矛盾时以 YoY 为主 |
| H6 地缘 | 无实质恶化→成立；新威胁未落地→部分漂移；**关税加征/制裁落地/供应链断裂→完全漂移**；本地化产能投产→对冲有效 |

**硬性规则**：

```text
单季负加速不得判拐点（R-2）
连续 3 季负加速必须判拐点（R-1）
```

### 规则三：四级漂移等级评定（第三步）

| 完全漂移项数 | 漂移等级 | 颜色 | 行动建议 |
| --- | --- | --- | --- |
| 0~1 项 | **未漂移** | 🟢 | 继续持有，关注 ⚠️ 项 |
| 2 项 | **轻微漂移** | 🟡 | 底仓持有，机动仓考虑减仓 |
| 3 项 | **显著漂移** | 🟠 | 大幅减机动仓，底仓设止损线 |
| ≥4 项 | **严重漂移** | 🔴 | **触发 exit-signal 卖出评估** |

**漂移趋势追踪**：逐季改善→逻辑修复，维持/加仓；逐季恶化→逻辑崩塌，准备退出。

### 规则四：多技能联动（第四步）

| 联动技能 | 内容 | 关键判定 |
| --- | --- | --- |
| implied-growth | 市值隐含增速 vs 实际景气增速 | 红/黄/绿灯；与漂移等级交叉矩阵（严重漂移+任意灯色→触发 exit-signal） |
| exit-signal P0~P5 | 漂移等级→P 级别映射 | **显著漂移→P3（景气拐点）；严重漂移→P2（逻辑止损）**；时间止损（持有≥4 季度且漂移≥🟡）→P2 |
| valuation-thermometer | 漂移等级作为估值温度修正因子 | 🟡→-0.3 档 / 🟠→-0.5 档 / 🔴→-1.0 档；**修正幅度上限 ±1.0 档** |
| qoq-accelerator | H5 判定与 qoq 评级交叉 | 一致→高置信度；矛盾时（本技能 ⚠️ 但 qoq 🔴）→**以 qoq 为准，升级为完全漂移** |
| trend-momentum-scan | 漂移等级 × 技术面动量 | 基本面漂移 + 技术破位→双重恶化，加速触发；**背离时以基本面漂移为准** |

### 规则五：矛盾化解方案融入（第五步，四大矛盾）

- **矛盾一（止损 vs 越跌越买）**：🟢 未漂移+建仓初期跌>8% → 止损；🟢+底仓已建跌 10%~20% 且三维度未恶化 → 可加仓；≥🟡 漂移 → **禁止加仓**；🔴 → **立即清仓，不存在「越跌越买」**。
- **矛盾二（噪音 vs 拐点）**：单季异常不判拐点；连续 3 季一致确认拐点；连续 2 季异常第 3 季反弹 → 降级为部分漂移。
- **矛盾三（长期持有 vs 中期兑现）**：持有<4 季度且≤🟡 → 继续持有；持有≥4 季度且≥🟡 → **时间止损（P2）**。
- **矛盾四（分散 vs 集中）**：单标的漂移仅减该标的机动仓；同行业多标的漂移 → 行业级减仓（映射 `mid-industry-research`）。

## 执行流程

### 第一步：解析输入与调用参数，确定标的与市场

- 解析 `{标的}`、`--thesis-date`、`--since`、`--export`、`--export-path`、`--json`。
- 运行 `date` 确认当天日期，作为报告「数据截止日期」基准。
- 识别市场（A 股 / 港股 / 美股），决定后续数据工具。

### 第二步：提取六大基准假设（H1~H6）

按「规则一」从基线来源提取 H1~H6；无基线时按降级策略处理，缺失项标注不纳入计数。

### 第三步：逐条假设验证

按「规则二」逐维采集最新季度数据并三档判定，每条附证据链（最新值 vs 基线值 + 偏差）。

### 第四步：四级漂移等级评定

按「规则三」统计完全漂移项数，输出四级等级 + 颜色 + 趋势。

### 第五步：多技能联动

按「规则四」执行五项联动（implied-growth / exit-signal / valuation-thermometer / qoq / momentum）。

### 第六步：矛盾化解应用

按「规则五」将矛盾一~四应用到当前漂移场景。

### 第七步：输出报告

按「输出结果」节固定模板落盘。

## 工具软件使用指南

### 固化命令（零开发，复用既有工具）

```bash
# 确认日期（研究质量规则 1）
date

# 建仓论文（基线来源 ①）
python tools/common/report_audit.py --help   # 如需核对论文文件
# 论文路径：reports/{公司名}/{公司名}-mid-thesis.md（thesis-tracker --horizon mid 产出）

# 最新季度财务（按市场，提取 H2~H5）
python tools/a_share/stock_financial.py --code {code} --indicator ROE,毛利率,营业总收入,归母净利润
python tools/a_share/stock_financial.py --code {code} --advanced 合同负债,存货,研发费用,员工总数
python tools/hk_stock/stock_financial.py --financial {code}
python tools/us_stock/stock_financial.py --code {code}

# 加速度/偏差百分比/匹配度计算（禁 LLM 心算）
python tools/common/financial_rigor.py calc --expr "..."

# 隐含增速交叉验证
python tools/common/financial_rigor.py implied-growth --market-cap {cap} --target-pe {pe} --net-margin {margin} --ttm-revenue {revenue} --guidance-growth {growth}

# PEG 与估值温度（联动 exit-signal P4 / valuation-thermometer）
python tools/common/financial_rigor.py peg --price {p} --eps {eps} --growth {g}

# 渗透率/订单/地缘信息（H1/H2/H6）
python tools/common/anysearch.py "{公司名} 渗透率 订单 地缘" --tag finance --count 10 --zone cn --json --export
python tools/common/doubao_search.py "{公司名} 关税 制裁 供应链" --finance --time-range month --need-content --content-format markdown --json --export
```

### 关键约束

- 所有算术（偏差百分比、加速度、PEG、隐含增速）必须经 `financial_rigor.py calc` 执行，禁止 LLM 心算。
- 关键数据 ≥2 独立来源，误差 >1% 显式标记。
- A 股累计转单季口径写死：QoQ 环比必须先「本期累计 − 上期累计」转单季。
- 报告中的每个数值必须能追溯到对应命令输出。

## 与 exit-signal / valuation-thermometer / qoq-accelerator 联动映射（硬编码）

| 本技能输出 | 目标技能 | 映射 |
| --- | --- | --- |
| 显著漂移 🟠（3 项完全漂移） | `exit-signal` P3 | 产业景气拐点，减机动仓 |
| 严重漂移 🔴（≥4 项完全漂移） | `exit-signal` P2 | 逻辑止损，减仓或清仓 |
| 持有≥4 季度且漂移≥🟡 | `exit-signal` P2 | 时间止损 |
| 漂移等级 | `valuation-thermometer` | 🟡→-0.3 档 / 🟠→-0.5 档 / 🔴→-1.0 档，上限 ±1.0 档 |
| H5 判定与 qoq 矛盾 | `qoq-accelerator` | 以 qoq 为准，升级为完全漂移 |

> 修正幅度上限 **±1.0 档**，防止过度修正。漂移→卖出映射**强制对齐全局约定**：显著→P3、严重→P2、时间止损→P2（草稿曾误映射 P5，已纠正）。

## 风控硬编码（R-1~R-10，不允许 AI 自由裁量）

| 编号 | 规则 | 不可做的事 |
| --- | --- | --- |
| R-1 | 连续 3 季负加速 → 必须判完全漂移 | 禁止以「基数效应」「季节性」豁免 |
| R-2 | 单季负加速 → 不得判拐点 | 必须等连续 3 季确认 |
| R-3 | 持有≥4 季度 + 漂移≥🟡 → 必须触发时间止损（P2） | 不得忽略时间止损 |
| R-4 | 漂移等级 🔴 → 必须触发 exit-signal | 禁止 AI「综合判断」后降级 |
| R-5 | PEG>1.5 → 标注「估值高估」 | 不得弱化 |
| R-6 | PEG>2.0 → 标注「严重透支」 | 不得弱化 |
| R-7 | PE 历史分位>90% → 标注「估值极端」 | 不得弱化 |
| R-8 | 估值修正幅度上限 ±1.0 档 | 禁止叠加修正超上限 |
| R-9 | 禁止跳过 P0 检查；发现治理线索 → 标注并建议运行 exit-signal | 不得跳过 P0 |
| R-10 | 利润增速负+营收增速正 → 标注「利润营收不匹配」 | 不得以「阶段性投入」美化 |

> 所有硬性规则输出必须包含规则编号引用（如「触发 R-1」），确保可审计可追溯。

## 注意事项

1. 开始前运行 `date` 确认当天日期，报告头部注明数据截止日期。
2. 关键财务数据须至少两个独立来源交叉验证，误差 >1% 须标记。
3. 禁止 LLM 心算，所有偏差百分比/PEG/隐含增速经 `financial_rigor.py`。
4. A 股累计转单季口径写死：QoQ 环比必须先「本期累计 − 上期累计」转单季。
5. 基线必须显式提取，缺项标注「无法验证，不纳入计数」，禁止脑补。
6. 禁止使用 WebSearch / WebFetch 工具（中国大陆不可用），统一用本地搜索工具。
7. 中期术语红线：禁止出现「护城河永续」「终局思维」「持有10年」等长期框架术语。

## 局限性

1. 本技能只输出漂移结论与行动建议，不判断个股买卖价位（归 `exit-signal`/`valuation-thermometer`）。
2. 无中期论文时基线降级为行业报告或用户 `--old` 指定，置信度降低须显式标注。
3. 地缘维度（H6）主观性强，以硬编码判定阈值约束，不量化打分。
4. 四级漂移等级基于「完全漂移项数」的等权计数，未按权重加权（权重仅用于展示优先级）。
5. 本技能不承担渗透率数据采集，渗透率数据归 `mid-industry-research` 供给。

## 与其他Skill的关系

- **前置**：`thesis-tracker`（`--horizon mid` 建仓论文，基线来源①）、`mid-industry-research`（行业基线结论）、`qoq-accelerator`（H5 加速度证据）、`trend-momentum-scan`（技术面触发信号）。
- **后置**：`exit-signal`（漂移等级→P2/P3 映射）、`valuation-thermometer`（漂移等级作估值修正因子）。
- **同级**：`thesis-drift`（长期护城河漂移，本技能与它物理隔离、功能互补）。
- **边界**：只出漂移结论与行动建议，不出买卖价位；季度频率，时间止损归 P2。
