# 微信公众号文章（1~3年景气投资版）：作者-编辑-读者三Agent协作

对 $ARGUMENTS 进行深度研究，产出一篇可直接发布的微信公众号文章。三个Agent各司其职：作者写深度初稿，编辑精修结构和表达，读者从目标受众视角审读。

**支持输入格式**：主题描述，例如：
- **景气投资类（默认）**：`腾讯2025Q4财报解读（景气视角）`、`AI算力产业链瓶颈分析`、`为什么PEG<1是买入信号`、`光模块行业中期景气怎么看`
- **技术解读类**：`大模型OPD技术解读`、`Qwen3技术报告解读`

> 本技能属**中期链（1~3 年）**，与长期链 `wechat-article`（10 年 / 巴芒段李）**物理隔离、功能互补**。禁止使用「护城河永续」「终局思维」「持有10年」等长期框架术语。

---

## 能力圈声明

本技能文件适用于 **1~3 年中长期投资框架下的公众号文章写作**，非短期交易工具，非「封仓十年」式超长期持有，也非日内/周级别波段交易。

**适用场景**：
- 科技/医药/高端制造/景气周期成长股等景气成长股的财报解读（景气视角）
- 产业链分析与行业景气研究类公众号文章
- 景气投资方法论科普（PEG、渗透率、ROE 拐点、卖出纪律等）
- 结合中期研究结论（`mid-investment-team` / `mid-earnings-team` / `mid-industry-research` 等）的内容输出

**不适用场景**：
- 纯周期股（用 PE/PB 估值，PEG 不适用，文章视角需特殊处理）
- 困境反转股（PEG 不适用，需特殊框架）
- 金融股（资产负债表结构特殊，需单独评估框架）
- 被动指数投资
- 短期交易/日内波段

## 与长期版 `wechat-article` 的关系说明

长期版 `wechat-article` 面向 10 年长期价值投资与通用技术解读，其核心如「护城河永续」「封仓十年」「巴芒段李」等口径与 1~3 年景气投资框架存在以下关系：

- **可复用的写作框架**：三 Agent 协作（作者-编辑-读者）、四阶段流程骨架、写作风格规范、配图提取流程、公式 LaTeX 规范——这些是内容生产标准，与投资框架无关，完全复用。
- **不适用的内容视角**：长期版投资类文章的巴芒段李视角与「永续持有」表述，不适用于 1~3 年景气投资框架。本版以欧奈尔-林奇-郑希-李进四大师口径为准，持有周期以「景气周期长度」为准。
- **定位**：本技能是中期链的内容输出承接技能（组合 5 发布环节），与长期版 `/wechat-article` 物理隔离，不互相引用口径。

## 设计理念

一篇好的公众号文章需要同时满足三个维度：

1. **深度**——对得起花时间读完的人（作者负责）
2. **可读性**——结构清晰、节奏好、不劝退（编辑负责）
3. **真的能看懂**——目标读者不会在中途放弃（读者负责）

单人写作容易"自嗨"——写的人觉得清楚，读的人看不懂。三Agent协作的本质是**强制引入外部视角**。

**景气投资类文章的特别说明**：

本技能支持两类文章：
1. **景气投资类（默认）**：财报解读/产业链分析/投资方法论——侧重**GARP 框架**（林奇 PEG、郑希 ROE 趋势、李进渗透率、欧奈尔止损纪律）
2. **技术解读类**：论文/技术报告/新产品解读——侧重技术深度和通俗表达

写景气投资类文章时，作者Agent需采用四位景气大师的分析框架（**对齐 `research/个人投资者1~3年中长期投资思想与理念 V2.0.md` 权威分工表**）：

| 大师 | 思维模式 | 在框架中的角色 | 在文章写作中的落点 |
|------|---------|---------------|-------------------|
| 欧奈尔 | 工程师思维 · 信号与纪律 | **风控底线**：8% 止损、卖出触发、防止深度套牢 | 风险与纪律章节：止损位、趋势信号、P0~P5 触发检查 |
| 林奇 | 侦探思维 · 常识与求证 | **选股起点 + 估值定价**：生活常识选股、六类分类、PEG | 生意本质章节：六类分类、常识验证、PEG 估值 |
| 郑希 | 物理学家思维 · 周期与第一性原理 | **赛道选择**：ROE 拐点、产业景气、渗透率、地缘政治 | 景气验证章节：ROE 趋势、产业景气、地缘风险 |
| 李进 | 系统工程师思维 · 均衡与渗透率 | **组合管理 + 治理**：渗透率定位、底仓/机动仓、管理层与科研转化、治理一票否决 | 风险与纪律章节：管理层评估、渗透率定位、仓位建议 |

## 阶段一：研究与素材收集

### 第一步：明确文章定位

在开始写作之前，先确认以下信息（如用户未指定则主动询问）：

| 维度 | 需要确认 | 默认值 |
|------|---------|--------|
| **文章类型** | 景气投资/技术解读/其他 | **景气投资** |
| **目标读者** | 技术背景程度 | 有点技术背景但非该领域专家 |
| **文章深度** | 科普/中深度/硬核 | 中深度 |
| **文章长度** | 字数范围 | 3000-4000字 |
| **是否需要下载原始论文/资料** | 需要PDF/配图 | 是 |
| **写作风格** | 正式/对话式/犀利 | 对话式（像写给聪明的朋友） |

**景气投资类文章额外确认**：
- 分析标的（公司名/行业名）
- 分析的景气维度：ROE 趋势/渗透率/PEG/管理层/地缘政治（可多选）
- 是否涉及卖出纪律讨论（涉及时引用 `exit-signal` P0~P5）

### 第二步：深度研究

使用 Task 工具**并行**启动2-3个研究Agent，收集足够的素材：

**研究Agent A：核心内容研究**
- **技术类**：下载论文PDF、提取核心贡献、关键图表、实验结果
- **景气投资类**：搜索公司最新财报、财务数据、估值指标、分析师观点

**研究Agent B：行业背景与应用**
- **技术类**：搜索该技术的行业落地情况、发展趋势、里程碑事件
- **景气投资类**：搜索行业景气数据、竞争格局、渗透率数据、地缘政治风险

**研究Agent C（可选）：对比/验证研究**
- **技术类**：同类方法/产品的对比、历史发展脉络
- **景气投资类**：同行业可比公司对比、历史估值区间、买卖信号验证

#### 信息丰富度评级（景气投资类必做）

研究Agent收集素材时，先做**资料可得性评级**（对齐 mid-* 技能体系范式），并告知每个 Agent，影响其分析深度：

| 等级 | 特征 | 影响 |
| ---- | ---- | ---- |
| A级 | 获取到完整原文（财报/研报/一手数据） | 正常执行全部步骤 |
| B级 | 仅获取到部分原文或第三方汇总 | 标注「非原始来源」，推算数据标注置信度 |
| C级 | 仅有新闻报道和数据网站摘要 | 转第一性原理模式：聚焦核心数据变化，明确标注「一手资料不足」，不展开细节推断 |

#### AI 研究偏见预警（贯穿全程）

- **共识偏见**：当搜索结果高度一致看多/看空时（A 级信息），主动做**反面检验**——搜"风险""质疑""不及预期"关键词，检验共识是否已被定价。
- **光环效应**：不能因公司名气/股价上涨而放松对管理层诚信、财务质量的核查。
- **信息缺口诚实**：渗透率等数据缺乏官方统计时，标注为「估计」并给出区间，不虚构精确值。

#### 网络信息获取工具

研究Agent收集素材时，统一使用本地五工具组合（详见 [web-search-tools](../tools-scripts/web-search-tools.md)）。工具选型按主题涉及的市场参照矩阵：

- **A股主题**：`anysearch --tag finance` 主 + `doubao --finance` 辅
- **港股/美股/国际主题**：港股 `doubao --sites hkexnews.hk` + `tavily`（双源）；美股 `exa --type deep` + `doubao`（双源）
- **技术/论文主题**：英文文献优先 `exa --type deep`，中文资讯用 `doubao`，多源互补
- 使用 `--time-range month/week` 限制时间范围，优先获取最新信息

#### PDF文档内容提取（技术类文章）

论文解读类文章必须从PDF提取高清原图（≥500KB）。文字与表格提取**首选** `tools/common/pdf_extract.py`（基于pdf-inspector库，支持自动乱码检测+OCR回退），返回失败时才回退Poppler；**高清图像渲染提取配图仍需使用 Poppler `pdftoppm`**（`pdf_extract.py` 不提供图像渲染能力）。完整流程见 [PDF文档内容提取技能](../tools-scripts/pdf-extraction.md)。

```bash
# 文字与表格提取（首选）
python tools/common/pdf_extract.py markdown 论文.pdf --save-md --out-dir reports/pdf

# 高清图像渲染（用于配图，使用 Poppler pdftoppm）
pdftoppm -png -r 900 -f {页码} 论文.pdf output/page
```

### 第三步：整理素材框架

研究Agent全部完成后，整理出：

1. **核心论点**（一句话概括文章要传达的核心信息）
   - 技术类：论文/技术的核心突破是什么？
   - **景气投资类**：景气逻辑是否成立？买入/卖出信号是什么？（若涉及卖出纪律，标注引用 `exit-signal` 的层级）
2. **关键数据**（3-5个最有冲击力的数据点）
3. **配图清单**（需要哪些图，来源是什么）
4. **文章大纲**（6-8个章节的标题和核心内容）

## 阶段二：作者Agent写初稿

使用 Task 工具启动**作者Agent**，给出详细的写作指令。

### 作者Agent的Prompt模板（通用版）

```markdown
你是一位深度写作者（Author Agent），需要写一篇微信公众号文章。

## 目标读者
{根据第一步确认的读者画像}

## 写作风格要求
- 纯中文表达，避免中英文夹杂（技术术语首次出现时给英文，后续用中文）
- 像写给聪明的朋友看，不是学术论文翻译或研报搬运
- 用类比帮助理解，但类比要贴切、不俗套
- 关键公式/数据要有，但每个都要用大白话解释
- 不用emoji
- 段落不超过4行（公众号阅读环境）

## 核心内容
{整理好的素材、数据、论点}

## 文章结构要求
1. **开头（前3段）**：必须有强钩子——用数据冲击力或反直觉的结论开场
2. **背景**：为什么这件事重要？解决什么问题？
3. **核心内容（2-3节）**：深度在这里体现，但每个技术点都要有"大白话翻译"
4. **实证/案例**：用数据和案例说话，不要空谈
5. **影响/展望**：这件事对行业或投资意味着什么
6. **结尾**：一句有传播力的判断收束，适合被截图转发

## 配图要求
- 论文解读类：必须从论文PDF中提取原图，直接插入
- 每张图不小于500KB，确保高清
- 图片存放在 `assets/{主题简称}/` 目录

## 公式要求（技术类文章）
- 所有数学公式使用 LaTeX 格式
- 每个公式后面必须配"大白话翻译"

请写出完整的文章初稿，约{目标字数}字。
```

### 景气投资类文章专用Prompt扩展

当主题为景气投资类时，在作者Agent的Prompt中**追加**以下内容：

```markdown
## 景气投资类文章的特别要求

你正在写一篇**景气投资（GARP）**框架下的分析文章。本框架为 1~3 年中期视角，禁止使用「护城河永续」「终局思维」「持有10年」「巴芒段李」等长期框架术语。

### 分析框架
采用四位景气大师的视角（对齐 V2.0 权威分工表）：

1. **林奇（选股起点 + 估值定价）**：
   - 这家公司属于六类中的哪一类？（快速增长型/稳定增长型/周期型等）
   - 六类分类变化是卖出信号：快速增长型变稳定增长型 → 可能触发估值重新定价
   - 用生活常识验证：你/用户用过这家公司的产品吗？"10分钟能解释清这家公司靠什么赚钱吗？"
   - PEG 估值档位**以 `valuation-thermometer` 五档输出为准**，不自行罗列阈值

2. **郑希（赛道选择）**：
   - ROE 趋势向上还是向下？拐点到了吗？
   - 产业景气在什么位置？渗透率区间判断引用 `mid-industry-research` 口径（<5%过早 / 5%~10%萌芽 / 10%~30%黄金区 / 30%~50%成长期 / >50%成熟期）
   - 增速二阶导（增速加速度）是正是负？
   - 地缘政治风险敞口如何？（海外收入依赖度、供应链安全、制裁清单）

3. **李进（组合管理 + 治理）**：
   - 管理层诚信吗？承诺兑现率如何？（四维度 20 分制，口径引用 `mid-management-deep-dive` 与 V2.0）
   - 科研转化效率如何？（20 分制，科技/医药企业；口径同上）
   - **治理一票否决红线**：管理层失信/财务造假实锤/监管立案 → 立即清仓，不看估值和趋势
   - 仓位定位：底仓（60%~80%）还是机动仓（20%~40%）？渗透率定位在哪个阶段？

4. **欧奈尔（风控底线）**：
   - 止损位设在哪里？8~10% 是生存红线（止损比例取值规则以 `exit-signal` P1 为准）
   - 趋势信号确认了吗？
   - 卖出纪律检查：P0~P5 逐级核对（**映射表见下，细则引用 `exit-signal` 输出，不重复展开**）

### 卖出纪律映射表（引用 `exit-signal` P0~P5，不重复定义阈值）

| 级别 | 触发条件 | 决策 | 思想来源 |
|------|---------|------|---------|
| P0 治理一票否决 | 管理层失信、财务造假实锤、监管立案 | 立即清仓，不看估值趋势 | 李进（治理） |
| P1 硬止损 | 单笔亏损 8%~10%，且无基本面反转信号 | 无条件止损 | 欧奈尔 |
| P2 逻辑止损 | 连续 2 季业绩低于预期且产业景气未改善；或持有满 4 季度逻辑未兑现（时间止损） | 减仓或清仓 | 林奇 + 郑希 |
| P3 产业景气拐点 | 渗透率减速 / ROE 拐头向下 | 减机动仓 | 李进 + 郑希 |
| P4 估值透支 | PEG 进入高估/严重透支档（引用 `valuation-thermometer`） | 减 / 清机动仓 | 林奇 |
| P5 性价比替换 | 其他标的 PEG 显著更低且产业趋势更强 | 调仓（每季度最多 1 次） | 机会成本 |

> 核心原则：P0 > P1 > P2 > P3 > P4 > P5，命中即停，禁止跳过 P0。触发条件与阈值一律以 `exit-signal` 输出为准，本技能仅作映射表引用。

### 文章结构（景气投资类）
1. **开头钩子**：用估值/景气数据冲击开场（如"PEG 从 0.8 涨到 1.6，该卖了吗？"）
2. **生意本质**：一句话说清楚这家公司靠什么赚钱（林奇测试：10分钟能解释清吗？）+ 六类分类
3. **景气验证**：ROE 趋势、渗透率、二阶导、地缘风险（郑希/李进视角）
4. **估值判断**：PEG 档位（引用 `valuation-thermometer` 五档），给出操作区间（林奇视角）
5. **风险与纪律**：管理层 20 分制、科研转化 20 分制、地缘政治、止损位、P0~P5 触发检查（李进/欧奈尔视角）
6. **结论**：持有/加仓/减仓/清仓 + 核心理由；**对持有者、观望者分别给出操作指引**（对齐 mid-earnings-team 读者价值检测）
```

## 阶段四：定稿

### 第一步：综合两个Agent的反馈

重点关注以下高频问题：

| 问题类型 | 编辑常见反馈 | 读者常见反馈 | 处理方式 |
|---------|------------|------------|---------|
| 开头太弱 | 钩子不够强 | 前3段没动力继续 | 用数据/反直觉结论重写开头 |
| 技术/估值段劝退 | 公式/PEG计算太密集 | 某段需要重读3遍 | 删公式或加更直觉的类比 |
| 节奏拖沓 | 某节太长 | 某处失去耐心 | 合并或删减 |
| 结尾无力 | 缺传播力 | 不会转发 | 重写为一句可截图传播的判断 |
| **景气投资类特有** | 卖出纪律不够具体 | "不知道该卖还是该买" | 明确 P0~P5 层级和止损位 |
| **景气投资类特有** | PEG 档位口径模糊 | "不知道贵还是便宜" | 对齐 `valuation-thermometer` 五档结论 |

### 第二步：执行修改

根据反馈重写文章。核心修改原则：

1. **编辑和读者都指出的问题，必须改**
2. **只有编辑指出的问题，大概率要改**
3. **只有读者指出的问题，视情况改**
4. **两者矛盾时，偏向读者**

### 第三步：提取配图

#### 论文解读类文章

必须在定稿前完成配图提取：

1. **渲染**：`pdftoppm -png -r 900 -f {页码} 论文.pdf /tmp/page`（900 DPI起步）
2. **定位**：先用150 DPI渲染全页，目视确认各图表的像素坐标
3. **裁切**：用 PIL 按坐标裁切，确保每张 ≥ 500KB
4. **存储**：保存到 `assets/{主题简称}/` 目录
5. **插入**：文章中用 `![描述](../../assets/{主题简称}/fig{序号}.png)` 引用

#### 景气投资类文章

如需配图（估值图表、趋势图等），可使用以下方式：

1. **数据可视化**：使用工具生成图表（如matplotlib），保存为PNG
2. **网络搜索图片**：使用 `tools/common/web_search.py` 搜索相关图表，下载后保存到 `assets/{主题简称}/` 目录

### 第四步：数据抽检（准出流程）

文章落盘后**必须**执行数据抽检，通过后方可视为定稿：

```bash
# Step 1 - 提取抽检清单（15%随机抽样）
python tools/common/report_audit.py extract \
  --report reports/{公司名}/{公司名}-mid-wechat-{YYYYMMDD}.md --seed 42

# Step 2 - 对清单每项从可靠信源取数（按市场分别使用对应工具）
#   A股：tools/a_share/stock_financial.py（东方财富主）-> 巨潮资讯副 -> 年报PDF原始一手
#   港股：tools/hk_stock/stock_financial.py -> HKEX披露易
#   美股：tools/us_stock/stock_financial.py -> SEC EDGAR
#   计算验算：tools/common/financial_rigor.py（禁止 LLM 心算）

# Step 3 - 输出准出/打回判决
python tools/common/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report {公司名}-mid-wechat-{YYYYMMDD}.md
```

**【准出】** 所有抽检点偏差 ≤ 1% → 文章可发布；**【打回】** 任意点偏差 > 1% → 修正后重新抽检。

### 第五步：产出最终文件

将定稿保存为 md 文件，文件末尾附上参考资料链接：

```markdown
**参考资料：**
- {资料名称}: {链接}
- {报告名称}: {链接}

**风险提示与免责声明：**
本文内容基于公开信息和投资研究框架，不构成任何投资建议。市场有风险，投资需谨慎。文中提及的任何具体公司、估值指标或操作规则均不构成买卖依据。
```

## 注意事项

1. **不虚构数据**。引用的数据必须有来源，搜不到就标注"估计"
2. **不用AI腔调**。禁止"让我们一起来看看"、"不得不说"等套话
3. **不过度承诺**。技术文章不说"颠覆性的"，用数据说话
4. **公式必须配大白话**。每个公式后面都要有"翻译成人话就是……"
5. **公式必须用LaTeX**。`$$...$$` 格式，禁止纯文本公式
6. **配图必须实际插入**。禁止用 `[图X]` 占位符
7. **类比要一以贯之**。全文用一个主线类比
8. **结尾必须有传播力**。最后一句话要值得被单独截图转发
9. **景气投资类文章的特别要求**：
   - PEG 必须附计算依据和来源，档位结论与 `valuation-thermometer` 五档一致
   - 卖出纪律必须与 `exit-signal` P0~P5 一致，止损位具体明确
   - 林奇六类分类不能跳过
   - 四位景气大师的视角应均衡体现（对齐 V2.0 权威分工表）
   - 结论段须对持有者、观望者分别给出操作指引
10. **客观性原则**。区分事实与观点，用数据支撑判断
11. **诚实面对信息缺口**。无法获取的信息明确标注"信息不足"，渗透率等估算数据标注置信度
12. **引用不重复定义**。估值档位引用 `valuation-thermometer`，卖出纪律引用 `exit-signal`（P0~P5），产业景气/渗透率引用 `mid-industry-research`，管理层/科研转化 20 分制引用 V2.0 与 `mid-management-deep-dive`——本技能不自行罗列阈值
13. **中期口径红线**。禁止使用「护城河永续」「终局思维」「持有10年」「巴芒段李」等长期框架术语，持有周期以「景气周期长度」为准
14. **数据抽检**。文章落盘后必须执行 `report_audit.py extract → verdict` 抽检，偏差 ≤1% 准出、>1% 打回

## 局限性

1. **网络信息获取限制**：网络搜索须使用本地五工具组合
2. **图片生成质量**：AI生成的图片可能不符合预期
3. **论文PDF可得性**：部分论文可能需要付费或无法下载
4. **技术术语准确性**：非常专业的领域可能需要领域专家审核
5. **时效性限制**：网络搜索结果可能有延迟
6. **读者视角模拟局限**：Agent模拟的读者视角可能无法完全代表真实读者体验
7. **景气数据可得性**：部分行业渗透率等数据缺乏官方统计，需按 A/B/C 三级置信度标注
8. **数据工具延迟**：本地数据工具获取的数据可能有延迟，非实时数据
9. **不构成投资建议**：涉及投资内容仅用于学习与研究，不构成任何投资建议
