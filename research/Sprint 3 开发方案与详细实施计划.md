## 三、任务 A：`mid-industry-research`（1.5 天）

对 1~3 年景气赛道做深度研究，输出「**四维筛选 + 产业链卡脖子环节 + 景气周期定位 + 头部公司清单 + 多技能交叉验证**」的系统判断。与长期 `industry-research` **物理隔离、功能互补**：

| 维度 | `mid-industry-research`（本技能） | `industry-research`（长期） |
| --- | --- | --- |
| 时间维度 | 1~3 年景气周期 | 10 年永续经营 |
| 核心框架 | 郑希/李进产业景气周期定位 | 李录文明趋势判断 |

### A3 第一步：四维筛选验证（硬编码，对齐理念文档第 1 步 + 6.1）

#### 维度一：产业空间（TAM ≥ 1000 亿，复合增速 ≥ 20%）

| 检查项 | 通过标准 |
| --- | --- |
| 行业潜在市场规模（TAM） | ≥ 1000 亿元 |
| 未来 3 年复合增速（CAGR） | ≥ 20% |
| 市场空间可验证性 | ≥2 个独立来源，差异 >30% 时列出全部来源并标注「需人工判断」 |

处理逻辑：`TAM≥1000亿 且 CAGR≥20%` → 通过，进入下一维度；`TAM≤500亿 且 CAGR≤15%` → 触发 R-1，评级 C/拒绝，终止四维判断（不得推荐）；`TAM<1000亿 或 CAGR<20%` → 标注「市场规模或增速不足，降低优先级」，评级 ≤B，不得重仓推荐；数据来源冲突（差异>30%）→ 标注「需核实」。

#### 维度二：渗透率位置（10%~30% 黄金区，15% 加速临界，50% 兑现分水岭）

| 渗透率区间 | 评级 | 投资策略 |
| --- | --- | --- |
| < 5% | 过早 | 不参与，保持观察 |
| 5%~10% | 萌芽期 | 少量观察仓，仅限高风险承受者 |
| **10%~30%** | **黄金区** | **积极布局，重仓参与** |
| 30%~50% | 成长期 | 持有为主，机动仓逐步兑现 |
| > 50% | 成熟期 | 逐步退出，仅保留底仓 |

**二阶导验证（李进「增速的加速度」）**：渗透率加速上行（二阶导为正）→ 景气扩散；减速上行（二阶导转负）→ 接近增速峰值，需警惕。渗透率数据质量按来源分 A/B/C 三级置信度（行业协会官方 A 级、券商转引 B 级、媒体估算 C 级，需交叉验证）。

#### 维度三：业绩兑现度（连续 2 个季度验证）

| 验证维度 | 通过标准 |
| --- | --- |
| 营收增速 | 连续 2 季 > 行业平均 |
| 毛利率 | 连续 2 季稳定或提升 |
| 行业整体盈利 | 龙头已盈利，二线扭亏 |
| 利润 vs 营收匹配度 | 利润增速跟上营收增速，否则警惕费用失控 |

判定：强兑现（营收>行业+毛利率稳+利润匹配）/ 弱兑现（增收不增利）/ 未兑现（营收<行业）/ **题材炒作（无头部公司财报或均亏损 → 一票否决）**。先行指标验证：合同负债环比↑（未来收入加速）、存货合理↑（备货景气）、研发费用持续↑（企业信心）。

#### 维度四：地缘政治风险敞口（含「华为式」抗封锁韧性）

六维评估：海外收入依赖度 / 供应链安全 / 制裁与清单风险 / 本地化对冲能力 / 政策与合规环境 / **自主研发抗压韧性**。

「华为式」抗封锁韧性四子项：①研发投入强度与持续性（研发费用率 >15% 且逆周期不减 → 强韧性）；②核心技术自主可控（掌握底层专利/工艺 vs 仅集成组装）；③「备胎计划」与替代方案；④极端情形生存能力（制裁后能否靠替代市场维持现金流）。

综合评级与估值修正：🟢 低风险（海外收入<30%+供应链可控+无制裁+韧性强）无修正；🟡 中风险（海外 30%~50%+有对冲）估值折价 -10%~-20%；🔴 高风险（海外>50%+无对冲+制裁风险+韧性弱）**降低行业优先级**，估值折价 -20%~-40%。

#### 综合赛道评级（硬编码输出）

`A 级（四维全过）/ B 级（三维过，一项待观察）/ C 级（未达门槛或业绩未兑现）/ 拒绝（题材炒作或地缘一票否决）`。评级 A/B 才允许进入 `/mid-trend-tech-screen` 正向排序。

### A4 第二步：产业链全景图 + 卡脖子环节识别

绘制「上游→中游→下游→辅助」产业链结构，叠加**全球产业链利润分配视角**（郑希框架：哪个环节 ROE 率先向上，优先配置哪个）。

**卡脖子环节识别（6 条标准）**：供给集中度 ≤2 家 / 扩产周期 >2 年 / 替代难度高 / 产能利用率 >80% / 需求增速 >30% / 客户验证周期长。

### A5 第三步：全球上市公司扫描 + 确定性分层

| 层级 | 条件 | 仓位建议 |
| --- | --- | --- |
| Tier 1 | 大市值、纯正标的、行业龙头 | 核心仓位（底仓） |
| Tier 2 | 中市值、纯正或高占比、细分龙头 | 卫星仓位 |
| Tier 3 | 小市值、开发阶段、高风险高弹性 | 机动仓 |
| Tier 4 | 多元化公司中有相关业务 | 观察仓或回避 |

必须标注**未上市关键玩家**（独角兽/初创，可能是未来 IPO 后的竞争格局变量）。

### A6 第四步：头部公司四维打分排序

| 维度 | 权重 | 打分标准 |
| --- | --- | --- |
| 产业景气度 | 35% | 供需格局、价格趋势、CR3 集中度 |
| 基本面 | 30% | ROE 趋势、毛利率、营收利润匹配度 |
| 管理层与科研 | 20% | 诚信度、战略聚焦、科研转化（详见 `management-deep-dive`） |
| 地缘政治 | 15% | 海外依赖、供应链、制裁、抗封锁韧性 |

综合评分：≥80 S 级（核心仓位候选）/ 65~79 A 级（卫星仓位候选）/ 50~64 B 级（机动仓/观察）/ <50 C 级（回避）。

### A7 第五步：产业景气周期定位（中期与长期最关键区分点）

四阶段判断：

| 阶段 | 特征 | 渗透率位置 | 投资策略 |
| --- | --- | --- | --- |
| 技术跃迁期 | 新技术突破、供给创造需求 | 5%~15% | 积极布局，关注技术路线 |
| 需求爆发期 | 订单爆发、供给紧缺、价格上行 | 10%~20% | **重仓参与**（ROE 向上斜率最陡） |
| 供给受限期 | 产能瓶颈、价格维持高位 | 20%~35% | 持有为主，关注产能释放 |
| 成熟稳定期 | 增速放缓、竞争加剧、价格下行 | >40% | 逐步兑现，机动仓退出 |

**ROE 拐点判断（郑希框架）**：连续 3 季向上 → 拐点确认，积极配置；连续 3 季向下 → 景气下行，警惕；季度波动 → 噪音，不判拐点（对齐矛盾二规则）。

### A8 第六步：多技能交叉验证（草稿增量，Sprint 3 核心价值）

| 联动技能 | 验证内容 | 判定输出 |
| --- | --- | --- |
| implied-growth（`financial_rigor.py`） | 行业头部公司加权隐含增速 vs 实际预期增速 | 🟢绿灯（隐含≤实际）/ 🟡黄灯（隐含>实际但<2倍）/ 🔴红灯（隐含>实际2倍） |
| qoq-accelerator | 头部公司加速度汇总 → 行业加速度矩阵 | 多数加速=行业加速；分化=精选个股；多数减速=景气拐点预警 |
| trend-momentum-scan | 行业 ETF 动量（SMR/RSI50/MA50 vs MA200/抛售日频率） | 基本面×技术面交叉矩阵；**背离时以基本面（qoq 加速度）为准** |
| valuation-thermometer | 头部公司 PEG 五档汇总 → 行业整体温度 | 多数<0.8 显著低估 / 多数0.8~1.2 合理 / 多数1.2~1.5 偏贵 / 多数>1.5 高估 / 多数>2 严重透支 |
| mid-thesis-drift | 本报告结论作为漂移检测基线假设 | 输出漂移触发条件清单 |

### A9 第七步：组合配置建议（对齐理念文档仓位规则）

- **仓位结构**：行业 ETF 20%~40%；龙头白马（Tier 1）30%~50%；成长黑马（Tier 2）15%~25%；期权标的（Tier 3）5%~15%。
- **行业仓位上限**：需求爆发/技术跃迁期 40%；供给受限期 25%；成熟稳定期 15%（单一行业不超过总资产 40%）。
- **底仓/机动仓**：底仓 60%~80%（赚 1~3 年成长的钱）、机动仓 20%~40%（赚估值波动的钱）。
- **分批建仓**：进入黄金区且估值合理先建 1/3 底仓 → 恐慌/短暂利空（逻辑未破坏）加 1/3 → 景气加速或财报超预期补齐 1/3。
- **矛盾一化解（止损 vs 越跌越买）**：建仓初期（<最终仓位 50%）下跌超 8% → 止损优先；底仓已建且三维度未恶化 → 可估值下限加仓；逻辑被证伪 → 立即清仓。**核心原则：杀估值可逆向，杀逻辑必须止损。**

### A10 第八步：卖出条件预览（对齐 exit-signal V1.0 P0~P5）

| 级别 | 触发条件 | 操作 |
| --- | --- | --- |
| P0 治理一票否决 | 行业龙头管理层诚信问题、财务造假实锤、监管立案 | **立即清仓**，不看估值趋势 |
| P1 硬止损 | 行业 ETF/核心标的单笔亏损 8%~10% 且无基本面反转 | 无条件止损 |
| P2 逻辑止损 | 头部公司连续 2 季业绩低于预期且景气未改善；或持有满 4 季度逻辑未兑现（时间止损） | 减仓或清仓 |
| P3 景气拐点 | 渗透率增速转负（二阶导转负）；或头部公司 ROE 连续 3 季向下 | 减机动仓 |
| P4 估值透支 | 行业整体 PEG>1.5 → 减机动仓；PEG>2 → 加速清机动仓 | 减/清机动仓 |
| P5 性价比替换 | 其他行业 PEG 显著更低且产业趋势更强 | 调仓（每季度最多 1 次） |

> 本报告为**行业级预警**；个股级卖出需调用 `exit-signal` 执行完整 P0~P5 检查。

### A11 风控硬编码（R-1~R-10，不允许 AI 自由裁量）

| 编号 | 规则 |
| --- | --- |
| R-1 | TAM≤500 亿 且 CAGR≤15% → 必须标注「不满足中期投资门槛」，不得推荐 |

### A12 矛盾化解（行业级）+ 决策优先级速查卡

- 矛盾二（单季噪音 vs 趋势拐点）：单季波动标记「噪音」，连续 3 季同向才确认拐点。
- 矛盾四（分散 vs 集中）：行业间分散（3~5 个不同景气阶段的行业），行业内集中（每行业 2~3 只 Tier 1/2 龙头）。
- **决策优先级速查卡（P0~P5）**：与 A10 一致，核心原则「先保命（防造假/止损），再谈收益（景气/估值）」。

## 四、任务 B：`mid-thesis-drift`（1.5 天）

### B1 定位与边界

对比**建仓时投资论文中的景气假设**与**最新季度财报数据**，逐条验证假设是否仍成立，输出「**四级漂移等级 + 证据链**」及行动建议。与长期 `thesis-drift` 区分：

| 维度 | `mid-thesis-drift`（本技能） | `thesis-drift`（长期） |
| --- | --- | --- |
| 检测对象 | 景气假设（渗透率/订单/ROE/毛利率/加速度/地缘政治） | 护城河永续性、商业模式 |
| 核心追问 | 「当初的景气逻辑还在吗？」 | 「公司还是不是好公司？」 |
| 判定口径 | 四级漂移等级 + 证据链 | Improved / Unchanged / Weakened |
| 检测频率 | 季度 | 年度/半年度 |
| 时间止损 | 满 4 季度逻辑未兑现即触发 P2 | 可容忍数年业绩平淡 |
| 参考大师 | 郑希（景气跟踪）+ 李进（二阶导） | 巴菲特（护城河评估） |

**核心理念**：基于证据而非信仰。用最新季度数据逐条验证景气假设，假设被证伪（≥4 项完全漂移）无论股价涨跌均应触发卖出评估。

2. **被动触发**（上游产出下列信号时提示转入）：

### B3 第一步：提取六大基准假设（H1~H6）

**基线来源（优先级递减）**：① `thesis-tracker --horizon mid` 论文（`reports/{公司名}/{公司名}-mid-thesis.md`）→ ② 最近一次 `mid-industry-research` 报告结论 → ③ 用户 `--old` 显式指定旧报告。**必须从论文中明确提取，禁止 AI「脑补」**。

| 编号 | 假设类型 | 提取内容 | 权重 |
| --- | --- | --- | --- |
| H1 | 渗透率假设 | 建仓时渗透率位置、预期提升路径 | 20% |
| H2 | 订单/合同负债假设 | 建仓时合同负债水平、预期订单增长 | 20% |
| H3 | ROE 趋势假设 | 建仓时 ROE 水平、预期方向 | 20% |
| H4 | 毛利率假设 | 建仓时毛利率水平、预期趋势 | 15% |
| H5 | 增速加速度假设 | 建仓时加速度方向、预期持续 | 15% |
| H6 | 地缘政治假设 | 建仓时地缘评估、关税/制裁/供应链预期 | 10% |

假设完整性检查：无中期论文 → 提示先运行 `/thesis-tracker {标的} --horizon mid`（或降级从行业报告提取）；论文缺某假设 → 标注「该项无法验证，不纳入漂移计数」；H6 缺失 → 标注「地缘风险未设基线」。

### B4 第二步：逐条假设验证（三档判定 + 证据链）

每维输出「✅ 成立 / ⚠️ 部分漂移 / 🔴 完全漂移」，仅 🔴 计入完全漂移计数。

| 维度 | 关键判定阈值（硬编码） |
| --- | --- |
| H1 渗透率 | 最新≥预期→成立；偏差<20%→部分漂移；偏差≥20%→完全漂移；**渗透率>50%→完全漂移**；二阶导为负→完全漂移 |
| H2 订单 | 合同负债≥预期→成立；偏差<15%→部分漂移；偏差≥15%→完全漂移；**环比绝对下降→完全漂移**；存货大增但合同负债未增→库存积压预警 |
| H3 ROE | 连续 3 季向上→成立；持平或小幅降（<10%）→部分漂移；**下降≥10% 或连续 3 季下降→完全漂移**（郑希「ROE 向上是重力加速度」被证伪） |
| H4 毛利率 | ≥建仓时→成立；下降<3 个百分点→部分漂移；**下降≥3 个百分点或连续 3 季下降→完全漂移**；利润增速<营收增速（差距≥10%）→费用失控预警 |
| H5 加速度 | 连续 3 季增速上升→成立；先升后平/正负交替→部分漂移；**连续 3 季增速下降→完全漂移**（李进二阶导）；QoQ/YoY 双口径，矛盾时以 YoY 为主 |
| H6 地缘 | 无实质恶化→成立；新威胁未落地→部分漂移；**关税加征/制裁落地/供应链断裂→完全漂移**；本地化产能投产→对冲有效 |

**硬性规则**：单季负加速不得判拐点（R-2）；连续 3 季负加速必须判拐点（R-1）。

### B5 第三步：四级漂移等级评定

| 完全漂移项数 | 漂移等级 | 颜色 | 行动建议 |
| --- | --- | --- | --- |
| 0 项 | **未漂移** | 🟢 | 继续持有，关注 ⚠️ 项 |
| 1 项 | **轻微漂移** | 🟡 | 底仓持有，机动仓考虑减仓 |
| 2~3 项 | **显著漂移** | 🟠 | 大幅减机动仓，底仓设止损线 |
| ≥4 项 | **严重漂移** | 🔴 | **触发 exit-signal 卖出评估** |

附加**漂移趋势追踪**：逐季改善→逻辑修复，维持/加仓；逐季恶化→逻辑崩塌，准备退出。

### B6 第四步：多技能联动

| 联动技能 | 内容 | 关键判定 |
| --- | --- | --- |
| implied-growth | 市值隐含增速 vs 实际景气增速 | 红/黄/绿灯；与漂移等级交叉矩阵（严重漂移+任意灯色→触发 exit-signal） |
| exit-signal P0~P5 | 漂移等级→P 级别映射 | **显著漂移→P3（景气拐点）；严重漂移→P2（逻辑止损）**；时间止损（持有≥4 季度且漂移≥🟡）→P2 |
| valuation-thermometer | 漂移等级作为估值温度修正因子 | 🟡→-0.3 档 / 🟠→-0.5 档 / 🔴→-1.0 档；**修正幅度上限 ±1.0 档** |
| qoq-accelerator | H5 判定与 qoq 评级交叉 | 一致→高置信度；矛盾时（本技能 ⚠️ 但 qoq 🔴）→**以 qoq 为准，升级为完全漂移** |
| trend-momentum-scan | 漂移等级 × 技术面动量 | 基本面漂移 + 技术破位→双重恶化，加速触发；**背离时以基本面漂移为准** |

### B7 第五步：矛盾化解方案融入（四大矛盾）

- 矛盾一（止损 vs 越跌越买）：🟢 未漂移+建仓初期跌>8% → 止损；🟢+底仓已建跌 10%~20% 且三维度未恶化 → 可加仓；≥🟡 漂移 → **禁止加仓**；🔴 → **立即清仓，不存在「越跌越买」**。
- 矛盾二（噪音 vs 拐点）：单季异常不判拐点；连续 3 季一致确认拐点；连续 2 季异常第 3 季反弹 → 降级为部分漂移。
- 矛盾三（长期持有 vs 中期兑现）：持有<4 季度且≤🟡 → 继续持有；持有≥4 季度且≥🟡 → **时间止损（P2）**。
- 矛盾四（分散 vs 集中）：单标的漂移仅减该标的机动仓；同行业多标的漂移 → 行业级减仓（映射 `mid-industry-research`）。

### B8 风控硬编码（R-1~R-10）

| R-5 | PEG>1.5 → 标注「估值高估」 |
| R-6 | PEG>2.0 → 标注「严重透支」 |
| R-7 | PE 历史分位>90% → 标注「估值极端」 |
| R-8 | 估值修正幅度上限 ±1.0 档 |
| R-9 | 禁止跳过 P0 检查；发现治理线索 → 标注并建议运行 exit-signal |
| R-10 | 利润增速负+营收增速正 → 标注「利润营收不匹配」 |
