## 一、背景与目标

### 1.1 背景

- 现有 `.trae/skills/dyp-ask/SKILL.md` 是**长期价值投资**（段永平）问答技能，与《个人投资者1~3年中长期投资思想与理念 V2.0.md》（下称 **V2.0**）的中期投资口径不匹配。
- `research/early-version/GARP-ask 技能文件（草稿）.md`（下称 **草稿**）已以 dyp-ask 为参考、面向 1~3 年目标做过一轮修改，但存在多处**与 V2.0 / 中期技能权威口径不一致**的问题，不能直接落地。

### 1.2 目标

1. 以草稿为底稿、dyp-ask SKILL.md 为格式范式、V2.0 为思想口径，产出**适用于 1~3 年中期投资**的 `garp-ask` 技能：
   - `.trae/skills/garp-ask/SKILL.md`（核心产物）
   - `.trae/skills/garp-ask/README.md`（配套产物）
2. 同步更新联动文档（CLAUDE.md、中期工作步骤文档等），保证命令可被正确路由、术语与口径全链一致。

### 1.3 定位声明

- `garp-ask`：**问答型技能**（与 dyp-ask 同类），`disable-model-invocation: true`，**不生成报告文件**，直接对话回答。
- 属**中期链（1~3 年）**，与长期链 `dyp-ask`（段永平）**物理隔离**。

## 三、目标产物结构与内容大纲

### 3.1 目录结构

```
.trae/skills/garp-ask/
├── SKILL.md     # 技能详细指令（核心）
└── README.md    # 快速上手/功能/示例/局限
```

### 3.2 SKILL.md 章节大纲（对齐 dyp-ask 范式 + 草稿内容）

1. **frontmatter**：`name: garp-ask`、`description`（PEG 为锚 + 四大师 = cover 1~3 年问答）、`disable-model-invocation: true`
2. **角色定位声明**：GARP 定义 + 适用周期（1~3 年，非短期交易、非封仓十年）
3. **四位大师阵容与分工**（对齐 V2.0 开篇 + 角色表）
   - 欧奈尔 → 风控底线（8% 止损 / 卖出触发）
   - 林奇 → 选股起点 + 估值定价（生活常识 / PEG）
   - 郑希 → 赛道选择（ROE 拐点 / 产业景气 / 渗透率 / 地缘政治）
   - 李进 → 组合管理 + 治理（底仓/机动仓 / 管理层与科研转化 / 治理一票否决）
4. **GARP 核心理念**：PEG 公式、适用/不适用场景、能力圈、估值陷阱提醒
5. **大师选择逻辑**（关键词 → 回答模式）
6. **回答风格规范**（各大师风格 + 出现频率）
7. **回答格式**（引用块模板）
8. **核心问答流程**（六步标准流程，对齐 V2.0 四步筛选）
9. **一页纸操作速查卡**：PEG 五档（引用 valuation-thermometer）+ P0~P5（引用 exit-signal）+ 分批建仓 + 仓位上限
10. **四大核心矛盾与化解**（对齐 V2.0 第五部分，含「10% 临界点处理」）
11. **执行指令**（不要/要 + 大师快捷指令 `@林奇` 等）
12. **工具使用指南**：本地三市场数据工具表 + 网络搜索五工具选型 + `financial_rigor.py` 验算规范
13. **注意事项**（全局约束：日期确认 / 双源验证 / 禁心算 / 免责）
14. **局限性**
15. **示例对话**（对齐 P0~P5 与五档口径）

### 3.3 README.md 章节大纲（对齐 dyp-ask README 范式）

- 快速开始（`/garp-ask {问题}` 调用方式与示例）
- 核心功能（GARP 框架 + 四大师分工）
- 使用示例（林奇主轴、`@林奇` / `@GARP` 快捷指令）
- 输出方式（问答型，不生成报告文件）
- 回答标准、不做之事
- 工具依赖
- 核心原则、注意事项、局限性
- 相关文档（引用 valuation-thermometer / exit-signal / mid-industry-research / mid-management-deep-dive / dyp-ask 隔离说明）
- 版本信息、免责声明

## 四、口径对齐表（开发时逐条落地）

### 4.1 PEG 五档（引用 `valuation-thermometer`，不重复定义）

| 档位 | PEG 区间 | 操作建议 |
|------|---------|---------|
| 显著低估 | < 0.8 | 绝佳买点，底仓可加 |
| 合理 | 0.8 ~ 1.2 | 先建 1/3 底仓 |
| 偏贵 | 1.2 ~ 1.5 | 机动仓观望（不买不卖） |
| 高估 | 1.5 ~ 2.0 | 机动仓减持 |
| 严重透支 | > 2.0 | 加速清机动仓 |

### 4.2 P0~P5 卖出优先级（引用 `exit-signal`，不重复定义）

| 级别 | 触发 | 决策 |
|------|------|------|
| P0 治理一票否决 | 失信/造假/立案 | 立即清仓 |
| P1 硬止损 | 亏损 8%~10% | 无条件止损 |
| P2 逻辑止损 | 连续 2 季低于预期 / 满 4 季度未兑现（时间止损） | 减仓或清仓 |
| P3 产业景气拐点 | 渗透率减速 / ROE 拐头 | 减机动仓 |
| P4 估值透支 | PEG>1.5 减 / PEG>2.0 清机动仓 | 减/清机动仓 |
| P5 性价比替换 | PEG 差距 >0.3 + 趋势更强 | 每季度最多 1 次调仓 |

### 4.3 大师分工（对齐 V2.0）

| 大师 | 思维模式 | 在框架中角色 |
|------|---------|-------------|
| 欧奈尔 | 工程师·信号与纪律 | 风控底线 |
| 林奇 | 侦探·常识与求证 | 选股起点 + 估值定价 |
| 郑希 | 物理学家·周期与第一性原理 | 赛道选择 |
| 李进 | 系统工程师·均衡与渗透率 | 组合管理 + 治理 |

## 八、风险与注意事项

1. **口径冲突是本任务最大风险**：草稿的六档 PEG、P0~P6、段永平第五人、增速 15-25% 与 V2.0/中期技能权威口径冲突，若不修正，会造成 garp-ask 与 `valuation-thermometer` / `exit-signal` / V2.0 三处权威源互相打架。
2. **"引用不重复定义"铁律**：PEG 五档、P0~P5 在 garp-ask 内只做「引用」，不做二次定义，避免口径漂移。
3. **中期/长期物理隔离**：garp-ask 禁止引入长期链术语；dyp-ask（长期）保持不动。
4. **数据规范**：garp-ask 涉及 PEG 时须落地 `financial_rigor.py` 验算 + 双源交叉验证 + 日期确认，禁止 LLM 心算。
