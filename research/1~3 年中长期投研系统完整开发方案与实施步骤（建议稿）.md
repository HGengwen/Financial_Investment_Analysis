## 一、项目概述

### 1.1 项目背景

当前系统（V2.0）已完整实现**10年长期价值投资**的投研框架，包含22个技能、完整的数据工具链（A股/港股/美股）、以及基于四位投资大师（欧奈尔、林奇、郑希、李进）的分析体系。

现需在同一代码基座上，扩展**1~3年中长期趋势投资**的投研能力，满足个人投资者在"景气上行+估值修复"周期中的选股、验证、持仓管理与卖出决策需求。

### 1.2 项目目标

| 维度 | 目标描述 |
|------|----------|
| **功能目标** | 提供从行业景气扫描到个股卖出信号触发的**完整1~3年投研闭环** |
| **输出形态** | Markdown格式的结构化研究报告（暂不实现复杂UI） |
| **性能目标** | 单标的完整分析 ≤ 3分钟；行业扫描（30家）≤ 15分钟 |
| **兼容目标** | 与现有长期系统**共享数据层和工具层**，逻辑层**物理隔离**，互不干扰 |

### 1.3 项目范围

**包含**：
- 6个新增中期特有技能（均以 `mid-` 前缀命名，与长期技能同级存放）
- 2个现有技能的参数化增强（原文件增加条件分支）
- 1个独立的"证券AI中长期（1~3年）价值投资研究工作步骤.md"导航文档
- 路由决策树的建立与实施

**不包含**：
- 用户界面开发（Web/Streamlit等）
- 自动交易执行
- 高频数据接入
- 现有长期技能的核心逻辑修改


## 二、核心理念与设计原则

### 2.1 中期投资的三大核心理念

| 理念 | 内涵 | 与长期投资的区别 |
|------|------|------------------|
| **产业景气是β** | 选赛道比选个股更重要，渗透率10%~30%为黄金区 | 长期投资更看重护城河的永续性 |
| **估值是温度计** | PEG和PE历史分位决定买卖时点，而非DCF绝对估值 | 长期投资用DCF看内在价值，中期用PEG看估值弹性 |
| **时间是法官** | 持有满4个季度未兑现即触发替换建议 | 长期投资可以容忍数年业绩平淡 |

### 2.2 设计原则

1. **分支独立，绝不修改原长期技能核心文件**：所有中期特有技能新建 `mid-` 前缀文件（如 `mid-industry-research/SKILL.md`），与长期技能（如 `industry-research/SKILL.md`）在 `.trae/skills/` 目录下同级存放，**不采用**子目录隔离方式，简化路径结构。
2. **数据层完全共享**：`tools/` 下所有Python工具（数据获取、估值计算、PDF解析、网络搜索）零改动复用。
3. **路由显式化**：根据用户输入关键词，显式路由到长期或中期技能链。
4. **文档双轨制**：长期和中期各自拥有独立的"研究工作步骤.md"文档，便于用户按需查阅。
5. **风控硬编码**：欧奈尔8%~10%止损、1年时间止损、技术面破位（MA200）作为硬性规则写入Prompt，不允许AI自由裁量。

### 2.3 四位大师在中期框架中的角色重定位

| 大师 | 长期投资角色 | 中期投资角色（调整后） |
|------|------------|----------------------|
| **欧奈尔** | 底线止损（8%） | **提升至最高优先级**：8%硬止损 + 突破新高买入 + 抛售日识别 |
| **林奇** | 常识选股起点 | **增加GARP维度**：PEG<1为合理，关注"增速与估值匹配" |
| **郑希** | ROE拐点定方向 | **核心主轴**：全球产业链景气追踪 + ROE拐点判断 + 二阶导思维 |
| **李进** | 渗透率定位产业阶段 | **保留并强化**：15%临界点理论 + 渗透率50%后考虑兑现 |


## 三、兼容性方案：一套引擎，两套驾驶舱

### 3.1 架构决策

**明确结论**：不拆分两个独立系统，采用"一套代码基座 + 两种策略模式"架构。

**决策依据**：
- 数据层（AkShare/缓存等）完全共享，拆分将导致双倍维护成本
- 用户可能同时持有长期底仓和中期机动仓，需在统一组合中管理
- 工具库（`financial_rigor.py`、`pdf_extract.py`等）完全通用

### 3.2 物理隔离方案

采用 **"mid-" 前缀命名 + 同级存放** 方案，不采用子目录方式：

```
.trae/skills/
│
├── [长期技能 - 保持原样]
│   ├── industry-research/
│   │   └── SKILL.md
│   ├── quality-screen/
│   │   └── SKILL.md
│   ├── investment-team/
│   │   └── SKILL.md
│   ├── thesis-tracker/              ← 将被增强（加 --horizon 参数）
│   │   └── SKILL.md
│   ├── portfolio-review/            ← 将被增强（加 --mode 参数）
│   │   └── SKILL.md
│   └── ... (其余17个)
│
├── [中期技能 - 新增 mid- 前缀，与长期技能同级存放]
│   ├── mid-industry-research/       ← 中期版入口（基于原版改造）
│   │   └── SKILL.md
│   ├── valuation-thermometer/       ← 新增
│   │   └── SKILL.md
│   ├── qoq-accelerator/             ← 新增
│   │   └── SKILL.md
│   ├── trend-momentum-scan/         ← 新增
│   │   └── SKILL.md
│   ├── mid-thesis-drift/            ← 新增
│   │   └── SKILL.md
│   └── exit-signal/                 ← 新增
│       └── SKILL.md
│
├── [独立导航文档]
│   ├── 证券AI价值投资研究工作步骤.md                 ← 现有，保持不变
│   └── 证券AI中长期（1~3年）价值投资研究工作步骤.md   ← 新建
│
└── tools-scripts/                    ← 共享工具参考文档
```

**"mid-" 前缀命名的优势**：
- ✅ 与长期技能在文件系统中**同级展示**，便于用户通过 `ls` 或IDE侧边栏一览无余
- ✅ 命名自带语义（`mid-` 清晰标识中期属性），无需进入子目录即可识别
- ✅ 路由逻辑更简洁：直接匹配 `mid-` 前缀即可路由至中期技能链
- ✅ 避免长期积累后子目录嵌套过深的问题

### 3.3 路由决策规则

> **本节核心**：在原有路由规则基础上，新增独立的"证券AI中长期（1~3年）价值投资研究工作步骤.md"文档作为中期技能链的完整入口和导航，同时保留现有长期版本文档，形成双文档并行、统一路由决策的架构。

#### 3.3.1 路由决策总览

沿用"一套引擎，两套驾驶舱"的架构决策，路由层在收到用户请求后，执行以下两步判断：

**第一步：持有周期意图识别**

| 用户输入信号 | 路由目标 | 示例 |
|-------------|----------|------|
| 含"长期/10年/永续/收息/护城河/巴菲特/段永平" | 长期技能链 | "长期研究一下茅台" |
| 含"中期/1-3年/景气/趋势/弹性/加速/拐点/动量" | **中期技能链** | "中期景气筛选AI算力行业" |
| 含"短期/下周/本月/短线/波段" | 提示不在支持范围内 | "短期走势如何" → 回复"本系统仅支持中长期投资" |
| 无明确信号 | 追问确认 | "研究一下新能源" → 追问"请问是长期价值投资（10年）还是中期景气投资（1-3年）？" |

**第二步：路由执行（双文档并行机制 + mid- 前缀路由）**

| 路由目标 | 加载的导航文档 | 技能文件路径特征 |
| --- | --- | --- |
| 长期技能链 | `证券AI价值投资研究工作步骤.md` | 无前缀（如 `industry-research/`） |
| **中期技能链** | **`证券AI中长期（1~3年）价值投资研究工作步骤.md`** | **`mid-` 前缀（如 `mid-industry-research/`）** |

#### 3.3.2 双文档并行架构对比

| 对比维度 | 长期版文档（现有） | 中期版文档（新建） |
| --- | --- | --- |
| **文件名** | `证券AI价值投资研究工作步骤.md` | `证券AI中长期（1~3年）价值投资研究工作步骤.md` |
| **核心思想** | 永续经营、护城河、DCF估值 | 景气上行、PEG匹配、时间止损 |
| **入口技能** | `industry-research` | `mid-industry-research` 或 `trend-tech-screen` |
| **估值核心** | DCF、股息率、ROE-PB | **PEG、PE历史分位、PSG** |
| **卖出触发** | 护城河崩塌、管理层失信 | **止损/透支/时间/破位（四级优先级）** |
| **特有章节** | 文明趋势判断（李录框架） | 特殊纪律与风控规则（五条硬性规则） |
| **组合管理** | 护城河变化分析 | **时间止损清单** |
| **技能文件标识** | 无前缀 | **`mid-` 前缀** |

#### 3.3.3 路由规则更新位置

| 文件 | 更新内容 | 操作类型 |
|------|----------|----------|

### 6.2 新增技能2：`valuation-thermometer`（估值温度计）

**文件路径**：`.trae/skills/valuation-thermometer/SKILL.md`

**功能定位**：对单只或多只标的，综合计算PEG、PE历史分位、PSG，输出四档评级。

**输入参数**：
- `{公司名或代码}`（必填，支持批量逗号分隔）
- `--growth-horizon`：增长预期年限，默认2年

**执行流程**（5步）：
1. 获取标的TTM EPS、TTM营收、当前PE、历史5年PE序列
2. 获取一致预期未来2年EPS增速（`anysearch` 抓取券商研报）
3. 计算：PEG = 当前PE / 未来2年EPS复合增速
4. 计算：PE历史分位 = 当前PE在5年PE序列中的百分位
5. 输出四档评级及决策建议

**评级标准**：

| 评级 | 条件 | 颜色标识 | 决策建议 |
|------|------|----------|----------|
| 低估 | PEG<0.8 且 PE分位<40% | 🟢 | 可建仓或加仓 |
| 合理 | PEG 0.8~1.2 且 PE分位40%~70% | 🟡 | 可持有或轻仓 |
| 高估 | PEG>1.5 或 PE分位>80% | 🟠 | 减机动仓 |
| 严重透支 | PEG>2 | 🔴 | 加速清机动仓，不追高 |

**依赖工具**：
- `python tools/common/financial_rigor.py peg --pe {pe} --growth {growth}`
- `python tools/common/financial_rigor.py pe-percentile --pe-series '{json}' --current {pe}`

### 6.3 新增技能3：`qoq-accelerator`（季度加速度分析）

**文件路径**：`.trae/skills/qoq-accelerator/SKILL.md`

**功能定位**：专门分析单季度营收、归母净利润的环比增速和加速度（二阶导），判断景气拐点方向。

**输入参数**：
- `{公司名或代码}`（必填）
- `--quarters`：回溯季度数，默认8个季度

**执行流程**（5步）：
1. 获取标的最近8个季度的**单季**营收、单季归母净利润
2. 计算每个季度的环比增速（QoQ growth %）
3. 计算加速度 = 本季度环比增速 - 上季度环比增速
4. 判断趋势：
   - 加速度连续2个季度为正 → 景气加速 🟢
   - 加速度正负交替 → 景气平稳 🟡
   - 加速度连续2个季度为负 → 景气减速 🔴
5. 输出加速度拐点方向、最新季度增速是否高于过去8个季度均值

**依赖工具**：
- `python tools/a_share/stock_financial.py --code {code} --indicator 营业总收入,归母净利润`

### 6.4 新增技能4：`trend-momentum-scan`（景气动量扫描）

**文件路径**：`.trae/skills/trend-momentum-scan/SKILL.md`

**功能定位**：对持仓清单进行技术面动量扫描，判断趋势是否延续。

**输入参数**：
- `{持仓清单}`（逗号分隔的代码或名称，必填）
- `--benchmark`：基准指数，默认沪深300

**执行流程**（4步）：
1. 获取每只标的最近250个交易日日线数据
2. 计算：250日涨幅、SMR百分位（同板块）、RSI(50)、MA50/MA200偏离度
3. 自动获取同板块成分股（通过 `stock_quote --auto-peers`）
4. 输出趋势健康度评分和"趋势延续/趋势弱化/趋势反转"判断

**趋势判断标准**：

| 条件 | 判断 | 颜色 |
|------|------|------|
| SMR>70 且 股价>MA200 且 股价>MA50 | 趋势延续 | 🟢 |
| SMR 40~70 或 股价在MA50附近震荡 | 趋势弱化 | 🟡 |
| SMR<40 或 股价<MA200 | 趋势反转 | 🔴 |

**依赖工具**：
- `python tools/a_share/stock_quote.py --code {code} --momentum --auto-peers`

### 6.5 新增技能5：`mid-thesis-drift`（逻辑漂移检测-中期版）

**文件路径**：`.trae/skills/mid-thesis-drift/SKILL.md`

**功能定位**：对比最新季报数据与买入论文，检测五个维度是否存在逻辑漂移。

**输入参数**：
- `{公司名或代码}`（必填）
- `--since`：买入日期（YYYY-MM-DD）

**执行流程**（5步）：
1. 读取建仓时的 `thesis-tracker` 论文
2. 提取论文中的核心逻辑：产业景气方向、业绩增速预期、PEG目标
3. 获取最新季报数据
4. 五维度对比检测：

| 检测维度 | 数据来源 | 漂移判定 |
|----------|----------|----------|
| 产业景气 | 营收增速 vs 论文预期增速 | 低于预期>20% → 漂移 |
| 订单能见度 | 合同负债环比变化 | 环比下降>10% → 漂移 |
| 盈利能力 | 毛利率变化 | 下降>3个百分点 → 漂移 |
| 估值匹配度 | 当前PEG vs 建仓时PEG | 上升>50% → 漂移 |
| 竞争格局 | 市占率变化 | 下降或持平 → 漂移 |

5. 输出综合判断：✅ 逻辑完好 / ⚠️ 部分漂移 / ❌ 严重漂移

**依赖工具**：
- 读取 `reports/thesis/` 下的论文文件
- `python tools/a_share/stock_financial.py --code {code} --advanced 合同负债,毛利率`

### 6.6 新增技能6：`exit-signal`（卖出信号触发）——**最关键的新增技能**

**文件路径**：`.trae/skills/exit-signal/SKILL.md`

**功能定位**：综合欧奈尔止损、PEG透支、时间止损、技术面破位四个维度，输出"持有/减仓/清仓"信号。这是中期投资的最终决策模块。

**输入参数**：
- `{公司名或代码或持仓清单}`（必填）
- `--buy-date`：买入日期
- `--buy-price`：买入价格
- `--mode`：`daily`（每日检查）/ `quarterly`（季度检查）

**执行流程（四级优先级检查）**：

| 优先级 | 检测维度 | 触发条件 | 输出信号 | 思想来源 |
|--------|----------|----------|----------|----------|
| **P0（最高）** | 欧奈尔硬止损 | 当前价 ≤ 买入价 × 0.92 | **立即清仓** | 欧奈尔 |
| **P1** | 技术面破位 | 当前价 < 200日均线 | **降级/清仓** | 欧奈尔/李进 |

| **P3** | 估值透支 | PEG>1.5 且 PE分位>80% | **减机动仓** | 林奇/李进 |
| **P4** | 逻辑漂移 | 五维度检测中≥3项漂移 | **清仓或大幅减仓** | 林奇/郑希 |

**执行逻辑**：
- 从上到下依次检查，**高优先级触发即停止后续检查**
- 输出最终信号：`持有` / `减机动仓` / `减仓至观察仓` / `清仓`

**依赖工具**：
- `python tools/a_share/stock_quote.py --code {code}`（获取当前价和MA200）

## 附录B：关键术语表

> 本表按估值财务、三大报表、现金流、景气周期、技术动量、策略风控与本系统特有七类汇总，供阅读正文时速查。

### B.1 估值与财务指标类

| 术语 | 定义 |
|------|------|
| **PE（市盈率）** | 股价 / 每股收益（TTM），最基础的估值倍数；中期投资须与增速结合使用（见PEG），不宜孤立看绝对值 |
| **PB（市净率）** | 股价 / 每股净资产，适用于银行、保险、周期股等重资产行业估值 |
| **PEG** | 市盈率相对盈利增长比率 = PE / EPS增长率，<1为低估、0.8~1.2为合理（林奇GARP核心指标） |
| **PSG** | 市销率相对盈利增长比率 = PS / 营收增长率，适用于尚未盈利或毛利极低的成长股估值 |
| **PE历史分位** | 当前PE在近5年PE序列中所处的百分位；<40%偏低、>80%偏高，是"估值温度计"的核心刻度 |
| **DCF（现金流折现）** | 将未来自由现金流按折现率折算为现值的内在价值法；长期投资主用，中期投资仅作参考基准 |
| **ROE（净资产收益率）** | 净利润 / 净资产，衡量股东资本回报效率；ROE拐点方向是郑希中期体系的核心主轴 |
| **ROE-PB 估值法** | 以ROE判断盈利能力、以PB衡量市场定价，高ROE可支撑更高PB，两者背离时提示机会或风险 |
| **股息率** | 每股分红 / 股价，衡量收息回报；中期投资中仅作辅助参考，不作为核心估值锚 |
| **毛利率** | (营业收入 - 营业成本) / 营业收入，反映产品竞争力与议价能力；毛利率持续下滑是逻辑漂移信号 |
| **合同负债** | 已收款尚未履约的订单金额，属于"订单能见度"的代理指标，环比变化用于中期景气判断 |
| **存货周转率** | 营业成本 / 平均存货，反映库存消化速度；周转率下降提示产品滞销或需求走弱 |
| **归母净利润** | 归属于母公司股东的净利润，A股财报核心利润口径，QoQ加速度分析基于该口径 |
| **环比增速（QoQ）** | 本季度较上季度增长的比率，用于捕捉短期景气拐点（受季节性扰动较大） |
| **同比增速（YoY）** | 本季度较去年同期增长的比率，消除季节性干扰，适合观察中期趋势 |
| **复合增速（CAGR）** | 一定年限内盈利的年化复合增长率，PEG计算中"增速"的规范口径（如未来2年EPS CAGR） |
| **一致预期（EPS）** | 券商研报对未来盈利的汇总预测，是PEG增速的数据来源（通过 anysearch 抓取） |

### B.2 财务三大报表指标类

**资产负债表**

| 术语 | 定义 |
|------|------|
| **总资产** | 企业拥有或控制的全部经济资源总额，反映公司规模（资产负债表左侧） |
| **资产负债率** | 总负债 / 总资产，衡量杠杆水平；<50%较稳健，>70%需警惕偿债风险 |
| **货币资金** | 库存现金、银行存款等变现能力最强的资产，充裕的货币资金是分红与抗风险的基础 |
| **有息负债** | 需支付利息的负债（银行贷款、债券、租赁负债等），与货币资金对比判断财务安全 |
| **应收账款** | 已确认收入尚未收回的货款；应收增速持续高于营收，提示回款放缓与坏账风险 |
| **流动比率 / 速动比率** | 流动资产 / 流动负债（速动比率再剔除存货）；>1.5（速动>1）短期偿债较安全，<1警惕流动性风险 |
| **商誉** | 并购支付对价高于可辨认净资产公允价值的溢价部分；占净资产比重过高时存在减值暴雷风险 |
| **股东权益（净资产）** | 总资产 - 总负债，归股东所有的账面价值，是ROE、PB的计算基础 |

**利润表**

| 术语 | 定义 |
|------|------|
| **营业收入（营收）** | 主营业务销售商品/提供服务取得的收入，是增速、PEG、PSG 分析的起点 |
| **营业成本** | 与营收直接对应的生产成本，营收 - 营业成本 = 毛利（毛利率见B.1） |
| **净利率** | 归母净利润 / 营业收入，反映最终盈利能力，与毛利率之差体现费用与税负 |
| **扣非净利润** | 扣除非经常性损益后的净利润，剔除一次性项目，反映真实可持续经营盈利 |
| **非经常性损益** | 与主业无关的一次性收益/损失（政府补助、资产处置、公允价值变动等），评估盈利质量时须剔除 |
| **研发费用率** | 研发费用 / 营业收入，衡量技术投入强度，是成长股护城河的观察指标 |
| **期间费用率（三费）** | （销售+管理+财务费用）/ 营业收入，反映费用管控能力 |

**现金流量表**

| 术语 | 定义 |
|------|------|
| **经营活动现金流净额（OCF）** | 主营经营活动产生的现金净流入，是盈利含金量与企业"造血"能力的核心指标 |
| **投资活动现金流净额** | 购建资产、对外投资等产生的现金净流，反映资本开支与扩张力度（多为负值） |
| **筹资活动现金流净额** | 融资（借款、发债、增发）与回报股东（分红、回购）产生的现金净流 |

### B.3 现金流类术语

| 术语 | 定义 |
|------|------|
| **自由现金流（FCF）** | 经营现金流净额 - 资本开支，公司可真实支配的现金，用于校验盈利质量与分红能力 |
| **净现比（净利润现金含量）** | 经营现金流净额 / 归母净利润，>1 说明利润有真实现金支撑，盈利含金量高 |
| **收现比（营业收入现金含量）** | 销售商品、提供劳务收到的现金 / 营业收入，>1 说明收入真金白银回收，过低提示赊销占比大 |
| **资本开支（Capex）** | 购建固定资产、无形资产等长期资产支付的现金，是FCF的主要扣减项，反映再投资强度 |
| **折旧与摊销（D&A）** | 固定资产折旧 + 无形资产/长期待摊费用摊销，属非现金费用，加回后更接近真实现金创造能力 |
| **EBITDA** | 息税折旧摊销前利润 = 净利润 + 利息 + 所得税 + 折旧摊销，衡量主营业务现金创造能力，常用于 EV/EBITDA 估值 |
| **净现金** | 货币资金 + 交易性金融资产 - 有息负债，净现金为正表示"账上现金多于欠款"，财务更安全 |
| **现金转换周期（CCC）** | 存货周转天数 + 应收账款周转天数 - 应付账款周转天数，越短说明运营效率越高、占款越少 |
| **自由现金流收益率（FCF Yield）** | 每股自由现金流 / 股价，从现金回报角度衡量投资吸引力 |
| **现金分红覆盖倍数** | 经营现金流净额 / 年度现金分红，衡量分红可持续性（收入投资的核心校验指标） |

### B.4 景气与产业生命周期类

| 术语 | 定义 |
|------|------|
| **产业景气** | 某产业当前需求所处的扩张或收缩状态；景气上行期是1~3年中期投资的核心β来源 |
| **景气周期定位** | 判断产业处于导入期→成长期→成熟期→衰退期的哪个阶段，决定采用进攻还是防御策略 |
| **渗透率** | 产品在目标市场中的普及比例；10%~30%为"黄金区"，接近50%后需考虑兑现 |
| **渗透率黄金区** | 10%~30%渗透率区间，产业加速突破临界点，业绩弹性最大 |
| **ROE拐点** | ROE由降转升或由低转高的转折点，常领先于股价走强（郑希核心工具） |
| **供需缺口弹性** | 需求每增加一定幅度（如+10%）时利润的放大倍数，衡量景气上行期的业绩弹性 |
| **二阶导（加速度）** | 本季度环比增速 - 上季度环比增速，为正表示景气加速、为负表示景气减速 |
| **订单能见度** | 由合同负债、在手订单等预示的未来4个季度业绩可预期性，越高越支持"景气延续"判断 |

### B.5 技术面与动量类

| 术语 | 定义 |
|------|------|
| **SMR** | 同板块相对强度百分位，>70表示跑赢同板块70%的股票，是动量扫描的核心指标 |
| **RSI(50)** | 相对强弱指标（50日参数），>70超买、<30超卖，用于辅助判断短期动能强弱 |
| **MA50 / MA200** | 50日 / 200日均线；股价>MA200视为中期趋势多头，<MA200触发技术面破位止损 |
| **250日涨幅** | 过去一年（约250个交易日）的累计涨幅，动量扫描的基础输入 |
| **动量（Momentum）** | 股价与相对强度的延续性，据此输出"趋势延续/弱化/反转"判断 |
| **技术面破位** | 股价跌破关键均线（如MA200），视为中期趋势反转信号（exit-signal P1级触发） |
| **创新高突破** | 股价突破前期整理平台创阶段新高，是欧奈尔体系的经典买点 |
| **抛售日（Distribution Day）** | 主要指数放量下跌的交易日，连续出现预示大盘见顶风险（欧奈尔体系） |

### B.6 投资策略与风控类

| 术语 | 定义 |
|------|------|
| **β（贝塔）/ α（阿尔法）** | 相对市场的系统性收益 / 超额收益；本框架中"产业景气是β，个股质量是α" |
| **GARP策略** | 合理价格成长投资（Growth at a Reasonable Price），要求PEG<1，是林奇中期框架的核心 |
| **CANSLIM** | 欧奈尔成长股七要素选股体系：当季盈利、年度盈利、新产品/新高、供需、领导股、机构认同、大盘方向 |
| **戴维斯双击** | 盈利增长与估值提升同时发生带来的股价倍增效应，是"景气上行+估值修复"的投资盈利机制 |
| **安全边际** | 买入价相对内在价值的缓冲空间；低估程度越高、确定性越强时安全边际越大 |
| **护城河** | 企业抵御竞争、长期维持超额利润的壁垒（品牌、成本、网络效应、转换成本、特许经营权等） |
| **时间止损** | 持有满4个季度（1年）后，若买入逻辑未兑现则触发替换建议 |
| **止损（8%硬止损）** | 欧奈尔规则：股价较买入价下跌8%无条件卖出，属P0级最高优先级 |
| **底仓/机动仓** | 底仓（60%~80%）长持赚成长钱；机动仓（20%~40%）做估值波段 |
| **集中度约束** | 单只持仓≤15%、单行业≤40%的组合风控红线（portfolio-review --mode mid 检查项） |

### B.7 本系统特有术语

| 术语 | 定义 |
|------|------|
| **四档评级** | 估值温度计（valuation-thermometer）输出的低估/合理/高估/严重透支四个等级 |
| **四级优先级** | exit-signal 的 P0~P4 检查顺序（止损/破位/时间/透支/漂移），高优先级触发即停止后续检查 |
| **`mid-` 前缀** | 中期技能文件的标识符，与长期技能同级存放于 `.trae/skills/` 根目录 |
