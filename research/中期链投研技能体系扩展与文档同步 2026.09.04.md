## 3. 详细变更分析

### 3.1 🆕 组件 A：新增 `mid-bottleneck-hunter`（供应链瓶颈猎手中期版）

- **位置**: `.trae/skills/mid-bottleneck-hunter/{SKILL.md, README.md}`
- **定位**: 中期链（1-3 年）入口技能；与长期 `bottleneck-hunter`（10 年）**物理隔离、功能互补**。
- **关键差异（vs 长期版）**:

| 维度     | 长期版（10年）                     | 中期版（1~3年，本新增）                                     | 类型 |
| :------- | :--------------------------------- | :---------------------------------------------------------- | :--- |
| 估值体系 | PS/PE + 10年 25x PE 退出           | **PEG 五档（引用 `valuation-thermometer`）+ 3 年隐含回报**  | 替换 |
| 景气度   | 无                                 | 渗透率/ROE 趋势/二阶导/订单能见度四维                       | 新增 |
| 业绩兑现 | 无                                 | 近 2 季收入增速 > 行业平均（BN-3）                          | 新增 |
| 地缘政治 | 简单检查                           | **六维度 + 华为式抗封锁韧性**                               | 强化 |
| 卖出纪律 | 无                                 | 引用 `exit-signal` P0~P5（时间止损并入 P2）                 | 新增 |
| 仓位管理 | 无                                 | 底仓 60%~80% / 机动仓 20%~40%；单只 ≤10/15/20%；单行业 ≤40% | 新增 |
| 报告路径 | `reports/bottleneck-map/{趋势名}/` | **`reports/mid-bottleneck/{趋势名}/`**                      | 替换 |
| 风控编号 | 无                                 | **BN-1~BN-10**（避开 F-/R-/MC- 前缀）                       | 新增 |
| 扫描节奏 | 含每小时扫描                       | 季度/月度增量更新                                           | 移除 |

- **七步流程** (SKILL.md): 趋势确认 → 物理拆解 → 瓶颈识别+景气度叠加 → 公司筛选+地缘六维 → 估值检查 → 交叉验证 → 输出看板
- **来源**: `research/early-version/bottleneck-hunter技能文件（草稿）.md` + `research/mid-bottleneck-hunter 开发方案与详细实施计划.md` (Phase 1~4 已落地)
