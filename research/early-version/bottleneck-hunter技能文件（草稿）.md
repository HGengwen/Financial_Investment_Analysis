# 修改分析：`bottleneck-hunter` 与 1~3 年景气投资框架的匹配度（草稿）

## 一、兼容性诊断

```
bottleneck-hunter 是一个供应链瓶颈扫描工具，其核心方法论与1~3年景气投资框架高度兼容，但存在以下需要补充和调整的维度：
```

| 维度 | 原版（通用版） | 1~3 年景气投资要求 | 兼容性 |
| --- | --- | --- | --- |

| **Layer拆解框架** | 从终端拆到基础设施 | 与景气投资的产业链分析完全一致 | ✅ 高度兼容 |

### 第三步：瓶颈识别——寻找"咽喉"

#### 3.1 瓶颈判定6条标准

```
对Layer 2-3的每个环节，逐条评估：
```

| # | 标准 | 问题 | 得分 |
| --- | --- | --- | --- |
| 1 | **供给集中度** | 全球供应商≤3家？ | 🔴 ≤2家 / 🟡 3-5家 / 🟢 >5家 |
| 2 | **扩产周期** | 新增产能需要多久？ | 🔴 >2年 / 🟡 1-2年 / 🟢 <1年 |
| 3 | **替代难度** | 能否用其他技术/材料替代？ | 🔴 不可替代 / 🟡 部分可替代 / 🟢 易替代 |
| 4 | **产能利用率** | 当前产能利用率？ | 🔴 >90% / 🟡 70-90% / 🟢 <70% |
| 5 | **需求增速** | 下游需求增速？ | 🔴 >50%/年 / 🟡 20-50% / 🟢 <20% |
| 6 | **客户验证周期** | 新供应商进入需要多久验证？ | 🔴 >1年 / 🟡 6-12月 / 🟢 <6月 |

```
瓶颈评级：
```

-   ```
    🔴🔴🔴 ≥4个 → S级瓶颈（单点故障级，最高优先级）
    ```
    
-   ```
    🔴🔴 3个 → A级瓶颈（严重受限）
    ```
    
-   ```
    🔴 1-2个 → B级瓶颈（有压力但可控）
    ```
    
-   ```
    无🔴 → 非瓶颈，跳过
    ```
    

#### 3.2 瓶颈景气度叠加判断（新增）

```
瓶颈评级 ≠ 投资时机。 必须叠加景气度判断：
```

| 景气维度 | 问题 | 判断 |
| --- | --- | --- |
| **渗透率位置** | 该瓶颈所在产业处于渗透率什么位置？ | 10~30%黄金区 → 加分 / >50%减速区 → 减分 |
| **ROE趋势** | 该环节头部企业的ROE在向上还是向下？ | 向上 → 加分 / 拐头向下 → 警惕信号 |
| **二阶导** | 需求增速在加快还是放缓？ | 正二阶导 → 加分 / 负二阶导 → 减分 |
| **订单能见度** | 头部企业订单排期到多久？ | \>6个月 → 加分 / <3个月 → 减分 |

```

### 第四步：公司筛选——从瓶颈到标的

#### 4.1 初筛标准（快速过滤）

| 标准 | 要求 | 理由 | 1~3年框架特别关注 |
| --- | --- | --- | --- |
| 上市状态 | 已上市（A/港/美/日/台/欧） | 可交易 | — |
| 瓶颈业务占比 | \>30%收入来自瓶颈环节 | 纯正度 | — |
| 市值 | 优先<100亿美元 | 大市值已被充分定价 | — |
| 流动性 | 日均成交额>100万美元 | 可进出 | — |
| **业绩兑现** | **最近2季度收入增速>行业平均** | **避免纯概念** | **必须检查** |

> ```
> 💬 李进式提醒："'瓶颈'概念必须有订单、收入、利润支撑——营收翻倍但扣非利润为负，是题材而非瓶颈。"
> ```

#### 4.2 估值检查（必须执行，不可跳过）

```
瓶颈真实 ≠ 投资机会。 必须对每家公司计算 PS、PE、PEG 并标注在报告中。
```

##### PEG五档估值体系（林奇核心估值工具）

| 档位 | PEG范围 | 含义 | 操作建议 |
| --- | --- | --- | --- |
| **显著低估** | < 0.8 | 市场过度悲观，增速未被充分定价 | **绝佳买点**，可建底仓 |
| **合理** | 0.8 ~ 1.2 | 估值与增速匹配 | **可建仓**，分批买入 |
| **偏贵** | 1.2 ~ 1.5 | 估值略高，但增速可消化 | **谨慎参与**，仅建机动仓 |
| **高估** | 1.5 ~ 2.0 | 估值透支未来增长 | **减持机动仓**，不动底仓 |
| **严重透支** | \> 2.0 | 价格远超内在价值 | **加速清仓机动仓**，绝不追高 |

##### 估值红灯（满足任意一条 → 信号强度封顶 ★★，标注"⚠️ 估值透支"）

1.  ```
    市值 > TAM的20%：公司市值已超过其可触达市场规模的20%
    ```
    
2.  ```
    PS > 30x 且 收入增速 < 100%：高估值但增速不足。增速>100%可豁免PS红线
    ```
    
3.  ```
    市值 > 5年乐观收入预测的10倍：即使最乐观假设全部兑现，定价仍然过高
    ```
    
4.  ```
    增发后60天内股价翻倍：情绪驱动特征明显
    ```
    
5.  ```
    PEG > 2.0（严重透支）：当前PE已是未来2年预期增速的2倍以上
    ```
    

##### 估值黄灯（需要额外解释）

1.  ```
    亏损 + PS > 15x：必须说明盈利路径和时间表
    ```
    
2.  ```
    PS 是同行盈利公司的 5 倍以上：必须解释溢价来源
    ```
    
3.  ```
    PE > 80x：需要计算 PEG 并说明增速是否支撑
    ```
    
4.  ```
    PEG 1.5~2.0（高估）：估值偏高但增速可覆盖
    ```
    

##### 估值绿灯（加分项）

-   ```
    PS < 10x 且收入在增长 → 信号强度可加一级
    ```
    
-   ```
    PE < 30x 且有护城河 → 标注"估值具有安全边际"
    ```
    
-   ```
    PEG < 0.8（显著低估）→ 标注"林奇式绝佳买点"
    ```
    
-   ```
    PEG 0.8~1.2（合理）→ 标注"合理估值区间"
    ```
    

##### 估值合理性检验（必做）

```
回答："以当前市值买入，假设最乐观情景全部兑现，10年后以25x PE退出，年化回报是多少？"
年化回报<10%→标注"当前价格不具备安全边际"。
```

> ```
> 💬 林奇式追问："这家公司的PEG是多少？如果PEG>2，即使增速很快，当前价格也不是好买点。记住：PEG<1才是真正低估的信号。"
> ```

    ```

    ```
