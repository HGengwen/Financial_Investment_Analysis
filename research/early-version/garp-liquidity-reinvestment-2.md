# 修改分析：`income-investment` 与 1~3 年景气投资框架的匹配度（草稿）

## 一、兼容性诊断

`income-investment` 是一个**收入/分红型投资分析技能**——评估公司是否能够产生足够持久且有吸引力的可分配收入，判断其适合长期收入核心持仓还是机会型收益仓位。它与1~3年景气投资框架的**冲突程度最高**，原因如下：

| 维度 | 原版（长期收入投资） | 1~3 年景气投资要求 | 冲突程度 |
|------|---------------------|---------------------|----------|
| **核心目标** | 寻找持久、可持续的分红收入 | **寻找PEG<1的快速增长型公司**——分红不是核心目标 | ❌ **根本冲突** |
| **适用对象** | 成熟企业、REITs、公用事业、高分红股 | **快速增长型公司**（增速>20%），通常分红率低或不分红 | ❌ **根本冲突** |
| **估值工具** | 股息率、FCF收益率、DDM | **PEG为核心**，关注估值与增速的匹配 | ❌ **核心冲突** |
| **卖出逻辑** | 分红削减、股息率下降 | **P0~P6六级触发体系**——止损失效、景气拐点、估值透支 | ❌ **核心冲突** |
| **持有周期** | "长期持有"——收息为主，复利增长 | **1~3年景气持有**——景气下行即退出 | ❌ **核心冲突** |
| **质量评估** | 分红覆盖率、资产负债表强度 | **ROE趋势、二阶导、渗透率、管理层+科研转化** | ⚠️ 部分兼容 |
| **三情景** | 分红削减情景 | **景气情景**——乐观/中性/悲观增速 | ⚠️ 部分兼容 |
| **四位大师** | 未指定（通用收入投资框架） | **欧奈尔/林奇/郑希/李进** | ❌ 需指定 |

## 二、核心判断

`income-investment` **完全不适用于1~3年景气投资框架**，原因不在于"分红投资不好"，而在于：

1. **目标根本不同**：收入投资追求的是"稳定分红"，而1~3年景气投资追求的是"快速增长公司的估值与业绩双击"——一个收息，一个赚资本利得，两者投资逻辑本质对立。

2. **适用对象不同**：收入投资的理想标的（公用事业、REITs、成熟消费品）通常是**缓慢增长型或稳定增长型**，而1~3年景气投资的理想标的是**快速增长型**（增速>20%）。

3. **估值工具不同**：收入投资用股息率、FCF收益率、DDM；景气投资用**PEG**。

4. **林奇的六类分类法**：林奇明确指出——不同类型的股票适用不同的估值方法。"快速增长型"不适合用股息率估值，它们应该把利润再投资于增长而非分红。

**但是**，`income-investment` 的**部分分析模块**（现金流覆盖、资产负债表健康度、估值安全边际、三情景分析）对景气投资仍有参考价值——可以作为"流动性质量与再投资能力"的验证工具。

**修改方案**：
1. **完全重写核心定位**——从"收入投资分析"变为"流动性质量与再投资能力验证"
2. **修改适用对象**——聚焦快速增长型公司的现金流质量与再投资能力
3. **替换估值框架**——以PEG为核心，股息率降级为次要参考
4. **修改判决分类**——从"核心收入/机会型收入"变为"高质量流动性/中等质量/低质量流动性"
5. **融入四位景气大师框架**——欧奈尔（纪律）、林奇（PEG+六类）、郑希（ROE+景气）、李进（管理层+科研转化）

# 流动性质量与再投资能力验证（1~3 年景气投资版）

对 $ARGUMENTS 进行系统化流动性质量与再投资能力分析。

> 💬 **核心理念**：在1~3年景气投资框架中，**分红不是核心目标**——快速增长型公司应该把利润再投资于增长，而非分红。本技能的核心问题是：**这家公司自由现金流的质量如何？管理层在高效地再投资吗？资本配置纪律是否严格？**
>
> **彼得·林奇式提醒**："快速增长型公司（增速>20%）通常不分红或分红率很低——这恰恰是好事，说明它们有足够的高回报再投资机会。如果你用股息率去筛选快速增长型公司，你会错过几乎所有伟大的成长股。"

## 设计理念

在1~3年景气投资框架中，**流动性质量与再投资能力**是验证成长可持续性的关键维度：

1. **自由现金流质量**：赚的是真钱还是账面利润？（郑希关注的"ROE向上"需要现金流支撑）
2. **再投资效率**：新增资本的回报率是否高于存量资本？（李进关注的"增量资本回报率 > 存量ROIC"）
3. **资本配置纪律**：管理层是否在高效配置资本？（李进管理层评估的核心维度）
4. **资产负债表强度**：是否有足够的财务弹性支撑增长？

本技能与以下工作流的关系：

- `investment-research`（景气版）：全面公司研究 → 本技能提供**流动性质量的专项验证**
- `investment-team`（景气版）：四Agent全面研究 → 本技能为财务/流动性维度的补充
- `portfolio-review`：组合管理 → 本技能提供**单只标的的流动性风险敞口评估**

**本技能不是**：分红选股工具、股息率筛选器、收入型投资决策工具。本技能是**景气投资中"现金流质量"维度的专项验证工具**。

---

## 研究纪律

1. 研究前运行 `date` 确认当天日期，在报告头部注明数据截止日期。
2. 优先使用年报、中期报告、业绩发布、投资者文档、监管文件、官方公告和交易所数据，其次用二手来源填补空白并标注为二手。
3. 遵循 `financial-data` 技能规范：关键财务数据至少两个独立来源验证，误差>1%须标记。
4. 每个时效性数据标注日期或期间。将每项重要陈述区分为**已验证事实**、**估计**、**假设**或**分析判断**。
5. 使用 `tools/common/financial_rigor.py` 进行精确的自由现金流、再投资回报率、估值、市值和流动性指标计算。**禁止 LLM 心算决策敏感数据**。
6. 跨币种（港股/美股）收入折算时，先用 `python tools/common/fx_rate.py --code HKDCNY`（或 `USDCNY`）获取实时汇率，勿用固定汇率。
7. 报告保存后，运行 `tools/common/report_audit.py extract` 和 `verdict` 审核流程。未通过审核的报告是草稿，不是可发布的研究。
8. **本技能不替代分红/收入投资分析**——如需专门的收入型投资决策，请使用原版 `income-investment` 技能（长期投资版）。

## 执行流程

### 第一步：确认标的适用性（林奇六类分类）

**在开始分析前，必须确认标的属于快速增长型（或至少是有再投资需求的成长型）公司。**

使用林奇六类分类法：

| 类型 | 特征 | 是否适用本技能 |
|------|------|---------------|
| **快速增长型** | 增速>20%，有大量再投资需求 | ✅ **最适用** |
| **稳定增长型** | 增速10-20%，部分再投资+部分分红 | ✅ 适用 |
| **周期型** | 增速随周期波动 | ⚠️ 谨慎适用（需区分周期位置） |
| **困境反转型** | 暂未盈利或增速为负 | ⚠️ 不适用（现金流不可预测） |
| **隐蔽资产型** | 资产价值被低估 | ❌ 不适用 |
| **缓慢增长型** | 增速<10%，主要靠分红 | ❌ **不适用**（请使用原版收入投资技能） |

如果标的属于缓慢增长型或主要靠分红驱动，**本技能不适用**——建议用户使用原版 `income-investment` 技能。

> 💬 **林奇式提醒**："如果你在用股息率筛选快速增长型公司，你很可能错过了它。快速增长型公司的核心价值在于利润再投资——如果它们把赚的钱都分掉了，增长从哪里来？"

### 第二步：数据收集与质量确立

#### 2.1 核心数据获取（流动性质量专用）

| 数据类型 | 来源 | 景气投资关注重点 |

| FCF/净利润比率 | 计算 | >100%为佳（利润质量高） |
| 资本开支结构 | 财报附注 | 维护性 vs 扩张性 |
| 营运资本变化 | 资产负债表 | 应收账款/存货周转趋势 |
| 再投资回报率（ROIC） | 计算 | 税后经营利润 / 投入资本 |
| 增量资本回报率 | 计算 | 新增资本产生的边际回报 |

### 第三步：自由现金流质量分析（郑希+巴菲特视角）

> 💬 **郑希式提醒**："ROE向上是科技股最可靠的'重力加速度'。但ROE向上必须以真实的现金流为基础——如果净利润增长但经营现金流在萎缩，ROE'向上'是虚假的。"

#### 3.1 利润质量检验

| 指标 | 公式 | 健康标准 | 警惕信号 |
|------|------|---------|----------|
| **FCF/净利润比率** | 自由现金流 ÷ 净利润 | >100%为佳 | <80%需警惕 |
| **经营现金流/净利润** | 经营现金流 ÷ 净利润 | >100%为佳 | 持续<100%且差距扩大 |
| **应收账款周转天数** | 应收账款 ÷ 日均收入 | 稳定或下降 | 上升且快于收入增速 |
| **存货周转天数** | 存货 ÷ 日均成本 | 稳定或下降 | 上升且快于收入增速 |

**历史趋势分析**（至少4个季度）：

| 季度 | Q-4 | Q-3 | Q-2 | Q-1 | 本期 | 趋势 |
|------|-----|-----|-----|-----|------|------|
| 经营现金流 | | | | | | |
| 自由现金流 | | | | | | |
| FCF/净利润 | | | | | | |

**关键判断**：
- FCF/净利润趋势：↑/→/↓
- 如果FCF/净利润 < 80%且持续下降 → 利润质量存疑（黄灯）
- 如果FCF/净利润 < 50%且无合理解释 → 利润质量严重存疑（红灯）

#### 3.2 资本开支结构分析

| 维度 | 本期 | 上期 | 变化 | 解读 |
|------|------|------|------|------|
| 总资本开支 | | | | |
| 维护性资本开支 | | | | 维持现有业务所需 |
| 扩张性资本开支 | | | | 新业务/产能扩张 |
| 扩张性资本开支占比 | | | | >60%为成长型特征 |

**判断标准**：
- 扩张性资本开支占比高 + ROIC>WACC → **良性扩张**（创造价值）
- 扩张性资本开支占比高 + ROIC<WACC → **毁灭式扩张**（李进"一票否决"）
- 扩张性资本开支占比低 + 增速快 → **轻资产模式优势**

### 第四步：再投资效率分析（李进视角）

> 💬 **李进式提醒**："新增资本是否带来同等或更高的利润增长？增量资本回报率 > 存量ROIC，说明扩张在创造价值——这是再投资效率最好的检验标准。"

#### 4.1 ROIC（投入资本回报率）

**ROIC = 税后营业净利润 ÷（总资产 - 现金 - 无息负债）**

| 判断标准 | 评级 |
|---------|------|
| ROIC > 15% | 优秀 |
| ROIC > WACC且≥10% | 合格 |
| ROIC < 5%且仍在扩产 | 🔴 **一票否决** |

#### 4.2 增量资本回报率

**增量资本回报率 = 新增税后营业利润 ÷ 新增投入资本**

| 对比 | 判断 |
|------|------|
| 增量回报率 > 存量ROIC | **扩张在创造价值**（加分） |
| 增量回报率 ≈ 存量ROIC | 扩张在维持效率（中性） |
| 增量回报率 < 存量ROIC | 扩张在稀释效率（减分） |

#### 4.3 再投资充分性

**核心问题**：公司产生的自由现金流是否足以支撑其增长计划？

| 情景 | 判断 |
|------|------|
| FCF > 再投资需求 | 自主融资能力强（高质量流动性） |
| FCF ≈ 再投资需求 | 刚好覆盖（需监控） |
| FCF < 再投资需求 | 需要外部融资（警惕股权稀释或债务风险） |

**外部融资检查**：
- 近3年股本稀释率：____%
- 有息负债变化：↑/→/↓
- 再融资需求：____亿（12个月内）

### 第六步：资产负债强度与财务弹性

#### 6.1 资产负债表健康度

| 指标 | 数值 | 判断 |
|------|------|------|
| 净现金/净负债 | | 现金+短期投资 - 有息负债 |
| 有息负债/EBITDA | | <3x健康，>5x警惕 |
| 利息覆盖率 | EBIT ÷ 利息费用 | >5x健康，<3x警惕 |
| 流动性比率 | 流动资产/流动负债 | >1.5健康 |

#### 6.2 财务弹性评估

- 在手现金能支撑____个月的运营（不考虑收入）
- 信用额度/可动用的银行授信：____亿
- 股票增发/可转债通道：是否已利用？剩余额度？

### 第八步：综合判决

#### 判决分类

| 判决 | 定义 | 操作建议 |
|------|------|----------|
| **高质量流动性** | FCF质量高、再投资效率高、财务弹性强 | 可安全持有，景气逻辑强化 |
| **中等质量流动性** | FCF质量一般、再投资效率中等、财务弹性可接受 | 持有但需密切监控流动性指标 |
| **低质量流动性** | FCF/净利润<50%、增量ROIC<存量ROIC、财务弹性弱 | **减仓或回避**——景气逻辑可能脆弱 |
| **数据不足** | 无法获取足够的流动性数据 | 标注缺口，降低置信度 |

#### 判决门控

| 阻断门控 | 触发条件 | 操作 |
|---------|---------|------|
| FCF/净利润 < 50% 且连续2年恶化 | 利润质量严重存疑 | 判决≤中等质量流动性 |
| 增量ROIC < 存量ROIC 且持续2年 | 扩张在毁灭价值 | 判决≤中等质量流动性 |
| 有息负债/EBITDA > 5x | 债务风险过高 | 判决≤中等质量流动性 |
| 管理层诚信问题（李进维度A） | 一票否决 | **立即回避** |

### 第九步：输出报告

## 工具使用指南

同原版 `income-investment` 的工具使用指南（详见上方），包括：

- 本地数据获取工具：A股/港股/美股
- 精确计算工具：`financial_rigor.py` 验证PEG、FCF收益率等
- 网络搜索工具：禁止使用 Anthropic WebSearch/WebFetch，统一使用本地五工具组合
- 报告审核工具：`report_audit.py`

**⚠️ 本技能特有的工具使用注意**：
- **FCF计算必须精确**：经营现金流 - 资本开支，注意资本开支口径（维护性 vs 扩张性）
- **ROIC计算必须精确**：税后营业净利润 /（总资产 - 现金 - 无息负债）
- **增量资本回报率必须精确**：新增利润 ÷ 新增投入资本
- **跨币种折算必须用 `fx_rate.py` 获取实时汇率**，禁用固定汇率
- **PEG计算必须精确**：PE(TTM) ÷ 未来2年预期利润增速


## 注意事项

1. **本技能不替代分红投资分析**：如需专门的收入型投资决策，请使用原版 `income-investment` 技能（长期投资版）
2. **快速增长型公司不分红是正常的**：不要因为分红率低而扣分
3. **FCF质量是核心**：赚真钱比赚账面利润重要得多
4. **再投资效率比FCF绝对值更重要**：即使FCF为负，如果增量回报率极高，也可能是好的投资
5. **数据验证**：关键数据必须至少来自两个独立来源
6. **客观分析**：严格区分"事实"与"观点"
7. **呈现两面**：每个核心判断都必须附带反面论据
8. **网络搜索时效性**：使用 `--time-range month/week` 限制时间范围
9. **非境内上市双源验证**：港股/美股须按市场双源验证


## 局限性

1. **资料可得性**：部分公司的完整财报原文可能难以获取
2. **FCF口径差异**：不同来源对资本开支的定义可能不同
3. **增量回报率计算依赖准确的分部数据**：部分公司不披露分部资本开支
4. **AI解读局限**：AI无法完全替代专业财务分析师的深度分析能力
5. **不构成投资建议**：本技能仅用于学习与研究
