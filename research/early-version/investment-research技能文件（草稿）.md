# 修改分析：`investment-research` 与 1~3 年景气投资框架的匹配度（草稿版V0.0.1）

## 一、兼容性诊断

`investment-research` 的核心问题与 `investment-checklist` 相同——它基于 **巴菲特、芒格、段永平、李录** 四位长期价值投资大师的框架，而附件1的1~3年景气投资框架基于 **欧奈尔、林奇、郑希、李进**。两者在以下维度存在**结构性错配**：

| 维度 | 原版（巴芒段李长期版） | 1~3 年景气投资要求 | 冲突程度 |
|------|----------------------|---------------------|----------|
| **四大师阵容** | 巴菲特（10年护城河）、芒格（逆向风险）、段永平（生意本质）、李录（文明级20年） | 欧奈尔（止损纪律）、林奇（常识选股）、郑希（产业景气ROE拐点）、李进（渗透率与二阶导） | ❌ **核心冲突** |
| **护城河评估** | 10年后是否还在 | 1~3年内是否被侵蚀，是否支撑景气上行 | ⚠️ 部分冲突 |
| **估值核心** | DCF绝对估值，内在价值折价 | PEG相对估值 + 分批建仓规则 | ⚠️ 部分冲突 |
| **行业趋势分析** | 文明级范式转移（10~20年） | 1~3年产业景气周期（渗透率、二阶导） | ⚠️ 部分冲突 |
| **管理层评估** | 诚信+资本配置+长期主义 | 诚信+资本配置+**科研转化+承诺兑现率** | ⚠️ 部分缺失 |
| **风险与卖出** | 长期持有的风险（护城河侵蚀、管理层变质） | **硬止损、逻辑止损、景气拐点、时间止损**多维度卖出 | ❌ 缺失 |
| **买入决策** | 内在价值折价买入 | PEG合理区间 + 分批建仓 + 欧奈尔止损 | ❌ 缺失 |
| **地缘政治** | 无 | **海外收入依赖/供应链安全/制裁清单/本地化对冲/备胎计划** | ❌ 缺失 |
| **渗透率分析** | 无 | **渗透率定位（15%临界/50%减速）+ 二阶导监测** | ❌ 缺失 |
| **科研转化** | 无 | **研发质与量/产出效率/资本回报效率 20分制** | ❌ 缺失 |

## 二、结论

**原版 `investment-research` 不适用于1~3年景气投资研究**，核心障碍在于：

1. **四大师视角完全不匹配**——原版巴芒段李 vs 需要的欧奈尔/林奇/郑希/李进
2. **缺少卖出纪律**——1~3年框架的核心是"动态持有+纪律退出"，原版是"买入并持有"
3. **估值方法不同**——PEG+分批建仓 vs DCF折价
4. **缺少产业景气与渗透率分析**——这是1~3年投资的核心驱动
5. **缺少地缘政治和科研转化评估**
6. **缺少管理层4维度20分制评分体系**

**修改方案**：将原版"巴芒段李长期深度研究框架"完全重构为"四位景气大师深度研究框架"，保持八步研究结构（数据收集→生意分析→护城河→逆向风险→产业景气→管理层→估值→综合决策），但每一步的**核心思想、分析工具、输出内容**全部对齐附件1的四位大师体系。

修改后的框架依然保持系统化、结构化的研究流程，但内在逻辑从"买入并永远持有"切换为"1~3年景气持有+纪律退出"。

## 设计理念

本Skill是1~3年景气投资研究的**核心框架**，整合四位景气投资大师的方法论：

- **欧奈尔**：趋势信号、8%止损底线、抛售日减仓、机构持仓跟踪
- **林奇**：生活常识选股、六类股票分类、PEG估值、逆向情绪管理
- **郑希**：ROE拐点判断、全球产业链景气传导、季度景气数据验证
- **李进**：渗透率定位（15%临界/50%减速）、二阶导监测、系统均衡配置

**哲学根基**：**景气驱动，动态持有，纪律退出**——买入不是终点，每季度的景气数据验证才是持有或卖出的依据。好公司不等于好投资，买贵了会亏钱，景气拐了要离场。

适用于深度研究单家公司，产出完整1~3年投资研究报告。

## 研究框架

基于欧奈尔、林奇、郑希、李进四位景气投资大师的方法论，按以下八个模块顺序执行研究：

### 前置步骤：AI研究偏见预警（必须执行）

在开始研究前，评估该公司的"可研究性"，识别潜在数据偏见：

**信息丰富度评级**：

| 等级 | 特征 | AI研究陷阱 | 应对策略 |
|------|------|-----------|----------|
| A级（信息充裕） | 上市多年、券商覆盖多、媒体报道密集 | 共识过强，AI输出趋同于市场定价 | 重点做反面检验：景气是否被充分定价？哪些风险被忽略？ |
| B级（信息适中） | 上市1-3年、覆盖有限、部分数据需推算 | AI可能用"合理推测"填补空白，产生虚假确定性 | 每个推算数据标注置信度，区分"有据推算"和"凭空填充" |
| C级（信息稀缺） | 刚上市/冷门股/新兴市场、几乎无覆盖 | AI会因资料不足而过度保守，误判为"看不清=不好" | 用第一性原理提问（见下方），从有限信息中提取核心商业逻辑 |

**C级公司的第一性原理研究法**（林奇式追问）：

当公开资料不足时，聚焦以下底层问题：
1. 客户是谁？为什么付钱？有没有替代选择？（林奇的"生活常识"）
2. 复购靠什么驱动？是习惯、锁定、还是持续创造新价值？（林奇的"客户黏性"）
3. 竞争对手拿100亿能复制这门生意吗？（郑希的"ROE护城河"）
4. 管理层做过什么关键决策？这些决策反映什么判断力和价值观？（李进的"治理评估"）
5. 这个产业未来1~3年的核心驱动力是什么？（渗透率、技术迭代、政策支持）

**偏见自查清单**（研究全程保持警惕）：
- [ ] 我的"确定性"感受来自生意本质，还是来自资料数量？
- [ ] 如果把这家公司的资料量减少一半，我的结论会变吗？
- [ ] AI输出的分析是否与市场共识高度雷同？如果是，我的信息优势在哪？
- [ ] 是否存在"公开资料很少但生意本质极好"的可能性被低估了？
- [ ] 我正在把"数据不足"等同于"风险过高"吗？（对C级公司尤其重要）

将信息丰富度评级结果写入报告开头，并在最终结论中注明"AI分析置信度"与"投资确定性"的区别。

### 第一步：数据收集（景气投资版）

> **数据源规范**：参见 `financial-data` 技能。所有财务数据必须来自两个独立来源，误差>1%须标记。
> - A股：使用 `tools/a_share/stock_financial.py`（主）+ 巨潮资讯年报（副）
> - 港股：使用 `tools/hk_stock/stock_financial.py`（主）+ aastocks（副）
> - 美股：使用 `tools/us_stock/stock_financial.py`（主）+ Yahoo Finance/SEC EDGAR（副）

使用 Task 工具启动后台 Agent，从网络收集以下**1~3年景气投资特别关注**的数据：

1. **收入结构**：最近财年及近4季度分部收入、增速、毛利率
2. **财务指标**：近5年收入、净利润、ROE（趋势是关键）、毛利率、经营利润率、自由现金流、现金储备
3. **景气数据**：近8个季度营收增速趋势（加速还是减速？）、扣非净利润增速、订单增速、产能利用率
4. **产业渗透率**：当前行业渗透率（估计值）、变化趋势、未来12个月预期位置
5. **竞争格局**：市场份额、主要竞争对手对比、CR3变化趋势
6. **护城河证据**：1~3年内能守住的核心竞争优势来源
7. **科研转化**（科技/医药）：研发费用率、研发资本化率、新产品收入占比、在研关键项目进展
8. **管理层**：创始人/CEO履历、持股比例、关键决策记录、历史承诺兑现率
9. **地缘政治**：海外收入占比、供应链关键环节依赖度、制裁/关税风险敞口、本地化布局进展
10. **当前估值**：市值、PE、前瞻PE、PEG（当前PE/未来2年预期增速）、PB、FCF Yield
11. **多空双方核心论点**

#### 数据交叉验证（必须执行，使用金融严谨性工具）

数据收集完成后，**必须调用 `tools/common/financial_rigor.py` 对关键数据进行程序化验证**，杜绝LLM心算误差。

**必须验证的数据点**：
- 总股本（从交易所、Yahoo Finance、StockAnalysis 等至少2个源确认）
- 当前股价和市值（**手动计算 股价×总股本 并与报告市值对比，防止单位错误**）
- 最近财年收入和净利润（从公司年报+至少1个第三方源确认）
- ROE（最近3年趋势，用工具验证）
- PEG（当前PE/未来2年预期增速，必须精确计算）

**强制验证步骤（使用Bash调用工具）**：

Step 1 — 市值验算（精确十进制，非浮点）：
```bash
python tools/common/financial_rigor.py verify-market-cap \
  --price {股价} --shares {总股本} --reported {报告市值} --currency {币种}
```

Step 2 — 估值指标精确验算（PEG为核心）：
```bash
python tools/common/financial_rigor.py verify-valuation \
  --price {股价} --eps {EPS} --bvps {每股净资产} --fcf-per-share {每股FCF} --dividend {每股股息}
```
对PEG，需手动填入：PEG = PE(TTM) ÷ 未来2年预期利润增速（%）。

Step 3 — 三情景估值（PEG+远期PE情景分析）：
```bash
python tools/common/financial_rigor.py three-scenario \
  --price {股价} --eps {EPS} --shares {总股本亿} \
  --growth {乐观增速} {中性增速} {悲观增速} \
  --pe {乐观PE} {中性PE} {悲观PE} --years 3 --currency {币种}
```

**验证规则**：
1. 每个关键数据点至少2个独立来源
2. 发现来源间有差异时，优先采用公司年报/交易所数据
3. **所有涉及计算的数据必须通过工具验算，禁止LLM心算**
4. 工具输出结果直接嵌入报告附录"关键数据交叉验证记录"

### 第二步：生意本质与产业定位 — 林奇"常识验证" + 李进"渗透率刻度"

**核心问题**：这门生意我看得懂吗？它处在产业周期的什么位置？

分析要点：
- 用一句话定义这门生意的本质——林奇式："如果10分钟讲不清楚，业务太复杂"
- **林奇六类股票分类**（必须明确归类）：
  - 缓慢增长型 → 看股息率，卖出逻辑：股息率下降
  - 稳定增长型 → 看PE区间，卖出逻辑：PE过高
  - **快速增长型** → 核心关注类别，看PEG，卖出逻辑：增速放缓
  - 周期型 → 看行业供需拐点，卖出逻辑：景气顶峰
  - 困境反转型 → 看反转证据，卖出逻辑：复苏不及预期
  - 隐蔽资产型 → 看资产重估，卖出逻辑：资产价值兑现
- **收入结构拆解**：钱从哪来？哪些业务在增长？哪些在萎缩？
- **5年盈利能力趋势**：毛利率、净利率、ROE——是向上走还是向下走？
- **商业模式画布**：一次性销售 vs 订阅/复购？硬件 vs 软件 vs 平台？生态锁定强度？
- **渗透率定位**（李进核心）：
  - 当前渗透率在什么位置？（<5%过早 / 10%~30%黄金区 / >50%警戒区）
  - 距离15%加速临界点还有多远？距离50%减速区间还有多远？
  - 渗透率变化速度（一年能提升多少百分点）？
- **生活常识验证**（林奇核心）：
  - 你或身边人在使用这家公司的产品吗？
  - 产品力如何？是否愿意向朋友推荐？
  - 竞争对手的产品体验如何？

**林奇式追问**：这家公司属于六类中的哪一类？不同类型的卖出逻辑完全不同——你清楚这只股票的"类型标签"吗？

**李进式追问**：渗透率在什么位置？如果渗透率<10%，产业还有不确定性；如果>50%，增速可能已经放缓。当前是否处于15%~50%的黄金加速区间？

### 第三步：护城河评估（1~3年景气视角）— 郑希"ROE护城河" + 欧奈尔"趋势信号"

**核心问题**：1~3年内，这家公司的竞争优势能守住吗？ROE是向上走还是向下走？

逐一验证五类护城河，**但不问"10年后是否还在"，而是问"1~3年内能否支撑景气上行"**：

| 护城河类型 | 1~3年验证方法 |
|-----------|-------------|
| 品牌/定价权 | 过去1年是否提价？提价后销量变化？竞品能否跟进？ |
| 转换成本 | 客户迁移到竞品的成本有多高？迁移需要多长时间？ |
| 网络效应 | 用户增长是否带来更高的客户黏性？竞争对手进入壁垒多高？ |
| 规模效应 | 产能扩张后单位成本是否下降？与竞争对手成本差距多大？ |
| 技术/专利壁垒 | 核心技术领先竞品多少年？下一个技术迭代周期多长？ |

**追加检验**：
- **ROE趋势**（郑希核心）：近3年ROE是向上还是向下？最近季度是否出现拐点？
- **毛利率趋势**：是否有提价或成本下降的空间？
- **ROIC vs WACC**：扩张是在创造价值还是在毁灭价值？

**郑希式追问**：ROE向上是科技股最可靠的"重力加速度"——这家公司的ROE在过去8个季度是上行、持平还是下行？如果ROE已经拐头向下，护城河讨论的意义就大打折扣。

### 第四步：逆向思考与风险清单 — 欧奈尔"止损底线" + 林奇"逆向情绪" + 地缘政治六维度

**核心问题**：如果我看错了，我会亏多少？什么时候该认错离场？

#### 4.1 失败路径分析

- 列出"这家公司在1~3年内可能失败的所有路径"（表格：路径/概率/影响程度）
- **偏误自查**：叙事偏差、锚定效应、幸存者偏差、线性外推偏差

#### 4.2 硬止损位设定（欧奈尔核心）

- 基于当前价格，8%~10%止损设在什么位置？
- 建仓初期（持仓<最终仓位50%）下跌超8%，无条件离场
- 底仓已建立且逻辑已验证，可考虑在合理估值下限加仓（仅限杀估值而非杀逻辑）

#### 4.3 逻辑止损触发条件

- 连续2个季度业绩低于预期且产业景气未改善 → 减仓/清仓
- 产业渗透率超50%且增速明显放缓 → 减机动仓
- ROE拐头向下且无合理解释 → 系统性减仓

#### 4.4 时间止损

- 持有满4季度，买入逻辑未兑现（订单/收入/利润无实质改善）→ 减至观察仓

#### 4.5 地缘政治六维度风险评估（李进"系统均衡"视角）

| 评估维度 | 核心问题 | 风险信号 |
|---------|---------|---------|
| **海外收入依赖度** | 海外收入占总收入比例？是否过度依赖单一市场？ | 海外收入占比>50%且依赖单一国家/地区 |
| **供应链安全** | 关键零部件/原材料是否依赖特定国家或单一供应商？ | 核心芯片/材料/设备依赖单一海外供应商 |
| **制裁与清单风险** | 是否已被或可能被列入实体清单、未经核实清单？ | 已在清单上或处于被关注名单 |
| **本地化对冲能力** | 是否有海外建厂、本地化运营、多元供应链？ | 无海外产能布局，完全依赖出口 |
| **政策与合规环境** | 目标市场的数据安全、ESG、外资准入、技术出口管制变化？ | 目标市场正在收紧外资或技术准入 |
| **自主研发能力与抗压韧性**（"华为式"抗封锁能力） | 外部封锁下能否凭借自身研发体系实现技术自主与替代？ | 研发投入强度低、核心技术不自主、无备胎计划 |

**"华为式"抗封锁能力评分**（每项0-5分，满分20分）：
- **研发投入强度与持续性**：研发费用率是否长期维持高位且逆周期不减？（0-5分）
- **核心技术自主可控程度**：是否掌握底层专利、源代码、工艺与关键设备？（0-5分）
- **"备胎计划"与替代方案**：关键环节被断供时，是否有自研替代路线？（0-5分）
- **极端情形下的生存能力**：被列入制裁清单后，能否依靠国内/替代市场维持现金流并继续投入研发？（0-5分）

**评分解读**：≥15分抗封锁能力强（地缘政治估值折价低）；10-14分中等；<10分需高度警惕。

> **参考华为案例**：连续多年遭遇实体清单与芯片断供，但凭借长期高研发投入（研发费用率常年>15%）与"备胎转正"，从芯片（海思/麒麟）到操作系统（鸿蒙）再到数据库、EDA等底层根技术实现自主突破，是"打压之下逆势成长"的标杆样本。凡身处制裁/断供风险中的标的，此项能力越强，地缘政治估值折价越低、持有容忍度越高。

**欧奈尔式追问**：如果买入后下跌8%，你会加仓还是止损？——如果答案是"加仓"，说明你还没想清楚最坏情景。先想清楚亏多少再想赚多少。

**林奇式追问**：市场恐慌时，这家公司的基本面发生了什么变化？如果基本面没变，恐慌是买入机会；如果基本面恶化了，恐慌是逃命信号。

### 第五步：产业景气与ROE拐点分析 — 郑希"景气判断" + 李进"二阶导监测"

**核心问题**：产业处在景气周期的什么位置？增速的加速度（二阶导）是正还是负？

分析要点：

**郑希维度 — 产业景气判断**：
- **ROE趋势**：近8个季度ROE数据——趋势是上行、筑顶、还是下行？
- **营收增速加速度**：近8个季度营收增速——是逐季加快、持平、还是放缓？
- **订单增速/产能利用率**：领先指标显示什么方向？
- **全球产业链位置**：公司在产业链中处于什么环节？上下游景气是否共振？
- **季度验证**：过去4个季度，每个季度的数据是否都在验证买入逻辑？

**李进维度 — 渗透率与二阶导**：
- **渗透率定位**：当前渗透率精确刻度；距离15%加速临界点多远？距离50%减速区间多远？
- **二阶导判断**（李进核心）：最近2~3个季度增速的加速度是正还是负？
  - 正二阶导 = 增速在加快 → 估值扩张阶段
  - 负二阶导 = 增速在放缓 → 估值收缩信号
- **二阶导预警**：即使行业仍在增长，一旦二阶导转负，估值中枢必然下移
- **真实趋势 vs 题材炒作**：有订单/收入/利润支撑？还是纯概念？

**郑希式追问**："长期判断由无数短期客观判断拼接而成"——过去4个季度的财报数据是否一致支持你的买入逻辑？如果不是，哪一季度的数据出现了偏离？

**李进式追问**：当前渗透率到50%了吗？二阶导（增速加速度）是正是负？——这两个问题的答案直接决定你该重仓、持有还是减仓。

### 第六步：管理层评估 — 李进"治理+科研转化" + 林奇"诚信观察"

**核心问题**：管理层可信吗？科研能力能转化为业绩吗？

#### 6.1 现任管理层画像

- **CEO/创始人**：姓名、年龄、任职起止时间、关键决策记录（近3-5年）
- **核心高管团队**：CFO/COO/技术负责人稳定性
- **持股比例与利益对齐**：持股比例及变化、近1年增减持情况
- **薪酬结构**：是否与长期业绩挂钩

#### 6.2 管理层评估四大维度20分制（≥15分方可重仓）

**维度A：诚信与品格（一票否决项 + 5分）**

| 检查项 | 操作指引 | 评分 |
|--------|---------|------|
| 年报"说到做到"验证 | 翻阅过去3年年报中管理层对下一年度的战略规划与业绩展望，对比实际落地情况。兑现率≥80%为优秀，<50%则一票否决 | 达标+2分 |
| 业绩预告准确性 | 统计近5次业绩预告与实际财报的偏差。频繁大幅修正（偏差>20%）且方向向下，则一票否决 | 达标+1分 |
| 归因习惯 | 阅读每次季报/年报中"经营情况讨论"。习惯性将未达目标归咎于宏观/疫情/政策，从不自省——一票否决 | 达标+2分 |
| 监管记录 | 查询证监会、交易所网站，近3年是否有违规、问询、警示函记录。若有财务造假相关——一票否决 | 一票否决项 |

**满分5分，加分≥3分且无否决项，方可通过此维度。**

**维度B：对待股东的态度（5分）**

| 检查项 | 操作指引 | 评分 |
|--------|---------|------|
| 分红历史 | 近3年分红比例（分红/净利润）是否≥30%（成长型可放宽至≥15%）？若连续盈利且现金流充裕却常年不分红，警惕"铁公鸡" | +2分 |
| 融资记录 | 近5年是否有高价增发、可转债等大额融资？若频繁融资且募投项目频繁变更或延期，减分 | +1分（无则+2） |
| 回购行为 | 股价低迷时是否有回购计划且实际执行？若承诺回购但迟迟不动，减分 | +1分 |
| 大股东质押率 | 大股东质押比例是否>50%？若是，警惕资金链风险及利益输送可能 | 一票否决预警 |

**维度C：战略眼光与执行力（5分）**

| 检查项 | 操作指引 | 评分 |
|--------|---------|------|
| 战略聚焦度 | 是否聚焦主业，还是频繁跨界追逐热点？聚焦加分，跨界减分 | +2分 |
| 核心战略落地 | 管理层公开承诺的重点战略（如"开拓海外市场""加大研发投入"），跟踪后续是否在财报中兑现 | +2分 |
| 行业格局认知 | 在公开讲话/年报中，管理层对行业竞争格局、自身定位的表述是否深刻、客观？泛泛而谈者减分 | +1分 |

**维度D：管理层稳定性与激励（5分）**

| 检查项 | 操作指引 | 评分 |
|--------|---------|------|
| 核心团队稳定性 | 近3年核心高管离职率是否<10%？频繁更换财务总监、董秘是危险信号 | +2分 |
| 股权激励合理性 | 是否对核心骨干有合理股权激励？行权条件是否具有挑战性但可达？ | +2分 |
| 内部人交易 | 高管近期是否有大额减持？若产业景气上行但高管持续减持，需高度警惕 | +1分 |

**管理层总评分**：满分20分，≥15分方可重仓；10-14分需观察；<10分回避。

#### 6.3 科研转化能力专项评估（高科技/医药企业必填，20分制）

**维度A：研发投入的"质"与"量"（8分）**

| 检查项 | 操作指引 | 评分标准 |
|--------|---------|---------|
| 研发强度（R&D/营收） | 查看近3年研发费用率趋势 | ≥15%且逐年提升：+4分；10%~15%且稳定：+2分；<5%：+0分 |
| 研发投入资本化率 | 查看财报附注中"开发支出"资本化比例 | <30%为审慎：+2分；>50%需警惕利润粉饰，扣分 |
| 研发人员占比与学历结构 | 查阅年报"员工构成" | ≥30%且硕士/博士比例高：+2分 |

**维度B：研发产出效率与转化率（8分）**

| 检查项 | 操作指引 | 评分标准 |
|--------|---------|---------|
| 专利与知识产权 | 查询国家知识产权局或公司公告 | 近3年发明专利数量及质量（是否为核心技术专利）：+2分 |
| 新产品收入占比 | 财报中"新产品/新技术收入占比" | 占比逐年提升且当前≥20%：+2分 |
| 技术产品化周期 | 关注研发投入转化为收入的周期 | 核心产品从研发到上市周期合理，符合行业规律：+1分 |
| 关键技术突破 | 跟踪公司在国产替代/行业前沿领域的突破 | 有实质性突破（如国产首颗、进口替代）：+1分 |

**维度C：资本回报效率（4分）**

| 检查项 | 操作指引 | 评分标准 |
|--------|---------|---------|
| ROIC（投入资本回报率） | 是否>WACC且≥10% | >WACC且≥10%：+2分；>WACC但<10%：+1分；<WACC：+0分（一票否决预警） |
| 研发费用化 vs 资本化 | 研发支出是否被过度资本化以美化利润？ | 费用化占比高：+2分；资本化率>50%：扣分 |

**科研转化能力总评分**：满分20分，≥15分优秀；10-14分合格；<10分需警惕（一票否决预警）。

**管理层质量评级**（综合20分制+科研20分制）：
- **A**：管理层≥15分且科研转化≥15分，或管理层≥18分
- **B**：管理层10-14分且科研转化≥10分
- **C**：触碰一票否决项，或管理层<10分，或科研转化<10分

#### 6.4 接班人问题专项分析

**触发条件**（满足任一）：CEO年龄≥60岁、任职超15年、近1年有变更传闻/公告、家族企业二代已进入高管层。
- 依赖度评估：创始人离开的冲击
- 接班人计划现状：是否有培养中的候选人
- 历史高管离职情况

**林奇式追问**：如果CEO明天退休，你会继续持有这家公司吗？——如果答案是否定的，你是在赌一个人，而不是投资一门生意。

### 第七步：估值与买入时机 — 林奇"PEG" + 李进"分批建仓" + 欧奈尔"趋势确认"

**核心问题**：当前价格是否合理？PEG在什么区间？应该分几批建仓？

#### 7.1 PEG五档估值体系（核心锚）

| PEG区间 | 估值判断 | 操作建议 |
|---------|---------|---------|
| <0.8 | 显著低估 | 绝佳买点，可建底仓 |
| 0.8~1.2 | 合理 | 正常建仓区间 |
| 1.2~1.5 | 偏贵 | 仅适合小仓位试探 |
| 1.5~2.0 | 高估 | 回避或减仓 |
| >2.0 | 严重透支 | 坚决回避，持仓者考虑减仓 |

**PEG口径说明**：PEG = 当前PE(TTM) ÷ 未来2年预期利润复合增速（%）。增长率取保守估计，不要被卖方研报的乐观预测蒙蔽。

#### 7.2 其他估值工具（辅助）

| 估值工具 | 适用类型 | 可接受标准 |
|---------|---------|----------|
| **远期PE** | 稳定增长型公司 | 当前PE ≤ 未来3年EPS复合增速×1.2 |
| **股息率** | 缓慢增长型/防御仓 | 股息率 ≥ 10年期国债收益率×1.5倍 |
| **DCF模型** | 现金流稳定的成熟企业 | 当前市值 ≤ 保守DCF估值的80%（20%安全边际） |

#### 7.3 当前估值读数（必须通过工具验算）

| 指标 | 数值 | 历史分位 | 判断 |
|------|------|---------|------|
| PE (TTM) | | | |
| 前瞻PE | | | |
| **PEG**（当前PE/未来2年预期增速） | | | <0.8绝佳 / 0.8~1.2合理 / >1.5高估 |
| PB | | | |
| FCF Yield | | | |

#### 7.4 分批建仓规则（李进系统工程师思维）

| 批次 | 触发条件 | 仓位比例 |
|------|---------|---------|
| 第一批 | 价格进入合理区间（PEG<1.2） | 最终仓位的1/3 |
| 第二批 | 价格回调至合理区间下限以下（PEG<0.7）或恐慌性下跌 | 再加1/3 |
| 第三批 | 产业景气加速确认或财报超预期 | 补齐剩余1/3 |

**总仓位控制**：
- 单只个股初始≤总资产的10%
- 逻辑验证后≤15%
- 绝对上限≤20%
- 单一行业不超过总资产的40%

#### 7.5 左侧布局 vs 右侧重仓策略

| 渗透率阶段 | 策略类型 | 仓位上限 | 说明 |
|-----------|---------|---------|------|
| <10% | 左侧试探 | ≤5% | 不确定性高，小仓位试错 |
| 10%~30% | 右侧加仓 | ≤15% | 黄金加速区，确认趋势后加仓 |
| 30%~50% | 右侧重仓 | ≤20% | 景气主升浪，重仓持有 |
| >50% | 逐步兑现 | 逐步减仓 | 增速放缓信号，分批兑现 |

#### 7.6 "假如空仓"测试（克服沉没成本的最强工具）

**核心问题**：假如你现在空仓，你会以当前价格买入这家公司吗？

- **会买入** → 继续持有或加仓
- **不会买入** → 立即卖出，不要犹豫
- **犹豫不决** → 说明你的买入逻辑不够清晰，需要先回到第一步重新研究

> 这个测试的核心目的是克服"沉没成本谬误"——你已经亏了多少不应该成为你继续持有的理由，唯一应该考虑的是：如果现在从头开始，你还会买这只股票吗？

#### 7.7 趋势确认（欧奈尔）

- 当前股价处于上升通道、盘整还是下跌通道？
- 近30天是否有放量突破或放量下跌信号？
- 机构持仓近几个季度变化趋势？

**欧奈尔式追问**：如果股市明天关门5年，你愿意以这个价格买入吗？——这是段永平的检验。但对1~3年框架，你应该问：如果这只股票停牌1年，你还能睡得着吗？

**林奇式追问**：PEG<0.8时你有多大把握增速可持续？——PEG是很好的指标，但前提是对增长率有把握。保守估计增长，不要被卖方研报的乐观预测蒙蔽。

## 专节一：四大矛盾化解方案

在1~3年景气投资中，投资者常面临四大核心矛盾。以下是在本框架中的具体化解方案：

### 矛盾一：买点哲学冲突（左侧逆向 vs 右侧确认）

- **林奇/郑希派**：偏好左侧布局，在渗透率10%~30%区间逐步建仓
- **欧奈尔派**：偏好右侧确认，等趋势信号明确后再介入
- **化解方案**：**左侧试探（5%仓位）+ 右侧加仓（10%~15%）**。左侧试探用小仓位控制风险，右侧确认后再加大仓位。不追求买在最低点，追求"买在确定性最高的区间"。

### 矛盾二：持有时间冲突（长期持有 vs 动态调整）

- **林奇/段永平派**：好公司应该长期持有
- **郑希/李进派**：每季度用景气数据验证，景气下行则果断调仓
- **化解方案**：**以季度为单位的动态持有**。每持有满1个季度，做一次"景气体检"：ROE趋势是否向上？渗透率是否仍在加速？二阶导是否为正？三项中有两项转负，则启动减仓流程。不是"买入并遗忘"，也不是"频繁交易"，而是"有纪律的动态持有"。

### 矛盾三：止损 vs 越跌越买

- **欧奈尔派**：8%止损，无条件执行
- **林奇派**：基本面没变，越跌越买
- **化解方案**：**区分"杀估值"和"杀逻辑"**。如果是杀估值（市场恐慌、行业利空但公司基本面未变），可在合理估值下限加仓；如果是杀逻辑（业绩不及预期、景气拐点、管理层变质），必须止损离场，不加仓。判断标准：回到第四步的风险清单，看最坏情景是否已经发生。

### 矛盾四：分散 vs 集中

- **保守派**：分散投资，降低单一风险
- **激进派**：集中投资，重仓好公司
- **化解方案**：**行业分散、主线集中**。单一行业不超过总资产的40%（分散控回撤），但主线行业（景气度最高的1~2个行业）可占20%~30%（集中求收益）。单只个股初始≤10%，逻辑验证后≤15%，绝对上限≤20%。

## 专节二：决策优先级速查卡

当多个信号同时出现时，按以下优先级执行：

| 优先级 | 信号类型 | 触发条件 | 操作 |
|--------|---------|---------|------|
| **P0** | 一票否决 | 管理层诚信问题/财务造假/监管处罚 | 立即清仓，不犹豫 |
| **P1** | 硬止损 | 建仓初期下跌8~10% | 无条件离场 |
| **P2** | 逻辑止损 | 连续2季度业绩低于预期+景气未改善 | 减仓/清仓 |
| **P3** | 景气拐点 | 渗透率>50%+增速放缓 / ROE拐头 | 减机动仓 |
| **P4** | 估值透支 | PEG>1.5 / PEG>2 | 减机动仓/加速清仓 |
| **P5** | 时间止损 | 满4季度逻辑未兑现 | 减至观察仓 |
| **P6** | 技术面辅助 | 跌破关键支撑+放量下跌 | 减仓确认 |

**核心原则**：P0和P1是硬规则，不允许AI自由裁量；P2~P6可结合具体情况灵活处理，但必须有明确触发条件。

## 专节三：每季度复盘检查清单

持有期间，每季度末必须完成以下检查：

| 序号 | 检查项 | 检查方法 | 触发条件 |
|------|--------|---------|---------|
| 1 | ROE趋势 | 最近4个季度ROE数据 | 连续2季下降 → P3减仓 |
| 2 | 营收增速加速度 | 最近4个季度营收增速 | 连续2季放缓 → 检查二阶导 |
| 3 | 渗透率位置 | 第三方数据更新 | >50% → 减机动仓 |
| 4 | 二阶导方向 | 增速加速度正负 | 转负 → 估值收缩信号 |
| 5 | 管理层动态 | 公告/新闻/季报 | 核心高管离职/战略变更 → 重新评估 |
| 6 | 地缘政治变化 | 关税/制裁/政策变化 | 新制裁/关税 → 重新评估风险敞口 |
| 7 | 估值水平 | PEG/PE历史分位 | PEG>1.5 → P4减仓 |

## 专节四：能力圈声明

### 适用场景
- 本Skill适用于1~3年中长期投资研究，适合希望在好赛道中挖掘好公司、赚企业成长钱的个人投资者
- 适用于A股、港股、美股的个股深度研究
- 适用于漏斗筛选后对终选标的进行深度研究

### 不适用场景
- 不适用于短线交易（<1季度）
- 不适用于事件驱动型交易（如并购套利、IPO打新）
- 不适用于大宗商品/期货/外汇等纯投机品种
- 不适用于"代码推荐"式的一键投资——本Skill产出的是研究框架，最终决策需投资者自行判断

### 局限性
1. **网络限制**：网络搜索须使用本地五工具组合，美股数据需通过浏览器手动获取
2. **数据源覆盖**：本地工具主要覆盖A股和港股，美股数据源较少
3. **实时性**：本地工具数据可能滞后1-2天，最新财报建议查原始来源
4. **港股接口稳定性**：东方财富港股接口在中国大陆网络连接不稳定（非地理封锁），工具已内置重试机制
5. **AI偏见**：AI分析可能受训练数据影响，需要通过偏见自查清单进行校验
6. **一手验证**：对于C级公司（信息稀缺），需要通过田野调查、产品体验等方式补充AI的盲区
7. **渗透率数据可得性**：细分行业渗透率缺乏官方统计，需依赖第三方估算
8. **地缘政治数据更新频率**：制裁清单、关税政策等变化较快，需定期更新
