# 管理层纵深研mid-management-deep-dive技究：买股票就是买人（1~3 年景气草稿V0.0.1）

对 $ARGUMENTS 进行管理层深度研究。

**支持输入格式**：公司名 或 人名 公司名，例如：`美团`、`王兴 美团`、`黄仁勋 英伟达`

> "买股票就是买人。找到你信任的人，然后长期持有。" —— 段永平（长期投资的核心原则，在1~3年景气框架中同样适用，但评估维度更聚焦）
>
> "评估管理层，要看他们在没人看着的时候做什么。" —— 巴菲特（诚信度，在景气框架中仍然是基石）
>
> "管理层是'人'的因素，科研转化是'技术'的因素。两者必须交叉验证——再好的技术，交给不诚信的人，也是价值毁灭。" —— 李进（治理评估的核心逻辑）
>
> "ROE向上是科技股最可靠的'重力加速度'，但研发效率决定了ROE能向上多久。" —— 郑希（科研转化与ROE的联动）

## 设计理念

在1~3年景气投资框架中，管理层评估的核心不是"这个人值不值得信任10年"，而是：

1. **在景气上行周期中，管理层能否抓住机遇最大化股东价值？**
2. **诚信度是否足以支撑1~3年的持有？**（诚信问题是最高优先级卖出触发）
3. **科研投入能否高效转化为业绩增长？**（科技/医药企业的核心竞争力）
4. **资本配置是否与景气周期匹配？**
5. **治理结构是否稳健？**（地缘政治环境下的治理风险）

本Skill是 `/mid-investment-research`（景气版）第五步"管理层评估"的**深化版**。当标准投资研究中管理层评分不确定（B级或以下）、或管理层/科研转化是核心投资逻辑时，使用本Skill做纵深研究。

AI无法和管理层吃饭，但可以通过公开信息做到：
- **追踪管理层的话与做是否一致**（承诺vs兑现——在1~3年框架中权重更高）
- **分析每一笔重大资本配置决策的回报**
- **评估科研投入的转化效率**（研发费用率→新产品收入→ROE提升）
- **从困难时期的决策中推断品格**
- **通过员工/商家/客户的反馈侧面验证**

### 四位投资大师的思维模式与本文档的关系

| 投资大师 | 核心思维模式 | 在管理层评估中的角色 | 评估维度映射 |
|----------|--------------|----------------------|--------------|
| **欧奈尔** (William O'Neil) | 工程师思维：信号与纪律 | **风控底线**：设定硬止损与逻辑止损，防范管理层欺诈或重大失误 | 诚信度一票否决、8%~10%硬止损联动、决策优先级P0/P1 |
| **林奇** (Peter Lynch) | 侦探思维：常识与求证 | **常识求证**：从产品、员工、客户侧面验证管理层言行一致性 | 侧面验证（员工/客户/行业口碑）、承诺兑现追踪 |
| **郑希** | 物理学家思维：第一性原理 | **科研转化+ROE拐点**：评估研发效率与资本回报的底层逻辑 | 科研转化能力20分制、ROIC/再投资回报率 |
| **李进** | 系统工程师思维：渗透率坐标 | **治理框架+渗透率定位**：评估治理结构稳健性及战略与产业周期的匹配度 | 治理结构评估、战略眼光与执行力、地缘政治风险 |

**以上四位大师的组合，构成了本Skill的完整拼图：**
- 用**欧奈尔**的风控底线，设定管理层诚信的一票否决和硬止损纪律（解决"如何防止被骗"）；
- 用**林奇**的常识求证，从产品、员工、客户侧面验证管理层言行一致性（解决"如何验证真假"）；
- 用**郑希**的科研转化评估，从第一性原理判断科技/医药企业的研发效率与资本回报（解决"研发是否值得信任"）；
- 用**李进**的治理框架，评估治理结构稳健性及战略与产业周期的匹配度（解决"管理层是否配得上这个赛道"）。

## 能力圈声明

### 适用场景
- 科技、医药、高端制造等需要深度评估管理层科研转化与战略执行能力的标的。
- 处于景气周期（渗透率15%临界点前后）的成长型企业。
- 治理结构复杂、存在AB股或特殊投票权安排的企业。
- 地缘政治风险敞口较大的出口导向型企业。

### 不适用场景
- 纯周期股（如煤炭、钢铁、航运）：核心变量为供需与价格，管理层权重极低。
- 深度价值/困境反转股：核心变量为资产负债表修复，而非景气成长。
- 金融股（银行、保险、券商）：评估逻辑完全不同，需使用专门的金融股评估框架。
- 被动指数投资：无需个股层面管理层评估。

- 公司基础信息

确认关键人物后，使用 Task 工具启动多个后台 Agent **并行**收集以下数据：

1. Agent 1：CEO公开发言与承诺记录（股东信、电话会、采访、社交媒体）——**重点是过去3年的承诺与兑现**
2. Agent 2：资本配置决策记录（并购、回购、分红、新业务投资）——**重点是景气周期中的配置效率**
3. Agent 3：治理结构与薪酬（股权结构、关联交易、高管薪酬）——**重点是AB股、独立性、地缘政治风险**
4. Agent 4：侧面验证信息（员工评价、客户反馈、行业口碑）
5. Agent 5（科技/医药企业）：科研转化数据（研发费用率、研发资本化率、新产品收入占比、在研关键项目进展）

### 第二步：诚信度评估（一票否决项）

在1~3年景气框架中，诚信问题的重要性**不降反升**——因为持有周期短，一旦暴雷可能来不及逃生。

**欧奈尔式提醒**：诚信度是一票否决项，不是加分项。只要触碰红线，立即终止后续评估。

#### 2.1 承诺vs兑现追踪（1~3年视角，权重更高）

从过去3年的财报电话会、股东信、公开采访中，提取管理层做过的**具体承诺**：

**使用财报下载工具获取年报**（详见原版 `management-deep-dive` 的工具使用指南）：

```bash
# 下载年报PDF（A股）
python tools/a_share/stock_equity.py --code 601899 --download-report
# 用pdf_extract.py提取文本（首选），返回失败时回退Poppler
python tools/common/pdf_extract.py markdown 601899_2025年报.pdf --save-md --out-dir reports/pdf
```

**承诺兑现追踪表**：

| # | 时间 | 承诺内容 | 承诺场合 | 兑现情况 | 评价 |
|---|------|---------|---------|---------|------|
| 1 | | "我们将在2025年实现X业务盈利" | 2024年报电话会 | | ✅/⚠️/❌ |
| 2 | | "我们计划回购$X亿" | 2024年股东信 | | ✅/⚠️/❌ |
| 3 | | "研发投入占比将提升至X%" | 2023年财报 | | ✅/⚠️/❌ |

**1~3年景气框架的特别关注**：

- **兑现率权重更高**：在1~3年持有期中，管理层必须在**这个景气周期内**兑现承诺。兑现率<50% → 一票否决
- **时间维度**：承诺的兑现时间是否与产业景气周期匹配？如果承诺的兑现节点在景气见顶之后，警示信号

**兑现率统计**：

| 承诺兑现率 | 评价 | 在1~3年框架中的决策 |
|:---------:|------|-------------------|
| >80% | 优秀——说到做到 | ✅ 可以重仓 |
| 60-80% | 合格——大方向对但执行有偏差 | ⚠️ 可以持有但需提高监测频率 |
| 40-60% | 令人担忧——承诺过多交付不足 | ❌ 建议减仓或回避 |
| <40% | 严重问题——不可信赖 | ❌ 一票否决 |

### 第三步：科研转化能力评估（科技/医药企业必填——新增核心维度）

这是1~3年景气投资框架中**最关键的差异化评估维度**。科技/医药企业的景气上行，必须由高效的科研转化支撑。

**郑希式追问**："ROE向上是科技股最可靠的'重力加速度'——但研发效率决定了ROE能向上多久。研发费用率高的公司很多，但能转化为利润的很少。这家公司属于哪一种？"

#### 3.1 研发投入的"质"与"量"（郑希核心关注）

| 检查项 | 操作指引 | 该公司数据 | 评分标准 |
|--------|---------|-----------|----------|
| 研发强度（R&D/营收） | 查看近3年研发费用率趋势 | | ≥15%且逐年提升：+4分（优秀）<br>10~15%且稳定：+2分（合格）<br><5%：+0分（科技公司不合格） |
| 研发投入资本化率 | 查看财报附注中"开发支出"资本化比例 | | <30%：+2分（审慎加分）<br>>50%：需警惕利润粉饰，扣分 |
| 研发人员占比与学历结构 | 查阅年报"员工构成" | | ≥30%且硕博比例高：+2分（优秀） |

#### 3.2 研发产出效率与转化率（郑希核心关注）

| 检查项 | 操作指引 | 该公司数据 | 评分标准 |
|--------|---------|-----------|----------|
| 专利与知识产权 | 查询国家知识产权局或公司公告 | | 近3年发明专利数量及质量，是否为核心技术专利：+2分 |
| 新产品收入占比 | 财报中"新产品/新技术收入占比" | | ≥20%且逐年提升：+2分（优秀） |
| 技术产品化周期 | 关注研发投入转化为收入的周期 | | 符合行业规律即可（消费电子1~2年，创新药5~7年）：+1分 |
| 关键技术突破 | 跟踪公司在国产替代/行业前沿领域的进展 | | 有实质性突破（如进入大客户供应链、获得关键认证）：+1分 |
| 重大科研项目进展 | 跟踪在研核心项目的节点里程碑：创新药临床阶段推进、芯片流片与良率爬坡、新产品认证、中试/量产进度等 | | 关键项目按节点推进且达预期：+2分（优秀）<br>关键节点滞后/中止：减分或一票否决预警 |

#### 3.3 资本回报效率——警惕"毁灭式扩张"

| 检查项 | 操作指引 | 该公司数据 | 评分标准 |
|--------|---------|-----------|----------|
| ROIC（投入资本回报率） | 计算：ROIC = 税后营业净利润 /（总资产 - 现金 - 无息负债） | | >WACC且≥10%：+1分（合格）<br>>15%：+2分（优秀）<br><5%却还在扩产：一票否决 |
| 再投资回报率 | 新增资本是否带来同等或更高的利润增长？ | | 增量资本回报率 > 存量ROIC：创造价值，+2分 |

### 第四步：资本配置能力（景气周期中的配置效率）

### 第八步：管理层维度四大矛盾化解

在评估过程中，常遇到以下矛盾，需按以下原则化解：

#### 矛盾一：买点哲学——左侧布局 vs 右侧重仓

| 维度 | 左侧布局（逆向） | 右侧重仓（顺势） |
|------|-----------------|-----------------|
| 适用场景 | 行业遭遇短期利空，但长期逻辑未破坏 | 渗透率突破15%临界点、财报连续2季加速 |
| 管理层要求 | 诚信度必须通过（一票否决项均无） | 战略执行力必须优秀（核心战略已落地） |
| 操作要点 | 分批建仓，第一批在合理估值下限介入 | 可一次性建立2/3仓位，剩余1/3回调补齐 |
| 仓位上限 | 该标的最终仓位的50%以内 | 可达该标的最终仓位 |

**化解原则——以"逻辑是否完整"为分水岭**：
- 若回撤源于**系统性恐慌**，且**产业逻辑完好 + 管理层诚信 + 财务健康**三项均通过，则采用左侧布局策略，分批建仓。
- 若回撤伴随**基本面恶化**（连续2个季度业绩低于预期、ROE拐头向下、管理层诚信问题），则按欧奈尔规则，**不抄底，等待趋势明朗**。
- **核心原则**：左侧布局仅适用于"杀估值"而非"杀逻辑"。杀估值可逆向，杀逻辑必须止损。

#### 矛盾二：持有时间——长期持有 vs 每季度景气检验

| 维度 | 林奇/欧奈尔视角 | 郑希/李进视角 | 化解方案 |
|------|----------------|---------------|----------|
| 持有逻辑 | 好公司长期持有，不择时 | 每季度用景气数据检验，不达标则调仓 | 以基本面持续向好为前提，每季度做"体检" |
| 卖出触发 | 买入逻辑被破坏 | 景气数据恶化（ROE拐头、增速放缓） | 两者叠加时立即卖出 |

#### 矛盾三：止损 vs 越跌越买

| 情形 | 操作 | 管理层评估关联 |
|------|------|---------------|
| 杀估值（市场情绪）可逆向加仓 | 管理层诚信通过 + 科研转化正常 + 财务健康 | 三层均通过方可左侧加仓 |
| 杀逻辑（管理层失信/战略失误/科研失败）必须止损 | 一票否决项触发 → 立即清仓 | 诚信度一票否决 → 不犹豫 |

#### 矛盾四：分散 vs 集中

| 管理层评级 | 仓位策略 | 说明 |
|-----------|---------|------|
| A级 | 主线集中（可占组合15%~20%） | 管理层可信，可重仓长期持有 |
| B级 | 分散配置（单只不超过10%） | 有亮点但也有隐忧，控制风险 |
| C级 | 禁止建仓 | 管理层不可信，不参与 |

### 第九步：综合评分与结论（引入李进20分制框架）

在1~3年景气投资框架中，管理层评分采用**李进20分制框架**（≥15分方可重仓）：

#### 维度A：诚信与品格（一票否决项 + 5分）

| 检查项 | 评分标准 | 得分 |
|--------|---------|:----:|
| 年报"说到做到"验证——兑现率≥80%：+2分；<50%：一票否决 | | |
| 业绩预告准确性——频繁大幅修正且方向向下：一票否决 | | |
| 归因习惯——习惯性甩锅外部：一票否决 | | |
| 监管记录——财务造假相关：一票否决 | | |

**满分5分，加分≥3分且无否决项方可通过此维度。**

#### 维度B：对待股东的态度（5分）

| 检查项 | 评分标准 | 得分 |
|--------|---------|:----:|
| 分红历史——近3年分红比例≥30%（成长型≥15%）：+2分 | | |
| 融资记录——近5年无高价增发/募投频繁变更：+1分（无则+2） | | |
| 回购行为——股价低迷时有回购且执行：+1分 | | |
| 大股东质押率——>50%：一票否决预警 | | |

#### 维度C：战略眼光与执行力（5分）

| 检查项 | 评分标准 | 得分 |
|--------|---------|:----:|
| 战略聚焦度——聚焦主业：+2分 | | |
| 核心战略落地——重点战略在财报中兑现：+2分 | | |
| 行业格局认知——深刻客观：+1分 | | |

#### 维度D：管理层稳定性与激励（5分）

| 检查项 | 评分标准 | 得分 |
|--------|---------|:----:|
| 核心团队稳定性——近3年高管离职率<10%：+2分 | | |
| 股权激励合理性——行权条件有挑战性但可达：+2分 | | |
| 内部人交易——产业景气上行但高管无异常减持：+1分 | | |

#### 科研转化维度（科技/医药企业加分项 +5分）

| 检查项 | 评分标准 | 得分 |
|--------|---------|:----:|
| 研发强度≥15%且逐年提升：+2分 | | |
| 研发资本化率<30%：+1分 | | |
| 新产品收入占比≥20%且逐年提升：+2分 | | |
| 重大科研项目按节点推进：+2分；关键节点滞后：减分或一票否决预警 | | |

**评分汇总**：

| 维度 | 得分 | 满分 |
|------|:----:|:----:|
| A. 诚信与品格（一票否决项） | | 5 |
| B. 对待股东的态度 | | 5 |
| C. 战略眼光与执行力 | | 5 |
| D. 管理层稳定性与激励 | | 5 |
| E. 科研转化能力（科技/医药） | | 5 |
| **总分** | | **20（25）** |

**评级标准**：
- **≥15分**：可重仓
- **10~14分**：可轻仓参与，提高监测频率
- **<10分**：建议回避
- **触碰任何一票否决项**：立即清仓/回避

#### PEG五档估值与管理层的联动

管理层质量直接影响估值折价/溢价：

| 管理层评级 | PEG估值调整 | 说明 |
|-----------|------------|------|
| A级 | 可在PEG合理区间（0.8~1.2）给予溢价，甚至容忍至1.5 | 执行力强、兑现度高，市场愿意给溢价 |
| B级 | 严格按PEG估值，>1.2即视为偏贵 | 需警惕，估值偏高时果断减持 |
| C级 | PEG必须<0.8才考虑，且需大幅折价 | 任何>1.0的估值均需极度谨慎 |

**PEG五档体系**：显著低估(<0.8) / 合理(0.8~1.2) / 偏贵(1.2~1.5) / 高估(1.5~2.0) / 严重透支(>2.0)

#### 底仓/机动仓与管理层质量的联动

| 管理层评级 | 底仓建议 (60%~80%) | 机动仓建议 (20%~40%) | 操作指引 |
|-----------|---------------------|----------------------|----------|
| A级 | 可纳入核心底仓 | 景气回调时可加仓 | 长期持有，每季度检验 |
| B级 | 谨慎纳入底仓（上限30%） | 仅作为卫星配置 | 严格止损，逻辑破坏即清仓 |
| C级 | 禁止纳入底仓 | 禁止参与 | 仅观察，不建仓 |

### 第十步："假如空仓"测试（克服沉没成本）

在综合评分完成后，**必须**执行此测试——这是克服沉没成本的最强工具：

> **假设你现在完全空仓，没有任何持仓成本，以当前价格和已知信息，你是否还会买入这只股票？**

| 答案 | 含义 | 操作 |
|------|------|------|
| **会买** | 逻辑完整，管理层可信，估值合理 | 继续持有或加仓 |
| **不会买** | 逻辑已破坏，管理层失信，或估值严重透支 | **立即卖出**，不要犹豫 |
| **犹豫不决** | 存在不确定性 | **减仓至舒适仓位**，等待更多信号 |

### 第十一步：决策优先级金字塔（卖出纪律联动）

管理层评估结果直接嵌入卖出决策，按以下优先级执行：

| 优先级 | 触发条件 | 操作 | 与管理层评估的联动 |
|:------:|----------|------|---------------------|
| **P0** | 一票否决项触发（监管处罚、财务造假、重大失信） | 立即清仓 | 诚信度评估直接触发，不讨论 |
| **P1** | 硬止损：股价跌破买入价8%~10% | 无条件止损 | 欧奈尔纪律，与管理层无关 |
| **P2** | 逻辑止损：核心投资逻辑被证伪 | 立即清仓 | 管理层战略失误、科研转化失败 |
| **P3** | 景气拐点：渗透率见顶或增速连续2季下滑 | 分批卖出 | 李进二阶导思维，管理层未能开辟第二曲线 |
| **P4** | 估值透支：PEG>2.0（A级可放宽至2.5） | 分批卖出 | 管理层质量影响透支容忍度 |
| **P5** | 时间止损：持有4个季度未达预期 | 减仓或清仓 | 管理层执行力不足，景气检验不通过 |
| **P6** | 技术面辅助：趋势破位、放量下跌 | 减仓/止损 | 欧奈尔信号，作为上述优先级的确认 |

**欧奈尔式提醒**：P0和P1为刚性纪律，禁止人为干预或延迟执行。先保命（防造假/防失信），再谈收益（景气/估值）。

### 第十二步：季度复盘检查清单（7项必查）

每季度末必须逐项核查，确保管理层质量未发生恶化：

| 序号 | 检查项 | 检查要点 | 恶化信号 |
|:----:|--------|---------|---------|
| 1 | 承诺兑现追踪 | 上季度业绩会/年报承诺是否兑现？ | 连续2季承诺未兑现 |
| 2 | 科研转化进度 | 研发项目是否按计划推进？有无重大突破或失败？ | 核心项目中止/技术路线被证伪 |
| 3 | 资本配置效率 | 新投资/并购/回购是否产生预期回报？ | 高价并购后整合失败 |
| 4 | 治理结构变化 | 实控人、核心高管、股权结构有无重大变动？ | 核心高管集体离职 |
| 5 | 地缘政治变化 | 海外政策、供应链、制裁风险有无新动态？ | 被列入制裁清单/新增关税 |
| 6 | 侧面验证更新 | 员工/客户/行业口碑有无恶化？ | 核心技术人员流失>20% |
| 7 | 综合评分更新 | 重新打分，评级是否发生变化？ | 评级从A降为B，或B降为C |

### 第十三步：保存报告

将报告写入 `reports/{公司名}/{公司名}-management-{YYYYMMDD}.md`，例如 `reports/腾讯/腾讯-management-20260409.md`

下载的财报 PDF 提取管理层承诺、战略发言等内容时，**首选** `tools/common/pdf_extract.py`：

```bash
# 分类检测 PDF 类型
python tools/common/pdf_extract.py detect 601899_2025年报.pdf

# 提取 Markdown（含表格）并写盘
python tools/common/pdf_extract.py markdown 601899_2025年报.pdf --save-md --out-dir reports/pdf

# 强制 OCR 提取（适用于 pdf-inspector 提取乱码时）
python tools/common/pdf_extract.py text 688235_2025年报.pdf --force-ocr --ocr-langs chi_tra+eng
```

**⚠️ 汇率获取强制规范**：任何涉及汇率折算的场景，**必须首选 `python tools/common/fx_rate.py --code USDCNY,HKDCNY` 获取实时汇率**。仅当 `fx_rate.py` 返回失败时，才可回退搜索工具。

## 注意事项

- **诚信是一票否决项**——能力不足可以学习，品格有问题无法修复（在1~3年框架中同样适用）
- **科研转化是科技/医药企业的生命线**——研发费用率高但转化率低的企业，是价值毁灭
- **看行为不看言辞**——管理层说什么不重要，做了什么才重要
- **在困难中看真相**——顺风时谁都是好CEO，逆风时才见真功夫
- **资本配置是终极考试**——赚钱容易，把赚到的钱配置好难
- **不要爱上管理层**——保持客观，即使是你欣赏的人也可能犯大错
- **数据必须标注来源**——关键数据至少2个来源交叉验证
- **货币单位要明确**——港币/人民币/美元，防止混淆
- **市值必须手算校验**——股价 × 总股本，与报告市值对比
- **网络搜索时效性**——使用 `--time-range month/week` 限制时间范围
- **"假如空仓"测试必须独立执行**——禁止与综合评分混淆
- **P0/P1为刚性纪律**——禁止人为干预或延迟执行

## 局限性

1. **信息不对称**：AI无法像巴菲特那样和管理层面对面吃饭聊天
2. **时效性限制**：公开信息可能有延迟
3. **侧面信息不完整**：员工评价、客户反馈等可能不完整
4. **主观判断风险**：尽管遵循客观原则，评分仍有一定主观性
5. **扫描版PDF限制**：A股年报常为扫描版PDF
6. **多地上市复杂性**：A+H股、港股+美股ADR等股权结构分析较复杂
7. **科研转化数据可得性**：部分公司新产品收入占比等数据披露不充分

**管理层深度研究是投资决策的重要参考，但不是唯一依据。**
