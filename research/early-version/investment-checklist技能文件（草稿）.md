# 1~3年景气投资买入前 investment-checklist技能文件（V0.0.1草稿）

> **核心思想**：景气投资不是盲目追涨，也不是盲目抄底，而是在产业爆发的前夜，用严苛的纪律筛选出"好行业、好公司、好价格"的共振点。
>
> **适用对象**：希望通过1~3年中长期持有、拒绝频繁短线交易，在好赛道中挖掘好公司、赚企业成长钱的个人投资者。
>
> **适用周期**：1~3年中长期景气成长。
>
> **底层框架**：欧奈尔（CANSLIM信号与纪律）+ 林奇（PEG与常识求证）+ 郑希（科技产业周期与ROE拐点）+ 李进（渗透率坐标与系统均衡）。

---

## 执行流程

### 第一步：解析输入，识别所有待分析公司

从用户输入中解析出所有公司名称/代码。对每家公司确定：
- 公司全称、股票代码、上市交易所
- 如果公司未上市，标记为"未上市"并给出简要说明（是否有间接投资途径），跳过完整Checklist

### 第一步半：AI研究偏见预警

对每家公司进行"信息丰富度"快速评级（A/B/C），并在报告中标注：

| 等级 | 判断标准 | 对Checklist的影响 |
|------|---------|-----------------|
| A级 | 上市多年、数据充裕 | 正常执行，但警惕"共识陷阱"——所有指标看起来都清晰不代表真的确定 |
| B级 | 数据有限需推算 | 每个推算指标标注置信度 |
| C级 | 信息极度稀缺 | 不勉强填满关卡，诚实标注"数据不足"，聚焦可验证的核心问题 |

**核心原则**：Checklist的目标是**排除坏选择**。对于C级公司，"数据不足"不等于"不通过"——应诚实标注为"灰色地带，需补充一手信息"。

段永平说过："看不懂"有两种——一种是生意太复杂真的看不懂，一种是你还没花时间去看。AI研究的局限是容易把"资料少"和"看不懂"混为一谈。

---

### 第二步：并行数据收集

使用 Task 工具为**每家公司**启动独立的后台 Agent 进行数据收集（所有公司同时并行启动），每个Agent负责收集：

**1~3年景气投资框架下需要收集的核心数据**：

1. **盈利能力与景气度**：ROE（3~5年趋势及最新季度）、毛利率、净利率、**营收增速（近8个季度趋势）**、**扣非净利润增速（近8个季度趋势）**
2. **估值数据**：当前股价、市值、PE(TTM)、前瞻PE、PEG（当前PE/未来2年预期增速）、PB、股息率
3. **产业景气数据**：行业渗透率（当前值及变化趋势）、行业供需格局、CR3集中度、价格趋势
4. **财务健康**：负债水平、经营性现金流净额（是否为正且匹配净利润）、应收账款/存货周转
5. **竞争格局**：市场份额、主要竞争对手、份额变化趋势、定价权
6. **护城河证据**：品牌/转换成本/网络效应/规模效应/技术壁垒的具体证据
7. **管理层记录**：CEO履历、关键决策、持股、资本配置记录、历史承诺兑现率
8. **科研转化能力**（科技/医药企业）：研发费用率、研发资本化率、专利数量、新产品收入占比、在研关键项目进展
9. **地缘政治风险**：海外收入占比、供应链关键环节依赖度、制裁/关税风险敞口
10. **最新动态**：近6个月重大事件（业绩、并购、监管、管理层变动等）

**数据获取工具规范**：详见SKILL.md的"工具使用指南"章节。

**网络搜索工具选择**：详见 [web-search-tools](../tools-scripts/web-search-tools.md)。

### 第三步：逐公司执行七关 Checklist（1~3年景气投资版）

对每家已上市公司，依次过七关：

---

#### 第一关：产业赛道是否具备"爆发潜力"？（一票否决项）

> 💡 **大师点评**："在错误的赛道里寻找好公司，就像在沙漠里种水稻，再努力也是徒劳。" —— 郑希

**修改目标**：将原版"10年后确定性"改为"1~3年产业趋势的确定性"，融入渗透率坐标。

必须回答：
- [ ] 能用一句话说清楚这家公司靠什么赚钱吗？
- [ ] **未来1~3年，这个产业的需求是否确定增长？（核心问题）**
- [ ] 这个产业的**关键驱动变量**是什么？（渗透率？价格？政策？技术迭代？）
- [ ] 产业渗透率当前在什么位置？（<5%过早，10%~30%黄金区，>50%警惕减速）
- [ ] 驱动产业增长的是**真实需求**还是**政策补贴**？
- [ ] 对这个产业的认知来自深度研究还是道听途说？

**渗透率坐标（核心锚点）**：

| 渗透率区间 | 阶段定性 | 投资动作 | 检查项 |
| :--- | :--- | :--- | :--- |
| **< 5%** | 导入期/过早 | **回避** | 技术路线未定，商业模式未跑通，纯题材炒作 |
| **10% ~ 30%** | **黄金爆发区** | **重仓出击** | 需求真实爆发，EPS开始兑现，戴维斯双击起点 |
| **30% ~ 50%** | 成长中后期 | **精选龙头** | 增速边际放缓，竞争格局恶化，需极度挑剔 |
| **> 50%** | 成熟/衰退期 | **回避/减仓** | 渗透率见顶，杀估值风险极大 |

**真实趋势 vs 题材炒作**：
- **EPS支撑检测**：必须有真实的业绩（EPS）或订单落地支撑。纯概念、纯PPT、无业绩兑现的**坚决回避**
- **政策驱动检测**：若产业景气完全依赖纯政策补贴，无真实市场需求支撑，**一票否决**

**评分标准**（★1-5）：

| 星级 | 判断标准 |
| :--- | :--- |
| ★★★★★ | 商业模式极简，1~3年产业趋势高度确定，渗透率在10%~30%黄金区 |
| ★★★★☆ | 商业模式清晰，产业趋势确定性较高，渗透率处于合理区间 |
| ★★★☆☆ | 模式可理解但产业趋势存在不确定性，渗透率偏低（<10%）或偏高（>50%） |
| ★★☆☆☆ | 业务线复杂或产业处于剧变期，1~3年趋势难以判断 |
| ★☆☆☆☆ | 完全不在能力圈内，或产业是纯政策驱动无真实需求支撑 |

**硬性否决**：如果连赚钱方式都说不清，或产业趋势完全依赖补贴而无真实需求，直接标记为"不在能力圈，不做分析"。

> 💬 **林奇式提醒**："如果你花10分钟都解释不清一家公司是做什么的，那它的业务可能太复杂了——而复杂的业务往往意味着你无法真正理解它。"
> 💬 **李进式提醒**："渗透率是产业的'GPS定位'，没有这个坐标，一切判断都是盲人摸象。"

#### 第二关：行业景气度是否处于"主升浪"？

> 💡 **大师点评**："不要试图去接一把正在下落的飞刀，等它落地企稳，或者等它重新飞起来。" —— 欧奈尔

**修改目标**：保留原版经济特征评估，但增加**景气位置判断**（郑希/李进核心维度）。

用数据说话，**关键指标必须通过工具精确计算**（命令详见SKILL.md）：

| 指标 | 该公司数值 | 参考标准 | 判断 |
|------|-----------|---------|------|
| ROE（3年均值，最新趋势） | | >15%优秀，>20%卓越，**趋势向上为佳** | |
| 毛利率 | | >40%暗示定价权 | |
| 营收增速（近4季度 vs 前4季度） | | **加速or减速？** | |
| 扣非净利润增速（近4季度趋势） | | **是否匹配营收增速？** | |
| 自由现金流 | | 持续为正、≈净利润 | |
| 资本开支强度 | | 轻资产优于重资产 | |
| 负债水平 | | 有息负债/净利润<3年 | |
| **产业渗透率位置** | | **10%~30%为黄金区，>50%警戒** | |
| **行业供需格局** | | 供不应求 > 供需平衡 > 供过于求 | |
| **CR3集中度** | | 龙头份额是否持续提升 | |
| **价格趋势** | | 核心产品价格是否稳定或上涨 | |

**增速匹配度检测**：营收增速与扣非净利润增速必须匹配。若营收大增但利润不增，需警惕"增收不增利"的虚假景气。

**连续负加速红线**：**连续3个季度**业绩负加速，必须判定为景气拐点，不可跳过验证（R-1）。*注：单季负加速需交叉验证，不可直接判死刑（R-2）。*

**评分标准**（★1-5）：

| 星级 | 判断标准 |
| :--- | :--- |
| ★★★★★ | ROE>20%且向上 + 毛利率>40% + 营收增速加速 + 渗透率10%~30% + 供需偏紧（全部达标） |
| ★★★★☆ | 4项达标 |
| ★★★☆☆ | 3项达标 |
| ★★☆☆☆ | 2项达标或趋势恶化 |
| ★☆☆☆☆ | 多数不达标或FCF持续为负，或渗透率已>60%且增速明显放缓 |

> 💬 **郑希式提醒**："ROE向上是科技股最可靠的'重力加速度'——只要这个趋势在，估值波动只是噪音。但ROE一旦拐头，必须立即重新评估。"
> 💬 **李进式提醒**："渗透率突破15%后加速上行期可以重仓，达到50%~60%后必须逐步兑现——不要恋战。"

#### 第三关：公司质地是否具备"核心竞争力"？（护城河 × 壁垒可持续性）

> 💡 **大师点评**："最终，决定股价的不是华尔街的喧嚣，而是公司的盈利、盈利、再盈利。" —— 彼得·林奇

**修改目标**：保留原版护城河框架，但评估视角从"永远"缩短为"1~3年内能否守住"，并新增科研转化能力。

逐项检查：

| 护城河类型 | 是否具备 | 具体证据 | 1~3年内会变宽还是变窄？ |
| :--- | :--- | :--- | :--- |
| 品牌/定价权 | | | |
| 转换成本 | | | |
| 网络效应 | | | |
| 成本/规模优势 | | | |
| 技术/专利壁垒 | | | |
| **科研转化能力**（科技/医药） | | **研发费用率、专利产出、新产品收入占比** | |
| **客户粘性** | | **续费率/NPS/复购率** | |

追加检验：如果给竞争对手100亿，1~3年内能否复制这门生意？

**评分标准**（★1-5）：

| 星级 | 判断标准 |
| :--- | :--- |
| ★★★★★ | 多重护城河叠加且1~3年内持续变宽 |
| ★★★★☆ | 至少一条强护城河且稳定 |
| ★★★☆☆ | 有护城河但不够深，或趋势不明 |
| ★★☆☆☆ | 护城河正在被侵蚀（技术被追赶、客户流失） |
| ★☆☆☆☆ | 无明显护城河，或技术路线面临被颠覆风险 |

> 💬 **段永平式提醒**："护城河不是看它今天多宽，而是看它明天会不会变窄。技术在变，用户在变，唯一不变的是变化本身。"

#### 第四关：管理层是否值得信任 & 科研转化能力（40分制核心评估）

> 💡 **大师点评**："买股票就是买公司，买公司就是买管理层。如果管理层不诚实，所有的财务模型都是废纸。" —— 巴菲特/林奇

**修改目标**：保留原版管理层评估，大幅增加**科研转化能力评估**（附件1第二部分）和**承诺兑现率**，形成完整的40分制评估体系。

##### 维度一：管理层诚信与品格（一票否决 + 5分）

| 检查项 | 评分标准 | 一票否决/预警触发条件 |
| :--- | :--- | :--- |
| 年报"说到做到" | 过去3年战略规划兑现率≥80% (+2分) | 兑现率<50%，或频繁更改战略方向 |
| 业绩预告准确性 | 近5次预告偏差<20% (+1分) | 频繁大幅向下修正（偏差>20%） |
| 归因习惯 | 客观分析内外部原因 (+2分) | 习惯性将未达标归咎于宏观/疫情，从不自省 |
| 监管记录 | 近3年无违规 (+0分) | **有财务造假、重大违规记录 → 一票否决！** |

**满分5分，加分≥3分且无否决项，方可通过此维度。**

##### 维度二：对待股东的态度（5分）

| 检查项 | 评分标准 | 警惕信号 |
| :--- | :--- | :--- |
| 分红历史 | 近3年分红率≥30%（成长型≥15%） (+2分) | 连续盈利且现金流充裕却常年不分红（铁公鸡） |
| 融资记录 | 无大额频繁融资 (+2分) | 频繁高价增发/可转债，且募投项目频繁变更/延期 |
| 回购行为 | 股价低迷时有实际回购 (+1分) | 承诺回购但迟迟不动（忽悠式回购） |
| 大股东质押 | 质押率<30% (+0分) | **质押率>50% → 一票否决预警！**（警惕资金链断裂与利益输送） |

##### 维度三：战略眼光与执行力（5分）

| 检查项 | 评分标准 | 减分项 |
| :--- | :--- | :--- |
| 战略聚焦度 | 聚焦主业 (+2分) | 频繁跨界追逐热点，主业荒废 |
| 核心战略落地 | 公开承诺的重点战略在财报中兑现 (+2分) | 战略只停留在年报致辞中 |
| 行业格局认知 | 对竞争格局表述深刻、客观 (+1分) | 盲目自大，无视竞争对手威胁 |

##### 维度四：管理层稳定性与激励（5分）

| 检查项 | 评分标准 | 危险信号 |
| :--- | :--- | :--- |
| 核心团队稳定性 | 近3年核心高管离职率<10% (+2分) | 频繁更换财务总监、董秘（财务暴雷前兆） |
| 股权激励合理性 | 行权条件具挑战性且可达 (+2分) | 行权条件形同虚设，或激励对象过于集中 |
| 内部人交易 | 无大额减持 (+1分) | **产业景气上行但高管持续大额减持 → 高度警惕！** |

**管理层评分规则**：满分20分。≥15分方可重仓；10~14分可轻仓参与；<10分建议回避。

##### 维度五：科研转化能力评估（20分制，科技/医药/高端制造必查）

| 评估维度 | 检查项 | 评分/预警标准 |
| :--- | :--- | :--- |
| **A. 研发投入质与量 (8分)** | 研发强度(R&D/营收) | ≥15%且逐年提升 (+4分)；10%~15% (+2分)；<5% (+0分) |
| | 研发投入资本化率 | <30%为审慎 (+2分)；>50%需警惕利润粉饰 (扣分) |
| | 研发人员结构 | 占比≥30%且硕博比例高 (+2分) |
| **B. 产出效率与转化 (8分)** | 专利与知识产权 | 近3年发明专利数量及质量 (+2分) |
| | 新产品收入占比 | 占比逐年提升且当前≥20% (+2分) |
| | 技术产品化周期 | 核心产品从研发到上市周期合理 (+1分) |
| | 关键技术突破 | 有实质性突破（进入大客户供应链、获得关键认证）(+1分) |
| | 重大科研项目进展 | 按节点顺利推进 (+2分)；**核心项目滞后/中止/路线被证伪 → 一票否决预警** |
| **C. 资本回报效率 (4分)** | ROIC与再投资回报 | ROIC>WACC且≥10% (+1分)；ROIC>15% (+2分)；增量回报>存量 (+2分) |
| | **毁灭式扩张** | **ROIC长期<5%却还在拼命投入扩产 → 一票否决！** |

**科研转化最终评分**：满分20分。≥15分可重仓，10~14分可轻仓参与，<10分建议回避。

> 💬 **李进式提醒**："管理层是'人'的因素，科研转化是'技术'的因素。两者必须交叉验证——再好的技术，交给不诚信的人，也是价值毁灭。"

#### 第五关：估值是否具备"安全边际"？（PEG五档 + 建仓策略）

> 💡 **大师点评**："任何价格买入伟大的公司都是好投资？错！再好的公司，买贵了也是灾难。" —— 欧奈尔/林奇

**修改目标**：从绝对估值（DCF折价）转向**PEG为核心的景气估值 + 分批建仓规则 + 左右侧布局策略**。

##### 1. PEG 五档估值体系

| PEG 区间 | 估值定性 | 操作策略 |
| :--- | :--- | :--- |
| **< 0.8** | 显著低估 | 左侧逆向布局良机（需确认非"杀逻辑"） |
| **0.8 ~ 1.2** | 合理区间 | 分批建仓核心区域 |
| **1.2 ~ 1.5** | 偏贵 | 停止加仓，持有底仓，准备减持机动仓 |
| **> 1.5** | 高估 | **触发减仓机动仓（R-5）** |
| **> 2.0** | 严重透支 | **触发加速清仓机动仓（R-5）** |

##### 2. 估值指标总览

| 指标 | 数值 | 历史分位 | 判断 |
|------|------|---------|------|
| PE (TTM) | | | |

##### 3. 建仓策略：左侧逆向 vs 右侧顺势

**左侧布局（逆向）**：
- **适用场景**：行业遭遇短期利空但长期逻辑未破坏（杀估值，非杀逻辑）
- **操作要点**：分批建仓，第一批在合理估值下限介入，第二批在利空最恐慌、成交量放大时介入
- **仓位控制**：总仓位控制在最终目标仓位的 **50%以内**

**右侧重仓（顺势）**：
- **适用场景**：渗透率突破15%临界点，财报连续2季加速
- **操作要点**：可一次性建 **2/3** 仓位，剩余1/3在回调至20日均线时补齐
- **止损纪律**：必须设定 **8%~10%** 硬止损线（R-7）

**分批建仓规则**：
- 当股价进入"合理买入区间"后，先建 **1/3底仓**
- 若股价继续回调至合理区间下限以下（如PEG<0.7），再加 **1/3**
- 确认产业景气加速或财报超预期后，补齐剩余 **1/3**

追加检验（**必须通过工具精确计算**）：
- 三情景下的估值区间（乐观/中性/悲观）
- 如果景气判断有误，在当前价格买入最多亏多少？
- 股价腰斩你敢加仓吗？（仅限于逻辑未被破坏的情况）

**评分标准**（★1-5）：

| 星级 | 判断标准 |
| :--- | :--- |
| ★★★★★ | PEG<0.8 + 隐含年化回报>25% + 处于合理建仓区间下沿 |
| ★★★★☆ | PEG 0.8~1.2 + 隐含年化回报15%~25% |
| ★★★☆☆ | PEG 1.2~1.5 + 安全边际一般 |
| ★★☆☆☆ | PEG>1.5，偏贵，仅机动仓可持有 |
| ★☆☆☆☆ | PEG>2，严重高估，等待回调 |

> 💬 **林奇式提醒**："PEG是我最喜欢的估值指标——但前提是你对增长率有把握。用'未来2年预期增速'时，务必保守，不要被卖方研报的乐观预测蒙蔽。"

#### 第六关：持仓管理与卖出触发（底仓/机动仓分离）

> 💡 **大师点评**："会买的是徒弟，会卖的是师傅。卖出不是因为跌了，而是因为逻辑变了。" —— 李进

**修改目标**：从原版"是否因为FOMO想买"的主观检查，升级为**完整的仓位管理 + 卖出触发规则**。

##### 1. 仓位结构分离

| 仓位类型 | 定位 | 操作规则 |
| :--- | :--- | :--- |
| **底仓（60%~80%）** | 长线核心，赚企业1~3年成长的钱 | 只要买入逻辑未被破坏（产业景气上行、护城河稳固、管理层可信），始终保留。不因短期20%以内的波动而卖出。可每季度结合最新财报做小幅调整（±5%） |
| **机动仓（20%~40%）** | 平滑波动，赚估值波动的钱 | 当股价进入高估区间（PEG>1.5或估值分位>80%）时减持，回落至合理区间时回补。机动仓的操作不影响底仓的长期判断 |

##### 2. 仓位管理硬约束

| 管理维度 | 具体规则 |
| :--- | :--- |
| 总持股数 | 5~10只为宜。过少则非系统性风险过大，过多则跟踪精力不足 |
| 单只个股初始仓位 | ≤总资产的10% |
| 单只个股验证后仓位 | ≤15% |
| 单只个股绝对上限 | ≤20% |
| 单一行业上限 | ≤总资产的40%，避免行业黑天鹅导致组合崩溃 |
| 行业相关性管理 | 持有的行业之间相关系数<0.5 |
| 流动性管理 | 持有标的日成交额至少>1亿元（市值<100亿的公司可放宽至>3000万） |

##### 3. 卖出触发条件（P0~P6 优先级排序）

| 优先级 | 触发条件 | 动作 | 对应风控硬编码 |
| :--- | :--- | :--- | :--- |
| **P0** | 管理层诚信问题 / 财务造假 / 严重漂移 | **立即清仓** | R-4 |

| **P5** | 产业渗透率>50%且增速放缓 / ROE拐头向下 | 减机动仓 | - |

**核心原则**：杀估值可逆向，杀逻辑必须止损。

#### 第七关：地缘政治风险系统评估（新增否决项）

> 💡 **大师点评**："在逆全球化时代，不考虑地缘政治的投资，就像在雷区里闭眼狂奔。"

6维度评估矩阵：

| 评估维度 | 核心检查项 | 一票否决/预警触发条件 |
| :--- | :--- | :--- |
| **1. 海外收入依赖度** | 海外营收占比 | **>60% 且无本地化产能 → 一票否决预警（R-10）** |
| **2. 供应链安全** | 核心零部件/材料是否依赖单一敌对国家？ | 无国产替代方案，断供即停产 |
| **3. 制裁与清单风险** | 是否在美国实体清单/SDN清单？ | 已上榜且无实质应对方案 |
| **4. 本地化对冲能力** | 是否有海外建厂/合资规避关税？ | 无对冲手段，完全暴露于关税大棒下 |
| **5. 政策与合规环境** | 所在国政策是否突变？ | 面临没收资产、强制技术转让等极端风险 |
| **6. "华为式"抗压韧性** | 研发费用率>15%？核心技术自主可控？备胎计划？极端生存能力？ | **无备胎计划，无极端生存能力 → 一票否决** |

**"华为式"抗封锁能力详解**：
- **研发费用率**：是否长期维持高位且逆周期不减（>15%为优秀）
- **核心技术自主可控**：是否掌握底层专利、源代码、工艺与关键设备，而非仅做集成组装
- **备胎计划**：关键环节被断供时，是否有自研替代路线
- **极端生存能力**：被列入制裁清单后，能否依靠国内/替代市场维持现金流并继续投入研发

> 💬 **参考华为案例**：连续多年遭遇实体清单与芯片断供，但凭借长期高研发投入（研发费用率常年>15%）与"备胎转正"，从芯片（海思/麒麟）到操作系统（鸿蒙）再到数据库、EDA等底层根技术实现自主突破，是"打压之下逆势成长"的标杆样本。

## 关键原则

- **景气优先**：1~3年持有周期的核心是产业景气方向，而非"永远持有"
- **宁可错过，不可做错**：Checklist的目标是排除坏选择，不是找到最好的
- **诚实面对能力圈**：看不懂就说看不懂，不要勉强分析
- **安全边际是生命线**：好公司买贵了也会亏钱——用PEG而非信仰估值
- **止损纪律优先于逆向加仓**：先保命，再谈收益（欧奈尔优先于林奇）
- **每季度体检**：买入不是终点，每季度的景气数据验证才是持有或卖出的依据
- **镜子测试不可跳过**：说不清楚理由就不买，没有例外
- **杀估值可逆向，杀逻辑必须止损**：这是1~3年框架的第一铁律

## 四大矛盾化解方案

在融合四位大师理念时，必然存在冲突。以下为实战化解方案：

| 矛盾点 | 冲突表现 | 化解方案（实战准则） |
| :--- | :--- | :--- |
| **1. 买点哲学** | 欧奈尔追涨突破 vs 林奇/郑希/李进逆向布局 | **以"逻辑是否完整"为分水岭。** 杀估值可逆向（左侧），杀逻辑必须止损。右侧突破必须有基本面加速确认。 |
| **2. 持有维度** | 林奇/欧奈尔"长期持有" vs 郑希/李进"每季度检验" | **底仓长期持有 + 机动仓灵活调整。** 底仓(60%~80%)不动，机动仓(20%~40%)根据估值和景气调整。每季度用景气数据做体检，逻辑不变则底仓不动，景气恶化则砍机动仓。 |
| **3. 止损 vs 越跌越买** | 欧奈尔严格止损 vs 林奇"跌了更便宜" | **区分"杀估值"和"杀逻辑"。** 建仓初期（验证期）止损优先（R-7）；深度验证期，若仅为杀估值且逻辑完好，可逆向加仓。 |
| **4. 分散 vs 集中** | 林奇"分散抗风险" vs 欧奈尔/李进"集中求收益" | **行业分散控回撤，主线集中求收益。** 单行业≤40%（防黑天鹅），单只≤20%（求弹性），行业相关系数<0.5。 |

## 决策优先级速查卡

当多个信号同时出现时，严格执行以下优先级：

**P0 治理一票否决 → P1 硬止损 → P2 逻辑止损 → P3 产业景气拐点 → P4 估值透支 → P5 技术面辅助**

- **P0**：管理层诚信问题/财务造假/严重漂移 → 立即清仓（不可豁免）
- **P1**：建仓初期触及硬止损（8%~10%） → 无条件离场（不可豁免）
- **P2**：连续2季度业绩低于预期 + 产业景气未改善 → 减仓/清仓
- **P3**：产业景气拐点（连续3季负加速/ROE拐头） → 减仓/清仓
- **P4**：满1年（4季度）买入逻辑未兑现 → 减仓至观察仓
- **P5**：估值PEG>1.5/PE分位>90% → 减机动仓；PEG>2.0加速清
- **P6**：技术面辅助信号（MA200破位等）→ 作为确认/背离参考，不独立触发

**核心原则**：命中即停、禁止跳过高级别。P0>P1>P2>P3>P4>P5>P6，高级别信号优先于低级别信号。

## 阈值口径说明（统一标准）

1. **PEG五档阈值**：显著低估(<0.8) / 合理(0.8~1.2) / 偏贵(1.2~1.5) / 高估(>1.5) / 严重透支(>2.0)。*注：理念文档中多处提及PEG，统一以此五档为执行标准。*
2. **底仓/机动仓区间**：底仓(60%~80%) / 机动仓(20%~40%)。
3. **修正幅度上限**：±1档（R-8）。防止因主观情绪过度修正估值或景气判断。
4. **利润/营收不匹配**：利润负+营收正，必须标"不匹配"（R-9），需深挖原因。
5. **单只个股上限**：初始≤10%，验证后≤15%，绝对上限≤20%。
6. **单一行业上限**：≤40%。

## 风控硬编码（R-1 ~ R-10）

以下规则**不允许AI自由裁量**，必须严格执行：

| 编码 | 规则描述 | 执行要求 |
| :--- | :--- | :--- |
| **R-1** | 连续3季负加速必须判拐点 | 不可跳过，不可用"一次性因素"自我安慰 |
| **R-2** | 单季负加速不得判拐点 | 需交叉验证（行业/公司/宏观），防止误杀 |
| **R-3** | 持有≥4季度 + 漂移≥轻微 | 必须触发时间止损（P4） |
| **R-4** | 严重漂移 / 诚信问题 | 必须触发exit-signal，立即清仓 |
| **R-5** | PEG > 1.5 / PEG > 2.0 | 减机动仓 / 加速清机动仓 |
| **R-6** | PE分位 > 90% | 进入高估预警区，停止买入 |
| **R-7** | 硬止损 8%~10% | 建仓初期不可豁免，不可补仓摊平 |
| **R-8** | 修正幅度上限 ±1档 | 防止过度修正，保持客观 |
| **R-9** | 利润负 + 营收正 | 必须标"不匹配"，触发深度排查 |
| **R-10** | 地缘政治风险敞口过大 | 海外收入>60% + 无本地化 + 面临制裁 → 一票否决 |

## 局限性

1. **数据缺失风险**：产业渗透率、科研转化细节（如专利质量、研发人员结构）在部分非上市公司或信披不全的公司中难以获取，需依赖行业调研或专家访谈
2. **地缘政治复杂性**：地缘风险具有突发性和不可预测性，6维度评估仅为静态快照，需动态跟踪
3. **主观判断成分**：管理层诚信、战略眼光等维度虽有量化指标，但仍包含主观判断，需结合多方信息交叉验证
4. **产业渗透率数据**：部分细分行业渗透率缺乏官方统计，需依赖第三方机构或券商研报估算，应标注"估计"
5. **科研转化评估数据限制**：对于非上市或信息披露不充分的公司，科研项目进展难以获取可靠数据
6. **不构成投资建议**：本 Checklist 仅为个人投资思维框架与决策辅助工具，**不构成任何投资建议**。市场有风险，投资需谨慎。
