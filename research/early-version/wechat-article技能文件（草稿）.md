# 微信公众号文章（景气投资版）：作者-编辑-读者三Agent协作

对 $ARGUMENTS 进行深度研究，产出一篇可直接发布的微信公众号文章。三个Agent各司其职：作者写深度初稿，编辑精修结构和表达，读者从目标受众视角审读。

**支持输入格式**：主题描述，例如：
- **技术类**：`大模型OPD技术解读`、`Qwen3技术报告解读`
- **景气投资类**：`腾讯2025Q4财报解读（景气视角）`、`AI算力产业链瓶颈分析`、`为什么PEG<1是买入信号`

## 设计理念

一篇好的公众号文章需要同时满足三个维度：

1. **深度**——对得起花时间读完的人（作者负责）
2. **可读性**——结构清晰、节奏好、不劝退（编辑负责）
3. **真的能看懂**——目标读者不会在中途放弃（读者负责）

单人写作容易“自嗨”——写的人觉得清楚，读的人看不懂。三Agent协作的本质是**强制引入外部视角**。

**景气投资类文章的特别说明**：

本技能支持两类文章：
1. **技术解读类**：论文/技术报告/新产品解读——侧重技术深度和通俗表达
2. **景气投资类**：财报解读/产业链分析/投资方法论——侧重**GARP框架**（林奇PEG、郑希ROE趋势、李进渗透率、欧奈尔止损纪律）

写景气投资类文章时，作者Agent需采用四位景气大师的分析框架：
- **林奇**：六类分类、PEG估值、常识验证
- **郑希**：ROE趋势、产业景气、二阶导
- **李进**：渗透率、管理层评估、地缘政治
- **欧奈尔**：止损纪律、趋势信号、CAN-SLIM


## 阶段一：研究与素材收集

### 第一步：明确文章定位

在开始写作之前，先确认以下信息（如用户未指定则主动询问）：

| 维度 | 需要确认 | 默认值 |
|------|---------|--------|
| **文章类型** | 技术解读/景气投资/其他 | 技术解读 |
| **目标读者** | 技术背景程度 | 有点技术背景但非该领域专家 |
| **文章深度** | 科普/中深度/硬核 | 中深度 |
| **文章长度** | 字数范围 | 3000-4000字 |
| **是否需要下载原始论文/资料** | 需要PDF/配图 | 是 |
| **写作风格** | 正式/对话式/犀利 | 对话式（像写给聪明的朋友） |

**景气投资类文章额外确认**：
- 分析标的（公司名/行业名）
- 分析的景气维度：ROE趋势/渗透率/PEG/管理层/地缘政治（可多选）
- 是否涉及卖出纪律讨论

### 第二步：深度研究

使用 Task 工具**并行**启动2-3个研究Agent，收集足够的素材：

**研究Agent A：核心内容研究**
- **技术类**：下载论文PDF、提取核心贡献、关键图表、实验结果
- **景气投资类**：搜索公司最新财报、财务数据、估值指标、分析师观点

**研究Agent B：行业背景与应用**
- **技术类**：搜索该技术的行业落地情况、发展趋势、里程碑事件
- **景气投资类**：搜索行业景气数据、竞争格局、渗透率数据、地缘政治风险

**研究Agent C（可选）：对比/验证研究**
- **技术类**：同类方法/产品的对比、历史发展脉络
- **景气投资类**：同行业可比公司对比、历史估值区间、买卖信号验证

#### 网络信息获取工具

研究Agent收集素材时，统一使用本地五工具组合（详见 [web-search-tools](../tools-scripts/web-search-tools.md)）。工具选型按主题涉及的市场参照矩阵：

- **A股主题**：`anysearch --tag finance` 主 + `doubao --finance` 辅
- **港股/美股/国际主题**：港股 `doubao --sites hkexnews.hk` + `tavily`（双源）；美股 `exa --type deep` + `doubao`（双源）
- **技术/论文主题**：英文文献优先 `exa --type deep`，中文资讯用 `doubao`，多源互补
- 使用 `--time-range month/week` 限制时间范围，优先获取最新信息

#### PDF文档内容提取（技术类文章）

论文解读类文章必须从PDF提取高清原图（≥500KB）。文字与表格提取**首选** `tools/common/pdf_extract.py`（基于pdf-inspector库，支持自动乱码检测+OCR回退），返回失败时才回退Poppler；**高清图像渲染提取配图仍需使用 Poppler `pdftoppm`**（`pdf_extract.py` 不提供图像渲染能力）。完整流程见 [PDF文档内容提取技能](../tools-scripts/pdf-extraction.md)。

```bash
# 文字与表格提取（首选）
python tools/common/pdf_extract.py markdown 论文.pdf --save-md --out-dir reports/pdf

# 高清图像渲染（用于配图，使用 Poppler pdftoppm）
pdftoppm -png -r 900 -f {页码} 论文.pdf output/page
```

### 第三步：整理素材框架

研究Agent全部完成后，整理出：

1. **核心论点**（一句话概括文章要传达的核心信息）
   - 技术类：论文/技术的核心突破是什么？
   - **景气投资类**：景气逻辑是否成立？买入/卖出信号是什么？
2. **关键数据**（3-5个最有冲击力的数据点）
3. **配图清单**（需要哪些图，来源是什么）
4. **文章大纲**（6-8个章节的标题和核心内容）


## 阶段二：作者Agent写初稿

使用 Task 工具启动**作者Agent**，给出详细的写作指令。

### 作者Agent的Prompt模板（通用版）

```markdown
你是一位深度写作者（Author Agent），需要写一篇微信公众号文章。

## 目标读者
{根据第一步确认的读者画像}

## 写作风格要求
- 纯中文表达，避免中英文夹杂（技术术语首次出现时给英文，后续用中文）
- 像写给聪明的朋友看，不是学术论文翻译或研报搬运
- 用类比帮助理解，但类比要贴切、不俗套
- 关键公式/数据要有，但每个都要用大白话解释
- 不用emoji
- 段落不超过4行（公众号阅读环境）

## 核心内容
{整理好的素材、数据、论点}

## 文章结构要求
1. **开头（前3段）**：必须有强钩子——用数据冲击力或反直觉的结论开场
2. **背景**：为什么这件事重要？解决什么问题？
3. **核心内容（2-3节）**：深度在这里体现，但每个技术点都要有“大白话翻译”
4. **实证/案例**：用数据和案例说话，不要空谈
5. **影响/展望**：这件事对行业或投资意味着什么
6. **结尾**：一句有传播力的判断收束，适合被截图转发

## 配图要求
- 论文解读类：必须从论文PDF中提取原图，直接插入
- 每张图不小于500KB，确保高清
- 图片存放在 `assets/{主题简称}/` 目录

## 公式要求（技术类文章）
- 所有数学公式使用 LaTeX 格式
- 每个公式后面必须配“大白话翻译”

请写出完整的文章初稿，约{目标字数}字。
```

### 景气投资类文章专用Prompt扩展

当主题为景气投资类时，在作者Agent的Prompt中**追加**以下内容：

```markdown
## 景气投资类文章的特别要求

你正在写一篇**景气投资（GARP）**框架下的分析文章。

### 分析框架
采用四位景气大师的视角：

1. **林奇（常识与PEG）**：
   - 这家公司属于六类中的哪一类？（快速增长型/稳定增长型/周期型等）
   - PEG是多少？<1.2是合理买入区间吗？
   - 用生活常识验证：你/用户用过这家公司的产品吗？

2. **郑希（ROE与景气）**：
   - ROE趋势向上还是向下？拐点到了吗？
   - 产业景气在什么位置？渗透率10~30%黄金区？
   - 增速二阶导（增速加速度）是正是负？

3. **李进（管理层与治理）**：
   - 管理层诚信吗？承诺兑现率如何？
   - 科研转化效率如何？（科技/医药企业）
   - 地缘政治风险可控吗？

4. **欧奈尔（纪律与趋势）**：
   - 止损位设在哪里？8~10%是生存红线
   - 趋势信号确认了吗？

### 文章结构（景气投资类）
1. **开头钩子**：用估值/景气数据冲击开场（如“PEG从0.8涨到1.6，该卖了吗？”）
2. **生意本质**：一句话说清楚这家公司靠什么赚钱（林奇测试：10分钟能解释清吗？）
3. **景气验证**：ROE趋势、渗透率、二阶导（郑希/李进视角）
4. **估值判断**：PEG为核心，给出操作区间（林奇视角）
5. **风险与纪律**：管理层、地缘政治、止损位（李进/欧奈尔视角）
6. **结论**：持有/加仓/减仓/清仓 + 核心理由
```

## 阶段四：定稿

### 第一步：综合两个Agent的反馈

重点关注以下高频问题：

| 问题类型 | 编辑常见反馈 | 读者常见反馈 | 处理方式 |
|---------|------------|------------|---------|
| 开头太弱 | 钩子不够强 | 前3段没动力继续 | 用数据/反直觉结论重写开头 |
| 技术/估值段劝退 | 公式/PEG计算太密集 | 某段需要重读3遍 | 删公式或加更直觉的类比 |
| 节奏拖沓 | 某节太长 | 某处失去耐心 | 合并或删减 |
| 结尾无力 | 缺传播力 | 不会转发 | 重写为一句可截图传播的判断 |
| **景气投资类特有** | 卖出纪律不够具体 | “不知道该卖还是该买” | 明确PEG区间和止损位 |

### 第二步：执行修改

根据反馈重写文章。核心修改原则：

1. **编辑和读者都指出的问题，必须改**
2. **只有编辑指出的问题，大概率要改**
3. **只有读者指出的问题，视情况改**
4. **两者矛盾时，偏向读者**

### 第三步：提取配图

#### 论文解读类文章

必须在定稿前完成配图提取：

1. **渲染**：`pdftoppm -png -r 900 -f {页码} 论文.pdf /tmp/page`（900 DPI起步）
2. **定位**：先用150 DPI渲染全页，目视确认各图表的像素坐标
3. **裁切**：用 PIL 按坐标裁切，确保每张 ≥ 500KB
4. **存储**：保存到 `assets/{主题简称}/` 目录
5. **插入**：文章中用 `![描述](../../assets/{主题简称}/fig{序号}.png)` 引用

#### 景气投资类文章

如需配图（估值图表、趋势图等），可使用以下方式：

1. **数据可视化**：使用工具生成图表（如matplotlib），保存为PNG
2. **网络搜索图片**：搜索相关图表，下载后保存到 `assets/{主题简称}/` 目录

### 第四步：产出最终文件

将定稿保存为 md 文件，文件末尾附上参考资料链接：

```markdown
**参考资料：**
- {资料名称}: {链接}
- {报告名称}: {链接}

**风险提示与免责声明：**
本文内容基于公开信息和投资研究框架，不构成任何投资建议。市场有风险，投资需谨慎。文中提及的任何具体公司、估值指标或操作规则均不构成买卖依据。
```

## 注意事项

1. **不虚构数据**。引用的数据必须有来源，搜不到就标注“估计”
2. **不用AI腔调**。禁止“让我们一起来看看”、“不得不说”等套话
3. **不过度承诺**。技术文章不说“颠覆性的”，用数据说话
4. **公式必须配大白话**。每个公式后面都要有“翻译成人话就是……”
5. **公式必须用LaTeX**。`$$...$$` 格式，禁止纯文本公式
6. **配图必须实际插入**。禁止用 `[图X]` 占位符
7. **类比要一以贯之**。全文用一个主线类比
8. **结尾必须有传播力**。最后一句话要值得被单独截图转发
9. **景气投资类文章的特别要求**：
   - PEG必须附计算依据和来源
   - 卖出纪律必须明确具体（止损位、PEG阈值）
   - 林奇六类分类不能跳过
   - 四位景气大师的视角应均衡体现
10. **客观性原则**。区分事实与观点，用数据支撑判断
11. **诚实面对信息缺口**。无法获取的信息明确标注“信息不足”

## 六类分类：快速增长型还是稳定增长型？

林奇的第一问：这家公司属于六类中的哪一类？

腾讯当前的增速（12%）已经从“快速增长型”（>20%）滑落至“稳定增长型”（10-20%）。这个分类变化本身就是一个信号——不同类型的股票，卖出逻辑完全不同。

林奇的核心工具：PEG = PE ÷ 增速
