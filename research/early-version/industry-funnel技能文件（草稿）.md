## 一、兼容性诊断与冲突化解

```
针对长期价值投资的ndustry-funnel 的漏斗筛选流程（全市场→粗筛→精细→终选→深度分析）在架构上与 1-3 年景气投资完全兼容，但原草稿在决策逻辑与风控维度上存在结构性错配。以下是核心冲突与完善方案：
```

```
| 冲突维度 | 原草稿/通用漏斗逻辑 | 1-3年景气投资核心要求 | 完善方案/化解策略 |
```

```
|---|---|---|---|
```

```
| 思维模式 | 偏重巴菲特/芒格/段永平（长坡厚雪、商业模式） | 需兼顾欧奈尔（信号）、林奇（常识）、郑希（产业周期）、李进（回撤控制） | 引入四位大师思维模式，在深度分析环节强制四视角交叉验证。 |
```

```
| 筛选指标 | 侧重财务质量与护城河 | 需前置产业景气度与地缘政治风险 | 粗筛阶段新增“产业景气度”硬指标；全市场扫描增加“地缘政治初筛列”。 |
```

```
| 管理层评估 | 定性原则为主（5条） | 需量化4维度20分制 + 科研转化20分制 | 深度分析环节植入标准化打分表，<15分一票否决或限制仓位。 |
```

```
| 估值体系 | 绝对估值或历史分位 | 需PEG五档阈值 + 分批建仓纪律 | 估值快评强制使用PEG锚定，明确<0.8至>2.0的仓位应对策略。 |
```

```
| 卖出逻辑 | 单一基本面或价格触发 | 需三级优先级（基本面>估值>性价比） | 建立卖出决策金字塔，基本面恶化立即清仓，估值透支仅卖机动仓。 |
```

```
| 止损纪律 | 模糊的“逻辑证伪” | 需硬止损(8-10%) + 逻辑止损 + 时间止损 | 引入“仓位状态变量”决策表，区分左侧布局与右侧重仓的止损标准。 |
```

```
| 持仓结构 | 集中或分散二选一 | 需3+2结构 + 底仓/机动仓分离 | 终选3家为底仓(60-80%)，机动仓(20-40%)做波段，明确分离管理规则。 |
```

## 二、漏斗结构总览：1-3年景气投资版

```
本体系采用“宽口扫描** → 硬指标粗筛 → 四大支柱精析 → 大师视角终选 → 动态组合输出”的五步漏斗：

第一步：全市场扫描（渗透率 + 地缘初筛 + 景气赛道锁定）

第二步：6条硬指标粗筛（景气度 + 财务 + 估值 + 流动性 + 治理底线 + 地缘红线）

第三步：四大支柱精细分析（产业/公司/治理/环境 + PEG估值 + 假如空仓测试）

第四步：四位大师深度研判（欧奈尔/林奇/郑希/李进 + 量化打分 + 矛盾化解 + 决策金字塔）

第五步：综合输出与执行**（3+2组合 + 底仓/机动分离 + 止损纪律 + 季度复盘）
```

## 三、第一步：全市场扫描

```
目标：从全市场 5000+ 标的中，快速锁定 50-100 个潜在景气赛道及核心标的。
执行动作： 1. 赛道锁定：基于郑希“第一性原理”，寻找渗透率在 5%~20% 爆发区间的产业。 2. 地缘初筛：快速标记高海外收入依赖、供应链单一、潜在制裁清单标的。 3. 数据输出：
```

```
| 代码 | 名称 | 所属赛道 | 产业渗透率(估) | 海外收入占比 | 供应链风险等级 | 初步结论 |
```

```
|---|---|---|---|---|---|---|
```

```
| 300XXX | 某光模块 | AI算力 | 12% | 85% | 高(依赖美芯) | 观察/对冲 |
```

```
| 600XXX | 某电网设备 | 出海基建 | 8% | 45% | 中(本地化强) | 入池 |
```

> ```
> ⚠️ 注意：此阶段不求精准，但求不遗漏与快速排雷。渗透率数据允许 ±3% 误差，但趋势必须向上。
> ```

## 四、第二步：6条硬指标粗筛

```
目标：从 50-100 个标的中，筛选出 10-20 个进入精细分析池。
6条硬指标： 1. 产业景气度：季度营收增速 > 20% 或 行业高频数据（排产/价格）连续2月环比向上。 2. 财务健康：经营性现金流净额/净利润 > 0.7（或合理理由如高资本开支期）。 3. 估值底线：PEG < 2.0（防止在泡沫期入场）。 4. 流动性：日均成交额 > 5000万（确保机动仓进出无滑点）。 5. 治理底线：无立案调查、无大额违规担保、审计意见非非标。 6. 地缘红线：非实体清单核心制裁对象，或已有成熟“华为式”抗封锁方案。
放宽条件说明： * 若产业景气度极强（如渗透率<5%的0-1阶段），可放宽“财务健康”至现金流为负，但需郑希视角确认“烧钱换市场”逻辑。 * 若治理有瑕疵但非致命（如小额诉讼），需管理层评估得分 ≥ 18分方可豁免。
```

## 五、第三步：四大支柱精细分析

```
目标：对 10-20 个标的进行标准化体检，输出《精细分析单》。
```

### 1\. 四大支柱交叉验证

```
| 支柱 | 核心问题 | 关键验证点 |
```

```
|---|---|---|
```

```
| 产业景气度 | 景气是β还是α？能持续多久？ | 渗透率曲线位置、供需缺口测算、技术迭代路线 |
```

```
| 公司基本面 | 竞争优势是否可量化？ | 市场份额变化、毛利率趋势、研发转化效率 |
```

```
| 管理层与治理 | 是否利益一致？是否有能力？ | 4维度20分制评估、过往承诺兑现率 |
```

```
| 地缘与环境 | 外部冲击是否致命？ | 六维度地缘评估、政策合规成本、本地化产能 |
```

### 2\. 地缘政治六维度评估（华为式韧性）

```
海外收入依赖度：>50% 扣分，但有非美市场分散加分。
供应链安全：核心零部件国产化率、备货周期。
制裁清单风险：是否在SDN/Entity List边缘？
本地化对冲能力：海外工厂/研发中心布局、法律合规团队。
政策合规环境：数据跨境、ESG标准、反垄断风险。
“华为式”抗封锁韧性：是否有“备胎计划”？极限生存测试报告？
```

### 3\. 估值快评：PEG五档阈值

```
| PEG区间 | 估值状态 | 操作指引 |
```

```
|---|---|---|
```

```
| < 0.8 | 显著低估 | 右侧重仓或左侧大底仓，分批买入 |
```

```
| 0.8 ~ 1.2 | 合理 | 正常建仓，持有 |
```

```
| 1.2 ~ 1.5 | 偏贵 | 仅底仓持有，禁止加仓，机动仓准备止盈 |
```

```
| 1.5 ~ 2.0 | 高估 | 逐步卖出机动仓，底仓设移动止盈 |
```

```
| > 2.0 | 严重透支 | 清仓机动仓，底仓设严格止损，不再看多 |
```

### 4\. “假如空仓”测试

> ```
> 灵魂拷问：“如果我现在持有现金，以当前价格、当前基本面，我还会买入这只股票吗？” * YES → 继续持有/加仓。 * NO → 无论盈亏，必须减仓或清仓（这是克服沉没成本的最强工具）。
> ```

## 六、第四步：四位大师深度研判

```
目标：对精细分析池前 5 名进行终极决策，选出 3 家底仓 + 2 家机动仓候选。
```

### 1\. 四位大师思维模式

```
欧奈尔（工程师）：看信号与纪律。技术面是否突破？RPS强度？止损位是否明确？
林奇（侦探）：看常识与求证。产品是否好用？身边人是否在用？财报是否有“猫腻”？
郑希（物理学家）：看第一性原理。产业周期位置？技术路线是否被颠覆？渗透率斜率？
李进（系统工程师）：看均衡与回撤。组合相关性？极端情景下的最大回撤？仓位上限？
```

### 2\. 管理层评估：4维度20分制

```
| 维度 | 分值 | 核心考察点 | 一票否决项 |
```

```
|---|---|---|---|
```

```
| 诚信品格 | 5分 | 历史信披、关联交易、个人操守 | 财务造假、实控人涉刑 |
```

```
| 股东态度 | 5分 | 分红/回购、再融资摊薄、市值管理 | 长期不分红且无合理理由 |
```

```
| 战略执行力 | 5分 | 目标达成率、战略定力、纠偏能力 | 连续3年战略方向摇摆 |
```

```
| 稳定性激励 | 5分 | 核心团队流失率、激励方案合理性 | 核心技术人员批量离职 |
```

> ```
> 决策线：总分 ≥15分 方可重仓；<12分 直接剔除。
> ```

### 4\. 四大矛盾化解方案

```
| 矛盾场景 | 冲突点 | 化解方案 |
```

```
|---|---|---|
```

```
| 买点哲学冲突 | 欧奈尔要突破买，林奇要低估买 | 杀估值（PEG<0.8）→ 林奇左侧买；杀逻辑（景气证伪）→ 欧奈尔止损 |
```

```
| 持有时间冲突 | 郑希看3年周期，欧奈尔看3月趋势 | 连续3季度数据：趋势向上→郑希持有；连续2季下滑→欧奈尔减仓 |
```

```
| 止损 vs 越跌越买 | 李进要控回撤，林奇要逆向 | 引入仓位状态变量：底仓<30%且逻辑未坏→越跌越买；底仓>60%或逻辑微瑕→硬止损 |
```

```
| 分散 vs 集中 | 李进要分散，郑希要集中 | 3+2结构：3家核心（单只≤25%），2家卫星（单只≤10%），总仓位≤80% |
```

### 6\. 止损与越跌越买：仓位状态决策表

```
| 仓位状态 | 跌幅 | 逻辑状态 | 操作 |
```

```
|---|---|---|---|
```

```
| 底仓 < 30% | -8% | 逻辑完好，仅情绪杀 | 越跌越买（补至40%） |
```

```
| 底仓 > 50% | -8% | 逻辑完好，仅情绪杀 | 持有，观察企稳信号 |
```

```

```

```
| 任意仓位 | 任意 | 逻辑证伪（如技术路线被替代） | 立即清仓（不等反弹） |
```

```
| 持有 > 4季度 | 横盘 | 逻辑未兑现 | 时间止损（调仓换股） |
```

### 2\. 底仓/机动仓分离管理

```
底仓** (60%~80%)：

来源：郑希/林奇视角确认的产业趋势+李进确认的回撤可控。

操作：长持，忽略短期波动，仅在基本面恶化或PEG>2.0时卖出。

考核：年度收益率 + 最大回撤控制。

机动仓 (20%~40%)：

来源：欧奈尔视角的技术突破 + 估值合理区间。

操作：波段，PEG>1.5** 分批止盈，硬止损 坚决执行。
考核：绝对收益 + 胜率。
```

### 3\. 左侧布局 vs 右侧重仓策略

```
| 阶段 | 特征 | 策略 | 仓位上限 |
```

```
|---|---|---|---|
```

```
| 左侧布局 | 渗透率<5%，估值合理，逻辑未完全验证 | 小仓试探，越跌越买（需仓位状态表支持） | 30% |
```

```
| 右侧确认 | 渗透率5-20%，业绩兑现，技术突破 | 重仓出击，分批买入（1/3→1/3→1/3） | 60% |
```

```
| 高潮/透支 | 渗透率>30%，PEG>1.5，情绪亢奋 | 只卖不买，机动仓止盈，底仓设移动止盈 | 80%→降仓 |
```

### 4\. 常见估值陷阱提醒

```
低PE陷阱：周期顶点利润爆发，PE极低，但景气即将反转（用郑希视角看周期位置）。
高PE但增速不可持续：一次性收益或会计调整，非核心业务增长（用林奇视角看扣非/现金流）。
忽略股权稀释：频繁定增/可转债，EPS增长但每股价值下降（用李进视角看摊薄后PEG）。
```

### 5\. 每季度复盘检查清单

```
景气度：渗透率是否按预期提升？高频数据是否验证？
基本面：营收/利润增速是否匹配？毛利率是否稳定？
管理层：4维度打分是否有变化？是否有新的治理瑕疵？
地缘政治：制裁/政策是否有新变化？对冲措施是否有效？
估值：当前PEG处于哪一档？是否触发卖出条件？
假如空仓：现在还会买吗？
止损记录：本季度是否有触发止损但未执行的情况？原因？
```

### 6\. 能力圈声明

> ```
> 本体系仅适用于： 1. 有明确产业渗透率曲线、可跟踪高频数据的成长/周期成长行业。 2. 持有周期 1-3年，能容忍 15-20% 阶段性回撤。
> ```

> ```
> 不适用： 1. 纯红利/深度价值（无景气驱动）。 2. 纯主题炒作/无业绩支撑的概念股。 3. 无法获取产业数据/地缘信息不透明的标的。
> ```
