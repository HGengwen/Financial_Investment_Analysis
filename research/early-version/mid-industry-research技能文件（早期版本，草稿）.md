# 中期行业景气深度研究：四维赛道选择 + 景气周期定位 + 多技能联动

对 $ARGUMENTS 行业进行系统性中期景气研究，输出"景气阶段 + 渗透率位置 + 头部公司 + 地缘风险 + 隐含增速验证"五维判断。

## 设计理念

在1~3年的中期投资中，**选赛道比选个股更重要**。郑希强调"ROE向上是科技股最可靠的'重力加速度'"，李进强调"渗透率突破15%后加速上行期重仓"。

本技能是中期投研闭环的**入口**，与长期 `industry-research` 的**本质区别**：

| 维度 | 长期 `industry-research` | **中期 `mid-industry-research`** |
|------|-------------------------|--------------------------------|
| **时间维度** | 10年永续经营 | **1~3年景气周期** |
| **核心框架** | 李录文明趋势判断 | **郑希/李进产业景气周期定位** |
| **估值锚** | DCF、护城河永续性 | **PEG、渗透率、增速加速度** |
| **关键追问** | "10年后护城河还在吗？" | **"未来4个季度订单能见度如何？"** |
| **卖出指引** | 护城河崩塌 | **渗透率减速/ROE拐头/时间止损** |

**四位大师在中期行业研究中的角色**：

| 大师 | 核心贡献 | 在本技能中的体现 |
|------|---------|----------------|
| **郑希** | 全球产业链景气追踪 + ROE拐点判断 | 行业景气周期定位的核心框架 + 全球产业链利润分配视角 |
| **李进** | 渗透率坐标 + 二阶导思维 | 渗透率15%临界点 + 50%兑现线 + 增速加速度 |
| **林奇** | 产业链全景扫描 + 常识化验证 | 行业全景图 + 经营验证 + GARP估值匹配 |
| **欧奈尔** | 行业景气信号 + 龙头股识别 | CAN SLIM行业版 + 抛售日识别 + 买入时机 |

**核心理念**：用产业景气定方向，用渗透率定位阶段，用订单验证兑现，用地缘政治控风险，用implied-growth验证估值合理性。

## 执行流程

### 第一步：赛道选择——四维筛选验证

基于理念文档 V2.0 第一部分"第1步：赛道选择"，从四个维度验证行业是否具备1~3年投资价值。

#### 维度一：产业空间（TAM ≥ 1000亿，复合增速 ≥ 20%）

| 检查项 | 数据来源 | 通过标准 |
|--------|----------|----------|
| 行业潜在市场规模（TAM） | 券商深度研报、行业协会数据 | ≥ 1000亿元 |
| 未来3年复合增速（CAGR） | 第三方行业预测、上市公司招股书 | ≥ 20% |
| 市场空间可验证性 | 至少2个独立来源交叉验证 | 数据一致性 > 80% |

**搜索命令**：

```bash
# 搜索行业规模与增速
python tools/common/anysearch.py "{行业名} 行业规模 市场规模 2026" --tag finance
python tools/common/doubao_search.py "{行业名} 行业规模 增速 预测" --finance --need-content
python tools/common/anysearch.py "{行业名} TAM 市场规模 预测" --tag finance

# 搜索券商深度研报（含市场空间测算）
python tools/common/anysearch.py "{行业名} 深度研报 市场空间" --tag finance
```

**处理逻辑**：

| 场景 | 判断 | 处理 |
|------|------|------|
| TAM ≥ 1000亿 且 CAGR ≥ 20% | ✅ 通过 | 进入下一维度 |
| TAM < 1000亿 或 CAGR < 20% | ⚠️ 不达标 | 标注"市场规模或增速不足，降低优先级" |
| 数据来源冲突（差异>30%） | ⚠️ 需核实 | 列出所有来源及差异，标注"需人工判断" |

#### 维度二：渗透率位置（10%~30% 黄金区）

渗透率是李进框架的核心坐标：**15%是加速临界点，50%是兑现分水岭**。

| 渗透率区间 | 评级 | 含义 | 投资策略 |
|-----------|------|------|----------|
| < 5% | 🔴 过早 | 不确定性极高，技术路线尚未清晰 | 不参与，保持观察 |
| 5%~10% | 🟡 萌芽期 | 开始有商业化验证，但风险仍高 | 少量观察仓，仅限高风险承受者 |
| **10%~30%** | 🟢 **黄金区** | 加速突破临界点，确定性+弹性兼备 | **积极布局，重仓参与** |
| 30%~50% | 🟡 成长期 | 增速仍快但边际放缓 | 持有为主，机动仓逐步兑现 |
| > 50% | 🔴 成熟期 | 增速明显放缓，估值中枢下移 | 逐步退出，仅保留底仓 |

**搜索命令**：

```bash
# 搜索渗透率数据
python tools/common/anysearch.py "{行业名} 渗透率 2026" --tag finance
python tools/common/doubao_search.py "{行业名} 渗透率 提升 趋势" --finance --need-content

# 搜索第三方专业数据（新能源车/光伏/AI等）
python tools/common/anysearch.py "{行业名} 装机率 应用率 渗透" --tag finance
```

**渗透率数据质量标注**：

| 数据来源 | 置信度 | 标注 |
|----------|--------|------|
| 行业协会官方数据 | A级 | ✅ 高置信度 |
| 券商研报引用第三方数据 | B级 | ⚠️ 中等置信度 |
| 媒体估算/专家访谈 | C级 | ⚠️ 低置信度，需交叉验证 |

**处理逻辑**：

```
IF 渗透率 > 30%:
    → 标注"已过黄金区，增速可能边际放缓"
    → 检查是否有第二增长曲线（新产品/新市场）
    → 若无第二曲线，仅作为防御型配置

IF 渗透率 < 5%:
    → 标注"尚在萌芽期，技术路线不确定"
    → 建议不参与或极小仓位观察

IF 渗透率 10%~30%:
    → ✅ 进入黄金区，积极关注
```

**二阶导验证**（李进"增速的加速度"思维）：
- 不仅看渗透率绝对值，还需判断渗透率的**变化速度**（二阶导）
- 渗透率加速上行（二阶导为正）→ 景气仍在扩散
- 渗透率减速上行（二阶导转负）→ 接近增速峰值，需警惕
- 搜索行业渗透率的季度变化数据，计算加速度方向

#### 维度三：业绩兑现度（连续2个季度验证）

**核心原则**：李进强调"产业趋势必须有订单、收入、利润的客观数据支持，否则一律视为题材炒作"。

| 验证维度 | 数据来源 | 通过标准 |
|----------|----------|----------|
| 营收增速 > 行业平均 | 头部公司季报 | 连续2个季度 |
| 毛利率稳定或提升 | 头部公司季报 | 连续2个季度 |
| 行业整体盈利 | 多家公司季报 | 龙头已盈利，二线扭亏 |
| 利润增速 vs 营收增速匹配度 | 头部公司季报 | 利润增速跟上营收增速，否则警惕费用失控 |

**搜索命令**：

```bash
# 搜索头部公司最新季报数据（详见 qoq-accelerator 技能）
python tools/a_share/stock_financial.py --code {龙头代码} --indicator 营业总收入,归母净利润,毛利率
python tools/a_share/stock_financial.py --code {龙头代码} --advanced  # 合同负债/存货/研发费用等先行指标

# 搜索行业整体盈利情况
python tools/common/anysearch.py "{行业名} 行业盈利 情况 2026" --tag finance
python tools/common/doubao_search.py "{行业名} 上市公司 业绩 情况" --finance --need-content
```

**判断逻辑**：

| 场景 | 判断 | 处理 |
|------|------|------|
| 营收增速>行业平均 + 毛利率稳定 + 利润匹配 | ✅ 强兑现 | 行业进入实质业绩释放期 |
| 营收增速>行业平均 + 毛利率下降 | ⚠️ 弱兑现 | 增收不增利，需关注成本端 |
| 营收增速>行业平均 + 利润增速远<营收增速 | ⚠️ 费用失控 | 警惕"增收不增利"陷阱 |
| 营收增速<行业平均 | 🔴 未兑现 | 需验证"行业增速"数据是否准确 |
| 无头部公司财报或均为亏损 | 🔴 题材炒作 | 标注"纯概念阶段，无业绩支撑" |

**先行指标验证**（增强业绩兑现判断的前瞻性）：

| 先行指标 | 含义 | 数据来源 |
|----------|------|----------|
| 合同负债环比变化 | 预示未来收入确认 | `stock_financial.py --advanced` |
| 存货环比变化 | 预示生产备货节奏 | `stock_financial.py --advanced` |
| 研发费用环比变化 | 预示未来产品迭代 | `stock_financial.py --advanced` |

- 合同负债环比增长 → 未来收入确认加速的先行信号
- 存货合理增长 → 企业在为未来订单备货，景气可持续
- 研发费用持续增长 → 企业对未来有信心，愿意持续投入

#### 维度四：地缘政治风险敞口

基于理念文档 V2.0 "支柱四"的地缘政治评估框架，含"华为式"抗封锁韧性评估：

| 评估维度 | 检查项 | 数据来源 |
|----------|--------|----------|
| **海外收入依赖度** | 行业整体海外收入占比；出口导向型赛道需单独测算海外市场风险敞口 | 券商研报/行业协会 |
| **供应链安全** | 关键零部件/原材料进口依赖度；"卡脖子"环节越集中，断供风险越高 | 产业链分析报告 |
| **制裁与清单风险** | 是否已被/可能被列入实体清单、未经核实清单，或面临加征关税、反倾销/反补贴调查 | 商务部/海关公告 |
| **本地化对冲能力** | 是否有海外建厂、本地化运营、多元供应链来对冲关税与管制 | 企业公告/新闻报道 |
| **政策与合规环境** | 目标市场的数据安全、ESG、外资准入、技术出口管制等监管变化 | 政策跟踪 |
| **自主研发能力与抗压韧性（"华为式"抗封锁能力）** | 当外部封锁不可避免时，行业/头部企业能否凭借强大研发体系实现技术自主与替代 | 年报/专利数据/行业分析 |

**"华为式"抗封锁韧性评估**（理念文档 V2.0 新增维度）：

> 参考华为案例：连续多年遭遇实体清单与芯片断供，但凭借长期高研发投入（研发费用率常年>15%）与"备胎转正"，从芯片到操作系统再到数据库、EDA等底层根技术实现自主突破。

| 评估子项 | 检查方法 | 评分影响 |
|----------|----------|----------|
| ①研发投入强度与持续性 | 行业/头部研发费用率是否长期维持高位且逆周期不减 | 研发强度>15%且逆周期不减 → 强韧性 |
| ②核心技术自主可控程度 | 是否掌握底层专利、源代码、工艺与关键设备，而非仅做集成组装 | 底层自主 → 强韧性；仅集成组装 → 弱韧性 |
| ③"备胎计划"与替代方案 | 关键环节被断供时，是否有自研替代路线 | 有替代路线 → 韧性加分 |
| ④极端情形生存能力 | 被列入制裁清单后，能否依靠国内/替代市场维持现金流并继续投入研发 | 可维持 → 韧性加分 |

**地缘政治综合评级**：

| 评级 | 条件 | 对估值的修正 |
|------|------|-------------|
| 🟢 低风险 | 海外收入<30% + 供应链可控 + 无制裁风险 + 抗封锁韧性强 | 无修正 |
| 🟡 中风险 | 海外收入30%~50% + 有对冲措施 + 有一定抗封锁能力 | 估值折价-10%~20% |
| 🔴 高风险 | 海外收入>50% + 无对冲 + 存在制裁风险 + 抗封锁能力弱 | **降低行业优先级**，估值折价-20%~40% |

> **示例（车企）**：以整车出口为例，地缘政治可同时冲击**市场端**（欧盟反补贴关税抬高售价、压缩销量与利润）、**供应链端**（车规芯片与高端材料的进口依赖）与**合规端**（数据安全与本地化要求）。评估时需把这三类冲击对营收、成本与估值的边际影响量化后，折入估值判断。

### 第二步：产业链全景图绘制

绘制完整的产业链结构图，识别"卡脖子环节"（中期投资中供给最紧张、替代最难、利润率最高的环节）。

**产业链拆解格式**：

```
上游：原材料/资源 → 材料加工/提纯
  ↓
中游：核心设备制造 → 系统集成/工程建设 → 新技术研发
  ↓
下游：运营/服务 → 终端客户
  ↓
辅助：检测/认证 → 维护服务 → 金融工具（ETF/信托）
```

**全球产业链利润分配视角**（郑希框架）：

> 科技产业链是全球分工的。不同环节的利润率差异巨大——如AI算力中，美股GPU（英伟达）、A股光模块（中际旭创）、港股ASIC设计的利润占比各不相同。哪个环节ROE率先向上，就优先配置哪个。

| 产业链环节 | 全球利润分配占比 | ROE趋势 | 中国公司竞争力 | 配置优先级 |
|-----------|----------------|---------|--------------|-----------|
| 上游（核心材料/芯片） | 待评估 | 待评估 | 待评估 | 待评估 |
| 中游（制造/集成） | 待评估 | 待评估 | 待评估 | 待评估 |
| 下游（应用/服务） | 待评估 | 待评估 | 待评估 | 待评估 |

**卡脖子环节识别**（6条标准）：

| 标准 | 检查方法 | 数据来源 |
|------|----------|----------|
| 供给集中度 ≤ 2家 | 市场份额分析 | 行业报告 |
| 扩产周期 > 2年 | 行业投资回报周期 | 产业链分析 |
| 替代难度高 | 技术壁垒/专利分析 | 搜索工具 |
| 产能利用率 > 80% | 头部公司订单情况 | 季报/调研 |
| 需求增速 > 30% | 下游行业增速 | 行业数据 |

### 第五步：产业景气周期定位（替代李录文明趋势框架）

**这是中期 `mid-industry-research` 与长期 `industry-research` 最关键的区分点**——不分析"10-20年终局"，而是定位"1-3年景气周期位置"。

**景气周期四阶段判断**：

| 阶段 | 特征 | 渗透率位置 | 投资策略 |
|------|------|-----------|----------|
| **技术跃迁期** | 新技术突破、新应用场景涌现、供给创造需求 | 5%~15% | 积极布局，关注技术路线选择 |
| **需求爆发期** | 订单爆发式增长、供给紧缺、价格上行 | 10%~20% | **重仓参与**，ROE向上斜率最陡 |
| **供给受限期** | 产能瓶颈、扩产周期长、价格维持高位 | 20%~35% | 持有为主，关注产能释放进度 |
| **成熟稳定期** | 增速放缓、竞争加剧、价格下行 | >40% | 逐步兑现，机动仓退出 |

**"供给创造需求"视角**（郑希框架）：

> 传统周期通胀来自供需错配；科技成长的景气，来自新技术落地创造全新需求（如AI大模型对算力的需求、新能源车对充电桩的需求），爆发力更强。评估行业是否属于"供给创造需求"类型：若是，则景气持续性和爆发力可能超出传统周期预判。

**判断逻辑**：

```bash
# 搜索行业景气度信号
python tools/common/anysearch.py "{行业名} 景气度 订单 供需" --tag finance
python tools/common/doubao_search.py "{行业名} 需求 增速 2026" --finance --need-content

# 搜索产能和供给情况
python tools/common/anysearch.py "{行业名} 产能 扩产 供需缺口" --tag finance
```

**ROE拐点判断**（基于郑希框架）：

```bash
# 获取头部公司ROE趋势
python tools/a_share/stock_financial.py --code {龙头代码} --indicator ROE
```

| ROE趋势 | 判断 | 含义 |
|---------|------|------|
| 连续3季度向上 | 🟢 ROE拐点已确认 | 景气上行，积极配置 |
| 季度波动但整体向上 | 🟡 趋势尚可 | 关注，可配置 |
| 连续3季度向下 | 🔴 ROE拐点向下 | 景气下行，需警惕 |
| 无明显方向 | 🟡 平缓 | 等待确认，轻仓参与 |

> **矛盾化解——"单季噪音 vs 趋势拐点"**：以**连续3个季度数据趋势**区分波动与拐点。单季ROE波动不判拐点，仅连续3季同向变化才确认趋势。此规则与 `qoq-accelerator` 技能的判定逻辑一致。

### 第六步：组合配置建议

基于行业景气周期定位，输出配置建议：

| 资产类型 | 仓位比例 | 适用场景 |
|----------|----------|----------|
| **行业ETF** | 20%~40% | 不想选股的"懒人方案" |
| **龙头白马（Tier 1）** | 30%~50% | 核心仓位，确定性最高 |
| **成长黑马（Tier 2）** | 15%~25% | 卫星仓位，弹性较大 |
| **期权标的（Tier 3）** | 5%~15% | 高风险高回报 |

**行业仓位上限建议**（对齐理念文档"单一行业不超过总资产的40%"）：

| 景气周期阶段 | 建议行业仓位上限 | 说明 |
|-------------|-----------------|------|
| 需求爆发期/技术跃迁期 | 40% | 可重仓参与 |
| 供给受限期 | 25% | 持有为主，适度配置 |
| 成熟稳定期 | 15% | 逐步退出 |

**底仓/机动仓配置参考**（对齐理念文档"底仓60%~80%、机动仓20%~40%"）：

| 配置项 | 比例 | 操作规则 |
|--------|------|----------|
| 底仓（景气确认后的核心持仓） | 60%~80% | 只要景气逻辑未破坏，不因短期波动卖出 |
| 机动仓（估值波段） | 20%~40% | PEG>1.5减持，回落至合理区间回补 |

**分批建仓规则**（对齐理念文档第150行"合理买入区间先建1/3底仓"）：
1. 当行业进入黄金区且估值合理时，先建 **1/3 底仓**
2. 若市场恐慌或行业短暂利空（逻辑未破坏），再加 **1/3**
3. 确认产业景气加速或财报超预期后，补齐剩余 **1/3**

> **矛盾化解——"止损 vs 越跌越买"**：
> - 建仓初期（持仓<最终仓位的50%）：若下跌超过8%，按欧奈尔规则**止损优先**
> - 底仓已建立且逻辑已验证（持仓≥50%）：若三维度（产业/管理层/财务）均未恶化，可在估值下限加仓
> - 无论何种状态，逻辑被证伪 → 立即清仓，不存在"越跌越买"
> - **核心原则**：杀估值可逆向，杀逻辑必须止损

### 第七步：卖出条件预览（对齐 exit-signal V1.0 P0~P5 六级）

**这是中期行业研究必须包含的模块**——明确列出该行业在什么条件下应卖出/减仓，严格对齐 `exit-signal` V1.0 的六级优先级 P0~P5。

> **阈值口径说明**：PEG 阈值在本技能中与 `valuation-thermometer` V1.0、`exit-signal` V1.0 保持一致的五档标准：<0.8 显著低估 / 0.8~1.2 合理 / 1.2~1.5 偏贵 / >1.5 高估 / >2 严重透支。理念文档 V2.0 对 PEG 阈值有三处表述（第一部分"<1低估"、第三部分"0.8~1.2合理"、备忘卡"<1.2买入"），以第三部分"0.8~1.2合理区间"为主锚。

| 级别 | 触发条件 | 操作 | 思想来源 | 检查顺序 |
|------|----------|------|----------|----------|
| **P0 治理一票否决** | 行业龙头出现管理层诚信问题、财务造假实锤、监管立案 | **立即清仓**，不看估值趋势 | 李进（治理） | 最先检查 |
| **P1 硬止损** | 行业ETF或核心标的单笔亏损8%~10%，且无基本面反转信号 | **无条件止损** | 欧奈尔 | P0未触发后检查 |
| **P2 逻辑止损** | ①头部公司连续2季业绩低于预期且产业景气未改善；②持有满4季度逻辑未兑现（时间止损） | **减仓或清仓** | 林奇+郑希 | P1未触发后检查 |
| **P3 产业景气拐点** | ①渗透率增速转负或减速（二阶导转负）；②头部公司ROE连续3季度向下 | **减机动仓** | 李进+郑希 | P2未触发后检查 |
| **P4 估值透支** | ①行业整体PEG>1.5 → 减机动仓；②行业整体PEG>2 → 加速清机动仓 | **减/清机动仓** | 林奇 | P3未触发后检查 |
| **P5 性价比替换** | 发现其他行业PEG显著更低且产业趋势更强 | **调仓**（每季度最多1次） | 机会成本 | 最后检查 |

**执行顺序**：从 P0 到 P5 依次检查，命中即停止，输出对应动作。禁止跳过 P0。

**与 exit-signal 联动**：
- 本报告中的卖出条件预览为行业级别的预警提示
- 个股级别的卖出信号需调用 `exit-signal --horizon mid` 执行完整的 P0~P5 检查
- 行业 P0 触发 → 该行业内所有持仓均触发个股级 P0 检查

### 第九步：implied-growth 交叉验证（新增）

**目标**：在行业层面，倒推当前行业整体估值隐含的未来增速要求，与实际景气增速进行交叉验证，判断行业估值是否已被市场合理定价。

#### 9.1 行业层面的隐含增速倒推

对行业头部公司的加权平均市值/估值，倒推所需的未来3年复合增速：

```bash

```

#### 9.2 红/黄/绿灯判定

| 灯色 | 条件 | 含义 | 操作建议 |
|------|------|------|----------|
| 🟢 绿灯 | 隐含增速 ≤ 行业实际预期增速 | 估值已被业绩增长覆盖，合理 | 积极配置 |
| 🟡 黄灯 | 隐含增速 > 行业实际预期增速但未超过2倍 | 估值偏高，需要超预期增长消化 | 谨慎配置，关注景气验证 |
| 🔴 红灯 | 隐含增速 > 行业实际预期增速的2倍 | 估值严重透支，需要不切实际的增长才能支撑 | 降低行业优先级，减仓 |

#### 9.3 与四维筛选的交叉

| 四维筛选结论 | implied-growth | 综合判断 |
|-------------|----------------|----------|
| 四维全部通过 | 🟢 绿灯 | ✅ 强烈推荐，行业基本面与估值均支持 |
| 四维全部通过 | 🟡 黄灯 | ⚠️ 基本面好但估值偏高，分批建仓 |
| 四维全部通过 | 🔴 红灯 | ⚠️ 基本面好但估值严重透支，等待回调 |
| 四维部分通过 | 🟢 绿灯 | ⚠️ 估值合理但基本面有瑕疵，轻仓试探 |
| 四维部分通过 | 🔴 红灯 | 🔴 回避，基本面与估值均不支持 |

## 矛盾化解方案（行业级别）

本技能在执行过程中需融入理念文档 V2.0 的四大矛盾化解方案：

### 矛盾一：买点哲学的根本对立（行业级别）

| 场景 | 欧奈尔信号 | 林奇/郑希/李进信号 | 化解方案 |
|------|-----------|-------------------|----------|
| 行业从高点回撤20%+，但渗透率仍在黄金区 | 趋势走坏，不抄底 | 好行业打折，买入窗口 | 以"逻辑是否完整"为分水岭：系统性恐慌+逻辑完好 → 分批左侧布局；基本面恶化 → 等待趋势明朗 |
| 行业突破新高，但渗透率>50% | 突破买入 | 已过黄金区 | 以渗透率为锚：渗透率>50% → 即使突破也不追涨，仅作机动仓参与 |

### 矛盾二：单季噪音 vs 趋势拐点

- **硬性规则**：单季度数据波动不判拐点，仅**连续3个季度**同向变化才确认趋势
- 行业ROE单季波动 → 标记为"噪音"，不改变景气周期定位
- 行业ROE连续3季向下 → 确认为"拐点"，触发 P3 预警

### 矛盾三：止损 vs 越跌越买（行业ETF级别）

| 仓位状态 | 行业ETF下跌8%时的决策 |
|----------|----------------------|
| 建仓初期（<最终仓位50%） | 止损优先，按欧奈尔规则离场 |
| 底仓已建且三维度未恶化 | 可在估值下限加仓（林奇逻辑） |
| 逻辑被证伪 | 立即清仓，不存在"越跌越买" |

### 矛盾四：分散 vs 集中

- 行业层面**分散**：持有3~5个不同景气阶段的行业
- 行业内部**集中**：每个行业只选 Tier 1/Tier 2 的2~3只龙头
- 总体遵循"3+2"结构：3只核心（各12%~15%）+ 2~3只卫星（各5%~8%）

## 决策优先级速查卡

> 当行业研究中遇到多位大师理念冲突时，按以下优先级从高到低决策：

| 优先级 | 触发条件 | 决策 | 思想来源 |
|--------|----------|------|----------|
| **P0 一票否决** | 行业龙头管理层失信、财务造假、监管立案 | 整个行业回避 | 李进（治理） |
| **P1 硬止损** | 行业ETF/核心标的亏损8%~10% | 无条件止损 | 欧奈尔 |
| **P2 逻辑止损** | 连续2季业绩低于预期 + 景气未改善；或满4季度未兑现 | 减仓或清仓 | 林奇+郑希 |
| **P3 景气拐点** | 渗透率减速/ROE连续3季向下 | 减机动仓 | 李进+郑希 |
| **P4 估值透支** | PEG>1.5减机动仓；PEG>2加速清 | 减/清机动仓 | 林奇 |
| **P5 性价比替换** | 其他行业PEG更低且趋势更强 | 调仓（每季最多1次） | 机会成本 |

**核心原则**：先保命（防造假/止损），再谈收益（景气/估值）。杀估值可逆向，杀逻辑必须止损。

```
  /trend-momentum-scan {标的}            ← 动量体检
  /qoq-accelerator {标的}                ← 加速度分析
  /mid-thesis-drift {标的} --horizon mid ← 漂移检测
        ↓
（触发卖出）→ /exit-signal --horizon mid ← 执行卖出
```

## 注意要点

### 1. 与长期 `industry-research` 的本质区别

| 维度 | 长期 | 中期（本技能） |
|------|------|---------------|
| **时间维度** | 10年永续经营 | **1~3年景气周期** |
| **核心框架** | 李录文明趋势判断 | **郑希/李进产业景气周期定位** |
| **关键术语** | "护城河""永续""终局" | **"渗透率""二阶导""ROE拐点""订单能见度"** |
| **卖出指引** | 护城河崩塌 | **渗透率>50%/ROE拐头/PEG>2** |

**禁止行为**：
- ❌ 在报告中出现"持有10年""永续经营""终局思维"等长期框架术语
- ❌ 用DCF模型评估爆发期科技行业（不适用）
- ❌ 忽视渗透率数据，仅凭"行业前景好"就推荐
- ❌ 跳过P0直接评估P1~P5（P0为一票否决，必须最先检查）
- ❌ LLM心算估值数值（必须通过 `financial_rigor.py` 工具）

### 2. 渗透率数据质量

| 场景 | 处理方式 |
|------|----------|
| 多个来源数据一致 | 采用平均值，标注A级置信度 |
| 来源数据不一致（差异>20%） | 列出各来源，标注"需人工判断" |
| 无法获取渗透率数据 | 标注"数据不足，暂不判定黄金区" |
| 渗透率数据仅有估算值 | 标注C级置信度，降低决策权重 |

### 3. 地缘政治风险评估

| 评估维度 | 数据来源 | 硬性红线 |
|----------|----------|----------|
| 海外收入占比 | 券商研报/行业协会 | >70% → 高风险，降低优先级 |
| 制裁清单风险 | 商务部/海关公告 | 已在实体清单且无抗封锁能力 → 回避 |
| 供应链依赖度 | 产业链分析 | 单一供应商占比>80% → 高风险 |
| 抗封锁韧性 | 年报/专利/行业分析 | 无底层自主+无备胎计划 → 弱韧性 |

### 4. 禁止LLM心算

所有数值计算**必须**通过工具完成，禁止LLM心算：

```bash
# 正确用法
python tools/common/financial_rigor.py peg --pe 25 --growth 32

# 错误用法
# "PEG = 25 / 32 = 0.78" ← 禁止手动计算
```

### 5. 行业研究的特殊偏见警惕

| 偏见类型 | 表现 | 应对 |
|----------|------|------|
| 龙头偏好 | 大公司资料多，AI天然倾向推荐龙头 | 刻意搜索小公司，评估是否有更好的风险回报比 |
| 成熟行业偏好 | 传统行业资料多，AI分析看起来"更确定" | 确定性来自商业模式，不来自研报数量 |
| 新兴行业低估 | 新兴行业资料少，AI分析偏保守 | 用"渗透率+订单"判断，而非"研报数量" |
| 上市偏好 | 只扫描上市公司，遗漏未上市关键玩家 | 必须标注"未上市关键玩家" |
| 地缘政治忽视 | 忽略供应链/制裁风险 | 必须完成六维地缘评估 + 抗封锁韧性评估 |

### 6. 多技能联动的注意事项

| 联动技能 | 注意事项 |
|----------|----------|
| `qoq-accelerator` | 行业加速度判断需基于多数头部公司，不能仅看单一龙头 |
| `trend-momentum-scan` | 背离时以基本面为准，技术面仅作时机辅助 |
| `valuation-thermometer` | 行业估值温度是头部公司的加权平均，非行业指数PE |
| `exit-signal` | 本报告仅做行业级预警，个股级卖出需单独调用 |
| `mid-thesis-drift` | 本报告的结论作为漂移检测的基线假设 |

## 局限性

1. **渗透率数据可得性**：部分新兴行业（如AI应用）渗透率数据不成熟，可能依赖估算
2. **行业边界模糊**：部分行业（如"AI算力"）跨多个子领域，产业链界定可能存在偏差
3. **地缘政治信息滞后**：制裁清单、关税政策等外部信息可能存在延迟
4. **全球扫描完整性**：日韩台欧等市场的公司可能因语言和资料限制被遗漏
5. **implied-growth 参数敏感性**：行业层面的合理PE、净利率等参数选择对结果影响较大，需交叉验证
6. **产业非线性风险**：高科技产业演进非线性，渗透率拐点可能迟迟不来或被证伪
7. **不构成投资建议**：本技能仅为行业研究工具，需结合其他技能综合决策
