## 三、通用设计：`--horizon` 参数化机制（两技能共用）

### 3.1 参数语义

| 参数 | 取值 | 行为 |
| --- | --- | --- |
| `--horizon` | 未指定 | **默认 `long`**，完全走现有流程，输出与增强前逐字一致 |
| `--horizon` | `long` | 显式长期，与未指定等价 |
| `--horizon` | `mid` | 切换中期规则（本 Sprint 新增的专节） |

### 3.2 SKILL.md 组织方式（零回归关键设计）

采用 **"顶部参数解析 + 文末中期专节"** 结构，**现有 long 正文一字不动**：

1. **顶部**：在"支持输入格式"之后，新增"## 参数说明"小节（约 10 行），说明 `--horizon mid|long`、默认值、以及 `mid` 时的跳转指令；
2. **第零步**：在原"第一步"之前，插入"第零步：解析 horizon 参数"——若为 `mid` → 跳转至文末"中期模式"专节；否则 → 继续原有流程；
3. **文末**：新增"## 中期模式（--horizon mid）"完整专节，承载全部中期分支内容。

**回归保证**：未传参 / `--horizon long` 的读取路径（第零步判断 + 原有第一~七步）在语义上不新增、不删除、不改写任何现有指令，故 B-1 / B-3 的"逐字一致"由结构设计天然满足。

### 3.3 与 `exit-signal` 的关系（边界澄清）

| 技能 | 定位 | 本 Sprint 处理 |
| --- | --- | --- |
| `exit-signal` | 独立的 P0~P5 硬性风控触发 | 本 Sprint **不修改**，仅引用其 P0~P5 映射表 |
| `thesis-tracker --horizon mid` | 中期论文的季度健康度追踪 | 将 P0~P5 作为"红线清单"的替代检查项，命中即停 |
| `portfolio-review --horizon mid` | 组合层面的中期仓位结构审视 | 不逐项执行 P0~P5，仅引用底仓/机动仓与上限规则 |

### C-3 模式 M-A：建立中期论文

**M-A1 中期核心论文**（替代 A1 的"永续护城河"5 问，聚焦 1~3 年景气逻辑）：

```markdown
我以 ___元 买入 ___公司（1~3 年中期），因为：
1. 赛道景气阶段：___，渗透率位于 ___%，处于（加速突破 / 快速放量 / 临近见顶）期
2. 中期驱动：订单/收入/利润的可见度来自 ___（具体订单、装机、客户验证）
3. 管理层与治理：___，科研转化/执行力的证据是 ___
4. 当前估值水位：PEG = ___，处于（显著低估/合理/偏贵/高估/透支）档
5. 退出条件：若 ___ 发生，我将按 P0~P5 规则卖出
```

**M-A2 中期假设清单**（替代 A2 核心假设清单，维度对齐 6.7"景气/渗透率/订单/估值"）：

| # | 中期假设 | 验证方式 | 验证频率 | 当前状态 |
| - | -------- | -------- | -------- | -------- |
| 1 | 渗透率：行业渗透率按预期推进（例：AI 应用装机率季增 X pct） | 第三方渗透率数据 | 每季度 | 🟢 成立 |
| 2 | 景气：营收/订单增速连续 2 季高于行业均值 | 季报营收 + `qoq-accelerator` | 每季度 | 🟢 成立 |
| 3 | 订单：在手订单/合同负债兑现为收入 | 季报合同负债/订单公告 | 每季度 | 🟢 成立 |
| 4 | 估值：PEG 维持 0.8~1.2 合理区（或随业绩消化） | `financial_rigor.py peg` | 每季度 | 🟢 成立 |
| 5 | 竞争格局：竞对未取得同等技术/份额突破 | 行业数据/竞对财报 | 每半年 | 🟢 成立 |

**M-A3 P0~P5 卖出检查表**（替代 A3 红线清单，硬编码，对齐总计划 6.6）：

| 级别 | 触发条件 | 决策 |
| --- | --- | --- |
| P0 治理一票否决 | 管理层失信、财务造假实锤、监管立案 | 立即清仓，不看估值趋势 |
| P1 硬止损 | 单笔亏损 8%~10%，且无基本面反转信号 | 无条件止损 |
| P2 逻辑止损 | 连续 2 季业绩低于预期且产业景气未改善；**或持有满 4 季度逻辑未兑现（时间止损）** | 减仓或清仓 |
| P3 产业景气拐点 | 渗透率减速 / ROE 拐头向下 | 减机动仓 |
| P4 估值透支 | PEG > 1.5（减机动仓）；PEG > 2（加速清机动仓） | 减/清机动仓 |
| P5 性价比替换 | 其他标的 PEG 显著更低且产业趋势更强 | 调仓（每季度最多 1 次） |

> 执行顺序：从 P0 到 P5 依次检查，**命中即停止**，输出对应动作，**禁止跳过 P0**。

| 股价 / PE / 市值 | （同长期） | | | |
| **PEG** | 当前值 | 对应档位 | | |
| **PEG 档位** | 显著低估 / 合理 / 偏贵 / 高估 / 透支 | | | |

**M-A5 保存**：写入 `reports/{公司名}/{公司名}-mid-thesis.md`（与长期论文 `reports/{公司名}-thesis.md` 物理隔离，互不覆盖）。

### C-4 模式 M-B：中期追踪检查

**M-B1**：读取 `reports/{公司名}/{公司名}-mid-thesis.md`（若不存在则回落到模式 M-A）。
**M-B2**：数据收集复用 B2，并追加引用 `qoq-accelerator`、`trend-momentum-scan` 的既有输出（若已生成）。
**M-B3**：逐条检查中期假设，状态沿用 🟢/🟡/🔴/⚫ 四级，并**加入连续 3 季趋势判定**：

> 单季波动不判拐点；连续 3 季同向（连续加速 = 景气向上 / 连续减速 = 拐点预警）才确认趋势。

**M-B4**：P0~P5 依次检查（替代 B4 红线检查），命中即停、输出行动。

**M-B5**：估值更新，加入 PEG 水位对比（用 `financial_rigor.py peg --pe ... --growth ...` 计算）。

**M-B6**：中期健康度评分（加入 PEG 水位维度，见下），输出中期追踪报告。

**M-B7**：将检查记录追加到 `reports/{公司名}/{公司名}-mid-thesis.md` 的追踪记录表。

### C-5 中期健康度评分公式（新增设计）

在长期公式基础上加入 PEG 水位项与 P0~P5 命中惩罚：

```markdown
中期健康度 = 10 - (⚫破裂假设×3) - (🔴受损假设×2) - (🟡弱化假设×1)
            - (P0~P5命中扣分) - (PEG水位扣分)
最低 1 分，最高 10 分
```

**P0~P5 命中扣分**（因"命中即停"，只取命中的最高优先级一项，不累加）：

| 命中级别 | 扣分 |
| --- | --- |
| P0 | 直接判 1 分（立即清仓） |
| P1 | -5 |
| P2 | -4 |
| P3 | -3 |
| P4 | -2 |
| P5 | -1 |
| 未命中 | 0 |

**PEG 水位扣分**（对齐 `valuation-thermometer` 五档口径）：

| PEG 档位 | 区间 | 扣分 |
| --- | --- | --- |
| 显著低估 | < 0.8 | 0（可作安全边际） |
| 合理 | 0.8 ~ 1.2 | 0 |
| 偏贵 | 1.2 ~ 1.5 | -1 |
| 高估 | > 1.5 | -2 |
| 严重透支 | > 2 | -3 |

**评分含义表**（中期）：

| 评分 | 含义 | 建议动作 |
| :--: | --- | --- |
| 9-10 | 景气假设全部成立 + PEG 合理 | 底仓持有，机动仓可加 |
| 7-8 | 核心假设成立，个别边际弱化 | 底仓持有 |
| 5-6 | 假设受损或 PEG 偏贵 | 持有但减机动仓 |
| 3-4 | 多假设受损或 PEG 高估 | 减仓（先减机动仓） |
| 1-2 | P0~P2 命中或核心假设破裂 | 按 P0~P5 规则卖出 |

### D-3 中期分支：底仓/机动仓分离判定

**归属判定**（按优先级，二选一或结合）：

1. 用户显式标注（`标的=底仓/机动仓`）→ 以标注为准；
2. 无标注 → 按以下规则辅助判定，并在报告中标注"推断"：
   - 有深度研究报告 且 论文健康度 ≥ 7 且 PEG ≤ 1.2 → **底仓候选**；
   - PEG > 1.5 或论文健康度 < 5 的部分 → **机动仓**（且触发减持提示）；
   - 卫星/试探性小仓位（≤8%）→ **机动仓**。
