# 景气趋势筛选：1-3年回报周期的趋势投资体系

对 $ARGUMENTS 执行景气趋势筛选，从**1-3年中期回报周期**的角度，识别最具爆发潜力的成长股。

**支持输入格式**：

| 输入方式 | 示例 | 说明 |
|---------|------|------|
| 个股 | `腾讯, 美团, 英伟达` | 逐家筛选 |
| 行业 | `中国AI算力行业` `全球半导体设备` `港股创新药` | 先搜索该行业主要上市公司（10-20家），再逐家筛选 |
| 市场/指数 | `恒生科技指数成分股` `科创50` `纳斯达克100` | 拉取成分股列表，逐家筛选 |
| 主题 | `全球AI算力链` `中国国产替代50强` | 先搜索主题相关公司，再逐家筛选 |

行业/市场/主题模式下，输出额外包含：通过率统计、行业内排名、景气一致性判断、板块对比总结。


## 设计原则

- **目标**：识别未来1-3年盈利增速有望排进行业前10%的公司，而非验证10年永续经营能力
- **逻辑**：五维加权打分（满分100 + 奖励分）+ 地缘政治二维修正（乘数系数）+ 技术面止损（独立否决），**允许历史瑕疵，但要求边际快速收窄**
- **适用范围**：科技成长、产业趋势、景气上行阶段的上市公司（不适用于纯周期股和早期未盈利Biotech）


## 本技能的思想渊源（四位投资大师的理论基石）

本技能融合了以下四位投资大师的核心思想，将他们的经典理论转化为可量化的筛选指标：

### 威廉·欧奈尔（William O'Neil）——趋势识别的“操作手册”

- **核心贡献**：CAN SLIM选股系统——首次将基本面与技术面完美统一，通过对1880年以来美股牛股的统计研究，提炼出七大共同特征
- **融入本技能**：
  - **C（季度收益）** → 订单增速（合同负债同比）作为景气前瞻核心指标
  - **N（新品/新服务）** → 新品收入占比与MROI作为研发转化核心指标
  - **L（领涨股/相对强度）** → 250日SMR（股价相对强度评级）作为动量共识核心指标
  - **I（机构认同）** → 机构覆盖度与增仓追踪
  - **M（市场趋势）** → 产业链周期定位作为前置判断
  - **技术面纪律** → 跌破50日/200日均线作为止损触发条件

### 彼得·林奇（Peter Lynch）——成长与估值的“度量衡”

- **核心贡献**：GARP策略（Growth at a Reasonable Price）——成长与估值的平衡艺术；“翻石头”式研究——每年实地调研200-300家公司
- **融入本技能**：
  - **PEG指标** → 估值安全垫模块的核心工具
  - **PSG指标（新增）** → 爆发期科技股的辅助估值工具
  - **成长优先，估值兼顾** → 景气模块权重最高（35分），估值模块作为辅助校验（10分）
  - **“翻石头”式研究** → 年报PDF强制挖掘，至少覆盖15家公司
  - **买入自己懂的东西** → 产业链周期定位前置判断，确保理解行业逻辑

### 郑希（易方达基金）——全球科技景气的“公募一哥”

- **核心贡献**：景气度投资 + 全球科技通胀逻辑——“科技成长的‘通胀’是由新技术落地带来的需求创造的，其爆发力远比传统供需错配更强”
- **融入本技能**：
  - **科技通胀逻辑** → 研发转化模块权重提升，评估新技术是否真正创造了需求
  - **全球视野** → 跨市场筛选支持（A/港/美股），美股龙头映射验证
  - **产业链验证** → 从下游倒推上游，验证景气传导链条
  - **供应链话语权（新增）** → 应付账款周转天数与预付款项变化作为科技通胀的验证工具

### 李进（融通基金）——“时代感”景气的实践者

- **核心贡献**：聚焦社会变迁与产业演进主线，寻找“需求大幅扩张、产业规模快速增长”的领域；通过产业链调研验证景气度（“每周爆单”）
- **融入本技能**：
  - **需求扩张验证** → 订单增速+毛利率变化双指标验证
  - **产业链调研** → 供应链卡点排查六层溯源
  - **动态调仓** → 反证清单机制，关键指标触发阈值时及时调整评级
  - **“时代感”判断** → 社会变迁与产业演进主线的定性评估


## 四层递进式评估流程

> **执行顺序**：**第零层：产业链周期定位** → **第一层：前置硬性淘汰** → **第二层：五维加权打分（满分100+奖励分）** → **第三层：地缘政治二维修正** → **估值倒推验证 + 技术面止损校验** → **最终评级 + 反证清单**


### 第零层：产业链周期定位（前置判断，动态调整权重）

在执行任何筛选之前，先判断标的所处的产业链周期阶段。不同阶段赋予不同指标更高权重。

#### 精准关键词搜索（替代模糊“景气度”搜索）

```bash
# ① 判断需求侧热度：订单与产能
doubao_search.py --time-range month "{行业名} 产能利用率 排产 订单排期"
doubao_search.py --time-range month "{行业名} 合同负债 预收账款 变化"

# ② 判断供给侧压力：库存与价格
doubao_search.py --time-range month "{行业名} 库存水位 去库存 周转天数"
doubao_search.py --time-range month "{行业名} 涨价函 价格走势 价格谈判"

# ③ 判断资本开支：扩张信心
doubao_search.py --time-range month "{行业名} 资本开支 扩产 设备投资"
```

#### 周期判定逻辑表

| 定位维度             | 关键搜索词            | 需求爆发期信号     | 供给受限期信号              | 成熟稳定期信号  |
| :------------------- | :-------------------- | :----------------- | :-------------------------- | :-------------- |
| **产能利用率** | `产能利用率 排产`   | > 85%且排产满      | > 90%                       | < 70%           |
| **库存水位**   | `库存水位 周转天数` | 同比下降 > 15%     | 极低库存（<30天）           | 同比持平或上升  |
| **产品价格**   | `涨价函 价格走势`   | 主流产品发布涨价函 | 价格持续攀升                | 价格战/以价换量 |
| **资本开支**   | `资本开支 扩产计划` | 头部公司大幅扩产   | 扩产受限（环保/设备卡脖子） | 扩产谨慎        |

#### 周期阶段权重调整

| 周期阶段             | 判断标准                       | 权重调整                                                         |
| -------------------- | ------------------------------ | ---------------------------------------------------------------- |
| **需求爆发期** | 下游需求暴增，订单能见度极高   | ①景气前瞻模块 35→**42分**；②研发转化 25→**18分** |
| **技术跃迁期** | 新技术替代旧技术，行业标准重塑 | ②研发转化模块 25→**32分**；①景气前瞻 35→**28分** |
| **供给受限期** | 关键原材料/设备被卡            | 地缘政治修正系数权重提升                                         |
| **成熟稳定期** | 行业格局稳定，增长靠份额提升   | ⑤估值安全垫 10→**15分**                                  |

#### 郑希式科技通胀周期判断

触发“需求爆发期”权重调整的三项标准：

1. 是否存在**颠覆性新技术**（如大模型、固态电池、减肥药）？
2. 该技术是否已进入**商业化落地阶段**（非实验室阶段）？
3. 相关产业链是否存在**“每周爆单”式需求**（通过调研纪要/公告验证）？

若三项均为“是” → 判断为科技通胀周期，触发①模块权重提升至42分。

> *执行纪律：必须基于具体数据（如“某龙头发布涨价通知”、“行业库存已降至XX天”）做出判断，禁止仅凭新闻标题定性。若搜索返回结果过多噪声，可组合使用 `--tag finance` 参数过滤非财经类信息。*

### 第一层：前置硬性淘汰（一票否决）

满足以下任一条件，**直接淘汰，不再进行后续打分**：

| # | 前置淘汰条件                                                                                                 | 判断逻辑/数据来源                       |
| - | ------------------------------------------------------------------------------------------------------------ | --------------------------------------- |
| 1 | **被列入实体清单 + 核心环节国产化率 < 30% + 无非制裁海外有效实体**（既无硬替代，又无软迂回，彻底封死） | 年报“供应链风险”章节 + 子公司列表核查 |
| 2 | **核心技术人员流失 > 30% 且 人均创利连续2年暴跌 > 40%**（人才体系崩塌，不可逆）                        | 年报“员工情况”历年对比 + 财务数据     |
| 3 | **在手订单（合同负债）同比 < -50% 且 存货周转天数同比增加 > 80%**（订单崩盘+库存爆仓）                 | 季报合同负债 + 存货周转率               |

> **关键修正**：被制裁本身**不再**是一票否决项。华为的案例证明，制裁可以倒逼出更强的自主创新。我们只淘汰“被制裁后毫无应对能力”的公司。

## 各指标详细定义与阈值

### 1. 景气前瞻维度（35分）

| 指标                                           | 计算方式                                      | 得分梯度                                                                                                                                                                                 | 大师思想溯源                                                                                                                                                                                               |
| :--------------------------------------------- | :-------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **订单增速（欧奈尔C因子）**              | （最新季报合同负债 - 上年同期）/ 上年同期     | >30%得12分；15%-30%得8分；<15%得4分；负增长0分                                                                                                                                           | **欧奈尔**：历史上最牛的股票在暴涨前，当季每股收益同比至少增长20%。A股中“合同负债”是收入的前瞻指标                                                                                                 |
| **政策环境**                             | `doubao_search` 搜索国家级规划+财政补贴落地 | 明确写入+资金配套（8分）；仅提及支持（4分）；政策收紧/集采（0分）                                                                                                                        | **李进**：聚焦社会变迁与产业演进主线                                                                                                                                                                 |
| **毛利率变化**                           | 最新季度毛利率同比提升百分点                  | >2pct得8分；0-2pct得4分；下滑0分                                                                                                                                                         | **李进**：需求扩张的验证指标                                                                                                                                                                         |
| **供应链话语权（科技通胀验证）（新增）** | 应付账款周转天数同比变化 + 预付款项同比变化   | **应付账款周转天数同比增加 > 10%** → +4分（公司占用上游资金能力增强，产业链地位提升）；**预付款项同比增加 > 30%** → +3分（公司需提前锁定上游产能，说明需求旺盛，供不应求） | **郑希**：科技成长的通胀本质是“供不应求”。供应链话语权是验证“供不应求”最直接的财务证据——若一家科技公司能占用上游资金（应付增加）或需要提前锁定产能（预付款增加），说明其在产业链中处于强势地位 |
| **行业景气一致性（批量模式）**           | 同行业筛选通过率                              | 行业通过率>60%→该行业公司集体+2分；<30%→集体-2分                                                                                                                                       | **郑希**：行业景气聚合效应                                                                                                                                                                           |

### 2. 研发执行力与转化维度（25分 + 奖励分）

| 指标                                                        | 计算方式                                                                         | 得分/扣分逻辑                                                                                                                                       | 大师思想溯源                                                                                                                                                                                            |
| :---------------------------------------------------------- | :------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **MROI（边际回报率，欧奈尔N因子）（含时间滞后备选）** | **主公式（成熟期公司）**：（本年毛利 - 去年毛利）/ 本年研发费用            | >5倍（10分）；3-5倍（7分）；1.5-3倍（4分）；<1.5倍（0分）                                                                                           | **欧奈尔**：95%的大牛股暴涨源于“新东西”。MROI衡量“新东西”是否真正创造了利润增量                                                                                                               |
|                                                             | **备选公式（高成长/研发密集型公司）**：（本年毛利增量）/（前一年研发费用） | >4倍（10分）；2-4倍（7分）；1-2倍（4分）；<1倍（0分）                                                                                               | *研发→利润转化存在1-2年滞后。对于研发费用率>15%的高成长公司，备选公式更能反映真实转化效率。例：2023年投入10亿研发，2025年毛利增50亿，用备选公式得5倍（50/10），用主公式得4.2倍（50/12），前者更准确* |
| **研发费用率变化趋势（辅助，不占分）**                | 本年研发费用率 vs 前一年                                                         | 若研发费用率同比下降 > 2个百分点，且营收增速 > 30%，额外+1分                                                                                        | 识别“研发效率提升”的积极信号                                                                                                                                                                          |
| **新品占比/溢价（欧奈尔N因子）**                      | 年报“新品收入占比”；新品毛利率-旧品毛利率                                      | 占比>30%且溢价>8pct（8分）；占比15-30%（5分）；<15%（2分）                                                                                          | **欧奈尔**：量化评估“新”的成色                                                                                                                                                                  |
| **落地速度**                                          | 年营收 / 平均（开发支出+专利账面值）                                             | >2.5倍（4分）；1.5-2.5倍（2分）；<1.5倍（0分）                                                                                                      | **郑希**：科技通胀需要快速商业化落地                                                                                                                                                              |
| **存货匹配**                                          | 研发费用增速 vs 存货周转天数变化                                                 | 研发增>30%且周转天数缩短（3分）；同步增加（-3分扣分）                                                                                               | **李进**：产业链验证——研发成果是否转化为实际销售                                                                                                                                                |

|                                                             |                                                                                  | **Level C - 普通产品迭代**：不适用此加分规则                                                                                                  |                                                                                                                                                                                                         |
| **供应链备选方案（奖励）**                            | 供应链卡点排查中红色层级是否有已验证的备选供应商                                 | 每个红色层级有备选方案→**+1分**，上限3分                                                                                                     | **李进**：产业链韧性验证                                                                                                                                                                          |

> *卡脖子替代分级依据*：参照国家工信部“卡脖子”技术清单及美国BIS出口管制清单进行对照。执行流程中包含“卡脖子清单查证”步骤确保准确性。

### 3. 人才质量与密度维度（15分）

| 指标                     | 计算方式                         | 得分逻辑                                                  | 大师思想溯源                            |
| :----------------------- | :------------------------------- | :-------------------------------------------------------- | :-------------------------------------- |
| **人均创利增速**   | （今年人均净利 - 去年）/ 去年    | >20%（5分）；10-20%（3分）；负增长（0分）                 | **郑希**：衡量人才效率的提升      |
| **人才密度**       | 研发人员/总员工；硕博占比        | 研发占比>30%且硕博>30%（5分）；仅满足一项（3分）          | **郑希+李进**：科技企业核心竞争力 |
| **团队稳定与薪酬** | 核心人员流失数；人均薪酬行业分位 | 无流失且薪酬前30%（5分）；流失1人（3分）；流失>2人（0分） | **郑希**：核心团队稳定性          |

### 4. 动量与市场共识维度（15分 + 奖励分）

| 指标                                      | 得分逻辑                                                                                          | 大师思想溯源                                                                                                                               |
| :---------------------------------------- | :------------------------------------------------------------------------------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------- |
| **250日SMR相对强度（欧奈尔L因子）** | 个股过去250日涨幅在全市场（或同板块）的百分位排名：>80%分位得5分；60%-80%分位得3分；<60%分位得0分 | **欧奈尔**：只买领涨股，相对强度排名前80%分位。SMR（股价相对强度评级）是欧奈尔原版CAN SLIM中的标准工具，比14日RSI更适合1-3年中期判断 |
| **RSI(50)中期动量（备选）**         | 50周期RSI：50-65区间（5分）；65-75（3分）；>75或<40（0分）                                        | *当SMR数据不可用时使用。50周期相比14日RSI过滤了短期噪音，更适合1-3年中期趋势判断*                                                        |
| **盈利预测上调（含超预期追踪）**    | 近3月上调次数>5次（5分）；2-5次（3分）；<2次（0分）；最新季报超预期>10%→+1分                     | **林奇**：市场共识的验证                                                                                                             |
| **低关注度溢价（欧奈尔I因子）**     | 覆盖券商≤3家且市值<200亿→**+2分**                                                         | **欧奈尔**：机构认同但未扎堆，预期差最大                                                                                             |

### 5. 估值安全垫维度（10分 + 辅助校验）

| 指标                                              | 得分逻辑                                                                                                                                                   | 大师思想溯源                                                                                                                                             |
| :------------------------------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **PEG（林奇核心指标）**                     | <1.0（5分）；1.0-1.5（3分）；>1.5（0分）*                                                                                                                  | **林奇**：PEG<1意味着市场低估了成长潜力                                                                                                            |
| **PSG（市销率增长比，爆发期专用）（新增）** | 当前市销率(PS) / 近一年营收增速。**仅当**：①净利率<5%（微利/亏损）或 ②营收增速>50%（高速放量期）时触发。< 0.5（3分）；0.5-1.0（2分）；> 1.0（0分） | *在AI算力、早期新能源车等“需求爆发期”，企业往往先把营收做起来（规模效应），利润滞后释放。此时PEG虚高甚至为负，使用PSG更能反映“抢占市场”的战略价值* |
| **PE历史分位**                              | <40%（2分）；40-60%（1分）；>60%（0分）                                                                                                                    | **林奇**：对照公司历史估值区间                                                                                                                     |

> *关于PEG在爆发期的特殊处理*：若公司同时满足“营收增速>50%”且“毛利率>35%”（说明产品有竞争力，利润迟早会释放），PEG即使介于1.5-2.5之间，可豁免“0分”惩罚，改为“2分（观察）”。但若PEG>3，无论增速多快，均触发估值透支警告。

### 第三层：地缘政治二维修正系数（硬替代 × 软对冲）

地缘政治风险由 **X轴：核心环节国产化率（硬替代能力）** 与 **Y轴：海外非制裁实体对冲有效性（软迂回能力）** 共同构成二维矩阵。

#### Y轴评估标准：海外非制裁实体对冲有效性

| 评估子项                | 数据来源       | 高有效性                               | 低有效性                   |
| :---------------------- | :------------- | :------------------------------------- | :------------------------- |
| **注册地**        | 年报子公司列表 | 新加坡、马来西亚、阿联酋、墨西哥、瑞士 | 仅在美国、英国、荷兰、日本 |
| **业务功能**      | 子公司业务描述 | 研发中心/采购中心/销售中心             | 仅为空壳控股公司           |
| **收入/资产占比** | 分部报告       | 非制裁区收入>10%且3年复合增长>20%      | 非制裁区收入<5%            |
| **团队规模**      | 员工地区分布   | 非制裁区海外员工>200人                 | 海外员工<50人              |

#### 二维修正系数矩阵

| 国产化率（X轴）\ 海外对冲（Y轴） | **高有效性**               | **中有效性**     | **低/无效**    |
| :------------------------------- | :------------------------------- | :--------------------- | :------------------- |
| **高（>70%）**             | **× 1.10** 🔥（韧性溢价） | **× 1.00**      | **× 1.00**    |
| **中（30%-70%）**          | **× 0.95** ✅             | **× 0.80** ⚠️ | **× 0.65** ❌ |
| **低（<30%）**             | **× 0.90**                | **× 0.60**      | **× 0.40** 🚫 |

> **最终得分 = （五维加权总分 + 奖励分） × 地缘修正系数**

### 估值安全垫：市值隐含业绩倒推验证（林奇式估值校验）

本验证**不占分**，但若触发红灯，直接下调一个评级：

```
当前市值 ÷ 目标PE（取行业均值或公司历史中位）= 市场隐含的全年净利润
隐含净利润 ÷ 最新季度净利率 × 4 = 隐含年化营收目标
隐含年化营收目标 ÷ 当前TTM营收 = 隐含营收增速要求
```

| 验证结果                              | 判断                                     |
| :------------------------------------ | :--------------------------------------- |
| 隐含增速要求 < 公司指引上限           | ✅ 估值合理                              |
| 隐含增速要求 ≈ 公司指引上限（±10%） | ⚠️ 估值公允                            |
| 隐含增速要求 > 公司指引上限 × 1.5    | 🔴**红灯**：估值严重透支，下调评级 |

### 技术面止损校验（欧奈尔卖出纪律，独立否决项）（新增）

> **执行位置**：在最终评级确定后，对S/A级公司执行本校验。若触发止损条件，**强制下调评级**（S→B，A→B或C），无论基本面得分多高。

| 止损等级                   | 触发条件                                        | 执行动作                                | 大师思想溯源                                                                    |
| :------------------------- | :---------------------------------------------- | :-------------------------------------- | :------------------------------------------------------------------------------ |
| **初级预警**         | 股价跌破50日均线（10周线）且成交量高于均值1.5倍 | 下调评级至B级；建议减仓50%              | **欧奈尔**：技术破位是基本面预期变化的提前信号                            |
| **强制止损（红牌）** | 股价跌破200日均线（年线）                       | **直接清仓/移出关注池**，不再持有 | **欧奈尔**：跌破年线意味着过去1年所有买入者全部被套，中期上升趋势已被破坏 |

> *欧奈尔技术面释义*：欧奈尔强调“截断亏损”，技术破位往往是基本面预期变化在交易层面的提前反应。在1-3年的中期趋势中，跌破年线意味着过去1年的所有买入者全部被套，中期上升趋势已被破坏。**技术面红牌为最高优先级，即时生效，无需等待基本面确认。**

### 最终评级 + 反证清单

**最终得分 = （五维加权总分 + 奖励分） × 地缘修正系数**

**评级映射**：

- **S级（强烈买入）**：≥ 80分
- **A级（配置）**：65-79分
- **B级（观察/轻仓）**：50-64分
- **C级（回避）**：< 50分

#### 反证清单（林奇式动态调仓 + 欧奈尔技术面纪律）

对每一个S/A级公司，必须列出以下“关键跟踪指标与反证阈值”：

| 跟踪指标                                   | 当前值     | 反证阈值（触发下调评级）                                                                       | 验证频率 | 对应大师                       |
| :----------------------------------------- | :--------- | :--------------------------------------------------------------------------------------------- | :------- | :----------------------------- |
| 季度订单增速                               | +45%       | 连续两个季度 < 20%                                                                             | 每季     | **李进**（需求扩张验证） |
| 毛利率                                     | 42%        | 单季跌破 35%                                                                                   | 每季     | **郑希**（景气持续性）   |
| 核心团队                                   | 无流失     | 任一核心技术人员离职                                                                           | 即时     | **郑希**（人才质量）     |
| 国产化率进展                               | 65%        | 连续两季度无进展公告                                                                           | 每季     | **郑希**（自主替代）     |
| SMR相对强度                                | 82%分位    | 跌破60%分位                                                                                    | 每月     | **欧奈尔**（领涨股地位） |
| **技术面（欧奈尔卖出纪律）（新增）** | 当前收盘价 | **初级预警**：跌破50日均线且放量 → 下调至B级；**强制止损**：跌破200日均线 → 清仓 | 每周     | **欧奈尔**（截断亏损）   |
| 机构覆盖度                                 | 5家        | 连续两季机构减持>10%                                                                           | 每季     | **欧奈尔**（机构认同）   |

> *执行纪律*：若报告发布后，任一**基本面指标**触及反证阈值，或**技术面指标**触发止损线，必须重新评估并下调评级。**技术面红牌为最高优先级**，即时生效，无需等待基本面确认。

#### 步骤0：产业链周期定位（前置判断）

```bash
# 精准关键词搜索（替代模糊的“景气度”）
doubao_search.py --time-range month "{行业名} 产能利用率 排产 订单排期"

```

根据搜索结果，对照“周期判定逻辑表”判断行业周期阶段，相应调整各维度权重。

#### 步骤1：卡脖子清单查证（R6分级评分的前置准备）

```bash
# 查证国家卡脖子清单
doubao_search.py --sites gov.cn,miit.gov.cn --time-range year "卡脖子 技术 清单 光刻机 EDA 光芯片"

# 查证美国BIS出口管制清单
```

将公司公告中的替代产品与清单对照，确定R6加分等级（Level A/B/C）。

#### 步骤2：地缘政治与制裁状态扫描

```bash
doubao_search.py --sites gov.cn,news.cn --time-range month "{公司名} 制裁 实体清单 出口管制"
doubao_search.py --finance "{公司名} 海外子公司 注册地 2025 年报"
doubao_search.py --finance "{公司名} 海外收入 占比 非美国 2025"
```

#### 步骤3：年报下载与PDF文本挖掘（林奇“翻石头”式研究）

```bash
python tools/a_share/stock_equity.py --download-report --code {code} --year 2025
```

使用 `pdf-extraction` 工具在年报中强制搜索以下字段，并优先用 `annual_report_parser.py`（阶段四已完成）一键结构化抽取：

- **“研发投入”章节** → 资本化率、研发人员薪酬占比、被制裁后研发投入变化
- **“员工情况”章节** → 研发人数、硕博人数、核心技术人员名单（与上年比对）
- **“经营情况讨论与分析”** → 新品收入占比（**欧奈尔N因子**）、核心环节国产化进展
- **“合并财务报表附注—在其他主体中的权益”** → 所有主要子公司名称及注册国家
- **“收入分部报告”** → 按地区拆分（美国/欧盟 vs 其他地区）
- **“供应链风险”章节** → 供应商集中度、进口依赖程度

```bash
# 结构化抽取（阶段四已完成）：员工/子公司/研发/收入分部/新品/供应链
python tools/common/annual_report_parser.py {年报md} --output-json
```

#### 步骤4：财务与运营数据拉取

- **A股**：`tools/a_share/stock_financial.py --advanced` 提取研发费用、毛利、无形资产、开发支出、存货周转天数、员工总数、合同负债、**应付账款周转天数**、**预付款项**（阶段二已完成）
- **港股**：`tools/hk_stock/stock_financial.py --advanced` 提取同类科目（合约负债/存货/应付账款/预付款项）
- **美股**：`tools/us_stock/stock_financial.py --indicators` 指标化输出（毛利/研发费用/合同负债/存货周转）

#### 步骤5：跨市场景气联动验证（郑希全球视野）

```bash
# 美股龙头映射
doubao_search.py --finance "英伟达 最新季度 业绩 订单 2026"
doubao_search.py --finance "Coherent 最新季度 业绩 光模块 2026"
```

验证“美股龙头业绩爆发 → A股/港股产业链跟随”的传导逻辑是否成立。

#### 步骤6：动量与共识数据（欧奈尔CAN SLIM核心）

- **SMR相对强度（欧奈尔L因子）**：`stock_quote.py --momentum` 输出250日同板块/全市场百分位排名（阶段三已完成）
- **RSI(50)中期动量（备选）**：`stock_quote.py --momentum` 直接输出50周期RSI
- **机构覆盖度（欧奈尔I因子）**：`stock_info.py --profile`（A股）统计近6个月出具研报的券商数量

```bash
# A股：动量 + 申万行业自动截面（阶段三已完成）

python tools/a_share/stock_info.py --code 300502 --profile
```

> **注**：港股/美股 `--momentum --auto-peers` 会输出 SMR "不可用"提示（板块成分无可靠公共数据源）并置 SMR 百分位为 None，需手动指定 `--peers` 或用搜索补充。

#### 步骤7：估值倒推验证 + 技术面校验

- **估值倒推**：`financial_rigor.py implied-growth` 根据最新市值、行业均值PE、最新季度净利率和TTM营收，计算隐含增速要求并做红/黄/绿判定（阶段一已完成）
- **技术面（新增）**：`stock_quote.py --momentum` 输出 MA50/MA200 位置与量能，判断是否触发止损条件

```bash
python tools/common/financial_rigor.py implied-growth \
  --market-cap {市值} --target-pe {目标PE} --net-margin {净利率} \
  --ttm-revenue {TTM营收} --guidance-growth {公司指引增速上限}
```

### 打分引擎与工具链的配合

`trend_tech_screen.py` 是**聚合计算层**，**不直接拉取网络数据**。执行流程如下：

1. **LLM 采集与判断**：用上方各数据/搜索/年报工具采集指标，定性判断周期阶段、政策环境、自主替代分级、地缘二维（x=国产化率、y=海外对冲）、技术面数据
2. **工具计算**：`financial_rigor.py` 计算 PEG/PSG/PE分位/隐含增速；`annual_report_parser.py` 结构化抽取年报字段
3. **打分引擎聚合**：将五维得分（`--dims`）、地缘二维（`--geo`）、技术面数据（`--tech`）传入 `trend_tech_screen.py score`，引擎自动执行五维加权（含4种周期权重）、地缘乘数修正、技术面止损校验（S/A级强制降级）、评级映射、反证清单输出；批量模式用 `batch --input` 做行业景气一致性两轮修正

### 关键约束

- **财务计算验算**：使用 `tools/common/financial_rigor.py` 五维估值命令 + `trend_tech_screen.py` 打分引擎，**禁止 LLM 心算**
- **年报一手数据**：关键财务数据须从年报PDF一手提取，禁止用研报替代；结构化字段优先用 `annual_report_parser.py` 抽取
- **网络搜索**：禁止使用 Anthropic 官方 WebSearch，统一使用本地五工具组合
- **时效性**：搜索时须使用 `--time-range month` 或 `--time-range week` 限制时间范围
- **跨市场市值统一口径**：恒生/纳斯达克等跨市场筛选时用 `tools/common/fx_rate.py` 折算到统一币种

## 注意事项

1. **与原始 `quality-screen.md` 的定位差异**：

   - 原始技能：**逆向淘汰**，排除非一流公司，强调永续经营能力
   - 本技能：**正向排序**，识别景气趋势公司，强调1-3年盈利爆发力
   - 两者互为补充，根据用户持有周期自动路由
2. **大师思想的应用边界**：

   - **欧奈尔CAN SLIM**：最适用于**需求爆发期**和**技术跃迁期**的科技成长股；SMR（而非14日RSI）和200日均线纪律是其核心
   - **林奇GARP**：适用于**所有成长股**的估值校验；PSG作为爆发期补充
   - **郑希全球景气**：适用于**全球产业链联动**的科技行业（AI算力、半导体、光模块）；供应链话语权（应付/预付款）是其科技通胀逻辑的验证工具
   - **李进产业验证**：适用于**有明确上下游可追踪**的制造业和科技硬件
3. **周期权重调整的纪律**：

   - 若无法明确判断周期阶段，默认采用“需求爆发期”权重分配（最贴合1-3年趋势投资场景）
   - 权重调整仅影响①和②模块的分值分配，不影响③④⑤模块
4. **数据窗口要求**：

   - 本技能不要求10年历史数据，**近6个季度的边际变化**比历史均值更重要
   - 上市不足3年的公司，允许用IPO招股书中的“管理层指引”代替历史数据
5. **技术面止损的执行纪律（新增）**：

   - **200日均线止损为最高优先级**，触发即执行，无需等待基本面确认
   - 50日均线放量破位为初级预警，可减仓观察
   - 欧奈尔体系强调“截断亏损”，技术破位是基本面预期变化的提前信号
6. **局限性声明**：

   - 本模型在纯周期股（航运、养猪）和早期未盈利Biotech中有效性显著下降
   - 地缘政治突变（战争、突发极端制裁）无法预测，需用户自行关注新闻动态
   - **四位大师的思想是本技能的“魂”**，但任何大师的理论都不能替代对具体公司管理层诚信度和实际控制人背景的深入调研
