## 一、定位与目标

Sprint 1 交付中期投研闭环的**两个核心技能**——`valuation-thermometer`（估值择时）与 `exit-signal`（卖出触发）。这是整条中期链"买入之后"的两道关键闸门：前者决定**何时买、买多少**，后者决定**何时卖、卖多少**。两者通过 PEG 档位形成数据衔接（估值输出 → 卖出 P4 输入）。

**工作量：2 天。**

**原则**（沿用主方案 2.2 设计原则）：

1. 两个技能均为**新建功能命名技能**（无 `mid-` 前缀，见主方案附录 C），存放于 `.trae/skills/` 根级，与长期技能同级；
2. **零 Python 开发**：全部数据依赖直接调用 `tools/` 既有工具（`financial_rigor.py` 四个估值命令）；
3. **风控硬编码**：止损 8%~10%、时间止损 4 季度、PEG 五档阈值、底仓/机动仓区间、P0~P5 检查顺序均作为硬性规则写入 Prompt，不允许 AI 自由裁量；
4. **输出全 Markdown**，落地 `reports/valuation/` 与 `reports/exit-signals/`（Sprint 0 已建）；
5. **输出格式与现有技能文件范式一致**：两技能 SKILL.md 的「执行输出内容」均按现有技能统一范式编写——完整 Markdown 输出模板（固定结构）+ 报告文件输出路径（命名规则）+ 报告示例（输入→输出），对齐 `quality-screen`、`mid-trend-tech-screen`、`thesis-tracker` 三份已有 SKILL.md。

#### 1.1 目标

#### 1.2 SKILL.md 内容要点

description: "估值温度计（1-3年中期）：用 PEG/PSG/PE历史分位/implied-growth 四工具输出五档估值温度，映射到底仓/机动仓操作。Invoke when user asks 估值/贵不贵/合理买入区间/建仓/加仓/减仓/PEG/PE分位/估值温度."

**（2）五档温度表（唯一权威口径，硬编码；对齐主方案 6.2 + 理念文档第三部分 + F-9）**

| 档位     | PEG 区间（边界约定） | 操作建议                       |
| -------- | -------------------- | ------------------------------ |
| 显著低估 | PEG < 0.8            | 绝佳买点，底仓可加             |
| 合理     | 0.8 ≤ PEG ≤ 1.2    | 合理买入区间，先建 1/3 底仓    |
| 偏贵     | 1.2 < PEG ≤ 1.5     | 机动仓观望（过渡档，不买不卖） |
| 高估     | 1.5 < PEG ≤ 2.0     | 机动仓减持                     |
| 严重透支 | PEG > 2.0            | 加速清机动仓                   |

> **边界约定（消除歧义）**：PEG=0.8 归「合理」；PEG=1.2 归「合理」（1.2 为买入线，与理念文档备忘卡「PEG<1.2 买入」一致）；PEG=1.5 归「偏贵」；PEG=2.0 归「高估」。区间均为下开上闭（首档除外），保证任意 PEG 值有唯一档位归属。

**（3）主锚选择规则（四工具如何组合）**

| 场景                                  | 主锚                                                                     | 辅助校验                     |
| ------------------------------------- | ------------------------------------------------------------------------ | ---------------------------- |
| 常规增长（增速 >0 且非爆发期）        | PEG                                                                      | PSG、PE 分位、implied-growth |
| 爆发期（净利率 <5% 或 营收增速 >50%） | PSG（<0.5 显著低估 / 0.5~1.0 合理 / >1.0 高估）                          | PEG 降为辅助                 |
| 增速 ≤ 0（PEG 无意义）               | 直接判「不适用 PEG」，转 PSG（若营收增速 >0）或标注「亏损/负增长不适用」 | PE 分位、implied-growth      |

**（4）交叉校验与降级规则**

- PE 历史分位（<40% 低估 / 40%~60% 合理 / >60% 偏高）与主锚档位冲突时，**降一档处理并显式标注冲突原因**；
- implied-growth 红灯（隐含增速 > 指引上限 ×1.5）时，**主锚档位下调一档**；黄灯标注「偏贵预警」；绿灯标注「估值未透支」。

**（8）growth 口径与一致预期增速获取（补充自早期草稿，已按 D-1 口径过滤）**

PEG 的 `--growth` 输入为「未来 2 年 EPS 复合增速」，获取与校验流程：

| 步骤 | 操作                                                                                                                                                       | 说明                                                             |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 1    | 搜索一致预期：`anysearch.py "{公司名} 一致预期 EPS {年份}" --tag finance`；A 股辅源 `doubao_search.py --finance`；港美股 `exa_search.py --type deep` | 优先取 mean/consensus                                            |
| 2    | 提取未来第 2 年一致预期 EPS                                                                                                                                | 至少 2 个来源，误差 >10% 须标记                                  |
| 3    | 计算复合增速：`(未来第2年EPS / 当前TTM EPS)^(1/2) - 1`                                                                                                   | **必须经 `financial_rigor.py calc` 执行，禁止 LLM 心算** |
| 4    | 校验：一致预期增速 > 历史 3 年增速 ×2 时                                                                                                                  | 标注「过于乐观预警」                                             |

- **缺失降级**：无一致预期时，用历史 3 年 EPS 复合增速替代，并标注「基于历史增速推算，未经一致预期验证」；两者皆无则输出「数据不足，无法计算 PEG」。
- **同口径原则**：PE 与增速必须同口径（本技能统一 TTM PE + 未来 2 年一致预期增速）。

**（12）边界说明（过滤早期草稿，防止口径冲突与范围蔓延）**

以下早期草稿内容**不纳入**本技能，开发时不得照搬：

- 安全边际参考价位（低估/合理上下沿/高估阈值 + 合理PE=增速×1.2）：若需参考价位，用 `financial_rigor.py three-scenario` 输出，不在 SKILL 内定义价位公式；

**P1 硬止损——止损比例取值规则（按仓位状态）**

| 仓位状态                        | 止损比例 | 说明               |
| ------------------------------- | -------- | ------------------ |
| 建仓初期（持仓 < 目标仓位 50%） | 8%       | 严格执行，保护本金 |
| 底仓已建立且逻辑已验证（≥50%） | 10%      | 容忍空间更大       |
| 波动大标的（如科技成长股）      | 10%      | 避免噪音触发       |

- 触发止损 + 无明确基本面反转信号 → **无条件清仓**；
- 触发止损 + 有明确基本面反转（产业 / 管理层 / 财务三维度均未恶化）→ 暂不清仓，降为观察仓，并在报告说明证据；
- **10% 临界点处理**：10% 同时落在硬止损上限与「越跌越买」加仓下沿，触及先做止损复核——仅当三维度均未恶化且属已建立的底仓逻辑仓位时，才允许在合理估值下限加仓，否则一律退出。

**P2 逻辑止损——两个子项**

- **子项 A（连续 2 季业绩低于预期）**检查维度：营收增速（连续 2 季低于买入时预期增速 50%）、扣非净利润（连续 2 季放缓或为负）、合同负债/订单（环比连续 2 季下降 >10%）、产业景气交叉（行业景气同步下行）。
- **连续 3 季度趋势判定**（区分波动与拐点）：连续 3 季加速 → 不触发；单季放缓 + 全年预期不变 + 渗透率 <40% → 短期波动，不触发、仅调机动仓；连续 2~3 季减速 + 订单增速同步放缓 + 竞争加剧 → 趋势拐点，**触发 P2**。
- **子项 B（时间止损，满 4 季度未兑现）**判断维度：订单（合同负债/在手订单未显著增长）、收入（季度营收增速 < 买入时预期 50%）、利润（扣非未增长或为负）。满 4 季度 + 完全未兑现 → 减仓至观察仓（原仓位 30%~50%）；部分兑现 → 缓刑 1 季度；已兑现 → 继续持有并重置计数器。

**P3 产业景气拐点——检查维度**

| 检查项                   | 触发条件                      | 数据来源                                |
| ------------------------ | ----------------------------- | --------------------------------------- |
| 渗透率减速（二阶导转负） | 渗透率接近或超 50% 且增速放缓 | `mid-industry-research` 输出          |
| ROE 拐头向下             | 从上行转为走平或下行          | `qoq-accelerator` 输出                |
| 行业供需逆转             | 供不应求 → 供过于求          | `mid-industry-research` 输出          |
| 技术面辅助               | 当前价 < MA200 + 放量破位     | `stock_quote --momentum --auto-peers` |

**P4 估值透支——implied-growth 红黄绿灯联动**

| 判定 | 条件                      | 操作                 |
| ---- | ------------------------- | -------------------- |
| 红灯 | 隐含增速 > 指引增速 ×1.5 | 强化 P4，加速减持    |
| 黄灯 | 隐含增速在指引 ×1.0~1.5  | 温和预警，减持机动仓 |
| 绿灯 | 隐含增速 ≤ 指引增速      | 估值可消化，不触发   |

> P4 仅影响机动仓，不影响底仓；P4 与 P1/P2 同时触发时以高优先级为准。

**P5 性价比替换——细化**

- 更优标的 PEG 差距 >0.3 且产业趋势更强；
- 调仓前新标的须通过完整选股流程验证，不可仅因 PEG 低就替换；
- 逐步切换：先建新标的底仓，再清旧标的机动仓；
- 每季度最多 1 次。
