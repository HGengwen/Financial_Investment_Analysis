## 3. 技能一：`qoq-accelerator`（季度加速度分析）

### 3.1 目标

用连续 3 个季度财务数据判断"增速的加速度"（二阶导），区分短期波动与趋势拐点——对应理念文档 V2.0 第五部分矛盾二化解方案（第 338–340 行）与李进二阶导思维（第 55 行）。

### 3.2 核心判定规则（硬编码口径）

#### 规则 A：加速度定义与连续 3 季趋势判定（主规则）

**加速度（二阶导）定义**：

```
加速度 = 本季度增速 − 上季度增速
主口径加速度：YoY 营收增速的一阶差分（相邻两季 YoY 增速之差）
辅口径加速度：QoQ 营收增速的一阶差分（需先累计转单季）
```

**连续 3 季趋势判定**（以最近 3 个加速度值 a₁=最早、a₂=中间、a₃=最新）：

```
IF a₁ > 0 AND a₂ > 0 AND a₃ > 0:
    → 景气向上 🟢
ELIF a₁ < 0 AND a₂ < 0 AND a₃ < 0:
    → 拐点预警 🔴
ELSE:
    → 噪音/波动，不判拐点 🟡
```

等价表述（与开发方案 10.2 用例对齐，以 YoY 增速序列本身单调性判定）：

| 序列形态（最近 3 季 YoY 营收增速） | 判定 | 动作建议 |
| --- | --- | --- |
| 连续加速（Q(-3) < Q(-2) < Q(-1)） | **景气向上 🟢** | 维持/可加底仓（结合估值） |
| 连续减速（Q(-3) > Q(-2) > Q(-1)） | **拐点预警 🔴** | 触发 P2/P3 复核（交 `exit-signal`） |
| 单季异动（不单调，如 Q(-3)<Q(-2)>Q(-1)） | **噪音，不判拐点 🟡** | 标记噪音，底仓不动 |

> **硬编码边界**：
> - 相邻两季增速差 < 1 个百分点视为"持平"，不构成加速/减速（避免浮点误差误判）；
> - **仅当连续 3 季同向**才判"景气向上/拐点预警"；单季或连续 2 季异动**不得**判拐点，仅标注"需关注下季确认"（对齐 Q-3）；
> - 连续 3 季数据不足时标注"数据不足，趋势判定置信度降低"。

#### 规则 B：QoQ / YoY 双口径与一致性

| 口径 | 定义 | 用途 |
| --- | --- | --- |
| YoY（同比） | 本期累计值 ÷ 去年同期累计值 − 1 | **主口径**（累计值同比口径一致，无需换算） |
| QoQ（环比） | 本期单季值 ÷ 上期单季值 − 1 | 辅口径（**必须累计转单季**：单季值 = 本期累计 − 上期累计） |

**双口径一致性判定**（QoQ 受季节性影响时以 YoY 为准）：

| QoQ 方向 | YoY 方向 | 判定 |
| --- | --- | --- |
| 加速 | 加速 | 高置信度加速 |
| 减速 | 减速 | 高置信度减速 |
| 不一致 | — | **季节性干扰，以 YoY 为主**，须在报告标注"季节性干扰" |

#### 规则 C：利润增速 vs 营收增速匹配度

| 形态 | 判定 | 含义 |
| --- | --- | --- |
| 利润增速 − 营收增速 > +5pct | ✅ 匹配（利润跑赢） | 费用可控，规模效应 |
| −5pct ≤ 差值 ≤ +5pct | ⚠️ 基本匹配 | 正常，观察费用结构 |
| 差值 < −5pct（利润增速 < 营收增速） | 🔴 不匹配 | 警惕费用失控/增收不增利 |
| 营收增速 > 0 但利润增速 < 0 | 🔴 背离 | 强拐点预警信号 |

毛利率趋势辅助：毛利率稳定/提升→弱匹配可容忍；毛利率连续下降→不匹配为结构性（护城河侵蚀）。

#### 规则 D：先行指标佐证（`--advanced`）

| 先行指标 | 加速信号 | 减速信号 |
| --- | --- | --- |
| 合同负债 | 环比增长 > 营收增速（订单领先） | 环比下降 |
| 存货 | 存货增速 < 营收增速（周转改善） | 存货增速 > 营收增速（积压风险） |
| 研发费用 | 研发费用率提升（未来储备） | 研发费用率下降（短期化倾向） |

**综合判断**：先行指标与加速度方向一致→结论置信度高 ✅；部分一致→谨慎 ⚠️；相反→加速度方向可能被证伪 🔴。

#### 规则 E：季节性调整（辅口径专用）

强季节性行业（零售/旅游/农业/消费电子）Q1 环比 Q4 常系统性下滑，产生"假减速"。处理：

| 方法 | 规则 |
| --- | --- |
| YoY 辅助验证 | QoQ 连续为负但 YoY 加速/稳定 → 季节性干扰，维持"平稳 🟡" |
| 同季 QoQ 基准比较 | 调整后 QoQ = 本季 QoQ − 去年同季 QoQ；>0 为真实改善 |

> 季节性调整是辅助手段，**不替代连续 3 季主判定**；报告同时展示"调整前/调整后"结论。

#### 数据质量与降级处理

| 场景 | 处理 |
| --- | --- |
| 上市不足 8 季 | 用全部可用数据，标注"数据不足 8 季，趋势判定置信度降低" |
| 仅 4 季 | 可算加速度，但**不执行连续 3 季趋势判定**（样本不足），仅展示数据 |
| 仅 3 季 | 仅展示 QoQ 增速，不计算加速度 |
| 单季数据缺失 | 用相邻季度均值估算，标注"估算值" |
| 利润为负 | 改用 YoY 替代 QoQ，标注"因利润为负改用同比" |

### 3.7 与 exit-signal / valuation-thermometer / mid-thesis-drift 联动映射（硬编码）

| 本技能输出 | 目标技能 | 映射 |
| --- | --- | --- |
| 🔴 连续 3 季负加速（营收+利润） | `exit-signal` P3 | 产业景气拐点核心触发之一 |
| 🔴 连续 4 季负加速 + 业绩低于预期 | `exit-signal` P2 | 逻辑止损辅助触发 |
| 🔴 连续负加速 | `valuation-thermometer` | 估值修正 **−0.5 档** |
| 🟢 连续 2 季以上正加速 | `valuation-thermometer` | 估值修正 **+0.3 档** |
| 🟡 平稳/波动 | `valuation-thermometer` | 无修正 |
| 连续 3 季负加速 | `mid-thesis-drift` | 作为漂移检测的核心证据（Sprint 3 消费） |

> 修正幅度上限 **±1 档**，防止过度修正。

**P3 完整触发条件（跨技能依赖，非本技能单点判定）**：加速度连续 3 季为负是 P3 的**核心输入之一**，但 P3 完整触发还需结合：
- 渗透率位置（>50% 且增速放缓）→ 由 `mid-industry-research` 提供（Sprint 3）；
- ROE 趋势（拐头向下）→ 由 `stock_financial.py --indicator ROE` 提供；
- 技术面辅助（MA200 下方 + 放量破位）→ 由 `trend-momentum-scan` 提供。

> 硬编码：加速度连续 3 季为负 → 报告中必须标注"P3 产业景气拐点预警"，不可因"产业前景长期向好"而弱化该预警。

#### 加速度-估值二维矩阵（与 valuation-thermometer 联合决策）

将加速度评级与 PEG 五档估值温度联合，生成操作建议：

| 加速度 \ 估值 | 显著低估（PEG<0.8） | 合理（0.8~1.2） | 偏贵（1.2~1.5） | 高估（>1.5） | 严重透支（>2.0） |
| --- | --- | --- | --- | --- | --- |
| 🟢 加速向好 | 积极加仓 | 建仓/加仓 | 机动仓观望 | 机动仓不加仓 | 不加仓，等估值回落 |
| 🟡 平稳 | 分批建仓 | 持有/小仓位建 | 持有观望 | 机动仓减持 | 减机动仓 |
| 🔴 减速/拐点 | 轻仓试探 | 持有不动 | **机动仓减持** | **减机动仓** | **加速清机动仓** |

**核心逻辑**：加速度为正且估值合理 → 最佳买点（戴维斯双击条件）；加速度为负且估值偏高 → 双重风险，必须减仓；加速度为负但估值极低 → 可能是短期波动，轻仓试探。当 🔴 减速 且 高估/严重透支 时，同时触发 P3（景气拐点）与 P4（估值透支），以 P3 优先。

### 3.8 风控硬编码（不可被 AI 自由裁量）

| 硬性规则 | 不可做的事 |
| --- | --- |
| 加速度连续 3 季为负 → 必须判"拐点预警 🔴" | 不可输出"虽连续减速但产业前景向好"等弱化表述 |
| 单季负加速 ≠ 拐点 | 不可因单季波动触发拐点预警 |
| 利润连续 2 季为负且营收为正 → 必须判"不匹配 🔴" | 不可输出"阶段性费用投入"等美化表述 |
| QoQ 与 YoY 方向不一致 → 必须标注"季节性干扰" | 不可忽略方向矛盾直接取 QoQ 结论 |
| 加速度与先行指标相反 → 必须标注"方向可能被证伪" | 不可忽略反向先行信号 |
| 修正因子幅度 ≤ ±1 档 | 不可叠加多个正向因子上调超 1 档 |
| 数据不足 4 季 → 必须标注置信度降低 | 不可在数据不足时仍给明确拐点判定 |
| 禁止 LLM 心算 | 所有增速/加速度/匹配度须经工具链 |

## 4. 技能二：`trend-momentum-scan`（持仓动量体检）

### 4.1 目标

对**已持仓**标的做纯技术面体检，判断趋势是否走坏并触发技术破位预警。与 `mid-trend-tech-screen`（选股正向排序）区分（开发方案 F-6，第 53 行）。

> 定位一句话：`mid-trend-tech-screen` 回答"哪些股票值得买入？"（正向排序）；`trend-momentum-scan` 回答"我手里的股票趋势还在吗？"（体检预警）。

### 4.2 核心判定规则（硬编码口径）

#### 规则 A：SMR / 绝对动量（双口径，消除"SMR 正负"歧义）

| 字段 | 语义 | 判定 |
| --- | --- | --- |
| `return_250d_pct` | 250 日涨幅（绝对动量） | ≥ 0 为正；< 0 为负 |
| `smr_percentile` | 板块内相对强度百分位（0–100） | **>70 强势 🟢 / 40~70 中性 🟡 / <40 弱势 🔴**；**None = 截面不可用** |

> **口径约定**：测试用例 M-1/M-2 的"SMR 正负"指 `return_250d_pct` 符号；`smr_percentile` 作为相对强弱辅助，None 时按 M-3 降级。

**板块相对强弱（个股涨跌幅 vs 板块平均，`--auto-peers` 截面补充）**：

| 个股 vs 板块 | 判定 | 含义 |
| --- | --- | --- |
| 个股涨跌幅 > 板块平均 ×1.5 | 显著跑赢 | 个股有 α，继续持有 |
| 个股涨跌幅 > 板块平均 | 小幅跑赢 | 正常表现 |
| 个股涨跌幅 < 板块平均 | 跑输板块 | 个股相对走弱，需警惕 |
| 个股涨跌幅 < 板块平均 ×0.5 | 显著跑输 | 个股 α 消失，考虑替换 |

> SMR 百分位反映"过去 6 个月累计相对位置"，板块相对强弱反映"近期相对动量"；二者互补，SMR 高但近期跑输板块 → 标注"相对走弱需跟踪"。

#### 规则 B：RSI50 超买超卖

| RSI50 | 状态 |
| --- | --- |
| > 70 | 超买 🟠（机动仓可部分止盈，不追高） |
| 50 ~ 70 | 偏强 🟢（动量健康） |
| 30 ~ 50 | 偏弱 🟡（关注是否跌破关键均线） |
| < 30 | 超卖 🔴（结合基本面判断是否逆势加仓） |

#### 规则 C：MA50 / MA200 多空排列

| 排列 | 判定 |
| --- | --- |
| 股价 > MA50 > MA200 | 多头排列 🟢，趋势健康 |
| MA50 > 股价 > MA200 | 中性偏弱 🟡，短期均线已破 |
| 股价 < MA200（不论 MA50 位置） | 空头排列/破位 🔴，**独立否决项** |

**价格偏离度辅助**（股价 ÷ MA200）：>1.3 极度偏离 / 1.1~1.3 健康溢价 / 0.9~1.1 合理 / 0.7~0.9 深度折价 / <0.7 极度折价（需查基本面是否恶化）。

#### 规则 D：破位预警阈值（欧奈尔）与 MA200 破位决策树（FIX-2 修正）

| 级别 | 触发条件 | 动作 |
| --- | --- | --- |
| 初级预警 | close < MA50 且放量（量比 > 1.5） | 减机动仓，观察 |
| 独立技术预警 | close < MA200 | **降级至观察仓**（不直接映射单一 P 级） |

**MA200 破位决策树**（融入"仓位状态"变量）：

```
MA200 破位
├─ 建仓初期（持仓 < 最终仓位 50%）
│   ├─ 亏损 > 8% → 交 exit-signal P1 硬止损
│   └─ 亏损 ≤ 8% → 降级至观察仓，等待重新站上 MA200
├─ 底仓已建且三维度（产业/管理层/财务）未恶化
│   ├─ 缩量破位（量比 < 0.7）→ 给 1~2 周观察期
│   └─ 放量破位（量比 > 1.5）→ 机动仓减持 50%，底仓不变
└─ 任一维度恶化或逻辑证伪 → 立即交 exit-signal 完整检查/清仓
```

**预警解除条件**：观察期内股价**放量重新站上 MA200** → 解除预警，恢复原仓位；持续运行在 MA200 下方超 2 周且未站回 → 按放量破位处理，不再延长观察期。

#### 规则 E：成交量辅助（欧奈尔抛售日）

| 信号 | 定义 | 影响 |
| --- | --- | --- |
| 放量上涨 | 量 > 5 日均量 ×1.5 且上涨 | 确认趋势 🟢 |
| 放量下跌 | 量 > 5 日均量 ×1.5 且下跌 | 风险信号，可能反转 |
| 缩量下跌 | 量 < 5 日均量 ×0.7 且下跌 | 抛压有限，可能洗盘 |
| 天量滞涨 | 量异常放大、股价不涨 | 危险信号，可能见顶 |

> 欧奈尔抛售日：放量下跌（量比 >1.5 且跌幅 >0.2%）记 1 个；一周内 ≥3 个抛售日 → 输出"抛售日预警"，建议大幅降低总仓位。

#### 综合趋势判定矩阵

| 条件组合 | 综合评级 | 操作建议 |
| --- | --- | --- |
| SMR>70 且 RSI>50 且 股价>MA50>MA200 | 趋势健康 🟢 | 底仓+机动仓继续持有 |
| SMR>40 且 RSI>30 且 股价>MA200 | 趋势正常 🟡 | 底仓持有，机动仓观望 |
| SMR<40 或 RSI<30 或 MA50<股价<MA200 | 趋势弱化 🟠 | 底仓不变，机动仓减仓 |
| 股价<MA200（任一组合） | 趋势破位 🔴 | **降级至观察仓**（独立否决，见决策树） |

| Q-3 | 10% → 18% → 8% | 单季波动，不判拐点（标记噪音） |

**`trend-momentum-scan`**

| 编号 | 构造输入 | 预期输出 |
| --- | --- | --- |
| M-1 | `return_250d_pct<0`、MA50<MA200、RSI50 超卖 | 技术破位预警 |
| M-2 | `return_250d_pct>0`、MA50>MA200 | 趋势健康，无需动作 |
| M-3 | 港股标的（板块截面不可用） | SMR 置 None 并标缺口，不静默使用错误数据 |
