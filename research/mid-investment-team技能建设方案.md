## 一、背景与问题

当前 `.trae/skills/investment-team/SKILL.md` 是**长期价值投资版**（段永平-巴菲特-芒格-李录口径，10 年持有，护城河/终局思维），与 `V2.0.md`（欧奈尔-林奇-郑希-李进口径，1~3 年景气投资）不匹配。

`research/early-version/investment-team技能文件（草稿）.md` 是参考长期版后、针对 1~3 年目标修改的草稿（frontmatter `name: mid-investment-team` 已正确），但存在以下问题，需在转正为 `mid-investment-team` 时逐一修正：

1. **frontmatter description 四大师分工混乱**：出现「李进」两次，且「林奇验证生意与估值」是长期版段永平口径残留。
2. **四 Agent 职责与 V2.0 权威分工错位**（详见第五节修正 2）：
   - 草稿把「估值定价 / PEG 五档」给欧奈尔 → V2.0 应归林奇；
   - 草稿把「管理层四维度评估」给林奇 → V2.0 应归李进；
   - 草稿把「产业景气度验证」给林奇 → V2.0 应归郑希；
   - 草稿 Agent 4（李进）缺少「管理层与科研转化评估、治理一票否决」。
3. **卖出纪律用草稿自造的 P0~P6**（权威口径应为 P0~P5，时间止损归 P2，技术面不构成独立层级）。
4. **PEG 五档自行重复定义**（违反「引用不重复定义」）。
5. **卖出优先级自相矛盾**：决策优先级表 P5=时间止损，正文卖出规则 P5=性价比替换。
6. **附录 D「原版 vs 完善版」差异对照表**属草稿开发过程说明，转正时应删除。
7. **缺少执行流程范式**：草稿是内容模块罗列，缺少长期版的七步执行流程（展示团队框架 → 信息丰富度评估 → A 股财报下载 → 4 Agent 并行 → 进度跟踪 → Team Lead 汇总 → 保存报告）。
8. **缺少信息丰富度评级（A/B/C 级）与 AI 研究偏见预警**。
9. **缺少数据抽检准出流程（report_audit.py）**。
10. **缺少正式报告结构**（一句话结论 → 四维评分总表 → 核心数据 → 各维度摘要 → Bull/Bear → 买入建议 → 总结）。

## 二、设计原则

1. **物理隔离**：中期链（1~3 年）与长期链（10 年）口径分离，禁止「护城河永续」「终局思维」「持有 10 年」等长期术语；采用欧奈尔-林奇-郑希-李进四大师口径。
2. **四位大师口径（对齐 V2.0「四位大师与个人投资者的连接方式」表）**：

   | 大师 | 思维模式 | 在框架中的角色 |
   |------|---------|---------------|
   | 欧奈尔 | 工程师思维 · 信号与纪律 | **风控底线**：8% 止损、卖出触发、防止深度套牢 |
   | 林奇 | 侦探思维 · 常识与求证 | **选股起点**：从生活体验发现机会，用常识做第一道筛选 |
   | 郑希 | 物理学家思维 · 周期与第一性原理 | **赛道选择**：用 ROE 拐点和全球产业景气定方向 |
   | 李进 | 系统工程师思维 · 均衡与渗透率 | **组合管理 + 治理**：渗透率定位、底仓/机动仓、管理层与科研转化评估、治理一票否决 |

3. **引用不重复定义**（中期技能体系铁律）：
   - 估值档位 → 引用 `valuation-thermometer`（PEG 五档判定/边界约定一律以其输出为准，不自行重复列出阈值）
   - 卖出纪律 → 引用 `exit-signal`（P0~P5 唯一权威口径，时间止损归 P2，技术面仅作 P3 辅助、不构成独立层级）
   - 产业景气/渗透率 → 引用 `mid-industry-research`
   - 管理层 20 分制 / 科研转化 20 分制 → 引用 `mid-management-deep-dive` 与 V2.0 理念文档
4. **数据规范**：双源交叉验证、误差 >1% 标记、禁止 LLM 心算、`financial_rigor.py` 精确计算、`report_audit.py` 抽检准出。
5. **网络限制**：禁止 Anthropic WebSearch/WebFetch，统一本地五工具（anysearch/doubao_search/exa_search/tavily_search/web_search）。
