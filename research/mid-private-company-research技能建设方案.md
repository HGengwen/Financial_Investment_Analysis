## 一、背景与目标

`private-company-research`（长期链）是"未上市公司研究"技能，用 **6 个并行 Agent** 拼凑分散信息还原企业真实价值，回答"这家公司现在值多少钱、值不值得投资"。其底层框架绑定段永平/芒格式长期价值投资（护城河六维、终局市值倒推法、5~10 年视角），与 1~3 年景气投资的"渗透率/ROE 拐点/PEG/二阶导/地缘"框架**不匹配**。

`mid-private-company-research` 的核心转变是**研究问题本身的重构**：

| 维度 | 长期版 `private-company-research` | 1~3 年景气版 `mid-private-company-research` |
| --- | --- | --- |
| 核心问题 | 这家公司现在值多少钱？内在价值是多少？ | **这家公司若上市，是否符合 1~3 年景气 GARP 框架？上市后值得持有吗？** |
| 时间视角 | 5~10 年永续视角 | 1~3 年景气周期视角（上市后估值即接受景气检验） |
| 估值方法 | 最近融资 / 可比公司 / DCF / **终局市值倒推（5~10 年）** / 交易对标 | 最近融资 / 可比 GARP 标的 / DCF 短周期 / **PEG 潜力推演（上市后 PE÷增速）** / 交易对标 |
| 壁垒判断 | 护城河六维（永续壁垒） | 1~3 年内能否守住赛道地位与 ROE 趋势（景气竞争力） |
| 卖出联动 | "论文已破就止损"（论文语言） | YYN→ 转 `exit-signal` P0~P5 + `mid-thesis-drift` H1~H6 |
| 报告路径 | `reports/{公司}/{公司}-private-{YYYYMMDD}.md` | `reports/{公司}/{公司}-mid-private-{YYYYMMDD}.md`（物理隔离） |

**目标定位**：本技能是**上市前的“预研建档”工具**，为上市后的 1~3 年景气投资**提前建立标的池与判断框架**——判断一家未上市公司"上市后是否可能成为 GARP 标的、值不值得在 IPO/Pre-IPO/上市后等待机会买入"，而非研究"现在是否买入未上市股权"。

## 四、mid-private-company-research SKILL.md 结构设计

严格比照 `private-company-research/SKILL.md` 的叙事范式（frontmatter + 定位 + 六 Agent + 报告结构 + 工具 + 原则），叠加景气口径与"引用不重建"原则。

### 4.1 frontmatter

```yaml
---
name: mid-private-company-research
description: "未上市公司研究（1-3年景气版）：6 个并行 Agent 拼凑分散信息，判断'这家公司若上市，是否符合 1~3 年景气 GARP 框架、值得持有吗'。覆盖商业模式/财务/竞争/风险治理/科研IP/信号挖掘，输出林奇六类分类 + PEG 潜力推演 + 渗透率位置 + ROE 趋势 + 管理层·科研·地缘评估 + 是否值得等待上市。Invoke when user asks 未上市公司 / Pre-IPO / 一级市场 / 独角兽研究（1-3年景气视角）."
disable-model-invocation: true
---
```

### 4.2 章节大纲

1. **标题与定位** — "未上市公司研究（景气投资版）：上市后 GARP 适配性预判"；明确"为上市后 1~3 年景气投资建档"，非"现在买一级股权"。
2. **设计理念** — 四位大师视角：林奇"从生活常识拼出商业模式真相 + 六类分类"、郑希"ROE 拐点与产业景气"、李进"管理层四维 + 科研转化 + 地缘六维 + 渗透率坐标"、欧奈尔"信号驱动与风控底线"。
3. **适用场景与不适用场景** — 未上市公司/Pre-IPO/独角兽；不适用：已上市公司（转 `mid-investment-research`）与纯一级股权现在买入决策。
4. **执行流程（七步）**：
   - 第一步：确认参数（公司名/市场/是否已知上市计划/研究侧重），信息太少先反问。
   - 第二步：信息可得性分级 A/B/C（A 多源可验证 / B 单源 + 需交叉 / C 情报稀缺用替代数据）。
   - 第三步：启动 6 个并行研究 Agent（同一条消息 6 次 Task 调用）。
   - 第四步：实时跟踪进度。
   - 第五步：Team Lead 综合研判 + GARP 适配性总览 + "值得等待上市吗"判定（✅/⚠️/❌/❓）。
   - 第六步：上传研究报告（wiki/tasks）。
   - 第七步：保存报告到 `reports/{公司}/{公司}-mid-private-{YYYYMMDD}.md`。
5. **六个 Agent 详细设计**（见第五节）。
6. **GARP 适配判断与估值推演**（见第六节）。
7. **报告结构**（见第七节）。

## 五、六 Agent 角色设计（对齐四位大师）

Agent 名称与长期版保持一致，但每个 Agent 增加景气大师视角与"上市后 GARP 适配"聚焦：

| Agent | 核心问题 | 景气视角特别关注（新增） | 对应大师 |
| --- | --- | --- | --- |
| **business-decoder**（商业模式解码） | 这家公司靠什么赚钱？可持续吗？ | 必须给出**林奇六类分类**（快速增长/稳定增长/周期/困境反转/隐蔽资产/缓慢增长）+ 是否有生活常识可验证的产品力/客户喜爱度 | 林奇 |
| **financial-detective**（财务侦探） | 财务真实性与成长质量如何？ | **郑希 ROE 趋势四维推断**（利润率/资产周转/财务杠杆/再投资回报率，↑/→/↓）+ 营收增速与扣非利润匹配度（识别题材炒作） | 郑希 |
| **competitive-mapper**（竞争格局测绘） | 赛道格局与公司位置？ | **渗透率位置**（<5%/>15%~30%/>50%）+ CR3 集中度 + 全球产业链分工位置 + 供需格局 | 郑希 + 李进 |
| **risk-governance-analyst**（风险与治理分析） | 治理与外部风险？ | **李进管理层四维度**（诚信/股东态度/战略执行/稳定性+一票否决检查）+ **地缘政治六维** | 李进 + 欧奈尔 |
| **tech-ip-analyst**（技术与 IP 分析） | 技术壁垒与转化能力？ | **李进科研转化四维度**（研发强度≥15%/资本化率<30%/研发人员占比≥30%/新产品收入占比≥20%/ROIC>WACC 且≥10%）+ "华为式抗封锁"韧性 | 李进 |
| **signal-miner**（信号挖掘） | 分散的替代数据隐藏什么信号？ | 上市时机信号（融资轮次/辅导备案/赛道热度）+ 是否出现"题材炒作 vs 真实趋势"特征 | 欧奈尔 |

每条关键结论统一标注：**来源链接 / 一句话摘要 / 置信度（🟢高 / 🟡中 / 🔴低）**。

## 六、GARP 适配判断与估值推演（核心新增）

### 6.1 林奇六类分类（必答）

| 分类 | 特征 | 上市后 GARP 适配 |
| --- | --- | --- |
| 快速增长型 | 增速>20%，PEG 工具适用 | ✅ 核心适配 |
| 稳定增长型 | 增速 10%~20% | ✅ 用远期 PE |
| 周期型 | 利润随周期波动 | ⚠️ 需景气择时 |
| 困境反转型 | 前期低迷，有望反转 | ⚠️ 看反转证据 |
| 隐蔽资产型 | 含未反映在报表的资产 | ⚠️ 看资产兑现 |
| 缓慢增长型 | 增速<10% | ❌ 不适合 1~3 年景气 |

### 6.2 PEG 潜力推演（替换长期版"终局市值倒推法"）

上市后 PEG = 预估上市 PE ÷ 未来 1~3 年净利润复合增速。五档对齐 `valuation-thermometer`：

| 档位 | 范围 | 结论 |
| --- | --- | --- |
| 显著低估 | PEG<0.8 | 若上市且增速可持续，为绝佳潜在 GARP 标的 |
| 合理 | 0.8~1.2 | 符合 GARP 合理区 |
| 偏贵 | 1.2~1.5 | 需等待更优价格或景气再确认 |
| 高估 | 1.5~2.0 | 上市初期机动仓需谨慎 |
| 严重透支 | >2.0 | 不符合 GARP，回避或仅观察 |

> **注意**：一级市场最近融资估值/Pre-IPO 估值可能已显著高于上市后合理 PE，需明确"当前一级定价"与"上市后合理定价"的**折溢价**，防止把一级高估值直接套到上市后判断。

### 6.3 渗透率位置判定（对齐 V2.0 + mid-thesis-drift H1）

| 区间 | 判定 |
| --- | --- |
| <5% | 过早，不确定性高 |
| 5%~15% | 培育期，关注是否逼近 15% 临界点 |
| 15%~30% | **黄金加速区（重仓窗口）** |
| 30%~50% | 成熟期，关注增速二阶导 |
| >50% | 警戒减速区 |

### 6.4 估值方法改造对照

| 长期版方法 | 中期版改造 |
| --- | --- |
| 最近融资估值法 | 保留：仅作"当前一级市场定价锚"，并标注与上市后合理估值的折溢价 |
| 可比上市公司法 | 改造：对标**已上市 GARP 标的**的 PEG/PE 区间，而非同类公司绝对市值 |
| DCF 情景分析 | 改造：1~3 年短周期折现（配合景气假设 H1~H6），不做 10 年终局 |
| 终局市值倒推法（5~10 年） | **删除**，替换为 **PEG 潜力推演法**（见 6.2） |
| 交易对标法 | 保留：参考同类公司并购/融资交易倍数作交叉验证 |
