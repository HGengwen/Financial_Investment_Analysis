# mid-industry-funnel 技能方案与计划

> 状态：已确认并按方案完成开发（2026-09-01）。
> 日期：2026-09-01

---

## 一、现状与问题

1. `.trae/skills/industry-funnel/SKILL.md` 是长期（10年）漏斗技能，核心为「巴菲特/芒格/段永平/李录」四大师 + 价值投资 5 条硬指标（PE/ROE/现金流/负债率/护城河）+ 管理层五原则，与 `research/个人投资者1~3年中长期投资思想与理念 V2.0.md` 的中期理念不匹配。
2. 中期链目前缺一个**「赛道确定后，从全市场/赛道内候选池逐层漏斗精选到 3+2 终选组合」的个股级漏斗技能**。现有 `mid-industry-research` 只出赛道结论与候选清单（不出个股买卖价位），`mid-trend-tech-screen` 是五维打分排序（输出 S/A/B/C 评级），二者都不产出「收敛到 3 家终选」的组合级结论。
3. 用户已提供基础稿 `research/early-version/industry-funnel技能文件（草稿）.md`（已按中期改造的草稿），以此为基础改写。
4. **草稿 Markdown 格式严重损坏**（大量表格/代码块被逐行 ` ``` ` 包裹），新技能文件需**完全重写**，而非基于混乱格式做结构化复制。

## 二、新技能定位与边界（本次最关键的结构决策）

`mid-industry-funnel` 定位为中期链的**个股级漏斗精选技能**，与长期 `industry-funnel` 对等、与中期现有技能分工如下：

| 技能 | 层级 | 职责 | 输出 |
| --- | --- | --- | --- |
| `mid-industry-research` | 赛道级 | 四维筛选判断赛道值不值得进（TAM/渗透率/业绩兑现/地缘） | 赛道评级 + 头部公司清单（Tier 1~4） |
| **`mid-industry-funnel`（新）** | **个股级漏斗** | **在赛道已确认的前提下，对候选池逐层漏斗精选** | **3 家底仓 + 2 家机动仓终选组合** |
| `mid-trend-tech-screen` | 个股级排序 | 五维打分 + 地缘修正 + 技术面止损，正向排序 | S/A/B/C 评级 |
| `mid-investment-checklist` | 个股级验证 | 买入前七关硬门槛 | 通过/否决 + 仓位建议 |

**边界三原则**：
1. **赛道判断引用不重做**：`mid-industry-funnel` 第一步的赛道结论**直接引用** `mid-industry-research` 的四维筛选结果（A/B 级准入），不重复做 TAM/渗透率的独立测算。
2. **漏斗 vs 排序分工**：`mid-industry-funnel` 用「硬指标淘汰 → 四大支柱 → 四大师研判」的**逐层漏斗**收敛出 3+2 组合；`mid-trend-tech-screen` 用**五维加权打分**做正向排序。两者互补：漏斗出终选组合后，可对终选标的跑 `mid-trend-tech-screen` 做技术面确认（可选）。
3. **终选不越权**：`mid-industry-funnel` 只输出「终选组合 + 仓位区间 + 建仓价区间 + 止损价」，**不替代** `mid-investment-checklist` 的买入前七关硬门槛；终选标的须再过 `mid-investment-checklist`。

## 三、漏斗结构设计（五步，保留草稿骨架 + 对齐 V2.0 口径）

| 步 | 名称 | 收敛 | 核心内容 |
| --- | --- | --- | --- |
| 第一步 | 赛道确认与候选池构建 | 全市场 → 30~60 家 | 引用 `mid-industry-research` 赛道评级与 Tier 1~4 清单，构建候选池 |
| 第二步 | 硬指标粗筛 | 30~60 → 10~20 家 | 对齐 V2.0 财务门槛 + 估值 + 流动性 + 治理 + 地缘（见第四节 #2） |
| 第三步 | 四大支柱精析 | 10~20 → 5~8 家 | 产业景气/公司基本面/管理层与治理/地缘与环境 + PEG 估值 + 「假如空仓」测试 |
| 第四步 | 四位大师研判 | 5~8 → 3+2 终选 | 欧奈尔/林奇/郑希/李进四视角 + 管理层 20 分 + 科研转化 20 分 + 四大矛盾化解 + P0~P5 优先级 |
| 第五步 | 综合输出 | 终选组合 | 3+2 组合 + 底仓/机动仓分离 + 建仓价/止损价 + 季度复盘清单 |

## 四、草稿与 V2.0 + 现有中期体系的冲突对齐（10 处）

| # | 冲突点 | 草稿现状 | 对齐方案（权威口径） |
| --- | --- | --- | --- |
| 1 | 渗透率口径不一致 | 草稿「5%~20% 爆发区间」；左侧<5%、右侧5-20%、透支>30% | 统一 V2.0/`mid-industry-research` 口径：<5% 过早、**10%~30% 黄金区**、15% 加速临界、30%~50% 成长中后期、>50% 成熟兑现 |
| 2 | 硬指标与 V2.0 财务门槛脱节 | 草稿 6 条：产业景气/财务健康(现金流/净利>0.7)/估值(PEG<2.0)/流动性(成交>5000万)/治理/地缘 | 保留 6 条框架，内容对齐 V2.0 初筛五门槛：营收≥10亿、3年CAGR≥15%、负债率<60%、经营现金流为正、3年至少2年扣非为正；流动性改为**日成交额>1亿（市值<100亿放宽>3000万）** |
| 3 | 「3+2」仓位冲突 | 草稿「3家核心单只≤25%、总仓位≤80%」 | 对齐 V2.0：核心 3 只单只 **12%~15%**（绝对上限≤20%）、卫星 2~3 只单只 5%~8%、单行业≤40%、底仓 60%~80%/机动仓 20%~40%、持股 5~10 只 |
| 4 | 管理层评分决策线过粗 | 草稿「≥15分重仓；<12分直接剔除」 | 对齐 V2.0：管理层 **≥15 可重仓、10~14 轻仓、<10 回避**；科研转化 **≥15 可重仓、10~14 轻仓、<10 伪科技回避** |
| 5 | 决策优先级金字塔层级不足 | 草稿 5 级，逻辑止损不含时间止损 | 统一 **`exit-signal` P0~P5 六级**，时间止损并入 P2，直接引用不重建 |
| 6 | PEG 五档重复定义 | 草稿自行定义五档 | 五档**唯一权威**由 `valuation-thermometer` 定义，本技能**引用不重复** |
| 7 | 风控编号缺失 | 草稿无硬编码编号 | 新技能风控码命名 **F-1~F-10**，避开 `mid-industry-research` 的 R-1~R-10 与 `mid-investment-checklist` 的 MC-1~MC-10 |
| 8 | 与 `mid-industry-research` 边界重叠 | 草稿第一步「全市场扫描 + 赛道锁定」实为赛道级判断 | 赛道结论**引用** `mid-industry-research`，本技能聚焦「赛道确定后的个股漏斗」（见第二节） |
| 9 | 报告输出路径缺失 | 草稿未定义落盘路径 | 新增 `reports/{行业名}-mid-funnel-{YYYYMMDD}.md`（对齐 `mid-industry-research` 的扁平行业级路径） |
| 10 | 思维大师残留 | 草稿「一、兼容性诊断」首表残留「偏重巴菲特/芒格/段永平」表述 | 全文统一为欧奈尔/林奇/郑希/李进四大师，剔除长期模型表述 |

## 五、权威引用清单（不自建、不重复）

| 内容 | 权威来源 | 本技能处理 |
| --- | --- | --- |
| 赛道四维筛选（TAM/渗透率/业绩/地缘） | `mid-industry-research`（A/B 级准入） | 第一步引用结论 |
| PEG 五档 | `valuation-thermometer` | 第二步估值底线 + 第三步估值快评，引用不重定义 |
| 卖出优先级 P0~P5 | `exit-signal` | 第四步决策金字塔，引用不重建 |
| 五维打分/技术面止损 | `mid-trend-tech-screen` | 可选联动：终选标的做技术面确认 |
| 买入前七关硬门槛 | `mid-investment-checklist` | 终选标的的后置动作，不替代 |
| 精确算术 | `financial_rigor.py` | 全部估值/仓位/打分计算 |

## 六、风控硬编码 F-1~F-10（拟定，开发时细化）

| 编号 | 规则 | 不可做的事 |
| --- | --- | --- |
| F-1 | 赛道评级非 A/B（引用 `mid-industry-research`）→ 终止漏斗 | 不得对不合格赛道执行漏斗 |
| F-2 | 财务五门槛任一不过（营收<10亿/3年CAGR<15%/负债率>60%/现金流为负/扣非连续亏损）→ 淘汰 | 不得以「成长想象」豁免财务底线 |
| F-3 | PEG>2.0 → 严重透支，淘汰出终选（仅可观察） | 不得纳入 3+2 终选 |
| F-4 | 流动性不达标（日成交<1亿且市值≥100亿；市值<100亿时<3000万）→ 淘汰 | 不得纳入机动仓 |
| F-5 | 治理一票否决（立案调查/大额违规担保/非标审计）→ 淘汰 | 不得进入精析 |
| F-6 | 地缘红线（实体清单核心对象且无抗封锁方案）→ 淘汰 | 不得以「利空出尽」纳入 |
| F-7 | 管理层<10 分或科研转化<10 分 → 淘汰（伪科技按传统制造业估值） | 不得重仓 |
| F-8 | 所有估值/市值/PEG/仓位计算必须走 `financial_rigor.py` | 禁止 LLM 心算 |
| F-9 | 终选组合违反仓位上限（单只>20%/单行业>40%）→ 强制调整 | 不得输出超限组合 |
| F-10 | 关键数据单一来源 → 标注「单一来源，置信度低」 | 不得作为确定性结论 |
