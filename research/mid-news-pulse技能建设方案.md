## 一、背景与目标

`news-pulse`（长期链）是"股价异动快速归因"情报响应技能，本身不绑定特定大师框架，因此与 1~3 年景气投资框架的**底层架构冲突较低**——四 Agent 并行侦察（公司事件/监管政策/行业对手/市场情绪）可以复用。差异集中在**输出口径**与**风控联动**上：

| 维度 | 长期版 `news-pulse` | 1~3 年景气版 `mid-news-pulse` |
| --- | --- | --- |
| 归因性质判断 | 价值事件 / 情绪波动 / 真因不明 / 混合 | 同四类，但**叠加"对景气逻辑的影响"**（ROE/二阶导/渗透率/订单/毛利率/地缘） |
| 风控联动 | "是否触发投资论文重审" | 升级为"**是否触发 P0~P5 卖出纪律**"，命中即提示转 `exit-signal` |
| 行动建议 | 重审论文 / 财报研读 / 管理层重审 / 调仓 | 卖出纪律检查 + 景气假设复核（`mid-thesis-drift` H1~H6）+ 估值复核 + 财报研读 + 管理层重审 |
| 后续跟踪 | 一般性跟踪清单 | 聚焦**景气指标**（ROE/二阶导/渗透率/订单/毛利率/地缘） |
| 报告路径 | `reports/{公司}/{公司}-news-{YYYYMMDD}.md` | `reports/{公司}/{公司}-mid-news-{YYYYMMDD}.md`（物理隔离） |

**目标**：10~15 分钟内回答"发生了什么？真因是什么？是否触发 P0~P5 卖出纪律？是否动摇景气逻辑？"——是**情报快速响应 + 风控触发检查**，不是深度投研。

## 四、mid-news-pulse SKILL.md 结构设计

严格比照 `news-pulse/SKILL.md` 的六步范式，叠加景气口径：

### 4.1 frontmatter

```yaml
---
name: mid-news-pulse
description: "公司新闻脉搏（景气投资版·1-3年）：股价异动快速归因。4 个并行 Agent 侦察公司事件/监管政策/行业对手/市场情绪，产出事件时间线 + 异动主因 + 对景气逻辑（H1~H6）的影响 + 是否触发 P0~P5 卖出纪律。Invoke when user asks 股价异动/暴跌/暴涨/为什么跌/为什么涨/新闻归因."
disable-model-invocation: true
---
```

### 4.2 章节大纲

1. **标题与定位** — "公司新闻脉搏（景气投资版）：股价异动快速归因 + P0~P5 卖出纪律触发检查"；明确"快响应 + 风控触发"，非深度投研。
2. **设计理念** — 四大师风控视角：欧奈尔"异动是信号不是噪音"，李进/郑希"判断是否动摇景气逻辑"，回答"是什么/为什么/是否触发卖出/是否动摇景气"四问。
3. **适用场景** — 与长期版一致（触发线单日 ±5%、一周 ±10%）；"不适用"改为中期技能清单。
4. **执行流程（六步）**：
   - 第一步：确认参数与场景（公司名/时间窗口/股价异动/关注侧重），若只说公司名先反问。
   - 第二步：信息可得性分级 A/B/C。
   - 第三步：启动 4 个并行侦察 Agent（同一条消息 4 次 Task 调用）。
   - 第四步：实时跟踪进度。
   - 第五步：Team Lead 综合归因 + P0~P5 卖出纪律联动检查 + 景气影响评估。
   - 第六步：保存报告到 `reports/{公司}/{公司}-mid-news-{YYYYMMDD}.md`。
5. **四个 Agent 详细设计**（见第五节）。
6. **归因报告结构**（见第六节）。
7. **工具使用指南** — 本地工具 + 五工具搜索双源验证（见第七节）。
8. **与其他 mid- 技能关系**（见第八节）。
9. **注意事项 / 局限性 / 报告示例**。

## 五、四 Agent 角色设计（对齐四位大师）

Agent 名称与长期版一致，但每个 Agent 增加"景气视角特别关注"：

| Agent | 核心问题 | 景气视角特别关注（新增） | 对应大师 |
| --- | --- | --- | --- |
| **company-event-scout**（公司事件） | 公司本体发生了什么？ | 事件对 ROE 趋势、营收增速二阶导、订单/合同负债的影响（↑/→/↓） | 郑希 + 李进 |
| **regulatory-watcher**（监管政策） | 监管/政策有何变化？ | 政策黑天鹅是否落地；地缘政治（关税/制裁/供应链）对 H6 的影响 | 郑希（地缘六维） |
| **industry-peer-analyst**（行业对手） | 个股事件还是行业 beta？ | 同行 ROE 趋势、行业渗透率节奏、供需格局收紧/宽松 | 郑希 + 李进 |
| **sentiment-tracker**（市场情绪） | 基本面还是情绪/资金驱动？ | 估值是否透支（联动 PEG 五档线索）、技术面破位信号 | 欧奈尔 + 林奇 |

每条事件输出统一标注：**日期 / 来源链接 / 一句话摘要 / 对景气逻辑的影响（↑强化 / →中性 / ↓削弱）**。
