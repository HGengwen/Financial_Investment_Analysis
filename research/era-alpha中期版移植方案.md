# era-alpha 移植到「证券AI中长期（1~3年）价值投资研究」——可行性分析与实施方案

> **方案类型**：可行性研究 + 技术实施方案（未进入开发）
> **数据基准日期**：2026-09-10
> **依据文档**：
> - 源技能：`.trae/skills/era-alpha/SKILL.md`（长期 10 年版，时代α捕手）
> - 目标框架：`research/个人投资者1~3年中长期投资思想与理念 V2.0.md`
> - 目标工作流：`.trae/skills/证券AI中长期（1~3年）价值投资研究工作步骤.md`
> **状态**：待用户明确确认后方进入开发

## 0. 结论摘要

1. **可行，但属「框架整体替换式移植」，不是照搬**。`era-alpha` 的**骨架**（时代α五步法、三项修正、并发硬约束、报告自证伪结构）值得保留；但其**四大师透镜、估值方法、持有纪律、工具链、输出口径**全部是 10 年长期口径，必须逐项替换为 V2.0 的 1~3 年中期口径。

2. **建议新建 `mid-era-alpha`（「时代α捕手·1~3年景气版」），保留 `era-alpha` 原样**。理由：`era-alpha` 第 10 行明确声明「与 1-3 年中期景气链（mid-* 系列）物理隔离」，且本项目全局铁律是「长期链（10 年）与中期链（1-3 年）双轨并存、物理隔离」（CLAUDE.md 路由规则）。覆盖式改造会破坏这条铁律，也与现有 `industry-research/mid-industry-research`、`investment-research/mid-investment-research` 一路下来的「成对隔离」约定不一致。

3. **定位为中期链的「时代主线识别入口」**：现有 `mid-industry-research`（四维筛选单一已命名赛道）、`mid-trend-tech-screen`（给定标的五维打分）均要求「先给定行业/公司名」。`mid-era-alpha` 补齐缺口——在方向未明时，自上而下锁定「当下 1~3 年最具确定性的时代级高增长主线 + 该主线核心 α + 介入/退出纪律」，锁定后再下钻到后续 mid-* 链。

## 1. 背景与目标

### 1.1 背景

`era-alpha`（时代α捕手）当前是**长期（10 年）链**技能，其定位是「时代级高增长主线的 α 识别 + 增长可持续性验证 + 持有/退出纪律」。它使用段永平/巴菲特/芒格/李录四位长期大师透镜，估值用 `terminal_value.py`（十年 DCF），持有纪律是「持有到基本面拐点前」。

V2.0 文档则定义了**中期（1-3 年）**完整框架：欧奈尔/林奇/郑希/李进四大师、PEG 核心估值、底仓/机动仓分离、P0~P5 卖出优先级、8-10% 硬止损、渗透率坐标（10-30% 黄金区/15% 临界点/50% 兑现）、四大支柱（含地缘政治六维 + 华为式抗封锁韧性）、管理层 20 分 + 科研转化 20 分、决策优先级金字塔、四大矛盾化解。

今次目标：判断能否把 `era-alpha` 的「时代主线识别 + 核心 α 识别 + 介入/退出纪律」能力移植到中期（1-3 年）框架，并以 V2.0 为其唯一理念口径。

### 1.2 目标产物

- 一个与 `era-alpha` 成对隔离、口径完全对齐 V2.0 的中期版「时代α捕手」技能；
- 与既有 16 个 mid-* 技能无重复、有清晰分工；
- 融入六阶段闭环，作为「时代主线识别」入口；
- 同步更新工作流文档与 CLAUDE.md 路由。

## 2. 可行性评估

### 2.1 可直接保留的骨架（约 6 项）

| 骨架要素 | 保留理由 |
|---|---|
| **时代α五步法**（认知地图 → 自问核心问题 → 全方位验证 → 估值锚点与介入 → 持有纪律与拐点清单） | 方法抽象层与持有周期无关，10 年/1-3 年都适用 |
| **修正一（精简范围到 2-3 核心环节）** | 与 V2.0「做减法」「3~5 个重点赛道」「赛道比个股更重要」完全一致 |
| **修正二（高频数据交叉验证，周度/月度体温计）** | 1-3 年景气投资比 10 年更需要高频景气校验（郑希「每季度景气体检」的上位强化） |
| **修正三（估值锚点替代闭眼买）** | 与 V2.0「PEG 核心锚 + 分批建仓」高度契合，只是锚的具体工具要换 |
| **并发硬约束**（最多 2 子代理、分批串行、搜索间隔 ≥2s、指数退避、15min 超时降级） | 为解决 Deepseek request burst 而加的工程约束，与持有周期无关，必须原样继承 |
| **报告自证伪结构**（六章节 + 「本报告可能错在哪≥3条」+ 不挂投资人名字） | 与 V2.0 结语「独立判断」「证伪」精神一致 |

### 2.2 必须替换的框架内容（约 5 项）

| 待替换要素 | era-alpha（10 年口径） | 必须替换为（1-3 年口径，V2.0） |
|---|---|---|
| **四大师验证透镜** | 段永平/巴菲特/芒格/李录 | 欧奈尔/林奇/郑希/李进 |
| **估值方法** | `terminal_value.py` 十年 DCF + long-term 安全边际 | PEG 五档（引用 `valuation-thermometer`）+ `financial_rigor.py peg/implied-growth/pe-percentile` + 3 年后隐含回报 |
| **持有纪律** | 「基本面正常就死拿，股价是噪音」 | 底仓 60-80% + 机动仓 20-40%；单只≤15%（上限 20%）/单行业≤40% |
| **卖出与拐点** | 长期拐点清单 + 链接长期 `exit-signal`/`thesis-drift` | P0~P5（引用 `exit-signal`）+ 8-10% 硬止损 + 时间止损（满 4 季度不兑现减仓）+ 渗透率减速/ROE 拐头/技术面破位 |
| **输出口径与关联链接** | 链接长期 `investment-research`/`quality-screen`/`thesis-tracker` | 链接 `mid-industry-research`/`mid-trend-tech-screen`/`mid-investment-checklist`/`valuation-thermometer`/`qoq-accelerator`/`thesis-tracker --horizon mid`/`mid-thesis-drift`/`exit-signal` |

### 2.3 判断结论

- **五步法抽象层不变**：仍然是「识别 → 验证 → 持有」，只是每一步的**内部口径**切换到 1-3 年景气投资。
- **三项修正全部保留且更契合中期**：高频数据（修正二）与估值锚（修正三）在 1-3 年景气投资中地位更高。
- **四大师、估值、持有/卖出是移植的核心工作量**，必须整体替换，不能只改几个名词。

**结论：可行。工作量集中在「框架口径的整体替换」而非「重写方法论」。**

## 3. 架构决策：新建 vs 原位改造（重点）

## 4. 移植映射表（一页对照）

### 4.1 四大师验证透镜

采用**功能对应映射**（非人名逐一代换），落地报告时仍遵循 era-alpha 既有风格「不挂投资人名字，用分析维度命名章节」：

| 原 lens（10 年） | 追问内核 | mid-era-alpha 替换透镜（1-3 年） |
|---|---|---|
| 段永平：生意本质 | 这门生意是否简单、可理解、可持续 | 林奇：六类分类 + 常识求证 + 是否「看得懂」 |
| 巴菲特：护城河 | 10 年后护城河还在吗 | 郑希：ROE 曲线位置 + 产业景气周期 + 全球产业链分工 |
| 芒格：风险逆向 | 这家公司最可能怎么失败 | 李进：渗透率坐标 + 增速二阶导 + 治理一票否决 |
| 李录：文明趋势 | 文明级范式转移 vs 阶段性热潮 | 欧奈尔：技术面趋势确认 + 8% 止损底线 + 抛售日信号 |

### 4.2 估值锚点与介入

| 维度 | era-alpha（10 年） | mid-era-alpha（1-3 年） |
|---|---|---|
| 核心工具 | `terminal_value.py audit`（十年 DCF、ROIC/g 硬约束） | `financial_rigor.py peg / implied-growth / pe-percentile` |
| 估值锚 | 长期安全边际、10 年 IRR | PEG 五档（<0.8 显著低估 / 0.8~1.2 合理 / 1.2~1.5 偏贵 / 1.5~2 高估 / >2 严重透支） |
| 介入方式 | 低估/合理可重仓、泡沫只看不买 | 分批建仓（合理区间 1/3 底仓 → 回调加 1/3 → 景气确认补 1/3）；左侧布局 vs 右侧重仓二选一 |
| 增速加速度 | 不涉及 | `qoq-accelerator` 连续 3 季二阶导（区分波动 vs 拐点） |

## 5. 与现有 mid-* 技能的分工（去重定位）

| 现有技能 | 定位 | 与 mid-era-alpha 的关系 |
|---|---|---|
| `mid-industry-research` | 给定行业名 → 四维筛选单赛道 | mid-era-alpha 先回答「当下哪些是时代级主线」，锁定主线后转 mid-industry-research 深挖单赛道 |
| `mid-industry-funnel` | 单赛道内 3+2 漏斗 | 锁定主线核心 α 后，转 funnel 做组合收敛 |
| `mid-trend-tech-screen` | 给定标的 → 五维打分 + 技术面排序 | mid-era-alpha 是「自上而下锁定主线与 α」；trend-tech-screen 是「给定标的打分排序」 |
| `mid-investment-checklist` | 单股买入前七关硬门槛 | mid-era-alpha 产出的核心 α 仍须过七关 |
| `valuation-thermometer` | PEG 五档 | mid-era-alpha 引用不重算 |
| `qoq-accelerator` | 连续 3 季二阶导 | mid-era-alpha 第四步引用 |
| `exit-signal` | P0~P5 卖出 | mid-era-alpha 第五步链接 |

**核心价值定位**：`mid-era-alpha` 是中期链的**「时代主线识别入口」**，回答「当下 1-3 年最具确定性的时代级高增长主线是什么？这条主线的核心 α 是谁？值不值得重点跟进？」。现有 mid-* 技能均为「给定行业/标的后」的执行工具，缺一个「先自上而下锁定主线与核心 α」的统领性入口。

**诚实边界**：若用户已明确给出行业名/公司名，直接走 `mid-industry-research` / `mid-trend-tech-screen` 更高效；`mid-era-alpha` 的价值集中在「方向未明、需跨行业锁定当下第一主线与核心 α」的场景。
